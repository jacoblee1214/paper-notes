# 03. 수치 재계산, 일관성 검사, 주장 판정

재계산 스크립트는 `analysis/recompute.py`이고, 결과는 `analysis/recompute_results.json`입니다(수 초, 표준 라이브러리와 scipy). 입력은 논문 표와 본문에서 옮긴 값이며, 원자료는 없습니다. 학습과 재현은 하지 않았습니다.

## 0. 방법과 가정

- **시행 수는 논문에 없습니다.** Video-CraftBench 시험 영상은 "약 150개"(§4.1)이고, 롤아웃은 사례당 3회(§4.2)입니다. 그래서 두 시나리오를 함께 씁니다.
  - **A (사례 단위, n = 150):** 같은 사례의 3회 롤아웃을 한 번의 독립 시행으로 봅니다. 사례 내 상관을 무시하지 않는 보수적 설정입니다.
  - **B (롤아웃 단위, n = 450):** 롤아웃 450회를 독립 시행으로 봅니다. 상관을 무시하므로 과대 추정(검정력 과장)입니다.
- **블록 과제 시도 수는 없습니다.** 블록은 A 시나리오(n = 150)만 씁니다.
- **단계 누적:** 단계 k 성공률은 "1–k단계를 모두 통과한 롤아웃 비율"입니다. 단계끼리는 독립이 아니므로, 단계별 검정은 같은 롤아웃을 여러 번 쓰는 셈입니다. 검정의 목적은 차이의 크기를 보는 것이지 다중 비교 보정된 결론이 아닙니다.
- **가장 중요한 한계:** 이 계산은 **평가 표본 추출의 불확실성**만 다룹니다. 방법마다 학습을 한 번만 했다고 보고하므로, 학습 시드에 따른 분산은 전혀 반영되지 않습니다. 따라서 p값이 작아도 "방법 간 차이가 학습 실행에 대해 확실하다"는 뜻은 아닙니다.
- **CALVIN:** 사슬 수가 없으므로 CI는 계산하지 않고, Avg. Len.을 단계별 비율의 합과 맞춰 봅니다(V1).

**해석:** 평가 표본 추출만 보면 Craft-only 설정에서 단계 1부터 7까지 차이는 매우 큽니다. OpenX 설정의 1단계 차이(+6.5, 대 VideoWorld, A에서 p = 0.031)는 유의하지만 작습니다. 표 1은 기준선 학습을 한 번씩만 했으므로, 실제 격차가 학습 실행 간 변동보다 큰지는 **이 논문만으로는 판정할 수 없습니다.**

블록의 시도 수는 모르므로 B 시나리오 값은 참고만 합니다(탑 p ≈ 4e-34).

### 1.3 CALVIN 평균 길이 (표 2)

Avg. Len.은 단계별 순차 성공률의 합으로 정의됩니다(단위 %의 합을 100으로 나눔). 본문에 정의는 없지만 표의 값과 일치하는지 확인하는 것이 목적입니다. 결과는 V1을 보세요. 도메인 내 사전학습에서 VideoWorld 2(10%)와 LAPA(10%)의 차이는 보고값 기준 0.38, 단계 합 기준 0.23입니다. 그런데 LAPA 행의 보고값 1.49는 단계 합(1.63)과 맞지 않아, 어느 쪽이 맞는지는 원자료 없이 판정할 수 없습니다.

### 1.4 주요 수치의 CI 폭

시나리오 A에서 종이접기 7단계 VideoWorld 2의 95% CI 폭은 약 15포인트(61.0–75.7)입니다. 같은 값에서 시나리오 B는 약 8포인트입니다. 블록의 CI 폭은 약 12–15포인트입니다.

## 4. 토이 검증

이번 분석에서는 **토이를 만들지 않았습니다.** 핵심 주장은 "대규모 사전학습 VDM을 쓴 잠재 코드"이므로, CPU 토이로 직접 확인할 수 있는 부분이 좁습니다. 예를 들어 FSQ 양자화와 인과 교차 주의를 작게 만드는 것은 구조 확인에 그치고, 논문 수치(영상 품질, 과제 성공률)와 연결되지 않습니다. 대신 재계산과 일관성 검사를 주 작업으로 삼았습니다.

## 5. 재실행

```bash
python3 analysis/recompute.py
python3 analysis/plot_figures.py
```

`plot_figures.py`는 `report/figures/own_seq_ci.png`와 `report/figures/own_calvin_check.png`를 만듭니다. 두 스크립트 모두 논문 원문이나 공식 코드를 쓰지 않으며, 네트워크를 쓰지 않습니다.
