# 03. 수치 재계산과 일관성 검사

모든 값은 `analysis/recompute.py`(표준 라이브러리, 1초 안)가 `recompute_results.json`에 남깁니다. 표 5(RoboTwin 과제별)는 `paper/paper.txt`를 읽어 직접 파싱합니다. 검정은 양측입니다. 시행 수는 논문 본문(F.2–F.4)이 밝힌 값을 쓰고, 밝히지 않은 것은 가정으로 표시합니다. 재현(학습, 시뮬레이션)은 하지 않았습니다.

검사 번호는 V1–V7, 불일치 목록은 I1–I9, 주장 판정은 C1–C14, 토이는 T1입니다.

## 1. 표 1: LIBERO (V1)

**V1a. 평균 열.** 14개 행 모두 네 스위트 평균이 보고된 평균과 ±0.05 안에서 일치합니다 (π0.5는 96.85가 96.9로, GR00T-N1.6은 97.025가 97.0으로, LingBot-VA는 98.45가 98.5로 반올림). LaWAM은 (97.0 + 98.4 + 99.6 + 99.4)/4 = 98.6.

**V1b. 정수 가능성 (스위트당 10과제 × 50회 = 500회 가정).** LaWAM의 네 값은 485, 492, 498, 497회 성공으로 정수가 되고 합계는 1,972/2,000 = 98.6%, Wilson 95% 구간 [97.98, 99.03]입니다. 반면 기준선 일부는 500회로는 정수가 되지 않습니다.

| 행 | 500회에서 정수가 안 되는 값 | 해석 |
|---|---|---|
| OpenVLA-OFT | 94.5, 97.9 | 원 논문의 3 시드 평균(1,500회)으로 보임 |
| GR00T-N1.6 | 97.5, 98.5, 97.7 | 재인용 값 |
| UniVLA | 96.5 | 재인용 값 |
| F1 | 91.3 | 재인용 값 |
| Cosmos-Policy | 98.1 | 재인용 값 |
| LingBot-VA | 98.5 (Long), 98.5 (Spatial) | 1,500회(3 시드 × 500) 프로토콜 값 |

즉 표 1은 "과제당 50회" 한 가지 프로토콜의 표가 아니라 **평가 횟수가 다른 값을 합친 표**입니다 (E.6: "원 논문 값을 우선 쓴다"). 캡션의 "50 trials per task"는 LaWAM 행에만 확인됩니다 (I1).

**V1c. 유의성 (LaWAM 1,972/2,000 대 기준선, 기준선도 2,000회라고 가정한 근사).**

해석: 2,000회 대 2,000회의 검출 가능한 최소 차이는 약 1.1 pp(80% 검정력)입니다. 98.6 대 98.5는 구분되지 않습니다. Fast-WAM과 Motus 대비 우위는 다중 비교 보정 전 p < 0.05 수준에서만 보입니다. 스위트별로 보면 **LIBERO-Long 최고는 LingBot-VA 98.5**이고 LaWAM 97.0은 4위(Motus와 Cosmos-Policy 97.6 다음)입니다. 스위트별 우열은 엇갈립니다 (LingBot-VA 대비 Long −1.5, Goal +1.2, Object 0.0, Spatial +0.9; Cosmos-Policy 대비 Long −0.6, Goal +0.2, Object −0.4, Spatial +1.3).

## 2. 지연, 메모리, 파라미터, 학습 비용 (V2)

- **V2a. 지연 비율.** 4,482/187 = 23.97, 3,231/187 = 17.3, 1,413/187 = 7.56, 486/187 = 2.60, 399/187 = 2.13, 259/187 = 1.39, 220/187 = 1.18. 초록의 "최대 24×"는 LingBot-VA 대비로만 맞습니다. Fast-WAM에는 2.6배, 주류 VLA(π0.5, 220 ms)에는 1.18배입니다 (표 1).
- **V2b. 작업량이 맞춰지지 않은 비교.** F.1이 "각 방법은 자기 입력 해상도, 예측 지평선, 연산량을 유지한다"고 밝힙니다. LaWAM의 LIBERO 청크는 공식 설정상 0.4 s × 20 Hz = 8 행동(`04` D8)이므로 187 ms가 1청크 8스텝분입니다. 다른 방법의 청크 길이는 논문에 없습니다. **스텝당 지연**으로 환산하는 비교는 불가능합니다 (I2).
- **V2c. 파라미터.** 230M/5B = 4.6% (95.4% 감소, 맞음). 단 F.1이 "WAM 파라미터 수는 영상 확산 VAE와 텍스트 인코더를 제외한다(이 둘이 5B를 넘을 수 있다)"고 밝히므로 LaWAM의 2.3B와 기준선 크기는 같은 규칙으로 센 값이 아닙니다. LaWAM 쪽 2.3B가 LAM 인코더, DINOv3, 상태 예측기를 포함하는지는 적혀 있지 않습니다.
- **V2d. 메모리.** 23.68/6.04 = 3.92배 (Fast-WAM 대비, A100, BF16, 배치 없음).
- **V2e. 학습 비용 (표 7).** 400 + 3,000 + 40 = 3,440 H100-시간(LIBERO까지), RoboTwin은 +1,200. 스텝·배치와의 정합성: 1단계 LaWM은 100k 스텝 × 배치 1,024 / (400 × 3,600 s) = 71.1 샘플/GPU·초, 2단계 사전학습은 200k × 1,024 / (3,000 × 3,600) = 19.0, LIBERO 후학습은 25k × 256 / (40 × 3,600) = 44.4, RoboTwin은 100k × 1,024 / (1,200 × 3,600) = 23.7 샘플/GPU·초입니다. 16 GPU로 25 h, 64 GPU로 46.9 h, 8 GPU로 5 h에 해당하며 모순은 없습니다. RoboTwin 후학습(1,200 H100-시간)이 LIBERO(40)의 30배인 점은 학습 데이터(시연 27,500개, F.3)와 청크 길이(1.2 s)에서 설명되는 것으로 보입니다(추정).

## 3. LaWM 크기 산술 (V3)

논문은 LaWM이 "230M"이라 하고(1절, F.1), E.2는 "역동역학 인코더와 디코더 모두 24층 트랜스포머"라고 적습니다. 공식 설정(`dino_large_vae.yaml`)은 **인코더 24층, 디코더 12층**, 은닉 1,024입니다 (`04` D4).

- **디코더 파라미터 산술** (adaLN 블록: MHA 4d²+4d, FFN 8d²+5d, 변조 6d²+6d = 18d²+15d, d = 1,024 → 블록당 18,889,728): 12층 = 226.7M, 입출력 투영(768↔1,024)과 z 투영 포함 **228.3M ≈ "230M"**. 24층이면 **455.0M**입니다.
- **공개 LAM 체크포인트 크기 대조.** HF `lawam_lam`의 `pytorch_model.pt`는 2,900,637,794 바이트이고 fp32이면 725.2M 파라미터입니다. 인코더 24층(302.3M + 투영) + 디코더 12층(228.3M) + DINOv3-B(약 85.7M) + 상태 예측기(약 101.7M, max_state_dim 14, 32 형태 범주) ≈ 723.0M(2.892 GB)으로 0.3% 안에서 맞습니다. 디코더가 24층이면 949.7M(3.80 GB)이라 맞지 않습니다.
- 결론: **230M은 디코더 12층 구성의 값**이고 E.2의 "24층" 서술은 인코더에만 맞습니다 (I3). 체크포인트 크기는 교차 확인입니다(가중치는 받지 않았고 파일 크기 메타데이터만 썼습니다).
- 정책 체크포인트 7.17 GB(fp32 + VLM bf16 혼합)와 "2.3B": VLM(첫 16층 + 비전 타워 + 임베딩, 약 1.5B) + 행동 전문가(약 0.3B) + LAM 전체(0.72B)면 약 2.6B, LAM 인코더와 상태 예측기를 빼면 약 2.1–2.2B입니다. 2.3B가 어느 구성인지는 논문에서 정할 수 없습니다(추정값, 정확한 계수는 모델 로드 없이 불가).

| 부분 목표 조건 제거 94.6 대 증류만 95.2 | −0.6 | 0.77 |

해석:
- 보정 전에도 p < 0.05인 것은 기본 VLA, 용량 일치 어댑터(둘 다 "미래 예측·증류가 없는 모델 대 있는 모델"), 증류 제거, 미래 예측 보조만 변형입니다. **논문의 핵심 문장인 "디코딩된 미래를 행동 전문가에 넣는 것이 이득"에 해당하는 1.8 pp(96.4 대 94.6)는 구분되지 않습니다.** 같은 초기 상태를 쓰는 쌍체 정보가 있으면 검출력이 올라가지만 공개 자료에 없습니다 (저장소 이슈 11에서 저자는 절제 코드를 공개할 수 없다고 답했습니다).
- **KI의 효과는 증류에 의존합니다.** 증류가 있을 때 KI 제거는 −2.2 pp(96.4 → 94.2)인데, 증류가 없으면 −0.2 pp(93.4 → 93.2)입니다. 4.5절 문장("증류와 KI가 각각 필요하다")은 이 상호작용을 말하지 않습니다.
- **부분 목표를 넣은 변형(증류 제거, 93.4)이 부분 목표를 뺀 변형(94.6)보다 낮습니다** (1.2 pp, p = 0.51). 부분 목표를 넣는 이득은 증류가 함께 있을 때만 나타난다는 해석과 소음이라는 해석을 구분할 수 없습니다.
- 증류만 쓴 변형(미래 디코더 없음, 95.2)이 "미래 예측 + 증류, 부분 목표 없음"(94.6)보다 높습니다. 미래 예측 보조 손실을 더하면 오히려 −0.6 pp입니다 (p = 0.77).
- 2단계 사전학습 3,000 H100-시간의 이득은 +0.6 pp(p = 0.72)입니다. Table 1의 97.0은 이 사전학습을 포함한 값이고, 표 4의 모든 다른 행은 제외한 값이라 표 1과 직접 대조되지 않습니다 (I8).
- 기본 VLA(91.0)는 VLM과 행동 전문가 구성이 같은지, 같은 학습 예산인지 논문에 적혀 있지 않습니다.

## 8. 토이 T1: 교차 어텐션 키에 순서·유형 표시가 없다 (`toy_key_order_invariance.py`, 1초 미만)

공식 코드의 행동 전문가는 키로 `torch.cat((h_t, cond_future, cond_vlm))`을 쓰고, 이미지 교차 어텐션 층(16층 중 4층)은 `h_t`와 `û_T`(512 토큰)에 **함께** 어텐션합니다. 키에는 위치·유형 임베딩이 없습니다 (`04` D12). numpy로 같은 구조(단일 헤드, 임의 가중치)를 만들면 두 블록의 순서를 바꿔도 출력이 같고(최대 차이 3.3e-16), 유형 임베딩이 있어도 순서만 바꾸면 같으며, 라벨을 맞바꾸면 달라집니다(1.54). 어텐션이 집합 연산이라는 자명한 성질입니다. 의미: 논문이 말하는 "역동역학 어텐션"은 모델이 현재 특징과 예측 특징을 **특징 통계로만** 구분하게 하는 구조이며, 분리 효과를 시험한 절제는 없습니다. 학습된 모델의 거동에 대한 주장이 아니라 구조 확인입니다.
