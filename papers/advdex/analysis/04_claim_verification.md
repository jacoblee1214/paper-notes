# 04. 주장 검증과 구현 가능성

공식 코드가 없어서(`02_prior_work.md` §1) 코드 대조(D 항목) 대신 **주장 검증(C 항목)**을 했습니다. 검증 방법은 논문 표 재계산(`03_analysis.md`), 본문 일관성, 논문이 내놓은 근거의 종류 확인입니다. 코드나 데이터로 확인할 수 없는 것은 "검증 불가"로 적었습니다.

판정 기준: **맞음** (수치와 근거가 주장을 지지), **부분** (방향만 맞거나 일부 조건에서만 맞음), **근거 약함** (수치는 있으나 통계나 반복이 없음), **검증 불가** (코드, 데이터, 로봇이 없어 확인할 수 없음), **미확인** (본문에 수치가 없거나 이 분석에서 읽지 않음).

**논문이 주장하지 않지만 확인이 필요한 것.**

- 기준선 학습 설정. π0.5와 VITRA를 "같은 로봇 데이터, 같은 행동 표현, 같은 학습 스텝"으로 맞췄다고 씁니다 (§4.3). 그러나 π0.5의 사전학습 가중치 사용 여부, VITRA의 후학습 방식은 자세히 적혀 있지 않습니다.
- 평가자 맹목성. 실로봇 평가에서 평가자가 어떤 방법인지 알았는지 적혀 있지 않습니다.

## 3. 구현할 수 있는가 (핵심 판정)

**결론: 전체 시스템은 구현할 수 없습니다. 부분 메커니즘(JAAS 마스킹, GRL 학습 신호)은 이 맥에서 작은 규모로 확인할 수 있습니다.**

### 3.1 이유

- **데이터 없음.** OmniShare가 공개되어 있지 않아 사람 데이터 5:4:1 사전학습을 만들 수 없습니다. 같은 종류의 장갑 데이터를 직접 모으려면 장갑과 촉각 센서, 다시점 카메라 설정이 필요합니다.
- **규모 가정.** 사전학습은 VLM 백본(SigLIP 계열)과 DiT 행동 전문가를 대규모 데이터로 학습하는 작업입니다. 이 맥의 M4 Pro (24 GiB, MPS, CUDA 없음)로는 실용적인 시간 안에 되지 않습니다. 논문이 쓴 GPU 종류와 학습 시간도 없습니다.
- **로봇 없음.** 실로봇 평가에는 Paxini Tora와 DexH13 같은 하드웨어가 필요합니다. 로봇 없이는 Table 3, 4를 재현할 수 없습니다.
- **설정 누락.** 손실 가중치 λ, 판별기 구조, 청크 길이, 디노이즈 스텝, 학습률, 배치 크기, 학습 스텝 수가 본문에 없습니다. 값 없이는 같은 결과를 기대할 수 없습니다.

### 3.2 맥에서 가능한 것 (CPU 또는 MPS)

| 무엇 | 필요 자원 | CPU 가능 | 판정 | 근거 |

| 표 재계산과 검정 | numpy, scipy | 예 | 완료 (`03`) | 수 초 |
| JAAS 마스킹 손실 (빈 슬롯 제외) | numpy 또는 torch CPU | 예 | 가능 | §3.2.1 설명이 충분함. 두 구현체 (예: 15슬롯과 7슬롯)로 손실 계산만 확인 |
| GRL 학습 신호 (작은 MLP, 두 도메인 합성 데이터) | torch CPU 또는 MPS | 예 | 가능 (토이) | §3.2.2 식이 명확함. 합성 데이터로 λ에 따른 판별기 정확도와 특징 겹침만 확인. 실제 로봇 효과와는 무관 |
| 전체 VLA 추론 | 가중치 없음 | — | 불가 | 공개 가중치 없음 |
| OmniShare 규모 사전학습 | GPU, 데이터 | 아니오 | 불가 | 데이터 없음 |
| 실로봇 Table 3, 4 재현 | 로봇, 장비 | 아니오 | 불가 | 하드웨어 없음 |

### 3.3 노력 추정

- JAAS 마스킹 + GRL 토이 (합성 데이터, CPU/MPS): **0.5–1일** (추정. 측정 전).
- 본문 수준의 VLA 재구현 (VLM + DiT, 학습 레시피 추정): 공개 코드 없이 **수 주 이상**, GPU 학습은 별도 (추정).
- 실로봇 검증: 장비 조달 필요. 판정 불가.

### 3.4 분석에서 하지 않은 것

- 토이 실험은 하지 않았습니다. 이 논문의 핵심 주장(표 3, 4의 실로봇 성공률)을 CPU 토이로 검증할 수 없고, 토이는 "GRL이 기술적으로 작동한다"만 보여 주기 때문입니다.

## 4. 주장의 한계 요약 (재현과 별개)

1. 정책 1개, 과제 5개(실로봇) 또는 4개(사람 전용), 과제당 20회. 차이 15 pp 이하는 구별되지 않습니다 (`03` §1.3).
2. 기준선 설정이 불투명합니다. 같은 조건이라고 주장하지만 세부가 적혀 있지 않습니다.
3. 데이터 규모 숫자가 맞지 않습니다 (V6).
4. 행동 차원이 명시되지 않습니다 (V7).
5. 공개 자료가 없습니다. 주장을 독립적으로 검증할 방법이 없습니다.
