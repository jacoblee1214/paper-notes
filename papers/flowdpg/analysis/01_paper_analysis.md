## 1. 한 문단 요약과 핵심 질문

흐름 정합(flow matching) 정책에 DDPG식 크리틱 기울기를 쓰려면 노이즈에서 행동까지의 다단계 ODE를 따라 역전파(BPTT)해야 합니다. 비용이 단계 수에 비례하고 야코비안 곱이 폭주하거나 사라집니다. FlowDPG는 중간 점 x_t에서 속도 예측기 한 번으로 깨끗한 행동을 추정(â = x_t + (1−t)v)하고, 그 지점에서 크리틱 기울기 g를 구해 **정규화한 보정 Δ를 더한 목표 a\* = â + Δ**를 만든 뒤, 속도장을 L2 회귀로 a\* 쪽으로 당깁니다(식 4–8). 추론은 일반 흐름 정합 그대로입니다. 저자는 이 갱신이 세 가지 근사 아래에서 바닐라 DPG와 같은 방향이라고 주장합니다(식 10–11).

실험은 실로봇 두 과제입니다. 양팔 Franka 에어팟 조립(8단계, 25 케이스 한 번의 스윕)에서 종단 성공 92%(BC 64%, QAM 80%), 양팔 YAM 스크램블 에그(14단계)에서 오프라인만으로 평가 점수 64.2% → 85.8%를 보고합니다.

**핵심 질문:** (a) 한 번의 단계 추정 â에서 얻은 기울기가 실제로 정책 개선 방향인가, (b) 표본 25–50개 수준의 실로봇 비교에서 "QAM보다 약 10점 높다"를 주장할 수 있는가, (c) 이 방법을 구현하려면 무엇이 빠져 있는가.

## 2. 방법

### 2.1 값 추정 (§3.1, 식 1–3)

- 쌍둥이 크리틱 IQL. V는 데이터 행동에서 min Q의 기대분위(expectile τ) 회귀(식 1), Q는 y = r_t + γ^H V(s_{t+H})로 부트스트랩(식 2). 청크 단위 보상입니다.
- 보상은 얼린 SARM(단계 인식 보상 모델) 출력의 합: 진행도 증가분 φ(o_{t+H}) − φ(o_t) + β_stage·1[단계 상승] + 종료 보상(식 3).
- 같은 보상, 가치 머리, 오프라인 데이터를 모든 기준선이 공유한다고 합니다(§4 기준선).

### 2.2 FlowDPG 정책 추출 (§3.2, 식 4–9)

| 단계 | 식 | 내용 |
|---|---|---|
| 한 단계 추정 | (4) | â = x_t + (1−t)·v_θ(x_t, t, s) (no grad) |
| 크리틱 기울기 | (5) | g = ∇_â min_i Q_i(s, â) (크리틱 파라미터 stop-grad) |
| 적응 이동 | (6) | Δ = α·‖u_t‖/(‖g‖+ε)·g, u_t = x1 − x0 |
| 증류 목표 | (7) | a\* = â + Δ, u\* = a\* − x0 |
| 손실 | (8) | L = λ‖v − u\*‖² + (1−λ)‖v − u_t‖², λ는 N_warmup 동안 0에서 선형 증가 |
| 일관성 정규화 | (9) | L_cons = E‖â − x1‖² = E[(1−t)²‖v − u_t‖²] (논문이 직접 보인 동치) |

공개된 값은 v1 부록 표 3에만 있습니다(v2에서 삭제, §6): α = 0.5, ε = 1e-6, λ_max = 0.5, N_warmup = 2,000, µ_cons = 1.0, T = 12 단계, 청크 H = 30, DiT 14층, DINOv2 ViT-B/14, 오프라인 10,000 스텝, 온라인 6,000 스텝.

### 2.3 바닐라 DPG와의 관계 (§3.2 끝, 식 10–11, 부록 A)

바닐라 DPG는 ODE 끝점 x1을 결정적 행동으로 보고 ∇θ L = −∫₀¹ gᵀΦ(1,t)∇θv dt를 얻습니다(식 10, 부록 A에서 민감도 방정식으로 유도). FlowDPG의 g 의존 항은 ∇θ L|_g = −2λα‖u_t‖·ĝ·∇θv(식 11)이고, 세 근사로 식 10을 회복한다고 합니다. (i) g를 ODE 끝점이 아니라 â에서 평가해 Φ(1,t)를 I로 대체, (ii) 시간 적분을 t ~ U(0,1) 한 점의 몬테카를로로 대체, (iii) ‖g‖를 적응 크기 2λα‖u_t‖로 대체.

### 2.4 오프라인 → 온라인 (§3.3, 알고리즘 1)

오프라인 단계에서 FlowDPG 목표로 백본, 행동 머리, 가치 머리를 함께 학습합니다. 온라인 단계는 로봇을 굴려 롤아웃을 비동기로 모으고, 오프라인 데이터와 온라인 데이터에서 약 1:1로 배치를 뽑습니다. BC 앵커는 시연과 성공한 롤아웃에만 걸립니다(v2에서 추가). 백본과 SARM은 얼립니다. 계란 과제는 오프라인만 평가했습니다.

## 3. 실험과 결과

### 3.1 설정 (§4)

- **에어팟 조립(Franka 두 대, 8단계):** 케이스 잡기, 열기, 오른쪽 포드 잡기와 삽입, 왼쪽 포드 잡기와 삽입, 닫기, 놓기. 카메라 4대(정면, 위, 손목 둘). 시연은 GELLO 원격 조종.
- **스크램블 에그(YAM 두 대, 14단계):** 달걀 두 개 깨기, 소금, 포크로 휘젓기, 팬에 붓기, 뒤집개로 젓기, 옮기기, 서빙. 카메라 3대.
- **평가 방식 둘:** (i) 전체 스윕(표 1): 방법마다 25 케이스(포드 조작 50회) 한 번. 단계 내 실패는 에피소드를 끝내지 않고 재시도는 단계별 분모에 들어가며 Overall은 모든 포드가 제대로 들어가야 성공. (ii) 반복 평가(그림 4): BC, QAM, FlowDPG만, 셀마다 50 롤아웃(한 번의 학습 실행에서 체크포인트 5개 × 10), ±는 체크포인트 평균의 표준오차. 루브릭은 단계별 0–3점(부록 D).
- **기준선 8개 + BC:** 값 조건화(RA-BC, AWR, RECAP), 보조 모듈(DSRL, PLD, RLT), 크리틱 기울기(QAM). 같은 백본, 청크 길이, 보상, 가치 머리, 오프라인 데이터.

## 4. 저자가 말한 한계 (§5)

크리틱은 데이터 근처에서만 믿을 만하고, 한 단계 추정과 적응 이동은 크리틱 오류를 줄이지만 없애지 않으며, 온라인 교정은 보상 모델이 새 상태를 정확히 채점할 때만 됩니다. 보상은 밀집 진행 신호가 있는 단계 분해 과제를 가정하고, BC 앵커가 개선 폭을 제한할 수 있습니다. 평가는 과제 둘, 로봇 둘이며 큰 VLA와 다양한 과제로의 확장은 남겨 두었습니다.

## 5. 주장과 증거의 틈 (우리 판단)

각 항목의 계산은 `03`과 `04`에 있고, 번호는 그쪽의 V, K, C와 같습니다.

1. **표 1의 단계별 비율 상당수가 25 케이스로는 만들어지지 않습니다**(`03` V2). 기준선의 비정수 셀 38개 중 26개가 n ≤ 75의 어떤 k/n으로도 표현되지 않습니다(예: QAM 70.58%는 n ≥ 452). FlowDPG 열 10개는 최소 n = 6–32의 분수로 표현됩니다. 기준선과 FlowDPG의 수치 생성 방식이 같다고 보기 어렵습니다.
2. **FlowDPG 단계별 값 4개는 성공 수가 25를 넘어야 합니다**(오프라인 Grasp R 90.63%=29/32, Insert R 84.38%=27/32, Grasp L 96.43%=27/28, 온라인 Grasp L 96.67%=29/30). 케이스당 단계 성공을 한 번만 센다면 불가능하므로 재시도 성공을 여러 번 세는 것으로 읽어야 하지만 논문이 정의하지 않습니다.
3. **"QAM보다 약 10점"은 검정되지 않습니다**(`03` V3). 90% 대 80%(각 n = 50) Fisher p = 0.26, 검정력은 약 0.2이고 80% 검정력에는 팔당 약 225 롤아웃이 필요합니다. 표 1의 88/92% 대 QAM 80%(n = 25)도 p = 0.42–0.70입니다. BC 64% 대 FlowDPG 92%는 p = 0.037입니다.
4. **그림 4의 오차막대는 시드 변동을 담지 않습니다.** 한 번의 학습 실행의 체크포인트 5개 평균 표준오차입니다. 시드 하나, 방법마다 학습 한 번입니다.
5. **표 1과 그림 4가 네 곳에서 정확히 2점씩 어긋납니다**(BC 64/62, QAM 80/78, FlowDPG 88/86, 92/90). 25와 50 롤아웃의 독립 표본이라는 가정에서는 드문 일치이므로(거친 가정에서 대략 6e-5, `03` V4), 두 평가가 같은 롤아웃을 공유하는지 또는 다른 체계적 원인이 있는지 저자 확인이 필요합니다.
6. **절제 차이는 케이스 4–5개입니다**(그림 5d, n = 25로 추정). 92 → 76은 Fisher p = 0.25, 92 → 72는 p = 0.14. "일관성 정규화 효과"는 L_cons가 (1−t)²로 가중한 BC 항과 같아서(식 9 아래), 정규화 효과와 BC 가중 증가를 구분하지 못합니다(`04` C5).
7. **크리틱 값이 보상 척도를 넘습니다**(`03` V5, `04` C11). v1의 보상 값(β = 1, 성공 +5)으로 에어팟의 반환 상한은 약 14인데, 표 3의 Q는 33.58, 그림 7의 V는 30–42입니다. v2는 보상 계수를 삭제했으므로 값이 다시 척도화되었는지 알 수 없습니다.
8. **진행도 정의가 둘입니다.** §3.1은 "within-episode progress", 부록 C 설명은 "within-stage progress"이고 그림 7의 곡선은 에피소드 전체에서 0 → 1로 단조 증가합니다.
9. **표 3의 변화는 작고 크리틱이 최적화한 점수입니다.** Wasserstein 증가는 +0.9%(에어팟), +1.8%(계란), 분산 감소 −6%, −2%, Q 증가가 시연 Q 대비 +4.08, +5.42입니다. ρ = 0.28–0.36의 기울기 정렬이 "국소적으로 정보가 있다"는 근거의 전부입니다(진행도 상관).
10. **계란 과제는 성공률이 없고 오프라인만, 기준선은 BC와 QAM뿐입니다.** 85.8%(루브릭) 대 76.9%의 차이는 표준오차 막대로만 주어지고 분모 구조(50 롤아웃 × 42점)로 검정할 수 없습니다.
