# 03. 재계산, 집계 주장, 검정, 일관성 검사

이 문서의 수치는 모두 `analysis/recompute.py`(결과 `analysis/recompute_results.json`)가 만든 것입니다. 논문 부록 표의 값을 스크립트에 그대로 옮겨 적었고, 외부 데이터는 쓰지 않았습니다. 실행 시간은 수 초입니다.

## 0. 방법과 가정

- **부분 점수.** 표 4 캡션이 부분 성공 0.5를 허용한다고 밝힙니다. 표 5, 9, 11의 값에도 .5 단위가 있습니다. 성공 횟수는 실수로 둡니다.
- **표준오차.** 논문은 ±를 StdErr라고 씁니다. 공식은 밝히지 않았습니다. §2에서 확인했습니다.
- **A/B 설계.** 같은 과제와 초기 상태를 쓰므로 방법끼리 쌍을 이룹니다. 하지만 시도별 원자료가 없어 시도 단위 쌍 검정은 불가능합니다. 그래서 (a) 시도 단위 두 비율 z 검정(쌍을 무시한 보수적 판정)과 (b) 과제 단위 쌍 Wilcoxon 검정을 함께 봅니다. 과제 수가 작아 정확 p값이 제한됩니다.
- **Franka 평균.** 논문 표 7의 "Average"는 시도 가중 평균입니다(테이블탑 99회, DROID 30회에서 재현됨, §1). 과제 평균과 다릅니다.
- **반올림.** 33/80이나 57/80 같은 값은 소수 첫째 자리 반올림 때문에 1자리 차이가 날 수 있습니다(예: 57/80 = 71.25는 논문 71.3).

## 2. 집계 주장과 표준오차 확인

### 2.1 ± 값 (표준오차)

- 표 4의 ±(RT-1-X 2.7, Octo 2.6, RT-2-X 3.5, OpenVLA 3.2)는 n=170 이항 표준오차(2.98, 3.07, 3.83, 3.49)보다 8–15% 작습니다. 과제 수준 SE(과제별 SD ÷ √17)는 그보다 훨씬 큽니다(4.0–6.9). 두 공식 어느 쪽과도 맞지 않습니다. 논문은 공식을 쓰지 않았습니다.
- 표 12(LIBERO)의 ±는 √(p(1-p)/1500)과 0.1 이내로 맞습니다. 세 시드 × 500회를 독립 시도로 본 값입니다.
- 표 7의 ±는 이항 SE(n=99, n=30)에 가깝습니다(예: 테이블탑 DP 보고 4.9 대 이항 5.0, OpenVLA 보고 4.0 대 이항 4.7). 일부 값은 조금 작습니다.

### 2.2 "16.5%p, 29과제"

- 29과제(BridgeData 17 + Google 12)를 시도 가중으로 합치면 OpenVLA 74.35%, RT-2-X 57.83%, 차이 16.52%p. **재계산 일치.**
- 이 평균은 시도 가중입니다. 과제 가중(29과제에 같은 가중치)으로 계산하면 OpenVLA 76.55%, RT-2-X 62.07%, 차이 14.5%p입니다. 논문은 어떤 가중인지 밝히지 않으며, 16.5%p는 시도 가중일 때만 나옵니다. Bridge 과제는 시도 10회, Google 과제는 5회라서 시도 가중은 Bridge 과제를 두 배로 셉니다.

### 2.3 "Diffusion Policy보다 20.4%p" (초록, 서론, §5.2 아님)

| 집계 | OpenVLA | DP | 차이 (%p) |
|---|---|---|---|

- **재현 실패.** 20.4는 위 어떤 집계와도 맞지 않습니다. 논문은 어떤 집계인지 쓰지 않습니다. 방향(OpenVLA가 높음)은 맞고, 크기는 18.7–23.3 범위입니다.
- 두 환경에 대한 시도 합산 검정은 p = 0.0014(두 비율 z 검정)입니다.

### 2.4 "모든 과제에서 50% 이상을 달성한 유일한 방법"

- 표 7 최솟값: OpenVLA 40.0%(당근 넣기 OOD, 5회 중 2회), DP 8.3%, DP matched 0%, Octo 0%, 처음부터 학습 0%.
- **반증.** OpenVLA도 50% 아래 과제가 있습니다. 어떤 방법도 모든 과제에서 50%를 넘지 못합니다. 이 문장은 세 판본 모두에 있습니다(v1 §5.2, v2·v3 §5.2 동일 문장).

- OpenVLA 1위 평균 주장(C19)은 DP에 대해서는 확실하고, Octo에 대해서는 경계입니다. 두 값의 차이 1.4%p는 스위트별 표준오차(0.6–1.3)가 독립이라고 가정하면 z ≈ 1.9입니다.
- 스위트별로는 OpenVLA가 Spatial(84.7)과 Long(53.7)에서 1위입니다. Object에서는 DP가 1위(92.5, OpenVLA 88.4), Goal에서는 Octo가 1위(84.6, OpenVLA 79.2)입니다.

- `analysis/toy_action_bins.py`(numpy, 1초 미만)는 공식 코드의 `ActionTokenizer` 로직을 옮겨 왕복을 검사합니다. 결과: 균일 난수 200,000개에서 실제로 쓰인 토큰은 255개, 디코딩 값은 255개입니다. 최대 왕복 오차 0.00392는 반 빈 너비와 같습니다. +1.0은 0.996으로 디코딩됩니다. 자세한 내용은 `04` D2.
