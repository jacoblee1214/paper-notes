# 02. 선행연구와 관계

번호 [n]은 논문의 참고문헌 번호입니다(`paper/paper.txt`의 References). 논문 밖 문헌은 이 문서 작성자의 판단이며, 원문을 열어 확인하지 않은 것은 그렇게 표시했습니다. GitHub 정보는 2026-11-10에 `gh`로 확인했습니다.

## 1. 계보

- **자연 장을 이용한 위치추정:** 지자기 이상 [1, 2], 무선 신호 세기 [3], 시각 랜드마크 [4](FastSLAM). 이 논문은 같은 틀(장을 측정과 맞춘다)을 쓰지만, 장이 **시간에 따라 PDE로 진화한다**는 점을 더합니다.
- **유동장 기반 AUV 위치추정과 지도:** 배경 흐름 기반 위치추정 [6], 흐름 기반 동시 위치추정·지도 [7], 다로봇 흐름 기반 위치추정·지도 [8]. 논문은 이들이 **정상 또는 천천히 변하는 흐름**과 특정 동역학에만 맞는다고 봅니다.
- **PDE 기반 환경 모형:** 수중 비행체 궤적 추정용 PDE 관측기 [12, 13], 가스 확산 PDE와 희소 베이즈 학습으로 가스원 위치를 찾는 다로봇 연구 [15](Wiedemann et al.). [14]는 이류–확산 PDE와 가우시안 과정으로 장과 그 기울기를 실시간 추정하는 적응 항법입니다(Fuentes et al., ICRA 2025). 이 계열은 **장 추정, 탐사, 원천 식별**이 목적이고, 로봇의 **위치추정**은 목적이 아닙니다(논문 Sec. I의 주장).
- **Rao-Blackwell 입자 필터:** RBPF 원전 [16, 24](Murphy & Russell), 주변화 입자 필터 [25](Schön et al.), 입자 평활 SLAM [17](Kok et al., 2024), 연결 차량 위치추정 [18], 6자유도 페그인홀 [19]. 이 논문은 장 기반 위치추정에 RBPF를 **처음 적용**한다고 주장합니다.

## 2. 가까운 대안

### 2.1 논문이 인용했지만 비교하지 않은 것

| 연구 | 관련 이유 | 이 논문과 차이 |
|---|---|---|
| 흐름 기반 위치추정·지도 [6–8] | 흐름장으로 위치와 지도를 동시에 추정 | 정상 흐름 가정. 확산 PDE나 얕은 물 방정식은 다루지 않음 |
| 가스 확산 PDE 위치 추정 [15] | 확산 PDE 모형 + 희소 베이즈(SBL) | 위치가 아니라 원천을 추정. 측정 모형은 PDE 해와 비슷함 |
| 적응 항법 + GP [14] | PDE의 장을 GP로 추정하면서 항법 | 장 기울기 추정이 목적. 위치추정은 없음 |

### 2.2 논문이 인용하지 않았지만 가까운 대안(작성자 판단, 원문 미확인)

| 연구 | 관련 이유 | 이 논문과 차이 |
|---|---|---|
| 가우시안 과정 장 지도 + 입자 필터 (Rasmussen & Williams, 2006) | 장 지도를 데이터로 학습하고 측정 우도로 위치를 맞춤 | 장을 학습 데이터로 만듦. PDE를 풀지 않으므로 시간 변화를 직접 다루지 않음 |
| 앙상블 칼만 필터 기반 데이터 동화 (Evensen, 1994) | 해양 모형의 상태와 매개변수를 관측으로 보정 | 필터 상태가 장 전체. 로봇 위치를 추정하는 목적은 아님 |
| 물리 정보 신경망 PINN (Raissi et al., 2019) | PDE 잔차를 손실로 넣어 장 대리 모형을 만듦 | 미분 가능한 장을 줄 수 있으나, 이 논문은 수치 해를 씀. 아래 §4 참고 |

## 3. 이 저장소의 다른 분석과의 관계

- **robosimstudio/** (arXiv:2610.18835, 시뮬레이션 솔버와 물성의 식별, Real2Sim): 시뮬레이터의 매개변수를 실측에 맞추는 축이 같습니다. 이 논문의 κ, 경계 조건, 초기 조건이 **식별해야 할 대상**이라는 점에서 직접 관련됩니다. 이 논문은 식별을 하지 않으므로, robosimstudio의 식별 절차를 장 모형에 적용하는 것이 자연스러운 다음 단계입니다.
- **reactive_grasp/** (arXiv:2609.30082, 모형 기반 QP 제어): 모형을 써서 실시간으로 행동을 계산하는 점은 비슷하지만, 위치추정과 직접 대응하지 않습니다. 이 논문의 필터는 제어 루프 밖에 있습니다.
- **PINN 관련:** 이 저장소에는 PINN 전용 분석 폴더가 없습니다(02·README 검색, 2026-11-10). 물리 기반 모형을 다루는 폴더는 위 두 곳뿐입니다.
- **결론:** 장을 측정 모형으로 쓰는 위치추정에는 이 저장소에 **직접 대응하는 분석이 없습니다.** 가장 가까운 것은 robosimstudio의 모형 식별이고, 제어(reactive_grasp)와는 연결이 약합니다.

## 5. 이 분석에서 가져오는 것

- 장 기반 위치추정은 **시간 의존 지도**가 핵심입니다. 정적 지도는 시험에서 가장 나쁩니다(`analysis/03_analysis.md` §6).
- 측정 모형의 **명목 장 값을 어떻게 읽는지**(반올림, 보간, 건조 칸)가 위치 분해능을 정합니다.
- 장과 편향을 같이 추정하면 **식별성**을 따로 확인해야 합니다(`analysis/03_analysis.md` §2.4).
