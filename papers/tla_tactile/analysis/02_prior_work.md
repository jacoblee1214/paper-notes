# TLA 선행연구와 관련 자료

이 문서는 TLA(arXiv:2503.08548)의 선행연구 계보, 공식 저장소 탐색 결과, 함께 읽을 만한 관련 분석을 정리합니다. 분석일 2026-11-22.

## 1. 선행연구 계보

TLA가 붙이려는 자리는 두 줄기가 만나는 곳입니다. 하나는 VLM을 로봇 행동으로 바꾸는 VLA 줄기이고, 다른 하나는 촉각과 언어를 맞추는 촉각-언어 줄기입니다. 논문은 두 줄기 모두 "시각 중심"이거나 "지각 전용"이라고 봅니다(§I, §II).

| 줄기 | 대표 연구 (논문 인용 번호) | TLA와의 관계 |
|---|---|---|
| VLM을 행동 토큰으로 | RT-2 [11], OpenVLA [13], RoboFlamingo [22], TinyVLA [14] | TLA는 행동을 숫자 텍스트로 쓰고 Qwen 토크나이저를 그대로 씀. OpenVLA의 드문 토큰 bin과 대비 (§IV-B) |
| 생성형 사전학습 | GR-1 [23], GR-2 [24] | 논문은 "영상 사전학습이 물리 정보를 준다"고 설명만 함. TLA는 영상 사전학습이 없음 |
| 확산·흐름 기반 VLA | RDT-1B [25], π0 [26] | 논문은 행동 디토크나이저의 단순함을 한계로 듦 (§VI). 저널본은 흐름 매칭을 향후 과제로 씀 |
| 촉각-언어 정렬 (지각) | Binding touch [17], Touch100k [18], Fu et al. (VTL 데이터셋) [19] | 논문은 "행동을 생성하지 않는 지각 연구"로 분류 (§II-B) |
| 촉각을 VLA에 넣기 | FuSe [20] (Jones et al. 2025) | 논문에서 가장 가까운 대안. 이종 센서를 언어로 묶는 VLA. TLA는 "촉각만"이라고 주장 (§II-B) |
| 조립 시뮬레이션과 촉각 | Tactile-RL for insertion [9], Lee et al. [8] | 삽입 과제의 촉각 강화학습과 표현 학습 |
| 기준선 | BC: Torabi et al. [35] (관찰 기반 행동 복제 BCO), DP: Chi et al. [37] | BC의 인용은 관찰 기반 논문이므로 기준선 정의와 맞는지 확인이 필요함 (`01` §6) |
| 백본 | Qwen2-VL [29], Qwen2 [31], LoRA [34], ViT [30] | TLA는 Qwen2-VL의 ViT를 촉각 인코더로 씀 (고정) |
| 센서와 시뮬 | GelStereo 2.0 [27, 28] (촉각 임프린트 시뮬) | 같은 저자 그룹(CASIA)의 센서. 공개 센서 소프트웨어는 확인하지 않음 |

**계보에서 보이는 것:** TLA의 새로움은 "촉각을 이미지 한 장으로 붙여 VLM에 넣고, 행동을 숫자 문자열로 쓴다"는 조합입니다. 개별 요소(VLM 행동 토큰, 촉각 이미지 표현, 촉각 이미지의 언어 정렬)는 모두 선행연구에 있습니다. 논문이 "처음"이라고 주장하는 부분(§I 끝, "first language-grounded tactile-action generation framework")은 FuSe와 비교해 좁은 범위(촉각 전용)에서만 맞습니다.

## 2. 공식 저장소와 프로젝트 페이지

| 자료 | 상태 | 확인 방법 | 비고 |
|---|---|---|---|
| 공식 코드 저장소 | **찾지 못함** | GitHub 저장소 검색 (`tactile-language-action`, `TLA tactile peg-in-hole`, `2503.08548`, `GelStereo peg hole` 등). 코드 검색은 요청 제한으로 실패 | 검색 결과에 TLA 공식 구현으로 보이는 저장소 없음. 같은 이름의 다른 논문 저장소만 있음(아래 §3). 코드 검색 미완료는 `README`의 미확인 항목에 적음 |
| 프로젝트 페이지 | 있음 (Google Sites, `sites.google.com/view/tactile-language-action/`) | HTML 확인 | 영상 다섯 개(Google Drive 링크: 파이프라인, 페그 종류, 간격, 실로봇 두 개). **GitHub 링크, 데이터 링크, 모델 링크는 없음** |
| 데이터셋 | **공개 링크 없음** | 프로젝트 페이지와 arXiv 페이지 | 초록은 "publicly release all data and code"라고 씀. 저널본은 "문의 시 제공"으로 씀 |
| 모델 가중치 | 찾지 못함 | Hugging Face 데이터셋 검색 (`tactile-language-action`) 결과 없음. 모델 검색은 하지 않음 | |
| 저널 게재본 | 있음 (Robot Learning 2026, DOI 10.55092/rl20260001) | Crossref, 발행사 페이지 | 게재본에 따르면 데이터는 문의 시 제공. 코드 공개 문장은 없음 |

따라서 `04`는 **코드 대조(D-항목)가 아니라 주장 검증(C-항목)** 으로 씁니다. 저장소를 클론하지 않았습니다.

### 2.1 학회 확인 (venue)

- **CoRL 2026 공식 채택 목록** (corl.org 기준 755건, 2026-11-14 수집): 제목 "TLA" 또는 "Tactile-Language-Action" 항목이 없습니다.
- **arXiv 댓글:** 없음 (abs 페이지에 Comments 필드 없음).
- **저널 참조:** arXiv 페이지에 없음. OpenAlex와 Crossref는 이 논문의 저널 게재본 DOI(10.55092/rl20260001)를 연결합니다.
- **결론:** 학회 게재는 확인되지 않습니다. 저널 게재가 확인되었으므로 `venue`는 "저널 Robot Learning 2026"으로 적습니다.

## 4. 그 밖의 확인 사항

- **GitHub 검색 제한:** REST 검색 API가 요청 제한에 걸려 `gh` CLI로 저장소 검색을 다시 했습니다. 코드 검색은 끝내 성공하지 못했습니다.
- **OpenAlex의 저널 연결:** 제목 일치 기준으로 연결했고, 저자 목록(7명)이 arXiv와 같습니다. 게재본 소속은 arXiv와 일부 다릅니다(공개 노트에는 소속을 쓰지 않음).
- **저널 "Robot Learning"의 성격:** ELS Publishing이 발행하고 ISSN 2960-1436을 씁니다. Crossref에 41건이 등록되어 있습니다. 신생 저널이므로 인용 가치는 독자가 직접 판단해야 합니다.
