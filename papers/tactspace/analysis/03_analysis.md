재계산 스크립트: `analysis/table_check.py` → `table_check_results.json` (1초 미만). 토이: `analysis/align_toy.py` → `align_toy_results.json` (numpy, 1스레드, 약 14초). 표 값은 논문 PDF를 렌더링해 옮긴 값이다. 샘플별 원자료가 없어서 정밀한 검정은 할 수 없고, 가정 아래의 근사만 한다.

## 1. 헤드라인 수치의 출처 (재계산 확인)

## 2. 불확실성: 샘플 검정과 궤적 검정

표는 평균 오차와 20–80% 백분위만 준다. 시드별 반복이 없으므로 학습 분산은 알 수 없다. 대신 **유효 표본 수**를 가정해 두 비율(정확도)의 차이를 검정한다.

- 테스트 궤적 수 (25% 분할 근사): 분포 내 ≈58, OOD-Size ≈53, OOD-Shape ≈42.
- 궤적당 샘플 m ≈ 32,942/840 ≈ 39.2.
- 설계효과 DEFF = 1 + (m − 1)ρ, 유효 n = n_샘플 / DEFF. ρ는 궤적 내 상관이며 알 수 없다. 0, 0.05, 0.2를 훑었다.

| 비교 | ρ = 0 (샘플 단위, 과대) | ρ = 0.05 | ρ = 0.2 (보수적) |
|---|---|---|---|
| InfoNCE 대 MSE, 분포 내 정확도 | z = 5.84 (p < 0.001), n_eff 2,265 | z = 3.42, n_eff 778 | z = 1.98 (p = 0.047), n_eff 262 |
| InfoNCE 대 MSE, OOD-Size | z = 1.30 (p = 0.19) | z = 0.76 | z = 0.44 |
| InfoNCE 대 MSE, OOD-Shape | z = 0.63 (p = 0.53) | z = 0.37 | z = 0.22 |
| RBS 15x 대 1x, 분포 내 정확도 | z = 8.48 | z = 4.97 | z = 2.88 (p = 0.004) |

- **해석.** 분포 내 정확도에서 InfoNCE 우위는 ρ가 0.2 근처에서도 p≈0.05다. OOD 분할의 차이는 ρ가 0.05만 넘어도 유의하지 않다. 논문이 OOD 우위를 강조하는 것은 이 불확실성을 반영하지 않은 것이다.
- **연속 변수(깊이, 힘).** 백분위 범위로 로그 표준편차를 근사했다(σ_log = (ln P80 − ln P20)/(2·0.8416)). InfoNCE 대 MSE 분포 내 깊이의 효과 크기는 d_log = −0.33이고, 정렬 없음 대비는 −0.31이다. 힘은 MSE 대비 d_log = −0.07로 거의 없다. 힘 개선은 정렬 방식보다 "정렬 자체가 있는가"에 달린 것으로 보인다. 단, 이 d는 평균의 차이가 아니라 중앙값의 차이에 기반하므로 참고용이다.

## 3. 교란: Table III는 요인 설계가 아니다

Table III는 정렬 데이터, 재구성 모달리티, 과제 데이터를 **동시에** 바꾼다.

- R2(과제 Mp)와 R3(과제 Ms)는 과제 모달리티가 다르다. 따라서 "Mp 재구성이 깊이를 돕는다"는 해석에 쓸 수 없다. R3가 R2보다 깊이가 낮은(48 대 58) 것도 재구성 차이가 아니라 과제 차이일 수 있다.
- R1과 R4는 재구성 항만 다르다(과제는 둘 다 Mp, Ms). 이 쌍이 재구성 효과의 유일한 깔끔한 비교다. 깊이에서는 R1 45, R4 26으로 재구성이 도움이 된다. 힘에서는 R1 60, R4 65로 재구성이 오히려 나쁘다. OOD-Shape 깊이에서도 R1 7, R4 13이다. 따라서 재구성의 효과는 **과제에 따라 부호가 바뀐다**.
- **사실상의 실험 설계.** 완전 요인 설계(정렬 3 × 재구성 3 × 과제 3)에서 최소 여러 시드가 필요하다. 논문은 이를 하지 않았다.

## 5. 토이: 공유 잠재는 언제 직접 회귀와 도메인 무작위화를 이기나

### 5.1 설정 (`analysis/align_toy.py`)

- 자극 z ∈ R³ ~ N(0, I). 라벨 y = w·z + 0.5 z₀z₁ (w = [1, −0.5, 0.8]). 힘 대리 변수.
- 시뮬 관측 x_s = tanh(Az) + 잡음 0.05, 차원 12. 실측 관측 x_r = tanh((A + δE)z) + γ·Q(z) + 잡음 0.1. Q는 이차항(시뮬 가족 밖의 비선형 왜곡), γ는 그 세기.
- 시뮬 라벨은 모두 있고, 실측 라벨은 평가에만 쓴다. 쌍 (z 같은 실측·시뮬 관측)은 N개.
- 방법: M0 시뮬 회귀 그대로, M1 도메인 무작위화(시뮬 매핑 근처 섭동), M2 실측 라벨 N개 직접 회귀, M3 CCA 공유 잠재(쌍 N개, 시뮬 라벨로 회귀), M4 InfoNCE 정렬(쌍 N개, 선형 인코더 on 91차원 고정 특징, 온도 0.1), M4b 같은 인코더를 정규화 없이 사용.
- 평가 지표는 실측 테스트 R² (1이 완벽, 음수면 평균보다 나쁨). 시드 3개(N ≤ 300), 2개(N > 300).

### 5.2 기울기 검산

대칭 InfoNCE의 기울기 dL/dS = ½[(P_row − I) + (P_col − I)]/B를 유한 차분으로 검산했다. 처음 구현에서 배치 크기 B로 한 번 더 나누는 오류가 있었고, 검산에서 최대 오차 0.51이 나와 고쳤다. 고친 뒤 최대 오차는 1.2e−9다. 결과 파일은 고친 코드로 다시 만들었다.

### 5.4 읽는 법

1. **시뮬 그대로(M0)와 도메인 무작위화(M1)는 비선형 간극에서 실패한다.** γ ≥ 0.5에서 R²가 음수다. 무작위화는 선형 섭동에는 도움이 된다(γ=0에서 M1 0.77 대 M0 0.46). 시뮬 가족에 없는 비선형은 무작위화로 덮이지 않는다.
2. **공유 잠재(M3)는 M0와 M1을 크게 이긴다.** 쌍이 N ≥ 100이면 비선형 간극에서도 R² 0.4–0.7을 얻는다.
3. **그러나 같은 N의 실측 라벨 직접 회귀(M2)가 항상 더 낫다.** γ ≥ 0.5에서 M2가 M3보다 0.2–0.4 높다. γ = 0에서는 N ≤ 300에서 둘이 비슷하다. 쌍은 자극 z를 담고, z는 라벨을 결정한다. 따라서 **쌍 1개는 라벨 1개와 같은 정보를 준다.** 정렬의 이득은 "라벨을 모을 수 없고 쌍만 모을 수 있을 때"로 한정된다. 논문의 상황에서는 실측 쌍이 형상·위치·깊이를 알려 주므로 이 조건이 맞는지 따져 봐야 한다.
4. **필요한 쌍 수.** 특징 차원은 91이다. N이 특징 차원보다 작은 100 이하에서 CCA는 불안정하다(γ = 1, N = 10에서 R² = −4.6). 포화는 N ≈ 300–1000에서 온다. 즉 실측 쌍은 특징 차원의 몇 배 이상이 필요하다. 논문의 실측 쌍 규모(약 9,000 샘플)는 이 범위를 넘는다. 단, 이는 toy 기준이고 논문 인코더의 실효 차원은 알 수 없다.
5. **InfoNCE 기준선의 실패.** 선형 인코더와 배치 대조 학습은 3000쌍에서도 R² 0.1–0.3이다. 학습 길이를 2000단계로 늘리거나 학습률을 낮춰도 나아지지 않았다. 정규화 없는 M4b도 비선형 간극에서 크게 음수다. 원인으로 보이는 것은 대조 목표가 "구별만" 하면 되고, 잠재가 y를 선형으로 해독 가능해야 한다는 조건을 주지 않는다는 점이다. 논문에서 재구성 항을 빼면 깊이가 나빠지는 결과(C7)와 맞는다. 다만 이 toy는 재구성 항을 구현하지 않았으므로, 재구성 효과를 직접 검증한 것은 아니다.

### 5.5 이 toy가 보여 주지 못하는 것

- 재구성 항, 실제 ViT, 실제 센서 잡음, 히스테리시스 모델링.
- 논문의 세 모달리티 설정 (두 모달리티만 썼다).
- 대조 학습의 배치 크기 효과. 배치 B에서 InfoNCE의 상호 정보 추정은 log B를 넘지 못한다(유도 §6). 논문의 배치 크기는 공개되지 않았다.

## 6. 유도

**(a) 16.7%와 45.8%.** 감소율 = (기준 − 새 값)/기준. 78→65, 48→26을 대입하면 16.67%, 45.83%다.

**(b) InfoNCE의 상호 정보 상한.** 배치 B의 InfoNCE 손실 L_NCE는 I(Z_s; Z_r) ≥ log B − L_NCE를 만족한다(van den Oord et al. [14]). 따라서 L_NCE가 0에 가까워도 추정 상한은 log B다. B = 256이면 log B ≈ 5.55 nats, B = 32면 3.47 nats다. 배치가 작으면 자극을 구별하는 정보량이 구조적으로 제한된다. 논문은 배치 크기를 주지 않았다(04 D18 참조).

**(c) 노름을 버리는 정규화.** 정렬 임베딩을 u = a/‖a‖로 쓰면 반지름 ‖a‖의 정보가 사라진다. y가 반지름에 의존하면(toy의 y = w·z에서 z의 크기), 방향만 맞춘 잠재로는 y를 회귀할 수 없다. 이것이 M4(정규화)가 실패하는 한 이유일 수 있다. 다만 M4b(정규화 없음)도 실패하므로 이 설명은 부분적이다.

**(d) 대칭 InfoNCE의 기울기.** L = ½(CE_row + CE_col), CE_row = −(1/B)Σ_i log P_row,ii. 그러면 ∂L/∂S = ½[(P_row − I) + (P_col − I)]/B. 정규화 u = a/‖a‖의 역전파는 ∂L/∂a = (∂L/∂u − u(u·∂L/∂u))/‖a‖다. 검산 결과 §5.2.

**(e) 설계효과.** n_eff = n/(1 + (m − 1)ρ). ρ가 0.2이고 m = 39.2이면 DEFF ≈ 8.6이다. 그래서 샘플 수 2,265가 유효 262로 줄어든다.

## 7. 열린 항목 (검증 못 한 것)

- 시드 반복 결과가 없어 학습 분산을 모른다. 이 때문에 모든 검정은 조건부다.
- 실측 깊이 정답의 정의 (01 §6).
- 실측 쌍의 수와 그 중 형상·위치·깊이가 실제로 몇 개인지. 샘플 수와 쌍 수가 같은지도 본문에 없다.
- 재구성 항과 λ 설정의 효과 (toy에 구현하지 않음).
- 시뮬레이터 품질 (C 항목 밖): 공개 저장소 접근 불가 (04 D10).
