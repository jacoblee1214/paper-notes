## 1. 한 장 요약

**문제.** 시뮬레이션에서 PPO로 학습한 인간형 동작 추종 정책은 실제 로봇에서 질량·마찰·구동기 차이를 만나 성능이 떨어집니다(1절). 저자들은 시뮬 파라미터를 다시 맞추는 방식은 블랙박스 튜닝이라 비효율이라 주장하고, 실제 데이터로 정책을 직접 미세조정하는 "last mile"을 겨냥합니다.

**방법.** 반복 루프 세 단계입니다(그림 2).
1. **데이터 수집(FENCE).** 기준 궤적의 관절 위치 `Q`에 저주파(≤ kc) 복소 가우시안 잡음을 DFT 영역에서 더해(식 1–2) 정책이 그 섭동 궤적을 추종하게 합니다. 섭동 세기 σ는 K개 후보 중 UCB 밴딧이 고르고(식 9–10, 인접 수준으로만 이동), 보상은 정책 이웃 점유 비율 `C`(식 3, 가중판 식 7–8)입니다.
2. **모델 학습.** 고유수용(proprioceptive) 입력만 쓰는 이력 기반 신경 동역학 모델(NDM). 상태 `s_t = {q, q̇, g, ω, h}`, 길이 H의 이력을 입력으로 다음 상태를 예측합니다(식 4). 미분 가능 FK로 링크 6자유도 자세를 내고 구성 공간 + 유클리드 공간 이중 손실(식 5)로 Lw 단계 자기회귀 롤아웃을 학습합니다. 부록 A.5: 트랜스포머 2층(d = 64, 4 헤드, d_ff = 16) + MLP 디코더 + 5개 머리, 파라미터 약 51만 개(우리 계산, `03` V11).
3. **정책 미세조정.** NDM을 통해 Lπ 단계 롤아웃을 만들고 추종 손실(식 6)을 NDM 기울기로 직접 역전파합니다(DreamerV1류·SHAC류의 해석적 모델 기울기 방식, 참고문헌 15–18, 35).

**주장.** (a) 시뮬 5개 동작 × 3 교란에서 60개 지표 중 40개가 최선이고, 직접 전이 대비 Elink pos·rot를 30%·47% 줄입니다(5.1.1절). (b) FENCE는 실로봇에서 행동 잡음보다 흔들림이 작습니다(표 5). (c) 이중 공간 손실과 이력 입력이 모두 필요합니다(그림 4). (d) Unitree G1 실로봇 6과제에서 직접 전이보다 개선됩니다(표 4). (e) "첫 온라인 MoCap-free 인간형 추종 정책 미세조정"입니다(초록).

## 2. 방법 상세

### 2.1 기본 정책과 PD 제어 (3절)

- 정책 `π(a_t | o_t)`, 관측 = 고유수용 상태(q, q̇, 중력 벡터 g, 각속도 ω) + 이전 행동 + 미래 기준 상태. 행동 `a_t ∈ [-1, 1]`, `q_des = c·a_t + q̂_t`, PD 토크 `τ = Kp(q_des − q) − Kd q̇`.
- 기본 정책은 MuJoCo-JAX(MJX)에서 PPO로 학습합니다. 정책 구조(층 수, 크기)는 논문에 없습니다.

### 2.2 FENCE (4.1절, 부록 A.1)

- **섭동(식 1–2).** `Q̃ = DFT(Q)`, `Z_0 = 0`, `0 < k ≤ kc`에서 `Z_k ~ CN(0, σ² I)`, 켤레 대칭 `Z_{T−k} = Z_k*`, 나머지 0, `Q' = IDFT(Q̃ + Z)`. 속도는 `Q'`에서 다시 유도합니다. 표 6은 kc = 1.0 Hz로 적습니다(식의 `k`는 인덱스이고 Hz와의 환산은 T와 dt에 달려 있습니다).
- **이웃 점유 `C`(식 3).** 최신 정책을 섭동 없이 돌려 얻은 `x_t = [s_t, a_t]` 주변에 반지름 R, 반경 빈 Nr = 2, 방향 빈 Nd = 16(표 6)의 이웃을 잡고, 버퍼 B가 각 빈과 겹치는 비율의 평균입니다. 식 3의 합은 `t = 1..T−1`인데 정규화는 `1/T`입니다. R은 동작마다 다른 하이퍼파라미터입니다(A.1.1).
- **가중판(식 7–8).** 위치 추종 오차 `e_t`로 `C_t`를 가중해 `C̄`로 씁니다. 본문 식 3은 가중치가 없습니다.
- **밴딧(식 9–10).** 팔 i의 보상 `S(σ_i) = C̄`(최근 버퍼 `B_i` 기준), `U = S + β·sqrt(ln N / n_i)`, β = 0.05. 현재 수준과 인접 수준 중에서만 argmax. 우리 계산: N = 200, n_i = 1이면 보너스는 0.115입니다(`03` V13). 보상이 [0, 1] 점유 비율이라 보너스가 보상 차이와 비슷한 크기가 될 수 있습니다.

### 2.3 NDM (4.2절, 부록 A.2, A.5)

- 입력 `s_{t−H+1:t}, a_{t−H+1:t}`(H = 10), 상태 64차원 `[ω(3), ρ(2, roll-pitch), q, q̇, h]`, 행동 23차원(A.5). 64차원이 맞으려면 `q`, `q̇`가 각각 29차원이어야 하고(3 + 2 + 29 + 29 + 1 = 64), 행동은 23차원이므로 6개 관절은 정책이 내지 않는 것으로 읽힙니다. 논문에 이 부분의 설명은 없습니다(`03` V11).
- 중력 벡터는 roll-pitch 2차원으로 바꾸고, 관절 위치는 예측한 속도를 한 번 적분해 얻습니다(`q̂_{t+1} = q_t + q̇̂_{t+1}·Δt`, Δt = 0.02 s). 예측은 잔차 형태입니다.
- 앙상블은 "공유 백본 + 5개 머리"입니다. 머리별 부트스트랩 마스크(확률 0.8). 독립 모델 5개가 아닙니다(A.2.2).
- 손실(A.2.3): `L_ω`, `L_rp`, `L_q`, `L_h`는 L2, `L_link_pos`는 프로베니우스, `L_link_rot`은 측지 거리 제곱(가중치 5.0). 표 6의 가중치는 `L_link_rot`만 5이고 나머지 1.0입니다.
- 루트 높이 `h`는 "지속적 지면 접촉을 가정하고 q와 g에서 추정"합니다(4.2절). 점프에서는 접촉이 없어 `h`를 모델에서 빼고 기준 높이를 씁니다(부록 G).

### 2.4 정책 미세조정 (4.3절, 부록 A.3)

- 버퍼에서 길이 H의 이력 + Lπ = 128 단계 구간을 뽑아 롤아웃을 초기화합니다. 손실: `L_q`, `L_rp`(가중치 10), 평활화 `L_sm`(10, 관절 2차 차분), `L_link_pos`, `L_link_rot`(1). 정책 학습률 1e-4, 최종 1e-7, 감쇠 계수 1.0(표 6, `03` V11에서 이 세 값의 관계를 따짐).
- 반복당 NDM 학습 미니배치 32개(512), 정책 미니배치 2개(512). 에폭 수는 표에 없습니다.

## 3. 실험과 수치

### 3.1 시뮬레이션 (5.1절, 표 2, 부록 B–C)

- MuJoCo, Unitree G1. 동작 5개(walk, balance, squat, swing, stride) × 교란 3종(extra weight, scaled KP, small friction) = 15개 설정, 지표 4개(Elink pos, Elink rot, Eqpos, Ekey qpos) = 60칸.
- 교란 값(부록 C): 예) walk extra weight = 몸통 질량 ×1.2 + CoM [-0.2, 0, 0], scaled KP = waist yaw Kp 300 → 0, small friction = 1.0 → 0.3.
- 기준선: PPO w/ Disturb.(교란을 알고 학습한 PPO), Direct Transfer, ASAP(델타 행동 모델), RWM. HumanoidNDM, ASAP, RWM은 배포 환경 궤적 200개를 씁니다. 5회 시행의 mean ± std(표 2 캡션). ASAP와 RWM은 설정마다 격자 탐색해 최적 구성을 보고합니다(부록 B).
- 결과(5.1.1절): "60개 중 40개 최선", 직접 전이 대비 Elink pos·rot 30%·47%(ASAP 23%·27%, RWM 9%·35%). PPO w/ Disturb.과 "대등".
- 절제(5.1.2절): 탐색 방식 교체(그림 3), 다른 프레임워크에 FENCE 적용(표 3), 이중 공간 손실 대 구성 공간 손실(그림 4 왼쪽), 이력 대 단일 프레임(그림 4 오른쪽).
- 부록: 학습 곡선(그림 5–9), σ 적응 대 고정(그림 10–12), 점프(표 7, 그림 13), 사전학습 효과 없음(그림 14), 모델 시각화(그림 15–19).

### 3.2 실로봇 (5.2절, 표 4–5, 부록 D)

- 6과제: 무게 교란 3개(Swallow Balance 종아리 1.5 kg ×2, Arm Swing 왼손 1.5 kg, Pen Capping 왼손 0.75 kg), 모델링하기 어려운 교란 3개(Lateral Raise 탄성 밴드, Walking 물 2 kg 양동이, Bowing 손상된 모터).
- 미세조정 궤적 200개(Pen Capping은 50개). "각 실험은 3회 반복"(5.2절), 부록 D: "3개의 독립 시행, 실패 실행 없음". 반복당 NDM·정책 최적화 약 3 s(RTX 4090), 데이터 수집 약 10 s이므로 200반복 ≈ 1시간.
- 지표: Elink pos, Eqpos와 과제별 지표(체공 시간, 팔 높이, 말단 거리, 편향각, 소음). 실로봇의 링크 위치 오차를 어떻게 얻는지는 적혀 있지 않습니다(MoCap은 쓰지 않는다고 함).
- 표 5(Lateral Raise): FENCE의 Sqpos 0.099 ± 0.018, Action Gaussian 1.275, OU 0.707, Obs Gaussian 1.151, No Noise 0.076. 시행 수는 적혀 있지 않습니다.

## 4. 논문이 말하는 한계 (6절)

- 시간에 따라 변하지 않는 교란만 다룹니다.
- 더 방향성 있는 탐색을 위해 사전 지식을 쓸 수 있습니다(향후 과제).
- 위 범위 밖에서 이 글이 보는 간격은 `03`과 `04`에 있습니다. 요약하면 (i) 실로봇 표본이 작고(3회), 일부 칸의 SD가 0.00이라 검정이 안 되며, (ii) 시뮬 우위는 동작별로 갈리고(balance·stride에서는 ASAP·RWM이 앞서는 칸이 있음), (iii) FENCE의 σ와 DFT 규약, 정책 구조, 실로봇 오차 계측 방법이 논문만으로는 재구성되지 않으며, (iv) 코드가 아직 없어 이를 확인할 수 없습니다.
