## 2. 통계 검정 (과제별 30회, 합산 150회)

검정은 양측 Fisher 정확 검정을 썼다. 보정은 Holm. 논문은 단측 Fisher를 쓰지 않았고, 대부분 기준선 비교에서 검정 자체를 보고하지 않았다.

### 2.1 PACE 대 기준선 (표 1)

| 비교 | 합산 PACE / 기준선 | 합산 p (양측) | Holm (30개) |
|---|---|---|---|
| PACE vs Vision-only ACT | 136 / 15 | 6e-50 | 2e-48 |
| PACE vs Vision-only DP | 136 / 23 | 5e-43 | 1e-41 |
| PACE vs π0 | 136 / 28 | 3e-39 | 8e-38 |
| PACE vs Cross-Attn | 136 / 59 | 1e-21 | 3e-20 |
| PACE vs Concat | 136 / 69 | 2e-17 | 5e-16 |

과제별 Concat 비교(Holm 보정, 30개 family)는 Key 0.0013, 2-pin 0.0013, 3-pin 0.00013, USB 0.0013, Ethernet 0.012로 모두 유의하다. 가장 가까운 기준선도 차이가 크다. 기준선 간 차이에 주의가 필요하다는 논문의 주장(교차 주의가 연결보다 낫지 않음)은 검정하지 않았다.

### 2.2 절제 (표 2, 합산 150회)

| 변형 | 변형 / PACE | 합산 p | Holm (4개) | 판정 |
|---|---|---|---|---|
| w/o Pred. | 128 / 136 | 0.21 | 1.0 | 유의하지 않음 |
| w/o Phase | 118 / 136 | 0.006 | 0.11 | 보정 후 유의하지 않음 |
| w/o Event | 100 / 136 | 5e-7 | 1e-5 | 유의 |
| Phase-only | 90 / 136 | 6e-10 | 1e-8 | 유의 |

해석: Event 역할은 강하게 지지된다. Phase 역할은 보정 전에는 지지되지만 보정 후에는 확정하기 어렵다. Pred. 역할은 이 데이터에서 근거가 없다. 논문 본문도 Pred.를 "보조 표현 학습"으로 낮춰 쓴다(§4.2). Pred.가 유의하지 않다는 사실은 "PACE의 세 역할이 모두 필요하다"는 주장을 약하게 만든다.

## 3. 일관성 검사

1. **평균과 구간**: 모두 일치(§1).
2. **본문의 "약 2,500 롤아웃"**: 표 기준 61 실행 × 30 = 1830 실로봇, 여기에 ManipulationNet 150 (6구성 × 25)과 절제·신호 대체·DP·RDP·피드백 실험을 더하면 "거의 2,500" 근처다. 정확한 합산은 논문이 제시하지 않는다.
3. **표 1(b)의 ManipulationNet 구성 수**: 6개 구성 × 25회 = 150. 본문 "25 rollouts per configuration"과 일치.
4. **Event 보정 길이**: h_corr=5, 20 Hz → 0.25 s. 일치.
5. **파라미터 세부**: 위상 인코더의 층별 선형 변조기(128→1024, 4층)와 MLP는 약 0.546 M. 게이트(입력 7, 은닉 64·64, 출력 7)는 0.005 M. 잔차(입력 24 = T_w×D_w, 은닉 128·128, 출력 35 = 5×7)는 0.024 M. 예측 헤드(512→512→6)는 0.266 M. 모두 맞다.
6. **기계적 분석 통계 (불일치)**:
   - Pearson r=0.356의 p를 n에 따라 계산하면 n=30에서 p≈0.054, p<0.001이 되려면 n≥83이다. 본문은 "rollout-level summaries"라고 했으니 n=30이어야 한다. 불일치.
   - ANOVA F=8.36, η²=0.236은 η²=SSb/(SSb+SSw)와 F=(η²/(k−1))/((1−η²)/(N−k))에서 N을 정할 수 있다. k=2면 N≈29, k=3이면 N≈57, k=4면 N≈85, k=5면 N≈113이다. 이 N에서 p는 각각 약 7e-3, 7e-4, 7e-5, 6e-6이다. 따라서 보고된 p<1e-4는 k≥4이고 N≈85 이상일 때만 나온다. N=30에서는 F=8.36의 p가 k=2 7e-3, k=3 1.5e-3, k=4 5e-4, k=5 2e-4로 어느 경우도 1e-4보다 크다. 따라서 보고된 ANOVA는 30 롤아웃이 아닌 다른 단위로 계산되었다.
   - 결론: 두 통계 모두 "롤아웃당 한 관측"이라는 설명과 맞지 않는다. 단위(시간 스텝인지 구간 수인지)를 저자에게 물어야 한다.
7. **힘 피드백 실험의 162 에피소드 대 약 160**: 같은 데이터인지 불분명.
8. **"과제당 30% 미만에서 피드백 없이 수집"**: 근거 수치 없음.

## 4. 토이

### 4.1 토이 1: 상태와 사건을 나누면 사건 검출이 나아지는가

설계(전부 가정): 1차원 촉각 신호 = 상태(접근 0 → 첫 접촉 1.0 → 안정 삽입 3.0, EMA로 매끄럽게) + 사건(±1.5, 3스텝, 확률 0.01/스텝) + 잡음. 안정 삽입 구간의 잡음은 2배로 둔다. 전역 허위경보율을 1/1000 스텝으로 맞추고(사건 없는 에피소드에서 분위수로 임계값 결정, 측정 FA 0.001) 두 검출기를 비교한다.

- 단일 특징: f_t = |x_t − x_{t−4}|에 고정 임계값.
- 상태 분리: 상태 ŝ = EMA(x), 잔차 r = x − ŝ, 점수 |r_t − r_{t−4}|를 EMA 척도(α=0.02)로 나눈다.

결과(사건 후 10스텝 내 검출률, 사건 수 약 2300–2400):

| 잡음 σ | 단일: 전체 / 접근 / 접촉 / 안정 | 분리: 전체 / 접근 / 접촉 / 안정 |
|---|---|---|
| 0.1 | 1.00 / 1.00 / 1.00 / 1.00 | 0.65 / 0.29 / 0.81 / 0.69 |
| 0.3 | 0.24 / 0.13 / 0.12 / 0.45 | 0.22 / 0.12 / 0.34 / 0.14 |
| 0.6 | 0.05 / 0.00 / 0.00 / 0.12 | 0.04 / 0.02 / 0.05 / 0.04 |
| 0.3, 잡음 동일 (이분산 끔) | 0.98 / 0.98 / 0.98 / 0.99 | 0.60 / 0.28 / 0.72 / 0.70 |

해석:
- 상태 분리가 일관되게 낫다는 증거는 없다. σ=0.1에서는 단일이 압도한다. σ=0.3에서는 접촉 구간에서만 분리가 낫고 안정 삽입 구간에서는 단일이 낫다.
- 이분산 잡음을 끄면 단일이 거의 완벽하고 분리는 낮아진다. 분리의 이득은 "상태에 따라 잡음이 바뀐다"는 가정에서만 나온다. 그 가정도 이 토이에서 임의로 정했다.
- 따라서 이 토이는 논문의 Event 설계(상태 조건부 게이트)를 지지하지도 반박하지도 않는다. 논문 실험 결과(표 2의 Event 제거 손실)가 이 메커니즘 때문이라는 증거는 아니다.

### 4.2 토이 2: 과제당 30회의 검정력과 부풀림

가정: 기준 성공률 46%(Concat 평균), 참 차이 Δ, 단측 Fisher α=0.05, 반복 2000회.

| 참 차이 Δ | 검출력 | 유의한 경우의 평균 관측 차이 |
|---|---|---|
| 0.10 | 0.12 | 0.31 |
| 0.20 | 0.35 | 0.33 |
| 0.30 | 0.67 | 0.36 |
| 0.45 | 0.99 | 0.45 |

- 30회로 참 차이 0.20을 검출할 확률은 0.35에 그친다. 논문의 "기준선 대비 44 pp 이상" 차이는 검출력이 충분하다. 반면 과제별 작은 차이(예: 피드백 on/off나 F/T 대 촉각)는 검출하기 어렵다.
- 유의한 결과는 참 차이보다 크게 부풀려진다(Δ=0.20에서 0.33, Δ=0.10에서 0.31). 과제별로 "유의한 차이"를 강조하는 해석은 조심해야 한다.
- 귀무 아래 25개 독립 비교(기준선 5 × 과제 5) 중 하나 이상 p<0.05가 나올 확률은 0.46이다. 논문 표 1·2의 과제별 비교를 보정 없이 보고한다면 이 확률로 "우연한 유의"가 생길 수 있다.

## 5. 요약

- 표 수치는 모두 재현된다.
- 대규모 차이(PACE 대 기준선)는 어떤 보정에서도 유의하다.
- Event 제거의 손실은 유의하다. Phase 제거는 보정 후 불확실하다. Pred. 제거는 유의하지 않다.
- 신호 대체(F/T, 관절 전류)는 검정으로 차이를 증명하지 못했다. 같다고 말하기에 검정력이 부족하다.
- 기계적 분석의 통계(r, ANOVA)는 보고된 단위(30 롤아웃)와 맞지 않는다.
- 토이 1은 상태 분리의 이득이 잡음 구조에 크게 의존함을 보인다.
- 토이 2는 30회 비교의 검출력과 부풀림을 보인다.
