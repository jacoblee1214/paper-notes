# 04. 공식 코드 대조와 구현 가능성

## 0. 대상과 방법

- 저장소: `yuffish/VLA-CF` (공식, arXiv 초록 페이지와 프로젝트 페이지의 Code 링크). 커밋 `8280a500a01f7f7d45efe202cb416ca362aa8c1a` (2026-10-30, "Update README.md"; 첫 커밋은 2026-04-23). 얕은 복제를 `repo/`에 두었습니다. 저장소 전체는 약 218 MB(GitHub API 크기)이고 대부분 LIBERO 에셋(질감, 메시)이라, **에셋, 초기 상태 파일, 원본 LIBERO BDDL을 뺀 부분 복제(약 5 MB)**만 읽었습니다.
- **정적 읽기만 했습니다.** 코드를 실행, import, 설치하지 않았습니다. 가중치와 데이터를 받지 않았습니다. Hugging Face의 VA 체크포인트는 파일 목록 메타데이터만 확인했습니다(`openvla-oft-libero-VA` 15.9 GB, `pi0-libero-VA` 12.0 GB, `pi05-libero-VA` 12.4 GB).
- 복제 내용과 내려받은 파일은 신뢰하지 않는 데이터로 다뤘고, 어떤 스크립트도 실행하지 않았습니다(pickle 형식의 초기 상태 파일은 열지 않았습니다).

## 1. 설치 요구사항과 라이선스

- README 설치: `uv venv --python 3.8`, PyTorch cu113 인덱스, `requirements.txt` + `requirements_libero.txt`로 평가 환경을 만들고, 정책 서버는 별도 환경(openpi는 `uv sync`와 JAX, OpenVLA-OFT는 업스트림 저장소에 `openvla-oft-cf/`를 덮어쓰기)에서 WebSocket으로 서빙합니다. 모든 예시 명령이 `CUDA_VISIBLE_DEVICES`를 씁니다.
- README의 예시 출력은 "과제당 50회, NVIDIA RTX 6000, 과제당 약 17분"입니다. 50과제면 한 설정(모델 × 변형)이 약 14시간입니다(`50 × 17분`, README 값에서 계산).
- **라이선스.** 루트 `LICENSE`는 MIT("Copyright (c) 2026 LIBERO-CF"), GitHub API도 MIT. 하위 폴더는 `openpi-cf` Apache-2.0(+ `LICENSE_GEMMA.txt`), `openvla-oft-cf` MIT(Copyright 2025 Moo Jin Kim, Chelsea Finn, Percy Liang). Hugging Face 모델 카드에는 라이선스가 표기되어 있지 않습니다.

## 3. 읽은 코드의 요점

- **CAG 구현은 짧습니다.** openpi: 입력을 변환한 뒤 같은 입력의 언어 토큰을 0으로 가려 두 번째 입력을 만들고, 같은 노이즈로 `_sample_actions`를 두 번 호출해 `a_u + ω(a_c − a_u)`를 계산합니다. VA는 두 번째 모델을 별도로 불러 같은 방식으로 합니다(`serve_policy_VA.py`). OpenVLA-OFT: `infer_with_logits`를 두 번 부르고 같은 식으로 합칩니다.
- **평가의 단위.** 에피소드마다 조건별 `{touched, success}`를 JSON으로 저장합니다(`per_condition`). 따라서 논문의 F와 B 비율은 이 JSON에서 조건을 F 또는 B로 매핑하면 얻을 수 있습니다. 매핑은 코드에 없어 직접 만들어야 합니다.

## 4. 구현 가능성 판정 (이 맥: Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)

**논문 전체의 재현은 이 맥에서 불가능합니다. 표 수치 재계산과 CAG 구조의 축소판(토이)은 이미 했고, 작은 PyTorch 모델로 같은 현상을 다시 만드는 것은 가능합니다.**

| 항목 | 판정 | 근거 |
|---|---|---|
| 표·그림 재계산, 검정 (`03`) | 가능, 완료 | `recompute.py`(수 초) |
| CAG 구조 토이 (`toy_cag_mixture.py`) | 가능, 완료 | numpy, 수 초 |
| 공식 코드 정적 대조 (`04`) | 가능, 완료 | 읽기만 |
| LIBERO-CF 평가 환경 실행 | 불가에 가까움 | `requirements`가 Python 3.8, cu113 PyTorch 인덱스, 정책 서버가 CUDA 전제. LIBERO와 robosuite의 맥 오프스크린 렌더링은 미확인. 새 설치와 공식 코드 실행 승인이 필요 |
