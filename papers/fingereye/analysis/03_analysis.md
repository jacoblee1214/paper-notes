시뮬 평균이 9회 평가(각 64롤아웃, 총 576)의 평균이면 값은 100k/576 %(0.1 단위 반올림) 위에 있어야 합니다. 이 격자는 0.1 단위 값의 약 57.6%만 덮으므로 임의의 값이면 우연히 맞을 확률은 칸마다 0.576입니다. 표 1–3의 시뮬 평균 27개(중복 3개 포함)는 **모두** 격자 위에 있고(우연이면 24개 독립 값 기준 약 2e-6), 학습 시드 하나의 값(192회 격자)은 13/27, 평가 하나의 값(64회 격자)은 6/27만 맞습니다. 표의 평균은 3x3x64 전체의 평균이라는 서술과 정합합니다.

## V7. 센서 감도 (A.2.2)와 보정 오차

- 산술: Δl_min = 0.25 x 2/37 = 0.01351 mm ✓, Δθ_min = (π/12) / (2 x 18.5 x sin(π/24)) x 0.25 = 0.01355 rad ✓ (보고 0.0136). 37 px = 2 mm는 공식 설정 파일의 카메라 내부 파라미터(fx ≈ 346 px, 640 x 480)에서 카메라-태그 거리 약 18.7 mm에 해당합니다. 본문의 "작업 거리 약 10 mm"(DH1, A.1.1)에서는 태그 폭이 약 69 px이 되므로 두 거리는 다른 양으로 보입니다(정의 확인 필요, `04` D10). 태그 배열 폭(23 mm)이 640 px 시야에 들어가려면 거리가 약 12.5 mm 이상이어야 합니다.
- F_min은 ΔL_min을 보정 모델에 통과시킨 값이므로 F_min/ΔL_min이 보정 강성입니다(비대각 항이 있으면 근사): 힘 318 / 312 / 735 N/m, 토크 0.0236 / 0.0096 / 0.631 N·m/rad. 공식 시뮬 가상 관절 강성(`04` D11)은 힘 70 / 29.2 / 100 N/m, 토크 0.50 / 0.20 / 13.3 N·m/rad로, 시뮬/논문 암시값 비율이 힘 0.22 / 0.09 / 0.14, 토크 21 / 21 / 21입니다. 논문은 "게인을 실측 포즈-힘 관계로 맞춘다"고 쓰므로(4.1절), 단위나 보정 방식 차이일 가능성이 있습니다.
- **K6.** 보류 RMSE(0.013, 0.009, 0.047 N)는 최소 검출 힘(4.30, 4.22, 9.93 mN)의 3.0 / 2.1 / 4.7배입니다. 둘은 정의가 다른 양(이론 하한 대 보정 잔차, 저울 오차 포함)이므로 "실제 해상도는 보정 오차가 정할 수 있다"는 정도로 읽어야 합니다. (그림: `report/figures/own_sensitivity.png` 왼쪽)
- **K7.** 세 병진 감도에 같은 값(0.0135 mm)을 쓰는 것은 x, y에는 맞지만 z(깊이)는 단일 태그의 원근 모델에서 Δz = Z·δ/w ≈ 18.7 x 0.25/37 = 0.126 mm로 약 9배(Z = 10 mm 기준 0.068 mm, 5배) 거칠어집니다. 다중 태그 PnP는 이보다 좋을 수 있습니다(V12).

## V9. 기타 산술 검사

- 표 4 BoM: 항목 합 60.19 ✓(보고 60.19). 카메라 둘이 56.49(93.9%)이고, 3D 인쇄 몰드 1.78은 모듈마다 계상됨.
- 표 5: 보이는 태그 비율 0.85(1개 배치) / 0.73 / 0.59 / 0.57(35개 배치). 지터(병진): 1태그 0.426, 5태그 0.207, 20태그 0.015, 35태그 0.012 mm. 20태그와 35태그의 지터는 1.25배 차이지만 시뮬 SR은 68.3 대 65.9(+2.4%p, 표준편차 정보 없음). "20태그 편차 0.068 mm"는 35태그 추정이 기준이어서 독립 오차가 아닙니다(논문도 명시).
- A.2.4: 이력 비율 0.39/3 = 13.0%, 0.46/3 = 15.3%로 본문 "13%에서 15%"와 일치. 10,000회 x 1 Hz = 2.8시간. 실험 후 Coin 20회 "변화 없음", Chip 20회 중 1회 감소는 시행 수가 너무 작아 성능 유지의 근거로는 약합니다(예: 14/20 → 13/20은 p = 1.0).
- 4.2절 "1.6초 청크, 0.8초마다 재계획": Tp = 16, Ta = 8, 10 Hz → 맞음. 표 9의 시뮬 Coin·Peg는 Ta = 16(1.6초 열린 루프), 나머지는 8.

## V12. 태그 배열의 이론 정밀도 하한 (토이)

공식 설정 파일의 35개 태그 위치와 카메라 내부 파라미터로 핀홀 모델을 세우고, 모서리 잡음 0.25 px(논문의 가정과 같음, 독립 등방)에서 6자유도 자세의 Cramér–Rao 하한을 계산했습니다(렌즈 왜곡·검출 편향·가림 없음). 카메라-태그 거리 18.7 mm(태그 37 px)에서:

| 보이는 태그 | 병진 표준편차 x / y / z (mm) | 회전 x / y / z (rad) |
|---|---|---|
| 35 | 0.0016 / 0.0014 / 0.0020 | 0.00036 / 0.00031 / 0.00011 |
| 20 | 0.0021 / 0.0019 / 0.0028 | 0.00050 / 0.00042 / 0.00015 |
| 5 | 0.0051 / 0.0044 / 0.0093 | 0.0015 / 0.0013 / 0.00035 |
| 1 (중앙) | 0.0096 / 0.0096 / 0.089 | 0.126 / 0.127 / 0.0048 |

- 논문의 Δl_min 0.0135 mm와 Δθ_min 0.0136 rad는 35태그 하한(병진 약 0.002 mm, 회전 약 0.0004 rad)보다 병진은 7–10배, 회전은 38–120배 큽니다. 논문의 값은 단일 태그 폭만 쓴 보수적 계산이고, 태그를 하나만 쓰면 z는 0.089 mm로 횡방향보다 9배 거칩니다(K7).
- 표 5의 측정 지터(35태그 0.012 mm, 0.109° = 0.0019 rad)는 이 하한의 약 7배입니다. 지터가 표준편차라면 유효 모서리 잡음은 0.25 px보다 큰 약 1.8 px에 해당합니다(지터 정의가 본문에 없어 가정).
- 그러므로 최소 검출 변위 0.0135 mm는 이상적 하한의 7배이고 측정 지터와 같은 자릿수입니다. 보통 쓰는 3σ 검출 기준으로 읽으면 측정 지터 기준 약 0.036 mm가 됩니다(가정).
