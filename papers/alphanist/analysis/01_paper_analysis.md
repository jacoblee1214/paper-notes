## 1. Abstract (한 줄 요약과 주장)

**한 줄 요약:** NIST Assembly Task Board #1의 조립 과제 20개(너트 체결, 기어 끼우기, 막대·페그 삽입, 커넥터)를 Franka 팔 하나와 평행 그리퍼로, **이진 성공 보상 하나와 PPO 정책 하나**로 시뮬레이션에서 학습합니다. 시연, 진행도 보상, 스크립트 동작, 과제별 조정 없이 학습 성공률 98.2%를 보고합니다.

논문이 내세우는 기여는 세 가지입니다(Sec. I).

1. 다중 과제 RL 틀을 제시합니다. 구성 요소는 (A) 이질적인 조립 쌍에 걸친 reset 상태 cache(OmniReset[10]), (B) cache 안에서의 success-guided sampling(SGS[7]), (C) 공통 이진 과제 보상, (D) 다중 GPU 대규모 학습입니다.
2. NIST ATB1의 20개 과제를 모두 푸는 최초의 다중 과제 RL 정책이라고 주장합니다. 점군을 입력으로 받고, 부품 초기 자세를 넓게(뒤집힌 상태 포함) 뽑습니다. 분리 학습한 전문가 정책보다 성공률이 높아 **긍정적 전이**가 있다고 합니다.
3. 조립 쌍 최대 10개를 순서 지정 없이 한 episode에서 이어서 푸는 최초의 조립 정책이라고 주장합니다. 계층 구조나 과제 분해 없이 순서 정하기 행동이 나온다는 것입니다.

## 2. Method

### 2.1 전체 구조 (Sec. IV, Algorithm 1)

```
reset bank D = {(e_i, s̄_i)}   e: 조립 쌍(20종), s̄: 로봇·보드·부품 상태      (Eq. 3)
   reset 종류: 놓인 부품 · 집기 · 운반 · 끼우기 직전 · 부분 조립 (OmniReset[10] 방식, Fig. 4)
        │  항목별 최근 L개 결과의 성공률 p̂_i
        ▼
Beta 샘플링: q_i ∝ ε_q + √(p̂_i (1 − p̂_i))   (Eq. 4)   ← SGS[7]
        │  병렬 환경마다 (e, s₀) 배정, 과제 ID는 관측에 없음
        ▼
공유 정책 π_θ(a | o): 부품·짝 형상·로봇 표면 점군 + 고유감각 → Δq(7) + 그리퍼(1), 25 Hz
        │  표준 PPO, actor·critic 분리 SimBa 망(Fig. 3)
        ▼
보상 r = 1[d_asm < 1 mm] − c(‖a‖² + ‖q̇‖² + ‖τ‖²)   성공 시 1을 한 번 주고 종료   (Eq. 5–6)
```

### 2.2 문제 설정 (Sec. III, Eq. 1–2)

20개 조립 과제를 공유 정책 하나의 유한 horizon MDP로 둡니다. 각 episode 시작에 (과제 e, 초기 상태 s₀) ∼ ρ를 뽑고, 정책은 부분 관측 o_t만 봅니다. 과제 차이는 **이산 과제 ID가 아니라 표면 점군**으로만 드러납니다(Sec. III-A).

### 2.3 Reset bank (Sec. IV-B, Eq. 3)

OmniReset[10]의 다양한 reset을 이질적 조립에 맞게 바꿔, 각 reset 상태에 조립 정체(e_i)를 함께 저장합니다. bank는 놓인 부품, 집기, 운반, 끼우기 직전, 부분 조립 상태를 포함합니다(Fig. 4). 논문은 "이 reset 종류는 학습 분포의 영역일 뿐 정해진 순서가 아니며, 정책은 단계 식별자를 받지 않는다"고 강조합니다. bank 크기 M과 종류별 비율은 적혀 있지 않습니다.

### 2.4 Beta 샘플링 (Sec. IV-B, Eq. 4)

항목 i의 최근 L개 episode 성공률을 p̂_i라 할 때, 다음 확률로 고릅니다.

```
q_i ∝ ε_q + √(p̂_i (1 − p̂_i))
```

√(p(1−p))는 베르누이 표준편차입니다. 성공률이 중간인 항목을 자주 뽑고, ε_q > 0으로 모든 항목이 계속 뽑힐 수 있게 합니다. 균등 샘플링 비교군은 q_i = 1/M으로 두고 나머지를 그대로 둡니다. **ε_q와 L 값은 적혀 있지 않습니다.**

논문은 "SGS의 샘플링 규칙을 유지한다"(Sec. II-A)고 씁니다. 하지만 SGS 원 논문의 조작 설정(κ = 1, t = 0.5, ε = 1e-4, 온도 T = 2)을 풀면 q ∝ (p(1−p))^¼입니다. 식 4의 지수 ½과 다르고, 이 차이 때문에 학습 후반에 표본이 배분되는 방식이 크게 달라집니다(`03` §1).

### 2.5 보상 (Sec. IV-C, Eq. 5–7)

- **이진 과제 보상(Eq. 5):** 부품의 현재 상대 자세와 완전 조립 자세 사이 거리 d_asm이 ε = 1 mm보다 작으면 1, 아니면 0입니다. 성공 보상은 한 번만 주고 episode를 끝냅니다. 진행 중에는 과제 보상이 없습니다.
- **제어 비용(Eq. 6):** −c(‖a_t‖² + ‖q̇_t‖² + ‖τ_t‖²)이고, c는 과제 공통입니다. c 값은 적혀 있지 않습니다.
- **종료:** 조립 성공, horizon T, 또는 팔 관절이 하드웨어 속도·토크 한계를 넘을 때입니다. 다중 부품 episode에서는 모든 활성 쌍이 조립되어야 성공 보상이 나옵니다.
- **dense 비교군(Eq. 7):** r + c₂ r_reach + c₃ r_align이고, c₂ = c₃ = 0.01은 "OmniReset의 계수와 같다"고 합니다. r_reach는 엔드이펙터가 부품 중심에 가까울수록, r_align은 목표 조립 방향에 맞을수록 커집니다. 함수 꼴은 적혀 있지 않습니다.

### 2.6 정책과 제어 (Sec. IV-D, Fig. 3)

- actor와 critic은 같은 구조에 파라미터만 따로 둔 SimBa[28] 망입니다. 점군 인코더(3 × n_pts → 256 → 128, ELU)와 고유감각 150차원(running normalization)을 이어 278차원을 만들고, 폭 256·확장 1024의 residual block 2개를 지납니다.
- 150은 [자세 7, twist 6, 관절 9, 직전 행동 8] = 30의 5배라, 고유감각 5프레임 이력으로 보입니다(가설, `03` §6).
- 로봇은 식별된 관성·구동계를 쓴 7-DoF Franka와 평행 그리퍼(구동 손가락 1 + 수동 결합 손가락 1)입니다. 25 Hz로 관절 위치 상대 목표 Δq(7)와 그리퍼 명령(1)을 냅니다. libfranka 강성·감쇠의 implicit impedance 제어기를 쓰고, 속도 한계는 2.175 / 2.61 rad/s, 토크 한계는 87 / 12 N·m입니다.

### 2.7 분산 학습 (Sec. IV-E)

동기식 PPO를 1K–256K 환경으로 늘리고, 다중 GPU에서는 GPU당 4K 환경을 둡니다. iteration마다 환경당 32 step을 모으고, 5 epoch × minibatch 4개로 최적화합니다. 이 세 값은 OmniReset 공개 설정(`rsl_rl_cfg.py`: 32 step, 5 epoch, minibatch 4, γ = 0.99, λ = 0.95, lr 1e-4)과 같습니다. 그래서 AlphaNIST도 나머지 PPO 값을 OmniReset에서 가져왔을 가능성이 있지만, 논문에는 없습니다.

**논문에 없는 설정값:** γ, λ, 학습률, clip, entropy 계수, c, ε_q, L, M, n_pts, horizon T(본문 "15초"에서 375 step으로 추정), reset 종류별 비율, GPU 종류.

## 3. Experiments

### 3.1 설정 (Sec. V)

- **질문:** (Q1) 이진 보상에서 공동 학습과 과제별 분리 학습의 비교, (Q2) 병렬 경험과 reset 샘플링의 영향, (Q3) 이진 보상과 dense 진행도 보상의 비교입니다. 다중 부품 조립과 창발 행동은 추가 관찰입니다.
- **이질성 비교:** 공유 정책 하나와 과제별 정책 20개를 비교합니다. "실행당 상호작용 예산을 맞추고 나머지는 같게" 했고, 실행마다 64K 환경입니다.
- **규모 평가(Fig. 7):** GPU 수, 환경 수, rollout 배치를 함께 늘리고, 25K iteration checkpoint를 평가합니다. 평가는 확률적 행동으로 하고, 공통 고정 혼합 reset bank에서 과제 안 균등 샘플링으로 시작합니다. 시드 5개 × 과제당 32회 × 과제 20개 = 점마다 3,200회입니다.
- **성공 판정:** 15초 안에 완전 조립하고 안전 위반이 없어야 합니다. "모든 실험에서 성공률은 모든 reset 구성을 포함한다"(Sec. V)고 적혀 있습니다.

### 3.2 Q1: 이질적 조립 쌍의 공동 학습 (Fig. 5, Fig. 6)

| 조건 (64K env) | 논문 값 (Fig. 5b) | 그림 6 판독: 25K | 그림 6 판독: 50K |
|---|---|---|---|
| 공유 정책, sparse | 98.2 ± 0.986% | 98.3 | 99.9 |
| 분리 20개, sparse | 81.4 ± 1.732% | 81.4 | 88.1 |
| 공유 정책, dense | 17.8 ± 0.010% | 17.9 | 18.2 |
| 분리 20개, dense | 78.3 ± 0.573% | 70.9 | 78.3 |

판독은 `analysis/fig_digitize.py`로 했습니다. 그림 5(a) heatmap 80칸을 색 막대로 역산한 행 평균(99.9 / 81.9 / 17.1 / 79.0)과, 본문의 칸 값(분리 dense M4 45.0%, 중간 기어 93.6%)이 ±0.7%p 안에서 재현되어 판독 정확도를 확인했습니다.

해석 (재계산은 `04` C1–C6):

- **공유 정책의 우위는 판독으로도 확인됩니다.** 같은 25K에서 98.3% 대 81.4%이고, 분리 정책은 50K까지 돌려도 88.1%입니다.
- **그림 5(b)는 checkpoint가 섞여 있습니다.** 캡션은 "25k iterations"인데, 분리 dense 막대 78.3%는 그림 6의 50K 값입니다(25K에서는 70.9%). 본문도 "최종 checkpoint에서 78.3%"라고 씁니다.
- **"39.3배"는 iteration 수가 다른 비교입니다.** 분리 정책 20개의 총 16.1K GPU-h를 나누면 정책 하나당 805 GPU-h로, 공유 정책(410 GPU-h, 25K iteration)의 1.96배입니다. 분리 정책이 50K까지 돈 비용으로 보입니다. 같은 25K 기준이면 약 20배이고, 이때 분리 정책 성공률은 81.4%입니다(가설: 비용이 iteration에 비례).
- **분리 정책의 실패는 몇 과제에 몰려 있습니다.** 판독값으로 분리 sparse에서 60% 미만인 칸은 N4 50.0, R4 51.7, P4 31.3, RJ 56.9이고, 나머지 16개 과제의 평균은 90.4%입니다. 같은 칸에서 공유 정책은 99.4–100입니다.
- **본문의 "0.3% 이하"와 heatmap이 다릅니다.** 본문은 분리 정책이 M4 너트, 4 mm 페그, 막대 삽입에서 0.3% 이하라고 쓰지만(Sec. V-A), heatmap의 해당 칸은 50%, 31%, 52%입니다. 본문 문장은 "무작위 초기 상태에서"라는 조건이 붙어 있으므로, heatmap은 쉬운 reset(손에 쥔 상태, 끼우기 직전, 부분 조립)이 섞인 평균으로 읽힙니다. 그렇다면 이 과제들의 bank에서 그런 쉬운 시작점이 30–50%를 차지하고, 98.2%라는 헤드라인도 같은 혼합 분포의 평균입니다(`03` §3).
- **dense 보상은 분리 학습에서는 통합니다.** 분리 dense 정책은 M4 너트에서 45%로, 분리 sparse의 무작위 초기 상태 성공률(0.3% 이하)보다 오히려 낫습니다. dense의 실패는 공유 학습에서만 극적입니다(17.8%). 논문의 해석은 "dense 항이 형상마다 다른 부분 해를 선호한다"는 것입니다.

### 3.3 Q2: 병렬 경험과 샘플링 (Fig. 7)

| 조건 | 1K | 4K | 8K | 256K |
|---|---|---|---|---|
| sparse + Beta | 38.6 | 78.9 | 86.9 | 97.4 |
| sparse + 균등 | 약 35 | 약 48 | 약 79 | 84.3 |
| dense + Beta | 약 12 | 11.8–12.0 | 약 12 | 77.4 |
| dense + 균등 | 약 12 | 약 12 | 약 12 | 34.3 |

"약"은 그림에서 눈으로 읽은 값(±1)이고, 나머지는 본문 값입니다.

- **Beta와 균등의 차이는 평가 잡음보다 훨씬 큽니다.** 256K에서 13.1%p 차이인데, 3,200회 기준 이항 표준오차는 0.3–0.6%p입니다. 다만 SD는 평가 시드 5개의 것이고, 학습 시드는 설정마다 하나로 보입니다.
- **계산량이 고정된 비교가 아닙니다.** iteration은 25K로 고정하고 환경 수를 1K에서 256K로 늘리므로, 오른쪽 끝은 env step이 256배(2.05×10¹¹)이고 GPU가 64장입니다(`04` C8). "sparse 보상이 규모에서 이득을 본다"는 결론은 맞지만, 같은 계산량에서 무엇이 나은지는 이 그림으로 알 수 없습니다.
- **dense는 64K까지 12% 근처에 머물다가 128K 이후 오릅니다.** 256K에서는 Beta와 함께 77.4%에 이릅니다. 즉 dense도 규모가 충분하면 학습되며, 이진 보상이 우월한 폭은 규모가 커질수록 줄어듭니다(64K에서 약 84%p, 256K에서 20%p).

### 3.4 Q3: 보상 형식

"모든 규모에서 이진 과제 목표가 평가한 dense shaping보다 낫다"(Sec. VII)는 결론은 Fig. 7의 비교에서 나옵니다. 다만 dense 비교군의 구조를 따져 볼 필요가 있습니다. 이 비교군은 OmniReset의 dense 보상을 그대로 쓴 것이 아니라, OmniReset의 보조 계수(0.01)를 "성공하면 1을 한 번 주고 종료"하는 AlphaNIST 구조에 붙인 것입니다.

OmniReset 구현은 성공 상태에 머무는 동안 매 step 성공 보상을 주고, 성공으로는 종료하지 않습니다(`04` C14). 반면 매 step 양의 보조 보상이 있고 성공 시 종료하면, s/(1−γ) > R일 때 **완료를 horizon 끝까지 미루는 것이 최적**이 됩니다. toy에서 γ = 0.99, s ≈ 0.02, R = 1이 이 조건에 해당했습니다(`03` §2). 이 유인이 실제 학습에서 얼마나 작용했는지는 보조 항의 꼴과 γ가 논문에 없어서 판단할 수 없습니다. 하지만 "이진 > dense"라는 결론은 **이 dense 변형에 한정**해서 읽어야 합니다.

### 3.5 창발 행동과 다중 부품 조립 (Fig. 8, Fig. 9, Table I)

- **단기 전략(Fig. 8):** 보드 접촉으로 커넥터 돌리기, 내려놓고 다시 잡기, 페그를 끝 쪽으로 다시 잡기, 옆에서 감싸 기어 세우기, 너트 굴려 눕히기, 한쪽 손끝 두드림으로 M4 너트 나사산 진행, 막대 밀어서 집기 쉬운 곳으로 옮기기, 그리퍼가 너트 둘레를 돌며 M16 체결.

## 4. Limitations

### 4.1 저자가 밝힌 한계 (Sec. VI)
모든 결과가 시뮬레이션입니다. 하드웨어에 맞춘 속도·토크 한계는 지키지만, 인식 오차, 지연, 접촉 모델 불일치에 대한 강건성은 확인하지 않았습니다. 실제 보드에서 센서 관측과 접촉·지연 랜덤화로 평가할 예정입니다. 10개 정책을 이어 쓰면 보드 전체를 풀 수 있겠지만, 20개 다중 부품으로 넓히는 것은 과제로 남았습니다.

### 4.2 분석하면서 추가로 발견한 한계와 의문점
1. **헤드라인 98.2%는 reset 혼합 분포의 평균입니다.** 분리 정책이 무작위 초기 상태에서 0.3% 이하인 과제도 heatmap에서는 31–52%로 나오므로, 쉬운 reset이 상당한 비중을 차지합니다(§3.2). 논문은 공유 정책의 **reset 종류별 성공률**(특히 테이블에 놓인 부품에서 시작하는 경우)을 보고하지 않습니다. 반면 독립 MuJoCo 구현은 이 값을 보고합니다(놓인 부품 98.1%, 끼우기 직전 98.7% 등, `02` §5).
2. **그림 5(b)는 checkpoint가 섞여 있고, 39.3배는 iteration 수가 다른 비교입니다**(§3.2, `04` C2–C3).
3. **dense 비교군은 OmniReset의 보상 구조와 다릅니다.** 성공 시 종료하는 구조에 매 step 양의 보조 보상을 붙이면 완료를 미룰 유인이 생깁니다(§3.4, `03` §2). "이진이 dense보다 낫다"는 일반 결론의 근거로는 약합니다.
4. **SGS를 정확히 옮겼는지 불분명합니다.** 식 4의 지수(½)는 SGS 원 설정(¼)과 다르고, ε_q·L·M이 없어 샘플러 동작을 정할 수 없습니다(`03` §1). 또 본문은 SGS가 "작업별 보조 파지·그리퍼 shaping을 유지한다"(Sec. II-C)고 쓰지만, SGS v1 부록 A.3.2의 조작 보상은 성공·실패·행동 정규화 항뿐입니다(`04` C13). SGS는 Reaching 초기 분포에서 평가하므로(SGS Table 6), AlphaNIST의 혼합 분포 성공률과 바로 비교할 수 없습니다.
5. **학습 시드 반복이 없습니다.** 그림 5와 7의 ±는 평가 시드의 표준편차입니다. "17.8 ± 0.010%"는 시드당 1,460만 회가 필요한 값이라 단위 오기(1.0%)로 보입니다(`04` C6).
6. **그림 7은 계산량을 맞춘 비교가 아닙니다**(§3.3).
7. **관측은 시뮬레이터의 정답입니다.** 점군은 알려진 메쉬를 참 자세에 놓고 표면에서 뽑은 것이라, 사실상 완벽한 자세 추정과 형상 정보를 줍니다. "자세 추정 대신 점군"(Sec. I)이라는 장점은 실제 센서로 옮길 때 다시 검증해야 합니다.
8. **재현 정보가 부족합니다.** 코드가 공개되지 않았고, §2.7의 설정값과 reset bank 구성이 없습니다. 64K 환경 실행 하나가 16 GPU × 약 26시간(410 GPU-h)이고, GPU 종류는 적혀 있지 않습니다.
