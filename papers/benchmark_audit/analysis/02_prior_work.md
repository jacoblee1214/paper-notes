# 02. 선행연구, 가까운 대안, 관련 분석

## 1. 계보: 네 실패 양식은 어디서 왔나

논문의 네 진단은 새로운 발상이라기보다, 컴퓨터 비전과 NLP 벤치마크 감사를 조작 벤치마크에 옮긴 것입니다(§2.1). 계보를 양식별로 정리하면 다음과 같습니다.

| 양식 | 원 연구 | 핵심 결과 | 논문에서의 역할 |
|---|---|---|---|
| 지름길 | Goyal 외 [7] (VQA v2) | "Do you see a…"에 언어 편향만으로 87% | 무언어 프로브의 근거 |
| 지름길 | Lapuschkin 외 [8] (Clever Hans) | 저작권 태그로 "말" 예측 | 같은 방향 |
| 유의성 | Everingham 외 [9] (PASCAL VOC) | Friedman/Nemenyi로 상위 6개 차이 없음 | 집계 검정의 선례 |
| 유의성 | Musgrave 외 [10] | 개선 주장이 공정 비교에서 사라짐 | 주장 감사의 선례 |
| 과적합 | Torralba·Efros [1] | 데이터셋 간 전이가 나쁨(평균 정확도 약 50% 하락) | 누적 과적합의 출발 |
| 과적합 | Recht 외 [12] (ImageNet v2) | 새 테스트 세트에서 순위가 대체로 유지 | 표본 과적합 검사 설계 |
| 과적합 | Hendrycks·Dietterich [13] (CIFAR-C) | 손상 입력에서 정확도 급락 | 분포 과적합 검사 설계 |
| 데이터 출처 | Barz·Denzler [14] (CIFAR 중복) | 테스트 근접 이미지가 있음 | 학습-테스트 근접 |
| 데이터 출처 | Lewis 외 [16] (QA 중복) | 테스트 질문의 대부분이 학습에 답이 있음 | 같은 방향 |

이 계보에서 중요한 점은 두 가지입니다. 첫째, 과적합 검사는 "테스트 세트를 새로 만든다"(Recht)와 "테스트 분포를 흔든다"(Hendrycks)로 나뉜다는 것입니다. 논문은 둘 다 로봇에 적용합니다. 둘째, 유의성 검사는 사후 순위 검정이었는데, 논문은 집계 점수만으로 판정 가능 범위를 정하는 쪽으로 옮겼습니다.

## 2. 가까운 대안과 보완 방법

- **LIBERO-PRO [17], LIBERO-Plus [18].** LIBERO 장면과 지시문을 바꿔 점수 하락을 보입니다. 논문은 이 하락이 학습 분포 밖이라 약한 일반화일 수 있다고 봅니다. 논문의 진단은 입력을 학습 분포 안에 두어 과적합만 재려 합니다(§2.2).
- **항목 반응 이론(IRT)과 적응형 평가 [46–49].** 논문 §7은 고정 집단 평균을 버리고, 정책 능력과 과제 난이도를 함께 추정하는 방향을 제안합니다. 과적합, 데이터 출처, 검정력 문제를 한꺼번에 다룰 수 있다고 봅니다. 우리 저장소의 평가 설계 분석(`03` §4, 토이 1)은 같은 문제를 쌍 설계로 풉니다.
- **쌍체 평가 설계.** 논문 §7은 "개별 시도 결과를 공개하면 누구나 쌍체 검정을 돌릴 수 있다"고 권합니다. 공식 저장소는 LIBERO Goal 다섯 정책의 시도별 결과를 공개해 이 주장을 실제로 검증할 수 있게 했습니다(`03` §1.4).
- **동급 연구의 평가 감사.** 데이터셋 중복과 누출 감사는 NLP와 CV에 많지만, 로봇 조작에서 같은 목적의 공개 감사는 드뭅니다. 이 논문의 데이터 출처 진단은 시뮬레이션 격자에 맞춘 학습 데이터 수집이라는 점에서 새롭습니다.
