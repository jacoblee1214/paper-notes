## 4. 구현 가능성 판정

**이 맥(Apple M4 Pro, 약 24 GiB 통합 메모리, MPS, CUDA 없음)과 저장소 기준으로 나눠 씁니다.**

| 대상 | 판정 | 이유 | 노력 (추정) |
|---|---|---|---|
| **NEXT 추정기 (학습과 추론)** | **구현 가능 (조건부)**: 자유 운동 H5 데이터가 있어야 함 | 모델은 약 24만 파라미터이고 추론 0.83 ms로 CPU에서 충분합니다(§03 §6). 학습은 CPU로 가능합니다(추정: 1분이 아니라 수 분). 저장소의 `dataset.py`, `models.py`, `train.py`는 ROS 없이 쓸 수 있다고 README에 나와 있습니다. 데이터는 저가 팔에서 10분 기록이 필요합니다 | 재구현 반나절 (학습 루프 포함). 데이터 수집 10분 + 검증 |

**재구현 노력 합계 (추정):** NEXT 2일 이내, FIRST 1–2일, 정책 학습 포함 전체 재현 2–4주 (GPU 시간 별도).
