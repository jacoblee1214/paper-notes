## 1. 문제와 주장

대규모 로봇 데모는 비싸고 느리게 모입니다. 저자들은 **사람이 맨손으로 하는 작업을 Project Aria 안경으로 찍은 1인칭 영상과 3D 손 추적**을 로봇 데모와 같은 학습 데이터로 씁니다. 핵심 주장은 다음 세 가지입니다 (§1 Abstract, §I Introduction, §IV 가설 H1–H3).

| 가설 | 내용 |
|---|---|
| H1 | 사람 데이터는 장기 과제 성능을 높인다 (Table III) |
| H2 | 사람 데이터는 새 물체와 새 장면으로의 일반화를 돕는다 (Fig. 7) |
| H3 | 같은 시간이면 사람 데이터 1시간이 로봇 데이터 1시간보다 가치가 크다 (Fig. 8) |

Introduction은 기존 연구(Mimicplay 등)가 사람 영상에서 **고수준 의도**만 뽑아 저수준 정책이 로봇 데이터로 학습되는 한계를 지적합니다. 이 논문은 사람과 로봇 데이터를 **같은 행동 공간에 맞춰 한 정책으로 함께 학습**하는 것을 제안합니다.

## 2. 방법

### 2.1 데이터 수집 (§III-A, 부록 B)

- **사람:** Project Aria 안경으로 RGB, SLAM 카메라, 3D 손 추적을 얻고, Aria MPS(클라우드 SLAM과 손 추적)로 장치 포즈를 얻습니다.
- **로봇 "Eve":** 두 개의 ViperX 300 S 6자유도 팔, 손목 카메라(Intel RealSense D405), 거꾸로 달린 "상체" 구조. 부품비 1,000달러 미만(팔 제외), 리더 팔은 WidowX.
- **핵심 설계:** 로봇 머리에도 **같은 Aria 안경**을 달아 카메라 차이(FOV, 동적 범위)를 줄입니다 (§III-A, Fig. 2).

### 2.2 행동 정렬 (§III-B, 부록 A)

- **카메라 기준 좌표계:** 사람 데이터는 MPS SLAM 포즈로 손 궤적을 현재 카메라 좌표계로 옮깁니다 (식 `H p^a_i = [(T_t)^-1 T_i p_i]`). 로봇은 손-눈 보정으로 같은 방식을 씁니다.
- **속도 정렬:** 사람은 로봇보다 빨라서 사람 데이터를 **4배 느리게** 맞춥니다 (부록 A). 로봇 행동은 4초 구간, 사람은 1초 구간을 씁니다. 두 쪽 모두 **청크 길이 100**으로 맞춥니다.
- **Z-score 정규화:** 사람과 로봇의 손·말단 포즈와 행동을 **각각** 평균과 표준편차로 정규화합니다 (식 `norm(p) = (p − μ)/σ`, §III-B, Fig. 3a, 부록 A). 이 방식은 Gaussian 정규화입니다.
- **시각 마스킹:** SAM2로 사람 손과 로봇 팔을 가리고, 그 위에 빨간 선을 그립니다 (Fig. 3b, 부록 A).

### 2.3 정책 (§III-C, 부록 C–D, Fig. 4, Alg. 1)

- **구조:** ACT(CVAE 인코더 4층, 디코더 7층, hidden 512) 위에 얹은 공유 트랜스포머. 입력은 정규화된 proprio 토큰, ResNet-18 시각 토큰, CVAE 스타일 토큰입니다. 로봇 데이터에서만 손목 카메라 토큰이 추가됩니다.
- **출력:** 얕은 두 헤드. 포즈 헤드(사람과 로봇 공유)와 관절 헤드(로봇 전용). 관절 행동은 로봇 제어에 씁니다. 포즈 행동은 두 데이터 모두에 감독을 줍니다.
- **손실 (논문 부록 D):** `L_robot = L1(R p̂, R p) + L1(R q̂, R q) + KL`, `L_hand = L1(H p̂, H p) + KL`, `L = L_robot + L_hand`.
- **불일치 (논문 내부):** Alg. 1은 MSE를 쓰지만 본문과 부록 D는 L1을 씁니다. 코드는 L1입니다 (`04` D1).

### 2.4 구현 세부 (부록 D, Table V)

| 항목 | 논문 값 (Table V, §D) |
|---|---|
| 배치 | 전체 128 (4대 A40) |
| 반복 | 120,000 |
| 학습 시간 | 약 24시간 |
| 옵티마이저 | AdamW, 초기 학습률 5e-5, 선형 스케줄 |
| 증강 | Color jitter |
| 추론 | 1 Hz 추론, 25 Hz 제어 (RTX 4090 데스크톱), 행동 지평 4초 중 첫 1초 실행 |
| 기록 주파수 | 사람 30 Hz, 로봇 50 Hz (Table VII) |

### 4.3 일반화와 확장 (Fig. 7, Fig. 8)

- 새 색깔 셔츠: ACT 25% SR, EgoMimic 85% SR (Fig. 7a). 시행 수는 본문에 없습니다.
- 새 장면 Object-in-Bowl: EgoMimic 63점 (로봇 데이터 없이 사람 데이터만으로), Mimicplay 4점 (Fig. 7b). 시행 수 없음.
- 확장: EgoMimic (로봇 2시간 + 사람 1시간) 128점, ACT (로봇 3시간) 74점 (Fig. 8). 시행 수 없음.

## 5. 한계 (논문이 스스로 밝힌 것)

- **단일 과제 정책:** 목표 조건부 정책이 아닙니다.
- **결론의 범위:** 한 로봇 (Eve)과 세 과제에서만 검증했습니다. 새 로봇이나 새로운 행동(바지 접기 등)은 future work입니다 (§V).
- **사람 데이터의 빈 칸:** Aria는 손 포즈만 기록하므로 **파지(grasp) 행동은 사람 데이터에 없습니다.** 로봇 파지는 로봇 데이터의 관절 감독에서만 옵니다 (부록 D).
- **반복 실험 없음:** 시드나 반복 실험 결과가 없고, 평가 시행 수는 과제마다 40–50회입니다.
- **통계 검정 없음:** 신뢰구간과 검정을 보고하지 않습니다 (`03` 에서 재계산).

## 6. 논문 내부의 확인할 곳

1. **손실 함수:** Alg. 1 MSE vs 본문·부록 D L1 (`04` D1).
2. **배치와 반복:** 본문 Table V와 부록 D (128, 120k) vs 공식 설정 파일 (16, `num_epochs` 10000). (`04` D3)
