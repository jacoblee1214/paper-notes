## 1. 한 문단 요약

접촉이 많은 **입자·변형체**(모래 삽질, 반죽 밀기, 모래 긁기)를 시뮬레이션하지 않고, **도구의 강체 6D 포즈 궤적**만 추종하는 정책을 학습합니다. 궤적은 도메인 파라미터 c(삽 각도, 삽입 거리, 속도 등)로 절차적으로 생성되고(§III-A), 정책 π(p; o; c)는 c를 입력으로 받아 c를 무작위로 바꿔 가며 학습합니다(§III). 학습 뒤에는 c를 **탐색**해(Genesis 시뮬레이터, 무작위 탐색) 과제 지표가 가장 높은 c를 고르고, 그 c로 실로봇에 zero-shot 전이합니다(§IV-B, §V-B). 이 설정에서 "최선 c"는 평균 c보다 1.5–3.8배 높다고 주장합니다(초록, 표 IV, 그림 3).

## 2. 방법 (§III)

**2.1 도메인 파라미터와 절차적 궤적 (§III-A, 부록 A.1).** 궤적 T(c; t) = {g_t, j_t}는 물체의 6D 포즈 g_t ∈ SE(3)과 관절값 j_t로 정의됩니다. 모래 삽질의 c = {α, d, v_i, v_l}은 삽입 각도, 삽입 거리, 삽입 속도, 들기 속도입니다(§III-A, 그림 2). 과제마다 파라미터가 다릅니다(부록 A.1: 삽질, 반죽 밀기, 긁기, 마우스 휠, 디스펜서, 스프레이). 각 과제의 파라미터 **범위는 본문에 없습니다.**

**2.2 접촉 궤적.** 매 제어 스텝마다 물체 링크와 손 링크 사이의 접촉 쌍과 접촉 위치를 명시합니다(§III-A). 접촉 보상(r_contact)과 접촉 지시 함수가 여기에 쓰입니다. 반죽 밀기에서는 접촉 쌍이 손끝에서 관절로 바뀌도록 설계합니다(§III-A).

**2.3 강화학습 설정 (§III-B).** 두 단계 MDP입니다. 운반 단계(무한 지평)는 물체를 목표 영역으로 옮기고 첫 스텝의 접촉 상태를 맞추는 것이 목표입니다. 추종 단계(유한 지평)는 궤적의 매 스텝을 추종합니다. 보상은 r_contact, r_reach, r_pose,c = exp(−β_c·d)·1_contact, 추종 단계의 r_pose,f(더 큰 β_f), 관절 보상 r_joint = exp(−β_joint·|θ−j_t|)·1_contact, 고정 보너스 r_step입니다. 계수 β_c, β_f, β_joint, r_step의 **값은 논문에 없습니다.** 궤적 길이가 도메인마다 달라 환경은 끝 스텝에 비동기로 리셋됩니다(§III-B).

**2.4 교사 학습 (§III-C).** 상태 기반 교사 π(s; c)는 로봇 상태, 물체 포즈, 단계 인덱스, 현재 목표 포즈, 도메인 파라미터 c를 입력받습니다. 행동은 손목 6D 델타 포즈와 XHand1 관절 12개의 절대 목표입니다. IK로 Franka R3의 7자유도 관절에 옮깁니다. PD 제어기의 Kp는 낮게 두고, 실로봇 궤적과 맞추도록 Kd를 보정합니다(§III-C, 부록 B). PPO와 비대칭 critic을 씁니다. 시연 10–20개를 [35](DexPilot)로 수집해 학습 초기에 행동 복제 목표를 더하고, 그 비율을 수백 에포크에 걸쳐 줄입니다(§III-C). 도메인 무작위화는 19개 관절의 PD 이득, 물체 질량·마찰·강성·감쇠, 행동 잡음, 말단 장치와 도구 질량 중심의 임의 힘으로 구성됩니다(§III-C, 부록 B, 표 V).

**2.5 증류와 추론 (§III-D).** DAgger [38]로 교사를 시각 정책 π(p; o; c)로 증류합니다. 입력은 로봇 상태, 말단 포즈, 델타 포즈, 손 관절값, 포인트 클라우드 1024점(작업 공간 안, 로봇 기준 좌표)입니다. 인코더는 PointNet++ [39]이고, 포인트 클라우드에 흔들림 잡음과 드롭아웃(0.4)을 넣어 실센서와의 차이를 줄입니다(§III-D, 표 V). 추론 때는 c를 자유롭게 고르며, 논문은 **무작위 탐색으로 과제 지표가 최대인 c를 찾는다**고 씁니다(§III-D).

## 3. 실험 (§IV, §V)

**3.1 시뮬레이션 (IsaacLab 학습, Genesis 평가; §IV-A).** 학습은 강체 IsaacLab에서 하고, 평가는 MPM 입자와 강체의 결합을 쓰는 Genesis로 합니다(§IV-A). 평가 대상은 "Genesis Avg"(무작위로 뽑은 c 전체 평균)와 "Genesis Best"(지표 최대 c)입니다(§IV-B). 에피소드 수는 "multiple episodes"라고만 씁니다.

| 표 | 내용 | 주요 값 |
|---|---|---|
| 표 I | Genesis Best 대 SimToolReal [16] | 긁기 17% 대 95%(낮을수록 좋음), 반죽 2.85 cm 대 0 cm, 삽질 13.9 g 대 9.2 g, 마우스 휠 0.37 rad 대 0.19 rad, 디스펜서 2.26k 대 0, 스프레이 9.12k 대 0 |
| 표 II | Genesis Best 도메인 조건 대 고정 도메인 | 마우스 0.37 대 0.19, 디스펜서 2.26k 대 0.96k, 삽질 13.9 대 0.32 g. 하락 48.6%, 57.5%, 97.7% |
| 표 III | 실로봇 20회 | 아래 §3.3 |
| 표 IV | 평균 대 최선, 추종 오차 포함 | 삽질 3.64 → 13.9 g, 반죽 1.55 → 2.85 cm, 긁기 33 → 17%, 마우스 0.23 → 0.37 rad, 디스펜서 0.97k → 2.26k, 스프레이 5.64k → 9.12k |

SimToolReal [16]은 "oracle"(물체 실제 포즈를 씀)이라고 표시합니다. 이 기준선에는 GPT-6이 만든 6D 궤적을 넣고, 같은 횟수만큼 반복해 **최선**을 보고합니다(§IV-B). 기준선도 최선 값을 보고하는 것입니다.

**3.2 절제 (§IV-C, 그림 4).** 시연(BC 목표)과 접촉 궤적 보상을 각각 뺐을 때 추종 오차를 그림 4로 보입니다(수치 표 없음). 고정 도메인 학습(표 II)은 지표가 "nearly more than 50%" 떨어진다고 씁니다. 마우스 휠은 48.6%이므로 이 문장과 맞지 않습니다(`03` §1.2 참조).

**3.3 실로봇 (§V-B, 표 III, 부록 A.1).** Genesis Best 파라미터 하나로 과제당 20회 시행했습니다. "Motion Success"는 안정적인 파지와 올바른 궤적, "Task Success"는 과제 지표 임계 통과입니다(임계는 부록 A.1: 삽질 4 g, 반죽 2 cm, 긁기 절반 이상 밀기, 마우스 3 단위 이상).

| 과제 | Motion | Task | 지표 (성공 시행 평균) |
|---|---|---|---|
| 삽질 | 20/20 | 14/20 | 7.7 g |
| 반죽 밀기 | 16/20 | 11/20 | 2.7 cm |
| 긁기 | 19/20 | 19/20 | 29% 남음 |
| 마우스 휠 | 19/20 | 19/20 | 0.33 rad |
| 디스펜서 | 18/20 | 14/20 | 물은 안전상 생략 |
| 스프레이 | 16/20 | 10/20 | 물은 안전상 생략 |

**3.4 정성 분석 (§V-C, 그림 5).** 삽질은 c의 평균에서 10회 시행에 평균 2.9 g, Genesis Best에서 7.7 g입니다. 반죽 밀기는 낮은 목표 속도가 더 깊은 접촉을 만듭니다. 긁기는 목표 높이가 낮을수록 모래가 덜 새어 나갑니다. 이 정성 결과는 그림으로만 있고 시행 수는 10회입니다.

## 5. 주장과 증거의 틈

- **"1.5–3.8×"의 하한 1.5는 표 IV에서 나오지 않습니다.** 최소 배율은 마우스 휠 1.61입니다(`03` §1.1).
- **"최선"은 평가 시뮬레이터 안에서 고른 값입니다.** 같은 Genesis에서 탐색하고 같은 Genesis에서 보고합니다. 탐색 단계 시드와 보고 시드가 분리되었는지 논문에 없습니다. 선택 편향이 이 배율을 얼마나 부풀리는지는 §2 토이로 간접적으로만 봅니다(`03` §2).
- **기준선이 비대칭입니다.** DAPPT는 도메인 파라미터 최선을, SimToolReal은 GPT-6 반복 최선을 씁니다. 두 방법의 탐색 예산과 GPT-6 버전과 프롬프트는 없습니다.
- **통계 정보가 없습니다.** 시드 수, 시뮬레이션 에피소드 수, 표준편차, 신뢰구간이 모두 없습니다(`03` §3).
- **실로봇에 기준선이 없습니다.** "comparable real-world task performance"(§I)는 비교 대상 없이 쓰였습니다.
- **재현에 필요한 값이 빠져 있습니다.** β 계수, r_step, Kp·Kd 값, 학습 예산, 도메인 파라미터 범위, 궤적 함수 식, GPT-6 모델명, 무작위 탐색 횟수가 없습니다(`04` §3).
- **편집 오류가 몇 개 있습니다.** 저자 소속은 "Princeton Unversity"(철자 오류, 첫 쪽). 참고문헌 [5]와 [17]은 같은 논문(Visual dexterity)이 두 번 실려 있습니다.
