# 03. 수치 재계산과 일관성 검사

재현 실험(시뮬레이션, 실로봇, API 호출)은 하지 않았습니다. 모든 계산은 논문과 저장소 문서에 적힌 집계 값으로 했습니다. 스크립트는 `analysis/recompute.py`(numpy, scipy), 결과는 `analysis/recompute_results.json`입니다. 검산 항목은 V1–V5로 적었습니다.

## 0. 요약

- **표의 합계와 평균은 모두 맞습니다.** 실로봇 합계(2, 54, 47), ForceBench 평균 다섯 행과 학습 기준선 여섯 행, HiddenPhys 합계 열세 행, 분포 이동 분모가 모두 일치합니다. 유일한 차이는 Dual-Path의 35.125가 35.13으로 반올림된 것입니다(반올림 방식 차이).
- **검정 주장은 대부분 맞습니다.** 실로봇 여섯 과제의 Fisher p가 모두 0.01보다 작고(최대 0.0055), ForceBench 개발 시드의 Astra 짝 McNemar p(20 대 6)는 0.0094로 논문의 0.009와 맞습니다. 보류 시드 22 대 6은 p = 0.0037로 저장소 문서의 0.004와 맞습니다.
- **"전문가와 같다"는 HiddenPhys 주장은 차이가 −0.7 pp이며 95% 구간이 [−5.6, +4.0] pp입니다.** 같은 수준이라고 말해도 좋습니다. 다만 ±5 pp 밖의 차이는 배제하지 못하는 표본 크기입니다.
- **ForceBench의 17.5 pp는 개발 시드에서 나왔습니다.** 보류 시드에서는 20.0 pp이고, 구간은 [4.8, 29.7] pp(비짝 Newcombe, 근사)입니다. 방향은 같지만 크기는 표본 10회로 정하기 어렵습니다.
- **표 6의 결정 정확도 차이는 분모를 모릅니다.** 분모에 따라 p가 0.004–0.031로 바뀌어, 방향은 맞지만 강도는 확정할 수 없습니다.

## 2. ForceBench 표 4 (V2)

**평균 재계산.** 제로샷 다섯 행(70.00, 87.50, 65.00, 87.50, 75.00)과 학습 기준선 여섯 행(23.25, 35.31, 23.31, 21.94, 6.88, 35.13)이 모두 맞습니다. Dual-Path의 35.125는 반올림 차이입니다.

**총 성공 수.** 80회 중 Astra 무힘 56, ForceHarness 70. Sol 무힘 52, ForceHarness 70. Fable 60.

| 비교 | 결과 | 방법 |
|---|---|---|
| Astra 무힘 70.0% [59.2, 78.9] | - | Wilson |
| Astra ForceHarness 87.5% [78.5, 93.1] | - | Wilson |
| 차이 +17.5 pp [4.8, 29.7] | 짝 아님 | Newcombe 근사 |

| 개발 시드 짝 McNemar (20 대 6) | p = 0.0094 | 정확 이항 (논문 0.009와 일치) |

**보류 시드 320–329 (저장소 문서와 프로젝트 페이지, 논문에는 없음).** Astra ForceHarness 66/80 [72.7, 89.3], 무힘 50/80 [51.5, 72.3]. 저장소 문서의 "73–89%, 52–72%"와 맞습니다. 짝 집계는 ForceHarness만 성공 22, 무힘만 성공 6이며 정확 McNemar p = 0.0037입니다(문서 0.004와 일치). 집계 구조도 맞습니다. ForceHarness 66 = 둘 다 44 + 22, 무힘 50 = 둘 다 44 + 6. 개발 시드도 같은 방식으로 맞습니다(70 = 50 + 20, 56 = 50 + 6).

**과제별 기여.** 보류 시드에서도 짝 차이의 대부분은 Drawer Pull(10 대 0)이고, Drawer를 빼면 12 대 6입니다(저장소 문서 p = 0.24). 본문의 "대부분 Drawer에서 나온다"는 말과 맞습니다.

**Sol의 McNemar p = 0.001은 확인할 수 없습니다.** 짝 자료가 없습니다.

**Fable.** 무힘 대조가 없어서 Fable 자체의 힘 효과는 계산할 수 없습니다. Fable 75.0% 대 Astra ForceHarness 87.5%는 비짝 Fisher로 p = 0.067입니다(단순 비교, 근거로 쓰지 말 것).

**주요 차이 (비짝, 근사. 모든 행이 같은 시드 20개를 쓰므로 짝 검정이 더 정확합니다).**
- ForceHarness 대 무힘 (Astra): +34.3 pp [25.4, 42.8], Fisher p ≈ 2 × 10⁻¹³.
- ForceHarness 대 전문가: −0.7 pp [−5.6, +4.0], p = 1.0.
- ForceHarness 대 Diffusion Policy: p ≈ 7 × 10⁻¹⁵.

**분포 이동 (네 과제, 표의 "Shift" 열).** 상대 감소는 다음과 같습니다. ## 4. 형식 비교 표 6 (V4)

표 6은 Sol 70회, 소형 모델 125회로 적혀 있습니다. 판정 정확도의 분모는 적혀 있지 않지만, 실험 설정 파일로 정할 수 있습니다. 소형 모델은 `force_form_cheap.yaml`에서 과제 5개(Weight, CoM, Wipe, Stack, Lock) × 시드 5개 × 모델 5개 = 125회이고, 판정은 이 중 Weight, CoM, Lock 세 과제이므로 **75회**입니다. Sol은 과제 7개 × 시드 10개 = 70회이고 판정은 30회입니다.

- **성공률 값의 격자성.** 모든 값이 분모 70 또는 125의 정수 비율로 반올림됩니다. 예를 들어 Sol 0.87은 61/70, 소형 0.63은 79/125에 해당합니다. 불일치는 없습니다.
- **결정 정확도, 원시 수치 대 L2 (0.69 → 0.85).** 설정에서 얻은 분모 75로 비짝 Fisher를 하면 p = 0.031입니다(125로 두면 0.004). 논문의 짝 McNemar p = 0.023은 이 범위 안에 있어서 일관됩니다. 짝 자료가 공개되지 않아 정확한 값은 확인할 수 없습니다.
- **결정 정확도, 무힘 대 원시 수치 (0.57 → 0.69).** 분모 75에서 p = 0.175(125에서는 0.067). 본문의 "유의하지 않게 올림"과 맞습니다.
- **성공률, 원시 대 L2 (0.63 → 0.70).** 비짝 Fisher p = 0.28(125). 논문도 성공률 차이를 강하게 주장하지 않습니다.
- **Sol의 무힘 대 L2 (0.63 → 0.90).** p = 0.0003(70). 이 차이는 확실합니다. 다만 그림 4의 막대 값은 본문에 텍스트로 없어서 재계산하지 못했습니다.

## 6. 통계 재현 가능성

- 저장소에는 Wilson 구간만 있습니다(`forceharness/eval/metrics.py`). 짝 McNemar와 Fisher 검정 코드가 없습니다(`grep`으로 확인). 에피소드별 결과 파일도 공개되지 않았습니다.
- 그래서 짝 검정은 공개된 집계로만 확인했습니다(개발 시드와 보류 시드의 Astra). 나머지 짝 검정(Sol, 표 5 행 사이, 표 6)은 확인할 수 없습니다.

## 7. 실행과 제외 항목

- 시뮬레이션, 실로봇, API 호출, 가중치와 데이터 다운로드는 하지 않았습니다. 데이터셋은 메타데이터(`meta/info.json` 등)만 확인했습니다.
- CPU 토이는 만들지 않았습니다. 논문의 핵심 주장(물리량 형식이 소형 모델을 돕는다)은 LLM 호출 없이는 검증할 수 없고, 토이로 바꾸면 주장과 다른 질문이 됩니다.
