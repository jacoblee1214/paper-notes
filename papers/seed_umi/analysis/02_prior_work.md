# 02. 선행연구와 관련 저장소: SEED-UMI (arXiv:2609.11753)

근거: 논문 본문과 참고문헌(§1–2, [1]–[39]), arXiv abs 페이지(2026-11-26 조회), 프로젝트 페이지 `tengbo-yu.github.io/SEED-UMI/`, GitHub API 메타데이터. 논문에 없는 계보는 "이 분석의 판단"으로 표시합니다.

## 1. 선행연구 계보

### 1.1 손 동작 수집 방식 (논문 §1의 분류)

| 방식 | 논문이 드는 예 | 논문이 말하는 한계 |
|---|---|---|
| 비전 기반 손 추적 | Kinect 추적 [6], DexPilot [7], AnyTeleop [8], DexCap [9] | 접촉 중 가림과 시간적 떨림으로 품질 저하 |
| 장갑(관성·굽힘) | 소프트 센서 장갑 [10], 힘·포즈 장갑 [11, 12], MANUS [13], DOGlove [15], 재구성 가능 장갑 [18] | 피부 움직임 잡음, 사람-로봇 관절 대응 매핑 필요 |
| 외골격 | SAFE 글러브 [14], DexUMI [19] 등 | 가장 일관된 측정이지만 착용감과 처리량이 희생됨 |

### 1.2 외골격 계열

- **UMI** [22] (Chi 외, 2024): 휴대형 그리퍼로 현장 시연을 모으고 로봇 없이 정책 학습. SEED-UMI의 이름과 "수집 장치와 배포 로봇의 관측 정렬" 철학의 뿌리입니다(이 분석의 판단. 논문은 §2에서 UMI를 장갑 계열 사이에 인용만 합니다).
- **DexUMI** [19] (Xu 외, 2025): 손 외골격에 엔코더를 달고 로봇 손에 매핑. 자유 공간에서 관절별 회귀를 맞추고 영상은 인페인팅으로 메웁니다. SEED-UMI가 직접 대비하는 대상입니다. 다른 점은 (a) 외골격을 로봇에도 낀다, (b) 매핑을 접촉 하의 짝지은 재생으로 미세조정한다, (c) 영상 변환을 쓰지 않는다입니다.
- **WHED** [24], **DexOP** [25], **MILE** [26], **DexViTac** [27] (2025–2026): 손 착용형 외골격과 시각촉각 센서를 결합하는 후속 시스템들입니다. 논문은 이들이 "외골격을 사람 쪽에만 장착하고 일회성 자유 공간 회귀로 전달한다"고 요약합니다(§2). 각 시스템의 세부는 이 분석에서 읽지 않았습니다.
- **영상 정렬:** Mirage [20](cross-painting), RoVi-Aug [21](로봇·시점 증강)이 인페인팅/생성 계열로 인용됩니다. SEED-UMI는 하드웨어 정렬로 이 단계를 생략한다고 주장합니다.

### 1.3 인코더-모터 매핑

- DexUMI [19]는 자유 공간 관절별 회귀, DexterityGen [28]은 대규모 시뮬레이션 RL 저수준 컨트롤러로 매핑합니다. SEED-UMI는 "시뮬레이션도 RL도 없이 실세계 재생으로 지도 신호를 얻는" 중간 지점이라고 위치를 정합니다(§2). 시연 증강 계열(MimicGen [33], DemoGen [34], DexMV [35] 등)과 "정신이 비슷하다"고 씁니다.

### 1.4 정책 백본

ACT [37], Diffusion Policy [38], π0.5 [39]를 그대로 씁니다. 방법의 새로움은 정책이 아니라 데이터 수집 인터페이스와 매핑입니다.

## 5. 이 분석의 판단 (논문에 없는 것)

- SEED-UMI의 새로움은 "외골격을 로봇에도 낀다"는 하드웨어 설계 결정 하나가 매핑 학습(지도), 시각 정렬(정책), 효율 세 가지에 모두 작용한다고 주장하는 데 있습니다. 각 효과를 따로 떼어 본 절제 실험은 없습니다(`04` C7, C8).
- 같은 계열의 선행 논문 DexUMI가 보고한 수집 효율 3.2배(그림 7의 막대 위 숫자 판독 값 36/11)와 SEED-UMI의 3.0배는 모두 한 세션·한 과제의 점추정입니다. 두 값을 서로 비교하는 것은 근거가 되지 못합니다.
