# 02. 선행연구

## 1. 계보

WiTac은 세 흐름이 만나는 자리에 있습니다.

1. **자기지도 촉각 표현.** 시각과 촉각을 짝지어 학습한 표현(Lee 외 2018, 주석 [12])에서 출발해, Sparsh [9]가 촉각 이미지의 자기지도 목표(접촉 복원, 변형 예측)를 정리했습니다. Sparsh-X [10]는 여러 감각으로, AnyTouch [4]는 여러 센서로 넓혔습니다. VT-MUSE [22]는 순차 시각-촉각 잠재 표현을 교차 모달 정렬과 마스크 복원으로 학습합니다. WiTac이 직접 비교하는 대상입니다.
2. **VLA에 촉각 붙이기.** GR00T [17]와 π0.5 [18]는 카메라와 언어 입력만 받습니다. 이후 방법은 촉각을 붙이는 방식이 다릅니다. SimpleTouch [25]는 촉각 토큰을 별도 전문가로, TacFiLM [15]은 FiLM으로 시각 인코더를 변조하고, ResTacVLA [30]는 예측된 촉각과의 잔차를 씁니다. 모두 **시각 특징과 촉각 특징이 정책 안에서 만난다**는 점이 공통입니다.
3. **촉각 세계 모델과 WAM.** DreamTacVLA [26], OmniVTA [33], VTAM [29], Dream-Tac [14], FAWAM [7], ForceWAM [23]은 미래 촉각이나 힘을 예측합니다. WiTac은 이들과 달리 생성 모델을 학습하지 않고, 정책 학습 때 고정할 **인코더**를 만듭니다.

다지 손(dexterous hand) 쪽에서는 FTP-1 [27], ME-Dex 1.0 [31], SaTA [11], ViTacFormer [8], STAR [13], T-Rex [16], DeCAL [5], DexTacWAM [28]이 있습니다.

## 2. 가까운 대안과 구성 요소별 출처

### 2.1 가장 가까운 대안

| 방법 | 같은 점 | 다른 점 | WiTac 논문의 비교 |
|---|---|---|---|
| **VT-MUSE** [22] | 같은 SharpaDex에서 사전학습, 같은 게이트 주입 | 촉각과 시각을 순차 잠재로 정렬, 손목 패치를 토큰으로 바꾸지 않음 | 실험에 포함(GR00T 50.0%) |
| **STAR** [13] | 손가락별 촉각 토큰, 사전학습에서 손목 패치 예측 | 촉각 토큰을 VLA에 따로 넣음(융합 없음) | 비교 없음. WiTac의 "분리 주입" 변형과 가장 가까움 |
| **SaTA** [11] | 손목 기준 손가락 포즈로 촉각 특징을 고정 (FiLM) | 손목 시각 교차 주의 없음 | WiTac이 포즈 조건화를 그대로 가져옴. 실험 비교 없음 |
| **ViTacFormer** [8] | 시각과 촉각을 교차 주의로 융합 | 자기회귀 촉각 예측 머리, 정책 내 융합 | 비교 없음 |
| **FTP-1** [27], **T-Rex** [16] | 다지 손, 촉각 정책 | 독립 촉각 정책(VLA 없음) | 실험에 포함(40.0%, 50.0%) |
| **SimpleTouch** [25], **TacFiLM** [15], **ResTacVLA** [30] | VLA에 촉각 주입 | 촉각을 정책 내부에서 처리 | 실험 비교 없음. 서론에서 언급 |

**WiTac의 기여는 "사전 융합 + 시각 복원 + 게이트 주입"의 조합입니다.** 각 요소는 선행연구에 있습니다. 조합의 효과는 절제 실험(표 5)으로 보입니다. 이 가운데 시각 복원 효과는 통계적으로 확인되지 않았습니다(`03` §2).

### 2.2 구성 요소별 출처

| 구성 요소 | 출처 | 논문의 설명 |
|---|---|---|
| 손목 기준 손가락 포즈로 특징 변조 (FiLM) | SaTA [11] | 명시적 인용 |
| 접촉 기술, 변형 이력, 운동 이력 복원 | Sparsh [9] | 명시적 인용 ("sensory self-supervision rationale") |
| 마스크 특징 예측 | I-JEPA 계열 [1] | 명시적 인용 |
| 행동 조건 힘 변화 예측 | Lee 외 2018 [12] | 명시적 인용 |
| 고정 시각 백본 | DINOv3 [21] | 명시적 인용 |
| 촉각 인코더 초기화 | SharpaWave Deform Encoder [20] | HF에 공개(Apache-2.0) |
| 게이트 교차 주의 주입 | 논문에 별도 인용 없음 | 설계로 설명 |
| 행동 전문가 주입 위치 | GR00T N1.7 [17], π0.5 [18] | 기반 VLA |

## 4. 정리

- 이 논문의 위치는 "VT-MUSE와 STAR 사이"입니다. 두 방법의 장점(같은 데이터 사전학습과 손가락 토큰)을 가져오고, 손목 시각 융합을 더했습니다.
- 가장 큰 공백은 **SaTA, STAR, ViTacFormer와의 직접 비교가 없다**는 점입니다. 손목 융합의 효과가 "융합 방식"의 효과인지 "추가 파라미터"의 효과인지도 나뉘지 않았습니다.
