## 1. 문제 설정

VLA가 행동 청크를 한 번에 생성하면, 생성 중 흐르는 시간 동안 로봇은 이미 실행 중인 행동을 계속합니다. 그래서 비동기 실행에서는 새 청크를 만들 때 관측과 실행 시점이 어긋나고(stale observation), 새 청크의 앞부분이 현재 실행 중인 행동과 불연속이 됩니다(§1, Fig. 1). 기존 해결책은 두 갈래입니다.

- **학습 기반:** 지연을 반영한 데이터, 보조 네트워크, 수정된 구조 (논문 [14], [11], [15]). 학습 파이프라인에 손을 대야 하고 동결된 VLA에는 적용하기 어렵습니다.
- **추론 기반:** RTC [12]는 고정 접두부 인페인팅과 **VJP(벡터-야코비안 곱) 안내**로 연속성을 맞춥니다. 효과는 있지만 추론마다 역전파 비슷한 계산이 들어가 지연이 커집니다.

FreeBar는 세 번째 자리를 노립니다. 학습 없이, 행동 공간의 차이만으로 닫힌형 보정을 만들어 VJP를 없앱니다.

## 2. 방법

### 2.1 설정 (§3.1)

흐름 기반 생성기 dx_t/dt = v_θ(x_t, t, c)를 가정합니다. d 제어 스텝 동안 추론이 걸리면 새 청크는 오래된 관측에서 나오고, 이미 커밋된 행동과 어긋날 수 있습니다. 이전 청크에서 시간을 맞춘 참조 Ā가 있고, 이 참조로 새 청크를 맞춥니다.

### 2.2 바리어 점수와 안내 방향 (§3.2, 식 (1)–(3))

- 깨끗한 행동 추정: x̂_1 = x_t + (1−t) v_θ (식 1).
- 가중 일관성 점수: B(x̂_1) = −½ Σ_i w̃_i ‖x̂_{1,i} − ā_i‖² (식 2). 여기서 w̃_i = m_i·w_i로, m_i는 참조 유효 여부, w_i는 수평선 가중치입니다.
- 안내 방향: g = ∇B, g_i = −w̃_i(x̂_{1,i} − ā_i) (식 3). 역전파 없이 행동 차이에서 바로 나옵니다.

### 2.3 닫힌형 투영 (§3.2, 식 (4)–(5), Algorithm 1)

- 속도를 최소로 바꿔 g^T ṽ ≥ b(t)를 만족시킵니다. b(t) = α E_w/τ(t), E_w = −B, τ(t) = 1−t (식 4).
- 한 변수 QP의 해는 λ = max( (b − g^T v_θ)/(‖g‖² + ε), 0 ) (식 5)이고, 갱신은 x_{t+Δt} = x_t + Δt(v_θ + λg) (식 6)입니다.
- 논문은 GR00T에서 **보정 크기에 상한 10**을 둔다고 씁니다(§3.2). Algorithm 1에는 이 상한이 없습니다.

### 2.4 에너지 감쇠 (§3.2 식 (7)–(8), §3.3 식 (9)–(10))

- 식 (7)이 성립하면 E_w(t) ≤ E_w(0)(1−t)^α (식 8)입니다. α > 1이면 b(t) = O((1−t)^{α−1})로 끝점에서도 유계입니다.
- 논문은 이것을 **"Lyapunov형 에너지 감쇠"**이며 CBF의 전방 불변 보장이 아니라고 스스로 적습니다. 식 (7)의 유도는 dx̂_1/dt = ṽ이라는 **국소 대리(local surrogate)**에 기대고 있습니다(§3.3). 따라서 감쇠 식은 이상화된 연속시간 투영에서만 성립합니다.

### 2.5 수평선 등급 제약 (§3.4, 식 (11))

- 접두부 [0, d)는 w=1(강한 정렬), 중간 [d, h)는 exp(−β(i−d+1)/(h_s−d)) (부드러운 정렬), 꼬리 [h, H)는 w=0(자유)입니다. h_s는 기본값으로 실행 수평선 h입니다.
- β는 감쇠율입니다. 본문에는 β의 값이 없습니다.

### 2.6 추론 절차

Algorithm 1은 K번 디노이징 스텝 안에서 위 계산을 반복합니다. 한 스텝의 추가 비용은 참조와의 차이 계산, 수평선 합, 스칼라 λ입니다. 역전파는 없습니다.

## 5. 논문의 한계 (저자 서술)

- 참조 청크의 신뢰도에 성능이 달려 있습니다(§5).
- 근접 행동을 강하게 맞추면 매우 동적인 장면에서 반응성이 떨어집니다(§5).
- 향후 과제로 신뢰도 기반 참조 선택과 적응형 바리어 일정을 듭니다(§5).
