## 0. 한눈에 보기

월드 액션 모델(WAM)은 미래 영상을 상상하는 비디오 확산 모델을 정책에 붙여 쓰는데, 추론 때도 비디오 모델이 돌아 느립니다. W2A는 **학습 때만** 비디오 DiT(Cosmos-Predict2)를 교사로 쓰고, 교사의 중간 잠재 표현을 PCA로 482차원으로 줄여 행동 DiT의 중간 표현에 맞추도록 **코사인 손실**을 더합니다. 추론 때는 비디오 모델과 정렬 모듈(Q-Former)을 버리고 행동 DiT만 씁니다.

## 1. 문제 설정과 주장 (§1, §3)

- 문제: 기존 WAM은 추론 때 미래 상태를 상상해야 해서 계산과 지연이 큽니다(§1).
- 두 질문: (1) 행동 생성에 필요한 세계 선험(world prior)이 저차원 부분공간에 담기는가, (2) 그것을 행동 모델에 증류해 추론 비용을 없앨 수 있는가.
- 가설(초록, §1): 비디오 잠재는 고차원이지만 행동 생성에는 압축된 저차원 부분공간이면 충분합니다. 비디오 잠재와 행동 잠재가 "같은 행동 조건부 동역학을 공유"하므로 증류가 개념적으로 타당하다고 논문은 설명합니다(§1 마지막 문단). 이 부분은 근거가 가설로만 제시되어 있습니다.
- 정식화: 일반 정책 `a ∼ π(·|o, l)`(식 1)과 WAM `p(a, v|o, l) = p_a(a|o, l, v) p_v(v|o, l)`(식 2)를 놓고, W2A는 배포 정책을 식 1의 형태로 유지하되 학습 중 은닉 표현만 교사의 영향을 받게 합니다(§3.1).

## 2. 방법 (§4, 부록 B)

흐름 정합 규약은 `x_τ = τ x_1 + (1−τ) x_0`, τ = 1이 잡음, τ = 0이 데이터이고, 손실은 `L_FM = E‖v_θ − (x_1 − x_0)‖²`(식 3–5), 추론은 역방향 오일러(식 6–7)입니다(§3.2).

### 2.1 1단계: 비디오 도메인 적응과 PCA (§4.1, 식 8)

- Cosmos-Predict2를 로봇 영상에 **LoRA로 적응**합니다. LoRA 순위, 데이터 양, 학습 스텝은 본문과 부록에 없습니다.
- 교사 잠재 `Z^v ∈ R^{T_v×H_v×W_v×D_v}`는 비디오 DiT의 **14번째 블록 출력, 디노이징 시간 τ_v = 0.5**에서 뽑습니다(표 8). 이는 그림 10의 "깊이 50%"와 같고 블록 수 28 가정과 맞습니다(논문은 28을 적지 않았으며 `D_v = 2048`은 Cosmos-Predict2 2B 구성과 같은 값입니다).
- 모든 시공간 위치의 벡터 `z_{t,h,w}`에 PCA를 적합해 평균 μ와 상위 K개 주성분 `U_K`를 구하고 `z̃ = (z − μ) U_K`로 투영합니다(식 8). **K = 482**는 설명 분산 99%에 해당합니다(그림 8: 90% → 65, 95% → 94, 99% → 482개).
- 표 8의 교사 잠재 형상 `[B, 24, 14, 14, 2048]` → PCA 후 `[B, 24, 14, 14, 482]`입니다. 224×224 입력에서 14×14는 VAE 8배 압축과 2×2 패치로 설명됩니다. 시간축 24는 93프레임을 4배 압축한 길이와 같습니다(`03` V11). 반면 4.2절·부록 B.4는 시간 그룹 G = 4개를 쓰고 그림 7은 시간 토큰 5개를 보입니다. 24와 5의 관계(어느 토큰을 쓰는지)는 부록 B.4에 "현재 관측 토큰을 제외하고 이어지는 G개"라고만 적혀 있습니다.
- PCA를 적합하는 표본 집합(전체 데이터셋인지 일부인지)은 적혀 있지 않습니다.

### 2.2 2단계: 행동 DiT와 잠재 증류 (§4.2, 식 9–12, 부록 B.4)

- 행동 DiT를 **처음부터** 학습합니다(은닉 768, 10블록, 헤드 8, MLP 비율 4, 교차 주의로 조건 주입, AdaLN으로 흐름 시간 주입, 표 7). 관측은 정면·손목 RGB 224×224를 ResNet-18로 인코딩하고 이력 길이 2, 언어는 미리 계산한 T5 임베딩입니다. 행동 길이 H = 16, 실행 8.
- 5번째 블록(10블록 중 중간)의 출력 `Z^a ∈ R^{H×D_a}` (16×768)에서 Q-Former(1층, 은닉 128, 헤드 8)가 학습 가능한 쿼리로 읽어 `Ẑ^a`를 만듭니다(식 9).
- 정렬 구조(부록 B.4, 식 13–16): 행동 토큰 16개를 시간 압축률 r_t = 4로 G = 4그룹(그룹당 4토큰)으로 나누고, 그룹마다 14×14 공간 쿼리가 교차 주의로 정보를 모읍니다. 출력은 `G×H_vW_v×K = 4×196×482`로 교사 쪽 선택 토큰과 같은 배치입니다. 정렬 위치 수는 M = G×H_v×W_v = 784입니다. 논문은 "Q-Former는 현재 구현에서 구조화된 정보 읽기 모듈"이라고 설명합니다(부록 B.4, E).
- 증류 손실(식 10): 위치별 코사인 거리 `1 − cos(ẑ, z̃)`를 평균하고 행동 흐름 시간 τ_b에 가우시안 가중 `w(τ) = exp(−(τ − τ_c)²/(2σ_w²))`(식 11, τ_c = 0.5, σ_w = 0.1)을 곱합니다. 전체 손실은 `L = L_FM + λ_dist L_distill`, λ_dist = 1.0(식 12, 표 11).
- 해석: 가중이 τ = 0.5 부근에서만 크므로(τ가 0.3 또는 0.7이면 가중이 약 0.14) 증류 신호는 흐름 시간 중간대의 행동 잠재에만 걸립니다. 교사 잠재가 τ_v = 0.5에서 추출된 것과 맞춘 설계입니다.

### 2.3 추론 (§4.3, 부록 B.3)

- 비디오 DiT와 정렬 모듈을 제거하고, 관측 인코더, 언어 임베딩, 행동 DiT, 행동 정규화기만 씁니다.
- 16개 행동을 예측하고 앞 8개만 실행합니다. 남은 뒷부분은 다음 예측의 **웜스타트** 기준으로 캐시하며, 순수 잡음 대신 τ_ws = 0.5로 교란해 정제합니다(표 12). 추론 디노이징 20스텝, 학습 흐름 스텝 100(표 11).
- 지연과 메모리 측정은 **CLIP 텍스트 인코더로 학습한 변형**으로 했고, 기본 성능은 T5 사전 계산 임베딩 변형이며 "성능은 비슷하다"고 적었습니다(부록 B.3). 두 변형의 성능 비교표는 없습니다.

### 2.4 학습 설정 (표 9–11)

배치 128, 100 에폭, AdamW(학습률 1e-4, 가중치 감쇠 1e-4), 기울기 클리핑 1.0, 코사인 어닐링, EMA 0.999, 흐름 시간 로짓 정규 표집. 학습 데이터 구성(표 9): W2A는 외부 로봇 행동 데이터가 없고, 일반 영상 사전학습과 벤치마크 목표 행동·목표 영상을 씁니다. 하드웨어와 학습 시간은 적혀 있지 않습니다.

## 3. 실험 설정 (§5.1)

- LIBERO 네 스위트(과제 10개씩), CALVIN ABC→D. "공식 평가 프로토콜, 세 시드의 평균"으로 보고합니다. 시드는 0, 5, 42(표 15). 시행 수는 적혀 있지 않습니다(`03`은 스위트당 500회로 가정).
- 실로봇: Franka Research 3, 정면 RealSense D435i와 손목 D405. 과제 유형 PnP, Cube, Long은 각각 소과제 4개, 실용 과제 Towel folding, Table clearing, USB insertion 3개. 소과제당 50개 시연(Omega 7 햅틱 장치 원격 조작, 총 750개), 소과제당 **연속 30회 평가**. 정책은 실로봇에서 15 Hz로 동작합니다(부록 F).

## 7. 한계 (논문 §7)와 부록 I

- 비디오 백본의 용량과 명시적 미래 상상을 버리므로, 분포 변화·처음 보는 물체 동역학·더 긴 지평 적응에서 견고성이 제한될 수 있다고 논문이 씁니다.
- 교사 잠재를 고정된 저차원 부분공간으로 압축하므로 고차 구조가 보존되지 않을 수 있습니다.
- 부록 I: 보지 못한 객체·과제, 초기 배치가 학습 분포에서 크게 벗어난 경우에 실패하는 사례를 그림 17에 보입니다.

## 8. 읽을 때 눈여겨볼 곳 (논문이 적지 않은 것)
