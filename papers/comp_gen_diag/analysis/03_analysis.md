# 03. 수치 재계산, 일관성 검사, 설계 검사

재계산은 `analysis/recompute.py`(수 초, numpy, scipy)가 하고 결과는 `analysis/recompute_results.json`에 있습니다. 논문 v2는 본문 수치가 적고 대부분의 결과를 그림으로 보여 줍니다. 그래서 저자의 프로젝트 페이지 저장소가 공개한 집계 파일(CSV 15개와 `results/data.json`, 합계 약 3 MB)을 입력으로 썼습니다(`analysis/fetch_page_data.py`로 받음). 이 파일의 값이 논문 그림과 같은지는 그림 판독으로 확인했습니다(2S-PP 그림 14, 16은 값이 정확히 일치). 학습 재현이나 새 실험은 하지 않았습니다.

번호: **V**는 수치 재계산, **K**는 설계·구조 검사, **C**는 주장 판정입니다.

## 0. 가정과 읽는 법

- 별도 표시가 없으면 구간은 Wilson 95%, 두 비율 차이는 Newcombe 구간과 Fisher 정확 검정, 시드 단위 비교는 Welch t 검정입니다. 시드가 3–5개라 시드 단위 검정은 검정력이 낮습니다.
- 분모(롤아웃 수)는 내보낸 파일에서 읽었습니다. 과제·시드당 시도 수는 논문 §5.1과 B.3이 "30회"라고 쓰지만 내보낸 파일에서는 과제마다 다릅니다(V2). 분모를 읽은 방법은 해당 항목에 적었습니다.
- "p ≈ 0.06"처럼 경계의 값은 방향과 크기를 함께 봅니다. 가설 서술은 "가능성"으로만 씁니다.

## 1. 재계산 결과

### 1.1 Q1: 전체 조합이 필요한가 (그림 2, 3, 4)

**V1. 총합 = 가중 평균 (자체 일관성).** 시드별 Total = (B·ID + (N−B)·OOD)/N 이 PPP 75행(N = 64)과 PP 48행(N = 16) 모두에서 0.0001 포인트 안에서 맞습니다. 내보낸 파일의 ID, OOD, Total 열은 서로 일관됩니다.

### 1.2 손실 분석 (§5.2)

**V5.** ID 손실 0.00648, 0.00663, 0.00667은 상대 범위 2.9%로 거의 일정하고, OOD/ID 비는 5.28, 2.33, 1.13입니다(문장과 일치). 같은 문장의 OOD 성공률 0.83%, 23.93%, 82.29%를 내보낸 시드별 값과 맞춰 보았습니다.

세 체크포인트는 단일 실행의 값으로 읽히고(그중 하나는 내보낸 값과 연결되지 않음), 손실 격차 축소 주장은 이 세 점에 기댑니다. B = 8의 성공률이 어느 설정의 값인지 저자 확인이 필요합니다.

### 1.4 Q2: 파인튜닝 (그림 6, 7, 부록 D)

**V7a. 헤드라인 0.4% → 54.7%.** 사전학습 B = 4 대각의 사전학습에 없던 60과제 성공률은 7/1,800 = 0.389%(Wilson 0.19–0.80), 64과제 파인튜닝 뒤 492/900 = 54.67%(Wilson 51.4–57.9, 시드 SE 1.6이므로 시드 3개 t 구간 47.9–61.4)입니다. 수치는 논문과 일치합니다. 내보낸 Wilson 구간으로 분모를 역산하면 사전학습 기준과 처음부터 학습은 60과제 × 30 = 1,800, 파인튜닝 행은 60과제 × 15 = 900(B = 6 사전학습은 58과제 × 15 = 870)입니다. 파인튜닝 평가의 롤아웃 수가 기준 평가의 절반이라는 뜻입니다.

**V7b. 처음부터 학습 대비.** 같은 시연 수의 처음부터 학습(보류 60과제 OOD)은 64개 0.28%, 128개 7.3%, 256개 24.8%, 512개 45.1%이고, 파인튜닝은 54.7, 63.6, 58.4, 61.2%입니다. 시드 단위 Welch p는 64개 0.001, 128개 < 0.001, 256개 0.007, 512개 0.27(처음부터 학습의 시드 SE가 10.8)입니다. 512개에서는 구분이 안 됩니다. 처음부터 학습은 사전학습 데이터를 쓰지 않으므로 "같은 총 예산"의 의미가 사전학습 데이터를 포함하는지에 따라 달라집니다(논문에 사전학습 데이터 양이 적혀 있지 않음).

**V7c. ID 감소.** 사전학습 ID 83.3% → 파인튜닝 76.7, 73.3, 66.7, 61.7% (64, 128, 256, 512 시연). 논문의 "ID 성공이 파인튜닝 뒤 줄어든다"와 일치합니다.

**V7d. 직교 대 무작위 파인튜닝 (그림 7).** 16, 32시연에서 보류 과제 성공률(내보낸 `ft_heldout`):

| 사전학습 | 시연 | 직교 | 무작위 5집합 | 직교 순위 | 정확 단측 p |
|---|---|---|---|---|---|
| B = 4 | 16 | 18.6% | 4.7–13.8% | 1/6 | 0.167 |
| B = 4 | 32 | 37.1% | 24.0–31.3% | 1/6 | 0.167 |
| B = 6 | 16 | 28.1% | 13.3–17.8% | 1/6 | 0.167 |
| B = 6 | 32 | 39.4% | 27.1–40.0% | 2/6 | 0.333 |

직교가 4개 중 3개에서 무작위 5개를 모두 앞서지만, 6개 중 1위에 대한 정확 p의 최솟값이 1/6이라 이 설계로는 0.05에 닿을 수 없습니다. 또 32시연에서 직교의 보류 과제 수는 48, 무작위는 32로 평가 과제 집합이 다릅니다. 직교의 보류 48과제는 정의상 모두 세 쌍을 본 과제입니다(K1).

**V7e.** 64시연 직교(16과제 × 4)의 OOD는 50.3%로 전체(54.7%)와 같은 총 시연에서 4.3 포인트 낮습니다. 평가 과제는 사전학습 기준의 OOD이므로, 전체 64과제 파인튜닝에서는 평가 과제 60개가 모두 파인튜닝 데이터에 1회씩 들어 있습니다. 해석은 `03` §4 C7에 있습니다.

### 1.5 Q3: 2S-PP (그림 8, 9, 14, 15, 16)

**V8. 48과제 (5시드, 과제·시드당 10회).**

- 그림 16의 Sankey 흐름(시작 → 집기 → 놓기 → 1단계 성공 → 2단계 성공)의 산술은 9개 칸 모두 맞습니다(예: Cov6 ID 800 − 36 − 229 − 46 − 147 = 342 = 42.8%).
- 내보낸 시드별 CSV의 합산(집기 실패, 같은 컨테이너, 성공)이 그림 16의 숫자와 9개 칸 모두 일치합니다(Cov16 ID 성공 38.25% 대 그림 38.3%는 반올림).
- 성공률(5시드 평균 ± SEM):

| 조건 | OOD | ID |
|---|---|---|
| Cov6 | 9.19 ± 2.25 | 42.75 ± 1.26 |
| Cov9 | 18.88 ± 3.02 | 41.88 ± 2.87 |
| Cov12 | 25.88 ± 4.73 | 34.75 ± 1.87 |
| Cov16 | 31.44 ± 3.85 | 38.25 ± 1.12 |
| Full (ID) | - | 34.33 ± 2.06 |

  OOD 9.19 → 31.44는 3.42배("3.4×")입니다. Cov6 대 Cov16 Welch p = 0.002, 인접 쌍은 Cov6 대 Cov9 p = 0.035, Cov9 대 Cov12 p = 0.25, Cov12 대 Cov16 p = 0.39입니다. 쌍 수에 대한 선형 추세는 기울기 2.2포인트/쌍(p = 0.0002, r = 0.74, 시드 20개). Cov16의 OOD(31.4)는 Full(34.3)과 구분되지 않습니다(p = 0.53).
- ID는 쌍이 적을수록 높습니다: Cov6 42.75 대 Cov16 38.25 (p = 0.029), Cov6 대 Full 34.3 (p = 0.011). 논문의 "denser supervision per pair" 설명과 방향이 같습니다.
- 같은 컨테이너 위반율(첫 배치 완료 롤아웃 중, 그림 15 오른쪽)은 시드 평균과 합산이 같은 값을 줍니다(Cov6 OOD 21.4%, Cov16 OOD 13.7%, Full 12.0%). 전체 롤아웃 분모로 나눈 값은 절반 정도입니다(Cov6 OOD 10.25%, Cov16 OOD 8.75%, Full 7.58%). 그림 16의 "Wrong cont. 10.2% (164)"는 전체 롤아웃 분모이고 그림 15의 막대는 조건부 분모입니다(V8의 두 열).

**V9. 36과제 (그림 8, 14).**

- 내보낸 값의 시드 0–2 합산이 그림 14의 성공률 9개 칸과 모두 일치합니다(예: Cov4 OOD 1.2%, Cov12 OOD 18.5%).
- 시작 수 360(ID, 12과제), 720(OOD, 24과제), 1,080(Full)은 과제당 30회(= 3시드 × 10회)입니다. §5.1의 기본 "3시드 × 과제·시드당 30회"라면 1,080 / 2,160 / 3,240이 됩니다. 부록 E는 이 설정의 시도 수를 쓰지 않습니다.
- Cov6에는 시드 0–2 외에 시드 6 행(360 OOD 롤아웃)이 하나 더 있습니다(합산 제외).
- OOD: Cov4 1.25 ± 1.05, Cov6 7.50 ± 1.91, Cov9 16.11 ± 0.28, Cov12 18.47 ± 2.70 (시드 3, SEM). Cov4 대 Cov12 p = 0.014. ID는 Cov4 39.7 대 Cov12 31.7 (p = 0.12).

**V10. 오라클 단계 정책 (그림 9b).** 활성 지시만 보는 정책의 같은 컨테이너 위반율은 Cov16 ID 24.1, OOD 24.5, Full 24.4%입니다. 정책이 c2를 보지 못하고 c1의 학습 분포가 c2에 대해 대칭이면 네 컨테이너에 균등하게 놓아 위반 기댓값은 25%이므로 관측값과 맞습니다. 전체 지시 정책의 Cov16 OOD 13.7%(5시드)와의 차이는 Welch p = 0.002(오라클 정책 2시드, SD 1.3 가정)입니다. 그림 9의 막대는 오라클 정책이 SD, 전체 지시 정책이 SEM이고 단계 정책의 시드 수는 Cov16 2개, Full 3개입니다(프로젝트 페이지의 출처 문서). 논문 캡션은 이 규약을 적지 않으며 본문 B.3은 "오라클 단계 비교의 시드 수는 부록 E에 있다"고 하지만 부록 E에는 없습니다.

### 1.6 부록 수치

**V11. 표 1 (시도 수 민감도, 2S-PP).** 15 → 30회 변화는 ID −1.04, OOD −0.41 포인트로 본문과 같습니다. 해석은 두 가지입니다.

- 정수 가능성: 표의 8개 칸(ID 56.25, 63.75, 62.92, 61.88, OOD 15.00, 15.70, 16.30, 15.89)이 모두 k/N으로 나오는 조합은 48과제 집합(ID 16, OOD 32과제)에서 **평가 시드 4개**를 합산할 때뿐입니다(시드 1, 3, 5개 또는 36과제 집합에서는 불가). 부록 E는 48과제 집합에 시드 5개를 적고, 표 1 캡션은 집합과 시드 수를 적지 않습니다. 시드 수나 평가 집합이 표와 본문에서 다를 가능성이 있습니다.
- 구간: 같은 설정(48과제, 5시드, 30회)에서 ID 61.88%의 Wilson 반폭은 1.9포인트, 1시드이면 4.3포인트입니다. 15회와 30회의 차이 1.04는 이 구간 안입니다. 15회 평가가 30회 평가의 부분집합이라면 두 값은 독립이 아니어서 차이가 작게 나오는 것이 당연합니다. 이 경우 표 1은 평가 노이즈 크기를 보여 주기보다 부분집합 일관성을 보여 줍니다(논문이 이를 밝히지 않음).

**V12. 사람 시연 (부록 C).** ID 11.67%와 OOD 12.96%를 3시드 × 30회 가정(ID 9과제 810회, OOD 18과제 1,620회)으로 정수 성공 수에서 보면, OOD 12.96% = 210/1,620은 가능하지만 ID 11.67%는 810개 중 94개(11.60%)나 95개(11.73%)이고 11.67%는 불가능합니다. 11.67%가 나오는 분모는 540(= 2시드)입니다. 시드·시도 수 서술과 분모가 다를 수 있습니다. OOD − ID = +1.2 포인트(Newcombe [−1.6, +3.9], 위 가정), OOD의 Wilson 구간은 11.4–14.7%입니다. 논문은 "comparable rates provide preliminary evidence"라고 쓰고 우연 수준과의 비교는 없습니다. 절대 성공률이 낮아서(약 12–13%) 직교 커버리지가 일반화를 만든다는 증거로는 약하고, 사람 시연에서는 ID 자체가 낮은 상태로 OOD와 같다는 관찰입니다.

**V13. PP 입력 생략 (부록 E).** 컨테이너 지시를 빼면 성공이 71.05 ± 5.00% → 49.95 ± 1.14% (5시드). ±가 SD이면 Welch p = 0.0005, SEM이면 0.012입니다(논문이 ±를 정의하지 않음). 차이는 21.1 포인트로 두 해석 모두에서 확실합니다. 71.05%는 차트의 PP 전체 학습 73.5 ± 4.0(SEM, 3시드)과 같은 범위입니다.

### 1.7 이론 (정리 4.1, 4.2)

**V14.** (a) 이산 분포 200개에서 `Δ = A + B + C` 정확 분해와 식 5의 상한이 모두 성립합니다(위반 0, `|Δ|/상한`의 최댓값 0.05). 증명은 문제없습니다. (b) PPP의 q = 64과제 균등, p = 훈련 과제 균등으로 식 5의 첫째 항과 둘째 항을 설계마다 계산했습니다.

| 설계 | B | 첫째 항 | 둘째 항 | OOD (%) |
|---|---|---|---|---|
| 직교 16 | 16 | 0 | 1.500 | 78.2 |
| 무작위 16 (3 집합) | 16 | 0.21–0.38 (인자 평균) | 1.41–1.46 | 68.3–78.1 |
| 무작위 8 (2 집합) | 8 | 0.17–0.25 | 1.72–1.73 | 30.8–34.3 |
| 대각 4 | 4 | 0 | 1.875 | 0.4 |
| 전체 64 | 64 | 0 | 0 | 78.6 |

균형 잡힌 16과제 설계에서는 인자마다 값 하나당 4과제이므로 둘째 항이 `2(1 − 4/16) = 1.5`로 설계와 무관합니다. 즉 식 5의 둘째 항은 직교 설계와 균형 잡힌 다른 16과제 설계를 구분하지 않습니다. 52개 설계 전체에서 첫째+둘째 항과 OOD의 순위상관은 −0.79이고(B 단독 +0.91), 같은 B와 같은 항 값을 가진 설계들의 OOD가 B = 6에서 7.1–16.6%, B = 8에서 22.1–41.7%로 퍼집니다. 식 5는 상한이라 정확한 예측을 기대하는 값이 아니며, §5.2의 "쌍 커버리지가 이 항을 줄인다"는 서술은 상한의 계산이 아니라 해석입니다.

## 3. 설계 검사 (K)

**K1. 직교 16 설계.** 그림 4의 16행을 옮겨 쌍 3종(객체-컨테이너, 객체-버튼, 컨테이너-버튼) 각 16쌍이 정확히 한 번씩 나오는지 확인했고 모두 그렇습니다. 표시용 데이터의 `train_tasks`와도 같습니다. 이 16행은 `버튼 = 객체 XOR 컨테이너`(색 순서 red, green, blue, yellow)와 같고, 공개 코드의 `xor_oa_4x4x4` 설명과 같은 구성입니다. 이 설계에서 48개 보류 과제는 모두 세 쌍을 본 과제(본 쌍 수 3)입니다. 강도 2 직교 배열의 최소 행 수는 q² = 16(인자 수와 무관)이므로 PPP에서 "1/4"은 최솟값입니다. 인자 수가 늘면 같은 설계가 전수 곱의 1/16(4인자), 1/64(5인자)가 되고, 강도 3이 필요하면 64행(4인자에서 1/4)입니다. 무작위 B과제(모든 값 1회 이상) 집합에서 보류 과제의 본 쌍 수 분포 몬테카를로(1,500회): B = 16에서 0/1/2/3쌍이 5.3/29.7/45.7/19.3%, B = 24에서 0.8/11.8/43.4/44.0%로 직교(100%가 3쌍)와 다릅니다. 대각 4는 보류 60과제 중 24개가 0쌍, 36개가 1쌍이고 2쌍 이상이 없습니다.

**K2. 본 쌍 수 재계산 일치.** V6a, 2,775개 셀 모두 일치.

**K3. 내보낸 두 판의 같은 값.** 전체 64의 PPP 성공률이 차트 CSV 78.65%(시드 3개 평균)와 표시용 데이터 79.0%(1,600롤아웃)로 둘로 나옵니다. 프로젝트 페이지의 노트가 "두 내보내기는 별도 스냅샷이며 서로 맞추려고 덮어쓰지 않았다"고 적습니다. 직교 16은 두 곳에서 같은 78.19%입니다.
