## 1. 한 줄 요약과 주장

월드 모델이 로봇 학습 파이프라인(합성 데이터 생성, 시뮬레이터 대체)에 들어오면, 데이터 공급자가 **사람 눈에 안전한 텔레오퍼레이션 영상**에 작은 색 섭동을 넣어 월드 모델의 입력으로 쓰일 때만 위험한 궤적이나 변형된 전이 동역학이 나오게 할 수 있다는 위협 모델과 두 가지 공격 방법(VPH, VTH)을 제시합니다 (초록, §4–5).

초록과 §1이 내세우는 기여는 다음입니다.

1. 월드 모델을 겨냥한 첫 공격으로 텍스트 조건 모델(Visual Prompt Hijacking, VPH)과 행동 조건 모델(Visual Transition Hijacking, VTH)을 제안.
2. 텍스트 조건 월드 모델은 약간 분포 밖이거나 프롬프트가 모호하면 훨씬 조작되기 쉽다는 발견 (§6.1, 표 1).
3. 월드 모델 입력 조작만으로 DRL 정책에 백도어를 심은 첫 사례 (§6.2, 그림 4).
4. VLA에 대해서는 "개념 증명"(초록). 본문 §6.1은 IDM 한계로 VLA 학습까지는 못 갔다고 적습니다.

## 2. 위협 모델 (§4)

- 공격자: 제3자 텔레오퍼레이션 데이터 공급자. 피해자의 월드 모델에 **화이트박스 접근**(질의와 그래디언트)이 있다고 가정합니다. 정당화는 "SOTA 월드 모델은 훈련 비용이 커서(4096 H100) 정책 학습자는 공개 모델을 쓸 것"입니다(v2에서 추가).
- 제약: (a) 영상이 눈으로 볼 때 안전하고 고품질이어야 하며, (b) 영상 프레임만 바꿀 수 있고 행동 시퀀스, 프롬프트, 보상 함수는 건드리지 못합니다.
- 섭동 크기: LAB 색공간에서 l_p 공 안(식 3·4·5의 `‖x − x_δ‖^LAB_p ≤ β`)으로 제한하고 "눈에 띄지 않는다"고 주장합니다(§4). 실제 예산은 β_L = 5, β_AB = 20 (표 2)이며 저자도 "대부분의 회피 공격보다 크다"고 적습니다(부록 A.1). 환산은 `03` V11.
- 백도어 정의 (식 2): "공격 성공"(트리거 관측 시 적대 목표 쪽으로 정책 행동 이동)과 "공격 은밀성"(트리거가 없으면 벤치 정책 가치 V와 같음)을 함께 요구합니다.

월드 모델 형식 (식 1): θ_t: 𝒯 × Ω → Ω* × A* (텍스트 조건), θ_a: A × Ω → Ω (행동 조건).

## 3. 방법

### 3.1 Visual Prompt Hijacking (VPH, §5.1, 식 3)

Cosmos-Predict2.5는 조건 이미지를 시각 임베딩으로만 넣기 때문에 이미지에 글자를 심는 방식이 통하지 않는다고 봅니다. 대신 월드 모델의 "의미 인코딩" S_θ(교차 어텐션 또는 확산 벡터장)가 **안전 프롬프트 t와 섭동 이미지**에서 나온 것이 **위험 프롬프트 t_δ와 원본 이미지**에서 나온 것과 가까워지도록 섭동을 최적화합니다.

식 3: `min_{x_δ} E_{t∼T_safe, t_δ∼T_δ} [ D( S_θ(x_δ, t) ‖ S_θ(x_δ, t_δ) ) ]  s.t. ‖x − x_δ‖^LAB_p ≤ β`

구현은 PGD + 모멘텀 0.9, 400 스텝, α = 0.025(채널 예산의 비율 → AB 0.5/스텝), 섭동 대상 프레임은 생성 프레임 10개입니다(표 2, 부록 A.1). 손실은 "진짜 프롬프트와 목표 프롬프트에서 모델의 **벡터장(디노이징 속도)** 사이 MSE"입니다(부록 A.1). 식 3의 두 항에 모두 x_δ가 있다는 점과 본문 서술(§5.1 "S_θ(x_δ, t)를 S_θ(x, t_δ)에 맞춘다")이 다른 점은 `03` K1에서 다룹니다.

### 3.2 Visual Transition Hijacking (VTH, §5.2, 식 4·5)

행동 조건 월드 모델을 "목표 행동 a⁺ 근처에서만 정상 예측, 그 밖의 행동에서는 예측이 붕괴"하도록 섭동합니다. 무조건 버전은 잠재 인코더 E_θ의 코사인 유사도를 최소화합니다(식 4). 행동 조건 버전(식 5):

`min_{x_δ} E_{a', ε} [ cos(θ(x_δ, a'), θ(x, a')) + (1 − cos(θ(δ(x_δ), a⁺+ε), E(x))) ]`

a'은 a⁺에서 충분히 먼 행동에서 뽑고, ε는 a⁺ 근처의 작은 교란입니다. RL 에이전트가 월드 모델 안에서 학습하면 목표 행동 a⁺를 고를 때만 처벌(붕괴한 예측)이 없으므로 a⁺가 강화됩니다. 배치 후 트리거 객체가 보이면 a⁺를 고르게 됩니다. 부록 A.2: 목표 행동 시퀀스 4개와 비목표 시퀀스 4개를 매 스텝 샘플링하고, 나머지 3개 행동은 균일 무작위, 비목표 시퀀스는 최소 한 차원의 부호가 반대가 되도록 뽑습니다. 프레임은 4개를 씁니다.

### 3.3 DRL 파이프라인 (부록 A.2)

Dino WM(Single Wall)을 Gymnasium 래퍼로 감싸고(프레임 스킵 5), 관측은 [현재 잠재 z, 목표 잠재 z_g]입니다. PPO는 CleanRL 구현입니다. 보상 (식 6):

`R(z, z_best, z_g) = min(0, ‖z_best − z_g‖₂ − ‖z − z_g‖₂) + c · 1[‖z − z_g‖₂ ≤ ε]`

서술은 "가까워지면 보너스"이지만 첫 항은 항상 0 이하입니다(`03` K6).

## 4. 실험과 결과

### 4.1 VPH: Cosmos-Predict2.5 2B (§6.1, 표 1, 표 2)

- 설정: Cosmos-Predict2.5 2B post-trained 모델을 LIBERO(Cosmos-Policy용 256×256 재렌더)에서 LoRA로 미세조정하고 432×432 영상을 생성합니다(부록 A.1). 새 과제 3개(Stove, Microwave, Gift Box), 각 장면에 위험 물체 3개씩 총 9개입니다.
- 지표: 생성 영상을 **수동 검사**해 위험 목표(예: 폭탄을 선물 상자에)를 수행하면 성공. 예측 붕괴는 실패로 셈(§6.1).
- 시행: 위험 과제마다 섭동 이미지 5개 × 생성 시드 4개 (§6.1). 표 1의 모든 값이 5%의 배수이므로 셀당 n = 20이 일관됩니다(`03` V1). 무공격 행의 시행 수는 논문에 없습니다.
- 변수: 프롬프트(모호/구체), 카메라(분포 안 ID / 분포 밖 OOD).

**표 1 (v2) 행별 평균(9물체 단순 평균)**: OOD 모호 41.7%, OOD 구체 26.1%, OOD 무공격 1.1%, ID 모호 15.0%, ID 구체 4.4%, ID 무공격 0.6%(`03` V3). 가장 높은 값은 Gun OOD 모호 100%, OOD 구체 95%(무공격 10%)입니다.

**해석(저자)**: ID 카메라에서는 대부분 성공률이 낮고 OOD 카메라에서 크게 오르며, 모호한 프롬프트가 구체적 프롬프트보다 높습니다. 저자는 이것을 "월드 모델은 분포 밖이고 불확실성이 높을 때 가장 취약하다"는 가설의 증거로 읽습니다.

**한계(저자)**: 현재 월드 모델과 IDM이 너무 취약해서 VLA 학습에 쓸 데이터를 얻지 못했고, 결과는 "개념 증명"입니다(§6.1, 부록 A, "Further Comments on Implementing the VLA Pipeline"). 따라서 **하류 VLA 정책이 위험해졌다는 실험은 이 논문에 없습니다.**

### 4.2 VTH: Dino WM + PPO (§6.2, 그림 3·4)

- Single Wall에서 PPO를 월드 모델 안에서 학습하고 실제 시뮬레이터에서 평가합니다. 두 학습 묶음 각 5시드: "무오염"과 "VTH 백도어"(초기 상태의 **5%**를 VTH로 오염, 목표 행동 = 모든 차원 1).
- 지표: 공격 성공 = 트리거 관측 시 선택 행동이 목표의 모든 차원 0.2 이내인 비율. 공격 Cos Sim = 목표 행동과 선택 행동의 평균 코사인. 실제 환경 성공률(무트리거).
- 결과(그림 4, 그림 판독 값): 공격 성공이 VTH 약 0.33 (최고 약 0.40), 무오염 약 0.03. Cos Sim은 VTH 약 0.88, 무오염 약 −0.45. 실제 환경 성공률은 두 묶음 모두 약 0.9. 저자는 "두 지표 모두에서 큰 증가, 무트리거 성능 동일"이라 판단합니다(`03` V9).

### 4.3 VTH: Cosmos-Predict2.5 AC (§6.2, 그림 5)

DROID 샘플 20개에 VTH를 만들고, 입력 행동 값(모든 차원 같은 값, −1~1)에 따라 깨끗한 입력과 섭동 입력의 생성 결과 사이 L2 거리(임베딩, 픽셀)를 잽니다. 행동이 목표 1에 가까워지면 거리가 줄어든다고 보고합니다. 그림 판독 값으로 임베딩 L2가 약 44.8(−1)에서 34.6(+1)로 약 23% 줄어듭니다(`03` V10). DRL 파이프라인에는 연결하지 않았습니다.

### 4.4 r2Dreamer (부록 B.6, 표 5, 식 7)

Dino WM과 달리 r2Dreamer는 노이즈 영상에도 그럴듯한 궤적을 환각해서 식 5만으로는 안 되어, 크리틱 ψ를 쓰는 항을 더한 변형(식 7)을 썼습니다. 오염 비율 25%로 Cartpole Swing Up과 Reacher Easy에서 "트리거 행동 오차"가 줄었다고 보고합니다(5회 평균, 95% 구간). 저자는 이를 부록 결과로 두었습니다.

### 4.5 방어와 가드레일 (§7, 부록 B.4)

Cosmos Guardrail은 "pick up the handgun" 같은 직접 위험 프롬프트도, VPH 입력도 막지 못했다고 보고합니다(시행 수 없음). 교차 프롬프트-영상 검증기는 §7에서 "순진하게 적용하면 효과 없다"고 쓰지만 부록에 실험이 없습니다(`03` K9).

### 4.6 부록 B.1 VLM 라벨링 (표 4)

Qwen3-VL이 영상에서 "목표 물체를 집었는가"를 맞히는 비율은 물체별 10~100%입니다. 그래서 수동 라벨을 썼습니다(`03` V7).

## 5. 한계와 열린 질문

저자가 적은 것: 더 현실적인 파이프라인에서의 검증 부재, 공격이 최적이 아님(§7). 이 분석이 덧붙이는 것(자세한 근거는 `03`, `04`).

1. 하류 VLA 정책 실험이 없어 "위험한 정책이 배포된다"(초록)는 VPH 쪽에서는 아직 시연이 아닙니다.
2. 표 1의 시행은 5이미지 × 4시드이며 같은 섭동 이미지가 시드 4개에 공유되므로 셀 안의 20회가 독립이 아닙니다. 이미지 5개를 단위로 보면 구간이 크게 넓어집니다(`03` V2).
3. 월드 모델은 피해자의 **미세조정된 같은 모델**을 화이트박스로 공격합니다. 다른 체크포인트나 블랙박스로의 전이는 시험하지 않았습니다.
4. VTH의 DRL 결과는 2차원 점 이동 환경 하나(Single Wall)입니다. Push-T는 학습이 안 된다고 적습니다(부록 A.2).
5. 섭동 예산(ΔE76 최대 약 28.7)은 일반적 가시성 기준보다 큽니다(`03` V11). "눈에 띄지 않는다"는 서술과 비교가 필요합니다.
6. 같은 크기의 무작위 색 섭동(최적화하지 않은 섭동)이 만드는 붕괴를 대조군으로 둔 결과가 그림 5와 표 1에 없습니다.
