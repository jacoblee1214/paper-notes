## 1. 문제 설정

- 사람 손 영상은 싸고 많지만, 로봇 관절 명령이 없습니다. 손 추적 결과는 손목 자세와 손끝 위치(EEF 행동)로만 바꿀 수 있습니다(Sec. 1, 3.1). 관절 행동은 역기구학(IK)으로 얻지만 몸체 의존적이고 로봇 분포 밖의 팔 자세를 만듭니다(Sec. 1, D.2).
- 질문은 두 가지입니다(Sec. 1, Fig. 1).
  1. **학습 질문:** 사람 데이터가 정책을 어떻게 지도해야 하는가. 연속 디코더로 EEF를 지도하면 그래디언트가 백본에 간접으로만 닿습니다. 이산 토큰(FAST)을 함께 쓰는 VLA도 있지만, 데이터와 구조를 동시에 바꿔서 토큰 효과가 분리되지 않았습니다.
  2. **배치 질문:** 다지 손을 쓰는 로봇은 배치 때 관절과 EEF 중 무엇을 읽어야 하는가. 기존 이중 출력 정책은 관절 출력만 실행합니다. 논문은 로봇 시연에서는 관절이, 사람 시연에서는 IK로 바꾼 EEF가 낫다는 상반된 결과를 보입니다(Sec. 1, 5.3).

## 2. 방법 (Sec. 3, Fig. 2, Table S1–S2)

**구조.**
- 백본: Qwen3-VL-4B (언어 모델 36층, 은닉 2,560). 입력은 이미지 토큰, 지시문, 상태 접두부 두 토큰(EEF 상태와 로봇의 관절 상태). 학습 때 각 상태 토큰은 확률 0.5로 빠집니다(Sec. 3.2).
- 행동 전문가: 0.6B 흐름 매칭 트랜스포머. 백본의 모든 층의 키와 값을 읽습니다(Sec. 3.2, A.1). 추론은 10 Euler 단계입니다.
- 두 출력 스트림: **EEF 스트림 55차원**(팔마다 손목 위치 3, 회전 6, 손끝 5×3, 그리고 몸통과 목 7). **관절 스트림 65차원**(팔 7×2, 손 22×2, 몸통과 목 7). 두 스트림은 입출력 투영을 따로 갖고, 주의 마스크로 서로 보지 못하게 막습니다. 어느 한 스트림만 실행해도 됩니다(Sec. 3.2, Fig. 2 아래 오른쪽).
- 행동: 60 Hz, 청크 64스텝(1.07 s). 배치에서는 50스텝(0.83 s)을 실행한 뒤 다시 계획합니다(A.2).
- 보조 목표: 백본은 EEF 청크의 FAST 토큰(어휘 1,024)을 예측합니다. 사람과 로봇 청크가 같은 어휘를 씁니다. 전문가는 토큰을 볼 수 없어 배치 때 토큰을 버립니다(Sec. 3.3). 세부 과제 텍스트(L_text)와 미래 프레임(L_video, Wan2.1-T2V-1.3B DiT 기반, 1 s 앞)도 보조 목표입니다(Sec. 3.2, A.1).

**손실 (식 1, Sec. 3.4).**

L = L^EEF_FM + m_J · L^joint_FM + λ_F · L_FAST + λ_V · L_video + λ_T · L_text, λ_F = 0.1, λ_V = 1, λ_T = 0.2.

- m_J는 관절 라벨이 없는 샘플을 마스크합니다. 사람 샘플은 EEF 손실만 받고, 관절 스트림은 공유 백본과 전문가를 통해서만 영향을 받습니다.
- 사전학습은 사람과 로봇 샘플을 1:1로 뽑습니다. 로봇 시연 미세조정은 사전학습 손실을 그대로 유지하고, 사람 시연 미세조정(H2R)은 L_FAST를 모든 모델에서 끕니다(Sec. 3.4, 5.2).

**배치 (Sec. 3.5).** 백본과 전문가만 실행합니다. 관절 스트림은 관절 제어기에 직접 명령하고, EEF 스트림은 손목 자세와 손끝 위치를 IK로 관절 목표로 바꿉니다. 같은 체크포인트에서 두 방식을 고를 수 있습니다.

**사람 데이터 리타게팅 (Sec. 3.1).** 사람 손은 MANO로 추정한 뒤 로봇 손에 리타게팅합니다. 손끝 위치는 리타게팅된 손의 값입니다. EEF 행동은 현재 손목 좌표계에서 표현해 카메라 외부 파라미터와 팔 관절 배치의 영향을 지웁니다.

## 3. 실험 설정 (Sec. 4, Table 1, Table S3)

- **로봇:** 7자유도 팔 2개, 22자유도 손 2개, 머리 카메라 1대와 손목 카메라 2대(Sec. 4). 원문은 손의 제품 이름을 쓰지 않습니다.
- **데이터:** 사람 2,811시간(73,077 에피소드, 320과제, EEF만), 로봇 228시간(10,505 에피소드, 105과제, EEF와 관절). Table 1.
- **네 모델의 2×2 설계:** SHAPE, w/o FAST(사람 데이터, 토큰 없음), w/o human(로봇만, 토큰 있음), w/o both. 구조, 로봇 데이터, 학습 예산이 같습니다(Table 1 오른쪽).
- **실로봇 과제(로봇 시연, 6개, Fig. 3):** Insert Battery(이진), Reinsert USB(0.5/1.0 부분 점수), Reinsert Type-C(0.3/0.6/1.0), Wipe Bowl(이진), Open Cabinet(이진), Close Bottle Cap(이진). 과제당 로봇 시연 196–447회. 과제당 20회 평가, 물체 위치 무작위(Sec. 4).
- **사람 시연만 쓰는 과제(H2R, 3개):** Pick Eggplant, Pick Cup, Stack Cups. 사람 시연 188–1,187회로 미세조정하고 로봇 시연은 0회. 과제당 20회(Sec. 4, 5.2).
- **기준선:** π0.5와 GR00T N1.7을 같은 시연으로 관절 공간에서 미세조정합니다. GR00T N1.7은 사람 영상 20k시간으로 사전학습되었다고 적혀 있습니다(Zheng et al., 2026)(Sec. 4, G).
- **시뮬레이션:** RoboCasa GR-1 테이블 과제 24개(Close 6, PnP 18), 시연 20,802회, 과제당 50 에피소드를 체크포인트 3개에서 평가(Sec. 5.4, F).
- **통계 (Appendix C):** 6과제 점수의 95% 구간은 분산 상한 Var(S) ≤ Σ µ_t(1−µ_t)/(36n)으로 계산합니다. 집계는 두 점수의 z 검정, H2R은 Fisher 검정과 과제 층화 CMH입니다.

## 4. 결과 (Sec. 5, Table 2–4)

**4.1 로봇 시연 6과제 (Table 2).** 관절 스트림 SHAPE의 6과제 점수는 0.80입니다. π0.5는 0.63, GR00T N1.7은 0.51입니다. 엄격 완료(연결부 최종 삽입 포함) 수는 SHAPE 76/120(63.3%), π0.5 61/120(50.8%), GR00T 51/120(42.5%)입니다(Sec. 5.1). 사전학습 없이 LFAST만 쓴 w/o human은 0.64로 π0.5와 같습니다(Sec. 5.1 끝부분).

**4.2 사람 시연만 (H2R, Table 3).** 네 모델 모두 EEF 스트림만 성공합니다(총 32/240). SHAPE 21/60(35.0%), w/o FAST 7/60(11.7%), w/o human 4/60(6.7%), w/o both 0/60. **관절 스트림은 240회 모두 실패했습니다**(Table S5). 기준선(π0.5, GR00T)은 H2R 실험에 없습니다.

**4.3 EEF와 관절 스트림 비교 (Sec. 5.3).** 같은 체크포인트에서 관절 스트림이 24쌍 중 23쌍에서 EEF보다 높습니다(예외는 w/o FAST의 Open Cabinet, 11 대 13). 점수 차는 0.17–0.28입니다. 그러나 오프라인 손목 오차(52개 검증 에피소드)는 두 스트림이 거의 같습니다(우측 손목 11.6 대 11.5 mm). 저자는 실행 중 차이를 "22자유도 손에 대한 손끝 IK가 덜 제약되어 생긴다"고 설명합니다(Sec. 5.3). 이 설명은 직접 검증하지 않았습니다.

**4.4 시뮬레이션 (Table 4).** SHAPE 72.2%, π0.5 64.8%, GR00T 62.6%, w/o human 65.2%, w/o FAST 69.6%, w/o both 62.0%. 사람 데이터 효과는 두 설정에서 +7.0과 +7.6 포인트, LFAST 효과는 +2.6과 +3.2 포인트입니다. 저자는 "거의 덧셈적"이라고 씁니다(Sec. 5.4).

**4.5 오프라인과 표현 분석 (Sec. 6, Fig. 5–7, Table 5).**
- 사람 데이터와 함께 있을 때 LFAST는 사람 새 에피소드에서 우측 손목 오차를 1.5–2.6 mm 줄입니다(Sec. 6.1). 로봇만 있을 때는 LFAST가 과적합을 만듭니다(held-out 로봇 과제 오차 +1.1 mm).
- 마지막 층의 사람 프레임에 대한 선형 프로브 R²는 0.089에서 0.143으로, 로봇 프로브의 사람 전이 r은 0.205에서 0.281로 오릅니다(Sec. 6.2).
- 같은 과제 이웃 비율(10-NN, 세 과제군)은 SHAPE 57%, w/o FAST 37%, 우연 33%입니다(Sec. 6.2).
- 백본 그래디언트의 70%(사람 배치)와 93%(로봇 배치)가 L_FAST에서 옵니다. L_FAST와 L_FM은 충돌하지 않습니다(코사인 −0.15–0.28, Sec. 6.3).
- 연속 회귀 헤드(L1 MLP, 그래디언트 크기 맞춤)는 프로브 R²를 0.230까지 올리지만 과제 구조(마지막 층 이웃 비율 0.40)를 깨뜨리고, H2R에서 18.3%로 SHAPE의 35.0%보다 낮습니다(p = 0.055, Table 5, Sec. 6.4).
- FAST 토큰을 테스트 때 디코딩하면 robot 창의 15%가 유효하지 않고 손목 오차가 1.4 mm 나빠집니다(Sec. 6.4, E.5). 토큰은 학습 목표로만 쓰고 실행은 전문가가 맡는다는 근거입니다.

## 5. 주장과 근거 사이의 간격

1. **단일 사전학습 실행.** 모델마다 사전학습을 한 번 했는지 논문에 명시되지 않습니다. 시드 반복도 없습니다. 모든 검정은 시도나 에피소드 수준의 분산만 반영합니다. "2×2 설계의 덧셈성"이나 작은 차이(예: LFAST +2.6 포인트)는 사전학습 실행 간 변동을 모릅니다.
2. **H2R에 기준선이 없습니다.** 초록의 "사람 데이터만으로 새 과제를 배운다"는 SHAPE 내부 비교(어블레이션)만으로 보였습니다. π0.5나 GR00T가 같은 사람 데이터로 얼마나 하는지는 모릅니다.
3. **관절 스트림의 H2R 0/240.** 저자는 리타게팅된 팔 자세가 로봇 분포 밖이라서 관절 오프셋이 전이되지 않는다고 설명합니다(D.2, Fig. S1). 대안(예: 손 관절 리타게팅 오차 자체, 또는 학습 설정)은 검증되지 않았습니다.
4. **RoboCasa 검정 방식.** Table 4의 p값은 1,200개 과제-시드 쌍을 독립으로 봅니다. 같은 과제의 시드는 독립이 아닙니다. 과제 24개를 단위로 한 쌍체 검정을 해 보면 SHAPE 대 π0.5(+7.5 포인트)는 여전히 유의하지만 LFAST 효과(+2.6)는 p = 0.04(Wilcoxon 0.057)로 약합니다(`analysis/robocasa_task_level.py`, `03_analysis.md` §5).
5. **어휘와 설정 불일치 가능성.** 본문 설명과 부록 설정이 대체로 맞지만, 실로봇 평가 조건(부분 점수의 단계 정의 등)은 부록 C와 S4에 의존합니다. 04 문서에서 검사합니다.
6. **공개 자료 없음.** 코드, 체크포인트, 데이터, 로봇 시연 공개 계획이 원문에 없습니다. 재현 가능성은 `04_claim_verification.md`에서 판정합니다.

## 6. 이 논문이 기여하는 것 (요약)

- 사람 데이터 지도에서 **이산 토큰 보조 목표가 백본 그래디언트를 지속적으로 주고**, 연속 헤드를 그래디언트 크기만 맞춰도 같은 효과가 나지 않는다는 통제 실험(Sec. 6.4).
- **같은 체크포인트에서 관절과 EEF 두 스트림을 실행하는 구조**와, 배치 방식 선택에 따라 결과가 뒤집힌다는 관찰(Sec. 5.3).
- 공개 데이터가 없는 상태에서도 **표 수치는 내부적으로 일관**합니다(`03_analysis.md` §2). 다만 통계는 시도 수준이라 과제 간 차이를 과대평가할 가능성이 있습니다.
