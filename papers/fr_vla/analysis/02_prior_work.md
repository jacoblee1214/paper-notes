# FR-VLA 선행연구와 공식 저장소 (arXiv:2610.25981)

본문의 `[n]`은 논문 참고문헌 번호입니다(`paper/paper.txt`의 References, 12쪽까지). 공식 코드 조사일은 2026-11-21입니다.

## 1. 선행연구 계보

FR-VLA는 세 흐름이 만나는 자리에 있습니다. 논문 §2의 분류를 따르고, 각 구성 요소의 출처를 함께 적습니다.

### 1.1 힘을 쓰는 정책 학습과 접촉 제어 (§2 첫 문단)

- 고전 접촉 제어: 하이브리드 위치/힘 제어 [25], 임피던스 제어 [26], 가변 임피던스 학습 [33, 34], 잔차 강화 학습 [30, 31].
- 힘을 쓰는 학습 정책: ForceMimic [32], Force Policy [21](상호작용 프레임을 추정하는 로컬 힘 정책), Reactive Diffusion Policy [29](촉각 입력).
- 힘 활용을 강제하는 학습: FACTR [35](시각을 점차 흐리는 커리큘럼으로 힘에 주의를 옮김), CRAFT [36](VLA의 모달리티 불균형을 변분 정보 병목으로 조절).

FR-VLA가 가장 가깝게 대비하는 것은 FACTR [35]와 CRAFT [36]입니다. 둘 다 "정책이 힘을 무시하지 않도록" 학습 쪽을 고칩니다. FR-VLA는 구조로 "언제 힘을 쓸지"를 정합니다.

### 1.2 힘을 쓰는 VLA와 접촉 의존 융합 (§2 둘째 문단)

| 방식 | 대표 연구 | 힘의 주입 위치 |
|---|---|---|
| 혼합 전문가 행동 디코더 | ForceVLA [18] | 행동 디코더 |
| 힘 프롬프트 + 교차 스케일 융합 | ForceVLA2 [14] | VLM 입력과 행동 전문가 |
| 토크 인지 설계 공간 | TA-VLA [19] | 토크-행동 공동 확산 디코더 |
| 빠른-느린 힘 적응 VLA | FAVLA [20] | 느린 VLM과 빠른 힘 경로 (세부는 원문 확인 필요) |
| 힘 증류 (학습 때만 사용) | FD-VLA [15], HapticVLA [39] | 잠재 토큰, 학생 정책 |
| 접촉 예측 기반 융합 | FoAR [10], 3D 세계 모델 정책 [40] | 미래 접촉 예측 |
| 촉각 토큰 주입 | Tactile-VLA [16], VLA-Touch [17], VTLA [37], OmniVTLA [38], TLA [13] | 촉각 토큰 |

FR-VLA의 차이는 힘 입력을 "행동 쪽 경로"에 두되, 그 경로로 들어갈 **주의 질량을 VLM 쪽 힘 쿼리가 정하게** 한다는 점입니다. 논문 §2 셋째 문단과 §3.3에서 이 점을 강조합니다.

### 1.3 교차 모달 질의 인터페이스 (§2 셋째 문단)

- Perceiver IO [22]: 잠재 배열이 구조화된 입력을 처리합니다.
- Flamingo [23]: 시각 특징과 언어 모델 사이의 게이트형 교차 주의입니다.
- BLIP-2 [24]: 고정된 시각과 언어 모델 사이의 질의 기반 인터페이스입니다.

FR-VLA의 힘 쿼리는 이 계열의 질의 인터페이스를 쓰되, 질의에 **위상 감독**을 줍니다([24]의 Q-Former와 구조는 다르지만 사용 관점은 같습니다).

### 1.4 구성 요소별 출처

| 구성 요소 (논문 위치) | 출처 | 우리가 확인한 것 |
|---|---|---|
| 힘 쿼리 토큰 (§3.2) | Perceiver IO [22], BLIP-2 [24] 계열 질의 | 식과 구조는 논문에 있음 |
| tanh 게이트와 엔트로피 감쇠 (식 2) | 논문 고유 설계 | 수식 확인 (`04_claim_verification.md` C14) |
| 어블레이션 기준 (표 2) | ForceVLA [18], TA-VLA [19] 계열 | 기준선 구현 출처는 논문에 없음 |
| 어댑터식 행동 브리지 (식 3–5) | VLA-Adapter [43] | 공식 저장소 있음 (아래 표) |
| VQ-VAE 토크나이저 (식 8–10) | van den Oord 외 [41] | 표준 방식 |
| FiLM 조건화 (식 11) | Perez 외 [42] | 0 초기화는 논문 고유 설정 |
| Cartesian impedance 시연 수집 (식 14) | 표준 제어식 [26] | 식 본문에 있음 |

## 4. 정리 (게시본에도 남는 절)

- FR-VLA의 구조적 주장은 "힘 노출"과 "힘 근거" 구분입니다. 이 구분은 기존 VLA 힘 주입 방식(§1.2)과 학습 쪽 대안(§1.1)을 나눠 봐야 이해됩니다.
- 공식 코드는 찾지 못했습니다. 기준선의 공식 저장소는 셋 있고 모두 허용적 라이선스(MIT, Apache-2.0)입니다.
- 어블레이션의 기준선 구현, 학습 설정, 백본은 논문에 없습니다. 재구현을 하려면 이 부분을 가정으로 채워야 합니다.
