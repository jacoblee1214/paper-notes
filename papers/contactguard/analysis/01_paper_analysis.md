# 01. 논문 분석: ContactGuard (arXiv:2608.13438 v2)

*ContactGuard: Pre-Contact Execution Monitoring with Action-Conditioned Latent World Models* (Gehan Zheng, Matthew Johnson-Roberson, Weiming Zhi; Vanderbilt University, University of Sydney). CoRL 2026 포스터(corl.org 공식 채택 목록). 분석 대상은 **v2(2026-11-14)** 이고, v1(2026-08-13)과의 차이는 §6에 정리했습니다. 이 문서의 표 번호, 절 번호, 식 번호는 v2 기준입니다.

## 1. 한눈에 보기

**문제.** 접촉이 많은 조작에서 실패는 대개 로봇이 접촉을 시작한 뒤에야 검출됩니다. 손목 카메라가 접촉 근처를 잘 보여 주지만, 그때는 이미 물체를 밀거나 놓쳤을 수 있습니다(초록, §1).

**제안.** 청크 정책(ACT 등)이 낸 행동 청크를 받아, 그 청크를 실행했을 때의 결과를 **잠재 공간에서 미리 굴려 보고**, 실패 확률이 임계값 τ를 넘으면 접촉 전에 중단하는 **접촉 전 모니터**입니다(그림 1, §3.5). 세계모델은 라벨 없는 궤적으로 학습하고, 실패 프로브는 라벨이 붙은 접촉 전 클립 약 250개로 학습합니다(§4.1).

**구성 요소**(§3.3, 부록 A):

| 요소 | 내용 |
|---|---|
| 인코더 | 고정 DINOv2-S(ViT-S/14, 224x224, CLS 384차원). 세 카메라의 CLS를 평균한 뒤 고정 선형 사영으로 z_t ∈ R^384 |
| 행동 임베더 | 1x1 시간 conv + 2층 MLP로 14차원 관절 행동을 384차원으로 |
| 예측기 | 4층 AdaLN-zero 인과 Transformer(폭 384, 8헤드, FF 1536, dropout 0.1) + 2층 예측 MLP(은닉 1536). 맥락 C = 3 |
| 파라미터 | 학습 13.2 M, 고정 인코더 21.8 M, 전체 35.0 M |
| 학습 | 차원별 표준편차로 나눈 다음 잠재 회귀(식 4), AdamW lr 1e-4, wd 1e-3, 30 에폭, 배치 40, cosine, 클리핑 1.0, 혼합 정밀도 |
| 프로브 | ℓ2 로지스틱 회귀(ρ = 1, 클래스 균형), 표준화는 학습 분할 통계(식 5, 6) |
| 온라인 | 계획된 청크에서 첫 그리퍼 열림→닫힘 전이를 찾고, 닫힘 15프레임(0.5 s) 전에 앵커, K = 30 스텝 롤아웃(닫힘 후 0.5 s), ẑ_{t+K}를 프로브에 넣음 |

**주장**(초록, 기여 4개):
1. 접촉 전 실행 모니터링이라는 문제를 정식화합니다.
2. 행동 조건 잠재 세계모델 모니터를 제안합니다.
3. 예측된 미래 잠재가 현재 관측과 행동만으로는 얻기 어려운 실패 정보를 준다고 보입니다(현재 잠재, Direct 기준선, 반사실 행동 교란).
4. 후보 행동 탐색, 픽셀 영상 예측, 정책 수정 없이 실로봇에서 접촉 전 중단 신호를 냅니다.

## 2. 방법의 세부

### 2.1 세계모델 (식 1–4)

- 데이터 D_wm은 V개 카메라 관측과 관절 공간 행동의 궤적입니다(식 1). 성공 라벨은 쓰지 않습니다.
- 예측기 P_θ는 길이 C의 잠재 맥락과 행동 하나로 다음 잠재를 냅니다: ẑ_{t+1} = P_θ(z_{t−C+1:t}, a_t)(식 2). LeWorldModel [11]의 인터페이스를 쓰되 SIGReg 규제항은 인코더가 고정이라서 뺍니다(부록 A "No SIGReg").
- 손실(식 4): 교사 강제 한 스텝 오차 m개(m = 3)와 자기회귀 롤아웃 오차를 희소 지평 집합 H = {1, 2, 3, 5, 8, 12, 18, 24, 30}에서 더하고, 각 차원을 인코더 잠재의 표준편차로 나눕니다(7,200개 잠재로 한 번 추정). 롤아웃 타깃은 stop-gradient입니다.
- 윈도 구성: 맥락 C = 3 뒤로 최대 30프레임의 실제 잠재가 필요합니다. 30 Hz에서 1 s입니다.

### 2.2 프로브 (식 5–6)

앵커 t = T_g − k_pre에서 롤아웃을 K 스텝 돌리고 ẑ_{t+K}만 입력으로 씁니다. K > k_pre이므로 읽는 시점은 계획된 닫힘 직후(T_g + 15프레임)입니다. 과제마다 (w, b)를 따로 학습하고, 임계값 τ는 검증 분할에서 Youden-J로 한 번 고릅니다(표 7 캡션).

### 2.3 온라인 모니터 (§3.5, 그림 1)

네 단계입니다. 트리거(첫 열림→닫힘 전이 위치 g 찾기), 앵커(닫힘이 k_pre 프레임 안에 있을 때 활성화), 롤아웃과 점수, 중단 결정(P(fail) > τ). 트리거는 학습이 없고 그리퍼 명령만 봅니다. 다른 접촉 사건(삽입, 미끄러짐)용 트리거는 "직교적"이라며 다루지 않습니다.

**평가 프로토콜의 핵심**(§4.1 "Closed-loop real-robot evaluation"): 모니터가 중단해야 할 때 로봇은 **그리퍼를 연 채 5초 멈춘 다음 남은 청크를 재개**하고, "중단하지 않았다면의 결과"를 기록합니다. 즉 이 표들은 실제로 중단했을 때 성공이 늘었는지가 아니라, 점수가 결과 라벨을 얼마나 가르는지를 잽니다.

## 3. 실험

### 3.1 설정 (§4.1, 부록 A, C)

- 로봇: 14자유도 AgileX Piper 양팔, RGB 카메라 3대(왼쪽, 가운데, 오른쪽). 정책은 ACT.
- 과제 네 가지: 컵(Cup)과 상자(Box) 집기(pick-and-place), 연필(Pencil, pencil-and-notebook), 수건(Towel, towel-fold). 파지 시도마다 성공/실패 이진 라벨(수동).
- 라벨 있는 집합은 과제당 "대략 250 시도"이고(§4.1), 라이브 시험은 따로 모은 과제당 N = 50회입니다. 클래스 수(N+/N−, 양성 = 실패): Cup 25/25, Box 22/28, Pencil 22/28, Towel 25/25(표 7). 학습, 검증, 시험 분할 크기와 라벨 없는 궤적 수는 본문에 없습니다.
- 비교: Single view(가운데 카메라만 쓴 같은 모델), Direct-linear(롤아웃 없이 (z_t, 행동 청크)로 선형 프로브), Current latent(z_t만 프로브), 외부 검출기 FAIL-Detect, RND, PCA-kmeans, SAFE.

### 3.5 저자의 해석 (§4.2–4.3)

멀티뷰가 Single view보다 BAcc와 AUC가 네 과제 모두 높고(AUC 이득 Box 최대 0.041, Towel 최소 0.014), Direct-linear는 AUC가 모든 라이브 과제에서 낮습니다(Cup, Pencil에서 격차 최대, Box는 "거의 동률"). 현재 잠재 기준선(표 2)이 일관되게 낮아 "롤아웃이 현재 관측 이상의 정보를 더한다"고 결론짓고, 상태를 빼면 오히려 AUC가 오르며(저자 해석: 고정 융합과 소량 데이터에서 과제별 지름길을 만들 수 있음), 행동 이식이 Δp를 올리므로 모니터가 "구체적인 대기 행동"에 반응한다고 합니다.

## 4. 한계 (저자, §5.1)

- 중단만 할 뿐 복구나 과제 완료는 다루지 않습니다.
- 결과가 다음 행동 청크 안에서 정해지는 임박한 접촉 사건만 대상입니다. 긴 호라이즌 기술에는 계층적 또는 반복 모니터가 필요합니다.
- 미래 과제: 중단 후 새 청크 선택, 재계획, Diffusion, Flow Matching, Streaming 정책과의 결합.

## 5. 주장과 증거 사이의 틈

각 항목의 수치는 `03`, 점검 번호는 V, 주장 대조는 `04`의 C 항목입니다.

1. **"실패를 막는다"는 평가되지 않았습니다.** 평가는 5초 정지 후 재개로 "중단하지 않았다면의 결과"를 기록하는 방식이라, 중단 후 성공률이나 피해 감소는 측정하지 않았습니다. "live real-robot pre-contact aborts"(기여 4)는 중단 신호가 나온다는 의미로 읽는 것이 맞습니다(§4.1, `04` C2).
2. **핵심 비교(롤아웃 대 직접 예측)의 AUC 간격이 시행 50개에서 작습니다.** Box 0.966 대 0.963(쌍 환산 약 2개), Towel 0.904 대 0.898(약 4개)입니다. 평균 간격은 v1 0.225에서 v2 0.048로 줄었습니다(`03` V6, V13).
3. **모든 비교의 표본이 과제당 25–28개 클래스입니다.** 쌍을 이루는 검정이 없고, AUC 신뢰구간도 없습니다. Hanley-McNeil 근사로 검출 가능한 AUC 차이는 상관 0.5 가정에서 약 0.11입니다(`03` V16).
4. **유병률 의존.** 표 7의 시험 집합은 실패 44–50%입니다. 정밀도는 이 비율에 의존하고, 실제 실패율이 10%이면 Box의 정밀도는 약 0.31로 내려갑니다(재현율, FAR 고정 가정, `03` V14b).
5. **반사실 행동 교란의 해석.** Transplant는 다른 시도의 행동을 이 관측에 붙이므로 관측과 행동이 어긋난 입력입니다. Δp 증가가 "행동의 결과를 예측한다"는 뜻인지, "어긋난 입력에 낮은 신뢰"인지 이 설계로는 가를 수 없습니다. Towel의 Δp > 0 비율 0.64는 25개 중 16개로 부호 검정 p = 0.115(단측)입니다(`03` V10).
6. **고유감각 절제의 결론 범위.** 융합이 초기화 값으로 고정되어 있어 "상태가 해롭다"가 아니라 "이 융합 설계는 도움이 되지 않는다"입니다. 저자도 같은 한계를 적었습니다(§4.3).
7. **외부 검출기 비교의 의미.** FAIL-Detect, RND, PCA-kmeans의 Box AUC가 0.28–0.33으로 0.5 아래입니다(부호를 뒤집으면 0.67–0.72). 성공 데이터로만 학습한 이상 점수가 이 과제에서는 실패에 더 낮은 점수를 준다는 뜻이고, 이 기준선들이 이 설정에서 작동하지 않았음을 보여 줄 뿐입니다. 입력 정의는 "Baseline inputs are defined in the text"라는 한 문장 외에 본문에 없습니다(표 2 캡션, §4.1).
8. **코드와 데이터 부재.** 공식 코드, 프로젝트 페이지, 데이터가 확인되지 않아(2026-11-26) 위 항목을 재실행으로 확인할 수 없습니다(`04`, `02` §4).
