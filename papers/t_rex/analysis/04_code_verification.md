# 04. 공식 코드와 논문 대조 (정적 읽기)

대상: `ZhuoyangLiu2005/T-Rex` main `ba4047ce3e9f3d2013d60de600e136897e90ccb8` (2026-10-08), `full-pipeline` 브랜치 `b23eafe` 중 `midtrain.py`, `midtrain.sh`, `pretrain.sh`, `prepare_midtrain_merged.py`. **코드를 실행·임포트·설치하지 않았습니다.** 내려받은 내용은 신뢰하지 않는 데이터로 다뤘습니다.

## 1. 라이선스와 공개 범위

- 코드 MIT(저작권 UC Regents), HF 데이터셋·체크포인트 카드도 MIT.
- main은 사후학습·추론 서버·텔레옵 스택·VQ-VAE·데이터셋 도구입니다. 사전·중간학습 코드는 `full-pipeline` 브랜치(2026-06-01)에 있고, 사전·중간학습 코퍼스는 공개되지 않았습니다(README).
- 공개 체크포인트: 사전학습(~22k 에피소드, 1 epoch)과 중간학습(6 epoch, VQ-VAE 내장). 공개 데이터 5,464 에피소드 약 50.7시간, 1.55 TB.

## 2. 논문 ↔ 코드 차이 (D)

일치한 항목: 청크 16, 행동 62차원, N=10·Kslow=6·τsplit=0.4(`train.py` 기본 `cascaded_*`), Beta(1.5,1.0) 샘플링(`train.py` `_beta_sample`)과 τtac=τsplit·τ̃, λtac=1.0, λfuture=0.5, 두 전문가가 같은 v*=ε−A를 회귀, 행동 전문가는 (0,1] 전체 훈련, KV 재인코딩(`refresh_clean_kv`), 촉각 토큰 10+10+10 구성(식 2), VQ-VAE(K=64, 256차원, T=16, 손가락 공유 가중치+손가락 ID, EMA+재시드, 크기 가중), 지연 증강 {0,4,8,12}(중간학습 스크립트), 촉각 전문가 FFN 1536과 0.62B(`03` V16), AdamW 1e-4·wd 0·클립 1.0.

## 3. 운영상 주의

- 추론 서버(`scripts/test.py`)가 `0.0.0.0`에 ZMQ REP 소켓을 열고 `pickle.loads`로 요청을 받습니다. 인증이 없어 신뢰하지 않는 네트워크에서는 원격 코드 실행 위험이 있습니다.
- 체크포인트 로딩이 `torch.load`(일부 `weights_only=False`)를 씁니다. 출처가 확인된 파일만 열어야 합니다.
- 저장소는 약 673 MB(얕은 복제), URDF·USD 자산이 대부분입니다.

## 4. 구현 가능성 (이 맥: Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)

**전체 재현은 불가능합니다. 구조의 축소판과 수치 재계산은 가능하고 재계산은 끝냈습니다.**

| 수준 | 판정 | 근거 |
|---|---|---|
| 실로봇 평가(표 1, 2) | 불가 | Dexmate Vega-1, Sharpa Wave 손, Manus 장갑, VIVE 트래커가 필요 |
| 사전·중간학습 | 불가 | 코퍼스 비공개, H100 24장 규모. 4.2B 모델 AdamW 전체 미세조정은 대략 67 GB(`03` V16) |
| 공개 체크포인트로 사후학습 | 불가(이 맥) | 코드가 CUDA, DeepSpeed, bf16을 전제하고 메모리가 모자람 |
| 추론(체크포인트 8.5 GB) | 조건부 | bf16 가중치는 24 GiB에 들어갈 수 있으나 CUDA 전제 코드의 MPS 이식, 다운로드, 실행 승인이 필요. 속도는 측정 전 |
| VQ-VAE(작은 conv) 학습 | 가능 | 소형 모델. 공개 데이터의 힘 열만 필요(수 GB, 다운로드 승인 필요) |
| 흐름 매칭 계단식 구조의 축소판(소형 트랜스포머) | 가능 | 새 설치 없이 torch로 구현 가능 |
| 표 재계산 | 가능, 완료 | `recompute.py` |

노력 추정(측정 전): 계단식 축소판 구현 3–5일, VQ-VAE 재학습 실험 3–5일, 공식 코드 MPS 이식 추론 1–2주.
