## 1. 문제와 주장

모바일 매니퓰레이터는 물체뿐 아니라 물체가 놓인 공간(탁자, 선반, 서랍, 가림)에 맞춰 베이스 위치, 팔 궤적, 시선, 잡는 방식을 바꿔야 합니다. 저자들은 이를 **문맥적 전신 조작(contextual whole-body manipulation)**이라 부릅니다(§1). 장면마다 RL을 직접 돌리면 장면 표현, 보상 설계, 고차원 행동 공간이 한꺼번에 어려워지므로(§1), 문제를 둘로 나눕니다.

1. **전역 자유공간 접근:** 환경을 아는(environment-aware) 전신 제어기(WBC)가 맡습니다. 기하 패브릭(geometric fabrics)으로 구현하고, 입력은 말단 목표 자세와 응시점뿐입니다(§3.1).
2. **국소 접촉 상호작용:** 국소 장면(상자, 선반 같은 직육면체 영역)에서 RL 전문가를 학습합니다. 전문가는 3종입니다. top-down, side, constrained side(§3.2).
3. **증류:** WBC와 전문가를 이어 붙인 교사(teacher)를 전체 장면 8192개에 넣고, 점군을 입력으로 받는 트랜스포머 학생 하나로 DAgger 증류합니다(§3.3).

주장(초록, §5, 결론):

- 실환경 24개 장면, 물체 약 100개에서 평균 **91%** 파지 성공(그림 5, 표 3).
- 시뮬레이션 보류(held-out) 8,000개 환경·물체 150개에서 학생 92.4%, 교사 95.6%(표 2).
- end-to-end RL은 0%, ManipGen은 63.1%(표 1).
- 관측 설계 세 요소(능동 시각, LiDAR, 렌더링된 부분 관측)가 모두 실환경에서 필요하다(표 3).
- fabric WBC가 가중 IK와 "충돌 회피 없는 fabric"보다 낫다(표 4).

## 2. 방법

### 2.1 로봇 (그림 2, 부록 C.1)

전방향 TidyBot++ 베이스(3 DoF) + Franka 팔(7) + LEAP 손(16) + 카메라를 든 ARX X5 팔 "목"(6) = **32 DoF**. 베이스에는 Unitree L2 LiDAR, ARX 팔 끝에는 RealSense D435가 있습니다. WBC의 구성 공간은 q = [x, y, θ, q_Franka, q_ARX]이고 LEAP 손은 패브릭 상태에 포함하지 않습니다(부록 C.1).

### 2.2 벡터화 fabric WBC (§3.1, 부록 A–C)

- 식 (1): 각 작업 공간 i의 사상 x_i = φ_i(q), 메트릭 M_i, 힘 f_i를 관절 공간으로 당겨와(pullback) 합칩니다. Σ J_iᵀ M_i J_i · q̈ + Σ J_iᵀ (f_i + M_i J̇_i q̇) = 0. B개 환경의 텐서 q ∈ R^{B×n}, J_i ∈ R^{B×m_i×n}, M_i ∈ R^{B×m_i×m_i}를 배치 행렬곱으로 계산하므로 계산 그래프 모양이 고정입니다. 그 뒤 에너지화(energization)를 적용합니다(부록 C.8).
- 식 (2): 거리 게이트 메트릭 M(x) = η diag( m_far + (m_min − m_far)(½ tanh(−α_m (dist − r_m)) + ½) ). 베이스 어트랙터(BA)는 m_min = 0이라 목표가 팔 작업 공간에 들어오면 사라지고, 말단 어트랙터(EEA)는 m_far = 0이라 가까워질 때만 켜집니다. 그래서 먼 곳은 베이스가, 가까운 곳은 팔이 맡는 coarse-to-fine이 나옵니다(§3.1, 부록 C.2–C.3).
- 항 목록(부록 C): EEA, BA, 자세 정칙화(PR), 관절 한계 반발(JLR), 몸체 반발(BR, 충돌 구와 직육면체·캡슐·구 사이 거리, Warp 커널), 시선 어트랙터(GCA, 카메라 광축을 응시점으로).
- 규모: 60 Hz, 최대 4096개 서로 다른 환경, 환경당 제어 스텝 0.03 ms(§3.1). 이 수치의 측정 조건은 적혀 있지 않습니다(`03` V9).

### 2.3 국소 RL 전문가 (§3.2, 부록 D)

- 국소 정책(ManipGen [33] 형식): 말단 좌표계 관측, 말단 상대 행동. 행동 a ∈ [−1, 1]^22 = 말단 이동 3 + 회전 3 + LEAP 16(D.2, α_p = α_R = 0.6, α_h = 3.0, Δt = 0.01667).
- 관측(배우): 61차원(표 6). 비대칭 critic: 106차원(표 7).
- 보상(D.4): R_top = 1.0 r_hand,obj + 4.0 r_obj,goal + 2.0 r_lift + 0.5 r_curl − 0.001 r_act, r_hand,obj = exp(−5.0 d_hand,obj), r_obj,goal = I[lift] exp(−5.0 d_goal). side 전문가는 손 방향 항 2.0 r_hand,ori를 더합니다. 충돌 벌점은 없습니다("WBC가 충돌 없는 행동을 만들기 때문", D.4).
- 학습(D.5, 표 8): 비대칭 PPO, Isaac Gym, 환경 8192개, A6000 한 장, 수렴까지 약 **36시간**, 전문가 3종 각각. 학습률 5e-4(적응형), KL 0.008, 클립 0.2, horizon 32, 미니배치 8192, 5 미니 에폭.
- 무작위화(표 9, 10): 관측·행동 잡음, 중력, 관절 댐핑·강성, 마찰, 물체 질량(0.2–0.8배), 물체 외력(0.5 → 5 N까지 선형 증가), 200,000 스텝에 걸친 선형 스케줄.

### 2.4 전체 장면 다중 교사 증류 (§3.3, 부록 E, F)

- 장면 생성: 전문가 종류마다 호환되는 장면 가족(탁자·서랍·상자, 길쭉한 물체, 선반)을 절차적으로 만들고, 국소 영역을 그 안에 끼웁니다(그림 3, 9). 로봇은 목표에서 0.2–2 m에서 시작합니다.
- 교사: 접근 단계(WBC가 스테이징 자세까지 접근, 시선 유지) + 상호작용 단계(전문가 행동을 WBC로 실행).
- 학생(그림 4, E.4–E.5): 점군 3072점(깊이 카메라와 LiDAR 각각 기저 크롭 1024 + 물체 크롭 512) → PointNet 집합 추상화로 128 토큰, 상태 토큰 5개 → 6층 인코더 + 6층 디코더(폭 128, 8 헤드, FFN 1024). 출력은 32차원 전신 행동(베이스 속도 3 + Franka 7 + LEAP 16 + ARX 6). 보조 머리가 목표 물체 위치의 3차원 갱신량을 예측합니다(스케일 0.01 m). 손실 L = L_act + 0.1 L_obj(MSE).
- 센서 시뮬레이션(부록 F): 장면과 로봇 메시에서 점을 뽑아 z-버퍼와 방위·극각 격자로 가림을 없앱니다. A6000 한 장에서 환경 1024개에 깊이(212×120) 0.07 s, LiDAR(32768점) 0.25 s.
- 학습(E.5): 8장의 A6000, 약 **60시간**, 랭크당 환경 512개, 온라인 DAgger. 처음 10k 그래디언트 스텝은 교사 행동으로 실행하고 그다음 10k 스텝에 걸쳐 0으로 줄입니다. 객체 순간이동 증강(ρ_tele = 0.2)도 씁니다(E.7).
- 실환경 목표 지정(§4, E.6): SAM3 마스크의 점군 중심을 목표 위치 초기값으로 쓰고 이후 정책이 자기회귀로 갱신(60 Hz), SAM3가 3 Hz로 덮어씁니다.

## 3. 실험과 수치

### 3.1 실환경 (§4, 그림 5, 그림 6, 표 3)

- 24개 장면(탁자 여러 높이, 선반, 상자, 의자, 냉장고, 서랍, 혼합), 장면마다 **고정 20개 물체 + 무작위 5개(100개 풀에서)**, 물체마다 **3가지 방향** → 장면당 75회, 총 1,800회(이 곱셈은 §4의 서술에서 계산한 것이며 총 시도 수가 직접 적히지는 않았습니다).

## 4. 저자가 인정한 한계 (§6)

잡는 방식을 장면과 물체 맥락만으로 정하므로, 같은 물체에 여러 유효한 잡기가 있는 "기능적" 파지에는 추가 조건이 필요합니다. 그 밖에 쓰이지 않은 한계가 `04` §2에 있습니다(규모 효과 실험 없음, 시드·신뢰구간 없음, 실험 시작 전 검출 실패 제외 등).
