## 3. 재현에 필요한데 논문에 없는 정보

- **고정·학습 구분:** 2단계에서 시각 백본을 어떤 학습률로 얼마 동안 학습했는지, 고정 3 epoch 뒤 전체 학습의 학습률.
- **손실 가중치** λ_ADD, λ_attr, λ_pen 값, 그리고 n_t(축별 정규화기 0.01 m)를 쓰는 식의 세부.
- **구조 크기:** 관절 토큰 입력 C(추정 7: q, q̇, F/T 3축, 접촉, 가용 플래그), 헤드 수 H, Graphormer 층 수, 손가락 풀링 질의 수, transformer 헤드 수, 두 transformer 층의 차원.
- **학습 설정:** 최적화기, 배치, epoch, 학습 데이터 분할(깨끗 2,000 / 가림 1,000 프레임이 학습과 평가를 어떻게 나누는지), 시드 정의.
- **가림 증강의 분포:** 사각형 마스크의 위치와 크기 분포, 힘 채널 증강의 크기.
- **정책:** 재배향 RL 정책의 구조, 학습 스텝, 관측(ground-truth 자세 외 입력), 성공 판정 기준의 구현.
- **지표:** ADD인지 ADD-S인지(대칭 물체 처리), 프레임 단위 ADD의 단위와 교란 분포.
- **Table III:** 기준 시점, 궤적 수, 프레임 레이트, 힘 센서 보정.
- **영 입력 실험:** 학습 절차, 결과 표.
- **하드웨어:** F/T 센서의 좌표계와 보정, 접촉 임계값, 제어 주기.
- **계산 자원:** GPU 종류, 학습 시간, 파라미터 수.

## 4. 구현할 수 있는지

### 4.1 공식 코드로 재현: **불가능**

- 공개 코드, 가중치, 데이터, 학습 스크립트가 없습니다. 저장소는 프로젝트 페이지입니다(`02` §5).
- 시뮬레이션 데이터는 IsaacLab으로 만드는데, IsaacLab은 NVIDIA GPU(CUDA)가 필요합니다. FoundationPose 시각 백본도 CUDA 확장을 씁니다.
- 실환경 검증에는 저자 그룹이 만든 16자유도 F/T 손(Park & Hwang [35])이 필요합니다.
- 따라서 논문 결과 재현은 공개 자료로 불가능합니다.

### 4.2 이 맥(Apple M4 Pro, 약 24 GiB 통합 메모리, MPS 사용 가능, CUDA 없음, torch 미설치)에서

| 작업 | 가능 여부 | 근거 |
|---|---|---|
| 표 재계산과 유의성 | **가능, 완료** | `table_check.py`, CPU 0.3초 |
| 노름, 드리프트 toy | **가능, 완료** | numpy, 각 수 초 |
| FoundationPose 추론 | **불가** | CUDA 확장 필요 |
| IsaacLab 데이터 생성 | **불가** | Isaac Sim은 NVIDIA RTX GPU 필요 |
| 소형 융합 모델 학습(합성 데이터) | **조건부** | torch(MPS) 설치 승인 필요. 설치 전 목록을 보여 줘야 함 |
| 실물 손 재현 | **불가** | 하드웨어 없음 |

### 4.3 아이디어만 다시 구현

- **난이도: 중간.** 손가락 토큰화, 손가락 내 마스크 attention, 16→4 풀링, URDF 편향 Graphormer 층은 PyTorch로 수백 줄입니다. 구현 자체는 어렵지 않습니다.
- **가장 큰 장벽은 데이터입니다.** 고유감각, 근위 F/T, 접촉이 함께 기록된 in-hand 시퀀스에 물체 자세 GT가 있어야 합니다. 공개 자료에서 이 조합을 찾지 못했습니다. ALOHA류 데이터에는 F/T가 없고, 다지 손 데이터에는 촉각 신호가 없는 경우가 많습니다.
- **평가 설계의 장벽:** 프레임 평가와 chain 평가를 같이 보고, 학습 절차를 맞춘 영 입력 대조, 고유감각 대조가 필요합니다. 논문이 빠뜨린 대조들입니다.
- **하드웨어:** 재현용 최소 구성은 촉각이 있는 손(또는 손가락별 토크·전류 신호) 하나와 RGB-D 카메라입니다. 근위 F/T가 없는 손이라면 `beyond_implicit_force`의 전류 대리값으로 대신할 수 있지만, 검증은 별도로 필요합니다.

### 4.4 판정 요약

- **공식 재현:** 불가능(코드·데이터·GPU·하드웨어).
- **이 맥에서 할 수 있는 것:** 수치 재계산과 toy는 끝났습니다. 소형 모델 학습은 torch 설치 승인 뒤에 가능하지만 데이터 생성이 막힙니다.
- **아이디어 재구현:** 중간 난이도. 데이터(촉각 + 자세 GT)가 가장 큰 제약입니다.

**한 줄 판정: 공식 재현은 불가능하고, 이 맥에서는 계산 검증까지만 가능합니다. 아이디어 재구현은 구조 자체는 쉽지만 촉각·자세 데이터 확보가 어려워 조건부입니다.**

## 5. 검증 방식 요약

- 표 I, II, III 값은 PDF 텍스트와 렌더링을 대조해 옮겼습니다(`table_check.py` 상수).
- 평균, 비, 유의성, 상관은 `table_check.py`로 재계산했습니다.
- 노름과 드리프트의 메커니즘은 `norm_dominance_toy.py`, `drift_toy.py`의 가정 모델로만 시험했습니다. 논문 실험을 재현한 것이 아닙니다.
