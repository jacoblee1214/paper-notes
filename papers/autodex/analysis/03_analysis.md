## 3. 파생 식과 유도

**(a) Wilson 구간.** 관측 비율 p̂ = k/n, z = 1.96.
center = (p̂ + z²/2n) / (1 + z²/n), half = z √(p̂(1−p̂)/n + z²/4n²) / (1 + z²/n).

**(b) Newcombe 차이 구간.** 두 Wilson 구간 [l1, u1], [l2, u2]에서 d = p̂1 − p̂2,
L = d − √((p̂1 − l1)² + (u2 − p̂2)²), U = d + √((u1 − p̂1)² + (p̂2 − l2)²).

**(c) 라벨 오차와 관측 성공률.** 거짓 성공 비율 e0(참 실패를 성공으로), 거짓 실패 비율 e1(참 성공을 실패로)이면 관측 성공률은
q = e0 + (1 − e0 − e1) p, 따라서 참 성공률 p = (q − e0) / (1 − e0 − e1).
관측 q = 53.2%일 때 (e0, e1) = (0.02, 0.02)이면 p = 53.3%, (0.10, 0.02)이면 49.1%, (0.02, 0.10)이면 58.2%다. 즉 **라벨 오차 10%면 참 성공률이 ±5 pp 움직인다.** 자동 라벨의 오차율을 보고하지 않은 상태에서 53.2%를 "생성기의 성공률"로 읽을 수 없다.

**(d) 선택 편향.** 라벨이 붙는 시도만 DB에 남을 때(라벨 지시자 L), 남는 집합의 성공률은
E[y | L=1] = E[p·L] / E[L]이고, 차이는 E[y | L=1] − E[p] = Cov(p, L) / E[L]이다.
라벨 가능성이 난이도와 음의 상관이면 Cov(p, L) > 0이므로 DB 성공률이 과대 추정된다. 이것이 토이 B의 선택 편향이다. 논문 코드는 "사진이 없는 시도"를 버린다(04 D4). 그 조건이 난이도와 관련되면 Cov ≠ 0이다.

**(e) 처리량 모형.** 벽시계 시간 T = Σ_i loop_i + N·o + Σ_{리셋 j} 1[실패_j]·T_int, 사람 시간 H = Σ_j 1[실패_j]·H_int.
논문 값으로 보정하면 N = 500, loop 평균 48.2 s, o = 26 s(10.3 h − 6.69 h를 500회로 나눈 값). 이 o는 리셋 시간과 개입을 모두 담는다고 가정한 값이다. 리셋 시간과 실패율이 따로 보고되지 않아서 분해할 수 없다.
개입 31회를 리셋 실패로 설명하려면, 리셋이 r회 시도마다 한 번이라면 q = 31 / (500/r). r=1이면 q = 6.2%, r=3이면 18.7%, r=10이면 62%다. 어떤 r이 맞는지는 본문에 없다.

**(f) 개입 시간 예산.** 사람 0.2 h = 720 s, 개입 31회면 회당 23 s다. 벽시계 예산 3.61 h가 모두 개입이라 해도 회당 419 s까지 가능하다. 그러나 개입 한 번이 600 s(토이 가정)라면 31회는 5.2 h가 된다. 그러면 전체 벽시계는 6.69 + 5.2 = 11.9 h가 되어 10.3 h와 맞지 않는다. 따라서 개입 한 번의 벽시계 비용은 최대 419 s(3.61 h ÷ 31, 루프 밖 시간 전부가 개입이라고 가정한 상한)보다 작아야 한다. 이 제약은 본문 수치들 사이의 내적 일관성 조건이다.

해석:
- **순위는 대체로 견딘다.** 균일 오차 10%에서도 AUC는 0.001 미만(N=3,593), 0.011(N=200) 떨어진다. 상위 20% 정밀도는 거의 그대로다. 검색(ranking)으로 쓰는 경우 라벨 오차 자체는 큰 문제가 아니다.
- **절대 성공률은 편향된다.** 거짓 성공이나 거짓 실패가 한쪽으로 치우치면 예측 평균이 ±4–5 pp 움직인다. 논문 53.2%나 "생성기 성공률" 같은 절대값을 말할 때 문제가 된다.
- **특징 의존 오차는 더 나쁘다.** x0이 큰 시도(어렵다고 가정한 자세)에서 거짓 실패가 늘면 기울기가 0.70까지 줄고 편향이 −5.3 pp가 된다. 어려운 자세일수록 라벨이 나쁘면 "어려움"이 과소평가된다.
- **한계.** 토이의 신호는 강하다(AUC 0.82). 신호가 약하면 순위 손실이 커진다. 실제 파지 성공 신호는 이보다 약할 가능성이 높다. 결론은 방향만 쓴다.

| 3회마다 (r=3) | 10.3 h | 10.8 h (46.1) | 11.7 h (42.9) | 13.1 h (38.3) | 15.8 h (31.6) |
| 10회마다 (r=10) | 10.3 h | 10.5 h (47.7) | 10.7 h (46.7) | 11.1 h (44.9) | 12.0 h (41.8) |

개입 수는 r=1, q=6.2%일 때 약 31회다. 이때 벽시계는 10.3 h + 31 × 600 s ≈ 15.5 h로 10.3 h보다 크다. 그러므로 **본문 10.3 h와 31회 개입은 개입 한 번이 600 s가 아니어야 맞는다.** 리셋이 드물거나(r ≥ 10) 개입이 짧으면 두 값은 맞는다. 처리량의 민감도는 리셋 빈도와 개입 시간에 달려 있다.

**선택 편향 (라벨 가능성이 난이도와 결합, 후보 20,000개, 40 반복):**

| γ (결합 세기) | 라벨 가능 비율 | 라벨 DB 성공률 − 전체 후보 | 상관 |
|---|---|---|---|
| 0 | 69.0% | −0.06 pp (sd 0.39) | 0.00 |
| 0.5 | 68.1% | +3.0 pp (sd 0.42) | 0.21 |
| 1.0 | 66.1% | +5.7 pp (sd 0.45) | 0.38 |
| 2.0 | 62.0% | +9.5 pp (sd 0.46) | 0.58 |

전체 후보 성공률은 46.0%다. γ가 클수록 라벨 가능 비율이 줄고, DB 성공률이 최대 9.5 pp 과대 추정된다. 이 편향은 "DB 성공률"을 생성기의 성공률로 해석할 때 생긴다. 검색 실험의 42 pp 격차를 설명하지는 못한다. 격차는 검증 행위 자체에서 온다. 다만 기준선(모델 선별 집합)과 검증 DB가 같은 "라벨 가능" 필터를 거쳤는지 논문은 말하지 않는다. 기준선이 필터를 거치지 않았다면 격차는 필터 효과를 포함한다.

스크립트: `analysis/extra_label_rules.py` → `analysis/extra_label_rules_results.json` (numpy 단일 스레드, 1초 미만).

### 추가 검증 1: 라벨 규칙 세 가지를 같은 합성 궤적에 적용

**목적.** 공식 코드에 있는 성공 라벨 규칙 세 가지가 같은 시도에 대해 얼마나 같은 판정을 내는지, 불일치는 어떤 행동에서 생기는지 본다. 세 규칙은 (1) 본문의 "5 cm 이상 3 s 유지", (2) 실행 중 charuco 보드 가시성, (3) 데이터셋의 "높이 최댓값 50 mm 이상"이다(`04` D1·D2 근거).

**설정(가정).**
- 궤적 20,000개, 10 Hz, 8 s. 행동 여섯 가지와 확률은 다음과 같다. 파지 유지 0.40, 유지 중 미끄럼 0.15(튕김 확률 0.3), 짧게 들었다 떨어뜨림 0.15, 손이 보드를 가린 유지 0.15, 기울어진 유지 0.05, 들리지 않음 0.10.
- 측정 높이 잡음 σ = 5 mm.
- Cc(charuco): 들어 올린 높이 ≥ 3 cm인 프레임 중 보드가 보이는 프레임이 하나라도 있으면 성공. 보드는 손에 가려지거나 기울기 ≥ 60°이면 보이지 않는다.
- Cz(최댓값): 측정 높이 최댓값 ≥ 50 mm이면 성공. 지속 시간 조건은 없다.
- C3(본문): 측정 높이 ≥ 50 mm가 3 s 이상 연속이면 성공.
- 참 값(GT): 실제 높이 ≥ 50 mm가 3 s 이상 연속(잡음과 가림 없음).

**결과.**

| 규칙 | 성공률 |
|---|---|
| GT | 38.4% |
| C3 (5 cm·3 s) | 35.3% |
| Cc (charuco) | 89.3% |
| Cz (최댓값 50 mm) | 89.3% |

일치율: C3와 GT 96.5%, Cc와 GT 48.4%, Cz와 GT 49.1%, Cc와 Cz 99.3%, C3와 Cc 45.4%.

GT 실패 중 성공으로 판정된 비율은 C3 0.4%, Cc 83.2%, Cz 82.6%다. GT 성공 중 실패로 판정된 비율은 C3 8.6%(경계 근처의 잡음), Cc 0.9%, Cz 0%다.

행동 유형별 성공률(GT / C3 / Cc / Cz)은 다음과 같다. 파지 유지 0.60 / 0.55 / 1.00 / 1.00, 미끄럼 0.18 / 0.16 / 1.00 / 0.98, 짧은 들어 올림 0 / 0 / 1.00 / 1.00, 가림 유지 0.60 / 0.55 / 0.98 / 1.00, 기울어진 유지 0.59 / 0.54 / 1.00 / 1.00, 들리지 않음 0 / 0 / 0 / 0.

**결론.**
- 짧은 들어 올림, 미끄럼, 튕김을 세는 두 규칙(Cc, Cz)은 서로 99%로 같지만 GT와는 절반만 맞는다. 둘 다 지속 시간을 보지 않기 때문이다.
- 본문 규칙(C3)은 GT와 96%로 맞는다. 불일치는 높이가 경계(5 cm) 근처인 시도에서 잡음 때문에 생긴다. 보드 가림은 C3에 영향을 주지 않는다.
- 규칙 선택만으로 같은 합성 혼합에서 성공률이 35%에서 89%까지 움직인다. §2.2에서 "두 팔의 라벨 규칙이 같은지 불분명하다"고 한 것은, 어떤 규칙이 DB를 만들었는지에 따라 53.2%의 해석 범위가 매우 넓어진다는 뜻으로 읽어야 한다. 이 크기는 행동 혼합에 달려 있으므로 방향으로만 읽는다.
- **한계.** 행동 혼합, 가림과 잡음의 확률은 설계값이다. 실제 DB의 행동 분포는 알 수 없다. 실제 charuco 판독은 다시 만들지 않았다(검증용 영상이 없음).
