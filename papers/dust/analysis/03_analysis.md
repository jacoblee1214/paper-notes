  - 100k와 1M에서 backprop보다 낮아지는 지점

- **극한 재적합:** Table 1의 ∞ 행을 다섯 칸 power law로 다시 적합하면 7.162 / 5.892 / 5.013 / 4.434로, 보고값과 같습니다.

실험이 놓인 구간은 다음과 같습니다.

| 예산 | step 수 (16,384 토큰/step) | 토큰/파라미터 | backprop 손실 | ln V = 8.32 대비 줄어든 비율 |

- "Dust가 backprop을 넘는다"는 두 칸(100k, 1M)은 **업데이트가 6번과 61번**인 구간입니다. 이 구간의 손실은 학습률, 모멘텀, 초기화, 업데이트 잡음에 크게 좌우됩니다. gradient 방향의 질을 비교하는 실험으로 읽기는 어렵습니다.
- Fig. 4의 모델 크기 비교(10M 토큰)에서 243M 모델의 토큰/파라미터는 0.04입니다. backprop에서도 243M(5.048)이 38M(5.015)보다 나쁜 구간입니다.

## 2. 연산량: "같은 토큰"이지 "같은 연산"이 아니다

부록 Table 3·4의 draw 배분과 "블록 l부터 다시 계산" 규칙으로 update 한 번의 연산량을 forward 횟수로 환산했습니다(`table_check.py` R2).

- **계산에 쓴 비용:**
  - 블록 하나: 12d² + 2·ctx·d MAC/토큰
  - head: d·V
  - attention 내부 draw는 그 블록의 attention만, head draw는 캐시된 logit의 256열만 다시 계산합니다.

| population K | forward 환산 / update | backprop step(≈ forward 3회) 대비 | 같은 K의 EGGROLL 대비 |
|---|---|---|---|
| 256 | 229 | 76배 | 0.89 |
| 1k | 864 | 288배 | 0.84 |
| 4k | 3,404 | 1,135배 | 0.83 |
| 16k | 13,565 | **4,522배** | 0.83 |

- **draw 한 번의 비용:** 평균 0.82 forward입니다. 논문의 "draw는 forward보다 조금 싸다"와 맞고, "256 이상에서 EGGROLL보다 연산이 적다"도 맞습니다.
- **같은 연산량이면:** 1M 토큰에서 K = 16k인 Dust와 같은 연산이면, backprop은 약 45억 토큰을 학습할 수 있습니다. 논문 표에서 backprop은 20M 토큰만으로 4.633에 이르고, 이는 Dust의 어떤 1M 칸(최저 5.911)보다 낮습니다. 저자들도 "연산 효율은 목표가 아니다"라고 밝혔지만, TL;DR의 "backprop을 넘는다"는 이 조건을 붙여서 읽어야 합니다.
- **10³–10⁴배 효율:** 이 수치는 **EGGROLL 대비 population(= forward 수) 효율**입니다. backprop 대비가 아닙니다.

## 3. 20M의 "backprop보다 낮은 극한"은 한 칸에 달려 있다

Table 1의 20M 다섯 칸에서 한 칸씩 빼고 다시 적합했습니다(`report/figures/ladders.png`).

| 뺀 칸 | 64 | 256 | 1k | 4k | 16k | (모두 사용) |
|---|---|---|---|---|---|---|
| 극한 | **4.679** | 4.599 | 2.567 | 4.463 | 4.608 | 4.434 |

- **결론이 한 칸에 좌우됩니다.** 64 draw 칸을 빼면 극한이 backprop(4.633)보다 높아집니다. 1k 칸을 빼면 2.57로 발산에 가깝게 흔들립니다. 지수 α = 0.146으로 매우 작아서, 극한이 사실상 몇 개 점의 곡률로 정해집니다.
- **맨 위 칸의 조건이 다릅니다.** 20M의 16k 칸은 다른 칸과 달리 자기만의 상수로 따로 튜닝되었습니다(부록 F). 손실 보상 draw도 16,384개가 아니라 14,336개입니다(부록 E). 그래서 사다리 맨 위 칸의 하락에는 population 효과와 튜닝 효과가 섞여 있습니다.
- **해석:** 저자들도 "측정된 극한이 아니라 간격이 계속 줄어든다는 증거로 읽는다"고 썼고, 보고한 95% 구간(3.89–4.58)도 넓습니다. 따라서 "compute가 충분하면 backprop을 넘을 수 있다"는 이 적합만으로는 지지되지 않습니다.
- **EGGROLL 외삽(Table 2):** 직선 적합 두 가지는 9칸이 모두 일치합니다. power law 적합은 1M(23,000배)만 맞고, 10M과 20M은 우리 재적합에서 10,200배와 5,700배가 나와 보고값(16,000배, 8,100배)과 다릅니다. 시드 단위로 적합했거나 초기값이 달랐을 수 있습니다. 결론(10³–10⁴배)은 바뀌지 않습니다.

- **cosine 수준:** 학습에 실제로 쓴 population에서 대부분 층의 cosine은 0.2–0.6입니다. "backprop gradient에 가깝다"는 K가 10만을 넘는 측정 구간(64–128k)의 이야기입니다.
- **그런데도 손실이 비슷한 이유:** 모멘텀 SGD는 여러 step에 걸쳐 잡음을 평균하므로, step마다 cosine이 0.5여도 학습이 됩니다. 다만 Table 8은 backprop으로 학습한 체크포인트에서 잰 값이라, Dust 학습 중의 cosine과 같다는 보장은 없습니다.

## 5. cosine 법칙의 유도와 c_max < 1의 원인 (numpy toy)

### 5.1 법칙의 유도
σ → 0의 선형 근사에서 한 draw의 보상은 r_t ≈ σ a_tᵀ g_t입니다. 그러면 다음이 성립합니다.

- E[ĝ_t] = g_t
- Cov(ĝ_t) = (‖g_t‖² I + g_t g_tᵀ) / K

이를 가중치 gradient Ĝ = Σ_t ĝ_t x_tᵀ로 모으면 다음 식이 나옵니다.

  cos(Ĝ, G) ≈ 1 / √(1 + c/K),   c = (d_out + 1) · Σ_t ‖x_t‖² ‖g_t‖² / ‖Σ_t g_t x_tᵀ‖²

- **법칙의 정체:** 논문 Eq. 5는 c_max = 1인 이 식에, 편향 c_max를 더한 형태입니다.
- **c의 의미:** "출력 차원 × 토큰별 gradient의 비정합도"입니다. 토큰마다 gradient가 서로 상쇄할수록 c가 커집니다.
- **toy 검증:** 적합한 c와 이론 c가 hidden층 308 vs 314, head 76 vs 89로 맞습니다(T1).

### 5.2 c_max < 1은 "자기 토큰만 보상"하는 편향이다
toy에 토큰 사이 영향(인과 평균 혼합, 세기 β)을 넣었습니다(T2).

| β | cos(국소 gradient, 전체 gradient) | γ = 0 적합 c_max | γ = 1 적합 c_max | γ = 1의 c / γ = 0의 c |
|---|---|---|---|---|
| 0 | 1.000 | 0.995 | 1.000 | 171배 |
| 1 | 0.936 | **0.933** | 1.000 | 177배 |
| 3 | 0.694 | **0.692** | 1.000 | 216배 |

- **γ = 0일 때:** 추정기는 전체 gradient가 아니라 "자기 토큰 손실에 대한 국소 gradient"를 추정합니다. 그래서 c_max가 정확히 cos(국소, 전체)가 됩니다.
- **γ = 1일 때:** 미래 토큰까지 보상하면 편향은 사라지지만, 보상에 T개 토큰의 잡음이 더해져 분산(c)이 170–220배 커집니다.
- **Table 8과의 대응:** Table 8의 패턴이 이 해석과 맞습니다.
  - c_max = 1인 층: LM head와 Q(출력이 자기 토큰에만 영향), K와 value emb(미래 credit을 받음)
  - c_max < 1인 층: writer, MLP, token emb(γ = 0이지만 뒤 블록의 attention을 거쳐 미래 토큰에 영향)
  - V(0.88)와 value gate(0.67)는 예외입니다. credit을 받지만 c_max < 1입니다. 이유는 확인하지 못했습니다.
- **성능 한계:** 이 편향 때문에 Dust는 population을 아무리 늘려도 MLP·writer 층에서 backprop 방향의 약 0.86–0.88까지만 다가갑니다. 논문은 이를 "다른 궤적이라 오히려 좋은 성질"이라고 해석하지만, 원인이 구조적 편향이라는 점은 밝히지 않습니다.

### 5.3 그 밖의 toy 결과
- **간섭(T3):** 두 층을 같은 forward에서 함께 흔들면 c_max는 그대로이고, c가 277에서 446으로 1.6배 커집니다. 즉 간섭은 편향이 아니라 분산입니다. 층 종류별로 pass를 나누는 설계가 정당합니다.
- **weight-space ES(T4):** 같은 forward 수에서 Dust가 앞섭니다(K = 64에서 cosine 0.41 vs 0.18). 다만 toy의 W1은 파라미터가 1,024개뿐이라 K = 4,096에서 ES가 0.82까지 따라옵니다. ES의 분산은 파라미터 수에 비례하므로, 37.7M 모델에서는 격차가 훨씬 큽니다.
- **묶음 중심화(T5):** n개 draw를 묶어 평균을 빼면 추정 크기가 (1 − 1/n)배가 됩니다. 측정값은 n = 2에서 0.494, 8에서 0.878, 16에서 0.942입니다. 공식 코드는 population에 따라 n = 2–16을 씁니다. 따라서 population마다 실효 학습률이 달라지고, 이는 학습률을 population별로 다시 튜닝하는 이유 중 하나일 수 있습니다. 논문 Eq. 1의 c_s = ℓ̃_s − ℓ_s는 n = 1(64 draw)에서 0이 되는데, 코드는 이때 깨끗한 손실을 baseline으로 씁니다.

## 6. "backprop보다 낮아진다"에 대한 다른 설명

논문은 Dust가 "고차 곡률을 암묵적으로 탐색해 평평한 영역으로 간다"는 가설을 제시합니다. 다른 설명도 가능합니다.

1. **가우스 평활화:** 유한 σ의 섭동 추정기는 평활화된 손실 E_a[ℓ(y + σa)]의 gradient를 추정합니다. 이는 잡음 주입 정규화와 같아서, 극초기 학습의 test 손실을 낮출 수 있습니다.
2. **튜닝 비대칭:** Dust는 층별 잡음 크기, credit decay, draw 배분까지 튜닝합니다. 특히 맨 위 칸은 학습으로 다시 튜닝했습니다. backprop은 모멘텀과 학습률만 튜닝합니다(부록 F).
3. **극초기 구간:** 6–61 step에서는 gradient 방향의 정확도보다 step 크기와 잡음이 손실을 더 좌우합니다.

시드별 값이 없어서 100k의 차이(0.05–0.07)가 시드 변동보다 큰지도 판단할 수 없습니다.
