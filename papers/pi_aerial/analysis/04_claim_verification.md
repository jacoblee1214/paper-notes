# 04. 주장 검증과 구현 가능성

## 0. 대상과 방법

- **공식 코드가 없어서 코드 대조(D 항목)는 하지 않았습니다.** 대신 논문의 주장을 C 항목으로 나눠 (1) 표와 본문 수치의 재계산(`03`), (2) 방법 서술의 내부 일관성, (3) 보고되지 않은 정보를 점검했습니다.
- 코드 상태: 프로젝트 페이지 "Code (Coming Soon)", "Data (Coming Soon)". `Shadow581/AirVLA`는 README만 있는 빈 저장소(2026-06-12)이고 저자 계정인지 확인되지 않았습니다(`02` §5). 확인일 2026-11-23. CoRL 2026 채택이 확정(공식 목록)된 뒤에도 코드가 올라오지 않았습니다.
- 자료: 논문 v1(유일한 판), 프로젝트 페이지 HTML(본문과 표가 논문과 같음, 식과 부록 없음). 가중치와 데이터는 받지 않았습니다.
- 판정: **지지**(수치와 서술이 맞음), **부분**(방향은 맞으나 근거가 약하거나 표현이 근거보다 강함), **불충분**(검증할 정보가 없음), **불일치**(내부 모순).

## 2. 판정을 가르는 세 가지

1. **초록의 헤드라인은 조건부 비율입니다.** 표 캡션과 §IV-D는 조건부임을 밝히지만, 초록은 이를 "success"와 "overall"로 적었습니다. 종단 값으로 바꾸면 모든 숫자가 작아지고 신뢰구간이 겹칩니다.
2. **효과의 방향은 일관되고 크기는 불확정입니다.** 가이던스(세 비교 모두 가이던스가 위), 합성 데이터(RTC에서만), RTC(naive 대비 대부분)가 모두 같은 방향입니다. 그러나 같은 절차에서 10–25 pp 차이가 잡음으로 나오는(V7) 20회 설계에서는 크기를 해석하기 어렵습니다.
3. **방법의 핵심 파라미터가 빠져 있습니다.** s(τ), α의 조리개 사상, 행동 정규화, 합성 궤적의 N_s, Δ x. 코드가 공개되지 않으면 가이던스 구현을 같은 세기로 재현할 수 없습니다.

## 3. 코드가 나왔을 때 먼저 볼 항목

코드가 공개되면 `04_code_verification.md`를 새로 만들어 다음을 D 항목으로 대조합니다.

- D-후보 1: s(τ) 스케줄과 VJP 구현(역전파 경로, 정규화 포함 여부).
- D-후보 2: α의 조리개 사상과 K = 4, λ_z = 0.5, Δ z = 0.15, w_t 정의(C7).
- D-후보 3: 행동 공간(상대 대 절대)과 z_des의 단위(C15).
- D-후보 4: RTC 설정(H = 25, prefix 25, 10 스텝)과 naive 설정(50 스텝 열린 고리)의 차이(C4).
- D-후보 5: 3DGS 합성 파라미터(N_s, Δ x, b)와 합성 50개의 구성.
- D-후보 6: 평가 스크립트(성공 판정 기준, 단계별 마커)와 시도 로그(공개 시 표 재계산).

## 4. 구현할 수 있는지 (판정)

**판정: 알고리즘의 핵심(가이던스 샘플러)은 이 맥(Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)에서 소형 정책으로 구현할 수 있습니다. 논문의 결과는 재현할 수 없습니다. 실기체, 모션 캡처, 비공개 데이터, 3B급 미세조정이 모두 필요합니다.**

| 구성 | 이 맥에서 | 필요한 것 | 노력 (추정) |
|---|---|---|---|
| 가이던스 샘플러 (식 2, 3, 6, 8, 9)를 소형 흐름 정책에 구현 | **가능** (CPU/MPS, PyTorch) | VJP는 torch.autograd로 충분 | 1–2일 |
| α 계산과 단위 테스트 | **가능** | 조리개 사상 가정 필요 | 반나절 |
| 1D/2D 페이로드 동역학에서 고도 처짐 시뮬레이션 | **가능** (numpy, 설치된 mujoco) | 질량, 추력, PX4식 PID 모형 | 2–4일. 논문 기체와의 일치는 보장 못 함 |
| 드론 동역학 합성(식 12–14) | **가능** (numpy 적분) | ACADOS는 별도 설치 필요(승인) | 2–3일 |
| 3DGS 장면 복원(Nerfstudio, gsplat) | **어려움** | gsplat은 CUDA가 기본. 영상 데이터 필요 | CUDA 기기에서 며칠 |
| 그리퍼 SAM 합성(식 10, 11) | **조건부** | SAM 가중치(수 GB급 추정, 다운로드 승인 필요) | 1일 |
| π0 추론 (3.2B, bf16) | **조건부** | 약 7 GB 메모리로 맞으나 JAX 체크포인트의 MPS 경로 확인 필요 | 설치·다운로드 승인 후 반나절–1일 |
| π0 미세조정 (30k step, 배치 32) | **불가** | CUDA GPU와 3B 학습 메모리 | GPU 기기에서도 데이터 필요 |
| 실기체 평가 (표 I–III, 460회) | **불가** | Starling 2 Max, UMI 형 그리퍼, 모션 캡처, 인형·빈·게이트 | 비행 시간만 수십 시간 |
| 데이터 (교시 270, 합성 50) | **없음** | 공개 예정 | 공개 전에는 재현 불가 |

노력 추정은 측정 전 추정입니다. 가능한 최소 작업은 "소형 정책 + 가이던스 샘플러 + 1D 페이로드 시뮬"이고, 이것으로 가이던스의 **효과 세기가 s(τ)에 얼마나 민감한지**와 **α 휴리스틱의 실패 모드**를 확인할 수 있습니다. 논문의 성공률 수치는 확인할 수 없습니다.
