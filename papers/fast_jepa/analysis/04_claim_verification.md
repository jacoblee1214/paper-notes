## 4. 구현 가능성 판정 (이 맥 기준)

이 맥: Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음.

**판정: 부분 구현 가능.** 알고리즘(앵커 질의, 제안 생성, 제안 중심 CEM, 종점 채점)과 학습 목표(식 7–11)는 PyTorch로 구현할 수 있습니다. 그러나 **논문 수치는 재현할 수 없습니다.** 코드, 체크포인트, DynaGoal 케이스 목록이 없고, 학습은 GPU가 필요하며, 지연 비교는 RTX PRO 6000 기준입니다.

| 항목 | 이 맥에서 | 필요한 것 | 판정 |
|---|---|---|---|
| 제안 생성과 CEM, 종점 채점 알고리즘 | PyTorch MPS 또는 CPU로 작은 모델에서 구현 | 기반 세계 모델(LeWM 스타일) | **가능** (구현 설계는 논문 부록 A로 충분) |
| 행동 모델 식 (8)–(9)와 SiGReg | 구현 가능 | 부록 A 하이퍼파라미터 (λ, lr, 배치) | **가능** |
| 토이 검증 (작은 2D 과제, 세계 모델 대신 해석 가능한 모델) | CPU로 2분 이내 | - | **가능** (이 분석에서는 실행하지 않음, 아래 참고) |
| PushT, Reacher, Cube, TwoRoom 평가 | MuJoCo, 시뮬은 CPU에서 가능 | 설치 승인, 세계 모델 체크포인트 (공개 안 됨) | **조건부** (체크포인트를 자체 학습해야 함) |
| 4과제 × 3 시드 학습 | MPS에서 가능성 미측정 | 논문은 RTX PRO 6000에서 5.95 GPU-h | **불가 (현재 범위)**: 사용자 승인 필요, 무거움 |
| DynaGoal 재현 | 부록 B.2의 규칙으로 재구현 가능 | 케이스 목록 없음, 재구현은 근사 | **부분 가능**: 정확한 수치 재현 불가 |
| 지연 비교 (10.88 ms) | 이 맥에서 측정 가능 | 같은 조건의 INTACT 구현 | **불가 (직접 비교)**: 하드웨어가 다름 |
| 실로봇 | 논문에 실로봇 실험 없음 | - | 해당 없음 |

- **이 분석에서 토이를 돌리지 않은 이유:** 논문의 핵심 주장(성공률과 지연의 파레토 개선)은 학습된 세계 모델의 품질에 달려 있습니다. 토이로는 이 주장을 검증할 수 없습니다. 주장 C11(직접 채점 동등성)과 C12(계산량 산술)는 토이 없이 이미 확인했습니다.
- **노력 추정 (근거 없는 추정, 측정 전):** 알고리즘 구현과 자체 소형 과제 검증 3–5일. 4과제 학습 포함 재현 2–4주와 GPU 필요. 실제 값은 학습 시간 측정 후 정해야 합니다.
