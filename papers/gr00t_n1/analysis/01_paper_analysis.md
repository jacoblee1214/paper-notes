# GR00T N1 논문 분석 (arXiv:2503.14734)

- 제목: *GR00T N1: An Open Foundation Model for Generalist Humanoid Robots*
- 저자: NVIDIA (알파벳 순, 프로젝트 리드 Linxi "Jim" Fan, Yuke Zhu)
- 분야: cs.RO (cs.AI, cs.LG 교차). 형식: 기술 보고서. 학회 확인: arXiv 댓글과 저널 참조에 학회 표기가 없고, 프로젝트 페이지 본문에도 GR00T N1의 학회 표기가 없다 (페이지에 보이는 "RSS 2025"는 다른 논문의 목록이다). 따라서 venue는 "기술 보고서·블로그"로 둔다.
- 분석 대상: **arXiv v2 (2025-03-27)**. 원문 `paper/paper.pdf` (36쪽, 본문 + 부록 A–F)
- 버전 이력: v1 (2025-03-18), v2 (2025-03-27, 현재 최신). v1과 v2의 차이는 §6에 정리했다.
- 라이선스 판정과 공개 범위는 `README.md`와 §7에 적었다.

## 1. 한 문장 요약

GR00T N1은 VLM(Eagle-2, System 2)과 흐름 매칭 DiT(System 1)를 한 모델에서 end-to-end로 학습하는 2.2B 규모 VLA이며, 실제 로봇 텔레오퍼레이션, 인터넷 영상(잠재 행동 라벨), 시뮬레이션 생성 데이터, 영상 생성 모델의 신경 궤적을 "데이터 피라미드"로 섞어 사전학습한다.

## 2. 문제 설정과 주장

- 휴머노이드는 같은 형태의 데이터가 부족하다(§1, "data islands"). 그래서 실로봇 데이터, 사람 영상, 합성 데이터를 한 모델로 합치는 것이 핵심 주장이다(§1–2, 그림 1 "데이터 피라미드").
- 주장 목록 (본문과 표에서 확인한 것만):
  - **C1 (구조).** System 2(VLM)와 System 1(DiT)를 결합하고 end-to-end로 공동 최적화한다 (§2, 그림 2–3).
  - **C2 (데이터).** 잠재 행동 VQ-VAE와 IDM으로 행동 없는 영상에 행동 라벨을 붙여 로봇 임베디먼트처럼 쓴다 (§2.2, 그림 4).
  - **C3 (신경 궤적).** 영상 생성 모델을 실제 텔레오퍼레이션 데이터로 미세조정해 88 h를 827 h로 늘린다 (§2.2, §3.2). 표 7에서 확인된다.
  - **C4 (벤치마크).** 시뮬레이션 3종(RoboCasa 24과제, DexMG 9과제, GR-1 24과제)에서 BC-Transformer와 Diffusion Policy보다 높다 (표 2, §4.4).
  - **C5 (실로봇).** GR-1에서 DP보다 10% 데이터로 DP 전체 데이터 수준에 가깝다 (표 3, §4.4).
  - **C6 (사전학습 일반화).** 사전학습 체크포인트가 새 물체·새 용기 과제에서 73–77%를 낸다 (§4.4, 그림 8).
- 한계는 §4.6에서 짧게 인정한다. 짧은 수평선(short-horizon) 탁상 작업에 한정되고, 합성 데이터의 물리성과 다양성이 부족하다.

## 3. 방법

### 3.1 모델 구조 (§2, §2.1, 그림 2–3)

- **System 2 (VLM).** Eagle-2 (SmolLM2 LLM + SigLIP-2 이미지 인코더). 224×224 입력에 픽셀 셔플을 적용해 프레임당 64개 이미지 토큰을 만든다. 마지막 층 대신 **12번째 층** 표현을 쓴다(§2.1). 이유는 추론 속도와 정책 성공률이 모두 좋아졌기 때문이라고 적었다.
- **System 1 (DiT).** 교차 주의와 자기 주의를 번갈아 쓰는 DiT. 상태와 노이즈가 섞인 행동 토큰은 자기 주의로, VLM 토큰은 교차 주의로 받는다. 임베디먼트별 MLP 인코더·디코더가 서로 다른 상태·행동 차원을 공통 차원으로 바꾼다.
- **행동 청크.** H = 16 (§2.1). 제어는 120 Hz 폐루프라고 적었지만, 데이터 기록은 텔레오퍼레이션 20 Hz다 (§3.1). 두 주파수의 관계는 본문에 설명되어 있지 않다.
- **규모.** 총 2.2B (VLM 1.34B). 16개 행동 청크 추론은 L40에서 bf16으로 63.9 ms (§2).

### 3.2 흐름 매칭 목표와 추론 (§2.1, 식 (1))

- 노이즈 섞기: A^τ = τA + (1−τ)ε, τ ∈ [0,1]. 목표는 식 (1)에서 ε − A로 쓰여 있다.
- 시간 분포: p(τ) = Beta((s−τ)/s; 1.5, 1), s = 0.999.
- 추론: 4단계 오일러 적분 A^{τ+1/K} = A^τ + (1/K)V_θ, K = 4 (§2.1).
- **표기 문제.** 식 (1)의 목표 ε − A와 오일러 갱신 "+V"를 같이 읽으면 부호가 맞지 않는다. 보간식에서 dA/dτ = A − ε이므로 학습 목표는 A − ε여야 한다. 공식 코드는 A − ε를 쓴다. 자세한 대조는 `04_code_verification.md`의 D1에 있고, 부호 토이는 `03_analysis.md` §5에 있다.

### 3.3 학습 목표와 미세조정 (§2.2–2.3, 부록 D·F)

- 손실은 식 (1)의 흐름 매칭 손실 하나다. 부록 F는 보조 손실 L_det(OWL-v2 상자 중심 좌표, 선형층, 제곱 손실)을 추가로 적었다. 본문에는 이 보조 손실이 언급되지 않는다.
- **사전학습.** AdamW, 학습률 1e-4, 배치 16,384, 200,000 스텝, 텍스트 토크나이저와 언어 모델은 고정, 비전 인코더와 DiT는 학습 (표 6).
- **미세조정.** 임베디먼트마다 따로 한다. 배치 128 또는 1024, 20,000–60,000 스텝 (표 6, §4.3). 시뮬레이션에서 과제당 30, 100, 300 시연을 쓴다.
- **인프라.** H100 최대 1,024 GPU, 사전학습 약 50,000 H100 GPU 시간 (§2.3). 미세조정은 A6000 1장에서도 확인했다고 적었다.

### 3.4 데이터 피라미드 (§2.2, §3, 표 1, 표 7)

| 층 | 데이터 | 시간 (h) | 프레임 (M) | 행동 라벨 |
|---|---|---|---|---|
| 꼭대기 | GR-1 텔레오퍼레이션 (실로봇) | 88.4 | 6.4 | 실제 행동 |
| | OXE 부분집합 (DROID, RT-1, Language Table, Bridge-v2 등, 표 7) | 1,221.0 (합계) | 42.1 | 실제 행동 |
| | AgiBot-Alpha (발사 시점 14만 궤적) | 1,979.4 | 213.8 | 실제 행동 |
| 가운데 | 시뮬레이션 (표 7 "GR-1 Simulation Pre-Training"; 본문의 DexMimicGen 540k 시연과 대응) | 1,742.6 | 125.5 | 실제 행동 |
| | 신경 궤적 (영상 생성 827 h, 약 300k 궤적) | 827.3 | 23.8 | IDM·잠재 행동 |
| 바닥 | 사람 영상 7종 (Ego4D 등) | 2,517.0 (합계) | 181.3 | 잠재 행동 |

- 잠재 행동: 연속 프레임 쌍을 받는 VQ-VAE 인코더를 역동역학 모델처럼 쓴다. 그 연속 임베딩이 "LAPA" 임베디먼트의 목표다 (§2.2).
- 신경 궤적: Wan2.1-I2V-14B에 LoRA를 붙여 GR-1 텔레오퍼레이션 영상으로 미세조정하고, 다중모달 LLM으로 지시문 준수를 걸러 낸다 (부록 F). 생성 비용은 L40 기준 영상 1초당 약 2분, 총 105k L40 GPU 시간이다 (§3.2).
- 시뮬레이션: DexMimicGen으로 과제당 1,000회 시연을 만든다. 사전학습은 receptacle 쌍 54개 × 10,000 = 540k 시연 (§3.2).

## 4. 실험

### 4.1 벤치마크 (§4.1, 그림 7)

- RoboCasa Kitchen 24과제 (Franka, 3카메라, 공개 데이터셋 과제당 3,000 시연).
- DexMimicGen Cross-Embodiment 9과제 (양팔 평행 그리퍼, 양팔 손, GR-1).
- GR-1 탁상 24과제 (사전학습에 없는 용기 조합, 관절 물체 6과제 포함).
- 실로봇 13과제 (표 5 기준; 물체-용기 5과제는 seen/unseen 두 조건).

### 4.2 평가 절차 (§4.3)

- 시뮬레이션: 100회 시행 평균, **마지막 5개 체크포인트 중 최댓값** (RoboCasa 프로토콜). 체크포인트는 500 스텝마다 저장.
- 실로봇: 과제당 10회 (Machinery Packing은 5회, 30초 제한). 부분 점수를 준다 (예: 물체를 잡았지만 용기에 못 넣으면 0.5). 과제별 부분 점수 기준은 본문에 없다.
- 기준선: BC-Transformer(RoboMimic), Diffusion Policy (U-Net, 16 스텝 행동 청크).

### 4.3 주요 결과

- **표 2 (시뮬, 100 시연/과제).** 평균: BC 26.4, DP 33.4, GR00T N1 45.0. 벤치마크별로 RoboCasa 25.6→32.1 (DP→GR00T), GR-1 32.7→50.0. DexMG 열은 표 2와 표 4가 맞지 않는다 (`03_analysis.md` V3).
- **표 3 (실로봇).** 평균: DP 10% 10.2, DP 전체 46.4, GR00T 10% 42.6, GR00T 전체 76.8. 본문은 "10% 데이터의 GR00T가 DP 전체보다 3.8 낮다"고 적었다.
- **사전학습 평가 (§4.4).** 좌→우 손 인계 76.6% (11.5/15), 새 물체 새 용기 73.3% (11/15). 15회라 신뢰구간이 매우 넓다 (`03_analysis.md` V6).
- **신경 궤적 공동학습 (§4.4, 그림 9).** RoboCasa 평균 +4.2 / +8.8 / +6.8 %p (30/100/300 시연), GR-1 8개 과제 평균 +5.8 %p. 그림 9의 막대값은 그림에만 있어 텍스트에서 확인할 수 없다.
- **정성 (§4.5).** 사전학습 체크포인트는 사과를 왼손에서 오른손으로 넘겨 바구니에 넣는다 (그림 11). 미세조정 후에는 이 행동이 사라진다.

### 4.4 제한과 보고상 빈틈

- 평가 시행 수는 보고하지만 **학습 시드의 분산은 보고하지 않는다.** 실로봇 10회와 시뮬 100회 기준의 불확실성만 있다.
- "마지막 5개 체크포인트 최댓값"은 낙관적 선택 편향을 만든다. 얼마나 큰지는 체크포인트별 값이 없어 계산할 수 없다.
- 표 5에서 10% 데이터의 기계 포장(Machinery Packing)은 GR00T 8.0 vs DP 20.0으로 졌다. 그런데 본문은 "모든 과제에서 유의하게 높다"고 적었다 (`03_analysis.md` V9).
- 시뮬 DexMG 열 불일치 (V3) 때문에 표 2 평균 자체의 출처를 확인할 수 없다.

- 부록 F: 보조 검출 손실, IDM 학습, 신경 궤적 필터링 (`04_code_verification.md` D3, D4).
- 부록 F 말미 (그림 13, 14): 신경 궤적 예시와 사람 영상 예시. 정량 결과는 없다.

## 6. v1 과 v2 의 차이

- 두 PDF의 추출 텍스트를 토큰 단위로 비교했다 (차이 42곳). 본문 수치와 표 2–5, 표 6–7은 v1과 v2가 같다.
- 바뀐 것은 다음뿐이다.
  - **그림 9 캡션.** v1은 "24 과제 시뮬과 8 실로봇 과제의 평균 성공률"이라고 적었고, v2는 "신경 궤적 공동학습 ablation"으로 고쳤다. v2 캡션에는 3개 데이터 규모가 명시되었다. 본문은 두 판이 같다.
  - **부록 구성.** v1은 A(기여자), B(상세 결과), C(하이퍼파라미터), D(시스템 설계, D.1·D.2), E(추가 학습 세부), F(추가 정성 결과)다. v2는 C(추가 정성 결과), D(하이퍼파라미터), E(시스템 설계), F(추가 학습 세부)다. 절 번호가 바뀌어 본문 참조 번호(예: "Appendix F")도 달라졌다.
  - **감사의 말과 기여자 목록.** v2에 몇 명이 더 들어가고 일부 이름 순서가 바뀌었다.
- 본문 §1의 "VLM은 10 Hz로 돈다" 문장은 두 판 모두에 있다.
- 결론: v2는 본문 주장을 바꾸지 않고 캡션과 부록 구성을 다듬은 판이다. 분석 수치는 두 판 모두에 적용된다.
