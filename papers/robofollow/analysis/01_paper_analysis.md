## 1. 한 문단 요약과 핵심 질문

기존 조작 벤치마크는 시작 장면만 봐도 할 일이 정해져 언어가 필요 없는 경우가 많아서, 성공률이 높아도 정책이 지시를 쓰는지 알 수 없다는 문제의식(§1)에서 출발합니다. 저자들은 이를 **낮은 장면 엔트로피**라고 부르고, 같은 장면에서 서로 다른 과제가 여럿 가능한 **RoboFollow**를 만들었습니다(§3). RoboTwin 2.0 위에서 장면 4개, 학습 과제 75개, 평가 과제 554개를 두고, 평가를 L0(분포 내), L1(배치 변경), L2(언어 재조합), L3(둘 다)로 나눕니다. 점수는 최종 성공 대신 단계별 의도 점수(IS), 실행 점수(ES), 완료율(CR)을 씁니다(§3.2).

VLA 7개와 WAM 2개를 3,750 에피소드로 미세조정해 평가하면 L0는 높지만(π0.5 평균 IS 92, π0 94, ACoT-VLA 93) L1–L3에서는 크게 떨어집니다(표 1). 더 강한 VLM(Qwen3-VL-4B), QA 공동학습, LangForce, CFG는 Scene 2에서 격차를 줄이지 못했다고 보고합니다(표 2, §5.2).

**핵심 질문:** 높은 L0 점수는 지시를 쓴다는 증거인가, 그리고 L1–L3의 하락은 언어 이해의 부족을 뜻하는가. 03은 표에서 이 둘을 재검토합니다.

## 2. 벤치마크 설계 (§3, 부록 A, B)

### 2.1 장면 엔트로피 (식 (1), 부록 A.1)

- 정의: H_scene = H_train(T | S) = −Σ_s p(s) Σ_t p(t|s) log2 p(t|s). T는 학습 과제 라벨, S는 지시와 목표를 뺀 시작 장면 명세입니다.
- 과제당 시연 수가 같으면 H = Σ_s (K_s/K) log2 K_s입니다. RoboFollow는 K_s = (16, 16, 16, 16, 7, 4), K = 75이고 **3.782 bits**입니다. LIBERO(Spatial/Object/Goal/Long)는 0/0/3.322/0.200이고 같은 가중치 평균이 **0.880 bits**입니다.
- 저자는 이 값을 "최종 평가 지표가 아니라 데이터셋 설계 원리"로 쓴다고 밝힙니다(§3).

### 2.2 장면 네 개와 수준 네 개

| 장면 | 초점 | 학습 과제 | 지시문 변형 | 평가 과제 L0/L1/L2/L3 |
|---|---|---|---|---|
| S1 외재 공간 관계 | "~의 오른쪽 블록", "뒤에 놓기" | 16 | 48 | 16 / 8 / 16 / 76 |
| S2 내재 속성 | 색, 크기, 모양 x 집기, 밀기, 쌓기, 그릇에 놓기 | 16 | 52 | 16 / 24 / 68 / 24 |
| S3 세밀한 동작 | 경유 슬랩, 최종 방향 | 16 | 48 | 16 / 40 / 64 / 96 |
| S4 논리 | 순서, 부정, 조건 분기 | 27(그룹 16, 7, 4) | 81 | 27 / 14 / 25 / 24 |
| 합계 | | 75 | 229 | 75 / 86 / 173 / 220 = 554 |

평가 과제 수와 지시문 변형 수는 논문 본문에 없고 **공식 저장소 README의 표**에서 옵니다(`04` D6).

- **L0:** 학습 분포. **L1:** 지시는 그대로, 물체 위치를 교환(그림 1, 2). **L2:** 배치는 그대로, 지시는 학습에서 본 개념의 새 조합. **L3:** 둘 다 바꿈. 저자는 수준이 엄격한 난이도 순서는 아니라고 말합니다(§3.1).
- 학습 에피소드는 과제당 50개(총 3,750)이고, 같은 배치에서는 물체에 1–2 cm 무작위 위치 변동을 줍니다. 지시는 3개 안팎의 바꿔 쓰기에서 뽑습니다(부록 A).
- Scene 3의 L2는 "paired-route convention"에서 "avoid passing over the red slab"를 "pass over the green slab"으로 바꾸고, 방향 표현도 "long side facing right"를 "short side facing front"로 바꿉니다. 저자는 이 둘이 같은 의도 경로와 같은 최종 방향을 가리킨다고 설명합니다(부록 A).

### 2.3 지표 (§3.2, 부록 B)

- **IS(의도):** 각 단계에서 올바른 의미 대상(물체, 관계, 경유점, 논리 분기)을 고르는지. 물리 실행이 불완전해도 점수를 줍니다.
- **ES(실행):** 선택한 하위 목표를 실제로 끝내는지.
- 단계: 최대 세 단계(출발 물체 선택, 동작 목표, 후처리). 마지막 "마무리 단계"가 전체의 20%이고 "지시와 무관한 행동을 더 하지 않아야" 만점입니다(§3.2).
- **CR(완료율):** 동작에 따라 다른 이진 기준. 집기류는 최종 IS와 ES가 둘 다 0.8 이상, 나머지는 최종 배치나 진행 신호를 씁니다. 장면과 수준 안에서 과제별 완료율의 **단순 평균**입니다(부록 B). 모든 단계가 만점일 필요는 없습니다.

## 4. 저자가 말한 한계 (§7)

진단용이라 물체 형상, 과제 길이, 상호작용을 단순화했고, 장기 계획, 접촉이 많은 조작, 개방 어휘, 대규모 실세계 배치는 다루지 않습니다. 통제 실험은 구조적 배치 다양성을 늘리지 않았고, 실로봇 파일럿은 서로 다른 지시문 집합을 비교하며, 시뮬레이터 간 전이와 복잡한 실세계 과제로의 전이는 확인하지 않았습니다. 초록과 결론은 "우리의 미세조정 설정에서"라는 한정을 둡니다(abstract, §6).

## 5. 주장과 증거의 틈 (우리 판단)

번호는 03의 검사(V), 04의 코드 대조(D)를 가리킵니다.

1. **L0 대조 기준이 하나입니다.** 표 1의 빈 언어 π0.5는 L0 IS 14.8로, 언어가 장면 명세에서 과제를 정하는 데 필요하다는 설계 가정을 직접 뒷받침합니다. 이 행은 본문에서 설명되지 않고 다른 모델에는 같은 대조가 없습니다. 언어 없는 정책의 L0 완료율 상한은 장면 그룹 수 대 과제 수로 계산되고(S1–S3 6.25%, S4 11.1%), 빈 언어 π0.5의 L0 CR(6.3/9.4/0.0/8.2)과 같은 범위에 있습니다(03 V4).
2. **일부 모델은 L0에서 이미 언어 사용을 보여 주지 못합니다.** OpenVLA-OFT의 L0 평균 IS 17.5는 빈 언어 π0.5의 14.8에 가깝습니다. 이 모델의 L0→L1–L3 하락(9.1포인트)은 지시 사용의 붕괴라기보다 L0에서 학습이 되지 않은 경우로 읽힙니다. 초록의 "where attained"가 이 구분을 담고 있습니다(03 V5).
3. **IS는 누적·관문 구조입니다.** 코드에서 뒤 단계의 의도 점수는 앞 단계 의도가 만점일 때만 인정됩니다(`04` D3). Scene 3 L2에서 7개 모델의 IS가 29.7–33.2로 모이는 값은 단계 1의 가중치 0.3과 같고, 같은 칸의 CR은 9개 모델 모두 2.0 이하입니다(03 V6). 이 칸은 "물체는 맞게 고르지만 경로·방향 단계는 통과하지 못함"으로 읽을 수 있습니다.
4. **시행 수와 불확실성이 보고되지 않았습니다.** 코드 기준 평가 과제 x 10회(5,540회)로 가정하면, CR 격자 검사에서 160칸 중 149칸이 맞습니다. 그러나 표에는 구간이 없고 학습 시드는 하나로 보입니다. π0.5 대 ACoT-VLA의 평균 CR 차이 4.8포인트는 시행 단위 이항 근사에서는 z = 5.2, 과제 단위 군집을 반영한 거친 근사에서는 z = 1.6입니다(03 V11).
5. **더 강한 VLM의 효과는 짝을 맞춘 비교가 아닙니다.** Qwen-GR00T(L0 IS 67.9)와 π0.5(93.6)는 VLM뿐 아니라 행동 머리, 로봇 사전학습, 학습 파이프라인이 다릅니다. 표 2에는 같은 데이터로 학습한 GR00T 기본 행이 없습니다. L1에서 Qwen-GR00T 6.3 대 π0.5 75.7이라는 격차는 백본 효과로 분리되지 않습니다(03 V7).
6. **LangForce 서술과 표 2.** "미미한 변화"라는 서술은 Qwen-GR00T 행을 기준으로 하면 L0 CR 65.6→35.0, L2 IS 31.1→18.6, L3 IS 14.8→0.0과 맞지 않습니다. 비교 기준(LangForce의 기본 정책)이 표에 명시되지 않았습니다(03 V7).
7. **표 3의 작은 차이.** 시연 25→50과 스텝 2k→6k의 4–7포인트 차이는, 평가 시행 수를 과제 x 10회로 가정한 보수적 하한 검정에서 대부분 유의 판정이 나지 않습니다. 지시 변형 1→5의 L3 +11.5만 z ≥ 2.5입니다(03 V7).
8. **실로봇 파일럿.** 시행 단위 검정(Fisher p = 0.0016)과 지시문 단위 검정(순열 p = 0.081)이 주는 증거의 강도가 다릅니다. 저자가 이 파일럿을 "예비"라고 한 서술과 맞습니다(03 V8).
9. **QA 진단.** 1/20, 2/20, 3/20은 서로 구분되지 않고(Fisher p ≥ 0.6), 맞힌 문항 수 3개에서의 "절반"은 근거가 얇습니다. 같은 20문항이 기본 배치만 묻고 L1 배치는 묻지 않습니다(03 V9).
10. **CFG 해석은 가설입니다.** CFG 배율 1.2에서 L0 IS가 93.6에서 55.9로 떨어지는 원인이 학습 중 언어 드롭아웃 유무인지는 논문에서 알 수 없습니다. 이 모델이 무조건부 분기를 학습했는지가 결정적인데 기재되어 있지 않습니다.
