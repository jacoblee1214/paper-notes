## 1. 한 문단 요약

Play2Perfect는 2단계 RL입니다. (1) 절차적으로 만든 두 조각 짜임새 물체(cuboid/cylinder 조합) 1000개로 **자유 공간에서 6D 목표 자세를 따라가는 손-팔 정책**을 사전학습합니다(SAPG, 24,576 환경, 7일, 단일 A6000). (2) CAD에서 **조립 분해(assembly-by-disassembly)**로 희소 목표 순서를 만들고, 보상은 **성공 보너스와 부드러움 항만** 두어 미세조정합니다. 실로봇(KUKA iiwa 14 + Sharpa 22-DoF 손, FoundationPose 추적)에서 0.5 mm 틈 끼우기 6/10, 빔 두 단계 12/20, 스크류 5/10을 **영점 전이**로 보고합니다. 핵심 주장은 "사전학습은 손가락으로 하는 in-hand 6D 제어를 가르칠 때 가장 잘 전이된다"입니다.

## 2. 문제 설정과 방법 (§1–3)

- **문제**: 희소 보상 조립에서 탐색이 어렵고, 원격조작이 접촉이 많은 과제에 어렵습니다(§1). 기존 해법은 전용 그리퍼, 고정구, 밀집 보상에 의존합니다(§2).
- **목표 조건부 정책** π(s_t, o_t, g_t, φ) (§3.1). o_t, g_t ∈ SE(3), φ는 상자 치수. 팔과 손을 한 정책이 제어합니다.
- **사전학습 보상** (식 4–9, 부록 J): r = r_smooth + I_grasped·r_goal (식 4) 를 기본으로 하고, 리프트 전에는 r_approach, 리프트 뒤에는 r_goal을 씁니다. r_goal은 키포인트 최대 거리 d(o, g) = max_i ‖o_i − g_i‖ (식 3) 의 감소량과 d < ε 보너스(B_succ = 1000)로 구성됩니다. 기본 ε = 1 cm.
- **사전학습 설계 축** (§3.1): 물체 다양성(10/100/1000), 목표 방식(6D / 평행이동만 / 회전만), 궤적 다양성(10·100 고정 또는 매번 무작위), 목표 정밀도(ε = 1/5/10 cm).
- **미세조정 보상** (식 11–14, 부록 L): r_t = r_smooth + r_goal, r_goal = B_succ I[d < ε] + r_retract. 접근·잡기·리프트 보상이 없습니다. 목표는 CAD 기반 **사전 삽입 자세 → 최종 자세**(스크류는 90° 간격)이며, 최종 후퇴 보너스(식 14)를 줍니다.
- **sim2real**: 동작 지연 0–3 스텝, 물체 상태 지연 0–10 스텝, 위치 1 cm·회전 5° 잡음, 20 N·2 N·m 외력 (Table 3, 4).
- **구조** (부록 I, Table 2): LSTM[1024] + MLP[1024,1024,512,512] 액터, 비대칭 critic, SAPG(블록 4096), lr 1e-4, clip 0.1, γ 0.99, λ 0.95.

## 4. 한계 (§5)

- 짧은 수평의 조립 기술만 학습합니다. 과제 순서, 능동 부품 선택, 목표 자세는 외부에서 줍니다.
- 과제 계열마다 미세조정합니다.
- 물체 자세 추정 실패(가림, 빠른 움직임)에 취약합니다.
- 목표 자세 말고는 고정구와 주변 기하를 보지 않습니다.

저자 한계 설명에는 **시험 수가 적은 점, 사전학습 비용을 포함하지 않은 점, 실로봇 Play-only 비교의 n이 없는 점**은 들어 있지 않습니다. 이 셋은 `03`과 `04`에서 다룹니다.
