# 03. 수치 재계산과 주장 검증

재현 실험은 하지 않았습니다. 논문이 주는 수치(그림 7의 막대 높이)를 시행 수 20으로 환산해 구간과 검정을 다시 계산했고, 본문 주장과 대조했습니다. 계산은 `analysis/recompute.py`(수 초, scipy), 결과는 `analysis/recompute_results.json`, 그래프는 `analysis/plot_figures.py`(`report/figures/own_success_ci.png`)입니다.

## 1. 판독의 한계

- 논문은 표를 주지 않고 그림 7만 줍니다. 막대 높이를 눈으로 읽었고, 모든 값이 5%p 배수(= 20회 중 정수 회)로 보여 판독 오차를 ±1회로 가정합니다.
- 판독 오차가 ±1회이면 p 값과 구간이 조금 달라집니다. 아래 결론(유의 여부)이 바뀌는 항목만 따로 표시합니다.
- DP 촉각 전용 막대는 그림에 없습니다. 본문대로 0/20으로 둡니다.

## 3. 재계산 결과 요약

1. **촉각+시각 정책에서 사전학습 효과는 통계적으로 확인되지 않습니다.** USB에서는 5%p(1/20)이고 p = 1.0입니다. 블록 쌓기에서 가장 큰 차이는 직사각형 DP의 35→55(20%p)이지만 p = 0.34이고, 정육면체 DP 55→70은 p = 0.52입니다. 정육면체 ACT 30→95만 p < 0.001입니다.
2. **시각 전용 정책의 ACT 사전학습 효과는 확인됩니다.** USB 20→85와 직사각형 10→75 모두 p = 0.0001(Holm 0.001 이하).
3. **시각 전용 DP의 사전학습 효과는 확인되지 않습니다.** USB 45→75 (p = 0.105), 직사각형 35→60 (p = 0.205), 정육면체 75→95 (p = 0.182).
4. **"시각 전용 사전학습 ≈ 촉각+시각"은 USB ACT에서 통계적으로 구별되지 않습니다.** 시각 전용 사전학습 17/20 대 촉각+시각 사전학습 19/20은 p = 0.605, 대 미사전학습 18/20은 p = 1.0입니다. "on par"는 맞는 말이지만 동등성 검정은 아닙니다.
5. **촉각 전용 ACT에서 사전학습은 낮추는 방향입니다** (70 → 45%, p = 0.20). 논문도 과적합을 원인으로 듭니다. 근거는 없습니다.

| ID | 본문 주장 (위치) | 재계산 | 판정 |
|---|---|---|---|

## 5. 일관성 검사 (본문과 그림)

- 초록의 "USB 시각 전용 20%에서 85%"는 그림 7의 ACT 막대와 맞습니다.
- 본문 "ACT 95%, 시각 전용 ACT 20%, DP 45%" (§IV-A)는 그림과 맞습니다.
- "모든 실험은 20회" (그림 7 캡션)와 막대 높이가 모두 5%p 배수인 점이 맞습니다.
- v1과 v2의 USB 수치(본문 기준)는 같습니다(`analysis/01` §0). v1에 블록 쌓기가 없어 v2에서 추가되었고, 이 차이로 과제 수가 1개에서 3개로 늘었습니다. 다중 비교 보정은 v2에서만 필요합니다.
- 실패 감소 "20%"(C4)만 그림과 맞지 않습니다(약 17%).

## 6. 검정력 (새 실험을 설계할 때의 기준)

80% 검정력, 양측 α = 0.05, 군당 시행 수(정규 근사, 두 비율):

| 비교 | 군당 시행 수 |
|---|---|
| 45% 대 75% (DP 시각 전용 USB 크기) | 41 |
| 70% 대 85% (ACT 시각 전용 USB 대비 촉각+시각) | 121 |
| 90% 대 95% (USB 촉각+시각 향상 크기) | 435 |

논문의 20회 설계로는 20%p 이상 차이만 잡을 수 있습니다. 5%p 차이는 수백 회가 필요합니다.

## 7. 재현에 필요한 계산 (실험 아님)

- 공식 코드의 대비 손실은 온도 1로 계산합니다(`04` D3). 코사인 유사도 범위 [-1, 1]에서 정답 항목의 softmax 확률 상한은 e/(e + (n-1)/e)이므로 교차엔트로피에 하한이 생깁니다. n = 5이면 0.433, n = 7이면 0.594입니다. 이 하한 때문에 학습 손실의 절댓값은 정렬 품질의 지표로 쓸 수 없고 상대 비교에만 쓸 수 있습니다.
- 이 값은 `recompute_results.json`의 `loss_floor_tau1`에 있습니다.

## 8. 검증하지 못한 항목

- 접선 변형률, 힘 감소(C9).
- 원인 실험 (과적합 주장, C6).
- 데이터 셋과 학습 체크포인트가 공개되지 않아 그림 7을 직접 재현할 수 없습니다.
