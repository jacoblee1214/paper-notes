# 주장 검증 (Current as Touch, arXiv:2607.03529)

분석일 2026-11-21. 공식 코드가 아직 공개되지 않아(02 §4) 논문과 코드를 대조하지 않았습니다. 대신 논문의 주장(C1–C10)을 표, 식, 절과 대조하고, 재계산은 `03_analysis.md`를 따릅니다. 일관성 검사 항목(V1–V18)은 `03_analysis.md` §3에 있습니다.

## 1. 판정 기준

- **지원**: 표 수치와 재계산 검정이 주장과 맞고, 방향이 일관됩니다.
- **부분 지원**: 방향은 맞지만 시도 수, 과제 수, 검정 결과 중 하나가 약합니다.
- **미지원**: 표 수치가 주장과 맞지 않거나 반대입니다.
- **검증 불가**: 데이터나 측정이 없어 논문 밖에서 확인할 수 없습니다.

### 2.1 주장 사이의 긴장

1. **라벨이 사람의 명령입니다.** 모델은 "사람이 다음에 어떤 목표를 줄지"를 배웁니다. 이것이 물리적 적정 힘과 같다는 증거는 없습니다(C9). 그래서 성능 향상이 접촉 물리 때문인지, 전류가 사람의 수정 시점을 알려 주기 때문인지 구분하기 어렵습니다.
2. **힘을 측정하지 않은 "힘 제어" 논문입니다.** 찌그러짐과 미끄러짐은 간접 지표입니다. 힘 크기를 바꾸어 보는 실험이 없습니다.
3. **손과 과제가 섞여 있습니다.** LEAP는 컵과 물병, Dex3는 칠판과 카드에만 쓰였습니다(03 V10). "여러 손에서 검증"은 손 효과와 과제 효과를 나누지 못합니다.
4. **외부 측정 장비가 정책 추론에 들어갑니다.** 카드 자세는 VICON으로 잽니다(부록 A.2). "외부 센서 없음"은 촉각과 힘 센서에 한해 맞습니다.

## 3. 저장소 관점의 요약

- 논문은 "외부 센서 없이 전류로 유연함을 얻는다"는 방향으로 설득력이 있습니다. 전류를 넣었을 때 실패가 줄어드는 효과(C2)가 가장 확실합니다.
- 하지만 "힘을 맞추는 메커니즘"이라는 해석은 측정 없이 주장됩니다(C9, C10). 확인하려면 힘 센서가 있는 실험이 필요합니다.
- 연구 재사용 관점에서는 "목표 위치 인터페이스"와 "전류 입력 한 개 추가"가 가장 가져다 쓰기 쉬운 부분입니다.
