## 1. 한 줄 요약과 주장

손목 sEMG 밴드(8채널 + IMU)로 사람 손가락 힘을 추정(EMG2Force)해, 사람 영상 시연에 손가락별 힘 라벨을 붙이고, 이를 평행 그리퍼 로봇의 "동작 + 힘" 정책으로 옮기는 파이프라인입니다.

초록과 서론의 주장은 다섯 가지입니다.

1. 약 $300의 오픈소스 손목 밴드(§2, 부록 A–B).
2. 10시간 다중 모달 데이터셋(영상, sEMG, IMU, 손끝 힘)을 공개(§3, 그림 4).
3. 근육 위치를 고려한 전극 배치가 균등 배치보다 오차가 약 18% 낮음(표 1, §5.1).
4. 비전 기반 기준선보다 힘 예측 오차가 50% 넘게 낮음(그림 5, §5.2).
5. pick-squeeze-place 9개 물체에서 **87%** 성공(표 2, §5.3).

## 2. 방법

### 2.1 하드웨어 (§2, 부록 A–B)

- 수집 보드는 OpenBCI Cyton(ADS-1299, 노이즈 0.14 µV rms, SNR 119.5), 양극(bipolar) 차동 전극, **8채널**(손가락 근육 7 + 손목 굽힘 1). 채널 배치는 EPB, ED, EPL, extensor indicis, FDP, FDS, FCR, FPL 위이고 기준 전극은 척골 붓돌기 위입니다(부록 A).
- 정답 힘은 얇은 필름형 힘 감지 저항(FSR)을 투명 젤 손가락 골무에 넣어 측정합니다. 배선은 손바닥 쪽으로 빼 영상 가림을 줄입니다(§2.2). **FSR의 보정 방법, 측정 범위, 히스테리시스는 논문에 없습니다.**
- 총비용은 "공급처에 따라 $300까지"이고 BOM을 공개한다고 쓰지만(§2) 본문에 부품별 비용표는 없습니다(저장소 README는 Google Sheets BOM 링크를 둠).
- 16채널로 데이지체인 확장이 가능합니다(부록 B). 이 확장은 본문 실험에 쓰이지 않았습니다.

### 2.2 데이터셋 (§3, 그림 4)

- 동기화된 egocentric 영상, sEMG, IMU, 5손가락 힘을 **10시간**. 행동 4종(pinch/grasp 46%, pick-and-place 27%, open/close 16%, pour 11%)과 제스처 4종(본문: 2-finger 51%, 3-finger 17%, 5-finger 11%, in-the-wild 21%)입니다.
- 사용자는 **4명**(한계 절)이고 사용자별 보정을 씁니다.
- 본문 제스처 비율과 그림 4B의 색 대응이 다르게 읽힙니다(`03_analysis.md` K1).

### 2.3 EMG2Force (§3, 그림 2, 부록 D)

- 입력: sEMG 8채널 + IMU 10차원(가속도 3, 자이로 3, 쿼터니언 4), 창 T = 5 s, **250 Hz**(창당 1250 샘플).
- 두 입력을 채널 방향으로 이어 붙여 STFT 스펙트로그램 S를 만들고, 시계열은 1-D 합성곱 인코더, 스펙트로그램은 사전학습된 **DINOv3** 인코더에 넣은 뒤 이어 붙여 트랜스포머 디코더가 5손가락 힘 F_ftp ∈ R^(5×N)을 예측합니다. 손실, 최적화기, 에폭, 파라미터 수, STFT 설정은 본문에 없습니다.
- 사용자 보정: 사용자가 밴드와 손끝 힘 센서를 착용하고 약 15분간 무작위 움직임을 합니다(§5.3, 부록 E). 미세조정 방식(전체 가중치인지 일부인지)은 본문에 없습니다.

### 2.4 힘 포함 정책 (§4, 부록 C)

- 사람 영상에서 Aria MPS 손 키포인트로 SE(3) 말단 자세와 1-DoF 열림 g를 만들고(엄지·검지 끝 중점이 위치, MCP 관절로 Gram–Schmidt 자세), 물체는 Grounding DINO, SAM2, CoTracker, Orient-Anything으로 6-DoF 자세를 얻습니다. 사람 팔은 SAM2 분할 + LaMa 인페인팅으로 지우고 가상 그리퍼와 물체 키포인트를 덧그립니다.
- 개체별 토큰(손, 물체)에 상대 자세를 넣고, **힘 채널은 손 토큰에만** 붙입니다. 힘 f_t는 F_ftp의 **엄지와 검지 평균**입니다(부록 C).
- 정책: 흐름 매칭(flow matching) 트랜스포머, 행동 청크 K = 50, 행동 a_t = [p; r_6D; g; f] ∈ R^11(3 + 6 + 1 + 1). 힘이 관측과 행동 양쪽에 들어갑니다(§4). 성분별 손실 가중치는 값이 없습니다.

### 2.5 로봇 배치와 힘 제어 (§5.3, 부록 E–F)

- UR-5, Robotiq 평행 그리퍼, ZED 2i(3인칭 RGB-D 한 대). 물체당 사람 시연 **15개**.
- Robotiq가 힘 응답이 느려 **Paxini 힘 센서 4개**를 손끝에 붙였습니다. 닫기 명령이 나오면 정책을 멈추고 **고정 5 N** 사전 파지 힘으로 맞춘 뒤 재개하고, 이후 squeeze·place 구간은 PD 힘 제어기가 정책이 예측한 목표 힘을 따라갑니다(부록 F, 그림 11).
- 사람의 손끝 힘(엄지·검지 평균)이 그리퍼 힘 목표로 어떻게 대응되는지(배율, 센서 합산 방식)는 본문에 없습니다.

## 3. 실험과 수치

### 3.1 전극 배치 (표 1, §5.1)

|---|---|---|---|---|---|---|
| 1 ch | 1.89 | 3.69 | | 8 ch even | 0.94 | 1.77 |
| 2 ch | 1.76 | 3.06 | | 8 ch ours | 0.77 | 1.33 |
| 4 ch | 0.93 | 2.00 | | | | |

- 왼쪽: 공개 데이터셋에서 사용하지 않는 채널을 마스크한 결과. 오른쪽: 균등 배치와 근육 기반 배치를 **같은 시간에 둘 다 달 수 없어** 두 개의 30분 데이터(물체 10개, 2·3·5-finger 파지, 물체당 5회)를 따로 수집한 비교입니다. 표 주석이 두 표를 직접 비교하지 말라고 적었습니다.
- 18%는 MAE (0.94 − 0.77)/0.94 = 18.1%입니다(`03` V9). 사용자 수, 반복, 구간은 없습니다.

### 3.2 접촉·힘 추정 (그림 5, §5.2)

- 기준선: VISOR-HOS(원본과 자체 데이터 미세조정), FEEL(DINOv3 동결 특징 위 2층 MLP, 이진 접촉 검출 BCD와 손가락별 힘 회귀). 접촉 임계 0.8 N.
- 손 단위: 접촉 검출 ROC AUC 0.94, PR AUC 0.89, F1 0.85, 균형 정확도 0.89(FEEL 0.85, 0.86, 0.77, 0.76). 힘 MAE 0.80 대 1.58 N, RMSE 1.36 대 2.80 N(그림 5B).
- 손가락 단위 PR AUC(그림 5C): 약지 ForceBand 0.76 대 FEEL 0.38, 소지 0.59 대 0.27(그림 인쇄 값). 본문은 FEEL을 0.398과 0.314로 적습니다(`03` K2).
- 손가락 단위 MAE(그림 5D): 엄지 1.45/2.72, 검지 1.06/2.09, 중지 0.86/1.57, 약지 0.34/0.75, 소지 0.26/0.76 N.
- 평가 자료의 분할, 사용자, 창 수, 시드, 신뢰구간은 본문에 없습니다.

### 3.3 정책 성공률 (표 2, §5.3)

물체 9개, 칸마다 10회 시행, "pick-and-place 성공 – squeeze 성공" 형식입니다.

- squeeze 성공은 "사람 평가자가 pick·place에 쓰는 힘과 구분할 수 있는 물체별 힘 프로파일을 적용"한 경우입니다(§5.3). 이진 그리퍼는 구조상 힘 프로파일을 만들 수 없어 squeeze가 0입니다.
- 합계(`03` V1): ForceBand pick-and-place 80/90 = 88.9%, squeeze 72/80 = 90.0%. 이진 그리퍼는 pick-and-place 84/90이 가장 높습니다. 초록과 서론의 87%는 이 표에서 정수 시행 수로 정확히 나오는 정의가 없습니다(`03` V2).
- 그림 6: 정점 힘 3.2–19.3 N. 표 2 주석의 파악 폭은 "초기 접촉부터 20 N 인가까지의 그리퍼 열림 범위"입니다.

### 3.4 절제 (부록 D, 그림 9)

검증 MAE(epoch 50): 전체 0.92 N, 스펙트로그램 제거 1.14, IMU 제거 1.02. 한 번의 학습 곡선이고 표본·시드 정보가 없습니다(`03` V11).

### 3.5 일반화 (부록 H, 그림 13)

새 배경, 새 물체(650 g/49 mm에서 210 g/19 mm), 극단 조명, 방해물에서 3단계 구조(집기, squeeze, 놓기)를 유지하며, "배경과 질감 변화가 정확한 힘 크기에 영향을 줄 수 있다"고 적습니다. 성공 수나 힘 오차 수치는 없습니다.

## 4. 저자가 적은 한계와 분석에서 본 간격

저자 한계(§한계): 절대 힘 정확도가 직접 센싱보다 낮음, 4명 사용자와 사용자별 보정, 보정에 아직 손끝 힘 센서가 필요함.

분석에서 확인한 간격(근거는 `03`, `04`):

1. **어디까지가 sEMG의 기여인지** 분리하는 대조가 없습니다. 정책 비교는 힘 채널이 없는 두 그리퍼 기준선뿐이고, 손끝 센서 정답 힘을 쓴 정책이나 비전 기반 힘(FEEL)을 쓴 정책과의 비교가 없습니다.
2. **평가 프로토콜**: 힘 추정의 분할, 사용자, 반복 정보가 없고, 같은 8채널 모델의 MAE가 문서 안에서 0.77–0.92 N로 서로 다른 평가 자료에 붙어 있습니다(`03` V10).
3. **정책 학습 범위**: 물체당 시연 15개로 정책을 물체별로 학습했는지 하나로 합쳐 학습했는지, 9개 중 어느 물체가 OOD인지가 본문에 없습니다.
4. **공개 코드와 논문의 모델 구성**: 모델 입력(직전 힘 입력), 백본(DINOv2), 표본 주파수(1 kHz), 창 길이(10 s)가 논문과 다릅니다(`04`).
5. **샘플링 주파수**: 250 Hz 표본화이면 나이퀴스트 주파수는 125 Hz입니다. 일반적으로 sEMG 신호 에너지는 수십에서 수백 Hz에 걸쳐 있다고 알려져 있어(논문 밖의 일반 지식), 스펙트로그램의 정보량이 125 Hz 이하로 제한됩니다. 논문은 이를 논의하지 않습니다.
