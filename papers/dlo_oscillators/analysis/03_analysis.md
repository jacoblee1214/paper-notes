# 03. 재계산과 일관성 검사

재현(학습, 실행)은 하지 않았습니다. 이 절은 논문 표와 본문에 적힌 수치만으로 다시 계산한 결과입니다. 원자료가 없어서 목표별 점 단위 검정은 할 수 없고, 표의 평균과 SD에서 계산할 수 있는 것만 확인했습니다. 계산 스크립트는 `analysis/recompute.py`(수 초), 결과는 `analysis/recompute_results.json`, 그래프는 `analysis/plot_figures.py`가 만든 `report/figures/own_*.png`입니다.

## 2. 표 1의 유의성 (V5)

표 1은 5 시드의 평균 ± SD입니다(A.3). SD가 표본 SD라고 가정하고 Welch 검정을 했습니다. 시드 평균에 대한 검정이므로 목표 수준 변동은 들어가지 않습니다.

| 조건 | Φ-CON 대 NODE (t, df, p) | Φ-CON 대 LNN (t, df, p) |
|---|---|---|
| 기준 | −1.58, 8.0, **0.15** | −5.62, 5.6, **0.002** |
| 무거움 | −9.28, 7.7, < 0.001 | −13.73, 7.5, < 0.001 |
| 감쇠 낮음 | −0.71, 6.7, **0.50** | −11.85, 6.7, < 0.001 |
| 유연 | −10.44, 5.2, < 0.001 | −24.05, 7.8, < 0.001 |

**읽는 법.** 평균은 모든 조건에서 Φ-CON이 가장 낮습니다. 그러나 기준과 감쇠 낮음에서 Φ-CON과 NODE의 차이는 5 시드로는 구별되지 않습니다. 본문 §5.3의 "모든 DLO에서 가장 낮은 평균 RMSE"는 평균에 대한 말이고, 차이가 있다는 주장은 무거움과 유연 두 조건에만 맞습니다. 초록의 "NODE·LNN과 비슷한 정확도"는 기준과 감쇠 낮음에서 이 해석과 맞습니다.

## 3. 실로봇 개선율의 구간 (V6, V7)

목표별 상대 개선율 23.5 ± 8.8%(왼쪽)와 32.2 ± 10.5%(오른쪽)의 95% 구간을 정규·t 근사로 구했습니다. SD는 목표 간 분산이라고 가정했습니다.

| 끝점 | n = 76 (정상상태 목표) | n = 80 (4개 미관측 목표 포함) |
|---|---|---|
| 왼쪽 | [21.5, 25.5]% | [21.5, 25.5]% |
| 오른쪽 | [29.8, 34.6]% | [29.9, 34.5]% |

- 구간은 0을 크게 벗어납니다. 목표 간 분산이 평균 개선을 가리지 않는다는 뜻이고, 이 점은 맞습니다.
- **문제는 표본입니다.** 76개 목표는 학습·검증 궤적에서 뽑은 정상상태 형상입니다(6.3절). 학습에 쓴 궤적의 목표이므로 "본 적 있는" 형상에 대한 결과입니다. 본 적 없는 목표는 4개뿐이고, 그 4개의 개별 값은 보고되지 않습니다(04 C5).
- 독립 가정의 Welch 검정(V7)은 대응 표본이 아니므로 참고로만 둡니다. 왼쪽 t ≈ 13.7, 오른쪽 t ≈ 14.0입니다.

## 4. 시간 측정의 불일치 (V8)

부록 C는 표 2의 제어 시간이 표 8과 "같은 방식으로" 측정했다고 적습니다. 하지만 두 표의 값은 다릅니다.

| 항목 | 표 2 | 표 8 | 차이 |
|---|---|---|---|
| Φ-CON CPU [µs] | 12.6 ± 3.4 | 13.9 ± 3.0 | −9.4% |
| Φ-CON GPU [µs] | 72.1 ± 8.1 | 64.8 ± 15.8 | +11.3% |
| LNN CPU [µs] | 25.5 ± 2.9 | 25.4 ± 3.9 | +0.4% |
| LNN GPU [µs] | 114.6 ± 4.1 | 105.2 ± 5.0 | +8.9% |

- 표 2는 "제어 한 걸음"이고 표 8은 "예측 한 번"입니다. 측정 대상이 같다는 본문과 다릅니다. 차이가 몇 µs이므로 결론(GPU가 CPU보다 느림, Φ-CON이 LNN보다 빠름)은 바뀌지 않습니다. 그러나 두 표가 같은 실험에서 나왔다는 주장은 맞지 않습니다.
- 측정 기계는 CPU Ryzen 9 5900HS와 노트북 GPU RTX 3050 Ti입니다(부록 C). 표 2의 기계는 본문에 없습니다.

## 5. 파라미터 수 재계산 (V9)

표 5의 구조(은닉층 수 × 폭)와 대칭 행렬의 자유도로 다시 셌습니다.

| 설정 | 모형 | 재계산 | 표 4 | 차이 |
|---|---|---|---|---|
| 시뮬 | NODE (입력 3·3N = 270, 은닉 3×512) | 710,234 | 710,234 | 0 |
| 시뮬 | LNN (질량망 5×32, 퍼텐셜망 4×128) | 203,584 | 203,584 | 0 |
| 시뮬 | FBCON | 12,105 | 12,375 | **270** |
| 시뮬 | Φ-CON | 19,761 | 20,031 | **270** |
| 실제 | NODE (은닉 2×512) | 336,932 | 336,932 | 0 |
| 실제 | LNN (질량망 6×128, 퍼텐셜망 7×64) | 200,603 | 200,603 | 0 |
| 실제 | FBCON | 1,926 | 2,034 | **108** |
| 실제 | Φ-CON | 3,048 | 3,156 | **108** |

- NODE와 LNN은 표 5의 구조와 정확히 맞습니다. LNN 질량망의 출력은 3N(3N+1)/2 = 4095(시뮬)와 666(실제)이고, 하삼각 Cholesky 성분으로 읽었습니다. 이 해석이 맞다는 근거입니다.
- FBCON과 Φ-CON의 차이는 **모형 종류와 무관하게 정확히 9N**입니다(시뮬 270, 실제 108). 두 모형에 공통으로 들어가는 파라미터 블록이 있는데 논문에는 없습니다. 가능한 설명은 3N×3 행렬 하나 (예: 입력 쪽 3차원 항)이지만 확인할 수 없습니다. 방식 차이라면 표 4의 파라미터 수가 틀린 것이고, 빠진 설명이라면 재현에 영향을 줍니다.
- Φ-CON 자체의 구성 가정: A_r = L_rU_r의 자유도 n²(n = 3N − 3), 대칭 행렬 K_r과 M_w, D_w. 논문은 이 구성을 명시하지만 Φ-CON 파라미터 수 자체는 설명하지 않습니다.

## 6. 물리량 확인 (V10, 가정이 들어간 계산)

Table 3과 A.5 값으로 질량과 무게를 계산하고, 정적 PD 잔차 힘 K_p × e와 비교했습니다. 이 절은 **추정**이며 논문이 제시한 값이 아닙니다.

| 항목 | 값 |
|---|---|
| 시뮬 기준 DLO 질량, 무게 | 0.236 kg, 2.31 N |
| 시뮬 무거움 DLO 질량, 무게 | 0.613 kg, 6.01 N |
| 실제 케이블 질량, 무게 (ρ 3500, r 9 mm, L 0.76 m) | 0.677 kg, 6.64 N |
| 시뮬 PD 단독 잔차 힘 (K_p = 10 × 238.6 mm) | 2.39 N (기준), 4.59 N (무거움) |
| 실제 PD 단독 잔차 힘 (K_p = 200 × 63.7 mm, 48.3 mm) | 12.7 N (왼쪽), 9.7 N (오른쪽) |
| 임피던스 게인에서 암묵적 질량 (ζ = 0.77, K_d = 21.8, K_p = 200) | 1.00 kg |

- **시뮬 기준:** PD 단독 잔차 힘이 전체 무게(2.31 N)와 거의 같습니다. 게인을 바꿔도 K_p × e가 2.39, 2.41, 2.42 N으로 일정합니다(V11). 정적 하중이 오차의 원인이라는 해석과 맞습니다.
- **시뮬 무거움:** 잔차 힘 4.59 N이 무게 6.01 N보다 작습니다. 중력만으로 설명하면 맞지 않습니다. 끝점에 걸리는 힘의 방향과 탄성 장력이 섞여 있기 때문으로 보입니다.
- **실제:** PD 단독 잔차 힘(9.7–12.7 N)이 케이블 무게(6.6 N)보다 큽니다. 중력 보상만으로는 설명되지 않습니다. 탄성 장력이나 임피던스 제어기 자체의 영향이 큽니다. 논문은 실제 τ̄의 값을 보고하지 않아서 이 해석을 검증할 수 없습니다.
- **암묵적 질량 1.00 kg:** 논문의 ζ와 K_d를 맞추면 제어기 질량이 1 kg입니다. 논문은 이 가정을 적지 않았습니다. 재현 시 제어기 관성을 정해야 합니다.

## 7. 게인 민감도 (V11, 표 9)

- K_d/√K_p = 0.316, 0.317, 0.316. 감쇠비가 일정하다는 설정과 맞습니다.
- K_p × e = 2.386, 2.410, 2.420 N. 정적 힘이 게인과 무관하게 같습니다. PD 단독 오차가 1/K_p에 비례한다는 설명과 맞습니다(부록 D).
- 감소율 99.37, 99.09, 98.76%. 본문과 일치합니다.

## 8. 전체 판정

- **재계산으로 맞는 것:** 초록과 본문의 감소율(V1–V4), 시뮬 감쇠비와 게인 설정(V11), NODE와 LNN의 파라미터 수(V9).
- **재계산으로 맞지 않는 것:** 두 표의 계산 시간(V8), FBCON과 Φ-CON 파라미터 수의 9N 차이(V9).
- **통계로 약한 것:** 표 1의 기준·감쇠 낮음에서 NODE와의 차이(V5). 실로봇 목표별 개선은 통계적으로 크지만 학습 목표와 겹쳐 있습니다(V6).
- **확인할 수 없는 것:** 실제 예측 오차(그림 4, 수치 없음), 4개 미관측 목표의 개별 값, τ̄의 실측값, 시드 수준의 실로봇 분산.
