# 04. 주장 검증 (공식 코드 없음)

공식 코드가 확인되지 않아 코드 대조(`04_code_verification.md`) 대신 **주장 검증**을 씁니다. 주장은 C1–Cn, 논문 내부 불일치와 표현 문제는 D1–Dn입니다. 검증 수준은 세 가지입니다.

- **재계산**: 논문 표 숫자로 다시 계산해 일치 확인 (`03_analysis.md`, `analysis/recompute.py`)
- **일관성**: 표 사이 또는 본문과 표 사이가 맞는지 확인
- **미검증**: 원본 텐서, 에피소드 로그, 코드가 필요해 확인 불가

## 2. 검증 결과 요약

- **재계산으로 확인된 주장 (C4, C5, C6, C7, C11, C12, C13, C15, C16):** 개수와 구간, p 값이 모두 맞음. 정확도는 좋음.
- **일관성으로만 확인된 주장 (C2, C3, C18):** 표 사이 맞음. 원자료가 없어 개별 값은 확인 못 함.
- **미검증 (C9, C10, C14, C17, C20):** 원본이 없거나 텍스트에만 있음.
- **재계산되지만 해석이 약한 주장 (C8, C11–C12, C19):** 숫자는 맞으나 결론의 강도가 근거를 넘는 부분이 있음 (§3).

## 4. 구현 가능성 판정

### 4.1 판정

- **논문의 측정(끝점 질량, value 개입, 폐루프 BOS 실험)은 이 맥에서 재현할 수 없습니다.** 공개 체크포인트는 π0.5 계열(약 3B 파라미터)이고, 측정 코드는 공개되지 않았습니다. Apple M4 Pro(24 GiB, MPS, CUDA 없음)에서 체크포인트 로드와 짧은 추론은 메모리상 가능할 수 있으나, 폐루프 실험(5개 과제, seed 50개, 개입 8개, 실행 3회 이상)은 시간이 매우 오래 걸리고 GPU 비결정성 문제도 있습니다. **이번 분석 범위에서는 재현을 시작하지 않았습니다.**
- **구현 자체(측정 도구)는 가능합니다.** attention 가중치를 꺼내는 hook, RoPE 제거 옵션, value 0과 교체 개입, 쌍체 McNemar 집계를 짜는 일은 PyTorch로 한두 주 정도(추정)입니다. 측정 도구는 공개 체크포인트 없이도 작은 모델에서 시험할 수 있습니다.
- **CPU만으로 가능한 것:** 논문 표 재계산(이미 완료), 쌍체 검정과 구간 계산, 작은 랜덤 모델에서 RoPE가 양방향 행동 청크에 끝점 질량을 만드는지 보는 toy 실험. 이번 분석에서는 toy를 만들지 않았습니다. 논문의 중심 주장(위치 효과)을 직접 검증하는 것은 아니고 메커니즘 설명을 보는 수준이라 우선순위가 낮다고 판단했습니다.

### 4.3 노력 추정 (추정치)

- 측정 도구 구현 (hook, RoPE 옵션, 개입, 집계): 1–2주
- 공개 체크포인트에서 끝점 질량 측정: 체크포인트 설치와 로드 포함 2–3일
- 폐루프 재현 (5개 과제, 개입 8개, 실행 3회): GPU 기준 며칠, 이 맥에서는 주 단위 이상
