# 03. 재계산, 일관성 검사, 권리 확인

논문 수치를 두 종류로 확인했습니다. (1) 논문에 적힌 개수, 비율, 검정을 다시 계산하고, (2) 저자가 공개한 결과 파일(`inputs/`에 복사한 작은 JSON 네 개)과 대조했습니다. 공개 데이터 파일(10,000행)은 재배포 금지 조건이 있어 복사하지 않고, 원 저장소에서 정적으로만 읽었습니다. 학습과 정책 실행은 하지 않았습니다. 분석일 2026-11-21.

재계산 스크립트: `analysis/recompute.py` (결과 `recompute_results.json`), 데이터 구조 검사: `analysis/data_checks.py` (결과 `data_checks_results.json`), 그래프: `analysis/plot_figures.py`.

## 2. 부호 검정과 독립 단위

- 10개 에피소드가 모두 같은 부호일 때 정확 양측 부호 검정의 p는 2/2^10 = 0.00195로 논문 "p = 0.002"와 맞습니다 (§5.1).
- 4개 궤적이 모두 같은 부호면 p는 2/16 = 0.125입니다. 논문의 "1/8 아래로 갈 수 없다"(§3.6)와 맞습니다.
- 주 풀의 독립 궤적 4개와 다섯 분할 풀의 20개는 §3.4와 일치합니다. 두 에피소드에서 각각 겹치지 않는 궤적 두 개를 얻기 때문입니다 (1000행 / 400스텝 = 2.5, 정수 부분 2).

## 4. 저장소 대조 결과

- 시험 18개(`n_tested` 18), 세 번째 정책 4개(`n_third_policy` 4)는 논문과 같습니다. 정책은 36 + 4 = 40개입니다.
- 학습 붕괴(점수 0.000) 정책은 3개입니다.
- 정책 실패 기준(점수 < 0.15 또는 붕괴)으로 셌을 때 실패 정책은 27개이고, 그중 낙상률이 0.5보다 큰 것은 21개입니다. 논문과 같습니다.

- 학습률별로 보면 논문 §9.5의 문장과 맞습니다. 원래 학습률(1e-4)에서 20·80스텝 미세조정 8개는 모두 실패했습니다. 5스텝 4개 중 3개는 실패하지 않았고, 혼합 데이터 실행 하나(M_s0)만 5스텝에서도 실패했습니다. 1/10 학습률(1e-5)에서는 80스텝 2개가 모두 실패하지 않았고, 160·320스텝 4개가 모두 실패했습니다.

## 5. 권리 확인

- **arXiv 라이선스:** abs 페이지의 "view license" 링크는 `creativecommons.org/licenses/by/4.0/`입니다. CC BY 4.0입니다. 확인 날짜 2026-11-21.
- **PDF 저작권 표시:** `pdftotext` 결과에서 ©, copyright, All rights reserved, confidential, proprietary, trademark, license 문자열을 찾지 못했습니다. 첫 쪽의 저자 정보에는 이메일 주소가 있으나 이 분석의 공개 산출물에는 쓰지 않았습니다.
- **그림:** 13개(`pdfimages -list` 기준 이미지 객체 여러 개, 그래프와 도식). 캡션 기준으로 저자가 만든 그래프와 도식이며, 외부 사진이나 실로봇 사진은 보이지 않습니다. 그러나 그림별 육안 검토는 하지 않았습니다.
- **판정:** 논문 그림은 CC BY 4.0 조건을 만족할 수 있습니다. 그러나 공개본에는 **우리가 그린 그래프만** 넣습니다(`report/figures/own_*.png`). 논문 그림을 빼면 출처 표기와 그림별 권리 확인의 부담이 없습니다.
