# UMI 수치 재계산과 검정 (논문 본문, 그림 8·9·11·12)

원자료(시행별 기록, 시드, 로그)는 공개되지 않았습니다. 따라서 이 장의 검정은 **논문이 보고한 성공 횟수**에서 다시 계산합니다. 시행은 독립 이항이라고 가정합니다. 같은 장면과 같은 정책 체크포인트를 반복한 결과이므로 실제 분산은 이보다 클 수 있습니다. 실행 명령은 `python3 analysis/recompute.py`(numpy, scipy, 수 초)이고, 결과는 `analysis/recompute_results.json`입니다.

재현(로봇 실험)은 하지 않았습니다. 이 장의 모든 수치는 논문 보고값의 재계산입니다.

## 4. 주장 판정 (C1–C13)

판정 기준은 다음과 같습니다. **지지**는 재계산이 주장과 같은 방향이고 유의하거나 수치가 맞음, **부분 지지**는 방향은 맞지만 검정이 약하거나 범위가 좁음, **미검증**은 실험이 없는 설계 주장, **불일치**는 보고 수치끼리 어긋남입니다.

| 번호 | 논문 주장 (위치) | 근거 재계산 | 판정 |
|---|---|---|---|
| C1 | 네 과제 모두 시연 데이터만으로 동적·양손·정밀·장기 행동을 학습 (§I, §V) | 과제 4종의 성공률 0.70–1.00 (표본 20, 던지기 120) | 지지 (같은 환경에서 평가, 로봇과 객체 초기 상태만 무작위) |
| C2 | 어안 원본 입력이 시야와 정책 성능을 높임 (HD2, §V-A) | 20/20 대 11/20, p = 0.0012 | 지지 (과제 한 개, 한 실행) |
| C3 | 상대 궤적 행동이 절대·델타 행동보다 낫다 (PD2.1, §V-A) | 대 절대 p = 8e-7. 대 델타 p = 0.11 | 부분 지지 (절대 행동 대비만 유의) |
| C4 | 추론 시 지연 맞춤이 동적 과제에 필수 (PD1, §V-B) | 105/120 대 69/120, p = 2.5e-7 | 지지 (한 과제, 같은 정책 체크포인트 가정) |
| C5 | 두 그리퍼 사이 상대 자세가 양손 협응에 필수 (PD2.3, §V-C) | 14/20 대 6/20, p = 0.026 | 지지 (표본 작음, 과제 한 개) |
| C6 | 거울 영상을 반사하고 좌우를 바꾸면 최선 (HD3, §V-A) | 거울 없음 18/20, 반사 없음 17/20, 최종 20/20. 최종 대 반사 없음 p = 0.23 | 부분 지지. 반사 효과의 방향은 맞으나 유의하지 않음. "최선"은 20/20 한 번으로 봄 |
| C7 | 시연을 여러 환경에서 모으면 미지 환경과 물체에 0-shot으로 일반화 (§VI) | 협소 데이터만 0/20. 전체 43/60 = 72%. 미지 컵 15/20 | 지지 (환경 두 곳, 미지 컵 2종, 평가 표본 작음) |

| C9 | UMI 수집이 원격 조작보다 3배 이상 빠르고 사람 손의 48% (§VII) | 그림 11 추출값: 111/35 = 3.17, 111/231 = 48.0% | 지지 (그림 숫자 추출 기준. 원 그림 확인 필요) |

## 5. 검정이 말하지 않는 것

- 같은 정책 체크포인트를 여러 시드로 반복하지 않았습니다. 시드 분산은 수치에 없습니다.
- 과제마다 객체, 초기 상태, 평가자가 다릅니다. 과제 간 비교는 하지 않았습니다.
- 성공 기준의 일부는 주관적입니다(접시 닦기의 "깨끗함", 스웨터 접기의 "정사각형"). 논문도 이를 인정합니다(부록 C).
- 델타 행동 기준선은 같은 SLAM 출력에서 만든 것입니다. 보정이 더 나은 절대 행동의 가능성은 논문도 열어 둡니다(§V-A).

## 6. 토이 검사

원래 분석 틀에서는 CPU 토이를 선택 사항으로 두었습니다. 이 분석에서는 **토이를 만들지 않았습니다.** 논문의 핵심 주장인 상대 궤적 행동의 장점과 지연 맞춤 효과는 실제 로봇 없이는 정량적으로 옮길 수 없고, 토이로 얻는 수치는 논문 수치와 비교할 근거가 약하기 때문입니다.
