# 03. 재계산과 일관성 검사

재현(학습, 시뮬 실행)은 하지 않았습니다. 논문 Table 5의 수치와 본문·부록의 숫자만으로 재계산했습니다. 스크립트는 `analysis/recompute.py`, 결과는 `analysis/recompute_results.json`입니다(수 초, CPU, numpy·scipy).

## 0. 입력과 가정

- 대상: Table 5 (p.11), 전 20개 체크포인트 × 2 과제 = 40개 셀. 열은 SFT 직후 i.i.d. 학습 성공률, 반복 잡음 학습 성공률, i.i.d. 추가 평가 성공률(사전 RL), DSRL 후 학습·추가 평가 성공률(3시드 평균)입니다.
- **분모 가정(부록 D):** 사전 RL은 placement당 25회 (ScrewLightbulb 추가 평가는 20회). 학습 placement는 2개라 합치면 50회, ScrewLightbulb 추가 평가는 2 × 20 = 40회입니다.
- **사후 RL 분모:** 평가는 5회 × 5에피소드 (400k–500k, 25k 간격 가정)라 시드당 25회/placement입니다. 3시드 평균이라 분모를 역으로 확정할 수 없습니다. 개별 시드 값이 없어 사후 값의 구간은 근사로만 씁니다.
- **독립성:** SFT를 레시피당 한 번(시드 1개) 했습니다(부록 B 끝). 따라서 레시피 간 차이에는 SFT 실행 효과가 섞여 있고, 체크포인트 4개는 같은 실행의 시점이라 독립 표본이 아닙니다. 아래 검정 p값은 참고용입니다.

## 1. 분모 검사 (V1)

Table 5의 사전 RL 값이 정수 개수 k/N을 반올림한 값으로 설명되는지 확인했습니다(|100k/N − v| ≤ 0.5인 정수 k가 존재하는 N).

| 열 | 가능한 N | 부록 D 가정과 일치 |
|---|---|---|
| ScrewLightbulb 학습 (i.i.d., 반복) | 50, 100, 120, 150 | 50 (2 × 25) 일치 |
| ScrewLightbulb 추가 (i.i.d.) | 40, 50, 60, 100, 120, 150 | 40 (2 × 20) 일치, 20이나 25 불가 |
| CoffeePressButton 학습 (i.i.d., 반복) | 50, 100, 120, 150 | 50 일치 |
| CoffeePressButton 추가 (i.i.d.) | 50, 100, 120, 150 | 50 (2 × 25) 일치 |

**판정:** 사전 RL 분모는 부록 D와 맞습니다. 사후 RL 분모는 3시드 평균이라 이 방법으로 판정할 수 없습니다.

체크포인트 4개의 단순 평균입니다. 사후 값은 3시드 평균의 평균입니다.

| 레시피 | Screw 학습 | Screw 추가 | Coffee 학습 | Coffee 추가 | 두 과제 학습 | 두 과제 추가 |
|---|---|---|---|---|---|---|
| EXPERT-ONLY | 100.0 | 76.0 | 97.8 | 88.5 | **98.9** | **82.3** |
| FROZEN-LM | 49.8 | 39.3 | 90.3 | 69.8 | 70.0 | 54.5 |
| FULL-FT | 61.5 | 22.0 | 91.8 | 45.3 | 76.6 | 33.6 |
| LORA | 50.0 | 17.0 | 77.5 | 35.5 | 63.8 | 26.3 |

사전 RL 평균(두 과제, 학습 i.i.d. / 반복)은 EXPERT-ONLY 18.0 / 24.0, FROZEN-LM 32.0 / 31.3, FULL-FT 30.0 / 29.3, LORA 40.8 / 36.3, LORA-LM 44.8 / 32.8입니다. 전체 값은 `recompute_results.json`의 `recipe_means`에 있습니다.

## 3. 신뢰구간 (V3)

**사전 RL (단일 시도, 이항 Wilson 95%):**

- Coffee EXPERT-ONLY 4k, i.i.d. 학습 16/50 = 32% → [20.8, 45.8].
- Coffee LORA-LM 18k, i.i.d. 학습 44/50 = 88% → [76.2, 94.4]. Coffee FROZEN-LM 18k, i.i.d. 학습 39/50 = 78% → [64.8, 87.2]. 두 구간이 겹쳐 "FROZEN-LM이 18k에서 더 낫다"는 주장은 이 자료로 확정되지 않습니다.
- Screw EXPERT-ONLY 2k 반복 학습 23/50 = 46% → [33.0, 59.6]. Screw EXPERT-ONLY 16k, i.i.d. 학습 8/50 = 16% → [8.3, 28.5].
- 추가 평가 0/40 (Screw) → 상한 8.8%. 즉 Screw 추가 평가 사전 RL 값 0–8%는 대부분 구분되지 않습니다.

**사후 RL (3시드 평균):** 시드별 값이 없어 구간을 만들 수 없습니다. 분모 25 × 2 placement × 3시드 = 150 가정이면 성공률 90%의 이항 표준오차는 약 2.4 pp입니다. 따라서 두 레시피의 차이가 5 pp 이하인 경우는 이 자료로 구분할 수 없습니다.

## 4. 상관 검사 (V4 / K1)

체크포인트 20개 × 과제, 사전 RL 열과 사후 RL 열의 상관입니다. 점들이 레시피 안에서 묶여 있어 p값은 참고용입니다.

| 과제 | 사전 열 → 사후 열 | Pearson r (p) | Spearman ρ (p) | 논문 주장 |
|---|---|---|---|---|
| Screw | i.i.d. 학습 → 학습 | −0.08 (0.74) | 0.15 (0.53) | 양의 상관 없음: **일치** |
| Screw | **반복 잡음 학습 → 학습** | **+0.84 (<0.001)** | **+0.86 (<0.001)** | 양의 상관 없음: **불일치** |
| Screw | 반복 잡음 학습 → 추가 | +0.81 (<0.001) | +0.87 (<0.001) | 양의 상관 없음: **불일치** |
| Coffee | i.i.d. 학습 → 학습 | −0.36 (0.12) | −0.51 (0.02) | 음의 상관: 약하게 일치 |
| Coffee | i.i.d. 학습 → 추가 | −0.60 (0.005) | −0.48 (0.03) | 음의 상관: 일치 |
| Coffee | 반복 잡음 학습 → 학습 | −0.75 (<0.001) | −0.86 (<0.001) | 음의 상관: 일치 |
| Coffee | 반복 잡음 학습 → 추가 | −0.83 (<0.001) | −0.82 (<0.001) | 음의 상관: 일치 |

**반복 잡음 Screw 상관은 EXPERT-ONLY 때문이 아닙니다.** EXPERT-ONLY 4개를 뺀 16개에서도 r = +0.83 (p = 0.0001), ρ = +0.88입니다. 다만 이 양의 상관은 체크포인트 시점과 같이 움직입니다. 2k에서 반복 잡음 성공률과 사후 성공률이 모두 높고, 16k에서는 둘 다 낮습니다. SFT 시간이 두 값을 함께 낮추는 교란일 수 있습니다. 이 자료로는 "SFT 성공률이 조종 가능성을 예측한다"는 뜻인지 "SFT 시간이 둘 다 움직인다"는 뜻인지 구분할 수 없습니다.

Coffee에서 반복 잡음 값이 높을수록 사후 성공률이 낮다는 결과는 논문 §4와 맞습니다. EXPERT-ONLY를 뺀 16개에서도 r = −0.74 (p = 0.001)입니다.

## 6. 재계산에서 확인한 주장 판정 요약

자세한 주장별 판정은 `analysis/04_claim_verification.md`의 C1–C14에 있습니다. 여기서는 숫자 근거만 적습니다.

- **확인됨:** EXPERT-ONLY 학습 사후 95–100% (두 과제 모두), Screw 8k에서 100 / 88 대 나머지 최대 33, 과제 평균 기준 추가 평가 순위 (LoRA < FULL-FT < LORA-LM < FROZEN-LM < EXPERT-ONLY).
- **부분 확인:** LM 업데이트 레시피 3개가 추가 평가에서 최하위 (맞음). 학습 평가에서는 FULL-FT가 최하위가 아니고 FROZEN-LM이 세 번째로 낮습니다.
- **불일치:** Coffee SFT 성공률 최고 (K10), Screw 반복 잡음 상관 (K1), 부록 F의 6–12% (K9).
- **구별 불가:** LoRA가 학습 기준으로도 최하위라는 주장 (LoRA-LM과 0.25 pp 차이).

## 7. 재현 가능성과 재계산의 한계

- 이 재계산이 확인하는 것은 논문 표 안의 산술과 통계 설명뿐입니다. 학습된 정책, 시뮬레이터, 데모 데이터는 확인하지 않았습니다.
- 검정 대부분은 레시피당 SFT 1회 기준입니다. 가장 큰 제한은 "레시피 효과"와 "SFT 실행 효과"를 구분할 수 없다는 점입니다. 논문 §5의 첫 번째 한계와 같은 내용입니다.
- 사후 RL 불확실성은 시드 3개와 체크포인트 4개만 있어 근사입니다.
