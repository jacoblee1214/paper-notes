## 1. 풀려는 문제와 주장

- **문제.** 한 장면에서 일부 과제만 시연된 데이터로 미세조정한 VLA는 다른 지시를 받아도 훈련 과제를 수행하는 경향이 있습니다(§1, 그림 2). 저자는 이를 "반사실 실패"라 부르고 원인을 시각 주도 데이터 불균형과 모달리티 불균형(§3.1)으로 설명합니다. 시각 토큰은 수백–수천 개, 언어 토큰은 수십 개라는 토큰 수 비대칭이 근거로 제시됩니다(추정, 논문에 측정은 없음).
- **기여 세 가지(§1).** (1) LIBERO-CF 벤치마크, (2) CAG, (3) 시뮬레이션과 실세계 분석. 주장의 핵심은 "CAG는 구조나 가중치를 바꾸지 않고 언어 반응성을 키운다"입니다(초록).

## 2. 벤치마크: LIBERO-CF (§4)

- 같은 LIBERO 장면에서 **다른 가능한 지시**를 준다. 네 스위트: CF-Spatial 15과제(배경 물체를 목표로), CF-Object 10과제(다른 물체), CF-Long 10과제(긴 과제), CF-OOD 15과제(미세조정에서 본 적 없는 물체). 합계 50과제입니다(그림 1의 "50+"가 가리키는 범위는 본문에 없고, CF-Focused 15과제를 더한 65과제를 뜻할 수 있습니다. 추정).
- **지표.** 접촉률("grounding"): 그리퍼가 지시된 물체에 닿았는가(완료 여부와 무관). 성공률("success"): 과제 완료. 각 지표에서 지시된 과제를 따른 비율(Faithful, F)과 원래 훈련 과제를 따른 비율(Biased, B)을 보고합니다.
- **CF-Focused(§4.1, 표 2).** CF-Spatial에서 훈련 과제 물체를 장면에서 뺀 변형. 같은 지시에서 접촉률 39.0 → 64.4%, 성공률 20.0 → 40.0%(세 모델 평균).
- **입력 제거(§4.1, 표 1).** 언어를 빼도 성공률이 유지됨: OpenVLA-OFT 97.1 → 69.1%, π0.5 96.9 → 51.7%, π0 94.2 → 18.5%. LIBERO-Goal은 장면이 하나이고 지시로만 목표가 갈려서 언어를 빼면 10% 안팎입니다.
- **시험 모델.** OpenVLA-OFT, π0, π0.5(공식 LIBERO 체크포인트), 부록에 X-VLA. 과제당 50회(부록 B.1).

## 3. 방법: Counterfactual Action Guidance

- **식.** 행동 청크 두 개를 만든 뒤 합칩니다(식 2): `a_CAG = a_uncond + ω (a_cond − a_uncond)`, ω ≥ 0. ω = 1이면 조건부 정책 그대로입니다. 두 가지 비조건 가지:
  - **TF(학습 없음).** 같은 VLA에서 언어 입력을 빼고 추론(§5.2 1).
  - **VA(Vision-Action 사전).** 언어를 뺀 채 따로 미세조정한 모델(§5.2 2). OpenVLA-OFT는 LoRA 300k 스텝(배치 64, 학습률 5e-4), π0·π0.5는 전체 미세조정 30k 스텝(배치 32, 학습률 5e-5, EMA 0.999), X-VLA는 50k 스텝(부록 B.3).
- **ω 선택(§6.2, 부록 B.3).** π0, π0.5는 1.5, OpenVLA-OFT는 3.0, X-VLA는 1.5. TF와 VA에 같은 값을 씁니다. 그림 4의 곡선은 CF-Spatial의 VA-CAG 값이고, 선택 근거로 제시됩니다(`03` V8).
- **동기식(식 1).** `P(a|o,l) ∝ P(a|o) P(l|a,o)`는 "개념적" 식입니다(§3.2). 이 식에서 식 2가 유도된다는 서술은 v3에 없습니다.
- **비용(§7.3, 표 6).** VA-CAG 학습은 8 H100에서 LIBERO 약 3시간, 실세계 데이터 약 1시간. 추론 지연은 π0.5 80.0 ms, TF-CAG 126.6 ms(1.6배), VA-CAG 132.6 ms(1.7배), GPU 메모리 8.5 GB → 16.5 GB(VA).

## 4. 시뮬레이션 결과 (§6, 표 3, 4, 7)

π0.5의 평균(표 3, 네 스위트 단순 평균):

| | 접촉률 F | 접촉률 B | 성공률 F | 성공률 B |
|---|---|---|---|---|
| 기준선 | 30.8 | 65.6 | 13.2 | 60.9 |
| TF-CAG | 40.5 | 59.8 | 16.8 | 43.5 |
| VA-CAG | 46.3 | 52.2 | 21.7 | 36.2 |

- OpenVLA-OFT는 접촉률 F 4.7%, 성공률 F 0.4%로 가장 낮고, VA-CAG(ω = 3.0)에서 11.3%, 2.1%가 됩니다. π0는 접촉률 28.8 → 37.3%(VA)이고 성공률은 9.6 → 10.4%입니다. X-VLA(표 7)는 CF-Long 접촉률 F가 98.2%로 높고 CF-Object는 1.4%입니다.
- **전략 비교(§6.2, 표 4, π0.5, CF-Spatial과 CF-Long).** 전략 1 기준선, 전략 2 언어 드롭아웃 미세조정(접촉률 F 9.5%로 크게 나쁨), 전략 3 TF, 전략 4 LoRA VA, 전략 5 전체 미세조정 VA. 전략 3 대 5의 CF-Spatial 성공률 차이는 4.3 %p로 본문과 같습니다.
- **안내 배율(그림 4).** π0.5 접촉률은 ω 1.0, 1.5, 2.0, 3.0에서 39.3, 50.7, 56.8, 58.4%로 오르고 성공률은 24.4, 31.6, 28.8, 16.4%로 1.5에서 최대입니다. OpenVLA-OFT 성공률은 ω = 3.0에서 7.9%로 최대입니다.

## 5. 실세계 결과 (§7, 그림 5와 7, 표 5, 9, 10)

- **설정.** Franka Research 3 + Robotiq 2F-85, DROID 구성(ZED 2i, ZED mini). 장면마다 세 과제: 시연 20개인 in-domain 과제 하나, 시연 1개씩인 under-observed 과제 둘(OOD는 제로샷). π0.5-DROID를 VLA와 VA 둘 다 10k 스텝, 배치 32로 미세조정. 지시당 10회(§7.1).
- **여섯 장면(그림 5).** 물체 인식 2, 공간 2, 목표 1, OOD 1. 부록 C에 긴 과제 2장면(그림 7). 접촉률과 성공률은 표 9와 10의 "실행한 대상 / 시도" 분수로 환원됩니다(`03` V14).
- **헤드라인.** 초록과 그림 1(d): 접촉률 +9.4%, 성공률 +17.2%(52.2 → 69.4%). `03` V15에서 이 값이 여섯 주요 장면의 세 지시(in-domain 포함) 평균임을 확인했습니다. 그림 1(d)의 "Biased 18.9 → 10.6%"는 지시된 대상이 아닌 물체를 성공적으로 수행한 비율(180회 중 34회, 19회)과 일치합니다.
- **분석(§7.3).** 반사실 시연 0, 1, 2개일 때 CAG를 더하면 40개 중 성공이 3 → 8, 8 → 20, 22 → 30입니다(`03` V11). 시연이 없으면 CAG도 도움이 되지 않는 칸이 있다는 점은 §8 한계 문단과 같습니다.

## 6. 한계 (§8)

저자는 두 가지를 적습니다. (1) 기반 정책에 필요한 기술이 없으면 행동 공간 안내가 만들어 낼 수 없다. (2) 추론 비용이 늘고 VA-CAG는 별도 모델이 필요하다. 이 분석이 덧붙이는 점은 `03`에 있습니다. 가장 큰 것은 (a) CF-Long의 시행 수가 보고된 비율과 맞지 않는 점(V5), (b) CAG가 기존 과제 완수를 낮추는 정도(V19), (c) ω를 시험 스위트에서 고른 점(V8), (d) 행동 외삽이 단일 청크의 모드 확률을 바꾸지 않는다는 토이 결과(§5)입니다.

## 7. 한 문장으로

반사실 지시에서 VLA가 훈련 과제를 따르는 경향은 LIBERO-CF에서 일관되게 측정되고, 행동 외삽 안내는 이 경향을 줄입니다. 다만 효과의 크기는 ω와 기반 모델에 달려 있고, 이득은 훈련 과제 성공의 감소보다 작습니다.
