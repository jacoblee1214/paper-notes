# WorldEval: World Model as Real-World Robot Policies Evaluator — 논문 분석 (arXiv:2505.19017)

*WorldEval* (Yaxuan Li, Yichen Zhu, Junjie Wen, Chaomin Shen, Yi Xu; Midea Group · East China Normal University). 분석 대상은 arXiv **v1 하나**(2025-05-25)입니다. API 기준 최신 버전이 v1이고, v2는 없습니다(§6 참고). 원문은 `paper/paper.pdf`(20쪽, 17 MB)이며 `paper/paper.txt`는 `pdftotext -layout` 결과입니다. 본문 표 번호와 절 번호는 원문 기준입니다.

## 1. 한 문단 요약

실물 로봇 정책을 평가하려면 시간과 장비가 많이 듭니다. 이 논문은 영상 생성 세계모델을 **정책 평가기**로 쓰자고 제안합니다. 핵심은 **Policy2Vec**입니다. 정책 네트워크의 잠재 행동 벡터(액션 디코더 직전의 표현)를 Wan 2.1 14B I2V 모델의 조건 신호로 넣고, 같은 관측과 지시문에서 정책이 실제로 하는 행동을 영상으로 그립니다. 생성 영상의 성공 여부는 Gemini-2.0이 판정하고, 이 성공률 순위를 실물 성공률 순위와 비교합니다. 평가 지표는 Pearson r과 MMRV입니다. 5개 과제 중 3개(Place Cup, Strike Block, Handover Block)에서 4개 정책을 비교한 표 1 평균은 **r = 0.942, MMRV = 0.044**입니다. 같은 과제에서 실물 시뮬레이터(RoboTwin, MidJourney 변환 사용) 평가는 r = 0.411, MMRV = 0.261입니다.

## 3. 방법 (Policy2Vec + WorldEval)

- **잠재 행동 조건 (§3.2).** 정책의 액션 디코더 직전 잠재 벡터를 투영층으로 차원을 맞추고, 학습 가능한 스칼라 α를 곱한 뒤 언어 임베딩에 더합니다. 그 결과를 DiT에 넣습니다. 미세조정은 LoRA(rank 16, alpha 16)이며 투영층과 DiT 블록의 선형층을 조금 학습합니다. 학습 데이터는 실제 로봇 궤적 1,400개이고, 각 궤적을 세 번 샘플링해 81프레임, 480×480으로 만듭니다(§4, 부록 C).
- **성공 판정 (§3.3).** Gemini-2.0에 "Is this apple place on the plate? Answer yes or no" 형식의 질문과 생성 영상을 넣습니다. 판정기의 정확도는 보고되지 않습니다. 이 점이 가장 큰 공백입니다(`03` §4).
- **지표 (§4).** Pearson r과 MMRV(SIMPLER의 정의를 따름). 과제당 정책 4개(π0, DexVLA, OpenVLA, Diffusion Policy)입니다.
- **학습 설정 (부록 C).** 8× H800, 데이터 병렬, 약 11시간, 생성은 50 diffusion step입니다.

## 4. 실험 설계

- **로봇.** AgileX 양팔 ALOHA형, 14차원 관절 공간, 상단 RealSense 카메라 1대, 50 Hz 텔레오퍼레이션(§4, 그림 3).
- **과제 5개.** Bussing Table(100궤적으로 미세조정), Collect Toy(미학습 과제·물체), Place Cup·Handover Block·Strike Block(RoboTwin 기반, 각 50궤적). 과제마다 40 롤아웃을 같은 물체 세트에서 돌립니다(§4).
- **실물 시행 수.** 본문은 "over 1,000 real-world trials"라고 씁니다. 표 1·2의 40 × 5과제 × 4정책은 800회입니다. 표 3의 체크포인트 시행을 더해야 1,000회를 넘습니다. 정확한 합계는 확인하지 못했습니다(`03` §3).
- **실물 시뮬레이터 비교 (§4.2).** RoboTwin 시뮬레이터에서 같은 정책을 돌리고, 관측을 MidJourney API로 실사처럼 바꿉니다(부록 C). 이 단계는 재현 비용이 크고 외부 API에 의존합니다.

## 5. 한계 (논문 자체 서술 + 우리 보완)

논문 부록 A가 적은 한계는 네 가지입니다. (1) 조건이 행동 출력뿐이라 언어나 추론 신호를 쓰지 않습니다. (2) 저성능 정책일수록 물체 변형, 환각, 팔 잔상이 생깁니다. (3) 사전학습 생성 모델에 의존해 새 장면에 약할 수 있습니다. (4) 생성 영상이 잠재 행동을 완전히 따르지 않습니다.

우리가 덧붙이는 한계는 다음과 같습니다.
- **판정기 정확도 미보고.** 성공률의 기준이 Gemini-2.0 판정이므로, 정답 라벨과 비교한 정확도가 없으면 표 1의 성공률 자체가 측정 오차를 가집니다.
- **n = 4 정책.** 과제당 정책이 4개뿐이라 Pearson r의 신뢰구간이 0 근처까지 내려갑니다(`03` §1).
- **코드에 시간 평균 풀링.** 행동 청크를 시간축으로 평균내 뒤 투영합니다. 시간 순서가 조건에서 사라지므로 "행동을 따른다"는 주장과 긴장 관계에 있습니다(`04` D3, `03` §5).
- **평가 대상이 영상 기반 정책으로 한정.** 논문 §4의 질문 중 하나는 "정책 신경망이 예측한 행동을 영상이 충실히 따르는가"입니다. 이 질문에 대한 정량 결과는 없고, 그림 5의 정성 비교만 있습니다.
