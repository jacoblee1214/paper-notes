## 1. 풀려는 문제

월드-액션 모델(WAM)은 미래 영상 예측을 행동 생성과 함께 학습합니다. 논문은 기존 WAM이 두 부류라고 봅니다. 하나는 미래 영상을 만든 뒤 역동역학으로 행동을 복원하는 영상 우선 방식(Motus 등), 다른 하나는 예측된 미래를 행동의 조건으로 쓰는 방식입니다(1절). 두 경우 모두 미래 목표가 전문가 시연이라서 "좋은 행동에 짝지어진 그럴듯한 미래"만 봅니다. 그 결과 나쁜 행동이 들어와도 성공으로 치우친 미래를 예측한다고 주장합니다(1절, 참고문헌 [13, 14]는 다중모달 LLM 환각 서베이).

질문(1절): **실패 롤아웃을 모방 목표로 쓰지 않고, 행동의 결과를 알려 주는 감독으로만 쓸 수 있는가.**

## 2. 방법 (3절)

### 2.1 문제 설정 (3.1절, 식 1–3)

- 관측 o_t = (메인 영상, 좌우 손목 영상, 고유감각 s_t), 행동 청크 a_{t:t+H}. 표준 정책은 p(a | o, ℓ)(식 1).
- 행동 조건 세계 가지를 추가합니다(식 2): p(o'_{t:t+K}, v_t(a) | o_t, ℓ, a). v_t는 [0,1] 진행도입니다. 진행도는 누적 진행 보상 G_t로 p_t = G_t / G_T로 정규화합니다(식 3). 실험에서는 보상을 균일하게 두어 **p_t = t/T**입니다(3.3절).

### 2.2 구조 (3.2절, 식 4–5, 그림 2–3)

- **토큰 순서** z = [P(관측 접두) ‖ A(노이즈 낀 예측 행동) ‖ G(깨끗한 교사 행동) ‖ V(가치) ‖ I(미래 영상)] (식 5).
- 세계 쪽(V, I)은 **G를 보고 A는 보지 않습니다.** A는 G를 보지 못합니다. 이 마스크(그림 3)가 "무엇을 모방할지"(A)와 "무엇을 예측할지"(V, I)를 갈라 줍니다.
- 추론은 2단계입니다. 1단계에서 A를 디노이징해 행동 청크 â를 얻고, 행동만 필요하면 여기서 멈춥니다. 2단계에서 â를 G 자리에 넣어 V(와 선택적으로 I)를 디노이징합니다(3.3절, 알고리즘 3).
- 백본은 WAN2.2-5B 영상 확산 트랜스포머 하나를 공유하고, 각 블록의 FFN 뒤에 로봇 토큰용 **행동 어댑터**를 붙입니다. 혼합 트랜스포머(MoT)처럼 별도의 세계 전문가를 두지 않아, 세계 쪽 손실이 행동 생성에 영향을 준다고 설명합니다.

### 2.3 학습 (3.3절, 식 6–9)

- **가치 목표(식 6):** 성공이면 p_{t+H}, 실패면 clip(p_{t+H} − λ_fail · 1_fail(t+H), 0, 1). 에피소드마다 최종 성공 여부와 실패 시작 시점을 주석합니다.
- **손실:** 행동, 가치, 영상 모두 같은 흐름 매칭 노이즈 제거 손실(식 7). 성공 시연은 L = w_a L_a + w_v L_v + w_I L_I(식 8), 실패 롤아웃은 **L_a 항을 제거**한 w_v L_v + w_I L_I(식 9).
- **구현 값(3.3절):** AdamW, 학습률 행동 FFN 2e-4 / WAN 백본 2e-5, w_a = 20, w_v = w_I = 1, H = 48, λ_fail = 1, 미래 영상은 현재 프레임과 네 오프셋 [0, H/4, H/2, 3H/4, H], 추론 흐름-오일러 20단계.
- **후보 점수화(식 10):** N개 행동 후보를 1단계로 뽑고, 각 후보의 V를 2단계로 계산해 argmax를 실행합니다. 별도 비평가 없이 가치 가지를 씁니다. 논문은 이를 선택 사항으로 둡니다.
- **실패 수집(알고리즘 2):** 성공 시연으로 초기 정책 π_θ0를 학습하고, 이 정책을 굴려 실패한 에피소드를 모아 D_f를 만든 뒤 D_s ∪ D_f로 학습을 이어 갑니다.

## 3. 실험

### 3.1 설정 (4절, 부록 B–D)

- **시뮬레이션:** RoboTwin 2.0의 50과제. clean 분할은 과제당 50개(2,500개), 무작위화 분할은 과제당 500개(25,000개) 시연으로 학습하고, 실패 롤아웃 약 1.3K를 추가합니다. **평가는 과제·분할당 100회**(표 6 설명).
- **실로봇:** YAM 팔 두 대, RealSense D435 한 대(메인), D405 두 대(손목), GELLO 원격조종(부록 C). 본 과제 5개(Stack Cubes, Pick Cubes, Hand-over, Stack Bowls, Pour)와 미학습 변형 3개(색, 모양, 지시 변경). **시연 수:** 큐브 과제 200개, 나머지 50개. **실패 롤아웃:** 큐브 과제당 약 30개. **칸당 20회 평가**(4.2절). 기준선은 같은 성공 시연으로 미세조정했다고 합니다(부록 C).

### 3.3 서술된 해석

- 영상 공동학습은 행동 생성의 정규화로 작동합니다(4.3절).
- 인과 마스크(교사 행동 조건)는 영상 예측을 더 강한 행동 생성으로 바꿔 줍니다(77 → 82).
- 실패의 행동 손실을 마스크하지 않으면 63으로 떨어집니다. 실패 행동은 결과 감독으로만 써야 합니다.
- 점수화는 실패 결과로 학습한 뒤에야 유용합니다("scoring alone ... does not help (79%)").

## 4. 한계 (5절)와 이 분석이 본 간격

논문이 적은 한계는 데이터 확장, 가치 헤드 대체, best-of-N의 연산 비용입니다. 수치 재계산과 코드 대조로 확인한 간격은 `03`과 `04`에 있습니다. 요약하면 다음과 같습니다.

1. 식 (6)을 λ_fail = 1로 쓰면 실패 이후 창의 목표가 0 하나로 정해집니다(`03` V9). 공개 코드는 다른 식을 씁니다(`04` D3).
2. 실로봇 비교는 칸당 20회, 본 과제 합산 100회, 미학습 합산 60회입니다. 실패 데이터 효과(82 → 89, 67 → 77)는 이 시행 수에서 구분 경계에 못 미칩니다(`03` V6).
3. 실패 데이터 규모 실험(그림 6)의 절대 성공률이 같은 세 과제의 표 6 값과 크게 다르고, 설정 설명이 없습니다(`03` V10).
4. 실패 데이터를 쓰는 학습은 초기 정책 학습 뒤 계속 학습하는 절차(알고리즘 2)라서, 같은 학습 단계를 성공 데이터만으로 이어 간 대조군이 없습니다.
5. 공개 코드는 RoboTwin 파이프라인이고 실패 롤아웃 데이터, 실로봇 코드, 절제·기준선 코드는 저장소에서 찾지 못했습니다(`04`).
