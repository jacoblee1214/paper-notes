## 2. 가장 중요한 세 가지

1. **구속 아래 격차의 원인은 학습이 아니라 계획기의 실현 가능성입니다(C14).** KALM의 구속 실패는 6자유도 링크 포즈를 구속 때문에 IK로 풀지 못해 "무계획"이 되는 데서 나오는 것으로 읽힙니다(표 5의 KALM 계획 성공이 표 1 실행 성공과 같은 개수). 이 설계 속성은 가치가 있지만 "맨손 시연으로 학습"이 아니라 "위치 + 법선 표현을 쓰는 계획기 자유도"가 주 효과입니다. 가장 직접적인 반사실 기준선(위치 + 법선을 예측하되 링크를 고정하는 것)은 링크 고정 절제(PressButton 6/10, 7/10)가 가장 가깝지만 구속 아래의 OpenCoffee 같은 어려운 과제에서는 없습니다.
2. **학습된 구성요소의 기여는 입증되지 않았습니다(C11, C16).** 재생(6/10)과 정책(7/10)은 구분되지 않습니다. 접촉 궤적을 확산 정책으로 학습하는 것이 필수인지, 몇 개의 시연을 정합해서 재생하는 것이 충분한지는 이 논문의 증거로 가를 수 없습니다.
3. **실행 중 구속 준수는 측정되지 않았습니다(C18).** 성공은 하위 목표 도달로 정의되고 구속은 계획 게이트로만 확인됩니다. 컵이 실제로 수직을 유지했는지, 그리퍼가 영역 안에 있었는지는 보고되지 않습니다(추종 오차와 개루프 접촉 때문에 실행 시 이탈이 있을 수 있음).

## 3. 공개되지 않은 것

- 코드 전부(앵커 샘플러, 표면 접촉 IK, 빔 탐색, 게이트, 프롬프트 파서, 로봇 모델 설정).
- 시연 데이터(시연자 동의 문제로 공개하지 않는다고 부록 C에 명시)와 학습된 체크포인트.
- 정확한 GPT-5.5 스냅샷, 과제별 프롬프트 예시(본문 프롬프트는 과제별 예시를 생략).
- 배치별 성공 여부(쌍체 검정의 원자료), 표 5의 30장면 목록.
- 로봇별 θ_dead, 충돌 버퍼 값, 최대 Δq 임계값(A.5는 "최대 Δq 임계값"이라고만 씀).

## 4. 구현 가능성 (이 맥: Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)

**판정: 논문 수치의 재현은 불가능합니다. 다만 핵심 알고리즘(표면 접촉 IK + 링크·앵커 빔 탐색 + 구속 게이트)의 축소판은 이 맥에서 구현할 수 있고, 공식 코드가 없어 처음부터 짜야 합니다.**

| 구성 | 이 맥 | 이유 |
|---|---|---|
| 표·통계 재계산, 토이(삼각측량) | **완료** | numpy, scipy. 1초 미만 |
| 구속 프리미티브(AxisCone, PositionRegion)와 위반량 비교 | **가능** | 손실식(식 6, 7) 몇 줄. 각도 L1 대 코사인 hinge의 복원력 비교도 numpy로 가능 |
| 축소판 표면 접촉 IK + 앵커 샘플링 + 빔 탐색 | **조건부 가능** | torch/numpy 배치 IK(CPU 또는 MPS). xArm 7 기구학과 링크 형상(MuJoCo MJCF 모델은 작은 다운로드)이 필요. 링크는 캡슐 근사로 대체하면 메쉬 라이브러리 설치가 불필요. 640 앵커 × 16 시드 × 8 웨이포인트의 배치 IK가 CPU에서 얼마나 걸리는지는 측정하지 않음 |
| 키포인트 조건부 확산 정책(KALM 구조) | **가능(소형)** | 입력 8 × 3, 출력 16 × 6의 작은 모델은 CPU로 충분. KALM 증류와 DINOv2 + FPFH 매처는 이미지와 3D 데이터, 가중치가 필요해 합성 키포인트로 대체해야 함 |
| 맨손 파이프라인(SAM3, HaPTIC, MANO) | **불가** | 게이트된 가중치와 GPU 전제, 시연 영상 없음 |
| GPT-5.5 제약 생성(표 4 감사) | **불가** | API 호출 금지와 스냅샷 미공개. 제약은 수작업으로 대체 가능 |
| cuRobo 기반 병렬 IK, 전체 계획기 | **불가** | CUDA 전제 |
| 실로봇(xArm 7, FR3, RealSense, 업무대) | **불가** | 장비 |

**노력 추정(측정 전, 추정):** 축소판(MuJoCo xArm 7 시뮬레이션 + 배치 IK + 빔 탐색 + 구속 게이트 + 소형 정책)은 3–4주. 시뮬레이션에서 구속 아래 링크 고정 대 링크 탐색의 실현 가능성 비교만이라면 1–2주. 전체 파이프라인(실로봇, 손 추적, VLM, cuRobo)은 하드웨어를 갖춘 상태에서 2–3개월 이상입니다.
