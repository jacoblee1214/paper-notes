## 1. 문제 설정 (2절)

- 목표: 두 끝점(양손)에서 힘 τ ∈ R⁶을 받는 DLO의 **동역학을 데이터에서 학습**하고, 학습된 모형으로 **원하는 평형 형상 x_d로 조절(regulation)** 하는 것입니다(식 2).
- 형상은 N 마커의 3차원 위치 x ∈ R^{3N}로 표현합니다. 입력은 끝점 두 개뿐이고, 내부 마커는 수동적으로 움직입니다(Fig. 6, 부록 A).
- 가정 1(Assumption 1, 2절): N개 마커 위치가 충분한 일반화 좌표이고 (x, ẋ)가 완전한 상태라고 봅니다. 비틀림과 단면 변형은 무시합니다. 이 가정은 실험에서 검증하지 않았습니다(04 C10).
- 가정 2(Assumption 2, 4절): 목표 x_d에서 내부 좌표의 중력·탄성 기울기 g_u(x_d) = 0. 실제로는 "정적으로 가능한 목표"만 쓸 수 있다는 뜻입니다.

## 2. 방법: Φ-CON (3절, 4절)

**구성요소 세 가지를 쌓은 구조입니다.**

1. **고정 좌표 변환 (3.1).** 첫 마커를 기준점 q_b = x₁로 두고, 나머지는 기준점 기준 상대좌표 q_r로 씁니다. q = Tx(T는 고정 가역 행렬), 표준화 q̂ = S_q(q − q̄).
2. **학습 가능한 아핀 미분동형 Φ (3.2).** z_w = Φ(x) = A q̂ + c, A = diag(I₃, A_r), A_r = L_r U_r. 기준점 좌표는 그대로 두고 상대좌표만 바꿉니다. 속도와 힘은 야코비안 J_Φ = A S_q T로 변환하고, 힘은 가상일 원리에 따라 τ_w = α J_Φ^{-T} B(τ − τ̄)입니다(식 4). α는 학습 데이터로 정한 고정 스케일이고 τ̄는 정적 하중 추정치입니다.
3. **FBCON, 떠 있는 기준점을 가진 결합 진동자 네트워크 (3.3).** 잠재 동역학 M_w z̈ + D_w ż + ∇U_w = τ_w(식 5)에서 잠재 퍼텐셜 U_w(z) = ½ z_rᵀK_r z_r + 1ᵀ log cosh(z_r + b_r)는 **형상 좌표에만** 의존합니다(식 6). 기준점 방향으로는 복원력이 없어서 전체 평행이동이 허용됩니다. M_w, D_w, K_r은 학습되는 상수 대칭 양의정부호 행렬입니다.

관측 공간으로 옮긴 동역학은 식 7이며, 질량 M_x = α⁻¹J_Φᵀ M_w J_Φ, 감쇠 D_x, 퍼텐셜 기울기 g(x)를 가집니다. 이 구조는 라그랑주 형식을 유지합니다(U_x = α⁻¹U_w(Φ(x)) + τ̄ᵀBᵀx).

**제어(4절).** 식 9는 τ = g_a(x_d) + K_p(x_d^a − x^a) − K_d ẋ^a입니다. 학습된 정적 힘 g_a를 목표에서 미리 더하는 **피드포워드**와 끝점 PD 피드백을 합칩니다. 최적화 없이 닫힌 형태로 계산합니다.

**학습(3.5절).** 손실 ℓ = ℓ_z + ℓ_x + λ_ss ℓ_ss. ℓ_x(관측 공간 롤아웃, 위치와 속도 가중치 분리)가 주 목적이고, ℓ_z는 잠재 공간 보조 손실, ℓ_ss는 정상상태 근처 샘플에서 g_a(x) ≈ τ를 맞추는 정적 힘 손실입니다. Φ가 가역이라 재구성 손실은 없습니다.

## 3. 이론 결과 (3절, 4절, 부록 E)

| 명제 | 내용 | 확인 |
|---|---|---|
| Prop. 1 | 잠재 FBCON(τ_w = 0)의 평형 집합 E_w가 전역 점근 안정. 기준점 위치는 임의, 형상은 유일 | 증명 부록 E.1을 읽음. 에너지 V와 LaSalle 논법은 맞음. Hessian 식 (13)과 기준점 극한 식 (16)도 확인(16쪽 그림 확인: D⁻¹_bb(c_b − D_br z*_r)) |
| Prop. 2 | 개루프 Φ-CON(τ = τ̄)의 평형 집합 E_x가 전역 점근 안정 | 부록 E.2. Φ의 가역성으로 전달 |
| Prop. 3 | 가정 2 아래 닫힌 루프(식 10)에서 (x_d, 0)이 전역 점근 안정. K_p ≻ 0, K_d ⪰ 0 | 부록 E.3. 강볼록 W(x)와 식 (22)의 V̇ = −ẋᵀD_xẋ − ẋᵀ_a K_d ẋ_a ≤ 0 |

**주의점 (논문 자신도 밝힘, 4절 끝).** 전역 보장은 **학습된 모형**에 대해서입니다. 실제 DLO가 모형과 전역적으로 같다는 보장은 없습니다. 또 Prop. 3은 목표가 정적으로 가능해야 하고(가정 2), 학습 모형이 정확해야 성립합니다. 초록의 "closed-loop stability guarantees"와 "ensuring convergence"는 이 범위로 읽어야 합니다. 기여 1(§1)은 "compatible target equilibria of the learned model"이라고 한정합니다.

**α 스케일에 관한 메모.** 가상일 원리는 τ_w = J^{-T}τ_x까지만 정확하고, α는 임의 스케일입니다. Lagrangian과 질량이 함께 α⁻¹로 바뀌므로 운동방정식은 맞지만, 에너지와 질량의 절대값은 α에 따라 달라집니다. 논문 본문은 "the inverse-transpose factor follows from the principle of virtual work"라고만 적고 α의 역할을 따로 설명하지 않습니다.

### 4.2 실로봇 (6절)

- 두 대의 Franka Panda가 길이 0.76 m, 반지름 9 mm 전선의 양 끝을 잡습니다. 힘 센서(Bota SenseOne 2개), 모션캡처(OptiTrack 5대), 마커 N = 12.
- 데이터: 166 궤적 중 28 테스트, 138 학습·검증(시드마다 110 학습과 28 검증, A.1). 식별한 케이블 물성은 A.5.
- 예측(그림 4, 본문만): 2 s 안에서는 NODE가 정확하고 Φ-CON은 NODE와 맞먹으며, LNN은 약 1 s 뒤 오차가 가장 큼. 수치 표는 없습니다.
- **제어 (그림 5, 본문):** 76개 정상상태 목표(학습·검증 궤적에서 추출)와 4개 미관측 목표. PD(임피던스, K = 200 N/m, ζ = 0.77, K_d = 21.8 N·s/m) 대 PD+Φ-CON 피드포워드.
  - 왼쪽 끝점 오차 63.7 ± 8.0 → 48.4 ± 5.6 mm, 목표별 개선 23.5 ± 8.8%.
  - 오른쪽 끝점 48.3 ± 8.5 → 32.3 ± 5.2 mm, 목표별 개선 32.2 ± 10.5%.
  - 본문 평균 27.9%.

### 4.3 데이터와 시드의 세부

- 시뮬 학습 설정: 1 s 창, Δt = 10 ms, 배치 512, AdamW, 에폭 5000(NODE와 LNN은 각각 5000과 2000 등, 표 4).
- 하이퍼파라미터: Optuna TPE 40–60회 탐색, 검증 롤아웃 오차와 중앙값 끝점 힘 오차로 선택(A.4, 표 7).
- 실로봇 학습 궤적의 정상상태 기준: 마커 속도 < 0.01 m/s, 가속도 < 0.1 m/s².

## 5. 한계와 논문이 스스로 말한 것 (7절)

- 재료 기억(히스테리시스, 소성 변형)은 다루지 않음. 향후 과제.
- 궤적 추종은 다루지 않음(정상상태 조절만).
- 장애물, 자기접촉, 고정 파지 방향 변화 없음.
- 실로봇 실험은 케이블 한 종류, 파지 방향 고정.

## 6. 읽으면서 본 확인 사항 (상세는 03과 04)

- 초록의 파라미터 감소율 97.2%와 90.2%는 맞습니다(03 V1).
- 표 2와 표 8의 계산 시간이 같은 측정이라고 적혀 있는데 수치가 다릅니다(03 V8).
- 표 4의 NODE와 LNN 파라미터 수는 표 5 구조로 정확히 재현됩니다. Φ-CON과 FBCON은 9N 차이가 남습니다(03 V9).
- 실로봇 개선은 76개 목표가 학습 궤적에서 나왔습니다. 외삽 검증은 4개뿐입니다(04 C5).
- 시뮬 기준 PD(적분 항 없음)는 정상상태 오차가 1/K_p에 비례합니다. 그래서 감소율 97.5–99.7%의 대부분은 "정적 힘 보상"에서 옵니다. 정적 피드포워드만 쓰는 기준선이 없습니다(04 C6).
