## 0. 한 줄 요약

사람 자세를 로봇 어깨-팔꿈치-손목(SEW) 표현으로 옮긴 뒤 닫힌 형식의 해(c-SEW)로 손바닥 위치를 **hard constraint**로 맞추고, 몸통 위치 보정(adaptive offset)과 느린 기지 제어(lazy base)를 붙인 오프라인 리타게터입니다. 주장의 핵심은 "리타게팅 정밀도와 일관성이 좋아지면 같은 정책을 학습했을 때 성공률이 오른다"입니다. 그런데 헤드라인 수치(150배, 머신 정밀도)는 **관절 한계와 lazy base를 모두 끈 변형**에서 나오고, 하위 정책 비교(시뮬)는 **사람이 아니라 GR1 로봇 시연**을 옮긴 것이며, 실물 비교는 **과제당 10회**입니다. 이 셋을 구분해서 읽어야 합니다.

## 2. 방법 (§3, 부록 B)

### 2.1 입력과 목표
- 사람 시연 τ^h = {o_t, H(t)}: 헤드셋의 상체 운동학 트리와 양손(60 Hz), 루트 자세. 로봇 행동 q^r_t = Ret(H(t))를 per-timestep 사상으로 정의하고, 같은 행동을 상태 이력과 감독 신호로 함께 씁니다(§3 식 정의).
- 보조 객체는 사람 상체 좌표계에서 표현합니다(Algorithm 1, 부록 B.1). 어깨 중점과 두 어깨 선, 몸통 기준점으로 직교 기저를 만들고, 이 기저는 사람과 로봇에 같은 방식으로 적용합니다.

### 2.2 SEW 표현과 "스케일 불변" 주장
- 팔을 (s, e, w, H, t)로 표현합니다. 단위 방향 u = unit(e−s), l = unit(w−e)는 사람과 로봇 모두 같은 형태로 정의됩니다.
- 직접 복사하면 손바닥이 어긋납니다: t̂^rb = s^rb + ℓ_SE u + ℓ_EW l + H p_WT, 여기서 t̂ ≠ t (§3). 이 차이의 크기는 링크 길이 비율에 비례합니다(`03_analysis.md` §4 유도).
- 논문은 "scale-invariant"라고 부르지만, 정확히는 **방향은 복사하고 길이는 로봇 값을 쓴다**는 뜻입니다. 길이 불일치는 아래 adaptive offset과 손바닥 정합이 맡습니다.

### 2.3 c-SEW의 단계 (식 (1)–(3))
1. **Adaptive offset (식 (2)):** 두 팔 손바닥 중점의 차이만큼 로봇 상체 원점을 옮깁니다. 몸통 자세로 흡수하는 장치입니다.
2. **팔별 손바닥 정합 (식 (1)):** 손 방향은 H^rb = H^hm로 그대로 옮기고, 손목 위치는 손바닥 목표에서 역산해 **정확히 맞춥니다(hard)**. 여기서 가중합이 아니라 등식입니다.
3. **팔꿈치 자유도 해소 (식 (3), 부록 B.4):** Stereo-SEW(Elias & Wen)로 사람의 팔꿈치 반평면 법선 n̂을 얻고, SP3 부분문제로 팔꿈치 위치를 구합니다. 근은 최대 2개이고 사람 반평면과 맞는 가지 θ_SEW > 0을 고릅니다.
4. **몸통 6자유도:** ik-geo로 몸통 자세를 풀고 "무릎 앞" 해를 항상 택합니다.
5. **관절각:** SEW-Mimic(Kong et al. 2026, arXiv:2602.01632)으로 닫힌 형식으로 푼니다. 반복 최적화는 어느 단계에도 없다고 주장합니다.

논문이 주장하는 성질: (i) 비퇴화 자세에서 유일해, (ii) 사람 손바닥과 정확히 일치, (iii) 자세 유사도를 최대화하는 배치(제약 하에), (iv) 마이크로초 단위 계산과 로봇별 보정 없음. **(iv)는 측정값과 맞지 않습니다** (§5 참고, Table 3의 6.8 ms/프레임).

### 2.4 Lazy mobile base (식 (6)–(7), 부록 B.5)
- 사람 상체 목표가 함의하는 기지 자세 q_d ∈ SE(2)를 바로 따라가면, 작은 상체 움직임이 바퀴 움직임으로 번집니다. 그래서 기지 목표 q_b를 따로 두고, 데드밴드(δ_xy = 0.05 m, δ_θ = 0.1 rad) 안에서는 스프링력을 0으로 둡니다. 몸통 6자유도가 미세 조정을 맡습니다.
- 필터는 2차 시스템 p̈ = ω_n² ẽ − 2ζω_n ṗ이고 ζ = 1(임계 감쇠), f_n ≈ 1.5 Hz입니다. 이 값은 코드 설정(`warp` 프리셋)과 일치합니다(`04_code_verification.md` C14).

### 2.5 손 처리와 정책
- 손가락은 리타게팅 대상이 아니라 XHand 내부 리타게터(논문), 시뮬에서는 GR1의 Fourier 손 명령을 그대로 복사합니다(부록 C.2). **두 방법의 손 처리가 같은지는 시뮬에서만 명시됩니다.**
- 정책 (부록 B.7): HPT 기반 흐름 정합(flow matching) 트랜스포머. 행동 청크를 기지 ≼ 몸통 ≼ 팔 ≼ 손 순서로 나누고 block-causal 마스크를 씁니다. 약 11M 파라미터, 배치 32, 체크포인트는 epoch 599. 학습 장치, 시간, 시드 수는 없습니다.

### 2.6 데이터 수집 (§3, 부록 C.1)
- Meta Quest 한 대만 사용(외부 모캡, 마커, 로봇 없음). 손 관절 포함 상체 트리 60 Hz.
- 물체: 헤드셋의 AprilTag. 실물 정책 입력은 AprilTag로 얻은 물체 포즈와 로봇 상태이고, 이미지는 쓰지 않습니다(한계로 명시, D.1).
- 로봇: RB-Y1 (holonomic 기지, 몸통 6자유도, 7자유도 팔 두 개, XHand 두 개), 관절 임피던스 100 Hz. 재생과 정책 롤아웃은 원래 속도의 30%(6 Hz)로 실행합니다. 기지 위치는 Vicon으로 측정합니다.

## 3. 실험 (§4, 부록 C)

### 3.1 리타게팅 품질 (§4.1, Fig. 5, Table 3, Table 4)
- **데이터:** BONES-SEED SOMA Proportional에서 "table/everyday/object"를 포함하고 "sit/seated"를 뺀 514개 조작 동작(원본 257 + 좌우 반전 257, 프레임 135,896개). 고높이 동작은 파일명 필터로 제외합니다(부록 C.2.1). 부록 C.3.2는 7,623개 확장 부분집합을 보입니다.
- **비교 대상:** MINK-EF(손만), MINK-TE(손 + 몸통 방향 0.5 + 팔꿈치 0.2 (표 2), SEW-M(SEW-Mimic, 목표 없음). 본문 서론은 GMR[4]과 HOMIE[10]도 비교 기준으로 인용하지만 실험 표에는 없습니다.
- **지표:** 추종(손바닥 평균·P95, 방향), 실현 가능성(몸통 이탈 비율, 관절 한계 근접 비율, 자기 충돌 비율), 일관성(NNAD, 해의 PCA 고윳값, RMS 표준편차), 시간(ms/프레임). 정의는 부록 B.8.
- **결과 (514 부분집합, JL off 기준):** 손바닥 평균 오차 WARP 0.0046 mm, MINK-EF 0.701 mm (152배), 방향 오차 WARP 8.7e-6°. 자기 충돌 WARP 0.163, SEW-M 0.243, MINK-EF 0.977. 처리 시간 WARP 6.8 ms, MINK-EF 192 ms.
- **하지만:** 공개 저장소의 대응 프리셋 기준으로 "JL off"는 관절 한계와 lazy base를 모두 끈 설정입니다(`04` C15, D5). "JL on"(WARP 전체)에서는 손바닥 평균 오차가 24.0 mm, 방향 오차 3.26°로 올라가며, MINK-EF on(0.75 mm, 0.011°)보다 나쁩니다. 논문은 이를 "목표가 작업공간 밖에 있어서"라고 설명하지만 검증하지 않았습니다.
- **7,623 부분집합 (부록 Table 4, JL off만):** WARP의 정상 프레임 손바닥 오차 1.51 mm, MINK-EF 0.79 mm로 MINK-EF가 더 정확합니다. 원시 평균의 우위(11.9 mm 대 248 mm)는 이상치가 MINK-EF에 몰린 결과입니다. 관절 한계 여유 최솟값 WARP −7.7°, SEW-M −4.9°로 WARP가 더 나쁩니다.

### 3.2 시뮬레이션 하위 학습 (§4.2, Table 1)
- **설정:** DexMimicGen으로 만든 **GR1 시연** 200개씩 세 과제(coffee, pouring, can-sort)를 RB-Y1 Fourier 손으로 옮깁니다. 리타게터마다 BC 정책을 하나씩 학습하고, 두 방법이 모두 성공한 시연의 교집합으로 학습합니다(부록 C.2).
- **중요:** 이 실험의 원천 데이터는 **사람이 아니라 로봇(GR1) 시연**입니다. 사람 데이터 조건은 시뮬 실험에 없습니다. §1의 "사람 데이터 제로샷"은 실물 실험에만 해당합니다.
- **결과:** 재생 성공 WARP 80.0%, MINK 79.5%. 정책 성공 WARP 71%, MINK 59% (+12%p). 과제별 정책 차이는 can-sort +6, pouring +4, coffee +26%p.

### 3.3 실물 (§4.3, Fig. 7, Fig. 8–9)
- **과제:** 세탁 바구니 들기(양손 손목 자세), 카트 밀기(기지–팔 접촉), 상자 회전(몸통–팔 비틀림), 냉장고 문 닫기(팔꿈치 접촉, 재생만).
- **Fig. 7 (과제당 10회):** 상자 회전 재생 100 대 95(MINK), 롤아웃 65 대 40. 카트 밀기 재생 95 대 25, 롤아웃 75 대 25. 세탁 재생 70 대 0, 롤아웃 37.5 대 7.5. 냉장고 재생 90(MINK 없음).
- **"35%"의 출처:** 서론의 "35%"는 세 과제 롤아웃 차이의 평균 35%p입니다((25 + 50 + 30) / 3). 상대 비율이나 시드 평균이 아닙니다(`03_analysis.md` §2).
- **MINK 변형 미지정:** 실물 MINK가 EF인지 TE인지 적혀 있지 않습니다.

## 4. 한계 (§D.1과 읽은 사람의 지적)

논문 D.1의 한계: (1) 기구학 중심이며 제어기 오차와 동역학을 무시, (2) 정책이 이미지를 쓰지 않고 AprilTag에 의존, (3) Quest 관성 추적의 지터가 그대로 감독 신호가 됨. 추가로 읽은 쪽에서 본 한계:
- 평가 지표 대부분이 WARP의 목적함수와 같은 기하량(손바닥, 팔꿈치 ψ, 몸통 방향)이라 **지표와 목적이 맞물립니다**. MINK-TE도 같은 ψ를 쓰지만, 공정한 비교 대상이 되려면 MINK 목적을 같은 기하량으로 두고 가중치만 바꿔야 합니다. 부록 A.2 스윕이 이 방향이지만 그림으로만 있습니다.
- 일관성 지표(NNAD, PCA, RMS)는 닫힌 형식 해에 대해 **수치 잡음 수준 0에 가까워지도록 되어 있습니다**. 즉 "결정적 함수는 흔들리지 않는다"를 측정할 뿐, 학습 성능과의 관계는 측정하지 않았습니다.
- 정책 비교의 교란 요인: 시뮬에서 WARP는 **재생 시 온라인으로 SEW를 푸는** 반면 MINK는 **미리 계산한 관절 목표를 저장**합니다(부록 C.2). 두 데이터 생성 경로가 다릅니다.
- 시드 수, 반복 학습, 신뢰구간, 검정 모두 없습니다(§6 참고).

- v1 PDF는 `.scratch/v1.pdf`에 임시 보관했고 저장소에는 넣지 않았습니다.
