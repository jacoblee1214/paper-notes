# RT-1 논문과 공식 코드 대조 (04)

공식 코드(`google-research/robotics_transformer`, 커밋 `4569641`, 2023-02-10, Apache-2.0)를 `repo/`에 얕게 클론해 **정적으로만** 읽었습니다. 실행, import, 설치는 하지 않았습니다. 클론에 함께 온 체크포인트와 EfficientNet 가중치는 받은 뒤 삭제했습니다(`02` §4). 대조 기준은 논문 본문 `01`의 절 번호입니다. 차이 항목은 D1–Dn으로 씁니다.

## 1. 코드가 담은 것과 담지 않은 것

| 있음 | 없음 |

| `configs/transformer_mixin.gin` (구조 하이퍼파라미터, 학습률) | Kuka 데이터 변환 코드, SayCan 코드 |
| `*_test.py` (단위 테스트, 실행하지 않음), `trained_checkpoints/` 세 개 (README 기준: rt1main, rt1multirobot, rt1simreal) | 논문에 나오는 기준선 Gato, BC-Z 구현 |

## 2. 대조 요약 (D1–D16)

| 번호 | 항목 | 논문 | 코드 | 판정 |
|---|---|---|---|---|
| D1 | 행동 차원 11개 (팔 7, 기지 3, 모드 1) | §4, §5.1 | `ACTION_ORDER`나 행동 명세가 설정에 없음. 토큰화기는 호출자가 준 `action_spec`을 씀 | **미검증** (명세가 코드 밖) |
| D2 | 차원당 256 빈, 균일 | §5.1 | 정규화 값 × 255를 정수로 바꿈 (256 수준). 범위 밖 토큰은 0으로 되돌림 | 일치 |
| D3 | 입력 300×300, 이력 6장 | §5.1 | EfficientNet-B3 기본 크기 300, 내부에서 300으로 resize. 6장은 `SEQUENCE_LENGTH = 6` | 일치 (크롭 설정 불일치, 아래 설명) |
| D4 | 81 토큰 → 이미지당 8 토큰 | §5.1 | TokenLearner 기본 `num_tokens=8`, 미사용 시 81 | 일치 |
| D5 | Transformer 8층, 19M | §5.1 | `num_layers=8`, 헤드 8, `layer_size=128`(헤드당 키 차원). 층당 2.37M, 합 19.05M(`03` V10) | 일치 (피드포워드 구조는 논문에 없음) |
| D6 | 어휘 256 | §5.1 | `vocab_size=256` | 일치 |
| D7 | 범주형 교차엔트로피, 인과 마스크 | §5.1 | `SparseCategoricalCrossentropy(from_logits=True)`, 블록 마스크 구성 | 일치 |
| D8 | FiLM 0 초기화, (1+γ) 형태 | §5.1 | 커널·편향 모두 `zeros`, 결과 `(1+mult)*x + add` | 일치 |
| D9 | EfficientNet-B3 (ImageNet 사전학습) | §5.1 | 계수 width 1.2, depth 1.4, 입력 300 | 일치 (가중치는 저장소의 `.h5`) |
| D10 | 문장 임베딩 USE 512차원 | §5.1 | `natural_language_embedding` (512)를 입력으로 받음. USE 자체는 없음 | 부분 (임베딩 생성 코드 없음) |
| D11 | TokenLearner, "element-wise attention" | §5.1 | GELU 병목 MLP가 토큰별 가중치를 만들고 토큰 축에서 softmax | 용어 차이 (구현은 토큰 축 softmax) |
| D12 | 토큰 재사용으로 1.7배 가속 | §5.1 | `seq_idx`와 컨텍스트 토큰을 상태로 유지 | 구조 존재, 속도는 미검증 |
| D13 | 280 ms 고정 대기, 3 Hz | 부록 C.1 | 로봇 쪽 루프에 있을 것. 이 코드에는 없음 | **미검증** |
| D14 | 학습 설정 (학습률, 배치, 스텝) | 논문에 없음 | Adam 학습률 1e-4 (`gin`), 시퀀스 길이 6 | **논문 누락**, 코드에서만 확인 |
| D15 | 130k 에피소드 학습 | §5.2 | 데이터 로더와 학습 실행 스크립트가 없음 | 재현에 필요한 부분 없음 |
| D16 | 공개 체크포인트 | 논문에 없음 (코드 공개만 언급) | rt1main(700 과제), rt1multirobot(Kuka 혼합), rt1simreal(시뮬 혼합). §6.3 실험과 대응 | 추가 공개물 (미실행) |

### 2.1 차이의 세부

- **D3 (크롭).** 원시 영상 크기는 `preprocessors.py`의 `CROP_SIZE = 472`를 쓰고(512×640 입력 가정), `TransformerNetwork`의 `crop_size` 기본값은 **236**입니다(`transformer_network.py:48`). 두 기본값이 다르고 gin 설정에는 `CROP_SIZE`가 정의되어 있지 않습니다. 실제 학습 값은 호출하는 쪽에서 정해집니다. 논문은 크롭을 언급하지 않으므로, 논문의 "300×300"은 EfficientNet 입력 크기이고 원시 크롭은 미공개입니다.
- **D5 (피드포워드).** 층의 피드포워드는 `Dense(512)` 하나입니다(`transformer.py:47`). 일반적인 두 층 MLP가 아닙니다. 논문은 이 세부를 쓰지 않습니다. 19M에 맞춘 계산에서 이 구조가 쓰였습니다(`03` V10).
- **D8 (FiLM).** 논문 §5.1의 "가중치를 0으로 초기화"가 코드에서 그대로 확인됩니다. 이 초기화가 사전학습 특징을 보존한다는 주장은 어블레이션(표 13, "사전학습 제거")과 함께 읽어야 합니다.
- **D11 (TokenLearner).** 논문은 "element-wise attention module"이라고 씁니다. 코드는 토큰 축 softmax로 가중치를 만들고 가중합을 냅니다. 원래 TokenLearner 논문의 설명과 같은 방식입니다. 용어만 다릅니다.
- **D14 (학습 설정).** 논문은 학습률, 배치 크기, 스텝 수, 학습 장치, 시간을 하나도 쓰지 않았습니다. 재현 가능성에서 가장 큰 공백입니다. 코드의 학습률 1e-4(Adam)만 확인되었습니다.

## 3. 실질적 차이 (D 항목의 결론)

논문과 코드는 **모델 구조에서는 대체로 일치**합니다(D2, D4–D9). 차이와 공백은 다음 세 종류입니다.

1. **설정의 공백:** 원시 크롭(D3), 행동 명세(D1), 학습 설정(D14). 논문만으로는 모델을 같은 크기로 세울 수 있지만, 입력 전처리와 행동 차원 순서를 맞추려면 추측이 필요합니다.
2. **데이터와 학습의 공백:** 데이터 로더와 학습 스크립트가 없어서(D15), 논문의 130k 에피소드 학습은 코드만으로 재현할 수 없습니다. 공개 데이터(GCS, 용량 미확인)와 로더를 따로 짜야 합니다.
3. **속도 주장의 검증 공백:** 3 Hz, 280 ms, 1.7배 가속(D12, D13)은 로봇 쪽 측정이 필요합니다. 코드만으로는 확인할 수 없습니다.

## 4. 구현 가능성 판정

**결론: 이 맥(Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)에서 RT-1을 재현하는 것은 불가능합니다. 모델 구조를 다시 짜는 것은 가능하지만 학습에는 GPU와 대규모 데이터가 필요하고, 체크포인트 추론은 TensorFlow 환경 설치 승인 후에 가능합니다.**

| 작업 | 맥에서 가능? | 근거와 조건 |
|---|---|---|
| 논문 표 재계산과 검정 | 가능, 완료 | `03` (표준 라이브러리 스크립트, 1초 미만) |
| 모델 구조 파라미터 계산 | 가능, 완료 | `03` V10 (19.05M) |
| 공식 체크포인트 추론 (TensorFlow SavedModel) | 조건부 | TensorFlow 설치(승인 필요), 체크포인트 약 175 MB 다운로드(승인 필요). macOS에서 TF의 Metal 지원은 제한적이라 CPU 경로가 현실적 (추정, 미확인) |
| PyTorch로 구조 재구현, 무작위 가중치로 형태 검사 | 가능 | 35M 파라미터는 메모리 문제 없음. 구조 검사와 토큰 수 확인에 1–2일 (추정) |
| 학습 (130k 에피소드) | 불가능 | 데이터 수백 GB 규모로 추정(미확인), 로봇 데이터 없이는 의미 없음. GPU 학습은 범위 밖 |
| 소규모 시뮬레이션 학습 (행동 토큰화와 손실만) | 조건부 | 공개 데이터 일부 받기와 학습 설정 추정 필요. 다른 환경의 데이터로는 논문 수치와 비교 불가 |
| 실로봇 평가 | 불가능 | Everyday Robots 장비 필요 |

**노력 추정 (측정 아님):** 체크포인트 추론 검사 2–3일(환경과 승인 포함), 구조 재구현과 형태 검사 1–2주, 소규모 학습 한 설정은 GPU에서 수일. 논문 수치 재현은 현재 자원으로 불가능합니다.
