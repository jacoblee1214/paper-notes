## 4. 구현 가능성 판단

**결론:** 논문 결과는 **그대로 재현할 수 없습니다**. GNR 코드, 가중치, 데이터, 데이터 엔진이 모두 비공개입니다. 시뮬레이터(SuperDex)와 로봇 모델(FR3 + DG-5F), HOT3D, DIAL-MPC 원 구현은 공개되어 있습니다. 그래서 **방법을 작은 규모로 다시 구현하는 것은 가능**합니다. 어려운 부분은 생성 모델이 아니라 시드 데이터를 만드는 물리 리타겟팅 파이프라인입니다. 이 맥에서는 재계산과 toy를 끝냈습니다. SuperDex와 torch(MPS)를 설치하면 작은 규모의 재구현을 해 볼 수 있습니다(둘 다 설치 승인 필요).

### 4.1 논문 그대로 재현

불가능합니다.
- 코드·가중치·데이터·mocap 시연이 없습니다.
- 데이터 엔진(HOT3D → SuperDex 장면, keypoint IK, 파지 재설정, SuperDex 위 DIAL-MPC, Γ 판정, 증강)을 처음부터 다시 만들어야 합니다.
- 계산량이 큽니다. 전부 MPC로 돌리면 390k CPU core-h(512코어 31.7일)이고, 실제 배치 시나리오도 148.7k core-h입니다. HOT3D 모델 학습은 A100 1장입니다(시간 미보고).

### 4.3 아이디어만 옮기는 경우

- **생성기 자체는 쉽습니다.** IK 기준에 대한 잔차 Δ를 조건부 flow matching으로 학습하고, Euler 10단계로 S개 뽑아 시뮬레이터에서 거르는 것은 수백 줄입니다.
- **비용의 대부분은 시드 생성기와 판정기입니다.** 접촉 많은 시뮬레이터에서 sampling MPC가 어느 정도 풀어야 하고(HOT3D 26%, 시드 시도당 1 core-h), Γ 같은 판정 기준을 신중하게 정해야 합니다. 판정이 느슨하면(C12) 성공률이 부풀려집니다.
- **먼저 할 기준선:** 최근접 시드 잔차 검색과 결정론적 회귀를 같은 거부 표집 틀에 넣어 비교해야 합니다. toy에서는 검색만으로도 범위 안에서 MPC를 넘었습니다(`03` §3).
- **보고 방식:** pass@S와 함께 조기 종료 기대 표본, 꼬리 지수 a, 쌍(문제) 단위 성공률을 같이 보고하는 편이 정확합니다(`03` §2, §4).
