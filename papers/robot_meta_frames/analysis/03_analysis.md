# 재계산, 일관성 점검, 토이 검사, 주장 판정

재계산은 `analysis/recompute.py`(수 초), 토이는 `analysis/toy_readout_check.py`(수 초, numpy)로 한다. 결과는 `recompute_results.json`과 `toy_readout_results.json`에 있다. 논문은 원자료 (샘플 단위 성공 여부)를 주지 않아 아래 검정은 요약값에서 다시 계산한 것이다.

**공통 가정.** 대조군의 시도 수는 논문에 없으면 두 방법이 같다고 가정한다. 시도는 독립이라고 본다. 과제와 시드에 묶인 분산은 논문에 없어 넣지 못했다. 따라서 모든 p 값은 **낙관적**이다.

## 1. 재계산

### 1.1 표 2: RoboCasa 평균 성공률

| 항목 | 값 |
|---|---|
| 시도 | 24 과제 × 50회 × 3 시드 = 3600회 (두 방법 같다고 가정) |
| MetaWAM | 68.9% (Wilson 95%: 67.4–70.4) |
| Cosmos Policy | 67.1% (Wilson 95%: 65.6–68.6) |
| 차이 | +1.8 pp, z = 1.62, p = 0.11 (양측, 독립 가정) |
| 80% 검정력의 최소 차이 | 약 3.1 pp |

차이는 방향만 맞다. 독립 가정에서도 검출 한계보다 작다. 시드 간 분산을 넣으면 p는 더 커진다. 표 2는 "두 기준선보다 낫다"를 말할 수 있는 근거가 아니다. 다만 "Cosmos Policy와 같은 설정에서 나쁘지 않다"는 말은 가능하다.

### 1.2 표 8: LIBERO 원 벤치마크 (4 스위트 평균)

| 항목 | 값 |
|---|---|
| 스위트별 평균 | MetaWAM 98.05 (표 8의 98.1과 일치), Cosmos Policy 98.475 (표 8의 98.5와 일치) |
| 시도 | 4 스위트 × 500회 × 3 시드 = 6000회 (같다고 가정) |
| 차이 | MetaWAM − Cosmos = −0.4 pp, z = −1.70, p = 0.09 |

LIBERO 원 벤치마크에서 MetaWAM이 Cosmos보다 낮다. 논문은 이 열에서 우위를 주장하지 않는다. 초록과 본문도 98.1%를 기준선 비교 없이 말한다.

### 1.3 표 4: 실로봇 (과제당 20회, 3과제)

과제별 성공률에서 성공 수를 역산했다 (예: MetaWAM ID 80, 85, 90% → 16, 17, 18회). 모든 평균이 정수 계수와 맞는다 (`recompute_results.json`의 `t4_counts`).

| 방법 | ID 성공 수 (60회) | OOD 성공 수 (60회) |
|---|---|---|
| π0 | 30 (50.0%) | 22 (36.7%) |
| π0.5 | 43 (71.7%) | 28 (46.7%) |
| Cosmos Policy | 47 (78.3%) | 38 (63.3%) |
| MetaWAM | 51 (85.0%) | 41 (68.3%) |

| 비교 | Fisher 양측 p |
|---|---|
| MetaWAM 대 Cosmos, ID (51/60 대 47/60) | 0.48 |
| MetaWAM 대 Cosmos, OOD (41/60 대 38/60) | 0.70 |
| MetaWAM 대 Cosmos, 합계 (92/120 대 85/120) | 0.38 |
| MetaWAM 대 π0.5, ID (51/60 대 43/60) | 0.12 |

- 60회에서 80% 검정력의 최소 차이는 약 22 pp다. 논문이 보고한 ID 6.7 pp, OOD 5.0 pp 차이는 이 검출 한계보다 작다.
- MetaWAM ID의 Wilson 95% 구간은 73.9–91.9%, Cosmos는 66.4–86.9%다. 두 구간은 크게 겹친다.
- 방향 (MetaWAM이 높다)은 모든 열에서 같다. 강도는 이 표본으로 말할 수 없다.

### 1.4 표 3: LIBERO-Plus의 Total

Total은 일곱 범주의 단순 평균이 아니다. 단순 평균과 보고된 Total이 방법마다 다르게 어긋난다.

| 방법 | 보고된 Total | 일곱 범주 단순 평균 |
|---|---|---|
| MetaWAM | 83.4 | 83.46 |
| Cosmos Policy | 82.2 | 83.01 |
| π0.5 (원자료 표 4, 표 3에는 없음) | 85.7 | 86.49 |
| π0 rerun (원자료 표 4, 표 3에는 없음) | 69.4 | 70.74 |

- 보고된 차이 (MetaWAM − Cosmos)는 1.2 pp (본문 83.44 − 82.2 = 1.24 pp)다.
- 단순 평균으로 보면 차이는 **0.45 pp**다.
- 범주별 시도 수가 없어 가중치를 알 수 없다. 따라서 Total의 신뢰구간도 못 낸다.
- 원자료에서 π0.5의 Total 85.7은 MetaWAM 83.4보다 2.3 pp 높다. 표 3은 이 행을 뺐다.

범주별로 보면 MetaWAM이 이긴 범주는 카메라 (82.9 대 75.8), 언어 (89.5 대 81.7), 조명 (97.8 대 96.5), 잡음 (94.8 대 92.7), 배치 (86.7 대 82.2)다. 배경 (72.6 대 88.9)과 로봇 초기 상태 (59.9 대 63.3)에서는 낮다. 본문 5.1절의 서술과 맞는다.

### 1.5 표 5: 지연과 어텐션 산술

- 지연: (0.479 − 0.291) / 0.479 = 39.2%. 초록의 "39%"와 일치한다. 측정 조건 (GPU 종류, 배치, 프레임 처리 방식)은 논문에 없다.
- 어텐션: 프레임 11개에서 8개로 줄면 전체 자기 주의 쌍 수는 (8/11)² = 0.529로 줄어 47.1% 감소다. 프레임당 토큰 수가 같고 주의가 전체 쌍에 걸린다는 가정에서 맞다. 본문의 "roughly 47%"와 일치한다.
- 순위: 신호 복원 지표 (이득, 상대 L2)와 SR은 네 배치에서 같은 순서다. 배치가 4개뿐이라 이 일치는 통계적 의미가 거의 없다.

## 3. 토이 V1: 식 (2)–(3)의 읽기·쓰기 왕복과 슬롯 용량

`analysis/toy_readout_check.py`는 논문 식 (2)–(3)과 공식 코드의 슬롯 배치 (k_H = 0 행, 채널 대역)를 numpy로 재현한다. VDM은 쓰지 않는다. 잡음은 가우시안으로 흉내 낸다. 격자 크기 H = W = 28은 224 px 입력과 8배 압축을 가정한 값이다. 논문 본문에는 격자 크기가 없다.

| 검사 | 결과 |
|---|---|
| 잡음 없는 왕복 (과제, 현재 고유감각, 행동 32 × 7, 미래 고유감각, 가치) | 최대 오차 1.1e-15 (정확히 복원) |
| 행 0 패킹의 공간 잠재가 H 방향으로 상수인가 | 예 (편차 0). 채널당 실제 자유도는 W = 28개 |
| 행동 슬롯 용량 (8 × W = 224) 대 RoboCasa 청크 (32 × 7 = 224) | 꽉 찬다. LIBERO와 실로봇 청크 16은 절반 (112) |
| 고유감각 슬롯 용량 (3 × W = 84) 대 9 원소 | 충분 |
| 독립 잡음 σ = 0.1을 주입했을 때 읽기 오차 표준편차 | 0.100 (σ와 같다). 정규직교 변환이라 잡음이 줄지 않는다 |
| 읽기 식 행 0 계수 = √H · DCT_W(H 방향 평균) | 최대 오차 1.8e-15. 읽기는 H 방향 평균에 해당한다 |

**해석.**

- 식 수준에서 "decoder-free 정확한 복원"은 맞다. 디노이저가 잠재를 정확히 내면 신호도 정확히 나온다.
- 행 0만 쓰면 채널마다 정보는 열 방향 W개뿐이다. 논문이 말하는 2D 분포는 실제로 1차원 패턴이다. 이 점은 "분포 정렬" 논리가 어떤 정보 표현에 기대는지 바꾸지 않지만, 2D 주파수 구조를 활용한다는 표현은 과장일 수 있다.
- 디노이저 오차가 있으면 읽기 오차는 잡음 주입 때와 같은 크기다. 평균으로 줄지 않는다. 디노이저 오차가 그대로 신호 오차가 된다.
