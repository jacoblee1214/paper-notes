## 1. 문제와 주장

초록과 §1은 슬립 검출 연구의 두 가지 빈틈을 듭니다. (i) 슬립 시작부터 첫 정답 검출까지의 **검출 지연**이 거의 보고되지 않고 오탐과의 상충도 평가되지 않는다. (ii) 보지 못한 물체, 센서 개체, 로봇 플랫폼으로의 **일반화**가 약하다. 저자들은 센서와 학습 파이프라인을 함께 제안해 두 가지를 모두 다룬다고 주장합니다.

주요 기여 세 가지(§1):

1. 압전저항 배열(Piezo)과 가속도계(XL)가 상보적이라는 것을 보이는 다중 모달 학습 틀. 융합이 Macro F1 96.7%이고 한 모달만 쓸 때는 81–84%, 오탐률(FPR) 1.6% 미만.
2. 240 Hz 슬립 검출 시스템. 슬립 사건의 76%를 23.1 ms 안에 검출(검출 지연과 모델 추론 포함).
3. **140만 프레임, 37개 물체**로 물체, 센서 개체, UMI → Tesollo 로봇 손으로의 영점(zero-shot) 일반화를 평가.

**라벨링(§3.2, 그림 2·3).** Mark-10 F105-EM 전동 시험대의 크로스헤드가 물체 한쪽을 잡고, 센서가 달린 그리퍼가 다른 쪽을 잡습니다. 늘어나지 않는 물체에서는 크로스헤드 변위가 그리퍼 표면의 슬립과 같다고 보고, 크로스헤드 위치(0.02 mm 해상도)로 라벨을 만듭니다.

- 수집은 여섯 단계: 크로스헤드 하강·정지, 그리퍼 닫기, 사람이 파지력을 바꿈, 크로스헤드 상승(슬립), 정지, 그리퍼 열기. **슬립은 상승 단계에서만 발생.**
- 슬립 시작은 크로스헤드 누적 변위가 0.07 mm를 넘는 시점, 끝은 크로스헤드가 멈출 때. 그 사이 모든 프레임이 슬립.
- 접촉이 있고 슬립 구간 밖이면 슬립 없음. 평균 taxel 값이 1 ADC count 미만이면 접촉 없음(전 물체·센서에 같은 임계값).
- 3-클래스 라벨 (접촉 없음, 슬립 없음, 슬립). Mark-10은 라벨링에만 쓰고 배포 때는 없음.

**데이터셋(§5.1, 그림 5, 부록 C.1).** 37개 물체(케이블, 커넥터, 소재, 공구). 28개 학습, 9개 보류(Shore 경도 블록 81 HA, 88 HA는 학습에 없음). 슬립 속도 다섯 가지(2–18 mm/s)와 사람이 바꾸는 파지력. 슬립 없는 대조 시나리오 세 가지(각 5회 시행): 접촉 없이 크로스헤드만 움직임, 물체를 쥐되 크로스헤드와 연결 안 됨, 슬립 없는 자유 파지·옮기기(UMI). 프레임 비율은 접촉 없음 57.6%, 슬립 23.7%, 슬립 없음 18.8%.

## 3. 방법 (§4, 식 1–5, 부록 B)

관측 길이 T 프레임의 창에서 **마지막 프레임**의 클래스를 맞히는 인과적 분류기 $\hat y_T = f_\theta(O_{1:T})$ (식 1). 기본 T = 60 (250 ms).

| 구성 | 내용 | 출처 |
|---|---|---|
| Piezo 인코더 | 3×3 conv 블록 3개(ReLU, 2×2 max pool) + FC → 128차원. ResNet-18, ViT-MAE도 시험했으나 이쪽이 더 낫고 가볍다고 함 | §4.2, 부록 D |
| XL 인코더 | 10 Hz 고역 통과 → 축별 로그 멜(인과, 16 ms 창, 프레임 이동 1/240 s) → **로그합지수(log-sum-exp)로 세 축 통합** → SSAST-Tiny (멜 128 → 16 bin, 16×1 패치로 주파수 차원을 한 토큰으로, 패치 임베딩만 재초기화, 나머지 사전학습 유지) → 128차원 | §4.2, 부록 B, 식 5 |
| 센서 간 융합 | 같은 모달의 센서 개체별 임베딩을 원소별 max pooling (센서 수와 손가락 정체성을 버림) | §4.2 |
| 모달 간 융합 | 양방향 다중 헤드 교차 어텐션(식 2–3, 질의는 현재 시점, 키·값은 과거 포함 상대 모달), LayerNorm 잔차, 두 결과를 이어 붙임 | 식 2, 3 |
| 시간 | 인과 자기어텐션 한 층 + 예측 헤드. 학습은 마지막 프레임 T의 교차 엔트로피만 (식 4) | §4.2 |
| 학습 | 10 에폭, 학습률 1e-5, 배치 32, 5 에폭 선형 워밍업 + MultiStepLR(γ = 0.5), EMA. Piezo 증강(최대 360° 회전, ±30% 롤, 반전, σ = 0.001 가우시안), XL 증강(프레임별 표준화, 주파수 마스킹 최대 5 bin 확률 50%, 균일 잡음). 3 시드 평균 보고 | 부록 C.2 |

로그합지수의 방향 불변성은 부록 I가 증명합니다. 가정 1–4(진동이 고정 단위 방향 d를 따라 스칼라 s(t)로 전파, d 단위 벡터, 창 안에서 d 고정, 단일 진동원) 아래 세 축 파워의 합이 $|S|^2$이 되어 d가 사라진다는 것입니다(식 6–14). 이 증명과 이를 확인한 토이는 `03` §3입니다.

- 그림 7(a): 슬립 사건의 43%가 시작 프레임, 33%가 2–5 프레임, 15%가 6–21 프레임, 9%가 21 프레임 초과에서 검출됩니다. 76%가 5 프레임(20.8 ms) 이내이고, 모델 추론 평균 2.3 ms(RTX A4500, 1,000회)를 더해 23.1 ms라고 씁니다.

### 4.5 실로봇 (§5.3, 부록 H)

Tesollo 손에 닫힌 루프 재파지 제어기를 붙이고 사용자 네 명이 보지 않은 물체 10개에서 100회를 당겨 슬립을 유발합니다(위, 아래, 회전, 경사, 속도 두 가지). 슬립이 검출되면 손가락이 안쪽으로 움직여 힘을 올립니다. 보고: 100/100회 슬립 검출과 오탐 없음, 물체 낙하 방지 95/100, 검출부터 최대 힘까지 약 50 ms. 실패 5회는 케이블이 센서 가장자리에 있어 거친 안쪽 움직임이 물체를 밀어낸 경우로 분류됩니다. 부록 H는 손으로 든 UMI에서 오탐이 없었다고도 씁니다.

## 5. 저자가 밝힌 한계 (§7)

슬립 축이 선형 하나뿐(회전·다방향은 실로봇에서 검출만 하고 지연은 정량화 안 함), 로봇이 움직이는 중 슬립은 정량 검증 전, Piezo는 법선 압력만 측정하고 전단은 시간 순서로 간접 추정, 물체와 환경 범위, GPU 워크스테이션에서만 추론을 측정.

## 6. 읽으면서 남은 질문 (자세한 검증은 `03`, `04`)

1. 지연은 "첫 정답 검출까지의 프레임"인데, 놓친 사건과 오탐이 먼저 난 사건을 어떻게 처리하는지 본문에 없습니다.
2. FPR의 분모가 정의되어 있지 않습니다("슬립으로 잘못 예측된 프레임의 비율").
3. 헤드라인 96.7%는 보류 물체가 아니라 학습 물체 28개의 별도 시험 분할(UMI ID)입니다. 보류 물체는 95.75%입니다.
4. 시드 간 분산이 표에 없고, ID 분할이 에피소드 단위로 나뉘었는지 본문에 없습니다.
5. 설계 선택(XL 증강, 융합 방식)을 Tesollo 시험 분할로 평가한 표가 있어 "영점"의 범위를 정의해야 합니다.
6. 슬립이 크로스헤드 상승 단계에서만 일어나므로, 이 단계의 다른 신호(인장, 시험대 진동)와 라벨이 얽혀 있는지 대조 시나리오 15회(3종 × 5회)가 충분한지 확인이 필요합니다.
