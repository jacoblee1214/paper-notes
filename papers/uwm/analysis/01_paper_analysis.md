## 1. 한 문단 요약

UWM은 Diffusion Transformer 하나에 두 확산 과정, 즉 행동(길이 16 청크)과 다음 관측(VAE 잠재 공간의 영상)을 함께 넣습니다. 두 과정은 서로 독립인 확산 시각 `t_a`, `t_o'`로 제어됩니다(§III.B). 학습은 두 시각을 각각 균일하게 뽑아 노이즈를 더한 뒤, 두 노이즈 예측의 MSE 합을 줄이는 방식입니다(식 1). 한 시각을 완전 노이즈(T)로 두면 그 변수를 주변화하고, 0으로 두면 그 변수를 조건으로 씁니다. 그래서 같은 모델로 정책 p(a|o), 순방향 동역학 p(o'|o,a), 역동역학 p(a|o,o'), 영상 예측 p(o'|o)를 샘플링할 수 있습니다(식 2–5). 행동 정보가 없는 영상은 `t_a = T`로 두고 행동을 노이즈로 채워 같은 손실에 넣습니다(§III.D). 저자들은 DROID 2000개 궤적으로 사전학습하고 다섯 실로봇 과제에서 DP, PAD, GR1과 비교해 ID 평균이 가장 높다고 보고합니다(표 I, 그림 6). LIBERO 시뮬(LIBERO-90 사전학습, 5과제)에서도 교란 조건 평균이 가장 높습니다(표 II). 다만 실로봇 시도 수가 칸당 50(Rice-Cooker는 20)이라 과제별 차이 대부분은 통계적으로 확실하지 않습니다(`03` §1).

## 2. 문제 설정과 방법

### 2.1 문제 설정 (§III.A)

- 행동 라벨이 있는 데이터 `D_e = {(o_i, a_i, o'_i)}`와 행동 없는 영상 `D_af = {(o_i, o_{i+1})}`를 가정합니다. 질문은 두 데이터에서 정책을 어떻게 얻을지입니다.
- 원하는 모델은 네 가지입니다. 정책 p(a|o), 순방향 동역학 p(o'|o,a), 역동역학 p(a|o,o'), 영상 예측 p(o'|o)입니다.
- 관측은 마르코프라고 가정합니다. 이 가정은 DROID 청크 학습에서 다중 프레임 관측(h_o = 2)으로 완화합니다(부록 A.1).

### 2.2 결합 확산과 주변화·조건화 (§III.B, 식 1–5)

- 노이즈 예측망 `s_θ(o, a_{t_a}, o'_{t_o'}, t_a, t_o')`가 두 노이즈 ε_a, ε_o'를 함께 예측합니다.
- 학습 목표(식 1): `ℓ(θ) = E[ w_a ||ε_θa − ε_a||² + w_o' ||ε_θo' − ε_o'||² ]`, `t_a, t_o' ~ U(0,T)`. 저자 설정은 `w_a = w_o' = 1`입니다(표 V).
- 추론 방식(식 2–5)은 다음과 같습니다.
  - **정책** (식 2): `t_o' = T`로 두고 `o'_T ~ N(0,I)`, `a`만 역확산합니다.
  - **영상 예측** (식 3): `t_a = T`, `a_T ~ N(0,I)`, `o'`만 역확산합니다.
  - **순방향 동역학** (식 4): `t_a = 0`, `a_0 = a`(실제 행동)로 두고 `o'`를 역확산합니다.
  - **역동역학** (식 5): `t_o' = 0`, `o_0 = o`(실제 다음 관측)로 두고 `a`를 역확산합니다.
- 이 설계의 핵심 주장은 "확산 시각은 부분 마스킹과 같다"입니다(§III.B). 완전 노이즈는 가림이고 노이즈가 없으면 보임입니다.

### 2.3 구조 (§III.C, 그림 2–3, 부록 A.1, 표 V)

| 항목 | 값 (표 V / 부록 A.1) |
|---|---|
| 관측 | 세 카메라(두 외부, 한 손목), 프레임 2개 |
| 관측 인코더 | ImageNet 사전학습 ResNet-18, 학습 중 갱신 |
| 영상 표현 | 동결된 SDXL VAE: 224×224×3 → 28×28×4 잠재 |
| 패치 | 3D 합성곱 패치 (표 V는 (4,4,2), 코드는 (2,4,4)로 표기. 같은 뜻) |
| 행동 | 길이 16 청크, 얕은 MLP 토큰화 |
| 백본 | DiT, 깊이 12, 폭 768, 헤드 12, AdaLN 조건(시각 임베딩 512) |
| 레지스터 | 8개 (표 V). LIBERO 설정은 24개 (`04` D5) |
| 확산 | 학습 100 스텝, 추론 DDIM 10 스텝, `squaredcos_cap_v2`, clip sample |
| 학습 | AdamW, lr 1e-4, wd 1e-6, 배치 36×4 GPU, 사전학습 상수 학습률, 미세조정 코사인+워밍업 1000 |
| 계산 | 100K 스텝, A100 4장 기준 24시간 (부록 A.3). 측정 방법은 없음 |

- 추론 시 첫 h'_a = 8 행동만 실행하고 다시 계획합니다(부록 A.2).
- 레지스터는 행동과 영상 패치 사이의 정보 교환 통로입니다(§III.C). 표 VII에서 레지스터가 없으면 점수가 낮다고 보고합니다.
- 조건 결합은 AdaLN(표 VII에서 교차 어텐션보다 낫다고 보고).

### 2.4 행동 없는 영상의 공동 학습 (§III.D, 부록 A.2)

- 행동 없는 샘플은 `t_a = T`로 두고, 행동을 단위 가우시안 노이즈로 채웁니다. 손실은 식 1 그대로 계산합니다.
- 부록 A.2는 "행동 손실은 로봇 샘플과 영상 샘플 모두에서 계산된다"고 씁니다. 이 점은 `04` D1에서 코드와 대조합니다.
- 영상 데이터는 DROID의 나머지 2000 궤적에서 행동 라벨을 지운 것입니다(§IV.B.1). 인터넷 영상(Kinetics-400, Something-Something v2)은 부가 실험(표 IX)입니다.

## 3. 실험 결과

### 3.1 실로봇 다섯 과제 (표 I, §IV.B, 그림 5–6, 부록 C)

- 설정: Franka Panda, DROID 플랫폼, 제어 10 Hz, 델타 엔드이펙터 행동, 그리퍼 한 차원(부록 C.1). 사전학습 100K 스텝, 미세조정은 과제별 10K–50K 스텝(표 VI).
- 평가: 과제당 50개 초기 위치(Rice-Cooker는 20개), 위치마다 3번 시도(부록 C.3). ID와 OOD(조명, 배경, 산만 물체)로 나눕니다(그림 9는 범주별 OOD).
- 표 I의 UWM 사전학습 성공률: Stack-Bowls ID 0.86 / OOD 0.76, Block-Cabinet 0.76 / 0.60, Paper-Towel 0.78 / 0.78, Hang-Towel 0.82 / 0.64, Rice-Cooker 0.60(ID). 기준선 최고치는 GR1입니다(예: Stack-Bowls ID 0.66, Block-Cabinet ID 0.66).
- 저자 주장: "ID 평균에서 최고 기준선보다 최대 20% 높다"(§IV.B.2). 재계산에서는 ID 차이가 10–20pp이고 OOD 차이는 Stack-Bowls에서 28pp입니다. 즉 "최대 20%"는 ID에만 맞습니다.
- 공동 학습(표 I의 "/" 뒤 값): UWM은 9개 칸 모두에서 0.04–0.12 올라갑니다. 저자 주장은 "일관되게 향상"입니다(§IV.B.2). GR1은 Stack-Bowls, Paper-Towel, Rice-Cooker에서 떨어진다고 씁니다.
- 과제 평균(그림 6): 막대그래프만 있고 수치는 없습니다. 표 I에서 칸을 평균해 얻은 값과 막대의 눈대중 값은 맞습니다(`03` V8).

### 3.2 LIBERO 시뮬 (표 II, §IV.C, 그림 7, 부록 C.5)

- 사전학습: LIBERO-90 (4500 궤적), 100K 스텝. 미세조정: LIBERO-10 중 5과제, 과제당 50 궤적, 10K 스텝(§IV.C).
- 교란: 초기화 범위를 0.03 키우고 배경 물체를 뺍니다(부록 C.5).
- 결과(평균 ± 표준편차 가정, 시드 3): UWM 0.79 ± 0.11, DP 0.71 ± 0.12, PAD 0.57 ± 0.19, GR1 0.58 ± 0.14 (평균 열). 저자는 UWM이 5과제 모두에서 가장 높다고 씁니다. 평가가 교란 조건이므로 본문의 "OOD"는 이 교란을 가리킵니다.
- 본문은 "±"를 "신뢰구간"이라고 부르지만, 시드 3개로 만든 SD인지 표준오차인지 명시하지 않습니다. `03` §1.2에서 두 해석을 모두 씁니다.

### 3.3 궤적 추적 (표 III, §IV.D.2)

- 평가: LIBERO 학습 궤적 50개를 역동역학 모드와 정책 모드로 따라가게 함.
- 결과 (v3): Book-Caddy에서 정책(궤적 길이 제한) 0.47, 역동역학 0.65. Soup-Cheese에서 0.26과 0.55. 정책 1000 스텝 제한에서는 1.00과 0.97입니다.
- 해석: 역동역학이 기준 궤적에 더 가깝게 따라간다고 봅니다. 정책은 결국 과제를 풀지만 궤적에서는 벗어난다고 씁니다.

### 3.4 범주별 OOD (표 IV, 그림 9, §IV.D.3)

- 설정: 조명 2종, 배경 2종, 물체 2종(C1, C2)을 분해해 칸당 초기 위치 5개를 평가합니다. 열 6개(Stack-Bowls와 Block-Cabinet의 UWM co, UWM pre, DP)입니다.
- 결과: 합계는 Stack-Bowls에서 co 21/30, pre 15/30, DP 12/30이고 Block-Cabinet에서 co 15/30, pre 8/30, DP "6/30"입니다. 그러나 Block-Cabinet DP 열의 칸을 더하면 5/30이 나옵니다(`03` V4). 저자는 "co가 pre와 DP보다 크게 강건하다"고 씁니다.

### 3.5 설계 선택 (표 VII, 부록 D.1)

- 설정: LIBERO 단일 과제(Book-Caddy, Soup-Cheese), 처음부터 학습, 50 초기화, 시드 3.
- 결과: 레지스터 8 개 0.88 / 0.90, 4 개 0.83 / 0.86, 없음 0.81 / 0.85, 교차 어텐션 0.78 / 0.86입니다.
- 저자 해석: "레지스터가 도움이 되고 교차 어텐션은 나쁘다". 시드 3에서 차이가 SD 안에 들어갑니다(`03` §1.5).

### 3.6 학습 목표 절제 (표 VIII, 부록 D.2)

- 미래 관측 재구성 대 현재 관측 재구성 대 DP(재구성 없음): Stack-Bowls 0.86 / 0.70 / 0.48, Block-Cabinet 0.76 / 0.66 / 0.60.
- 주장: "동역학 예측이 단순 재구성보다 낫다"(부록 D.2). 이 표의 값은 표 I의 사전학습 ID 칸과 같습니다.

### 3.7 인터넷 영상 (표 IX, 부록 D.3)

- 로봇 데이터 + 로봇 영상: Stack-Bowls 0.92, Block-Cabinet 0.84. 로봇 + 인터넷 영상: 0.88, 0.80. 로봇만: 0.86, 0.76.
- 주장: 인터넷 영상도 조금 도움이 되지만 같은 도메인 로봇 영상이 더 낫다(부록 D.3). 인터넷 영상 열에서 주는 이득은 칸당 시도 수 50에서 확인되지 않습니다(`03` §1.6).

### 3.8 저자가 한계로 인정한 것 (§VII)

- 사람 영상으로는 학습하지 않음(구현 체화 차이).
- 순방향 동역학 재구성에 아티팩트가 있어 계획에 쓰기 어려움.
- 더 조밀한 영상 예측으로 개선할 여지.
- 시뮬 동역학이 실제보다 단순해서 OOD 이득이 실로봇보다 작다는 해석(§IV.C).
