요약

  1. 무엇을 했나: 선형층 출력(활성값)에 토큰마다 독립인 가우스 잡음을 더하고 토큰별 손실 변화로 보상해서, forward만으로 출력 오차를 추정하고 입력과의 외적으로 가중치 gradient를 만든다. 토큰 하나가 population 구성원 하나가 되는 "가상 population"이다.
  2. 숫자는 맞다: 본문 수치 12개, Table 1의 power law 극한 4개, 파라미터 수(37.75M), 공식 코드의 draw 배분이 부록과 모두 일치한다.
  3. "backprop을 넘는다"는 학습 극초기, 같은 토큰 기준이다: 넘는 두 예산은 update 6번(100k)과 61번(1M)이다. 16k population의 update 한 번은 forward 약 13,600회, backprop step의 약 4,500배 연산이다.
  4. 20M 극한 4.431 < backprop 4.633은 불안정하다: 다섯 칸 중 한 칸을 빼고 다시 적합하면 2.57–4.68이 나오고, 64 칸을 빼면 backprop보다 높다. 맨 위 칸만 따로 튜닝되었다.
  5. c_max < 1은 "자기 토큰만 보상"하는 구조적 편향이다: cosine 법칙 cos(K) = c_max/√(1 + c/K)를 유도하면 c = (d_out + 1) × 토큰별 gradient 비정합도다. numpy toy에서 c_max는 국소 gradient와 전체 gradient의 cosine과 일치했다. 학습 population(16k)의 cosine은 head를 빼면 0.16–0.57이다.
  6. 확실한 것: 같은 forward 수에서 가중치 공간 ES(EGGROLL)보다 훨씬 효율적이라는 결과와, population에 따른 cosine 상승 법칙은 견고하다.
  7. 재현: 하지 않았다(공식 코드는 GPU 전용). 표 재계산, 연산량 환산, numpy toy만 CPU로 했다.

1. Abstract

Transformer 언어모델을 역전파 없이 forward만으로 사전학습하는 0차(zeroth-order) 방법 Dust를 제안합니다. 두 가지가 핵심입니다.

  • 가중치가 아니라 활성값을 흔듭니다: 각 선형층의 출력에 토큰마다 독립적인 가우스 잡음을 더합니다. 이것을 node perturbation이라고 합니다.
  • 보상을 토큰 단위로 줍니다: 각 토큰의 잡음은 그 토큰의 손실 변화로 보상받습니다. 따라서 forward 한 번에 토큰 수만큼의 "가상 population"을 평가합니다.

저자들의 주장(TL;DR)은 다음과 같습니다.

  1. Transformer 사전학습에서 backprop과 경쟁할 수 있는 최초의 0차 방법이고, population이 크면 여러 설정에서 backprop보다 낫습니다.
  2. 가중치 공간 ES(EGGROLL)보다 10³–10⁴배 효율적입니다(외삽 기준).
  3. 모델이 클수록 population 효율이 높습니다. 243M 모델이 120배 작은 모델보다 대부분의 population에서 낫습니다.
  4. population이 커질수록 Dust의 gradient가 backprop의 gradient와 더 잘 정렬되고, 1B 토큰까지 정렬이 유지됩니다.

2. Method

2.1 활성값 공간의 섭동 (§2.1)

선형층 y_t = W x_t의 출력에 y_t → y_t + σ a_t (a_t ~ N(0, I))를 모든 토큰에 독립적으로 더합니다.

  • 토큰 t에서 이 섭동은 그 층 가중치에 저랭크 섭동을 준 것과 같습니다. 따라서 가중치를 실제로 복사하지 않아도 됩니다.
  • 시퀀스 길이 2,048이면 forward 한 번에 2,048개 "구성원"을 평가하는 셈입니다.
  • 잔차 혼합 스칼라 2L개만 가중치 공간 ES로 학습합니다.

2.2 보상과 추정 (§2.2, Eq. 1–3)

  • 보상: c_s = ℓ̃_s − ℓ_s입니다. ℓ̃_s는 같은 forward 묶음 안 draw들의 평균 손실입니다.
  • 미래 토큰 credit: r_t = Σ_{s≥t} γ^{s−t} c_s (Eq. 1). γ = 0이면 자기 토큰만 봅니다.
  • 층 출력 오차 추정: ĝ_t = −(1/Kσ) Σ_i r_t^(i) a_t^(i) (Eq. 2). K는 population, 즉 draw 수입니다.
  • 가중치 gradient: Ĝ_W = Σ_t ĝ_t x_tᵀ (Eq. 3). backprop과 같은 외적이고, 출력 오차를 chain rule이 아니라 population에서 얻는다는 점만 다릅니다.

2.3 간섭 줄이기와 튜닝 (§2.3, Eq. 4, 부록 E·F)

  • 층 종류별 분리: 층 종류마다 다른 forward pass에서 흔듭니다. 블록 l의 draw는 깨끗한 forward를 캐시해 두고 블록 l부터만 다시 계산합니다.
  • attention 내부(q, k, v, gate, value embedding): 손실이 아니라 추정된 attention 출력 오차와의 정렬 c_s = −⟨ĝ_s, Δo_s⟩로 보상합니다(Eq. 4). k, v, gate, ve는 미래 토큰이 읽으므로 γ ≈ 0.98–0.99를 쓰고, 나머지는 γ = 0입니다.
  • LM head: 캐시된 logit에서 256열 묶음(slab)씩만 흔들고 cross-entropy만 다시 계산합니다.
  • 하이퍼파라미터 튜닝: 층별 잡음 크기, credit decay, draw 배분을 정합니다. 배치 한 개에서 backprop gradient와의 cosine을 최대화해 후보를 고르고, 짧은 학습으로 확정합니다.
  • draw 배분(K = 16,384, 1M 기준):
    • writer 쌍(attn·MLP 출력 투영) 7,040, MLP hidden 7,040, attention 출력 1,664, 토큰 임베딩 640
    • 앞 블록에 많이 줍니다(블록 1: 2,432 → 블록 8: 128).
    • head는 별도로 65,536 slab draw를 씁니다.

3. Experiments

3.1 설정 (§3.1, 부록 A)

  • 모델: modded-nanoGPT형 decoder 8층, 폭 512, 37.7M 파라미터.
    • RMSNorm, RoPE, squared-ReLU MLP
    • sliding window(블록 4개 중 3개는 1,024)
    • 블록 절반에 value embedding
  • 데이터와 학습: FineWeb, BPE 4,096. 배치 16,384 토큰(8 × 2,048), 1 epoch, 모멘텀 SGD, 상수 학습률.
  • 평가: 셀마다 3 시드. 검증 손실 기준으로 고른 체크포인트의 test 손실을 보고합니다.
  • 비교 대상: backprop(같은 grid로 튜닝), EGGROLL-Transformer(가중치 공간 ES, 같은 구조).

굵은 값은 backprop보다 낮은 칸입니다. 저자 해석은 다음과 같습니다.

  • 100k와 1M에서는 Dust가 backprop보다 낮습니다.
  • 10M에서는 적합 극한이 backprop 바로 위입니다.
  • 20M에서는 사다리가 아직 내려가는 중이고, power law 극한 4.431(95% 구간 3.89–4.58)이 backprop 4.633보다 낮습니다.
  • EGGROLL은 population을 256배로 늘려도 Dust@64에 못 미칩니다.

3.3 Adam (§3.3, Fig. 3)

1M 토큰에서 세 방법을 모두 Adam으로 다시 튜닝했습니다. Dust의 극한은 5.248(구간 5.17–5.30)로, backprop보다 낮다고 보고합니다. 그림에 표시된 backprop 값은 5.361입니다. EGGROLL은 Adam으로 거의 나아지지 않습니다.

3.4 과대매개변수화 (§4.1, Fig. 4)

10M 토큰에서 2M, 7.3M, 38M, 243M 네 가지 크기를 비교했습니다. 저자 해석은 다음과 같습니다.

  • 256 draw 이상에서는 2M → 7M → 38M으로 갈수록 손실이 낮아집니다. 243M은 조금 나쁩니다.
  • 1k 이후 population 증가로 얻는 이득은 큰 모델이 약 30% 더 큽니다.
  • 모델 크기를 "탐색 공간의 크기와 기하"로 봐야 한다고 해석합니다.

3.5 gradient 정렬 (§4.2, Fig. 5, 부록 G)

backprop으로 학습한 10M, 100M, 1B 토큰 체크포인트에서, Dust 추정치와 backprop gradient의 cosine을 population 64–128k에 걸쳐 쟀습니다.

  • cos(K) = c_max/√(1 + c/K)가 층 종류마다 RMSE 0.06 이하로 맞습니다(Eq. 5).
  • c_max는 head·Q·K·value emb에서 1.0이고, MLP·attn out·V에서 0.86–0.88, token emb 0.73, value gate 0.67입니다(Table 8).
  • 같은 forward 수의 EGGROLL은 head를 빼면 cosine 0.05 미만입니다.

4. Limitations

4.1 저자가 밝힌 한계 (§1, §5)

  • 연산 효율은 목표가 아니었습니다. backprop을 대체하려면 연산 효율이 몇 자릿수 더 좋아져야 합니다.
  • 미분 불가능한 구조, 외부 프로그램이 들어간 망, 루프 구조 학습은 향후 과제입니다.
  • population이 크면 backprop보다 낮아지는 메커니즘은 아직 모릅니다.

4.2 추가로 확인한 한계 (03, 04에서 근거)

  1. "backprop을 넘는다"는 고정 토큰 비교이고, 연산량은 수천 배입니다.
    • K = 16k의 update 한 번은 forward 약 13,600회, 즉 backprop step(약 forward 3회)의 약 4,500배입니다(우리 환산).
    • 같은 연산량이면 backprop은 1M 대신 수십억 토큰을 볼 수 있습니다(03 §2).
  2. 실험이 학습 극초기에 몰려 있습니다.
    • step 수는 100k 예산에서 6, 1M에서 61, 20M에서 1,221입니다.
    • 토큰/파라미터는 최대 0.53입니다. Chinchilla 기준의 약 2.7%입니다.
    • backprop 손실도 균등 예측 손실(ln 4096 = 8.32)에서 13–44%만 내려간 구간입니다(03 §1).
  3. 20M의 "극한이 backprop보다 낮다"는 결론이 불안정합니다.
    • 다섯 칸 중 한 칸을 빼고 다시 적합하면 극한이 2.57–4.68로 흔들립니다. 64 draw 칸을 빼면 극한이 backprop보다 높습니다.
    • 사다리 맨 위(16k) 칸만 자기 상수로 따로 튜닝되었습니다(부록 F)(03 §3).
  4. 학습 population에서의 cosine은 "가깝다"고 하기 어렵습니다. Table 8 법칙으로 K = 16k의 cosine을 계산하면 head 0.98을 빼고 0.16–0.57입니다(03 §4).
  5. c_max < 1인 층에는 공통점이 있습니다.
    • c_max < 1인 층은 자기 토큰 손실만으로 보상받는 층(γ = 0이고, 출력이 뒤 토큰에도 영향을 주는 층)입니다.
    • c_max = 1인 층은 영향이 자기 토큰에만 미치거나(head, Q), 미래 credit을 받는 층(K, value emb)입니다.
    • 우리 toy는 이 해석과 맞습니다(03 §5).
  6. 과대매개변수화 결론은 약합니다.
    • 243M은 모든 population에서 38M보다 나쁩니다. backprop에서도 243M(5.048)이 38M(5.015)보다 나쁩니다.
    • 10M 토큰은 243M에게 토큰/파라미터 0.04입니다.
    • backprop과의 차이는 64 draw에서 2M 0.525 → 243M 0.671로 커집니다(03 §1).
  7. 불확실성이 표에 없습니다. 시드별 값과 표준편차가 보고되지 않았습니다. 100k의 Dust-backprop 차이(0.05–0.07)가 시드 변동보다 큰지 판단할 수 없습니다.

  • 계산에 쓴 비용:
    • 블록 하나: 12d² + 2·ctx·d MAC/토큰
    • head: d·V
    • attention 내부 draw는 그 블록의 attention만, head draw는 캐시된 logit의 256열만 다시 계산합니다.

16k 13,565 4,522배 0.83
  • draw 한 번의 비용: 평균 0.82 forward입니다. 논문의 "draw는 forward보다 조금 싸다"와 맞고, "256 이상에서 EGGROLL보다 연산이 적다"도 맞습니다.
  • 같은 연산량이면: 1M 토큰에서 K = 16k인 Dust와 같은 연산이면, backprop은 약 45억 토큰을 학습할 수 있습니다. 논문 표에서 backprop은 20M 토큰만으로 4.633에 이르고, 이는 Dust의 어떤 1M 칸(최저 5.911)보다 낮습니다. 저자들도 "연산 효율은 목표가 아니다"라고 밝혔지만, TL;DR의 "backprop을 넘는다"는 이 조건을 붙여서 읽어야 합니다.
  • 10³–10⁴배 효율: 이 수치는 EGGROLL 대비 population(= forward 수) 효율입니다. backprop 대비가 아닙니다.

5. cosine 법칙의 유도와 c_max < 1의 원인 (numpy toy)

5.1 법칙의 유도

σ → 0의 선형 근사에서 한 draw의 보상은 r_t ≈ σ a_tᵀ g_t입니다. 그러면 다음이 성립합니다.

  • E[ĝ_t] = g_t
  • Cov(ĝ_t) = (‖g_t‖² I + g_t g_tᵀ) / K

이를 가중치 gradient Ĝ = Σ_t ĝ_t x_tᵀ로 모으면 다음 식이 나옵니다.

cos(Ĝ, G) ≈ 1 / √(1 + c/K), c = (d_out + 1) · Σ_t ‖x_t‖² ‖g_t‖² / ‖Σ_t g_t x_tᵀ‖²

  • 법칙의 정체: 논문 Eq. 5는 c_max = 1인 이 식에, 편향 c_max를 더한 형태입니다.
  • c의 의미: "출력 차원 × 토큰별 gradient의 비정합도"입니다. 토큰마다 gradient가 서로 상쇄할수록 c가 커집니다.
  • toy 검증: 적합한 c와 이론 c가 hidden층 308 vs 314, head 76 vs 89로 맞습니다(T1).

5.2 c_max < 1은 "자기 토큰만 보상"하는 편향이다

toy에 토큰 사이 영향(인과 평균 혼합, 세기 β)을 넣었습니다(T2).

β cos(국소 gradient, 전체 gradient) γ = 0 적합 c_max γ = 1 적합 c_max γ = 1의 c / γ = 0의 c
0 1.000 0.995 1.000 171배
1 0.936 0.933 1.000 177배
3 0.694 0.692 1.000 216배
  • γ = 0일 때: 추정기는 전체 gradient가 아니라 "자기 토큰 손실에 대한 국소 gradient"를 추정합니다. 그래서 c_max가 정확히 cos(국소, 전체)가 됩니다.
  • γ = 1일 때: 미래 토큰까지 보상하면 편향은 사라지지만, 보상에 T개 토큰의 잡음이 더해져 분산(c)이 170–220배 커집니다.
  • Table 8과의 대응: Table 8의 패턴이 이 해석과 맞습니다.
    • c_max = 1인 층: LM head와 Q(출력이 자기 토큰에만 영향), K와 value emb(미래 credit을 받음)
    • c_max < 1인 층: writer, MLP, token emb(γ = 0이지만 뒤 블록의 attention을 거쳐 미래 토큰에 영향)
    • V(0.88)와 value gate(0.67)는 예외입니다. credit을 받지만 c_max < 1입니다. 이유는 확인하지 못했습니다.
  • 성능 한계: 이 편향 때문에 Dust는 population을 아무리 늘려도 MLP·writer 층에서 backprop 방향의 약 0.86–0.88까지만 다가갑니다. 논문은 이를 "다른 궤적이라 오히려 좋은 성질"이라고 해석하지만, 원인이 구조적 편향이라는 점은 밝히지 않습니다.

5.3 그 밖의 toy 결과

  • 간섭(T3): 두 층을 같은 forward에서 함께 흔들면 c_max는 그대로이고, c가 277에서 446으로 1.6배 커집니다. 즉 간섭은 편향이 아니라 분산입니다. 층 종류별로 pass를 나누는 설계가 정당합니다.
  • weight-space ES(T4): 같은 forward 수에서 Dust가 앞섭니다(K = 64에서 cosine 0.41 vs 0.18). 다만 toy의 W1은 파라미터가 1,024개뿐이라 K = 4,096에서 ES가 0.82까지 따라옵니다. ES의 분산은 파라미터 수에 비례하므로, 37.7M 모델에서는 격차가 훨씬 큽니다.
  • 묶음 중심화(T5): n개 draw를 묶어 평균을 빼면 추정 크기가 (1 − 1/n)배가 됩니다. 측정값은 n = 2에서 0.494, 8에서 0.878, 16에서 0.942입니다. 공식 코드는 population에 따라 n = 2–16을 씁니다. 따라서 population마다 실효 학습률이 달라지고, 이는 학습률을 population별로 다시 튜닝하는 이유 중 하나일 수 있습니다. 논문 Eq. 1의 c_s = ℓ̃_s − ℓ_s는 n = 1(64 draw)에서 0이 되는데, 코드는 이때 깨끗한 손실을 baseline으로 씁니다.

6. "backprop보다 낮아진다"에 대한 다른 설명

논문은 Dust가 "고차 곡률을 암묵적으로 탐색해 평평한 영역으로 간다"는 가설을 제시합니다. 다른 설명도 가능합니다.

  1. 가우스 평활화: 유한 σ의 섭동 추정기는 평활화된 손실 E_a[ℓ(y + σa)]의 gradient를 추정합니다. 이는 잡음 주입 정규화와 같아서, 극초기 학습의 test 손실을 낮출 수 있습니다.
  2. 튜닝 비대칭: Dust는 층별 잡음 크기, credit decay, draw 배분까지 튜닝합니다. 특히 맨 위 칸은 학습으로 다시 튜닝했습니다. backprop은 모멘텀과 학습률만 튜닝합니다(부록 F).
  3. 극초기 구간: 6–61 step에서는 gradient 방향의 정확도보다 step 크기와 잡음이 손실을 더 좌우합니다.

시드별 값이 없어서 100k의 차이(0.05–0.07)가 시드 변동보다 큰지도 판단할 수 없습니다.

C6 큰 모델이 population 효율이 더 높다 (§4.1) ⚠️ 2M → 38M은 맞음. 243M은 모든 population에서 38M보다 나쁘고, backprop과의 차이도 64 draw에서 0.525 → 0.671로 커짐. 243M에게 10M 토큰은 토큰/파라미터 0.04
C7 population이 커질수록 gradient가 backprop에 정렬, 1B 토큰까지 유지 (§4.2) ✅ 법칙 적합 RMSE 0.0032–0.0367 확인. 다만 학습 population(16k)의 cosine은 head를 빼면 0.16–0.57(03 §4)
C8 근사가 backprop과 정확히 같지 않은 것이 오히려 좋은 성질이다 (§4.2) ❌ (해석) c_max < 1의 주요 원인은 자기 토큰만 보상하는 구조적 편향으로 설명됨(toy에서 c_max = cos(국소, 전체 gradient)). 더 좋은 궤적이라는 근거는 C2의 극초기 결과뿐(03 §5–6)
C9 활성값 섭동이 가중치 섭동보다 population을 싸게 만든다 (§2.1) ✅ toy에서 같은 forward 수로 cosine 0.41 vs 0.18(K = 64). 이론상 분산이 파라미터 수가 아니라 d_out × 토큰 비정합도에 비례

5. 구현 가능성

5.1 공식 코드로 재현하는 경우

  • 요구 사항: 공식 코드는 CUDA GPU만 받습니다(parser.error('Training requires a CUDA GPU.')).
  • 1M × 256 단일 GPU: 61 step × update당 약 229 forward이므로 forward 약 1.4만 번입니다. 최소 구현에서는 블록 l부터가 아니라 전체 forward를 다시 계산하므로 더 걸립니다. GPU 한 장에서 시간 단위로 예상합니다(우리 추정).
  • 10M × 16k: 610 step × 13,565 forward ≈ 830만 forward이고, 8 GPU를 씁니다.
  • 이 기기: GPU 재현이라 하지 않습니다.

5.2 CPU로 가능한 것

  • numpy toy(dust_toy.py): 추정기 식, cosine 법칙, γ의 편향-분산 교환을 확인했습니다(이 문서 §4의 C8, C9 근거).
  • 아주 작은 Transformer: 2층, 폭 64, 문맥 64 정도라면 CPU PyTorch로 Dust vs backprop을 몇백 step 돌릴 수 있습니다. torch 설치가 필요합니다.

                 Dust: 토큰마다 독립인 활성값 섭동 + 토큰 단위 보상 → "가상 population"
  • 가중치 공간 ES: population의 구성원마다 가중치 사본과 forward가 필요합니다. 그래서 population을 늘리는 비용이 큽니다. EGGROLL은 저랭크 섭동으로 사본 비용을 줄였지만, 구성원 하나가 배치의 한 시퀀스입니다.
  • node perturbation: 출력 차원(d_out)이 가중치 차원(d_out × d_in)보다 작다는 차원 논리가 근거입니다. Transformer에서는 토큰 T개 × d_out의 잡음이 가중치 수보다 많아서, 이 논리가 그대로 성립하지 않습니다(§2.1).
  • Dust의 관점 전환: 토큰 축을 배치 축과 직교하는 새 population 축으로 씁니다. 토큰마다 보상이 따로 있으므로, forward 한 번에 T개 구성원을 평가합니다.

4. 논문이 말하지 않은 관련 연구

  • REINFORCE / likelihood-ratio gradient: Eq. 2는 가우스 정책의 score function 추정기와 같은 꼴입니다. 분산을 줄이는 기법인 baseline, control variate, antithetic sampling은 그 문헌에 많이 있습니다. Dust는 묶음 평균만 baseline으로 씁니다.
  • SPSA, randomized smoothing: 유한 σ에서 추정하는 것은 실제 손실이 아니라 가우스로 평활화한 손실의 gradient입니다. 논문이 "backprop보다 낮아지는" 이유로 추측하는 "평평한 영역으로 끌리는 효과"는 이 평활화로 설명될 가능성이 있습니다(03 §6). 논문은 이 연결을 언급하지 않습니다.
  • noise injection 정규화(Gaussian noise, dropout): 학습 극초기(6–61 step)에 backprop보다 낮은 손실이 나오는 현상은, gradient의 질보다 잡음이 섞인 업데이트와 튜닝 차이의 영향일 수 있습니다.

5. 이 저장소의 다른 논문과의 관계

논문 관계
DDPG (ddpg/) 같은 "가우스 탐색 잡음 + 보상" 구조입니다. DDPG의 OU 잡음 분석(상관 시간, 정상 표준편차)이 Dust의 σ 선택과 대응합니다. Dust의 Eq. 2는 결정적 정책 gradient가 아니라 확률적 정책의 score function 추정에 해당합니다.
GQKAE (gqkae/) 미분하기 어려운 생성기(양자 회로)를 GRPO식 보상으로 학습합니다. Dust가 노리는 "미분 불가능한 구조 학습"의 한 사례입니다.
PINN 연구 전반 PINN의 잔차 손실은 자동미분이 전제입니다. 시뮬레이터나 접촉이 섞여 미분할 수 없는 물리 모듈이 루프에 들어가면, Dust식 활성값 섭동이 대안이 될 수 있습니다. 다만 연산량 문제가 있습니다(03 §2).
GPT-as-Tactile-Policy, AW-0 둘 다 외부 프로그램(LLM 도구 호출, Code-as-Policies)이 정책 루프에 들어갑니다. 저자들이 Dust로 학습하고 싶다고 한 "외부 프로그램이 루프에 있는 망"의 예입니다.
