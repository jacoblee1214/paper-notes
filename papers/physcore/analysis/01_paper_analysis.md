## 1. 문제와 주장

변형체(줄, 천, 찰흙 인형)는 같은 행동에도 재료 특성(탄성계수, 포아송 비, 소성)에 따라 다른 모양이 됩니다. 재료는 RGB-D로 직접 읽을 수 없습니다. 논문은 두 흐름을 나눠 설명합니다(§1, §2.1).

- **물리 기반**(PhysTwin, EMPM 등): MPM 같은 해석 시뮬레이터로 물리 구조는 지키지만, 재료를 객체마다 최적화로 맞춰야 해서 느리고 일반화되지 않습니다.
- **학습 기반**(GNN, 파티클 모델 등): 보정 없이 데이터로 예측하지만 데이터를 많이 먹고 분포 밖에서 약하며 물리 구조를 어깁니다.

PhysCoRe의 주장은 **미분 가능 MPM을 중심에 두고 학습 모듈 두 개를 붙이는 것**입니다.

1. **MfM** (Material from Motion): 관측된 짧은 움직임(10 프레임 창)에서 파티클별 `(log E, ν)`와 파티클별 신뢰도 `c_p`를 **한 번의 전방 계산**으로 냅니다. 객체별 최적화가 없습니다.
2. **RfD** (Residual from Dynamics): MLS-MPM 격자 속도에 **보정량 Δv_i**를 더합니다. 보정은 `δ_max · tanh(·)`로 제한되고, 출력층을 0으로 초기화해서 처음에는 MPM과 같습니다.

세 가지 기여 (§1 목록): MfM, RfD, 그리고 MfM 신뢰도가 변형이 큰 곳과 맞는다는 관찰(능동 탐색의 신호).

## 2. 방법

### 2.1 시뮬레이터 (§3, 부록 A, 표 6)

- MLS-MPM + APIC 전달, 입자 N개와 격자 G = 32 (∆x = 1/32).
- 고정 corotated 탄성(식 9) 또는 von Mises 소성 (MfM이 에피소드마다 한 분기를 고름, §4.2).
- 시간 적분: 서브스텝 ∆t = 6.66e-4 s, 카메라 프레임당 H = 50 서브스텝. 감쇠 α = 0.999, 밀도 100, 바닥 Coulomb 마찰 μ = 0.5, 반발 e = 0.
- 행동 시퀀스는 카메라 프레임 단위로 주어지고 Catmull–Rom으로 서브스텝 비율까지 보간 (§3).

### 2.2 MfM (§4.2.1, 부록 B)

- 입력: 정규 좌표(푸리에 4 밴드), 추적 점 변위(푸리에 16 밴드), 가시성 마스크, 제어점 블록(거리 가중 평균 위치와 변위, 가중치). 프레임 창 K = 10. 입력 차원 128.
- 백본: 그래프 U-Net (은닉 128, 4층, 이웃 k = 8, 증거 가중 메시지 식 10–11, a_t = 8, a_c = 4, r_c = 0.04 m), 이어서 깊이별 1D 합성곱(커널 9)과 GRU (상위 절반 층).
- 출력: 시그모이드로 범위를 제한한 `log E ∈ [5, 11]`, `ν ∈ [0.05, 0.45]`. 신뢰도는 `c = 1 + exp(r)` (축마다). 에피소드 단위 소성 확률 π도 같이 냅니다.
- 사전 학습 손실 (식 7): 신뢰도 가중 Smooth-L1 - λ log c + β·BCE(π). λ = 0.2, β = 0.1.

### 2.3 RfD (§4.2.2, 부록 C)

- 격자 노드마다 19차원 특징 (속도 3, log(1+질량), 응력 대칭 성분 6, MfM의 log E, ν, 신뢰도 2, 입자 속도 3, 접촉 지시자, 바닥 거리). 입자 값은 P2G 질량 가중 평균으로 격자에 옮깁니다 (식 13–14).
- 희소 3D U-Net (spconv, FiLM 조건 16차원, 식 15–16). 출력은 δ_max = 0.05 m/s로 제한된 `tanh`.
- 10 서브스텝마다 한 번 적용 (H_r = 10). BPTT는 세그먼트 단위로 끊습니다.

### 2.4 학습 (§4.2.3–4.2.4, 부록 D–E)

1. **재료 증강.** 실제 PhysTwin 에피소드 14개 (`LRM-Zero`식 증강). 공간 상관 Perlin 잡음 장으로 `log E`, `ν`를 만들고 평균과 표준편차를 에피소드마다 뽑습니다 (식 6). 실제 제어 궤적으로 MPM을 다시 굴리고 카메라 시점에서 다시 렌더링합니다. 증강 1,120개.
2. **MfM 사전 학습**: 증강 데이터의 정답 재료로 식 7을 최적화 (2000 에포크, 배치 4, 같은 소스끼리 묶음, 학습률 1e-4, 가중치 감쇠 0.01).
3. **RfD 학습**: MfM을 고정하고 실제 에피소드의 **앞 절반**으로 학습. MfM이 앞 절반으로 재료를 추정하고 그 값을 고정한 뒤, 같은 구간을 MPM으로 굴리며 식 8로 손실을 계산합니다 (편측 Chamfer + 가시 추적점 L2, w_C = w_L2 = 1).

## 3. 실험

### 3.1 설정 (§5.1)

- **실제 데이터 12개 에피소드**: 사람 손으로 조작. 탄성 (줄, 수건, 봉제 곰 인형)과 탄소성 (플레이도 찰흙). RealSense D455 3대, CoTracker3와 Grounded-SAM2로 추적과 마스크.
- 학습과 시간 측정은 **RTX 5090 1장**.
- 비교: PhysTwin [2], PGND [5]. EMPM [6]은 코드가 없어 표 1의 기능 비교에만 나옵니다.
- 로봇 실험: KUKA 팔과 Robotiq Hand-E (§5.5, §5.6).

### 3.2 미래 예측 (§5.2, 표 2)

식별 창은 에피소드 앞 절반, 나머지를 고정된 재료로 예측합니다. 지표는 CD, 추적 손실, IoU, PSNR, SSIM, LPIPS입니다. 표 값은 `02`와 `03`에서 다시 계산했습니다.

- PhysCoRe는 PhysTwin 대비 CD를 탄성 **43.7%**, 탄소성 **30.5%** 줄입니다. 추적 손실은 15.2%, 8.3%.
- 탄성 객체에서 **IoU (70.5 → 68.2)와 SSIM (0.309 → 0.302)은 PhysTwin이 더 높습니다.** 논문은 "competitive"라고 적었습니다.
- 식별 시간: PhysCoRe 11.4 s, PhysTwin 930.0 s, PGND 8280.0 s (표 5).

### 3.3 절제 (§5.3, 표 3)

RfD를 넣으면 CD가 탄성 13.1%, 탄소성 17.8% 줄어듭니다. 표 3의 MfM+RfD 행은 표 2의 PhysCoRe 행과 같습니다.

### 3.4 신뢰도 (§5.4–5.5, 그림 3–4)

신뢰도 맵이 관측된 변형 영역에 모인다는 것을 **그림으로만** 보였습니다. 정량 지표(상관, 영역별 변형량과의 관계)는 없습니다.

### 3.5 계획 (§5.6, 표 4, 그림 5)

KUKA 팔에서 밧줄 S자 모양과 수건 대각선 접기, 두 과제. 계획자는 기울기 기반이고, 기저 동역학만 PhysCoRe, PhysTwin, PGND로 바꿉니다. 결과: 밧줄 6.2 mm (PhysTwin 17.3, PGND 48.8), 수건 5.3 mm (7.1, 30.6). 반복 횟수와 분산은 없습니다.

### 3.6 표 1 (기능 비교)

PhysCoRe만 네 칸(시뮬레이션, 온라인 정제, 전방 추론, 일반화)을 모두 채웁니다. 이 표는 기능의 유무를 적은 것이고, 성능 근거가 아닙니다.

## 4. 한계 (§7, 원문)

- 탄성과 탄소성만 다룹니다. 찢김, 절단, 접착, 유체형 운동, 복잡한 접촉은 범위 밖입니다.
- 평가는 **같은 범주 안의 객체**에만 했습니다. 범주 수준의 제로샷 전이는 시험하지 않았습니다.
- RfD는 제한된 객체로 학습했고, 더 넓은 동역학 분포로의 확장은 확인하지 않았습니다.
