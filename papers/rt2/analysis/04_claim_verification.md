# 04. 주장 대조 (공식 코드 없음)

RT-2에는 공식 코드와 가중치가 공개되어 있지 않습니다(02 §2). 그래서 코드 대조(D 번호) 대신 **본문 주장을 보고 수치와 대조**했습니다(C 번호). 수치 계산은 `03_analysis.md`(V 번호)에 있고, 여기서는 주장마다 판정만 적습니다.

판정 기호: **일치** (수치로 확인), **부분** (방향은 맞지만 정도나 범위가 다름), **약함** (검정이나 근거가 부족), **확인 불가** (필요한 자료가 논문에 없음), **불일치** (표나 본문끼리 다름).

## 2. 본문 안의 불일치와 정리 필요 항목

1. **표 4와 표 6의 같은 모델이 62와 63으로 다름** (C22). 셀 값은 같습니다. 반올림 관례도 MOO(34.5 → 35)와 PaLM-E(62.5 → 62)에서 다릅니다.
2. **"2–3배"(부록 H.2)와 "3배 넘게"(§4.2)** (C4, C5). 두 문장이 같은 결과를 다르게 말합니다.
3. **"over 280 tasks"** (C9)와 표 2의 지시문 수(138)가 맞지 않습니다. 셀 시행 수를 밝혀야 합니다.
4. **Language-Table의 "significant"** (C11)는 검정이 없습니다.
5. **표 1 ±의 뜻**이 없습니다(표준편차, 표준오차, 실행 간 범위 등).
6. **창발 평균 정의**(C21): 단순 평균이라는 설명이 없습니다.

## 3. 논문이 밝히지 않은 한계

- 셀 시행 수, 원시 성공·실패, 지시문별 결과가 없습니다. 모든 구간 추정이 가정에 의존합니다.
- 평가 판정 기준(자동 또는 사람), 맹검 여부, 평가자 수가 없습니다.
- 하드웨어 한 종류(7자유도 모바일 매니퓰레이터)와 사무실 한 곳입니다. 외부 타당성 근거가 없습니다.
- 사전학습 데이터(WebLI)와 평가 장면의 중복 검사가 없습니다.

## 4. 구현할 수 있는지 (판정)

**질문:** 이 맥(Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)에서 RT-2 결과를 재현하거나 같은 방법을 구현할 수 있는가?

| 작업 | 판정 | 근거 |
|---|---|---|
| RT-2 자체 (PaLI-X 5B·55B, PaLM-E 12B) 추론 | **불가** | 가중치 비공개, 55B는 TPU 클라우드 전제(§3.3) |
| RT-2 자체 학습 | **불가** | 공식 코드, 데이터 파이프라인, TPU 학습 설정(부록 E) 중 공개된 것이 없음. 학습은 8만~100만 스텝 (부록 E) |
| 표 재계산과 검정 | **완료** | 03 |
| 행동 토큰화 왕복 (256 구간, 8 정수 문자열) | **가능** (CPU, 설치 승인 후) | numpy와 토크나이저만 필요. 몇 분 |
| 출력 제약 (행동 토큰만 샘플링) 구현 | **가능** (CPU, 소형 LM에서) | 로짓 마스크 한 줄 수준. 설치 승인 필요 |
| 소형 공개 VLM (1B 이하)에 같은 토큰화 씌우고 추론 지연 측정 | **조건부** (MPS) | 맥 메모리에는 들어가지만 측정 전. 승인 필요 |
| 소형 공개 VLM으로 공동 미세조정 (로봇 데이터 + VQA) | **조건부** (GPU 권장) | 학습은 RTX급 이상 GPU가 필요. 이번 분석에서는 GPU 재현을 하지 않음 |
| Language-Table 시뮬 평가 | **조건부** (설치 승인과 학습 필요) | 환경 설치와 학습이 필요 |
| 평가 설계 (셀 크기, 검정력, 구간) | **가능** (CPU) | 일반 통계 |

**판정 요약:** 논문의 **결과**는 맥에서 재현할 수 없습니다. 논문의 **방법**(행동을 VLM 어휘의 구간 토큰으로 쓰고, 웹 VQA와 로봇 데이터를 함께 학습하는 것)은 소형 공개 VLM으로 구현할 수 있지만, 학습은 GPU가 필요합니다.

**노력 추정 (추정치, 측정 안 함):**
- 토큰화와 출력 제약, 데이터 변환: 2–3일 (CPU).
- 소형 공개 VLM 한 개에 방법을 붙이고 추론 지연을 맥에서 측정: 1주 (추정).
- 공동 미세조정 한 설정 (GPU 1장): 수일에서 1–2주 (추정, GPU 종류와 데이터 크기에 따라 다름).
- 합계: 수 주 (GPU 접근 전제). 대형 모델 수준(55B)의 재현은 이 맥과 GPU 한 장으로는 불가.
