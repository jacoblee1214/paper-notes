# TacSL 선행연구와 관련 저장소 (02)

## 1. 계보: 촉각 시뮬레이션과 촉각 정책 학습

논문은 두 문제를 나눕니다. 하나는 **촉각 신호 생성**(접촉 물리와 영상 렌더링)이고, 다른 하나는 **촉각 정책 학습**입니다. 각각의 선행연구는 다음과 같습니다.

**접촉 물리 (논문 §II-A)**
- 유한요소(FEM)가 금 표준이지만 느립니다 ([26], [27], [17]).
- 강체 근사 접근은 접촉력에서 관통 깊이를 추정합니다 ([19] Tacto).
- 연성 접촉 모델은 강체끼리 관통을 허용합니다 ([16], [35]). 논문의 출발점입니다.
- 가장 가까운 GPU 대안: 논문이 정면 비교하는 [16] Xu et al. (CoRL 2023, 힘장, CPU 직렬). 이 논문은 [16]을 "원시 도형만 다룬다"고 대비합니다.
- FEM 기반 센서 물리 엔진 [34] (Chen et al., IEEE T-RO 2024): 논문은 "느린 복잡 강체"와 "범용 시뮬레이터 통합 부족"을 한계로 듭니다.

**촉각 영상 렌더링 (§II-A)**
- 깊이 영상을 RGB로 바꾸는 방식이 주류입니다. Taxim [18] (RA-L 2022, 보정된 룩업 테이블)이 논문의 기준선입니다. 이 방법은 CPU 한 코어에서 7.28 FPS입니다.
- 다른 방식: 조명 모델 [37], 학습 생성 모델 (GAN [38], [39], 확산 [40]).

**촉각 정책 학습 (§II-B)**
- 대부분 지도 학습입니다 (데이터셋을 만든 뒤 학습). 온라인 RL은 드뭅니다 ([16], [36], [44]).
- 온라인 촉각 RL로 실로봇 전이를 보인 예: 스윙업 [44] (Bi et al., RA-L 2021), 페그 삽입 [16], 비잡기 조작 [36] (Church et al., CoRL 2022).
- 두 단계 교사-학생 증류: 보행 로봇 [21] (Hwangbo et al.), 손안 재배치 [22] (Chen et al., CoRL 2022). 온라인 증류 DAgger [55], 증류 일반론 [56], [57].
- 비대칭 액터-크리틱 [59] (Pinto et al., 2017)이 AAC의 기반입니다. PPO [58]가 교사 RL의 기본입니다.
- 조립 과제 시뮬레이션 기반: Factory [52] (RSS 2022), IndustReal [62] (RSS 2023), AutoMate [61]. 논문의 삽입과 배치 과제는 이 계열과 맞닿아 있습니다.
- 동시 연구: 촉각과 제3자 카메라를 함께 쓰는 손안 회전 [45] (Qi et al. 2023, arXiv). 논문은 이것이 접촉 위치만 쓴다고 구분합니다.

**정리:** 이 논문의 기여는 새 물리 식보다 **두 시스템의 통합**입니다. 하나는 GPU 물리 엔진에서 접촉 힘과 촉각 영상을 같이 만드는 것이고, 다른 하나는 온라인 증류와 AACD를 같은 도구 안에 넣는 것입니다. 두 기여 모두 공식 코드 공개 상태가 불완전합니다 (`04` D1, D5).

## 2. 가까운 대안과 현재 상태

| 대안 | 성격 | 이 논문과의 관계 |
|---|---|---|
| Taxim [18] | CPU 영상 렌더링 | 이 논문의 영상 단계가 같은 룩업 테이블을 씀 (GPU 병렬화) |
| [16] Xu et al. 2023 | 힘장, CPU 직렬 | 힘장 기준선. 이 논문의 힘장 식을 대부분 따름 |
| Isaac Lab TacSL 센서 (NVIDIA, 공식 문서 Release 3.0) | 같은 접촉 식과 같은 상수(k_n=1, µ=2, k_t=0.1)의 후속 구현, 실험적 기능, PhysX 백엔드 | 공식 후속. 이 맥에서 실행 불가 (`04` §4) |
| Isaac Gym TacSL (IsaacGymEnvs `tacsl`) | 논문의 공식 코드, 지원 중단 | 논문이 재현되는 유일한 공개 코드 (독점 조건 파일 포함, `04` §1) |
| UniVTAC (CoRL 2026 포스터) | Isaac Sim 기반 촉각 시뮬레이션 플랫폼 | 같은 문제를 다른 엔진으로 풂 |
| MuJoCo, PyBullet 등 범용 시뮬레이터 | 촉각 모듈 없음 | 논문 서론 [13]–[15] |

**참고:** 같은 상수와 같은 식을 쓰는 Isaac Lab 버전은 감쇠 항(k_d)을 뺍니다. 논문 식 (f_n의 k_d ḋ)과 다르고, 공식 IsaacGymEnvs 코드도 같습니다(`04` D2).
