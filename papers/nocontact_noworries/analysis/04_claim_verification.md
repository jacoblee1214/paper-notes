추가로 확인한 항목:
- **"F1은 시간 단계마다 계산해 접촉 지점 평균"(Sec. V-B):** 지점별 F1과 지점별 접촉 비율이 없습니다. 접촉 비율이 지점마다 다르면 평균 F1은 해석이 어려워집니다.
- **"held-out policies에 일반화"(Sec. VI):** 평가 분할은 정책 분리(policy-disjoint)입니다. 그러나 보고된 분할이 검증 세트(validation)로 불리고, 별도 테스트 세트가 없습니다. 모델 선택에 같은 세트를 썼는지 불명입니다.
- **실물 Oracle이 어려운 물체(Star, R)에서 유리하다(Sec. V-C):** 방향은 맞습니다(Star 14.95 대 14.37, R 15.39 대 15.12). 그러나 차이는 검출력 밖입니다.

## 4. 구현 가능성 판단

**질문:** 이 논문을 구현할 수 있는가? (1) 공식 재현, (2) 이 맥에서의 실행, (3) 아이디어 재구현의 노력, (4) 필요한 하드웨어.

**맥 사양:** Apple M4 Pro, 통합 메모리 약 24 GiB, MPS 사용 가능, CUDA 없음, torch 미설치(이 작업에서는 설치하지 않음).

### 4.1 공식 재현: **불가**

- 코드, 학습 데이터, 체크포인트 모두 공개되지 않았습니다(§0).
- 학습 데이터는 Isaac Gym 시뮬레이터(LEAP Hand, NVIDIA GPU 필요)에서 만듭니다. 정책은 PPO로 같은 시뮬레이터에서 학습합니다.
- 실물 평가는 LEAP Hand, Intel RealSense D455, 맞춤 FSR 센서가 필요합니다.

### 4.2 이 맥에서 실행: **부분 가능**

| 구성 요소 | 맥에서 가능? | 이유 |
|---|---|---|
| 시뮬레이션 데이터 생성 (Isaac Gym, LEAP) | **불가** | Isaac Gym은 NVIDIA GPU를 전제로 함. CUDA 없음 |
| 정책 학습 (GRU PPO) | **불가** | 위와 같음 |
| 인코더 AsymFormer 추론 | 가능 (추정) | 공개 저장소 Fourier7754/AsymFormer(Apache-2.0)가 있으나 가중치 출처와 동작은 확인하지 않음 |
| 접촉 헤드 (교차 어텐션 + 인과 transformer, 1층 256차원) 학습 | 가능 (추정) | 작은 모델. 데이터만 있으면 MPS나 CPU로 학습 가능. 수 시간 규모로 추정(확인 안 함) |
| 실물 데모 | **불가** | 하드웨어 없음 |
| 감각·제어 toy | **가능 (완료)** | `03_analysis.md` §6, numpy로 실행 |

### 4.3 아이디어 재구현 노력

- **모델 구조:** 교차 어텐션 두 질의(현재·명령 자세), 연결 후 MLP, 인과 transformer 창 8, 접촉 머리의 sigmoid. PyTorch로 수백 줄 안쪽으로 가능합니다(추정). 쉬운 편입니다.
- **학습 데이터:** 병목입니다. 공개 손-물체 접촉 데이터가 RGB-D와 관절 명령을 함께 제공하는지 아직 확인하지 않았습니다. 없으면 시뮬레이터(CUDA)나 실물 LEAP Hand가 필요합니다.
- **정책 통합:** 시뮬레이터에서 RL을 다시 돌려야 합니다. 맥에서는 불가입니다.
- **평가 설계:** 가림 조건별 AUC, 접촉 비율 보고, 속도 결합 대조는 맥에서도 할 수 있습니다. 논문에 없는 항목이라 재구현 시 먼저 추가해야 합니다.

### 4.4 필요한 자원

| 목적 | 필요 |
|---|---|
| 접촉 헤드만 (공개 데이터 있을 때) | 맥 MPS 또는 CPU, RGB-D·관절 데이터 |
| 논문 규모 재현 | NVIDIA GPU(Isaac Gym), LEAP Hand, RealSense, FSR 센서 |
| downstream 정책 | 위와 같음 + RL 학습 시간 |

### 4.5 판정

- **공식 재현:** 불가 (코드·데이터 없음, 시뮬레이터·하드웨어 필요).
- **이 맥에서 논문 재현:** 불가 (CUDA 시뮬레이터, 실물 하드웨어).
- **아이디어 재구현:** 모델 구조는 쉬움. 데이터 확보가 어려움. 평가와 검정은 논문보다 엄격하게 다시 설계해야 함.
- **구현할 수 있는가:** 예. 다만 "접촉 헤드 + 가림 인식 평가" 수준까지만이고, 논문의 downstream 결과는 CUDA 시뮬레이터와 LEAP Hand 없이는 재현할 수 없습니다.
