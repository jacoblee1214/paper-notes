|---|---|---|---|---|

| all-fast | LA w=1 | 67.33 | 67.3 | 202 |
| one-fast | EDF | 83.00 | 83.0 | 11 + 238 = 249 |
| one-fast | RR | 83.33 | 83.3 | 6 + 244 = 250 |

### V4. 유의성

(a) **Poisson 정확 검정**(총 조각 수가 독립 Poisson이고 노출이 같다고 가정. 시드 간 변동을 무시하므로 p가 작게 나오는 낙관적 방향입니다).

| 비교 | 조각 수 | 비 | p |
|---|---|---|---|
| one-fast 총량 LA@5 대 EDF | 296 대 249 | 1.19 | **0.049** |
| one-fast 총량 LA@5 대 RR | 296 대 250 | 1.18 | 0.054 |
| one-fast 총량 LA@5 대 LA@1 | 296 대 277 | 1.07 | 0.45 |
| one-fast 총량 LA@1 대 EDF | 277 대 249 | 1.11 | 0.24 |
| all-fast 총량 LA@1 대 EDF / RR | 202 대 188 / 180 | 1.07 / 1.12 | 0.51 / 0.28 |
| half-fast 총량 LA@5 대 EDF | 190 대 188 | 1.01 | 0.96 |
| one-fast **빠른 로봇 한 대** LA@5 대 EDF / RR | 25 대 11 / 6 | 2.3 / 4.2 | 0.029 / 0.0009 |
| half-fast **빠른 계층** LA@5 대 EDF | 92 대 47 | 1.96 | **0.0002** |
| half-fast **느린 계층** LA@5 대 EDF | 98 대 141 | 0.69 | **0.0065** |

(b) **그림 4 오차 막대로 Welch 검정**(n = 3, 막대가 SD, SEM, 95% CI라는 세 가정).

| 비교 | SD라면 p | SEM이라면 p | 95% CI라면 p |
|---|---|---|---|
| one-fast LA@5 대 EDF | 0.028 | 0.099 | 0.0025 |
| one-fast LA@5 대 RR | 0.061 | 0.20 | 0.0036 |
| all-fast LA@1 대 EDF | 0.50 | 0.69 | 0.14 |
| all-fast LA@1 대 RR | 0.20 | 0.43 | 0.021 |
| half-fast LA@5 대 EDF | 0.91 | 0.95 | 0.79 |

해석:
- **"이질 구성에서 빠른 계층과 느린 계층의 몫을 바꾼다"는 주장은 지지됩니다**(half-fast 계층 재분배 p = 0.0002, 0.0065. one-fast 빠른 로봇 p ≤ 0.03).
- **"총 처리량을 +18% 올린다"는 경계입니다.** 가장 호의적인 가정(SD 또는 시드 간 변동 무시)에서 p ≈ 0.03–0.05, SEM이면 0.10이며, 한 칸을 고른 뒤의 p이므로 3개 구성 × 2개 가중치를 보정하면 유의하지 않습니다. all-fast의 +7%(LA@1)는 어느 가정에서도 유의하지 않거나 RR에 대해서만 CI 가정에서 유의합니다.
- 오차 막대가 무엇인지 캡션에 쓰이지 않은 것이 이 평가의 가장 큰 공백입니다.

## 2. 시뮬레이션과 부록 표

### V5. 표 4: 잡음 크기와 "총 처리량이 비슷하다"는 문장

**가중치 불변 구성으로 잡음을 잽니다.** all-fast에서는 모든 로봇이 같은 계층이라 LA@1, LA@3, LA@5는 모든 점수에 같은 상수를 곱한 것과 같아 같은 알고리즘입니다(`04` D4의 후보 생성과 점수 계산 참고). 따라서 표 4의 all-fast 세 값의 차이는 실행 간 잡음입니다. N별 처리량 SD는 0.24–0.51 (상대 1.1–3.7%, 합동 상대 SD **2.4%**), 기아율 SD는 0–0.1 %p입니다.

잡음을 기준으로 표 4의 총 처리량을 기준선(RR, EDF 평균) 대비 보면(`own_sim_tradeoff.png`):
- **LA@1은 모든 칸이 잡음 범위 안**(−4.6%–+3.8%)입니다.
- **LA@3도 대체로 잡음 범위 안**입니다(half-fast N = 4에서 +6.0%, z = 1.8).
- **LA@5는 half-fast에서 크게 떨어집니다.** N = 4에서 −17.7%(z = −5.3), N = 8에서 −12.4%(z = −3.7), **N = 10에서 −41%**(z = −12, 처리량 35.9 → 20.8, 기아 48.3%). one-fast N = 10에서는 −5.7%(z = −1.7).
- 따라서 부록 A.7의 "b = 3에서 모든 스케줄러가 총 처리량과 기아율이 비슷하다"는 문장은 **LA@5 half-fast에서 맞지 않습니다.** 본문 §4.2가 "LA@5가 트레이드오프의 경계를 보여 준다"고 쓴 것과는 일치합니다.
- **시뮬레이션에는 총 처리량 이득이 없습니다.** 초록의 "최대 18%"는 실로봇 한 칸의 값이며, 같은 구성(one-fast)의 시뮬 LA@5는 N = 6–10에서 총량이 −4%–−6%입니다(N = 2는 −7%, N = 4는 0%). 부록 A.7도 "핵심 기여는 총량이 아니라 계층 간 재분배"라고 씁니다.
- 처리량과 기아율의 칸 안 순위 상관(14칸): 평균 Spearman ρ = −0.34이고 78.6%의 칸에서 음의 상관입니다. "기아가 적을수록 처리량이 높다"는 방향은 일관되지만 약합니다(처리량은 기아 외에도 정책 품질을 반영합니다).

### V6. 표 3(L 절제)과 표 4의 정합

- 45개 칸(구성 3 × N 5 × 가중치 3) 중 **31개(68.9%)에서 L = 3의 기아율이 L = 1보다 큽니다.** 평균 차이 +0.75 %p(N ≥ 6에서 +1.35 %p). all-fast N = 10에서는 +1.5, +1.6, +1.2 %p입니다. "L이 커지면 기아가 약간 늘어난다"는 서술과 일치합니다.
- 그러나 같은 설정(L = 1, 같은 구성·N·가중치)의 기아율이 **표 3과 표 4에서 다릅니다.** 평균 절대 차이 0.48 %p, 최대 1.9 %p(half-fast N = 4, LA@5: 표 3 19.5 대 표 4 21.4). 이 차이는 L 효과(평균 0.75 %p)와 같은 크기입니다. 두 표는 서로 다른 실행 묶음으로 보입니다. L 효과를 잡음과 분리하려면 반복 실행이 필요합니다.

### V10. 식 10, 13의 L = 1 퇴화

식 10의 보상은 한 에폭 [t_k, t_{k+1}] 동안의 **모든 로봇**의 비기아 스텝 가중 합이고, 새 청크는 t_{k+1} + d̃_action에 도착합니다(식 6, 7). 그러면 에폭 안의 실행은 이미 도착한 청크로만 결정되어 **배치의 구성에 의존하지 않고, 배치 크기(에폭 길이)에만 의존**합니다. L = 1이면 식 13은 어떤 로봇을 고르는지와 무관한 점수가 됩니다. 반면 실험(§4.1)은 L = 1이 "이질성 인식 스케줄링에 충분"하다고 하고, 가중치 w_j가 서비스 순서를 바꿉니다. 이 모순은 부록 A.1의 "1초 창 안의 총 실행 로봇 시간" 서술과 코드(`04` D2)가 풀어 줍니다. 실제 점수는 한 에폭이 아니라 1초 창에서 새 청크가 만드는 실행 스텝을 세기 때문입니다. **식 10, 13은 구현된 알고리즘의 형식적 설명으로 부적절합니다.**

### V11. 요약과 부록의 일관성

- 초록 "improves overall system throughput by up to 18% in real-world experiments"(§1, 결론 §6 "up to 18% in the real world")는 정확히는 실로봇 one-fast 한 칸입니다. 시뮬은 그렇지 않고(V5), 부록 A.7이 이를 인정합니다.
- 결론의 "simple schedulers like RR and EDF perform comparably to more sophisticated alternatives (homogeneous)"는 표 4·5로 지지됩니다(V5, V3).
- "LA는 모든 설정에서 지배하지 않는다"는 §4.2 마지막 문단은 정직한 표현이며 표 4와 맞습니다.

## 3. 토이 시뮬레이터 TS (독립 재구현)

논문의 거울 모델(§3.1, 식 6–9, 부록 A.1, A.9)과 표 1의 지연 표로 **폐루프 큐 모델**을 numpy로 다시 짰습니다(`toy_mirror_sim.py`, 약 15초, 단일 프로세스). 로봇은 f_c로 행동을 소모하고, GPU는 한 번에 한 배치를 처리하며, 청크는 배치 완료 + 네트워크(편도 5 ms) 후 도착해 인덱스 ≥ 시작을 덮어씁니다. 정책과 과제 성공은 모델링하지 않으므로 **기아율과 실행 스텝률만** 비교합니다. 공식 코드를 실행하거나 가져오지 않았습니다.

**TS-1. 기준선과 LA@1은 표 4를 잘 재현합니다.** 15개 설정(3 구성 × N = 2..10)의 평균 기아율의 평균 절대 오차(MAE): RR 1.1 %p, EDF 1.4 %p, LA@1 1.6–1.8 %p(`own_toy_vs_paper.png`). all-fast N = 10에서 토이는 RR 39.6, EDF·LA 38.1(논문 38.2, 37.4, 37.6). 즉 **표 1의 지연 곡선과 "청크 H_max개, 도착 시 덮어쓰기" 모델만으로 표 4의 기아율이 설명됩니다.** 이는 논문의 거울 모델 서술이 일관적이라는 간접 증거입니다.

**TS-2. LA는 작은 배치(중앙값 3)를 고릅니다.** all-fast N = 10, 상한 10에서 LA의 배치 크기 평균 3.38, 중앙값 3(논문 그림 7: 평균 3.3, 중앙값 3). 상한을 키우면 EDF·RR 기아율이 38 → 60%로 오르고 LA는 36–38%로 평평합니다(논문 그림 7과 같은 형태). 다만 토이의 EDF·RR 평균 배치 크기는 10(논문 4.6–4.7): 토이는 모든 로봇을 후보로 보고, 실제 시스템은 H_min 미달·중복 요청을 뺍니다(`04` D5). 시드 잡음(10시드 SD)은 실행 스텝률의 0.3%였습니다.

**TS-3. 가중 Lookahead는 "보상 읽기"에 민감합니다.** 가중 LA(w = 3, 5)의 점수를 두 방식으로 구현했습니다.
- **읽기 A(코드의 문자적 읽기, `04` D2):** 1초 창에서 **후보 청크가 만드는 실행 스텝만** 센다. 이 경우 w = 5에서 빠른 로봇이 항상 우선이라 **느린 계층이 완전히 굶습니다**(one-fast N = 10 기아 90%, half-fast 59%). 논문 표 4(21.4%, 48.3%)와 크게 어긋납니다(MAE 32 %p).
- **읽기 B(한계 이득):** 후보 청크가 **서빙하지 않았을 때보다 늘리는** 1초 창 실행 스텝(가중 합)을 GPU 시간으로 나눔. 이 경우 LA@3은 MAE 1.6 %p, LA@5는 4.0 %p로 표 4와 맞고, 계층 간 트레이드오프(one-fast N = 10 기아 20.3% 대 논문 21.4%, half-fast LA@3 33.3% 대 30.0%)를 재현합니다. LA@5 half-fast N = 10은 토이 58.6% 대 논문 48.3%로 과대합니다.
- 결론: **논문 결과는 한계 이득 형태의 점수와 맞고, 내가 읽은 코드의 보상 산식(후보 청크 보상만)과는 맞지 않습니다.** 읽기 오류일 수도 있고 코드가 실험 당시와 다를 수도 있습니다. 실행해 확인해야 합니다(`04` D2).

**TS-4. 후보 8개 절단(`step_budget_nodes = 8`)의 영향은 작거나 불명확합니다.** 후보 배치가 8개를 넘는 경우(두 계층, b = 5)만 해당합니다. 토이에서 half-fast N = 10 LA@5(b = 5) 읽기 B는 평균 배치가 4.7 대 2.0(절단)으로 바뀌고 계층 기아가 바뀌지만, 결과가 이미 한쪽 계층 굶김이라 결론이 약합니다. 이 항목은 "정적 읽기에서 의심되는 차이"로만 남깁니다.
