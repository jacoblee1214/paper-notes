## 1. 한 줄 요약

언어 지시, 여러 시점 RGB, 물체 점군에서 **기능에 맞는 손 자세를 한 번의 생성으로** 만든다. 데이터는 대규모 자동 합성(OpenDex-Scale)과 소규모 텔레오퍼레이션·범주 전이(OpenDex-Align)를 **Coverage-to-Alignment**(C2A) 순서로 쓴다. 모델은 Qwen3-VL-4B 특징과 PointNet++ 점군 토큰을 받아 흐름 매칭 액션 헤드가 손목과 관절을 만들고, 점 단위 affordance 손실이 같은 잠재 표현을 보조로 지도한다.

## 2. 문제와 동기

- 기존 기능 파지는 보통 **affordance 예측 → 자세 최적화**의 두 단계입니다. 두 번째 단계가 느리고, 첫 단계의 오류가 그대로 넘어갑니다(§1, §2).
- 저자의 핵심 관점은 affordance와 파지 자세를 **한 잠재 상태 z의 두 관측**으로 보는 것입니다(§3, 식 두 번째). affordance는 해석을 위한 지도 신호이고, 추론에서는 affordance를 입력으로 쓰지 않습니다(§5.4, 부록 D.2).
- 데이터 측면에서는 최적화 기반 합성은 양이 많지만 기능 접촉이 거칠고, 사람 시연은 품질이 좋지만 비쌉니다. 그래서 두 원천을 순서대로 씁니다(§1, §4.1).

## 3. 방법

### 3.1 입력과 출력

- 입력: 다시점 RGB 세 장(`Input views 3`, 표 5), 언어 지시 u, 점군 P (2,048점, 색 포함, 미터 좌표 유지).
- 출력: 자세 a = [p, r6D, q] (손목 이동 3, 6D 회전 6, 관절 22, 합계 31차원, 표 5). 행동 지평은 1(한 번에 한 자세, 표 5).

### 3.2 구성

| 구성 요소 | 내용 | 출처 |
|---|---|---|
| 의미 인코더 | Qwen3-VL-4B-Instruct, 선택한 은닉 상태 18개 사용, FlashAttention-2, bf16 | §5.2, 부록 A.1, 표 5 |
| 기하 인코더 | PointNet++ 계층 추상화 → 전역 점 토큰 1024차원 | §5.2, 부록 A.1 |
| 액션 헤드 | DiT 18블록, hidden 1024, 어텐션 16, 짝수 블록은 Qwen 은닉과 교차 어텐션, 홀수 블록은 인과 자기 어텐션 | 부록 A.1 |
| 학습 목표 | 흐름 매칭. x_t = (1−t)a_0 + t·a_1, 목표 속도 a_1 − a_0, 시간 분포 Beta(2, 1) | §5.3, 부록 A.1 |
| 추론 | 가우시안 노이즈에서 32 스텝 오일러 적분 | 표 5, 부록 D.1 |
| affordance 보조 | 전역 점 토큰이 Qwen 은닉에 교차 어텐션하고, 점마다 점수를 냄. 손실은 focal + Dice, λ_aff = 0.3 | §5.4, 부록 A.1 |

핵심 설계는 **추론 시 affordance 맵을 입력으로 쓰지 않는다**는 점입니다. 보조 손실이 잠재 표현을 기능 영역으로 당기는 효과만 남깁니다. 이것이 논문의 "affordance-to-pose 단계 없음" 주장의 실체입니다.

### 3.3 학습 설정 (표 5)

- 최적화 2M 스텝(v4), 웜업 1k, 최소 학습률 3e-7, GPU당 배치 16, 기울기 누적 1, AdamW (0.9, 0.999), 가중치 감쇠 1e-4.
- 학습률은 모듈별로 다름: Qwen 인터페이스 5e-7, 나머지 3e-5.
- 가속 방식: Accelerate와 DeepSpeed ZeRO-2, bf16.
- **GPU 수는 논문에 없습니다.** 총 학습 비용을 알 수 없습니다(`04` §4).

## 4. 데이터: OpenDexVerse와 C2A

| 부분집합 | 원천 | 범주 | 쌍 | 자세 수 | 기능 비율 |
|---|---|---|---|---|---|
| OpenDex-Scale | BODex 합성 + VLM(GPT) 주석 | 105 | 185 | 1.24M | 44.93% (557.18k) |
| OpenDex-Align | 텔레오퍼레이션(Manus 장갑) 1,590 + 범주 전이(OakInk 방식) 25,835 | 95 | 159 | 27.42k | 68.02% (18.65k) |

- 물체 원천은 Omni6DPose(153범주, 4,302인스턴스, 부록 B.1). 파지 가능한 범주 105개를 골랐고 크기로 나눠 쌍을 만듭니다.
- 주석(부록 B.3)은 각 자세를 **여섯 장의 렌더링과 접촉 정보**(어느 손 링크가 어느 물체 부분에 몇 % 닿는지)로 GPT에 보내 기능 여부, 설명 5개, 과제 지시 5개를 JSON으로 받습니다. 프롬프트 전문이 부록에 있어 재현 가능성이 높습니다. 다만 GPT 버전과 샘플링 설정은 적혀 있지 않습니다.
- 전이(부록 B.2)는 범주별 DeepSDF 형상 공간에서 보간하고 접촉을 옮긴 뒤, SAPIEN에서 300 스텝 시뮬레이션으로 관통을 줄입니다. 8단계 절차가 자세히 적혀 있습니다.
- 데이터 공개는 논문에 언급이 없고, 공식 저장소도 비어 있습니다(`02` §4).

## 5. 실험

### 5.1 설정

- 기준선은 **DexGraspNet 2.0⋆** 하나입니다. DexGraspNet 2.0에 CLIP 텍스트 특징을 붙여 같은 데이터와 분할로 학습했습니다(§6.1, 부록 C.3). 저자는 "이 설정의 공개 방법이 없다"고 씁니다.
- 분할: 기능과 비기능 각각에 seen과 unseen. 표 6 기준으로 기능-seen 25범주(75 인스턴스), 기능-unseen 5범주(15), 비기능-seen 46범주(138), 비기능-unseen 5범주(15), 합계 243 인스턴스.
- 시뮬 지표: SIV, PD, SD, SR (MuJoCo, 손 고정, 2초), Style Diversity, 인지 점수 (GPT-5, 인간).

### 5.4 실로봇 (표 4, 그림 5, 10)

- 로봇: Sharpa Wave Hand 5지 손, Franka Panda, RealSense D435 (부록 C.4).
- 객체 10개(seen 5, unseen 5), 객체당 예측 자세 10개를 한 번씩 실행.
- 결과: SR Ours 72.0% 대 기준선 59.0%, GPT-5 7.5 대 6.7, 인간 7.7 대 6.5.
- 객체 단위로는 SR 8승 2무 0패, 인지 점수는 9승 1패입니다(`03` §2). 시도 단위 Fisher 검정은 p = 0.074입니다.
- 방법의 한계: 테이블과 충돌하거나 가려지는 자세는 사람이 버렸습니다. 위험한 객체는 시험에서 뺐습니다(부록 C.4).

### 5.5 추가 실험 (부록 D)

- **직접 생성 대 최적화** (표 7): 최적화 변형 SR 49.15%, Ours 71.65%. 시간은 2.84 s 대 0.93 s입니다. 기준선과의 시간 비교는 없습니다.
- **affordance 예측 시각화** (그림 9): 지시마다 다른 affordance 맵과 생성 자세가 대체로 맞아 보입니다. 정성 결과라서 정량 근거는 아닙니다.
- **실패 사례** (그림 11): 얇은 형상(키보드, 프리스비, 꽃병)과 세밀한 기능 지시(샴푸 펌프)에서 실패합니다. 저자가 직접 실패 유형을 분류했습니다.

## 6. 주장과 증거의 틈 (요약)

자세한 대조는 `04_claim_verification.md`에 있습니다. 가장 중요한 틈은 다음과 같습니다.

1. **기능성을 직접 재는 지표가 없습니다.** 시뮬레이션의 SR은 "0.2 m 이하 이동"이라서 기능 검사가 아니고, 기능 정확성은 GPT-5와 인간 점수에만 의존합니다.
2. **성공 기준이 느슨합니다.** 0.2 m 허용과 손 고정 설정은 들기도 기능도 확인하지 않습니다(부록 C.2).
3. **기준선이 하나입니다.** 같은 문제의 공개 방법이 없다는 이유로, 기준선을 저자가 직접 만들었습니다(§6.1). 기능 파지의 다른 계열(GraspGPT, G-DexGrasp 등 §2에서 인용)과는 비교하지 않았습니다.
4. **데이터와 코드가 공개되지 않았습니다.** 학습에 2M 스텝이 필요하고 GPU 수가 없습니다.
5. **분모와 검정 정보가 부족합니다.** SR 분모가 표 6의 인스턴스 수와 맞지 않습니다(`03` §1.4). 신뢰구간이 없습니다.
