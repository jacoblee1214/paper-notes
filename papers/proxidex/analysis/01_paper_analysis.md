## 1. 한 문단 요약

다지(multi-finger) 손 조작에서 손이 물체를 가려 접촉 영역이 보이지 않고, 촉각 센서는 하드웨어마다 달라 일반화가 어렵다는 문제에서 출발합니다(Abstract, §1). 저자들은 **손-물체 기하 근접도(proximity)** 를 접촉의 대리 신호로 씁니다. 사전에 복원한 물체 메시와 FoundationPose++ 자세 추적으로 손과 물체 표면 점군(interaction point cloud, Int.PC)을 만들고, 손 영역(손바닥, 손가락 뿌리, 손끝)별로 거리를 가우시안 커널로 바꿔 지역 근접도 벡터를 얻습니다(§4.1, 부록 A.3, 식 11–15). 학습은 두 단계입니다. 1단계(§4.2)는 근접도 VAE, 관측 인코더, 행동 조건 순방향 동역학(FDM, DiT 기반), 잠재 변화에서 근접도 잠재를 복원하는 역방향 차분 모듈(IDM), 접근/접촉 단계 분류 헤드를 함께 학습합니다. 2단계(§4.3)는 인코더를 고정하고 비대칭 인과 트랜스포머 확산 정책을 학습하며, 단계 확률 p로 근접도 토큰의 기여를 조절합니다(게이트). 배포(§4.4)에서는 IDM이 근접도를 추정하고, FDM의 예측과 실제 인코딩의 거리(식 5)가 임계값을 넘으면 FDM이 자기회귀로 잠재를 이어 가는 "dream 모드"로 바꿉니다. 시뮬 10과제(Adroit 3, DexArt 4, IsaacLab 자체 3)에서 평균 83.9%로 DP3, ManiFlow, AFRO, CordViP보다 높고(표 1), 실로봇 11개 설정에서 합산 72.6%로 CordViP 62.9%보다 높다고 보고합니다(표 2). 공식 코드는 공개되지 않았습니다.

## 2. 문제 설정과 방법

### 2.1 표기와 문제 (§3)

시연 D = {τ_i}, 관측 o_t, 전문가 행동 a_t^E, 정책 π_θ, 인코더 f_φ (z_t = f_φ(o_t)). 기존 잠재 동역학 보조 손실은 식 (1)입니다.

> ẑ_{t+k} = h_ψ(z_t, a^E_{t:t+k−1}),  L_dyn = E[‖ẑ_{t+k} − f_φ(o_{t+k})‖²₂]

저자들은 (i) 손-물체 가림으로 접촉 영역이 관측되지 않고, (ii) L_dyn만으로는 물체 자세 변화 같은 눈에 띄는 움직임을 우선하고 손-물체 거리의 세밀한 변화를 놓친다고 주장합니다(§3). 이 두 가지가 "접촉 영역을 복원한 점군 + 근접도 기반 동역학"의 동기입니다. (ii)에 대한 직접 실험(L_dyn만 쓴 대조)은 없습니다. 가장 가까운 대조는 AFRO(동역학 사전학습, 표 1)입니다.

### 2.2 상호작용 인지 데이터 취득 (§4.1, 부록 A)

| 단계 | 내용 | 출처 |
|---|---|---|
| 팔 원격조작 | VR 손목 변위 → 로봇 말단 목표(식 6), 쿼터니언 증분(식 7), PyBullet 수치 IK | 부록 A.1 |
| 손 원격조작 | 21개 손 키포인트 정규화 → 목표 벡터 흐름, Huber 손실과 평활 항으로 관절 해(식 8), DexPilot식 접촉 prior | 부록 A.1 |
| 물체 복원 | Grounded-SAM으로 마스크, SAM 3D로 메시 복원, 깊이로 균일 배율 κ = median(정렬 축 비) 보정(식 9, 10) | 부록 A.2 |
| 자세 추적 | FoundationPose++로 6D 자세 추적 (약 10 Hz) | §4.1, §4.4 |
| 상호작용 점군 | 물체 표면 점과 손 링크 표면 점을 로봇 기저 프레임에서 합집합 o^p_t = P^o_t ∪ P^h_t | §4.1, 부록 A.3 |
| 근접도 | 손 점마다 최근접 물체 점 거리 d_i^nn(식 11), SDF 음수면 0으로 처리(식 12), η_i = exp(−½(d_i/σ)²)(식 13) | 부록 A.3 |
| 지역 근접도 | 손 영역 S_k의 평균 γ_k = (1/\|I_k\|) Σ η_i (식 14), o^prox = [γ_1…γ_K](식 15) | 부록 A.3 |
| 단계 라벨 | o^traj = I(γ_palm > τ_palm): 0 접근, 1 접촉 상호작용(식 16) | §4.1, 부록 A.3 |

원격조작 보조: 점군을 헤드셋에 색(c_i = c_base + η_i(c_hot − c_base))으로 돌려보내 조작자가 손-물체 거리를 봅니다. 손 키포인트 약 30 Hz, 자세 검출 약 10 Hz, 점군 스트림 약 23 Hz(부록 A.1). 사용자 연구는 참가자 20명(부록 D.1)입니다.

σ(가우시안 폭)와 τ_palm(단계 임계값)의 값은 논문 어디에도 적혀 있지 않습니다. 근접도 입력 차원은 124, 잠재 차원은 16으로 적혀 있고(부록 B.1), 영역 수 K와 손별 영역 구성은 적혀 있지 않습니다(`04` C7).

### 2.3 1단계: 잠재 상호작용 동역학 (§4.2, 부록 B.1)

- **근접도 VAE**(100 에폭 사전학습 후 고정): 124차원 근접도 → 16차원 잠재 z^prox, 손실 식 (17) (λ_rec = 1.0, λ_KL = 0.01). 이후 사후 평균 μ^prox가 결정적 목표로 쓰입니다.
- **관측 인코더 E_θ**: Int.PC와 로봇 상태 s_t → z^obs_t (점군 특징 128차원).
- **FDM**: DiT 기반 조건부 잡음 제거 모델(식 18). 현재 z^obs_t와 행동열 a_{t:t+h−1}에 조건을 두고 미래 관측 잠재를 예측하며, H_dyn = 2가 기본입니다(표 4, 표 8).
- **IDM**: LayerNorm이 있는 MLP. 식 (2)의 주 본문은 ẑ^obs_{t+h} − ẑ^obs_{t+h−1}에서 z^prox_{t+h}를 맞추도록 쓰고(h = 1…H), 부록은 한 단계 예측으로 ẑ^prox_{t+1} = IDM(ẑ^obs_{t+1} − z^obs_t)를 씁니다(식 19).
- **궤적 헤드**: z^obs로 접촉 단계 확률 p^int를 예측하고 o^traj에 교차 엔트로피(L_traj).
- 총 손실 식 (3): L_stage1 = λ_v L_vae + λ_f L_for + λ_c L_inv + λ_t L_traj (모두 1.0, 표 4). 에폭: VAE 100 + 나머지 201 = 301(부록 B.1).

### 2.4 2단계: 궤적 적응 근접도 정책 (§4.3, 부록 B.2)

- 인코더 고정, Transformer 기반 확산 정책(8층, 8 헤드, 임베딩 256, 표 5). z^obs는 모든 행동 스텝에 보이고, 근접도 토큰열 z^prox는 **인과 메모리 마스크**로 현재와 과거만 봅니다(비대칭 인과 인코더).
- 학습 때 z^prox는 고정 VAE에서, 추론 때는 IDM 추정 ẑ^prox로 바뀝니다(§4.3 마지막 문단).
- 게이트(식 20): z̄^prox = g(p)·z^prox, g(p) = 1 − α + αp, α ∈ [0, 1]. 처음 2,000 스텝은 p = 0.5로 고정, 이후 p = sigmoid(c/τ), τ는 50,000 스텝에 걸쳐 2.0 → 0.7, α는 20,000 스텝에 걸쳐 0 → 1(표 5). 게이트 정규화 L_gate는 음의 이진 엔트로피(식 21), λ_gate = 10⁻³. 본문 식 (4)는 확산 손실에 λ_gate L_gate를 더합니다.
- 확산 학습 단계 K = 100, 추론 잡음 제거 10 스텝, 정책 horizon 16, 관측 4, 행동 8(표 4, 5).

### 2.5 동역학 일관성 안내 추론 (§4.4, 부록 B.3, 알고리즘 1)

1. 인코더로 z^obs_t를 얻고, Mode = Normal이면 입력 z^in_t = z^obs_t, Dream이면 z^in_t = ẑ^obs_t.
2. Δz_t = z^in_t − z^in_{t−1}에서 ẑ^prox_t = IDM(Δz_t), 궤적 헤드에서 p^int_t, 게이트로 z̄^prox_t.
3. 정책이 행동 청크를 만들어 receding horizon으로 실행하고, FDM으로 ẑ^obs_{t+1}을 예측합니다.
4. 다음 관측을 인코딩해 e^dyn_{t+1} = ‖z^obs_{t+1} − FDM(z^obs_t, a_t)‖₂ (식 5, 22)를 계산합니다. τ_dyn 이하면 Normal, 초과면 Dream (FDM 잠재를 자기회귀로 사용).
5. τ_dyn은 "말단 위치 편차 1 cm에 처음 대응하는 관측 특징 차이"로 정합니다(부록 D.5).

실행 속도: FoundationPose++ 약 10 Hz, 근접도 정책 약 28 Hz, FDM 약 20 Hz(§4.4). 학습·추론 장비는 i9-14700K, RTX 4090D(부록 B).

## 3. 실험

### 3.1 시뮬레이션 (§5.1, 부록 C)

- 10개 과제: Adroit(Hammer, Door, Pen), DexArt(Laptop, Faucet, Toilet, Bucket), IsaacLab 자체(Box, Driller, Banana). 과제당 시연 30개, Adroit·DexArt는 RL 전문가 시연, 자체 과제는 VR 원격조작(§5.1). 시뮬에서는 물체 자세를 직접 얻어 Int.PC를 만듭니다.
- 기준선(§5.1): DP3(장면 점군), ManiFlow(장면 점군), AFRO(장면 점군 + 동역학 사전학습), CordViP(복원 Int.PC + 팔 협응 잡음 제거).
- **표 1**(과제 묶음별 평균 ± SD, 시드 수 미기재): 평균 성공률 DP3 71.8, ManiFlow 74.2, AFRO 76.9, CordViP 81.0, **ProxiDex 83.9**. 묶음별 ProxiDex는 Adroit 90.3, DexArt 73.7, 자체 91.1(CordViP 85.6, 71.8, 88.8).

- **데이터 크기 (그림 15, 부록 D.3)**: 5, 10, 20, 30, 50, 100 시연에서 6과제 평균이 약 11.5, 40.0, 64.0, 77.5, 80.0, 81.8%.

## 4. 논문이 적은 한계 (§7, 부록 E.3)

- 정확한 물체 복원과 실시간 자세 추적에 의존합니다(작은 부품, 관절 물체, 고정밀 조작에서 불안정할 수 있음).
- 동역학 인계(dream)는 짧은 지각 실패에만 효과적이고 오래 가리면 오차가 쌓입니다.
- 근접도는 기하 기반이라 실제 접촉력이나 손끝 힘 분포를 재지 못합니다.
- 부록 E.3: 가운데 손가락과 엄지의 비대칭 닫힘, 컵 집기에서의 흔들림이 자세 추정 안정성을 낮춥니다. 향후 데이터 글러브, 가벼운 촉각 센서, 대비 학습 정렬을 제안합니다.

## 5. 주장과 근거의 간격 (본 분석의 관점)

수치 재계산은 `03`, 주장별 검증은 `04`에 있습니다. 여기서는 읽으며 눈에 띈 점만 정리합니다.

1. **근접도는 Int.PC의 함수입니다.** 근접도는 물체 자세와 손 순기구학에서 닫힌 식(식 11–14)으로 계산되므로, 평상시 배포에서 Int.PC를 이미 가진 시스템이 IDM으로 근접도를 다시 추정하는 이유는 dream 모드(자세 추적을 쓸 수 없는 구간)와 학습 신호 정렬에 있습니다. 평상시에 식 11–14로 직접 계산한 값을 정책에 넣는 대조(w/o IDM의 한 형태)는 없습니다. w/o IDM은 77.6 → 75.3입니다(표 7).
2. **시뮬의 점군 입력 조건이 방법마다 다릅니다.** 시뮬에서는 물체 자세가 시뮬레이터에서 바로 나오므로 Int.PC 계열(CordViP, ProxiDex)이 추적 오차 없는 입력을 받고, 장면 점군 계열(DP3, ManiFlow, AFRO)은 카메라 점군을 받습니다(§5.1). 따라서 DP3 대비 +12.1점의 한 부분은 입력 차이입니다. 동일 입력 대조는 CordViP(+2.9점)입니다.
3. **통계 설명이 적습니다.** 표 1, 6, 7, 8의 "±"가 몇 번의 시드·평가에서 나온 값인지 적혀 있지 않습니다(부록 C.2 "repeated evaluations"). 실로봇은 설정당 20, 40, 30회로 표 2에만 있고 신뢰구간은 없습니다. 재계산은 `03` V4, V5.
4. **학습 스케줄과 데이터 규모.** 표 5의 게이트 스케줄(α 상승 20,000 스텝, τ 어닐링 50,000 스텝)은 시뮬 30시연, 301에폭, 배치 128에서 시연 하나의 평균 길이에 따라 끝까지 도달하지 못할 수 있습니다(`03` V10, 시연 길이는 논문에 없어 가정).
5. **표 사이 같은 값.** 표 8의 Toilet 열 네 칸이 표 7의 Toilet 열 네 칸과 평균±SD까지 같습니다(`03` V8). 표 8의 H_dyn = 2 우위(+0.7점)는 Toilet 열이 약 90%를 차지합니다(`03` V7).
6. **용어.** "hardware-agnostic contact representation"은 접촉 정보가 아니라 거리 정보입니다. 논문도 한계에서 접촉력은 재지 못한다고 적습니다(§7). 촉각과의 비교는 그림 9의 3개 과제 하나뿐입니다.
7. **코드와 데이터가 없습니다.** 시뮬 과제 세 개(IsaacLab), 시연 데이터, 영역 정의, σ·τ_palm 값이 공개되어 있지 않아 이 논문은 지금 재현할 수 없습니다(`04` §4).
