# 02. 선행연구와 계보

번호 [n]은 논문의 참고문헌 번호이고, arXiv ID는 논문 참고문헌 목록에 적힌 값을 그대로 옮겼습니다. 이 문서의 각 논문을 별도로 열어 내용을 검증하지는 않았습니다.

## 1. 계보도

```
[행동 생성] Diffusion Policy [4] (RSS 2023) ─ 관측 → 행동 청크, U-Net, DDIM, FiLM 조건
        │
        ├─ [촉각을 관측으로 추가] 3D-ViTac [13], PolyTouch [41], Reactive DP [34], FACTR [19], ViTacFormer [9]
        │     촉각을 입력 특징이나 보조 예측 목표로 사용 (Table I의 "executable contact modeling 없음")
        │
        ├─ [촉각·힘을 예측 목표로] ViTacFormer [9], Unified Multimodal Diffusion Forcing [14], MLA [20]
        │     미래 촉각·힘을 예측해 표현을 다듬지만, 예측한 접촉을 제어 목표와 직접 잇지 않음
        │
        ├─ [제어 가능한 접촉 표현: 단일 힘 벡터] Adaptive Compliance Policy [12], Compliant Residual DAgger [31], UMI-FT [5]
        │     팔 엔드이펙터 힘 하나 또는 그리퍼 손가락당 힘 하나 → 임피던스 목표
        │
        └─ [제어 가능한 접촉 표현: 손끝 힘] KineDex [39], DexForce [3]
              다지 손이지만 손끝마다 sparse한 힘
                    ▼
  ★ CGP: 손 전체의 분포 접촉을 (실제 상태, 촉각) 궤적으로 생성하고, 학습된 사상으로 compliance 목표로 변환
```

**차별점 요약 (Table I):** 제어기가 실행할 수 있는 접촉 모델을 두면서, 다지 손과 **분포 접촉**(손 전체 다중 패치)까지 다루는 것은 CGP뿐이라고 주장합니다. 차이는 접촉을 힘 벡터 몇 개로 매개화하지 않고 촉각 신호 자체를 예측한다는 점입니다.

## 3. 이 저장소의 다른 논문과의 관계

| 논문 | 관계 |
|---|---|
| **GPT-as-Tactile-Policy** (`gpt6_astra_tactile/`) | 둘 다 촉각 정책이지만 촉각을 쓰는 위치가 다릅니다. 그쪽은 촉각을 정책의 입력(판단 근거)으로 쓰고, CGP는 촉각을 **예측 대상이자 제어 목표의 근거**로 씁니다. 그쪽 UniVTAC 2×2 재현 실험에서는 촉각이 Task Skill(촉각을 쓰는 규칙)과 함께 있을 때만 유의했습니다(+50%p, Skill이 없으면 +15%p로 비유의). CGP Table II에서 촉각을 관측으로만 넣은 visuotactile DP의 이득이 작거나 음수인 것(병뚜껑 열기 73.3% → 66.7%)과 같은 방향의 관찰입니다. 두 결과 모두 촉각을 "어떻게 쓰는지"가 구조로 주어질 때 효과가 난다는 쪽을 가리킵니다. |
| **DexScrew** (`dexscrew/`) | 텔레옵으로 다지 손 촉각 데이터를 모아 BC를 학습한다는 점이 같습니다. DexScrew는 어려운 손가락 동작을 RL 기술로 맡기고, CGP는 compliance 제어기와 목표-실제 간극으로 접촉을 다룹니다. 두 방법은 결합할 수 있습니다. |
| **FlashDexRetarget** (`flashdexretarget/`) | FlashDexRetarget 정책은 링크별 접촉 wrench를 privileged 관측으로 씁니다. CGP의 M_φ는 촉각에서 그와 같은 접촉 효과(목표-실제 간극)를 복원하는 학습 모듈로 볼 수 있습니다. 시뮬레이션에서 만든 대량 궤적에 촉각 배열을 붙이면 CGP의 학습 데이터가 됩니다. |
| **Do as I Do** (`do_as_i_do/`) | 사람 시연을 로봇 궤적으로 바꾸는 쪽입니다. CGP는 텔레옵(RelaxedIK)으로 직접 시연을 모으므로 리타겟팅 품질 문제는 텔레옵 단계에서 사람이 보정합니다. |

## 4. 논문이 다루지 않았지만 관련 있는 연구 (내 판단)

| 주제 | 관련성 | 근거 수준 |
|---|---|---|
| **임피던스·강성 제어의 고전 관계** τ_ext = K(a − x) | M_φ가 학습하는 사상의 물리적 구조입니다. 관절 PD라면 a = x + Kp⁻¹(g − Jᵀf)입니다(`03` §1). 저자들이 향후 과제로 든 "제어기 이득 조건화"의 해석식이기도 합니다. | 교과서 수준의 관계. 유도는 `03` |
| **Feel the Force** (사람 시연에서 접촉력을 예측해 힘 제어로 실행하는 계열) | "예측한 힘을 제어기로 실현한다"는 같은 문제의식이고, 그리퍼 중심입니다. | 내 사전 지식. 서지 확인 필요 |
| **Real-Time Chunking 등 청크 경계 처리** | CGP는 8스텝 청크 동안 관측 촉각을 쓰지 않습니다(`01` §4.2). 청크 안에서 촉각 오차를 반영하는 방법과 연결됩니다. | 내 해석 |
| **Tactile beyond pixels [10]** (Meta 계열 다감각 촉각 표현) | 같은 Meta 생태계의 사전학습 촉각 표현입니다. CGP는 촉각 인코더를 과제마다 처음부터 학습하므로, 사전학습 인코더로 바꾸는 실험이 자연스럽습니다. | 인용은 됨. 결합은 내 해석 |
