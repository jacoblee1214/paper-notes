## 0. 한 문단 요약

변형체 시뮬레이터(스프링-질량 모델)를 **물리 백본**으로 두고, 그 한 스텝 예측에 더할 **속도 잔차(residual velocity)**를 신경망으로 예측하는 하이브리드 시뮬레이터(PGRD)입니다. 백본 파라미터는 CMA-ES로 객체마다 맞추고(미분 불필요), 잔차 네트워크는 PTv3 인코더, NeRF식 디코더, 슬라이딩 윈도 트랜스포머(게이트 포함)로 구성합니다. 잔차는 **위치가 아니라 속도에** 더한 뒤 적분하고, 학습은 자기 예측을 다시 넣는 다중 스텝 롤아웃으로 합니다. 실로봇 6개 객체의 추종 지표(MDE, CD, EMD, 표 I)와 영상 지표(J, F, LPIPS, 표 II)를 합한 36개 셀에서 PGRD가 최선 또는 동률이라고 보고합니다. 응용으로 MPPI 계획(케이블 재배선 8/10 대 2/10), 언어 조건 목표 영상을 쓴 계획, 3DGS 상호작용 렌더링을 보입니다.

## 1. 문제 설정

- 변형체 시뮬은 물리 기반(스프링-질량, MPM, PBD, FEM)과 학습 기반(GNN, 입자-격자 신경 동역학)으로 나뉩니다(§I, §II).
- 물리 기반은 재질 파라미터가 필요하고, 미분 가능 시뮬로 식별하려면 접촉의 불연속 때문에 기울기가 깨집니다(§II 첫 문단). 저자들은 이 때문에 **미분 없는 CMA-ES**를 씁니다(§III-A).
- 학습 기반은 데이터가 많이 필요하고 본 적 없는 재질·상황에서 약합니다(§I, §II).
- 제안의 핵심 가설: 물리 백본이 일반화의 사전 정보를 주고, 학습은 **보정만** 맡으면 데이터가 적게 든다(§I 네 번째 문단, §II "Residual Dynamics").

## 2. 방법 (§III)

### 2.1 물리 백본 (§III-A)

- 객체를 질량점(노드)과 스프링(엣지) 그래프로 둡니다. 각 노드의 위치와 속도를 **semi-implicit Euler**로 적분합니다(§III-A 첫 문단).
- 파라미터 θ는 다섯 개입니다: 강성, 감쇠, 스프링 생성 임계 거리, 노드당 최대 스프링 수, 바닥 마찰(§III-A 두 번째 문단). 이 다섯 개의 탐색 범위는 공식 코드의 `cmaes_bounds/paper.yaml`과 같습니다(`04` §2의 확인 항목).
- 파지 입자는 집게와 **같이 움직이고**(prehensile), 비파지 조작에서는 집게를 구 모양 충돌체로 두어 관통 입자를 표면으로 밀어냅니다.
- 목적함수: 후보 θ로 궤적을 굴려 얻은 예측 점군과 관측 점군 사이의 점별 MSE를 시간 평균. CMA-ES로 최소화(§III-A 세 번째 문단).
- 부피가 있는 객체(sloth, teddy)는 표면 셸만 두면 무너지므로, RaySt3R로 표면을 복원하고 마칭 큐브로 수밀 메시를 만든 뒤 내부에 입자를 채웁니다(§III-A 네 번째 문단, Table III의 "internal particles" 행).

### 2.2 속도 잔차 (§III-B)

- 백본의 한 스텝 예측 $(X^{sim}_{t+1}, V^{sim}_{t+1})$에 네트워크가 예측한 입자별 잔차 속도 $\Delta V_{t+1}$을 더합니다.
  - $\hat V_{t+1} = V^{sim}_{t+1} + \Delta V_{t+1}$
  - $\hat X_{t+1} = X^{sim}_{t+1} + \Delta V_{t+1} \cdot dt$ (식 두 개, §III-B)
- 저자들은 **위치 잔차를 직접 예측하면 불안정해서 NaN이 나온다**고 씁니다(§III-B). 이 주장을 뒷받침하는 정량 실험은 없습니다. 표 III 캡션에도 "divergence"라고만 적혀 있습니다(`03` K2).
- 파지 입자의 잔차는 0으로 둡니다(경계 조건, §III-B).
- 식 (1)의 학습 목표는 **다중 스텝 예측 위치의 MSE**입니다. 시뮬을 실제 상태로 되돌리지 않고 예측 상태를 다음 입력으로 넣습니다(§III-B, 노출 편향 대응).

### 2.3 네트워크 (§III-C, Fig. 2, Table IV)

| 구성 | 역할 | 논문의 설정 (Table IV) |
|---|---|---|
| 인코더 (PTv3) | 입자별 특징. 입력은 현재 상태 $(X_t, V_t)$, 과거 $(X_{his}, V_{his})$, 시뮬 예측 $(X^{sim}_{t+1}, V^{sim}_{t+1})$을 이어 붙인 **18채널** | 특징 차원 64 |
| 디코더 (NeRF식 MLP) | Fourier 위치 부호화와 인코더 특징을 이어 초기 잔차 $\Delta V^{init}$ 예측 | 은닉층 2, 폭 64, 출력 3 |
| 시간 집계 (슬라이딩 윈도 트랜스포머) | 최근 W 프레임의 $\Delta V^{init}$ 버퍼를 트랜스포머로 처리. 마지막 시점 특징 $h_t$에서 $\delta_t = \tanh(\cdot)$, $g_t = \sigma(\cdot)$ | 임베딩 64, 헤드 4, 층 2, FFN 128, 게이트 스케일 0.1 |

- 최종 잔차: $\Delta V^{res} = 0.1 \cdot [(1-g_t) \odot \Delta V^{init} + g_t \odot \delta_t]$ (§III-C 식).
- 윈도 길이 W의 값은 본문과 표 IV 어디에도 없습니다(`03` K8).

### 2.4 학습 (§III-B, §IV-A)

- 5-step 롤아웃으로 학습하고(§IV-A 끝 부분), 평가는 전체 에피소드 **37 스텝**으로 합니다. 학습에서 본 적 없는 길이로 일반화를 보는 설계입니다.
- 손실은 위치 MSE 하나입니다. 속도 손실은 없습니다(공식 코드 `loss_factor_v: 0.0`, `04` 확인 항목).
- 옵티마이저, 학습률 스케줄, 에폭 수, 학습 시간, GPU 종류는 논문에 없습니다(`03` §4).

## 3. 실험 설정 (§IV-A, §IV-B, §IV-C, 부록 D)

- **객체 6개** (Fig. 3): rope(1차원, 한쪽 끝 파지), paper(얇은 2차원 시트, 위에서 파지), flag(천, 위쪽 막대를 강체 제약으로 처리), sloth toy(부피, 긴 유연 팔다리), duster(강체 자루 + 부드러운 깃털), teddy toy(부피, 강성 있음, 비파지로 찌르기).
- **데이터**: xArm 7 로봇, RealSense D455 4대(30 Hz), Grounded SAM 2 분할, CoTracker 추적, 깊이로 3D 리프트, 반복 롤아웃으로 대응 유지(부록 D). 로봇 자세는 본체 고유 감각(proprioception)으로 얻어 행동열로 씁니다.
- **분할**: 학습 100 에피소드, 검증 20 에피소드. 에피소드는 4초이고 연속 에피소드는 2초 간격으로 겹칩니다(§IV-A). 본문은 이를 합쳐 120 에피소드, 244초(약 4.07분)라고 씁니다. 공식 학습 스크립트(`train.sh`, paper_uiuc)는 객체 하나당 학습 0–100, 평가 100–120을 씁니다. 따라서 **객체별 분할**로 읽는 것이 맞습니다. 본문 문장은 전체 합계처럼 읽혀서 모호합니다(`03` K4).
- **추종 지표** (3D): MDE(cm, 대응점 평균 거리), CD(양방향 최근접 평균), EMD(최소 수송 비용).
- **영상 지표** (3DGS 렌더링): J(IoU), F(윤곽), LPIPS. 3DGS는 첫 프레임에서 맞추고 위치와 공분산만 예측 입자에 맞춰 갱신합니다(§IV-B).
- **기준선 5개** (§IV-C): Spring-Mass(PhysTwin [34]의 백본, 같은 파라미터), MPM [73], GBND [94](GNN), PGND [93](입자-격자 신경 동역학), Diff. Spring-Mass(공간 변화 파라미터를 미분으로 추가 학습, PhysTwin 기반이지만 **저자가 새로 구현한 변형**).
- **± 의미**: 논문은 ±가 무엇인지 쓰지 않습니다. 표준편차인지 표준오차인지, 에피소드 단위인지 프레임 단위인지 모릅니다(`03` §0, `04` D8).

## 4. 결과

### 4.1 추종 정확도 (Table I, §IV-D)

- 6개 객체 × MDE, CD, EMD에서 PGRD가 최선 또는 동률입니다(`03` V1). 
- 물리 기준선끼리: Spring-Mass가 MPM보다 대부분 낫습니다(MPM은 Flag에서 MDE 23.1 cm, 종이에서 15.5 cm로 붕괴). Diff. Spring-Mass는 Spring-Mass보다 6개 객체 모두 MDE가 낮습니다(`03` V3).
- 학습 기준선: PGND는 GBND보다 대부분 낫지만 **Teddy에서는 MDE(1.6 대 1.5)와 EMD(0.8 대 0.8)에서 GBND가 같거나 낫습니다**. 본문의 "모든 객체에서 크게 낫다"는 표현과 맞지 않습니다(`03` K1).
- 가장 큰 개선은 rope에서 나옵니다: MDE 2.6 대 최선 기준선 3.3(PGND)으로 21% 낮습니다.

### 4.2 영상 정확도 (Table II)

- J, F, LPIPS에서도 PGRD가 6개 객체 모두에서 최선 또는 동률입니다(`03` V1).
- 다만 SD가 크고 객체당 시행 수가 20이라는 가정에서 PGRD 대 최선 기준선 차이는 어느 것도 p < 0.05가 아닙니다(`03` §4).

### 4.3 절제 (Table III, 부록 A)

- Rope와 Sloth에서 MDE만 보고합니다. 단일 값이고 SD와 시드 수가 없습니다.
- 인코더를 PointNet++로 바꾸면 Rope 2.6 → 3.0, Sloth 2.7 → 3.2로 가장 큽니다. 디코더 제거, 시간 집계 제거, 게이트를 덧셈으로 바꾸기 모두 0.1–0.4 cm 차이입니다. 내부 입자 제거는 Sloth에서 2.7 → 3.8로 1.1 cm 차이입니다.
- 시드 하나에서 나온 값이라 0.1–0.4 cm 차이는 해석하기 어렵습니다(`03` §5).

### 4.4 응용 (§V)

- **MPPI 계획 (rope 4 과제, Fig. 6, 부록 C의 sloth 4 과제 Fig. 11)**: 과제당 10회, CD 수렴 곡선만 그림으로 보고합니다. 수치 요약과 검정이 없습니다.
- **케이블 재배선 (Fig. 7, 8)**: 학습에 없던 로프-슬롯 상호작용에서 성공 8/10(PGRD) 대 2/10(Spring-Mass). 성공 기준은 "로프가 슬롯을 완전히 통과하고 최종 자세에서 집게가 슬롯 높이 아래" (§V-A). 유일한 성공률 비교입니다(`03` §6: Fisher 양측 p = 0.023).
- **언어 조건 계획 (Fig. 9)**: Nano Banana Pro로 목표 영상 생성 → Depth Anything V2 깊이 + 배경 평면 정렬 → AnyGrasp 파지 후보 → DINOv2 대응으로 대상 점 선택. 과제 몇 개를 실로봇에서 보이는 정성 결과만 있습니다. 성공률은 없습니다.
- **상호작용 3DGS (Fig. 10)**: 키보드로 명령을 주고 렌더링. 정성 결과만 있습니다.

## 5. 주장과 근거의 간격 (요약, 판정은 `03` §7)

1. "모든 지표·객체에서 최선": 표 I·II에서 셀 단위로는 맞습니다. 다만 대부분 차이가 SD 안쪽이라 통계적 우위는 약합니다.
2. "PGND가 GBND보다 모든 객체에서 낫다": Teddy에서 반례.
3. "위치 잔차는 불안정하다": 정량 근거가 없습니다.
4. "PGRD가 계획 성공률을 높인다": 한 과제 10회 비교만 있고 p = 0.023입니다. 다른 계획 과제는 정성입니다.
5. "언어 조건 계획이 동작한다": 정성 사례만 있습니다.
6. "데이터가 적게 든다": 실험이 없습니다. 학습 데이터 크기를 바꾸는 곡선이 없습니다(§I의 주장).

## 6. 한계 (논문과 본문에서 읽히는 것)

- 논문에 **Limitations 절이 없습니다**. 본문에서 읽히는 한계는 다음과 같습니다.
  - 백본은 스프링-질량이라 부피 보존과 얇은 객체 표현에 입자 수와 내부 입자 설정이 필요합니다(§III-A, Table III의 Sloth).
  - 학습 데이터는 객체당 약 3분이고, 실험 대상은 6개 객체, 한 로봇(xArm 7), 한 카메라 배치입니다.
  - 플래닝은 MPPI 샘플 8개, 3회 반복(Table V, 단순 과제)으로 작습니다. 예산 민감도 분석이 없습니다.
  - 공식 코드는 CUDA, Warp, DGL, 미분 래스터라이저 등 GPU 의존이 강합니다(`04` §5).
