## 1. 문제 설정

사람이 던진 물체를 **단일 RGB 카메라**만으로 잡는 문제입니다. 저자들은 3D 위치 추정을 피하고(RGB-D, 모션캡처 대비 센서 민감도 감소), 물체의 **화면 위 중심과 크기의 변화**로 운동을 나타냅니다(§I, §III-A, Fig. 1). 로봇은 UR5e 6축 팔과 Allegro 손(세 관절 고정, 13 자유도 제어)입니다. 카메라는 RealSense D435의 RGB만 씁니다(§III-B).

핵심 주장은 세 가지입니다.

1. 픽셀 특징 $z_{pixel} \in \mathbb{R}^6 = \{c_x, c_y, \Delta c_x, \Delta c_y, \Delta w, \Delta h\}$가 3D 위치 없이 접근 동역학을 알려 준다(§IV-B).
2. 팔과 손을 서로 다른 역할의 두 에이전트로 나눈 **이질적 MARL**(MAPPO, CTDE)이 단일 에이전트 PPO보다 한 번의 학습으로 낫다(§IV-A, §IV-D, §V-C).
3. 시스템 식별과 도메인 랜덤화로 시뮬 정책을 **추가 학습 없이** 실로봇에 옮긴다(§IV-F, §V-D).

## 2. 방법

### 2.1 MAMDP와 학습 구조 (§IV-A, §IV-E)

- 팔 정책 $\pi_{arm}$은 물체를 향해 손목 위치를 맞추고, 손 정책 $\pi_{hand}$은 잡는 동작을 맡습니다(Fig. 2).
- 학습은 skrl의 MAPPO입니다. 정책과 가치 네트워크는 두 에이전트에서 따로 둡니다. 은닉층은 [512, 256, 128], 활성 함수는 ELU, 클리핑 0.2, $\gamma$ 0.99, KL 임계 0.016입니다(§IV-E).
- 가치 네트워크만 물체 위치 $p^{obj}$를 씁니다(특권 정보, §IV-C). 정책은 두 프레임을 이어 붙인 관측을 씁니다.
- 학습은 512 병렬 환경, RTX A6000 두 장입니다(§IV-E). 학습 스텝 수와 소요 시간은 보고하지 않습니다.

### 2.2 픽셀 특징 (§IV-B, Fig. 4)

바운딩 박스의 중심, 너비, 높이와 연속 프레임 사이의 차이를 씁니다. 중심은 횡방향과 종방향 위치를, 너비와 높이는 거리 변화를 나타낸다고 설명합니다. 학습 중에는 바운딩 박스 모서리에 최대 5 픽셀의 무작위 잡음을 더합니다. 실로봇에서는 SAM2로 분할합니다(§IV-A 말미).

### 2.3 상태와 행동 (§IV-C)

- 관측: $z_{pixel}$(6), 손 끝 자세 $pose_{eef}$(7), 관절 상태(팔 6, 손 13), 행동, 두 시점 이어 붙임.
- 행동: 팔은 $a_{arm}$(6)을 현재 관절 위치에 더해 PD 제어로 보내고, 손은 $a_{hand}$(13)을 관절 한계에 맞춰 목표 위치로 씁니다(§IV-C).
- 제어 주기 30 Hz, 물리 120 Hz, decimation 4(§III-C).

### 2.4 보상 (§IV-D, 식 (2)–(4))

- 팔: $R^{arm} = r_{time} + r_{dist} + \lambda_{succ} 1_{succ} + \lambda_{app} 1_{app} - \lambda_{fail}(1_{drop} + 1_{coll}) - \lambda_{act}\|a^{arm}_t\|$.
- 손: $R^{hand} = \frac{1}{5}\sum_{k \in \{palm, thumb, index, middle, ring\}} r^k_{dist} + \lambda_{succ}1_{succ} - \lambda_{fail}(1_{drop}+1_{coll}) - \lambda_{act}\|a^{hand}_t\|^2$.
- $r_{dist}$는 링크와 물체 사이 거리의 시간 차분입니다(식 (4)). 계수는 $\lambda_{succ}=10$, $\lambda_{fail}=5$, $\lambda_{app}=0.1$, $\lambda_{act}=0.01$, $r_{time}=-0.01$입니다.
- 논문은 $1_{succ}$, $1_{app}$의 기준 거리를 적지 않습니다.

### 2.5 시스템 식별과 도메인 랜덤화 (§IV-F, Table I)

- 실로봇에서 관절 궤적을 기록해 강성, 감쇠, 마찰, 전기자(armature)를 맞춥니다. 맞춘 값과 오차는 보고하지 않습니다.
- Table I: 팔 관절 강성과 감쇠 스케일 U[0.8, 1.2], 손 U[0.7, 1.3], 행동 잡음 가우시안(팔 σ 0.03, 손 σ 0.02), 관측 잡음(팔 σ 0.005, 손 σ 0.005), 초기 관절 각 ±0.125, 물체 질량 U[0.5, 1.5], 반발 계수 U[0, 0.5].

### 2.6 물체와 궤적 (§III-C, Fig. 3)

- 학습 물체 5종, 크기를 바꿔 일반화를 노립니다(Fig. 3a). 시작 위치, 방향, 선속도, 질량을 무작위로 뽑습니다(Fig. 3b).
- 시뮬레이션 카메라는 D435와 같은 시야각의 핀홀 카메라입니다.

## 3. 실험과 결과

### 3.1 실험 설정 (§V)

- 지표: T.R. (손바닥이 물체에 **접촉**한 시도의 비율), S.R. (접촉 뒤 떨어뜨리지 않고 잡은 시도의 비율).
- 시뮬: 정책마다 100 병렬 환경 × 10회 = 1000회, 학습 물체와 미지 물체에서 평가. 3 seed(§V 서두, Table II 캡션).
- 실로봇: 물체당 30회(§V 서두, Table III 캡션). 세 물체(Cube, L-block, Triangle).
- 기준선: w/o-PF(픽셀 특징 없음, 초기 물체 위치만), S-A RL(PPO, 팔과 손을 한 정책으로), Only-Center(중심 $c_x, c_y$만), Only-WH(너비와 높이만).

논문의 해석은 세 가지입니다. 물체 궤적이 다양해 초기 위치만으로는 부족하다(§V-B (i)). 중심 정보는 방향을, 크기 정보는 거리를 준다(§V-B (ii)). 이질적 MARL이 S-A RL보다 낫다(§V-C). 재계산 결과는 `03_analysis.md` §1.2에 있습니다.

### 3.3 실로봇 (Table III, v1)

| only-WH | 0 / 0 / 0 | 0 / 0 / 0 |

본문은 "T.R. 약 70%, S.R. 약 50%"라고 씁니다(§V-D 끝). Only-WH는 한 번도 잡지 못했다고 보고합니다(§V-D 둘째 단락). S-A RL은 "약 24%"입니다. 본문 설명은 저자들이 실로봇 저하를 궤적 분포 차이(변형, 탄성, 공기역학)로 설명한다는 것입니다(§V-D 끝).

### 3.4 저자들이 말하지 않는 것

- 실로봇 결과에 반복 측정이나 seed가 없습니다. 물체당 30회가 전부입니다.
- 던지는 사람, 거리, 속도를 어떻게 통제했는지 적지 않습니다.
- SAM2 추론 지연과 30 Hz 제어 루프 안에서 실제로 맞았는지 측정하지 않습니다.
- 실로봇 실패 사례와 원인 분석이 없습니다(Fig. 6은 성공 사례뿐입니다).
- 실로봇에서 3D 위치 기준선(오라클이 아닌 추정 위치)과 비교하지 않습니다.
- 시뮬에서 색 분할을 쓴 것과 실로봇에서 SAM2를 쓴 것의 차이는 논의하지 않습니다(§IV-A는 색 분할이 조명에 민감하다고 씁니다). 코드 대조는 `04_code_verification.md` D6를 보세요.
- 학습 스텝과 학습 곡선의 숫자(Fig. 5)는 텍스트에 없습니다.

## 4. 한계 (저자 서술과 우리 판단)

저자는 단일 팔 구성에 머문다는 한계와 양팔 확장을 future work로 적습니다(§VI). 우리 판단은 다음과 같습니다.

- 물체 형상이 실로봇(Cube, L-block, Triangle)과 시뮬(코드에 있는 기본 형상 10종)에서 다릅니다. 시뮬 물체 목록에 L-block과 Triangle에 해당하는 형상이 없습니다(코드 기준). 논문 Fig. 3a를 봐야 확정할 수 있는데, 그림은 이 분석에서 쓰지 않았습니다.
- 던지기 조건이 논문 본문과 코드에서 다릅니다. 본문은 무작위 방향과 속도라고 쓰지만, 코드는 목표 지점을 정하고 그 지점을 지나도록 속도를 계산합니다(`04_code_verification.md` D12).
- 정책 입력에 픽셀 특징의 무작위 지연(0–2 스텝)이 있는데 논문에는 없습니다(D5).

## 6. 판정 요약

- 논문의 핵심 주장(시뮬에서 픽셀 특징과 이질적 MARL이 기준선보다 낫다)은 **시뮬 표 기준으로 방향은 맞고 통계적으로도 대부분 유의합니다**. 다만 3 seed이므로 seed 간 변동을 충분히 잡았는지는 판단할 수 없습니다.
- 실로봇 주장은 **방향은 맞지만 근거가 얇습니다**. 물체당 30회, 반복 없음, 실패 분석 없음입니다. 프로젝트 페이지의 360회 설계가 이를 보강하는지는 RA-L 본문을 봐야 확정할 수 있습니다.
- 재계산과 토이 결과는 `03_analysis.md`에 있습니다.
