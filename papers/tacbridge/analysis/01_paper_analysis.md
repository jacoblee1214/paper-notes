## 1. 문제 설정

광학 촉각 센서(GelSight, DIGIT, GelSlim, GelSight Mini, DuraGel, TacTip 등)는 같은 접촉을 센서마다 다르게 봅니다. 조명, 탄성체, 마커 배치, 해상도가 다르기 때문입니다 (Introduction 1–2쪽). 기존 멀티센서 표현 학습(§II-A의 [7]–[12])은 센서 정보를 공유 특징 공간에 넣지만, 어떤 차이가 센서 때문이고 어떤 차이가 접촉 때문인지 가르쳐 주지 않는다고 저자들은 주장합니다. 저자들의 제안은 **같은 접촉 사건을 여러 센서로 본 짝(paired)을 직접 제약으로 쓰는 것**입니다.

데이터 쌍은 두 곳에서 옵니다 (§IV-A):
- **TacQuad**: DIGIT, GelSight Mini, DuraGel이 같은 접촉을 기록한 실측 쌍. 본문은 "progress-matched, 동기 기록이 아님"이라고 씁니다 (§IV-C, 321행). 그래서 프레임 단위 정답으로는 쓰지 않습니다.
- **ToucHD-Sim**: 같은 시뮬 접촉을 9개 광학 센서 외형으로 렌더링한 쌍. 프레임이 정확히 동기화되어 있습니다.

## 2. 방법 (§III)

세 단계입니다.

**(a) 멀티센서 마스크 사전학습 (§III-A).** 여러 센서의 촉각 비디오로 마스크 오토인코더를 학습합니다. 인코더는 보이는 패치만 받고, 두 개의 재구성 헤드가 마스크된 내용과 프레임 차분(frame-to-frame difference)을 **같은 센서 안에서** 예측합니다. 그림 1은 4프레임 비디오와 80% 마스킹을 보여 줍니다.

**(b) 쌍 기반 교차 센서 학습 (§III-B).** 식 (1)에서 원본 센서 a의 보이는 패치와 목표 센서 b의 조건 e_b로 목표 프레임 X'_b와 차분 V'_b를 예측합니다. 목표 영상은 **정답으로만 쓰고 순전파에는 넣지 않습니다**. 같은 샘플에 대해 식 (4)로 원본 센서 복원도 합니다.
- 같은 센서 손실 식 (5): L_same = ℓ_MSE(X'_a, X̄_a; Ω) + λ_Δ ℓ_MSE(V'_a, ΔX̄_a; Ω)
- 교차 센서 손실 식 (3): L_pair = ℓ_S1(X'_b, X̄_b; Ω) + λ_Δ ℓ_S1(V'_b, ΔX̄_b; Ω). 손실 함수가 **Smooth L1**로 바뀝니다.
- 전체 식 (6): L_train = L_same + λ_pair L_pair.

**(c) 조건부 잠재 흐름 모델로 번역 (§III-C).** 인코더 E_θ로 잠재 Z를 뽑고, 디코더 D_φ가 목표 센서의 무접촉 배경 B_b와 센서 조건 e_b를 받아 RGB 영상을 복원합니다 (식 (7)). 정렬 손실 식 (8)은 디코더 특징 S와 인코더 특징 Q를 맞춥니다. 흐름 모델 TacDiT는 선형 경로 Z_τ = (1−τ)Z_b + τε (식 (10))에서 속도 장을 예측합니다. 추론은 소음에서 시작해 τ=1→0으로 적분하고, 마지막 잠재를 고정된 디코더에 넣습니다 (식 (12)).

**하위 과제 평가 (§III-D).** 인코더를 고정하고 선형 헤드만 학습합니다.

### 2.1 식 (10)–(11)의 검산

흐름 손실 식 (11)은 예측 Ẑ_b와 정답 Z_b의 제곱오차를 τ² 가중 속도 오차로 바꿔 씁니다. 정의 v_ψ = (Z_τ − Ẑ_b)/τ에서 Ẑ_b − Z_b = −τ(v_ψ − (ε − Z_b))가 성립합니다. 임의의 값 10,000개로 수치 확인했고 최대 절대 오차는 9e-16입니다 (`analysis/recompute_results.json`의 `eq11_identity_max_abs_err`). 그러니 식 (11)의 두 번째 등호는 맞습니다. 다만 **τ의 샘플링 분포는 논문에 없습니다.** 재현하려면 이 값이 필요합니다.

## 4. 한계 (저자 서술과 독자 판단)

**저자가 쓴 한계 (§V):** 센서 수가 제한적이고, 번역 정확도는 시뮬 쌍에서만 검증했으며 실센서 쌍의 충실도는 "확립되지 않았다"고 씁니다. 짧은 클립과 오프라인 인식만 다루고 장기 시간 일관성과 폐루프 조작은 미래 과제입니다.

**독자가 보는 추가 한계:**
1. **진짜 쌍 번역 정답이 없다.** TacQuad는 진행률을 맞춘 짝이라 프레임 정답이 아닙니다 (§IV-C). 실센서 번역 성능은 측정하지 않았습니다.
2. **"동기 기록"과 "진행률 맞춤"이 충돌합니다.** Introduction(33–35행)은 TacQuad가 "synchronized real observations"를 준다고 쓰는데, §IV-C(321행)는 "progress-matched rather than synchronously recorded"라고 씁니다. 한쪽이 틀렸거나 표현이 부정확합니다.
3. **실로봇 평가는 직물 하나의 분류입니다.** 5개 미본 직물 OOD 테스트는 독립 단위가 5개뿐입니다 (`03_analysis.md` §3).
4. **기준선이 같은 조건인지 알 수 없습니다.** AnyTouch, Sparsh MAE/V-JEPA의 사전학습 데이터와 크기가 TacBridge와 같은지 본문에 없습니다. 특히 TacBridge만 TacQuad와 ToucHD-Sim 쌍을 씁니다. 쌍 데이터의 효과와 구조의 효과를 분리하는 절제 실험이 없습니다.
5. **Table I에서 MAE가 힘 변화 Mini에서 더 낮습니다** (102.64 대 104.56). 저자도 본문에서 인정합니다.

## 5. 이 논문의 위치 (요약)

- 촉각 표현 학습 계보: VideoMAE와 Sparsh (V-JEPA, MAE) → AnyTouch (정적·동적 통합) → 교차 센서 번역 (Touch2Touch, T2D2, Grella) → 저자들의 쌍 기반 사전학습 + 번역 흐름 모델.
- 가장 가까운 대안은 AnyTouch(센서 통합)와 UniForce, UniTac입니다. 자세한 비교는 `02_prior_work.md`.
- 저자 제안의 핵심 차별점은 **같은 접촉 사건의 쌍을 사전학습 손실에 직접 넣는 것**입니다. 쌍 없는 정렬과 비교한 실험은 없습니다.
