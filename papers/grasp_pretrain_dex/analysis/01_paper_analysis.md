## 1. 문제와 주장

질문은 "대규모 **파지(grasp) 데이터**가 파지 합성과 pick-and-place를 넘어 **관절 도구 사용**(도구를 잡고, 접촉을 유지하고, 가동부를 움직이는 일)에 쓰일 수 있는가"입니다(§1, §2). 논문의 주장은 세 가지입니다.

1. **벤치마크:** 6개 관절 도구 과제로 된 시뮬레이션 벤치마크 DexCraft (xArm6 + LEAP 16자유도 손, ManiSkill3, PartNet-Mobility 자산, §4).
2. **데이터:** Dexonomy 파지 주석 9.5M개(Shadow 손, 31 grasp type)를 3단계 궤적으로 바꾼 G2D-Pretrain 355k 궤적 (§5.2, 표 7).
3. **방법:** 고수준 손 부목표 예측 + 저수준 목표 조건부 DP3를 쓰고, 저수준 정책을 G2D-Pretrain으로 먼저 학습한 뒤 과제 시연으로 미세 조정합니다(§5.1, 그림 3).

성능 주장은 다음과 같습니다. 시뮬레이션 6과제 평균이 20/50/100 시연에서 45.4/60.3/64.6%이고, DP3(2.4/8.4/19.1%)와 처음부터 학습한 계층 정책(HP-Scratch, 38.7/48.9/58.0%)보다 높습니다(표 1). 실로봇 3과제에서는 전체 과제 성공률이 DP3보다 33.3 percentage point 높습니다(표 4, 초록).

## 2. 방법 요약

- **고수준 정책 π_high (§5.1, 부록 B.1, 표 5).** 현재 점군에서 PointNet++(MSG, SA 6층)로 **16개 손 키포인트**를 예측합니다. 4점 부목표(ArticuBot, GHOST 계열)가 손에 부족하다는 것이 근거입니다. 출력은 점마다 변위와 혼합 로짓을 내는 dense GMM이며, 고정 분산 {0.01, 0.05, 0.1, 0.25, 0.5}와 균일 가중치 계수 0.1을 씁니다. 학습은 50 epoch, 학습률 3e-4, 배치 32입니다.
- **저수준 정책 π_low (§5.1, 부록 B.2, 표 6).** DP3를 고친 구조입니다. 현재 손과 목표 손 키포인트, 장면 점군을 Act3D형 교차 주의로 묶고, 상태 임베딩과 합쳐 DP3 확산 모델의 조건으로 씁니다. 예측 구간 16, 관측 2, 실행 4, 학습 확산 단계 100, 추론 DDIM 10단계입니다.
- **부목표 정의 (§5.1, 부록 A.1).** 시연을 파지·정렬·작동 세 단계로 나누고, 각 단계의 마지막 프레임을 부목표로 씁니다. 단계 성공 기준은 파지(2개 이상 손가락이 0.5 N 이상 접촉), 정렬(목표 위치 0.04 m 이내, 방향 30° 이내), 작동(가동 관절이 과제별 임계값 이상)입니다.
- **G2D-Pretrain (§5.2, 부록 B.3, 표 7).** 각 Dexonomy 항목(접근 전 자세, 파지 자세, 쥐기 자세)을 (1) 무작위 시작 자세에서 모션 플래닝으로 접근, (2) 파지와 쥐기를 보간, (3) 무작위 위치로 이동하는 3단계 궤적으로 바꿉니다. 마지막 프레임에서 파지가 유지되는 궤적만 남기고, 그 결과가 355,677개입니다.
- **전이 방법 (§5.2, 부록 B.4, 표 8).** 사전학습은 22자유도 Shadow 손 공간(6 + 22 = 28차원 행동)에서 합니다. 하위 과제는 LEAP 손(6 + 16 = 22차원)이므로, 16개 관절을 표 8의 매핑으로 Shadow 슬롯에 넣고 나머지는 0으로 채웁니다. 매핑은 학습 가능한 파라미터가 없는 고정 어댑터입니다.

## 3. 실험

### 3.1 시뮬레이션 (표 1, 표 2, 표 3, 표 10)

- **설정:** 과제마다 키보드 시연 5개를 MimicGen으로 늘립니다(§4, 부록 A.3). 학습 시연은 20, 50, 100개이고 평가는 500 에피소드입니다(표 1 캡션).
- **방법 비교:** DP(이미지 기반, 부록 C.1), DP3, DP3-PT, GraspXL-PT, HP-Scratch, Ours. 표 2는 UniDex-VLA, 표 3은 Dex1B를 추가합니다.
- **결과(과제 평균, %):**

| 방법 | 20 | 50 | 100 |
|---|---|---|---|
| DP | 1.0 | 1.8 | 2.3 |
| DP3 | 2.4 | 8.4 | 19.1 |
| DP3-PT | 10.1 | 22.3 | 29.7 |
| GraspXL-PT | 13.0 | 37.8 | 48.7 |
| HP-Scratch | 38.7 | 48.9 | 58.0 |
| **Ours** | **45.4** | **60.3** | **64.6** |

- **절제 (표 3, 50 시연):** Ours 60.3, PT-215k 55.6, PT w/o Appr. 52.8, PT w/o Lift 56.9. 사전학습 데이터를 줄이거나 단계를 빼면 낮아집니다.
- **UniDex-VLA (표 2):** 접촉 98.8%, 파지 62.3%지만 들기 26.1%, 목표 도달 4.1%, 전체 0.5%입니다. 논문은 VLA와 대립하지 않고 "보완적"이라고 씁니다(Q3).
- **Dex1B (표 3):** 100 시연으로 2.9%입니다. 다른 행은 50 시연이라 예산이 다릅니다(`03` C11).

### 3.2 실로봇 (표 4)

- **설정:** Franka Panda, LEAP 손, Azure Kinect 두 대, GELLO와 Manus 장갑으로 시연(30 Hz), 시연 50개, 배치 15 Hz, 과제 3개(주사기, 분무기, 가위), 과제당 18회 평가입니다(§6.1).
- **결과(%, 파지 / 정렬 / 작동, 표 4의 평균 열):** Ours 77.8 / 66.6 / 40.7, HP-Scratch 61.1 / 42.6 / 25.9, DP3 38.9 / 20.4 / 7.4입니다. "33.3 percentage point"는 작동(=전체 과제) 단계의 40.7 - 7.4입니다.

## 4. 한계 (논문 §8과 본 분석의 보충)

논문이 밝힌 한계는 다음과 같습니다. 부목표를 사람이 붙입니다. 과제마다 물체가 한 개입니다. 키보드 시연입니다. 실로봇 평가가 작습니다(촉각과 온라인 적응 없음).

본 분석이 더 짚는 한계는 다음과 같습니다.

1. **통계 근거가 얇습니다.** 시드 수가 보고되지 않았습니다. 실로봇 과제당 18회라 Wilson 95% 구간이 ±15pp 정도입니다(`03` §3).
2. **재현 자료가 공개되지 않았습니다.** G2D-Pretrain 데이터셋은 저장소와 README 기준으로 재생성해야 합니다. 공개된 HF 데이터는 시연과 MimicGen 생성분이며, README에 G2D-Pretrain 항목은 없습니다(`04` D13).
3. **비교 프로토콜이 한 줄로 적혀 있습니다.** GraspXL-PT는 인코더만 옮기는 방식이고(부록 C.3), Ours는 전체 체크포인트를 옮깁니다. 표 1이 같은 프로토콜인지 본문에 명시되지 않았습니다(`03` C12).
4. **부록과 본문 설정이 어긋납니다.** 인코더 출력 차원, 옵티마이저, 사전학습 epoch 수가 코드와 다릅니다(`04` D2, D4, D6).

## 5. 핵심 수치 확인 요약

자세한 재계산은 `03_analysis.md`에 있습니다. 요약하면 다음과 같습니다.

- 표 1 평균 재계산은 보고값과 최대 0.17pp 차이입니다(반올림 범위를 조금 넘습니다).
- 표 7 궤적 수 합계는 355,677로 보고값과 같습니다. 31개 grasp type이 있다는 본문과도 맞습니다.
- 표 4 작동 단계에서 Ours 대 DP3는 Fisher p < 0.001입니다. Ours 대 HP-Scratch는 p = 0.15로 유의하지 않습니다.
- 시뮬레이션에서 Ours가 HP-Scratch보다 낮은 셀은 18개 중 1개(Pen, 20 시연: 43.8 대 48.8)뿐입니다. 예산이 늘수록 떨어지는 단계는 Lighter(50→100, -1.0pp)와 Pen(50→100, -1.8pp)뿐이라, 셀 단위 잡음이 1–2pp 수준임을 보여 줍니다(`03` C4).
