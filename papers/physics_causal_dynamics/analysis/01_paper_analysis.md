## 1. 문제와 주장

**질문.** 같은 관절 상태와 같은 토크라도 숨은 물리 조건(여기서는 페이로드 질량과 무게중심)에 따라 결과 운동이 다릅니다. 조건이 바뀌는 로봇이 재학습 없이 그 변화를 따라가려면 무엇이 필요한가? (Intro, §1)

**저자의 답.** 최근 상호작용에서 4차원 **문맥 z**를 추정하고, z가 고정된 Lagrangian 신경망(DeLaN 계열)의 관성 행렬 H와 위치에너지 V를 **FiLM**으로 바꿉니다. c(코리올리·원심)와 g(중력)는 H와 V에서 유도하므로 어떤 z에서든 Lagrangian 구조가 유지됩니다. 네트워크 가중치는 오프라인에서 한 번 학습하고, 온라인 적응은 z만 갱신합니다(§1, §4.2).

**주장 목록 (저자 본문 기준).**
- 초록: 학습 밖 페이로드(2–4 kg)에서 ADD 오차를 기준선 대비 **1.6–3.8배** 줄입니다.
- 초록: 대안 토크에 대한 반사실 질문(counterfactual)에도 확장됩니다.
- 초록: 문맥이 페이로드 물리량을 인코딩하고 변화를 추적하며, 팔의 응답을 지배합니다(§5.3).
- 초록: 문맥에서 나온 중력항과 관성항이 시뮬레이터와 항 단위로 일치합니다(§5.4, 근사적).

## 2. 방법

### 2.1 동역학 식과 DeLaN (§3)
- 식 (1): H q̈ + c + g = τ, L = ½ q̇ᵀH q̇ − V. c와 g는 H와 V에서 유도되는 양이라 독립 모델링 요소가 아닙니다.
- DeLaN(Lutter 2019): 하삼각 A(q)의 대각은 softplus, H = AAᵀ + εI, V는 스칼라 망입니다.

### 2.2 문맥 인코더 (§4.2.1, 부록 A.1)
- 입력: 최근 K = 12 프레임의 (q_k, q̇_k, τ̄_{k−1}), 21 × 12 = 252차원. q는 기본 Franka 자세 기준 상대값. 물체 자세, 파지 오프셋, 질량, CoM은 넣지 않습니다(식 4).
- MLP 2층(폭 256, SiLU), 출력 μ, log σ² (식 5–7). μ = 10 tanh(·/10)의 soft bound를 씁니다.
- 학습 때 z = s(μ + σ⊙ε), s(x) = 10 tanh(x/10), 추론 때 z = μ (식 8). 인코더 파라미터 132,616개입니다.

### 2.3 FiLM 조건화 Lagrangian (§4.2.2, 부록 A.2)
- 세 망(A 대각 7출력, A 하삼각 21출력, V 1출력)을 두고 각 망은 q만 입력으로 받습니다. 폭 1024, 은닉층 3개 중 마지막 두 층을 변조합니다.
- 변조식 (10): a_ℓ = 1 + ψ(γ_ℓ(z)) ⊙ (W_ℓ h_ℓ + b_ℓ) + ψ(β_ℓ(z)). 게이트 ψ(u) = αT tanh(u/T), α = 0.3, T = 3 (식 15). 즉 은닉 유닛의 배율은 (0.1, 1.9), 편향 이동은 (−0.9, 0.9)입니다.
- 모든 FiLM 맵을 0으로 초기화해서 시작점은 같은 DeLaN입니다.
- 야코비안 ∂H/∂q, g = ∂V/∂q를 순전파와 한 번에 계산합니다(식 16–17).
- 파라미터: 망 하나당 약 2.13M, 세 망 6.41M, 인코더 포함 총 **6,545,957개**(표 2). 폭 256으로 줄이면 **0.56M**(표 6).

### 2.4 학습 목적 (§4.2.3)
- L_q̈ = MSE(H⁻¹(τ − c − g), q̈_data), L_ID = MSE(H q̈_data + c + g, τ). 둘 다 관절별 스케일 후 계산합니다. q̈_data는 기록된 관절 속도의 유한차분입니다.
- L_con (식 3): 배치 안 문맥 µ의 정규화 벡터 u_i = µ_i/‖µ_i‖, 온도 κ = 0.1. 가중치 w_ij = exp(−(m_i−m_j)²/2σ_m² − ‖r_i−r_j‖²/2σ_r²). 같은 에피소드 쌍을 강제로 양성으로 두지 않습니다. 부록 C.2에서 σ_m = 0.271 kg, σ_r = 1 cm.
- L_KL: N(µ, σ²) ∥ N(0, I), 계수 10⁻⁴.
- L_total = λ_a L_q̈ + λ_ID L_ID + λ_con L_con + λ_KL L_KL. **λ_a와 λ_ID 값은 본문에 없습니다.** 저장소 설정은 1.0과 0.3입니다(`04` D3).
- 라벨(질량, CoM)은 학습 때만 쓰고 추론 때는 쓰지 않습니다.

### 2.5 학습 설정 (§5.1, 부록 B.1, D)
- 데이터: Isaac Lab 2.3.2 / Isaac Sim 5.1 / PhysX. 2 kHz 시뮬, 50 Hz 제어(Δt = 20 ms). 관절별 코사인 스윕에 PID와 OU 토크 교란을 얹었습니다. 질량 8단계(0.1–2.0 kg), CoM 53 격자(125점).
- 학습 318 에피소드, 검증 40 에피소드. 질량 0.1–2 kg만 씁니다.
- Adam 3×10⁻⁴, 코사인 스케줄, 배치 256, 40 에피소드(epoch). 8스텝 교사 강제 구간, 15스텝(300 ms) 개루프 평가.
- 평가 세트: PPO 정책이 만든 3D 8자 추종에서 질량을 0.1 → 4.0 kg로 20초 동안 선형으로 올립니다(32,967 창). 반사실 실험은 같은 이력에 ±10–40 N·m 토크 offset을 15스텝 주고, 쌍 1,887개를 씁니다(5,616쌍 중).
- 평가 지표: 큐브 ADD(2000점, 평균 유클리드 거리). 큐브 자세는 Franka 정기구학과 파지 변환으로 계산합니다.

**표 3 (시드 0, 단일 값).** 대조 학습 항 제거: ADD 0.1–2 kg 4.58 → 6.07, 2–4 kg 6.92 → 9.78. 3 kg 캐리 RMSE(g₂, [Hq̈]₂, c₂)는 1.84/1.63/1.46 → 2.11/2.87/1.15. 코리올리만 나빠지지 않았습니다(부록 C.1).

**표 5 (3 시드, 평균 ± SD).** 조건화 방식 비교. FiLM 4.93 ± 0.54 / 6.76 ± 1.28. 입력 연결 4.45 ± 0.37 / 8.49 ± 0.69. 시프트만 4.59 ± 0.54 / 8.43 ± 0.80. 저랭크 하이퍼네트워크 4.26 ± 0.35 / 11.75 ± 2.63(부록 C.3).

## 4. 논문이 스스로 밝힌 한계 (§6)
- 단일 시뮬레이션 로봇(Franka Panda, Isaac Sim)입니다. 실로봇 평가가 없습니다.
- 파지가 단단하다고 가정합니다(post-grasp, 미끄럼 없음). 페이로드는 큐브 하나입니다.
- 개루프 300 ms 예측입니다. 폐루프 제어 평가가 없습니다.
- CoM 변화의 효과는 작고(학습 데이터의 토크 영향 약 5%), 문맥이 CoM 축을 따라 정렬되지 않는다고 적었습니다(§5.3). CoM을 조건화했다고 해서 CoM을 예측한다는 뜻은 아닙니다.
- 문맥에서 질량을 읽는 불확실성(영역이 겹침)은 향후 과제로 남깁니다(§5.3).
- 저자 본문은 "생성형 AI 도구(ChatGPT, Claude)를 글쓰기와 코드 작성에 썼다"고 밝힙니다(Acknowledgments).

## 5. 본문 주장과 근거의 간격 (요약)
자세한 판정은 `03_analysis.md` §7(C1–C16)입니다. 요점은 다음과 같습니다.
- **수치 주장은 대체로 맞습니다.** 1.6–3.8배, 1.8 cm, 12.7–18.8 cm, 25–74%, 2.7과 8.1 cm 등은 표에서 다시 계산해도 맞습니다(`03` §2–§4).
- **"통계적으로 우월"에 해당하는 근거는 약합니다.** 표 5의 FiLM 대 대안은 3 시드, 학습 밖 Welch p = 0.06–0.14입니다. 표 3과 4는 단일 시드입니다.
- **표 1 PICR 행은 저장소와 다릅니다.** 저장소 README, 프로젝트 페이지, 논문 표 3·6은 시드 0 값(4.58/6.92, gain 0.86, RMSE 1.84/1.63/1.46)을 씁니다. 표 1(3 시드 평균)과 차이가 있습니다. 시드 0 체크포인트만 공개되어 3 시드 값은 재현할 수 없습니다(`04` D6).
- **"여러 배 낮다"는 표현은 일부만 맞습니다.** 중력은 CaDeLaC 5.3배, DeLaN 4.7배입니다. 관성은 DeLaN에 2.5배입니다. 그리고 RMSE는 단일 에피소드(`demo_2130`, 3 kg, 1 s)에서 계산한 값입니다(`04` 참조).
- **"하드코딩된 로봇 모델이 필요 없다"는 동역학 모델에 한정됩니다.** 큐브 자세와 ADD는 Franka 정기구학에 의존합니다(`04` D8).
