# 04. 주장 검증 (공식 코드 없음)

공식 코드, 프로젝트 페이지, 데이터, 체크포인트가 모두 없어(`02` §4) 코드 대조(D 항목) 대신 논문의 주장을 표·그림 수치로 판정합니다. 주장 번호는 C입니다. 근거 번호 V는 재계산(`03` §1), K는 일관성 점검(`03` §2)입니다. 판정은 **지지**(표·그림 수치와 맞음), **부분**(맞지만 범위나 조건이 서술보다 좁음), **확인 불가**(논문 자료만으로 판단할 수 없음), **표와 다름**으로 나눴습니다. 비판의 대상은 논문의 서술과 표이며, 저자 확인이 필요한 항목은 마지막 절에 모았습니다.

## 4. 구현 가능성 판정 (이 맥: Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)

**논문 수치의 재현은 불가능합니다. 방법의 구조 재구현과 합성 데이터 토이는 이 맥에서 가능합니다.**

| 수준 | 판정 | 필요한 것과 이유 |
|---|---|---|
| 논문 표 1·2·3·4·5와 실로봇 결과 재현 | **불가** | 140만 프레임 데이터셋, TacV5 센서 모듈, 개조 UMI(부록 A), Mark-10 시험대, Tesollo DG-5F, 코드와 체크포인트가 모두 공개되어 있지 않음 |
| 구조 재구현 (Piezo CNN + 로그멜·로그합지수 + SSAST-Tiny + 교차 어텐션 + 인과 자기어텐션) | **가능** | torch(이 맥에 설치됨). 논문이 적지 않은 크기(CNN 채널, 어텐션 폭)는 가정해야 함. SSAST 사전학습 가중치는 다운로드 승인이 필요하고, 그 전에는 무작위 초기화로만 가능 |
| 합성 데이터 학습·평가 | **조건부** | 압력 이미지와 진동 시계열을 만드는 합성 생성기를 직접 구현해야 함. 논문 수치와 비교할 수 없고 구조의 동작·절제 질문(C9, C14)에만 쓸 수 있음 |
| 추론 속도 (프레임 예산 4.17 ms) | **측정함 (가정 구조)** | MPS 3.0–3.2 ms, CPU 16–26 ms(창 60프레임 전체 재계산). 캐시를 쓰는 증분 추론은 미측정 |
| 센서 직접 제작과 데이터 수집으로 표 재현 | **불가 (이 저장소 밖)** | 32×32 압전저항 배열, 8 kHz 가속도계, 선형 시험대, 그리퍼가 필요 |

- **노력 추정(측정 전):** 구조 재구현 2–4일, 합성 데이터 생성기와 학습 루프 3–5일, SSAST 사전학습 효과 분리 같은 절제 1–2일. 실제 센서 데이터로의 재현은 이 저장소 밖에서 하드웨어 준비(수 주–수 개월)가 먼저입니다.
- 이 판정은 코드 대조가 아니라 논문과 부록의 서술에서 낸 것이므로, 공식 코드가 나오면 학습 설정(부록 C.2)과 구현의 차이를 다시 확인해야 합니다.

## 5. 저자 확인이 필요한 항목

1. FPR의 분모(K4)와 오탐 없음의 정의(K5).
2. 지연의 시작 프레임 규약, 미검출 사건의 처리, 23.1 ms에 포함한 항목(K6, K1).
3. ID 분할의 단위(프레임 또는 에피소드)와 Tesollo 시험 분할이 설계 선택에 쓰였는지(V1, K9).
4. SSAST 무작위 초기화 대비 사전학습 효과, 로그합지수 대비 축별 쌓기 절제(C9, C14).
5. 시드 분산과 사건 수준 재현율(K8, K13).
