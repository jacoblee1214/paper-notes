# 04. 주장 검증과 구현 가능성

공식 코드가 없어서(2026-11-23, `02` §4) 코드 대조(D 항목) 대신 **논문의 주장 C1–C15를 표, 그림, 식과 비교**했습니다. 계산은 `03`, 토이는 `analysis/toy_psnr_motion.py`입니다. 판정은 **확인**(수치와 논리가 맞고 검정을 통과), **부분 확인**(점 추정은 맞지만 증거가 약하거나 한 조건에서만), **근거 부족**(검정되지 않았거나 논문 안에서 검증 불가), **불일치**(논문 안에서 서로 어긋남)입니다.

## 1. 대조 범위

- 대상: v1 본문 §1–§5, 표 1–7, 그림 1–12, 부록 A–H(표 8–19).
- 실행, 설치, 가중치와 데이터 다운로드는 하지 않았습니다. 기준선의 원 논문 수치는 대조하지 않았습니다(`03` §4).
- 인용된 JoyAI-RA 0.1·0.5, WLA3는 arXiv 초록만 확인했습니다(`02` §2).

## 3. 비교에서 빠진 것 (저자에게 확인할 것)

1. **같은 LAM으로 라벨만 바꾼 통제.** 1단계에서 사람 영상 + 무작위(섞은) 잠재 라벨, 또는 영상 사전학습(마스킹/미래 예측)만 쓴 대조가 없어서, 이득이 "잠재 행동 라벨"인지 "사람 영상으로 시각 표현을 사전학습"인지 나뉘지 않는다.
2. **JoyAI-RA 0.5와의 비교.** 같은 그룹의 후속 모델이 암묵(잠재) 행동 정렬을 이미 포함한다(`02` §2). 표 1–3은 0.1 [44]를 쓴다.
3. **데이터 양 대 LAM 데이터 양.** LAM은 항상 23.3K 시간으로 학습했다. LAM 학습 시간 대 주석 시간(정책용)을 따로 바꾼 실험이 없다.
4. **스케일링의 시드·반복.** 감독 방식 × 크기 9칸이 각각 한 번의 학습(추정)이다. 손 동작 5K 하락이 학습 변동인지 구분하려면 반복이 필요하다.
5. **스케일링 부분집합의 출처 구성.** 1K, 3K, 5K의 출처 혼합과 자체 수집 비중.
6. **정제 대 비정제 1단계 말뭉치.**
7. **MSE 가중치, 학습률 스케줄, MSE만 진단의 하이퍼파라미터**(표 9 누락).
8. **RoboTwin·RoboCasa 시행 수와 기준선 값의 출처**(부록 C가 약속한 표가 없음).
9. **LARY 설정**(클래스 수, 분할, 프로브 학습 방식)과 무작위 잠재 기준선.
10. **VQ-LAM과 LAPA가 같은 모델인지**, 다르다면 왜 표 값이 같은지.

## 4. 구현 가능성 (이 맥: Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)

**논문 결과의 재현은 불가능합니다. LAM의 구조와 손실은 구현할 수 있고, 소형 규모의 절제와 합성 영상 검증은 이 맥에서 가능합니다.** 공식 코드, 가중치, 정책의 기반 모델(JoyAI-RA)과 데이터가 모두 공개되지 않았습니다.

| 대상 | 이 맥에서 | 근거 |
|---|---|---|
| LAM 구조(행동 질의 + 트랜스포머 VAE, 식 1–4) 구현 | **구현 가능** | PyTorch 약 400–600줄, 3–5일(추정). 논문의 크기(약 0.6 B, 320×240)는 MPS에서 느리고, 24블록 × 2를 10–50 M 규모로 줄이면 가능 |
| 소형 LAM 학습과 정렬 항 절제(MSE, LPIPS, DINO, flow 중 일부) | **조건부**(가중치 다운로드 승인) | LPIPS(VGG 계열), DINOv2 ViT-B/14, RAFT-large 가중치가 필요. 크기는 수십–수백 MB(확인 전). 합성 영상이나 소형 공개 영상(수 GB 이하)으로 64×64 해상도, 10–50 M 파라미터면 MPS에서 수 시간(추정) |
| 합성 영상에서의 지표 점검(PSNR 대 움직임 정확도, 코드 수 대 변위) | **완료(토이)** | `analysis/toy_psnr_motion.py`, CPU 5초 |
| 정책 1단계(잠재 행동 청크 예측)의 축소판 | **가능**(소형 정책) | 직접 짠 작은 트랜스포머 + 흐름 정합(식 5). Qwen-VL급 백본 없이 소형 시각 인코더로. 논문의 정책 규모(수 B 파라미터, 배치 1,024)는 불가 |
| 정책 전체(Qwen-VL + 행동 전문가) 학습 | **불가** | 32 H200, 1단계 43 h + 2단계 50 h. JoyAI-RA 가중치 비공개 |
| LAM 사전학습(23.3K 시간) | **불가** | 4,938 H200 GPU시간(`03` V4-5). 데이터 중 자체 수집 8.5K 시간은 비공개, Egocentric-10K 등 공개 출처는 수 TB 규모(크기 확인 전) |
| 정책 스케일링(손 동작, DreamDojo, LAPT × 1K/3K/5K) | **불가** | 한 번의 전체 파이프라인 약 9.6K GPU시간, 3 × 3 조합과 로봇 평가 |
| RoboTwin 2.0, RoboCasa-GR1 평가 | **조건부/불가** | 시뮬레이터 설치(승인), GPU 렌더링이 필요한 환경이 있음. 정책이 없어서 평가할 대상도 없음 |
| AgiBot G1 실로봇 평가 | **불가** | 로봇, 250시간 정렬 데이터(162,767 에피소드)가 비공개 |

**노력 추정(측정 전):** LAM 구조·손실 이식 3–5일, 합성 영상 또는 소형 공개 영상에서의 정렬 항 절제 1–2주, 소형 정책 1단계 축소판은 추가 1–2주. 논문 수치의 재현은 노력이 아니라 자원(GPU 약 1만 H200시간, 로봇, 비공개 데이터)이 막습니다.

**구현할 때 가장 위험한 부분:** (1) 손실 가중치의 척도(flow 3.3e-5, DINO 0.003, LPIPS 0.01, KL 1e-6, MSE 미기재)와 RAFT 출력 단위, (2) 사후 평균 z̄를 1단계 목표로 쓸 때의 척도·분포(KL 1e-6이면 분산이 크게 열려 있음), (3) 스케일링 비교에서 데이터 양과 에폭이 섞이는 문제, (4) 정렬 항 계산에 쓰는 고정 모델의 해상도(RAFT-large 입력 크기)와 비용.
