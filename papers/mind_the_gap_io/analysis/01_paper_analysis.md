## 1. 한 문단 요약

접촉이 많은 원격조작 데이터에는 로봇 실행 상태 E와 리더 명령 C가 함께 기록됩니다. 기존 방법은 E를 입출력으로 쓰는 E2E(UMI류), 또는 C를 출력으로 쓰는 E2C(ALOHA류)를 고릅니다. 저자들은 **EC2C**를 제안합니다. 입력에 E와 C 이력을 함께 넣고 출력은 미래 C로 둡니다. 명령과 실행의 차이(mismatch) ε = C − E가 접촉, 지연, 페이로드, 조작자 보상을 담는 감각 없는 신호가 됩니다. 저자들은 준정적 접촉에서 ε가 힘과 상관되고(Table 1, R² 0.98–1.00), 힘 센서 없이 플러그 삽입, 닦기, 던지기, 무게 분류에서 E2E와 E2C보다 낫다고 보고합니다. 추론 지연에는 **latency-adaptive inpainting**을 씁니다. 학습 목표는 바꾸지 않고, 지연 동안 이미 확정된 명령 접두부를 조건으로 넣습니다.

## 2. 방법

### 2.1 I/O 공간 (식 1–4)

- 식 (1): x^e_{t+1} = B(x^e_t, x^c_t; θ_t). 저수준 제어 스택 B(IK, PID, 지연, 접촉)을 블랙박스로 둡니다.
- 식 (2): x^c_t = x^des_{t+1} ⊕ Δ_t(x^e_t, θ_t), ε_t = x^c_t ⊖ x^e_t. 조작자 보상 Δ_t와 명령-실행 차이 ε_t를 정의합니다.
- 식 (3): 준정적·강체 접촉·안정 위치 제어·포화 없음 조건에서 F_ext ≈ K_x(x^e) ε. 이 근사가 "힘과 상관된 신호"라는 주장의 근거입니다. 그런데 K_x가 자세에 따라 달라지므로 단일 강성 상수로 바꿀 수 없다고 저자들도 씁니다(§4.2.1).
- 식 (4): 세 정책 정의. E2E는 E 이력에서 E 미래를 예측, E2C는 E 이력에서 C 미래를 예측, EC2C는 E와 C 이력에서 C 미래를 예측합니다. EC2C의 출력은 E2C와 같고 입력만 늘었습니다.

### 2.2 Latency-adaptive inpainting (식 5)

- 추론 지연 δ_inf 동안 로봇은 이전 명령 버퍼를 실행합니다. 접두부 길이는 d = ⌈δ_inf/Δt⌉입니다.
- 정책은 접두부 명령 X^{c,buf}와 마스크 M을 조건으로 받고 전체 청크를 예측합니다. 학습 때는 d ~ U[0, d_max]로 무작위화합니다. 생성된 접두부는 버리고 나머지만 실행합니다.
- 구현 방식: π0은 접두부 토큰을 미래 리더 상태와 현재 팔로워 상태의 연결로 만듭니다(B.2). DP는 노이즈 입력 채널에 명령 접두부와 마스크를 연결합니다(B.2).
- 학습 목표와 샘플러는 그대로입니다(B.3). **d_max 값은 논문에 없습니다.**

### 2.3 구현 세부 (부록 B, C)

- 좌표계: 각 팔의 로컬 베이스 기준 절대 자세 x ∈ R^7(xyz, rpy, 그리퍼 폭). 단일 팔 과제의 proprioception은 팔로워 7 + 리더 7 = 14차원, 양팔 Microwave는 4 × 7 = 28차원입니다. 맞습니다.
- 시각: 단일 팔은 손목 카메라 1대, Microwave는 손목 2대 + 1인칭 1대입니다. 본문 4.1은 "두 손목 + 헤드 카메라 1대"라고 씁니다. 용어만 다릅니다.
- 관찰 구간: 시각 T_img = 1. 고정 자세 과제(Microwave, Plug, Wipe)는 T_obs = 1, 동적 과제(Sorting, Tossing)는 T_obs = 9.
- 백본: π0 (PaliGemma-3B + 300M action expert), bf16, AdamW, lr 2.5e-5, batch 16, 30,000 스텝, A100 80GB 1장(C.1, Table 7). **DP의 학습 하이퍼파라미터(스텝, 배치, lr)는 없습니다.**
- 제어: 로봇 제어 60 Hz, 정책 입력 20 Hz, T_pred = 30, T_exec = 15 (C.2).

### 2.4 하드웨어와 과제 (4.1, 그림 4)

- 저비용 양팔 원격조작: ARX-R5 팔로워 2대, ARX-X5 리더 2대 (6-DoF). **힘, 촉각, 모터 전류 입력 없음**.
- 과제: Microwave (버튼 누르기, 물체 옮기기, 문 닫기, 4단계), Plug Clear / Blind (두 갈래 플러그 삽입), Surface Wiping (화이트보드 지우개로 미세 자국 지우기), Dynamic Tossing (운동 범위 밖 빈으로 던지기), Conveyor Weight Sorting (흔들리는 50 g / 350 g 물체 분류).
- 데이터 수집: DAgger식 복구 개입을 넣었습니다. 조작자는 접촉이 많은 과제에서 측면 카메라, 무게 분류에서 물체 질량 같은 **특권 정보**를 씁니다. 정책은 이 정보를 받지 않습니다(4.1).

## 4. 논문이 말하는 한계 (Sec. 5, 부록 C.2)

- ε는 접촉, 지연, 마찰, 중력, 페이로드, 제어 이득, 기구학 자세가 섞인 복합 신호입니다. 힘으로 보정해서 쓰면 안 됩니다(stick-slip, 비선형 컴플라이언스, 포화, 특이점 근처).
- 관찰 구간은 과제마다 다릅니다. 긴 이력은 무게 분류에는 필요하지만 닦기, 플러그에는 인과 교란을 일으킵니다.
- 학습된 ε 의미는 텔레오퍼레이션 장치, 저수준 제어기, 기구에 묶여 있습니다. 페이로드 실험은 **한 하드웨어 계열 안에서만** 강건성을 보입니다.

## 5. 읽으면서 본 문제 (상세는 와 )

1. **Table 3 π0 행은 두 요인이 섞여 있습니다.** EC2C는 inpainting, E2E와 E2C는 naive async로 실행했습니다(표의 "Inference" 열). 입출력 효과와 추론 방식 효과를 나눌 수 없습니다.
2. **"near chance"는 π0 E2C에서 맞지 않습니다.** 28/45 = 62%입니다. 0.5와의 차이는 p = 0.135로 유의하지 않지만 "거의 무작위"로 줄이기도 어렵습니다.
3. **통계 검정이 없습니다.** 모든 결과가 n = 10–50의 단일 비율입니다. 신뢰구간이나 학습 seed 반복이 없습니다. (`03` §1)
4. **지연 실험의 성공률 차이는 유의하지 않습니다.** 400 ms에서 40/50 대 45/50, p = 0.26입니다. Jerk에는 표준편차가 없습니다.
5. **Table 6의 100 ms 행이 두 방법에서 똑같습니다.** 성공 50/50, jerk 0.75가 둘 다 같습니다. 방법이 동일하게 작동하는지, 결과를 옮겨 적은 것인지 확인할 수 없습니다.
6. **d_max, DP 학습 세부, seed 수가 없습니다.** 재현 가능성을 떨어뜨립니다.
7. **공식 코드는 "Coming Soon"입니다** (프로젝트 페이지). 검증할 코드가 없습니다.
