# 03. 수치 재계산, 일관성 검사, 주장 판정

모든 계산은 `analysis/recompute.py`(수 초, CPU)가 하고 결과는 `recompute_results.json`에 있습니다. 표 12는 `table12_data.json`에 옮겨 두었습니다. 그래프는 `plot_figures.py`, 코드 쪽 마스크 확인은 `mask_check.py`입니다. 검사 번호는 V(재계산)와 K(일관성), 주장은 C입니다. 다른 번호와 섞이지 않게 논문 표 번호는 "표 N"으로 씁니다.

**전제.** 논문은 신뢰구간, 시드 수, 평가 횟수 표를 거의 싣지 않습니다. 아래 검정은 (1) 본문이 밝힌 평가 횟수를 쓰고, (2) 밝히지 않은 기준선의 횟수는 같은 횟수라고 **가정**합니다. 가정이 들어간 곳은 표시했습니다. 시도는 독립이고 학습은 시드 하나라는 가정이라, 실제 불확실성은 아래 값보다 큽니다.

## 4. 일반화 설정, 표 6, 저자 README (V17–V18)

- **V17 표 6 대 README**: 논문 표 6의 ImageWAM "Clean2Hard" 18.3과 README(2026-07-30 소식)의 "RoboTwin Clean2Random, 사전학습 없는 ImageWAM 대비 +40.9, 59.0%"를 맞추면 사전학습 없는 값이 59.0 − 40.9 = **18.1**이어서 논문의 18.3과 0.2점 다릅니다. 이름도 Hard와 Random으로 다릅니다. 같은 설정의 다른 이름일 가능성이 높지만 확인되지 않았습니다. README는 "π0.5 대비 +11.5"도 적어 π0.5는 47.5가 됩니다.
- 의미: 사전학습 없는 ImageWAM은 클린만 학습해 어려운 설정에서 18%대에 머물고, 저자가 InternData-A1(합성 로봇 데이터)로 사전학습하면 59.0%입니다. 즉 **"정책 사전학습이 필요 없다"는 분포 안 설정(표 1, 2)에 대한 주장이고, 일반화 설정에서는 사전학습이 +40.9점을 더합니다**(저자 README의 주장, 이 폴더는 재현하지 않음).
- **V18 표 6의 BagelVLA 비교**: 클린만 학습에서 ImageWAM 84.4 대 BagelVLA(키프레임 포함) 75.3, +9.1점. Clean2Hard에서는 ImageWAM 18.3 대 BagelVLA 키프레임 포함 20.9로 **낮고** 키프레임 없음 15.9보다 +2.4점입니다. 본문은 "비키프레임 설정에서 UniVLA와 BagelVLA보다 낫다"고 썼고 이 조건에서는 맞습니다. BagelVLA는 사전학습 모델입니다.

## 7. 효율과 비용 (표 5, 8–11)

- **V19 표 11 속도 향상**: Fast-WAM 기준 302 ms에서 1.15×(302/263 = 1.148), 1.56×(194), 3.78×(80), ImageWAM 1.53×(198), 3.55×(85), 3.92×(77), 4.38×(69). 모두 재계산과 일치합니다.
- **V20 표 5**: 1081/263 = 4.11배, 63.65/9.72 = 6.55배(초록 "1/4", "1/6" 부합). Fast-WAM 1스텝 대비 302/263 = 1.15배, 13.21/9.72 = 1.36배.
- **V21 접두부만 쓸 때**: Fast-WAM 194 ms, ImageWAM 198 ms(비율 1.02). 컴파일 후 80 ms 대 69 ms 차이는 ImageWAM에 최적화 단계(이미지 prefill 컴파일, 정적 그래프)가 더 적용된 결과이고, 같은 단계를 Fast-WAM에 적용한 값은 없습니다. 백본 크기도 다릅니다(Fast-WAM 약 5B 비디오 백본 + 1B 행동 전문가, ImageWAM 4B + 0.64B).
- 공식 코드의 추론 경로는 접두부만 쓰는 방식입니다(`04` D1). 표 5의 263 ms 변형("1× denoise")이 공개 코드에 있는지 확인되지 않았습니다.
- **V22 학습 비용(표 10)**: LIBERO FLUX.2 4B는 8 × 18 h = 144 H20-시간, 9B는 8 × 1.6일 = 307 H20-시간, RoboTwin은 8 × 5일 = 960 H20-시간입니다. 유효 배치는 LIBERO 4B 80(= 10 × 8), RoboTwin 표 10의 "48 × 8 = 384" 대 코드 12 × 4(accum) × 8 = 384로 같은 값입니다(accum이 3이라는 논문 서술과 4라는 코드가 다름, `04` D8).
