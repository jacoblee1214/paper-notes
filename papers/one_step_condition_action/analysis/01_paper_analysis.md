## 1. 한 문단 요약

UCA-Flow는 관측 두 스텝, 타임스텝 토큰, 구간(interval) 토큰, 노이즈가 섞인 행동 궤적 토큰을 **하나의 토큰 열**로 놓고, 그 위에서 여러 층의 셀프 어텐션을 돌리는 Transformer(Unified Condition-Action Transformer)를 씁니다(§3.2–3.3). 조건 토큰도 층마다 갱신되며, 마지막에는 행동 토큰의 출력만 쓰는 **평균 속도 u**(MeanFlow 계열) 예측기입니다. 학습은 평균 속도 u와 순간 속도 v를 함께 감독하는 **이중 통과(dual-pass)** 손실로 합니다(§3.4). 추론은 한 번의 순전파로 `x̂ = z1 − uθ(z1, 1, 1, o)`입니다(§3.1). 시뮬레이션은 Adroit 3개와 Meta-World 34개(37과제), 실로봇은 UR5e에서 2개 과제입니다(§4–5). 논문의 주장은 "조건을 외부 주입으로 두지 않고 행동과 함께 진화시키면 1 NFE에서도 정확도가 오른다"입니다.

## 2. 문제 설정과 방법

### 2.1 문제 설정과 흐름 정의 (§3.1)

- 입력은 관측 이력 `o`, 노이즈 궤적 `z_t`, 타임스텝 `t`, 구간 길이 `h`입니다. 출력은 구간 평균 속도 `uθ(z_t, t, h, o)`입니다.
- 경로는 `z_t = (1 − t)x + tε`, `v = ε − x`입니다(평균 흐름 관례). 구간은 `h = t − r`입니다.
- 한 스텝 추론은 `t = 1`, `h = 1`에서 `x̂ = z1 − uθ(z1, 1, 1, o)`입니다.

### 2.2 통합 토큰화 (§3.2, 식 1–4)

- 관측: 점군 특징 `p_i ∈ R^dp`와 로봇 상태 `s_i ∈ R^ds`를 이어 붙여 `c_i = φ_o([p_i; s_i]) + e_i^o`로 투영합니다(관측 두 스텝, `O = [c1, c2]`).
- 타임스텝과 구간: 사인 임베딩 `PE`를 두 개의 독립 MLP `φ_t`, `φ_h`에 넣고, 학습 가능한 토큰별 편향을 더해 `N_t`개 타임스텝 토큰 `τ_j = e_t + b_j^t`와 `N_h`개 구간 토큰 `η_j = e_h + b_j^h`를 만듭니다(식 1, 2). 논문은 `N_t`, `N_h` 값을 적지 않았습니다.
- 행동: 각 호라이즌 스텝을 `y_k = φ_a(z_{t,k}) + e_k^a`로 투영합니다(`T = 4`).
- 입력 열은 `S⁰ = [c1, c2, τ1…τ_Nt, η1…η_Nh, y1…y_T]`입니다(식 4).

### 2.3 통합 상호작용과 출력 (§3.3, 식 5–8)

- 각 블록은 조건과 행동 토큰을 **같은 셀프 어텐션**에 넣습니다(식 6). 조건 토큰은 현재 행동 토큰을 보고 갱신되고, 다음 층의 행동 토큰은 갱신된 조건을 봅니다.
- 마지막 층 뒤에는 조건 출력을 버리고 행동 토큰 `Y^L`만 씁니다(식 7). 출력 헤드 `ψ`는 하나입니다(식 8).
- 그림 3의 기울기 기반 민감도 지도는 질적 증거입니다. 정량 지표는 없습니다.

### 2.4 이중 통과 감독 (§3.4, 식 9–12)

- 첫 번째 통과는 `h = 0`으로 순간 속도 `vθ = uθ(z_t, t, 0, o)`를 냅니다.
- 두 번째 통과는 `h`를 쓰고 평균 속도 `uθ`를 냅니다. 평균 흐름 항등식에 따라 `D_t uθ = ∇_z uθ · sg(vθ) + ∂_t uθ + ∂_h uθ`(식 9)로 자코비안-벡터 곱을 구하고, 합성 속도 `Vθ = uθ + h · sg(D_t uθ)`(식 10)를 만듭니다.
- 손실은 `L = ρ(Vθ − sg(v)) + ρ(vθ − sg(v))`(식 11)입니다. `ρ`는 적응 가중 L2로, 식 12에서 `ρ(Δ) = sg( (‖Δ‖² + c)^{−(1−γ)} ) · ‖Δ‖²`입니다. `c`와 `γ`의 값은 논문 본문에 없습니다.
- 두 항은 가중 1:1입니다(코드 확인, `04` D4).

### 2.5 방법에서 확인되는 질문

1. **구간 샘플링.** `t`와 `r`의 분포, `r = t`의 비율은 본문에 없습니다. 식 9–10은 구간을 `h = t − r`로 쓰지만 `h = 0`과 `h = 1` 경계 사례의 샘플 비율은 적지 않았습니다.
2. **조건 토큰의 역할.** 조건 토큰이 층마다 갱신되는 이점은 주장되지만, 같은 파라미터 수와 같은 학습량의 대조(예: 조건 토큰을 고정 문맥으로 둔 모델)가 없습니다. 절제의 `Unified/c`, `Unified/a`는 어텐션 방식만 바꾼 것인지, 파라미터 수와 학습 예산을 맞췄는지 본문에 없습니다.
3. **"compact"의 근거.** 모델 파라미터 수, FLOPs, 메모리는 보고되지 않았습니다. 공식 설정(8층, 8헤드, 임베딩 384)으로 블록만 계산하면 약 1,400만 파라미터입니다(추정, `04` D9).

## 3. 실험 결과

### 3.1 설정 (§4.1, §5.1)

- 시뮬레이션: Adroit 3개(Hammer, Door, Pen), Meta-World 34개(Easy 21, Medium 4, Hard 4, Very Hard 5). 과제당 시연 10개, 시드 0, 1, 2, 평가는 매 200 에폭, "상위 5개 체크포인트"의 평균을 보고합니다.
- 학습: AdamW, 배치 128, 학습률 1e-4, 관측 창 2, 예측 호라이즌 4. Adroit과 Meta-World는 3,000/1,000 에폭(논문 본문). 점군은 FPS로 Adroit 1024점, Meta-World 512점입니다.
- 실로봇: UR5e 팔, RealSense L515 카메라(상단 시점), 과제 2개(Pick & Place, Drawer Close), 과제당 시연 40개, 호라이즌 16, 관측 간격 2, 300 에폭, 과제당 20회 시험.
- 하드웨어: 학습과 추론은 NVIDIA RTX A5000 한 장입니다. 지연은 "안정된 GPU 부하에서 시드 세 개를 동시에 돌리며" 측정했다고 적었습니다.

- 지연(과제 가중 평균): UCA-Flow 3.0 ms (1 NFE), MP1 6.8 ms (1 NFE), FlowPolicy 12.6 ms (1 NFE), DP3 132.2 ms (10 NFE), Simple DP3 97.0 ms (10 NFE).
