## 1. 문제와 주장

VLA 모델은 대개 수십억 파라미터이고, 학습과 배포 비용이 커서 소규모 연구실과 개인이 쓰기 어렵습니다. 논문은 세 가지를 내세웁니다(§1, §3).

1. **작은 모델:** 450M(주 모델)으로 "단일 GPU 학습, 소비자 GPU 또는 CPU 배포"를 목표로 합니다(초록).
2. **커뮤니티 데이터:** Hugging Face에서 가져온 481개 커뮤니티 데이터셋(약 22.9K 에피소드, 10.6M 프레임, Table 1)으로 사전학습합니다. 사전학습 로봇 데이터가 없는 VLM에서 출발합니다.
3. **비동기 추론:** 관측 처리와 행동 예측을 행동 실행과 분리해 제어 주기를 높입니다(§3.3, Algorithm 1, §4.6).

핵심 주장은 "10배 큰 VLA와 비슷한 성능"(초록)입니다.

## 2. 방법

### 2.1 구조 (§3.1, Figure 1)

- **VLM 백본:** SmolVLM-2(§3.1, §4.3). 공개 코드의 기본값은 `HuggingFaceTB/SmolVLM2-500M-Video-Instruct`입니다. 첫 **16개 층만** 씁니다(`num_vlm_layers=16`). 즉 N = L/2(§3.1)입니다.
- **시각 토큰:** 타일링을 쓰지 않고 전역 이미지 하나와 픽셀 셔플로 프레임당 **64 토큰**(§3.1)입니다. 입력 해상도는 512×512(§4.3)입니다.
- **상태:** 센서모터 상태는 선형 투영으로 **토큰 하나**가 되어 VLM 입력(prefix)에 들어갑니다(§3.1). 표 11은 이것이 액션 전문가 입력(suffix)보다 낫다고 보입니다.
- **액션 전문가:** 흐름 매칭(flow matching) 트랜스포머입니다. 은닉 폭은 VLM의 **0.75배**(§3.1, 표 9)입니다. VLM의 16개 층 각각의 키·값을 읽는 **교차어텐션(CA)과 인과 자기어텐션(SA)을 번갈아 쌓는 구조**입니다(§3.1, 표 6). 동작 토큰의 SA는 인과 마스크입니다(표 7).
- **출력:** 청크 n = 50개 행동(§4.3). 추론 시 흐름 적분 10 스텝(§4.3).
- **파라미터:** 총 450M, 그중 액션 전문가 약 100M(§4.3). VLM은 동결하고 액션 전문가만 학습합니다(§4.3).

### 2.2 학습 (§4.3)

- 사전학습 200,000 스텝, 전역 배치 256, 4 GPU, AdamW(β = 0.9, 0.95), 학습률 1e-4 → 2.5e-6 코사인 감쇠, 100 스텝 워밍업.
- 시뮬레이션 미세조정 100,000 스텝(배치 64), 실로봇 미세조정 200,000 스텝.
- bfloat16, `torch.compile`, accelerate를 씁니다.
- "프로젝트 전체가 약 30k GPU 시간을 썼다"고 적었습니다(§4.3).

### 2.3 데이터 정리 (§3.2, 부록 A.1)

- **과제 문장 재작성:** Qwen2.5-VL-3B로 과제 설명을 짧은 행동 문장으로 다시 씁니다(프롬프트는 A.1).
- **카메라 정규화:** 카메라 이름을 사람이 손으로 top, wrist, side 순서로 매핑해 OBS_IMAGE_1–3로 바꿉니다(§3.2).

### 2.4 비동기 추론 (§3.3, Algorithm 1, Figure 2–3)

- 로봇 클라이언트가 행동 큐가 임계 g(분율) 아래로 떨어지면 관측을 보냅니다. 서버는 청크를 계산해 돌려주고, 클라이언트는 겹치는 시점을 합칩니다.
- 관절 공간에서 거의 같은 관측은 ε(논문에 값 없음)보다 가까우면 버립니다. 큐가 빈 경우는 예외입니다.
- Figure 3의 g = 0.7은 설명용 예시입니다. **실험에 쓴 g와 ε 값은 논문에 없습니다.**

## 3. 실험

### 3.1 설정 (§4.1–4.2)

- **LIBERO:** 네 스위트(Spatial, Object, Goal, Long), 각 10과제, 과제당 10회(§4.1). 데이터는 `physical-intelligence/libero`(1,693 에피소드).
- **Meta-World:** MT50, 과제당 50회 시연(2,500 에피소드). 난이도 네 단계(Easy, Medium, Hard, Very Hard)로 묶은 평균을 씁니다.
- **실로봇:** SO100 세 과제(Pick-Place, Stacking, Sorting, 각 50시연: 5위치 x 10), SO101 한 과제(Pick-Place-Lego). 사전학습 데이터에는 SO101이 없습니다(§4.1).
- **지표:** 성공률. 실로봇은 부분 점수를 씁니다(0.5 단위, Sorting은 0.25 단위, §4.1).
- **비교 대상:** π0(Paligemma-3B, 3.3B, LeRobot 제공), ACT(약 80M, 과제별 학습)(§4.4). LIBERO와 Meta-World 표에는 Diffusion Policy, Octo, OpenVLA, TinyVLA도 있습니다.

## 4. 한계 (논문 §5.1)

논문이 직접 밝힌 한계는 여섯 가지입니다. 단일 로봇(SO100) 데이터, 약 23k 궤적으로 작은 데이터 규모, 0.5B 미만 모델 크기, 문서·OCR 중심 VLM 백본의 적합성, 로봇 데이터와 멀티모달 데이터의 공동 학습 미탐색, 긴 과제 적용 한계, 모방 학습 중심(강화학습 미사용)입니다.

## 5. 주장과 증거의 틈 (V-검사 결과, 상세는 `03_analysis.md`)

1. **"Vision-only 정책" 설명 없음:** 논문은 상태를 VLM에 넣는 설계를 강조합니다(표 11). 그러나 상태가 어떻게 정규화되고 몇 차원이 쓰이는지는 코드 쪽(`04` D11)에서만 확인됩니다.
2. **"10배 큰 VLA와 비슷"은 평균과 기준선 선택에 달려 있습니다.** LIBERO 평균에서 SmolVLA 0.45B(87.3)는 π0 3.3B(86.0)보다 1.3점 높지만, 차이는 통계적으로 구별되지 않습니다(이항 가정 p ≈ 0.59). 표 2의 π0 값 86.0은 다른 공개 분석에서 인용한 π0 LIBERO 평균 94.2와 다릅니다.
3. **효율 주장에 측정이 없습니다.** "π0보다 약 40% 빨리 학습하고 메모리는 6배 적게 쓴다"(§4.5)는 표나 그림이 없습니다. CPU 배포와 소비자 GPU 배포도 지연과 메모리 측정이 없습니다.
4. **"단일 GPU 학습"과 "30k GPU 시간"의 대조.** 초록은 단일 GPU 학습을 강조하지만, 사전학습은 4 GPU, 프로젝트 전체는 약 30k GPU 시간입니다(§4.3). 재현 비용은 이 규모를 기준으로 봐야 합니다.
5. **통계 보고 부재:** 시드 반복, 신뢰구간, 표준편차가 성공률에는 없습니다(그림 5의 시간 표준편차만 있음). 실로봇 시행 수는 보고되지 않았습니다.
6. **어블레이션 기준선 불일치:** 표 6의 "제안" CA+SA는 85.5인데, 같은 설정이라고 주장하는 표 10·11·12·13의 기준선 행은 80.3입니다. 표 6의 과제별 값(86/99/90/67)은 다른 표의 기준선(89/94/85/53)과 맞지 않습니다. 어떤 행이 실제 기본 설정인지 논문만으로는 정해지지 않습니다.
7. **전문가 폭 선택의 근거가 표와 맞지 않습니다.** 표 9에서 0.75(77.5)는 0.50(80.3)보다 낮습니다. 그런데 본문은 0.75를 "균형"이라고 하고, 주 모델도 0.75를 씁니다.
8. **사용 층 수 주장:** 표 8에서 격층 건너뛰기(75.5)는 VLM-256M(75.8)보다 낮습니다. 본문의 "건너뛰기가 작은 VLM보다 낫다"는 수치로는 성립하지 않습니다.
9. **청크 크기 선택:** 표 12에서 청크 10(84.0)이 주 모델의 청크 50(80.3)보다 높습니다. 본문은 10–50을 "균형"이라고만 하고 50을 고른 이유를 설명하지 않습니다.
10. **"흐름 매칭이 크게 낫다":** 5점 차이는 독립 가정 이항 검정에서 p ≈ 0.09로, 시드 반복 없이는 "유의하다"고 말하기 어렵습니다.
11. **데이터셋 개수 불일치:** 본문과 표 1은 481개입니다. 부록 A.1 목록에서 고유 ID를 세면 **532개**입니다(`recompute.py` V7). 목록은 이후 버전에서 바뀌었을 수 있습니다.
12. **표 1 캡션:** "~10M episodes"라고 적었지만 표의 10.6M은 프레임 수입니다.
13. **실로봇 평가 세부:** 시행 횟수, 시작 위치별 횟수, 채점자 정보가 없습니다. 실로봇 평가 데이터셋 3개(svla_so100_*)와 SO101 데이터셋은 A.1 목록에 없습니다. 그래서 사전학습 누출 가능성은 낮습니다.
14. **본문 표기 오류 몇 개:** "For the SO101 benchmark, the model is trained on a combination of three datasets"(§4.5)는 실제로는 SO100 표 3을 가리킵니다. 표 2의 Meta-World 베이스라인에서 TinyVLA를 "Zhou et al., 2024"로 인용하는데, 참고문헌의 Zhou et al.은 TinyLLaVA입니다(TinyVLA는 Wen et al., 2024). π0 파라미터 표기도 맞지 않습니다. LIBERO 행은 Paligemma-3B, Meta-World 행은 3.5B-Paligemma입니다. "Swayer"는 Sawyer의 오타입니다.
15. **학습 계획과 학습률 스케줄 세부:** 본문 100 스텝 워밍업은 코드 기본값 1,000과 다릅니다(`04` D1). 코사인 감쇠 길이는 본문에 없습니다.
16. **"Trained end-to-end"와 "VLM 동결" 모순:** 서론은 "end-to-end 학습"이라 쓰지만 §4.3과 §4.7, 코드 모두 VLM을 동결합니다.
