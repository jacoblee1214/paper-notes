## 1. 실로봇 정책 (표 2) 재계산

칸마다 10회, 표 주석이 "각 항목은 10회 중 성공 수"라고 적었습니다(시행 수는 논문 기재).

### V1. 합계와 Wilson 95% 구간

| 방법 | pick-and-place | squeeze (Chips 제외) |
|---|---|---|
| Continuous gripper | 44/90 = 48.9% [38.8, 59.1] | 6/80 = 7.5% [3.5, 15.4] |
| Binary gripper | 84/90 = 93.3% [86.2, 96.9] | 0/80 = 0% [0, 4.6] |
| **ForceBand** | **80/90 = 88.9% [80.7, 93.9]** | **72/80 = 90.0% [81.5, 94.9]** |

- 합계는 9개 물체가 같은 정책의 독립 시행이라는 가정입니다. 물체별 시행 수 10은 논문 기재, 합산은 가정입니다.
- ForceBand의 pick-and-place는 이진 그리퍼보다 4회 낮고(p = 0.43, Fisher), 연속 그리퍼보다는 높습니다(p = 7e-9). Chips(7/10 대 10/10)와 BBQ(6/10 대 7/10)에서 이진 그리퍼가 앞서고 칸 단위로는 구분되지 않습니다(Chips p = 0.21).

### V2. 초록의 "87%"

| 정의 | 값 |
|---|---|
| pick-and-place 합산 80/90 | 88.9% |
| squeeze 합산 72/80 | 90.0% |
| squeeze가 필요한 물체는 squeeze, Chips는 pick: (72 + 7)/90 | 87.8% |
| 같은 정의의 물체별 비율 평균 | 87.8% |
| pick·squeeze 칸 모두 합산 (80 + 72)/170 | 89.4% |

- 정수 시행 수로 87%에 반올림되는 값은 78/90(86.7%)이고, 표에서 만든 가장 가까운 정의는 79/90(87.8%, 소수 첫째 자리 반올림 시 88%)입니다. 소수점 아래를 버린 값이면 87%와 맞습니다. 논문은 87%의 정의를 적지 않았습니다(K4).

### V3. 방법 간 비교 (합산, 시행 수 가정)

- squeeze: ForceBand 72/80 대 연속 그리퍼 6/80 (p = 2e-28), 대 이진 그리퍼 0/80 (p = 1e-36). 이진 그리퍼는 힘 프로파일을 낼 수 없으므로 이 비교는 구조에서 정해집니다.
- 물체별 squeeze(ForceBand 대 연속, Fisher, Holm 보정 8개): 가장 약한 칸이 Face Wash(10/10 대 4/10, p_Holm = 0.022)와 BBQ(6/6 대 0, p_Holm = 0.022)이고 모두 0.05 미만입니다.

### V5. 칸 단위 불확실성과 검정력

- 10회 중 9회 성공의 Wilson 구간 폭은 0.39이고, 10/10의 하한은 72%입니다. 물체별 성공률 차이로 방법을 가르기에는 칸 하나의 정밀도가 낮습니다.
- 이진(93%) 대 ForceBand(89%)의 pick-and-place 차이를 80% 검정력으로 가르려면 팔당 약 640회가 필요합니다(정규 근사). 이 차이는 이 표로 판단할 수 없습니다.

## 4. 토이 (CPU, 합성 신호)

실제 sEMG 모델이나 자료를 쓰지 않은 사고 실험입니다. 가정이 결과를 정하므로 논문 수치의 검증이 아닙니다.

### T1. 이득 불일치와 짧은 보정 (`toy_calibration.py`)

접촉 on/off 힘 신호(접촉 평균 2 s, 비접촉 평균 3 s)에 대해 모델 출력 = 이득 × (신호 + 평활 잡음)이고 상관이 약 0.6이 되게 잡음을 두었습니다. 예측의 표준편차가 정답의 약 2.9배가 되게 이득을 둡니다(저장소 README 제로샷 수치에서 역산한 값).

| 보정 길이 (s) | 시험 r2 중앙값 (10–90% 구간) |
|---|---|
| 보정 없음 | −5.1 |
| 5 | 0.04 (−0.51, 0.30) |
| 10 | 0.24 (−0.12, 0.35) |
| 20 | 0.29 (0.09, 0.36) |
| 40 | 0.31 (0.20, 0.37) |
| 160 | 0.34 (0.28, 0.39) |

- 이 합성 세계에서는 두 모수(이득, 오프셋)만 맞추면 되므로 수십 초의 짝 데이터로 r² = 0.36 수준(이득만 틀린 모델이 이를 수 있는 상한)에 닿습니다. 실제로 전극 위치가 바뀌어 "모양" 자체가 달라지는 경우는 이 토이에 없으므로, 15분 보정이 필요한 이유(모양 변화)는 이 토이로 판단할 수 없습니다.
- 확인한 것: 상관이 같아도 r2가 크게 음수일 수 있고, 이득 불일치만 있다면 매우 짧은 보정으로 해소됩니다.

### T2. 직전 힘 입력의 이득 상한 (`toy_calibration.py`)

공식 코드의 모델은 직전 창의 마지막 정답 힘을 입력으로 받습니다(`04` D5). 10 s 창에서 "직전 값을 그대로 유지"하는 예측의 MAE를 0 예측, 전체 평균 예측과 비교했습니다(힘 단위 임의).

| 접촉 평균 지속 시간 | 0 예측 | 전체 평균 | 직전 값 유지 |
|---|---|---|---|
| 0.5 s | 3.2 | 5.5 | 5.5 |
| 1 s | 5.7 | 8.5 | 8.5 |
| 2 s | 8.9 | 10.9 | 10.8 |
| 5 s | 14.1 | 11.9 | 10.5 |

- 접촉이 몇 초 이내로 끝나는 합성 신호에서는 직전 값이 창 전체 예측에 주는 정보가 평균과 거의 같습니다. 접촉이 5 s 정도로 길어야 직전 값 유지가 평균보다 약간 낫습니다. 직전 힘 입력이 10 s 창의 평가를 크게 유리하게 만드는지는 접촉 지속 시간에 달려 있고, 이 가정 아래에서는 이득이 작습니다. 저장소 자체가 제공하는 `rollout` 평가의 결과는 이 문서에서 실행하지 않았으므로 알 수 없습니다.
