## 1. 한 줄 요약과 주장

휴머노이드 전신 제어(WBC)를 **여러 로봇의 롤아웃을 한 PPO 배치에 섞어 하나의 공유 인과 Transformer를 학습하는 문제**로 바꿉니다. 사람 중심 명령 토큰 공간(사람 전신, 로봇 기준 모션, 희소 VR 5점)을 정렬하고, 로봇별로는 고유감각 인코더·로봇 모션 인코더·행동 디코더만 둡니다(초록, §1, §3).

저자 주장(§1의 기여 세 가지):
1. 학습 단위를 로봇별 정책에서 **다중 로봇 공동 학습**으로 옮긴 형식화.
2. 공유 의미와 로봇별 실행을 나누는 구조(정렬된 명령 토큰, 공유 시간 백본, 가벼운 로봇별 모듈).
3. 공동 학습과 구성 요소의 효과, 다중 명령원 일관성, 외부 모션 추종, 토큰 검색, 실로봇 배치 실험.

## 2. 방법 (§3, 부록 A)

### 2.1 문제 설정 (§3.1)

- 로봇 i마다 MDP Mi = (Si, Ai, Ti, R, γ). 상태·행동·동역학은 로봇별이고 보상군 R과 γ는 공유입니다.
- 행동자 관측: 고유감각 s^p = (q, q̇, ω, g, a_{t-1})와 명령 하나 s^c. 평론가는 여기에 로봇 몸체 링크 위치·방향과 기저 선속도를 더 받습니다(비대칭).
- 입력 차원이 로봇마다 달라서 **관측과 행동을 최대 차원으로 패딩**해 한 배치에 섞고, 실행 때는 해당 로봇의 유효 행동 차원만 씁니다. 부록 표 A7: 고유감각 102, 행동 32, 평론가 399.
- 보상 r = R_track + P (부록 표 A1). 추적 항은 루트 위치(σ 0.3, 가중치 0.5), 루트 방향(0.4, 0.5), 몸체 위치·방향(상대, 0.3·0.4, 가중치 1.0), 몸체 선속도(1.0), 각속도(3.14)이고, 벌점은 행동 변화율 −0.1, 관절 한계 −10, 비허용 접촉 −0.1(힘 > 1 N)입니다.

### 2.2 명령 인코딩 (§3.2)

| 경로 | 입력 | 인코더 | 차원 (표 A7) |
|---|---|---|---|
| 사람 전신 | 모션캡처 22 관절 x 12 | **공유** | 264 |
| 희소 VR | 머리와 사지 끝 5점 x 12 | **공유** | 60 |
| 로봇 기준 모션 | 로봇 몸체 14개 x 12 | **로봇별** | 168 |

한 점(몸체)의 12값은 위치 3, 6D 방향 6, 선속도 3입니다. 목표는 루트 중심 또는 로봇 중심 좌표로 정규화됩니다. 학습 중 롤아웃마다 세 경로 중 하나를 1:1:1로 뽑아 에피소드 내내 백본 입력으로 씁니다(§3.4).

### 2.3 공유 백본과 로봇별 모듈 (§3.3, 식 (1))

- 현재 관측 토큰 = [명령 토큰 z_c ; 고유감각 토큰 z_p^i]. 인과 Transformer B_θ가 길이 L의 창(L = 32)을 처리해 행동 토큰 h_t^i를 냅니다(식 1). 실행 때는 KV 캐시로 새 토큰만 처리합니다.
- 로봇별 모듈은 로봇 ID로 고르는 **고유감각 인코더와 행동 디코더**(가벼운 층)입니다. 로봇 모션 인코더도 로봇별입니다.
- 네트워크(표 A8): 명령·상태 인코더 4개는 MLP [256, 256, 64], 융합 128 → 224, 행동자와 평론가의 별도 Transformer(깊이 3, 헤드 8, 헤드 차원 32, 창 32), 출력 224 → 32와 224 → 1. MLP 기준선은 같은 인코더에 백본만 [1024, 768, 384]로 바꿉니다.

### 2.4 학습 (§3.4, 식 (2))

- Isaac Lab에서 로봇 9종이 **같은 학습 틀 안에서 롤아웃**하고, 모든 전이가 하나의 PPO 배치로 섞여 공유 모듈과 활성 로봇별 모듈을 갱신합니다.
- 목적함수: **L = L_PPO + λ_align L_align**, λ_align = 1.0. L_align은 같은 모션 클립의 세 정규화 명령 토큰 사이 쌍별 MSE(세 쌍 동일 가중)입니다.
- 종료: 루트 높이 오차 > 0.25 m, 루트 방향 거리 > 0.8 rad, 끝단 수직 오차 > 0.25 m (표 A2).
- 적응적 모션 샘플링: 실패율 기반 구간 샘플링과 일관 실패 구간 제거(표 A4). 도메인 무작위화: 마찰, 반발, 기본 관절 위치, 기저 질량중심, 주기적 루트 속도 교란(표 A5).
- 규모(§4.1): 9종 로봇 x 1024 환경, H100 8장, 약 2일, 50 Hz, 이력 32 스텝, BONES-SEED 약 200시간(50 Hz로 재표본). 리타게팅은 GMR을 평활화와 로봇별 파라미터로 수정했습니다.

## 3. 실험과 수치 (§4)

### 3.1 평가 설정

- 표 1: Unitree G1(29DoF)과 H2를 **학습에 쓴 BONES-SEED 모션**에서 평가합니다. 저자도 "독립 모션 말뭉치에 대한 일반화가 아니라 분포 내 구조·적합 평가"라고 씁니다(§4.1). 평가 시도 수, 시드, 종료 규칙은 표 1에 대해 밝히지 않습니다.
- 표 2: 외부 모션 100STYLE(한 배우, 스타일 100개 x 이동 범주 8개 = 800 클립, 50 Hz로 133.02분)을 가중치 고정으로 평가합니다. 클립 종료 기준은 골반 높이 오차 > 0.25 m, 수직 투영 중력 성분 차이 > 0.8, 손목·발목 높이 오차 > 0.25 m. 클립당 결정적 롤아웃 한 번(시드 42, 평지, 무작위화 없음)이고 MPKPE와 속도 오차는 실패한 부분 롤아웃까지 활성 걸음 전체에서 평균합니다.

### 3.4 그림 3과 그림 4

- 그림 3 왼쪽: 9종 로봇의 성공률과 MPKPE(막대, 수치 표기 없음). 우리가 막대 높이에서 읽은 근사값은 `03` §4에 있습니다(GR3 성공률 약 83%, Adam MPKPE 약 113 mm가 가장 나쁨).
- 그림 3 오른쪽: 명령 토큰 검색 Recall@1. 교차 출처(같은 로봇의 사람·VR·로봇 토큰 사이) 같은 위상 86.0%, 같은 모션 94.2%. 교차 로봇(로봇 모션 토큰) 61.3%, 76.1%. 우연 수준 0.17%와 1.04%.
- 그림 4: 실로봇 G1, R1, H1-2, H2에서 희소 VR 상체 포즈와 하체(축구 킥, 잔디 달리기)의 **정성적 사진**. 성공 횟수, 시도 수, 지표는 없습니다(§4.5가 "정량적 교차 방법 하드웨어 비교는 앞으로의 과제"라고 인정).

## 4. 한계 (§6, 저자)

- 휴머노이드만 다룹니다. 로봇별 명령·고유감각 인코더, 행동 디코더, 제어 로직, 로봇별 리타게팅이 배포 파이프라인에 남습니다.
- 실로봇은 **Unitree 네 종**뿐이고 동작 범위가 제한적입니다. 센서 결측, 통신 지연, 상태 추정 잡음, 지속 교란에 대한 강건성은 평가하지 않았습니다.
- 미래: 미지 휴머노이드에 새 로봇별 모듈 없이 쓰는 영샷 X-WBC(로봇 기술에서 센싱·행동 매핑을 유도하는 형태 조건부 인터페이스).

## 6. 이 저장소에서 확인한 것

- 보상 식·가중치·σ와 종료 한계(0.25 m, 0.8)가 BeyondMimic의 공식 코드 설정과 같습니다(`03` K9). 부록 A.1은 이 출처를 밝히지 않습니다(§3.4 "적응적 샘플링"만 [4, 5]를 인용).
- 부록 표 A7의 차원은 서로 맞습니다(264 = 22 x 12, 60 = 5 x 12, 168 = 14 x 12, 102 = 32 x 3 + 6, 399 = 102 + 168 + 129). 399는 "몸체 14개 x 9 + 기저 선속도 3 = 129"를 평론가 특권 항으로 두면 정확히 나옵니다(우리 추정, 논문에 분해 없음).
