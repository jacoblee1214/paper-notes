# 03. 수치 재계산과 일관성 검사

논문 표의 수치를 옮겨 다시 계산했습니다 (`analysis/recompute.py`, 수 초, 결과 `recompute_results.json`). 재현은 하지 않았습니다. 학습, 시뮬레이션, 기준선 실행은 하지 않았습니다. 토이도 만들지 않았습니다. 이 논문의 핵심 주장은 학습된 MfM과 RfD가 MPM과 결합한 결과인데, 그 결합은 GPU와 데이터가 있어야 확인할 수 있고, 작은 토이로는 PhysTwin이나 PGND와의 비교를 대신할 수 없기 때문입니다.

## 1. 표 2: 미래 예측 (PhysTwin 대비 상대 변화, %)

양수는 PhysCoRe가 더 좋다는 뜻입니다. IoU, PSNR, SSIM은 높을수록 좋은 지표라서 부호를 맞췄습니다.

| 지표 | 탄성: 대 PhysTwin | 탄소성: 대 PhysTwin | 탄성: 대 PGND | 탄소성: 대 PGND |
|---|---|---|---|---|
| CD | **+43.7** | **+30.5** | +73.4 | +87.5 |
| Track | **+15.2** | **+8.3** | +80.6 | +87.4 |
| IoU | **−3.3** (PhysTwin이 높음) | +4.8 | +80.4 | +176.6 |
| PSNR | +2.3 | +6.1 | +34.7 | +52.2 |
| SSIM | **−2.3** (PhysTwin이 높음) | +0.4 | +193.2 | +253.1 |
| LPIPS | +2.5 | +15.6 | +53.4 | +70.5 |

(PGND 대비 값은 `recompute_results.json`의 `table2_vs_pgnd`입니다. PGND는 모든 지표에서 PhysCoRe보다 나쁩니다.)

**해석**
- 본문의 CD와 추적 손실 수치 (43.7, 30.5, 15.2, 8.3)는 재계산과 **일치**합니다 (`claim_checks`).
- 탄성 객체에서 IoU와 SSIM은 PhysTwin이 더 높습니다. 본문은 "competitive on visual quality"라고 적었습니다. 초록의 "outperforms state-of-the-art baselines in prediction accuracy"는 **기하 지표와 탄소성에서만 전면적으로 맞고**, 탄성 시각 지표에서는 맞지 않습니다.
- 표 2는 CD와 추적 손실 단위를 적지 않았습니다.

## 2. 표 3: RfD 절제

| 재료 | CD 감소 (MfM → MfM+RfD) | 추적 손실 감소 |
|---|---|---|
| 탄성 | **13.1%** (0.01047 → 0.00910) | 6.1% (0.02723 → 0.02557) |
| 탄소성 | **17.8%** (0.00658 → 0.00541) | 15.7% (0.01981 → 0.01670) |

- 본문의 13.1%와 17.8%는 **일치**합니다.
- 추적 손실 감소는 본문에 없습니다. 탄성에서는 6.1%로 작습니다.
- 표 3의 MfM+RfD 행은 표 2의 PhysCoRe 행과 같습니다 (소수 다섯째 자리까지). 일관됩니다.
- **중요한 단서 (코드 기준):** 공식 코드에서 "MfM only"의 전반부 식별 구간은 관측 추적 PID 보정을 쓰는 것으로 보입니다 (`04` D3). 표 3의 차이는 RfD 효과만 분리한 값이라고 보기 어려울 수 있습니다. 이 점은 논문에 적혀 있지 않습니다.

## 3. 표 4와 표 5: 계획과 실행 시간

**표 4 (계획, Chamfer 거리 mm, 과제 2개)**

| 과제 | PGND | PhysTwin | PhysCoRe | 개선 대 PhysTwin | 개선 대 PGND |
|---|---|---|---|---|---|
| 밧줄 S자 | 48.8 | 17.3 | 6.2 | 64.2% | 87.3% |
| 수건 접기 | 30.6 | 7.1 | 5.3 | 25.4% | 82.7% |

- 과제마다 한 번씩 보고된 것으로 보입니다. 반복 횟수와 분산이 없습니다. 차이가 실행 잡음보다 큰지 판단할 수 없습니다.
- 수건 과제에서 PhysTwin 대비 개선은 25%입니다. 같은 "PhysCoRe가 최선"이라도 과제마다 크기가 다릅니다.

**표 5 (실행 시간, s, 12개 평가 에피소드 평균)**

| 방법 | 식별·최적화 | 테스트 롤아웃 |
|---|---|---|
| PhysTwin | 930.0 | **7.6** |
| PGND | 8280.0 | **1.9** |
| PhysCoRe | **11.4** | 8.5 |

- 식별 속도 향상: 대 PhysTwin 81.6배, 대 PGND 726배 (재계산 일치).
- **본문에 없는 점:** 테스트 롤아웃은 PhysCoRe (8.5 s)가 PhysTwin (7.6 s)보다 **11.8% 느립니다.** 본문은 "PGND is faster in this column"만 적었습니다. PhysTwin이 더 빠르다는 말은 없습니다.
- 본문의 "110 ms per predicted frame"과 8.5 s를 맞추면 에피소드당 약 77 프레임입니다. 에피소드 길이는 논문에 없습니다.
- v1의 테스트 시간은 11.3 s였습니다 (`01` §0). v2/v3에서 8.5 s로 바뀌었고 이유는 없습니다.
- 측정 조건 (입력 프레임 수, 서브스텝, 동시 실행 여부, PhysTwin의 최적화 반복 수)은 적혀 있지 않습니다. 식별 시간 11.4 s에 PID 보정이 포함되는지도 모릅니다.

## 4. 통계 검정: 할 수 없는 이유와 필요 조건

- 표 2는 **평균만** 있습니다. 에피소드별 값, 표준편차, 구간, 검정이 없습니다.
- 평가 에피소드는 12개이고 (표 5 설명), 탄성과 탄소성으로 나누었습니다. 객체 유형별 개수는 적혀 있지 않습니다. 따라서 표 2의 각 행의 n은 12보다 작습니다.
- 정확한 검정은 불가능합니다. 대신 **"p < 0.05가 되기 위해 에피소드별 차이의 표준편차가 얼마 이하여야 하는가"**를 계산했습니다 (n = 12를 상한으로 가정, t 임계값 2.201).

| 대상 | 평균 차이 | p < 0.05를 위해 필요한 차이 SD 상한 | SD 상한 / PhysTwin 평균 |
|---|---|---|---|
| 탄성 CD | 0.00707 | 0.01113 | 68.8% |
| 탄성 추적 | 0.00459 | 0.00722 | 24.0% |
| 탄소성 CD | 0.00237 | 0.00373 | 47.9% |
| 탄소성 추적 | 0.00151 | 0.00238 | 13.1% |

- 탄소성 추적 손실은 차이 SD가 평균 PhysTwin 값의 13% 이하여야 유의합니다. 에피소드마다 개선 폭이 거의 같아야 한다는 뜻입니다.
- 참고 상한: 12개 모두 같은 방향이면 양측 부호 검정 p = 0.00049입니다. 실제 자료가 이런지는 모릅니다. 이것은 결과가 아니라 가능한 상한입니다.
- 결론: **통계적 유의성은 이 논문의 공개 자료로는 판정할 수 없습니다.** 저자에게 에피소드별 값을 요청해야 합니다 (`04` §6).

## 7. 재계산하지 못한 것

- 에피소드별 CD와 추적 손실, 분산, 구간 (표 2, 5)
- IoU, PSNR, SSIM, LPIPS 계산 (코드 없음, `04` D8)
- 기준선 PhysTwin, PGND의 실행 값 (코드는 공개, 실행하지 않음)
- 계획 실험 (코드와 로봇 없음)
- 그림 3–4 신뢰도 맵의 정량 분석 (데이터와 렌더 필요)
- 학습 시드 변동 (시드 1개로 보임. 논문에 기재 없음)
