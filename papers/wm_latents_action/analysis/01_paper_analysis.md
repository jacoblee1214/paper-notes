## 1. 한 문단 요약

저자들은 비디오 세계모델의 잠재 표현이 행동을 얼마나 복원할 수 있는지를, 공통 역동역학(inverse dynamics, ID) 프로브로 비교합니다. 대상은 이미지 자기지도, 비디오 사전학습(V-JEPA 2, VideoMAE), 재구성 오토인코더(SDXL VAE, Cosmos-1), 픽셀 확산(DIFF), 단축 강제 동역학(Dreamer 4), 잠재 행동 양자화(LAPA)입니다. LIBERO 보류 과제의 **고정된 4개 과제 부분집합**에서 픽셀 충실도(PSNR)가 높은 모델이 행동 복원도가 0 이하일 수 있고, 비디오로 사전학습한 인코더가 가장 높은 행동 판독을 보입니다. ID 보조 손실은 V-JEPA와 VideoMAE에서 큰 이득을 주고, 이 이득은 **올바른 전이-행동 짝짓기**에 의존합니다(26개 보류 과제, 쌍체 대조). 폐루프 실험(π0.5 목표 교체)에서는 LIBERO-10 위치 이동 성공률이 올랐지만 전체 LIBERO-PRO 평균은 오르지 않았습니다.

## 2. 문제 설정과 방법

### 2.1 문제 설정 (§1–§3)

- 질문: 프리즈된 비디오 세계모델 잠재 공간이 언제 행동 관련 구조를 가지며, ID 보조 손실이 이 구조를 어떻게 바꾸는가 (§1).
- 벤치마크: LIBERO 130개 과제, 7자유도 행동(이동 3, 회전 3, 그리퍼 1). 과제 분할은 학습 104개, 보류 26개입니다(§3).
- 프로브 설정: 학습 과제 10개(처음 400 에피소드)로 프로브를 학습하고, 보류 과제 4개(처음 200 에피소드)에서 평가합니다. 절대 R² 값은 이 4개 과제에 대한 값이며, 26개 전체의 행동 복원도가 아닙니다(§3, §5).
- 프로브: MLP [D → 256 → 128 → 7], 3000 스텝, AdamW lr 3×10⁻⁴, 배치 512, 평균 풀링 특징, 프로브 시드 3개(§3).

### 2.2 ID 보조 손실 (§3, 부록 A, 식은 본문에 번호 없이 적힘)

- 손실: L = L_primary + λ · MSE(â_t, a_t), 인코더 행은 L_primary = 0으로 ID 손실만 씁니다(§3). 사전학습 인코더는 λ = 1.0, DIFF는 λ = 0.05입니다(§3).
- 헤드 형태 비교(DIFF, 부록 A 표 6): L2 역동역학 0.578, L1 역동역학 0.629, 단일 프레임 행동 예측 0.523, 순방향 동역학 0.408, 시간 대조 0.073입니다. 저자들은 L2를 기본으로 골랐습니다(WAM과의 비교 목적).
- 예측 구간 k (부록 A): k = 1 0.578, k = 2 0.587, k = 4 0.608, k = 8 0.546입니다. k = 1을 기본으로 씁니다.
- ID 헤드 자체의 구조(은닉층 크기, 활성화)와 학습 중 입력 클립 길이는 본문과 부록에 적혀 있지 않습니다. 공식 코드는 은닉층 (512, 256)과 GELU, 클립 길이 32를 씁니다(`04` D6).

## 3. 실험 결과

### 3.1 픽셀 충실도와 행동 재현도 (§4.1, 그림 1, 표 1)

- 그림 1: 같은 200개 보류 클립에서 PSNR과 행동 R²의 관계입니다. 저자들은 PSNR 20 dB 근처의 +ID 체크포인트 다섯 개가 R² 0.16–0.84로 퍼진다고 적었습니다. PSNR이 가장 높은 DIFF(행동 조건 없음)와 재구성 오토인코더는 R² ≤ 0입니다.
- 저자들의 해석은 "점 배치가 상관을 확정하지 않는다"입니다(그림 1 주석). 체크포인트마다 데이터, 구조, 스케일이 달라 원인을 분리할 수 없습니다.
- 표 1(프리즈 값): 비디오 자기지도(V-JEPA 2 0.40), DIFF(0.43), LAPA(0.41)가 [0.40, 0.46] 범위에 몰립니다. 따라서 **ID 없이는 계열을 가르기 어렵고**, 차이는 ID 적용 뒤에 나타납니다(§4.1 마지막 문단).

### 3.2 ID 보조 손실의 이득은 백본마다 다르다 (§4.2, 표 1, 표 14)

| 백본 | 프리즈 | +ID | Δ |
|---|---|---|---|
| V-JEPA 2 ViT-L | 0.40 | 0.84 | +0.44 |
| V-JEPA 2.1 ViT-B | 0.44 | 0.82 | +0.38 |
| VideoMAE V1 ViT-L | 0.46 | 0.75 | +0.29 |
| Web-DINO ViT-L | −0.01 | 0.16 | +0.17 |
| SigLIP 2 ViT-L | 0.05 | 0.17 | +0.12 |
| LAPA-LAQ-OpenX | 0.41 | 0.51 | +0.10 |
| DIFF | 0.43 | 0.57 | +0.15 |
| SDXL VAE | −0.55 | −0.41 | +0.14 |
| Cosmos-1 tokenizer | −0.36 | −0.29 | +0.07 |
| Dreamer 4 (276M) | −0.04 | −0.04 | 0.00 |

- 저자 주장: 비디오 사전학습이 이미지 자기지도보다 크게 앞서고, V-JEPA가 VideoMAE보다 앞섭니다(0.84 대 0.75). 다만 데이터와 목적이 함께 달라 원인은 분리되지 않았습니다(§4.2).
- 같은 크기 비교: V-JEPA 2.1 ViT-B(87M) + ID 0.82 대 DIFF + ID 0.57입니다. 모델 용량만으로 순위가 설명되지 않는다는 주장입니다.
- λ 스윕(부록 A, 표 5, 표 7): DIFF에서 λ = 0.01과 0.05의 R²가 0.598과 0.572로 거의 같고, Web-DINO와 SigLIP 2는 λ = 0.01–1.0에서 0.07–0.17 범위에 머뭅니다. 따라서 "λ 때문에 생긴 차이가 아니다"는 주장은 이 범위에서 타당합니다.
- 확인 필요: 본문의 "V-JEPA가 VideoMAE보다 0.10 높다"는 표 1 값으로는 0.09입니다(`03` K10).

### 3.3 전이-행동 짝짓기 대조 (§4.3, 표 2, 부록 M, 표 18–19)

- 설정: 같은 공개 체크포인트에서 시작해 참 ID, 과제 안 행동 섞기 ID(within-task derangement), 순방향 동역학(FD)을 각각 20k 업데이트로 학습합니다. 학습 헤드는 버리고 새 프로브를 맞춥니다(부록 M). 학습 시드 2개 x 프로브 시드 3개입니다.
- 표 2 절대값(200 에피소드): V-JEPA 참 0.863 / 섞기 0.184 / FD 0.326 (프리즈 0.455). VideoMAE 참 0.829 / 섞기 0.422 / FD 0.454 (프리즈 0.513). Web-DINO 참 0.156 / 섞기 0.063 / FD −0.071 (프리즈 0.075).
- 쌍체 대비 ∆26(26개 보류 과제 전체, 과제 단위 부트스트랩 10k): V-JEPA 0.836 [0.752, 0.952], VideoMAE 0.578 [0.518, 0.658], Web-DINO 0.097 [0.026, 0.156].
- 악조건 부식(최악 손상): ∆26 V-JEPA 0.662, VideoMAE 0.686, Web-DINO −0.026(표 18).
- 해석: 올바른 짝짓기가 V-JEPA와 VideoMAE의 이득에 필요하고, FD는 이득을 회복하지 못합니다. V-JEPA에서 FD 값(0.326)은 프리즈 값(0.455)보다 낮습니다.
- 주의(실제 판단은 `03` §2와 §4):
  - CI는 학습 체크포인트 2개와 프로브 시드 3개를 조건부로 둡니다. 학습 시드 변동이 CI에 들어가지 않습니다.
  - 26개 과제 값과 200 에피소드 값은 서로 다른 집계입니다. 두 값의 차이로 ∆26을 읽으면 안 됩니다(논문도 이 점을 적었습니다).
  - 표 1(0.84)과 표 2(0.863)는 학습 조건이 다릅니다. 표 1은 실효 배치 4, 30k 업데이트이고, 매칭 대조는 실효 배치 16, 20k 업데이트입니다(부록 G, 부록 M).

### 3.4 어떤 특징이 행동 정보를 담는가 (§4.4, 그림 2, 그림 3, 표 11, 부록 E)

- 그림 2 (회전 축): 회전 R²가 계열을 가장 크게 가릅니다. V-JEPA만 세 축 모두에서 높습니다. Web-DINO와 SigLIP은 병진은 보통이지만 회전이 음수입니다.
- 그림 3과 표 11 (V-JEPA 2 ViT-L 블록별): 프리즈 특징은 블록 14–18에서 평탄하고 최고값 0.516(블록 15)이며, 블록 22에서 0.394로 떨어집니다. ID 30k 스텝 뒤에는 마지막 네 블록이 +0.25–0.32 올라가고 최고값은 블록 21(0.721)로 옮겨 갑니다.
- 해석: 저자들은 이를 "ID가 기존 행동 정보를 더 쉽게 읽히게 만든다"로 해석하고, 사전학습 예측기의 기여는 분리하지 못했다고 적었습니다.

### 3.5 교란에 대한 강건성 (§4.5, 표 3, 표 15–16)

- 프리즈 V-JEPA 2는 깨끗한 입력 0.40에서 최악 교란에서 −4.66으로 떨어집니다. ID 뒤에는 0.84에서 최악 0.56입니다. VideoMAE + ID는 최악에서도 양수(0.11)입니다.
- 잡음 0.15에서 V-JEPA + ID 0.66 대 VideoMAE + ID 0.11입니다(표 15).
- SDXL VAE와 Cosmos는 ID 뒤에도 교란이 강해질수록 더 음수가 됩니다.
- 표 16의 계열 평균은 프리즈와 +ID를 섞은 값이므로 쌍체 효과로 읽으면 안 됩니다(저자도 같은 주석을 달았습니다).

### 3.6 다른 벤치마크 (§4.2 마지막 문단, 부록 D, 표 10)

- MetaWorld(ML45, 4자유도): 순위가 LIBERO와 비슷합니다(저자 보고 ρ = +0.88).
- CALVIN(고정된 4개 환경): 이미지 자기지도 계열이 0.77–0.81까지 올라와 LIBERO와 다른 양상을 보입니다. 저자들은 고정 환경에서 정적 외형이 행동 신호를 대신할 수 있다고 해석합니다. 프로브 데이터량 통제(부록 D, F)로는 이 차이를 설명하지 못했습니다.
- 주의: 이 세 벤치마크의 값은 같은 프로브 프로토콜을 쓰지만 과제 분포와 행동 공간이 다릅니다.

### 3.7 프로브 데이터량과 커버리지 (부록 F, 표 12, 표 19)

- 프로브 학습 에피소드를 400에서 3200으로 늘리면 Web-DINO + ID는 0.16에서 0.37, SigLIP 2 + ID는 −0.02에서 0.26으로 올라갑니다. V-JEPA + ID(0.84)와의 차이는 여전히 0.47과 0.58입니다.
- 26개 전체 보류 과제에서 프리즈 프로브는 크게 떨어집니다. V-JEPA 2 −0.006 [−0.146, 0.099], VideoMAE −0.186 [−0.405, −0.005]. 상수 예측기(−0.034)와 구별되지 않습니다. CAIP(행동 중심 대조 사전학습)의 시각 전용 값은 −1.480입니다(표 19).
- 해석: **절대 프로브 값은 과제 범위에 민감하고, 26개 과제 전체로 보면 프리즈 백본의 행동 복원도는 거의 0입니다.** 저자들은 이를 한계로 적었습니다(§5). 이것은 초록의 "절대 프로브 성능은 과제 범위에 민감하다"와 맞습니다.

### 3.8 행동 중심 비교군 CAIP (§4.3, 부록 M)

- 공식 CAIP ViT-L(시각 전용)의 프리즈 R²는 0.019이고, V-JEPA 2는 0.449입니다. 상수 예측기는 −0.024입니다.
- 저자들은 이 결과가 "행동 중심 사전학습 일반"을 말하지 않는다고 적었습니다. 체크포인트 한 개의 비교입니다.

### 3.9 폐루프 목표 교체 (§4.6, 표 4, 표 20, 부록 N)

- 설정: π0.5를 LIBERO 5개 스위트에 10k 스텝 미세조정합니다. 흐름 정합 손실에 프리즈된 목표 인코더 손실을 더합니다(부록 N). 배치 32, 최대 학습률 1.2e-4입니다.
- 두 결합 방식:
  - 클립 결합(정규화 L2, 가중치 0.1): DIFF + ID 체크포인트가 목표입니다. 대조는 배치 섞기와 무작위 초기화입니다.
  - 토큰 결합(코사인, 가중치 0.01): V-JEPA 2 + ID와 Web-DINO가 목표입니다.
- 결과 (성공률 %, 시도 100회/셀):
  - LIBERO 평균: 기준선 93.0, DIFF + ID 93.8, 배치 섞기 89.0, 무작위 초기화 93.5, V-JEPA 2 + ID 90.2, Web-DINO 93.5.
  - LIBERO-10 위치 이동: 기준선 8, DIFF + ID 24, DIFF + ID(시드 1) 18, 배치 섞기 15, 무작위 초기화 14, V-JEPA 2 + ID(w 0.01) 23, V-JEPA 2 + ID(w 0.05) 8, Web-DINO 14.
  - LIBERO-PRO 전체 평균(5개 이동 x 4개 스위트): 기준선 68.7, DIFF + ID 69.0, 배치 섞기 65.8, 무작위 초기화 67.6, V-JEPA 2 + ID 67.5, Web-DINO 65.0, DIFF + ID(시드 1) 65.1.
- 저자 결론: 목표 두 개가 LIBERO-10 위치 이동을 올리지만 전체 OOD 평균은 올리지 않습니다. 가중치 0.05에서는 이 이득이 사라집니다. 정책 시드와 가중치에 민감합니다(§4.6, 부록 N).
- 확인한 내용: 원자료 CSV로 표 4와 표 20의 모든 셀을 다시 계산했고 일치합니다(`03` K1). 통계 판단은 `03` §1.4와 §4를 보세요.

## 4. 주장과 근거의 간격 (요약)

| 주장 | 근거 | 간격 |
|---|---|---|
| PSNR은 행동 재현도의 믿을 만한 대리 지표가 아니다 | 그림 1, 체크포인트 다섯 개 | 점 배치 설명 수준. 상관 아님(저자도 명시). 데이터·구조가 달라 원인 분리 불가 |
| 비디오 사전학습이 행동 판독을 가장 잘 한다 | 표 1, 표 10 | 프리즈 값은 4개 과제 기준. 26개 과제에서 프리즈 V-JEPA는 0과 구별되지 않음(표 19) |
| 올바른 짝짓기가 이득에 필요하다 | 표 2, 표 18 | 쌍체 CI가 학습 시드 변동을 빼고 있음. 섞기 대조의 학습 시드 차이가 V-JEPA에서 0.08(`03` K4) |
| V-JEPA의 우위는 시간 문맥 때문 | 표 1, 표 2 | 데이터·목적·스케일이 함께 달라 분리 불가. v2는 "일치한다" 수준으로 낮춤 |
| ID는 교란에 강건함을 준다 | 표 3, 표 15 | 4개 과제 부분집합. 프로브는 깨끗한 특징으로 학습 |
| 목표 교체가 폐루프 위치 이동을 올린다 | 표 4, 표 20 | 셀당 100회, 정책 시드 1개(DIFF + ID 시드 2 중 하나는 p = 0.06). 대조군(14–15)도 기준선(8)보다 높음 |
| 전체 OOD 성공률은 오르지 않는다 | 표 4 PRO 열 | 대체로 맞음. 차이 0.3 수준이고 통계 검정 없음 |

## 6. 이 논문이 말하지 않는 것

- 실로봇 실험이 없습니다(한계 §5에 명시).
- 공개 체크포인트 간 비교는 데이터, 구조, 스케일이 함께 달라 인과 주장이 아닙니다.
- 프로브 R²는 행동 정책 성공률과 같지 않습니다. 저자는 두 값을 따로 읽으라고 말합니다(§1 마지막 문단).
