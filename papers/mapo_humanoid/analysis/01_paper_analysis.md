## 1. 문제와 주장

**배경.** 범용 휴머노이드 모션 추종은 AMASS, LAFAN1 같은 큰 사람 모션 데이터를 로봇에 리타게팅해 따라 하게 만듭니다. 모션 종류가 다양해 단일(monolithic) 정책은 과제 간 간섭을 겪는다고 보고(§1), 전문가 혼합(MoE) 정책이 널리 쓰입니다(GMT, FAST, KungfuBot2, CLONE).

**이 논문의 주장.**
1. MoE 정책을 PPO 같은 정책 기울기로 학습하면 **발산 오추정(divergence misestimation)**이 생깁니다. 옛 정책과 새 정책의 KL(PPO 클리핑이 규제하는 양)이 라우터와 전문가 변화의 교차항 때문에 부풀거나 줄어, 갱신이 지나치게 보수적이거나 과격해진다는 것입니다(§1, §4).
2. 해결책 MAPO는 라우터와 전문가를 **번갈아(alternating)** 갱신합니다. 전문가를 갱신할 때는 혼합 가중치를 수집 시점 값으로 고정하고, 라우터를 갱신할 때는 전문가 출력을 수집 시점 값으로 고정해 각각 따로 비율을 계산하고 클리핑합니다(식 7, §5.1). 번갈아 한다는 말은 일정을 교대한다는 뜻이 아니라 같은 데이터에서 두 대리 손실을 따로 계산한다는 뜻입니다(§5.1).
3. 결과: 학습 집합 성공률 86.60% 대 PPO with MoE 83.38%, 초록의 "PPO with MoE가 실패하는 182개 모션을 MAPO는 일관되게 추종, 반대는 1개"(표 1, 부록 D).

## 2. 방법

### 2.1 가우시안 MoE와 발산 분해 (§4, 식 2–6)

정책은 π(a|s) = N(Σₑ wₑ μₑ, σ²I)이고 w는 라우터 소프트맥스, μₑ는 전문가 평균입니다. σ는 한 갱신 안에서 고정으로 가정합니다.
- 측정 KL: KL_measured = ‖m_old − m_new‖²/2σ² (식 2).
- 차이를 m_old − m_new = d_μ + d_w로 쪼갭니다. d_μ = Σ w_old(μ_old − μ_new)는 전문가 변화, d_w = Σ(w_old − w_new) μ_new는 라우터 변화입니다(식 3).
- 따라서 KL_measured = KL_expert + KL_router + d_w·d_μ/σ² (식 6). 교차항 d_w·d_μ의 부호가 양이면 **과대추정**, 음이면 **과소추정**입니다(정의 1).
- 식 (3)–(6)은 항등식입니다(`03` K8에서 수치로 확인: 오차 4e-16). 분해는 "전문가 먼저, 라우터 나중" 경로를 쓰므로 교차항이 경로에 따라 달라집니다(`03` K9).

그림 2는 바닐라 정책 기울기로 MoE를 학습할 때 교차항이 ε²(ε = 0.2) 이상인 갱신의 비율을 전문가 수 N = 2, 4, 8, 16에서 보입니다. 과대추정은 N이 클수록 많고(약 0.2–0.4), 과소추정은 N = 2에서 가장 많습니다(최대 약 0.05, 그림 판독). 본문은 "N을 조정하면 우세한 모드가 바뀔 뿐"이라고 결론 냅니다.

### 2.2 MAPO 대리 손실 (§5.1, 식 7)

- r_expert = N(Σ w_old μ_new)/N(Σ w_old μ_old), r_router = N(Σ w_new μ_old)/N(Σ w_old μ_old).
- 손실은 두 항 각각의 PPO 클리핑 손실이고, 전문가 파라미터는 r_expert로만, 라우터 파라미터는 r_router로만 기울기를 받습니다. 두 항 모두 σ에 기울기를 줍니다.
- 부록 B가 기울기 편향을 분석합니다. 전문가 쪽 평균 기울기는 PPO 기울기의 전문가별 양수 배(w_old/w)이고(식 25–26), 라우터 쪽은 전문가 사이 상대 편차에 비례하는 방향 편향이 있습니다(식 27–31). 라우터 기울기 각도는 학습 중 90° 아래라고 그림 B.1이 보입니다.
- 4절의 분해(순차 경로)와 5절의 알고리즘(둘 다 옛 값에서 출발)은 같은 분해가 아닙니다. 5절 방식은 Σ Δw_e Δμ_e 상호작용 항을 어느 비율에도 넣지 않습니다(`03` K9, 토이 T1).

### 2.3 교사–학생 틀과 학습 설정 (§5.2, 부록 C)

- 교사: MoE (공유 인코더 [512, 256] → 라우터 [256, 128] + 전문가 [128, 128] N = 6). 관측은 고유감각(관절, 속도, 중력, 이전 행동, 링크별 위치·방향·속도)과 기준 모션(미래 링크 위치·헤딩, 속도, 현재 대 기준 차이)입니다. 행동은 관절 목표 위치(PD 제어). 가치 함수 [512, 256, 128]. 라우터에서 공유 인코더로 가는 기울기는 끊습니다(부록 C.2).
- 보상(표 C.1): 상대 몸체 위치 항 가중치 20.0, σ² = 0.05. 나머지 양의 항은 1.0씩이고, 행동 변화율 −0.2, 관절 한계 −10, 원치 않는 접촉 −0.1입니다. BeyondMimic 보상보다 위치 항을 날카롭게 했다고 합니다(부록 C.1, 그림 C.1).
- PPO: 병렬 환경 4096, 스텝 24, 미니배치 4, 에폭 5, γ 0.99, λ 0.95, ε 0.2, 엔트로피 0.01, 학습률 적응형(Rudin et al.), 최대 기울기 노름 1.0, 초기 잡음 표준편차 1.0(표 C.2).
- 도메인 무작위화(표 C.3): PD 이득 0.75–1.25배, 질량 ±25%, 질량 중심 ±0.1 m, 제어 지연 0–60 ms, 밀기 ±1 m/s(5 s마다), 기준 모션 오프셋.
- 학생: DAgger로 단일 MLP [512, 256, 128]에 증류, 고정 학습률 2×10⁻⁴, 관측과 도메인 무작위화는 TWIST 설정. 실로봇 Unitree G1 (29 DoF)에 배포(§6.1).
- 환경: Isaac Lab, 단일 NVIDIA A6000, 4096 환경, 모션은 GMR로 리타게팅(§6.1).

## 3. 실험 (§6, 표 1, 그림 4–5, 부록 D)

- 학습: AMASS + LAFAN1, 시험: OMOMO. 모션 수는 본문에 없습니다.
- 성공: 모션 전체에서 평균 위치 추적 오차 0.5 m 미만. 실패 뒤에는 오차를 실패 시점 값으로 고정합니다(§6.2).

## 4. 한계 (논문 §8)

논문이 적은 한계: 전문가 특화를 더 끌어낼 방법(전문가 행동 판별 보조 손실), 분석이 밀집 소프트맥스 라우팅과 한 갱신 안 고정 σ를 가정해 전문가별 분산 학습이나 top-k 희소 라우팅을 다루지 않음.

## 5. 주장과 근거의 간격 (요약, 상세는 `03`, `04`)

1. **측정된 비교는 학습 집합 중심입니다.** 시험 집합에서 MAPO 대 Monolithic PPO는 +1.09 %p(85.45 대 84.36)이고, MoE 자체(PPO with MoE)는 Monolithic PPO보다 낮습니다(82.78 대 84.36). 시험 모션 수가 없어 이 차이의 구분 가능성을 판단할 수 없습니다(`03` V7).
2. **표 1은 한 시드입니다.** 시드 3개 평균으로 보면 학습 집합 성공률 차이는 4.14 %p이고 시드 SD가 작아(0.64, 0.43) 이 방향은 시드 3개 안에서 일관됩니다. 시험 집합과 N 절제, 기준선은 시드 정보가 없습니다(`03` V5).
3. **보상 격차의 상당 부분이 엔트로피 계수와 연결됩니다.** MAPO는 σ에 기울기가 두 번 들어가 유효 엔트로피 계수가 절반이 되는데, 그림 5(b) 판독에서 PPO도 엔트로피 계수를 낮추면 MAPO 기본값의 15k 보상(약 24)에 가까워집니다. 같은 계수끼리의 차이는 작습니다(`03` K5).
4. **본문 "대부분 지표에서 최저 오차"는 학습 집합에서 8개 오차 중 6개, 시험 집합에서 4개입니다**(`03` V3, K3).
5. **실로봇 증거는 정성적입니다.** 정량 결과와 시도 수가 없고, 이 논문의 알고리즘 효과를 학생 정책 성능과 연결하는 대조는 없습니다(`04` C19).
