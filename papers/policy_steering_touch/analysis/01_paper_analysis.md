## 1. 한 문단 요약

정책 추론 시 steering은 사전학습된 생성 정책(diffusion policy)이 낸 행동 후보를 세계 모델에서 굴려 보고, 보상으로 골라 실행하는 방법입니다. 기존 방법은 보상을 **시각 예측**에만 둡니다. ViTaL은 접촉이 많은 조작(피펫으로 액체 옮기기, 닦기, 구멍에 끼우기)에서 시각만으로는 힘과 접촉 상태를 볼 수 없다고 주장합니다. 그래서 두 단계 **이중 최적화(bi-level)**를 씁니다. 긴 시간 범위(H = 16)에서 시각 보상으로 행동 모드를 고르고, 짧은 범위(h = 8)에서 촉각 보상으로 그 모드의 접촉을 확산 편집으로 다듬습니다. 촉각 보상은 **텍스트 조건부 코사인 유사도**입니다. 예측된 촉각 잠재 표현과 "grasp lightly" 같은 문장 임베딩(CLIP 텍스트)을 비교합니다. 세 가지 실로봇 과제(닦기, 구멍 끼우기, 피펫)에서 전체 성공률이 기본 정책보다 평균 51.7%p 높다고 보고합니다(§4.2).

## 2. 문제 설정 (Sec. 3)

- 관측은 카메라 영상 `o^v`, GelSight Mini 촉각 영상 `o^τ`, 고유 상태 `q`로 이루어집니다(Sec. 3, Notation).
- 목표는 시각 보상 `R(ô^v, ô^τ; L)`을 최대화하는 행동 샘플을 고르는 것입니다. `L`은 자연어 과제 설명입니다.
- 두 가지 어려움을 듭니다(Sec. 3, Open Challenges).
  1. **관측 가능성의 시간 척도 차이.** 시각 결과는 긴 시간 범위에서 드러나고, 촉각 결과는 짧고 국소적입니다.
  2. **다중 모달 보상 설계.** 과제 설명이 중간 시각 목표와 접촉 요구를 명시하지 않습니다.

## 3. 방법 (Sec. 4, 부록 B)

### 3.1 이중 최적화 공식 (Sec. 4.1, 식 1)

식 (1)은 다음 두 단계로 읽습니다.

- **바깥(본문 식의 `arg max` 바깥쪽, 촉각):** `a*_{t:t+h} = argmax log p_θ(a_{t:t+h} | ā_{t:t+h}, o_t) + β R^τ(ẑ^τ_{t:t+h}; L)`. 시각으로 고른 행동 모드 `ā` 근처에서 촉각 보상으로 짧게 다듬습니다.
- **안쪽(시각):** `ā_{t:t+H} = argmax R^v(ẑ^v_{t:t+H}; L)`. 기본 정책에서 뽑은 후보를 세계 모델로 H = 16 단계까지 굴려 시각 보상으로 고릅니다.

부록 B.3–B.4의 알고리즘 1에서는 **바깥과 안쪽의 이름이 식 (1)과 반대**입니다(알고리즘 1의 "Outer level"은 시각 단계입니다). 내용은 같지만 읽을 때 혼동될 수 있습니다.

### 3.2 잠재 세계 모델 (Sec. 4.2, 부록 B.2)

- 시각 인코더는 DINOv3 ViT-B/16(768차원, 196 패치)입니다. 촉각 인코더는 AnyTouch2 TactileVideoMAE(512차원, 직전 4프레임 창)입니다. 두 인코더는 고정(frozen)합니다(Table 4).
- 동역학 모델은 인과적 패치 트랜스포머입니다. 깊이 6, 헤드 16, 헤드 차원 64, MLP 2048, 공통 차원 384입니다(Table 5). 행동은 프레임당 8개 원시 행동을 묶어 56차원으로 넣습니다(프레임 건너뛰기 F = 8).
- 학습은 다중 단계 롤아웃 손실입니다. 롤아웃 길이 k를 {3, 4, 5} 중에서 고르고, 손실은 모든 카메라와 상태의 MSE입니다(Table 6). 행동 노이즈는 Geometric(p = 0.05)으로 뽑은 DDIM 타임스텝으로 넣고, 마스크 확률을 올립니다(§5 참조).
- 디코더는 VQ-VAE 계열입니다. RAE 손실(L1 + LPIPS + 적응형 GAN)을 씁니다(Table 7). 디코더는 시각화와 시각 보상 입력에만 씁니다.

### 3.3 보상 (Sec. 4.3)

- **시각 보상.** 예측된 시각 잠재 표현을 디코딩해 RGB 영상으로 만들고, ROBOMETER-4B(VLM 기반 보상 모델)에 넣습니다. 과제 단계별 시각 목표 `ℓ^v_p`를 씁니다. 저자들은 ROBOMETER를 그대로 쓰지 않고 KV 캐시와 슬라이딩 윈도우 방식으로 고쳤다고 씁니다(부록 B.3).
- **촉각 보상.** `R^τ(ẑ^τ; ℓ^τ_p) = cos(ẑ^τ, E_ψℓ(ℓ^τ_p))` (식은 Sec. 4.3). 저자들은 "언어 조건부 촉각 보상의 첫 사례"라고 주장합니다(Sec. 4.3). 단계 목표는 피펫 과제에서 "grasp lightly" → "grasp heavily"입니다(부록 A.3).
- 단계 전환. 시각 보상이 0.7을 넘으면 촉각 목표를 바꾸고, 40 스텝 동안 유지한다고 씁니다(부록 A.3). 시각 2단계 목표는 "put the dropper back to the red cup"입니다.

### 3.4 최적화 (Sec. 4.4, 부록 B.3–B.4, 알고리즘 1)

- **시각 단계 (샘플링과 검증).** 기본 정책에서 후보 N = 10개를 뽑아 세계 모델로 H = 16 단계 굴리고, 마지막 시각 프레임의 보상이 가장 높은 후보를 고릅니다(Eq. 2–4). 시각 보상 기울기를 쓰지 않은 이유는 VLM, 디코더, 순환 세계 모델을 통과한 미분이 불안정하기 때문입니다(Sec. 4.4).
- **촉각 단계 (확산 편집).** 고른 후보의 앞 h = 8 행동을 K = 4 단계만큼 부분 잡음으로 덮은 뒤(Eq. 6), 각 역확산 단계에서 촉각 보상의 기울기를 단위 노름으로 정규화하고 λ = 10을 곱해 잡음 예측을 보정합니다(Eq. 7–11, Table 9). 여기서 보정 항의 크기는 `sqrt(1 − ᾱ_K)`로 맞춥니다(LPB 방식).
- 저자들은 이 방법을 "근사 샘플링"이라고 씁니다. 정확한 해가 아니라 역확산 보정입니다(Sec. 4.4).

## 4. 실험 (Sec. 5, 부록 A, C, D)

### 4.1 실험 설정

- 로봇은 Franka Emika 7-DoF입니다. 촉각 센서는 GelSight Mini이고, 카메라는 손목 카메라와 정면 카메라입니다(부록 A.1–A.3).
- 과제는 세 가지입니다. **닦기**(오렌지 마크 또는 검은 마크, 손가락 부드러운 그리퍼), **구멍 끼우기**(1 mm 여유, 좌우 구멍 두 목표), **피펫 액체 옮기기**(노란 컵 또는 파란 컵, 빨간 컵으로 복귀)입니다.
- 기본 정책은 확산 정책(ResNet-18, 16 스텝 행동 덩어리, 앞 8 스텝 실행, 80,000 반복)입니다(부록 B.1, Table 2–3). 데모는 과제당 50회입니다(Sec. 5). 세계 모델 데이터는 과제당 정책 롤아웃 250회를 더한다고 본문에 있습니다. 부록 A.1은 닦기 과제 롤아웃 280회를 씁니다(§5 불일치 참조).
- 기본 정책은 **시각 정책**(손목과 정면 두 카메라 + 고유 상태)입니다. 촉각을 넣은 정책은 부록 C.2에만 있습니다.

### 4.2 Fig. 2: 단일 모달 대 다중 모달 (Sec. 5.1)

- 비교 대상은 기본 정책, 시각 샘플링(시각 예측 8 또는 16 스텝, N = 10), 촉각 샘플링(N = 10), 촉각 가이던스(분류기 방식), 단순 결합(시각 보상과 촉각 보상을 정규화해 더함), ViTaL입니다.
- 지표는 전체(Overall), 시각(Visual), 접촉(Contact) 성공률입니다. 전체 성공은 시각과 접촉이 모두 맞은 경우입니다(부록 A).
- 시도 수는 **조건당 20회**입니다(Fig. 2 캡션). 막대 높이는 그림 자체에 숫자가 없어 **고해상도로 렌더링한 그림에서 눈으로 읽었습니다**. 값은 5%p 간격으로 떨어지고, 세 과제 값의 평균이 "Average Across Tasks" 패널과 모두 맞습니다(`analysis/recompute.py`). 읽기 오차는 최대 약 2.5%p로 봅니다.
- 읽은 값의 세 과제 평균(전체 성공): 기본 22%, 시각 8단계 25%, 시각 16단계 32%, 촉각 샘플링 33%, 촉각 가이던스 40%, 단순 결합 45%, **ViTaL 73%**.
- 본문 주장 "기본 정책 대비 51%"는 **%p 차이**입니다(73.3 − 21.7 = 51.7%p). 상대 증가로 쓰면 약 3.3배입니다. 본문 표현이 모호합니다.
- 본문 주장 "단일 모달 대비 최소 33%"는 세 과제 평균에서만 맞습니다(73.3 − 40.0 = 33.3%p). 과제별로 보면 닦기 30%p, 구멍 끼우기 25%p입니다.
- 본문 주장 "단순 결합 대비 최소 20%"는 평균 28.3%p이고 과제별로는 20–35%p입니다. 구멍 끼우기에서 정확히 20%p입니다.

## 5. 한계와 저자가 놓친 점

**저자가 쓴 한계 (Sec. 6).** (1) 세계 모델의 복합 예측 오차가 검증을 흐립니다. (2) 촉각 인코더가 VLM에 비해 작은 데이터로 학습되었습니다. (3) 손가락이 여럿인 손으로 확장하지 않았습니다.

**읽으면서 발견한 점 (근거는 `03`과 `04`).**

1. **통계가 약합니다.** 조건당 20회이고 검정이 없습니다. Fig. 2의 오차 막대는 캡션이 "standard errors"라고 하지만, 막대 반폭은 1.96 × SE(Wald 95%)와 맞습니다(`03` §1). 과제별 차이는 Fisher 검정 기준으로 p = 0.01–0.33입니다. 세 과제 합(60회)에서 ViTaL 대 촉각 가이던스 p = 0.0004, 대 단순 결합 p = 0.003입니다(`03` §1).
2. **공식 코드와 논문의 학습 설정이 다릅니다.** 세계 모델 홀드아웃은 본문에 30개, 공식 설정에 50개입니다. 마스크 확률 상승은 본문에 "마지막 에폭에 0.5"이고 코드는 학습 중간에 0.5에 도달합니다. 디코더 반복 수는 본문 5,000, 기록된 실행 15,000입니다(`04` D 항목).
3. **촉각 보상의 정의가 코드에서 다릅니다.** 공식 코드의 두 단계 프리셋은 양성 문장 점수에서 음성 문장 점수를 뺍니다(`cos(pos) − cos(neg)`). 논문 식 (8)–(10)에는 음성 항이 없습니다(`04` D 항목).
4. **단계 전환 임계값이 다릅니다.** 논문은 0.7이고, 공식 코드의 주 방법 기본값은 0.64입니다(`04` D 항목).
5. **기준선 설정이 다릅니다.** README는 단순 결합 기준선이 파란 컵을 목표로 하고, 주 방법은 노란 컵을 목표로 한다고 적습니다. 논문은 목표 컵이 실험마다 어떻게 배정됐는지 설명하지 않습니다(`04`).
6. **행동 차원이 맞지 않습니다.** 부록 A.1은 8차원(위치 3, 쿼터니언 4, 그리퍼 1)이라고 쓰지만, 표 2, B.2와 공식 코드는 7차원입니다.
7. **데이터 수가 맞지 않습니다.** 본문은 과제당 롤아웃 250회라고 쓰지만, 부록 A.1은 닦기에 280회입니다. 공개 데이터셋은 피펫 320, 구멍 끼우기 330, 닦기 330 에피소드입니다(`04`).
8. **시도 수가 불명확합니다.** 부록 A.3(피펫)에는 시도 수가 없습니다. 캡션은 20회입니다.
9. **재현 조건이 큽니다.** 로봇 하드웨어, 기본 정책 가중치(공개되지 않음), 로봇 서버(Robometer 서버는 공개되지 않음), CUDA 학습이 필요합니다(`04` §4).
