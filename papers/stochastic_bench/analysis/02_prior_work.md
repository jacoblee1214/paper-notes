# 02. 선행연구와 관련 자료

## 1. 계보: 실물 조작 벤치마크가 비교 가능성을 얻는 방법

논문의 서술(§1, §2)을 비교 가능성을 얻는 방식으로 다시 묶었습니다.

| 방식 | 대표 사례 (논문 인용 번호) | 비교 가능성의 근원 | 논문이 지적하는 한계 |
|---|---|---|---|
| 시뮬레이션 | RLBench [5], Colosseum [1], CALVIN [9], LIBERO [10], RoboCasa [12], BEHAVIOR-1K [13] | 같은 시뮬레이터와 시험 분할 | 물리 현실감 격차. 무작위성은 미리 정한 시뮬레이터·과제 집합 안에 있음(§2.1) |
| 고정 물체·배치 | YCB [2], GRASPA [14], Box and Blocks [15], SceneReplica [16] | 같은 물체와 배치 | 같은 장면을 반복 평가하면 과적합을 부추기고 과제 범위를 좁힘(§2.2) |
| 중앙 대회·과제 표준 | RoboCup, RB2 [17], NIST 조립 [18], OCRTOC [19], TOTO [20], Real Robot Challenge [21] | 한 장소에 모으거나 과제·하드웨어를 표준화 | 한 장소에 있어야 하거나 표준 하드웨어가 필요 |
| 복잡 조작·분산 평가 | FurnitureBench [22], FMB [23], ManipulationNet [4], RoboArena [3], RoboDojo [24] | 소형·표준 물체, 기관 간 프로토콜 | 축소 모형의 접촉 차이, 기능 조작에 치우침, 탁상 한정(§2.2) |
| **이 논문** | 분포를 표준화(시드 생성기) | 같은 분포에서 뽑은 표본이면 비교 가능 | 비교에 시도가 많이 필요, 재구성·보고 신뢰 문제(§6) |

- 가장 가까운 대안은 RoboArena [3]입니다. 분산 평가라는 점은 같고, RoboArena는 구성(로봇)을 표준화해 쌍별 선호로 순위를 매기는 반면 이 논문은 분포를 표준화하고 이질적 로봇의 성공률을 통계로 비교합니다(논문 §1이 각각 로봇 [3]과 과제 [4]를 표준화한다고 요약. 비교의 세부는 두 논문의 서술이며 우리가 RoboArena 본문을 대조하지는 않았습니다).
- 통계 쪽 선행은 논문에 거의 인용되지 않습니다. 표본 크기 공식, 시드 분산 분해, 쌍체 대 독립 비교는 임상시험·ML 재현성 문헌의 표준 도구입니다. 논문은 "기존 물리 벤치마크는 평균 성공률, 표준편차, 순위 통계를 보고한다"(§2.2)고만 비교합니다. 이 점은 아래 구성 요소 표에서 "출처 미표기"로 적었습니다.
