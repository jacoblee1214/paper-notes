- **`algorithm-steps.mjs`** 알고리즘 1·2의 텍스트. 논문 부록 C와 같은 내용이며 알고리즘 2에 "Use a uniform state reference" 줄이 따로 있고 보상 정규화가 두 줄로 나뉜 정도의 표기 차이입니다.

## 3. 주장 검증 (C1–C16)

| # | 주장 (출처) | 검증 방법 | 판정 |
|---|---|---|---|
| C1 | 정리 1: Î(ρ, π) ≤ I(ρ, π) (식 2, 부록 A.1) | 증명 단계별 유도, 토이 T1 (`03` §5.1, §10.1) | **수학적으로 맞음.** I − Î = E[KL(q_π‖q̂_π)] ≥ 0 |
| C2 | "데이터의 상호정보가 그 데이터로 학습한 어떤 모델의 행동 영향도 제한한다"(초록, §1) | 정리 1 우변의 분포 확인, 토이 T1 | **조건부.** 평가 분포 = 데이터 분포일 때 성립(토이 8행 모두 Î ≤ I_D). 평가 정책이 다르고 모델이 외삽하면 Î가 I_D보다 큼(σ_a = 0.01에서 3.69 대 0.35). 정리 자체는 데이터와 무관한 부등식. §3.2는 "추가 귀납 편향 없이"라고 조건을 둠 |
| C3 | Four Rooms에서 행동 영향과 시뮬 충실도의 r = 0.979, 95% CI [0.96, 0.99] (그림 3) | 사이트 JSON 36점 | **재현됨.** r = 0.9787, Fisher [0.958, 0.989]. 점 36개는 4시리즈 × 9규모라 독립이 아님(시리즈 군집 부트스트랩 [0.969, 0.990]). 가로축은 모델의 Î이고 데이터의 I가 아님 |
| C4 | 정리 2: AIM 보상의 최적 정책이 I(ρ, π)를 올린다 (식 5–6, 부록 A.3) | 증명 유도, 토이 T2 | **정확한 q에서 맞음**(2000/2000). 추정한 q̂에서는 보증 없음(표본 5개/상태에서 환경의 70%에서 I 감소). 논문이 §3.4, §5에서 순차 RL 근사의 간격을 인정함. r_cov는 상태만의 함수라 정리가 그 역할을 설명하지 않음 |
| C5 | "Push-T에서 AIM만 일관되게 제어 가능성을 높인다"(초록, §4.2) | 사이트 JSON 그림 5 | **BC 평가에서 지지**: AIM은 라운드마다 20.35 → 28.10 → 30.04 → 30.91 → 31.82 → 32.54, 기준선 7개는 모두 3k 전문가 값(20.35) 이하. Push Away에서는 DADS(+3.0p), METRA(+2.2p), 랜덤 워크(+1.8p)도 시작값보다 약간 오르나 비단조. 탐험 기준선은 시뮬 상태 입력, AIM은 픽셀(`03` K3) |
| C6 | 3k + AIM 500이 300k 전문가의 EE 제어 가능성과 같다 (§4.2, 그림 5) | 사이트 JSON | **지지(H=10, BC).** 32.54 대 32.33. 300k 전문가 점은 곡선 끝의 평탄한 구간 |
| C7 | "데이터 85배 절감"(초록, §5) | 산술, 그림 6 판독 | **산술 일치**(300000/3500 = 85.7). 같은 곡선에서 AIM 값에 처음 닿는 전문가 규모는 약 150k(약 43배, 그림 판독 값). 랜덤 워크·균등 랜덤 단독은 4.7k에서 이미 AIM 500의 값 이상(그림 판독 값). 비교 기준이 전문가 단독이고 H=10 설정 |
| C8 | BC Joint가 PPO-3K 대비 +69%, PPO-300K 대비 +54%, Recovery-3K 대비 +36% (§4.3) | 표 1 산술, 사이트 쌍대 부트스트랩 | **산술 일치**(69.5, 53.6, 35.7%). 비교는 BC 평가에 한정. PPO-300K 대비는 BC-Failure(.411 대 .432)와 Push Away(.165 대 .198)에서 반대 방향 |
