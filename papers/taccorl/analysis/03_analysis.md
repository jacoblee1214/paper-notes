# 03. 수치 재계산과 일관성 검사

`analysis/recompute.py`(numpy, scipy, 수 초)가 표 1·2와 본문 수치를 다시 계산해 `recompute_results.json`에 저장합니다. 재현(학습, 실로봇)은 하지 않았습니다. 이 논문에는 공개 코드가 없어 논문 안의 숫자끼리만 맞춰 봅니다.

**가정(문장마다 다시 적지 않음).** (1) 표 2의 각 셀은 20회 시행입니다. 본문 §4.2가 "과제당 20회"라고 쓰고 모든 값이 0.05의 배수입니다. (2) 표 1은 병렬 환경 128개 평가입니다(§4.2). 시뮬 값의 시행 수 정의(환경당 1회인지, 여러 에피소드 평균인지)는 논문에 없습니다. (3) 검정은 시행이 독립이고 과제가 교환 가능하다고 보는 단순 검정입니다. 학습 시드는 논문에 하나로 읽히며, 시드 변동은 반영되지 않습니다.

## 1. 보고된 평균의 재계산 (V1, V2)

**V1. 평균 일치.** 표 1·2의 4과제 평균은 본문 수치와 모두 일치합니다.

| 항목 | 재계산 | 본문 |
|---|---|---|
| 시뮬 공동학습 직후 V / VT | 33.0 / 40.5 | 33.0 / 40.5 (§4.3) |
| 시뮬 RL 시작 V / VT | 22.5 / 29.25 | 22.5 / 29.3 (§4.3) |
| 시뮬 RL 후 V / VT | 60.5 / 78.5 | 60.5 / 78.5 (§4.3) |
| 실로봇 RL 후 V / VT | 50.0 / 72.5 | 50.0 / 72.5 (초록, §4.4) |

**V2. 정수 가능성.** 실로봇 표 2의 16개 값은 모두 k/20로 나타납니다. 시뮬 표 1의 소수 둘째 자리 값은 n = 128에서 항상 가능해(간격 0.0078) 이 검사로 얻는 정보는 없습니다. 본문 §4.5의 시뮬 값은 다릅니다. 70.3%(90/128 = 70.31)와 14.1%(18/128 = 14.06)는 n = 128의 반올림 값이지만, **42.9%는 n = 128에서 소수 첫째 자리 반올림 값이 아닙니다**(54/128 = 42.19, 55/128 = 42.97 → 43.0). 세 값을 모두 만족하는 분모(20–1000)는 264개이고 첫 값이 333이며 128은 없습니다. 가능한 설명은 "최고 성공률"이 환경 수보다 큰 분모의 이동 평균이거나 버림 처리일 수 있다는 것입니다. 정의가 본문에 없어 저자 확인이 필요합니다(`K2`).

## 2. 실로봇 표 2: 구간과 검정 (V3–V6)

**V3. 셀별 Wilson 95% 구간(n = 20).** 예: Test Tube RL 후 VT 14/20 = [0.48, 0.85], V 7/20 = [0.18, 0.57]. 구간은 대부분 서로 겹칩니다. 폭은 셀당 약 ±0.20–0.27입니다(`own_real_ci.png`).

**V4. 촉각 효과(RL 후, VT 대 V).**

| 과제 | VT | V | 차이 | Fisher p | Holm 보정 p |
|---|---|---|---|---|---|
| Test Tube | 14/20 | 7/20 | +35%p | 0.056 | 0.22 |
| Do Puzzle | 9/20 | 5/20 | +20%p | 0.32 | 0.90 |
| Assembly #1 | 19/20 | 16/20 | +15%p | 0.34 | 0.90 |
| Assembly #2 | 16/20 | 12/20 | +20%p | 0.30 | 0.90 |
| **합산(80회)** | **58/80 (72.5%)** | **40/80 (50.0%)** | +22.5%p | **0.0056** | — |

합산에서 Mantel-Haenszel 검정(과제를 층으로)은 χ² = 8.85, p = 0.0029, 공통 오즈비 3.24입니다. 정리하면 **네 과제를 함께 보면 촉각 효과가 통계적으로 분명하지만, 과제 하나만으로는 어느 과제도 5% 수준에 이르지 못합니다**. 네 과제 모두 방향이 같다는 점(+15 ~ +35%p)이 합산 결과를 지지합니다.

공동학습 단계(VT 43.75% 대 V 30.0%, 합산 p = 0.10)와 실데이터만 미세조정 단계(33.75% 대 21.25%, p = 0.11)에서는 합산해도 5% 수준에 이르지 못합니다. 즉 촉각 효과가 통계적으로 분명해지는 것은 RL 단계입니다. RL 단계에서 효과가 커졌다는 해석과 시행 수 부족으로 앞 단계의 효과가 안 보인다는 해석이 모두 가능합니다.

**V5. 단계 효과(합산 80회).** V: 실데이터만 17 → 공동학습 24 → RL 40. VT: 27 → 35 → 58. RL 대 공동학습의 Fisher p는 V 0.015, VT 0.0004입니다. 공동학습 대 실데이터만은 V 0.28, VT 0.26으로 분명하지 않습니다. RL 단계의 이득은 V +20.0%p, VT +28.75%p로 촉각이 있을 때 더 큽니다(교호작용 검정은 시행 수가 부족해 하지 않았습니다). 초록의 기준선 50.0%는 **시각 전용에 같은 RL을 한 것**이고, 시각 전용 실데이터 미세조정(21.25%)과 최종 정책(72.5%)의 차이는 합산 p ≈ 1e-10입니다. 어느 기준선을 쓰느냐에 따라 "촉각의 기여"와 "RL의 기여"가 달라집니다.

**V6. 검정력.** 한 과제에서 50% 대 72.5%를 20회로 Fisher 검정(5%)할 때 검출 확률은 약 20%(몬테카를로 3000회, 시드 고정)입니다. 80회 합산이면 약 79%입니다. 80% 검정력에 필요한 시행은 과제당 약 73회(정규 근사)입니다. 이 논문의 과제별 실로봇 결과는 "방향"으로 읽는 것이 맞고 크기는 합산으로 읽는 것이 안전합니다.

**Do Puzzle 서술.** §4.4의 "45% 대 15%(실데이터만)와 25%(공동학습)"는 표 2와 일치합니다. 9/20 대 3/20은 p = 0.082, 9/20 대 5/20은 p = 0.32입니다.

## 3. 시뮬 표 1과 시뮬-실로봇 관계 (V7, V8)

**V7. 시뮬 촉각 이득.** RL 후 VT − V는 Test Tube +22%p, Do Puzzle +17%p, Assembly #1 +15%p, Assembly #2 +18%p입니다. 시행 128개와 독립을 가정한 두 비율 z 검정은 모두 p < 0.005(z = 2.8–3.6)입니다. 시뮬 값 하나의 표준오차는 최대 약 4.4%p(실로봇 20회는 11.2%p)입니다. 단 한 번의 학습 결과이고 시드 간 변동은 없으므로, 이 p는 "같은 학습 결과에서의 평가 잡음"만 반영합니다.

**V8. 시뮬과 실로봇의 대응.** 16개 셀(공동학습 8개 + RL 후 8개)에서 시뮬-실 Pearson r = 0.89(공동학습 0.92, RL 후 0.91), 평균 절대 차이 7.3%p입니다(공동학습 4.6%p, RL 후 10.0%p). RL 후 셀별 차이(시뮬 − 실)는 Assembly 두 과제와 Test Tube VT에서는 ±3%p 이내(Test Tube V는 +15%p)이고, **Do Puzzle에서 V +29%p, VT +26%p**로 큽니다(`own_sim_vs_real.png`). Do Puzzle은 가장 긴 과제입니다. 이 과제에서 시뮬 성공이 실로봇보다 높게 나온 이유는 논문에 설명이 없고, 조각 세 개의 연쇄 오차나 접촉 모델 차이 등이 가능한 원인으로 보입니다(추정).

## 4. 절제 (V9, Assembly #2, 20회 가정)

그림 7 막대와 본문의 실로봇 성공률: α = 0 → 25%(5/20), α = 0.95 → 40%(8/20), α = 0.5(β = 0) → 45%(9/20), β = 0.1 → 80%(16/20), β = 1.0 → 80%(16/20), β = 5.0 → 50%(10/20).

| 비교 | 결과 | Fisher p |
|---|---|---|
| α = 0.5 대 0.95 | 45% 대 40% | 1.0 |
| α = 0.5 대 0 | 45% 대 25% | 0.32 |
| β = 1.0 대 β = 0 | 80% 대 45% | 0.048 |
| β = 1.0 대 β = 5.0 | 80% 대 50% | 0.096 |
| β = 1.0 대 0.1 | 80% 대 80% | 1.0 |

해석: 앵커의 효과(45% → 80%)는 5% 근처에서 걸치고 비교가 여럿이라 보정하면 분명하지 않습니다. α의 실로봇 효과(40% → 45%)는 단일 시행 수준에서 구별할 수 없습니다. α의 효과는 시뮬 쪽(42.9% → 70.3%, 14.1%)에서 더 뚜렷하게 보입니다. 실로봇 막대는 β = 0.1과 1.0이 같은 80%라서 "β가 0.1–1.0 사이에서 둔감하다"는 읽기와 "20회가 해상도 한계"라는 읽기가 모두 가능합니다.

또 표 2 Assembly #2 VT의 공동학습 0.55(11/20)와 β = 0 RL의 0.45(9/20)는 앵커 없이 RL을 하면 실로봇 성공이 55%에서 45%로 내려간 값으로 읽힙니다(p = 0.75, 20회로는 구별 불가). β = 1.0은 80%(16/20, 공동학습 대비 p = 0.18)입니다.

## 5. 부록 수치와 계산량 산술 (V10, V11)

**V10. SysID 표(그림 9).** 여섯 관절의 Kp, Kd, Tref가 모두 탐색 범위(Kp ∈ [10, 1e5], Kd ∈ [1, 1e3], Tref ∈ [−8, 8])에 있습니다. 기준 시뮬(Kp = 500, Kd = 50, 비 0.10)에 비해 식별된 Kp는 J0–J2에서 1.9–3.6배로 크고 J4, J5는 0.30배로 작습니다. Kd/Kp는 0.088–0.119로 기준 0.10 근처입니다. J4의 Tref = 1.73 N·m는 다른 관절(|Tref| ≤ 0.44)보다 한 자릿수 큽니다. 중력 보상 불일치가 가장 큰 관절로 §4.1이 J4를 고른 서술과 방향이 맞습니다.

**V11. 구성 산술.** K = 4 × 32 × 12 = 1536 taxel은 패드 4개(양 그리퍼 × 2)로 읽을 때 맞습니다(부록 A는 "그리퍼마다 패드 두 개"). 행동 차원 14 = 2 × (6 관절 + 그리퍼 1). 롤아웃 한 번은 128 × 36 = 4608 청크 결정(H = 10이면 46,080 시간 스텝)이고 RL 배치 512로 나누면 9 미니배치입니다. 그림 6 가로축 "Steps"가 롤아웃 한 번을 뜻한다고 가정하면(단위는 논문에 없음) 300스텝은 약 138만 청크 결정입니다. 공동학습 샘플 수는 조립 1000 × 192 = 192,000, Do Puzzle·Test Tube 3000 × 192 = 576,000입니다.

## 6. 일관성 검사 (K1–K9)

**K1. 실 시연 수.** §4.2는 과제당 실 시연 50개라고 쓰고, Table 4는 "real-anchor episodes N = 200"입니다. 앵커 데이터가 실 시연의 4배입니다. 증강으로 늘렸거나 다른 수집분일 수 있으며, 논문에 설명이 없어 저자 확인이 필요합니다.

**K2. 42.9%.** V2 참조. n = 128 반올림과 맞지 않는 값이 하나 있고 "best simulator success"의 정의가 없습니다.

**K3. Assembly #2 시뮬 값 두 개.** 표 1의 시각-촉각 Assembly #2 "RL with Co-Training"은 0.79이고, §4.5는 같은 과제에서 β = 0.1과 1.0 모두 "best simulator success above 92%"라고 씁니다. Table 4의 기본 β = 1.0이 표 1의 설정이면 0.79(최종 또는 평균)와 92% 초과(최고)는 다른 통계량이라는 뜻으로 읽힙니다. 표 1이 어느 시점(마지막 스텝, 최고, 이동 평균)의 값인지 논문에 없습니다.

**K4. 그림 6과 표 1(그림 판독 값).** 그림 6의 곡선 끝값을 읽으면 Do Puzzle V ≈ 65%, VT ≈ 77%로, 표 1의 0.54와 0.71보다 높습니다(Test Tube, Assembly #1·#2는 표와 판독 값이 몇 %p 이내). 판독 오차가 아닐 수 있는 차이(10%p 이상)이지만, 표가 최종 평가이고 곡선이 학습 중 이동 평균이라면 설명됩니다. 정의 확인이 필요합니다.

**K5. "Steps" 단위.** 그림 6은 과제마다 가로 범위가 다르고(Test Tube, Do Puzzle 약 300, Assembly 약 150–200), 그림 7은 100입니다. 단위가 정의되지 않았습니다.

**K6. 초록의 기준선.** 초록은 "baseline of 50.0%"라고 쓰고, 이것은 시각 전용 + 같은 RL 후학습입니다(V5). 본문 §4.4는 이를 명확히 적고 있어 서술 사이 불일치는 없지만 초록만 읽으면 모방학습 기준선으로 읽힐 수 있습니다.

**K7. 특권 상태.** §3은 "simulator additionally exposes privileged state s_t for reward and critic learning"이라고 쓰고, Table 4는 critic을 "mean-token value head"로 적습니다. 가치 헤드가 정책 토큰만 쓰는지 특권 상태를 쓰는지는 이 표만으로 정해지지 않습니다. 배포에서 critic을 버리므로 전이에는 영향이 없지만, 학습 안정성에 관해 해석이 달라집니다.

**K8. 촉각 평균.** 그림 4B 범례의 정규화 읽기 평균은 실 0.616, 시뮬 0.658(상대 차이 6.8%)입니다. §4.1은 "similar"라고 쓰며 분산, 분포 거리, 정렬 전 값은 없습니다. 접촉 게이트 임계값 0.4(식 4)는 정규화 값 기준이므로 이 분포 차이가 게이트 열림 빈도에 주는 영향은 알 수 없습니다.

**K9. 평가 범위.** 그림 3 캡션은 누적 배치가 "도메인 무작위화와 평가에 쓰인 자세 범위"라고 씁니다. 시뮬 평가가 학습 때와 같은 분포라면 표 1은 학습 분포 성능이고 일반화 성능이 아닙니다. 실로봇 20회의 자세 선택 방식(고정 격자인지 무작위인지)도 논문에 없습니다.

## 7. 요약

- 산술은 모두 맞습니다(V1, V2 실로봇, V10, V11).
- 실로봇 촉각 효과는 4과제 합산에서만 분명하고(p = 0.0056), 과제별로는 20회가 부족합니다(V4, V6).
- 시뮬은 공동학습 직후 실로봇과 잘 맞고(r = 0.92) Do Puzzle RL 후에서 크게 벗어납니다(V8).
- 절제는 Assembly #2 하나이고 20회 해상도입니다. 앵커 효과의 방향은 시뮬과 실로봇 모두 같지만 크기는 확실하지 않습니다(V9).
- 표 1의 통계량 정의(최종·최고·평균), 앵커 데이터 수, 42.9% 처리 방식이 저자 확인 항목입니다(K1–K5).
