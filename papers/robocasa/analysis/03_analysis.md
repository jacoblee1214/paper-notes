# 03. 수치 재계산과 일관성 점검

논문 수치를 옮겨 다시 계산했습니다. 학습은 하지 않았고 공식 코드도 실행하지 않았습니다. 계산 스크립트는 `analysis/recompute.py`, 결과는 `analysis/recompute_results.json`입니다(numpy, scipy, 1초 미만).

## 0. 전제와 한계

- **평가 단위.** Fig. 13의 값은 모두 1/50의 배수이고, 열마다 합이 정수입니다(345, 315, 420, 571). 과제당 평가 50회로 보는 것이 맞습니다. 장면 5개 × 50회(과제당 250회)였다면 값이 1/250 단위여야 했습니다. 따라서 "50 trials across five scenes"는 과제당 총 50회로 읽었습니다(D9).
- **불확실성의 범위.** 아래 구간은 **평가 잡음**(과제당 50회 이항 표본)만 반영합니다. 학습 시드가 1개인지는 논문에 없습니다. 시드 변동이 더 크면 실제 불확실성은 더 큽니다. 따라서 아래 구간은 하한입니다.
- **실로봇 SD.** Fig. 10의 "±"는 3시드 표본 SD로 가정합니다(논문 미정의). 시드당 평가 횟수가 없어 이항 구간은 만들 수 없습니다.

## 1. 원자 과제 학습 (Fig. 13, V-A)

### 1.1 평균과 구간

| 설정 | 과제 평균 (재계산) | 논문 표기 | 평가 잡음 95% 구간 (평균 ± 1.96 SE) | 성공 수 (1200회 중) |
|---|---|---|---|---|
| Human-50 (과제당 50) | 28.75% | 28.8% | 26.6–30.9% | 345 |
| Generated-100 (과제당 100) | 26.25% | 26.3% | 24.3–28.2% | 315 |
| Generated-300 (과제당 300) | 35.00% | 35.0% | 32.8–37.2% | 420 |
| Generated-3000 (과제당 3000) | 47.58% | 47.6% | 45.3–49.9% | 571 |

- 재계산한 평균이 논문 평균과 모두 맞습니다(반올림 범위 안, K1).
- 과제 평균은 24개 과제의 단순 평균입니다. 논문도 단순 평균으로 보입니다. 과제별 시도 수가 같으므로 전체 성공률과 같습니다.

### 1.2 차이 검정

| 비교 | 차이 (pp) | 과제 대응 t 검정 | 과제별 방향 (양/음/동) | 해석 |
|---|---|---|---|---|
| G3000 − H50 | +18.8 | t = 6.9, df 23, p < 10⁻⁶ | 22 / 2 / 0 | 생성 데이터가 사람 데이터를 명확히 앞섬 (**C2**) |
| G300 − G100 | +8.8 | t = 3.5, p = 0.002 | 19 / 3 / 2 | 규모가 커질 때 개선 |
| G3000 − G300 | +12.6 | t = 4.2, p = 0.0003 | 19 / 5 / 0 | 규모가 커질 때 개선 |
| G100 − H50 | −2.5 | t = −1.2, p = 0.25 | 7 / 14 / 3 | 과제당 100개 생성은 사람 50개와 차이 없음 |

- 과제 대응 검정은 과제를 표본으로 봅니다. 과제마다 평가 잡음이 있으므로 과제 간 변동까지 포함합니다. 평가 잡음만 본 두 평균 차이 검정(z = 11.7)보다 보수적입니다.
- **중요한 결과.** 생성 100개(과제당)는 사람 50개와 구분되지 않습니다. 논문 본문이 "생성 데이터가 확장되면 성능이 오른다"고 쓴 것은 300 이상에서 맞고, 100 수준에서는 이득이 없습니다.

### 1.3 규모 추세

- 과제당 생성 수의 로그10 대 평균 성공률 기울기: **14.2 pp/십진 단위** (과제 부트스트랩 95% 구간 10.0–18.5). 기울기가 양인 부트스트랩 비율은 100%입니다(10000회).
- 과제별 단조성(G100 ≤ G300 ≤ G3000) 충족 과제: **17 / 24**. 평균은 단조이지만 과제 개별로는 7개 과제가 예외입니다. 예: PickPlaceMicrowaveToCounter(0 → 12 → 8%), CloseDoubleDoor(18 → 62 → 46%), TurnOnSinkFaucet(26 → 48 → 34%), TurnOffMicrowave(70 → 62 → 60%), CoffeePressButton(48 → 42 → 74%). 과제당 50회 평가의 이항 표준오차(성공률 0.1–0.5 구간에서 약 4–7 pp)로 설명될 수 있는 수준입니다.

### 1.4 기술 묶음별 평균 (우리가 묶은 방식)

논문 Fig. 7의 묶음과 같은 기준이지만 묶음 정의는 우리가 한 것입니다.

| 묶음 (과제 수) | H50 | G100 | G300 | G3000 |
|---|---|---|---|---|
| 수납·꺼내기 PnP (8) | 3.8% | 2.0% | 9.0% | 24.0% |
| 문 (4) | 39.5% | 38.5% | 53.5% | 59.5% |
| 서랍 (2) | 61.0% | 59.0% | 69.0% | 85.0% |
| 손잡이·버튼·가전 (7) | 44.3% | 40.0% | 49.4% | 60.3% |
| 커피 (3) | 23.3% | 20.7% | 23.3% | 40.0% |

PnP 과제에서 생성 데이터의 효과가 가장 큽니다(3.8 → 24.0%). 논문이 말한 "다양성이 큰 과제가 어렵다"와 맞습니다(V-A). 다만 이 표는 우리의 묶음이므로 인용하지 않습니다.

## 2. 실로봇 (Fig. 10, V-C)

| 구간 | 과제 | 실로봇만 (평균 ± SD) | 실로봇 + 시뮬 (평균 ± SD) |
|---|---|---|---|
| 보이는 객체 | 카운터→싱크 | 12.7 ± 2.5 | 22.0 ± 2.8 |
| | 싱크→카운터 | 20.0 ± 5.9 | 29.3 ± 4.1 |
| | 카운터→캐비닛 | 8.0 ± 1.6 | 22.0 ± 5.8 |
| | **과제 평균** | **13.6** | **24.4** |
| 미본 객체 | 카운터→싱크 | 3.3 ± 4.7 | 8.9 ± 7.9 |
| | 싱크→카운터 | 1.1 ± 1.6 | 7.8 ± 4.2 |
| | 카운터→캐비닛 | 3.3 ± 4.7 | 11.1 ± 11.0 |
| | **과제 평균** | **2.6** | **9.3** |

- 평균 재계산이 본문과 맞습니다(K5).
- **보이는 객체**: +10.9 pp, 상대 향상 **+80%**(표에서 계산). 본문의 79%는 반올림한 24.4/13.6에서 나온 값입니다(K6). Welch 근사(SD를 과제 독립으로 합산, 시드 3개) t = 5.6, df 3.9, p ≈ 0.005. 세 과제 모두 평균이 올랐습니다.
- **미본 객체**: +6.7 pp, 상대 향상 +261%(표에서 계산). 근사 t = 2.2, df 2.9, p ≈ 0.12. **방향은 같지만 통계적으로 확실하지 않습니다.** 과제 하나(카운터→캐비닛)의 SD가 11.0이라 시드 3개로는 구별이 어렵습니다.
- 본문 "performance suffers on unseen objects"는 절대 수준이 낮다는 뜻으로 읽힙니다. 시뮬을 더해도 미본 객체의 절대 성공률은 9.3%로 낮습니다. 이 점을 보고에 명시해야 합니다.
