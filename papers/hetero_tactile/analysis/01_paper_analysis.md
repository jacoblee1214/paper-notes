# 01. 논문 분석: Heterogeneous Tactile Transformer (HTT)

*Heterogeneous Tactile Transformer* (Jianxin Bi, Qiang Wang, Jayaram Reddy, Kelvin Lin, Soibkhon Khajikhanov, Ruihan Gao, Harold Soh; National University of Singapore, Carnegie Mellon University). arXiv:2606.29948, cs.RO. **CoRL 2026 포스터** (공식 채택 목록 확인, `02` §0). 분석 대상은 **v2 (2026-10-13)**입니다. 표와 절 번호는 v2 기준입니다.

- **본문의 비교 대상이 바뀝니다.** v1은 "가장 강한 기준선(SITR) 대비 9DTact +13.5%, GSMini +17%"라고 썼고(표 1 값으로 재계산하면 13.5, 17.04), v2는 "SPH와 AnyTouch 대비 +12.61%, +14.99%"입니다. 새 기준선 SPH(HTT 구조를 지도학습만으로 학습)가 들어가 격차가 줄었습니다.
- **절 5.3의 서술이 약해집니다.** v1 "정렬이 일관된 추가 이득을 준다(consistent additional gains)", v2 "평균 결과를 개선한다(improves the average results)". v1의 "모든 센서에서 기준선을 크게 앞선다"도 v2에서 "Scratch, T3, SITR, AnyTouch를 앞선다"(SPH 제외)로 좁혀집니다.
- **새 그림과 표.** v2의 그림 3(Procrustes 검색, R@1 3 → 20 → 41%)과 표 4 이름 변경(v1 표 3 → v2 표 4), 부록 표 5, 6에 SPH와 AnyTouch 열이 추가되었습니다. 값 자체는 v1과 같습니다(표 5의 T3, SITR, MAE, HTT 열과 표 6 같은 열을 대조했습니다).

## 1. 한 문단 요약

촉각 센서는 출력 형식이 달라(광학식은 이미지, 배열식은 taxel 시계열) 한 센서에서 학습한 모델을 다른 센서에 쓸 수 없습니다. HTT는 센서별 인코더(ViT 또는 시계열 트랜스포머)와 모든 센서가 공유하는 트렁크(9층)를 두고, 센서별 마스크 복원(MAE)과, 같은 접촉을 동시에 본 센서 쌍 사이의 교차 예측 손실(식 2)로 사전학습합니다. 쌍 데이터는 UMI 그리퍼 양 손가락에 서로 다른 센서를 달아 모은 HPT(Xela–9DTact, TAC-02–GelSight Mini)입니다. 평가는 물체 분류, 힘 추정, 슬립 검출 세 지각 과제, 실로봇 두 과제(toy screw, grasp tofu, 사전학습에 없던 Sharpa 센서), ManiFeel 시뮬 두 과제입니다.

## 2. 방법

### 2.1 데이터 (HPT, §3, 그림 1·2)

- 쌍 비지도 수집: UMI 양 손가락에 센서 둘을 3D 프린트 셸로 장착해 물체 30개와 상호작용(§3.1). 쌍 맞춤은 **접촉점 단위가 아니라 파지 단위**이며, 마주 보는 면이 거칠게 같은 접촉을 본다고 가정합니다(§3, v2 추가 문장). 시간 창 τ = 0.2 s(§4.1).
- 물체 분류: 20개 물체, 동작 press/twist/slide(§3.1, 부록 D).
- 힘 추정: 센서마다 탐침 하나(그림 2 A2: GSMini에 탐침 1, 9DTact에 탐침 2, Xela에 탐침 3, TAC-02에 탐침 4)를 6축 F/T 센서가 달린 장비로 눌러 라벨을 얻습니다. 범위 수직 40 N, 전단 14 N(그림 2 B1).
- 슬립 검출: 6축 힘에서 마찰계수 μ(t) = √(fx² + fy²)/(|fz| + ε)를 만들고 Page CUSUM으로 정적, 초기 슬립(incipient), 큰 슬립(slide) 3클래스를 붙입니다(부록 D, 식 4). 클래스 비율 13.6 / 1.2 / 85.2%(그림 2 B2).
- 헤드라인 "1.6M 쌍 프레임"의 구성은 `03` V8에서 따로 검산합니다.

### 2.2 모델 (§4, 부록 A.1)

| 항목 | 논문 값 |
|---|---|
| 임베딩 차원, 헤드 | D = 192, 3 |
| 인코더 깊이 | 광학 3, taxel 2 |
| 공유 트렁크 | 깊이 9, CLS 없음 |
| 교차 예측기 | 깊이 3 교차 어텐션, 학습형 마스크 토큰 |
| 광학 입력 | 224×224, 시간 튜블릿 크기 2, 튜블릿당 토큰 196 |
| taxel 입력 | 20프레임(Xela) 또는 40프레임(TAC-02), 시간 패치 4 → 토큰 5 또는 10 |
| MAE 마스크 | 광학 0.75, taxel 0.60 |
| 교차 예측 목표 마스크 | taxel 0.80, 광학 0.90 (소스는 마스크 없음) |
| 최적화 | AdamW, lr 3e-4, 배치 256, 워밍업 2,000스텝(3e-6에서), 코사인으로 3e-6, 클립 1.0 |
| 스케줄 | 총 50,000스텝. 정렬 가중치 0에서 시작해 20,000스텝 동안 선형 증가, 이후 α = 0.1 (본문은 "초기 워밍업 후 ramp") |

손실: L_HTT = L_MAE + α_t · L_Align (식 3). L_MAE는 센서 평균 마스크 MSE(식 1, 패치 정규화 목표), L_Align은 소스 전체 임베딩과 보이는 목표 임베딩으로 가려진 목표 임베딩을 예측하는 MSE(식 2)이고 목표에는 stop-gradient를 겁니다. 정렬 기울기는 예측기와 공유 트렁크만 갱신하고 인코더는 MAE 손실로만 갱신됩니다(§4.2). 사전학습 뒤 디코더와 예측기는 버립니다.

### 2.3 평가 방식 (§5.1, 부록 B·C)

- 비교 방법: Scratch(센서별 모델, 층 더 많음), T3, SITR, AnyTouch(광학식만, 공식 체크포인트), **SPH**(HTT와 같은 구조를 사전학습 없이 지도학습), MAE(구조 동일, MAE만 사전학습), HTT. 모든 사전학습 모델은 인코더와 트렁크를 과제 헤드와 함께 미세조정합니다.
- AnyTouch와 SPH는 시드 10, 20, 30의 평균±표준편차(부록 C). 다른 방법의 시드 수는 본문에 없습니다.
- 힘은 3D MAE(N), 슬립은 macro-F1, 분류는 20-클래스 top-1입니다. 하이퍼파라미터(미세조정 학습률, 스텝, 헤드)는 논문에 없습니다.

### 3.6 저자가 밝힌 한계 (§7)

광학식과 배열식만 다룸(자기식, 유체식 제외), 쌍이 항상 서로 다른 계열이라 같은 계열 쌍 효과는 미검증, 쌍이 시간과 접촉으로만 묶이고 공간(광학 패치 대 taxel)으로는 묶이지 않음.

## 4. 주장과 근거의 간격 (요약, 세부는 `03`)

1. **이득의 대부분은 구조(SPH)에서 옵니다.** 센서 평균 개선(Scratch → HTT) 중 구조 57–82%, 사전학습 −1–38%, 정렬 4–19%입니다(`03` V3).
2. **정렬 손실의 효과는 12칸 중 Holm 보정 후 2칸에서만 유의하고, 그중 하나(9DTact 힘)는 MAE가 더 낫습니다**(`03` V4, 시드 3개 가정).
3. **실로봇 두부 과제의 HTT 대 wrench는 p = 0.115입니다.** 나사는 p < 1e-4(`03` V5).
4. **"1.6M 쌍 프레임"은 같은 슬라이딩 프레임을 두 번 세고, 쌍으로 묶인 프레임은 0.95M, 사전학습 프레임은 0.71M입니다**(`03` V8).
5. **그림 3의 검색 점수는 객체 수준 정보만으로도 비슷하게 나올 수 있습니다**(`03` V7, 토이 2).
6. 부록의 평가 규모는 작습니다. 분류 테스트는 쌍당 40 에피소드, 힘·슬립 테스트는 센서당 약 10 에피소드입니다(`03` V8, 데이터셋 카드 기준).
