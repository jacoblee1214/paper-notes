# 04. 코드 대조, 주장 점검, 구현 가능성

이 논문의 **학습·평가 코드는 공개된 것을 찾지 못했습니다**(`02` §2). 공개된 것은 수집 때 교사로 쓴 **TactileReflex 제어기 저장소**입니다. 그래서 이 문서는 (1) 제어기 저장소를 논문 부록 C·D와 정적으로 대조한 D 항목, (2) 코드가 없는 부분을 표와 본문 수치로 점검한 주장 C 항목, (3) 구현 가능성 판정으로 구성합니다.

## 0. 대상과 방법

- 대상: `shayfeng/tactile-reflex-open-source` 커밋 `a3699b579555e03f1a12328db341cfd1da7014dd`(2026-10-10, 얕은 복제, 65 KB, 파이썬 5개 파일과 README). 복제 방법: `git clone --depth 1 https://github.com/shayfeng/tactile-reflex-open-source repo`. 이 논문의 arXiv v1(2026-09-22)보다 **뒤의 커밋**이고, 저장소는 커밋이 두 개(`30f336d`, `a3699b5`, 둘 다 2026-10-10)뿐입니다.
- 방법: 읽기만 했습니다. 코드를 실행하거나 import하거나 설치하지 않았고 저장소 안의 파일은 바꾸지 않았습니다. 저장소에 라이선스가 없어 코드를 옮기지 않고 식별자와 줄 번호만 인용합니다(`tactile_exp_v2.py:줄`).
- 저장소 README의 단서: "논문 실험 이후의 개선과 센서 확장을 포함하며, 논문에 실린 구현과 보정 임계값이 다를 수 있다." 아래 판정은 이 단서를 전제합니다. 즉 코드와 논문이 다르다는 것이 논문 수치가 다른 설정에서 나왔다는 뜻은 아닙니다.

## 3. 주장 점검 (C 항목)

코드가 없는 부분은 표와 본문 수치로 점검했습니다(`03`의 V, K 항목 참조). 판정: **맞음**(재계산과 일치하고 근거가 충분), **방향만**(방향은 맞으나 표본이 구분하지 못함), **교란 있음**(결과는 맞으나 원인 해석이 다른 요인과 섞임), **근거 약함**.

## 4. 구현할 수 있는지

판정은 이 맥(Apple M4 Pro, 약 24 GiB 통합 메모리, MPS, CUDA 없음)과 일반 연구실 환경을 기준으로 합니다. 노력 추정은 측정 전 값입니다.

| 작업 | 이 맥(CPU/MPS) | 필요한 것 | 노력(추정) |
|---|---|---|---|
| 논문 수치 그대로의 재현(실로봇, 표 1–5) | **불가** | Piper 팔과 그리퍼, SO101 리더, MC-Tac 센서 2개(3D 프린트, 카메라, LED, 젤), 카메라 2대, 일회용 컵, 조작자, 학습용 GPU | 장비 구성에 수 주 이상, 데이터 수집에 수일 |
| 교사 제어기의 실물 실행 | **불가** | 저장소는 리눅스 전용(카메라 자동 탐지가 `/sys/class/video4linux`를 읽음)이고 Piper는 CAN 필요. 라이선스 없음 | 장비가 있을 때 하루 안팎 |
| 교사 제어 논리의 재구현(상태 기계 + 세 채널) | **가능** | 150–200줄(제어 논리), 시뮬레이터에 붙이면 며칠 | 1–3일 |
| 중재기(알고리즘 1)와 동역학 손실(L1 2차 차분) 구현 | **가능** | 각각 수십 줄, 가짜 정책 출력이나 합성 궤적으로 시험 가능 | 1–2일 |
| ACT(18 M)를 작은 합성·시뮬 데이터로 학습 | **가능**(MPS, 수 시간 규모는 추정) | 데이터는 직접 만들어야 함(공개 시연 없음) | 시뮬 환경 포함 1–2주 |
| π0.5(2B+) LoRA 미세조정 | **불가에 가까움** | 논문은 RTX 5090 한 장. 공개 openpi는 JAX 기반이고 CUDA를 전제하는 것이 일반적 | — |
| 핵심 가설의 시뮬 축소판(MuJoCo, 얇은 컵, 힘 구간, 지연이 있는 조작자 모형 대 반사 교사, 모방 학생) | **가능** | 접촉 강성과 지연 등 많은 값을 가정해야 하고 실물 결과와 같다고 할 수 없음 | 1–2주 |

**한 줄 판정: 실물 재현은 이 맥에서 불가능하고, 중재기·동역학 손실·교사 논리의 소프트웨어 부분과 핵심 가설의 시뮬 축소판은 CPU에서 구현할 수 있습니다.** 논문 수치가 설정 값(닫기 스텝, 그리퍼 세기, EMA, 임계 1.5 대 1.3, 중재기 K)에 얼마나 의존하는지는 공개 자료로 확인되지 않습니다.
