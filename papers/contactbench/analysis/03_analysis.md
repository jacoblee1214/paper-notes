## 5. 유도

**5.1 Wilson 구간.** 성공 수 k, 시도 n, p̂ = k/n, z = 1.96 일 때

  center = (p̂ + z²/(2n)) / (1 + z²/n),  half = z·√(p̂(1−p̂)/n + z²/(4n²)) / (1 + z²/n)

구간은 [center − half, center + half]입니다. k = 0이면 하한이 0, k = n이면 상한이 1입니다.

**5.2 Fisher 정확 검정(양측).** 2×2 표 [[a, n₁−a], [b, n₂−b]]에서 주변합을 고정하면 a는 초기하분포를 따릅니다. 양측 p는 관측 확률 이하인 모든 표의 확률 합입니다. scipy의 `fisher_exact(alternative="two-sided")`가 이 값을 씁니다.

**5.3 CMH(층화 Mantel–Haenszel, 연속성 보정).** 과제 i마다 2×2 표 (a_i, b_i, c_i, d_i), 층 크기 n_i = a_i+b_i+c_i+d_i라 할 때

  E_i = (a_i+b_i)(a_i+c_i)/n_i
  V_i = (a_i+b_i)(c_i+d_i)(a_i+c_i)(b_i+d_i) / (n_i²(n_i−1))
  χ² = (|Σ(a_i − E_i)| − 0.5)² / Σ V_i,  p = P(χ²₁ > χ²)

공통 오즈비(Mantel–Haenszel)는 OR = Σ(a_i d_i/n_i) / Σ(b_i c_i/n_i)입니다. 어떤 층의 b_i c_i가 모두 0이면 정의되지 않습니다(이 경우 None으로 기록).

**5.4 Holm 보정.** 유의 p를 오름차순 p₍₁₎ ≤ … ≤ p₍ₘ₎로 정렬하면, 보정 p₍ⱼ₎ = max_{k≤j} min(1, (m−k+1)·p₍ₖ₎)입니다.

**5.5 Newcombe 차이 구간.** p₁ − p₂의 구간은 두 Wilson 구간 [l₁, u₁], [l₂, u₂]로부터

  lower = d − √((p₁ − l₁)² + (u₂ − p₂)²),  upper = d + √((u₁ − p₁)² + (p₂ − l₂)²),  d = p₁ − p₂

입니다.

**5.6 쌍 설계일 때의 McNemar(이 자료에는 적용 못 함).** 같은 초기 조건의 두 방법에서 불일치 쌍 수 b(A 성공, B 실패)와 c(A 실패, B 성공)가 있으면 χ² = (|b−c|−1)²/(b+c), 자유도 1입니다. 에피소드별 기록이 공개되면 Fisher 대신 이 검정을 써야 합니다.

**5.7 최소 검출 차이.** 방법당 n, 기준 비율 p̄(두 비율의 평균), 양측 α = 0.05, 검정력 1−β = 0.8일 때

  Δ_min ≈ (z_{α/2} + z_β) · √(2 p̄(1−p̄) / n)

n = 30이면 p̄ = 0.5에서 Δ_min ≈ 36.2 pp, p̄ = 0.2에서 28.9 pp입니다(`table_check_results.json`의 mde_80pct_n30).

## 7. 토이 P2: 초기 조건 공유와 학습 실행 분산

**설정(가정).** 로짓 모형 P(성공) = σ(μ_k + s_k + b_i). b_i ~ N(0, 1)은 초기 조건 난이도, s_k ~ N(0, σ_s²)은 정책 k의 **학습 실행 효과**입니다. 정책당 학습 실행이 1회이면 s_k는 한 번 뽑힌 값이고 시행을 늘려도 평균되지 않습니다. 설계 R은 시행마다 새 초기 조건을 뽑고, 설계 S는 두 방법이 같은 n개 초기 조건을 씁니다. 귀무가설은 μ_A = μ_B입니다. 대립은 δ = 0.85 로짓 차이(기준 0.5 대 0.7)입니다. 2000회 반복, Fisher 정확 양측 0.05입니다.

| 설계 | σ_s | n | 거짓 양성률(귀무) | 검정력(δ = 0.85) | McNemar 거짓 양성 / 검정력(설계 S만) |
|---|---|---|---|---|---|
| R | 0 | 30 | 0.030 | 0.19 | — |
| R | 0 | 150 | 0.040 | 0.82 | — |
| S | 0 | 30 | 0.013 | 0.17 | 0.018 / 0.21 |
| S | 0 | 150 | 0.025 | 0.85 | 0.038 / 0.88 |
| R | 0.25 | 30 | 0.059 | 0.22 | — |
| R | 0.25 | 150 | 0.180 | 0.72 | — |
| S | 0.25 | 30 | 0.036 | 0.19 | 0.048 / 0.22 |
| S | 0.25 | 150 | 0.186 | 0.72 | 0.222 / 0.75 |
| R | 0.5 | 30 | 0.141 | 0.27 | — |
| R | 0.5 | 150 | 0.429 | 0.65 | — |
| S | 0.5 | 30 | 0.129 | 0.28 | 0.149 / 0.30 |
| S | 0.5 | 150 | 0.449 | 0.67 | 0.475 / 0.69 |

**해석**
1. **초기 조건을 공유하는 것 자체는 거짓 양성을 늘리지 않습니다.** σ_s = 0에서 S의 Fisher 검정은 오히려 보수적입니다(0.013, 0.025). 같은 초기 조건은 두 결과를 양의 상관으로 묶고, 독립을 가정한 검정은 그만큼 차이를 과소평가합니다.
2. **거짓 양성을 늘리는 것은 학습 실행 분산입니다.** σ_s = 0.25 또는 0.5에서 R과 S 모두 거짓 양성률이 n과 함께 커집니다(σ_s = 0.5, n = 150: 0.43–0.45). 시행을 많이 해도 학습 실행 차이는 평균되지 않으므로, 시행 수가 늘수록 "유의한" 차이가 더 자주 나옵니다.
3. 쌍 검정 McNemar는 S에서 검정력을 약간 높입니다(+0.02–0.04). 에피소드별 기록이 있다면 쓸 가치가 있습니다.
4. 이 결과는 **σ_s의 값에 달려 있습니다.** σ_s = 0.25 로짓은 p = 0.5 근처에서 약 ±6 pp의 학습 실행 차이입니다. 실제 값은 이 논문 자료로는 추정할 수 없습니다. 방향만 주장으로 씁니다.
5. contact_disassembly 분석의 결과(1500 독립 가정 대 3 시드 × 50 초기 조건)와 같은 구조입니다. 그 분석에서 큰 차이는 독립 가정으로 시행을 세었기 때문에 생겼습니다. 이 토이는 독립 가정이 틀렸을 때의 방향을 보여 줍니다.

**(a) 가중 평균의 순위.** 과제 가중치를 Dirichlet(1,…,1)로 2만 번 뽑았습니다. 같은 순서가 유지되는 비율은 다음과 같습니다.

|---|---|---|

| DP > RDP (4과제) | 0.87 | 0.84 |
| π0.5 > FTP-1 (4과제) | 1.00 | 0.94 |

- π0.5 > DP, π0.5 > FTP-1은 가중치에 강합니다. DP > RDP는 plug 과제의 가중치가 커지면 뒤집힙니다(plug에서 RDP 4/30 대 DP 2/30).

**(b) 기술 수 가중**(Table II 기준: thread 2, tighten 2, plug 1, door 1, utensil 2, card 1)을 쓰면 6과제 평균은 DP 23.0%, π0.5 48.9%이고 4과제에서는 DP 26.7%, RDP 18.3%, π0.5 54.4%, FTP-1 37.2%입니다. 순서는 바뀌지 않습니다. 그러나 RDP와 DP의 차이는 4과제 균등 가중(5.8 pp)보다 커집니다(8.3 pp).

**(c) 과제 하나를 뺄 때** 6과제 평균 차이(π0.5 − DP, pp)는 thread 뺌 16.7, tighten 뺌 9.3, plug 뺌 18.0, door 뺌 20.7, utensil 뺌 10.0, card 뺌 28.7입니다. 조이기에서 가장 큰 차이가 나므로, 이 과제를 빼면 차이가 가장 작아집니다(9.3 pp). 방향은 모든 경우에 같습니다.

**해석**: 집계 점수는 "과제 선택"에 민감합니다. 6과제 평균이 4과제 평균과 다르고, 촉각 방법은 4과제만 있으므로 6과제 평균을 쓰면 안 됩니다. 논문은 집계 점수를 쓰지 않았습니다(Table III는 과제별 표). 이 벤치마크에 집계 점수를 도입한다면, 가중치와 누락 과제를 먼저 정해야 합니다.
