# 03. 수치 재계산, 일관성 검사, 토이 검사, 주장 판정

재계산은 `analysis/recompute.py`(결과 `recompute_results.json`, 수 초), 토이는 `analysis/toy_checks.py`(결과 `toy_checks_results.json`, 수 초)입니다. 그래프는 `analysis/plot_figures.py`입니다. 새로 학습하거나 공식 코드를 실행한 것은 없습니다.

항목 이름: **V**는 재계산(V1–V10), **K**는 문서 안의 불일치(K1–K10), **C**는 주장 판정(C1–C14)입니다. 공식 코드와의 차이는 `04`의 **D** 항목입니다.

## 0. 가정

- 표의 "±"는 시드 3개(10, 20, 30)의 표본 표준편차로 가정합니다. 부록 C는 AnyTouch와 SPH에 대해서만 이렇게 적었고 다른 방법의 시드 수는 없습니다. 표본 SD(ddof = 1)를 기본으로 하고, 모집단 SD로 읽은 p는 `recompute_results.json`의 `p_ddof0`에 둡니다(방향은 같고 p가 더 작음).
- 실로봇 분모는 표 3 캡션의 40회입니다. ManiFeel은 시드 3개(표 4)이고, 시드 안의 50회는 합산하지 않았습니다.
- 데이터셋 크기와 분할은 공개 데이터셋 카드의 `STATS.json`에서 옮긴 값입니다(데이터 파일은 받지 않았습니다).
- 검정은 양측입니다. 비율은 Fisher 정확검정과 Wilson 구간, 평균 비교는 Welch t 검정(요약 통계), 다중 비교는 Holm입니다. 시드 3개 검정은 검정력이 낮아 "차이가 없다"의 증거가 아니라 "구분할 수 없다"로 읽어야 합니다.

### V2. 표 2, 5, 6 일관성

- 표 2의 힘·슬립 열은 부록 표 5, 6의 값과 모두 일치(힘 22칸, 슬립 22칸). 힘 평균(Overall)과 슬립 평균도 일치.
- 3D MAE는 정의상 (2 × 전단 + 수직)/3입니다(부록 C). 22칸 중 21칸이 0.002 안에서 맞고, **TAC-02 Scratch 하나만 어긋납니다**(K1).
- 슬립 macro-F1은 세 클래스 F1의 평균이어야 합니다. 22칸 중 20칸이 0.06 안에서 맞고 Scratch 두 칸이 0.33 어긋납니다(K2).
- Scratch의 슬립 붕괴는 산술로 확인됩니다. 항상 "slide"만 내면 macro-F1은 slide F1/3입니다(Xela 89.4/3 = 29.8로 일치). 전부 slide일 때 이론 최댓값은 30.7(slide 비율 85.2% 기준)이고, 표의 Scratch 29.8–32.0이 이 값 근처입니다.

|---|---|---|---|---|---|---|---|

- 괄호는 Scratch → HTT 총개선 중 비율입니다. Scratch는 구조와 학습 조건이 HTT와 다르므로(광학 Scratch는 층이 더 많음, 부록 B) 이 분해는 "구조가 같은 SPH"를 기준으로 읽어야 합니다.
- 사전학습 효과는 분류에서 분명하고(MAE 대 SPH, 센서 4개 모두 +0.9–12.7), 힘에서는 일관되게 작은 개선, **슬립에서는 없습니다**(센서 평균 51.62 대 51.90, GSMini −3.0, Xela −0.4).
- 정렬(HTT 대 MAE)은 분류 평균 +0.82, 힘 평균 −0.028 N, 슬립 평균 +4.73입니다. 슬립 평균 개선 4.73 중 +12.0이 TAC-02 한 칸에서 옵니다(V4).

### V6. ManiFeel (표 4)

- 비율 평균은 3 × 50 = 150회에서 정수로 가능합니다(예: 0.44 = 66/150, 0.48 = 72/150).
- Welch(시드 3개): peg HTT(RGB) 대 SITR 0.44 대 0.35, p = 0.053. HTT(FF) 대 SITR 0.48 ± 0.12 대 0.35, p = 0.20. HTT(RGB) 대 tacRGB와 T3는 p = 0.003, 0.004(Holm 전). bulb은 전부 0.72–0.77이고 HTT(RGB)·(FF)와 SITR 사이 p = 1.0, 0.73.
- 시드 SD의 크기 점검: 한 시드 50회의 이항 표준편차는 약 0.06–0.07인데, 보고된 SD는 0.01(SITR peg)–0.06입니다. SITR peg의 SD ≤ 0.01이 나올 확률은 약 2%입니다. 시드 사이에 평가 환경 난수를 공유한다면 가능하므로 의심이 아니라 확인 사항입니다.
- 150회를 시드 구분 없이 합친 Fisher(낙관적): HTT(RGB) 대 SITR p = 0.12, HTT(FF) 대 SITR p = 0.026.

### V7. 교차 센서 검색 (그림 3, §5.4)

- R@K는 99 에피소드에서 정수로 가능합니다: 3/99, 20/99, 41/99 (R@1), 20/99, 60/99, 81/99 (R@5). 무작위 기준은 R@1 1.0%, R@5 5.1%(갤러리 50이면 2%, 10%)이고, 무작위 초기화의 R@5 20%는 이미 기준의 약 4배입니다.
- HTT 대 MAE만(Fisher, 같은 질의의 짝지음을 무시한 비교): R@1 41 대 20 p = 0.002, R@5 81 대 60 p = 0.0016.
- **객체 수준 기준.** 99 에피소드가 30개 물체에서 나왔다고 보면(균등 배정, 객체 라벨은 데이터셋 카드에서 제거됨), 같은 물체의 후보 중 임의로 고르는 검색자의 기대 R@1은 약 29%, R@5는 약 94%입니다(`V7`, 2,000회 모의). 논문의 HTT R@1 41%, R@5 82%와 같은 자릿수입니다.
- **토이 2** (합성 임베딩, 에피소드 99개, 객체 30개, d = 192, Procrustes를 절반 에피소드로 맞추고 49개에서 검색): 에피소드 정보 없이 **객체 코드만 공유**해도 창 잡음에 따라 R@1 32–41%, R@5 74–88%가 나옵니다(갤러리 49의 무작위 기준은 2%, 10%). 에피소드 코드를 공유하면(λ = 1.0, 낮은 잡음) R@1 80%까지 올라가므로 지표가 완전히 둔감한 것은 아니지만, 41/82%만으로는 "에피소드별 대응"과 "객체 수준 대응"을 가를 수 없습니다. 실제 임베딩이 아니므로 가능성의 확인입니다.
- 분할 서술이 모호합니다: "보류 쌍의 절반으로 사상을 맞추고 나머지 절반에서 시험"하는데 R@K는 "99 에피소드 전체"입니다(K9). 데이터셋 카드의 Xela–9DTact 사전학습 테스트 분할이 정확히 99 에피소드이므로 이 분할일 가능성이 높습니다. 검색 코드는 공개되지 않았습니다.

## 3. 토이 검사 (CPU, 각 수 초)

### 토이 1: 공식 코드의 최선 상태 저장이 스냅샷이 아닙니다 (`04` D9)

`run_probe.py`의 `best_probe_model_state = probe_mlp.state_dict().copy()`는 얕은 복사입니다. 작은 선형층으로 확인하면 50스텝 뒤 "스냅샷"이 현재 가중치와 같고(`shallow_snapshot_equals_current: true`) 스냅샷 시점 값과 다르며(`false`), 라이브 파라미터와 같은 저장소를 가리킵니다. 따라서 `load_state_dict`는 효과가 없고 헤드는 조기 종료 시점의 가중치로 남습니다. 인코더와 트렁크는 CPU로 복제해 저장하므로(코드 주석) best-val 스텝으로 복원됩니다. 모든 방법이 같은 경로를 쓴다면 영향은 비교 전반에 걸친 작은 잡음입니다. 이 경로가 논문 표에 쓰였는지는 확인할 수 없습니다(`results`는 공개되지 않음).

### 토이 2: 객체 정보만 있는 임베딩의 Procrustes 검색

V7에 결과를 적었습니다. 객체 코드만 공유하는 합성 임베딩도 R@1 32–41%, R@5 74–88%를 냅니다(논문 HTT 41/82%).
