## 2. Table II–III: 정책 평가 상관과 MMRV

### 2.1 Pearson r의 자유도
- 정책이 3개이므로 과제마다 상관은 점 3개로 계산됩니다(df = n − 2 = 1).

- p < 0.05가 되려면 |r| ≥ 0.9967입니다. 이 값은 `table_check.py`의 임계값과 일치합니다.

## 4. 토이 A: 사람 데이터는 언제 도움이 되는가

### 4.1 설정 (`analysis/transfer_toy.py`)
- 로봇 도메인: y = w_r^T x + ε, D = 8, 로봇 샘플 N_t = 25(5시간 고정의 소량 가정), σ = 0.5.
- 사람 도메인: 같은 입력 분포에서 y = (w_r + δ)^T x + ε. 격차 δ는 w 벡터에 1/√D 방향으로 더한 크기. 단위는 임의입니다.
- 리타게팅 오차: 사람 입력에 x + e, e ~ N(0, s_r² I). 입력 오차가 있는 회귀(errors-in-variables)입니다.
- 학습: 로봇 + 사람을 합친 최소제곱. 평가: 로봇 도메인 새 샘플 4000개의 MSE. 30회 반복 평균.
- 소스 샘플 N_s ∈ {0, 25, 50, 100, 200, 400}.

### 4.2 결과 (N_s = 400일 때 이득 = MSE(N_s=0) − MSE(N_s=400), 양수면 도움)

| 격차 δ \ 리타게팅 오차 s_r | 0 | 0.25 | 0.5 | 1.0 |
|---|---|---|---|---|
| 0 | +0.112 | +0.111 | −0.035 | −0.694 |
| 0.25 | +0.055 | +0.049 | −0.043 | −0.726 |
| 0.5 | −0.128 | −0.122 | −0.185 | −0.768 |
| 1.0 | −0.743 | −0.682 | −0.629 | −0.949 |

- **도움이 되는 조건:** 격차가 작고(δ ≲ 0.25) 리타게팅 오차가 작을 때(s_r ≲ 0.25)입니다.
- **해가 되는 조건:** 격차가 δ ≥ 0.5 이거나, 격차가 0이어도 리타게팅 오차가 s_r ≥ 0.5이면 소스를 섞는 쪽이 손해입니다. s_r = 0.5에서 격차가 0이면 소스 섞기가 약간 손해(−0.035)인데, 입력 오차가 회귀 계수를 0 쪽으로 끌어당기기 때문입니다.
- **결론:** 사람 데이터의 이득은 도메인 격차와 리타게팅 오차에 따라 부호가 바뀝니다. 논문이 리타게팅 오차를 측정하지 않았으므로, 사람 데이터가 도움이 되는지는 논문으로 판단할 수 없습니다. 이 점은 04 C11, C12와 연결됩니다.
- 한계: 선형 모델, 입력 분포는 표준정규, 격차를 w 벡터에 한 방향으로만 줬습니다. 실제 촉각 맵은 비선형이고 접촉 희소성이 있어 결과를 그대로 옮길 수 없습니다.

## 5. 토이 B: 희소 접촉 촉각 맵에서 MSE의 오해

### 5.1 설정 (`analysis/sparse_metric_toy.py`)
- 320 taxel을 20×16으로 근사. 접촉 taxel 비율 3%와 10%. 접촉 값은 0.4–1.0 균등, 정답은 가우시안으로 살짝 번짐.
- 후보 예측: zero(항상 0), blur(정답을 흐리고 0.6배), shift(정답을 1 taxel 옮김), noisy(정답 + 잡음 0.03).
- 접촉 지표: 임계값 0.1로 이진화한 IoU와 F1, 접촉 칸만 본 MAE. 200회 평균.
- **주의:** 임계값 0.1은 제가 고른 값입니다. blur는 최대값이 낮아 임계값 아래로 떨어지므로 F1이 0이 됩니다. 임계값을 바꾸면 blur 결과가 달라집니다.

### 5.2 결과 (접촉 3%)

| 후보 | MSE | PSNR | Contact-IoU | Contact-F1 | Contact-MAE |
|---|---|---|---|---|---|
| zero | 0.0038 | 24.3 | 0.000 | 0.000 | 0.234 |
| blur | 0.0031 | 25.2 | 0.000 | 0.000 | 0.208 |
| shift | 0.0040 | 24.0 | 0.166 | 0.278 | 0.192 |
| noisy | 0.0005 | 32.9 | 0.639 | 0.776 | 0.024 |

- **오해가 생기는 지점:** shift는 접촉 위치 1칸만 틀렸지만 접촉 F1이 0.28입니다. MSE는 zero보다 나쁩니다(0.0040 대 0.0038). 아무것도 예측하지 않는 쪽이 MSE로는 더 낫게 보입니다.
- blur는 MSE가 zero보다 낫지만(0.0031) 접촉 F1은 0입니다. 흐린 예측이 평균 오차만 줄이고 접촉은 찾지 못합니다.
- 접촉 10%에서도 같은 방향입니다(zero MSE 0.0157 F1 0, shift MSE 0.0133 F1 0.48).
- **결론:** 희소 맵에서 MSE와 PSNR은 "배경을 0으로 맞추는" 능력을 크게 보상하고 접촉 위치의 정확성은 작게 반영합니다. 논문이 Contact-MAE·IoU·F1을 추가한 것은 이 문제를 인식했다는 뜻이고, 방향은 옳습니다. 다만 논문의 접촉 임계값과 Contact-MAE 정의가 없어서 이 설계가 실제로 얼마나 효과가 있는지 확인할 수 없습니다.

## 6. 유도

### 6.1 잔차 촉각 잠재(식 2)는 표현력을 늘리는가
- 디코더 D_x는 주어진 것이고 z_0는 깨끗한 문맥입니다. 예측값 ẑ_t = z_0 + r̂_t이므로 잠재 오차는 e_t = z_t − ẑ_t = r_t − r̂_t입니다.
- 따라서 잔차 예측의 잠재 오차는 절대 잠재 예측의 오차와 같습니다(z_0가 맞다는 조건에서). 정보가 늘지 않습니다.
- 차이는 **학습 동역학과 귀납 편향**에서만 생깁니다. 배경 압력이 큰 장면에서 학습 신호가 작은 변화에 집중하므로 실제 이득이 있을 수 있지만, 논문은 이 효과를 분리하지 않았습니다(잔차 대 절대 ablation 없음). 이 점은와 연결됩니다.
- 접촉 마스크 손실: 손실 값이 접촉 토큰에서만 계산되면 비접촉 토큰의 오차는 학습에 들어가지 않습니다. 평가 지표는 전체 taxel에서 계산되므로 학습과 평가가 다른 영역을 봅니다. 논문의 MSE 개선 중 일부가 이 불일치 때문일 수 있습니다. 마스크 정의가 없어 확인하지 못했습니다.

### 6.2 Pearson 자유도 1의 임계값
- 양측 검정에서 t = r/√(1−r²), 자유도 1의 t 분포는 Cauchy입니다.
- P(|T| > t) = 1 − (2/π)·arctan(t). p = 0.05를 두면 t = tan(0.95π/2) ≈ 12.71이고 r = t/√(1+t²) ≈ 0.9967입니다.

### 6.3 MMRV의 닫힌 형식
- 정책 N = 3, 쌍 (i, j)에서 실제 순위가 뒤집힌 쌍이 하나뿐이고 실제 점수 차가 d이면 MMRV = (d + d)/3 = 2d/3입니다.
- 검산: Place Shoes WM-Robot d = 0.05 → 0.0333(본문 0.033). Stand Bottle d = 0.10 → 0.0667(본문 0.067). 두 값 모두 맞습니다.

### 6.4 Table IV 차이의 표준오차 (4.2절과 같은 가정)
- 셀 하나의 SE = SD/√10, 4과제 평균 SE = (SD/√10)/√4, 두 독립 평균의 차이 SE = √2 × 그 값.
