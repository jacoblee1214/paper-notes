## 0. 읽는 방법

- 식은 논문 번호(Eq. (n)), 표는 Table n, 알고리즘은 Alg. n으로 씁니다.
- 주장의 근거는 원문 절이나 표 번호로 붙였습니다. 수치 재계산과 검증은 `03`, 코드 대조는 `04`에 있습니다.

## 1. 한 문단 요약

접촉 마찰, 강성, 슬립과 물체 자세에 대한 믿음을 **미분 가능한 가우시안 혼합(K = 8)**으로 놓고, Gumbel-Softmax 성분 선택과 위치-척도 재매개변수화(Eq. (8)–(9))로 샘플을 믿음 매개변수의 매끄러운 함수로 만듭니다. 그러면 CVaR 대리 목표(Eq. (12))를 행동에 대해 바로 미분할 수 있고(Eq. (13), Alg. 1), 입자 필터 MPC보다 계획 시간이 짧아진다고 주장합니다. 시뮬레이션(MuJoCo, 11-DOF 손과 6-DOF 팔)에서 마찰 체제 3개와 교란 28개로 평가하고, 실물에서는 FR3 팔과 RealHand L6, 물체 3개, 시험 12회로 확인합니다.

## 2. 문제 설정 (§II)

- 잠재 상태 θ = (ξ_o, ψ). ψ는 접촉마다 (µ, κ, d, s)를 갖고, 접촉은 최대 5개입니다(Def. 1, §II).
- 관측 o_t는 자세 추정(ICP 공분산), 촉각, 관절, 가림·분할 신뢰도입니다(Def. 2, 식 (3)).
- 목적은 CVaR 기반 위험 민감 비용을 최소화하는 행동열입니다(Def. 4, Problem 1, 식 (5)–(6)).
- 행동은 6차원 손가락 관절 속도 명령입니다. 팔은 고정입니다(§II).

**관찰.** 문제 설정은 명확하지만 "잠재 상태"는 실제로 시뮬레이션에서 무엇이 바뀌는지 정의하지 않습니다. 강성 κ와 감쇠 d가 물리에 들어가는지는 §V-A와 `04` D9를 보세요.

## 3. 방법 (§III–IV)

### 3.1 GMM 믿음 (§III-A, 식 (7)–(9))

- 믿음 p(θ|ϕ) = Σ_k π_k N(θ; µ_k, diag σ_k²), 매개변수 ϕ = {ℓ, µ_k, log σ_k}.
- 샘플 θ = Σ_k ζ_k (µ_k + σ_k ⊙ ε_k), ζ는 Gumbel-Softmax 가중치(식 (9)), τ는 탐색과 활용을 조절합니다(§III-A).

**검증 결과(`03` §6d).** 식 (8)의 샘플은 혼합분포의 표본이 **아닙니다**. 두 봉우리 사이 간격(0.4–0.8)의 질량이 혼합에서는 0이지만, 코드가 쓰는 τ = 0.5에서는 27%입니다. "다중모드 믿음"이라는 핵심 주장과 맞닿는 문제입니다.

### 3.2 신경 믿음 갱신 (§III-B, Alg. 2, 식 (10), Table V)

- 전이 MLP f_trans([h_t; a_t])와 관측 MLP f_obs([h^pred; o])로 잠재 h를 갱신하고, 디코더 DecodeBelief가 ϕ를 냅니다. 지수이동평균 α_ema로 ϕ를 섞습니다(Alg. 2).
- 구조: d_h = 64, 전이 MLP [70, 128, 128, 64], 관측 MLP [105, 128, 128, 64], 디코더 [64, 64, K(2d+1)] (Table V).
- **학습 데이터와 손실은 본문에 없습니다.** Table V는 Adam, η = 3×10⁻⁴, 배치 64, 500 epoch만 적었습니다. 학습 데이터는 본문에서 찾지 못했습니다. 저장소에도 학습 스크립트가 보이지 않습니다(`04` D21, 미확인).
- 각주 1은 다중모드가 심하면 SIREN과 Langevin 샘플링(부록 B)을 쓸 수 있다고 합니다. 이 변형은 실험하지 않았습니다.

### 3.3 CVaR 대리 목표와 그래디언트 (§IV-A, 식 (11)–(13), 부록 A)

- 쌍대 형태 CVaR_β = min_η {η + E[(C − η)_+]/(1 − β)}(식 (11)). 샘플 근사에서 힌지를 softplus(κ = 5)로 바꿉니다(식 (12)).
- 그래디언트: ∇_a CVaR̂ = Σ σ_κ(C_i − η̂) ∇_a C_i / ((1−β)N)(식 (13)).
- 부록 A (Thm. 1): 식 (26)의 그래디언트는 η̂의 기여가 0이라는 포락 정리에 기댑니다. Remark 2는 η̂를 상수로 둔다고 적습니다.

**검증 결과(`03` §6c).** softplus 근사의 편향은 양수이고 β에 따라 커집니다. β = 0.99, N = 256에서 평균 +0.28입니다. Remark 1이 말하는 "negligible"은 힌지 근사의 상한에 대한 것이고, 꼬리 평균에서는 1/(1−β)만큼 커집니다.

### 3.4 비용 (§IV-B–D, 식 (14)–(19), Table V)

- 비용 C = C_str + C_ρ + C_ctc(식 (14)). 닫힘 강도 C_str(식 (15)), 마찰 여유 C_ρ, 접촉 안정성 C_ctc를 씁니다.
- 가중치: α_s = 1.0, α_g = 0.5, α_r = 2.0, α_n = 0.1(Table V).
- 시각 비용 C_vis(식 (16)): 자세 공분산 trace, 가림, 분할 신뢰도. 시뮬레이션에서는 λ_v = 0입니다(§IV-C, §IV-E).
- 실패 확률: P̂_fail = Pr(C > τ_f), 몬테카를로 식 (18), 부드러운 형태 식 (19), τ_f = 5.8(§IV-D).

**Table V의 λ_v = 0.3과 본문의 λ_v = 0은 다릅니다**(`04` D4).

### 3.5 MPC와 알고리즘 (§IV-E, 식 (20)–(21), Alg. 1)

- 목적 J = λ_c CVaR_β[C_t] + (1 − λ_c) E[C_t] + λ_v C_vis + γ H[b_{t+H}](식 (20)). 엔트로피 항은 정보 획득을 장려합니다.
- 믿음의 **성분마다** 행동을 따로 최적화하고, 목적이 가장 낮은 성분의 행동을 실행합니다(Alg. 1, "avoids optimizing against an averaged belief"). 다중 출발점은 3개의 초기 행동 크기입니다.
- 종료 조건은 ε ≥ ε_des, T_max = 80(Alg. 1, Table V)입니다. 실패 확률 제약 P̂_fail ≤ δ로 성분을 고릅니다.
- 실물 품질은 촉각 대리 ε̂ = Q(o)입니다(식 (34), 부록 D).

**관찰.** Alg. 1은 "미분 가능한 MPC"라고 하지만 행동 최적화의 세부(step size α_u, 기울기 단계 M, δ, γ, ε_des)는 Table V에 없습니다. 이 값들을 찾지 못했습니다. `04` D3는 저장소에서 λ_c가 실제로 어떻게 쓰이는지 보여 줍니다.

## 4. 실험 (§V)

### 4.1 시뮬레이션 설정 (§V-A, §V-D)

- MuJoCo, 11-DOF 손 + 6-DOF 팔(ZArm 622 + RealHand L6). 강성 κ ~ N(1000, 250²) N/m, 질량 ±20%(§V-A).
- 마찰은 식 (22) µ_eff = √(µ_f·µ_o)를 쓴다고 합니다. 각주 2: µ_f = 1.0을 시뮬레이터 기본값으로 씀(PEEK 0.35는 불안정).
- 체제: nominal U[0.4, 1.0], wide U[0.15, 1.2], bimodal 0.5 N(0.18, 0.03²) + 0.5 N(1.0, 0.05²).
- 교란 28개(§V-D, Table II): 횡 충격 3, 5, 8, 12 N × 4 방향(16), 토크 0.3, 0.6, 1.0 N·m × 3축(9), 마찰 저하 µ ∈ {0.05, 0.10, 0.15}(3).
- 객체: 큐브와 박스(두 프리미티브). 각 조건에서 β ∈ {0.5, 0.9, 0.95, 0.99}, 3 시드.

**검증 결과.** µ_eff 범위(Table I, §V-D)는 µ_f = 0.35일 때 값과 맞습니다. 각주 2의 µ_f = 1.0과 맞지 않습니다(`03` §6a). MuJoCo 문서의 최댓값 규칙이 적용되면 체제 자체가 달라집니다(`03` §6b, `04` D2).

주장과 검증.
- "Robust success가 CEM보다 높다": nominal 79 대 63, bimodal 38 대 33. wide는 같은 67. **Gauss보다 높은 곳은 nominal과 wide뿐이고 bimodal에서는 Gauss 42가 더 높습니다.** SR 차이는 통계적으로 구분되지 않습니다(`03` §2).
- "보정 오차가 0.14 이하": 0.14는 최댓값이고 평균은 0.113입니다. VNB와 Gauss는 세 체제 모두 과소 예측입니다(`03` §3).
- "계획 시간 약 10배": 표는 4.6–6.1배, 부록 Table V는 11–18배입니다(`03` §4).

### 4.4 실물 실험 (§V-C–D, §VI-B, Table IV, Fig. 6–9)

- 하드웨어: FAIR FR3(6 DoF), RealHand L6(11 DoF, 압저항 촉각 5개 접촉), RealSense D435i와 Orbbec Astra Pro Plus. 자세는 ICP로 추정하고 두 카메라를 covariance intersection으로 합칩니다(식 (23), ω_CI = 0.5).
- 시험: 물체 3개(박스, 머스타드 병, 수프 캔)와 오프셋 4개(식 (25)), 방법 2개 = 24회(방법당 12회).
- 결과: 두 방법 모두 12/12 성공. VNB 중앙값 단계 6(IQR 6–7), 시간 11.5 s, ε̂ 1.6×10⁻³. Gauss 단계 7(IQR 6–11), 시간 14.2 s, ε̂ 0.9×10⁻³.

검증. 12/12 두 개는 차이를 말할 수 없습니다(Fisher p = 1). 정확 하한은 0.735입니다(`03` §5). 논문도 "execution and convergence check"라고 적었습니다. ε̂는 대리 지표입니다(부록 D).

**보정 대상 "5 cm 리프트 후 1 cm 이내"(§V-D)와 코드의 성공 기준(ε ≥ 0.001, `04` D11)이 다릅니다.**

### 4.5 기타 주장 (§VI-C, §VII)

- "Gauss와 Gauss-CVaR가 같은 결과를 낸다": 같은 코드 경로이기 때문입니다(`04` D3). 행동 변화가 없었다는 실험 결과가 아닙니다.
- 결론의 "5–7배 빠름, CEM보다 높은 robust"는 §4.3의 검증과 맞지 않는 부분이 있습니다.

## 5. 한계와 논문이 말하지 않는 것

**논문이 인정한 것.**
- 실물 실험은 24회이고, 두 방법 모두 100%라서 차이를 말할 수 없습니다.
- 물체 프리미티브 2개(시뮬레이션), 실물 3개.
- Table III의 "Quality"는 모든 행이 0.90 근처라 구분력이 없습니다(표 자체에서 확인).

**논문이 말하지 않은 것 (그리고 확인된 것).**
1. 시도 횟수: 조건별 에피소드 수가 Table III에 없습니다. 코드 설정으로는 24입니다(`03` §1).
2. 시드 수와 분산: 시드 3개의 SR 분산은 보고하지 않습니다. 신뢰구간이 없습니다.
3. 절제 실험: Vnb와 Gauss의 차이를 K, λ_c, 엔트로피 항, 다중 출발점으로 나눈 실험이 없습니다(`04` D3).
4. 학습 데이터: 신경 믿음 네트워크가 무엇으로 학습되었는지 없습니다.
5. 비교 대상의 튜닝: Pf는 입자 100개와 샘플 기반 CVaR, CEM은 휴리스틱 점수입니다. 두 기준선의 튜닝 노력이 같은지 알 수 없습니다.
6. 계획 시간 측정 조건: CPU/GPU, 실행 횟수, 벽시계 시간 정의가 없습니다.
7. 교란 생존 기준과 SR 기준: 논문 값과 코드 값이 다릅니다(`04` D6, D11).

## 6. 선택과 대안

- **논문이 고른 것:** GMM 믿음 + 재매개변수화 + softplus CVaR + 성분별 행동 최적화 + 엔트로피 항.
- **더 단순한 대안:** 같은 목적을 입자 필터로 두고 CVaR 그래디언트를 점수함수 기울기로 추정하는 것(논문의 Pf 경로). 논문은 분산과 재샘플링 문제를 근거로 듭니다.
- **대안이 더 나을 수 있는 곳:** 믿음이 실제로 단봉이거나 샘플 수가 충분할 때, 가우시안 + 위험 목적이 같은 효과를 낼 수 있습니다. 토이(`03` §7)가 보여 주듯, 다중모드가 선택을 바꾸는 영역은 낮은 봉우리 질량 w ∈ [0.2, 0.9]에 한정됩니다.

## 9. 판정

- 주장의 방향(GMM 믿음과 CVaR 그래디언트)은 수학적으로 일관됩니다.
- 주장의 크기(계획 시간, 보정 우위, robust 우위)는 표 안에서도 서로 맞지 않습니다.
- 재현의 가치는 **µ 혼합 규칙과 λ_c 연결**을 먼저 확인하는 데 있습니다. 이것이 맞지 않으면 나머지 비교가 무의미해집니다.
