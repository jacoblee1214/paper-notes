## 1. 한 문단 요약

저비용 양팔 로봇(I2RT YAM 두 대, 약 8,000달러) 위에서 행동 복제(BC) 전체 스택을 공개한 논문입니다. 구성은 네 부분입니다. (1) **ABC-130K**: 134,806 에피소드, 195 과제, 3,553 시간의 실제 원격조종 데이터. (2) **ABC-Models**: 2B ABC-DiT(DINOv3 ViT-B 비전 인코더 + 1.93B DiT 헤드, 풀링 교차 어텐션)와 4.3B ABC-VLA(Gemma 3 4B + 45M adaLN 확산 헤드), 그리고 아키텍처·배치·스텝 절제. (3) **ABC-Sim**: MuJoCo로 다시 만든 시뮬레이터와 400시간 시뮬 데이터, 시뮬과 실제의 상관(r = 0.85, 0.91). (4) **ABC-Eval**: 100시간 이상의 실제 평가 롤아웃과 채점 기준. 하드웨어(GELLO 조종기), 학습·배포 코드, 데이터로더, 수동 리더암 DAgger 인프라도 함께 냅니다. 핵심 주장은 "열린 데이터·코드·평가로 산업 연구실 수준의 BC 실험을 재현 가능하게 한다"이고, 실험적 주장은 (a) DINOv3 + 풀링 교차 어텐션 DiT와 풀링 adaLN VLA가 가장 낫다, (b) VLA는 큰 배치에서 이득이 커지지만 DiT가 FLOP 효율이 좋다, (c) 학습 손실과 검증 행동 오차는 실제 성능을 예측하고 검증 손실은 못 한다, (d) 시뮬 성능은 실제 성능을 예측한다, (e) 사전학습이 단일 과제 미세조정에 도움이 된다, (f) DAgger가 상자 접기에 결정적이다입니다.

## 3. 모델과 학습 (§3, 부록 B)

### 3.1 ABC-DiT (§3.1, B.2, B.4)

- 입력: 카메라별 이미지 토큰을 비전 인코더로 얻고, 카메라마다 학습 질의 12개로 풀링(교차 어텐션)해 키·값으로 씁니다. 상태, 과제 문장(CLIP 텍스트), 확산 시간은 하나의 조건 벡터가 되어 adaLN으로 DiT를 조절합니다.
- 비교 3종: CLIP-AdaLN(카메라당 CLS 토큰 하나를 조건 벡터에 합침, LBM 기반), CLIP-교차 어텐션, DINOv3-교차 어텐션. 최종 ABC-DiT는 **DINOv3 ViT-B(85.7M)** + 32층, 은닉 1536, 헤드 24, MLP 비율 4의 DiT 헤드(1.93B), 합계 약 2B(`03` V6).
- 목적함수: 조건부 확률 흐름의 속도 예측(flow matching). 추론은 10 스텝(Euler).
- 학습(B.3): 200k 스텝, 전역 배치 9,216(96 GPU × 96, H200 12노드), AdamW, 학습률 1e-4(1k 스텝 선형 워밍업 뒤 일정), 가중치 감쇠 0.01, 비전 인코더 학습률 배율 0.1, 기울기 노름 한계 10, 고유감각 입력 드롭아웃 0.1.
- 크기 선택: 헤드를 키우는 쪽이 비전 인코더를 키우는 것보다 싸다는 논리로 헤드 1.93B를 택합니다(B.4, 그림 21: 모델 S/B/L/xL 153M–1.93B에서 큰 모델일수록 같은 스텝과 같은 FLOPs에서 학습 손실이 낮음).

### 3.2 ABC-VLA (§3.2, B.2)

- Gemma 3 4B(SigLIP 포함, 4.3B) 백본을 **행동 손실로 끝까지 미세조정**합니다("백본을 얼리면 성능이 나쁘다", §3.2). 행동 헤드는 작은 DiT(8층, 은닉 512, 헤드 8, 약 45M)입니다.
- 연결부 3종: 교차 어텐션(VLM 마지막 층 특징을 키·값으로), 교차 어텐션 + FAST(VLM에 FAST 토큰 다음 토큰 손실, DiT는 detach된 특징을 봄, π0.5 계열 "knowledge insulation"), **풀링 adaLN**(마지막 층 토큰을 학습 질의 8개로 어텐션 풀링(QK-Norm), 8 × 512 = 4,096차원 벡터 + 고유감각 임베딩 512 + 시간 임베딩 512 = 5,120차원을 MLP로 512로 줄여 adaLN 조절). 최종은 풀링 adaLN입니다.
- **다중 확산 샘플(variance reduction)**: 헤드(42M)가 VLM(4B)보다 훨씬 작으므로 VLM 순전파 한 번을 k개의 독립 (잡음, 시간) 샘플에 공유합니다. 순전파에서 특징과 정답 행동을 k번 복제하고, 역전파에서 조건 인터페이스에서 평균됩니다. k=1일 때 1.346 s/스텝, k=8일 때 1.366 s/스텝(+1.5%, H200)이고 그림 6은 같은 GPU 시간에서 학습 손실이 낮다고 보입니다. 토이로 분산 감소를 직접 확인했습니다(`03` §4 T1).
- 학습(B.3): 200k 스텝, 전역 배치 9,216(64 GPU × 24 × 누적 6), bf16 혼합 정밀도, 기울기 노름 10과 **기울기 값 상한 100**.

### 3.3 공통 평가 설정과 추론 (§3, 부록 D)

- 평가 과제 3개: 병을 쓰레기통에 던져 넣기(최대 6점), 접시를 식기 건조대에 놓기(6점), 컵을 바로 세우기(점수 규칙은 표 3에 없음, `03` V15). 과제당 50회, 30 Hz, 비동기 실행과 행동 prefix(RTC 방식 [15]).
- 채점: strict는 과제 완료 비율, progress는 점수를 최대 점수로 나눈 평균(부록 G, 표 3). 과제별 시간 제한 120–390 s.
- 추론 최적화(부록 D, RTX 5090): bf16, 시각 임베딩 캐시, `torch.compile`(fullgraph), CUDA graph. ABC-DiT 63.0 → 36.3 ms, ABC-VLA 47.8 → 17.5 ms(10 확산 스텝). VLA가 더 빠른 이유는 큰 VLM을 한 번만 돌리고 작은 헤드를 10번 돌리기 때문입니다.

### 4.2 배치·계산량 스케일링 (§3.3, 그림 5, 6)

- DiT와 VLA를 배치 1,536 / 4,608 / 9,216에서 100k와 200k 스텝으로 학습해 실제 성공률과 학습 FLOPs의 관계를 그립니다. 작은 배치에서는 DiT가 낫고, 9,216에서 VLA가 크게 오르며 DiT는 덜 오릅니다. DiT가 FLOP 효율이 더 좋다고 결론 짓습니다. 값은 그림에만 있고 표가 없습니다.
- 샘플당 학습 TFLOPs는 DiT 0.678, VLA 7.020입니다(표 2). 즉 같은 배치·스텝에서 VLA가 약 10.4배 많이 씁니다(`03` V6, V7).

### 4.3 오프라인 지표와 실제 성능 (§3.4, 그림 7, 8)

- 체크포인트 16개에서 학습 손실(r = -0.84), 검증 행동 오차(r = -0.89, ρ = -0.93)는 실제 성공률과 유의하게 상관하고, 검증 손실(r = -0.04)은 아닙니다. VLA에서는 검증 손실이 먼저 줄다가 다시 오르는데 실제 성능은 계속 오릅니다(그림 7).
- 검증 행동 오차는 확산 스텝 수를 고정할 때만 의미가 있습니다(스텝을 줄이면 오차가 쉽게 줄지만 성능은 오르지 않음).

### 4.4 시뮬-실제 상관 (§4, 그림 9–10, 12)

- MuJoCo로 로봇을 다시 만들고(240 Hz 물리, 렌더링은 저해상도), Blender 재렌더 파이프라인과 VR(Quest, Vision Pro) 원격조종 스택, 400시간 이상의 시뮬 데이터를 냅니다. 시뮬 과제 10개를 나열합니다.
- 체크포인트 12개(DiT 4 + VLA 4, ABC-130K 학습 + 사내 7K 시간과 시뮬 혼합 DiT 4)를 3과제 × 50회로 시뮬과 실제에서 평가해 strict r = 0.85(p = 4.2e-4), progress r = 0.91(p = 5.0e-5)을 보고합니다.

### 4.5 실제 능력, 사전학습, DAgger (§5, 그림 11–15)

- 5.1: 사전학습 ABC-DiT·VLA의 실제 progress(그림 11, 값은 그림에만 있음)와 사전학습 중 시뮬 progress(그림 12).
- 5.2: 네 가지 정밀 과제(신용카드 꺼내기, LEGO 분류, 펜 뚜껑 끼우기, 병뚜껑 풀기)에서 처음부터 / ABC-130K(3.5K h) 사전학습 / 사내 7K h 사전학습을 비교합니다(그림 13). 데이터가 많은 사전학습이 낫다는 결론이고, 값은 그림에만 있습니다.
- 5.3: 상자 접기. 10시간의 "collapsed" 데이터(엄격한 SOP로 수집)로 75k 스텝(배치 720) 미세조정하면 24%에 그치고, DAgger 라운드(라운드당 1–1.5 h, 개입 비율 30% → 15%)를 거듭하며 80:10:10(이전 라운드 : 현재 개입 : 현재 나머지)으로 섞어 75k 스텝씩 이어 학습합니다(그림 14, 값은 그림에만 있음). 개입 데이터만으로는 케이지 유무의 허위 상관을 배우므로 전체 에피소드를 같이 씁니다.
