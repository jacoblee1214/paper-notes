## 2. D2 자세히: 손실 가중

- 논문 식 (4)는 두 손실(행동 CE, 세계 모델 CE)을 따로 평균하고 α를 곱하는 것으로 읽힙니다.
- 코드는 **토큰마다 가중치**를 줍니다. 이미지 토큰 대상(인덱스 3~8194)은 0.04, 나머지는 1입니다. 그다음 `CrossEntropyLoss(weight=...)`의 평균 방식(가중치 합으로 나눔)을 씁니다.
- 결과적으로 한 배치에서 행동 토큰 1개의 상대 가중치는 1, 이미지 토큰 1개는 0.04입니다. 식 (4)를 토큰 평균으로 읽으면 이미지 토큰 1개의 상대 가중치는 α·(행동 토큰 수)/(이미지 토큰 수)입니다.
- 행동 샘플은 7×K 토큰(K=5면 35개), 세계 모델 샘플은 이미지 토큰 256개(256×256)입니다. 샘플 비율을 1:1로 두면 식 (4) 해석의 이미지 토큰 상대 가중은 약 0.04×35/256 ≈ 0.0055이고 코드는 0.04로, **약 7배 차이**가 납니다. 배치 구성은 논문에 없으므로 이 값은 추정입니다.
- 따라서 "α=0.04"라는 논문 수치를 그대로 옮기면 손실 균형이 다르게 재현될 수 있습니다. 재현 시에는 코드의 방식을 쓰고 논문과 다르다고 명시해야 합니다.

## 3. D5 자세히: 마스크

- 코드는 행동 블록 시작 토큰 `10004`와 끝 토큰 `15004`(`item_processor.py`의 `<reserved10000>`, `<reserved15000>` 토큰 id로 보이며, 정확한 id 매핑은 토크나이저로 확인하지 않음)로 블록을 찾습니다.
- 마지막 이미지 이후에 있는 행동 블록은, 자기보다 앞선 행동 블록 전체에 대한 attention을 0으로 만듭니다. 세계 모델 샘플은 행동 블록이 이미지 뒤에 오지 않으므로 마스크가 적용되지 않습니다(의도와 일치).
- 청크 안의 7×K 토큰은 여전히 서로 causal하게 봅니다. 논문은 "parallel decoding"이라고 쓰지만, 코드 기준으로는 청크 내부 토큰이 순서대로 생성되는 자기회귀 구조가 남습니다.
- 평가 쪽에서는 학습과 같은 마스크 함수를 호출하는지 확인하지 못했습니다(`eval_solver_libero_256.py`에 대한 정적 확인은 생략).
