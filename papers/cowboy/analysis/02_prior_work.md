# 02. 선행연구와 코드 현황: COWBOY (arXiv:2610.28948 v1)

## 1. 계보와 구성 요소의 출처

COWBOY는 새 알고리즘 하나라기보다 **이미 있던 부품을 한 파이프라인에 엮은 시스템**입니다. 구성 요소별 출처는 다음과 같습니다(참고문헌 번호는 논문 기준).

| 구성 요소 | 출처 | COWBOY에서 달라진 점 |
|---|---|---|
| 기하 패브릭 (식 1, 부록 B) | Van Wyk 외 2022 [46], Xie 외 2020 [47], 패브릭을 RL의 안전한 안내 매체로 쓴 [48] | 고정 베이스 팔용을 **전방향 베이스 + 팔 + 능동 카메라 팔**로 확장. BA(m_min = 0)와 EEA(m_far = 0)의 게이트 금속, GCA(시선 어트랙터), Warp 기반 충돌 구 거리 |
| 패브릭 WBC를 RL의 행동 추상으로 사용 | DextrAH-G [1], DextrAH-RGB [2]: 패브릭 기반 팔-손 파지와 교사-학생 증류 | 단일 장면 고정 팔에서 **수천 장면의 이동 매니퓰레이터**로. 장면 인식을 학생이 점군으로 흡수 |
| 국소 정책 형식 | ManipGen [33] (Dalal 외 2025): 말단 좌표계 국소 정책 + 추론 시 모션 플래너 + VLM | 추론 시 플래너를 없애고 WBC 접근 + 국소 전문가를 **한 학생으로 증류**. 대신 전문가 3종이 수백 물체를 공유(ManipGen은 물체별 전문가 수천 개, §5) |
| 교사-학생 온라인 증류 | DAgger [53] | 교사를 "WBC + 국소 RL 전문가" 조합으로 구성. 전문가별 다중 교사를 랭크로 분산 |
| 학생 구조 | Deep Reactive Policy [52] (같은 연구실, CoRL 2025)에서 영감: 점군 → PointNet 토큰 → 트랜스포머 | 상태 토큰 5개, 보조 물체 위치 머리 추가 |
| 시뮬레이터와 PPO | Isaac Gym [49], rl_games [50], PPO [51] | 표 8의 PPO 설정을 rl_games 형식으로 적음 |
| 센서 시뮬 | 점군에서 z-버퍼·각도 격자로 가림 제거(부록 F) | 메시 래스터라이저 대신 **점 표본 + 가림 근사**로 속도 확보. 정확도는 일부러 희생(F) |
| 실환경 목표 지정 | SAM3 [54] | 초기 마스크 + 3 Hz 보정 + 정책 자기회귀 갱신 |
| 물체 자산 | Objaverse [55] | 전문가: 304개 + 길쭉한 195개(D.1) |
| 하드웨어 | TidyBot++ [23], LEAP Hand [24] | 이 연구실이 만든 손과 같은 계열 |

### 가까운 대안과 차이

- **모바일 조작 모방학습 계열**(Mobile ALOHA [3], HoMeR [7], HoMMI [6], BEHAVIOR Robot Suite [8]): 사람 시연이 장면별 베이스 위치와 가림 회피를 담아야 합니다. COWBOY는 시연을 모으지 않고 시뮬레이션 RL + 수동 설계 WBC로 이를 대신합니다(§2.1).
- **전신 RL 계열**(Deep Whole-Body Control [18], Visual WBC [19], N2M2 [20], Boosted Hybrid RL [21]): 보통 한 장면 가족 안에서 학습합니다. COWBOY는 "장면 적응"을 학습에서 빼 WBC에 맡기는 점이 다릅니다(§1).
- **QP·MPC 계열**(Pink, Mink, PlaCo, OpenSoT, ARC-OPT, OCS2): 배치 병렬이 어렵다는 이유로 쓰지 않습니다(§2.3, 부록 A). 다만 부록 표 5는 **런타임 비교가 아니며**(저자가 그렇게 적었습니다), OCS2의 "Native Batch API"가 "Yes"로 적혀 있어 본문의 "배치 평가가 비싸다"는 서술과 정확히 맞물리지 않습니다(`03` §2).
- **sim-to-real 손재주 계열**(Dactyl [25], DeXtreme [26], Visual Dexterity [27], DexFunc [35], SimToolReal [36], 쌍팔·휴머노이드 [37, 38]): 대부분 고정 환경입니다(§2.2).

### 핵심 아이디어의 새로움에 대한 평가

- 새로운 것: (a) 패브릭을 모바일 매니퓰레이터로 확장한 항들, (b) "접근은 WBC, 접촉은 RL, 합치는 것은 증류"라는 분해를 수천 장면 규모로 돌린 시스템 통합, (c) 점군 기반 센서 시뮬을 증류 병목 해소에 쓴 점.
- 새롭다고 하기 어려운 것: 국소 정책(ManipGen), 패브릭 + RL(DextrAH), 증류 구조(DAgger + 점군 트랜스포머). 따라서 기여의 무게는 **통합과 규모**에 있고, 이 때문에 규모를 바꿨을 때의 효과(`04` C10)가 없다는 점이 더 아쉽습니다.

## 4. 한 줄 정리

기여는 새 알고리즘이 아니라 **분해 설계와 대규모 통합**이고, 구성 요소 대부분(패브릭, 국소 정책, DAgger, 점군 트랜스포머)이 같은 연구실과 NVIDIA 그룹의 앞선 작업에서 옵니다. 공식 코드가 없고, 가장 가까운 공개 자료는 저자 개인 fork의 6월 스냅샷이어서 논문 최종 설정과 직접 대조하는 데는 한계가 있습니다.
