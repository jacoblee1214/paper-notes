핵심 요약

  1. 무엇을 하는가: 다지 손 visuotactile diffusion 정책이 행동 대신 미래의 **실제 로봇 상태와 촉각(VAE 잠재)**을 예측한다. 학습된 contact-consistency mapping M(x, u) → a가 이를 compliance 제어기 목표로 바꾼다.
  2. M의 물리적 실체는 준정적 강성 역행렬이다: 관절 PD에서 a = x − Kp⁻¹(Jᵀf + τ_g)이다. 3-DoF 손가락 toy에서 해석식은 정확히 성립하고(오차 0.008 mrad), 순수 MLP는 20 mrad였다. 잔차형과 상태·촉각 결합이 필요한 이유도 이 식으로 설명된다.
  3. "일관되게 앞선다"는 점추정 기준이다: 다섯 과제 모두 1위지만, 과제별로 유의한 것은 시뮬레이션 접시 닦기(p = 0.001)뿐이다. 실제 로봇은 15회라 구분되지 않는다(p = 0.33, 0.43).
  4. 촉각 잡음 강건성은 과장되어 있다: Fig. 13을 읽으면 잡음 50%에서 상태+촉각 매핑 오차(약 10.0)가 상태만 모델(10.64)과 거의 같다. 촉각 이득의 86%가 사라진 상태다.
  5. 청크 실행 중에는 촉각 피드백이 없다: M은 예측된 (x̂, û)에 적용되고, 8스텝 동안 관측 촉각은 목표에 반영되지 않는다. 손끝만 감지하면 근위 링크 접촉이 빠져 식별이 무너진다(toy에서 오차가 잔차 0 수준 근처까지).
  6. 구현 가능성: 공식 코드·데이터·시뮬레이터(Meta 내부 FEM + Unreal)가 없어 그대로는 재현할 수 없다. 구성 요소는 표준(Diffusion Policy + VAE + MLP)이라 재구현은 쉽고, 어려운 것은 (목표, 실제 상태, 촉각) 세 쌍 데이터와 촉각 시뮬레이션이다. 이 맥에서는 MuJoCo(CPU)로 매핑 실험을, PyTorch MPS로 작은 정책 학습을 해 볼 수 있다(둘 다 설치 필요).

1. Abstract (한 줄 요약과 주장)

한 줄 요약: 다지 로봇손의 visuotactile 모방학습에서 행동(목표 관절각)을 직접 예측하지 않습니다. 대신 미래의 실제 로봇 상태와 촉각을 함께 예측하고, 학습된 contact-consistency mapping M_φ(x, u) → a로 이를 compliance 제어기가 추종할 목표 상태로 바꿉니다.

기여는 두 가지입니다(Sec. I).

  1. Contact grounding 정식화: 촉각을 추가 관측이나 보조 예측 대상으로만 쓰지 않습니다. 고정된 센서·제어기 조합에서는 (실제 상태 x, 촉각 u, 목표 상태 a) 세 쌍이 접촉을 나타낸다고 보고, 예측한 (x̂, û)를 실행 가능한 목표로 바꿉니다.
  2. 잠재 공간 촉각 예측: KL 정규화 VAE로 촉각을 압축하고(촉각 배열 748×3 → 32차원, Digit360 4개 이미지 → 80차원), 그 잠재 공간에서 상태와 함께 diffusion으로 생성합니다.

2.2 Contact grounding의 핵심 관찰 (Sec. III-B, Fig. 2)

관절마다 PD 제어기를 두면, 제어기는 목표 a와 실제 x의 차이를 토크로 바꾸는 가상 스프링-댐퍼가 됩니다. 자유 공간에서는 x가 a를 잘 따라가지만, 접촉이 생기면 물체가 손가락을 막아 a와 x 사이에 간극이 생기고, 그 결과가 촉각 u에 나타납니다. 저자들은 이 결합 관계를 데이터로 학습합니다.

a_t = M_φ(x_t, u_t)                                                          (Eq. 1)

접촉 위치나 접촉 모드를 명시적으로 모델링하지 않습니다. 대신 센서·제어기·embodiment에 묶인 암묵적 사상을 학습합니다. 이 식의 물리적 의미(준정적 평형에서 a = x + Kp⁻¹(…))는 03 §1에서 유도했습니다.

2.3 정책 구성 (Sec. III-C–E)

  • 분해의 이유: 관측에서 목표로 바로 가지 않고, 먼저 "접촉이 어떻게 전개되어야 하는가"를 (상태, 촉각) 쌍의 궤적으로 생성합니다. 그다음 그것을 실현할 목표를 M_φ로 구합니다.
  • 잔차 사상: M_φ는 목표를 바로 회귀하지 않고 실제 상태로부터의 offset을 출력합니다. 학습이 안정되고 목표가 강건해진다고 설명합니다(Table III에서 오차 33–66% 감소).
  • 촉각 VAE: 촉각 배열은 taxel 축 방향 1D ResNet, Digit360 이미지는 센서별 가중치 공유 2D ResNet을 씁니다. KL 가중치는 1×10⁻⁵–1×10⁻⁴입니다(Table V).
  • 조건 주입: 시뮬레이션에서는 시각·촉각·상태 특징을 이어 붙여 FiLM으로 넣습니다. 실제 로봇에서는 센서별 촉각 특징을 cross-sensor self-attention으로 모은 뒤 FiLM으로 넣습니다.
  • M_φ의 두 설계: 촉각 배열에서는 예측 잠재를 원래 촉각으로 복원한 뒤 다시 인코딩하고, 상태와 합쳐 MLP에 넣습니다(정확도 우선). Digit360에서는 이미지 복원이 비싸서 예측 잠재를 그대로 상태와 합쳐 MLP에 넣습니다(속도 우선).
  • 인코더는 공유하지 않습니다. diffusion 조건용, M_φ용, VAE용 인코더는 같은 구조이지만 따로 학습합니다.

시뮬레이션은 마지막 5개 체크포인트에서 총 250회, 실제 로봇은 연속 15회 시행입니다. 괄호 안 성공 수는 우리가 역산했고, 모두 정수로 떨어집니다(04 C1).

우리 분석: Table II 성공률과 Wilson 95% 구간, CGP vs 최강 기준선 Fisher p.

해석 (재계산은 04_claim_verification.md와 analysis/table_check.py):

  • "일관되게 앞선다"는 점추정으로는 맞습니다. 다섯 과제 모두에서 CGP가 가장 높습니다.
  • 과제별로 통계적으로 구분되는 것은 접시 닦기뿐입니다. 최강 기준선(visuotactile DP)과의 Fisher 검정은 접시 닦기 p = 0.001, 박스 뒤집기 p = 0.08, 달걀 집기 p = 0.27입니다. 세 시뮬레이션 과제를 묶은 Mantel–Haenszel 검정은 p = 2.4×10⁻⁴입니다. 다만 250회는 한 학습 실행의 체크포인트 5개 × 50회라 서로 독립이 아니므로, 이 p값은 낙관적입니다. 학습 seed 반복은 보고되지 않았습니다.
  • 실제 로봇 결과는 15회라 구분되지 않습니다. 병뚜껑 열기 14/15 vs 11/15(p = 0.33), 박스 뒤집기 12/15 vs 9/15(p = 0.43)입니다. 묶어도 p = 0.13입니다. 15회 대 15회에서 p < 0.05가 되려면 14/15 대 8/15 정도, 즉 40%p에 가까운 차이가 필요합니다.
  • 촉각을 관측으로만 넣는 것의 효과가 작습니다. visuomotor → visuotactile DP는 달걀 집기에서만 크게 오르고(+16.8%p), 병뚜껑 열기에서는 오히려 떨어집니다(73.3% → 66.7%). 이 결과는 "촉각을 관측에만 넣는 것으로는 부족하다"는 논문의 동기와 맞습니다.

3.2 Contact-consistency mapping 단독 평가 (Table III, Fig. 6, Fig. 13)

시뮬레이션에서 11개 물체를 150개 에피소드(4,114프레임, 에피소드당 평균 27프레임) 동안 텔레옵으로 잡고, 에피소드 단위 1:1로 학습·검증을 나눴습니다. (x, u) → a 예측의 관절각 MAE입니다(×10⁻³ rad, 3 seed 평균 ± 표준편차).

입력 인코더 절대 잔차
상태 + 촉각 ResNet1D 8.80 ± 0.24 5.94 ± 0.20
MLP / Transformer 12.50 / 14.39 8.33 / 9.58
상태만 — 16.05 10.64
촉각만 ResNet1D 35.93 12.15
  • 상태와 촉각이 둘 다 필요합니다. 잔차 기준으로 상태+촉각은 상태만보다 44%, 촉각만보다 51% 낮습니다(3 seed Welch p < 10⁻³).
  • 잔차형이 일관되게 낫습니다. 상태가 들어간 경우 33%, 촉각만일 때 66% 줄어듭니다. 촉각만+잔차가 크게 좋아지는 이유는 단순합니다. 잔차형에서는 실제 상태 x를 네트워크 밖에서 더해 주므로, 촉각만 쓰는 모델도 사실상 x를 받습니다.
  • 최고 MAE 5.94×10⁻³ rad는 0.34°입니다. 그러나 비교 기준인 "a = x"(잔차 0) 오차와 접촉 중 평균 간극 |a − x|가 보고되지 않았습니다. 이 수치가 얼마나 좋은지 판단하기 어렵습니다(04 C3).
  • 촉각 잡음 강건성 (부록 E, Fig. 13): 저자들은 "넓은 잡음 범위에서 안정적"이라고 썼습니다. 그림에서 읽으면 상태+촉각·잔차 오차는 잡음 0%에서 약 6.0, 50%에서 약 10.0으로 67% 오릅니다. 50%에서의 10.0은 상태만 모델(10.64)과 거의 같아서, 촉각이 주던 이득의 약 86%가 사라진 상태입니다. 직선으로 늘리면 잡음 약 58%에서 상태만 모델과 같아집니다. 실제 배포에서 diffusion이 예측한 촉각의 오차가 데이터셋 표준편차의 몇 %인지는 보고되지 않았습니다.

3.3 촉각 압축 (Table IV, Fig. 7, 부록 C)

  • KL 정규화를 빼면 복원 MAE는 낮아지지만 잠재 KL은 2–6배 커지고, 정책 성공률은 떨어집니다. 그림에서 읽으면 박스 66% → 약 62%, 달걀 75% → 약 64%입니다. 이 ablation은 세 시뮬레이션 과제 중 두 과제에서만 보고되었습니다. 박스의 4%p 차이(250회 기준 p ≈ 0.40)는 잡음 수준이고, 달걀의 11%p(p ≈ 0.009)는 의미가 있습니다.
  • MAE와 Active MAE의 비로 활성 taxel 비율을 거꾸로 추정할 수 있습니다. MAE = f·(Active MAE) + (1 − f)·(비활성 오차)이고 비활성 오차는 0 이상이므로 f ≤ MAE / Active MAE입니다. 계산하면 박스 ≤ 10%, 달걀 ≤ 12%, 접시 ≤ 23%입니다. 748개 taxel 가운데 한 시점에 힘이 걸리는 것은 많아야 75–170개라는 뜻으로, 촉각 배열이 매우 희소합니다.
  • Digit360 압축률은 센서당 15,552값(72×72×3) → 20차원으로 약 780배입니다. PSNR에서 거꾸로 구한 RMSE는 MAE의 1.8–2.1배로, 가우시안 오차(1.25배)보다 꼬리가 무겁습니다. 복원 오차가 접촉 영역에 몰려 있다는 뜻으로 읽힙니다.

4. Limitations

4.1 저자가 밝힌 한계 (Sec. VI)

M_φ는 센서 종류와 제어기 설정에 묶여 있어 그대로 옮겨 쓸 수 없습니다. sim-to-real 전이를 다루지 않았습니다(시뮬레이션과 실제를 따로 평가). 과제마다 따로 학습하는 단일 과제 프로토콜입니다. 향후 과제로 센서·제어기 간 공동 학습, 제어기 이득과 로봇 물리 파라미터를 조건으로 넣는 방법, 과제 간 공동 학습을 들었습니다.

4.2 분석하면서 추가로 발견한 한계와 의문점

  1. 청크 실행 중에는 촉각 피드백이 정책에 들어가지 않습니다. M_φ는 관측 촉각이 아니라 예측된 (x̂, û)에 적용됩니다. 8스텝을 실행하는 동안 실제 촉각이 예측과 달라져도 목표는 바뀌지 않고, 반응은 compliance 제어기의 수동적 순응에 맡겨집니다. "5 Hz"가 행동 스텝 주기라면 재계획은 1.6초마다입니다. 추론 주기라면 행동 스텝은 25 ms입니다. 논문은 둘 중 어느 쪽인지 밝히지 않았습니다(04 C8).
  2. M_φ의 물리적 실체는 준정적 강성 역행렬입니다(03 §1). 관절 PD에서 평형은 a = x + Kp⁻¹(g(x) − Σ Jᵀf)입니다. 접촉력 f와 접촉점 Jacobian을 알면 사상은 해석적으로 정해집니다. 시뮬레이션은 taxel마다 3D 힘을 주므로, 해석식이나 "해석식 + 학습 잔차" 기준선이 가능했지만 비교하지 않았습니다. 저자들이 향후 과제로 든 "제어기 이득을 조건으로" 넣는 방향도, 해석식에서는 Δ ∝ Kp⁻¹이라 구조가 이미 정해져 있습니다.
  3. 실제 상태 x에 속도가 없습니다. x는 손목 자세와 관절각뿐입니다. PD의 감쇠 항(Kd·ẋ)과 이동 중 목표가 실제 상태를 앞서는 성분은 (x, u)로 설명되지 않아 오차 하한으로 남습니다(03 §3, toy M4).
  4. 손끝 센서(Digit360)에서는 식별이 불완전합니다. 손가락 마디나 손바닥 접촉은 감지되지 않고, 비전 기반 촉각은 보정된 힘이 아니라 변형 이미지입니다. 실제 로봇 실험은 손끝 중심 과제(병뚜껑, 박스 뒤집기)로 골랐지만, 손 전체 접촉이 필요한 과제에서 어떻게 되는지는 실험되지 않았습니다. M_φ를 단독으로 평가한 Table III도 시뮬레이션 촉각 배열에서만 했습니다.
  5. 통계 정보가 부족합니다. 학습 seed 반복이 없고, 실제 로봇은 15회입니다. 시뮬레이션 250회도 독립 시행이 아닙니다(§3.1).
  6. 재현 경로가 막혀 있습니다. 코드가 공개되지 않았고, 시뮬레이션은 Meta 내부의 FEM 솔버와 Unreal Engine 플러그인입니다. 공개 시뮬레이터로 같은 과제를 다시 만들어야 합니다(04 §4).
  7. 정책 출력 차원이 커집니다. 행동 대신 상태와 촉각 잠재를 예측하므로 diffusion 출력이 2–4배입니다. 손 전체 촉각을 더 촘촘히 하거나 예측 구간을 늘리면 이 비용이 커집니다. 잠재 차원을 32와 80으로 작게 잡은 이유이기도 합니다.

03. Contact-consistency mapping의 물리적 의미와 toy 검증

재계산 스크립트는 analysis/mapping_toy.py(결과 mapping_toy_results.json, CPU 약 2분)와 analysis/table_check.py입니다. toy는 논문 Fig. 2와 같은 3-DoF 평면 손가락을 관절 PD로 제어하는 설정입니다. 논문 수치를 재현하려는 것이 아니라 Eq. 1이 무엇을 학습하는지 확인하는 것이 목적입니다.

1. Eq. 1 M_φ(x, u) → a는 무엇을 학습하는가

1.1 관절 PD 손가락의 준정적 평형

손 관절은 PD 제어기 τ_m = Kp(a − q) − Kd q̇로 구동됩니다(Sec. III-A). 관성을 무시할 만큼 느린 움직임(준정적)이라면 관절 토크 평형은 다음과 같습니다.

Kp (a − q) − Kd q̇ + Σ_k J_k(q)ᵀ f_k + Σ_i J_{c,i}(q)ᵀ m_i g = 0
  • f_k: 접촉점 k에서 물체가 손가락에 가하는 힘, J_k: 그 점의 Jacobian
  • J_{c,i}, m_i g: 링크 i 질량중심의 Jacobian과 중력

이를 목표 a에 대해 풀면 다음 식이 됩니다.

a = q  −  Kp⁻¹ [ Σ_k J_k(q)ᵀ f_k + τ_g(q) ]  +  Kp⁻¹ Kd q̇
    ───   ─────────────────────────────────     ───────────
    실제    접촉·중력이 만드는 간극 (x, u의 함수)    속도 항 (x에 없음)

해석:

  • 논문의 "잔차 사상"(a = x + Δ)은 이 구조와 정확히 맞습니다. 잔차 Δ는 강성 역행렬 × 외력 토크입니다.
  • Δ를 정하려면 접촉점 위치와 힘(촉각 u)뿐 아니라 Jacobian, 즉 자세(상태 x)도 필요합니다. 그래서 "상태와 촉각이 둘 다 필요하다"(Table III)는 결과가 나옵니다.
  • 접촉이 없으면 Δ = −Kp⁻¹τ_g(q)뿐입니다. 부록 Fig. 12가 "접촉 전 작은 간극은 중력과 마찰에 의한 정상상태 오차"라고 한 것과 같습니다.
  • 팔 쪽 작업공간 임피던스 F = K_x(a_x − x) − D ẋ에서도 똑같이 a_x = x + K_x⁻¹F_ext입니다. Fig. 5에서 접시 닦기 때 엔드이펙터 목표-실제 간극이 커지는 것은 스펀지를 누르는 힘이 K_x⁻¹만큼 목표를 밀어 넣은 결과입니다.
  • 저자들이 향후 과제로 든 "제어기 이득을 조건으로" 넣는 방향(Sec. VI)도, 이 식에서는 Δ ∝ Kp⁻¹로 구조가 이미 정해져 있습니다.

1.2 무엇이 식별을 깨는가

위 식이 정확하려면 세 조건이 필요합니다. 실제 시스템에서는 셋 다 깨질 수 있습니다.

  1. 모든 접촉이 감지되어야 합니다. 손끝 Digit360만 있으면 손가락 마디나 손바닥 접촉의 f_k가 빠집니다.
  2. 촉각이 힘을 줘야 합니다. 시뮬레이션 촉각 배열은 taxel마다 3D 힘을 줍니다. 비전 기반 촉각은 변형 이미지라서 힘과의 관계도 학습해야 합니다.
  3. 속도 항이 작아야 합니다. x에는 관절 속도가 없으므로 Kp⁻¹Kd q̇는 (x, u)로 설명되지 않는 오차 하한이 됩니다. 텔레옵 데이터에서는 이동 중 목표가 실제 상태를 앞서는 성분도 여기에 섞입니다.

  1. Eq. 1의 해석식이 정확히 성립합니다(오차 0.008, 수치 최적화 허용오차 수준). 이 사상은 "데이터로만 배울 수 있는 암묵적 관계"가 아니라 기구학과 강성으로 정해지는 관계입니다. 학습이 필요한 이유는 실제 시스템에서 강성, 마찰, 센서 보정, 감지되지 않는 접촉을 정확히 모르기 때문입니다.

  3. 상태만 모델의 가치는 데이터 분포에 달려 있습니다. toy에서는 물체 위치와 크기가 무작위라 자세만으로 힘을 알 수 없고, 상태만 모델(67.6)이 잔차 0 기준선(70.9)과 거의 같습니다. 논문에서는 상태만 모델(10.64)이 촉각만(12.15)보다 낫습니다. 파지 데이터에서는 자세가 "얼마나 쥐고 있는가"를 상당 부분 알려 준다는 뜻으로 읽힙니다. 같은 이유로 논문에 잔차 0 기준선이 없으면 5.94가 얼마나 좋은 값인지 판단할 수 없습니다.
  4. 학습된 MLP는 해석식보다 2,000배 이상 부정확합니다(20.5 vs 0.008). 학습 표본 3,000개로는 Jᵀf라는 곱 구조를 배우기 어렵습니다. 기구학을 아는 경우 "해석식 + 학습 잔차" 구조가 데이터 효율 면에서 훨씬 유리할 것입니다.
  5. 손끝만 감지하면 식별이 크게 무너집니다. 표본의 59%에서 감지되지 않는 근위 링크 접촉이 있고, MLP 오차가 58.3으로 잔차 0 기준선(70.9)에 가까워집니다. 해석식도 51.1입니다. 실제 로봇 실험이 손끝 접촉 위주 과제(병뚜껑, 박스 뒤집기)였던 것은 이 한계와 맞물립니다.
  6. 속도 항은 하한을 만듭니다. 하한(Kp⁻¹Kd|q̇|의 평균 6.4)이 생기고, 오차가 20.5 → 23.7로 늘어납니다.

논문과 다른 것 (촉각 잡음, M5): toy의 상태+촉각·잔차 모델은 데이터셋 촉각 표준편차의 10%만 잡음을 넣어도 오차가 20 → 35로 오르고, 약 25%에서 상태만 모델보다 나빠집니다. 논문 Fig. 13은 50%에서도 +67%에 그칩니다. 차이의 이유로는 세 가지를 생각할 수 있습니다. toy의 taxel 신호는 대부분 0이어서, 잡음이 "없는 접촉"을 만들어 냅니다. toy는 잡음 없이 학습했습니다. 논문의 ResNet1D 인코더는 공간적으로 매끄러운 특징을 써서 독립 잡음을 평균화합니다. 어느 쪽이든 강건성은 잡음을 무엇에 상대적으로 정의하는가와 학습 방식에 크게 좌우되므로, 논문의 "넓은 범위에서 안정적"이라는 표현을 일반화하기는 어렵습니다.

4. 논문 Fig. 13 다시 읽기

논문 자체 수치로도, 잡음 50%에서 상태+촉각·잔차 MAE(약 10.0)는 Table III의 상태만 모델(10.64)과 거의 같습니다. 촉각이 주던 이득(10.64 − 5.94 = 4.70) 가운데 남는 것은 약 0.64(14%)입니다. "오차가 안정적"이라기보다 **"촉각이 무의미해질 때까지 점진적으로 나빠진다"**가 정확한 표현입니다. 배포 시 diffusion이 예측한 촉각의 오차 크기가 보고되지 않았으므로, 실제 정책에서 이 곡선의 어느 지점에 있는지는 알 수 없습니다.

5. 실행 시간과 피드백 구조 (04 C8)

CGP는 매 추론마다 16스텝의 (x̂, û)를 만들고 8스텝을 실행합니다. M_φ는 예측값에 적용되므로, 실행 중인 8스텝 동안 실제 촉각은 목표에 반영되지 않습니다. "5 Hz"를 어떻게 읽느냐에 따라 시간 규모가 달라집니다.

해석 행동 스텝 재계획 주기 예측 구간 A100 추론(최대 약 134 ms)
5 Hz = 행동 스텝 주기 0.2 s 1.6 s 3.2 s 재계획 주기의 8%
5 Hz = 추론 주기 25 ms 0.2 s 0.4 s 주기의 67%

어느 쪽이든 미끄러짐 같은 빠른 사건에는 제어기의 수동적 순응이 먼저 반응하고, 정책은 다음 재계획에서야 촉각을 봅니다. 청크 안에서 관측 촉각과 예측 촉각의 차이(u_obs − û)로 목표를 보정하면 이 간극을 줄일 수 있습니다.
