# 03. 수치 재계산, 통계 검정, 일관성 검사

## 0. 방법과 입력

- **입력:** 논문 v2의 표 2, 3, 7, 8, 9, 그림 6, 그림 8 값. 원시 시도 기록과 학습 실행별 결과는 공개되지 않았습니다. 그래서 표의 비율은 모두 **시도 수 n = 20**(표 2, 3, 7, 그림 6), **n = 10**(그림 8)으로 보고 정수 횟수로 바꿨습니다. 값이 정수 횟수에 맞는지 확인했습니다(모든 비율이 k/20 또는 k/10과 정확히 일치).
- **스크립트:** `analysis/recompute.py` → `analysis/recompute_results.json`. 수 초에 끝납니다.
- **구간:** Wilson 95% 구간(셀별), Clopper–Pearson 95%(20/20 한 셀), Newcombe 점수 차이 구간(두 비율 차이).
- **검정:** 양측 Fisher 정확 검정(셀별, 풀링), Cochran–Mantel–Haenszel(과제를 층으로 둔 검정), Holm 보정(과제 8개 묶음), 검정력(정규 근사, Cohen's h).
- **한계 (모든 검정에 공통):** 조건별로 **학습 실행이 하나**로 보입니다. 시도 사이의 독립성만 가정하고 학습 시드 변동은 반영하지 않습니다. 따라서 p 값은 "이 체크포인트에 대한 시도 수준 차이"의 근거이지, 방법의 효과에 대한 일반화 근거가 아닙니다.

정규 근사, 양측 0.05, 검정력 0.8, 조건당 n = 20에서 찾을 수 있는 최소 차이입니다.

### 1.7 그림 8: 수집 효율 (n = 10, 그림 판독)

**값은 그림의 막대 위 라벨에서 읽었습니다.** 텍스트 추출로 읽은 값은 혼동되어 쓰지 않았습니다.

| 과제 | 사람 | AVP | Manus | RealDexUMI | RDU 대 Manus Fisher p | RDU 대 AVP Fisher p |

- 본문의 "가장 높은 성공률과 가장 짧은 시간"은 뚜껑 비틀기에서 Manus와 성공률이 같습니다(10/10). 차 집기 성공률은 Manus보다 높지만 n = 10입니다. 즉 "가장 높다"는 맞고 "확실히 높다"는 n = 10으로는 차 집기 대 Manus에서만 약하게 말할 수 있습니다(p = 0.011).

## 3. 토이 검사: 상대 행동 식 (V-a, V-b, V-c)

`analysis/toy_relative_action.py` (numpy, 2000회 무작위 SE(3), 1–2초). 정책 학습이나 실로봇 결과를 검증하지 않습니다. 식의 대수가 논문 본문과 맞는지 확인합니다.

- **V-a (기저 불변성):** 로봇 기저 좌표계가 고정 변환 B만큼 바뀌어도 ΔT = T_t^{-1}T_{t+k}는 바뀌지 않습니다. 최대 오차 4e-16. 식 (2)의 상대 행동은 기저 자세에 독립입니다. 다만 이것은 **라벨**의 성질이고, 정책이 기저 변화에 강한지는 Fig. 6 실험에서만 봅니다.
- **V-b (정의 순서):** 역순 정의 ΔT' = T_{t+k}T_t^{-1}를 4.2절 식 T̂_t ΔT̂에 넣으면 목표 위치 오차 중앙값 278 mm, 회전 오차 중앙값 32.8도가 납니다(무작위 자세에서 잰 값이라 크기 자체보다 0이 아니라는 점이 중요합니다). 따라서 식 (2)의 순서는 4.2절과 맞고, 순서를 바꾸면 배포가 깨집니다.
- **V-c (보정 오차 전파):** 손 기준 고정 보정 오차 E(이동 2 mm, 회전 1도)가 있으면 목표 자세 오차는 이동 2.0 mm, 회전 약 0.98도입니다. 이 오차는 상대 행동이 보정하지 않으므로 **추적기-손 변환과 로봇 FK-손 변환의 보정 오차가 배포 목표에 그대로 옮겨 갑니다.** 논문은 이 보정 절차를 자세히 쓰지 않습니다(부록 A.3은 장갑의 오프셋 보정만 설명).

## 4. 요약

1. 풀링된 수치는 모두 재현됩니다(V1). 과제 층화 검정에서도 차이는 확실합니다(CMH p ≤ 1.5e-5).
2. 과제별 차이는 n = 20으로 검출하기 어렵고, 보정 후 대부분 유의하지 않습니다. 과제별 해석은 약합니다.
3. 학습 실행이 하나씩이라 시드 변동이 빠져 있습니다. 가장 큰 한계입니다.
4. 교차 로봇의 FR3 값과 초기 자세의 큐브 값은 표 2 시도와 같을 가능성이 있습니다(V7). 논문 확인이 필요합니다.
5. DP 비교는 설정 차이가 섞여 있어 백본 우열로 읽을 수 없습니다(V10).
6. 수집 효율 실험은 n = 10이고 시간의 분산이 없어서 성공률 차이만 약하게 말할 수 있습니다(§1.7).
