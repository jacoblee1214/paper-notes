## 2. 가까운 대안과 차이

| 방법 | 안내 위치 | 제약 처리 | 논문 비교 여부 |
|---|---|---|---|
| 기울기 안내(x_t 밀기) | 입력 x_t에 비용 기울기 | 소프트 | 비교함 (표 1–2, [9]식) |
| σ-안내 | 섭동 슬롯에 기울기 g를 넣음(식 38) | 소프트 | 비교함 (표 2–3, 저자가 "가장 자연스러운 단일 기울기 대응"이라 부름) |
| 투영 안내 | 각 단계 투영 | 하드, 각 단계 | 비교함 (표 1, 5) |
| 사후 스냅(cuRobo) | 출력 후 가장 가까운 IK 해 | 하드, 사후 | 비교함 (표 1의 "DDIM [27]") |
| **이 논문(최적화 안내)** | 섭동 δ_k와 x_K를 최적화 | 하드(IPOPT)나 소프트(Theseus, L-BFGS) | - |
| 입자 재가중(Steer2Grasp, arXiv:2609.33546, 2026-09-27) | 입자 가중과 재표집(Feynman–Kac), 미분 불필요 | 보상 | 논문(2026-06)보다 늦은 동시기 연구. 비교 없음 |
| 확산 잡음 최적화(DNO, arXiv:2312.11994) | 초기 잡음과 잡음열 최적화 | 비용 | 논문의 참고문헌에 없음. 방법이 "잡음 변수 최적화"라는 점에서 구조가 가깝다 |
| PhysibleMDM(arXiv:2610.30500, 2026-10-21) | 모션 확산의 잡음 최적화 + 역동역학 | 물리 대리 제약 | 논문(2026-06)보다 늦음. 비교 없음 |

위 표에서 DNO, Steer2Grasp, PhysibleMDM은 초록과 서지만 확인했고 본문을 읽지 않았습니다. 논문(2026-06-23 제출)이 이들보다 앞서거나 같은 시기라서 비교가 없는 것은 자연스럽고, DNO처럼 앞선 연구와의 관계는 저자가 밝히지 않았습니다.

핵심 구분은 두 가지입니다. (1) δ_k를 샘플러 안의 **자유 변수**로 두고 초기 잡음까지 함께 최적화한다는 점, (2) 비용이 아니라 **종단 허용오차 제약**을 둘 수 있다는 점입니다. 기울기 안내는 각 단계에서 한 번의 지역 기울기만 쓰고, 이 방법은 샘플러 전체를 한 번에 푸는 직접 슈팅(IPOPT, L-BFGS)이나 완화된 최소제곱(Theseus)입니다. 대가는 시간입니다(Dynaarm 파지에서 DDIM 대비 46–69배, 시각운동에서 0.28–0.32 s 대 0.02–0.07 s).
