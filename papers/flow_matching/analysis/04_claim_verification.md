# 04. 주장 검증 (C1–C17)

공식 코드가 없으므로 코드 대조 대신 **논문의 주장을 하나씩 검증**합니다. 판정은 네 가지입니다. **확인**(증명 또는 수치로 맞음), **부분 확인**(표 값으로는 맞으나 강도나 조건이 과장됨), **확인 불가**(그림이나 설명만 있고 수치가 없음), **반박**(표나 식과 맞지 않음).

## 1. 주장 표

| ID | 논문 주장 (위치) | 검증 방법 | 판정 | 근거 |
|---|---|---|---|---|

| C3 | 가우시안 경로의 벡터장 식 (15) | ψ_t 역변환과 시간 미분으로 손 유도 | **확인** | 식 (25) 과정, `03` §5 |
| C4 | OT 벡터장 식 (21)과 흐름 (22) | 식 (21)을 ψ_t의 시간 미분과 수치 비교 | **확인** | `03` V1 (오차 6e-10) |
| C5 | VP 역방향 벡터장 식 (19)가 식 (15)와 같음 (부록 D) | 식 (15)에 μ, σ를 대입하여 수치 비교 | **확인** | `03` V2 (오차 3e-9) |
| C6 | OT 경로는 점마다 직선이고 속도가 일정함 (§4.1) | 식 (22)에서 x0 고정 시 ψ_t가 t에 대해 선형임을 확인 | **확인** | 식 (22) (자명) |

| C10 | FM-OT의 NFE 이득이 샘플 품질을 유지하며 얻어짐 (§6.2, 그림 7 오른쪽) | 그림으로만 표시됨 | **확인 불가** | 그림 7 |
| C11 | IN-128에서 FID가 BigGAN 등보다 낮음, IC-GAN 제외 SOTA (§6.1) | 표 1 오른쪽 값과 비교 | **부분 확인** | FID 20.9 < 21.7 < 25.3. 비교 목록은 논문이 고른 방법이고 IC-GAN은 빠짐. 최신 확산 모델과의 비교는 없음 |

| C13 | FM이 학습 중 더 빨리 수렴함 (§6.1, 그림 5) | FID 곡선만 있음. 수치 없음 | **확인 불가** | 그림 5 |

## 2. 판정 요약

- **수식과 증명(C1–C6)은 모두 확인됐습니다.** 구현 근거로 쓸 수 있습니다.
- **표 값의 주장(C7, C11, C12, C16, C17)은 부분 확인입니다.** 방향은 맞지만 강도가 과장되었고, 시드와 분산이 없어 검정할 수 없습니다.
- **그림에만 있는 주장(C8, C10, C13, C14)은 확인할 수 없습니다.** 수치가 공개되지 않았습니다.
- **C9(σ_min)는 재현을 막는 빠진 설정입니다.**
- **C15 초해상도 PSNR 주장은 표와 맞지 않습니다.**

## 3. 재현에 필요한 빠진 정보

| 항목 | 논문 상태 | 대응 |
|---|---|---|
| σ_min | 값 없음 (C9) | 0.01 등을 가정하고 민감도 확인 |
| 2차원 실험 학습 설정 | MLP 5층 × 512 (부록 E). 옵티마이저, 반복 수, 배치 없음 | 가정하고 기록 |
| 샘플링 NFE 측정 방법 | dopri5 허용오차 1e-5 (본문) | 명시되어 있음 |
| CIFAR 반복 수 | 표 3과 에폭이 맞지 않음 (K2) | 에폭 1000 또는 반복 391k 중 하나를 골라 명시 |
| 표 1 NLL의 K | 본문에 없음 (표 4에서 추정) | 최대 K로 가정 |
| 학습 반복 시 EMA 여부 | 언급 없음 | 확인 불가 |

## 4. 구현 가능성 판정 (이 맥 기준)

**판정: 목표와 샘플러는 구현할 수 있습니다. 논문 표 1 규모의 재현은 불가능합니다.**

| 작업 | 가능 여부 | 자원 | 노력 (추정) |
|---|---|---|---|
| CFM 목표(식 9, 23)와 OT 경로 구현, 샘플링 ODE | 가능 | CPU (PyTorch), 수십 줄에서 백여 줄 | 반나절 (추정) |
| 2차원 체커보드 재현 (MLP 5×512) | 가능 | CPU 또는 MPS. 분 단위 | 0.5–1일 (추정). 현재는 수식 검사만 함 |
| CIFAR-10 소형 U-Net 학습 | 조건부 | MPS에서 수일에서 수주. 1000 에폭은 불가 | 1–2주 (추정) |
| IN-32, IN-64, IN-128 | 불가 | 16–32 GPU, 157k–500k 반복 (표 3) | — |
| 우도(NLL) 평가 (dopri5 + Hutchinson) | 가능 (소형 모델에서) | CPU/MPS. 차원이 작을 때만 | — |

- **이 맥의 한계**: M4 Pro 24 GiB, MPS, CUDA 없음(`mac-apple-gpu` 메모). CIFAR 규모의 학습은 가능성이 있지만 논문 설정과 같은 조건은 아닙니다.
- **재현 우선순위**: (1) 2차원 OT 대 VP 비교로 C6과 정리 2를 학습 수준에서 확인, (2) CIFAR 소형 모델에서 FM-OT 대 FM-Dif 비교 (NFE와 FID), (3) 그 이상은 보류.
- 공식 코드는 없으므로 torchcfm(MIT)을 참고 구현으로 쓸 수 있습니다. 설치나 실행은 사용자 확인 후에 합니다.
