## 1. 문제와 주장

시각만으로는 접촉 상태(정렬, 접촉 위치, 압력 분포)를 알기 어렵습니다. 저자들은 큰 촉각 데이터로 사전학습하거나 촉각-언어-행동 모델을 처음부터 학습하는 대신, **이미 있는 VLA(π0.5)에 촉각 입력을 붙이고** 시뮬레이션에서 후학습하자고 제안합니다(§1). 핵심 주장은 두 가지입니다.

1. 촉각을 입력으로만 넣는 것이 아니라 "접촉 신호가 행동을 어떻게 조절해야 하는가"를, 시연에 드문 준실패 상태에서 시뮬 RL로 배운다(초록).
2. 시뮬 후학습 때 실데이터 BC 손실(앵커)을 같이 두면 시뮬 특화 과적합을 막는다(§3.4, §4.5).

초록의 수치: 네 개 양손 접촉 과제에서 최종 시각-촉각 정책 평균 성공률 72.5%, 기준선 50.0%.

## 2. 방법

### 2.1 정렬된 시뮬레이터 (§3.1, 부록 B)

시뮬은 닫힌 루프 접촉 환경으로 쓰이고, 세 가지를 실제에 맞춥니다.

- **컨트롤러 응답(부록 B.1):** 관절별 10초 주파수 스윕을 실로봇에서 기록하고 같은 목표를 시뮬에서 재생합니다. MIT식 임피던스 컨트롤러의 (Kp, Kd, Tref)를 SPSA로 최적화합니다. 손실은 식 9로 추종 오차 차이의 합과 0.1배의 유한 차분 차이입니다. 결과는 그림 9의 표(예: J0 Kp = 1813.0, Kd = 159.4, J4 Tref = 1.73 N·m)입니다.
- **촉각(부록 B.2):** 식 10의 스프링-댐퍼 모델 f = kn·δ + kd·δ̇(양수 부분)로 법선 방향만 맞추고 전단은 재구성하지 않습니다. 무접촉 실측으로 잡음 임계값을 정하고 (kn, kd)를 맞춥니다.
- **카메라(부록 B.3):** 외부 파라미터를 오프라인으로 맞춥니다(정성 비교, 그림 11).

### 2.2 촉각 증강 정책 (§3.2, 식 1–5)

- 정책은 π0.5 계열입니다. 관측 x_t = (언어, 영상, 고유감각, 촉각)이고 행동 청크 길이 H = 10, 행동 차원 14(Table 3).
- 촉각 창 h_t = (L = 10) × (K = 4 × 32 × 12 = 1536 taxel). CNN 두 층 인코더 E_τ가 토큰 M개를 만듭니다(prefix 8, suffix 8, Table 3).
- **접촉 게이트(식 4):** 창 안에서 |f| > λf = 0.4인 taxel이 m = 1개 이상이면 게이트가 열립니다. 닫히면 촉각 토큰을 주의에서 뺍니다.
- **두 경로(식 5):** (a) 기본 토큰이 촉각 토큰에 교차 주의, (b) 촉각 토큰이 행동 전문가의 조건 토큰으로 직접 들어감.

### 2.3 시뮬-실 공동학습 (§3.3, 식 6–7)

실 시연 D_real(과제당 50개)과 시뮬 시연 D_sim(텔레옵 20개를 MimicGen으로 200개로 확장)을 L_co = α·E_sim[ℓ_flow] + (1−α)·E_real[ℓ_flow]로 섞어 학습합니다(α = 0.5, Table 3). 공동학습 단계: 조립 두 과제 1000스텝, Do Puzzle과 Test Tube 3000스텝, 배치 192, AdamW(Table 3).

### 2.4 실데이터 앵커를 둔 후학습 (§3.4, 식 8)

PPO(희소 성공/실패 보상)에 실데이터 flow-matching 손실을 더합니다: L_RL = L_PPO + β·E_real[ℓ_flow]. 구현은 RLinf와 πRL의 Flow-SDE(σ = 0.5, 디노이징 4단계, 청크 단위 보상과 로그확률)를 따르고, 병렬 환경 128개, 롤아웃 청크 36스텝, 감마 0.99, GAE 0.95, 클립 0.2, 업데이트 에폭 1, RL 배치 512, 액터 학습률 5e-6, 가치 헤드 1e-4, 앵커 배치 32, β = 1.0입니다(Table 4). 배포 때는 critic과 보상, 특권 상태를 버립니다.

## 3. 실험

### 3.1 설정 (§4.2, 부록 A, E)

- **로봇:** AgileX PiPER 6자유도 팔 두 개, 외부 RealSense D415 하나와 손목 D405 둘, 그리퍼 접촉면마다 FlexiTac-V2 패드(32 × 12 taxel).
- **과제:** Test Tube Insertion, Do Puzzle(조각 3개), Assembly #1(나사와 너트), Assembly #2(소켓과 플러그).
- **데이터와 평가:** 과제당 실 시연 50, 시뮬 텔레옵 20 → 200, 시뮬 평가는 병렬 환경 128개, 실로봇은 과제당 20회(§4.2). 표 2의 모든 값이 0.05의 배수라서 셀당 20회로 읽습니다.
- **도메인 무작위화(Table 5):** 모든 과제에 카메라 자르기·회전(±5°)·밝기·대비·채도, 마찰 U(0.3, 0.7). 과제별 위치·자세 무작위화는 표에 있습니다(예: Test Tube 튜브 yaw ±20°).

### 3.2 정렬 검증 (§4.1, 그림 4, 그림 9)

- 한 관절(J4, "중력 보상 불일치로 보정 전후 차이가 가장 큰" 경우를 골랐다고 적음) 재생에서 보정 뒤 시뮬이 실제 응답에 가까워집니다.
- 촉각 분포는 정규화한 읽기 평균이 실 0.616, 시뮬 0.658(그림 4B 범례). 분산이나 거리 통계는 없습니다.

### 3.3 시뮬 결과 (표 1, 그림 6)

| 설정 (평균 %) | Vision-only | Visuo-tactile |
|---|---|---|
| 공동학습 직후 | 33.0 | 40.5 |
| RL 시작(탐색 잡음) | 22.5 | 29.3 |
| 기반 VLA에서 곧바로 RL | 0.0 | 0.0 |
| 공동학습 후 RL | 60.5 | 78.5 |

### 3.4 실로봇 결과 (표 2)

| 설정 (4과제 평균 %) | Vision-only | Visuo-tactile |
|---|---|---|
| 실데이터만 미세조정 | 21.25 | 33.75 |
| 시뮬-실 공동학습 | 30.0 | 43.75 |
| RL 후학습 | 50.0 | **72.5** |

Do Puzzle은 시각-촉각 RL 45%, 실데이터만 15%, 공동학습 25%입니다(§4.4). 부록 C는 기준선 실패 사례(회전 오차, 위치 오차, 방향 오차, 자세 오차)를 과제당 대표 한 장면으로 보여 줍니다(그림 12).

### 3.5 절제 (§4.5, 그림 7, Assembly #2만)

- α(β = 0): α = 0이면 시뮬 최고 성공률 14.1%, 실 25%. α = 0.95는 42.9%와 40%, α = 0.5는 70.3%와 45%.
- β(α = 0.5): β = 0.1과 1.0 모두 실 80%, 시뮬 최고 92% 초과. β = 5.0은 지도 손실이 가장 낮지만 시뮬과 실 성공이 낮아집니다(그림 7 오른쪽 막대 50%).
