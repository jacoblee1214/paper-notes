# Qwen-RobotWorld 주장 검증 (C1–Cn)

공식 코드와 가중치가 공개되지 않아 코드 대조(D1–Dn)는 할 수 없습니다(02 §4). 대신 논문의 주장을 하나씩 꺼내 **재계산 가능, 정성 근거만 있음, 근거 없음** 중 무엇인지 판정했습니다. 수치 재계산은 03과 `recompute.py`를 봅니다.

판정 기준: **맞음**(보고된 수치로 확인), **부분**(일부만 맞거나 선택적 서술), **정성**(그림만 있음), **미검증**(실험이나 수치가 없음), **불일치**(논문 내부 모순).

## 2. 가장 중요한 세 가지

1. **C2, C18, C6–C7의 문제.** 1위 주장의 차이가 작거나(PBench 0.002), 데이터 규모가 본문 두 곳에서 다르게 적혀 있고(주행 200K 대 1.74M), 낮은 점수의 원인을 해상도로 돌리는데 확인이 없습니다.
2. **로봇 제어 주장의 공백.** 초록의 세 응용 중 어느 것도 정책 성능이나 시뮬 정책 평가 상관으로 측정되지 않았습니다(C16, C21). 이 논문으로는 "로봇 학습에 쓸 수 있다"는 결론을 내릴 수 없습니다.
3. **재현 가능한 부분의 부재.** 정량 주장 대부분(C1–C5, C8)은 표 값으로만 확인되며, 공개된 코드나 평가 설정이 없어 외부 검증이 안 됩니다.

## 4. 구현 가능성 판정 (이 맥: Apple M4 Pro 24 GiB, MPS, CUDA 없음)

**판정: 이 논문의 모델은 이 맥에서 구현하거나 재현할 수 없습니다. 실제로 할 수 있는 것은 평가 수치 재계산(완료)과 논문 설계 요소를 작은 규모로 옮기는 토이 정도입니다.**

| 항목 | 가능 여부 | 근거와 노력 |
|---|---|---|
| 20B MMDiT 학습 | 불가 | 공개 코드, 가중치, 설정이 없음. 규모가 CUDA 다중 GPU 전제 |
| 7B Qwen2.5-VL 동결 추론 | 조건부 | MPS에서 가능하더라도 가중치 다운로드와 설치 승인 필요 |
