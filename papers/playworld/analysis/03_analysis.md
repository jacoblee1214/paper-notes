### 토이 T1: 시행 수 잡음이 만드는 상관 천장과 RMSE 바닥

설정(가정): 정책 18개의 진짜 성공률을 그림 7 PlayWorld 패널의 실제 SR(그림 판독)로 두고, 실제 평가 20회, 세계모델 평가 50회(§4.4)의 이항 표본에 세계모델 진짜 성공률 = 진짜 + N(0, σ²) 오차를 더해 20,000번 모의했습니다. 실제 SR 값에 이미 표본 잡음이 들어 있어 이 설정은 근사입니다.

| σ (세계모델 오차) | r 평균 (5–95%) | RMSE 평균 |
|---|---|---|
| 0 (완벽한 모델) | 0.944 (0.903–0.974) | 0.105 (해석적 바닥 0.106) |
| 0.05 | 0.933 (0.885–0.968) | 0.115 |
| 0.10 | 0.901 (0.834–0.953) | 0.139 |
| 0.15 | 0.855 (0.754–0.932) | 0.170 |
| 0.20 | 0.798 (0.659–0.906) | 0.203 |
| 0.30 | 0.677 (0.452–0.849) | 0.264 |

- 보고된 RMSE에 맞는 σ는 PlayWorld 약 0.15, 사람 시연 약 0.32, 사람 놀이 약 0.35입니다. 이 σ에서 모의 r은 0.85, 0.65, 0.62로 보고 r(0.88, 0.66, 0.66)과 같은 크기입니다. 즉 세 모델 모두 "시행 수 잡음 + 정책별 독립 오차 σ" 모형으로 r과 RMSE를 함께 설명할 수 있습니다.
- 시행 수 잡음만으로 완벽한 모델도 r ≈ 0.94(5–95% 0.90–0.97), RMSE ≈ 0.105이므로 PlayWorld의 0.8766과 0.171은 그 천장·바닥에 꽤 가깝고 baseline의 RMSE는 바닥의 약 2.6–2.8배입니다.
- **r은 체계적 과대 평가에 둔감합니다.** σ = 0.05에서 모든 정책을 +0.1, +0.3 높게 평가하는 모델의 r 평균은 0.929, 0.905로 거의 변하지 않고 RMSE만 0.15, 0.295로 커집니다. "환각 성공"처럼 성공률을 일률적으로 올리는 오차는 r로는 거의 드러나지 않으므로 RMSE와 평균 편향을 함께 보고하는 편이 낫습니다.

- **"최대 65%"의 정의:** 수건 과제에서 초기 2/20(0.10)과 2000 스텝 15/20(0.75)의 절대 차이 65%p(상대로는 7.5배)입니다. 같은 스텝의 baseline과 비교하면 +40%p(15/20 대 7/20, p = 0.025)이고 당근은 1200 스텝에서 +50%p(15/20 대 5/20, p = 0.004)입니다. 본문 §4.5는 "baseline 비디오 모델에서의 미세조정과 비교해 최대 65%"라고 쓰고 서론은 "사전학습 정책 대비"라고 써서, 비교 대상이 문장마다 다릅니다(K10).
- 두 과제 모두 PlayWorld가 초기 대비 올라갑니다(당근 6/20 → 15/20, p = 0.010, 수건 2/20 → 15/20, p = 0.0001). 다만 체크포인트 4–5개 가운데 가장 좋은 값을 고른 것으로, 같은 20회 시행으로 고르고 보고하면 최댓값이 부풀 수 있습니다(별도 평가 시행에 대한 언급 없음). 수건의 마지막 체크포인트(4000)는 10/20이고 초기 대비 +40%p(p = 0.014)입니다.
- **스텝 단위:** 표 5의 "Initial rollout steps 800"과 그림 9의 첫 체크포인트(당근 200, 400)가 어떤 단위의 스텝인지 적혀 있지 않습니다(K12).
- 과제당 한 번의 학습 실행(시드 표기 없음)이고 체크포인트 사이 변동이 큽니다(수건 baseline 0.10 → 0.40 → 0.25).
