## 04. 코드·데이터 대조와 주장 검증

대상 저장소: `narayananpp/semantic-humanoid-retargeting-blog`, 커밋 `84cbe2253`(2026-11-06), `repo/`에 shallow clone (git 제외). 라이선스 파일이 없다(GitHub API 404). 정적 읽기만 했고 실행하지 않았다.

### 1. 저장소에 무엇이 있나

| 경로 | 내용 | 방법 논문과의 관계 |
|---|---|---|
| `site/assets/analysis/*.json` | 과제별 추적 오차, LLM 판정, 토큰, 최선값 곡선, SPIDER 재실행 | 블로그 표·그림의 원자료. 재계산 가능 (03 참조) |
| `site/experience-story.json` | 경험 실험 10과제 | §5의 원자료 |
| `site/trace-explorer/` | 에이전트 트레이스(메시지, 시도 기록, 도구 호출 명칭만) | 에이전트 행동 확인 (01 §2) |
| `site/content/*.md` | 본문 원고 | 본문과 수치가 어긋나는 옛 문장 있음 (D5) |
| `tools/*.py`, `build.py` | 원자료 → 웹 데이터 export, 그림 생성 | 원자료 가공 방법 확인 |
| `validate.py` | 웹 페이지 검증 | 방법과 무관 |

없는 것은 다음과 같다. 에이전트 harness(실행 루프, 도구 정의), 프롬프트 원문, 에이전트가 만든 제어 코드와 기준 모션, 판정 프롬프트 원문, `object_path_v1`과 접촉 측정의 구현, G1 Dex3 어댑터 코드(SPIDER 재실행 설정은 `spider-rerun.json`의 protocol에만 있다), 시간 예산 기록.

따라서 이 저장소는 **방법의 코드가 아니라 결과의 원자료와 가공 도구**다. "방법을 코드로 검증"하는 것은 불가능하고, 대신 수치를 원자료에서 재계산했다(03 참조).

### 4. 구현 가능성 판단 (이 맥)

조건: Apple M4 Pro, 메모리 약 24 GiB, MPS 가능, CUDA 없음, torch 미설치, MuJoCo 미설치(설치는 승인 필요). 외부 LLM 호출 금지. 데이터 다운로드 금지.

**결론: 전체 재현은 이 맥에서 할 수 없다. 방법을 다시 만드는 것은 난이도 상이다. 일부 검증(수치, 통계, 원리 toy)은 가능하고 이미 했다.**

| 항목 | 판단 | 이유 |
|---|---|---|
| 수치 재계산 | 가능 (완료) | 원자료로 블로그 값 전부 재현 |
| 방법 재현 (Astra 루프) | 불가 | 외부 LLM API 필요. 금지 조건. 40과제 기준 단일 Codex 약 3.1억 토큰, 스웜 약 10억 토큰(03 §7). 단가 정보 없음 |
| 판정 재현 | 불가 | 판정 프롬프트 없음 (D3), 판정 모델은 API |
| 추적 지표 재구현 | 어려움 | `object_path_v1` 정의가 없다 (D2). "구간 단계 정렬" 규칙을 블로그 문장에서만 추정해야 한다 |
| SPIDER 기준선 (1과제) | 조건부 | MuJoCo 설치 승인 필요. SPIDER README의 기본 경로는 Mujoco Warp이며 GPU 의존 여부는 README에 명시 없음(미확인). 코드 라이선스 CC BY-NC 4.0이라 연구용 한정 |
| SONIC 제어기 | 조건부 | GR00T-WholeBodyControl 코드와 체크포인트 필요. 체크포인트 크기·GPU 의존은 미확인 |
| 데이터 (HUMOTO, OMOMO) | 불가 (지금) | 다운로드 금지. 라이선스 CC BY-NC-SA 표기 |
| 재구현 노력 | 상 (수 주) | harness, MuJoCo G1 + Dex3 장면, SONIC 연결, 피드백 이미지 생성, 판정 루프, 지표 정의 |
| 에이전트 비용 | 상 | 토큰 기록으로 과제당 약 8 M(단일)과 26 M(스웜) 규모. 달러 환산 자료는 없음 |

실행 가능한 다음 단계는 CPU만으로 할 수 있는 검증 항목이다(재계산 확장, toy 스윕). 재현은 사용자에게 묻고 시작한다.

### 5. 라이선스 판단

- 블로그 페이지와 저장소는 라이선스가 없다. 기본적으로 저작권 보유(all rights reserved)로 보고, 블로그의 그림·영상·텍스트는 공개 산출물에 넣지 않았다.
- 원자료의 수치는 사실 자료에 가깝지만, 원자료 공지는 상위 모션 데이터의 CC BY-NC-SA 4.0 조건을 따른다고 적는다. 그래서 공개본은 **수치 요약과 우리 그림만** 담는다(원자료 JSON, 트레이스, 영상 없음).
- HOI-Retarget(CC BY 4.0)은 그림을 쓰지 않았다. 필요 없었다.
- SPIDER 코드는 CC BY-NC 4.0 배지다. 재실행과 재배포는 비영리 연구 한정이다.

### 6. 검증 요약

- 재현된 것: 표 1–2, 의미 성공 비율, 추적 평균, 최선값 곡선, 경험 선반 값, 경험 집단 평균, 토큰 합계.
- 재현되지 않은 것: 방법 자체, 판정, 지표 정의, HOI+SPIDER 계산량.
- 보고에 적을 문장: 블로그의 정량 수치는 원자료와 일치하지만, 방법 비교의 통계적 힘은 기준선 대비 승리에만 있고, 스웜과 단일 실행의 우열은 없으며, 경험 효과는 과제 한 개에 기댄다.
