## 3. 구현 가능성

- **블로그 수치 재현:** 평가 쪽은 가능합니다. 실험 8의 편집 diff를 공개 Qwen3.5-0.8B에 적용하면 평가 모델을 비트 단위로 다시 만들 수 있다고 로그 README가 적고 있습니다. 다만 MATH-500을 thinking on, 32,768 토큰, 4표본으로 다시 평가하려면 GPU와 vLLM이 필요합니다. 실험 4·5의 편집된 네트워크는 공개되어 있어 Kinetix(JAX)·MinAtar(numpy)로 CPU 재평가가 가능합니다.
- **LLM 쪽 재현:** 같은 모델이 없으면 불가능합니다. 다른 모델(Claude, 공개 모델)로 같은 프롬프트를 돌리는 것은 가능하고, 이것이 "범용 LLM의 능력"인지 "특정 모델의 능력"인지를 가르는 실험이 됩니다. 실험 1·2·4·5는 도구가 없고 프롬프트가 공개되어 있어 API 호출만으로 다시 해 볼 수 있습니다.
- **이 노트북(CPU)에서 한 것:** 로그 수치 재계산 전부, 실험 1·2 가중치 시각화. 실행하지 않은 것: MinAtar·Kinetix 재평가(패키지 설치 필요), LLM 재실행(API 비용·외부 전송 확인 필요), 실험 8 재평가(GPU 필요).
