## 1. 한 문단 요약

22자유도 오른손 Sharpa Wave 로봇 손으로 물체를 손바닥 위에서 돌리는(in-hand rotation) 정책에, Dreamer 계열 RSSM(순환 상태공간 모델)을 "세계 공감각 모델(World Synesthesia Model, WSM)"이라 부르며 붙입니다. WSM은 고유감각, 이진 촉각 접촉, 손목 깊이 영상, 이전 행동으로 학습되고, 깊이는 **오염된 입력에서 깨끗한 깊이를 복원**하도록 감독됩니다. 정책(PPO)은 WSM의 결정론적 상태 h_t만 stop-gradient로 받습니다. 상상 롤아웃이나 모델 기반 최적화는 쓰지 않습니다. 아홉 개 z축 물체에서 사전학습한 WSM을 49개 물체 학습의 초기값으로 재사용하고, x·y축, 보류 물체, 섭동 복구, 실로봇 20개 물체 200회 시험을 보고합니다. 가장 큰 보고 수치는 실로봇 성공률 175/200 (기준선 33–53/200, 표 6)과 z축 Return 753.3 (표 1)입니다.

## 2. 문제 설정과 방법

### 2.1 관측과 행동 (§3.1, 식 1–2, 표 8)

- 정책 관측 o_t = (p_t^stack, c_t^stack, D_t, u_{t-1}) (식 1): 정규화한 고유감각 스택, 이진 촉각 스택, 현재 잡음 깊이, 이전 관절 목표. 시뮬레이터 깊이나 WSM 복원 깊이는 o_t에 없습니다.
- 명령 축 a ∈ {±x, ±y, ±z}를 정책이 받습니다. 한 스텝 진전은 Δθ_t = proj_a log(R_{t+1} R_t^{-1}) (식 2).
- 행동은 22관절 상대 목표 증분이며 q_target,t = q_target,t−1 + α u_t (식 9), 이후 신호 필터와 하드웨어 한계 클램프를 거칩니다. α 값은 논문에 없습니다.
- 시뮬레이션에서는 물체 자세, 속도, 접촉력이 보상, 비평가, 진단에만 쓰이는 비대칭 액터-크리틱입니다 (표 8).

### 2.2 다중모달 인코더와 RSSM (§3.2–3.3, 식 3–7, 부록 A.1, 표 7)

- 월드 모델 입력은 한 스텝 고유감각 p_t, 촉각 c_t, 잡음 깊이 I_t, 이전 행동 u_{t−1}, 에피소드 시작 플래그 m_t입니다. 깨끗한 깊이와 보상은 목표로만 저장됩니다 (식 3).
- 고유감각·촉각은 MLP, 깊이는 CNN으로 인코딩하고 Dreamer식 인코더로 융합합니다 (식 4). 깊이는 클립과 크롭을 하고, WSM 입력 깊이에는 시간 상관이 있는 픽셀 고장(dropout), 가우시안 잡음, 작은 무작위 회전이 들어갑니다. 복원 목표는 크롭만 한 깨끗한 깊이입니다.
- 사후 갱신 z_t, h_t = f_wm(z_{t−1}, h_{t−1}, u_{t−1}, e_t, m_t) (식 5). 정책은 w_t = h_t (식 6)를 detach해서 받고, 512차원 h_t를 작은 MLP로 16차원으로 줄입니다 (§3.3 본문, 표 7의 512→64→32→16).
- 손실 L_wm = L_img + L_prop + λ_c L_tac + λ_r L_reward + λ_dyn L_dyn-KL + λ_rep L_rep-KL + L_aux (식 7). 표 7에 적힌 값은 KL free 1.0, dyn 0.5, rep 0.1뿐이고 λ_c, λ_r, L_aux 가중치는 본문에 없습니다.
- 전체 WSM은 깊이, 고유감각, 촉각 접촉, 보상, 물체 자세, 가치, 물체 형상(basis-point-set에서 메시까지의 변위 벡터) 헤드를 씁니다 (§3.3). 자세와 형상 라벨은 시뮬레이터에서 옵니다.
- 학습은 PPO 롤아웃으로 채운 링 리플레이(256행, 워밍업 10,000 전이)에서 매 PPO 에폭 뒤 10회, 배치 16, 청크 길이 32로 합니다 (표 7).

### 2.3 사전학습한 공감각 사전분포 (§3.4, 부록 A.1)

아홉 개 z축 물체에서 사전학습한 뒤 인코더, 다중모달 RSSM, 깊이·고유감각 디코더, 보상 예측기를 49물체 PPO의 초기값으로 옮기고 계속 적응시킵니다. 액터-크리틱과 과제 헤드는 새로 학습합니다.

### 2.4 정책 학습과 보상 (§3.5, 부록 A.2, 식 10, 표 7)

PPO(1024 환경, 지평 16, 미니배치 4096, 미니 에폭 4, γ 0.99, GAE 0.95, LR 1e-4, 클립 0.2)로 학습하고 정책 MLP는 [512, 256, 256] ELU입니다. 보상은 축 회전(스핀) 항, 속도, 접촉, 거리, 토크, 일, 행동, 제어, 손 자세, 드리프트, 이탈 축, 무회전 항의 합입니다 (식 10). 시스템 식별은 1 Hz 사인파 명령으로 시뮬레이터 Kp, Kd를 맞추고(부록 A.3), 도메인 무작위화로 잔여 격차를 덮습니다.

## 3. 실험 결과

공통: 시뮬레이션 평균은 "무작위 평가 시드 아래 방법당 128 평가 에피소드"이고 CI는 95%입니다 (§4.1). 지표는 Return, EpLen, RotR(회전율), OffAxis, AngVar입니다. 실로봇은 20 s 에피소드당 회전 rad(RR)와 성공률(SR, 반 바퀴 초과 회전)이고, 네 명의 주석자가 영상으로 점수를 매겨 평균합니다.

### 3.2 실로봇 z축 (표 3, 표 6)

표 3(물체당 10회): 오리, 십자 블록, 모서리 블록, 보류 이중노치 블록. 제안법은 16.179/10, 8.01/10, 8.48/10, 4.32 rad 에서 SR 10/10, 10/10, 10/10, 8/10입니다. 표 6: 20개 물체(훈련 9 + 보류 11) x 10회에서 175/200, 기준선 33–53/200.

### 3.3 x·y축과 보류 물체, 섭동 복구 (표 4, 5, 6, §4.4–4.5)

- y축(표 4, 아홉 도구형 물체): 제안법 Return 272.7, RotR 1.025, 가장 낮은 낙하율 0.049. 기준선 최대 177.8, 0.545.
- x축(표 5, 네 물체): Return 432.8, RotR 1.114, 낙하율 0.020. 기준선 한 방법(IHR)은 295.1.
- 보류 물체(표 6, 축마다 네 개): 제안법이 세 축 모두에서 RotR과 Return이 가장 높습니다(x 1.002/333.6, y 0.715/203.5, z 0.842/533.1).
- 섭동 복구(시뮬 z축): 복구율 14.1% ± 6.0% 대 최강 기준선 6.2%, 평균 복구 시간 2.56 s (표 6).
- 49물체 사전분포(§4.3, 그림 5): 3000 에폭 뒤 물체당 9.37 ± 0.13 rad/에피소드 대 사전분포 없음 3.28 rad, 훈련 낙하율 6% → 0.3%. 별도 5블록 진단에서 RotR 처음부터/9물체/49물체 사전분포가 1.10/1.34/1.46.

### 3.4 표현 진단 (§4.3, 그림 3, 4, 8)

t-SNE는 "부분적으로 물체에 따라 나뉘고 겹침도 큼"으로, 깊이 복원은 "잡음을 줄이고 손-물체 기하를 보존"으로 서술됩니다. 정량 지표는 없습니다.

### 3.5 저자가 쓴 한계 (§5)

단기(short-horizon) 과제, 큰 섭동에서의 복구율 한계, 물체가 손 작업 공간을 넘거나 회복 영역 밖으로 밀리거나 끼임·드리프트가 생길 때의 실패. 도구 사용은 부록 B.3(드라이버 이동·회전, 정성 그림 9)에 그칩니다.

## 4. 주장과 근거의 간격 (요약, 자세한 판정은 `03` §4)

1. **고유 기여의 분리.** 표 1의 "처음부터 414.3"과 "사전학습 전체 753.3"의 차이는 WSM 구조와 추가 학습 예산을 함께 담습니다. 사전학습의 PPO·WM 에폭 수, 시드 수, 같은 예산의 기준선이 논문에 없습니다.
2. **통계 단위.** 표의 CI는 한 번 학습한 정책의 평가 에피소드 변동입니다. 학습 시드 수와 시드 간 변동은 보고되지 않았습니다.
3. **촉각의 효과.** 촉각을 테스트에서 지우면 Return이 3.8% 줄어듭니다(753.3 → 724.9). 촉각을 처음부터 뺀 학습 대조는 없습니다. 실로봇 촉각 절제도 없습니다.
4. **표 3의 정수 일관성.** 세 칸의 평균 RR이 SR에서 오는 하한(반 바퀴 = π rad 가정)보다 작습니다 (`03` V5).
5. **유의 문구.** "최강 기준선 대비 복구율 +7.9 %p"는 18/128 대 8/128로 Fisher p = 0.061입니다 (n=128 가정).
6. **공개 코드와의 범위.** 공개 체크포인트는 고유감각·깊이 헤드만 켠 설정이고 기준선, 보류 물체, 49물체 구성은 저장소에 없습니다 (`04`).
