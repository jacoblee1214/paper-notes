# 04. 주장 대조 (공식 코드 없음)

공식 저장소(`github.com/princeton-vl/DAPPT`)에는 README 한 장("Code coming soon")뿐이라 코드를 대조할 수 없습니다. 그래서 `04_code_verification.md` 대신 **논문 주장을 표와 본문 값으로 대조**합니다. 주장 번호 C1–C12는 이 문서 안에서만 씁니다. 결과 표의 값은 `03_analysis.md`와 `recompute_results.json`에서 왔습니다.

판정 기준: **지지**(표 값과 맞음), **부분**(방향은 맞지만 조건이나 크기가 다름), **불일치**(표나 본문 값이 다름), **검증 불가**(그림·영상·정보 부족).

## 2. 판정 요약

- **방향은 맞고 크기는 재현 불가.** 도메인 파라미터가 과제 결과를 바꾼다는 주장(C1, C4, C10)은 표와 맞습니다. 그러나 1.5–3.8배, 기준선 대비 우위(C3), zero-shot "comparable" 성능(C2)은 비교 설계와 통계 정보가 부족해 **확정할 수 없습니다**.
- **내부 불일치는 작지만 있습니다.** C4 문장, C1 하한, 표 II의 마우스 휠 값과 표 I의 SimToolReal 값이 같습니다(`03` §1.2).
- **부록 표 V의 항목 매핑이 모호합니다.** 행과 값 수가 맞지 않습니다. 아래 §3 참조.

## 4. 구현 가능성 판정

**판정: 이 맥(Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)에서 논문의 학습과 실로봇 실험은 불가능합니다. 축소판 중 도구 궤적 추종 toy는 조건부로 가능합니다.**

| 항목 | 필요 자원 | 이 맥 | 판정 |
|---|---|---|---|
| 교사 학습 (19자유도, IsaacLab) | NVIDIA GPU, Linux/Windows | IsaacLab은 macOS를 지원하지 않음(저장소 README) | **불가** |
| MPM 입자 평가 (Genesis) | Genesis 설치 | Genesis README는 Apple Metal을 언급함. 이 맥에서 설치와 성능은 **미확인** | **조건부** (설치 승인 후 확인) |
| 증류 (PointNet++, 1024점) | GPU 학습 | 작은 모델은 MPS 가능하나 교사 정책이 없음 | **불가** (교사 필요) |
| 실로봇 (XHand1, Franka R3, RealSense) | 하드웨어 | 없음 | **불가** |
| 절차적 궤적 생성 (스쿱 6D 궤적) | numpy | 가능 | **시작 가능** |
| 강체 도구 추종 toy (스쿱 1개, 파라미터 c 조건 소형 MLP) | MuJoCo 등 강체 시뮬레이터 (이 환경에 mujoco 없음) | 설치 승인 후 CPU 가능 | **조건부** |

**노력 추정.** 논문 방법을 **처음부터** 다시 짜야 합니다(코드 없음). 이 맥에서는 강체 도구 추종 toy가 1–2주입니다(설치와 궤적 함수, 보상 계수 추정 포함). 전체 재현은 GPU 기기에서 수 주이고, 보상 계수와 Kd 값을 저자에게 받지 못하면 시간이 크게 늘어납니다.
