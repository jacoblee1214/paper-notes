# 01. 논문 분석: GoalDex

## 메타

- 학회: **CoRL 2026** (10th Conference on Robot Learning, Austin, TX). 원문 1쪽 하단 "10th Conference on Robot Learning (CoRL 2026), Austin TX, USA." 표기로 확인했습니다. 채택 여부와 proceedings 게재 정보는 PDF에 없습니다.
- 저자: Bhardwaj, Mittal, Wilder-Smith, Patil, Hutter
- 원문: `paper/paper.pdf` (14.1 MB, 19쪽), 텍스트 `paper/paper.txt`, 프로젝트 페이지 HTML `paper/project_page.html`
- 프로젝트 페이지: https://rffr.leggedrobotics.com/works/goaldex/ (화면 확인 시점 "Code soon")
- 라이선스: arXiv abs 페이지의 라이선스 링크는 CC BY-NC-ND 4.0입니다. 1쪽에는 arXiv 스탬프와 CoRL 표기만 있고 "©"나 재인쇄 문구는 없습니다(`04` §5).

## 한 줄 요약

RGB 관찰, 고유감각, **목표 이미지**를 받아 Allegro 손의 관절 목표를 내는 단일 정책을, 특권 상태 교사의 행동 복제(온라인 DAgger)와 숨은 물체 상태 재구성 보조 손실로 학습합니다. 목표 이미지와 현재 이미지의 임베딩 거리를 두 자세의 측지 각에 맞추는 연속 대조 손실(α = 2.5)을 더합니다. 시뮬레이션 5개 물체에서 연속 성공 수(CS) 77.30 ± 3.25를 내고, 포즈 목표(같은 입력)는 69.20 ± 5.47입니다. 실로봇 5개 물체에서 100회 중 80회 성공하며, 같은 프로토콜의 포즈 기반 최강 기준선은 27회입니다(본문, 기준선 표는 없음).

## 구현 가능성 판정 (먼저 읽을 것)

- **공식 재현: 이 맥에서는 불가, NVIDIA GPU가 있는 리눅스에서는 노력이 큽니다(조건부).** 코드는 "Code soon" 상태라 아직 없습니다. 학습은 Isaac Lab, 3D Gaussian Splatting 렌더러(선행 연구 ViserDex [2]의 파이프라인), 객체 마스크용 SAM2 미세조정이 필요하고, 학생 한 정책이 H100 두 장에서 약 30시간입니다(부록 B.3). 실로봇은 Allegro 16-DOF 손과 손목 RealSense D435i가 필요합니다. 상세는 `04` §4.
- **이 맥(Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)**: Isaac Lab과 3DGS 학습은 불가입니다. 학습 방법의 핵심 손실(연속 대조, 재구성, DAgger 혼합)은 numpy와 CPU 토이로 옮겨 볼 수 있습니다. 이번에 했습니다(`03` §5–§6).
- **재구현 노력: 중간 이상.** 구조(ResNet-34 두 개, GRU 2층 512, 재구성 MLP)는 수백 줄이지만, 3DGS 렌더링과 물체 마스크, 학습 인프라가 실제 장벽입니다(추정).

## 1. 문제 설정 (§3.1)

- 목표는 SO(3)의 목표 방향을 **목표 이미지 I_g**로 지정하는 것입니다.
- 교사 MDP `M_priv = ⟨S, A, G, T, r, γ⟩`는 물체 기하, 질량, 마찰, 크기, 자세를 모두 봅니다. 배포 POMDP는 단안 RGB와 고유감각만 봅니다.
- 관찰은 "목표 중심(target-centric)" RGB 프레임 I_t라고 쓰지만, 실제로는 물체 마스크를 씌운 영상입니다(§3.3, 부록 B.3).
- 교사 상태에는 목표 상대 회전 q_rel과 물체 클래스 one-hot이 들어갑니다(§3.2).

## 2. 방법

| 구성 요소 | 내용 | 위치 |
|---|---|---|
| 교사 | PPO, 여러 물체 하나의 정책, 목표 SO(3)를 월드 좌표로 줌 | §3.2, 부록 B.1, 표 8·9 |
| 학생 시각 | 현재 영상 ResNet-34 → z_obj, 목표 영상 별도 ResNet-34(φ) → z_goal | §3.3–3.4, 부록 B.3 |
| 시간 통합 | GRU 2층, 은닉 512 (x_t = [z_obj, z_goal, z_prop]) | §3.3 |
| 재구성 | 은닉 상태에서 물체 위치, 자세, 속도, 크기, 질량 등을 MSE로 예측. 손가락 힘과 중력은 제외 | §3.3, 표 8 |
| 연속 대조 | s* = exp(-α d_θ(q_rel)), L_cont = MSE(s*, ⟨z_obj, z_goal⟩), α = 2.5 | §3.4, 표 11 |
| 성공 예측 | 카메라 기준 상대 쿼터니언 q̂_rel을 예측하고 각도가 0.4 rad 아래로 3 스텝 연속이면 성공 선언 | §3.4, 부록 B.3 |
| 손실 | L_total = L_BC + 0.2 L_recon + 0.1 L_cont | §3.4, 표 11 |
| 증류 | 온라인 DAgger, 교사 혼합 β = 0.9에서 0.995 감쇠 | 부록 B.3 |
| 렌더링 | 다물체 3DGS, 스케일은 카메라 뷰 행렬에 적용(Ṽ = VS). 물체 스케일 U(0.5, 1.5) | §3.4, 부록 B.2 |

- 목표 이미지는 **물체 메시를 샘플된 자세로 렌더링한 영상**입니다(부록 B.5). 시뮬레이션에서는 3DGS로 렌더링합니다.
- 실로봇 배포는 30 Hz 정책, 300 Hz 관절 PD, 시각 인코더는 비동기 실행이며 임베딩은 zero-order hold로 씁니다. 목표 임베딩은 한 번 계산해 재사용합니다(부록 B.3).

## 3. 실험과 결과

### 3.1 설정

- 시뮬레이션: 3 시드, 환경 64개, 평가 에피소드 2회(환경당). 한 정책은 시드당 128 에피소드입니다(§4).
- 지표: 연속 성공 수 CS(↑), 성공까지 시간 TTS(↓), 성공 예측 F1(↑), 예측 실패율(↓), 재구성 오차.
- 성공 기준: 정책이 완료를 예측하고 **실제** 오차 < 0.4 rad. 예측 실패는 예측은 성공인데 실제 오차 ≥ 0.4인 경우이며, 그 목표를 버리고 새 목표를 뽑습니다(§4).
- 물체: 5개 세트(Cube, Globe, Tablet Bottle, 3D Printed Toy, Rubber Duck, 선행 연구 [2]와 같음), 25개 세트(확장).

### 3.7 그림 5(부록 A.2): 물체별 시뮬레이션 값

- 5개 세트 CS(교사 대 ours): Globe 169 대 190, Tablet Bottle 141 대 90, 3D Printed Toy 130 대 59, Cube 145 대 47, Rubber Duck 25 대 9.0. 교사 평균은 122.96이고, ours 77.30은 교사의 63%입니다.

- 그림 속 Cube는 면에 글자(T 등)가 인쇄된 물체이므로 `03` §5의 "무늬 없는 대칭 물체" 토이와 직접 같지 않습니다.

### 3.8 언어 지시 데모 (§4.6, 그림 4)

- GPT-4o(논문 본문은 VLM [9]로 표기)가 후보 시점 128개에서 목표 이미지 한 장 또는 순서열을 고릅니다(부록 B.4, 질의 형식은 JSON 출력).
- 세 과제: 유통기한 위치, 대륙 크기 비교, 글자 H-E-R-E 순서 제시. **정량 평가는 없습니다.** 성공 횟수가 보고되지 않았습니다.

### 3.9 부록 A.1 (표 6): 특권 및 오라클 포즈

- 표 6(부록 A.1)의 CS: 오라클 포즈 22.49 ± 6.77, 오라클 포즈 + 클래스 43.77 ± 7.06, 오라클 포즈 + 클래스 + 스케일 98.64, 특권 학생 120.38 ± 7.85, 교사 122.96 ± 2.38입니다.
- 본문은 오라클 포즈 정책이 RGB 정책보다 높지 않다고 씁니다. 수치로는 맞습니다(22.49 < 77.30). 하지만 오라클 포즈 + 클래스(43.77)도 RGB 정책보다 낮습니다. 학습된 포즈 기반 기준선(11.23)과 오라클 포즈 + 클래스(43.77) 사이의 약 32 CS 차이는 포즈 추정 오차 몫이며, 본문의 "포즈 추정 오차만으로 설명되지 않는다"와 양립합니다.
- 오라클 + 클래스 + 스케일(98.64)은 RGB 정책을 넘지만 스케일은 배포 때 관찰할 수 없는 값입니다(본문도 인정, 부록 A.1).

## 4. 저자가 인정한 한계 (Limitations 절)

1. 25개 물체 학습이며 **보지 못한 물체 범주에는 일반화하지 않는다**고 씁니다.
2. 목표 이미지 생성에 물체 기하(메시 렌더링)가 필요합니다. 해결책으로 유사 물체 검색이나 3D 생성 모델을 듭니다.
3. 물체 마스크가 필요합니다(SAM2 미세조정). 전체 프레임 학습으로 바꿀 계획입니다.
4. 실로봇은 palm-up 구성뿐입니다. 팔 움직임과 결합하면 일반 조작으로 확장할 수 있다고 씁니다.

## 5. 내가 보는 추가 한계 (본문에 없음)

- **허용오차 0.4 rad(약 23°)는 크고, 성공 판단은 예측 헤드에 의존합니다.** 실로봇 성공 수 자체가 "정책이 성공을 선언하고 오프라인 FoundationPose로 확인한 결과"입니다(부록 B.5). 평가가 포즈 추정에 기대므로, 포즈를 쓰지 않는다는 주장과 평가 절차가 맞물려 있습니다.
- **같은 이미지에 여러 자세가 대응할 수 있습니다.** 대칭 물체와 몸체가 회전체인 물체가 그렇습니다. 연속 대조 목표는 이 모호성을 반영하지 않습니다(`03` §5).
- **목표 이미지는 시뮬레이션 렌더링(3DGS)과 실로봇 메시 렌더링이 섞입니다.** 실로봇 목표 영상의 도메인이 학습 분포와 같은지 논문은 보이지 않습니다.
- **3 시드 통계.** 시드가 3개이므로 차이 검정력이 낮습니다(`03` §2).
- **실로봇 재현 데이터가 없습니다.** 표 5만 있고 시도별 기록, 목표 자세, 기준선 프로토콜이 없습니다.

## 6. 부록 요약

- **B.1 교사:** 관찰은 고유감각, 상태(교사만), 목표(위치와 쿼터니언 차이), 물체 클래스. 목표는 64차원, 상태는 128차원 잠재로 인코딩. PPO 액터와 크리틱 1024×4.
- **B.2 렌더링:** 3DGS 물체 가우시안, 스케일 증강을 뷰 행렬에 적용.
- **B.3 학생:** 학생 관찰은 고유감각 4스텝 행동 이력과 객체 마스크 RGB 두 장(현재, 목표). 640 환경, 45 스텝, 학습률 3e-4, 보조 손실 계수 0.2, 대조 계수 0.1, α = 2.5.
- **B.4 VLM:** 128 후보 뷰, JSON 질의 형식.
- **B.5 실로봇 라벨:** 각 예측 성공 프레임에서 FoundationPose(고해상도 RGB-D, 마스크, 메시, 반복 정제)로 자세를 구하고 메시 오버레이로 수작업 확인. 10초 시간 초과.
- **C 포즈 추정기:** ResNet-34(ImageNet 초기화), 아홉 개 키포인트(u, v, 깊이), Huber(δ = 0.05), AdamW.
