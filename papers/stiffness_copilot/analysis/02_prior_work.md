# 02. 선행연구와 관계

## 1. 계보

논문 Sec. II가 세 갈래로 정리한 흐름을 따랐습니다.

- **학습 기반 가변 임피던스 정책**: 임피던스(강성)를 출력하는 모방학습 [1], [2], [3]과 힘을 출력하는 방법 [4], [5], [6]. 강화학습 기반 가변 임피던스 [7]은 자기 궤적에 맞춘 강성이라 공유제어에 그대로 쓸 수 없다고 봅니다.
- **원격조작에서 임피던스 조절**: 사람이 직접 고르는 방법(인터페이스 [9]–[11], 발 페달 [10], 버튼 [3])과 생체신호 기반 텔레임피던스 [13], 규칙 기반 자동 조절 [14]–[16], 데이터 기반 추정 [17]–[19](Michel 계열, 진동 분산에서 강성을 유도하는 방식).
- **학습 기반 공유제어**: 인간-에이전트 공동학습 [24], [25]과 점진 공유 자율 [26], 확산 모델 기반 의도 추정 [22], [23], 휴머노이드 접촉 배치 흐름 정합 [21].

논문의 위치는 "사람이 자세를 명령하고, 임피던스만 학습 정책이 맡는다"입니다. 시뮬레이션의 특권 접촉 정보로 방향별 강성 라벨을 만들고, 이를 손목 영상 정책으로 증류한다는 점이 새롭습니다(Sec. II-A 마지막 문단).

## 3. 이 저장소의 다른 논문과의 관계

- **DexForce와의 관계:** 두 연구 모두 "힘을 임피던스 목표에 반영"합니다. DexForce는 목표 위치를 밀고, SC는 강성을 바꿉니다. 같은 임피던스 법칙에서 위치 밀기와 강성 바꾸기는 정상상태에서 같은 힘을 냅니다. 그래서 SC 라벨 K_e의 고유방향이 DexForce의 k_f 방향 선택과 같은 역할을 합니다. 식 차이는 `03` §4.
- **BIF와의 관계:** BIF 논문은 원격조작 P 서보 게인(δ 안에 숨은 힘 신호)을 분석합니다. SC는 게인 자체를 정책 출력으로 씁니다. 두 연구가 함께 말하는 것은 "원격조작에서 힘 정보는 목표와 게인에 함께 들어 있다"입니다.
- **NestDex와의 관계:** NestDex의 사용자 연구는 시행 단위 통계(Table II 성공 1건당 시간)와 Holm 보정을 씁니다. SC의 사용자 연구 역시 반복측정 설계이지만 원자료가 없어 쌍체 검정을 재현하지 못합니다. 같은 분석 틀을 쓸 때 원자료 공개 여부가 재계산 범위를 결정합니다(`03` §1.6).
- **ResTacVLA와의 관계:** 둘 다 "손목 영상으로 접촉 상태를 예측해 정책에 붙인다"는 구조입니다. 차이는 SC는 **방향별 강성 라벨**을 감독으로 쓰고, ResTacVLA는 **촉각 잠재와 그 잔차**를 쓴다는 점입니다. 두 논문 모두 시각만으로는 접촉의 숨은 상태(거리·법선)가 식별되지 않는 경우를 한계로 둡니다(`03` §5).
- **reactive_grasp와의 관계:** 접촉 법선과 접점 기하가 중요하다는 점에서 같습니다. SC는 법선을 학습으로, reactive_grasp는 기하 계산으로 얻습니다.
