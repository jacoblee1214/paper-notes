# 02. 선행연구와 계보

번호 [n]은 논문의 참고문헌 번호입니다. 각 논문을 따로 열어 검증하지는 않았고, 제목과 저자는 논문 목록을 그대로 옮겼습니다.

## 1. 계보

```
[언어 조건 조작]   RT-2 [63], OpenVLA [19], π0.7 [41], GR00T N1 [2, 3], ForceVLA [57] …
        │  문제: 접촉(집기·열기·삽입) 중심 평가. 중력·마찰·관성은 거의 안 봄 (§1, §2.1)
        ▼
[동적 조작]        Mason & Lynch [35] (동역학 조작 개념) → DynamicVLA [54], Dynamic BC [62], DynamicManip [29], VLASH [49]
        │  문제: 빠른 추종과 정확도는 보지만 물리량 추정을 따로 평가하지 않음 (§2.2)
        ▼
[외재 손재주]      Extrinsic dexterity [8] (Dafle 외, 2014): 외부 접촉을 이용한 조작
        ▼
★ PhyDEX           던지기 과제 + 질량·CoM·마찰을 무작위화 + 실제 물리량 입력 ablation + 35K 자동 데이터
```

물리 속성 추정 계보는 두 갈래입니다(§2.3). 암묵적 인코딩 [1, 42, 52, 59]과 명시적 예측 [33, 46, 48, 58]입니다. 저자는 로봇 학습 쪽은 "pick-and-place 또는 접촉이 많은 조작"에만 쓰였다고 봅니다 [33, 55].

## 5. 참고: 이 논문의 주장이 기대는 선행 결과

- **"기본 하이퍼파라미터 사용"(§4.2):** 평가에 쓴 정책 설정은 각 저자가 공개한 기본값입니다. 이 기본값이 "PhyDEX에서 0%가 나온다"의 원인인지, 아니면 PhyDEX 설정에 맞지 않는 것인지 논문으로는 구분할 수 없습니다.
- **"다른 벤치마크는 무작위화가 약하다"(§4.4):** RoboSPA [10]와 LIBERO [30]를 인용하지만, 같은 정책으로 그 벤치마크를 돌린 수치를 함께 보이지 않습니다. 비교 기준이 간접적입니다.
- **"휴머노이드 실험은 같은 파이프라인"(§4.3):** 파이프라인은 같지만 데이터 규모는 2,400 에피소드로 훨씬 작고, 무작위화 설정 차이는 보고되지 않았습니다.
