## 1. 문제와 주장

- **문제.** 사람 행동은 로봇 데이터보다 훨씬 많이 모을 수 있지만, 사람 영상이 고자유도 손의 정교한 조작을 지원하는지는 불분명합니다. 선행 연구는 수십에서 수백 시간, 그리퍼나 저자유도 손에 머물렀다고 봅니다(서론, 1쪽).
- **주장 (초록과 서론).** (i) 사람 영상 2만 시간에서 손목과 손 행동 예측의 검증 손실이 데이터 규모의 로그-선형 법칙을 따름. (ii) 이 손실이 실로봇 장기 과제 성능과 강하게 상관함. (iii) 두 단계 전이(인간 사전학습 → 정렬된 인간-로봇 중간학습)가 22자유도 손에서 사전학습 없음 대비 평균 성공률을 54% 높임. (iv) 사람 동작 사전지식이 다른 손(3지 손)에도 전이됨.
- **판단.** 주장 (i)은 5개 점과 그림 라벨에 기댑니다. 상관 계수는 보고되지 않고, 최적 손실의 정의(학습 곡선의 최솟값)가 검증 세트 선택을 포함합니다. (iii)의 "54%"는 절대 차이입니다(`03` §1.2). 주장 (iv)은 G1에서 두 과제, 시드 2개, 10회 평가로 검증되었습니다.

## 2. 방법

### 2.1 행동 표현 (§2.1)

- **팔.** 프레임 간 손목 상대 변환 ΔW_t = (W_0)⁻¹ W_t (SE(3)). 카메라 이동에 불변이고, 사람과 로봇이 같은 식을 씁니다.
- **손.** 사람 손 21개 키포인트를 CasADi와 IPOPT로 Sharpa 22자유도 관절 공간에 리타게팅하고 지수 필터로 매끄럽게 함(부록 D). 관절 한계만 제약으로 씁니다.
- **센서.** 머리 카메라 한 대(30 fps), 손목 카메라 두 대. SLAM과 손 자세 추정기로 카메라 운동과 손 궤적을 얻음. 추정 잡음이 크다고 인정(§2.2).

### 2.2 데이터 (§2.2, 부록 C)

| 단계 | 내용 | 규모 (논문 수치) |
|---|---|---|
| I. 사전학습 | 야외 1인칭 영상(가정, 산업, 소매, 교육 등). 9,869개 장면, 6,015개 과제, 43,237개 물체. EgoDex 829 h를 추가 | 20,854 h (EgoDex 포함 여부는 본문 문장으로 확인) |
| II. 정렬 중간학습 | 사람은 Vive 트래커와 Manus 장갑, 로봇과 같은 카메라 설정. 344개 탁상 과제, 과제당 사람 약 30회와 로봇 약 5회 | 사람 약 50 h, 로봇 4 h |
| III. 사후학습 | 과제별 로봇 시연 | 과제당 100회 (셔츠 롤링 20회) |

- 부록 C는 카테고리(소매, 패션, 수리 서비스 등)와 환경 분포를 그림 10으로 보여 줍니다. 그림 10은 읽지 않았습니다.
- 이 데이터 중 공개된 것은 논문에 명시되지 않았습니다. EgoDex(arXiv:2505.11709, [8])만 외부 데이터로 인용되어 있습니다.

### 2.3 모델 (§2.3)

- GR00T N1 계열의 흐름 VLA. 시각-언어 백본 → DiT 행동 전문가, 흐름 매칭 목표.
- 사람 데이터에는 고유 근접 상태가 없어서 학습 가능한 자리표시자 토큰을 씀.
- 임베디먼트별 MLP 어댑터는 입출력에만 두고, 백본과 DiT는 공유.
- **빠진 정보.** VLM 백본의 이름과 크기, 전체 파라미터 수, 행동 청크 길이, 제어 주파수, 추론 시 흐름 스텝 수, 학습 비용(GPU 시간). 본문에 없습니다(`04` D9).

## 3. 실험 결과 (RQ1–RQ5)

### 3.1 설정

- 로봇: Galaxea R1Pro(양팔 7자유도, 몸통 고정), Sharpa Wave 22자유도 손. 과제 다섯 개: 셔츠 롤링, 카드 분류, 집게로 과일 옮기기, 병뚜껑 풀기, 주사기 액체 옮기기.
- 평가: 체크포인트당 2시드 x 10회. 병 과제는 4병 x 4회(§3.1은 16회, 부록 B는 총 12회로 다름, `04` D4). 점수는 과제별 루브릭(0–1)과 이진 성공률을 함께 보고.
- 초기 조건은 목표 장면 오버레이로 맞춤.

### 3.2 RQ1, 사전학습의 효과 (그림 4)

| 과제 | 점수: 없음 / 중간학습만 / 인간 / 인간+중간 | 성공률: 없음 / 중간학습만 / 인간 / 인간+중간 |
|---|---|---|
| 셔츠 | 0.40 / 0.55 / 0.83 / 0.90 | 0.05 / 0.20 / 0.40 / 0.50 |
| 카드 | 0.14 / 0.54 / 0.74 / 0.87 | 0.00 / 0.50 / 0.70 / 0.65 |
| 집게 | 0.35 / 0.85 / 0.79 / 0.87 | 0.05 / 0.60 / 0.45 / 0.65 |
| 병뚜껑 | 0.18 / 0.51 / 0.63 / 0.82 | 0.00 / 0.10 / 0.21 / 0.59 |
| 주사기 | 0.16 / 0.23 / 0.53 / 0.70 | 0.00 / 0.00 / 0.17 / 0.42 |
| 평균 | 0.24 / 0.53 / 0.71 / 0.83 | 0.02 / 0.28 / 0.38 / 0.56 |

값은 막대 라벨을 읽었습니다(`03` §1). 본문은 사전학습이 평균 과제 완료 점수를 "55% 넘게" 올린다고 하고, 초록은 "54%"를 씁니다. 두 수치 모두 절대 차이(점수 0.59, 성공률 0.54)와 맞습니다(`03` §1.2). 사전학습만으로 중간학습만보다 낫다는 주장은 다섯 과제 중 네 과제에서 점수로 맞고, 집게 과제에서는 반대입니다(0.79 < 0.85).

### 3.3 RQ2, 데이터 규모 (그림 5)

- 왼쪽: 1k–2k 시간은 학습 중반에 과적합하고, 10k–20k는 100K 스텝까지 줄어듭니다.
- 가운데: 최적 검증 손실 대 규모. 논문 식 L = 0.024 − 0.003 ln D, R² = 0.9983. **식의 단위와 계수에 문제가 있습니다**(`03` §2.3).
- 오른쪽: 평균 과제 완료 점수 0.30 / 0.45 / 0.48 / 0.57 / 0.71 (1k, 2k, 4k, 10k, 20k). 단조 증가. 본문은 "포화 신호가 없다"고 합니다.

### 3.4 RQ3, 중간학습과 한 번 시연 적응 (그림 6)

- 셔츠 접기: 시연 1회 + 사람 100회 → 성공률 0.88. 병 뚜껑 (병 세 종류): 0.55.
- 막대 값은 읽지 않았고, 본문 값만 씁니다. "사전학습 없음"과 "중간학습 없음"은 두 과제에서 실패합니다(본문).
- 이 결과의 시드 수와 시도 수는 본문에 없습니다.

### 3.5 RQ4, 다른 손으로의 전이 (그림 7)

- Unitree G1(7자유도 3지 손), 과제 두 개: 펜 통에 넣기, 접시 선반 놓기. 하반신은 별도의 Homie 정책.
- 성공률: 펜 통 0.30 → 0.67, 접시 0.20 → 0.50 (중간학습만 대비). 점수: 펜 0.45 → 0.83, 접시 0.54 → 0.88.
- 사전학습만(중간학습 없음)의 성공률은 두 과제 모두 0.30, 0.20으로 중간학습만과 같습니다. 이득은 사전학습과 G1 중간학습을 함께 쓸 때 나옵니다.
- 서론의 "30% 이상 절대 향상"은 접시 과제에서 정확히 30 pp이므로 "이상"이 아닙니다(`03` §1.3).

### 3.6 RQ5, 손 행동 표현 (그림 8)

- 사전학습 행동 표현 세 가지: 손목만, 손끝 SE(3), 리타게팅 관절(기본값).
- 점수 (카드 / 집게 / 병): 손목만 0.56 / 0.24 / 0.26, 손끝 0.17 / 0.76 / 0.55, 리타게팅 관절 0.74 / 0.79 / 0.61.
- 손끝 표현은 카드에서 가장 나쁘고, 집게에서는 리타게팅과 비슷합니다. 본문의 "손목만은 모든 과제에서 나쁘다"는 카드에서 0.56으로 중간입니다(`03` §4).
- 반복과 분산은 없습니다.

## 4. 한계

**논문이 스스로 말한 것.** 명시적 한계 절이 없습니다. 결론(§6)은 "관측된 범위 안에서"라고 한정하고, 더 큰 모델과 데이터로 포화가 올지는 열린 질문으로 둡니다. 약하게 말한 한계: 사람 데이터는 "잡음이 많고 제약이 없다"(§2.2), 로봇 실험은 두 시드입니다.

**우리가 본 것.**
1. 통계적 근거가 얇습니다. 시드 2개, 시도 10–20회, 신뢰구간과 검정이 없습니다. 같은 조건에서 집게 과제 성공률 0.45와 0.60의 차이는 검출력이 낮아서 판단할 수 없습니다(`03` §1.4, MDE 약 0.45–0.5).
2. 스케일 법칙의 증거는 5개 점이고, 상관과 적합 불확실성이 보고되지 않습니다(`03` §2).
3. 최적 손실은 같은 검증 세트에서 고른 학습 곡선의 최솟값입니다. 10k와 20k 곡선은 끝까지 감소하므로 "수렴 값"이 아니라 예산이 끝난 값입니다(`03` §2.8).
4. 사람 데이터 전처리(SLAM, 손 추정, 리타게팅)의 오차가 데이터 규모 효과와 어떻게 섞이는지 분석이 없습니다.
5. 재현 정보가 부족합니다(§2.3–2.4의 빠진 항목, 공개 코드와 데이터 없음).

## 6. 이 논문에서 가져갈 질문

- 사람 영상만으로 학습한 표현이 로봇 손 제어로 옮겨 가는 것은 설득력이 있습니다. 근거는 그림 4의 평균 격차(사전학습 없음 0.24 → 인간 0.71)와 그림 7의 G1 결과입니다.
- 스케일 법칙은 가능성 있는 관찰입니다. 5개 점과 최적화 기준의 문제가 있어서, 외삽(100k 시간)은 근거가 약합니다(`03` §3).
- 재현은 이 맥에서 불가능합니다. `04` §4에 구현 가능성 판단이 있습니다.
