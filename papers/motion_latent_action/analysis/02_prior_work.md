## 2. 가까운 대안

### 2.1 사람 영상을 쓰는 잠재 행동
- **DreamX** (저장소 `dreamx/`): 사전학습된 영상 확산 모델(Cosmos-Predict2.5 2B)에 질의를 붙여 잠재 프레임당 행동 토큰 4개를 뽑습니다. 이 토큰만으로 미래 영상을 재구성합니다. 이 논문과 **토큰 개수(4)와 "사람·로봇 공통 인터페이스"라는 목표가 같습니다.** 차이는 재구성 백본(확산 대 VQ-transformer)과 마스크 유무입니다. DreamX에는 마스크로 움직임을 분리하는 장치가 없습니다.
- **LAPA [9], IGOR [10]:** 사람 영상으로 잠재 행동을 학습하지만 마스크가 없습니다. 이 논문의 기준선(LAPA)입니다.
- **UniVLA [12]:** 사람 영상과 로봇 영상을 함께 쓰며, 언어 신호로 작업 중심 움직임을 고릅니다. 이 논문의 주된 비교 대상입니다(Table I, Table II, 실물).

### 2.2 논문이 인용하지 않은 가까운 연구
- **ThinkWorld** (저장소 `thinkworld/`): 사람·로봇 공유 손목 움직임 토큰을 쓰고, 1초 뒤 DINO 특징을 예측합니다. 이 논문과 "1초 간격 쌍"과 DINO 특징 예측이 비슷합니다. 인용되지 않았습니다.
- **FlashDexRetarget** (저장소 `flashdexretarget/`): 사람 손-물체 시연을 레퍼런스 조건부 RL 정책으로 로봇 손 궤적에 옮기는 연구입니다. 사람과 로봇을 궤적 수준에서 맞추는 방법이라서, 잠재 토큰을 공유하는 이 논문의 방식과 대비됩니다.

### 2.3 구성 요소별 출처

| 구성 요소 | 출처 | 이 논문의 새 점 |
|---|---|---|
| 이중 코드북 VQ, 쌍당 토큰 4 | LAPA [9]와 VQ 재구성 계열 | 행동 코드북과 배경 코드북을 분리 |
| 마스크 손실(전경·배경 경로) | SAM2 [19], RoboEngine [26] | 디코더 경로를 세 개로 나누고 영역별로 감독 |
| DINOv2 특징 | DINOv2 (코드 `dinov2_vitb14_reg`) | 미세조정에서 상태 인지를 DINO에 맡김 |
| VLM에 잠재 토큰 넣기 | UniVLA [12]의 어휘 확장 | 사람 영상으로 사전학습 |
| 의도-인지 분리 | 논문의 주장 | DINO와 VLM 임베딩을 바꿔 가며 절제 |

## 3. 이 저장소의 다른 논문과의 관계

| 폴더 | 공통점 | 차이와 시사점 |
|---|---|---|
| `dreamx/` | 사람 영상에서 잠재 행동 토큰 4개를 뽑고 사람·로봇 공통 인터페이스로 씀 | DreamX는 영상 확산 백본을 디코더로 쓰고, 이 논문은 VQ 재구성과 마스크를 씀. DreamX는 공개 코드가 없고, 이 논문은 있음. 두 논문 모두 **움직임과 배경을 어떻게 분리했는지** 직접 측정한 실험이 부족함 |
| `openwam/` | 행동 생성 설계 선택을 부품으로 쪼갬 | OpenWAM은 영상 생성 prior를 쓰고, 이 논문은 VLM에 잠재 토큰을 넣음. 둘 다 사전학습 데이터 규모가 재현의 장벽 |
| `agentic_wam/` | 행동과 미래 영상을 함께 다룸 | AW-0는 코드·미래 영상·행동을 Mixture-of-Transformers 하나에서 함께 denoise합니다. 이 논문은 잠재 행동 토큰만 VLM에 넣고 영상 생성은 하지 않습니다 |
| `pacevla/` | VLA의 action expert만 바꿈 | PaceVLA는 여러 decoder와 라우터. 이 논문은 action expert 입력에 DINO 특징과 VLM 의도를 함께 넣음 |
| `thinkworld/` | 1초 뒤 DINO 특징 예측 | ThinkWorld는 예측을 RL 보상으로 쓰고, 이 논문은 잠재 행동 학습에 씀. 이 논문의 "1초 간격 쌍"과 설계 근거를 비교할 수 있음 |
| `flashdexretarget/` | 사람 시연을 로봇 손으로 옮김 | 사람-로봇 연결 방식이 다름(이 논문은 잠재 토큰으로 연결) |
