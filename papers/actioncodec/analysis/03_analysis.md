# 03. 수치 재계산, 일관성 검사, 토이, 주장 판정

이 문서는 논문 표와 그림에 인쇄된 수치를 다시 계산하고(§1), 표와 본문 사이의 불일치를 모으고(§2, 항목 K), 작은 CPU 토이 하나로 중심 개념(OR과 재구성 오차의 절충)을 확인하고(§3, 항목 T), 본문 주장을 근거와 대조합니다(§4, 항목 C). 재계산은 `analysis/recompute.py`(결과 `recompute_results.json`), 토이는 `analysis/toy_or_tradeoff.py`(결과 `toy_or_tradeoff_results.json`)입니다. 항목 V는 재계산 번호입니다.

## 0. 가정

- LIBERO는 스위트당 10과제 × 50회 = 500회, 전체 2,000회입니다(부록 B.1, B.3). 시행이 독립이라고 보는 근사입니다. 같은 초기 상태 50개를 모든 모델이 쓰므로 실제 불확실성은 이보다 작을 수도, 학습 시드 변동을 합치면 클 수도 있습니다. 논문은 학습 시드 수를 적지 않았습니다(한 번의 학습으로 가정).
- 그림 3(LIBERO-Goal)과 그림 7(SO100)의 값은 PDF 그림에 인쇄된 숫자를 읽은 것입니다(그림 판독 값). 그림 3은 500회, 그림 7은 과제 10개 × 20회 = 200회(부록 B.1)로 가정합니다.
- 검정은 양측입니다. 비율은 Fisher 정확검정과 Newcombe 차이 구간(95%), 구간은 Wilson입니다.
- 표 1의 (a)(b) 행 중 다른 논문의 보고값을 인용한 칸은 시행 수를 알 수 없어 격자 검사 결과를 따로 적었습니다.

## 1. 재계산 결과

### 1.1 표 1의 평균과 평균 순위 (V1, V2)

- **행 평균(V1).** 4개 스위트 평균이 보고된 평균 열과 같은지 39행을 봤습니다. 37행이 일치합니다(반올림 허용). 일치하지 않는 두 행은 다음과 같습니다.
  - 표 1(c) VQVLA's: 네 칸의 평균은 59.4(= (60.5 + 56.0 + 69.8 + 51.4)/4)이고 보고된 평균은 60.5입니다. 보고된 평균은 Goal 칸의 값과 같고, 표 2의 SR 칸(60.5)도 같습니다(K1).
  - 표 1(b) π0.5(사전학습 없음): 네 칸 평균 93.55, 보고 93.3.
- **평균 순위(V2).** "Avg. Rank"는 네 스위트 열에서 모델별 순위를 매겨 평균한 값으로 재현됩니다. 결측('-')이 있는 행(VQ-VLA, MiniVLA의 (b) 행)은 순위 계산에서 빠집니다.
  - 표 1(a)는 패널 안에서 11행 모두 일치합니다.
  - **표 1(b)와 (c)는 두 패널을 한 풀로 합쳐서 순위를 매겨야 17행이 모두 일치합니다.** (c) 패널만으로 순위를 매기면 11행 중 1행만 맞습니다(예: Binning 보고 15.5, 패널 안 재계산 10.25). 캡션은 "relative performance across tasks"라고만 쓰고 순위를 매긴 범위를 적지 않습니다(K4).
  - 같은 모델이 풀에 따라 다른 값을 가집니다: ActionCodec(2.2B)는 (a)에서 5.1, (b)+(c)에서 3.8입니다. 다른 패널의 순위 값끼리 비교하면 안 됩니다.
  - 표 1(d)의 두 블록(Pt = Y 8행 + BAR, MiniVLA + BAR)은 각 블록 안에서 모든 순위가 재현됩니다(9/9, 2/2).

### 1.3 표 2: 효율 (V4)

- **처리량 = 지평선 / 지연.** 지연이 소수 첫째 자리로 반올림된 값이라고 보고 처리량의 가능 범위를 계산하면 8행 모두 보고 값(22.0, 13.1, 11.1, 7.7, …)이 범위 안에 있습니다. 예: ActionCodec 20/0.9 = 22.2(범위 21.0–23.5), FAST 20/1.5 = 13.3(범위 12.9–13.8).
- **토큰 예산.** Binning은 7차원 × 20스텝 = 140, × 8스텝 = 56으로 일치합니다.
- **SR 열.** Binning 53.4, String 49.6, VQVLA's 60.5, MiniVLA's 82.6, FAST 90.6, ActionCodec 95.5는 표 1(c)의 평균 열과 같습니다. Binning과 String은 T = 8 행입니다. T = 20 행(SR 3.5, 20.4)은 표 1에 없습니다.
- 지평선이 5, 8, 20으로 다르고 지연의 측정 조건(장비, 배치, 디코딩 방식)이 본문에 없습니다. 논문도 "matched-horizon 비교로 읽으면 안 된다"고 적습니다(부록 F.2).

### 1.6 그림 3과 표 5: 설계 원리 실험 (V7, V8, V9; 그림 판독 값, 500회 가정)

| 비교 (20k 스텝, LIBERO-Goal, 256M) | 차이 (pp) | Fisher p |
|---|---|---|
| OR 70% (86.2) 대 OR 40% (67.2) | +19.0 | 1.2e-12 |
| OR 70% 대 OR 26% (37.4) | +48.8 | 1.2e-59 |
| 500스텝: OR 70% (33.4) 대 OR 26% (8.2) | +25.2 | 1.4e-23 |
| 500스텝: OR 40% (12.4) 대 OR 26% (8.2) | +4.2 | 0.037 |
| n = 8 (73.4) 대 n = 16 (67.2) | +6.2 | 0.038 |
| S = 512 (77.0) 대 S = 2048 (67.2) | +9.8 | 7.0e-4 |

| OR 70% 대 FAST (52.0) | +34.2 | 1.5e-32 |

- **OR의 효과는 큽니다.** 이 크기의 차이는 한 번의 학습 오차로 설명하기 어렵습니다. 다만 OR을 올리는 개입(대조 손실의 세기)이 PPL(2016 → 1290)과 L1(0.020 → 0.028)도 함께 바꿉니다(표 5). OR, 토큰 사용 집중도, 재구성 충실도가 같이 움직이므로 "OR만의 효과"는 분리되지 않습니다. 논문 부록 E.1도 이 점을 적습니다.
- **n과 S 스윕에서 선택한 설정은 최고가 아닙니다.** 20k 스텝 성공률은 n = 8(73.4)이 n = 16(67.2)보다, S = 512(77.0)와 S = 1024(75.6)가 S = 2048(67.2)보다 높습니다(V7b). 그림 3의 L1은 S = 512에서 0.031, S = 1024에서 0.024, S = 2048에서 0.029로 S에 단조롭지 않습니다. 선택 근거는 재구성 오차와 FAST 어휘 크기(S = 2048, 부록 E.2)이고, 논문도 "고유한 최적이 아니다"라고 적습니다. 즉 이 스윕만으로는 (16, 2048)을 정당화하기 어렵고, 그 선택은 성공률이 아닌 다른 기준에 의존합니다.
- **독립 대 인과.** SA와 비교하면 독립이 확실히 높습니다. Causal과는 2.4포인트(p = 0.33)로 구분되지 않습니다. 그림 6(섞은 토큰 이후 오차)에도 오차 막대가 없습니다.
- **표 5와 그림 3의 일치.** 500스텝 성공률(8.2, 12.4, 33.4)과 L1(0.020, 0.029, 0.028)이 같습니다. PPL은 모두 상한 2048 이하이고, 엔트로피로 환산하면 7.61, 7.37, 7.16 nat입니다(ln 2048 = 7.62).
- **그림 1과 본문.** 5k 스텝 ActionCodec 89.5, FAST 38.6은 본문과 같습니다. 두 값의 차이는 구분됩니다(n = 2,000 가정, p는 극히 작음). 그림 1의 20k 스텝 점(95.5, 90.6)이 표 1의 최종 값과 같고, 부록 B.3은 30k 스텝까지 수렴을 관찰했다고 적습니다(그림 판독 값, K10).

### 1.7 SimplerEnv-WidowX 표 1(d) (V10)

- ActionCodec-BAR 칸은 과제당 120회(71.7 = 86/120, 64.2 = 77/120, 55.0 = 66/120, 70.0 = 84/120, 합 313/480 = 65.2%)와 일치합니다(부록 B.1).
- **한 표에 평가 횟수가 다른 값이 섞여 있습니다.** 정수 격자로 가능한 과제당 시행 수를 후보(24, 48, 50, 72, 96, 100, 120, 144, 240)에서 찾으면 다음과 같습니다.

| 행 | 가능한 시행 수 |
|---|---|
| ActionCodec-BAR, π0 | 120 (240) |
| SpatialVLA, OpenVLA-OFT, UniVLA | 24의 배수와 120 모두 가능 |
| Octo-Base | 72 (144). 24나 120으로는 Eggplant 43.1이 안 나옴 |
| OpenVLA, MiniVLA | 50 (100) |
| VQ-VLA | 후보에는 없고 200이면 가능 |
| π0 FAST | 후보에서 공통 시행 수 없음. 29.1, 10.8, 66.6은 7/24, 13/120, 2/3을 내림한 값처럼 보이고 21.9는 7/32의 반올림처럼 보임 |

  baseline 값은 다른 논문이나 다른 평가에서 가져왔을 가능성이 있고, 표에는 행마다 평가 조건이 적혀 있지 않습니다(K5). 부록 B.1은 "기본 24회를 120회로 늘렸다"고만 씁니다.
- **BAR 대 π0.** 평균 65.2 대 67.9(과제당 120회, 합 313 대 326/480)로 BAR가 낮고, 차이 −2.7 pp의 구간은 −8.6 ~ +3.3, Fisher p = 0.41입니다. 본문의 "keeps the best rank among models with or without prior robotic data"는 평균 순위 2.0이 π0와 같다는 뜻이고(둘 다 2.0), 평균 성공률은 π0가 높습니다(K6).
- **BAR 대 MiniVLA**(MiniVLA는 과제당 50회 가정, 합 98/200): 65.2 대 49.0, 차이 +16.2 pp(구간 8.1 ~ 24.2, p = 1e-4). 과제별로는 Spoon +3.7(p = 0.71), Carrot +20.2(p = 0.018), Block −15.0(MiniVLA가 높음, p = 0.087), Eggplant +56.0(p = 2e-11)입니다. 평균 격차의 대부분이 Eggplant 한 과제에서 나옵니다. 이 블록은 두 모델뿐이라 평균 순위 1.8 대 1.3은 이 비교 하나의 요약입니다.

### 1.8 xArm-PickVeg 표 3 (V11)

- 채소(과제) 수가 본문에 없습니다. 채소당 20회라고 쓰고 성공률 82.5, 74.1, 75.0, 72.5가 모두 정수 비율이 되려면 채소 수가 16, 22, 28, 32, … 중 하나여야 합니다(최소 16, 시행 320). 74.1이 가장 까다로운 칸입니다. 40회(2종)나 120회(6종) 같은 작은 수에서는 74.1이 나오지 않습니다.

### 1.9 SO100-ShapeSorter 그림 7 (V12, 그림 판독 값)

그림 7의 막대 위 숫자를 모아 합한 결과입니다(과제 10개 × 20회 = 200회).

| 모델 | Pick | Place | Place / Pick | 그림의 평균 막대 |

## 3. 토이 T1: OR과 재구성 오차의 절충

**목적.** OR(식 7)이 토큰 안정성의 대리 지표라는 점, 그리고 양자화 간격만으로도 OR이 오르고 재구성 오차도 같이 오른다는 점을 학습 없이 확인합니다. 논문 표 5도 OR 26% → 70%에서 L1이 0.020 → 0.028로 늘었다고 적습니다. 이 토이는 논문 수치를 재현하지 않으며, 학습된 VQ가 아니라 PCA 잠재 + 스칼라 양자화입니다.

**설정.** 7차원 매끄러운 합성 신호(가우시안 필터 폭 6과 12 스텝, 길이 20,000), 청크 T = 20, 보폭 1. PCA로 140차원 청크를 n개 성분으로 줄이고 성분마다 표준편차로 나눠 [−4, 4]를 S단계로 양자화합니다. 인접 청크의 같은 위치 토큰이 같은 비율이 OR입니다(식 7과 같은 정의). 약 10초, numpy.

**결과 (n = 16 토큰).**

| S | OR (필터 폭 6) | L1 | OR (필터 폭 12) | L1 |
|---|---|---|---|---|
| 16 | 0.784 | 0.0632 | 0.870 | 0.0435 |
| 64 | 0.376 | 0.0485 | 0.533 | 0.0178 |
| 256 | 0.105 | 0.0473 | 0.167 | 0.0143 |
| 1024 | 0.027 | 0.0473 | 0.042 | 0.0140 |
| 2048 | 0.013 | 0.0473 | 0.021 | 0.0140 |

- **OR은 S가 커질수록 단조롭게 감소하고 L1도 단조롭게 감소합니다**(두 필터 폭 모두). 즉 OR을 올리는 가장 쉬운 방법(거친 양자화)은 재구성 충실도를 잃습니다. n = 8, 32에서도 같은 방향입니다.
- **OR은 간격에서 예측됩니다.** 인접 청크의 잠재 변화 |Δz|와 간격 8/S로 계산한 예측 OR = mean(max(0, 1 − |Δz|/간격))이 측정값과 0.003 안에서 같습니다(예: S = 64, 필터 폭 6에서 0.376 대 0.376). OR은 "한 스텝에 잠재가 얼마나 움직이는가 대 양자화 간격"의 함수입니다.
- **한 데이터에서 읽어야 하는 지표입니다.** 같은 토크나이저 계열(Binning 1,000구간)의 OR이 이 합성 신호에서는 2.3~4.3%이고 논문 표 2의 LIBERO에서는 39%입니다. 신호가 얼마나 느리게 변하는지(그리고 정지한 차원이 얼마나 많은지)에 OR이 의존하므로 다른 데이터의 OR을 비교하면 안 됩니다.
- **한계.** 학습된 VQ, 대조 손실, VLA 학습은 이 토이에 없습니다. 이 토이는 "OR이 높아지면 VLA가 빨리 배운다"(논문의 중심 주장)를 확인하지 않습니다. 확인한 것은 OR을 단독 지표로 쓰면 안 되고 재구성 오차와 함께 봐야 한다는 점뿐이며, 논문도 같은 점(부록 E.1, 표 5)을 적고 있습니다.
