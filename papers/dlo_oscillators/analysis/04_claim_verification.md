# 04. 주장 대조 (공식 코드 없음): C1–C12, 구현 가능성, 라이선스

이 논문에는 공식 코드가 없습니다(01 §0, 02 §1). 그래서 논문과 코드를 대조하는 대신 **주장과 근거를 대조**했습니다. 판정 기준은 다음과 같습니다.

- **맞음:** 수치 재계산이나 증명 검토로 확인.
- **부분:** 맞지만 범위나 표본에 한계가 있음.
- **미검증:** 논문에 근거가 없거나, 있어도 수치로 제시되지 않음.
- **불일치:** 논문 내부 수치가 서로 맞지 않음.

## 2. 증명 검토 (C7)

- **Prop. 1 (부록 E.1).** 에너지 V = ½ż ᵀMż + U(z) − U(z*)의 미분이 −ż ᵀDż로 떨어지는 식 (12)는 맞습니다. U의 형상 방향 Hessian이 K_r + diag(sech²) ⪰ K_r ≻ 0인 식 (13)도 맞습니다. 기준점 방향 운동은 식 (14)–(15)의 적분으로 정리되고, 극한 식 (16)은 z_b → D_bb⁻¹(c_b − D_br z*_r)입니다. 원문 20쪽을 렌더링해 괄호까지 확인했습니다. 텍스트 추출에서 괄호가 깨져 보였을 뿐 식은 맞습니다.
- **Prop. 2 (부록 E.2).** 아핀 가역 사상으로 전달하는 논법입니다. 식 (17)–(18)의 V̇_x = −ẋᵀD_xẋ는 식 (7)과 맞습니다. 다만 α 스케일의 역할이 본문에 설명되지 않습니다(01 §3).
- **Prop. 3 (부록 E.3).** 식 (19)의 Lyapunov 함수, 식 (21)의 Hessian 하한, 식 (22)의 V̇ 전개를 확인했습니다. 강볼록 W와 LaSalle 논법이 성립합니다. 핵심 전제는 (i) 가정 2, g_u(x_d) = 0, (ii) 실제 시스템이 학습 모형과 같다는 것입니다. 논문은 (ii)를 명시적으로 한정합니다(4절 마지막 문단).
- **종합.** 증명 흐름은 타당합니다. 논문의 "closed-loop stability guarantees"는 학습 모형 기준으로 읽어야 합니다. 실제 케이블 위에서의 안정성은 보장이 아니라 가설입니다.

## 4. 구현 가능성 판정

**판정: 시뮬레이션 수준 재구현은 이 맥에서 조건부로 가능하고, 실로봇 검증은 이 맥에서 불가능합니다.**

| 수준 | 이 맥(M4 Pro, 24 GiB, MPS, CUDA 없음)에서 | 근거와 조건 |
|---|---|---|
| 논문 수치 재계산 (03) | **가능, 완료** | 수 초 |
| 제어 증명의 수치 확인 (toy) | **가능, 이번에는 실행하지 않음** | 가상의 작은 체인에서 수렴을 확인할 수 있음 (수 분, numpy). 요청 시 진행 |
| 시뮬 재구현: MuJoCo DER 시뮬 생성, FBCON·Φ-CON 학습, PD+FF 제어, 표 1·2 재현 | **조건부** | 모형이 2만 파라미터 안팎이라 CPU나 MPS 학습이 가능할 가능성이 큼. 학습 시간은 측정 전입니다(5000 에폭 × 설정 4 × 시드 5). 이번 분석에서는 torch와 mujoco 환경을 쓰지 않았고, 사용 전 버전 확인이 필요합니다 |
| 공식 코드 실행 | **해당 없음** | 코드가 없습니다 |
| 실로봇 (Franka 2대, Bota 센서, OptiTrack 5대, 임피던스 제어) | **불가** | 장비가 없습니다 |

**구현에서 빠진 세부 사항.** 논문만으로는 재구현 결과가 같다고 보장할 수 없습니다.

1. τ̄와 α를 어떤 데이터 구간으로 정하는지(A.4는 "training data"라고만 씀).
2. M_w, D_w, K_r을 어떻게 양의정부호로 파라미터화하는지(Cholesky 등). 논문은 "constant, symmetric positive definite"라고만 씀.
3. 파라미터 수가 표 4와 9N 차이가 나는 원인(C12).
4. 정상상태 샘플 선택(A.3)과 λ_ss의 최종 값을 정하는 Pareto 선택 기준(A.4).
5. 시뮬 DER 설정(MuJoCo 플러그인 파라미터, 감쇠, 마찰 등)과 PyRoki 필터 조건.
6. 실제 케이블의 마커 배치와 파지 방향 고정 세부(A.5는 식별값만 제시).
7. 임피던스 제어기의 질량 가정(03 V10, 암묵적 1 kg).

**노력 추정 (측정 전):** 시뮬 재구현 1–2주. 실로봇을 포함한 재현은 이 맥에서 할 수 없습니다.

## 5. 한계 요약 (재현 설계에 필요한 것)

- 실제 DLO 실험의 목표 수가 적고(76 + 4), 4개 미관측 목표는 개별 값을 보고하지 않습니다(C5).
- 시뮬 기준선이 적분 항 없는 PD라서, 감소율을 학습 구조의 효과로 읽기 어렵습니다(C6).
- 실제 예측 결과는 그림만 있습니다(C9).
- 시드 5개(A.3)는 모형 학습 설정으로 적혀 있습니다. 실제 제어 결과(표 본문)가 시드 간 분산인지 목표 간 분산인지는 구분되어 있지 않습니다.
