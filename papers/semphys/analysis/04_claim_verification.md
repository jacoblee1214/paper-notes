추가 확인 항목 (주장이라기보다 설계 사실):

- **C12 (설계):** 그래디언트는 창과 마지막 두 DDIM 단계를 지나고, 나머지 생성기 파라미터와 제어기, 매처는 고정입니다(식 9, 14, §3.3, §3.2). 본문과 식이 일치합니다. 학습되는 것은 투영 헤드 I뿐입니다(식 17). 이 제한이 성능 상한을 정하는지는 실험하지 않았습니다.
- **C13 (설계):** 창 밖 접미부는 stop-gradient입니다(식 11). 주장 C6의 "순서 문맥"과 이 설계 사이에는 긴장이 있습니다. 창 끝 이후의 효과가 점수에 반영되지 않기 때문입니다. 본문은 이를 한계로 적지 않았습니다. 재생 검사 C7이 짧은 스텝만 확인한 것도 이 때문입니다.

## 4. 구현 가능성 판정

**판정: 논문 수치의 재현은 이 맥(Apple M4 Pro, 약 24 GiB 통합 메모리, MPS, CUDA 없음)에서 불가능합니다. 방법의 핵심 아이디어(창 기반 미분 + 쌍 앵커)는 작은 모델에서 CPU나 MPS로 구현해 볼 수 있습니다. 구현 노력은 1–2주(추정, 측정 전)입니다.**

### 4.1 이 맥에서 불가능한 것

| 항목 | 이유 |
|---|---|
| 논문 표 1의 전체 재현 | 공식 코드 없음. DiT 생성기의 사전학습("paired text–motion data"), LLM 이벤트 계획 생성, GloVe 매처 학습, 제어기(SuperMimic 스타일)를 모두 새로 만들어야 함 |
| BONES-SEED 평가 | 데이터 미다운로드(요청 범위 밖, 승인 필요). 처리본 여부와 라이선스 미확인 |
| 적응 학습 (3 에폭, 84,287 레코드, 시드 여러 개) | MuJoCo 롤아웃과 DiT 투영 헤드 갱신을 반복. GPU 전제(추정, 측정 전) |
| 실로봇 G1 | 하드웨어 없음 |
| 16개 교란과 부록 표 | 부록 없음 |

### 4.2 이 맥에서 가능한 것 (조건부)

| 항목 | 조건 | 노력 (추정) |
|---|---|---|
| 창 기반 서로게이트 그래디언트를 **작은 생성기**(소형 MLP 또는 흐름 생성기)와 **작은 동역학 시스템**(2-링크 또는 점 질량 접촉)에서 구현, 쌍 앵커 포함 | torch(MPS 또는 CPU). 새 설치 승인 필요. 공식 코드 없이 재구현 | 1–2주 |
| 같은 toy에서 "창 밖 접미부 고정"과 "창 밖까지 재시뮬레이션"을 비교 (C13 검증) | 위와 같음 | 1주 추가 |
| 소형 G1 MuJoCo CPU 환경에서 추적 제어기와 서로게이트 학습 | G1 자산 다운로드 승인, 제어기 학습 (CPU 수 시간–수일, 측정 전) | 4–8주 |

### 4.3 판단 근거

- 논문의 실험 규모(BONES-SEED 13,302 클립, 84,287 레코드, 여러 시드, 기준선 8개)는 공식 코드 없이 맥에서 재현하기에는 큽니다.
- 그러나 방법의 "주장 검증"은 소형 실험으로도 할 수 있습니다. 가장 가치 있는 것은 C6–C7의 메커니즘(창 밖 효과)과 C5의 평균 효과(시드를 늘려 검정력 확보)입니다.
