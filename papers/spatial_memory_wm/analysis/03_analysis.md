# 03. 재계산, 일관성 검사, 주장 판정

재현은 하지 않았습니다. 학습과 추론을 돌리지 않고, 논문이 적은 평균과 시험 수만으로 다시 계산했습니다 (`recompute.py`, 수 초, 표준 라이브러리만 사용). 토이 실험은 만들지 않았습니다. 이 논문의 핵심 주장(공간 기억이 재방문 일관성을 높인다)은 확산 생성 모델이 있어야 시험할 수 있어서, 2차원 토이로는 주장과 직접 닿지 않기 때문입니다.

## 1. 재계산 결과

스크립트: `analysis/recompute.py` → `analysis/recompute_results.json`. 그림: `analysis/plot_figures.py`.

### 1.1 사용자 연구 (표 1 오른쪽)

원자료(개별 순위)가 없어서 분산은 모릅니다. 대신 범위 [1,4]에서 평균이 m이면 분산은 최대 (m−1)(4−m)이라는 상계를 씁니다. 이 상계로 보수적인 검정을 했습니다.

- **V1 순위 합 검사.** 4개 방법의 평균 순위 합은 세 기준 모두 **10.0000**입니다. 피험자가 네 결과를 1–4로 한 번씩 매긴 것과 맞습니다 (K0: 표 값이 순위 기반임을 확인).
- **V3 검정.** 제안 방법과 각 기준선의 차이를 두 가정으로 봤습니다.
  - 평가 단위 독립 (n = 20명 × 14사례 = 280): 분산에 상계를 썼으므로 표준오차는 넉넉하게 잡힙니다. 다만 독립 가정 자체는 같은 피험자와 사례가 묶여 있다는 점에서 낙관적입니다.
  - 피험자 단위 군집 (n = 20): 같은 피험자의 판단은 서로 묶여 있으므로, 실제 정보량은 이쪽에 가깝습니다. 보수적인 기준입니다.

| 기준 | 비교 | 차이 | 피험자 단위 z 하한 | 두 쪽 p 상한 |
|---|---|---|---|---|
| Cam-Acc | 대 DaS | 1.06 | 2.64 | 0.008 |
| Cam-Acc | 대 Wan2.1 | 1.45 | 3.67 | 0.0002 |
| Cam-Acc | 대 TrajectoryCrafter | 1.99 | 5.66 | 1e-8 |
| Stat-Cons | 대 DaS | 0.95 | 2.19 | 0.028 |
| Stat-Cons | 대 Wan2.1 | 0.99 | 2.30 | 0.022 |
| Stat-Cons | 대 TrajectoryCrafter | 1.60 | 4.01 | 6e-5 |
| Dyn-Plaus | 대 DaS | 0.70 | **1.63** | **0.102** |
| Dyn-Plaus | 대 Wan2.1 | 1.13 | 2.65 | 0.008 |
| Dyn-Plaus | 대 TrajectoryCrafter | 1.78 | 4.64 | 3e-6 |

독립 가정(n = 280)에서는 모든 비교가 p < 10^-8 수준입니다. 피험자 단위로 보면 **Dyn-Plaus의 대 DaS 비교만 5% 수준에서 유의하지 않습니다.** 논문의 "모든 지표에서 큰 차이로 앞섬" (§4.3)은 방향은 맞지만, 가장 가까운 기준선과의 동적 타당성 차이는 피험자 수 기준으로는 확실하지 않습니다.

그림: `report/figures/own_ahr_bounds.png` (피험자 단위 95% 구간 상한).

### 1.2 뷰 리콜 (표 1 왼쪽)

- V2 상대 개선: 가장 좋은 기준선 대비 PSNR **+6.94 dB** (Wan2.1 12.16 → 19.10), SSIM **+43.4%** (DaS 0.4512 → 0.6471), LPIPS **−47.8%** (DaS 0.5874 → 0.3069).
- 신뢰구간과 검정은 **계산할 수 없습니다.** 샘플별 분산이 없습니다. 시험 수는 본문에 "500개 테스트 시퀀스"로만 적혀 있고, 뷰 리콜 쌍이 몇 개인지는 적혀 있지 않습니다.
- 차이의 크기는 커서 방향 판단에는 충분해 보입니다. 다만 같은 조건에서 여러 시드로 반복한 값이 없으므로 "안정적이다"는 말은 못 합니다.

그림: `report/figures/own_view_recall.png` (구간 없음).

## 3. 주장 판정 (C1–C11)

판정: **지지** = 표와 본문이 맞고 통계 정보로도 방향이 확실, **방향만 지지** = 방향은 맞으나 통계 근거가 약함, **미검증** = 본문과 표에 근거가 없음.

| 번호 | 주장 (논문 위치) | 근거 | 판정 |
|---|---|---|---|
| C1 | 재방문 뷰 일관성이 기준선보다 좋다 (§4.1, Table 1) | PSNR, SSIM, LPIPS 모두 큰 차이 (V2). 분산 없음 | **방향만 지지** (차이는 크지만 반복 실험이 없음) |
| C2 | 사용자 연구에서 세 기준 모두 큰 차이로 앞섬 (§4.3) | 독립 가정에서는 모두 p < 10^-8. 피험자 단위 보수 기준에서 **대 DaS Dyn-Plaus는 p = 0.10** (V3) | **지지** (대부분), **예외 1건** |
| C3 | VBench에서 미적 품질, 시간적 깜빡임, 움직임 평활도, 주체 일관성이 좋다 (§4.1, Table 2) | 방향은 맞음. 주체 일관성 차이 0.0002 (V4) | **방향만 지지** (차이 대부분 0.01 미만, 검정 불가) |
| C4 | 배경 일관성과 Imaging은 Wan2.1이 더 낫다 (§4.1) | Table 2 그대로 | **지지** (본문이 정직하게 밝힘, K2) |
| C5 | 작업 기억과 에피소드 기억 각각이 품질을 높인다 (§4.4) | Table 3에서 두 제거 모두 전체보다 낮음 | **방향만 지지** (검정 없음) |
| C6 | **공간 기억**이 재방문 일관성을 높인다 (§1, §4) | 공간 기억 제거 조건 없음. 기준선 비교로만 간접 주장 | **미검증** (가장 중요한 빈칸, `01` §5.1) |
| C7 | 문맥 길이가 늘어난다 (초록, §5) | 측정 없음 | **미검증** (`01` §5.2) |
| C8 | 생성 중 복원기(CUT3R)와 데이터 구축 복원기(MegaSaM)의 차이는 "큰 차이가 없다" (부록 B) | 수치 없음 | **미검증** |

## 4. 이 검토가 말하지 못하는 것

- 평균과 시험 수만으로 계산한 검정입니다. 실제 샘플별 분산을 알면 결과가 달라질 수 있습니다.
- 피험자 단위 보수 검정도 피험자 간 분산 상계 (m−1)(4−m)을 씁니다. 실제 분산이 더 작으면 Dyn-Plaus 판정은 바뀔 수 있습니다.
- 표 2와 표 3은 평균만 있어서 검정하지 못했습니다. 차이 크기만 보고했습니다.
