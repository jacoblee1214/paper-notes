# 04. 주장 검증과 구현 가능성

공식 코드를 찾지 못했으므로 `04_code_verification.md`(논문과 코드 대조) 대신 이 문서를 씁니다. 주장 라벨 C1–C14는 이 문서 안에서만 씁니다.

## 1. 코드와 자료 검색 (2026-11-22)

| 경로 | 결과 |
|---|---|
| arXiv abs와 HTML (v1) | 코드 링크, 프로젝트 링크 없음. HTML에 GitHub 링크는 arXiv 자체 HTML 도구 링크와 wuji-retargeting(벤더 구현)뿐 |
| 프로젝트 페이지 https://fruitrabbit.github.io/WinDEX/ | 코드, 데이터, 가중치 링크 없음. 연구 영상과 논문 링크만 있음 |
| GitHub 저장소 검색 ("WinDEX", "WinDEX-Net", "CyberCap") | 관련 저장소 없음. 이름이 같은 무관한 프로젝트만 나옴 |

따라서 `repo/` 클론은 하지 않았습니다. 이 논문에 공식 코드가 없다고 판단하고, 재현 가능 여부는 논문 설명만으로 판정합니다.

**라이선스.** arXiv abs의 "view license" 링크는 `http://arxiv.org/licenses/nonexclusive-distrib/1.0/`입니다. 이것은 CC BY 4.0이 아니며, arXiv의 비독점 배포 허가입니다. 따라서 공개 산출물에 논문 그림을 싣지 않습니다. 원문 PDF의 본문과 첫·끝 쪽에는 저작권 표시나 회사 고지가 없습니다(`pdftotext` 확인).

**학회.** CoRL 2026 공식 채택 목록(`conferences/corl2026/papers.json`의 공식 목록 항목)에 WinDEX와 저자 이름(Peng Yin, Hongyu Ma)이 없습니다. 웹 검색에서도 학회 채택 표기가 없습니다. 따라서 `학회 표기 없음 (arXiv)`으로 둡니다.

## 3. 검증하지 못한 항목

1. 표 II, III, IV가 같은 평가 집합인지 (V1). 표 II 값과 표 IV 행이 같다는 점이 가장 큰 문제입니다.
2. 그림 5(크롭 효과)와 그림 10(재투영 기준선)의 수치는 그림에서 읽어야 하는데, 텍스트 추출로는 값이 없습니다. 그림 자체를 렌더링해 읽는 작업은 하지 않았습니다. 논문 그림을 공개 산출물에 쓸 수 없고, 개인용으로도 이 분석에 필요하지 않았습니다.
3. Hand2Policy의 물체별, 손별 성공 횟수. 그림 12에서 읽어야 합니다.
4. 실로봇 정책과 원격 조작의 정량 결과.

## 4. 구현 가능성 판정

**판정: 이 맥(Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)에서 논문 방법의 전체 재현은 불가능합니다. 다만 평가 지표 재계산과 작은 검사는 가능하며, 이번 분석에서 끝냈습니다.**

| 단계 | 필요 자원 | 이 맥 | 판정 |
|---|---|---|---|
| WinDEX-Net 학습 (VGGT-Omega, 식 17) | 4장 RTX 4090 (논문 §VII.A), 1,000시간 주석 데이터 | 불가 | 불가 (GPU, 데이터 비공개) |
| WinDEX-Window 학습 (DINOv3 교사 특징 증류 후 미세조정) | GPU, 교사 특징 캐시 | 불가 | 불가 |
| WinDEX-Stream 학습 | GPU, Window 교사 출력 | 불가 | 불가 |
| 추론 (Window, Stream) | 가중치 (미공개), RTX 4090 FP16 (논문 속도) | 가중치 없음 | 불가 (공개 전까지) |
| 기하-시간 라벨링 파이프라인 (MANO 피팅, 재투영 필터) | MANO 모델, 2D 키포인트, 스테레오 보정, 장치 기록 | 가능하지만 장치 데이터 없음. MANO 라이선스 확인 필요 | 조건부 (데이터와 MANO 승인 후) |
| 표 재계산과 검정 | 논문 수치 | 가능 | 완료 (`analysis/recompute.py`) |
| 필터 임계값과 선택 편향 모의 실험 | numpy | 가능 | 후보 |
| 실로봇 정책과 원격 조작 | Wuji 손, Inspire 손, 로봇 팔 | 불가 | 불가 |

**노력 추정(측정 없음).** 공개 코드가 나오지 않는다고 가정하면, 논문 설명만으로 WinDEX-Net을 다시 만드는 일은 2–4주 규모의 구현 작업에 GPU 학습 수 일이 더해집니다. 이 맥에서 학습은 불가능합니다. 데이터 장치(CyberCap 또는 동등한 스테레오 IMU)가 없으면 라벨링도 불가입니다.

**권장.** 이 논문은 재현 대상이 아니라 **평가 설계와 수치 검토의 사례**로 쓰는 것이 맞습니다. 재현은 사용자 확인 후에만 시작합니다(`CLAUDE.md`).
