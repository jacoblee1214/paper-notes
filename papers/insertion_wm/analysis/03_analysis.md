# 03. 수치 재계산, 유도, toy 검증

재현 코드는 `analysis/table_check.py`(→ `table_check_results.json`), `analysis/insertion_toy.py`(→ `insertion_toy_results.json`)에 있습니다. 둘 다 CPU, numpy·scipy, 단일 스레드입니다. toy는 약 73초 걸립니다. 논문에 없는 값은 가정으로 표시했습니다.

## 0. 요약

- 헤드라인 "56% 대 7%"는 **통계적으로는 확실**합니다. 56%(1000회)의 Wilson 95% 구간은 [52.9, 59.1]%입니다. 그러나 **객체 단위**로 보면 10개 객체의 평균이므로 구간은 약 ±15–19pp로 넓어집니다(§2). 비교 대상 7%는 학습 규모가 다른 점에서 나왔고, 시도 수도 밝혀지지 않았습니다(§1).
- 특수 모델 79.78 대 70.31%는 객체 쌍별 차이의 SD를 모르면 검정할 수 없습니다. 가정 SD 10–30pp에서 p는 10⁻³보다 작습니다(§3).
- 절제 실험의 차이(커리큘럼 +2.4pp, 시연 +2.0pp)는 시드 수가 밝혀지지 않아 판단할 수 없습니다. 시도 단위 검정은 과신입니다(§4).
- 미세조정은 1053, 1129, 1079, 1102에서 30k 스텝 시점 차이가 큽니다. 1036과 1041은 시작점부터 높아서 차이가 작고, 1132는 두 방법 모두 실패합니다(§5).
- 계획 비용은 모델 호출 약 9,300회/스텝, 약 15–93 GFLOP/스텝으로 추정됩니다. 기본 설정을 가정한 값입니다(§6).
- toy: 모델 오차가 **간극의 절반(c/2) 이상**이면, 모델이 간극을 좁게 본 에피소드가 모두 실패합니다. 샘플 수(16–256)는 성공률을 바꾸지 않았습니다. 이 toy에서는 **모델 없는 kNN 정책이 모든 미지 기하에서 더 좋았습니다**(§8). 이것은 toy 설계(오라클 시연, 접촉 규칙, 관측)에 따른 결과입니다.

## 1. 헤드라인 비교 (T1, `table_check.py`)

| 항목 | 값 | 근거 |
|---|---|---|
| 우리, 미지 10개 × 100회 | 560/1000 = 56.0%, Wilson 95% [52.9, 59.1] | 본문 VI-A(시도 수), Fig. 1 |
| AutoMate 미지 7% | 시도 수 불명. 100회 가정 → [3.4, 13.8]%, 1000회 가정 → [5.6, 8.8]% | Fig. 1 |
| Fisher 검정 (우리 대 AutoMate) | p = 1.9×10⁻²³ (n=100 가정), p = 1.1×10⁻¹³⁴ (n=1000 가정) | 이항 근사 |

**해석.** 시도 단위 검정은 의미가 있습니다. 그러나 이 검정은 "같은 조건"의 차이를 보지 않습니다. 세 가지가 달라서 비교가 불균형합니다.

1. **학습 규모.** Fig. 1 오른쪽 패널에서 AutoMate 7%는 학습 객체 약 15–25개 부근의 점 하나입니다. 우리 모델은 같은 부근(15개)에서 약 40%입니다(Fig. 1). 90개 대 15–25개에서 나온 값을 나란히 놓은 것입니다.
2. **입력.** AutoMate 생성 정책은 CAD 점군 임베딩을 입력으로 받습니다(VI-A). 우리 정책은 깊이와 고유감각을 받고, 고유감각에는 잡음 섞인 소켓 자세가 들어갑니다.
3. **분할.** AutoMate 측의 분할은 알 수 없다고 저자들이 씁니다(VI-B). 같은 10개로 평가했는지 모릅니다.

Fig. 1을 눈으로 읽어 같은 x 위치에서 비교하면 40% 대 7%입니다. 그래도 차이는 크지만, 헤드라인의 56% 대 7%보다는 작습니다. 이 값은 읽은 값이므로 ±2pp 정도 오차가 있습니다.

**재계산 확인.** 특수 모델 평균(79.78%)과 그 생성 모델 값(55.0%, 54.5%)은 Fig. 5와 Fig. 7에서 맞습니다. 55.0%(본문)와 54.5%(Fig. 7)가 다른 것은 반올림이나 평가 시점 차이로 보이지만 확인되지 않았습니다.

## 2. 객체 단위 불확실성 (T7)

미지 객체 10개의 평균 56%에서 객체 간 SD를 가정하면 다음과 같습니다.

| 객체 간 SD(가정) | 평균의 SE | 95% 구간 |
|---|---|---|
| 20pp | 6.3pp | [43.6, 68.4]% |
| 25pp | 7.9pp | [40.5, 71.5]% |
| 30pp | 9.5pp | [37.4, 74.6]% |

가정 근거: Fig. 6의 0스텝(미세조정 시작점)을 눈으로 읽은 값(1036 ≈ 0.95, 1053 ≈ 0.02, 1132 ≈ 0.0, 나머지 0.55–0.85)의 SD는 0.33입니다. 이 값도 눈으로 읽은 것이라 대략적입니다. 그래서 구간의 하한이 40% 근처라는 것, 즉 7%보다 훨씬 위라는 결론은 유지됩니다. 그러나 **"56%는 ±3pp 정확도로 알려졌다"는 해석은 틀립니다.**

Fig. 6의 0스텝 값 평균은 0.597입니다(§5). 본문 56%와 대략 같은 수준입니다.

## 3. 특수 모델 79.78% 대 AutoMate 70.31% (T3)

- 차이: 9.47pp (100개 객체, 객체당 5 seed × 100회).
- 쌍 설계(같은 객체에서 두 방법을 비교)이므로 검정에는 객체별 차이의 SD가 필요합니다. 논문에는 없습니다. Fig. 5 막대 높이로는 추정할 수 없습니다.

| 객체별 차이 SD(가정) | SE | z | p (정규 근사) |
|---|---|---|---|
| 10pp | 1.0 | 9.5 | < 10⁻¹⁰ |
| 15pp | 1.5 | 6.3 | 2.7×10⁻¹⁰ |
| 20pp | 2.0 | 4.7 | 2.2×10⁻⁶ |
| 30pp | 3.0 | 3.2 | 1.6×10⁻³ |

시도 단위로 계산하면 구간이 ±0.6pp로 나오지만, 객체를 단위로 두지 않은 과신입니다. 결론: 평균 차이 9.5pp는 가정 SD 30pp까지 유의합니다. 그러나 AutoMate의 특수 모델 수치가 **재측정이 아니라면**(VI-B 각주는 "재현 수치를 저자가 확인했다"고 씁니다) 같은 조건인지는 확인되지 않았습니다.

## 4. 절제 실험 (T4, Fig. 7)

막대 값만 쓸 수 있습니다. 시드 수와 시드별 분산은 없습니다.

| 비교 | 차이 | 근사 p(시도 단위, 시드 무시) | 해석 |
|---|---|---|---|
| 생성: 고유감각만 39.6 → 깊이(기본) 54.5 | +14.9pp | 2×10⁻⁸⁹ | 시각 효과는 크고 안정적으로 보임. 시드 분산이 14pp보다 작다고 보기 어려운 이유는 없음 |
| 생성: 깊이(기본) 54.5 → 대체 카메라 46.4 | −8.1pp | 3×10⁻²⁰ | 카메라 위치 효과. 시드 1개면 확인 필요 |
| 생성: 커리큘럼 없음 52.1 → 기본 54.5 | +2.4pp | 0.0013 | 시드 분산보다 작을 수 있음. "consistently"는 과장 |
| 생성: 커리큘럼 없음 52.1 → 시연 100개 56.5 | +4.4pp | 3×10⁻⁹ | 저자는 "marginal"이라고 씀 |
| 특수: 고유감각만 55.2 → 깊이 79.8 | +24.6pp | 0 | 특수 모델에서 시각 효과 매우 큼 |
| 특수: 커리큘럼 없음 76.2 → 기본 79.8 | +3.6pp | 6×10⁻⁴³ | 5 seed 평균이면 SE를 알아야 함 |

Holm 보정(8개 비교, 시도 단위 근사)은 모든 p를 그대로 두거나 키울 뿐입니다. 시드 분산을 넣으면 결론이 달라질 수 있습니다. 따라서 **시각 효과(특수와 생성 모두)는 방향이 안정적이고, 커리큘럼 효과(2–4pp)는 확인되지 않았습니다.**

## 5. 미세조정 (Fig. 6, T5)

- x축은 0–30k 환경 스텝입니다. 처음부터 학습의 2M 스텝 값은 점선으로만 있습니다. 즉 **데이터 효율**은 30k 스텝 시점의 곡선을 비교해야 확인됩니다.
- 객체별 시작점(0스텝, 눈으로 읽음 ±0.1): 1036 0.95, 1041 0.80, 1053 0.02, 1079 0.65, 1092 0.75, 1102 0.55, 1125 0.60, 1129 0.85, 1132 0.00, 1136 0.80. 평균 0.597.
- 30k 시점 차이가 큰 객체(눈으로 읽음, 처음부터 대 미세조정): 1053(≈0.05 대 ≈0.5), 1129(≈0.6 대 ≈0.95), 1079(≈0.7 대 ≈0.9), 1102(≈0.6 대 ≈0.75). 1092와 1136은 차이가 작습니다.
- 1132: 처음부터 2M 기준선 0.25, 미세조정 30k에서 약 0.05. **두 방법 모두 실패**에 가깝습니다. 얇은 판 형태라 깊이 영상이 잘 안 보이는 것으로 보이지만 논문은 이 원인을 확인하지 않았습니다.
- 본문의 "exceeds the asymptotic performance(1036, 1041)"는 2M 기준선과 비교한 것입니다. 1036은 미세조정 ≈0.9–0.95, 기준선 ≈0.85이고, 1041은 두 곡선이 겹칩니다. 차이가 작아 우연일 수 있습니다.

## 6. 계획 계산량 추정 (T6)

논문에는 샘플 수와 호라이즌이 없습니다. TD-MPC2 저장소의 기본 설정(`332f19e`: 호라이즌 3, 샘플 512, 반복 6, 정책 궤적 24)을 가정합니다.

- 제어 주기당 모델 호출 수 = 반복 × 샘플 × 호라이즌 + 정책 궤적 × 호라이즌 = 6 × 512 × 3 + 24 × 3 = **9,288회**.
- FLOPs ≈ 2 × (호출당 MLP 파라미터) × 호출 수. 호출당 파라미터가 0.8M(잠재 전이 d로 가정)이면 약 **15 GFLOP/스텝**, 전체 5M을 매번 쓴다고 보면 상한 **93 GFLOP/스텝**입니다. CNN 인코더와 가치 앙상블(5개)은 제외했으므로 실제는 더 큽니다.
- 시간 추정: 이 맥의 GPU 유효 처리량을 1–5 TFLOPS로 가정하면 3–90 ms/스텝입니다. 공개 사양 근사이고 MPS 실측은 하지 않았습니다. 제어 주기(논문에 없음)가 정해지면 판정할 수 있습니다.
- 학습 비용: 생성 모델 7M 스텝, RTX 3090 3일(VI-A). 스텝을 전체 합으로 세는지 환경당으로 세는지 논문에 없어 스텝당 시간은 계산하지 않습니다.

## 7. 세계 모델 목적 함수 (식 2–4) 해석

식 2는 λ 가중 합입니다. 단계 손실(식 3)은 보상의 two-hot 교차엔트로피, 가치의 교차엔트로피, 그리고 잠재 예측 손실(식 4)입니다. 식 4의 stop-gradient 대상은 목표 인코더 출력 h(s′)입니다. 따라서 **학습 신호는 잠재 공간의 일치와 보상·가치에서만 옵니다.** 픽셀 재구성 손실이 없으므로, 이 세계 모델은 "깊이 영상에서 무엇이 보이는지"를 직접 학습하지 않습니다. 소켓 위치와 간극은 보상과 가치를 통해서만 간접적으로 들어갑니다. 이 점이 "깊이 영상으로 기하를 추론한다"는 저자 설명과 어떻게 맞는지는 논문이 보여주지 않았습니다.

## 8. toy 실험 (`insertion_toy.py`)

**설계 (요약, 자세한 내용은 스크립트 설명).**
- 2D 점 peg(반지름 0.5), 깊이 2, 간극 c(슬롯 폭 = 2r + c). 벽에 막히면 그 스텝은 움직이지 않습니다(마찰 없음).
- 관측: 슬롯 중심 ĥ(잡음 0.01). 간극은 관측하지 않습니다.
- 계획자: MPPI, 호라이즌 8, 반복 2, 샘플 N. 모델은 벽 반폭에 δ 오차를 가지며, 부호는 에피소드마다 무작위입니다.
- 모델 없는 정책: 학습 간극 {0.2, 0.4, 0.6}에서 참 모델 MPPI 시연 약 6,500개로 학습한 kNN(k=10, 특징 (ĥ−x, −D−y)).
- 셀당 150 에피소드, 셀마다 고정 시드. 여러 번 다시 돌린 결과 셀 값은 ±10회 정도 흔들렸지만, 아래 결론의 방향은 바뀌지 않았습니다.

**결과 (마지막 실행).**

| 실험 | 조건 | 성공 |
|---|---|---|
| 모델 오차 δ | c = 0.1, N = 128 | δ=0: 150/150, δ=0.02: 150/150, δ=0.05: 71/150, δ=0.1: 77/150 |
| 부호별 (δ=0.05) | 모델이 간극을 넓게 봄 / 좁게 봄 | 72/72 대 0/78 |
| 부호별 (δ=0.1) | 같음 | 78/78 대 0/72 |
| 간극 c | δ = 0.05, N = 128 | c=0.05: 74/150, c=0.1: 74/150, c=0.2: 150/150, c=0.4: 150/150 |
| 샘플 수 N | δ = 0.05, c = 0.05 | N=16: 73/150, N=64: 72/150, N=256: 76/150 |
| 모델 없는 정책 | 학습 간극 0.2, 0.4 | 150/150, 150/150 |
| 모델 없는 정책 | 미지 간극 0.05, 0.1, 0.15 | 150/150 each |
| 모델 없는 정책 | 미지 오프셋 |h| ≤ 0.6 (학습 0.3) | 150/150 |
| 같은 미지 조건 비교 | 계획자(δ=0.05) 대 kNN | 간극 0.05: 85 대 150 (p = 7×10⁻²⁴), 간극 0.1: 77 대 150 (p = 2×10⁻²⁷), 오프셋: 65 대 150 (p = 2×10⁻³³) |

**해석.**
1. **실패는 "모델이 간극을 좁게 본" 절반에서 나옵니다.** 이 경우 모델의 자유 횡방향 범위 c/2 − δ가 0 이하가 되어 모델은 중앙 정렬조차 불가능하다고 판단합니다. 그래서 계획자는 전진하지 않습니다. 반대로 간극을 넓게 본 절반은 모두 성공합니다. 그 이유는 toy 규칙 때문일 수 있습니다(벽에 막히면 멈추고 관측 잡음이 섞이므로 무작위로 빠져나옴). 실제 접촉에서는 다르게 나올 수 있습니다.
2. **임계는 δ ≈ c/2입니다.** c = 0.1에서 δ = 0.02는 통과, δ = 0.05부터 실패합니다. c = 0.2에서 δ = 0.05는 통과합니다. 이는 "모델 정확도는 간극의 절반보다 작아야 한다"는 설계 규칙으로 읽을 수 있습니다.
3. **샘플 수는 모델 편향을 고치지 못합니다.** N을 16에서 256으로 늘려도 성공률은 약 50%로 같습니다. 샘플을 늘리면 모델 오차를 더 정확히 따라가는 것이지 오차를 줄이는 것은 아닙니다. 이 결과는 정책 최적화에서 흔한 "과대 최적화" 효과와 맞지만, toy에서만 확인됐습니다.
4. **모델 없는 kNN이 이겼습니다.** 이 toy의 기준선은 오라클 시연을 그대로 모방하는데, 시연은 간극에 관계없이 "정렬 후 하강"이라는 같은 행동 규칙을 씁니다. 그래서 간극이 줄어도 정책이 맞습니다. 이 결과는 **논문의 대비(7%)를 재현하지 않습니다.** 논문의 기준선은 AutoMate PPO로, 그리고 CAD 조건이 있는 증류 정책이라 이 toy 기준선과 다릅니다. 이 toy는 "모델 기반이 모델 없는 것보다 낫다"는 주장이 **기준선의 강도와 관측 설계**에 달려 있다는 점을 보여 줍니다.

**한계.** 점 peg, 운동학적 이동, 벽 접촉 규칙이 단순합니다. 학습된 모델을 쓰지 않고 δ를 주입했습니다. 깊이 영상과 소켓 잡음을 모델링하지 않았습니다. 따라서 "학습된 세계 모델의 오차가 얼마인가"에 대한 답은 주지 않습니다.

## 9. 유도: MPPI 업데이트 (TD-MPC2 참조)

샘플 행동 시퀀스 U_k ~ N(μ, σ²)에 대해 비용 J_k를 구하고, 가중치 w_k ∝ exp(−(J_k − min J)/λ)로 μ를 갱신합니다. toy와 TD-MPC2 모두 이 형태입니다. 여기서 온도 λ가 작으면 최적 샘플에 집중하므로, 모델 오차를 더 강하게 따릅니다. 이 논문은 λ를 보고하지 않아 민감도를 확인할 수 없습니다.
