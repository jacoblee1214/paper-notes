## 1. 공식성과 범위

- README 제목, 저자 목록(Bianco, Ren, Xing, Scaramuzza)과 BibTeX가 논문과 같습니다. 논문 초록의 코드 링크와 같은 주소입니다.
- 기반 코드는 `rpg_flightning`(Heeg 외, ICRA 2025, GPL-3.0)이고, README가 이를 밝힙니다. JAX 기반의 PureJaxRL과 gymnax 코드(Apache-2.0)를 일부 씁니다(NOTICE).
- **포함된 것:** 틈 환경 4개(정적·움직임 × 상태·시각), BPTT와 PPO, 평가 스크립트, 학습 설정, 학습 로그 CSV, 저충실도 쿼드로터 모델.
- **없는 것:** 하이-피델리티 시뮬레이터(Table 2의 81%), 실물 인식과 비행 코드, 5시드 실행 스크립트(`train_all.sh`는 시드마다 반복하지 않음), 논문 그림 생성 스크립트, 데이터셋(없음, 시뮬레이션), 시각 특징 추출의 실물 버전.

**추가 관찰 (D29–D31).**

- **D29. 기본 계산 설정이 논문과 다른 곳.** `static_gap_state_env.py` 기본 인자는 dt = 0.02, max_steps = 300, 지연 0.04이고, 학습 스크립트가 dt = 1/60, 2.5 s, 지연 0.035를 넘겨 줍니다(`create_env`). 기본값으로 실행하면 논문 설정이 나오지 않으므로, 재현에는 학습 스크립트의 값을 써야 합니다.
- **D30. 충돌 셋업과 제어 주파수.** 드론 반축 `drone_Q = diag(a, a, c)`는 `static_gap_state_env.py` 106행에 있고, 평가와 학습이 같은 Q를 씁니다. 틈의 크기는 `gap_dims = [0.80, 0.25]`(폭 × 높이)로 논문 Fig. 2와 맞습니다.
- **D31. 시각 관측의 지각 지연.** `delay = 0`(`moving_gap_vision_env.py` 339행)으로 고정하고, 무작위 지연은 주석 처리되어 있습니다. A.9의 "지각–구동 지연"은 행동 쪽에만 있고, 시각 관측에는 지연이 없습니다.

## 4. 구현 가능성 (이 맥 기준)

**이 맥의 조건:** Apple M4 Pro, 약 24 GiB 통합 메모리, MPS 사용 가능, CUDA 없음. torch 2.15와 mujoco 4.0은 이 맥에 설치되어 있습니다. JAX와 Flax는 설치되어 있지 않습니다.

**판정: 논문 결과의 재현은 이 맥에서 불가능합니다. 알고리즘의 재구현과 소형 검증은 가능합니다.**

| 항목 | 판정 | 이유 | 추정 공수 |
|---|---|---|---|
| 공식 코드 실행 (JAX GPU, 학습 파이프라인) | **불가** | JAX GPU 가속은 Linux 전용. 맥에서는 CPU JAX만 가능 (README). 학습은 CUDA GPU 전제 | - |
