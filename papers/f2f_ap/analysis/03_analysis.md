# 03. 수치 재계산, 일관성 검사, 토이, 주장 판정

재계산은 `analysis/recompute.py`(numpy, scipy, statsmodels, 수 초)이고 결과는 `analysis/recompute_results.json`입니다. 토이는 `analysis/toy_latency_intercept.py`(numpy, 약 2초)입니다. 항목 번호는 V(재계산), K(내부 일관성), T(토이), C(주장 판정)입니다. 표 수치는 논문 v4 표 1, 2에서 옮겼고, v1/v2 값은 PDF 그림에서 읽었습니다. 공식 학습·평가 코드는 실행하지 않았습니다.

## 1. 표 1 재계산

### 1.1 V1–V2. 성공률, Wilson 구간, 과제별 Fisher 검정

각 칸은 성공 횟수 / 시도 수입니다. 양측 Fisher 정확 검정, F2F-AP 대 각 기준선입니다(그래프: `report/figures/own_table1_ci.png`).

| 과제 | F2F-AP | 대 Syn. UMI | 대 Asyn. UMI | 대 RTC | 대 VLASH |
|---|---|---|---|---|---|
| Hammer | 15/20 (75%) | 5/20, p = 0.004 | 7/20, p = 0.025 | 12/20, p = 0.50 | 6/20, p = 0.010 |
| Banana | 13/20 (65%) | 5/20, p = 0.025 | 10/20, p = 0.52 | 12/20, p = 1.0 | 13/20, p = 1.0 |
| Carrot | 6/10 (60%) | 3/10, p = 0.37 | 5/10, p = 1.0 | 6/20, p = 0.14 | 3/10, p = 0.37 |
| Pull-Back Car | 8/20 (40%) | 0/20, p = 0.003 | 1/20, p = 0.020 | 0/20, p = 0.003 | 3/20, p = 0.16 |
| Chip Can | 9/20 (45%) | 3/20, p = 0.082 | 2/20, p = 0.031 | 3/20, p = 0.082 | 1/20, p = 0.008 |
| Bottle | 11/20 (55%) | 2/20, p = 0.006 | 2/20, p = 0.006 | 3/20, p = 0.019 | 2/20, p = 0.006 |
| Length Meas. | 7/10 (70%) | 4/10, p = 0.37 | 5/10, p = 0.65 | 5/20, p = 0.045 | 3/10, p = 0.18 |

- 28개 비교 중 **14개가 p < 0.05**입니다. 28개 전체에 Holm을 적용하면 **0개**가 남고(최소 보정 p = 0.092), 기준선별 7개 과제에 Holm을 적용하면 6개가 남습니다(Syn. UMI의 Hammer, Pull-Back Car, Bottle 각 0.023–0.029, Asyn. UMI와 VLASH의 Bottle 0.040, RTC의 Pull-Back Car 0.023).
- 과제 단위로 F2F-AP가 **구분되게 앞서는 상대**는 Pull-Back Car(0/20 두 기준선), Bottle(모든 기준선 p ≤ 0.019)입니다. **구분되지 않는 상대**는 Banana(VLASH와 같음, RTC와 1/20 차이), Hammer의 RTC(15/20 대 12/20, p = 0.50), Carrot·Length의 대부분입니다.
- Wilson 95% 구간은 폭이 약 ±20 %p입니다(예: 15/20 → 53–89%, 8/20 → 22–61%). 시도 수 10인 칸은 ±25 %p를 넘습니다.

### 1.2 V3. 과제를 층으로 합친 비교

과제를 층으로 한 Mantel-Haenszel(연속성 보정) 합산입니다. 층별 성공 확률이 비슷하다는 Breslow-Day 검정은 모든 비교에서 기각되지 않습니다(p = 0.21–0.72).

| F2F-AP 대 | 합산 오즈비 (95% 구간) | MH p | 단순 합산 성공률 (참고) |
|---|---|---|---|
| Syn. UMI | 6.9 (3.7–12.9) | 5.6e-10 | 22/120 = 18.3% |
| Asyn. UMI | 4.3 (2.4–7.7) | 1.1e-6 | 32/120 = 26.7% |
| RTC | 3.8 (2.2–6.7) | 3.1e-6 | 41/140 = 29.3% |
| VLASH | 4.3 (2.4–7.8) | 5.9e-7 | 31/120 = 25.8% |
| **F2F-AP** | - | - | **69/120 = 57.5%** (Wilson 48.6–66.0%) |

- **결론:** 한 과제 안에서는 구분이 약한 칸이 많지만, 7개 과제를 합치면 F2F-AP가 모든 기준선보다 분명히 높습니다(오즈비 3.8–6.9). 방향 일관성도 있습니다(F2F-AP가 7개 과제 모두에서 최고이거나 공동 최고).
- **주의:** 과제 간 독립 시행 가정이고, 모델은 방법·과제당 한 번 학습한 결과로 보여 학습 시드 변동은 반영되지 않습니다. 사람이 물체를 던지거나 건네는 시도들이 방법 사이에서 짝지어졌는지(같은 시도 조건) 보고되지 않았습니다. 이 불확실성은 구간을 더 넓힙니다.
- 단순 합산 성공률은 분모가 방법마다 다르므로(RTC 140, 나머지 120) 참고용입니다.

### 1.4 V5. 실행 시간 (ET)

ET는 **성공한 시도의 평균**이고 분산이나 시도별 값이 없어 검정할 수 없습니다. 비율만 계산했습니다(F2F-AP 대 기준선, 같은 과제).

| 대 | F2F-AP가 더 짧음 | 더 김 | 같음 | 비율 범위 |
|---|---|---|---|---|
| Syn. UMI | 6/6 | 0 | 0 | 0.57–0.86 |
| Asyn. UMI | 6/7 | 1 (Pull-Back Car 1.79배, 1.4 s는 성공 1회 기준) | 0 | 0.55–0.87 (Pull-Back 제외) |
| RTC | 5/6 | 1 (Banana 1.04배) | 0 | 0.80–0.90 |
| VLASH | 0/7 | **6** (1.03–1.36배) | 1 (Banana) | 1.03–1.36 |

- 본문의 "UMI보다 확연히 짧다"는 맞습니다. "VLASH·RTC와 비슷하다"는 RTC보다는 약간 짧고 **VLASH보다는 6개 과제에서 길다**는 뜻입니다.
- **생존 편향:** ET는 성공만 평균합니다. F2F-AP는 VLASH가 실패하는 더 어려운 시도(Chip Can 9/20 대 1/20)에서도 성공하므로 어려운 시도의 긴 시간이 평균에 섞입니다. 성공 수가 다른 평균끼리의 비교라서 효율 비교로는 약합니다(Pull-Back Car의 Asyn. UMI ET 1.4 s는 성공 1회 값).

- "대조 학습·미래 상태·히트맵 중 하나를 빼면 성능이 떨어진다"(§4.3)는 **세 가지 중 미래 상태만** 20회 시도로 확인됩니다. 대조 손실을 뺀 8/20과 가중치를 낮춘 7/20은 전체 11/20과 구분되지 않습니다(p = 0.53, 0.34). 20회 시도 검정으로 11/20 대 8/20를 80% 검정력으로 구분하려면 한 군당 약 170회가 필요합니다(정규 근사, V9와 같은 가정).
- v1/v2의 해머 절제(15/20 기준)에서는 대조 손실 제거 10/20(p = 0.19), 낮은 가중치 8/20(p = 0.054), 히트맵 제거 6/20(p = 0.010), 낮은 추론 빈도 4/20(p = 0.0012)이었습니다. 해머에서는 히트맵이 구분되고 병에서는 구분되지 않습니다. 과제에 따라 결론이 달라질 수 있습니다.
- "MF-UMI 1/20"은 F2F-AP와 구분되지만(p = 0.001) 같은 표의 Asyn. UMI 2/20과는 구분되지 않습니다. 이력 프레임 6개를 단순 적층한 것이 도움이 안 된다는 증거이고, F2F 흐름 대신 속도 정보를 다른 방식으로 준 경우의 비교는 아닙니다.

### 2.2 지연 추세 (V6)

300/500/600 ms의 성공은 12, 10, 4/20이고, 전체 모델(총 지연 375 ms 가정)은 11/20입니다. 지연 순서(300, 375, 500, 600)로 한 Cochran-Armitage 추세 검정은 z = −2.52, p = 0.012이고, 600 ms 대 300 ms는 Fisher p = 0.022입니다. "지연이 매우 클 때만 크게 떨어진다"는 방향은 맞지만, 조건이 무엇인지 정의되지 않아 해석이 약합니다(K7).

## 3. 지연 산술, 버전 변화, 검정력

### 3.1 V7. H와 추론 주기

- Δtotal = 0.125 + 0.200 + 0.050(상한) = 0.375 s, H = ⌈0.375/0.1⌉ = 4. Δc가 0이어도 ⌈0.325/0.1⌉ = 4이므로 4는 0.3 < Δtotal ≤ 0.4 구간에서 성립하는 값입니다.
- 표 2의 300/500/600 ms는 각각 H = 3, 5, 6에 해당하지만, 어떤 H로 학습·추론했는지 쓰지 않았습니다. H를 4로 두고 지연만 늘렸다면 이 실험은 "H 불일치에 대한 강건성"이고, H를 맞췄다면 "지연 크기에 대한 강건성"입니다(K7).
- 추론 주파수 5 Hz = 주기 200 ms = Δi입니다(부록 D.2). 공식 코드의 F2F·VLASH 평가 설정은 4스텝(0.4 s, 2.5 Hz)이고 기준선은 2스텝(0.2 s, 5 Hz)입니다(`04` D4).
- Pull-Back Car의 "유효 파지 5 cm, 평균 25 cm/s" → 창 0.2 s로, 본문 "0.4 s 미만"과 모순은 아니지만 총 지연 0.375 s가 창의 약 2배입니다. 지연 없이 이 과제를 잡으려면 예측이 필수라는 논지는 이 산술이 지지합니다.

### 3.2 V8. v1/v2 대 v4

- 같은 설정에서 값이 바뀐 칸: Banana-VLASH 7/20 → 13/20, Carrot-VLASH ET 1.7 → 1.4 s, Pull-Back Car-F2F ET 2.3 → 2.5 s, Length-Asyn. UMI 3/10 → 5/10. 사유는 기재되어 있지 않습니다.
- **Banana에서 F2F-AP 대 VLASH:** v1/v2의 13/20 대 7/20은 Fisher p = 0.11, v4의 13/20 대 13/20은 p = 1.0입니다. 어느 쪽이든 구분되지 않지만, v4에서는 VLASH가 F2F-AP와 같습니다.
- **지연 실험이 정확히 두 배:** v1 6/10, 5/10, 2/10(ET 7.4, 8.5, 11.2 s) → v4 12/20, 10/20, 4/20(ET 7.5, 8.5, 11.2 s). 20회를 독립 재실험했다면 세 칸 모두 성공 수가 정확히 두 배일 확률은 0.0069(이항 확률 곱, 각 칸 성공률은 v1 값 가정)입니다. 8.5, 11.2 s도 동일합니다. 같은 시도를 두 번 센 것인지, 처음 10회와 같은 비율을 새 10회가 재현한 것인지 알 수 없습니다. 분모 10이 맞다면 구간은 훨씬 넓어집니다(예: 600 ms 2/10 → 6–51%). **저자에게 확인이 필요한 항목입니다.**

### 3.3 V9. 검정력

참 성공률이 75%와 60%일 때 Fisher 양측 5% 검정으로 구분될 확률(모의 1,500회): n = 20 → **0.11**, 40 → 0.20, 80 → 0.44, 160 → 0.79. 과제별로 10–20회 시도에서는 15 %p 차이를 거의 구분하지 못합니다. 앞의 1.1절에서 구분되는 칸은 차이가 35 %p 이상인 칸입니다.

## 5. 토이 T1: 지연 아래의 1차원 포획 (`analysis/toy_latency_intercept.py`)

**목적:** 논문의 핵심 가설 "지연만큼 앞선 물체 위치를 예측해 행동에 쓰면 낡은 관측 문제가 줄어든다"에서 물체 운동 보상 부분만, 가장 단순한 형태로 시험합니다(학습 없음). **이것은 논문 실험의 재현이 아닙니다.**

**설정:** 물체 x(t) = 0.3 + v t, v ~ U(0.1, 0.4) m/s, 시각 t_c ∈ [0.4, 1.0]에서 속도가 dv만큼 바뀜(비선형 구간). 5 Hz로 영상 한 장을 쓰고 행동 덩어리는 총 지연 L = 0.375 s 뒤 반영되며 행동은 절대 시각표를 가집니다. 정책 세 가지: **stale**(마지막 관측 위치 유지), **flow**(6프레임 선형 적합 속도로 외삽, 예측 흐름의 최소 모형), **oracle**(실제 위치). T_g = 1.2 s에 그리퍼가 닫히고 오차 3 cm 이하이면 성공입니다. 셀당 6,000회, 관측 잡음 기본 1 cm, 시드 고정, 약 2초(그래프: `report/figures/own_toy_latency.png`).

| 조건 | 낡은 관측 유지 | 흐름 외삽 | 오라클 |
|---|---|---|---|
| 속도 0.1–0.2 / 0.2–0.3 / 0.3–0.4 m/s | 0.1 / 0 / 0 % | 95.9 / 95.3 / 94.1 % | 100 % |
| 속도 변화 σ = 0 / 0.05 / 0.1 / 0.2 / 0.3 m/s | 0 / 2 / 7 / 12 / 12 % | 95 / 82 / 60 / 35 / 24 % | 100 / 100 / 100 / 100 / 99.6 % |
| 총 지연 L = 0.2 / 0.3 / 0.375 / 0.5 / 0.6 / 0.8 s | 0.9 / 0.7 / 0 / 0 / 0 / 0 % | 95 / 92 / 95 / 74 / 47 / 3 % | 100 % |
| 지연 지터 σ = 0 / 0.05 / 0.1 / 0.2 s | 0 / 0.2 / 0.4 / 2.6 % | 95 / 90 / 87 / 84 % | 100 % |
| 관측 잡음 σ = 0.5 / 1 / 2 / 4 cm | 0 / 0 / 0.5 / 2.5 % | 99.98 / 95 / 69 / 38 % | 100 % |

**읽는 법과 한계:**
- **낡은 관측만 쓰면 실패합니다.** 총 지연 0.375 s에서 물체가 0.1–0.4 m/s로 움직이면 낡은 위치와 현재 위치가 3.8–15 cm 어긋나, 3 cm 창에 못 들어옵니다(논문의 핵심 동기와 같은 방향).
- **외삽 보상은 등속이 성립하는 동안 잘 작동하고, 속도가 바뀌면 급격히 무너집니다.** 외삽 거리는 영상 시각에서 T_g까지(L에 최대 한 주기 0.2 s가 더해짐)입니다. 속도 변화 σ = 0.2 m/s에서 95%가 35%로, L = 0.6 s에서 47%, 0.8 s에서 3%로 떨어집니다. 논문 표 2의 600 ms 열화(4/20)와 같은 방향이고, "병의 비선형 궤적"이 어려운 과제로 남는 이유와도 맞습니다. 다만 이 토이는 단순 외삽이라, 학습된 예측기의 정확한 열화 곡선을 재현한다는 의미는 아닙니다.
- **관측 잡음에 민감합니다**: 6프레임 선형 적합의 속도 오차가 지연 외삽 거리에 곱해집니다. 논문은 흐름 예측 정확도를 보고하지 않으므로 이 민감도는 확인되지 않은 부분입니다.
- **지연 지터**는 영상이 반영되는 시각을 바꿔 외삽 거리를 흔들며 성공이 95% → 84%로 줄었습니다. 논문 한계 1(지연 변동)에 대응합니다. 단, 행동이 절대 시각표를 가져 H와 실제 지연의 어긋남 자체는 이 토이에서 영향이 없습니다(학습·추론 분포 이동은 모형화하지 않음).
- **시험하지 못한 것:** (i) 로봇 상태는 정확히 안다고 가정해서 VLASH식 상태 굴림과 단순 비동기의 차이는 구분되지 않습니다. (ii) stale은 속도를 읽지 않는 약한 기준이라, 다중 프레임에서 속도를 스스로 읽는 정책과의 비교(MF-UMI 유사)는 없습니다. 흐름을 영상에 "그리는" 표현이 채널 입력보다 나은지도 시험하지 않았습니다. (iii) 속도 변화 분포, 잡음, 파지 반경은 가정입니다. 한 시드입니다.
- 총 지연이 0.2 → 0.375 s에서 외삽 성공이 단조 감소하지 않는 것(95 → 92 → 95%)은 L이 주기 0.2 s의 배수에 가까울 때 마지막으로 반영된 영상이 T_g에 가장 가까워지기 때문입니다(L mod 0.2에 의존하는 위상 효과).
