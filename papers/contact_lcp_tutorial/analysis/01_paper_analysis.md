## 1. 한 줄 요약

접촉 역학을 **상보성(complementarity)** 으로 쓰는 여러 표현(정확한 표현 다섯 개, 볼록 완화 두 개)을 한 표기법으로 정리하고, 각 표현이 **물리적으로 무엇을 바꾸는지**(들림, 크리프, 정적 마찰 상실, 힘의 비유일성)와 **어떤 솔버가 맞는지**를 비교한 튜토리얼입니다. 새로운 알고리즘이나 실험 결과는 없습니다.

## 3. 핵심 방법 (논문이 세운 틀)

### 3.1 기본 관점

접촉 법칙은 두 가지 현상학적 요구로 정해집니다. 침투하지 않는다(비관통)와 마찰로 에너지를 소산한다(최대 소산). 이 둘을 **원뿔 상보성**으로 쓰면 접촉 모드(떨어짐, 붙음, 미끄럼)가 미리 정해지지 않고 해에서 나옵니다(§3.4).

### 3.2 정확 표현 (Signorini–Coulomb → N-CCP → C-QCQP / C-QP / 근 찾기)

- **Signorini–Coulomb (39):** 법선 상보성, 마찰 한계 상보성, 최대 소산 방향. 이것이 출발점입니다.
- **N-CCP (40)–(43):** 세 조건을 한 식 `K ∋ f ⊥ (v⁺ + Γ(v⁺) + γ) ∈ K*`로 묶습니다. Γ(v⁺) = μ‖v_t⁺‖n̂이 de Saxcé 항이고, 이것이 미끄럼 때 법선 속도를 열어 줍니다.
- **근 찾기 (44):** SOCFB 잔차 = 0. 뉴턴 계열로 풀 수 있습니다.
- **C-QCQP (46)–(54):** 접선 방향을 고정하는 보조 변수 σ를 넣고, 원뿔 QP의 연쇄로 씁니다. 고정점에서 정확 해가 됩니다.
- **C-QP (55):** 법선과 접선 크기를 각각 상자 QP 둘로 나눕니다. 두 QP는 쿨롱 상한으로 묶입니다.

다섯 표현은 같은 해집합을 줍니다(논문 §4.1, §6.1). 차이는 계산 구조입니다.

### 3.3 볼록 완화와 정규화

- **L-CCP / QCQP (56)–(57):** Γ를 빼면 볼록 문제가 됩니다. 논문은 이를 "대부분의 시뮬레이터가 쓰는 방식"으로 설명합니다. 대가는 **미끄럼 접촉의 들림**입니다(§6.2).
- **정규화 (58)–(59):** `G → G + R`. 강볼록이 되어 힘이 유일해지지만 **정적 마찰이 사라집니다**(§6.2, 펜 예).
- **NLS (60)–(61):** 힘을 원뿔 투영으로 바꾸어 가속도 공간의 제약 없는 강볼록 문제로 씁니다. MuJoCo와 Drake가 쓰는 형식입니다. 역동역학 해석(§4.3.1)과 운동에너지 해석(§4.3.2)이 붙습니다.

### 3.4 해법 (§5)

- 완화 문제: PGS(접촉마다 투영), PGD, ADMM, 내점법, 뉴턴, Moreau–Jean.
- 정확 문제: 전체 원뿔 PGS, 분리 PGS(법선과 접선을 따로 투영), Alart–Curnier 뉴턴, Fischer–Burmeister 뉴턴, 엇갈린 상자 QP, 근접 최소화.
- 제안된 "근접 블루프린트"(Alg. 14): 볼록 완화 솔버를 안쪽 루프로 쓰고, 바깥 루프에서 de Saxcé 항과 근접항을 갱신합니다. 고정점이 정확 해입니다. 논문은 이것이 정확 표현과 빠른 볼록 솔버 사이의 간격을 메운다고 주장합니다.

### 3.5 비교 (§6)

- **표 1 (존재·유일성):** 정확 표현은 존재가 "엄격한 실현 가능성" 가정 아래서만 보장되고, 운동과 힘이 일반적으로 유일하지 않습니다. 완화 QCQP는 G가 가역일 때 힘이 유일합니다. 정규화는 힘과 운동이 항상 유일하지만 정적 마찰이 없습니다. LCP는 항상 해가 있고 힘은 일반적으로 유일하지 않습니다. 물리적 인공물은 각각 미끄럼 들림, 접촉 크리프와 정적 마찰 상실, 이방성 마찰입니다.
- **표 2 (알고리즘):** 1차 방법(PGS, PGD)은 반복당 비용이 싸지만 질량비에 약합니다. 뉴턴과 내점법은 반복이 적지만 반복당 선형계를 풉니다. 힘 공간과 가속도 공간의 크기 비교(3N 대 n_v)도 있습니다.
- **표 3:** 시뮬레이터별(Bullet, ODE, RaiSim, Siconos, MuJoCo, Drake, PhysX, MJX, MuJoCo Warp, Kamino 등) 변환과 알고리즘, 실행 장치.

## 4. 주장과 증거

이 논문은 실험을 하지 않습니다. 주장의 근거는 (a) 유도, (b) 문헌 인용, (c) 표의 정성적 분류입니다. 주장별 검증 결과는 `03_derivations.md`(수치 토이)와 `04_claim_verification.md`(주장별 판정)에 있습니다. 요약하면 다음과 같습니다.

- **식의 동치 주장 (§4.1):** 대수적으로 확인 가능한 부분은 맞습니다. 원뿔 투영, SOCFB, 자코비안, NLS와 정규화 QCQP의 동치, 운동에너지 항등식이 모두 수치로 확인됩니다(V1, V2, V6, V7).
- **완화의 물리적 인공물 (§6.2):** 들림(V4), 정적 마찰 상실(V5), 피라미드 이방성(V3)이 토이에서 확인됩니다.
- **정규화가 "최소 노름 해를 고른다"(§6.1):** 극한에서만 맞고 유한 R에서는 다릅니다(V10).
- **네 모서리 상자의 비유일성 (§6.1):** "합만 유일"이라는 문장은 랭크 계산과 맞지 않습니다(V9).
- **알고리즘 상충과 시뮬레이터 분류 (§6.3–6.5, 표 2–3):** 정성적 주장입니다. 이 맥에서 측정하지 않았고, 공식 코드와 대조할 수 없었습니다.

## 5. 한계와 빈틈

1. **실험 없음.** 어떤 시뮬레이터에서도 주장을 벤치마크하지 않습니다. 표 2, 3의 성능 서술은 문헌에 기댑니다.
2. **v1 단일 판본.** 정정 이력이 없습니다.
3. **공식 코드 없음.** 튜토리얼 자체의 코드나 노트북, 프로젝트 페이지를 찾지 못했습니다. 논문이 가리키는 구현(MuJoCo, Simple, Newton, Kamino, PhysX, Bullet, Drake)은 모두 별도 프로젝트입니다.
4. **§6.1 두 문장의 엄밀성.** "합만 유일"(V9)과 "최소 노름을 고른다"(V10)는 강한 표현입니다.
5. **2D 예시 부족.** 그림 1, 2, 6–9는 기하 설명이고, 수치 예(계산된 궤적)가 없습니다. 따라서 독자는 식을 따라가며 직접 검산해야 합니다.
6. **MuJoCo 해석 주장의 근거.** 각주 7(a_ref와 γ의 관계)은 대수로 맞지만, MuJoCo 코드와 대조하지는 않았습니다.
7. **시간 진행 방식의 범위.** 논문은 심플렉틱 오일러 이산화만 씁니다. 충돌 사건 기반 방법, 연속 시간 이론(Painlevé 예, Appendix B)은 역사적 설명으로만 다룹니다.
