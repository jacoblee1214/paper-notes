## 1. 한 문단 요약

WAM(world action model)은 사전학습된 비디오 확산 트랜스포머의 파라미터를 가져다 쓰면서 2B에서 14B 규모가 됩니다. LoopedWAM은 Wan2.1-T2V-1.3B에서 시작해, 두 전문가(비디오, 행동) 각각이 **12개 블록만 저장하고 가운데 6블록 코어를 4번 되풀이**해 30층을 실행합니다(§3.2). 비디오 전문가는 질의마다 한 번만 돌고 행동 전문가는 샘플링 스텝마다 돌기 때문에, 두 전문가의 되풀이 횟수를 따로 정합니다(§3.3). 그리고 **엘라스틱 자기증류(elastic self-distillation)**로 행동 루프 수 Ka∈{1,2,4}와 스텝 수 N∈{2,5,10}의 아홉 설정을 한 체크포인트(LoopedWAM-E)에 넣습니다(§3.5). 0.58B 파라미터, 로봇 사전학습 없음으로 LIBERO 96.1%, RoboTwin 2.0 91.9%, RoboCasa-GR1 52.2%를 보고합니다. 피크 GPU 메모리는 Fast-WAM의 1/7.4입니다(표 4).

## 2. 문제 설정 (§1, §3.1)

- 입력: 현재 카메라 영상(프레임 x0), 고유수용 상태 s, 언어 지시 ℓ. 출력: H=32 행동 청크(첫 Hx개 실행).
- Fast-WAM[63]의 설정을 따름. 테스트 시 미래 영상을 상상하지 않고, 학습 때만 미래 프레임을 공동 학습에 씀. 한 질의는 비디오 전문가 1회 + 행동 전문가 N회 순전파 (§3.1).
- 지연은 "실행된 블록 수"에 비례하고 파라미터 수에는 덜 비례한다는 관찰이 설계의 근거 (§1, 그림 3c).
- 목적함수: 플로우 매칭 식 (1). 가중치 w(τ)는 본문에 구체값 없음 (`04` D-항목 참조).

## 3. 방법

### 3.1 전문가 구성
- 비디오 전문가: 폭 1536, FFN 6144 (원래 8960에서 축소), 12 헤드 × 128. 행동 전문가: 폭 512 (별도 투영, FFN, 변조). 두 전문가는 층마다 하나의 공동 셀프 어텐션을 공유 (MoT[36]).
- 저장 블록 12개 = 프렐루드 3 + 코어 6 + 코다 3. K=4 루프로 실행 30층 (식 (2)).
- 파라미터: 비디오 479.2M + 행동 105.3M = **584.5M** (표 본문 §4.1, 합계 확인 `03` V5).

### 3.2 루프 전문가 (식 (2))
- h(0) = P(u), h(k) = C h(k−1), y = E h(K). 루프 간 입력 주입, 루프 인덱스 임베딩, 외부 잔차를 **넣지 않음** (§3.2 마지막 문장).

### 3.3 비디오와 행동 루프 분리 (식 (3), (4))
- 비디오 Kv, 행동 Ka를 따로 둠. 행동 루프 r은 비디오 루프 σ(r) = max(1, Kv−Ka+r)의 키·값을 같은 블록 위치에서 읽음 (늦은 정렬, late alignment). Ka=1이어도 가장 깊은 비디오 특징을 읽음.
- 지연 모델: T ≈ T0 + L(Kv)·tv + N·L(Ka)·ta (식 (4)). 비디오 깊이는 질의당 한 번, 행동 깊이는 N번 값을 치름.

### 3.4 초기화
- 프렐루드·코다는 Wan2.1 블록 1–3, 28–30을 복사, 코어는 블록 10–15(연속 그룹)을 복사 (§3.4, §4.1). 1-based 번호.
- 비디오 FFN은 8960→6144 등간격 선택. 행동 전문가는 "Fast-WAM[63]의 크기 조정 규칙"을 씀 (§3.4). 이 규칙의 세부는 본문에 없음 (`04` D-항목).

### 3.5 엘라스틱 자기증류 (식 (5), (6), 알고리즘 1)
- 교사: 학습된 LoopedWAM(Ka=K=4, NT=10 스텝), 동결. 학생: 교사 행동 전문가 복사본 + 단계 조건 MLP(d = 1/N을 임베딩해 행동 전문가의 시간 변조에 더함, 0으로 초기화, 약 0.4M 파라미터).
- 학생 비디오 전문가, VAE, 텍스트 인코더, 고유수용 투영은 교사와 **공유·동결**.
- 로컬 목표: 학생이 **자기 상태 z_j**에서 출발해 교사 Euler 사상을 따르는 평균 속도 (식 (5)). 교사 궤적을 따라가는 대신 학생 자신의 오차를 노출하는 것이 핵심 주장 (표 8).
- 끝점 손실 L_end (집행 청크 Hx개 MSE), 그리퍼 손실 L_grip (LIBERO만, 소프트플러스 여유), 앵커 L_anchor (Ka=K, d=0에서 원래 플로우 매칭).
- 설정 집합 S = {1,2,4}×{2,5,10}, 균형 순서로 아홉 설정을 한 번씩 순환.
- 역전파는 마지막 m개 스텝만 통과 (m 값은 본문에 없음).

## 4. 실험

### 4.1 설정 (§4.1)
- LIBERO: 4 suite × 10 task, 학습은 전 suite 한 모델. 평가는 task당 50 초기상태 × 3 seed = 6000 에피소드.
- RoboTwin 2.0: 50 task, task당 깨끗한 데모 50 + 무작위 데모 500, 평가 task당 100 에피소드 × (깨끗함, 무작위).
- RoboCasa-GR1: 24 task, 50 rollout/task (1200 에피소드).
- 학습: 로봇 사전학습 없음, H100 GPU. 아블레이션은 LIBERO 짧은 스케줄(본 스케줄의 절반), RoboTwin 10개 task (RT-10).
- 지연: H100, 배치 1, 원시 관측에서 행동까지, 500 질의 평균. Fast-WAM·Faster-WAM·Light-WAM은 공개 체크포인트로 재평가 (표 A1: 보고값보다 0.3–1.4점 낮음).

| RoboTwin 2.0 (표 2) | 91.9 (깨끗 92.1, 무작위 91.7) | Fast-WAM 91.8, LaWAM 91.2, LingBot-VA 92.2, Faster-WAM 92.6 | 2B 미만 최고 |
| RoboCasa-GR1 (표 3) | 52.2 | StarVLA-GR00T 47.8, DiT4DiT 50.8, ABot-M0 58.3, ACE-Ego-0 72.8 | 가장 어려운 벤치마크 |

### 4.3 엘라스틱 설정 (표 5, 그림 1c)
- 아홉 설정이 24.7–86.2 ms, LIBERO 95.2–96.2%. 같은 호출 수(60회)에서 (Ka,N)=(4,2)가 (1,5)보다 LIBERO·RoboTwin·RoboCasa에서 각각 0.4, 2.1, 5.0점 높음 (§4.4). "깊이가 스텝보다 중요" 주장.
- 교사 대비 학생: 긴 스케줄 교사(96.1)에서 증류하면 짧은 스케줄 교사(94.9)보다 모든 설정이 0.7–1.8점 나음 (표 5 이득, 평균 1.1).

### 4.4 아블레이션 (표 7, 표 8, 부록 B–D)
- 루프 배분: 같은 파라미터에서 비디오 루프(4/1)가 행동 루프(1/4)보다 LIBERO에서 2.3점 높고 지연은 1.8배 낮음.
- 초기화: 무작위 코어 −12.7점 (가장 큰 효과). 비디오 사전학습 없음 −9.2.
- 코다 제거 −4.6점, 프렐루드 제거 −0.5점.
- 증류 목적: 교사 궤적 방식 −0.21 (LIBERO), −1.20 (RT-10). 끝점 항 제거 −0.20. 앵커 제거 −0.33 (LIBERO).

### 4.5 실로봇 (§4.6, 표 9, 그림 5–6)
- AgileX PiPER 6관절 + 그리퍼, 전면·손목 카메라 2대, 과제 4개, 과제당 100 데모로 공동 학습, 과제당 20회 시험, 총 80회.
- 실패 23건 중 접촉 단계 19건 (그리퍼가 물체 옆·위에서 닫힘 10, 쓰러뜨림·밀어냄 4, 놓침 5), 비접촉 4건 (`01` 본문 §4.6).

## 5. 주장과 증거 사이의 틈 (`04`와 `03`에서 확인)

- **G1 실로봇 "동등"은 검출 한계 안.** 57/80과 57/80의 Wilson 95% 구간은 60.5–80.0%, Fisher 양측 p = 1.0 (`03` V11). 80회 시험이므로 "같은 성공률"은 보여주지 못하고 "차이를 보지 못함"만 말할 수 있음.
- **G2 RoboCasa 우위는 신뢰하기 어려움.** 52.2 vs DiT4DiT 50.8: 같은 50 rollout 기준으로 z ≈ 0.69, p ≈ 0.49 (`03` V7). 본문은 "ahead of"라고 씀. StarVLA(47.8)와는 z ≈ 2.2 (p ≈ 0.03, 다중 비교 보정 전).
- **G3 지연 비교 노이즈.** 저자 스스로 반복 측정이 최대 15% 차이 난다고 씀 (§4.3 측정 단락). 표 4의 1.2배(전체 깊이) 차이는 이 범위 안. 엘라스틱 설정의 3–4배 차이는 노이즈보다 큼.
- **G4 실로봇 지연.** 표 9에서 LoopedWAM 전체 모델은 160 ms, Fast-WAM은 150 ms. 본문은 엘라스틱 설정의 160 → 58, 46 ms만 강조. 전체 모델이 실로봇에서 더 빠르지 않다는 사실은 본문에 없음.
- **G5 통계 보고 불완전.** 표 5 이득의 "9개 중 7개 유의" (쌍체 순열검정)와 표 8 차이 (−0.15에서 −0.33)는 에피소드 단위 짝지음 자료가 공개되지 않아 재현 불가 (`03` V10 주석).
- **G6 학습 시드 하나.** 평가 seed 3개는 있으나 학습 seed 변동은 측정하지 않음. 아블레이션 차이 0.45점(KV-mix)은 노이즈 안이라고 저자가 인정함.
- **G7 베이스라인 재평가.** 자기 평가로 Light-WAM·Fast-WAM·Faster-WAM을 보고값보다 0.3–1.4점 낮게 얻음 (표 A1). 공정한 비교 방향이지만 세 베이스라인의 학습 데이터 규모(RoboTwin 500 무작위 데모 등)가 다른 논문과 같은지는 확인되지 않음.
- **G8 "로봇 사전학습 없음" 표현.** 텍스트·영상 웹 규모 사전학습(Wan2.1)은 사용함. 본문도 이를 명시하지만 "no pretraining"이라는 표현은 로봇 데이터 기준임.
- **G9 학습 레시피는 본문에 없음.** λ 값, m, 에폭, 옵티마이저, 플로우 shift, Hx 값, 행동 전문가 FFN 폭은 공개 코드에서만 확인됨 (`04` D-항목). 저자는 "재현 세부는 코드와 함께 공개"라고 씀.

## 6. 용어와 기호 (본문 기준)
- Kv, Ka: 비디오, 행동 루프 수. K: 기본값 4. N: 샘플링 스텝. NT=10: 교사 스텝.
- σ(r): 늦은 정렬 매핑 (식 (3)). L(K): 실행 층 수 = LP + K·LC + LE.
- Hx: 집행 행동 수 (LIBERO 10, RoboTwin 24, RoboCasa 12는 코드에서 확인, `04` 참조).
