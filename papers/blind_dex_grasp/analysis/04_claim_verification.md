# 04. 주장 검증과 구현 가능성 (공식 코드 없음)

공식 코드가 공개되어 있지 않아(`02` §2) 코드 대조(D 항목) 대신 논문의 주장을 표·식·부록 수치와 대조합니다. 주장은 C1–C17, 수치 검사는 `03`의 V·K 항목입니다.

## 0. 대상과 방법

- 공식 코드 확인(2026-11-25): 프로젝트 페이지(dex-blind-grasp.github.io)의 Code 버튼 주소가 `#`이고, 하드웨어 저장소는 "coming soon"으로 표기되어 있습니다. 프로젝트 페이지 소스 저장소(`Dex-Blind-Grasp/Dex-Blind-Grasp.github.io`)는 2026-09-06이 마지막 push입니다. `gh search repos`로 논문 제목, 프로젝트 페이지 이름, 주제어를 찾았으나 저자 소유로 보이는 코드 저장소는 없었습니다. 프로젝트 페이지가 링크한 저자 개인·연구실 페이지의 GitHub 계정에도 해당 저장소가 없습니다(2026-11-25, `gh api`).
- 그래서 논문 안에서 확인 가능한 것만 합니다. 표 재계산(`03`), 식과 부록 값의 내적 일관성, 주장과 증거의 대응입니다. 코드를 받거나 실행하지 않았고, 데이터와 가중치도 받지 않았습니다.
- 판정은 "지지", "부분 지지", "지지 안 됨", "확인 불가"입니다. 지지 안 됨은 "틀렸다"가 아니라 제시된 증거로 주장을 가리기 어렵다는 뜻입니다.

## 3. 식과 부록 사이의 구조 점검 (코드 없이 확인한 것)

- 입력 표현: 식 3(R^4) = 식 11(R^4) 일치. 식 12의 H × N_tac × 4와 표 12의 H = 16, N_tac = 44 일치. 인코더 6층, 6헤드, d = 384(FFN 1,536 = 4 × 384, 헤드 차원 64) 표 12와 일치.
- 점 출력: 질의 64 + 64, 질의당 16점 → 1,024 + 1,024, 식 14와 일치. 자세 7, 관절 22, 접촉 44 일치.
- 조건 차원: 식 5의 c_t = [z_t, x_t]와 달리 부록 G의 전역 조건은 관측창(5프레임) 평균 풀링 후 896차원(= 384 + 512)입니다. 512의 출처(저차원 MLP 출력 폭)는 본문에 없어 추정입니다.
- 손실: 식 19의 부호 불변 쿼터니언 손실은 내적의 절댓값을 쓰고, 식 17의 접촉 마스크 m_t로 물체 손실을 켭니다. 식 22는 접촉 없는 프레임의 물체 예측을 원점으로 끌어당깁니다. 가중치(λ)는 한 곳에 나열되어 있습니다.
- 계산량 정보: 사전학습 200 에폭(A40 × 4), PPO 2억 스텝 × 전문가, DP 학습 스텝 수는 없음. 총 비용을 추정하려면 데이터 크기와 스텝 수가 필요합니다.

## 4. 구현 가능성 (이 맥: Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)

**판정: 논문 수치의 재현은 불가능합니다. 공식 코드, 보정 값, 센서 하드웨어, 실로봇이 모두 없습니다. 축소판 구현(접촉 모델과 보정 토이, 인코더 사전학습, 증류)은 이 맥에서 부분적으로 가능합니다.**

| 구성 요소 | 이 맥에서 | 필요한 것 | 노력 (추정, 측정 전) |
|---|---|---|---|
| 접촉 모델 식 1과 격자 보정 토이 | 가능, 완료 (`analysis/toy_event_calibration.py`, 약 40초) | numpy | 완료 |
| 표 재계산과 검정 | 가능, 완료 (`analysis/recompute.py`) | numpy, scipy | 완료 |
| 촉각 인코더 + 특권 사전학습 축소판 | 조건부 가능(MPS, torch 2.15). 입력 H × 44 × 4의 작은 Transformer는 가벼움. 학습 데이터(점군, 자세 정답)를 만들 시뮬 궤적이 먼저 필요 | 손 모델·물체 메시, MuJoCo 시뮬 데이터 | 데이터 생성 포함 1–2주 |
| PPO 전문가 축소판(물체 1–2개) | 조건부. LEAP Hand MuJoCo 모델과 물체 메시를 받아야 하고(다운로드 승인), 논문은 물체당 2억 스텝(GPU, 병렬 2,048). CPU로는 100배 이상 작은 규모에서만 | MuJoCo, 손 모델 다운로드 | 2–3주 (수렴 여부는 미정) |
| Diffusion Policy 증류 축소판 | 조건부 가능(MPS). 10,000 궤적, 1D U-Net [256, 512]는 작은 편이나 총 스텝 수가 논문에 없음 | 위 두 단계의 데이터 | 1주 |
| 논문 실험 수치(표 1–9) 재현 | 불가 | 공식 코드·보정 θ*·센서·GPU 학습 | - |
| 실로봇(xArm6 + LEAP + TwinTac 4개 + FSR 12개) | 불가 | 하드웨어 전체(설계 미공개) | - |

- 전체 축소 파이프라인은 4–6주로 어림합니다(추정, 측정 전). 이 중 PPO 전문가 단계의 수렴 가능성이 가장 불확실하고, 보정 θ*와 센서 모델이 없어 "보정 효과"는 합성 센서로만 확인할 수 있습니다.
- 패키지 설치, 데이터·모델 다운로드는 하지 않았습니다(승인 필요).
