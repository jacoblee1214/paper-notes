## 1. 한 문단 요약과 핵심 질문

영상 생성 모델을 "임베디드 세계 모델"로 쓰려면, 일반 영상 품질(FVD, VBench의 화질·미적 점수)로는 부족하다는 주장에서 출발합니다. 로봇 조작에서는 배경, 물체 배치, 로봇 형태는 그대로 있고 팔의 자세와 상호작용만 지시에 따라 바뀌어야 합니다(§1). 저자들은 이를 **장면 일관성(Scene), 동작 정확성(Motion), 의미 정합성(Semantics)** 세 축으로 평가하는 벤치마크 EWMBench를 제안합니다. 데이터는 AgiBot-World에서 10개 과제를 골라 만들었고, 평가 도구는 DINOv2(미세조정), YOLO-World(미세조정)와 Qwen2.5-VL-7B 캡션, CLIP을 씁니다. 7개 영상 생성 모델을 Image-Text-to-Video 설정에서 비교하고, 그중 네 모델에 대해서만 사람 순위와 VBench 순위를 비교합니다(§4).

**핵심 질문:** 이 세 축의 점수가 사람 판단과 맞고, 모델 간 차이를 실제로 구분할 만큼 안정적인가? 논문은 "EWMBench 순위가 사람과 더 가깝다"(Fig. 6)를 주된 근거로 듭니다.

## 2. 방법

### 2.1 문제 설정 (§3.1, 식 (1))

생성 모델 g_world는 초기 장면 이미지 I(최대 4장), 언어 지시 L, 선택적 6D 자세 궤적 T를 받아 영상을 만들고, 평가 전에 vnorm으로 정규화합니다. 식 (1): V = vnorm(g_world(f_proc(I, L, T))). 논문은 T를 선택 사항으로 두지만, 실험은 행동 조건부 모델이 공개되지 않아 **Image-Text-to-Video만** 씁니다(§4 Models). 행동 조건부 평가는 향후 과제라고 씁니다.

### 2.2 데이터 구성 (§3.2, 부록 A.2)

- AgiBot-World에서 과제 10개(Toaster, Pour Water, Place Cutlery, Restock Freezer, Produce Ice, Factory Packing, Brush Bottle, Heat Food, Hang Showerhead, Store in Drawer)를 고릅니다(부록 A.2.1).
- 각 과제는 4–10개의 원자 동작으로 나누고, 동작마다 단계 캡션을 붙입니다(§3.2).
- 다양성 선택: 양손 말단 장치 궤적을 복셀로 바꾸고, 복셀 IoU(식 (2))의 평균이 가장 낮은 궤적부터 greedy로 10개를 고릅니다(부록 A.2.2).
- **표본 수가 여러 곳에서 다릅니다.** 서론은 "30 candidate samples across ten tasks", §3.2와 §4는 과제당 10개 에피소드, 부록 A.2.2는 "uniformly sample 100 video instances per task"입니다. 이 차이는 `03` §5에서 다룹니다.

### 2.3 평가 지표 (§3.3, 부록 A.3)

| 축 | 지표 | 정의 (논문) | 구현 특징 (`04`에서 대조) |
|---|---|---|---|
| Scene | SceneC | 미세조정 DINOv2(ViT-B/14, reg4)의 패치 토큰 코사인 유사도. 연속 프레임과 첫 프레임과의 평균 | 코드와 대체로 일치. 음수는 0으로 자름 |
| Motion | HSD | 1/d_symH(생성 궤적, GT 궤적). 식 (3) | 1/d 후 상수 24.979로 나눔(논문에 없음) |
| Motion | NDTW | 1/NDTW(G, P). 식 (4) | DTW 값을 경로 길이로 나눈 뒤 1/x, 상수 50.202 (논문에 없음) |
| Motion | DYN | 속도·가속도 분포의 Wasserstein 거리와 진폭 보정 VR, AR. 식 (5)–(7), α = 0.007, β = 0.003 | 식과 상수가 코드와 일치. 상수 22.519로 나눔(논문에 없음) |
| Semantics | Diversity | 같은 에피소드 내 3개 후보의 CLIP 임베딩 1 − 유사도 | 코드와 일치 (CLIP ViT-B/32) |
| Semantics | BLEU | 전역 캡션(General)과 GT 캡션의 BLEU | 코드와 일치 (torchmetrics BLEUScore, n = 4) |
| Semantics | CLIP | 단계 캡션(Events)과 GT 단계 캡션의 CLIP 점수 | **코드는 Events가 아니라 General을 씀**(`04` D2) |
| Semantics | Logics | 캡션 MLLM이 판정한 Overall_Constraints (참이면 1) | 코드는 참 비율을 평균. 논문은 "벌점"이라고 씀(`04` D7) |

궤적 지표는 양손(end-effector) 2D 궤적으로 계산합니다. 궤적은 YOLO-World 검출과 추적으로 얻고(부록 A.1), 검출 정확도는 검증 데이터에서 recall 0.91667, precision 1.0입니다(1,451 프레임, 과제 2개를 검증으로 씀).

Overall 점수는 Table 2에서 **SceneC + Motion 평균 + Semantics 평균**(세 축의 합, 각 축은 세부 지표의 합)으로 계산합니다. 이 식은 논문 본문에 명시되어 있지 않고, 표 값을 재계산해서 확인했습니다(`03` §1).

### 2.4 MLLM 프롬프트 (§3.4)

캡션 MLLM(Qwen2.5-VL-7B 계열로 코드에 명시)에 세 단계를 요청합니다. 전역 설명(General), 단계별 사건 목록(Events), 논리 제약 판정(Overall_Constraints)입니다. 프롬프트 전문은 프로젝트 페이지에 있다고 하지만(§3.4), 프로젝트 페이지 URL은 논문에 명시되지 않았고 코드의 `caption.py`에 같은 프롬프트가 있습니다(`04` §2).

## 3. 실험과 결과

### 3.1 설정 (§4)

- 모델 7개: 오픈소스 OpenSora 2.0, LTX-Video, COSMOS-7B. 상용 Kling-1.6, Hailuo I2V-01-live. 도메인 적응 LTX_FT(LTX 미세조정), EnerVerse_FT.
- 과제 10개 × 에피소드 10개 × 모델 7개 × 후보 3개 = 2,100 영상. 최고 후보 선택(best-of-three)의 기준은 §4에 적혀 있지 않습니다(§3.3은 HSD라고 씀, `04` D1).
- 평가 척도: 0–1 정규화라고 함(§4.1). 그러나 Overall 열은 최대 약 8까지 나오므로(세 축의 합), 정규화는 세부 지표 단위로만 맞다고 보는 편이 맞습니다.

논문 주장: 도메인 적응 모델이 의미와 동작 축에서 강하고, Kling이 상용·오픈 모델 중 최고이며, 정성 사례(그림 5, 10–14)는 손 생성, 빈 잡기, 카메라 불안정, 떨림 같은 실패 양상을 보여 줍니다(§4.4).

### 3.3 사람 평가와 VBench 비교 (§4.2, 그림 6 A·B)

- 대상: LTX_FT, Kling, Hailuo, OpenSora 4개 모델. 사람이 순위를 매기고 1위 3점, 2위 2점, 꼴찌 0점을 줍니다. **3위 점수가 본문에 없습니다.** 주석자 수, 샘플 수, 일치도는 적혀 있지 않습니다.
- 사람 순위: LTX_FT, Kling, Hailuo, OpenSora. EWMBench 순위(그림 6B 라벨 기준): LTX_FT 5.49, Kling 4.75, Hailuo 4.50, OpenSora 4.05. VBench 순위(그림 6B 라벨 기준): Hailuo 71.0, Kling 69.7, LTX_FT 68.3, OpenSora 59.8.
- 결론: EWMBench가 사람과 같은 순위를 내고 VBench는 LTX_FT와 Hailuo의 순서가 다르다. **4개 모델의 순위만 비교했고 검정은 없습니다.** 재계산(`03` §3)에서 완전 일치 확률은 1/24 ≈ 0.042, VBench 쪽 Kendall tau = 0입니다.
- 또한 그림 6B의 EWMBench 점수(5.49 등)는 표 2의 Overall(4.55 등)과 **같은 값이 아닙니다**. 차이는 0.88–1.09로 일정하지 않습니다(`03` §3.3).

### 3.4 궤적 지표의 상보성 (§4.3, 그림 6C)

- 시퀀스 뒤집기: nDTW만 크게 떨어짐.
- 이상치 삽입: HSD와 DYN이 크게 떨어짐.
- 정지 프레임 삽입: nDTW가 오르고 DYN이 떨어짐.

모두 한 번씩의 실험이고 반복 횟수, 분산, 검정이 없습니다. 그림 6C 막대 높이를 눈으로 읽었을 때 "frame repetition"의 nDTW 막대는 1.0 근처입니다(`03` §5).

### 3.5 DINOv2 대 VBench 장면 지표 (§4.4, 부록 A.3.1, 그림 8–9)

VBench의 DINO ViT-B/16 특징은 전경과 배경을 잘 나누지 못하고, 미세조정 DINOv2는 주로 로봇과 도구에 주의를 둔다는 정성 근거입니다(그림 8). 그림 9에서 VBench는 0.88–0.91을 주지만 EWMBench SceneC는 떨어집니다. **사례 수와 정량 비교가 없습니다.**

## 4. 저자가 말한 한계 (§5)

1. 말단 장치의 2D 궤적만 봅니다. 팔 전체의 상태와 구성은 보지 않습니다.
2. 고정 시점 장면만 다룹니다.
3. 조작 과제만 다룹니다. 항행과 이동 조작은 향후 과제입니다.

(행동 조건부 모델은 공개 모델이 없어 평가하지 못했다고 §4에 적혀 있습니다. 이것도 실질적 한계입니다.)

## 5. 주장과 증거의 틈 (우리 판단)

| 주장 | 증거 | 판단 |
|---|---|---|
| "EWMBench가 사람 판단과 더 잘 맞는다" | 4개 모델, 순위 4개, 검정 없음. 사람 평가의 샘플 수와 주석자 수 없음 | 근거가 약함. n = 4에서 완전 일치는 우연히 나올 확률 4%. 표본을 늘린 평가가 필요 |

| "정규화된 0–1 점수" | Overall이 최대 약 8. HSD, NDTW, DYN은 임의 상수로 나눔 | 척도 설명이 부족함. 상수 민감도는 측정하지 않음 |

| 그림 6B 점수 | 표 2 Overall과 다른 값 | 어떤 버전 또는 어떤 집계인지 설명 없음. 저자에게 물을 항목 |
| Logics 점수 | 표 2 값이 모두 1/90의 정수배 | 유효 표본 수가 90일 가능성. 과제 10 × 에피소드 10 = 100과 맞지 않음(`03` §2) |
