## 1. 한 줄 요약

사전학습 VLA의 **행동 전문가(DiT)** 옆에 **센서 모달리티마다 행동 전문가를 거울로 복제한 "스트림"** 을 붙이고(§3.1), 층마다 모든 스트림의 Q, K, V를 이어 붙여 한 번의 어텐션을 계산하게 하며(공동 교차 모달 self-attention), **1단계에서는 새 스트림만, 2단계에서는 전체를 학습**하고(§3.2), 각 센서 스트림이 **미래 센서 값의 flow-matching 손실**도 풀게 합니다(§3.3). Franka 팔(AnySkin 촉각 + 관절 토크)에서 GR00T N1.5와 π0에 적용해 네 과제 평균을 GR00T 20.8 → 49.0, π0 27.1 → 45.9로 올렸다고 보고합니다(표 1).

## 2. 방법

### 2.1 베이스와 표기 (§3)

- 입력: 언어 지시 ℓ, 시각 관측 I_t. VLM 백본 f_θ가 h_t = f_θ(ℓ, I_t)를 만들고, 행동 전문가 V_ψ가 h_t와 고유수용 상태 s_t로 H개 미래 행동 A_t = [a_t, …, a_{t+H−1}]를 예측합니다(행동 청킹).
- 식 1: 조건부 flow-matching. L = E ‖(A_t − ε) − V_ψ(A_t^τ, s_t | h_t)‖², A_t^τ = τA_t + (1 − τ)ε, ε ~ N(0, I).
- 대상은 **확산 기반 VLA**입니다(§2). 적용한 두 모델은 GR00T N1.5와 π0입니다(§4.1).

### 2.2 모듈형 센서 스트림 (§3.1)

- 센서 신호 집합 M = {m_t^(i) ∈ R^{d_i}}, i = 1…N (예: 촉각 30차원, 토크 7차원, 손 힘 6차원; 부록 A.2).
- 식 2: 행동 스트림 V_ψ(A_t^τ, s_t | {h_t} ∪ M), 센서 스트림 i는 V_{ϕ_i}(m_t^(i) | {h_t, A_t^τ, s_t} ∪ M∖{m_t^(i)}).
- **구성:** 각 센서 스트림은 원래 행동 전문가 V_ψ의 구조를 거울로 복제하고 **무작위 초기화**합니다. 각 스트림의 self-attention을 공동 교차 모달 self-attention으로 바꿉니다. 층마다 독립적으로 계산한 {Q_i, K_i, V_i}_{i=0..N}(i = 0이 행동 스트림)을 이어 붙여 **하나의 scaled dot-product attention**을 계산합니다(그림 2). 나머지 구성 요소는 분리되어 "기울기 간섭"을 막는다고 설명합니다.
- 모든 스트림은 시각-언어 표현 h_t에 cross-attention을 하고, 스트림 사이의 정보 교환은 공동 self-attention 층에서만 일어납니다(그림 2 캡션).
- 센서 인코더의 구체적 형태(MLP인지, 토큰 수가 몇 개인지), 스트림당 파라미터 수, 시간 이력 길이 H는 본문에 숫자로 없습니다. 입력은 "과거 신호 m_{t−H+1:t}"이고 H는 행동 청크 길이와 같다고만 씁니다(§3.3).

### 2.3 2단계 학습 (§3.2)

- **1단계 (물리 정렬):** 사전학습 행동 전문가 V_ψ를 동결하고 무작위 초기화된 센서 스트림 {V_{ϕ_i}}만 학습합니다. L_phy만 최적화합니다(§3.3 마지막 문장).
- **2단계 (공동 미세조정):** V_ψ를 풀고 L = L_act + λ_phy L_phy를 모든 파라미터에 대해 최적화합니다.
- 근거 서술: "곧바로 끝에서 끝으로 학습하면 무작위 센서 스트림과 사전학습 행동 스트림 사이의 기울기 간섭 때문에 최적화가 어렵다"(§3.2). 이 서술의 직접 근거는 표 2b(1단계 대 2단계, 시행 24회)입니다.

### 2.4 미래 물리 신호 예측 (§3.3, 식 3)

- L_phy = Σ_i E_{τ,ε_i} ‖(m_{t+1:t+H}^(i) − ε_i) − m̂_{t+1:t+H}^(i)‖², 각 센서 스트림이 과거 신호 m_{t−H+1:t}로부터 행동 구간 동안의 미래 신호를 flow-matching으로 예측합니다. λ_phy = 0.1(부록 A.3, 표 6에서 {0.1, 0.5, 1.0} 비교).
- TA-VLA [13]의 미래 토크 예측 보조 과제를 모든 모달리티로 확장한 형태입니다(서론의 "[13]" 인용).

## 6. 읽을 때의 쟁점 (자세한 수치는 `03`, 판정은 `04`)

1. **개선 폭의 규모와 불확실성.** 표 1의 일차 비교(촉각+토크 MoSS 대 기본)는 GR00T +28.1 %p(Fisher p ≈ 1e-4), π0 +18.8 %p(p ≈ 0.011)로 확실합니다. 기준선 대비 차이는 대부분 구간이 0을 포함합니다(예: GR00T 촉각 MoSS 대 ForceVLA +8.3 %p, p = 0.30). 과제당 24회라서 과제별 차이는 Holm 보정 후 모두 비유의입니다(`03` V7).
2. **"모달리티를 더할수록 좋아진다"는 방향만 확인됩니다.** MoSS 촉각+토크 대 촉각 단독은 +6.2 %p, p = 0.47입니다(`03` V9).
3. **절제 세 건은 모두 시행 24회 × 2과제**라서 개별 p는 0.24–0.77, 두 과제를 합쳐도 0.10–0.54입니다(`03` V10). 방향은 일치하지만 "significantly outperforms"(§4.3 표 2a 서술)는 이 시행 수로는 뒷받침되지 않습니다.
4. **통제 조건.** MoSS는 모달리티마다 행동 전문가 크기의 스트림을 더하는데, 파라미터 수·학습량을 맞춘 기준선은 없습니다. 기준선 구현은 저자가 적응한 것이고, GR00T + Tactile-VLA만 VLM을 학습시켰습니다(`04` C9).
5. **다중 신호 주장의 범위.** 한 모델에서 동시에 쓴 조합은 촉각+토크(플랫폼 I) 하나입니다. 힘 신호는 다른 로봇(플랫폼 II)에서 단독 사용이고 기준선이 없습니다(`04` C4).
