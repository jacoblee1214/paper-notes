### V7. IR의 분산이 없습니다

IR은 세 번의 학습 결과인데 표준편차나 개별 값이 없습니다. n = 3 대 3의 Welch 검정(df ≈ 4)이 과제별로 p < 0.05가 되려면 합동 표준편차가 다음 값 이하여야 합니다(`t1_ir_sd_sensitivity`): 대 HiL-SERL 차이 14.4–25.7 %p에서는 SD ≤ 6.4–11.3 %p, 대 FA-RL 차이는 Tube 6.3 %p에서 SD ≤ 2.8 %p, Fold 6.8 %p에서 SD ≤ 3.0 %p입니다. 대 HiL-SERL 차이는 SD가 현실적으로 크지 않으면 유의할 가능성이 높지만, 대 FA-RL 차이(특히 Tube, Fold)는 학습 간 변동이 3 %p만 되어도 구분이 안 됩니다. 논문이 이를 알 수 있게 하지 않습니다.

### V10. 본문 문장 오류: "가장 낮은 F1"

§4.4는 "removing value prediction yields the lowest F1 (0.845) and highest IR (18.7%)"라고 씁니다. 표의 F1은 0.878 / **0.845** / **0.832** / 0.882 / 0.882이고, 가장 낮은 것은 **w/o TVR의 0.832**입니다. 0.845는 둘째로 낮습니다. IR 18.7이 가장 높다는 부분은 맞습니다. 바로 뒤 문장 "TVR 제거는 comparable drop (F1 0.832, IR 16.9)"과도 어긋납니다(0.832 < 0.845). 표와 문장 중 어느 쪽이 맞는지 저자 확인이 필요합니다.

## 4. 방법 내부의 일관성

### V12. 트리거 학습 방식: 식 6 대 부록 D.3, E

본문 §3.3은 `R̂_t`를 `R_t`에 **회귀**하고 `s = σ(R̂_t)`, `s ≥ 0.5`에서 트리거한다고 씁니다. 부록 D.3은 "개입 머리가 풀링 래턴트와 **분리된 가치 스칼라**를 읽어 트리거 로짓을 낸다", 부록 E는 "트리거 머리는 채굴 라벨에 대해 이진 **초점 손실**로 학습"한다고 씁니다. 본문 식으로는 트리거가 회귀의 부호 검사이고, 부록은 분류기입니다. 같은 스칼라를 두 목적으로 쓰는 공식 코드가 이 둘을 한 로짓에 합쳐 놓은 것으로 보입니다(`04` D2).

### V15. TVR의 크기와 임계값 0.5의 의미 (해석식 + 토이)

`R_t`를 회귀 목표로만 쓰면 `σ(R̂) ≥ 0.5`는 `R̂ ≥ 0`, 즉 "창 안의 할인 가중 평균 가치 증가율이 ε = 0.005보다 낮다"와 같은 조건입니다(V_t < 1일 때). 따라서 임계값 0.5는 튜닝된 값이 아니라 부호 검사입니다.

| 에피소드 길이 T | 선형 NTTG 가치의 스텝당 증가 | R>0 비율(건강한 궤적) |
|---|---|---|
| 20 | 0.053 | 0.05 |
| 42 (RAM Insertion) | 0.024 | 0.05 |
| 95 (Fold Towel) | 0.011 | 0.03 |
| 200 | 0.005 | 0.04 |
| 300 | 0.003 | 1.00 |

ε = 0.005는 "에피소드 길이 약 200스텝"에 해당하는 진행률입니다. 논문의 두 사례(42, 95스텝)에서 건강한 진행은 ε의 2–5배라 R이 음수이고(비트리거), 가치가 거의 멈출 때만 양수가 됩니다. 건강한 궤적의 처음 2–3단계는 창을 첫 값으로 채우는 방식 때문에 R > 0으로 나옵니다(`04` D5, 토이 D항). `R_t`의 크기는 평평한 창에서 0.028이라 σ가 0.507에 그칩니다(σ의 포화 영역과 거리가 멉니다). 가치 증가율이 ±0.3일 때도 σ(R)는 0.16–0.85 범위입니다.

### V13. 그림 3의 "단조 상승"

§4.3은 복구 이후 "value rises smoothly and monotonically to completion"이라고 쓰지만 그림 3에서 RAM Insertion의 가치는 약 26단계의 0.63에서 27단계의 0.46으로 떨어지고, Fold Towel에도 50단계 전후에 진동이 있습니다. 또 "트리거가 국소 최솟값(RAM 13단계, Fold 8단계)에서 발생"하는데, RAM의 가치 최솟값은 5단계 부근(약 0.20)이고 13단계는 약 0.22입니다. Fold Towel의 8단계는 K = 8 창이 처음 가득 차는 시점과 같습니다(`fig3_claims`).

## 5. 토이 T1: 오프라인 라벨 규칙이 건강한 곡선을 어떻게 취급하는가

**질문:** 부록 E의 세 규칙(decline, plateau, abrupt-drop)으로 채굴한 라벨은 정체가 **없는** 건강한 에피소드를 얼마나 양성으로 표시하는가?

**설정:** 부록 C.1의 NTTG를 그대로 따른 이상적 선형 가치 `v_t = t/(T−1)`(T = 20–300), 에피소드별 최소-최대 정규화, 창 8. 규칙 임계값은 논문에 숫자가 없어 공식 설정의 값(decline: 기울기 −0.01, 하락 0.05, 하강 비율 0.7 / plateau: 평평 비율 0.6, δ = 0.03, 진폭 4δ / abrupt: 하락 0.12, 회복 지평 3, 비율 0.5)을 썼습니다. 코드를 읽고 numpy로 다시 쓴 것이며 공식 코드를 실행하지 않았습니다.

**결과 (건강한 선형 곡선):**

| T | 스텝당 증가 | 채굴 양성 비율 |
|---|---|---|
| 20, 30 | 0.053, 0.034 | 0.00 |
| 42 | 0.024 | 0.10 |
| 60 | 0.017 | **0.98** |
| 95 | 0.011 | **0.99** |
| 150–200 | 0.007–0.005 | 0.99 |

plateau 규칙은 "창 내 7개 증분이 0.03 이하인 비율 ≥ 0.6 그리고 창 진폭 ≤ 0.12"이므로 7/(T−1) ≤ 0.12, 곧 **T ≥ 60**에서 건강한 선형 상승의 모든 창이 plateau로 표시됩니다(해석식과 토이가 일치).

**정체 구간이 있는 곡선(길이 T − L의 선형 상승 + 길이 L의 정체, 잡음, 에피소드 200개):** T = 95(정체 14단계)에서 채굴 라벨의 양성 비율은 98.9%, 정체 대비 정밀도 0.15, 재현율 1.0입니다. 같은 곡선에서 R_t > 0은 정밀도 0.57, 재현율 0.68, 양성 비율 17.6%입니다. T = 42(정체 8단계)에서는 채굴 라벨 정밀도 0.41 / 재현율 0.51, R_t > 0은 정밀도 0.29 / 재현율 0.17이었습니다. 채굴 라벨과 R_t > 0의 일치는 T = 95에서 재현율 0.17(채굴 양성 대부분을 R이 놓침)입니다.

**해석과 한계:**
1. 이것은 **이상적 선형 가치**에서의 결과입니다. 실제 프록시 가치는 잡음이 있고 비선형이며, 논문 부록 C.4의 성공 궤적 평균 0.53(선형이면 0.5)은 선형에 가깝다는 정황입니다.
2. 만일 가치가 선형에 가깝다면 T ≥ 60인 긴 과제(Fold Towel 95단계)에서는 규칙이 정체와 무관하게 거의 모든 단계를 개입 지점으로 표시해 라벨이 퇴화합니다. 표 2의 F1은 Pick Eggplant와 RAM Insertion(RAM은 42단계 사례)만 보고하고 Fold Towel은 뺐습니다. 이 점은 토이로는 원인이 확정되지 않습니다.
3. 토이는 규칙의 정의를 읽어 다시 쓴 것이라 실제 데이터의 분포를 대신하지 못합니다.

## 7. 이 문서의 한계

- 표 값은 논문에 있는 것만 다시 계산했습니다. 에피소드 단위 원자료, IR의 세 번 학습 값, 그림 3의 곡선 값은 없어 재구성하지 못했습니다.
- 그림 3에서 읽은 값(V13)은 눈으로 읽은 근사입니다: RAM Insertion의 가치는 26단계 약 0.63에서 27단계 약 0.46으로 떨어집니다. 본문 "monotonically"와 어긋나지만 그림 전체가 같은 곡선이라는 점 외에 수치가 아닙니다.
- 토이는 이상적 곡선과 공식 설정 임계값을 가정합니다. 실제 프록시 가치에 대한 라벨 양성 비율은 데이터가 공개되지 않아 알 수 없습니다.
