# 03. 수치 재계산과 검정 (ABC, arXiv:2606.27375)

이 문서의 계산은 모두 `analysis/recompute.py`(numpy, scipy, 수 초)와 `analysis/toy_multidraw.py`(torch CPU, 약 10초)가 하고, 결과는 `recompute_results.json`, `toy_multidraw_results.json`에 있습니다. 논문의 원자료(시도별 결과, 체크포인트별 점수)는 공개 논문에 없어서, 표와 그림 제목에 적힌 값만 다시 계산했습니다. 그림에만 값이 있는 곳(그림 5, 11, 13, 14)은 계산하지 않고 "미검증"으로 표시했습니다. 번호 V는 재계산 검사, C는 주장 판정입니다.

## 1. 표 1 (아키텍처 절제)

### V1. 평균 열 재계산: 11/12 일치, 1칸은 0.1 어긋남

과제 세 개 평균을 다시 계산했습니다(strict, progress 각 6모델 = 12칸).

### V2. "과제당 50회"로는 만들 수 없는 비율이 많습니다

§3은 "Each task is evaluated for 50 trials"라고 씁니다(그림 8·9와 프로젝트 페이지도 같음). strict는 성공 횟수/시도 수이므로 50회면 2%의 배수여야 합니다. 표 1 strict 18칸 중 **9칸이 50회로는 불가능**합니다.

| 칸 | 보고값 | 가능한 시도 수(30–70 범위) |
|---|---|---|
| Bottles / VLA Pooled adaLN | 67.3 | 49, 52, 55 (예: 33/49) |
| Bottles / DiT DINOv3 | 73.5 | 34, 49, 68 (예: 36/49) |
| Bottles / DiT CLIP-adaln | 11.8 | 34, 51, 68 |
| Bottles / DiT CLIP-xattn | 38.9 | 36, 54 (예: 14/36) |
| Dishrack / VLA FAST | 2.8 | 36 (1/36) |
| Dishrack / DiT DINOv3 | 23.2 | 56, 69 |
| Dishrack / DiT CLIP-adaln | 28.6 | 35, 42, 49, 56, 63, 70 |
| Dishrack / DiT CLIP-xattn | 34.7 | 49 (17/49) |
| Mugs / VLA Pooled adaLN | 1.0 | 30–70 범위에 없음(96–104 필요, 예: 1/100) |

- progress도 Bottles·Dishrack(최대 6점, 표 3)에서 12칸 중 **6칸이 점수 합 정수 조건을 못 맞춥니다**(예: 5.2%는 300점 만점에서 15.6점, 93.1%는 279.3점). Mugs의 최대 점수는 표 3에 없어 검사하지 못했습니다.
- 해석: 칸마다 시도 수가 49, 36처럼 다르거나(중단된 시도 제외), 여러 실행·체크포인트의 평균일 수 있습니다. 어느 쪽이든 본문의 "50 trials"와 다르며, 어느 칸이 몇 회인지 표에서 알 수 없습니다. 공개한다는 평가 로그(ABC-Eval)가 있으면 해결되지만 이번에는 받지 않았습니다.

### V3. DINOv3 대 CLIP(둘 다 교차 어텐션)은 과제별로 방향이 갈립니다

논문은 "CLIP을 DINOv3로 바꾸면 더 낫다"(§3.1)고 하고 평균(progress 58.8 → 67.5, strict 24.5 → 32.9)으로 보입니다.

| 과제 | strict DINOv3 / CLIP | progress DINOv3 / CLIP | Fisher p (strict, 50회 가정) |
|---|---|---|---|
| Bottles | 73.5 / 38.9 | 93.1 / 74.1 | 0.0005 |
| Dishrack | 23.2 / 34.7 | 74.1 / **81.3** | 0.38 |
| Mugs | 2.0 / 0.0 | 35.3 / 21.0 | 1.0 |

- 평균 차이의 대부분이 Bottles 한 과제에서 나옵니다. **Dishrack에서는 CLIP이 strict와 progress 모두 높습니다.** 성공 횟수를 round(p × 50)로 근사한 검정이라 참고용이며, Bottles의 차이만 확실하고 나머지는 구분되지 않습니다.
- 같은 방식으로 CLIP-xattn이 CLIP-adaln보다 나은 방향은 세 과제 모두에서 일치합니다(progress 74.1 대 53.6, 81.3 대 72.3, 21.0 대 15.9).
- 최종 ABC-VLA(strict 32.8, progress 61.4)와 ABC-DiT(32.9, 67.5)는 strict가 같고 progress는 6.1점 차이입니다. 두 모델의 우열을 표 1이 가르지는 못합니다.

### V16. 검정력: 이 시도 수로 가를 수 있는 차이

Cohen의 h 근사(양측 α = 0.05, 검정력 80%, 두 비율의 평균 0.5 부근)로 계산한 **검출 가능한 최소 차이**입니다.

| 조건당 시도 수 | 10 | 20 | 50 | 100 | 200 |
|---|---|---|---|---|---|
| 최소 검출 차이(비율 %p) | 59 | 43 | 28 | 20 | 14 |

- 과제당 50회(표 1)에서는 성공률이 약 28%p 이상 다를 때만 80% 검정력으로 구분됩니다. 표 1의 이웃한 비교 대부분(예: Dishrack strict 34.7 대 23.2, 필요 시도 수 조건당 약 242회; Bottles 73.5 대 67.3, 약 849회)은 이 한계 밖입니다. 따라서 표 1이 모델을 가르는 증거는 **큰 차이(VLA의 교차 어텐션 대 풀링 adaLN, Bottles의 DINOv3 대 CLIP)에만** 있습니다.
- 시뮬 엔진 차이(0.71 대 0.54, `04` D14)를 가르려면 조건당 약 126개 월드가 필요합니다. 공식 README의 표는 20 월드(최소 검출 차이 43%p)이므로, 예컨대 MuJoCo 버전 변경에 따른 dishrack 15/20 대 12/20은 Fisher p = 0.50으로 시드 변동과 구분되지 않습니다(`04` D14의 "버전에 민감"이라는 서술은 이 정도의 증거입니다).
- 부록 H의 n = 10은 59%p 차이만 검출합니다(V9의 대부분이 비유의인 이유).

## 2. 상관 분석

### V4. 그림 8(오프라인 지표 대 실제 성능, n = 16): p값은 r에서 재현되지만 표본이 독립이 아닙니다

| 지표 → 실제 | r (보고) | p 보고 / 재계산 | r의 95% 구간(Fisher z) |
|---|---|---|---|
| 학습 손실 → strict | -0.84 | 4.1e-5 / 4.7e-5 | [-0.94, -0.59] |
| 검증 손실 → strict | -0.04 | 0.886 / 0.883 | [-0.53, 0.47] |
| 검증 행동 오차 → strict | -0.89 | 3.8e-6 / 3.9e-6 | [-0.96, -0.71] |
| 학습 손실 → progress | -0.78 | 3.9e-4 / 3.7e-4 | [-0.92, -0.46] |
| 검증 손실 → progress | 0.14 | 0.599 / 0.605 | [-0.38, 0.59] |
| 검증 행동 오차 → progress | -0.85 | 2.9e-5 / 3.1e-5 | [-0.95, -0.61] |

- 모든 p값이 (r, n = 16)에서 t 검정으로 재현됩니다(소수 둘째 자리 반올림 차이). Spearman p도 t 근사와 같은 규모입니다.
- **독립성 문제:** 16개 점은 같은 학습 실행의 서로 다른 스텝(100k와 200k)과 같은 아키텍처의 세 배치 크기를 포함합니다. 점이 독립이 아니면 유효 표본 수가 줄어 p가 커집니다. 유효 n을 8로 보면 검증 행동 오차 p = 0.003, 학습 손실 p = 0.009, 6으로 보면 0.018과 0.036입니다. 상관의 방향(두 지표 유효, 검증 손실 무효)은 이 가정에서도 유지됩니다.
- 검증 손실이 무상관이라는 결과는 "r이 0에 가깝다"이지 "무관하다"가 아닙니다. 구간이 [-0.53, 0.47]로 넓어 중간 크기 상관을 배제하지 못합니다.
- 저자도 쓰듯 이 지표는 "성공률을 예측하지 못하고 실패 모드를 못 보여 줍니다"(§3.4). 모델 계열이 섞인 상관이므로(DiT와 VLA 두 군집) 계열 안에서의 순위 예측력은 따로 알 수 없습니다.

### V5. 그림 9(시뮬 대 실제, n = 12): 수치는 재현, 구간은 넓고 묶음 효과가 있습니다

| 지표 | r | p 보고 / 재계산 | 95% 구간 | r² |
|---|---|---|---|---|
| strict | 0.85 | 4.2e-4 / 4.6e-4 | [0.54, 0.96] | 0.72 |
| progress | 0.91 | 5.0e-5 / 4.0e-5 | [0.70, 0.98] | 0.83 |

- 12개 점은 4개씩 세 묶음(ABC-130K DiT, ABC-130K VLA, 사내 7K + 시뮬 혼합 DiT)이고(§4), 각 점은 세 과제 평균입니다. 묶음 안의 점은 같은 실행의 다른 체크포인트이므로 독립이 아닙니다. 유효 n을 8로 보면 p = 0.0075(strict)과 0.0017(progress), 6이면 0.032와 0.012, 5이면 0.068과 0.032입니다. strict 상관은 유효 표본이 5 이하면 유의하지 않습니다.
- r = 0.85의 구간 하한 0.54는 "시뮬이 실제 성능의 약 30%만 설명한다"는 해석도 데이터와 모순되지 않는다는 뜻입니다. 따라서 이 상관을 선택 규칙의 근거로 쓸 때는 구간의 아랫부분까지 고려해야 합니다.
- 프로젝트 페이지 곡선(V12)에서 보면 사전학습 초기의 급격한 상승이 12개 점의 대부분의 분산을 만들 가능성이 있습니다(그림 9의 원자료를 받지 못해 확인 못 함).

### V9. 부록 H 조건화 실험(n = 10): 방향은 일관되지만 대부분 구분되지 않습니다

- 내부 정합: Table 4와 5의 H/M/L 합이 완료 수와 모두 일치(7행). 시간 초과를 390 s로 센 평균 시간에서 역산한 완료 시도 평균은 모두 0–390 s 범위입니다(예: Op-0 조건 8회 완료의 평균 완료 시간 199 s). Table 4의 "Op-0 조건" 행과 Table 5의 "Prefix = 1" 행은 같은 값(4.6, 8/10, 237 s, 4/3/1)이고 본문이 같은 체크포인트라고 밝힙니다.
- 검정(Fisher 정확 검정, 완료 횟수):

| 비교 | 완료 | p |
|---|---|---|
| Op-0 조건 대 Op-0만 필터 | 8/10 대 2/10 | **0.023** |
| Op-0 조건 대 전체·과제만 | 8/10 대 4/10 | 0.17 |
| Op-0 조건 대 Op-1 조건 | 8/10 대 5/10 | 0.35 |
| 주변화 대 전체·과제만 | 6/10 대 4/10 | 0.66 |
| Op-1 조건 대 전체·과제만 | 5/10 대 4/10 | 1.0 |
| Prefix 1 대 Prefix 4 | 8/10 대 5/10 | 0.35 |
| 하위 과제: 재펴기 실패 | 0/10 대 5/10 | **0.033** |

- 완료율 8/10의 Wilson 95% 구간은 49–94%이고 4/10은 17–69%입니다. 구간이 크게 겹칩니다. H.1의 "주변화 추론이 기준선보다 낫다 ... 조종자 ID 조건화는 **엄격하게** 유익하다"는 6/10 대 4/10(p = 0.66)이고 기준선이 다른 체크포인트이므로 과장입니다. "Op-0 조건이 가장 높은 품질"도 점수 4.6 대 4.0은 n = 10에서 구분되지 않습니다(다만 시간 평균은 237 s 대 277 s로 같은 방향).
- 통계적으로 지지되는 것은 두 가지입니다. 조종자 ID 조건화 체크포인트의 Op-0 조건이 Op-0만 필터한 체크포인트보다 낫다(p = 0.023, 필터 쪽이 30k 스텝만 학습해 비교가 완전히 공정하지는 않음), 하위 과제 프롬프트가 재펴기 실패를 줄인다(0/10 대 5/10, p = 0.033, 1회는 잡기 실패).

### V10. DAgger 혼합 비율의 효과(§5.3)

- 80:10:10에서 현재 라운드 데이터(개입 + 나머지)는 혼합의 20%를 차지합니다. 현재 라운드 안에서 개입 구간은 자연 비율이 30%(1라운드)와 15%(2라운드)인데 혼합에서는 50%이므로 **개입 구간은 약 1.7배(1라운드)와 3.3배(2라운드) 과대표집**됩니다. 첫 라운드 기준으로 라운드 데이터 1–1.5 h는 기반 10 h에 대해 9–13%인데 혼합에서 20%를 받으므로 현재 라운드 전체가 약 1.5–2.2배 과대표집됩니다. "implicitly overweights interventions"라는 논문 설명은 맞고, 그 크기를 이렇게 정량화할 수 있습니다.
- 그림 14는 DAgger 전후 평균 progress만 보여 주고 값이 없습니다. 본문 숫자는 DAgger 이전 24%뿐입니다. DAgger 라운드마다 데이터와 학습 스텝(75k씩)이 추가되므로 "DAgger 개입 데이터가 결정적"이라는 인과는 "같은 양의 비개입 데이터를 추가한 대조군"이 없어 확정되지 않습니다.

## 4. 토이 T1: 다중 diffusion draw가 백본 기울기 분산을 줄이는가 (§3.2, 그림 6)

설정(`analysis/toy_multidraw.py`): 문맥 6차원 → 작은 MLP 백본(32차원 특징) → 헤드가 flow matching 속도 (잡음 - 행동)을 예측합니다. 같은 배치 샘플을 k번 복제해 독립 (잡음, 시간)을 뽑고(코드의 `repeat_interleave`와 같은 방식) 손실을 평균합니다. 1,500 스텝 학습한 고정 모델에서 배치 32, 반복 300회로 백본 기울기의 총 분산(공분산 trace)을 잽니다. 시드 5개 평균 ± 표준편차입니다.

| k | 총 분산 / k=1 | 배치 고정, (잡음, 시간)만 새로 뽑은 분산 / k=1 |
|---|---|---|
| 1 | 1.000 | 1.000 |
| 2 | 0.696 ± 0.014 | 0.486 ± 0.051 |
| 4 | 0.554 ± 0.009 | 0.243 ± 0.017 |
| 8 | 0.482 ± 0.007 | 0.124 ± 0.011 |
| 16 | 0.435 ± 0.015 | 0.060 ± 0.005 |

- (잡음, 시간)에 의한 분산은 정확히 1/k로 줄고(k=8에서 0.124 ≈ 1/8), **총 분산은 데이터 샘플 분산에 막혀 0.43쯤에서 포화**합니다. 총 분산을 a + b/k에 맞추면 k=1에서 잡음 항이 약 60%(0.597 ± 0.012)입니다. 논문의 "strictly lower-variance gradient estimator"는 맞지만, 이득은 k를 늘릴수록 줄어듭니다(k=8 → 16에서 0.48 → 0.44).
- 논문은 k = 8을 쓰고 비용이 +1.5%라고 합니다(V7). 이 토이에서는 k = 4가 이미 총 분산의 대부분(0.55)을 얻고 8은 한 단계 더(0.48)입니다. 실제 VLA에서의 k 절제(그림 6은 1 대 8만 비교)는 없습니다.
- 한계: 토이는 2차원 이하의 가짜 문맥과 작은 헤드이므로 절대 비율은 의미가 없고 추세(1/k와 데이터 분산 바닥)만 봅니다. 실제 VLA에서 잡음 항의 비중이 얼마인지는 이 토이로 알 수 없습니다.
