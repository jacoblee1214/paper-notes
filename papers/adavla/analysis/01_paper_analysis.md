# 01. 논문 분석: AdaVLA

- **대상:** arXiv:2608.29208v2 (2026-09-11), *AdaVLA: Adaptive Step Flow Matching for Training-free Acceleration of Vision-Language-Action Models*, Sunghwan Han, Youngtae Han, Youngmin Yi (Sogang University). IROS 2026 채택(arXiv Comments).
- **원문:** `paper/paper.pdf`(8쪽, 2.4 MB), 추출 텍스트 `paper/paper.txt`. 식·표 번호는 논문 기준입니다.
- **판본 차이:** `04` 대신 이 문서 말미 §6과 `README.md`에 요약합니다. v1 → v2는 본문 숫자와 표가 같고, 감사의 글(IITP 과제 번호 추가)과 문단 위치만 바뀌었습니다.

## 1. Abstract: 무엇을 주장하나

- 흐름 매칭(flow matching) VLA의 **추론 가속**을 학습 없이 합니다. 기존 가속은 VLM 토큰 가지치기처럼 **VLM 쪽**에 맞춰져 있는데, 저자들은 π0.5에서 행동 전문가(Action Expert)의 ODE 반복이 지연의 58%(557.78 ms / 953.62 ms, Table I)를 차지한다는 점을 근거로 삼습니다.
- 핵심 신호는 **흐름 궤적의 곡률**입니다. 같은 시점에서 두 속도 v_τ와 v_mid를 비교한 상대 변화량 C(식 5)가 Cth보다 작으면 나머지 적분을 한 번에 건너뛰고(식 6), 크면 스텝을 줄여 더 조심스럽게 진행합니다(식 8–9). 동시에 MLP 가지치기 비율도 C와 층 중요도 δ_l로 조절합니다(식 7, 10).
- 주장 수치: LIBERO(4 suite, Jetson AGX Orin)에서 π0.5 지연 1.87배(958.54 → 513.35 ms), 평균 성공률 98.65 → 99.45%. X-VLA는 2.24배(387.52 → 173.09 ms). SmolVLA 실물 4과제에서 1.65배(806.73 → 488.49 ms), 성공률 87.50 → 90.00%.

## 2. Method

### 2.1 문제 설정 (Sec. III-A, III-B)
- 관측 o_t = [영상, 언어, 로봇 상태](식 1). VLM은 한 번만 돌고 KV 캐시를 행동 전문가에 넘깁니다(cross-attention).
- 선형 경로 A_τ = τA + (1−τ)ε, τ=0이 노이즈, τ=1이 데이터(식 2). 목표 속도 u = A − ε(식 3), 손실은 속도 회귀 MSE(식 4).
- 추론은 Euler, 기본 s=0.1(10단계).

### 2.2 곡률 기반 적응 추론 (Sec. IV-A, 식 5–10)
- **곡률 정의(식 5):** C = ‖v_τA − v_τB‖₂ / (‖v_τB‖₂ + ε), τA=τ, τB=τ_mid=τ+(1−τ)/2. 중점 상태는 A_mid = A_τ + v_τ·(1−τ)/2이고 v_mid = v(τ_mid, A_mid)입니다.
  - 주의: 이 값은 기하학적 곡률이라기보다 **구간 (1−τ)에서 속도가 얼마나 변하는지**를 정규화한 값입니다. 속도 변화가 구간 길이에 비례하므로 C는 τ에도 의존합니다(`03` §4).
- **NFE:** 반복마다 2회(v_τ, v_mid). 논문은 RK2라고 부르지만, 9식의 갱신은 일관된 중점 규칙이 아닙니다(§4 참고).
- **낮은 곡률(C < Cth), 식 6:** A_final = A_τ + v_mid(1−τ)로 한 번에 끝냅니다. 식 7로 해당 층 가지치기 비율을 올립니다.
- **높은 곡률(C ≥ Cth), 식 8–9:** ŝ = min((1−τ)/2, max(s, (Cth/C)·2s)), 갱신 A += v_mid·ŝ. 식 10으로 가지치기 비율을 내립니다.
- **한계 반복 소진:** "significant context shift"로 해석해 MLP 중요도 재계산과 채널 재정렬(§2.3, §2.4)을 발동합니다. 최대 반복 수는 논문에 없습니다.
- **단일 파라미터:** 저자들은 Cth 하나로 지연과 성공률의 절충을 조절한다고 주장합니다(Sec. IV-A 끝, Table III). Cth는 π0.5 LIBERO에서 0.15, X-VLA에서 0.002, SmolVLA 실물에서 0.075입니다.

### 2.3 MLP 블록 중요도 (Sec. IV-B, 식 11–15)
- 층 중요도로 **참여율(Participation Ratio)** 을 씁니다. PR = (tr G)² / ‖G‖²_F, G = AᵀA(식 13–14). SVD를 피하려는 목적입니다.
- 식 11–12의 실효 랭크(σ 정규화 Shannon)를 도입한 뒤, 실제로는 λ = σ²로 정규화한 collision 엔트로피 기반 PR을 씁니다. 두 양은 다릅니다(`03` §3).
- 층 간 정규화 δ_l = (PR_l − min)/(max − min)(식 15). 상대 순위만 반영합니다.

### 2.4 MLP 채널 재정렬 (Sec. IV-C, 식 16–19)
- 채널 중요도 I_i = ‖활성화_i‖₂ · ‖가중치_i‖₂(식 18–19). CATS[24]의 활성화 크기만 보는 기준에 투영 노름을 곱한 것입니다.
- 첫 forward나 한계 반복 소진 때만 재정렬합니다. 재정렬 비용은 보고되지 않습니다.

## 3. Experiments

### 3.1 설정 (Sec. V-A)
- 모델: π0.5(3.3B)와 X-VLA(0.9B). 체크포인트는 LeRobot 공개본(`lerobot/pi05_libero_finetuned`, `lerobot/xvla-libero`)입니다.
- 벤치마크: LIBERO Spatial/Object/Goal/Long, 과제당 50 rollout(10 과제 × 4 suite = 2000회 per 구성). 성공률은 A10 GPU에서, 지연은 A10과 Jetson AGX Orin에서 재고, 에너지는 Orin 전체 시스템을 잽니다. 지연과 에너지는 과제당 10 rollout 평균입니다.
- 실물: SO-ARM101, SmolVLA, 과제당 시연 50개, 과제당 30회 시험, 균일 Cth=0.075.

### 3.2 주요 결과 (Table II)
| 기반 모델 | 방법 | 평균 SR (%) | 지연 Orin (ms) | 에너지 Orin (J) |
|---|---|---|---|---|
| π0.5 | 기준 | 98.65 | 958.54 | 19.83 |
| π0.5 | +SparseVLM | 96.35 | 945.09 | 17.35 |
| π0.5 | +FastV | 67.05 | 863.84 | 17.38 |
| π0.5 | +Ours | **99.45** | **513.35** | **13.17** |
| X-VLA | 기준 | 98.50 | 387.52 | 10.73 |
| X-VLA | +Ours | **98.90** | **173.09** | **3.51** |

- SparseVLM과 FastV의 설정(유지 비율, 적용 층)은 논문에 없습니다. FastV는 π0.5에서 성공률을 약 31.6pp 떨어뜨립니다(98.65 → 67.05).
- π0.5 A10 지연은 기준 289.68, Ours 158.87 ms(1.82배). X-VLA A10은 151.32 → 64.90 ms(2.33배)입니다(Table II, 계산).

- "Random-step"과 10단계 기준의 성공률이 같다는 점은 "적응이 좋은 스텝 배분을 한다"는 주장과 맞물려 있습니다(§4 참고).

### 3.4 실물 (Table IV)
- 4과제 성공 수: 기준 25, 26, 29, 25 / Ours 29, 28, 27, 24(모두 /30). 평균 87.50 → 90.00%.
- 지연 평균 806.73 → 488.49 ms(1.65배). 3과제와 4과제에서 성공이 줄었고, 저자들은 "큰 적분 스텝에서 온 거친 궤적"으로 설명하며 행동 평활화로 고칠 수 있다고 씁니다(검증 안 됨).

### 3.5 적응 행동 분석 (Sec. V-E, Fig. 3, Fig. 5)
- 250개 궤적 시각화: 기준은 많은 반복, Ours는 적은 반복. 잡을 때와 놓을 때, 물체가 떨어질 때 추가 스텝이 쓰인다고 보입니다.
- 이것은 정성적 증거입니다. 반복 수 분포나 곡률 분포의 수치는 보고되지 않습니다.

## 4. Limitations (논문 자체 언급과 빠진 점)
- 논문은 한계 절을 따로 두지 않았습니다. 본문에서 명시한 것은 "Cth는 grid search로 정함"과 "분포 확인으로 새 모델에 맞출 수 있음" 정도입니다.
- 빠진 점(`04` §2에 정리): 최대 반복 수, ε, p_l 초기값과 허용 범위, 유지할 채널 비율, 재정렬 발동 조건, 정밀도(fp16/bf16 등), 프레임워크(PyTorch/JAX), 워밍업 처리, 기준 방법의 하이퍼파라미터, 코드.

## 5. 한 줄 평가
곡률로 "지금 한 번에 끝낼지"를 정하는 아이디어는 간단하고 학습이 필요 없어서 매력적입니다. 하지만 논문에서 지연 이득을 실제로 만드는 것은 식 9의 갱신과 낮은 곡률 점프가 만든 **평균 NFE 2–3**이고(`03` §5), 그 NFE를 맞춘 정적 기준선이 없어 "적응이 정적 감소보다 낫다"는 주장은 검증되지 않았습니다.
