# 02. 선행연구와 관련 저장소

이 문서는 CMP의 구성 요소가 어디서 왔는지, 가까운 대안이 무엇인지, 공식 코드가 있는지를 정리합니다. 번호는 논문 v2 참고문헌 번호(`paper/paper.txt`의 References)입니다. "해석" 표시가 붙은 관계는 논문이 직접 쓰지 않은 우리의 해석입니다.

## 1. 선행연구 계보 (구성 요소별 출처)

| CMP의 요소 | 출처 (논문 번호) | 관계 |
|---|---|---|
| 말단 목표 추종 전신 제어 (대상 문제) | UMI-on-Legs [1] (Ha 2024), MLM [4], 바퀴-사족 팔 [5] | 기준선이자 출발점. CMP는 UMI-on-Legs의 보상, 종료 조건, 데이터셋을 따릅니다(부록 F, G, H.2) |
| 전역 말단 포즈 인터페이스와 데이터 | UMI [2], FastUMI [3] | 인간 시연으로 궤적 데이터를 만드는 파이프라인. 학습 데이터 일부(cup 1,090, tossing 101)가 UMI-on-Legs 공개 데이터입니다(부록 F.1) |
| 분리형, 계층형 전신 제어 | Ma 2022 [8], Visual WBC [9], ASC [10], RoboDuet [11], Deep WBC [12] | 강건하지만 전신 상승 작용이 제한된다고 봅니다(§1). CMP의 비교 대상이 아니라 문제 배경입니다(표 1) |
| 안전 규범: 사후 복구 | 낙상 복구 [23, 24, 35, 25, 36], 복구 RL [48] | "break-then-fix". 부록 K는 복구 정책을 "최선 노력이 실패할 때의 보조"라고 분류합니다 |
| 안전 규범: 제약, 장벽, 도달 가능성 | 안전 RL [37–40], CBF [41–45], HJ 도달 가능성 [46–48] | 과제별 안전 함수를 손으로 설계해야 한다고 봅니다(§2.2). 기준선 Neural CBF가 이 계열입니다 |
| 안전 값 함수 W (식 1–2) | 도달-회피 RL [46], 복구 RL [48] (해석) | W는 "안전 집합에 영원히 머물 확률의 최댓값"으로 생존 가능 집합(viability)을 확률로 푼 값 함수와 같은 형태입니다. 논문은 이 연결을 직접 쓰지 않습니다 |
| 추론 시점 정책 조향 | Latent Policy Barrier [13], 확산 계획 [14–16], 예측 세계 모델 [17, 18], Latent Shielding [19], latent CBF [51] | 반복 샘플링 때문에 50 Hz 이상 제어에 느리다고 봅니다(§2.2). 기준선 Latent Shielding과 Neural CBF가 이 계열입니다 |
| OOD 검출과 실패 감시 | [20] (실패 데이터 없는 실패 검출), [21], [22], [49, 50], [26] | 경보와 긴급 정지에 그친다고 봅니다. CMP는 투영으로 능동 교정합니다(표 1) |
| 인코더-정책 구조 | CVAE [55] (Sohn 2015), PPO [56], Isaac Gym [58] | 잠재 의도 z를 인코더가 내고 정책이 소비하는 구조는 CVAE형입니다(§3.2) |
| 안전 추정기 학습 | TD(λ) [57] (Sutton & Barto) | 식 3은 λ-수익을 안전 확률에 적용한 형태입니다(부록 C.4) |
| 동형 잠재 공간 (ILS) | CVAE의 KL 사전분포, 고차원 가우시안 셸 성질 (해석) | 사전분포의 분산을 샘플마다 안전 값으로 바꾸는 부분(식 5–6)이 CMP의 새로움으로 제시됩니다 |

**가까운 대안과의 차이.** 가장 가까운 것은 두 갈래입니다. (1) 학습된 잠재 공간에서 안전을 보는 Latent Shielding [19]과 latent CBF [51]는 CMP와 같은 연구 흐름에서 나왔지만 추론 시점에 안전 검사나 그래디언트 계산을 합니다. CMP는 이를 학습 시점에 구조(노름)로 옮겨 실행 비용을 없앱니다(지연 2.99 ms 대 3.89, 5.36 ms, 표 4). (2) 입력 명령을 단순 규칙으로 자르는 방식은 논문 안에서도 비교됩니다(부록 K 표 8, 명령 클리핑). 이 방식이 OOD-Geometry에서는 CMP보다 높은 생존율이고 OOD-Rev에서는 낮습니다(`03` §4).

**표기 주의.** 표 2와 4의 기준선 이름 "Neural CBF"는 참고문헌 [51]의 제목 "How to train your latent control barrier function"에 해당합니다. 두 이름이 같은 방법을 가리키는지는 코드가 없어 확인하지 못했습니다.

## 4. 참고: 이 논문의 주장이 기대는 선행 결과

- **UMI-on-Legs의 평가 정의.** ID, 종료 조건, 보상이 UMI-on-Legs를 따르므로(부록 G, H.2) CMP의 ID 수치(표 2 첫 행)는 그 기준선의 재학습 결과입니다. 원 논문의 수치와 직접 비교하지 않았습니다.
- **고차원 가우시안의 셸 집중.** 식 6 아래의 "‖z‖₂ ≈ √d R"는 d가 클 때의 점근 성질입니다. d = 6에서 상대 분산은 약 29%입니다(`03` §6.2).
- **TD(λ)의 편향-분산 균형.** 부록 C.4가 λ = 0.8을 고르는 논거(전파 지연, 분산, 추정기 편향, 하한 간격)는 일반 TD(λ) 논의와 같고 이 과제에서 따로 측정하지 않았습니다.
