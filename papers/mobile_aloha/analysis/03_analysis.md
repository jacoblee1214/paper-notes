# 03. 수치 재계산과 일관성 검사

*대상:* arXiv v1 (2401.02117v1)의 표 1–4와 본문 수치. 실험 재현은 하지 않았습니다. 표 값은 페이지 이미지를 직접 읽었고, 재계산은 `analysis/recompute.py`(→ `recompute_results.json`)가 합니다. 그림은 `analysis/plot_figures.py`가 논문 수치로 그립니다.

## 0. 읽는 법

- 시도 수: 과제당 **평가 20회**, 쿡 쉬림프만 5회 (표 1 캡션과 6절 본문 일치).
- 하위 과제 성공률의 분모는 **직전 하위 과제 성공 수**이고, 전체 성공률은 하위 과제 성공률의 곱입니다 (6절). 이 정의가 맞으면 표의 각 셀은 정수 횟수 사슬로 설명되어야 합니다. 그래서 정수 가능성을 직접 검사했습니다 (블록 C·D).
- 반올림: 표 값은 정수 %입니다. 정확 일치는 0.5%p 이내, "반올림 차이"는 1%p 이내, "불일치"는 1%p를 넘는 경우로 나눴습니다.

## 1. 블록 A: 전체 성공률의 신뢰구간과 검정 (표 1, co-train 대 no-co, 과제당 20회)

| 과제 | 공동 학습 | Wilson 95% | 없음 | Wilson 95% | Fisher 양측 p | Holm 보정 p (7과제) |
|---|---|---|---|---|---|---|
| Wipe Wine | 19/20 (95) | 76.4–99.1 | 10/20 (50) | 29.9–70.1 | 3.3e-3 | 0.013 |
| Cook Shrimp (n=5) | 2/5 (40) | 11.8–76.9 | 1/5 (20) | 3.6–62.4 | 1.00 | 1.00 |
| Rinse Pan | 16/20 (80) | 58.4–91.9 | 0/20 (0) | 0.0–16.1 | 1.5e-7 | 1.0e-6 |
| Use Cabinet | 17/20 (85) | 64.0–94.8 | 17/20 (85) | 64.0–94.8 | 1.00 | 1.00 |
| Call Elevator | 19/20 (95) | 76.4–99.1 | 0/20 (0) | 0.0–16.1 | 3.1e-10 | < 0.001 |
| Push Chairs (5 의자) | 16/20 (80) | 58.4–91.9 | 0/20 (0) | 0.0–16.1 | 1.5e-7 | 1.0e-6 |
| High Five | 17/20 (85) | 64.0–94.8 | 17/20 (85) | 64.0–94.8 | 1.00 | 1.00 |

- **해석:** 차이가 큰 네 과제 (Rinse Pan, Call Elevator, Push Chairs, Wipe Wine)는 보정 후에도 유의합니다. 차이가 0 또는 20%p인 Cook Shrimp는 n=5라서 검정 자체가 힘이 없습니다.
- **주의:** 논문은 유의성 검정을 하지 않았습니다. 여기 p값은 **보고된 횟수로 계산한 참고값**입니다. 같은 시드 한 개를 여러 번 평가한 것이라 독립 시드 분산은 빠져 있습니다.
- 과제별 CI 폭은 최대 약 ±20%p입니다. Wipe Wine의 "95%"는 하한 76%, "50%"는 상한 70%입니다.

## 2. 블록 B: 본문의 평균 향상 (표 1, 7과제)

| 항목 | 값 |
|---|---|
| 공동 학습 평균 | 80.0% |
| 공동 학습 없음 평균 | 34.3% |
| **평균 절대 향상** | **45.7%p** |
| 최대 향상 | 95%p (Call Elevator) |

- 논문 서론: "an average of 34% absolute improvement compared to no co-training" (§1). **34%는 공동 학습 없음의 평균 성공률이며, 향상 평균이 아닙니다.** 향상 평균은 45.7%p입니다.
- 논문 초록: "co-training can increase success rates by up to 90%". 표 1의 최대 향상은 95%p이므로 초록은 최댓값을 낮게 씁니다.
- 판정: **두 문장 모두 표와 맞지 않습니다** (불일치). 잘못된 방향 (과소)이라 결론을 부풀리지는 않지만, 독자가 평균을 과소평가하게 만듭니다.

## 3. 블록 C: 표 1 정수 사슬 검사 (하위 과제 → 전체)

| 과제 · 조건 | 하위 과제 값 (%) | 전체 (%) | 판정 |
|---|---|---|---|
| Wipe Wine · 공동 | 100 / 95 / 100 | 95 | 정확 일치 (20 → 20 → 19 → 19) |
| Wipe Wine · 없음 | 95 / 58 / 90 | 50 | **반올림 차이** (19 → 11 (57.9%) → 10/11 (90.9%), 표는 90) |
| Cook Shrimp · 공동 (n=5) | 100 / 100 / 60 / 67 | 40 | 정확 일치 (5 → 5 → 3 → 2) |
| Cook Shrimp · 없음 (n=5) | 100 / 100 / 40 / 50 | 20 | 정확 일치 (5 → 5 → 2 → 1) |
| Rinse Pan · 공동 | 100 / 80 / 100 | 80 | 정확 일치 (20 → 16 → 16) |
| Rinse Pan · 없음 | 100 / 0 / 100 | 0 | 0회 뒤 "Place Pan 100"은 분모가 0이라 정의되지 않음 (표 표기 문제) |
| Use Cabinet · 공동 | 95 / 100 / 95 / 95 | 85 | **반올림 차이** (19 → 19 → 18 (94.7%) → 17/18 (94.4%), 표는 95) |
| Use Cabinet · 없음 | 95 / 95 / 100 / 95 | 85 | **반올림 차이** (같은 끝 단계 17/18) |
| Call Elevator · 공동 | 100 / 100 / 95 | 95 | 정확 일치 (20 → 20 → 19) |
| Call Elevator · 없음 | 100 / 5 / 0 | 0 | 정확 일치 (20 → 1 → 0) |
| **Push Chairs (5 의자) · 공동** | 100 / 85 / 89 | **80** | **불일치** |
| Push Chairs (5 의자) · 없음 | 100 / 70 / 0 | 0 | 정확 일치 |
| High Five | 전체 85 = 17/20 | 85 | 정수 가능 (하위 조건 attire 90, human 80은 별도 평가라 사슬이 아님) |

**Push Chairs 공동 학습 행 (불일치) 자세히:**

- 4번째 의자 85% → 20회 중 17회 성공.
- 5번째 의자는 17회를 시도한 값이어야 합니다. 89%에 가장 가까운 정수는 15/17 = 88.2%입니다.
- 그러면 전체 성공은 15/20 = **75%**가 되는데, 표는 **80%**입니다 (5%p 어긋남).
- 가능한 해석: (a) 5번째 의자 시도 수가 17회가 아니었다 (예: 다른 시도 집합), (b) 전체 값이 다른 평가 묶음에서 왔다. 논문은 둘 중 무엇인지 쓰지 않습니다.

**반올림 차이 (1%p 이내) 세 셀:** 모두 1%p 안쪽의 정수 반올림 문제이므로 결론에는 영향이 없습니다. 다만 Use Cabinet의 "Close Cabinet 95"는 17/18이 94.4%라서 94로 적었어야 합니다.

- 본문 "VINN 공동 학습은 Wipe Wine에서 5%p 하락, Push Chairs에서 20%p 상승": 15−20 = −5 ✓, 60−40 = +20 ✓.

## 5. 블록 E: 절제 실험 (표 3·4, 그림 4)

- 표 3 (정적 비율 30 / 50 / 70%, 20회): 95 / 95 / 90 → 19/20, 19/20, 18/20 (정수 ✓). 본문 "similar performance across the board" 는 맞지만, 차이 5%p는 CI 안에 모두 들어갑니다 (Wilson 95% 약 ±20%p). "민감하지 않다"는 결론은 **이 표로는 판단할 수 없습니다.**
- 표 4 (Wipe Wine): 공동 학습 95 (19/20), 사전학습 **40 (8/20)**, 없음 50 (10/20) → 정수 ✓. 본문 "pre-training provides no improvements over training solely" (§7)은 **40 < 50이므로 사전학습이 10%p 낮습니다.** 문장과 표가 맞지 않습니다 (불일치: 본문이 약하게 씀).
- 그림 4 (데이터 효율): 공동 학습 25 / 35 / 50 시연 → 약 40 / 70 / 95%, 없음 → 약 20 / 30 / 50%. 그림에서 읽은 근사값입니다. 본문 "35 공동 학습 70% 대 50 없음 50%" ✓ (그림과 일치).

## 8. 재계산이 말해 주지 않는 것

- 과제당 20회 평가는 한 정책 (시드 수 미기재)입니다. 시드 간 분산과 학습 반복의 차이는 이 표로 알 수 없습니다.
- 평가 조건 (randomization 범위)은 그림 3 캡션에 있지만, 조건을 바꾼 재평가는 없습니다.
- 공동 학습 효과가 "정적 데이터의 로봇 움직임 유사성" 때문인지 "손목 카메라 불변성" 때문인지는 구분되지 않습니다 (논문 §6.1은 둘 다 추측).
