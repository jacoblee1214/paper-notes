# 03. 수치 재계산, 검정, 일관성 검사

재현(학습·실행)은 하지 않았습니다. 논문에 보고된 표·그림 수치만 다시 계산했습니다. 스크립트는 `analysis/recompute.py`(수 초), 그래프는 `analysis/plot_figures.py`, 결과는 `analysis/recompute_results.json`입니다.

**가정.** 각 셀은 **50 rollouts**입니다(§4.1, Table 3·4 설명). 시드 수는 보고되지 않았으므로 셀 하나는 한 번의 학습과 50회 평가로 봅니다. 검정은 Fisher 정확 양측 검정을 쓰고, 여러 비교의 보정은 하지 않았습니다(목록이 짧고 비교가 대부분 명확해서). 반올림 차이는 ±0.1%p로 봅니다.

- 셀 평균과 pooled 평균이 같습니다(셀 n이 같기 때문). 세 정책 합계는 16/1350 = 1.19%입니다.
- 정수성 검사 통과(V1). 9셀 모두 2%의 배수입니다.

### 1.4 Figure 7과 21.24%

**Fig. 7 파이(전체)** 값 38.5, 22.0, 10.6, 28.8은 정책별 값의 무가중 평균(38.53, 21.97, 10.67, 28.80)과 맞습니다. 합은 89.3%입니다(본문 "약 89%"와 일치, V7·V10).

**21.24%는 재구성되지 않습니다(V8).** 본문은 21.24%를 두 곳에서 씁니다. (1) "파지에 성공한 궤적 비율"(§4.3 첫 문단). (2) "던지기 단계에 도달한 궤적 평균 비율"(§4.3 둘째 문단). 같은 값을 두 뜻으로 씁니다. 재구성은 다음과 같습니다.

- 실패 중 던지기 오류 비율(Fig. 7) × 실패 개수 + 성공 개수 = 던지기 시도 수
- GR00T 70/450 = 15.6%, DynamicVLA 16/450 = 3.6%, ForceVLA 71/450 = 15.8%, 평균 **11.6%**
- DynamicVLA의 3.6%는 본문 "파지 3.57%"(§4.3)와 맞습니다. 다른 두 정책에도 같은 방법을 쓰면 21.24%가 나오지 않습니다.
- 던지기 성공률 "5.6%"(본문, 1.2%를 21.24%로 나눈 값)도 같은 문제를 가집니다. 재구성 기준으로는 16/157 = **10.2%**입니다.

가능한 설명은 두 가지입니다. (a) 21.24%가 다른 정의(예: 파지 단계 전체 시도, 또는 다른 시행 집합)로 계산되었다. (b) 오타다. 논문만으로는 구분할 수 없습니다. 결론은 "본문 수치 중 하나가 Fig. 7 및 Table 1과 맞지 않는다"입니다.

## 2. 검정 결과 (Fisher 정확 양측, 원 p값)

| 비교 | 성공 | p |
|---|---|---|
| 시뮬 pooled: ForceVLA 대 GR00T | 11/450 대 4/450 | 0.12 |
| 시뮬 pooled: ForceVLA 대 DynamicVLA | 11/450 대 1/450 | 0.006 |
| 시뮬 α=1 정적 단일: ForceVLA 대 GR00T | 5/150 대 3/150 | 0.72 |
| 시뮬 α=0 대 α=1: ForceVLA | 53/150 대 5/150 | 3 × 10⁻¹³ |
| 시뮬 α=0 대 α=1: GR00T | 14/150 대 3/150 | 0.010 |
| 휴머노이드: ForceVLA 대 GR00T | 13/150 대 9/150 | 0.51 |
| 휴머노이드: ForceVLA 대 DynamicVLA | 13/150 대 1/150 | 0.001 |
| 실물: ForceVLA 대 GR00T | 77/150 대 16/150 | 1 × 10⁻¹⁴ |
| 실물 큐브 3: ForceVLA 대 GR00T | 20/50 대 2/50 | 2 × 10⁻⁵ |
| 실물 GR00T: 큐브 1 대 큐브 3 | 8/50 대 2/50 | 0.09 |
| 균일 단일 GT 효과: ForceVLA | 12/50 대 5/50 | 0.11 |

**읽는 법:**

- **무작위화 효과(α)는 명확합니다.** ForceVLA는 p = 3 × 10⁻¹³입니다. 이 결론은 튼튼합니다.
- **F/T 입력의 효과는 환경에 따라 다릅니다.** ForceVLA 대 GR00T 차이가 시뮬(α=1)에서는 p = 0.72, 실물에서는 p ≈ 10⁻¹⁴입니다. 저자는 실물 차이를 F/T 입력 탓으로 돌립니다(§4.3). 그러나 같은 입력이 시뮬에서는 차이를 만들지 못합니다. 실물 조건(고정 셋업, 큐브당 시연 300회)과 시뮬 조건(과제별 미세조정, 시연 수 미보고)의 차이를 분리할 수 없습니다. 이 교란은 논문이 확인하지 않은 가정입니다.
- **시뮬 정책 간 비교는 검정력이 낮습니다.** 셀당 50회일 때 80% 검정력에서 찾을 수 있는 최소 차이는 p₀ = 2%에서 약 17%p, p₀ = 6%에서 약 21%p, p₀ = 10%에서 약 23%p입니다(V6). GR00T 대 ForceVLA(2–10%) 사이의 차이는 이 범위 안에 있습니다.
- 실물 비교는 셀당 150회라서 검정력이 충분합니다. 그러나 **한 번의 학습**이라서 학습 시드 변동이 들어 있지 않습니다.

## 4. 식 (2)의 질량 의존성 점검

논문 식 (2)는 p_r + τ v_r + ½ g τ² = p_dst(T+τ) + (δ_x, δ_y, 0)ᵀ입니다. 식 (1)은 q_r에서 p_r과 v_r을 주고, 던지기 계획은 릴리스 상태 (q_r, q̇_r)와 T, τ를 정합니다(§3.2.3). 이 식에는 **질량, CoM, 마찰이 없습니다.** 또 릴리스 뒤 비행은 드래그 없는 탄도 운동이라고 가정합니다.

따라서 계획기가 계산하는 릴리스 상태는 물체 질량에 따라 변하지 않습니다. 질량은 다음 경로로만 결과에 들어갑니다.

1. 파지가 릴리스까지 고정이라는 가정이 깨지는 경우(슬립은 마찰에 의존, §3.2.3).
2. 페이로드가 관절 추종 오차를 만드는 경우(§3.2.3, "tracking error under the payload's mass and CoM").
3. 릴리스 시각의 지연(release delay).

즉 "질량을 추정해야 한다"는 주장은 실제로는 **추종 오차와 슬립을 보정해야 한다**는 주장으로 바뀝니다. 이 구분은 논문에 없습니다. 이 점검은 식의 구조에 대한 대수적 확인이고, 수치 시뮬레이션은 하지 않았습니다. 시뮬레이션 없이는 추종 오차의 크기를 알 수 없습니다.

**δ 갱신 규칙** δ_{k+1} = δ_k − 0.5 e_k(§3.2.3)는 오차가 선형으로 δ에 반응한다고 가정합니다. 게인 0.5는 이 가정 아래에서 한 번 보정할 때 오차가 절반으로 줄어든다는 뜻입니다. 수렴 조건은 논문에 없습니다.

## 6. 실행하지 않은 것

- **CPU 토이는 만들지 않았습니다.** 논문의 핵심 주장(물리 입력이 성공률을 올린다, 실패가 던지기 이전에 일어난다)은 시뮬레이터 없이는 검증할 수 없습니다. 식 (2)의 구조 점검은 대수로 했고, 추종 오차를 넣은 토이는 설계 근거가 부족합니다(매니퓰레이터 동역학, PD 게인, 페이로드 모델 전부 논문에 없음).
- **통계는 셀 n = 50을 가정했습니다.** 원자료(롤아웃별 결과)가 공개되면 검정을 다시 해야 합니다.
