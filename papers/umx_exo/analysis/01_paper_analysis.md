## 1. 한눈에 보는 주장

UME는 **상체 외골격 텔레오퍼레이션 장치**입니다. 팔로워 로봇이 접촉에서 받는 관절 토크를 사람이 팔로 직접 느끼게 하고(Cap1), 팔 전체 관절 구성을 기록해 여러 로봇에 재타깃팅하며(Cap2), IMU 하나로 이동 베이스를 몰 수 있게 합니다(Cap3)(§1). 이 장치로 모은 시연으로 ACT(Action Chunking with Transformers)에 토크 입력을 더한 정책을 학습하면 네 과제에서 85–95%의 성공률을 낸다고 주장합니다(표 1).

- **하드웨어 주장.** 재료비 $1,900(표 4), 약 12 kg, PLA 링크, 성인이 최대 2시간 착용 가능(부록 E.1), 인간 팔의 3-1-3 구조에 맞춘 동축 액추에이터 배치(§2.1).
- **방법 주장.** 팔을 가상 구면 어깨(3자유도)–팔꿈치(1)–가상 구면 손목(3)으로 나눠 위치·속도·토크를 독립 재타깃팅합니다(§2.2). 특이점이 6D 말단 제어보다 적고 예측 가능하다고 주장합니다.
- **학습 주장.** 토크를 관절 위치와 같은 방식으로 처리한 임베딩을 이미지 임베딩에 붙여 ACT에 넣습니다(§2.4). 토크가 없는 기준선(No-torque)과 말단 6D 자세만 쓰는 기준선(UMI)보다 낫다고 합니다.
- **수집 처리량.** 토크 피드백이 있으면 박스 뒤집기 수집이 3.3배, 사람 직접 시연의 71%라고 합니다(그림 5).

## 2. 방법

### 2.1 기구 설계 (§2.1, 부록 E)

- J1–J3(어깨)의 축이 어깨 구면 중심에서 만나고, J5–J7(손목)의 축이 손목 구면 중심에서 만나는 **동축 배치**입니다(Zimmermann 외 [26, 27]를 따름). J4는 팔꿈치 한 축입니다. 링크가 사람 동작을 덜 막아 손목 가동 범위 대부분과 어깨의 "대부분"을 재현한다고 합니다(그림 9).
- 액추에이터는 Damiao DM-J4340-2EC(9 Nm, 362 g, 40:1) 8개와 DM-J4310-2EC(3 Nm) 8개입니다(어깨·팔꿈치 4개씩 두 팔, 손목 3개와 그리퍼 1개씩 두 팔). 더 큰 감속비의 Dynamixel 대신 **준직접구동(낮은 감속비)** 계열을 써서 백드라이브성과 토크 투명성을 얻는다는 것이 핵심 논리입니다(§1, 부록 E.1).
- **재료비 $1,900**(표 4)에는 모터 16개 $1,640이 86%입니다. 컴퓨터, 3D 프린터, 공구, 인건비는 포함되지 않습니다(`03` K 항목).

### 2.2 범용 재타깃팅 (§2.2, 부록 C, 그림 2, 6)

세 하위 매니퓰레이터로 나눕니다. 어깨(q₁–q₃)와 손목(q₅–q₇)은 구면 관절로 다룹니다.

- **위치 피드포워드.** R_shoulder = f_FK(q_exo,shoulder) ∈ SO(3), 로봇 쪽은 q_robot,shoulder = f_IK(R_shoulder). 팔꿈치는 그대로 거울 대응(q_robot,elbow = q_exo,elbow).
- **속도 피드포워드.** ω = J_exo · q̇_exo, q̇_robot = J_robot† ω, 여기서 J† = (JᵀJ)⁻¹Jᵀ (§2.2). 3×3 정사각이면 J⁻¹입니다.
- **토크 피드백.** F = J̄ᵀ τ_robot, J̄ = A⁻¹Jᵀ(JA⁻¹Jᵀ)⁻¹ (동적 일관 역행렬, A는 관절 공간 관성). 3×3이면 J̄ = J⁻¹. 외골격 토크 τ_exo = J_exoᵀ F. 팔꿈치는 직접 대응. 부록 C의 그림 6은 같은 사상을 (J_robotᵀ)† 형태로 적습니다.
- **명령 토크.** τ_cmd = c(q, q̇) + g(q) + f(q̇) + τ_feedback (부록 C.1). 코리올리·중력·마찰 보상을 더합니다.
- 이 설계가 "6D 말단 제어의 특이점을 피한다"고 주장합니다(§2.2). 이 주장의 한계는 `03` T1에서 토이로 살펴봤습니다.
- 지원 로봇: OpenArm(실물), X-ARM 6DoF(실물, 블록 집기와 건네기), Franka 7DoF(시뮬레이션만, MuJoCo)(부록 C.2). Franka 실물은 납품 지연으로 못 했다고 §5가 밝힙니다.

### 2.3 휴대성과 모바일 조작 (§2.3, 부록 E.4)

- Yahboom IMU(약 $9)의 3축 오일러각을 이동 베이스 속도 [ẋ, ẏ, θ̇]에 선형 매핑합니다(VR 헤드셋 약 $300로 대체 가능하다고 함). 중력 보상은 IMU 자세로 구합니다.
- 팔로워는 자체 제작 이중 팔 모바일 매니퓰레이터입니다. WowRobo OpenArm 1.0(양팔 $5,200), Hexfellow PCW-25 파워 캐스터 4개($900씩), DJI Power 1000 배터리, 어안 카메라 3대(머리 1, 손목 2). 총 $9,533.1(표 5). Tidybot++의 스워브 모듈($300)을 더 낮은 감속비·백래시의 PCW-25로 바꿔 순응성과 오도메트리가 좋아졌다고 합니다.

### 2.4 정책 학습 (§2.4, 부록 D)

- ACT [13]. 토크는 관절 위치와 같은 방식으로 처리해 임베딩을 이어 붙여 ResNet18 이미지 임베딩에 덧붙입니다. 출력은 목표 관절 위치이고, "이 목표 위치가 관절 순응 정보를 담아 로봇 출력 토크를 정한다"고 합니다(§2.4). 즉 **정책이 토크를 직접 내지 않고 위치 목표를 내며**, 팔로워 쪽 PD가 순응성을 정합니다.
- 표 3: 배치 200, 인코더 4층, 디코더 7층, FFN 3200, 은닉 512, 8헤드, 트랜스포머 lr 1e-4, 백본 lr 1e-5, 드롭아웃 0.1. 40k 스텝, RTX 4090 한 장, 8시간.
- 과제별 시연 수: 박스 밀기 26, 박스 뒤집기 40, GPU 집기 42, 냉장고 음료 157.

|---|---|---|
| 박스 밀기 | 숨은 물체 때문에 틈이 남지 않을 때까지 큰 박스를 PC 사이로 밀기. 시각으로 틈을 볼 수 없어 토크로 판단 | Ch1, Ch3 |

| GPU 집기 | 데스크톱 두 대 사이 약 5 mm 여유 공간에서 GPU 카드를 꺼내기. 팔을 완전히 펴야 닿음 | Ch2, Ch1, Ch3 |

### 3.3 이 논문이 보여 준 것과 못 보여 준 것

보여 준 것은 (i) 토크 피드백 장치를 낮은 비용에 만들 수 있고 시연 수집이 가능하다는 **시스템 증명**, (ii) 토크 입력이 박스 뒤집기·밀기에서 큰 차이를 만든다는 사실입니다(`03` V3: 뒤집기 p = 3e-8, 밀기 p = 0.014). 못 보여 준 것은 아래와 같습니다.

- **토크 입력 효과가 GPU 집기(15/20 대 19/20, p = 0.18)와 냉장고 음료(18/20 대 19/20, p = 1)에서는 검출되지 않습니다.** 본문은 이 두 과제에서도 토크의 중요성을 서술하지만 표는 지지하지 않습니다(`03` V3).
- **"토크 피드백이 시연 데이터를 좋게 한다"와 "토크 입력이 정책을 좋게 한다"를 분리하지 않았습니다.** No-torque 정책도 토크 피드백으로 모은 같은 데이터로 학습했습니다(§3). 즉 피드백의 데이터 품질 효과는 표 1에서 빠져 있고, 토크 피드백 없이 수집한 데이터로 학습한 정책이 기준선에 없습니다(처리량 비교만 있음).
- **UMI 기준선은 UMI 하드웨어·데이터가 아닙니다.** 같은 UME 시연의 말단 자세만 써서 ACT로 학습하고 전신 IK로 변환합니다(§3). 따라서 "UMI 대비 우위"는 UMI 방식 일반이 아니라 "이 구현의 말단 자세+IK 경로" 대비입니다. 공식 코드의 IK에는 충돌 회피 항이 없습니다(`04` D13).
- **초기 조건, 시드, 반복 학습 횟수가 없습니다.** 방법당 20회, 분산 없음, 학습은 구성당 한 번으로 보입니다(§3, 부록 D).
- **상대 지표가 없습니다.** 안전성(충돌 횟수, 접촉력 크기), 접촉력 조절 정밀도는 정량하지 않았습니다. "순응적"이라는 주장은 성공률로만 간접 확인됩니다.

## 4. 한계 (논문과 우리 관찰)

논문 §5의 한계: PLA 링크(무게, 낮은 하중), 링크 길이 고정, Franka 실물 미검증.

우리가 추가로 확인한 한계:

1. 재료비 $1,900은 모터 중심 부품 합계입니다. 팔로워 로봇 $9,533, CAN 어댑터, 컴퓨터, GPU(RTX 4090)가 별도입니다.
2. 12 kg은 "lightweight"라는 초록 표현과 긴장 관계에 있습니다. 2시간 착용이 한계입니다(부록 E.1).
3. 실험 로봇은 자체 제작 모바일 매니퓰레이터 하나입니다. "universal"은 재타깃팅 설계의 범위이고, 학습 결과는 한 팔로워 형태에서만 확인했습니다.
4. 공식 코드의 되돌림 경로에는 논문에 없는 이득 0.5, 추종 오차 문턱, 4 Nm 클립이 있습니다(`04` D1–D3). "투명한 토크 피드백" 서술과 정량이 다릅니다.

## 5. 선행연구와의 연결 요약 (자세한 계보는 `02`)

- 순응 정책 학습 계열: Adaptive Compliance Policy(강성 예측 + 고정 어드미턴스), Compliant Residual DAgger 같은 상위 위치 정책 + 하위 순응 제어기 구성과, 정책이 토크를 직접 내는 구성의 중간입니다. UME는 위치를 내고 팔로워 PD가 순응을 정합니다(`04` D5).
- 텔레오퍼레이션 계열: ALOHA, GELLO(토크 노출 없음), AirExo(비동형), HOMIE(발 페달 이동), 핸드헬드 UMI 계열(말단 자세만).
