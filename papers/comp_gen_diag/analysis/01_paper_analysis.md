## 1. 한 문단 요약

로봇 조작에서 지시를 `(객체, 컨테이너, 버튼)`처럼 이산 인자의 순서쌍으로 주고, 학습 지시 집합의 **어느 조합**을 시연으로 채워야 처음 보는 조합(OOD)에서 성공하는지를 묻습니다. 일반화 격차를 **주변 지시 이동, 지시 조합 이동, 맥락-행동 이동** 세 항의 상한으로 분해하고(정리 4.1), 시뮬레이션에서 흐름 매칭 정책을 처음부터 학습해 세 질문을 실험합니다. Q1: 전체 조합이 필요한가. PPP(64과제)에서 무작위 16과제는 OOD 성공 약 74%이고, 모든 쌍 조합을 한 번씩 담은 직교 16과제는 78.2%로 전체 학습의 78.6%에 가깝습니다. Q2: 희소 학습이 실패하는 이유는 기술 부족인가 경로 선택인가. 대각 4과제로 사전학습한 정책은 OOD 0.4%인데, 64과제에 과제당 1회씩만 파인튜닝하면 54.7%입니다. Q3: 의존 지시에서는 어떤 커버리지가 필요한가. 첫 컨테이너가 두 번째 컨테이너와 달라야 하는 2단계 과제에서 (객체1, 컨테이너2) 쌍 커버리지를 6, 9, 12, 16으로 늘리면 OOD 성공이 9.2%에서 31.4%로 오릅니다. 결론은 "전수 조합이 아니라 의존 관계를 덮는 구조적 부분집합을 모으라"입니다.

## 2. 문제 설정과 이론 (§3, §4, 부록 A)

### 2.1 형식화 (§3)

- 지시 `l = (l_1, ..., l_n) ∈ L_1 × ... × L_n`, 맥락 `z`, 행동 `a`. 정책은 `p(a | z, l)`, 단계 지시자 `σ(z)`가 현재 활성 하위 과제를 가리킵니다.
- 학습 지원 `E_train = supp(p(l))`(식 1), 시험 지원 `E_total`, OOD 집합 `E_ood = E_total \ E_train`.
- 위험 `R_D(θ) = ∫ D(z,a,l) L_θ(z,a,l)`(식 3), 격차 `Δ_q(θ) = R_q(θ) − R_p(θ)`(식 4). 손실은 흐름 매칭 손실입니다.

### 2.2 정리 4.1 (식 5, 증명은 부록 A)

손실이 `0 ≤ L_θ ≤ M`이면 임의의 인자 `i`에 대해

`|Δ_q| ≤ M ( ‖q(l_i) − p(l_i)‖₁ + E_{l_i~p}‖q(l_{-i}|l_i) − p(l_{-i}|l_i)‖₁ + E_{l~p}‖q(z,a|l) − p(z,a|l)‖₁ )`.

증명은 `q·q·q − p·p·p`를 세 번에 나눠 빼는 표준 전개이고, 각 항에 `L ≤ M`을 씁니다. 항별 해석은 주변 이동(학습에 없는 값), 조합 이동(알려진 값의 낯선 조합), 맥락-행동 이동입니다. 이산 분포에서 임의로 뽑은 200개 경우에 분해식과 부등식이 모두 성립함을 확인했습니다(`03` V14). 읽을 때 주의할 점이 둘 있습니다.

1. 부등식의 우변에는 정책 `θ`가 `M`으로만 들어옵니다. 정리는 분포 이동의 크기를 말하며 "쌍 커버리지가 이 항을 줄인다"는 §5.2의 서술은 식 5에서 직접 나오지 않고 해석으로 덧붙은 것입니다. 균형 잡힌 16과제 설계에서 둘째 항은 설계와 무관하게 1.5입니다(`03` V14).
2. 셋째 항의 기댓값은 `l ~ p(l)`, 즉 학습 지시에 대해서만 취합니다. 시연 생성기가 같은 지시에 같은 행동 분포를 낸다면 이 항은 0이고, 식 5는 주변항과 조합항만 남습니다.

### 2.3 따름정리 4.2: 단계별 모듈러 정책

`π_θ(a|z,l) = π_{θ,σ(z)}(a | z, l_{σ(z)})`로 활성 지시만 보면 손실이 `Σ_i 1{σ(z)=i} ℓ_{i,θ}(z,a,l_i)`로 쓰이고, 조합항 `q(l_{-i}|l_i)`가 사라집니다(식 6). 대신 `p(z,a|l_i)`가 `l_{-i}`에 대해 주변화되어 있으므로 비활성 지시가 만드는 맥락 이동은 남습니다. 또 `l_{-i}`가 행동에 영향을 주면 `p(a|z,l_i)`가 모호해져 정보 병목이 생긴다고 쓰고, 2S-PP로 보입니다(§5.4).

## 3. 실험 설정 (§5.1, 부록 B)

| 과제 | 지시 | 과제 수 | 시연 풀 (부록 B.1) |
|---|---|---|---|
| PP (Pick-and-Place) | (객체 o, 컨테이너 c) | 4 × 4 = 16 | 과제당 500, 합계 8,000 |
| PPP (Pick-Place-Press) | (o, c, 버튼 b), 인자 독립 | 4 × 4 × 4 = 64 | 과제당 300, 합계 19,200 |
| 2S-PP (의존 2단계) | 전체 (o1, c1, o2, c2), o1≠o2, c1≠c2 | 4 × 4 × 3 × 3 = 144 | 과제당 100, 합계 14,400 |

- 2S-PP에서 정책은 부분 지시 `(o1, o2, c2)`만 받고 c1은 추론해야 합니다. 학습 시연은 각 지시마다 모든 유효한 c1 ≠ c2를 포함합니다(§5.1).
- 시뮬레이터: robomimic 위에 만든 과제(§5.1). 시연은 맞춤 모션 플래너로 생성합니다.
- 정책(부록 B.2, 그림 10): 두 카메라(3인칭, 손목)와 로봇 상태, 동결 DINOv2 영상 인코더, 지시 하나당 토큰 하나를 질의(Q)로 삼고 영상 토큰을 키·값으로 하는 Q-Former 형태의 융합, 출력 토큰을 교차 주의로 받는 트랜스포머 흐름 매칭 행동 디코더. 행동은 말단 위치·자세 변화량과 그리퍼 개폐입니다.
- 학습(부록 B.1): 배치 64, PPP 100k 스텝, 2S-PP 150k 스텝. 파인튜닝은 5k 스텝(부록 D). 크기 B를 비교할 때는 총 시연 수를 고정하고 B개 과제에 균등 배분하며, 총량은 "가장 작은 집합이 가진 데이터로 제한"됩니다. 그 총량의 숫자는 적혀 있지 않습니다.
- 평가(§5.1, 부록 B.3): 전체(Total), 학습 과제(ID), 보류 과제(OOD) 성공률. 별도 언급이 없으면 학습 시드 3개, 과제·시드당 30회(v2). 2S-PP는 같은 컨테이너 위반율을 따로 냅니다. Q1에서 각 B의 학습 과제는 모든 인자 값이 적어도 한 번 나오도록 뽑습니다.

## 4. 결과

### 4.1 Q1: 전체 조합이 필요한가 (§5.2, 부록 C)

- **PP, PPP (그림 2).** B가 작으면 모든 인자 값을 덮어도 OOD 성공이 낮고, PP는 B = 8 근처, PPP는 B = 16 근처에서 전체 학습과 비슷해집니다. 내보낸 파일의 PPP 무작위 집합 평균 OOD 성공은 B = 4(대각)에서 0.4%, B = 8 32.4%, B = 12 64.4%, B = 16 73.8%, B = 24 76.2%이고 전체 64과제는 78.6%입니다(`03` V3).
- **손실 분석 (§5.2).** B = 4, 8, 16 체크포인트에서 보류 지시 1,000개 시연의 흐름 매칭 손실: ID는 0.00648, 0.00663, 0.00667로 거의 일정하고, OOD는 0.03421, 0.01548, 0.00756으로 줄며 OOD 성공은 0.83%, 23.93%, 82.29%입니다. ID와 OOD 손실 비는 5.3배, 2.3배, 1.1배입니다. 저자는 이를 맥락-행동 이동이 작아진 증거로 읽습니다.
- **본 쌍 수 (그림 3).** 보류 과제 `(o, c, b)`에 대해 `(o,c), (o,b), (c,b)` 중 학습에 나온 쌍의 수(0–3)를 세면, 같은 B 안에서 이 수가 클수록 OOD 성공이 높고 효과는 B ≤ 12에서 큽니다.
- **직교 16 (그림 4).** 16과제가 모든 쌍 조합을 정확히 한 번씩 담습니다. 이 16과제는 `버튼 = 객체 XOR 컨테이너` 규칙(색 순서 red, green, blue, yellow)으로 만들어진 것과 일치합니다(`03` K1). 이 설계에서는 48개 보류 과제가 모두 세 쌍을 모두 본 과제입니다. OOD 78.2%, 전체 학습 78.6%.
- **고정 예산 (그림 5).** 총 시연 64, 128, 256, 512, 1,024에서 직교 16이 전체 64과제보다 낮은 예산에서 높고 예산이 커지면 격차가 줄어듭니다. 이 그림의 숫자 파일은 공개 목록에 없어 재계산하지 못했습니다.
- **부록 C.** PPP 55개 설정(그림 11), 사람 시연(Isaac Lab, 객체 3 × 컨테이너 3 × 목표 3 = 27과제, 직교 9과제로 학습, ID 11.67%, OOD 12.96%).

### 4.2 Q2: 희소 학습이 실패하는 이유 (§5.3, 그림 6, 7, 부록 D)

- 대각 `{(0,0,0),(1,1,1),(2,2,2),(3,3,3)}`로 100k 스텝 사전학습하면 ID는 높고 OOD는 0에 가깝습니다. 64과제 전체에 과제당 시연 1개(총 64개)로 5k 스텝 파인튜닝하면 사전학습에 없던 과제의 성공이 0.4%에서 54.7%로 오르고, 같은 총 시연으로 처음부터 학습하면 훨씬 낮습니다(내보낸 값 0.3%). ID 성공은 파인튜닝 뒤 줄어듭니다(83.3 → 76.7 → 61.7%).
- 직교 16으로 파인튜닝해도 비슷한 경향이고, B = 6, 8, 16 사전학습 체크포인트에서도 비슷합니다(부록 D, 그림 12, 13). 사전학습이 이미 좋으면(직교) 파인튜닝이 오히려 성능을 낮출 수 있다고 적습니다.
- 그림 7: 파인튜닝 시연이 16 또는 32개일 때 직교 집합이 무작위 5집합보다 OOD가 높다고 합니다.
- 결론 문장: 희소 학습은 "재사용 가능한 하위 기술"은 배우지만 "새 지시 조합에서 그 기술을 고르는 연결"을 배우지 못한다.

### 4.3 Q3: 의존 지시 (§5.4, 그림 8, 9, 부록 E)

- 2S-PP 36과제(o1 4값, o2 남은 3값, c2 3값): (o1, c2) 쌍 커버리지를 Cov12, 9, 6, 4로 줄이면서 학습 과제 수는 12로 고정합니다(그림 8, 14). OOD 성공은 Cov4 1.2% → Cov12 18.5%(그림 14), 같은 컨테이너 위반율은 Cov4에서 높습니다. ID 성공은 쌍이 적을수록 오히려 높고, 저자는 쌍당 감독 밀도 때문이라고 설명합니다.
- 48과제(c2 4값, 5시드·과제당 10회, 학습 과제 16개 고정): Cov6, 9, 12, 16 (그림 15, 16). OOD 성공 9.2%, 18.9%, 25.9%, 31.4%, 전체 학습 34.3%.
- **오라클 단계 지시자 정책 (그림 9).** 비활성 지시를 빼고 활성 지시만 주면 PPP에서는 희소 커버리지에서도 OOD가 높지만(그림 9a), 2S-PP에서는 c2를 볼 수 없어 같은 컨테이너 위반율이 전체 지시 정책보다 높습니다(그림 9b). 그래서 전체 지시 정책에 집중한다는 결론입니다.
- **c1이 빠진 부분 지시.** PP 보조 실험(5시드)에서 컨테이너 지시를 빼면 성공이 71.05 ± 5.00%에서 49.95 ± 1.14%로 떨어진다고 적습니다. 첫 배치의 다봉성이 2S-PP 실패의 한 요인이라고 해석합니다(부록 E).

### 4.4 평가 시도 수 민감도 (부록 B.3, 표 1)

2S-PP에서 과제당 시도 수를 5, 10, 15, 30으로 바꾸면 ID 56.25, 63.75, 62.92, 61.88%, OOD 15.00, 15.70, 16.30, 15.89%입니다. 본문은 15 → 30에서 ID 1.04, OOD 0.41 포인트만 변해 30회 선택을 뒷받침한다고 씁니다(`03` V11).

## 5. 저자가 밝힌 한계 (§6)

1. 작은 순차 조작 과제 몇 개에 한정(시연과 평가 과제가 지시 복잡도에 지수적으로 늘기 때문). 대규모 학습과 사전학습에의 시사점은 후속 과제.
2. 정책이 동결 비전 인코더 위에서 처음부터 학습된 것에 한정. 사전학습된 VLA로의 확장은 후속 과제.
3. 같은 부록 E는 2S-PP에서 c1이 빠지면 시연 분포가 다봉이 되고 학습이 어려워진다고 적으며, 다봉 시연 학습 개선을 후속 과제로 남깁니다.
