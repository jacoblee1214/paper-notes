# 03. 수치 재계산과 일관성 검사

재계산 스크립트: `analysis/recompute.py` → `analysis/recompute_results.json` (numpy, scipy, 1초 미만). 입력은 논문 본문·표·부록에 적힌 값뿐입니다. 학습, 시뮬레이션, 가중치 다운로드는 하지 않았습니다 (재현 대상이 아님, `04_claim_verification.md` §4 참조).

**결과 요약: 보고된 집계 수치는 대부분 정수 계수와 맞습니다. 틀린 값은 찾지 못했습니다.** 다만 NAVSIM 주 결과의 불확실성 구간은 논문에 없어 재계산할 수 없습니다.

## 2. 목표 선택 효과의 불확실성

| 방법 | 값 | 설명 |
|---|---|---|
| 나이브 두 비율 차이 95% CI (제안 독립 가정) | [12.21, 22.09] pp | 독립 가정이라 **과소 추정**. 실제 구간은 더 넓어야 함 |
| 논문의 세션 부트스트랩 95% CI | [11.88, 21.79] pp | 나이브 구간과 비슷함. 같은 클러스터 구조를 반영했다면 타당 |
| 개선 참조 비율 95% (Clopper-Pearson, 228/241) | [90.95, 97.10]% | 논문: [90.1, 97.9]%. 논문은 세션 부트스트랩이라 구간이 더 넓음. 모순 아님 |
| 참조별 부호 검정 (228 개선 대 11 악화, 동률 2 제외) | p ≈ 7 x 10⁻⁵⁴ | 참조별로 세 시드 평균을 낸 뒤의 차이에 대한 검정. 참조 독립을 가정 |

- 판단: **목표 선택 효과는 시드와 참조 수준에서 강하게 뒷받침됩니다.** 다만 세 시드는 학습 무작위성만 반영하고, 한 개발 세트(241 참조, 32 세션)에서 나온 결과입니다. 다른 장면 분포에서도 같은지는 검증되지 않았습니다.
- 참조별 중앙 실행 여유 차이 (16.45 − 4.32 = 12.13 cm)와 쌍 중앙값 차이 (14.20 cm)는 다릅니다. 쌍 중앙값은 참조 수준 차이의 중앙값이라 주변 중앙값의 차이와 같지 않습니다. 논문 부록 D의 설명과 같습니다.

## 3. NAVSIM 주 결과의 통계 근거: 계산할 수 없는 부분

- 논문은 NAVSIM v1 PDMS 차이 (EAS → FCRS +0.56, FCRS → CAST +0.21)에 **구간이나 시드 표준편차를 주지 않습니다.** 부록 C의 부트스트랩은 목표 선택 실험에만 있습니다.
- 장면별 PDMS 차이의 표준편차를 모르므로 직접 계산할 수 없습니다. 대신 **필요 조건**을 계산했습니다. 장면 12,146개를 독립 쌍으로 보고 95% 수준에서 0.56점 차이가 0이 아니려면, 장면별 차이의 표준편차가 약 **31.5점** 이상이어야 합니다 (`navsim_sd_needed_points`).
- 판단: PDMS는 0–100 척도이고 대부분 장면이 높은 값이므로 장면별 차이의 표준편차가 31.5점을 넘을 가능성은 낮습니다. 그래서 **0.56 차이는 독립 가정 아래 대체로 유의할 것으로 보입니다.** 하지만 장면이 세션에 묶여 있으면 실효 표본이 줄어드므로 이 판단은 조건부입니다. 확인하려면 장면별 점수가 필요합니다 (공개되지 않음).

## 5. 파라미터 수와 PDMS 상한

**파라미터 (부록 A.3):** 모두 정확히 맞습니다.

| 부분 | 계산 | 보고 |

| 잔차 MLP 96→64→32→2 | 6,208 + 2,080 + 66 = 8,354 | 8,354 |
| 학습 가능 합 | 24,770 | 24,770 |
| 학생 전체 | 183,620 | 183,620 |

**PDMS의 상한 (식 S5):** NC, DAC는 장면별 0/1이고 S = (5EP + 5TTC + 2C)/12는 0–1이므로 PDMS = E[NC·DAC·S] ≤ E[S]. E[S]는 평균의 선형 결합이라 정확히 계산됩니다.

| 방법 | E[S] | 보고 PDMS | 판정 |
|---|---|---|---|
| WorldDrive | 91.04 | 89.0 | 상한 이내 |
| FCRS | 91.71 | 91.0 | 상한 이내 |
| CAST | 91.79 | 91.2 | 상한 이내 |

**평균끼리 곱한 값 (근사치, 참고):** WorldDrive 86.7, FCRS 89.5, CAST 89.9. 보고 PDMS는 이 값과 상한 사이에 있습니다. 장면별 곱의 평균은 평균끼리의 곱과 다르므로 정상이지만, 집계 수치만으로 PDMS를 정확히 재현할 수는 없습니다.

**표 1의 ΔPDMS:** 모든 행에서 PDMS − 89.0과 일치합니다.

## 9. 이 분석에서 하지 않은 것

- **토이 실험은 만들지 않았습니다.** 브리프의 "중심 주장을 직접 검증하는 작은 CPU 토이 (2분 이내)"는 선택 사항이었고, 이 논문의 중심 주장 (목표 여유가 모방 오차를 흡수)은 실행 장치와 차량 모델에 의존해서 토이로 옮기면 가정을 새로 넣게 됩니다. 필요하면 별도 설계를 거쳐 시작할 수 있습니다 (사용자 확인 후).
- 시드 단위 원자료가 없어 세 시드 SD와 부트스트랩을 재현하지 못했습니다.
