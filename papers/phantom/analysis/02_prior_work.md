# Phantom 선행연구와 구성 요소 (02)

분석일 2026-11-22. 원문은 `paper/paper.txt`(v2)입니다. 논문 본문과 부록 6.1(표 4)의 인용을 따랐고, 인용하지 않은 주장은 쓰지 않았습니다.

## 1. 계보: 사람 영상을 로봇 학습에 쓰는 흐름

논문은 사람 영상 활용을 네 갈래로 나눕니다(2.1절).

1. **사람 영상으로 표현을 미리 학습하거나 보상을 만드는 방법** (R3M, VIP, OpenVLA 계열의 사전 학습 등). 로봇 데이터가 많이 필요합니다.
2. **사람 시연을 운동 사전 분포로 쓰는 방법** (MimicPlay, Bahl 2022, XSkill). 계층 구조이고 대부분 로봇 데이터를 씁니다.
3. **물체 중심 방법** (Ditto, ScrewMimic, Orion, SPOT). 물체 자세 추적을 전제하므로 변형체, 여러 물체에 약합니다.
4. **흐름과 점 궤적 방법** (Im2Flow2Act, R+X, Motion Tracks, Track2Act, Point Policy). 닫힌 루프가 아니거나 로봇 데이터를 씁니다.

Phantom은 여기에 **데이터 편집(data editing)** 계열을 더합니다. RoviAug(로봇-로봇 시점·외형 증강), Shadow(분할 마스크로 로봇 교체), EgoMimic의 빨간 선 오버레이(사람-로봇, 로봇 데이터 포함), AR2-D2(아이폰으로 가상 로봇 덧씌우기)가 직접 계보입니다(2.2절).

## 2. 가까운 대안과 논문의 비교 기준 (부록 6.1, 표 4)

논문은 "로봇 데이터 없음, 변형체, 닫힌 루프" 세 기준으로 표 4를 만듭니다. 이 기준에서 **표 4의 14개 중 세 기준을 모두 만족하는 것은 Phantom뿐**입니다.

| 방법 | 로봇 데이터 없음 | 변형체 | 닫힌 루프 | 논문의 제외 이유 |
|---|---|---|---|---|
| EgoMimic | ✗ | ✓ | ✓ | 로봇 데이터 41% 포함. 빨간 선 방식만 부분 비교 (표 1) |
| MotionTracks | ✗ | ✓ | ✓ | 로봇 데이터 22% 이상 |
| Track2Act | ✗ | ✗ | ✓ | 과제당 로봇 시연 약 40회 |
| Im2Flow2Act | ✗* | ✓ | ✓ | 시뮬레이션 필요 (*) |
| R+X | ✓ | ✓ | ✗ | 열린 루프 |
| ORION | ✓ | ✗ | ✓ | SE(3) 물체 변환 전제 |
| DITTO | ✓ | ✗ | ✓ | SE(3) 물체 변환 전제. 정량 결과 없음 |
| MimicPlay | ✗ | ✓ | ✓ | 로봇 데이터 75% 이상 |
| AR2-D2 | ✗ | ✓ | ✓ | 아이폰 전용, 키포인트 수동 주석, 과제 3개 |
| WHIRL | ✗ | ✓ | ✓ | 실로봇 시행 필요 |
| Learning by Watching | ✗* | ✗ | ✓ | 한 장면 시뮬레이션 |
| HOPMan, Vid2Robot | ✗ | ✓ | ✓ | 쌍으로 된 사람-로봇 데이터 |

논문은 이 표로 "공정한 비교 대상이 없다"는 입장을 세우고 Red Line만 비교합니다. **이 판단은 "로봇 데이터를 쓰는 방법과 비교하지 않는다"는 범위 제한**이며, 성능 우위의 증거가 아닙니다. 비교 범위는 `03` C-항목에 옮겼습니다.
