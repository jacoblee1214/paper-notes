# 03. 수치 재계산, 표 간 일관성, CPU 토이

재계산 스크립트는 `analysis/recompute.py` (표준 라이브러리), 결과는 `analysis/recompute_results.json`이다. 토이는 `analysis/toy_best_of_n.py`, 결과는 `analysis/toy_best_of_n_results.json`이다. 둘 다 CPU에서 몇 초 안에 끝난다.

## 1. 실로봇 성공률 (Table II): 표본 수와 검정

과제당 20회다 (§V-B, 부록 §X-C). 값은 논문 표에서 옮겼다. 검정은 Fisher 정확검정 양측이다. 과제 세 개는 같은 로봇과 같은 조건에서 나온 결과이므로 과제별 검정은 독립이 아니다. 여러 번 비교한 점도 보정하지 않았다.

| 과제 | DP-UMI | UVA | 차이 (pp) | Fisher p | 해석 |
|---|---|---|---|---|---|
| 단일 과제 Cup | 19/20 (0.95) | 17/20 (0.85) | -10 | 0.61 | DP-UMI가 높다. 유의하지 않다 |
| 다중 Cup | 10/20 (0.50) | 13/20 (0.65) | +15 | 0.52 | 유의하지 않다 |
| 다중 Towel | 14/20 (0.70) | 14/20 (0.70) | 0 | 1.00 | 같다 |
| 다중 Mouse | 8/20 (0.40) | 16/20 (0.80) | +40 | 0.023 | 과제 하나에서 유의. 보정하면 경계 |
| 다중 합계 60회 | 32/60 (0.53) | 43/60 (0.72) | +18 | 0.059 | 유의 수준 0.05에 약간 못 미친다 |

Wilson 95% 구간: 다중 합계 DP-UMI 0.41–0.65, UVA 0.59–0.82. 구간이 겹친다. 본문의 "Cup +15%, Mouse +40%" 수치는 표와 일치한다.

## 2. 블록 밀기 (Table V): 표본 수

- 조건 4개 × 10회 = 방법당 40회다 (§VII). 조건별 값은 0.2, 0.5, 0.6, 0.2 (DP-C), 0.8, 0.7, 0.5, 0.4 (UVA), 0.8, 0.8, 0.7, 0.7 (GT). 평균은 각각 0.375, 0.600, 0.750으로 표의 0.38, 0.60, 0.75와 맞는다.
- DP-C 15/40 (Wilson 0.24–0.53) 대 UVA 24/40 (0.45–0.74): Fisher p = 0.073. **유의하지 않다.** 본문은 "크게 높인다"고 쓴다.
- UVA 24/40 대 GT 30/40: p = 0.23. 두 방법은 구별되지 않는다.
- **논리 모순.** §VII은 "완벽한 정책이라면 평균 성공률 최대 50%"라고 쓴다. 그런데 GT 시뮬 선택은 0.75를 얻는다. 50% 상한이 맞다면 GT 선택이 상한을 넘을 수 없다. 두 주장을 함께 만족하려면 상한 계산의 가정(예: 한 번에 한 블록만 밀 수 있다는 가정)을 명확히 해야 한다. 논문은 이를 설명하지 않는다.

## 3. 시뮬 정책 (Table I)

### 3.1 n에 따른 정수성 점검

보고값이 표본 크기로 정수 비율이 되는지 확인했다 (`recompute_results.json`의 `integer_feasibility`).

| 칸 | 보고값 | 가정 n | 정수 비율로 가능한가 |
|---|---|---|---|
| PushT, DP-C | 0.91 | 50 | 불가 (45.5/50). 가장 가까운 46/50 = 0.92 |
| PushT, OpenVLA | 0.35 | 50 | 불가 (17.5/50) |
| PushT, UVA-action | 0.45 | 50 | 불가 (22.5/50) |
| Tool, DP-C | 0.95 | 50 | 불가 (47.5/50) |
| PushT, UVA | 0.98 | 50 | 가능 (49/50) |
| Libero10, UVA | 0.90 | 500 | 가능 (450/500) |

- 본문은 PushT와 ToolHang을 "50회 롤아웃 평균"이라고 쓴다 (§V-A). 위 네 칸은 n = 50으로는 나올 수 없다. **표본 수가 칸마다 다르거나, 여러 시드의 평균이거나, 다른 n을 썼을 가능성이 있다.** 논문만으로는 구별할 수 없다.
- Table III도 n = 50을 가정하면 BgColor 0.35, BgObject 0.31이 정수가 아니다. 표본 수가 명시되지 않았다.

### 3.2 Libero10 (500 에피소드 가정)

기준 모델의 표본 수가 보고되지 않아 n = 500을 가정했다. 가정이 틀리면 결과도 달라진다.

| 비교 | 차이 (pp) | z검정 p (정규근사) |
|---|---|---|
| UVA 0.90 대 π0 0.85 | +5 | 0.017 |
| UVA 0.90 대 UVA-action 0.86 | +4 | 0.052 |
| UVA 0.90 대 DP-T 0.58 | +32 | <0.001 |

- UVA 대 UVA-action의 4pp 차이는 **유의 수준 경계**다. 논문이 "영상 보조 학습의 효과"를 Libero10에서 주장하는 근거로는 약하다. PushT 단일 과제 차이(0.98 대 0.45)가 더 강한 근거다.

### 3.3 PushT-M: 지표 문제

- PushT-M은 "평균 보상"이다 (표 I, §V-A). 분산이 없다. 보상 차이 20pp를 "성공률 20%"로 서론에 쓴 것은 지표 이름이 섞인 것이다.
- 그림 6의 UVA 곡선은 이력 길이 1–16에서 약 0.77–0.81이다. 표 I의 UVA PushT-M 0.88과 맞지 않는다. 그림 6의 DP-C 1스텝 값 약 0.68은 표 I의 DP-C 0.68과 맞는다. 즉, **UVA의 PushT-M 값만 그림과 표가 어긋난다.** 평가 설정이 다른지 논문에 설명이 없다.

## 6. 기타 재계산

- 블록 밀기 조건별 평균 (§2)은 표 안에서 맞는다. Table VI는 단일 값만 있어 내부 검산 대상이 없다.
- 부록 Table VIII: 30회 (28/30 → 0.93, 29/30 → 0.97)와 500회 (450 → 0.90, 455 → 0.91) 모두 정수 비율이다. 사람 영상 추가 효과 +0.01 (500회)은 Fisher p = 0.67이다.
- Table IX: 마스킹 전략 두 가지, 비율 세 가지의 값을 그대로 옮긴 표다. 정책 성공률은 적용-의존 설정에서 0.84, 0.86, 0.84이고 비율을 올려도 크게 떨어지지 않는다. 본문은 "높은 비율이 전체 성능을 떨어뜨린다"고 쓰지만, 정책 성공률 열에서는 그 설명이 잘 드러나지 않는다. 표본 수는 적혀 있지 않다.

## 7. CPU 토이 1: 샘플링 후 예측 모델로 고르기 (best-of-N)

**질문.** 블록 밀기 실험 (Table V)에서 전 모델(forward model)이 행동 후보 100개 중 하나를 고르는 방식이 성공률을 38%에서 60%로 올린다. 단순한 선택 모델만으로 이 수준을 설명할 수 있는가? 전 모델 오차가 커지면 성공률이 얼마나 떨어지는가?

**설정 (논문에 없는 가정).**
- 후보 N = 100. 각 후보의 실제 결과 점수 g ~ N(0,1).
- 무작위로 고른 후보가 성공할 확률을 38%로 맞추도록 임계값 c를 잡는다 (Table V의 DP-C). 계산값 c = 0.306.
- 전 모델은 g + ε, ε ~ N(0, σ²)로 점수를 예측하고 argmax로 고른다. 에피소드 20,000회, 시드 고정.

**결과 (`toy_best_of_n_results.json`).**

| 전 모델 오차 σ | 성공률 |
|---|---|
| 0 (완벽) | 1.00 |
| 0.25 | 1.00 |
| 0.5 | 1.00 |
| 1.0 | 0.97 |
| 2.0 | 0.82 |
| 무작위 선택 (검증) | 0.378 |

**해석.**
- 이 단순 모델에서는 후보가 100개면 전 모델이 꽤 나빠도 성공률이 높다. 논문의 60%와 GT 시뮬 75%는 **이 모델로는 재현되지 않는다.**
- 따라서 논문의 60%와 75%를 제한하는 것은 전 모델 정확도가 아니라 **후보 다양성, 행동 실행 오차, 물체 검출 오차, 6스텝 실행 후 재계획** 같은 요인일 가능성이 크다. 논문은 물체 검출 오차를 한 번만 언급한다 (§VII).
- 이 토이는 "전 모델이 정확하면 충분하다"는 직관을 흔든다. 단, 후보가 서로 독립이라는 가정이 강하다. 실제 행동 샘플은 같은 정책에서 나오므로 상관이 있을 것이다. 상관을 넣으면 결과가 더 나빠질 수 있다. 이 토이는 검증이 아니라 감각을 잡기 위한 것이다.

## 8. 토이 2를 만들지 않은 이유

- 중심 주장은 "공동 학습이 정책을 돕는다"이다. 이를 시험하는 토이는 손실 설계(공동 합, 무작위 모드 선택, 행동 전용)에 민감하다. 논문이 손실 설계를 정확히 보고하지 않아 (`04` D1) 토이의 결과가 설계 선택을 반영할 뿐이다.
- 따라서 이 분석에서는 토이 1 하나로 제한한다.

## 9. 요약

1. 재계산 가능한 통계 주장 중 유의한 것은 실로봇 Mouse (p = 0.023) 하나다. 전체 다중 과제 차이는 p = 0.059이다.
2. 블록 밀기 0.38 → 0.60은 유의하지 않다 (p = 0.073). 상한 50% 주장은 GT 0.75와 모순된다.
3. 표 I의 여러 칸은 n = 50으로는 나올 수 없다. 표본 수가 명시되지 않았다.
4. Libero10 평가 규모는 본문 50회와 부록 10회가 맞지 않는다.
5. v1과 v3의 Libero10 기준선 값이 크게 바뀌었다. 인용할 때 버전을 밝혀야 한다.
6. 단순 best-of-N 토이는 논문 수치를 재현하지 못한다. 성공률의 병목은 선택 모델 밖에 있을 가능성이 있다.
