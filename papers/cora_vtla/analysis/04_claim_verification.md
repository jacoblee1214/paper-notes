# CoRA-VTLA: 주장 대조와 구현 가능성 (공식 코드 없음)

## 1. 저장소 상태

공식 코드가 없습니다. 프로젝트 페이지의 Code 버튼은 "coming soon"입니다. GitHub 검색으로 찾은 두 저장소(`Wbbeeitw/cora-vtla`, `cora-vtla/cora-vtla.github.io`)는 학술 페이지 템플릿이라 구현이 아닙니다 (`02_prior_work.md` §2). 그래서 논문과 코드를 대조하지 않고, 논문의 주장을 표와 본문으로 대조합니다. 클론, 실행, 설치는 하지 않았습니다.

요약하면, **평균과 대부분의 절제 수치는 재계산과 맞습니다.** 약한 부분은 세 가지입니다. (1) 시드 반복이 없어서 검정이 학습 변동을 빠뜨립니다 (C19). (2) 주의 분석의 p값과 엔트로피는 원자료 없이 확인할 수 없습니다 (C14–C16). (3) 3.4절의 명령 조건화 설명은 4.3절의 프로브와 맞지 않습니다 (C13).

## 3. 구현에 필요한데 본문에 없는 것

재현 또는 구현을 하려면 아래 값이 필요합니다. 공식 코드가 없으므로 모두 추정해야 합니다.

- **데모 수:** MuJoCo 세 과제, 실로봇 세 과제. UniVTAC만 50개입니다.
- **학습 설정:** 총 갱신 수, 배치 크기, 워밍업 길이, 코사인 감쇠 끝점, $\lambda_{sem}(k)$와 $\lambda_{gaze}(k)$의 스케줄 함수.
- **Gaze 손실 세부:** 목표 $\eta$, 적용 레이어 (VLM 마지막에서 두 번째 층이라고만 적힘), 정규화 방식.
- **인코더 구조:** $E_c$, $\mathcal T$의 층 수와 헤드 수, $Q$, $P_c$, $P_m$의 차원, 의미 분기의 단어 앵커 목록과 $M=3$ 속성의 단어, 잔차 크기.
- **헤드 $G$ 구조와 손실 가중치:** 세 그룹 평균 가중치는 명시됨 (3.4절). 헤드 구조는 없음.
- **촉각 레이블 임계값:** "임계값을 넘으면"이라고만 적힘. 값이 없음.
- **손가락 셀 투영:** 카메라 보정, 패치 격자 크기, 투영 실패 처리 (유효하지 않은 투영의 규칙은 "valid projections"로만 적힘).
- **MuJoCo 과제:** 물리 파라미터 범위, 과제 XML, 회복 초기 조건 생성 방식.
- **실로봇 센서 처리:** 샘플링 주기, 정규화 통계 출처, 사건 정의(연속 관측 차분)의 시간 간격.
- **UniVTAC 설정:** 동결 ResNet-18의 입력 해상도, 0.8 s 이력 길이의 프레임 수, 행동 인터페이스.
- **시드, 컴퓨팅 자원, 학습 시간, 추론 지연.**

## 4. 구현 가능성 판정

**판정: 구현은 조건부로 가능하지만, 이 맥에서는 재현할 수 없습니다.**

공식 코드가 없고, 방법 설명은 한 번의 구현을 위한 세부 값이 빠져 있습니다. 백본은 공개 openpi의 π0.5이므로 그 위에 촉각 모듈을 얹는 것은 가능합니다. 하지만 학습과 평가는 GPU와 실로봇을 전제합니다.

| 항목 | 이 맥 (M4 Pro, 24 GiB, MPS, CUDA 없음) | 판정 | 근거 |
|---|---|---|---|
| 메모리 계산 $r_i$, $K=16$ 창, 질의 Attention (무작위 가중치) | 가능 (CPU 또는 MPS) | 가능 | 수식이 명확하고 작음 |
| 반응 사전학습의 손실 계산 (작은 인코더, 시연 데이터를 가정) | 가능 | 가능 | 본문 3.4절이 필요한 식과 가중치를 줌 |
| π0.5 추론 (파라미터 수는 본문에 없음) | MPS 포팅과 JAX 지원 여부를 측정하지 않음 | 조건부 | 측정 전 |
| π0.5 미세조정 (촉각 모듈 포함) | GPU 메모리와 시간 필요. 이 맥에서 불가 | 불가 | 저장소 규칙상 GPU 재현 금지 |
| MuJoCo 3과제 학습과 평가 | 시뮬은 CPU에서 가능하지만 과제 XML과 데모가 없음. 학습은 GPU 필요 | 불가 (학습) | 과제 재구성과 데모 수집 필요 |
| UniVTAC 평가 | 시뮬레이터 요구사항을 이번에 확인하지 않음 | 확인 필요 | `02` §2 |
| 실로봇 (UR5e, Robotiq 140, 전자피부) | 하드웨어 없음 | 불가 | — |

- **노력 추정 (측정 전):** 촉각 모듈을 openpi 위에 구현하는 데 2–3주. MuJoCo 과제를 다시 만들고 데모를 모으는 데 2–4주. 학습은 외부 GPU가 필요합니다. 추정치이며 측정하지 않았습니다.
- **가치가 있는 최소 검증:** 메모리 계산과 "끼임 대 회피" 구별을 CPU 합성 시계열로 확인하는 것입니다. 그러나 논문 결과를 검증하는 것은 아닙니다. 이 작업은 사용자 승인 후에만 합니다.
