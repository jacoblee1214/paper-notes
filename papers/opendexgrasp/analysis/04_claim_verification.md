# 04. 주장 대조 (공식 코드 없음)

## 0. 대상과 방법

- 공식 코드가 아직 없습니다. `opendexgrasp/OpenDexGrasp` 저장소는 README 한 줄("coming soon!")과 GitHub 기본 템플릿이고, 커밋 2개입니다(2026-06-28, `02` §4). 프로젝트 페이지의 Code 버튼도 이 저장소를 가리킵니다. 따라서 **논문 ↔ 코드** 대조(차이 D1–Dn) 대신 **논문 주장 ↔ 논문 내 증거** 대조(주장 C1–Cn)를 했습니다.
- 대조 근거는 (a) 논문 본문과 표, (b) 부록 설정, (c) `03` 재계산 결과입니다. 외부 자료는 프로젝트 페이지 문구와 GitHub 저장소 상태만 씁니다.
- 판정 기준: **지지** = 증거가 주장과 맞고 강도도 맞음. **부분 지지** = 방향은 맞지만 강도, 범위, 비교 대상 중 하나가 과함. **약함** = 증거가 주장을 뒷받침하기에 부족함. **미확인** = 논문에 정보가 없어 검증 불가. **모순** = 논문 안에서 값 또는 문장이 서로 맞지 않음.

## 4. 구현 가능성 판정

**판정: 이 맥(Apple M4 Pro, 약 24 GiB 통합 메모리, MPS, CUDA 없음)에서 논문의 수치 재현은 불가능합니다.** 공식 코드도 데이터도 없고, 학습은 대형 VLM과 2M 스텝을 전제하며, 실로봇 하드웨어가 필요합니다. 아이디어와 평가 설계는 CPU나 소형 모델로 옮길 수 있고, 그쪽이 현실적인 목표입니다.

|---|---|---|---|---|
| 표 재계산과 검정 | 완료 | numpy, scipy (설치됨) | 가능 | 완료 |

## 5. 이 분석이 하지 않은 것

- 공식 코드 clone, 실행, 설치 (코드 없음).
- GPT-5 호출, 인간 평가 재수행 (API와 사람 평가는 이번 범위 밖).
- 데이터, 모델 가중치 다운로드 (논문 PDF와 메타데이터만 받음).
- 토이 실험 (이 논문의 핵심 주장은 CPU 토이로 검증할 수 있는 종류가 아님. 측정 정의 문제는 `03`에서 숫자로 보였음).
