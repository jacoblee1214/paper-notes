# 04. 주장 검증과 구현 가능성: ProxiDex (arXiv:2609.16586 v1)

**공식 코드가 없어서** 코드 대조(차이 D1–Dn) 대신 논문과 프로젝트 페이지의 주장을 C1–Cn으로 나누어 표·본문 수치와 맞대어 검증했습니다. 2026-11-24 기준 프로젝트 페이지(`https://proxidex.github.io/`)의 Code 버튼은 "Code: Coming Soon"이고, 페이지 저장소(`ProxiDex/ProxiDex.github.io`)에는 코드가 없으며 GitHub 검색에서도 구현 저장소를 찾지 못했습니다(`02` §2). 재계산 근거는 `03`의 V·K 번호입니다.

## 1. 판정 기준

| 판정 | 뜻 |
|---|---|
| 일치 | 산술 또는 서술이 표·본문과 맞음 |
| 지지 | 표·그림의 수치가 주장의 방향을 뒷받침함. 시드 수, 시행 수가 없어 구간은 가정 위에 있음 |
| 부분 지지 | 방향은 맞으나 주장의 강도나 원인 해석을 수치가 다 뒷받침하지는 않음 |
| 미검증 | 논문의 정보로는 확인할 수 없음 |

## 4. 구현할 수 있는지 (이 맥: Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)

**판정: 논문의 시뮬과 실로봇 결과를 재현하는 것은 지금 불가능합니다. 공식 코드, 시연 데이터, 체크포인트가 없습니다. 표 재계산과 주장 검증, 근접도 계산의 소형 토이는 끝냈습니다. 구조의 소형 재구현(합성 과제에서 근접도 + FDM/IDM + 게이트)은 이 맥에서 가능하고, 논문 수치의 재현은 아닙니다.**

| 수준 | 판정 | 근거 |
|---|---|---|
| 논문 표 1, 6, 7, 8(시뮬) 재현 | 불가 | 코드, 시연 데이터, IsaacLab 자체 과제 세 개가 모두 없음. Adroit, DexArt, Isaac Lab은 공개되어 있으나(`02` §2) 학습 설정(N3, N5, N8)이 불명. Isaac Sim은 NVIDIA GPU 전제라 이 맥에서 돌리기 어려움 |
| 표 2(실로봇) 재현 | 불가 | Realman RM75B, RealSense L515, CasBot-P1L, Wuji Hand, Quest 3S |
| 원격조작 시스템 재현 | 불가 | Hand Tracking Streamer(Apache-2.0)와 Quest, 실로봇이 필요. 논문 쪽 VR 점군 피드백 구현은 비공개 |
| 근접도 계산(식 11–16) 구현 | 가능 | numpy/scipy로 수십 줄. σ, τ_palm, 영역 정의는 직접 정해야 함 (N1, N2). 토이 T1이 이미 구현 |
| 구조 소형 재구현 | 가능 | 합성 접촉 과제(예: 2D 또는 3D 점-면 접근 후 접촉)에서 근접도 VAE, 관측 인코더, FDM(작은 MLP 또는 소형 DiT), IDM, 게이트와 인과 마스크를 torch로 구현. 이 맥(MPS 또는 CPU)에서 소형 모델은 학습 가능. 논문 수치의 재현은 아님 |
| 시뮬 과제에서의 소형 대조 | 조건부 | Adroit나 DexArt를 설치하려면 mujoco 계열과 렌더링 의존이 필요하고 새 설치 승인이 필요. 이 맥에는 mujoco 4.0과 torch 2.15가 설치되어 있어 직접 만든 소형 MuJoCo 과제는 가능 |

**노력 추정 (측정 전, 추정):** 근접도 계산과 합성 과제 데이터 생성 2–3일, 소형 구조 재구현과 절제(w/o IDM, w/o 게이트, w/o dream) 1–2주, 논문 수준의 시뮬 대조(공개 후)는 코드 공개와 데이터 크기 확인 후 다시 추정. 코드가 공개되면 `04`를 코드 대조(D 항목)로 갱신해야 합니다.
