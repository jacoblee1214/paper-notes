# 03. 재계산, 일관성 검사, 토이와 주장 판정

재계산은 `analysis/recompute.py` (수 초, numpy·scipy)이고 결과는 `analysis/recompute_results.json`입니다. 토이는 `analysis/toy_future_error.py` (수 초, numpy, 1 시드)입니다. 입력 값은 논문 v2 PDF의 표 1, 2, 5, 6, 7, 12에서 읽었습니다. 표 6과 7은 페이지 이미지로 다시 확인했습니다.

## 0. 가정

| 가정 | 값 | 근거 |
|---|---|---|
| CALVIN 채점 체인 수 | 1000 | 공식 `policy_conf/calvin_evaluate.yaml`의 `num_sequences: 1000`. 논문 본문에는 없음 |
| 실로봇 시도 수 | 표 6, 7 캡션 | Panda 학습 과제 pick·place 50, 나머지 20. 새 과제 25/10. Dex 학습 과제 pick·place 100, 나머지 25. 새 과제 50/20. 도구 10 |

## 4. 토이 T1: 예측 오차 대 역동역학 이득

`analysis/toy_future_error.py`. 2차원 점 질량, 행동은 AR(1) 과정(ρ), 다음 위치는 x_{t+1} = x_t + a_t + 0.05 잡음입니다. 정책은 선형 회귀로 a_t를 맞춥니다. 입력은 (A) 현재 위치만, (B) 현재와 직전 위치입니다. 예측 입력은 x̂_{t+1} = x_{t+1} + σ·잡음입니다.

- 학습 때 예측 오차 σ_tr = 0.1, 시험 때 σ_te를 바꿨을 때 기준선(예측 입력 없음)을 넘는 지점은 다음과 같습니다.

| ρ | 관측 | 기준선 MSE | 교차 σ_te |
|---|---|---|---|
| 0.0 | A (현재만) | 0.994 | 1.01 |
| 0.5 | B (현재 + 직전) | 0.747 | 0.87 |
| 0.9 | A | 0.747 | 0.86 |
| 0.9 | B | 0.191 | **0.46** |
| 0.99 | B | 0.022 | 0.21 |

- 학습과 시험 모두 같은 σ로 맞추면 예측 입력은 기준선을 넘지 않았습니다. 선형 회귀는 나쁜 입력의 계수를 0으로 줄일 수 있기 때문입니다.

해석. 이 토이는 "미래 표현이 역동역학을 돕는다"는 주장을 검증하지 않습니다. 보여 주는 것은 두 가지입니다. (1) 학습 때 맞힌 예측이 시험 때 나빠지면, 예측 입력의 이득은 **행동이 현재 관측으로 설명되지 않는 만큼만** 남고, 그 크기가 0.2–1.0 단위에서 사라집니다. (2) 교차 σ는 기준선 MSE의 제곱근 근처입니다 (ρ=0.9, 관측 B: √0.191 ≈ 0.44, 교차 0.46). 현재 관측으로 덜 설명되는 행동일수록 기준선 오차가 크고, 예측이 그만큼 나빠져도 이득이 남습니다. VPP의 미지 과제 결과(표 5, 7)를 읽을 때 이 간격이 중요합니다. 실제 영상 모델의 오차 분포와 정책의 비선형성은 토이에 없습니다.

## 6. 한계

- 이 분석은 논문 수치를 **표에서 읽은 값**으로 다시 계산했습니다. 원본 평가 로그가 없어 체인별 결과를 쓰지 못했습니다.
- 채점 표준오차는 체인 표집만 반영합니다. 학습 시드 3회 이상이 없으면 "차이가 확실하다"는 말은 여기까지입니다.
- 토이는 선형 모델이고 시드 1개입니다. 결론은 메커니즘의 방향에만 쓰십시오.
