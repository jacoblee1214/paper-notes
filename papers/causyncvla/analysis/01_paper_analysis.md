## 1. 한 장 요약

- **문제.** VLA 정책은 시각 인코딩(VLM 전방 계산)이 끝나기를 기다리는 동안 로봇을 멈추거나, 비동기로 돌리면 오래된 시각 기억(KV 캐시)과 어긋난 행동 청크를 씁니다(§1, Fig. 1).
- **방법.** 두 개의 흐름. 느린 흐름(System 2)이 완료된 시각 프레임의 KV 기억을 "앵커"로 발행하고, 빠른 흐름(System 1)은 앵커 뒤에 실제로 실행된 상태·명령 기록 H를 써서 현재 KV 기억을 예측합니다(**Causal Latent World Model**, 식 (2)). 이어서 **PFWS**가 아직 실행하지 않은 행동 꼬리를 이동·반복해 초기값으로 삼고, 동결된 flow 전문가를 **한 번의 Euler 스텝**으로 보정합니다(식 (3)).
- **학습.** 백본과 행동 전문가는 동결합니다. 예측기(24.27M)만 학습하며, 손실은 KV 회귀(L_KV)와 동결 전문가 출력을 통한 행동 증류(L_act)의 합입니다(식 (4), 가중치 1, 2, 그리퍼 0.1, Table 7).
- **주장.** LIBERO-10에서 93.8%(469/500)로 10-step 동기 π0.5의 91.2%(456/500)보다 높고, 모델 추론량 기준 5.04× 빠릅니다(초록). 실로봇 FR3 세 과제에서 86.96%(60/69) 대 72.46%(50/69).
- **내 판단 한 줄.** 메커니즘 기여(잠재 예측 + 행동 증류)는 쌍체 검정으로 강하게 지지되지만, 헤드라인 성공률 차이(LIBERO +2.6 pp, 실로봇 +14.5 pp)는 검정 근거가 약하고, "5.04× 처리량"은 빠른 흐름만 잰 값입니다. 수치 근거는 `03_analysis.md`.

## 2. 문제 설정과 방법 (§3)

### 2.1 실행 기반 비동기 제어 (§3.1)

- 시각 앵커 z_a = B_φ(o_a, ℓ)은 캡처 시점 a에서 만든 KV 기억이고, 지연은 k = t − a입니다.
- 빠른 흐름은 H step 계획을 C = 5 명령마다 다시 세웁니다(LIBERO: H/C = 10/5).
- 식 (1): A_t = R_ψ(Q_t, W_θ(z_a, H_{a:t})). Q_t는 실행하지 않은 꼬리 "사전 분포"이고 R_ψ는 PFWS입니다.
- H_{a:t}는 (s_i − s_a, u_{i−1}) 쌍의 순서 있는 기록입니다(i = a+1…t).

### 2.2 인과 잠재 세계 모델 (§3.2, 식 (2))

- ẑ_t = z_a + I[k>0] δz_t. δz_t는 KV 잔차이고, 나이 0이면 항등입니다(부록 A.1 "explicit gate").
- 입력 처리: 층별 RMS 척도 σ_KV로 K, V를 정규화하고, 궤적 MLP가 나이, 끝점, 순 변위, 상태 변화량 패딩 시퀀스를 인코딩합니다. 적응형 LayerNorm(AdaLN, 식 (6)–(10))으로 주입하고, 0으로 초기화한 출력 투영으로 시작할 때 항등입니다.
- **"인과"의 뜻.** 논문은 외부 장면 동역학의 인과 식별을 주장하지 않는다고 명시합니다(§3.2). 실제로는 "결정 시점까지의 정보만 쓴다(past-only)"는 뜻입니다. 이름이 주는 인상보다 좁습니다.

### 2.3 PFWS (§3.3, 식 (3))

- 전문가 출력 A_{t−C}에서 남은 H−C 항을 앞으로 옮기고 마지막 행동을 C번 반복해 Q_t = ShiftRepeat(A_{t−C}, C)를 만듭니다. 상태 상대 좌표는 s_t로 재기준화합니다.
- x_ρ = (1−ρ)Q_t + ρε, R_ψ = x_ρ − ρ v_ψ(x_ρ, ρ | ẑ_t). ρ = 0.5, NFE = 1(Table 7).
- ρ = 1은 콜드 스타트, ρ가 작을수록 이전 계획에 가깝게 붙습니다(§3.3).

### 2.4 행동 민감 증류 (§3.4, 식 (4)–(5))

- 교사 A★ = sg[D_ψ(z_t; x_ρ, ρ)]는 신선한 KV z_t로 동결 전문가를 돌린 결과입니다. 학생 Â = D_ψ(ẑ_t; x_ρ, ρ)와의 가중 차이가 L_act입니다.
- 식 (5)는 KV 오차 e를 1차 전개해 L_act ≈ ½‖Ω^{1/2} J_D e‖²를 얻습니다. 즉 KV 방향을 행동 영향(J_D)으로 가중합니다.
- Table 5 하단: KV 손실만 쓰면 KV 오차는 0.28461로 더 낮지만 행동 MSE는 0.02018로 높고 성공률은 85.6%. 행동 증류를 더하면 KV 오차는 0.31958로 올라가지만 행동 MSE는 0.00983, 성공률 92.8%입니다.

## 3. 실험 (§4, 부록 B–C)

### 3.1 설정 (§4.1, Table 7–8)

- 백본: 공개 π0.5-LIBERO(OpenPI). 예측기 24,273,024 파라미터, 6블록, 폭 384, 헤드 4. 학습 12k 갱신 선택(전체 18k).

### 3.3 저자들이 직접 인정한 한계 (§B.5, §B.13–B.15)

- 체크포인트와 평가 시드는 "초기 종점 비교" 뒤에 골랐고, 12k 체크포인트는 학습 예산 스윕(Fig. 8b)의 최고점입니다(§B.5). 같은 500 starts에서 6k 93.4%, 12k 93.8%, 18k 93.0%입니다.
- 실로봇 시행은 장면을 다시 놓아 정확한 쌍이 아니며, 쌍체 검정을 하지 않았습니다(§B.13).
- LIBERO-Plus에서 CauSyncVLA는 동기 PFWS보다 뒤집니다(§4.4: "CauSyncVLA still trails synchronous PFWS overall in Table 4"). 시점과 배치 변화에서 이득이 줄거나 음수입니다.
- PFWS의 성공률 이득은 통계적으로 확정되지 않았습니다(§4.2, §4.4, §B.13). 주된 이득은 연속성입니다.
- 단일 백본(π0.5)에서만 검증했습니다. PFWS는 흐름 속도 헤드가 있어야 하며, 다른 VLA(RTC·Latent Bridge·VLA-Rolling)는 기준선으로만 씁니다(§B.15).
- 갑작스러운 외부 변화(시점, 장면)에 대한 학습형 신뢰도 검사는 없습니다(§B.15).

## 4. 판단

### 4.1 논문이 잘 한 것

- 쌍체 설계가 많습니다(같은 500 starts, 같은 시드, Table 10). 표가 합계와 쌍 개수를 함께 줘서 재계산이 가능합니다(`03` §1–2에서 모든 합계가 맞음을 확인).
- 기여를 분리했습니다. 잠재 예측 제거(80.2%)와 PFWS 제거(92.0%)를 따로 봅니다. 행동 증류의 역설(KV 오차는 커지는데 성공률은 오름)을 식 (5)로 설명합니다.
- 한계를 부록에 많이 적었습니다(§B.5, §B.13–B.15).

### 4.2 헤드라인에 비해 약한 부분

- **초록의 "5.04× inference throughput"**은 Table 16의 모델 단독 지연 비입니다. 기준선(10-step π0.5)은 시각 인코딩을 포함하고 CauSync 공유 값은 인코딩을 다른 스트림에서 돌린 뒤의 빠른 경로만 잽니다. 1.67×(흐름 단계 10→1)과 3.02×(인코딩 분리)의 곱입니다(§B.4). 실제 20 Hz 단일 GPU에서는 재계획 1.28배, 반응 2.13배입니다(Table 2).
- **LIBERO 헤드라인 93.8%**는 같은 500 starts에서 고른 3개 체크포인트 중 최고값입니다. 2.6 pp 차이(13 starts)는 쌍 정보가 없어 검정할 수 없습니다. 쌍 결과가 없으면 p 값은 0.0002에서 0.2 이상까지 가능합니다(`03` §1.1).
- **실로봇 86.96%**는 과제당 23회, 쌍이 아닌 시행, 운영자 판정입니다. 풀링 Fisher p = 0.056(유의하지 않음)이고, 과제 층화 CMH p = 0.036입니다. 성공 한 건이 바뀌면 카이제곱 검정도 0.05를 넘습니다(`03` §1.3).
- **"강건성 개선" 주장**은 LIBERO-Plus에서 동기 PFWS보다 낮습니다(78.09 대 80.15). 초록은 이를 언급하지 않습니다.

### 4.3 재현 관점에서 중요한 점

- 공식 코드(Apache-2.0)는 공개됐지만 **실로봇 가중치와 학습 기록은 비공개**입니다(`04` D10). 실로봇 수치는 외부에서 재현할 수 없습니다.
- LIBERO 경로는 CUDA, Linux EGL, Python 3.11을 전제합니다(`04` §4).

## 6. 용어와 서술 메모

- 본문 표현 "Causal"은 past-only 정보 사용을 뜻합니다. 인과 발견이 아닙니다(§3.2).
- A.6의 "after selecting the training-budget peak in Table 10"은 Table 10이 아니라 Table 11과 Fig. 8b를 가리켜야 합니다.
- Table 4 제목의 "Episode-averaged flip rates over 500 native starts and 2,519 LIBERO-Plus variants"는 두 표본 크기가 섞여 있어 읽을 때 주의가 필요합니다.
- §4.6 "cutting median response fivefold"는 72.30/13.17 = 5.5배로, 5배보다 큽니다. 거의 맞는 서술입니다.
