## 1. 문제와 주장

- **문제:** 자기회귀(AR) 영상 확산 모델은 학습 때 정답 프레임을 문맥으로 보고, 추론 때는 자기 출력을 문맥으로 씁니다. 이 노출 편향(exposure bias)이 프레임이 쌓일수록 오류를 키웁니다(§1, §3.1).
- **방법 주장:** 학습 중에도 자기 출력으로 자기회귀 롤아웃을 하고(KV 캐시 사용), 영상 단위 분포 정합 손실로 감독합니다(§3.2–3.3, Alg. 1). 분포 정합에는 DMD, SiD, GAN 세 가지를 쓸 수 있다고 씁니다(§3.3).
- **효율 주장:** 4단계 few-step 백본과 기울기 절단(gradient truncation)으로 학습 비용을 줄이고, 같은 벽시계 시간에서 더 좋은 품질을 낸다고 합니다(§5 직전 단락, Fig. 6).
- **추론 주장:** 롤링 KV 캐시로 긴 영상을 재계산 없이 생성합니다(§3.4, Alg. 2). 이때 생기는 깜빡임은 "첫 잠재 프레임을 학습 중에 보지 못하게 하는" 국소 어텐션 학습으로 막는다고 합니다(§3.4, 부록 B).
- **결과 주장:** H100 한 장에서 17 FPS, 지연 0.69 s(chunk-wise). 품질은 VBench Total에서 Wan2.1-1.3B와 같거나 조금 높습니다(Table 1). 사용자 선호도 연구에서 네 기준선 모두에 대해 과반이 선택했습니다(Fig. 4, 부록 E).

## 2. 방법

### 2.1 기반 정식화 (§3.1)
- 프레임 연쇄 법칙 p(x_{1:N}) = Π p(x_i | x_{<i}), 각 조건부를 확산으로 모델링합니다.
- 기존 TF(Teacher Forcing)는 깨끗한 정답 문맥, DF(Diffusion Forcing)는 잡음이 섞인 문맥으로 프레임 단위 MSE를 최소화합니다(식 설명, Fig. 1 a–b, Fig. 2 a–b).
- 기반 모델은 Wan2.1-T2V-1.3B (흐름 정합 모델, 832×480, 16 FPS, 5 s)입니다(§4, 부록 A).

### 2.2 Self Forcing 학습 (§3.2, Alg. 1)
- 각 샘플 영상마다 디노이징 단계 s를 균등 추출합니다(Alg. 1 줄 4).
- 프레임 i를 T단계에서 시작해 s단계까지 디노이징하면서, 중간 단계는 기울기 없이 돌리고 s단계 출력 x̂_0만 기울기를 켠 상태로 계산합니다(줄 7–13).
- s단계 출력으로 KV 캐시를 채우되, 캐시로 들어가는 값은 기울기가 끊깁니다(줄 13, "restricting gradient flow into KV cache embeddings").
- 손실은 롤아웃으로 만든 영상 전체에 걸어 한 번 갱신합니다(줄 23).
- 4단계 스케줄은 [1000, 750, 500, 250]입니다(부록 A).

### 2.3 분포 정합 손실 (§3.3, 식 2–7)
- **DMD:** 역 KL을 최소화하며, 그래디언트는 실제 점수와 가짜 점수의 차로 계산합니다(식 2–3). 실제 점수에는 CFG 3.0을 씁니다(Table 3).
- **SiD:** 피셔 발산 기반입니다. 식 (4)에서 α = 1을 씁니다(부록 A).
- **GAN:** 상대론적 쌍 손실과 R1+R2 정규화를 씁니다(식 5–7). R3GAN 목적함수 계열입니다(§4).
- 논문은 TF/DF가 프레임 단위 정합이고, CausVid는 DF 출력에 DMD를 씌워 추론 분포와 어긋난다고 지적합니다(§3.3, 관련 연구 CausVid 단락).

### 2.4 롤링 KV 캐시 (§3.4, Alg. 2, Fig. 3)
- 재계산 없이 가장 오래된 캐시를 버리는 방식입니다. 시간 복잡도는 O(TL)입니다(§3.4, 복잡도 비교는 Fig. 3 a–c).
- 첫 프레임 불일치 문제: 첫 잠재 프레임은 시간 압축이 없어 다른 프레임과 통계가 다릅니다. 캐시가 밀리면 깜빡임이 생깁니다.
- 해결책: 학습 중 마지막 청크가 첫 청크를 보지 못하게 어텐션 창을 제한합니다(§3.4 마지막 단락, 부록 B, Fig. 7).

## 3. 실험

### 3.1 구현 (§4, 부록 A, Table 3)
- 기반 모델: Wan2.1-T2V-1.3B. 실제 점수 네트워크는 DMD에서 Wan2.1-T2V-14B, SiD와 GAN에서는 1.3B입니다(Table 3).
- 데이터: VidProM의 VidProS에서 약 100만 개 중 약 25만 개를 필터링하고, Qwen2.5-7B-Instruct로 확장합니다(부록 A, "Prompt preprocessing").
- 학습 규모: 주로 H100 64장, DMD는 약 1.5 h 수렴, SiD와 GAN은 2–3 h (§4, 부록 A). GAN은 배치 768입니다(Table 3).
- ODE 초기화: 기반 모델이 만든 ODE 해 쌍 16k개로 먼저 미세 조정합니다(§4, 세부는 CausVid 방식 인용).
- 학습 프롬프트 외에 ODE 쌍을 만드는 교사 샘플링의 가이드 값과 ODE 쌍 생성 설정은 논문 본문에 없습니다.

### 3.2 VBench와 사용자 선호도 (Table 1, Fig. 4)
- 지표: VBench 16개 차원의 Total, Quality, Semantic 점수와 사용자 선호도입니다(§4).
- Table 1에서 Self Forcing(chunk-wise)은 Total 84.31로 Wan2.1 84.26, CausVid 81.20보다 높습니다.
- 처리량과 지연: chunk-wise 17.0 FPS, 0.69 s. frame-wise 8.9 FPS, 0.45 s.
- 사용자 선호도(Fig. 4): CausVid 66.1%, Wan2.1 62.7%, SkyReels-V2 57.9%, MAGI-1 54.2%입니다. MovieGenBench 1003 프롬프트, 프롬프트당 사용자 한 명(부록 E).

### 3.3 절제 실험 (Table 2)
- Many(50×2)단계 TF/DF 기준선과 4단계 DF+DMD, TF+DMD, Self Forcing(DMD/SiD/GAN)을 비교합니다.
- 논문 주장: Self Forcing이 세 분포 정합 목적함수 모두에서 기준선보다 좋습니다(§4 "Ablation Studies").
- DF+DMD는 CausVid를 같은 설정에서 재현한 것이라고 명시합니다(§4).

### 3.4 학습 효율 (Fig. 6)
- 반복당 시간은 TF, DF와 비슷하고, 같은 벽시계 시간에서 VBench가 더 높다고 주장합니다.
- 이유로 전체 토큰 병렬 처리와 FlashAttention-3 사용을 듭니다(§4 "Training efficiency").

### 3.5 롤링 캐시 (§4 "Rolling KV cache", 부록 B)
- 캐시 재계산 방식은 10초 영상에서 4.6 FPS, 롤링 캐시는 16.1 FPS입니다.
- 학습 시 첫 청크 차단을 넣으면 아티팩트가 줄고 처리량이 유지됩니다(정성 비교만 있고 정량 지표는 없습니다).

## 4. 논문이 스스로 밝힌 한계 (§5 "Limitation")
- 학습 문맥 길이를 넘는 영상에서 품질이 떨어집니다.
- 기울기 절단이 장거리 의존성 학습을 막을 수 있습니다.
- 상태공간 모델 같은 순환 구조가 다음 과제로 제시됩니다.
- 윤리: 딥페이크와 편향 증폭 위험을 부록 D에 씁니다. 실시간화로 악용 장벽이 낮아진다고 적습니다.

## 5. 주장과 근거의 간격 (요약, 자세한 검증은 03)
1. **VBench 우위의 크기:** Wan2.1과 Total 차이는 0.05입니다. 단일 실행 값만 있고 분산이 없습니다.
2. **Table 2 "모든 기준선보다 우수":** Total에서는 맞지만, 의미 점수(Semantic)에서 SiD와 GAN 변형은 TF와 DF+DMD보다 낮습니다.
3. **실시간성:** 17.0 FPS는 재생률 16 FPS를 6% 넘습니다. frame-wise 8.9 FPS는 재생률보다 낮은데도 실시간이라고 부르지 않는 것이 논문 기준과 맞습니다(§4 "Evaluation metrics" 정의와 Table 1 대조).
4. **학습 시간:** 본문은 DMD 1.5 h, 저장소 README는 "2 h 이내", 8장 16 h 추정이라고 적습니다.
5. **벽시계 비교 그림 (Fig. 6):** 축이 10–30분이라 1.5 h 수렴과 직접 맞춰 읽기 어렵습니다.
