## 1. 한 문장 요약

π0.5와 π0.6에서 이어진 흐름 정합 VLA(Gemma3 4B 백본 + 860M 액션 전문가, 약 5B)에, **프롬프트를 크게 확장**합니다. 언어 지시에 더해 (a) 세그먼트 단위 세부 하위 과제 문장, (b) 에피소드 메타데이터(속도, 품질 1–5, 실수 여부), (c) 제어 모드(관절 또는 말단장치), (d) 근미래 하위 목표 이미지를 넣고, 각 요소를 무작위로 가려서(드롭아웃) 학습합니다. 이렇게 하면 시연뿐 아니라 실패와 자율 롤아웃(이전 모델이 평가하며 모은 데이터), 사람 egocentric 영상, 웹 데이터를 섞어도 모드 평균이 되지 않는다는 주장입니다(Sec. I, V, VI-A). 테스트 때는 품질 5, 실수 없음, 속도는 과제별 15 백분위로 프롬프트합니다(Sec. VII).

## 3. 프롬프트 구성과 드롭아웃 (Sec. V, 그림 3)

완성된 프롬프트 형태(Sec. V-E): `<다중 시점 관측><다중 시점 하위 목표> Task: … Subtask: … Speed: 8000. Quality: 5. Mistake: false. Control Mode: joint. <고유수용 상태>`.

| 요소 | 학습 때 처리 | 테스트 때 처리 | 위치 |
|---|---|---|---|
| 과제 지시 ℓ | 항상 | 사용자 입력 | Sec. V |
| 하위 과제 문장 ℓ̂ | 하위 목표 이미지가 있는 예시에서 30% 확률로 삭제 | 고수준 정책 또는 사람 코칭 | Sec. V-A, V-E |
| 하위 목표 이미지 g | 배치 예시의 25%에만 붙임. 실제 이미지(0.25는 세그먼트 끝, 0.75는 0–4초 앞 균일)와 세계 모델이 생성한 이미지를 섞음 | 세계 모델이 생성. 의미 변화 또는 4초(Δ)마다 갱신 | Sec. V-E, VI-C, VII |
| 메타데이터 m | 전체를 15% 확률로 삭제, 속도·품질·실수 라벨은 각각 5% 확률로 삭제 | 속도=과제별 에피소드 길이 15 백분위, 품질=5, 실수=false | Sec. V-C, V-E, VII |
| 속도 라벨 | 에피소드 길이(스텝)를 500 간격으로 이산화(1750–2250 → "2000 steps") | 위와 같음 | Sec. V-C |
| 품질 라벨 | 1–5, 사람이 거칠게 주석 | 5 | Sec. V-C |
| 제어 모드 c | 드롭아웃 없음 | 과제별로 선택 | Sec. V-D, V-E |

하위 목표 이미지 비율을 25%로 줄인 이유는 이미지가 있으면 "역동역학 문제"가 되어 학습이 훨씬 빨라지기 때문이라고 적혀 있습니다(Sec. V-E). 이 말을 정량으로 뒷받침하는 그림은 없습니다.

**CFG(Sec. VII):** 각 노이즈 제거 스텝에서 `∇ log π(C) + β(∇ log π(C) − ∇ log π(C_uncond))`를 씁니다. 메타데이터에 적용하고 β ∈ {1.3, 1.7, 2.2}입니다. 이 식은 무조건 분포 대비 조건 분포를 (1+β)배 외삽하므로 통상 표기의 안내 세기 w = 1+β는 2.3, 2.7, 3.2입니다(`03_analysis.md` V15).

## 4. 학습 데이터 (Sec. VI-A)

범주만 나열되고 양은 없습니다: 다양한 로봇(고정형, 모바일, 단일 팔·양팔)의 시연, 정책 평가에서 나온 자율 데이터, 정책 롤아웃 속 사람 개입, 공개 로봇 데이터셋, egocentric 사람 영상, 웹 보조 데이터(물체 위치·속성 예측, VQA, 텍스트 전용, 영상 캡션). 이전 모델 π*0.6이 RL 학습 중 모은 데이터를 포함해 "증류"한다고 설명합니다. **일반화 평가 과제(Sec. IX 전체)에서 모은 자율 데이터는 학습에서 제외**합니다(각주 1). 세계 모델은 별도로, 하위 과제 라벨의 시간 분할이 좋은 로봇·사람 데이터 일부와 공개 이미지 편집·영상 데이터를 섞어 학습합니다(부록 C).

## 5. 실행 시간 구조 (Sec. VII, 알고리즘 1, 부록 D)

- 고수준 정책, 세계 모델, VLA가 **서로 다른 스레드**로 비동기로 돕니다. VLA는 항상 가장 최근에 나온 하위 과제와 하위 목표를 씁니다(Sec. VII).
- VLA/고수준 정책: H100 한 장. 최소 변형은 38 ms(카메라 3, 노이즈 제거 5스텝, 학습 시점 RTC), MEM 인코더와 하위 목표 이미지를 더하면 최악 127 ms(부록 D).
- 세계 모델: 4×H100 텐서 병렬, 8비트 양자화, SageAttention 변형, 25 노이즈 제거 스텝(텍스트와 이미지 CFG 포함)에 1.25초, 시퀀스 길이는 약 1만 토큰(부록 D).
- 하위 목표 생성 중에도 VLA는 이전 목표로 계속 실행합니다(순진한 비동기, 부록 D).

- 가장 다양한 20%(과제 다양성 기준)를 뺀 모델과 무작위 20%를 뺀 모델 비교(쌀 뜨기, 물체 돌리기, 사무용품 닦기 성공률): 전체 모델 약 56/48/47, 무작위 20% 제외 약 52/35/47, 다양한 20% 제외 약 32/9/7.

## 7. 한계 (Sec. X)와 논문이 직접 인정한 점

- 처음 보는 과제와 로봇 조합의 성공률은 "60–80% 범위", 본 과제는 "90% 넘는 경우가 많다"고 적습니다(Sec. X).
- 학습 데이터가 너무 크고 다양해서 어떤 과제가 정말 처음인지 확정하기 어렵다고 인정합니다. 기술 관련 과제가 다른 라벨이나 부수 행동으로 데이터에 있을 수 있다고 적습니다(Sec. X).
- 코칭은 사람이 하위 과제를 불러 주는 방식이며, 고수준 정책을 코칭 데이터로 미세조정해 자율화합니다(Sec. V-A, IX-D).
