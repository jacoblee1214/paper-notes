# 04. 논문 ↔ 공식 코드 대조

대상: `apple/ml-egodex` 얕은 클론 (`repo/`, 커밋 `718d9eb`, 2026-09-11 push). 저장소에는 **지표 함수, 데이터 로더, 시각화 예제, 유틸**만 있습니다. 학습 코드, 모델 정의, 설정, 체크포인트는 없습니다. 모든 내용은 **정적 읽기**로만 확인했습니다. 코드는 실행, import, 설치하지 않았습니다. 내부 점검 표기는 K(코드 확인 항목)와 D(차이 항목)입니다.

관련 파일: `repo/compute_metrics.py`, `repo/simple_dataset.py`, `repo/utils/skeleton_tfs.py`, `repo/utils/data_utils.py`, `repo/visualize_2d.py`, `repo/README.md`, `repo/requirements.txt`.

## 1. 코드 확인 (K)

| 항목 | 논문 | 코드 | 판정 |
|---|---|---|---|
| K1 행동 48차원 레이아웃 | §4.1: 손당 3 + 6 + 15 = 24, 양손 48 | 코드 주석과 assert: 48. 손목 위치 0–2, 왼손 손가락 9–23, 오른손 손목 24–26, 오른손 손가락 33–47 | 일치 |
| K2 12개 키포인트 | 양 손목 + 손가락 끝 5개씩 | `[0..2] + [9..26] + [33..47]` = 36 값 = 12점 × 3 | 일치 |
| K3 평균 거리 | 청크 시점과 12점 평균 | `avg_dist.mean(dim=(1,2))`: 시점과 점 축 평균 | 일치 |
| K4 최종 거리 | 본문 정의 없음 | `final_dist`는 마지막 시점, 12점 평균 | 일치 (논문이 정의하지 않은 것을 코드가 채움, D6) |
| K5 best-of-K | 샘플 K개의 최소 | `torch.min(avg_dists[no_pad][:, :k], dim=1)`: 앞 K개의 최소, 샘플별 | 일치 |
| K6 결정론적 모델의 K 무관성 | §4.3 | 모델 측 문제라 코드 대조 대상 아님 | - |
| K7 손목 신뢰도와 손가락 신뢰도 | 부록 A.3: 손목은 손 전체 검출, 손가락은 손목 기준 | README와 부록 일치 | 일치 |
| K8 관절 목록 | 부록 A.3: 상체 20, 손당 25 (손목 포함) | `skeleton_tfs.py`: 손가락 24 + 손목(팔 목록에 포함), 상체 20. 합 68 + 카메라 = 69 | 일치 |
| K9 데이터 분할 | 1% 과제별 무작위 테스트 | 로더는 분할을 만들지 않음. 공개 `test.zip`이 테스트 세트 | 확인 불가 (분할 방법은 코드에 없음) |
| K10 입력 | 현재 이미지, 고유감각, 언어 | 로더는 이미지(VideoDecoder), SE(3) 쿼리, 언어, 신뢰도를 반환 | 부분 일치 (고유감각 정의 없음, D8) |

## 2. 차이 (D)

| 번호 | 논문 | 코드 | 영향 |
|---|---|---|---|
| D1 | 행동은 손목 위치, 6D 회전, 손가락 끝을 포함 (§4.1) | `SimpleDataset`의 기본 `query_tfs`는 `WRISTS`(양 손목 변환 두 개만). 행동을 만드는 함수 없음 | 기본 로더만으로는 논문 행동을 얻을 수 없음. 재구성은 사용자가 해야 함 |
| D2 | 포즈는 현재 카메라 프레임 (§4.1) | 로더는 ARKit 원점 프레임 반환. 카메라 변환 `convert_to_camera_frame`은 있지만 로더와 지표에서는 호출하지 않음 (시각화에서만 호출) | 프레임을 바꾸지 않으면 지표 값이 논문과 달라질 수 있음 |
| D3 | 6D 회전 표현 (Zhou et al.) | 6D 회전 생성과 변환 코드 없음. 지표 주석은 "6D 회전을 건너뛴다" | 코드 주석과 본문 일치, 학습 입력 생성은 없음 |
| D4 | 행동 청크는 상대 궤적 (Chi et al. 2024) | 상대 변환 코드 없음 | 상대 기준(첫 시점 기준인지, 현재 기준인지) 불명 |
| D5 | 지표는 "테스트 세트 전체 평균" (§4.3) | `evaluate_distance`는 **패딩이 없는 청크만** 남김(`no_pad`). 전체 평균은 호출자 몫이며, 배치 평균을 샘플 수 가중 없이 내면 편향 | 논문에 패딩 제외 규칙이 없음. 패딩이 많은 과제는 결과가 달라질 수 있음 |
| D6 | "Final distance"의 정의를 본문이 주지 않음 | 마지막 시점 기준 (K4) | 정의를 코드가 채움. 본문에 적었어야 함 |
| D7 | 샘플링 K는 "평가 시 샘플" | 함수가 `pred_actions`를 N×B×T×48로 요구하고 N ≥ max(K)를 assert. 샘플 생성은 없음 | 샘플러(스텝 수, 노이즈 시드)는 공개되지 않음 |
| D8 | 입력: 현재 이미지와 고유감각 (§5, 부록 A.4) | 로더에 고유감각 반환 없음. SE(3) 쿼리로 대신할 수 있지만 정의와 다름 | 재현 시 입력 정의를 따로 정해야 함 |
| D9 | 학습은 X-IL 코드베이스의 기본값 (부록 A.4) | 학습 코드, 설정, 모델 정의 없음 | 학습 재현 불가 (코드 외부 의존) |
| D10 | v1·v2 본문과 부록: 데이터는 "CC-by-NC-ND", 다운로드 URL 명시. v3에는 이 문장과 안내가 없음 | README: 데이터 CC-by-NC-ND, zip 구조와 HDF5 스키마 설명 | 본문 v3와 저장소 README의 권리 설명이 다름 (`01` §6) |

## 4. 구현 가능성 판정

**판정: 전체 재현은 이 맥에서 불가능합니다. 지표와 데이터 입력 파이프라인은 CPU와 MPS에서 할 수 있습니다.** 근거는 다음과 같습니다.

- **불가:** 14개 모델의 학습(모델당 A100 8장 약 72시간, 상한 약 8,000 A100 GPU시간). 전체 데이터 로딩(1.7 TB), 그림 5의 데이터 규모 실험, OOD 6과제(extra.zip 200 GB). 이 맥(Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)은 CUDA 학습을 할 수 없습니다.
- **가능 (CPU):** 지표 함수의 독립 구현과 합성 데이터에서의 단위 테스트(K1–K5 대조). 이 작업은 numpy 또는 torch 설치가 필요하므로 설치 전 목록을 먼저 보여 주어야 합니다.
- **조건부:** 테스트 세트 일부(한 과제)로 작은 Dec+BC를 MPS에서 학습해 지표 잡음을 측정. 16 GB 다운로드 승인이 먼저 필요합니다. 본 분석에서는 승인을 받지 않았습니다.
- **공수 (추정, 측정 아님):** 지표와 로더 재구현 1–2일, 한 과제 소형 BC와 시드 측정 1–2주. 전체 14모델 재현은 해당 없음.

**공식 코드의 한계.** 저장소는 "교육용 예제"라고 스스로 말합니다(README). 논문 결과를 재현하는 코드가 아니므로, 재현의 중심은 지표 정의와 데이터 스키마가 됩니다.
