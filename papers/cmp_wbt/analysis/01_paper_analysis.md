## 1. 한 문단 요약

로봇 학습 정책이 말단 목표 궤적을 따라가는 다리 달린 매니퓰레이터(Unitree Go2 + 6축 팔)에서, 정책이 한 번도 숙달하지 못한 명령(OOD: 뒤쪽 목표, 센서 드리프트)이 들어오면 넘어집니다. CMP는 목표 궤적을 6차원 잠재 명령 z로 인코딩하는 CVAE형 구조(인코더 ϕ, 정책 π)에 **안전 추정기 ω**를 붙입니다. ω는 "이 z를 지금 실행하고 이후 최적으로 고르면 영원히 안전할 확률" W(s, z)를 TD(λ)로 학습합니다(식 1–4). 인코더의 KL 사전분포 분산을 W에 따라 정하는 **ILS**(식 5–6)로 "안전할수록 원점에 가깝다"는 구조를 만들고, 실행 시 ‖z‖가 R_safe를 넘으면 노름만 잘라 투영합니다(식 7). 시뮬레이션(Isaac Gym, 궤적 7,000개)에서 OOD-Geometry 생존율이 UMI-on-Legs 4.7%에서 46.9%(R_safe = 2.0)로, 실로봇(범주당 15회)에서 중등도 OOD 0%에서 93.3%로 올랐다고 보고합니다(표 2, 4).

## 2. 문제 설정과 방법

### 2.1 문제 설정 (§3.1, 식 1)

- MDP (S, A, P, G). S_safe는 토크 포화와 접촉력 등으로 정의된 안전 상태 집합이지만, 실제 종료 조건은 부록 G가 정의합니다. 위험 몸체(몸통, 엉덩이, 허벅지, 머리, 팔 전 구간)가 지면과 1.0 N을 넘는 힘으로 접촉하면 종료입니다. 관절 한계, 토크 포화, 행동 변화율은 종료가 아니라 벌점입니다.
- 목표는 임의의 목표열 g에 대해 모든 t ≥ 0에서 s_t ∈ S_safe입니다. 이를 세 가지 어려움으로 나눕니다. (1) 시간-공간 복잡도: 안전한 명령 집합이 24차원(6-DoF × 키프레임 4개) 공간에서 흩어져 있어 원 명령 공간에서 O(1) 검사가 어렵다(부록 A, 그림 6a). (2) 경계 모호성: D_train ≠ D_safe라서 학습 분포에 들어 있다고 안전한 것이 아니다. (3) 끊김 없는 집행: 긴급 정지가 아니라 "가장 가까운 안전 명령"을 찾아야 한다.
- OOD의 정의는 "정책의 능력 분포 밖"이며 학습 분포 밖과 구별합니다(§1, §3.1).

### 2.2 프레임 단위 안전 도식 (§3.2, 식 1–2)

- 인코더 ϕ(MLP [256, 256])가 (s_t, g_t)에서 N(μ, Σ)를 내고 z_t를 뽑습니다. 정책 π(MLP [256, 256, 256])는 (s_t, z_t)에서 행동(12 + 6 = 18 관절)을 냅니다. 둘 다 PPO로 함께 학습합니다. 둘 다 s_t를 입력으로 받으므로 잠재 공간은 "현재 상태 대비 미래 궤적 의도"만 담는다고 설명합니다.
- **영속 안전 확률** W^π(s_t, z_t)는 z_t를 지금 실행하고 이후 잠재 명령을 최적으로 고를 때 영원히 S_safe에 머물 확률의 최댓값입니다(식 1). 마르코프 성질로 식 2의 재귀가 됩니다. 능력 다양체 C_δ(s) = {z | W(s, z) ≥ 1 − δ}이고, "무한 지평 안전 요구가 단일 단계 멤버십 검사 z ∈ C_δ(s)로 정확히 줄어든다"고 주장합니다(§3.2).

### 2.3 하한 안전 추정기 (§3.3, 식 3–4, 부록 C)

- ω(MLP [256, 256], 출력 시그모이드)가 W를 근사합니다. 식 2의 max_z' W(s_{t+1}, z')를 잠재 원점의 값 Ŵ(s_{t+1}, 0)로 바꾸고(원점이 최댓값에 가깝다는 가정, 부록 C.5), TD(λ_safe = 0.8)로 목표를 만듭니다. 목표는 실패 0, 타임아웃 1, 그 외 (1 − λ)Ŵ(s_{t+1}, 0) + λ W_target,t+1입니다(식 3). 손실은 BCE(식 4)입니다.
- 부록 C는 n단계 확장 P^(n)이 n에 대해 비증가이고(식 11–12) λ-목표가 W의 하한(식 14)이라는 증명을 제시합니다. 이 증명이 타임아웃 규칙과 원점 근사, 학습된 ω에 어디까지 적용되는지는 `03` §6, `04` C4에 정리했습니다.

### 2.4 동형 잠재 공간 ILS (§3.4, 식 5–7, 표 6–7)

- W_target에 대해 단조 감소하는 분산 R_t = clip(1/(W_target + ε)³, R_min, R_max)를 둡니다(식 5). ε = 1 − W̄_batch입니다. 인코더는 KL(N(μ, Σ) ‖ N(0, R_t² I))을 줄입니다(식 6). 고차원 가우시안이 반지름 √d R 근처 셸에 몰린다는 점을 이용해 ‖z‖ ∝ R, 즉 안전할수록 노름이 작게 만든다는 설명입니다.
- 실행 시 ‖z_raw‖ ≤ R_safe이면 그대로 쓰고, 넘으면 z_safe = z_raw · min(1, R_safe/‖z_raw‖)로 자릅니다(식 7). 유클리드 공 위의 투영이라 연속이고, 의도의 방향은 유지됩니다.
- 학습(표 7): PPO 환경 4,096개, 2,000 반복, PPO 에폭 32, 미니배치 4, 적응형 LR 1e-3, γ = 0.9, GAE λ = 0.95, 클립 0.2, **β_KL을 1k 반복에 걸쳐 0에서 1e-3까지 올림**, 안전 추정기는 고정 LR 1e-3이고 λ_safe = 0.8. A6000 한 장에서 약 2.5시간(부록 H). **R_min, R_max, 인코더 잠재 차원 6(표 6)을 제외한 상태·목표 차원, 한 반복당 롤아웃 길이, 제어 주파수, 보상 가중치는 본문에 없습니다.** 보상은 UMI-on-Legs와 같다고만 적습니다(부록 H.2).
- 잠재 차원이 d = 6이라서 "셸에 몰린다"는 서술의 선명도가 낮습니다(`03` §6.2).

## 3. 실험 결과

### 3.1 시뮬레이션 (§4.1, 표 2)

- 평가: 궤적 7,000개 × 13초(부록 F는 2,500 스텝 / 200 Hz = 12.5초), 세 장면. **ID**는 정면 yaw [−60°, 60°]. **OOD-Geometry**는 ID 데이터를 yaw U(179°, 181°)로 다시 증강해 뒤쪽으로 뒤집은 것(부록 F.2). **OOD-Sensor**는 ID 궤적에 1–5초 간격으로 위치 N(0, 0.2²) m, 회전 N(0, 30²)°의 지속 편향을 더한 것입니다.
- 학습 데이터: UMI-on-Legs의 "cup in the wild" 1,090개와 "tossing" 101개(3배 과표집)에서 2,000개를 뽑아 증강하고, 절차 생성 푸시 5,000개를 더해 7,000개(부록 F.1). 그림 3의 6.2% / 22.4% / 71.4%와 맞습니다(`03` V22). OOD 두 세트는 학습 데이터셋을 기반으로 만들었습니다("derived from the full ID dataset"). ID 시험 세트는 다른 시드로 같은 절차를 돌려 만들어 UMI 원본 궤적 풀이 겹칩니다(부록 F.1).
- 기준선: UMI-on-Legs, Latent Shielding, Neural CBF. 모두 같은 데이터로 학습하고, 필터를 끄면 매개변수 수를 맞춥니다(부록 K).
- **결과(R_safe = 2.0)**: ID에서 SR 94.7%, e_p 4.5 cm, e_r 0.106 rad(UMI 85.3%, 4.9 cm, 0.105). OOD-Geometry SR 46.9%(UMI 4.7%, Latent Shielding 5.6%, Neural CBF 7.1%), OOD-Sensor SR 40.3%(UMI 6.9%, 17.7%, 19.8%). R_safe를 1.0으로 줄이면 OOD-Geometry 82.5%지만 ID e_p는 15.6 cm가 됩니다. R_safe = 100(사실상 투영 없음)에서는 ID 3.5 cm, 0.086 rad, OOD-Geometry 5.1%입니다.
- 추적 오차는 SR < 30%인 칸에서 생략합니다(표 2 주석). OOD-Geometry에서 CMP가 생존한 칸의 e_p는 69–102 cm, e_r은 1.6–1.9 rad로 ID(4.5 cm)와 크게 다릅니다.

### 3.2 절제 (§4.2, 표 3, 그림 4)

- CVAE(프레임 안전 도식만, 잠재를 R_safe로 자름), SCVAE(안전 추정기 추가, W가 배치 평균을 넘는 샘플에만 KL), CMP(ILS 추가)를 R_safe 훑기로 비교합니다. 그림 4는 ID 위치 오차(로그)와 OOD-Geometry SR의 곡선이며 수치표는 없습니다. 본문 서술은 "SCVAE는 큰 반지름에서 CVAE보다 낫고 작은 반지름에서는 못하다, CMP가 더 좋은 교환 곡선"입니다.

### 3.3 실로봇 (§4.3, 표 4, 그림 5)

- 플랫폼: Unitree Go2 + Hexfellow Saber 6축 팔(그리퍼는 파손 방지로 제거), Intel RealSense T265 VIO. 15개 목표 궤적 × 4 방법. ID 5개, 중등도 OOD 5개, 극단 OOD 5개이고 **궤적당 3회**입니다(표 4 머리글). 그림 5는 9개 대표 과제(앞/옆/뒤 × 밀기/원/던지기)의 결과 사진입니다.
- 결과(SR, 표 4): ID에서 CMP 100%, UMI 80.0%, Latent Shielding 73.3%, Neural CBF 80.0%. 중등도 OOD에서 93.3%, 0.0%, 33.3%, 60.0%. 극단 OOD에서 86.7%, 0.0%, 20.0%, 40.0%. CMP는 45회 중 3회 실패(§4.3, §6). 지연(ms)은 UMI 2.97 ± 0.15, Latent Shielding 3.89 ± 0.49, Neural CBF 5.36 ± 0.54, CMP 2.99 ± 0.14입니다.
- 그림 5의 색 막대는 초록(과제 성공), 파랑(정확도가 낮아도 안전하게 생존), 빨강(치명적 실패)입니다. CMP는 앞 방향 3개와 옆으로 밀기(Trj 4)에서 "Success", 옆 원, 옆 던지기, 뒤 세 과제(Trj 5–9)에서 "Survive"로 표기됩니다. 표 4의 OOD "SR"이 생존율이라는 점과 과제 성공 횟수는 따로 보고되지 않는다는 점이 이 표기에서 읽힙니다(`03` §2, `04` C9).

### 3.4 안전 추정기 검증 (부록 D, 표 5, 그림 7)

- 정성: 옆으로 밀기 OOD 명령을 투영 없이 실행하며 W_max = W(s, 0), W_proj, W_raw 시계열을 그립니다(그림 7). 세 구간(정상, OOD, 넘어지기 직전)에서 W_max > W_proj > W_raw 순서와 하락이 보인다고 서술합니다.
- 정량: OOD 롤아웃 상태 500개를 5명이 "구제 가능/불가" 이진 투표로 라벨링하고, W_max 세 구간(< 0.6, 0.6–0.8, > 0.8)에서 라벨 분포를 보입니다(표 5). 두 극단 구간의 조건부 비율 97.7%와 97.6%를 근거로 제시합니다.

### 3.5 그 밖의 부록 검증

- 부록 E: 사인파 전진 궤적에서 VIO 드리프트가 되먹임으로 증폭되는 사례(그림 8). UMI-on-Legs는 발진, CMP는 감쇠합니다. 정성 비교 한 건입니다.
- 부록 J: 원점 값 Ŵ(s, 0)가 탐색한 max_z' Ŵ(s, z')보다 항상 작고(평균 2.5%, 최대 5.2%, 롤아웃 상태 100개), 안전 값과 반지름 쌍의 94%가 단조 감소(그림 9a)라고 보고합니다. "학습한 타원체 경계도 동등해서 구를 택했다"는 문장에는 수치가 없습니다.
- 부록 K: 추가 OOD(궤적 뒤집기, 속도 조절, 축 치환)를 "비슷하게 동작한다"고 서술하고 표 8에는 OOD-Rev만 수치가 있습니다(`03` §4).

## 4. 저자가 인정한 한계 (§6, 부록 I)

- 45회 실로봇 시도 중 3회 실패: 추정기가 안전을 과대 예측해 진동한 1회, 투영 뒤에도 불안전했던 2회(§6).
- 구형 경계는 통계적으로 성립하며 "보장에 가까운" 서술은 통계적으로 읽어야 한다(§6, 부록 I). CMP는 입력 명령의 OOD를 다루고 동역학 변화(적재, 지형, 부착물)는 평가하지 않았다(부록 I). 휴머노이드로의 확장은 열린 과제(§6).
