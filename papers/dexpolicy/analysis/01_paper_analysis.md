## 1. Abstract (한 줄 요약과 주장)

**한 줄 요약:** 사람 영상에서 얻은 손-물체 궤적을 RL로 다듬는 ViViDex의 state-policy 단계에서, PPO가 학습하던 행동 잡음 σ를 **학습 step의 함수로 미리 정해 줄이는 것**만으로 최종 결정론적 성공률이 오른다고 주장합니다. 손실, 구조, 보상, 최적화 설정은 쌍마다 그대로 둡니다.

논문이 내세우는 기여는 세 가지입니다(Sec. I).

1. 탐색 잡음 스케줄이 세 가지 정책 최적화 설정(PPO, critic 없는 GRPO 연속 학습, flow 평균을 쓰는 PPO 변형 "FPO") 모두에서 결정론적 Target 성공의 평균을 올린다. 시뮬레이션과 실제 로봇 모두에서 그렇다.
2. PPO 구성 요소 선별에서 "잡음 제어"가 "최적화기 수축"(학습률·clip·epoch 감소)보다 낫고, 고른 스케줄이 같은 끝점의 선형 감쇠보다 세 물체에서 평균이 높다.
3. 학습 return, 결정론적 Target 성공, 실행 잡음 내성이 서로 어긋난다. 따라서 스케줄은 의도한 실행 조건에서의 최종 과제 성공으로, 과제·최적화 설정마다 따로 판단해야 한다.

헤드라인 수치(초록, Table I·III):

| | 시뮬레이션 (물체 5개 × seed 3개) | 실제 로봇 (물체 3개 × 20회, 조건당 모델 1개) |
|---|---|---|
| PPO | 32.0 → 35.7% | 8.3 → 43.3% |
| GRPO | 14.1 → 45.4% | 10.0 → 63.3% |
| FPO | 49.4 → 68.1% | 25.0 → 85.0% |

## 2. Method

### 2.1 문제 설정 (Sec. III, Eq. 1–3)

```
ViViDex state-policy 단계: 영상에서 얻은 손-물체 궤적(DexYCB) → RL로 물체 재배치(relocation) 정책 학습
   (원래 ViViDex는 이후 visual policy로 증류하지만, 이 논문은 state policy까지만 다룸)

행동 정책  q_{θ,k}(a_t | o_t) = N( μ_θ(o_t), σ_k² I )        (Eq. 1)
   μ_θ : MLP(PPO, GRPO) 또는 flow로 만든 결정론적 평균(FPO)
   σ_k = σ(s_k) : 누적 환경 step s_k의 함수, 모든 행동 차원이 공유하는 스칼라
   rollout 수집과 모든 update epoch 동안 같은 σ_k → ratio의 분자·분모가 같은 σ를 씀   (Eq. 2)
PPO 목적함수: clipped surrogate                               (Eq. 3)
```

평가는 **결정론적 실행(σ_eval = 0)**을 기본으로 합니다. 학습 중 잡음 크기가 다른 두 조건을, 평가 때 잡음을 빼고 같은 규칙으로 비교하려는 설계입니다(Sec. I, V-A).

### 2.2 PPO + DexPolicy (Sec. IV-A, Eq. 4)

기준선 PPO는 ViViDex 설정 그대로 log σ를 학습합니다(초기 log σ = −1.60, 즉 σ ≈ 0.202). DexPolicy는 log σ를 얼리고 다음 곡선으로 정합니다.

```
σ(s) = 0.20 − 0.10·s/2M            0 ≤ s < 2M
       0.10 − 0.05·(s − 2M)/2M      2M ≤ s < 4M
       0.04                          s ≥ 4M
```

학습률 1e-5, clip 0.20, 5 epoch, 기울기 norm 상한 0.50은 그대로입니다. 곡선은 2M에서 연속이고 4M에서 0.05 → 0.04로 떨어집니다. 동기로 든 관찰은, 머스터드 기준선 세 실행에서 학습된 σ가 5M step 뒤에도 0.185–0.186에 머문다는 것입니다(Sec. I).

### 2.3 GRPO + DexPolicy (Sec. IV-B, Eq. 5)

value baseline 없이, 완료된 궤적의 할인 reward-to-go를 **같은 에피소드 나이끼리** 표준화한 것을 advantage로 씁니다.

```
G_{i,t} = Σ_{u=t}^{T_i−1} γ^{u−t} r_{i,u},   γ = 0.95
I_t = { j : T_j > t }  (나이 t에 도달한 완료 궤적)
Â_{i,t} = (G_{i,t} − mean_{j∈I_t} G_{j,t}) / (std_{j∈I_t} G_{j,t} + 1e-8)     (Eq. 5, |I_t| ≥ 2)
```

잘린 조각과 완료 궤적이 둘 미만인 나이는 advantage 0입니다. value loss, bootstrap, reference KL은 없습니다. 두 조건은 같은 물체·seed의 PPO 체크포인트(약 5M step)에서 출발합니다. 기준선은 물려받은 σ를 계속 학습하고, DexPolicy는 σ를 얼린 채 다시 키운 뒤 줄입니다(아래 3.3).

### 2.4 FPO + DexPolicy (Sec. IV-C)

MLP 평균 대신 조건부 flow를 씁니다. 0에서 시작하는 8단계 적분기가 정규화된 상태를 결정론적 행동 평균으로 바꿉니다. 그 위에 Gaussian likelihood와 PPO clip update를 그대로 씁니다. 논문도 밝히듯 McAllister et al.의 FPO[17]나 FPO++[18](flow matching 손실로 ratio를 만드는 방법)과는 다른 알고리즘입니다. 기준선은 σ = 0.10 고정이고, DexPolicy는 5M step에 걸쳐 0.20 → 0.05로 선형 감쇠합니다. 따라서 FPO 비교는 "PPO 곡선(Eq. 4)"이 아니라 **선형 감쇠 대 고정 잡음** 비교입니다.

## 3. Experiments

### 3.1 설정 (Sec. V-A)

- **과제:** ViViDex 다지 손 재배치, YCB 물체. 22차원 행동, 32개 학습 환경. 물체마다 정책을 따로 학습하므로 "물체 간 전이"는 정책이 아니라 스케줄 규칙의 전이입니다.
- **스케줄 선별:** 머스터드로 곡선을 고르고, 머그·바나나·설탕·피처·나무 블록에 다시 조정하지 않고 적용합니다.
- **지표:** Target(지정 접촉 + 최종 위치가 목표에서 3 cm 이내)이 주 지표이고 Lift(지정 접촉 + 높이 5 cm 초과)가 보조 지표입니다. 학습 곡선 쪽은 정규화 reward AUC, 접촉 비율, 들어 올린 높이를 진단용으로 봅니다.
- **평가량:** PPO·FPO는 체크포인트마다 확률적 100회 + 결정론적 100회입니다(체크포인트 96개, 19,200회). GRPO는 최종 모델마다 결정론적 200회, 확률적 200회, 공통 σ 0.03·0.10에서 각 100회입니다(모델 30개, 18,000회).
- **통계:** 평균과 seed 3개의 표본 SD만 보고하고, 유의성은 주장하지 않는다고 밝힙니다(Sec. V-B).

### 3.2 최종 정책 성공 (Table I)

|---|---|---|---|---|---|---|

| PPO + DexPolicy | 94.7 ± 9.2 | 40.7 ± 17.1 | 2.3 ± 2.1 | 0.0 ± 0.0 | 40.7 ± 9.1 | 35.7 ± 3.9 |
| GRPO | 30.8 ± 53.4 | 25.3 ± 15.0 | 3.0 ± 3.9 | 4.2 ± 4.3 | 7.0 ± 3.1 | 14.1 ± 8.5 |
| GRPO + DexPolicy | 34.5 ± 56.7 | 41.7 ± 3.3 | 3.2 ± 2.8 | 88.0 ± 12.3 | 59.8 ± 4.5 | 45.4 ± 14.4 |
| FPO | 51.7 ± 46.0 | 25.3 ± 34.8 | 16.3 ± 8.0 | 91.3 ± 13.3 | 62.3 ± 54.0 | 49.4 ± 21.5 |

해석 (재계산은 `04_code_verification.md` §3과 `analysis/table_check.py`):

- **표 수치는 맞습니다.** Overall은 다섯 물체 평균과 일치하고, 8개 물체 평균(PPO 20.0 → 22.3, FPO 30.9 → 42.5)도 나머지 세 물체를 ≈ 0으로 두면 맞습니다. 본문의 seed별 값으로 FPO 머스터드·머그·토마토, GRPO 머스터드의 평균과 SD도 재현됩니다.
- **PPO의 이득은 작고 엇갈립니다.** 다섯 물체 중 2개 증가, 2개 감소, 1개 동일이고, 8개 물체 평균은 seed 3개 중 1개에서만 올랐습니다(본문 Sec. V-B). seed 수준 Welch 근사 p ≈ 0.39입니다. "세 설정 모두에서 오른다"는 기여 문장은 평균 기준으로만 맞습니다.
- **GRPO와 FPO의 이득은 특정 물체에 몰려 있습니다.** GRPO는 설탕 +83.8%p와 토마토 +52.8%p가 Overall 증가(+31.3%p)의 대부분입니다. FPO는 머스터드 +48.3%p와 토마토 +30.4%p입니다. FPO의 실패 seed를 없앤 효과(머스터드 88/67/0 → 100/100/100)가 크고, 머그는 오히려 65/0/11 → 0/0/93으로 seed 0이 무너졌습니다.
- **seed 간 분산이 매우 큽니다.** FPO 토마토 기준선 SD는 54%p, GRPO 머스터드는 53%p입니다. seed 3개로는 평균 차이를 가려내기 어렵습니다(FPO Welch p ≈ 0.27, GRPO p ≈ 0.04).

### 3.3 GRPO 연속 학습과 잡음 내성 (Sec. V-C, Table II)

- **연속 학습 설계:** 두 단계로 507,904 step(학습률 1e-4)과 253,952 step(5e-5)을 더합니다. 둘 다 rollout 8,192의 정수배(62, 31)입니다. 토마토는 세 번째 단계(253,952 step, 3e-5)가 더 있습니다. DexPolicy 쪽은 σ를 0.20으로 **다시 키운 뒤** 0.20 → 0.10 → 0.03으로 줄입니다. 토마토 세 번째 단계는 0.10에서 0.02로 줄입니다. 그래서 이 개입에는 잡음 재확대, 얼림, 감쇠가 함께 들어 있고, 논문도 이 셋을 분리하지 못했다고 밝힙니다(Sec. VI).
- **개발용 seed:** 원래 네 물체에서 seed 0은 개발에 썼고 seed 1, 2가 재현입니다. seed 0을 빼도 다섯 물체 평균은 15.3 → 37.2%로 오릅니다. Table II의 seed 1/2 행 평균 차이(+21.9%p)와 일치합니다.
- **머스터드는 뒤집힙니다.** seed 1/2에서 46.25 → 1.75%입니다. 머스터드의 평균 이득은 seed 0(0 → 100%)이 만든 것입니다.
- **잡음 내성:** 공통 σ_eval = 0.03이면 14.8 → 41.8%로 이득이 유지됩니다. 0.10이면 16.1 → 8.7%로 **뒤집힙니다.** 작은 σ로 학습한 정책은 결정론적 성공은 높지만 큰 실행 잡음에 약합니다. 논문의 세 번째 기여(지표 해리)의 핵심 증거입니다.

### 3.4 실제 로봇 (Sec. V-D, Table III)

| 방법 | 토마토 T / L | 설탕 T / L | 머스터드 T / L |
|---|---|---|---|
| PPO → + DexPolicy | 10 / 35 → 45 / 70 | 0 / 5 → 0 / 10 | 15 / 75 → 85 / 95 |
| GRPO → + DexPolicy | 5 / 35 → 55 / 90 | 10 / 75 → 90 / 100 | 15 / 30 → 45 / 95 |
| FPO → + DexPolicy | 25 / 30 → 80 / 95 | 20 / 45 → 75 / 85 | 30 / 60 → 100 / 100 |

(T = Target %, L = Lift %, 조건당 20회)

- **장비와 절차:** RealMan RM75 팔 + Inspire/RH56 손입니다. 정책은 하드웨어에 맞춘 별도 시뮬레이션에서 학습했습니다(ViViDex 벤치마크와 다른 embodiment). 관측은 관절 상태, 엔드이펙터 상태, FoundationPose 물체 자세입니다. 20 Hz로 엔드이펙터 자세와 손 관절 목표를 냅니다. 물리 미세조정과 visual 증류는 없습니다. Fig. 3을 보면 실제 물체는 YCB 형상을 본뜬 흰색 복제품으로 보입니다(질량·마찰은 미보고).
- **평균은 모두 맞고(`04` C4), 시행 수준으로는 차이가 큽니다.** 합산 Fisher p는 PPO 1.7×10⁻⁵, GRPO 1.1×10⁻⁹, FPO 3.1×10⁻¹¹입니다. 다만 **조건마다 학습된 모델은 하나**이므로 이 검정은 "그 모델 하나를 20번 돌린 잡음"만 다룹니다. 시뮬레이션 seed 사이의 분산(SD 수십 %p)을 생각하면, 모델 하나씩의 비교는 seed 운에 크게 열려 있습니다(`04` C8).
- **효과 크기가 시뮬레이션과 다릅니다.** PPO는 시뮬레이션 +3.7%p, 하드웨어 +35%p입니다. 하드웨어 정책은 다른 시뮬레이터에서 학습했으므로 두 숫자의 차이를 sim-to-real 간극으로 읽을 수는 없습니다. 저자도 이 점을 밝힙니다(Sec. VI).

### 3.5 무엇이 이득을 만드는가 (Sec. V-E, Table IV–VII)

- **구성 요소 선별(Table IV, 머스터드 seed 0 하나):** 잡음 스케줄만 쓰면 reward AUC가 19.96 → 27.36으로 오릅니다. 최적화기 수축만 쓰면 12.35로 떨어지고, 둘 다 쓰면 19.13입니다.
- **모양 선별(Table V):** 기준 곡선(2M에서 0.10 → 0.08 점프 포함) 대비 AUC를 95% 이상 유지해야 통과합니다. 점프를 뺀 곡선만 통과합니다(100.3 / 95.5 / 108.3%). 선형 0.20 → 0.05와 앞당긴 감쇠는 탈락합니다.
- **최종 정책 선형 대조:** 0.20 → 0.04 선형 감쇠(seed 3개)는 머스터드 83.7%, 머그 29.7%, 바나나 1.3%입니다. 기준선(84.0 / 25.3 / 8.7)과 비슷하고, DexPolicy(94.7 / 40.7 / 2.3)보다 머스터드·머그에서 낮습니다. 다만 seed가 벤치마크 seed와 쌍을 이루지 않습니다.
- **학습 기간 지표(Table VI·VII·VIII):** reward AUC는 6개 물체 모두 오릅니다(쌍 16/18 승). 10M step까지 늘려도 머스터드 이득이 유지됩니다(+30.7%, 3/3). FPO는 머그·설탕에서 reward AUC가 1% 미만 오르는 사이 접촉과 높이 AUC가 떨어집니다.

## 4. Limitations

### 4.1 저자가 밝힌 한계 (Sec. VI)
- 물체마다 레퍼런스 하나로 학습한 정책이라 zero-shot 일반화를 보이지 않습니다. 8개 중 3개 물체는 사실상 풀리지 않았고, 긴 학습은 머스터드만 했습니다.
- ablation은 최적화기 수축 하나와 고정 FPO 잡음 하나뿐입니다. 잘 조정한 **고정 저잡음 PPO 기준선이 없어서**, 똑같이 조정한 대안보다 우월하다고 말할 수 없습니다.
- GRPO의 머스터드 뒤집힘이 재현성을 제한합니다. 연속 학습이라 처음부터 학습할 때의 효율이나 방법 간 비교를 말할 수 없고, 재확대·얼림·감쇠를 분리하지 못했습니다.
- seed 3개, 하드웨어 모델 1개, 플랫폼 1개입니다. 하드웨어 시뮬레이터가 벤치마크와 달라 sim-to-real 간극을 측정하지 않습니다.

### 4.2 분석하면서 추가로 발견한 한계와 의문점
1. **공개 GRPO 코드는 Eq. 5가 아닙니다**(`04` D1). `algos/grpo.py`는 완료 궤적마다 **할인 없는 총 보상**을 rollout 전체에서 표준화해 그 궤적의 모든 step에 같은 값을 줍니다. 나이별 그룹도, γ = 0.95 할인도 없습니다. Hugging Face 메타데이터의 GRPO 모델은 `credit_module: grpo_rtg`(reward-to-go)로 적혀 있어서, 실험에 쓴 모듈이 공개되지 않은 것으로 보입니다. toy에서 두 advantage의 상관은 0.73, 부호 불일치는 7.6%였습니다(`03` §3).
2. **기준선 PPO는 원래 ViViDex 예산의 1/20로 학습되었습니다.** ViViDex 공개 설정의 기본 학습량은 1억 step(`total_timesteps: 100000000`)이고, 이 논문의 비교는 5M step입니다. 이 예산에서 Adam(lr 1e-5)이 log σ를 움직일 수 있는 폭은 약 0.98입니다(`03` §2). 0.20에서 0.04로 가려면 1.62가 필요해서, **학습된 σ는 원리상 DexPolicy의 최종 잡음에 도달할 수 없습니다.** 따라서 PPO 비교는 사실상 "스케줄 대 거의 고정된 σ ≈ 0.19"이고, 저자가 한계로 든 "고정 저잡음 기준선 부재"가 정확히 이 지점입니다.
3. **Target 기준이 공개 환경과 다릅니다**(`04` D6). ViViDex 공개 코드의 목표 성공은 최종 물체 위치 오차 ≤ 0.01 × 5 = 5 cm입니다(`rewards.py: success_goal`). 논문 정의는 3 cm이고, Lift(5 cm 높이) 판정도 ViViDex에는 없습니다. DexPolicy가 환경·평가 코드를 수정했지만 공개하지 않아 확인할 수 없습니다.
4. **논문 실험의 일부 설정이 코드에 없습니다**(`04` D2·D3). GRPO 연속 학습 스케줄(0.20 → 0.10 → 0.03, 토마토 0.10 → 0.02)과 최종 정책 선형 대조(0.20 → 0.04)는 preset에 없습니다. 반대로 preset에는 A2C, TRPO 훅, "std_centered", 진행도 트리거, GRPO 재확대·해제 같은, 논문에 보고되지 않은 변형이 많습니다.
5. **스케줄을 고른 물체와 seed가 평가에도 들어갑니다.** 머스터드 seed 0으로 곡선을 고르고(Table IV·V), Table I 평균에 머스터드와 seed 0이 들어갑니다. GRPO는 네 물체에서 seed 0이 개발용이었습니다. 논문이 이를 밝히고 seed 0을 뺀 값도 주지만, PPO·FPO 쪽에는 같은 분리가 없습니다.
6. **"FPO"라는 이름은 혼동을 부릅니다.** 이 논문의 FPO는 0에서 출발하는 8단계 결정론적 적분으로 평균을 만드는 네트워크에 Gaussian PPO를 붙인 것입니다. 사실상 가중치를 공유하는 8블록 잔차 MLP 평균입니다. flow matching 목적함수도, 확률적 flow 샘플링도 쓰지 않습니다(`04` §1). 저자도 published FPO와 다르다고 밝힙니다.
7. **재현에 필요한 환경, 레퍼런스 선택, 보상 수정, 하드웨어 모델이 공개되지 않았습니다.** 물체마다 어떤 DexYCB 시퀀스를 썼는지도 없습니다(ViViDex 자산에는 논문의 8개 물체마다 시퀀스가 18–20개 있음). 공개 체크포인트는 머스터드 seed 0의 6개뿐입니다.
