## 1. 한 문단 요약

촉각 입력으로 고정된 시각 정책(ACT)의 행동을 고치는 잔차 프레임워크입니다. 두 결정을 분리합니다. 하나는 **언제, 어느 영역의 촉각 특징을 다시 계산할지**(인지 게이트 T1과 영역 단위 재사용 S2)이고, 다른 하나는 **보정 잔차를 적용할지**(자세와 그리퍼 게이트 T2)입니다. 보정은 말단 공간(translation, rotation, gripper)에서 bounded 잔차로 표현하고, 행동 복제로 학습합니다. 시뮬레이션의 실린더 세우기 30회에서 26회(86.7%) 성공했고, 같은 시뮬 설정의 Dense 촉각 잔차(DTR, 21/30)와 시각 전용 ACT(15/30)보다 높았습니다. 실로봇(OpenArm v2 + Paxini)에서는 네 과제를 정성적으로만 보였습니다.

## 2. 방법 (§3)

- **행동 공간 (§3.1).** 행동은 [−1,1]^7 (translation 3, rotation 3, 절대 그리퍼 명령)입니다. 보정은 관절이 아니라 말단 공간에서 정의합니다(근거: 관절 보정은 자세에 따라 변위가 달라진다고 씀).
- **변화 감지 T1 (§3.2, 식 1).** 영역 R_r의 변화량은 인접 샘플 변화 c_r[k]와 기준 대비 누적 드리프트 d_r[k]의 최댓값으로 정하고, τ1 이상이면 갱신합니다. τ1은 학습 데이터로 보정한다고만 써 있고 값이 없습니다.
- **영역 인코딩 S2 (§3.2).** 두 손가락 각 68 taxel을 32 영역으로 나눕니다. 그래프 이웃으로 영향을 전파하고, 영향을 받은 출력 토큰은 2-hop 의존성으로 다시 계산합니다. 나머지는 캐시를 씁니다. 나이 제한(age limit)이 있습니다.
- **보정 (§3.2–3.3, 식 2–4).** 잔차 제안은 `a_t = a0 + B ⊙ tanh f_θ(z, h, a0, e)`, B = (0.2516, 2)입니다. 자세 게이트와 그리퍼 게이트는 로짓을 0.5로 자릅니다. 합성은 `a = a0 + m ⊙ δa`입니다. 자세 게이트는 여섯 성분을 모두 켜고 끕니다.
- **이벤트 요약 e (§3.1).** 최근 50 ms 원시 촉각 요약을 넣어 특징 갱신 없이도 과도 신호를 씁니다.
- **학습 (§3.4, 식 5).** `L_BC = 2ℓ_B(â, a*) + 2ℓ_B(ā, a*) + BCE(p, y^ε) + ½(L_temp + L_next)`. ACT와 촉각 인코더, 표현은 고정합니다. 게이트 라벨은 전문가와 ACT 명령 차이를 B × 0.02로 나눈 값의 임계로 만듭니다. 릴리스 기억 규칙(세 결정 동안 열린 명령이 지속되면 그리퍼 열림 유지)은 학습이 아니라 실행 규칙입니다.

## 3. 실험 설계 (§4)

| 항목 | 내용 |
|---|---|
| 시뮬 | MuJoCo, OpenArm v2 + 모델링한 Paxini 패드, 촉각 68 taxel/손가락, 머리·왼쪽 손목 RGB |
| 과제 | 실린더 세우기: 잡기 → 세우기 → 놓기 → 빠지기. 4×8 cm (16회), 5×10 cm (14회) |
| 시작 조건 | 위치 오프셋 ±2 cm (4×8) 또는 ±5 cm (5×10), 잡기 피치 −30°~−10°. 재질, 마찰, 조명, 제어 지연은 고정. 기울기 무작위화 없음 |
| 평가 시작 30개 | 이전 실험에서 쓴 19개 + 새 11개 (크기 할당 맞춤). 논문은 "탐색적 개발 평가"라고 명시 |
| 기준선 | 시각 전용 ACT (BC), DTR (OmniTacTune 재구현, 온라인 SAC) |
| 실로봇 | OpenArm v2 + Paxini, 4과제 (실린더 세우기, 솔리드 페그, 중공 튜브, 열쇠). 성공률 없음 |
| 오프라인 절제 | 7개 내부 모델 선택 시작에서 나온 12개 전문가 궤적, 14,865 프레임, 재학습·재실행 없음 |

## 4. 주요 결과

**표 1 (성공률).** 실린더 세우기, 시뮬.

| 방법 | 4×8 cm | 5×10 cm | 전체 | 안전 정지 | 시간 초과 |
|---|---|---|---|---|---|
| 시각 전용 ACT | 7/16 | 8/14 | 15/30 (50.0%) | 9 | 6 |
| DTR | 13/16 | 8/14 | 21/30 (70.0%) | 6 | 3 |
| TacPilot | 13/16 | 13/14 | 26/30 (86.7%) | 2 | 2 |

**표 2 (A) 재사용과 비용 (오프라인).** 매 주기 전체 인코딩 대비 영역 474,912 → 206,975 (−56.4%), 인코더 시간 30.60 s → 19.17 s (−37.3%). 이벤트 시점만 바꾸면 영역 −14.1%입니다. 로컬 재사용에서는 주기 방식과 이벤트 방식이 같은 영역 수와 같은 인코더 호출 수(9,290)를 씁니다.

**표 2 (B) 자세와 그리퍼 게이트.** 그리퍼를 게이트로 바꾸면 그리퍼 MAE 0.04193 → 0.00841 (−79.9%). 자세를 항상 켠 A/G가 전체 MSE가 가장 낮고 (G/G 대비 −9.1%), 접근 단계 오차는 0.016 → 0.061로 나빠집니다.

**표 2 (C) 촉각 입력 제거.** 인코딩 특징을 빼면 전체 MSE가 7.70배 (0.948 → 7.296), 놓기 단계 0.576 → 24.531. 이벤트 요약을 빼면 전체 +3.07%, 잡기 보정 오차 +18.2%입니다.

**그림 4 (정성).** 세 가지를 보입니다. 촉각 변화 피크가 있는 영역과 재계산된 영역이 일치하지 않습니다(드리프트와 의존성 때문). 자세 확률은 접촉 중 대부분 0.5 아래에 있고, 그리퍼 게이트는 잡기와 놓기 근처에서 열립니다. 제안 보정은 실행되지 않은 값입니다.

**실로봇 (§4.5).** 네 과제에서 성공을 보였다고 쓰지만, 시도 수와 성공 횟수는 없습니다. 그림 5는 대표 단계의 스냅숏입니다.

## 6. 논문 주장과 근거의 간격

자세한 판정은 `04_claim_verification.md`의 C1–C20에 있습니다. 여기서는 큰 간격 세 가지만 적습니다.

1. **효율 주장과 성공률 주장이 같은 실행에서 나오지 않습니다.** 폐루프 평가는 접촉 중 모든 영역을 동기적으로 다시 계산합니다(§4.1). 따라서 86.7%는 로컬 재사용 없이 얻은 결과입니다. 56.4%는 오프라인 재생에서만 측정했습니다.
2. **기준선 차이를 게이트 효과로 돌릴 수 없습니다.** DTR은 온라인 SAC로, TacPilot은 행동 복제로 학습합니다. 릴리스 기억 규칙은 TacPilot에만 있습니다. 논문도 결론에서 "시스템 차이 때문에 기준선 결과의 원인을 게이트로 돌리기 어렵다"고 씁니다.
3. **통계 근거가 약합니다.** 시도 30회, 시작 조건 재사용, 단일 학습, 신뢰구간 없음. 재계산에서 TacPilot 대 DTR은 Fisher p = 0.21입니다(`03_analysis.md`).

## 7. 읽으면서 막힌 곳

- B = (0.2516, 2)의 단위와 두 성분의 의미가 본문에 없습니다.
- 자세 게이트 표의 "Pos. (mm)" 열 값은 0.10 근처입니다. 명령이 [−1,1]로 정규화되어 있어 mm 단위가 맞는지 확인할 수 없습니다.
- 표 2(A)에는 행동 MSE 열이 없고, "0.948 근처"라는 값은 본문에만 있습니다.
- 오프라인 절제의 12개 궤적이 학습에 쓰인 데모와 겹치는지 밝히지 않았습니다.
- 학습 데모 수, 에폭, ACT 백본, 잔차 네트워크 크기, τ1, 나이 제한 값이 없습니다.
- 실로봇 촉각 샘플링 주파수와 시도 수가 없습니다.
- LLM 사용 고지(GPT로 초고 작성)가 있습니다. 주장의 책임은 저자에게 있다고 밝혔습니다.
