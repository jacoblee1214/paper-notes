### 2.1 일치로 확인한 것

- 환경 수 4,096(교사), 3,200(학생), 점 128(교사), 64(학생)(`numEnvs`, `numKeypoints 128`, `kpDownsampleRatio 2`).
- PPO: 클립 0.2, 은닉 [1024, 1024, 512, 512], 원하는 KL 0.016, 행동 22차원(팔 6 + 손 16), 비대칭 관측 없음(대칭 PPO).
- 커리큘럼 설정 값 표 4: 단계 1·2 병만, 3단계 전체 범주(`object_cls_list: null`), 제어 주기 30 → 5 Hz, 초기 손 위치(팔 기본 관절 두 가지), 리셋 거리 0.3 → 1e6, 목표 안정 비율 0.1 → 0.2, 팔 속도 10 → 1.5. 학생 환경 설정은 3단계 설정과 같음(`xarm6_leap_hand_ap2ap_vision.yaml`).
- 상태 구성: 관절각·속도·토크, 손가락 끝 상태와 힘, 손 상태, 직전 행동, 물체·목표 상태, 64차원 사전학습 형상 특징(`meshdatav3_pc_feat`), 손가락-물체 벡터(부록 H와 같은 구성).

## 3. 정적으로 본 위험과 호환성

- **라이선스:** 코드 Apache-2.0. 깊이 모델 ViT-L 체크포인트의 모델 카드 라이선스는 cc-by-nc-4.0(1.54 GB, 허깅페이스 API 메타데이터)이고, 소형(ViT-S)은 Apache-2.0(116 MB)입니다. 받지 않았습니다.
- **체크포인트 형식:** `.pt`(pickle) 파일입니다. 신뢰하지 않는 파일로 보고 불러오지 않았고, zip 항목 크기만 읽었습니다.
- **의존성:** Python 3.8.20, CUDA 11.8, torch 2.0.1+cu118, Isaac Gym Preview(NVIDIA 개발자 사이트에서 따로 받음), pytorch3d, pointnet2_ops(CUDA 확장), wandb(코드가 `wandb.init`을 부름).
- **하드코딩:** `cuda:0` 기본값(스크립트), 설정 yaml의 PhysX GPU 옵션. 맥(MPS/CPU)에서는 Isaac Gym 자체가 동작하지 않습니다.
