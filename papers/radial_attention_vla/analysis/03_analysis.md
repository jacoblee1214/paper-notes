## 6. 두 기준 실행의 차이 (V5)

이 검사가 가장 중요합니다. 논문은 BOS 이득을 두 실행에서 보고합니다.

- 실행 A (표 6): 기준 107, value 0 140 → +33 에피소드, +13.2 pp.
- 실행 B (표 S9): 기준 114 (λ=1), λ=0 129 → +15 에피소드, +6.0 pp.
- **같은 체크포인트, 같은 seed, 같은 설정인데 비조작 기준이 107과 114로 7 에피소드 차이.** 불일치 에피소드는 27개 (기준만 성공 10, λ=1만 성공 17) (표 S10).
- 논문 자신이 이를 인정: "두 실행의 차이는 실행 간 변동이며, +13.2와 +6.0의 차이가 그 변동 안에 있는지 검정하지 않았다"(Appendix E).

**계산 관점:**

- 쌍체 검정은 한 실행 안에서 조작 효과만 봅니다. 실행 사이 변동(GPU 비결정성)은 p 값에 들어가지 않습니다.
- 실행 사이 변동의 추정은 기준 쌍 한 번(107 대 114)뿐이므로 믿을 만한 분산 추정이 아닙니다. 이 쌍의 차이 7 에피소드(2.8 pp)는 두 번째 실행의 +6.0 pp의 절반 가까이이고 실행 A의 +13.2 pp의 약 1/5입니다.
- 따라서 "+13.2와 +6.0 두 번 재현"은 같은 방향이라는 사실만 뒷받침합니다. 크기 차이와 "재현됨"이라는 표현은 근거가 약합니다. 세 번째 이상 실행 없이는 효과 크기를 말하기 어렵습니다.

## 7. 실행 간 변동과 최종 행동 편차 (V6 관련)

- 표 4의 개입 중 앞선 실행의 값: value 0 +2.0 pp, 교체 −6.4 pp (p = 0.036). 이 값을 본문 표 4와 맞춰 보면 과제 총계 차이 2와 7 에피소드(B.1에 적힌 값)와 일치합니다. 118 대 120 (차이 2), 97 대 104 (차이 7). 일관됨.
- 변동 자체는 9.2%, 10.8%, 8.0% (donor 쌍별 라벨 불일치, B.1). 같은 정책이라도 seed를 바꾸면 에피소드 라벨의 8–11%가 달라짐.

## 8. 여러 비교의 보정 (V7)

- Section 5.2와 Appendix B는 "seven comparisons"에 대해 p 값을 보정하지 않았다고 명시합니다.
- 가장 작은 p인 끝점 교체 d100의 p = 0.0198에 Bonferroni 7배를 하면 0.139. 보정하면 유의하지 않음.
- 논문은 "네 개의 교체 추정이 모두 음수이므로 3–7 pp의 작은 비용"이라고 해석. 방향은 일관되나, 크기와 유의성은 donor와 실행에 민감.

## 9. 중간 교체 대 끝점 교체의 차이 (V8)

- (2,3) 교체 대 끝점 교체: −28.4 − (−3.6) = −24.8. 보고 −24.8과 일치.
- (2,4) 교체 대 끝점 교체: −25.2 − (−3.6) = −21.6. 보고와 일치.
- 편집 크기(표 S6): 끝점 교체 d100, d101의 RMS는 0.0156, 0.0171. 중간 교체의 RMS는 0.0063, 0.0062. 끝점 편집이 실행 행동을 2–3배 더 바꾸지만 성공은 덜 떨어짐. 본문과 일치.
- 다만 끝점은 토큰 0만 실행되고 49는 실행되지 않음. 비교는 "실행 여부"와 "위치"가 섞임 (논문 자인).

## 10. 라우팅 폐루프 (V9)

- 표 8: 공유 오프셋 64, 기준 58 → 차이 +6 에피소드 = +4.0 pp. 보고와 일치.
- 과제별 +8, +2, +2 pp (Appendix F) = +4, +1, +1 에피소드 = +6. 총계와 일치.
- 셔플, key 치환, 균일: 5, 6, 6 에피소드 = 3.3–4.0%. 본문 "3–4%"와 일치. 기준 대비 손실 53, 52 에피소드 = 35.3, 34.7 pp. 본문과 일치.
- 공유 대 셔플/치환/균일: 64 − 5 = 59 (39.3 pp), 64 − 6 = 58 (38.7 pp). 본문과 일치.
