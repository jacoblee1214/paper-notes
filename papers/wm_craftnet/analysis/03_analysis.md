# 03. 수치 재계산, 일관성 검사, 토이 실험

재계산은 `analysis/recompute.py`(수 초, numpy·scipy)이고 결과는 `analysis/recompute_results.json`입니다. 토이는 `analysis/toy_clean_target.py`(약 1분)입니다. 검사 번호는 V(재계산), K(표·본문 일관성), C(주장 판정)입니다.

## 0. 가정

- 시뮬레이션 평균은 논문이 말한 "방법당 128 평가 에피소드, 95% CI" (§4.1)를 그대로 받습니다. CI 반폭을 1.96으로 나눠 표준오차를 복원하고, 평균 차이는 정규 근사 z 검정으로 봅니다. 이 표준오차는 **한 번 학습한 정책의 평가 에피소드 변동**만 담습니다. 학습 시드 수와 시드 간 변동은 논문에 없습니다.
- 표 6의 복구율은 n = 128 에피소드(시행)로 가정합니다. 아래 V2에서 이 가정이 표의 퍼센트와 ± 폭을 모두 정수 개수로 설명하는지 확인했습니다.
- 실로봇 표 3은 물체·방법마다 10회, 표 6은 방법마다 200회(20개 물체 x 10회)입니다(논문 명시). 시행은 독립이라고 보고 Fisher 정확 검정과 Wilson 95% 구간을 씁니다. 물체 단위 군집은 반영하지 못합니다(원자료 없음).
- 표 3의 "SR 정수 하한"은 "반 바퀴 초과 회전"을 π rad 초과로 읽은 경우입니다(그림 판독 값이 아니라 논문 표 값 사용). 다른 정의일 수 있습니다.
- 표 값은 논문 본문에서 옮겼고 그림 판독은 쓰지 않았습니다.

### V5. 실로봇 표 3 (물체당 10회)

- **SR에서 오는 평균 RR 하한.** 성공 한 번이 반 바퀴(π rad) 이상의 회전이라면 평균 RR ≥ k·π/10입니다. 다음 세 칸이 이 하한보다 작습니다.

| 칸 | 보고 평균 RR | SR | 하한 (k·π/10) |
|---|---|---|---|
| TD, 십자 블록 | 0.34 | 2/10 | 0.63 |
| IHR + WSM-denoised, 십자 블록 | 1.21 | 8/10 | 2.51 |
| IHR + WSM-denoised, 모서리 블록 | 2.43 | 10/10 | 3.14 |

나머지 열일곱 칸(제안법 네 칸 포함)은 하한을 만족합니다(한 칸은 거의 맞닿음: IHR 오리 1.83 대 1.57). 가능한 설명은 "반 바퀴"가 π rad보다 작게 정의됐거나, RR과 SR이 서로 다른 구간·채점자 평균으로 낸 값일 가능성입니다. 저자 확인이 필요합니다.
- **Fisher (제안법 대 각 기준선, 10회):** 오리에서 대 IHR+WSM-denoised 10/10 대 8/10 p = 0.47, 십자 블록 같은 값 p = 0.47, 모서리 10/10 대 10/10 p = 1. 보류 이중노치 블록 8/10 대 0/10은 모든 기준선에 대해 p = 0.0007. 보이는 세 물체를 합치면 30/30 대 26/30 p = 0.11, 네 물체 합산 38/40 대 26/40 p = 0.0015.
- **WSM-denoised 깊이 효과 (IHR 대 IHR + WSM-denoised):** 오리 5 → 8 p = 0.35, 십자 1 → 8 p = 0.0055, 모서리 1 → 10 p = 0.0001, 합산 7/30 → 26/30 p = 1e-6.
- **표 3과 표 6.** TD 합산 6/40 = 15.0% (표 6의 16.5%), IHR 7/40 = 17.5% (표 6의 26.5%), 제안법 38/40 = 95.0% (표 6의 87.5%). 표 3의 네 물체가 표 6의 20개 물체에 포함된다고 보면 나머지 160회는 137/160 = 85.6%입니다(포함 가정).

### V6. 표 1의 CI에서 복원한 에피소드 단위 변동

95% CI를 SD로 되돌리면(SD = CI·√n/1.96) Return의 변동계수(CV)가 n에 따라 달라집니다.

| 방법 | n=128: Return SD (CV) | n=1024: Return SD (CV) |
|---|---|---|
| Full WSM (753.3 ± 3.6) | 20.8 (2.8%) | 58.8 (7.8%) |
| 촉각 25% 드롭아웃 (743.4 ± 4.2) | 24.2 (3.3%) | 68.6 (9.2%) |
| Blind RL (304.1 ± 3.8) | 21.9 (7.2%) | 62.0 (20.4%) |
| WM 처음부터 (414.3 ± 15.7) | 90.6 (21.9%) | 256.3 (61.9%) |

아홉 물체를 섞은 평가에서 학습된 정책의 에피소드 Return CV가 3% 안팎인 것은 n=128 가정으로 복원한 값입니다. 공식 평가 집계기의 기본 창은 1024 에피소드이고 CI도 같은 식(1.96·SD/√n)으로 만듭니다(`04` D11). 표의 n이 128이 아니라면 같은 CI가 더 큰 SD를 뜻합니다. 이 차이는 서로 비교한 표준오차(V7)의 해석에는 영향이 없고, "에피소드 변동이 작다"는 인상에만 영향을 줍니다. 논문이 128 에피소드라고 쓴 문장(§4.1)과 표 6의 복구율 정수 분모(V2, n=128)는 서로 맞습니다.

### V8. 학습 물체 대 보류 물체 (표 4, 5, 1 대 표 6)

보류 물체 Return이 학습 물체 Return보다 큰 칸은 세 개입니다: x축 Blind RL 44.0 → 134.7 (3.06배, RotR은 0.867 → 0.852로 같음), y축 RL(촉각 없음) 154.8 → 168.9, y축 IHR 142.8 → 193.0. 나머지 열두 칸은 0.63–0.95배입니다. 제안법은 세 축 모두 0.71–0.77배입니다(RotR 0.65–0.90배). 보류 물체의 목록과 자산이 코드에 없어(`04` D16) 원인은 확인하지 못했습니다. x축 Blind RL의 Return만 RotR 변화 없이 3배가 된 점은 보류 물체 구성에 따른 보상 항(예: 낙하와 무회전 벌점) 차이일 가능성이 있습니다.

### V9. RotR의 단위와 월드 모델 메모리

- 공식 코드에서 RotR은 에피소드 평균 [clip(20·Δθ, −6.28, 2.0)·spin_coef]이고 Δθ는 제어 한 스텝의 축 회전(rad)입니다(`04` D11). 제어 10 Hz이므로 RotR/2 ≈ rad/s입니다. 전체 WSM(1.293)은 약 0.65 rad/s, 20 s에 약 12.9 rad입니다(스케일과 클립 가정). 실로봇 오리 16.18 rad/20 s(0.81 rad/s)와 같은 자릿수입니다. 49물체의 "9.37 rad per episode"는 에피소드 길이를 논문이 쓰지 않아(20 s 또는 500 스텝 = 50 s) 비교를 보류합니다.
- 월드 모델 링 리플레이: 256행 x 1024 환경 x 96x72 깊이(float32)가 영상 한 벌에 6.75 GiB이고 입력과 깨끗한 목표 두 벌이면 13.5 GiB(CPU 메모리, 코드 기본 `image_on_cpu`). 환경 256개로 줄인 코드 기본값은 3.4 GiB입니다. PPO 한 에폭은 16,384 환경 스텝이고 그 뒤 월드 모델은 5,120 프레임(10 x 16 x 32)을 한 번 봅니다. 3000 에폭은 4,915만 환경 스텝입니다.

### V10. 49물체 사전분포

9.37/3.28 = 2.86배, 낙하율 6% → 0.3%는 20배입니다. 5블록 진단의 RotR 이득은 1.34/1.10 = +21.8%, 1.46/1.10 = +32.7%입니다. 이 세 값은 시행 수, CI, 학습 시드가 보고되지 않아 검정하지 못했습니다.

CoRL 2026 공식 세션표는 총 687편(구두 21, 스포트라이트 72, 포스터 594)입니다. 스포트라이트 72편은 채택의 10.5%입니다. 프로젝트 페이지의 "Top 4.4%"는 제출 대비 비율로 보이며(분모 비공개), 스포트라이트만이면 제출 약 1,640편, 구두와 스포트라이트를 합치면(93편) 약 2,110편에 해당합니다. 분모는 확인하지 못했습니다.

## 3. 토이 T1: 재구성 목표가 깨끗한 깊이일 때와 오염된 깊이일 때

**질문.** 표 2에서 "잡음 깊이를 목표로 한 WSM"이 Return 708.0으로 "깨끗한 깊이 목표" 753.3보다 낮았습니다. 이 방향이 순환 잠재 상태에서 비롯될 수 있는지 최소 모델로 봅니다.

**설정(`analysis/toy_clean_target.py`, torch CPU, 약 1분).** 4차원 AR(1) 숨은 상태 x_t에서 32픽셀 "깊이" y_t = σ(W x_t)가 나옵니다. 입력은 (a) 시간 상관이 있는(지속 확률 0.95) 픽셀 고장(고장 픽셀 값 0, 새 고장 확률 0.03)과 작은 가우시안(0.02)이 섞인 깊이, (b) 고유감각 x_t의 앞 2차원(잡음 0.05)입니다. 인코더 MLP → GRU(32) → 디코더. 두 조건은 목표만 다릅니다: 깨끗한 y_t, 또는 입력과 같은 오염 y_t. 600 스텝, 5 시드. 지표는 보류 시퀀스에서 h_t로 x_t를 선형 복원한 R²(`r2`)와 깨끗한 깊이 복원 MSE입니다.

| 조건 | 목표 | r2 (보류, 평균 ± SD) | 분포 이동 r2 (고장 확률 2.67배) | 깨끗한 깊이 MSE |
|---|---|---|---|---|
| 고장 픽셀 + 작은 잡음 | 깨끗한 깊이 | 0.853 ± 0.005 | 0.699 ± 0.017 | 0.0051 |
| 고장 픽셀 + 작은 잡음 | 오염 깊이 | 0.677 ± 0.020 | 0.404 ± 0.029 | 0.0701 |
| 가우시안 0.15만 (대조) | 깨끗한 깊이 | 0.966 | 0.964 | 0.0012 |
| 가우시안 0.15만 (대조) | 오염 깊이 | 0.923 | 0.920 | 0.0128 |

**읽는 법.** 목표가 오염 깊이이면 디코더가 "고장 픽셀이 0이 되는 패턴"을 맞추는 데 잠재 용량을 씁니다. 고장이 시간 상관을 가지므로 이전 스텝의 고장 이력까지 상태에 담아야 합니다. 이 토이는 결핍성(dropout) 잡음에서 격차가 크고(r2 0.85 대 0.68) 평균이 0인 잡음에서는 격차가 작았습니다(0.97 대 0.92). 논문과 방향은 같지만 이것은 **논문의 RSSM, PPO, 시뮬레이터가 아닌 4차원 합성 문제**이므로 표 2의 45.3 차이가 같은 이유로 생겼다는 증거가 아닙니다. 공식 설정 파일에서 가우시안 잡음은 꺼져 있고(`04` D7) 시간 상관 고장과 작은 회전이 입력 잡음의 전부이므로, 이 토이의 첫 조건이 가장 가깝습니다.
