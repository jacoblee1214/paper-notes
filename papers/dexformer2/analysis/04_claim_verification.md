# 04. 주장 검증 (공식 저장소 정적 확인 포함)

공식 저장소(`DavidLXu/dexformer2`)에는 **정책 학습 코드, 정책 구현, 평가 스크립트, 체크포인트가 없습니다.** 저장소 README가 이를 명시합니다("Training code, the policy, evaluation scripts and model weights are not here yet"). 프로젝트 페이지도 "Code (soon)"입니다. 그래서 논문 코드와 1:1로 대조하는 `04_code_verification.md`(D1–Dn)는 만들 수 없습니다. 대신 논문의 주장(C1–Cn)을 두 방법으로 확인했습니다.

1. **논문 내부 검사:** 표와 본문의 수치 일관성(`03`), 통계 검정.

shallow clone은 `repo/`(gitignore)에 있습니다(커밋 `d964967`, 2026-11-14).
