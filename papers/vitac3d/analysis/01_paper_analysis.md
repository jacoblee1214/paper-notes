## 1. 한 문단 요약

3D-ViTac은 얇고 부드러운 핀형 그리퍼 손가락에 **압저항 촉각 패드(16×16, 손가락당 256점)**를 붙이고, 촉각 점과 다시점 깊이 카메라의 점군을 **같은 3D 좌표계의 한 점 집합**으로 합쳐 PointNet++ 인코더와 조건부 확산 정책(Diffusion Policy)에 넣는 모방 학습 시스템입니다. 실로봇 양팔 장비에서 4개 장기 과제(계란 찜, 과일 손질, 육각 렌치 수거, 샌드위치 서빙)를 20회씩 평가해, 시각 점군만 쓴 기준선(PC. Only)보다 전체 과제 성공률이 높다고 보고합니다(표 1). 촉각 해상도 절제(그림 6), 카메라 수 절제(표 2), 단일 팔 실험(표 3), 촉각 피드백을 쓴 데이터 수집 실험(그림 5)을 더 붙였습니다.

## 2. 문제 설정과 방법

### 2.1 센서와 그리퍼 (§3.1, 그림 2, 부록 A)

- 센서는 Velostat(압저항층)을 직교하는 도전성 실 16개 행과 16개 열 사이에 끼운 3층 구조입니다. 폴리이미드로 감쌉니다(부록 A.1.1). 두께는 1 mm 미만입니다(§3.1).
- 촉각 단위 하나는 "3 mm²"로 적혀 있습니다(초록, §3.1). 이 값이 면적인지 격자 간격인지는 본문만으로 분명하지 않습니다. 프로젝트 페이지의 FlexiTac-V1 표는 같은 센서의 "Sensing grid"를 **3 mm**로 적습니다(`04` C2 참고).
- 손가락 하나당 패드 하나, 양팔 합쳐 4개(손당 2개), 촉각 단위는 1024개입니다(§1).
- 판독 보드는 시프트 레지스터 두 개와 16채널 아날로그 스위치로 행을 훑고, Arduino Nano의 ADC로 읽어 시리얼로 보냅니다(부록 A.1.2). 프레임률은 "최대 약 32.2 FPS"입니다(§3.1).
- 그리퍼는 TPU로 3D 프린트한 연한 핀형입니다(§3.1). 패드 비용은 "보드를 뺀 패드와 판독 보드 약 $20"이라고 적었습니다(§3.1).

### 2.2 데이터 수집 (§3.2, 부록 B.1)

- 양팔 마스터-퍼펫 원격조작 [16]. 기구 모델과 컨트롤러 종류는 적혀 있지 않습니다.
- 카메라는 RealSense 세 대입니다. 위에서 보는 455 한 대와 근접 435 두 대입니다(부록 B.1). 단일 카메라 기준선은 위 카메라만 씁니다.
- 수집 주기는 10 Hz이고, 촉각은 ROS 노드에서 30 Hz로 발행합니다(부록 B.1). 시간 정합은 타임스탬프로 합니다.
- 데이터 수집 중 촉각 값을 화면에 실시간으로 보여 줍니다(그림 2(a), 그림 12).

### 2.3 3D 촉각-시각 표현 (§4.2, 그림 3(b))

- **시각 점군**: 다시점 깊이를 합치고, 작업 영역 상자로 자른 뒤, FPS로 512점으로 줄이고, 로봇 기저 좌표계로 옮깁니다(N_vis = 512). 네 번째 채널은 빈 값입니다.
- **촉각 점군**: 관절 상태에 기구학(FK)을 적용해 손가락 위 각 촉각 단위의 3D 위치를 구하고, 판독값을 네 번째 채널로 둡니다. N_tac = 256 × N_finger이며, 단일 팔은 N_finger = 2, 양팔은 4입니다.
- 두 점군을 합친 뒤 각 점에 one-hot으로 시각 점인지 촉각 점인지 표시합니다(§4.2). 그림 3(b)의 설명처럼 같은 좌표계에 놓이므로 접촉 위치와 물체 부분의 관계를 모델이 쓸 수 있다는 것이 논문 주장입니다.

### 2.4 정책 학습 (§4.1, §4.3, 부록 B.4)

- 행동은 **관절 상태 시퀀스**입니다(§4.1).
- 정책은 PointNet++ 백본(세트 추상화 세 층: 64점/0.04 반지름, 16점/0.08, 전역 층 MLP [256, 512, 1024]; 완전연결 1024→512→256; 배치 정규화 없음)을 쓰는 조건부 DDPM입니다(§4.3, 부록 B.4).
- 학습은 2,000 에포크입니다(§5.2). 확산 단계 수, 예측 지평, 옵티마이저, 학습률, 배치 크기, GPU 수와 시간은 적혀 있지 않습니다.
- 기준선은 네 가지입니다(§5.2): RGB Only(확산 정책 [13]과 같은 구현), RGB w/ Tactile Image(촉각을 이미지로 CNN에), PC. Only(점군만), PC. w/ Tactile Image(점군 + 촉각 이미지).

## 3. 실험 결과

### 3.1 실로봇 과제 (표 1, §5.2)

과제는 네 개이고 각 과제를 단계로 나눕니다. 표 1은 과제마다 **세 단계와 전체 과제(Whole Task)**를 보여 줍니다. 텍스트는 단계를 네 개로 적었으므로 단계 하나씩이 표에서 빠져 있습니다(`03` V2).

| 과제 (데모 수) | 표에 보이는 단계 | 전체 과제 (Ours / RGB Only / PC. Only / best baseline) | 시도 |
|---|---|---|---|
| 계란 찜 (30) | 뚜껑 전 계란 판 열기, 계란 잡기, 계란 놓기 | 0.85 / 0.50 / 0.55 / 0.70 | 20 |
| 과일 손질 (30) | 접시 잡고 놓기, 비닐 열기, 포도 잡기 | 0.80 / 0.45 / 0.45 / 0.70 | 20 |
| 육각 렌치 (30) | 오른손 잡기, 왼손 잡기, 손 안 조정 | 0.90 / 0.45 / 0.65 / 0.65 | 20 |
| 샌드위치 (50) | 주걱 잡기, 냄비 기울이기, 계란 꺼내기 | 0.85 / 0.60 / 0.65 / 0.75 | 20 |

- 전체 과제 성공률은 네 과제 모두에서 Ours가 가장 높습니다(best baseline 열은 네 기준선 중 최댓값). 단계별로는 과일 손질의 접시 잡기(PC. Only 1.00 대 Ours 0.95)와 비닐 열기(PC. w/ Tactile Image 0.90 대 Ours 0.85)에서 Ours가 낮습니다. 이 두 칸은 굵은 글씨가 아닙니다.
- 시도 수는 표 캡션에서 과제당 20회입니다. 표 값은 모두 0.05의 배수로 20회 시도의 성공 횟수와 맞습니다(`03` V1).
- 표준편차, 신뢰구간, 검정은 없습니다. 재계산 결과는 `03` §1.

### 3.2 카메라 수 절제 (표 2, §5.3)

| 설정 | 계란 전체 | 육각 렌치 전체 |
|---|---|---|
| 단일 카메라, 점군만 | 0.50 | 0.30 |
| 단일 카메라, 점군 + 촉각 | 0.80 | 0.70 |
| 다중 카메라, 점군만 | 0.55 | 0.65 |
| 다중 카메라, 점군 + 촉각 (Ours) | 0.85 | 0.90 |

- 캡션에 시도 수가 없습니다. 표 1의 Ours와 같은 값이므로 20회라고 가정합니다(`03` §0).
- 저자는 "가림이 심할수록 촉각이 더 중요하다"고 씁니다(§5.3). 촉각에 따른 이득은 계란에서 단일과 다중 카메라 모두 +0.30이고, 육각 렌치에서는 단일 +0.40, 다중 +0.25입니다. 두 이득의 차이는 0 근처이고 신뢰구간이 0을 포함합니다(`03` §3).

### 3.3 촉각 해상도 절제 (그림 6, §5.3)

- 촉각 표현을 16×16 연속, 8×8 연속, 4×4 연속, 16×16 이진으로 바꾼 막대 그래프입니다. 표가 없고 값이 그림에만 있으며, 시도 수와 오차 막대도 없습니다.
- 본문은 "16×16이 8×8보다 약간 높고, 4×4와 이진보다 뚜렷이 높다"고 씁니다. 막대 값은 근사로만 읽을 수 있어 정량 검증은 하지 않습니다(`04` C6).

### 3.4 단일 팔 실험 (표 3, 부록 B.3)

| 모델 | 전구 회전 | 전구 옮기기 | 못 잡기 | 못 꽂기 |
|---|---|---|---|---|
| RGB Only | 0.85 | 0.85 | 1.00 | 0.30 |
| RGB w/ Tactile Image | 0.95 | 0.95 | 1.00 | 0.65 |
| PC. Only | 0.85 | 0.85 | 1.00 | 0.65 |
| PC. w/ Tactile Points (Ours) | 1.00 | 1.00 | 1.00 | 0.85 |
| Ours, 새 센서 세트 | 1.00 | 1.00 | / | / |
| Ours, 센서 위치 약간 변경 | 0.95 | 0.90 | / | / |

- 시도는 20회입니다(캡션). 못 꽂기에서 Ours 17/20 대 PC. Only 13/20입니다(Fisher p = 0.27, `03` §4).
- "센서는 기기 사이에서 정규화 후 반복 가능하다"는 캡션 문장을 뒷받침하는 기기 간 비교 자료는 없습니다(`04` C11).

### 3.5 촉각 피드백 데이터 수집 (그림 5, §5.3)

- 처음 쓰는 사용자 10명을 촉각 화면 있는 그룹 5명과 없는 그룹 5명으로 나눠 두 과제의 완료 시간을 잽니다. 시도 횟수는 5회입니다(그림 5).
- 그룹 간 통계 검정은 없습니다. 그림에서는 촉각 그룹의 시간이 더 짧고 시도마다 줄어듭니다(`04` C13).

### 3.6 촉각 센서 특성과 포즈 추정 (부록 A.2)

- **개별 단위**: 10개 단위에 0–12 N을 가했을 때 9 N 부근부터 포화가 시작되고 1–9 N은 로그 축에서 대략 선형입니다(그림 10(a)). 원자료는 없습니다.
- **패드 일관성**: 16×16 패드를 2×2 단위 블록 64개로 나눠, 1, 3, 5, 11 N의 균일 하중을 걸고 블록별 합계를 봅니다. 하중은 "원형 접촉면 176.7 mm²"입니다(부록 A.2.1). 2×2 블록의 면적(3 mm² 단위 기준 12 mm²)보다 훨씬 넓어서 "블록마다 같은 하중"이라는 설명과 맞지 않을 수 있습니다(`03` V5).
- **촉각만으로 포즈 추정**: 입자 필터로 SE(3) 포즈를 추적하고, 가중치는 접촉 점에서 가장 가까운 물체 점까지의 거리 합입니다(식 2). 정성 결과 세 장(그림 11)이 있고 오차 지표는 없습니다(`04` C12).

## 6. 읽으면서 알게 된 글쓰기 문제

- 표 1, 표 2의 과제 이름이 "계란 찜(Egg Steaming)"과 "계란 요리(Egg Cooking)"로 다릅니다.
- 부록 B.2.2의 Step 3 문단에 문장이 끊긴 부분이 있습니다("since it aligns the gripper joint states ...").
- 텍스트의 단계 수(4)와 표의 단계 열(3)이 맞지 않습니다(`03` V2).
- 촉각 판독률 "32.2 FPS"(§3.1), 데이터 수집 "10 Hz"(§3.2), 촉각 발행 "30 Hz"(부록 B.1)가 다른 값으로 나옵니다. 역할이 다르므로 모순은 아니지만 어느 것이 정책 입력인지 밝히면 좋았을 것입니다.
