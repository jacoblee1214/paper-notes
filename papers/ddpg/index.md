## 한 줄 요약

결정적 정책 경사(DPG) actor-critic에 DQN의 재생 버퍼와 표적망을 붙이고, 배치 정규화와 Ornstein–Uhlenbeck(OU) 탐색 잡음을 더해 연속 행동을 신경망으로 학습했습니다. 같은 설정으로 MuJoCo 26개 과제와 Torcs를 저차원·픽셀 입력 모두에서 풀었다고 보고합니다. 오늘날의 TD3, SAC, 대규모 off-policy 학습기까지 이어지는 계보의 출발점입니다.

## 1. 알고리즘은 짧다

- **critic:** 표적망 Q′, μ′로 y = r + γQ′(s′, μ′(s′))를 만들고 제곱 오차를 줄입니다.
- **actor:** ∇J ≈ E[∇ₐQ(s, a)|ₐ₌μ(s) · ∇μ(s)]를 따라, critic이 보기에 Q가 커지는 방향으로 행동을 밉니다.
- **표적망:** 매 업데이트마다 θ′ ← τθ + (1−τ)θ′(τ = 0.001)로 천천히 따라갑니다. 지수이동평균이고, 반감기는 약 693 업데이트입니다.

엄밀히 말하면 actor 경사는 재생 버퍼 분포에서 취한 근사입니다. 정책이 바뀌면 Q 자체가 바뀌는 항을 버립니다. 그래서 critic이 틀리면 actor도 그대로 따라갑니다.

## 2. Table 1을 과제 단위로 다시 보면

26개 과제의 정규화 점수(무작위 정책 0, iLQG 계획기 1)를 다시 계산했습니다.

![Table 1 과제 단위 비교](images/table1_paired.png)

- **표적망 효과는 확실합니다.** 표적망 없는 DPG + 배치 정규화보다 DDPG가 26개 중 25개 과제에서 높습니다(평균 +0.50, Wilcoxon p = 6×10⁻⁸).
- **"계획기와 견줄 만하다"는 최고 시드 기준입니다.** 저차원 평균 점수는 0.72이고, 평균으로 계획기를 넘은 과제는 2개입니다. 최고 시드 기준으로는 10개입니다.
- **배치 정규화의 기여는 따로 보고되지 않았습니다.** 표에 "표적망만 쓴" 열이 없고, 학습 곡선 그림에서는 BN 유무가 여러 과제에서 겹칩니다.
- **시드 퍼짐이 큽니다.** 5개 시드의 평균과 최댓값만으로도 표준편차의 하한이 나옵니다. canada 0.80 이상, walker2d 0.49 이상입니다(최고 점수가 최종 점수의 최댓값이라는 가정에서).

## 3. 같은 "DDPG"라도 구현마다 설정이 다르다

공식 코드가 없어서, 널리 쓰이는 구현 네 개(SB3, Spinning Up, TD3 저장소, OpenAI baselines)를 논문 부록과 줄 단위로 대조했습니다.

| 항목 | 논문 | TD3 저장소 `DDPG.py` | SB3 | Spinning Up | baselines |
|---|---|---|---|---|---|
| 은닉층 / 행동 합류 | 400–300 / 2층 | 400–300 / 2층 | 400–300 / 입력 | 256–256 / 입력 | 2×64 tanh / 입력 |
| 배치 정규화 | 있음 | 없음 | 없음 | 없음 | 관측 정규화 |
| τ / 배치 | 0.001 / 64 | 실행 시 0.005 / 256 | 0.005 / 256 | 0.005 / 100 | 0.01 / 64 |
| 탐색 잡음 | OU (dt 없음) | 가우시안 0.1 | 기본 없음 | 가우시안 0.1 | 파라미터 잡음 |

눈여겨볼 점이 두 가지 있습니다.

1. **TD3 저장소의 "논문 재현" `DDPG.py`도 기본 실행에서는 논문 값이 아닙니다.** `main.py`가 τ(0.005)와 배치(256)를 모든 정책에 넘기기 때문입니다. 원래 설정을 원하면 `--tau 0.001 --batch_size 64`를 명시해야 합니다.
2. **OU 잡음의 dt가 논문에 없습니다.** rllab은 dt = 1, baselines와 SB3는 dt = 0.01이 기본입니다. 정상 표준편차는 거의 같지만 상관 시간이 6 step과 666 step으로 100배 다릅니다. 에피소드마다 0에서 다시 시작하면 dt = 0.01 잡음은 초반에 거의 0입니다.

![OU 잡음 표본 경로](images/ou_noise.png)

## 4. numpy로 직접 돌려 봤다

설치 없이 numpy로 DDPG를 구현했습니다. 수동 역전파는 중앙 차분으로 확인했습니다. 진자 swing-up에서 논문 설정(폭만 64-64로 줄임)을 기준으로 한 항목씩 바꿨고, 설정마다 시드 5개로 돌렸습니다.

![toy 최종 return](images/toy_final.png)

- **표적망을 빼면 5개 시드 모두 배우지 못했습니다.** 토크를 주지 않는 정책보다도 나빴습니다.
- **τ만 0.001에서 0.005로 바꿔도 5개 중 1개만 풀었습니다.** "τ = 0.005가 나쁘다"는 뜻은 아닙니다. 라이브러리들은 τ = 0.005로 MuJoCo를 잘 풉니다. τ가 학습률, 망 크기, 보상 크기와 묶여 있어서 하나만 따로 바꾸면 위험하다는 뜻입니다.
- **critic L2와 잡음 종류는 이 과제에서 차이가 나지 않았습니다**(p > 0.1).
- **Q는 과대추정되었습니다.** 잘 풀린 시드 15개 중 13개에서 Q(s₀, μ(s₀))가 실제 할인 return보다 컸고, 평균 +6.7%였습니다. 논문은 진자 같은 단순 과제에서 "체계적 편향이 없다"고 했지만, 이 toy에서는 재현되지 않았습니다. 이후 TD3가 이 과대추정을 DDPG의 핵심 약점으로 지목했습니다.

![toy 학습 곡선](images/toy_curves.png)

망이 작고, 배치 정규화가 없고, 과제가 하나라는 한계가 있습니다. 경향으로만 읽어 주세요.

## 5. 직접 구현할 수 있나

| 경로 | 판단 |
|---|---|
| 논문 Table 1 재현 | **불가능.** 코드, 32개 과제, 정규화 기준인 iLQG 계획기가 모두 비공개입니다. 픽셀 망의 커널·stride도 없어서, 같은 설정 세 층으로는 "43만 파라미터"를 7% 안으로 맞출 수 없습니다 |
| 알고리즘 재구현 | **매우 쉬움.** 150줄 안팎이고 공개 구현이 10개 넘습니다 |
| 공개 구현으로 실험 | **쉬움.** SB3 + gymnasium + MuJoCo는 노트북 CPU에서도 돌아갑니다. 단, 위 표의 설정 차이를 알고 명시해야 합니다 |

## 6. 정리

- DDPG의 핵심 기여는 표적망과 재생 버퍼로 결정적 정책 경사를 신경망에 올린 것이고, 그 효과는 표와 toy 모두에서 분명합니다.
- "계획기와 견줄 만하다", "같은 설정으로 강건하게"는 최고 시드나 넓은 점수 범위에 기댄 표현입니다.
- 오늘날 쓰는 "DDPG"는 대부분 배치 정규화가 없고 τ, 배치, 잡음이 논문과 다른 변형입니다. 기준선으로 쓸 때는 구현과 설정을 함께 적어야 합니다.
