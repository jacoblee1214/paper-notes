## 1. 문제와 주장

VLA가 VLM의 자기회귀 방식을 그대로 쓰면 행동을 이산 토큰으로 바꿔야 합니다. 기존 평가는 재구성 충실도만 봤고, 토큰화가 VLA 학습에 주는 영향은 묻지 않았다는 것이 논문의 출발점입니다(§1). 논문이 내세우는 것은 두 가지입니다.

1. **좋은 행동 토크나이저의 조건 4가지.** (i) 인접 청크 사이의 시간적 겹침 최대화, (ii) 어휘 중복 최소화(작은 코드북과 토큰 예산), (iii) 토큰과 다중 모달 문맥의 정렬, (iv) 구조적 토큰 결합 감소(독립적 토큰).
2. **이 조건을 반영한 토크나이저 ActionCodec.** SmolVLM2-2.2B를 사전학습 없이 미세조정해 LIBERO 95.5%, 블록 단위 자기회귀(BAR)를 쓰면 97.4%입니다(초록, 표 1).

## 2. 방법

### 2.1 정보이론 틀 (§3, 부록 E)

- **식 (2)** E[L_NLL] = D_KL(P_data ‖ P_θ) + H(C|V,L). 교차 엔트로피 = KL + 엔트로피의 항등식입니다.
- **식 (3)** H(C|V,L) = H(C|A) + I(C;A) − I(C;V,L). 이것도 항등식입니다. 토크나이저가 결정적이면 H(C|A) = 0이고 I(C;A) = H(C)이므로 H(C|V,L) = H(C) − I(C;V,L)로 줄어듭니다. 즉 "토큰 자체의 엔트로피는 낮추고, 문맥과의 상호정보는 높여라"가 이 식의 실질적 내용입니다.
- **식 (4)** 사슬 규칙으로 I(c_k; V,L,c_<k)를 "시각-언어 정렬"과 "잔여 문법(앞 토큰에 대한 의존)"으로 나눕니다.
- **세 가지 실험 축.** (a) 겹침률 OR, (b) 용량(토큰 예산 n, 어휘 S, 상한 n·log2 S), (c) 정렬 대 잔여 문법. 논문은 상호정보를 직접 추정하지 않는다고 밝힙니다(부록 E.3). 어텐션 시각화와 CLIP/TCL 비교는 "정성적 대리"입니다.
- **OR의 정의(식 7).** 보폭 1로 이웃한 두 청크 C_t, C_{t+1}의 토큰이 같은 위치에서 일치하는 비율의 평균, OR = E[1 − d_H/n]. 토큰 집합의 겹침이 아니라 위치별 일치입니다.

### 2.2 검증용 토크나이저와 VLA (§3, 부록 B.2)

- **구조.** Perceiver형 인코더/디코더(그림 2, 11). 학습 가능한 질의(latent)가 입력 행동에 교차 어텐션만 하는 "독립(Independent)" 변형, 질의끼리 양방향 자기 어텐션을 더한 SA, 인과 마스크를 더한 Causal 변형을 비교합니다.
- **VQ 목적(식 1).** 재구성 + 코드북 + 약속 손실(표준 VQ-VAE). OR을 조절하기 위해 InfoNCE를 더하고, 입력에 작은 가우시안 잡음을 준 쌍을 양성으로 씁니다(부록 B.2.1). 최종 모델은 이 방식 대신 TCL(식 5)과 CLIP형 시그모이드 손실(식 6)을 씁니다.
- **VLA.** SmolVLM2-256M의 어휘를 S개의 `<|action_i|>` 토큰으로 확장하고 전체 파라미터를 미세조정합니다. 평가는 LIBERO-Goal이고 500, 1k, 5k, 10k, 20k 스텝에서 봅니다(부록 B.2). 8×RTX 3090, 배치 128, 학습률 2e-4(표 6).

### 2.3 ActionCodec (§4, 부록 C, D)

- **임베딩별 소프트 프롬프트.** 로봇마다 학습 가능한 임베딩을 두고(인코더의 질의), 제어 주파수와 행동 길이에서 계산한 시각을 푸리에 임베딩으로 넣습니다(그림 15). 전체 파라미터는 공유합니다. 사전학습 데이터는 LIBERO, BridgeData, DROID입니다.
- **RVQ 사후 학습.** 1단 VQ를 먼저 학습한 뒤 인코더와 첫 코드북을 얼리고 잔차 코드북 2개(깊이 L = 3)를 추가로 학습해 재구성 오차를 줄입니다(부록 D, 그림 16). 첫 코드북의 토큰은 VQ 버전과 같고, 디코더만 사후 학습된 것으로 바꿔 VQ 모델에 되돌려 쓸 수 있다고 설명합니다. BAR만 전체 RVQ(토큰 48개)를 씁니다.
- **VLA 패러다임(부록 B.4, 그림 12).** 자기회귀(AR) 외에 PD(병렬 디코딩: 학습 가능한 [BOS] n개로 한 번에 예측), KI(지식 격리: flow-matching 전문가와 VLM KV 캐시), BAR(RVQ 층별 블록 단위 인과 마스크)를 비교합니다. 모두 약 300M 파라미터 전문가를 씁니다.
- **최종 설정.** n = 16, S = 2048은 "고유한 최적이 아니라 실용적 설정"입니다(§3.2, 부록 E.2).

## 4. 논문이 스스로 밝힌 한계와 우리가 본 간격

**논문이 적은 한계(§7, 부록 E, F).** 신경망 구조가 분석용이라 최종 성능에 최적화되지 않았습니다. 보조 대조 손실 2개 때문에 초매개변수가 늘어납니다. 15K시간 연구는 벤치마크가 적습니다. 식은 항등식이지만 각 항의 최적화가 정책 향상을 보장하지 않고, 설계 권고는 "경험적 지침"입니다. "독립 토큰"은 통계적 독립을 뜻하지 않고 교차 어텐션만 쓴다는 뜻입니다. 기준선 비교는 같은 토큰 수나 같은 지평선에 맞춘 것이 아닙니다(부록 F.2).

**분석에서 확인한 간격(자세한 근거는 `03`과 `04`).**

1. 설계 원리의 검증은 InfoNCE 섭동 방식으로 OR을 조절한 소형 실험(한 번의 학습, LIBERO-Goal)이고, 최종 모델은 TCL과 CLIP을 씁니다. 최종 레시피에서 TCL 대 CLIP 대 없음의 성공률 절제는 본문에 없습니다.
2. 선택한 설정(n = 16, S = 2048)은 그림 3의 스윕에서 20k 성공률이 가장 높은 설정이 아닙니다(03 V7).
3. 토크나이저 비교에서 ActionCodec의 토크나이저는 LIBERO 행동을 포함한 데이터로 사전학습한 반면, FAST는 공개된 범용 버전을, MiniVLA와 VQ-VLA는 공개 체크포인트를 "데이터 통계만 맞춰" 쓴 것으로 적혀 있습니다(부록 B.3). 토크나이저의 학습 데이터 차이가 성공률 차이에 섞여 있습니다.
4. PD가 AR을 "넘는다"는 서술은 0.1포인트 차이입니다(03 V5). BAR만 구분됩니다.
5. SimplerEnv 표에는 평가 횟수가 다른 값이 섞여 있고, "비교 대상 중 최고 순위"는 π0와 같은 순위 2.0입니다(03 K5, K6).
6. 공식 코드에는 토크나이저 학습, TCL/CLIP 손실, OR 측정, 기준선 코드가 없습니다(04 D1).

## 5. 읽는 순서 제안

식 (2)–(4)는 항등식이므로 §3의 결론은 실험 그림 3, 4, 표 5와 표 1(c)에 기댑니다. 이 둘을 먼저 보고, 04의 D 항목으로 코드와의 차이를, 03의 C 항목으로 주장별 근거를 확인하는 것이 빠릅니다.
