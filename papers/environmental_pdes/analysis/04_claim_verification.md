**요약.** 방법의 방향(시간 변화하는 PDE 장을 측정 모형으로 쓰면 PF보다 낫다)은 SWE에서 잘 뒷받침됩니다. ADE는 입자 수 증가에 따른 단조 개선이 없고, 저자들이 쓴 "일관되게"와 "steady"는 자료로 지지되지 않습니다. 실물과 계산 효율은 검증할 수 없습니다.

## 3. 재현에 필요하지만 논문에 없는 정보

1. **수치 방법:** 격자 크기와 영역, 기법(유한체적·유한차분·유한요소), 시간 간격, CFL 또는 암시적 처리(`analysis/03_analysis.md` §4).
2. **경계 조건:** 육지 경계, 바다 열린 경계, 바람 경계. 이류 장에서 유입 경계값(toy에서 0을 쓴 것처럼 임의로 정해야 함).
3. **계수:** ADE의 κ 값(채널별), κ를 얻는 방법, 초기 장 ϕ0를 데이터로 맞추는 절차, SWE 강제항의 밀도 비 ρ_w/ρ_a와 항력 계수 c_c.
4. **자료 전처리:** GEBCO의 해상도와 보간, 바람 자료의 출처와 시간 해상도.
5. **편향 사전 분포:** 초기 편향 평균 x̂_0와 공분산 P_0, 시뮬레이션에서 편향을 실제로 넣었는지(참값 편향의 크기).
6. **PF 구성:** 표준 PF가 편향 상태를 가지는지, 재표본추출 임계값, 초기 입자 분포, 매 스텝 재표본추출을 하는지(알고리즘 1 줄 1).
7. **실행 정보:** 입자 수별 수치 표(100–500, 각 5회), 난수 시드, SD의 정의(표본 또는 모집단), 참 궤적 생성 방법.
8. **Table I 설정:** 입자 수, 채널 선택 규칙(SWE는 0, 1, 2 중 무엇), 실행 수.
9. **계산 시간과 하드웨어:** "general-purpose laptop"의 사양, 장 해석 시간, 필터 시간.
10. **실물:** 센서 보정, 시간 동기화, GPS와 입자 추정의 오차 수치, 실행 횟수.
11. **공개 계획:** 코드와 데이터. 프로젝트 페이지에 "coming soon"만 있음.

## 4. 구현할 수 있는지 (판정)

**판정: 공식 재현은 불가능합니다. 아이디어 재구현은 ADE에서는 쉽고 SWE에서는 중간에서 어렵습니다. 이 맥에서는 CPU로 ADE 규모의 재구현과 시험까지 가능하고, SWE 규모와 실물은 데이터·장비 때문에 어렵습니다.**

| 항목 | 판정 | 근거 |
|---|---|---|
| 공식 재현 | 불가능 | 코드, 데이터, 장비 설정, 수치 방법이 공개되지 않음(§3) |
| 이 맥(Apple M4 Pro, 약 24 GiB 통합 메모리, MPS, CUDA 없음, torch 미설치)에서 ADE 규모 재구현 | 가능(CPU, numpy 1스레드) | `analysis/pde_toy.py`가 120 s, 30회 × 12설정을 3초에 실행. 장 계산은 80×80에서 1 s당 1.5 ms |
| 이 맥에서 SWE 규모 재구현 | 조건부 | 2D 얕은 물 솔버와 GEBCO·바람 자료가 필요. 자료 다운로드 승인 필요. 계산은 CPU로 가능하나 긴 시간(추정) |
| 아이디어 재구현 effort, ADE | 쉬움(추정) | 필터와 RB 편향 칼만 추가는 약 150–250줄 numpy. toy가 이미 PF 골격을 포함 |
| 아이디어 재구현 effort, SWE | 중간–어려움(추정) | 2D 얕은 물 해법(약 300–500줄), 지형 강제항, 바람 강제항, 자료 전처리 |
| 필요한 하드웨어 | 재현 실험에는 GPU가 필요 없음 | 논문이 "general-purpose laptop"이라고 씀. 실물 재현은 ASV, 수질 센서(온도, 용존산소, 염분), ADCP, GPS가 필요 |
| 실물 재현 | 불가능 | 장비와 현장이 없음 |

**결정 요인.** 재현의 실질적 장벽은 GPU가 아니라 **장을 어떤 수치 방법으로 풀었는지**와 **κ, 경계, 초기 조건을 어떻게 얻었는지**입니다. 이 값을 임의로 정하면 결과가 달라질 수 있습니다.

## 5. 판독 불확실 항목

- Table I의 ADE M=2 RMSE SD("1.2.06"), ADE M=2 최종 오차("0.3.9"), ADE M=1 최종 오차("0.132"), ADE M=1 RMSE("1.6.38", 본문 V-B의 1.63으로 읽음)는 판독할 수 없습니다. 텍스트 추출과 렌더링된 쪽 모두에서 같은 형태로 찍혀 있어, 추출 오류가 아니라 논문 표의 조판 오류로 보입니다.
- 잡음 표기: "diag(0.22, 0.22, 0.12)"와 "diag(0.52, 0.0872)"는 제곱으로 읽었습니다(0.2², 0.2², 0.1², 0.5², 0.087²). 단위가 제곱인지 표준편차인지는 원문에서 확정할 수 없습니다.
- Fig. 4·5의 중앙값과 꼬리는 그림에서 눈으로 읽은 값입니다. 수치로 적은 것은 본문에 있는 값뿐입니다.
- 본문 "PF's RMSE plateaus near 1.07–1.10 m"(V-C)는 Fig. 4 상자그림과 맞습니다.
