# 02. 선행연구와 관련 자료

## 1. 계보

논문이 다루는 문제는 "행동 생성의 반복 횟수"입니다. 계보를 세 줄로 나눕니다.

**(a) 반복 생성의 바탕: 흐름 매칭과 확산**
- 흐름 매칭 [38] → π0 [13] → π0.5 [14]. π0.5의 행동 expert는 Euler 10단계를 씁니다(Sec. III-B).
- 확산 정책 [19], Octo [15], RDT [16], CogACT [17]도 같은 반복 구조입니다.

**(b) 1단계 생성: 세 가지 방식**
- 증류: Shallow-π [7](π0.5를 얕은 학생으로), 일관성 정책 [29] 같은 단일 단계 학생 [29–31]. 교사의 출력 분포와 편향을 물려받습니다.
- 교사 없는 회귀: OpenVLA-OFT [8](L1 회귀 헤드). 저자들의 인용 내용으로는 L1이 조건부 중앙값으로 붕괴합니다. 그 해결을 7B 백본에 돌립니다(Sec. II).
- 교사 없는 cIMLE: 이 논문. IMLE [21] → AIMLE [22], ChIMLE [23], RS-IMLE [24]는 이미지 합성용입니다. WIMLE [25]은 같은 저자 Aghabozorgi가 참여해 세계 모델에 cIMLE를 쓴 연구입니다. 로봇 정책에 쓴 선행은 [31], [35–37]처럼 특화 정책입니다(Sec. II, "From specialists to a generalist").

**(c) 시스템 수준 가속: 이 논문과 보완**
- 커널 튜닝 [12] Ma et al.(realtime-VLA, Triton). 저자들은 55 Hz를 이 방식의 엔진 위에서 얻었다고 씁니다(Sec. II 첫 문단, IV-A).
- 비동기 흐름 [11], 양자화 [9], RLRC [10], FAST 토큰화 [6], VLA-perf [5].

**논문 밖에서 확인할 것:** cIMLE의 원 논문 Li & Malik(2018, arXiv:1809.09087)은 이 PDF에 없습니다. 이 폴더는 IMLE 이론을 원 논문에서 직접 확인하지 않았고, 식 3–4의 형태는 논문 본문에서만 읽었습니다.

**읽는 법.** 학습을 요구하는지, 단계 수가 몇인지, 다봉을 어떻게 다루는지, 어떤 기준선과 비교했는지가 셋의 차이입니다. 특히 AdaVLA는 같은 π0.5를 다루고 학습이 없다는 점에서 IMLE-VLA와 직접 비교해야 하는 가장 가까운 대안입니다. 두 논문 모두 "같은 학회(IROS 2026)"입니다.

## 3. 이 저장소의 다른 논문과의 관계

| 폴더 | 무엇인가 | IMLE-VLA와의 관계 |
|---|---|---|
| `adavla/` | π0.5·X-VLA 흐름 행동 머리의 학습 없는 적응 적분(AdaVLA, arXiv:2608.29208) | **가장 가까움.** 같은 π0.5 행동 머리의 단계 수를 줄이는 방법. 학습 유무, 다봉 처리, 비교 설정(NFE 대 단일 단계)이 다릅니다. adavla의 `02` §1은 이미 IMLE-VLA를 같은 학회 대안으로 적었습니다. 두 논문 모두 정적 기준선(같은 NFE)을 빠뜨렸다는 점이 공통입니다. |
| `pacevla/` | 행동 청크의 실행 속도(PaceVLA, arXiv:2610.25961) | 같은 "실행 시간" 축. IMLE-VLA의 처리량 11배는 빈도 × H로 정의되며, H를 늘리면 성공률이 떨어집니다(Fig. 3). 지연 이득과 실행 속도를 한 예산으로 봐야 합니다. |
| `chronospolicy/` | 관측·실행 시각을 명시하는 정책(Chronos Policy, arXiv:2610.13929) | 정지-이동 문제(stop-and-go)의 다른 해법. IMLE-VLA는 추론 지연을 줄이고, Chronos는 지연에 강건하도록 학습합니다. |
| `openwam/` | 영상·행동 WAM의 노이즈 평면과 설계 부품(OpenWAM, arXiv:2609.07398) | 잡음 설계 관점. IMLE는 잡음 z를 다봉 샘플의 색인으로 씁니다. 흐름 매칭의 잡음–데이터 보간과 다른 기하입니다. |
| `thinkworld/` | VLM이 손목 움직임 토큰을 생성하는 WAM(ThinkWorld, arXiv:2610.37666) | 직접 관계 약함. 평가에 LIBERO-PRO·LIBERO-Plus를 씁니다(IMLE-VLA와 같은 벤치마크지만 교란 설정이 같은지는 확인하지 않음). |
| `agentic_wam/` | 영상·코드·행동을 같은 흐름 루프에서 생성하는 AW-0(arXiv:2610.30136) | 공통 루프에서 흐름 단계를 나누는 문제. 단일 단계 행동 헤드를 공동 루프에 넣으면 영상 쪽 단계는 그대로 남습니다. |

## 5. 이 논문과 직접 맞대는 자료

- **AdaVLA** (`adavla/`): 같은 π0.5 행동 머리, 학습 없음. 비교 실험을 같은 평균 NFE에서 하면 두 방법의 차이가 드러납니다. 이 논문에는 그 비교가 없습니다.
- **Shallow-π** [7]: Table II의 Inf.(×) 값(H100 측정)이 여기서 옮겨졌습니다. IMLE의 L40S 측정과 장비가 다릅니다.
- **Dexmal realtime-vla** [12]: Table I의 Triton 25 Hz 행의 출처로 보입니다. 이 저장소에 `benchmark.py`가 있으나 이 행을 재현하는 실행 기록은 없습니다(`04` D14).
