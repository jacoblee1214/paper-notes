## 2. 통계적 불확실성 (롤아웃 50회)

- 과제당 50회에서 성공률 p의 95% 반폭: p=0.5일 때 ±13.9pp, p=0.85일 때 ±9.9pp, p=0.95일 때 ±6.0pp.
- 평균 SR은 과제 4개×50회=200회로 근사해 두 비율 z검정을 했습니다(과제 간 차이 무시, 정규 근사).

| 비교 | 차이 (pp) | z | p (양측) | 판정 |
|---|---|---|---|---|
| 표 3 행 1 → 2 (세계 모델 추가, 청크 없음) | +4.4 | 0.92 | 0.36 | 유의하지 않음 |
| 표 3 행 4 → 5 (세계 모델 추가, 청크+마스크) | +1.5 | 0.36 | 0.72 | 유의하지 않음 |
| 표 3 행 3 → 4 (마스크 효과, 청크) | +22.6 | 4.75 | <0.001 | 유의 |
| 표 3 행 4 Spatial, 행 3 대비 | +45.1 | 4.59 | <0.001 | 유의 |
| 표 3 행 4 Long, 행 3 대비 | +32.4 | 3.44 | 0.0006 | 유의 |
| 표 2 WorldVLA 256 vs OpenVLA (다른 논문 수치) | +2.6 | 0.63 | 0.53 | 유의하지 않음 |
| 세계 모델 추가(행 1→2)의 과제별 차이 | Goal +5.8, Object +5.1, Spatial +2.4, Long +4.3 | 0.3–0.7 | 0.26–0.77 | 모두 유의하지 않음 |

결론: **마스크 효과는 크고 견고합니다.** 세계 모델이 행동을 돕는다는 +4.4pp와 +1.5pp는 방향만 있고 증거가 부족합니다. 저자가 "mutual enhancement"라고 쓰는 주장은 이 실험 규모로는 확인되지 않습니다.

## 4. 검출력 toy (CPU, numpy, 1 프로세스, 0.2초)

질문: 과제 4개×50회(200회) 평균 SR로 논문이 보고한 차이를 95% 수준에서 검출할 수 있는가? (`analysis/toy_power.py`, 2만 회 모의실험, 독립 베르누이 가정)

| 기준 p | 참 차이 | 검출력 |
|---|---|---|
| 0.63 | 1.5pp | 6% |
| 0.63 | 4.4pp (행 1→2) | 15% |
| 0.63 | 10pp | 55% |
| 0.63 | 22.6pp (행 3→4) | 99.7% |
| 0.77 | 4.4pp | 18% |
| 0.77 | 10pp | 67% |

p=0.7 기준 80% 검출력에는 약 **13pp** 차이가 필요합니다. 따라서 논문 설계(과제당 50회)로는 +4.4pp나 +1.5pp를 안정적으로 구별할 수 없습니다. 같은 증거 수준을 원하면 과제당 롤아웃 수를 크게 늘리거나 여러 시드가 필요합니다. 이 toy는 독립 가정이므로 실제 값은 롤아웃의 상관(같은 초기 상태 사용)에 따라 달라질 수 있습니다.
