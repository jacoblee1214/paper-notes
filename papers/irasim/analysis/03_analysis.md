# IRASim 수치 재계산, 일관성 검사, 주장 판정

분석일 2026-11-21. 재계산 스크립트는 `analysis/recompute.py`이고 결과는 `analysis/recompute_results.json`입니다 (수 초, numpy와 scipy). 원자료는 논문의 표와 그림뿐입니다. 학습 로그나 샘플별 점수는 공개되지 않았습니다.

**표기:** V는 재계산, K는 일관성 검사, C는 주장 판정입니다. 주장 판정의 등급은 *지지*, *부분 지지*, *반박*, *근거 없음* 네 가지입니다.

## 1. 재계산 (V)

### V1. 정책 평가 상관 (표 4)

- 4개 체크포인트의 성공률은 50회 시행의 비율로 바꿨을 때 정수로 떨어집니다: GT 9, 25, 40, 50 / IRASim 14, 24, 37, 48 (50회 기준).
- Pearson r = **0.993** (p = 0.007, n = 4). 상관 계수의 Fisher z 95% 구간은 **0.70–1.00**입니다. 점이 4개뿐이라 구간이 넓습니다.
- Spearman ρ = 1.0 (순위 일치). 평균 절대 차이 0.055, 최대 0.10 (첫 체크포인트, GT 0.18 대 IRASim 0.28).
- Wilson 95% 구간: GT 0.18 [0.10, 0.31], IRASim 0.28 [0.18, 0.42]. 첫 체크포인트는 두 구간이 겹칩니다. 마지막 체크포인트는 GT 1.00 [0.93, 1.00]로 천장에 붙었습니다.

### V3. 실로봇 계획 (표 6)

- 셀마다 시행 수를 역산했습니다. 0.20, 0.07, 0.13, 0.60, 0.73, 0.80, 0.87이 모두 k/15에 맞습니다 (9개 셀 모두 오차 0.005 이하). 따라서 **셀당 15회**로 보입니다 (부록 G: 과제당 3회 반복 × 상위 5개 실행). 논문은 이 수를 쓰지 않았습니다. 5개 실행이 같은 초기 상태에서 나왔다면 독립이 아닙니다.
- 합산 (과제 3개 × 15회 = 45회): MSE 38/45 (84%, 95% 구간 71–92%), ResNet50 29/45 (64%, 50–77%), 무작위 6/45 (13%, 6–26%).
- 검정 (Fisher 정확): MSE 대 ResNet50 합산 **p = 0.052**, 과제별 (Close Drawer) p = 0.21. MSE 대 무작위 합산 p < 10⁻¹¹, ResNet50 대 무작위 합산 p = 10⁻⁶, Close Drawer MSE 대 무작위 p = 0.0007.

### V4. Push-T 계획 (표 5)

- K=1 열은 모든 P에서 0.637입니다. 기준선이 같다는 확인입니다 (일관).
- 셀당 100회 평균이라는 것만 적혀 있고 표준편차나 구간은 없습니다. 차이를 검정할 수 없습니다.
- 가정 아래 민감도 (논문에 없는 값): 시행별 IoU 표준편차를 s = 0.2로 가정하면 두 셀 평균 차이의 표준오차는 약 s × √2 / 10 = 0.028입니다. 따라서 차이 0.06 이내는 구별하기 어렵습니다. 0.912 대 0.916, 0.906 대 0.907처럼 0.01 이내 차이는 잡음 수준입니다. s가 더 크면 기준은 더 넓어집니다.
- 최고 셀 0.961 (P=1000, K=50)은 20개 셀 중 최댓값입니다. 최댓값 선택에 따른 낙관 편향이 있습니다.
- P=0 열 (사후 롤아웃 없음)은 K가 늘수록 나빠집니다: K=1 0.637, K=10 0.572, K=50 0.418. 사후 롤아웃 없이 계획하면 기준선보다 나빠집니다.

| C23 | 프레임 단위 조건이 행동과 프레임의 정렬을 높인다 (§3.3, 전체 주장) | 공간 블록에서만 프레임별 조건이 작동 (D1). 시간 블록은 타임스텝 조건만 받음. 표 1과 3의 PSNR, Latent L2 향상은 있음. 사람 평가는 Language-Table에서만 명확 | **부분 지지.** 정렬 주장은 공간 블록 기준으로만 코드와 맞음 |

## 4. 버전과 게재본 대조

- v1 (2024-06-20)과 v2 (2025-07-29)는 표 1 (짧은 궤적)과 표 3 (긴 궤적)에서 확인한 행 (Video-Ada, Frame-Ada)의 값이 같습니다. VDM과 LVDM 행은 같은 방식으로 대조하지 않았습니다.
- ICCV 2025 게재본 (CVF Open Access, 11쪽)은 확인한 값 (표 1의 Frame-Ada 행, 정책 평가 수치, Push-T 표 전체)이 v2와 같습니다. 게재본에서 표 번호만 바뀌었습니다 (정책 평가는 표 3, Push-T 계획은 표 4, 실로봇은 표 5).
- v1에는 정책 평가, Push-T, RoboNet, 실로봇 계획이 없습니다. v2에서 추가되었습니다.
- v1은 "§4.3에서 Latent L2와 PSNR이 사람 선호와 맞는다"고 썼는데, v1의 §4.3은 결과 절이고 사람 평가 그림 (그림 4)을 담고 있습니다. v2는 같은 문장의 근거를 부록 H로 옮겼습니다. 두 곳 모두 지표별 상관 분석은 없습니다 (C14).
- 게재본의 부록 (보충 자료)은 PDF에 없습니다. 게재본 기준의 주장 판정은 v2 부록을 근거로 합니다.

## 5. 한계 (분석 자체)

- 분산, 신뢰구간, 시드 반복이 본문에 없습니다. 많은 판정이 "부분 지지"나 "근거 불충분"으로 남는 이유입니다.
- 그림 4, 5, 6의 값은 판독입니다. 그림 4는 2%p 단위의 정수 구조가 있어 신뢰할 만하지만, 그림 5는 판독 오차가 약 0.002–0.003입니다.
- 학습 로그, 샘플별 점수, 사람 평가 원자료는 없습니다.
- 공식 코드로 수치를 재현하지 않았습니다. 재현은 GPU가 필요합니다 (`04` §4).

## 6. 토이 실험을 만들지 않은 이유

- 중심 주장은 프레임 단위 조건이 정렬을 개선한다는 것입니다. 이것을 CPU 토이로 검증하려면 영상 확산 학습이 필요합니다.
- 작은 토이 (예: 2차원 점 궤적)에서 프레임 단위 조건이 시간 블록 없이도 행동을 따른다는 것은 구조상 참이므로 정보가 적습니다.
- 따라서 이 분석에서는 토이를 만들지 않았습니다 (작업 지침의 선택 사항). 그 대신 D1–D2 (코드의 조건 경로)를 단위 검사로 확인하는 방법을 `04` §4에 적었습니다.
