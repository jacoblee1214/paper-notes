## 1. 풀려는 문제

마커 기반 시각 촉각 센서(GelSight 계열, DIGIT 등)는 엘라스토머에 마커를 넣어 마커 변위로 힘을 추정합니다. 같은 영상에서 마커가 표면 음영을 가려 형상 복원을 방해합니다(1절). 기존 데이터 기반 분리(TacDiff [21] 등)는 **마커 마스크를 추정한 뒤 인페인팅**하는 직렬 구조입니다. 저자들은 세 가지를 지적합니다(그림 1(c)).

1. **마스크 크기 딜레마.** 마커는 가려진 영역뿐 아니라 주변 엘라스토머에 함입(indentation) 흔적도 남깁니다. 마스크를 작게 잡으면 흔적이 남고, 크게 잡으면 형상 정보가 사라집니다.
2. **오차 잔류.** 마커 위치 오류가 복원 단계로 전파되고 되돌릴 수 없습니다.
3. **실제 쌍 데이터 부재.** 기존 합성 데이터는 마커를 이미지에 덧씌워 함입 흔적을 무시합니다.

## 2. 방법 (3절)

입력은 색 부호화 조명의 RGB 혼합 이미지 I_mix입니다. 출력은 마커 없는 음영 이미지 Î_sha(RGB)와 부드러운 마커 이미지 Î_mar ∈ [0,1]^{H×W}입니다(3.1절).

| 구성 | 내용 | 근거 |
|---|---|---|
| 음영 복원 분기 | I_mix를 조건으로 하는 DDPM(픽셀 공간). 6채널 입력(I_mix와 x_t 연결), 노이즈 예측 ε_θ = D_θ(x_t, t, I_mix), T = 1000 | 식 1–5, 부록 A.1–A.2 |
| 구조 | 채널 (64, 128, 256, 256), 단계당 잔차 블록 인코더 2, 병목 2, 디코더 3 → 합 22개, Swish와 GroupNorm | 부록 A.1 |
| 마커 추출 분기 | 3층 FCN(3→32→64→1, 커널 3), 시그모이드, BCE | 식 6, 부록 A.1 |
| 음영 손실 | L_sha = E‖ε − D_θ(√ᾱ_t I_sha + √(1−ᾱ_t) ε, t, I_mix)‖² | 식 3 |
| 주변 함입 손실 L_sur | Î_mar를 문턱 τ로 이진화해 반경 r = 2픽셀 팽창, 마커 자체를 뺀 고리 R_mar에서 ‖(Î_sha − I_sha)⊙R_mar‖₁ / (‖R_mar‖₁ + δ). Î_sha는 한 번의 노이즈 예측으로 구한 x̂₀ | 식 4, 7, 8, 부록 A.2 |
| 변화-마커 일관성 L_con | Ī_chg = mean_c(\|Î_sha − I_mix\|), I_chg = Ī^γ / (max Ī^γ + ε), γ = 2, L_con = ‖Î_mar − I_chg‖₁ | 식 9, 10 |
| 총 손실 | L = L_sha + λ_mar L_mar + λ_sur L_sur + λ_con L_con. λ_mar = 0.5, λ_sur = λ_con = 0.05. L_sur, L_con은 100 epoch 뒤부터 사용 | 식 11, 4.1절 |
| 학습 | RTX 4090 한 장, 300 epoch, 배치 2, 약 14시간. 학습률 음영 1e-5, 마커 1e-4. AdamW (β = 0.9, 0.999, wd 0.01) | 4.1절, 부록 A.2 |
| 추론 | 순수 노이즈에서 DDPM 샘플링(식 5). 저자도 "수백 단계"라 적고 실시간 배치의 한계로 인정 | 3.1절, 5절 한계 |

논문에 없는 값: 입력 해상도, 이진화 문턱 τ, 샘플링 단계 수와 시간, 보조 손실이 x̂₀를 어느 t에서 쓰는지, 보조 손실의 gradient가 다른 분기로 흐르는지(stop-gradient 여부), SAM에 쓴 프롬프트 개수와 후처리.

## 3. 데이터 (3.3절, 4.1절, 부록 A.3, B)

- **센서와 장치:** MC-Tac 센서에 정렬 핀 20개가 달린 외피를 씌우고, 5×5 교체식 질감 유닛이 있는 수집 패드(홈 20개)에 눌러 20개의 접촉 자세를 반복합니다(그림 3, 4). 순서는 (1) 마커 없는 엘라스토머로 I_sha 수집, (2) **같은 엘라스토머에 마커를 직접 제작**한 뒤 같은 자세 순서로 I_mix 수집입니다. 200 g 추를 눌러 힘을 일정하게 둡니다.
- **규모:** 객체 54개 × 자세 20개 = **1,080 쌍**(식 12, 4.1절). 미관측 객체 5개(100장), 나머지 49개 객체에서 자세 1개씩(49장)을 시험으로 두고 나머지를 학습에 씁니다. 이 산술은 맞습니다(`03` V1: 학습 931 + 49 + 100 = 1,080).
- **마커 정답(pseudo GT):** 마커 중심 점을 사람이 찍고 SAM [53]에 프롬프트로 넣어 분할 마스크를 만듭니다. 즉 마커 이미지의 정답은 사람이 아니라 SAM 출력입니다.
- **증강:** I_sha, I_mar, I_mix에 같은 자르기 후 크기 조절(마커 스케일 모사)과 I_mar 기반 블러(초점 흐림 모사)를 적용합니다.
- **한계(저자):** 마커를 되돌릴 수 없어 데이터를 늘리려면 센서를 새로 만들어야 하고, 전단력을 제어하지 못합니다(5절).

## 5. 주장과 증거 사이에서 확인할 점

1. **"TacDiff 대비 7 dB"의 비교 조건.** TacDiff와 LaMa는 합성 데이터(마커를 덧씌운 이미지)로, 회귀 기준선 셋은 같은 실제 쌍 데이터로 학습했습니다(4.1절 Baselines). 같은 쌍 데이터로 학습한 U-Net 회귀는 PSNR 38.56 / 39.03으로 DeTac 39.45 / 39.07과 0.89 dB / 0.04 dB 차이입니다(`03` V2). 7 dB의 대부분은 데이터 차이로 읽을 수 있고, 확산 모델 구조의 몫은 FID·KID 쪽에서 크게 나타납니다(FID 약 5–6배 낮음, `03` V12).
2. **절제의 해석.** L_sur를 빼면 PSNR이 4.8 / 4.0 dB 떨어져 회귀 기준선보다 낮아집니다(`03` V4). L_sur는 마커 고리에 가중한 L1이므로, "마커 인식 가중"이 효과의 원인인지 "x̂₀에 픽셀 손실을 더한 것"이 원인인지는 균일 가중 L1과의 비교 없이는 가를 수 없습니다(`04` C4).
3. **마스크 확대 기준선.** 마스크 크기 딜레마를 보이려고 마스크를 키운 변형을 넣었는데, TacDiff는 두 분할 모두 네 지표가 나빠지고 LaMa는 좋아집니다(`03` V5). 본문은 "여전히 DeTac보다 낮다"고만 적습니다.
4. **MCLE의 정답.** 정답 중심은 SAM 기반 pseudo GT에서 옵니다. 같은 절차가 학습 라벨도 만들므로 MCLE는 pseudo GT와의 일치도입니다(`04` C6). 0.00762 mm는 7.6 µm이고, 이미지 해상도와 mm/픽셀이 없어 픽셀 단위로 옮길 수 없습니다.
5. **시행 수와 불확실성.** 표 1–4에는 시드, 반복, 신뢰구간이 없습니다. 미관측 객체는 5개 객체(100장은 객체당 20자세)이고 미관측 자세는 49장입니다. FID는 2048차원 특징의 공분산을 쓰므로 49장·100장에서는 공분산 계수가 48·99입니다(`03` V1).
6. **하위 과제의 표본.** 힘 추정과 표면 복원은 시험 표본 수, 힘 범위, 힘 성분(Fx, Fy, Fz) 정의가 없습니다. 힘 MAE가 UVTac 0.119 → DeTac 0.089(25.2% 감소)이고, SAM 3.1의 마커로는 혼합 이미지보다 2.39배 큽니다(`03` V7).
7. **직물 분류.** 직물 B만 Fisher p = 0.035(세 직물 Holm 후 0.070), 직물 C는 90.0 → 96.7%로 p = 0.61입니다. 분류 범주 수가 "several"이라 우연 수준을 알 수 없습니다(`03` V8). 30회가 독립 시행인지(같은 직물 시료를 반복해 누르는지)도 적혀 있지 않습니다.
8. **교차 센서 일반화.** 정성 그림(그림 7) 한 장이고 수치가 없습니다. 학습은 센서 한 대(마커 제작 후 변경 불가)의 데이터입니다.

## 6. 저자가 적은 한계 (5절)

(1) 음영 분기는 수백 단계 샘플링이 필요해 실시간 배치가 어렵습니다(가속 샘플러, 증류 제안). (2) 마커 제작이 되돌릴 수 없어 데이터 확장에 새 센서가 필요합니다. (3) 전단력 제어가 불가능해 학습 분포가 제한됩니다.
