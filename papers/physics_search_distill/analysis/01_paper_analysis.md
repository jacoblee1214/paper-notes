# 01. 논문 분석: Efficient World-Model Planning via Physics-Guided Search Distillation

**arXiv:2611.24171** (분석 대상: v2, 2026-11-19). 저자 Hongyu Zhang, Xiaoshuai Hao 외 8명 (Yanshan University, Xiaomi, KAIST, Tsinghua, Beijing Automotive Technology Center). 원문 17쪽(본문 9쪽 + 참고문헌 + 부록 S1–S6). 원문: `paper/paper.pdf`, 텍스트: `paper/paper.txt`.

## 0. 한 문장 요약

자율주행 세계모델 기반 플래너(WorldDrive)가 고른 궤적이 **추적 오차 때문에 도로를 벗어나고**, 후보 풀 안에 실행 가능한 궤적이 없으면 재순위로는 못 고친다는 문제를 두고, **(1) 실행 검증으로 후보를 고르고(EAS), (2) 탐색 교사가 풀 밖 수정을 찾되 도로 여유가 큰 쪽을 목표로 삼고(CAST), (3) 동결된 세계모델 특징과 실행 피드백으로 수정 한 번을 예측하는 학생(FCRS)을 학습해 롤아웃 1회로 검증하는(SRV)** 방법입니다.

## 1. 문제 설정

- 세계모델은 행동 조건부 미래 장면을 예측하지만, **예측이 정확해도 실행 궤적이 도로 안에 있다는 보장은 없습니다** (§1, 1쪽).
- 진단 (§1, 1쪽): NAVSIM v1 12,146 장면 중 **278개(2.3%)가 개입 필요**, 그 가운데 **106개(38.1%)는 풀 안에 도로 준수 대안이 없음** (`03` §1.6로 재계산 확인). 이 106개가 풀 밖 수정이 필요한 경우입니다.
- 주장 범위: 단일 시점 카메라(SV), 맵 기반 실행 기하 사용 (§4.1, 표 1 캡션).

## 2. 방법 (§3, 부록 A)

| 구성 요소 | 무엇을 하나 | 핵심 식·절 |
|---|---|---|
| **EAS** 실행 인식 선택 (§3.1) | 상위 5개 궤적을 LQR 추종기와 운동학 자전거 모델로 4 s(Ne = 40, 0.1 s 간격) 실행, 발자국 네 꼭짓점의 부호 있는 도로 여유 m_i 계산. m_i ≤ −0.05 m인 후보가 있으면 점수 최고인 비음수 여유 후보로 교체 | 식 (2), (3), 부록 A.5 |
| **CAST** 탐색 교사 (§3.3) | 영 변형에서 출발해 횡방향 두 매개변수 θ = (θ1, θ2)로 궤적을 변형(Dlat). 실행 여유를 최대화하는 θ* 탐색, 유한 차분 4 probe + 제안 1, 업데이트 2회 = 롤아웃 10회 | 식 (7), (8), 부록 A.5 |
| **PRS** 물리 학생 (§3.2) | 실행 기록(추적 오차, 여유, 16 시점 x 31 채널)과 정적 특징 10개로 64차원 표현과 θ_phys 예측. 사전학습 | 부록 A.2, A.3 |
| **FCRS** 미래 조건부 학생 (§3.2) | 동결 PRS에 FAR 특징(EAS 참조의 512차원 평균, 32차원 투영)을 더한 잔차 MLP(96→64→32→2). 잔차는 0 초기화 | 식 (4), (5), 부록 A.3 |
| **SRV** 수정 한 번 검증 (§3.2) | 여유 ≥ 2 cm, 헤딩 차 ≤ 0.20 rad, 변형 한계 0.75 m. 실패하면 EAS 참조로 폴백 | 식 (6) |

구조 정량 확인: PRS 158,850 + 학습 24,770 = **183,620 파라미터** (학습: 투영 16,416 + 잔차 8,354). 논문 수치와 정확히 일치 (`03` §5).

학습 설정 (표 S1): AdamW, 750 업데이트, 학습률 3e-4, 가중치 감쇠 1e-4, 배치 64, 수정 48 + 이미 도달 16 예제, 손실 Lact + 0.25 Lplan + 0.10 Lkeep. 장치는 RTX 5090 1대.

## 3. 주요 실험

### 3.1 NAVSIM v1 navtest (표 1, 12,146 장면, PDMS)

| 방법 | 입력 | PDMS | ΔPDMS |
|---|---|---|---|
| WorldDrive (SV, 세계모델 기반 기준) | 단일 카메라 | 89.0 | 0 |
| EAS 선택만 (표 3, WorldDrive 위) | 〃 + 맵 | 90.4 | +1.4 |
| FCRS (학생) | 〃 + 맵 + FAR | **91.0** (본문 90.97) | +2.0 |
| CAST (교사, 참조) | 〃 + 맵 + 탐색 10회 | **91.2** | +2.2 |
| WoTE (MV + LiDAR, 세계모델) | 다중 카메라 + LiDAR | 88.3 | −0.7 |

- 단일 시점 주장: 표 1에서 SV 기준선 중 최고는 WorldDrive(89.0)이므로 "단일 시점 최고"는 목록 안에서 맞습니다.
- **주의:** PGSD는 도로 지도와 ego 상태, 실행 모델(LQR, 자전거)을 추가로 씁니다. 기준선은 센서만 씁니다. 표 1 캡션이 "PGSD also uses road maps"라고 밝힙니다. 공정성 비교가 아니라 **정보가 다른 두 시스템의 비교**입니다 (`04` C4).

### 3.3 구성 요소 분석 (표 3, 표 4, 그림 3)

| 변형 | PDMS | 이득 vs EAS | 추가 롤아웃/수정 | 중앙 지연(ms, 단일 스레드 CPU) |
|---|---|---|---|---|
| EAS | 90.4 | 0 | 0 | — |
| 고정 규칙 수정 | 90.6 | +0.22 | 1 | 23.96 |
| PRS | 90.7 | +0.32 | 1 | 24.85 |
| FCRS | 91.0 (90.97) | +0.56 (73.2% 유지) | 1 | 25.13 |
| CAST | 91.2 | +0.77 (100%) | 9.81 | 239.49 |

- 1 롤아웃 학생이 CAST의 73.2%를 유지하면서 롤아웃을 **89.8%** 줄입니다 (1,040 → 106, 106회 트리거 기준). 재계산 일치.
- 73.2%는 비정규화 점수로 계산한 값입니다. 공개 표의 반올림 값(0.56/0.77 = 72.7%)과 범위가 큽니다. 반올림 범위 전체로는 55.6–91.4%입니다 (`03` §4).

### 3.4 목표 선택 효과 (§4.2, 부록 D–E): 이 논문에서 가장 잘 뒷받침되는 결과

## 4. 한계와 논문이 스스로 밝힌 것

- 실행 가정: LQR 추종기 + 운동학 자전거 모델, 4 s 비반응 실행 (v1), 반응형 2단계 (v2). **실제 차량 동역학과 추종 오차의 실제 분포는 검증 대상이 아님.**
- 수정 한계: 횡방향 두 매개변수, 변형 한계 0.75 m. "더 풍부한 기동과 상호작용 제약은 향후 과제" (§5).
- 음의 여유 사례 남음: 개선 후에도 최소 −2.2 m (부록 D). 검증과 폴백이 필수라고 저자가 명시.
- 교사와 학생이 **같은 실행기·차량·수락 규칙**을 공유합니다. 학생은 교사가 낸 목표를 모방하므로 교사를 넘기 어렵다는 것이 구조에서 보이는 한계입니다 (추정, 논문은 이 점을 직접 다루지 않음). 실제 격차는 0.21 PDMS입니다.

## 5. 주장과 증거의 틈 (요약, 세부는 `04_claim_verification.md`)

1. **NAVSIM 주 결과에 불확실성 구간이 없습니다.** 표 1, 표 3, 표 4의 PDMS 차이 (0.2–0.8)에 CI나 시드 SD가 없습니다. 부록 C의 부트스트랩은 **목표 선택 실험에만** 있습니다. 세 시드의 개별 점수도 없습니다.
2. **정보 차이가 있는 비교.** 맵, ego 상태, 실행 모델이 PGSD에만 있습니다.
3. **재현 기준선.** WorldDrive의 v2 점수는 저자 재현이고, v1의 89.0 기준은 WorldDrive 보고치입니다. 두 기준이 같은 실행기에서 나왔는지 확인할 수 없습니다.
4. **하위 점수로 PDMS를 정확히 역산하지 못합니다.** 평균끼리 곱하면 WorldDrive 86.7, CAST 89.9이고 보고 PDMS는 89.0, 91.2입니다. 장면별 곱의 평균이라 정상적인 차이이지만, 공개된 수치만으로는 검증이 안 됩니다. 상한 조건 (PDMS ≤ E[S])은 모두 만족합니다 (`03` §5).
5. **공개 코드와 프로젝트 페이지 없음** (`02` §4). 재현 가능성은 부록 A의 정보로만 판단합니다.
