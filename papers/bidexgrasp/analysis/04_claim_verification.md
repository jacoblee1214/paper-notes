# 04. 주장 대조 (공식 코드 없음)

## 0. 대상과 방법

- 공식 코드와 데이터가 아직 없습니다. 프로젝트 페이지(`frenkielm.github.io/BiDexGrasp.github.io`)는 "Dataset and Code (Coming soon)"이고 저자 계정(frenkielm, wyl2077, Rain-Shuoyu)에도 저장소가 없습니다. 이름이 같은 `maxtensor33/bidexgrasp`는 다른 논문(IROS 2026 투고, 단일·이중 물체)의 익명 저장소입니다(`02` §4). 따라서 논문 ↔ 코드 대조(차이 D1–Dn) 대신 **논문 주장 ↔ 논문 내 증거** 대조(C1–Cn)를 했고, 코드 clone은 만들지 않았습니다.
- 대조 근거는 (a) v2 본문, 표, 부록, (b) v1과의 차이, (c) `03`의 재계산, (d) 합성 기반 코드(BODex)와 평가 도구(DexGraspBench)의 공개 설정 파일 두 개(정적 읽기만, `03` V12)입니다.
- 판정 기준: **지지** = 증거가 주장과 맞고 강도도 맞음. **부분 지지** = 방향은 맞지만 강도, 범위, 비교 대상 중 하나가 넓음. **약함** = 증거가 부족함. **미확인** = 논문에 정보가 없어 검증할 수 없음. **불일치** = 논문 안의 값 또는 문장이 서로 맞지 않음.

## 2. 측정 정의와 프로토콜 점검

| 지표 | 정의 | 읽을 때 | 참고 |

| SUC-F / SUC-L / SUC-A | 쥐기 자세로 실행 후 물체 이동 5 cm·15° 이내로 3초. F는 여섯 방향 교란, L은 책상 위 floating 손으로 들기, A는 팔 제어 손으로 들기 | 분모(파지 수)와 반복 없음. 세 시험이 같은 파지 위의 서로 다른 평가라 독립 아님 | 부록 D, `03` V11 |

## 4. 구현할 수 있는지 (판정)

**이 맥(Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)에서 논문 수치의 재현은 불가능합니다. 코드와 데이터가 공개되지 않았고, 합성은 GPU(3090 8장, 약 60시간 추정), 학습은 4090 1장, 실험은 양손 로봇이 필요합니다. 핵심 아이디어의 축소판(토이)은 이 맥에서 구현할 수 있고, 앵커 토이는 끝냈습니다.**

- **조건부 항목의 조건:** Shadow Hand MJCF(예: MuJoCo Menagerie)를 내려받는 것은 사용자 승인이 필요합니다. 새 패키지 설치는 필요 없습니다.
- **막힘:** 확산 스텝 수, 네트워크 크기, 학습 설정이 v2에서 삭제되어 논문만으로 모델 재구현이 어렵습니다(질문 8).
- **의존:** 합성 파이프라인은 BODex(cuRobo 포크, NVIDIA License)를 기반으로 하므로, 재구현은 BODex의 QP 에너지(식 7)와 ReLU-QP를 torch로 직접 옮기는 길뿐입니다.
- **노력 합계:** 토이 단계(분리 QP, 뷰 쌍 표집) 1주 안팎, 축소 생성 모델까지 3–4주 (추정, 측정 전).
