# 03. 수치 재계산, 일관성 검사, 토이

논문(arXiv:2606.00267 v2)이 보고한 수치를 다시 계산하고, 표·본문·그림 사이의 일관성을 확인했습니다. 코드는 `analysis/recompute.py`(numpy, scipy, 수 초), `analysis/toy_typical_set.py`(torch, CPU, 1초 미만), `analysis/plot_figures.py` 입니다. 결과는 `recompute_results.json`, `toy_typical_set_results.json` 에 있습니다. 공식 코드는 실행하지 않았고, 아무것도 학습하거나 내려받지 않았습니다.

## 0. 방법과 가정

- **그림 판독 값.** 논문은 대부분의 결과를 막대·곡선으로만 보여 줍니다. 그림 5, 8, 22, 26은 400 dpi로 렌더링해 막대 높이를 픽셀로 읽었습니다(격자선으로 눈금 보정, 오차 약 ±0.5 %p). 그림 2(a)는 점의 위치를 눈으로 읽었습니다(오차 약 ±0.01). 문장 안에 "(그림 판독 값)"으로 표시했습니다.
- **시행 수 가정.** 회수율은 본문 6.1절의 "실패 궤적 100개"를 분모로 둡니다(n = 100 가정). 정책 성공률은 그림 8 캡션의 "20 rollouts per task"와 6과제로 분모 120을 둡니다(n = 120 가정). 이 가정이 틀리면 구간과 p 값이 달라집니다. 결과 JSON의 `assumptions` 에도 적었습니다.
- **구간과 검정.** Wilson 95% 구간, Fisher 정확 검정(비쌍대), 이항 검정. 같은 궤적을 세 방법이 공유하는지는 논문에 없어서, 쌍 구조가 필요한 곳은 가능한 범위로 계산했습니다.
- 항목 번호: V는 수치 재계산, K는 표·본문·그림 사이 일관성, C는 주장 판정입니다.

## 1. 보고된 결과 수치

### V1. 실패 회수율 54% → 71% → 94% (그림 5, §6.1)

| 방법 | k / n (n = 100 가정) | Wilson 95% |
|---|---|---|
| Nominal (N=1) | 54 / 100 | [44.3, 63.4] |
| Best-of-N | 71 / 100 | [61.5, 79.0] |
| StressDream | 94 / 100 | [87.5, 97.2] |

- Fisher: Nominal 대 StressDream p = 4.9e-11, Best-of-N 대 StressDream p = 2.5e-5, Nominal 대 Best-of-N p = 0.019.
- **쌍 구조의 가능한 범위.** 세 방법이 같은 100개 궤적을 평가했다면, StressDream 이 놓친 6개 안에서만 Nominal 이 단독으로 맞힐 수 있습니다(c ≤ 6). 따라서 StressDream 단독 b = 40 + c, c = 0–6 이고 정확 McNemar p 는 1.8e-12(c = 0)에서 1.0e-8(c = 6) 사이입니다. 쌍이든 아니든 방향은 분명합니다.
- 94%의 아래쪽 구간 끝은 87.5%라서 "높은 회수율"이라는 서술은 이 가정에서 유지됩니다.

### V2. 정책 성공률 39% → 71% (그림 8, 26, §6.2)

- **정수 가능성.** 분모 120에서 39%(반올림)는 k = 47만, 71%는 k = 85(반올림) 또는 86(내림)만 가능합니다. 즉 헤드라인은 **47/120 = 39.2%, 85/120 = 70.8%** 로 읽힙니다. Wilson 95%: Nominal [30.9, 48.1], Robust [62.2, 78.2]. Fisher p = 1.3e-6 (비쌍대).
- **과제 부호 검정.** 6개 과제 모두에서 Robust 가 높습니다(그림 26). 양측 이항 p = 0.031.
- **그림 26 판독 값**(Nominal / Robust, %): Block Stack 30.4 / 51.6, Utensil Pick 65.7 / 87.8, Knife Put 46.4 / 80.5, Coffee Bean 15.4 / 59.9, Coffee Bag 30.1 / 74.3, Candy Bag 50.4 / 74.3. 단순 평균은 39.7 / 71.4로 헤드라인과 일치합니다.
- **5 %p 격자와의 거리.** 과제당 20회이면 막대 높이는 5 %p 배수여야 합니다. Nominal 의 6개 막대 중 5개와 Robust 의 6개 중 4개는 격자에서 1 %p 안쪽이지만, Knife Put(Nominal 46.4, 격자 45와 1.4 차), Block Stack(Robust 51.6, 50과 1.6 차), Utensil Pick(Robust 87.8, 85·90 어느 쪽과도 2.2 이상 차)은 판독 오차(약 0.5)보다 크게 벗어납니다. 격자로 반올림한 합은 Nominal 47, Robust 86이라 헤드라인(47, 85 또는 86)과 맞지만, 과제별 시행 수가 모두 20인지는 이 그림만으로 확정할 수 없습니다.
- **과제별 Fisher(격자 반올림 k/20 가정).** Block p = 0.33, Utensil 0.13, Knife 0.048, Coffee Bean 0.008, Coffee Bag 0.010, Candy 0.19. 과제 하나씩으로는 6개 중 3개만 5% 수준에서 구분됩니다. 합산(p = 1.3e-6)과 6/6 방향 일치가 근거입니다.
- 오차 막대의 정의(K4)가 없어 위 구간과 직접 비교하지 않았습니다.

### V3. 그림 22: 과제별 회수율과 "실패 상상 비율" (§E.1)

**왼쪽 패널(회수율, 그림 판독 값, %)**

| 과제 | Nominal | Best-of-N (N=20) | StressDream |
|---|---|---|---|
| Block Stack | 45 | 59 | 95 |
| Utensil Pick | 61 | 66 | 94 |
| Knife Put | 79 | 93 | 100 |
| Coffee Bean | 79 | 100 | 100 |
| Coffee Bag | 41 | 70 | 100 |
| Candy Bag | 29 | 50 | 71 |
| 6과제 단순 평균 | 55.6 | 72.9 | 93.2 |

- **본문 54/71/94 와의 관계.** 단순 평균(55.6, 72.9, 93.2)은 헤드라인과 1–2 %p 다릅니다. 헤드라인이 100개 궤적을 합친 값이고 과제별 개수가 다르다면 설명됩니다. 막대 값이 k_i/n_i(오차 ±1.3 %p)이고 n_i 합이 100이라고 가정하면 가능한 분해가 110개이고, 이 중 풀링 값이 54/71/94 로 정확히 나오는 분해는 둘입니다. 예: n = (22, 15, 24, 5, 20, 14), StressDream k = (21, 14, 24, 5, 20, 10). 과제별 개수는 논문에 없으므로 이 분해는 존재 확인일 뿐 추정값이 아닙니다.
- **Best-of-N 표기.** 이 그림의 범례는 N = 20이고 그림 5는 N = 10입니다(K1).

**오른쪽 패널(정답이 실패가 아닌 궤적 중 WM이 실패를 상상한 비율, 그림 판독 값, % ±2)**

| | Block | Utensil | Knife | Coffee Bean | Coffee Bag | Candy | 평균 |
|---|---|---|---|---|---|---|---|
| Nominal | 0 | 12 | 12 | 0 | 1 | 1 | 4.3 |
| Best-of-N | 0 | 16 | 24 | 9 | 1 | 1 | 8.5 |
| StressDream | 16 | 33 | 49 | 46 | 13 | 1 | 26.3 |

- 저자는 이 비율을 거짓 양성 비율로 읽으면 안 된다고 적습니다(위험했지만 우연히 성공한 시연일 수 있음). 이 해석은 가능하지만 이 데이터로 검증되지 않습니다. 대조 단서는 StressDream 의 비율이 높은 과제(Knife, Coffee Bean)에서 Nominal 회수율도 이미 79%라는 점입니다.

### V4. Dubins (그림 2, 16, 부록 C)

- **그림 2(a) 판독 값**과 J = TPR + TNR − 1: Nominal (0.640, 0.975) J = 0.615; Best-of-N(N=10) (0.765, 0.960) 0.725; StressDream (0.890, 0.925) 0.815; Classifier Guidance (0.685, 0.840) 0.525; StressDream w/o C_pla (0.905, 0.735) 0.640. 규제를 뺀 쪽의 TPR 은 오히려 높고 TNR 이 0.735로 떨어집니다. 이 그림은 논문의 두 주장(조종이 가능한 실패를 찾는다, 규제가 TNR 을 지킨다)을 모두 지지합니다. 판독 값이라 소수 둘째 자리는 의미가 없습니다.
- **정답 라벨의 문턱.** 10,000회 몬테카를로에서 한 번이라도 실패 집합에 들어가야 양성입니다. 실패 확률이 q 인 궤적이 걸릴 확률은 q = 1e-4에서 63%, 3e-4에서 95%, 1e-3에서 99.995% 입니다. 따라서 "가능한 실패"의 정의가 사실상 q ≳ 3e-4 인 궤적입니다. 경계 근처의 궤적은 라벨이 무작위에 가깝습니다. 평가 데이터 5,000개 중 양성 수와 q 분포는 논문에 없습니다.
- **그림 16(낙관 조종).** 정답 0.55 대비 차이: Nominal −0.06, Best-of-N −0.05, CG +0.08, 규제 없음 +1.11, 규제 있음 −0.02. 규제 있는 쪽이 정답 상한에 가장 가깝습니다(오차 막대 정의 없음, K4).

### V7. 보조정리 2의 기댓값과 표 4의 등방성 값

- 표 4의 Dubins 공칭 등방성은 0.02 입니다. 식 (4.2)와 표 3의 k = 16, m = 64 로는 기댓값이 0.27 이고, D = 1,024에서 0.02 가 되는 k 는 4(= 5/256 = 0.0195)입니다. 표 4가 같은 정의를 쓴다면 k 가 다르거나 정규화가 다릅니다. 정의는 논문에 없습니다(K7).

### V8. 표 4의 노름 로그확률

- D = 1,024의 χ² 로그밀도 최댓값은 −4.73 입니다. 공칭 표본의 "최소 로그확률"이 −7.6 이면 정점에서 z = 2.40 표준편차에 해당합니다. 공칭 궤적 한 개에서 L개 표본의 최소를 평균하면 L = 20에서 −7.17, 40에서 −7.76, 50에서 −7.96 이므로 **−7.6은 궤적당 약 30–40개 잡음을 본 최소와 맞습니다**(L 은 논문에 없어 가정). StressDream 의 −6.3(z = 1.77)은 같은 L 에서 공칭보다 중심에 가까운 노름입니다(노름 항과 투영의 효과로 해석 가능). 규제를 모두 뺀 −717.6은 z = 37.8 입니다.

### V9. 이동 예산: 알고리즘 1과 공개 설정

반복당 이동은 lr x (클립 후 기울기 노름) 이하이므로 총 이동의 상한은 반복 수 x 노름 클립 입니다. 알고리즘 1은 노름 클립 1.0, 공개 설정(`04`)은 Vista 20, Ctrl-World 20(최종 클립), Dubins 5 입니다. 독립 두 표본의 거리는 √(2D)입니다.

| WM | 반복 | √(2D) | 알고리즘 1 상한 (비율) | 공개 설정 상한 (비율) |
|---|---|---|---|---|
| Vista | 20 | 1,357.6 | 20 (1.5%) | 400 (29%) |
| Ctrl-World | 10 | 339.4 | 10 (2.9%) | 200 (59%) |
| Dubins | 10 | 45.3 | 10 (22%) | 50 (110%) |

- 상한이지 실제 이동은 아닙니다(실측 이동은 코드를 실행하지 않아 모릅니다). 부록 F의 "초기·최적 잡음 거리는 √(2D)보다 훨씬 작다"는 알고리즘 1의 상한 기준으로는 Vista·Ctrl-World 에서 맞고, 공개 설정의 상한 기준으로는 보장되지 않습니다.
- **한 방향으로 B 만큼 이동할 때 노름 통계의 변화.** Vista 에서 B = 20이면 노름이 √(D+B²) − √D = 0.208, 즉 표준편차의 0.29배 변합니다. 로그밀도는 B²/2 = 200 nat 감소하지만 로그밀도의 표준편차는 √(D/2) = 679 nat 이라서 0.29배입니다. Ctrl-World(B = 10)는 노름 0.29 sd, 50 nat 대 170 nat 입니다. **보상 방향 한 축으로 20 표준편차 이동해도 전역 통계로는 0.3 표준편차**입니다. 이것이 "타이피컬 셋 안 = 그럴듯함"(C10)의 근거가 통계 자체가 아니라 WM 디노이저의 강건성에 있다는 뜻입니다.

## 3. 비용 산술

### V10. 예산과 시간 (표 1, B.6)

- 표 1에서 근사 기울기 StressDream 은 N x (K·T_den + 2·T_ver), Best-of-N 은 N x (K·T_den + T_ver)입니다. T_ver/(K·T_den)가 0.05–1.0이면 비율은 1.05–1.5 입니다. 근사 없는 기울기(Dubins 설정, 본문 §5 "full gradient")는 N x (2K·T_den + 2T_ver)라서 비율이 약 2.0 입니다. 즉 **Dubins 에서 같은 계산량의 Best-of-N 은 N ≈ 20**입니다. 그림 2는 Best-of-N(N=10)입니다. 그림 5와 22의 Ctrl-World 는 근사 기울기라 N = 반복 수가 계산량으로 거의 같습니다.
- Vista: 생성 1–2분 x 20회 = 20–40분. 부록 B.6의 "약 30분"과 맞습니다.
- N개 표준정규 표본의 기대 최댓값은 N = 10에서 1.54, 20에서 1.87, 40에서 2.16 입니다. 보상이 한 방향에 선형이라면 Best-of-N 의 이득은 이 정도(표준편차 단위)이고, 1차 조종은 이동 상한이 허용하는 만큼(§V9, 토이)까지 올라갑니다. 선형 보상은 가정입니다.

## 5. 토이 T1: 타이피컬 셋 통계는 무엇을 보는가

논문 4.2절의 세 항을 Dubins 규모 잡음(D = 4 x 16 x 16 = 1,024)에 논문 정의대로 구현했습니다(`analysis/toy_typical_set.py`, torch CPU, 1초 미만). 보상은 **선형** r(ε) = ⟨ε, p⟩ (p 는 단위벡터)이고 알고리즘 1의 처리(성분 클램프 0.3, 노름 클립, 학습률 1, 10회, β = 10)로 잡음을 움직입니다. 스펙트럼 구간 수 B = 8(논문에 값 없음, 가정), 순열 20개. 이 토이는 통계가 무엇을 보는지 보일 뿐 VLM 보상이나 실제 WM 의 그럴듯함과는 무관합니다.

읽을 수 있는 것(이 토이 안에서):

1. **세 통계는 서로 다른 구조를 봅니다.** 무작위 방향의 이동은 스펙트럼을 거의 바꾸지 않고(0.030 대 기준 0.0205) 노름·등방성만 조금 올립니다. 매끈한 방향의 이동은 스펙트럼을 기준의 약 30배(0.642)로 올립니다. 노름 항만으로는 이 스펙트럼 이탈이 거의 줄지 않습니다(0.617).
2. **표 3의 계수(x1)에서는 스펙트럼 이탈이 거의 그대로**입니다(0.642 → 0.561). 기준 근처(0.016)로 돌리려면 약 25배 계수가 필요했고 그때 보상 이득이 9.7 에서 4.2 로 줄었습니다. 알고리즘 1이 합친 기울기를 노름 클립하므로, 보상 기울기(β = 10)가 크면 규제 기울기의 상대적 영향이 같은 비율로 작아집니다.
3. **같은 이동량에서 노름 통계는 1–4 sd 정도만 움직입니다.** 이동 상한 10(클립 1.0)에서 보상은 약 9.5σ 올랐는데 노름 편차는 1.3–3.6 sd 였습니다. 클립 5.0(상한 50)에서는 노름 편차가 3.4–6.8 sd 로 커져 규제 없이는 40 sd 입니다.
4. 이 토이는 "규제를 약하게 하면 이탈이 생기고, 강하게 하면 이득이 줄어든다"는 방향성을 보일 뿐이고, 실제 WM 에서의 계수 감도나 VLM 기울기의 구조는 알 수 없습니다.
