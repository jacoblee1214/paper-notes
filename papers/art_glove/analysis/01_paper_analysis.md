## 1. 문제 설정

로봇 손 학습에 쓰는 사람 시연은 두 조건을 같이 만족해야 합니다. 사람이 손을 자연스럽게 쓸 수 있어야 하고(손 동작 보존, 자연스러운 햅틱 피드백, 전체 손 접촉 면적), 기록된 시연에는 접촉 정보가 있어야 합니다(손 쪽 접촉 기하, 표면 움직임, 접촉 상태). 저자는 기존 방식이 둘 중 하나를 희생한다고 봅니다(Table 1). 텔레오퍼레이션은 촉각 피드백이 약하고, 외골격과 링크 장치는 자유도나 정렬 때문에 손 동작을 제한하며, 영상 기반 방법은 접촉 상태를 가려지는 상황에서 추론하고, 소프트 장갑은 표면이 변형되어 접촉 기하가 불확실합니다.

ART-Glove의 주장은 "손 쪽 접촉 면을 강체 기능면으로 명시하고, 그 면을 해부학적으로 정렬된 관절로 연결해 사람 손 동작을 따르게 한 뒤, 같은 면에 촉각 셀을 덮는다"입니다.

## 2. 설계 요구 (§3)

1. 강체 기능면으로 손 쪽 접촉 기하를 알 수 있을 것
2. 그 면이 사람 손 분절을 따르되 자연스러운 동작을 막지 않을 것
3. 접촉은 같은 기능면에서 측정할 것
4. 표면 움직임과 촉각 신호를 같은 장치에서 동기화할 것

## 3. 기계 설계 (§4, 그림 3–5, 부록 A·C)

- **강체 기능면 16개 (§4.1):** 손가락 4개 × 3마디 = 12, 엄지 3개(말단, 근위, 첫 중수골), 손바닥 1개. 면 사이 틈은 관절 움직임을 위해 비워 둡니다.
- **관절 22개 (§4.2.2):** 손가락 4개 × 4자유도(DIP, PIP, MCP-FE, MCP-AA) = 16, 엄지 6자유도(IP, MCP-FE, MCP-AA, MCP-AR, CMC-FE, CMC-AR) = 6. 엄지 축 회전(MCP-AR, CMC-AR)을 넣은 점이 특징입니다(§4.2.2, 생체역학 근거 [42, 43]).
- **해부학적 정렬 (§4.2.1):** 손끝만 추적하는 외골격은 외부 기구 연결로 손끝 자세를 복원할 수 있지만, 면 전체를 따르게 하려면 축을 맞춰야 한다는 논리입니다.
- **관절 구현 3종 (§4.2.3, 그림 5):** Type I 축-슬리브(두 면 여유, 측면 돌출 3.7 mm), Type II 축-베어링(한 면 여유, 엔코더 직결), Type III 호형 슬롯(양면 여유 없음, 기어 전달비 7.4:1). 축 배치마다 다른 방식을 쓴 것은 공간 제약 때문입니다.
- **재료:** 강체 면은 두께 1 mm의 3D 프린트 PLA (§8).

## 4. 센싱과 획득 (§5, 그림 6, 부록 B–D)

- **촉각 (§5.1):** 64 × 32 = **2048 taxel**이 16개 면을 덮습니다. 손가락 4개가 32행 × 32열 영역을 쓰고, 엄지 중수골과 손바닥은 각 17 × 16, 엄지 말단과 근위가 나머지 15행 × 32열을 나눠 씁니다(부록 B, 합계 1024 + 544 + 480 = 2048). FPCB 모듈 7개로 나뉩니다. 압전저항층(piezoresistive)에 행·열 전극 교차점마다 taxel이 생깁니다. 전극 선폭 0.3 mm. **taxel 물리 간격은 논문에 없습니다.**
- **관절 각도 (§5.2):** AS5600L 자기 엔코더 + 직경 자화 디스크 자석. 엔코더 PCB 5종(부록 C), 22개 자유도 전부. 엔코더 신호는 촉각 FPCB 커넥터를 거칩니다.
- **동기화 (§5.3, 부록 D):** 촉각은 저잡음 판독 PCB(인용 [41])가 행렬을 주사하고, STM32F411CE가 SPI로 촉각, I2C로 엔코더를 읽어 **120 Hz**로 묶습니다. 동기화 지터나 실제 달성 주기는 보고하지 않습니다.

## 6. 한계 (§8)

저자가 직접 쓴 한계는 다음과 같습니다.
- 강체 셸 1 mm PLA는 얇아서 변형이 촉각 노이즈를 만듭니다(엄지 첫 중수골면에서 관찰).
- 손끝에 손톱 구조가 없어 작은 물체 집기가 어렵습니다.
- Type III 호형 슬롯은 부피가 크고 조립 공차에 민감합니다(과조임은 마찰, 느슨함은 흔들림).
- **촉각은 법선 방향 접촉 크기만 잽니다. 곡면의 힘 보정은 미래 과제입니다.** 측면 면은 덮이지 않았습니다.
- 생산 규모: 현재 프로토타입은 특정 손 크기에 맞춥니다. 사용자별 설계 파이프라인은 미래 과제입니다.
- 로봇 전이: 한 장갑에서 한 로봇손으로 가는 1:1 전이를 목표로 하지 않습니다. 여러 사용자의 장갑과 여러 로봇손이 공통 표현(손 쪽 면의 기하와 재질, 면 운동, 접촉 상태)을 공유하는 다대다 전이를 제안하지만, 이 표현을 구현하거나 검증하지 않았습니다.

## 7. 논문이 답하는 것과 답하지 않는 것

**답하는 것**
- 기계적으로 사람 손 관절 범위를 크게 막지 않는다는 점 (ROM 표, Kapandji 10점, 외전 그림)
- 세 관절 방식 모두 서보 기준에서 MAE가 0.4–0.5° 수준이라는 점 (Fig. 9, 한 장치, 5회 왕복)
- 2048 taxel 촉각이 접촉 위치와 면 선택성을 보인다는 정성 증거 (Fig. 10)
- 22개 관절과 촉각을 120 Hz로 묶은 시스템이 돌아간다는 정성 증거 (Fig. 11)

**답하지 않는 것**
- 힘의 정확도 (보정 없음, §8이 인정)
- 손 자세 추정의 정확도 (사람 손 기준 장비, 예: 광학 모션캡처와 비교 없음)
- 촉각 위치 정확도 (기준 장치 없음)
- 시연 데이터의 양, 질, 로봇 학습 효과 (정책 학습 실험 없음)
- 리타게팅 오차, 접촉 라벨을 쓴 학습 효과
- 기존 장갑(DexCap, Osmo, OpenTouch 등)과의 정량 비교 (Table 1은 정성 표)
- 반복 측정, 피험자 간 차이, 통계 검정

## 8. 부록 요약

- **A (관절 세부):** 엄지 6자유도 구현, MCP-AA와 MCP-AR의 연동, CMC 신전이 금속 면을 끌 수 없어 양면 테이프로 고정한 사실, 새끼손가락 MCP-FE 방식, 검지–중지 간격 차이에 따른 Type III 중심 오프셋 (그림 12–14).
- **B (taxel 배치):** 3개 행 공유 그룹(손가락 32행, 엄지 중수골·손바닥 17행, 엄지 말단·근위 15행). 트레이스 폭 0.3 mm (그림 15).
- **C (엔코더 PCB):** 5종, 22개 자유도 배치. 공통 회로는 AS5600L, 디커플링 커패시터, I2C 풀업. 2층 PCB, 4핀 0.5 mm FFC (그림 16).
- **D (판독 전자장치):** 센서 허브, 판독 PCB, MCU 보드 3종 (그림 17).

## 9. 논문 내부 정합성 (요약)

자세한 대조는 `04_code_verification.md`와 `03_analysis.md`에 있습니다.
- 면 16개, 관절 22개, taxel 2048개, 엔코더 PCB 22개는 모두 서로 맞습니다.
- 다만 taxel 간격은 없고, Fig. 15의 엄지 영역 표기(20×15, 12×15)는 본문의 "15행 영역"과 모양이 다릅니다. 면적 합계 480은 같습니다.
- Type I 오차가 가장 큰 이유를 "기어 전달" 때문이라고 설명하지만, 기어를 쓰는 Type III가 Type II와 비슷한 오차를 보여 설명이 완전하지 않습니다.
- Type III의 7.4:1 전달비가 "분해능을 높인다"고 설명하지만, 엔코더 분해능 바닥(외부 데이터시트 기준 12-bit면 0.088°, 관절 환산 0.012°)은 MAE 0.38°보다 한참 작아서 오차 크기를 설명하지 못합니다.
