# 02. 선행연구와 공식 저장소

## 1. 계보: 시연 장치의 세 갈래

GELLO가 풀려는 문제는 "사람이 로봇을 조작해 시연을 모으는 장치"입니다. 논문 §II가 나누는 계보를 따르면 다음과 같습니다.

1. **저가 말단 공간 장치 (VR, 3D 마우스, 카메라).** SpaceNavigator 3D 마우스 [17], VR 컨트롤러 [18]–[32] 계열, RGB 카메라와 IMU 기반 장치가 있습니다. 말단 자세만 조작하므로 관절 한계와 특이점을 사용자가 느끼기 어렵습니다(§II-A).
2. **로봇과 같은 구조의 축소 또는 등가 장치.** ALOHA [9]는 저가 서보 팔 두 개를 조종 장치로 씁니다. 양방향 원격조작에서는 타깃과 같은 구조의 팔 [33]–[35], [38]–[40]이 있고, 고가 장비입니다. GELLO는 이 계열을 3D 프린트와 저가 서보로 낮춥니다.
3. **1대1 외골격과 햅틱 장치.** 외골격 [41]–[43]은 로봇마다 따로 설계하고, Omega7 같은 햅틱 장치 [44]–[46]는 작업 공간이 좁습니다.

시연 데이터를 키우려는 흐름은 배경입니다. RT-1 [5], RT-2 [6], BC-Z [7], Gato [8] 같은 대규모 데이터 학습과, 인간 영상 학습 [52]–[57]이 있습니다. GELLO는 이 흐름에서 **시연 수집 장치**의 자리를 맡습니다.

ALOHA [9]와 비교한 차이: GELLO는 "관절 대응 + 저가 서보"라는 원칙을 로봇 종류마다 다른 3D 프린트 부품으로 옮깁니다. ALOHA는 한 팔 구조에 맞춘 조종 팔을 씁니다(§II-A, 본문).

- 두 저장소는 모두 MIT입니다. 공개 저장소이므로 코드 인용과 재사용은 MIT 조건을 따릅니다. 클론은 읽기 전용으로 두고 실행하거나 설치하지 않았습니다(`04_code_verification.md`).
- `gello_mechanical` README는 "세 가지는 원 논문의 로봇(Franka FER, UR5, xArm7), 나머지는 커뮤니티 기여(YAM, Lite6, AR4, FR3)"라고 씁니다. 논문 이후의 로봇은 여기서 확인합니다.
- 두 저장소의 인용 블록은 `@misc{wu2023gello}`(연도 2023)이고 학회를 적지 않았습니다. 학회 확인은 Crossref DOI로 했습니다.
- 다른 구현 (커뮤니티 포크, ROS 2 포팅, 논문 외 로봇 설정)은 확인하지 않았습니다. 필요하면 GitHub 검색을 따로 합니다.
