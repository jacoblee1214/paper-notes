### 2.1 논문 주장의 코드 쪽 확인

- **"배경 제거와 참조 영상 조건화"** (§3.2): 코드에서 확인됩니다(D2, D9).
- **"2단계는 백본을 동결하고 학습된 힘-변형 대응을 보존"** (§3.2): 코드에서 백본 `requires_grad_(False)`, 어댑터 제로 초기화로 확인됩니다. 첫 스텝에서 2단계 출력이 1단계와 같다는 성질은 구조상 성립하지만 실행해 보지는 않았습니다.
- **"ΔF는 상대 힘"** (§3.2): `forces[j] − forces[i]`(훈련), `target − initial`(추론)으로 확인됩니다.
- **"자세 정보는 마스크로만"** (§3.2): 모델이 숫자 자세 벡터를 받지 않고 마스크만 받는다는 README 서술과 코드가 일치합니다.

## 3. 학습 목록의 구조 점검 (CSV 읽기만)

`force_train.csv`: 고유 참조 영상 8,236개, 객체별 3,333–3,334행. 한 스텝의 힘 단계 배치는 같은 (객체, 참조 영상) 묶음에서 뽑으므로 한 접촉 자세의 서로 다른 힘 영상끼리 쌍을 만듭니다. `force_pose_train.csv`는 객체 묶음에서 뽑으므로 다른 자세의 영상끼리 쌍이 되고, 목표 마스크가 자세 변화를 알려 줍니다(`train.py`의 `groups` 키). 이 두 방식은 논문 그림 3과 일치하지만 논문 본문에는 쌍 구성이 없습니다.

## 4. 구현 가능성 (이 맥: Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)

**판정: 논문 결과(표 1, 2, 6, 7, 그림 6, 8)의 재현은 불가능합니다. 공식 코드의 추론만 승인과 설치 뒤 조건부로 가능하고, 학습은 사실상 불가능합니다.**
