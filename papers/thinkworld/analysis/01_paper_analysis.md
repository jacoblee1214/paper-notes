## 1. Abstract (한 줄 요약과 주장)

**한 줄 요약:** VLA의 VLM이 행동 전에 **사람과 로봇이 공유하는 이산 손목 움직임 토큰(Chain-of-Dynamics, CoD)**을 생성하고, 그 CoD가 1초 뒤 장면(DINOv3 특징)을 어떻게 바꿀지 예측하도록 학습합니다. 그다음 예측한 미래와 실제 미래가 잘 맞는 CoD에 보상을 주는 GRPO로 VLM을 강화합니다. 배포할 때는 CoD도 미래 예측도 쓰지 않습니다.

저자들이 내세우는 기여는 세 가지입니다(Sec. 1).

1. 사람과 로봇에 공통인 VLM 고유의 행동 추론 인터페이스(CoD)와 내부 세계 상상(world imagination)을 결합한 VLA 학습 틀입니다.
2. **결과에 근거한 RL(consequence-grounded RL)**입니다. 관찰된 미래와의 일치로 CoD에 보상을 주므로, 행동 레이블이 없는 영상에서도 추론이 개선된다고 주장합니다.
3. 행동 레이블이 없는 사람 영상을 늘리면 성능이 오르고, 사람 영상만으로 보여 준 과제 순서를 로봇이 원자 기술을 조합해 수행한다고 보고합니다.

## 2. Method

### 2.1 전체 구조 (Fig. 2, 부록 A)

```
입력: 지시문 l, 이력 h_t(최대 16프레임, 2 Hz), 현재 관측 o_t(+손목 카메라), 고유수용 상태 s_t(256-bin 토큰)
        ▼
Qwen3-VL-2B (VLM)
  ├─ 학습: <think> CoD 토큰열 c_t </think>  ← FAST 토크나이저(어휘 2,048)로 만든 1초 손목 움직임
  ├─ 학습: 미래 질의 64개 q → MLP + 6층 cross-attention → DINOv3 ViT-H/16+ 패치 196개(1초 뒤)
  └─ 추론: 빈 <think></think> (CoD·미래 예측 없음)
        ▼  입력 토큰의 층별 KV만 전달 (CoD·미래 질의 토큰은 전달 안 함)
MolmoAct2 action expert (36블록, 폭 768, FP32, flow matching, Euler 10스텝) → 연속 행동 chunk
```

| 단계 | 학습 대상 | 목적 | 규모 (Table 5) |
|---|---|---|---|
| VLM SFT | 언어 모델 + 미래 projector | CoD·VQA cross-entropy + 3·L_future | 150k iter, 배치 128, GPU 16×8 |
| Action SFT | action expert만 (VLM 고정) | masked flow matching | 50k iter(현재 시점 5k + 이력 45k), GPU 8×8 → 16×8 |
| RL | 언어 모델만 (expert·projector 고정) | GRPO/GDPO + 약한 SFT replay | 2k iter, 배치 128, K = 4, GPU 8×8 |
| 사후학습 | LIBERO: 전체 미세조정 50k / YAM: 적응 후 과제별 LoRA 50k | 대상 embodiment | LIBERO GPU 32장, YAM GPU 64장 |

### 2.2 Chain-of-Dynamics (Sec. 3.2, 부록 A.2)

- **움직임 표현:** 로봇 궤적과 사람 손 궤적을 모두 정규화된 delta 엔드이펙터로 바꿉니다. 손 하나는 6D, 두 손은 12D(위치는 m, 회전은 rotation vector)이고, 그리퍼 상태는 뺍니다. 정규화 스케일은 0.3448 m와 0.9119 rad입니다.
- **좌표계:** 로봇은 베이스 좌표계, 사람은 중력 정렬 + 행위자 yaw를 따르는 좌표계입니다. 사람과 로봇의 기구학 대응은 가정하지 않습니다.
- **토큰화:** 1초 구간을 FAST 토크나이저[57]로 어휘 2,048의 이산 토큰열 c*로 바꿉니다. VLM은 이것을 autoregressive로 생성합니다(L_CoD).
- **실행:** CoD 토큰은 실행되지 않습니다. 별도의 action expert가 실행 행동을 냅니다.

### 2.3 CoD 조건부 미래 상상 (Eq. 1–2, 5)

CoD 뒤에 학습 가능한 미래 질의 q_{t+Δ}를 붙입니다. 질의는 VLM을 거쳐 q̃가 되고, 가벼운 decoder가 이것을 동결된 DINOv3 특징 공간의 z_{t+Δ}로 바꿉니다(Eq. 1). 표적은 Δ = 1초 뒤 주 카메라 프레임의 DINOv3 특징 z*입니다(±50 ms 안에 프레임이 없으면 손실에서 뺌).

```
L_SFT = L_CoD + λ_future · L_future                                  (Eq. 2, λ_future = 3)
dist(z, z*) = (1/|V|) Σ_p [ 1 − cos(z_p, z*_p) + λ_SL1 · SmoothL1_β(z_p, z*_p) ]   (Eq. 5, β = 0.01)
```

학습 때 미래 예측은 **정답 CoD(teacher forcing)**에 조건화됩니다.

### 2.4 세계 상상 보상 RL (Sec. 3.3, Eq. 3–4, 6, 부록 A.6)

같은 맥락에서 CoD 후보 K = 4개를 뽑고, 각 후보로 예측한 미래를 실제 미래와 비교해 보상을 줍니다.

```
sim(z, z*) = ½ [ (1/|V|) Σ_p s_p  +  Σ_p w_p s_p / Σ_p w_p ],   s_p = cos(z_p, z*_p)          (Eq. 6)
w_p = 0.2 (변화량 ≤ 중앙값) → 선형 증가 → 1 (≥ 90분위),  변화량 = 현재→관찰 미래의 DINO 특징 변화
L_RL = 0.999 · L_GRPO(r_world) + 0.001 · L_replay                                            (Eq. 4)
```

- **형식 오류:** 형식이 깨진 CoD는 그룹 최저 유사도보다 0.05 낮은 보상을 받습니다.
- **advantage:** 4개 후보 그룹 안에서 표준화하고, 다시 배치 전체에서 표준화합니다. 후보의 advantage는 그 후보의 모든 토큰이 공유합니다.
- **최적화 설정:** 토큰 단위 importance ratio를 [0.8, 1.28]로 자르고, KL 계수는 0.04, 학습률은 10⁻⁶입니다.
- **고정 부분:** RL 동안 미래 projector와 action expert는 고정입니다.

### 2.5 배포

Action SFT와 추론은 빈 `<think></think>`를 씁니다. **배포된 정책은 CoD도 미래 예측도 생성하지 않으므로, 구조상 Qwen3-VL + MolmoAct2 action expert VLA와 같습니다.** CoD, 미래 예측, RL은 모두 VLM 가중치를 바꾸는 학습 신호로만 작동합니다(부록 C.5).

### 3.2 실물 로봇 일반화 (Fig. 3, Table 6)

YAM 양팔(카메라 3대, RGB만)에서 세 과제를 평가합니다. 색 맞추기는 ID·OOD 설정이 6개씩, 컵 걸기와 분류는 3개씩이고, 설정당 5회입니다.

| 방법 | ID 성공 (60회) | OOD 성공 (60회) | Macro | Micro |
|---|---|---|---|---|
| Diffusion Policy | 31 | 13 | 32.8 | 36.7 |
| MolmoAct2 | 47 | 25 | 62.2 | 60.0 |
| LaWAM | 29 | 24 | 45.6 | 44.2 |
| **ThinkWorld** | **60** | **52** | **94.4** | **93.3** |

해석 (재계산은 `04` C1–C3):

- **차이는 크고 통계적으로 확실합니다.** 전체 112/120 대 72/120(MolmoAct2)이고 Fisher p = 6×10⁻¹⁰입니다. 다만 학습 seed는 1개이고(부록 D), 신뢰구간에는 평가 변동만 들어 있습니다.
- **"ID에서는 비슷하다"(Sec. 4.2)는 수치와 맞지 않습니다.** ThinkWorld는 ID에서도 60/60 대 47/60입니다(p = 1.2×10⁻⁴). 그래서 OOD 우위를 일반화 능력만의 효과로 떼어 읽기 어렵습니다.
- **"기준선이 OOD에서 크게 떨어진다"(Fig. 3 캡션)도 컵 걸기에서는 반대입니다.** MolmoAct2는 73.3% → 93.3%, LaWAM은 60.0% → 80.0%로 OOD에서 오히려 오릅니다.
- **설정별로 보면 MolmoAct2 대비 유의한 곳은 6개 중 3개입니다**(색 맞추기 ID·OOD, 분류 OOD).
- **비교가 목적 함수만의 차이가 아닙니다.**
  - ThinkWorld-YAM은 과제별 미세조정 전에 MolmoAct2-BimanualYAM 데이터로 embodiment 적응(GPU 64장)을 한 번 더 거쳤습니다.
  - 백본도 다릅니다. ThinkWorld는 Qwen3-VL-2B이고, MolmoAct2는 Molmo2-ER 기반입니다.
  - 기준선은 LeRobot의 모델별 레시피로 50k 스텝 학습했습니다.
- **Fig. 1의 막대는 과제별 평균입니다.** ID 100 / OOD 88.9는 Table 6 값을 과제 3개에 대해 평균한 것으로 정확히 재현됩니다.

### 3.3 사람 영상으로 기술 조합 (Fig. 4, 11)

오븐 과제(열기, 닫기, 왼쪽·오른쪽 물체 넣기)에서 로봇 데모는 원자 기술 100개 에피소드만 쓰고, 전체 순서는 사람 영상 90개에만 있습니다. ThinkWorld가 열기 → 왼쪽 넣기 → 닫기를 한 번의 rollout으로 수행하는 정성 결과를 보였습니다. 서랍 과제도 정성 결과만 있습니다. **시행 수, 성공률, 기준선 비교가 없습니다.** 이 사후학습에서 사람 영상은 VLM 미래 예측 손실만으로 학습되고, 행동 손실은 빠집니다(부록 B.3).

## 4. Limitations

### 4.1 저자가 밝힌 한계 (부록 D)
학습 seed가 하나라서 보고된 신뢰구간은 평가 변동만 반영합니다. 지연 시간은 하드웨어와 입력 설정에 따라 달라집니다. 재현성을 위해 시행 분모, 초기화, 학습 설정, 하드웨어를 적었다고 밝힙니다.

### 4.2 분석하면서 추가로 발견한 한계와 의문점

1. **"행동 레이블 없는 영상"으로 학습한다는 핵심 주장이 대규모로 시험되지 않았습니다.**
   - 학습에 쓴 사람 데이터(EgoDex, EgoVerse)는 모두 손목 자세 주석이 있고, 이것이 CoD 정답 토큰이 됩니다(Table 4). RL 데이터도 "Robot + human motion"입니다(Table 5).
   - 그런데 프로젝트 페이지는 "44% egocentric human video, no action labels"라고 씁니다. 주석이 없는 것은 로봇 행동이고, 손 자세 주석은 있습니다.
   - 진짜로 주석 없는 영상을 쓴 것은 실물 기술 조합 사후학습(미래 예측 손실만)뿐이고, 결과는 정성 사례입니다.
2. **배포 시점의 "추론"은 없습니다.** CoD와 미래 예측은 학습 신호입니다. 따라서 성능 이득은 "추론"보다 표현 학습(보조 손실 + 데이터)의 효과로 읽는 편이 정확합니다. Table 3에서 이득의 63%가 미래 예측 보조 손실 하나에서 나옵니다.
3. **RL 보상의 신호 폭이 작고, 자기 모델에 기대어 있습니다.**
   - 보상은 모델 자신의 미래 예측(동결 projector + 갱신되는 VLM)과 실제 미래의 일치도입니다.
   - Eq. 6의 순위 가중치는 상위 10% 변화 패치에 보상의 17%만 줍니다.
   - CoD가 바꾸는 보상 폭은 약 0.03으로, 형식 오류 벌칙 0.05보다 작습니다(`03` §2–3).
   - RL의 기여도 Table 3에서 +1.3%p입니다.
4. **비교 대상 구성이 고르지 않습니다.**
   - 실물 비교는 MolmoAct2, LIBERO 비교는 MolmoAct(이전 버전)입니다.
   - LIBERO-PRO의 MolmoAct 평균은 Environment가 없어 축 4개 평균입니다.
