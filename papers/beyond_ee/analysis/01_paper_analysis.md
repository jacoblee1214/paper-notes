## 1. 문제와 주장

사람은 손이 차 있을 때 팔꿈치와 팔뚝으로 문을 밀거나 서랍을 닫는다. 이것이 Whole-Arm Manipulation(Eberman 1989 [1])이고, 이 논문은 로봇이 **엔드이펙터의 주 작업(컵을 똑바로 들기)을 유지한 채 팔의 다른 링크로 보조 접촉 작업(커피 머신 손잡이 들기)을 하는** 설정을 다룹니다(§1).

저자가 든 어려움 두 가지(§1):

1. 같은 접촉이 링크(팔꿈치, 팔뚝, 위팔)에 따라 영상 관측과 관절 구성이 크게 달라 raw 입력 정책은 링크 사이 전이가 어렵다(로봇 내 일반화 간극).
2. 7-DoF 팔을 같은 접촉으로 원격조종하기는 느리고 직관적이지 않아 리더-팔 또는 외골격이 필요한데, 맨손 시연은 로봇 행동이 없고 사람-로봇 구현 간극이 있다.

주장: WACL은 세 가지 **로봇 비의존** 표현(의미 키포인트, 기준 접촉 궤적, 안전 인지 경로 제약)을 만들고 로봇 기구학은 **마지막 최적화기에만** 넣습니다. 그 결과 (i) 맨손 시연 10개만으로 접촉 궤적을 학습하고, (ii) 새 엔드이펙터 제약은 학습된 구성요소가 아니라 최적화기 입력만 바꾸며, (iii) 구속이 있을 때 링크 포즈 회귀 기준선 KALM보다 성공률이 높다(78% 대 33%, 초록, 표 1).

### 2.2 접촉 궤적 학습 (§3.2, A.1, A.2)

- **데이터 수집(§3.2.1, A.1):** 사람이 맨손으로 과제를 수행하고, 보정된 RGB-D 카메라 C = 3대(장면 카메라 둘과 팔의 손목 카메라, 정지 상태)가 10 Hz로 기록합니다. 시연 10개/과제, 접촉 위치를 의도적으로 다양화합니다. 손끝 속도 임계값으로 접촉 구간을 자동 분할합니다.
- **손 자세 복원:** SAM3로 손을 분할하고 4D 손 추적기 HaPTIC가 MANO 파라미터를 회귀합니다. 단안 추정의 깊이 오차를 줄이려고 각 뷰의 메시를 광축 방향으로 센서 깊이에 맞춰 이동한 뒤, **손끝 정점을 가중 중점 광선 삼각측량**(Hartley-Sturm [46])으로 융합합니다. 뷰별 가중치는 MANO 재투영 실루엣과 SAM3 손 마스크의 IoU입니다.
- **궤적 추출:** 융합한 손끝 궤적을 3차 스플라인으로 고정 길이로 리샘플하고 MANO 표면 법선을 짝지어 T*를 만듭니다. 사람은 손끝으로 접촉하며, 이는 로봇 링크 표면 접촉의 점 대용입니다.
- **정책:** KALM [16]의 조건부 궤적 확산 정책 π_θ(T* | K_obs)를 Diffuser 방식 노이즈 예측으로 학습합니다. 임베딩 256, 궤적 길이 16, 확산 100단계, 100k 반복, 배치 512, AdamW lr 1e-4, 가중치 감쇠 5e-4(A.2). 추론 때 여러 카메라 뷰가 있으면 기준과 키포인트 유사도가 가장 높은 뷰의 궤적을 씁니다.

### 2.3 안전 인지 경로 제약 생성 (§3.3, A.3, A.4)

- 고정된 **두 가지 프리미티브** 어휘: AxisCone(링크 축이 목표 방향의 half-angle α 원뿔 안), PositionRegion(링크 위치가 구 또는 축 정렬 상자 안).
- GPT-5.5 호출 **두 번**: (1) 장면 분해(RGB 한 장 + 과제 문장 → 객체 목록, SAM3 텍스트 프롬프트 앙상블, 접촉 대상), SAM3 분할과 깊이로 OBB를 만들어 장면 상태 S 작성(약 10.9 s + 2.8 s). (2) 제약 인스턴스화(텍스트 입력: 과제, 장면 OBB, FK로 구한 TCP 자세 → YAML 제약 목록, 약 14.7 s). 프롬프트 전문이 그림 4, 5에 있습니다.
- 위반량(식 6, 7): AxisCone은 c_k = [γ(q) − α]_+, γ = arccos(R_ℓ a, a_w), 코사인 도메인 hinge가 아니라 **각도 L1**을 씁니다(경계에서 복원력이 일정하다는 이유, A.3). PositionRegion은 구간 바깥 거리(pseudo-Huber 부드럽게).
- 위반량은 **소프트 비용과 하드 게이트**로 두 번 쓰입니다. 게이트는 정규화한 예산 소모율(γ/α 등)이 1.0을 넘으면 궤적을 버리고(τ_k = 0, 기술된 경계가 곧 안전 사양), 순위 정할 때 남은 예산을 feasibility margin으로 씁니다.

### 2.4 표면 접촉 궤적 최적화 (§3.4, A.5)

결정 변수는 접촉 링크 ℓ(이산), 앵커 u_t(링크 메시 표면, 2D), 관절 q_t(연속)입니다. 연속 최적화는 수렴하지 않아(A.5 "Why not a continuous optimization": 관절 궤적 경사 하강, IPOPT로 푼 삼각형 barycentric softmax 혼합) **샘플-탐색 형식**을 씁니다.

1. **도달 가능 앵커 집합:** 링크 충돌 메시를 최원점 샘플링하고, 인접 링크가 법선 방향 0.05 m 안을 가리는 앵커, 이웃 링크 SDF 안에 마진 −0.002 m로 묻힌 앵커, 볼록 껍질 안쪽 앵커를 제거. 슬라이딩 단계는 부모 앵커 0.03 m 이내에서만 재샘플링.
2. **표면 접촉 IK(식 4):** J_contact = w_pos ‖p(q,u) − p*‖² + w_align [cos θ_dead − ⟨n(q,u), n*⟩]_+ . 법선 정렬은 hinge(죽은 구간 θ_dead)라 위치 3자유도와 법선 2자유도, 즉 5자유도를 고정하고 **법선 축 둘레 롤은 여유(redundancy)**로 남겨 제약에 씁니다. 각 (웨이포인트, 앵커)마다 16개 랜덤 시드. cuRobo 위에 구현(§3.4, A.5).
3. **빔 탐색(식 5):** 폭 B = 20, 빔마다 앵커 후보 32개 → 한 단계에 최대 640개. 단계 비용 J_step = w_Δq ‖Δq‖ + w_slide d_slide + w_manip / μ(q), μ는 Yoshikawa 조작성. 가중치 w_pos = 1e4, w_align = 2e3, w_Δq = 1, w_slide = 10 m⁻¹, w_manip = 2e-3(모든 과제 공통, A.5). 슬라이딩 비용이 크게 잡혀 **앵커는 기본적으로 고정이고 제약 때문에 정지 앵커로 확장이 불가능할 때만 미끄러집니다**(A.5).
4. 링크마다 병렬로 탐색하고 결과를 모아 feasibility margin, 미끄러짐 합, 관절 경로 길이 순으로 정렬. 사전 접촉 자세는 t = 1 법선 방향 후퇴(작은 원뿔 안 샘플), 자유 공간 접근은 cuRobo 경로 최적화, 실패하면 MoveIt RRTConnect.
5. 충돌 버퍼: 슬라이딩 단계에서는 접촉 링크 충돌 구를 음의 버퍼로 줄여 제어된 관통을 허용하고, 나머지 링크는 작은 양의 여유를 줍니다(A.5).

수평선: 본문 §3.1은 T*를 H개 웨이포인트로 정의하지만 정책 궤적 길이는 16(A.2), 탐색 전 다운샘플은 과제별 H = 4(CloseCabinet, PressButton) 또는 8(OpenCoffee, CloseFaucet)(A.5), 한계 절은 "최대 8웨이포인트"(§6)입니다. 같은 기호 H가 두 의미로 쓰입니다.

## 4. 한계

**저자가 쓴 것(§6, 부록 C):**
- 기하 계획이라 힘과 물체 동역학을 모델링하지 않아 계획이 타당해도 미끄러지거나 눌림이 부족·과다할 수 있음.
- 접촉은 한 링크의 한 점. 동시 두 접촉이면 간격이 링크 길이로 정해져 기준 궤적이 로봇 비의존이 아니게 됨.
- 제약 어휘 두 가지, 한 장의 RGB-D 프레임, 개루프, 최대 8웨이포인트, 추론 34.6 s.
- 평가 범위: 고정 베이스 7-DoF 팔 두 대만. 물체 인스턴스는 바꾸지 않고(배치와 홈 자세만) 키포인트·궤적의 새 물체 일반화는 측정하지 않음. 법선 둘레 롤을 단독으로 고정한 실험은 없음. "safety-aware"는 엔드이펙터의 자기 작업 한정이며 사람에 대한 보증 없음.
- 데이터: 맨손 촬영은 시연자의 동의와 식별 정보 제거 없이 공개할 수 없음.

**이 분석에서 추가로 보이는 것은 `analysis/03_analysis.md`와 `analysis/04_claim_verification.md`에 있습니다.** 요점만 적으면:
- 모든 표 숫자는 재계산에서 맞고 내부 일관성도 높습니다(합산, McNemar 쌍 구성, Table 4·5 p 값).
- 약한 곳은 **설계의 교락과 표본 크기**입니다: KALM과의 비교는 표현과 시연 방식(맨손 대 원격조종)과 앵커 탐색 유무가 함께 다르고, 절제 일곱 행은 각 10회라 단독으로는 구분력이 없으며, 학습된 확산 정책의 기여는 ICP 재생(6/10)과 구분되지 않습니다.
