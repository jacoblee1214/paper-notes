# 04. 주장 검증과 구현 가능성: WAM-TTT (arXiv:2607.06988)

공식 코드가 없어(2026-11-26 확인) 코드 대조 대신 **논문의 주장 C1–C20**을 표·본문·부록과 대조합니다. 수치는 `03`의 재계산(V, K)에 기대고, 이 문서는 그 결과와 서술이 맞는지를 판정합니다.

## 1. 공개 자료 현황

- **공식 코드:** 찾지 못했습니다. 논문 본문과 프로젝트 페이지에 코드 링크가 없고, 프로젝트 페이지 저장소(WAM-TTT/WAM-TTT.github.io, HTML)가 저자 계정의 유일한 저장소입니다. 동명·유사 저장소 둘은 이 논문의 구현으로 확인되지 않았습니다(`02` §2).
- **체크포인트, 데이터:** 확인하지 못했습니다. 메타 학습 데이터(2,286쌍)와 평가 영상은 프로젝트 페이지의 영상 외에 공개된 곳을 찾지 못했습니다.
- **백본 LDA-1B**는 공개되어 있습니다(코드, 체크포인트, 16층 MMDiT 구성). 라이선스는 LICENSE 파일 기준 CC BY-NC 4.0이고 README 배지는 MIT로 달라 사용 전에 확인이 필요합니다.
- **TTT 층의 참고 구현**(Spatial-TTT)이 Apache-2.0으로 공개되어 있습니다. 이 논문의 층이 그 연산과 같은지는 본문에 없습니다.

## 3. 재현에 필요하지만 본문에 없는 것

1. TTT 가지를 붙이는 블록의 수와 위치, f_W의 구조(활성화, 헤드별 분리 여부, 폭 128이 어디에 쓰이는지), 고속 가중치의 총 크기.
2. 고속 가중치 갱신 규칙의 정확한 형태(식 3의 MSE인지, 인용한 층처럼 per-token 학습률, L2 정규화를 쓰는지), 초기 W_init의 크기.
3. 시험 시 사람 영상의 개수 |B_h|, 길이, 프레임 수, 어떤 노이즈 수준·확산 시각으로 L_vg를 평가하는지, 적응 소요 시간.
4. WAM-ICL이 문맥으로 받는 영상 수와 프레임 수, LDA·π0.5·EgoScale 기준선이 어떤 로봇 데이터로 미세조정되었는지.
5. WAM-Cotrain과 WAM-TTT의 학습 예산 대응(스텝, 데이터 혼합 비율).
6. 표 2와 4의 시행 수, 표 C.1 일부 칸의 시행 수와 채점 규칙(`03` §3).
7. 표 E.1에서 (r, h) = (100, 100)의 정의와 2,286쌍과의 관계, (200,0)과 (100,0)에서의 시험 시 적응 방식.
8. 데이터·가중치·평가 코드 공개 여부.

## 4. 구현 가능성 판정 ("구현할 수 있는지")

기준 기기: Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음. 공식 코드가 없고 정의가 비어 있는 부분이 많습니다(§3).

| 수준 | 판정 | 근거 |
|---|---|---|
| 논문 수치(표 1, C.1, 3, 4)의 재현 | **불가** | 로봇 세 기체(Unitree G1, Galbot gripper·sharpa)와 9과제 × 25회 평가, 2,286쌍 데이터, 공식 코드·체크포인트 없음 |

| 백본 LDA-1B 추론 | 조건부, 어려움 | 체크포인트 다운로드, flash-attn 등 CUDA 의존 설치, 코드 실행 승인 필요. 이 논문의 TTT 층은 없음 |

| **구조 재구현** (소형 MMDiT + 비디오 쪽 고속 가중치 + 메타 학습 + 사람 영상 한 단계 갱신) | **가능** | torch 2.15는 설치되어 있어 새 설치 없이 시작. 합성 과제나 MuJoCo 소형 과제의 "사람 영상" 대체물로 측정. 노력 추정 2–3주(추정, 측정 전) |

| 표 수치 재계산·일관성 검사 | **가능, 완료** | `analysis/recompute.py`(수 초) |

## 5. 저자에게 물을 질문

1. 표 C.1과 표 3, E.1의 일부 칸 값이 부록 D의 25회(또는 10회) 격자와 맞지 않습니다. 칸별 시행 수와 채점 규칙, 표 3 Swap Place 열의 설정(Orig/New)은 무엇입니까?

5. 불일치하는 사람 영상(다른 과제, 다른 전략)을 넣었을 때 로봇 행동이 어떻게 달라집니까?
6. 식 6의 λΣL_KVM 항은 v3에서 추가되었습니다. 표 1의 결과는 어느 목적으로 학습한 모델입니까?
