# Qwen-RobotWorld 수치 재계산과 일관성 검사

재계산 스크립트: `analysis/recompute.py` → `analysis/recompute_results.json` (수 초, CPU). 표 값은 `paper/paper.pdf` v3의 `pdftotext -layout` 결과를 직접 옮겼고, 표 2는 layout 추출과 한 줄씩 대조했습니다.

## 0. 먼저 알아 둘 것: 신뢰구간과 유의성 검정은 할 수 없습니다

논문은 벤치마크 점수의 평균이나 표준편차, 샘플별 점수, 시도 횟수를 보고하지 않습니다. EWMBench는 21개 샘플, WorldModelBench는 350개 인스턴스이고, DreamGen Bench와 PBench의 샘플 수는 본문에 없습니다. 따라서 Welch나 Fisher 검정, 부트스트랩 신뢰구간은 계산할 수 없습니다. 대신 (1) 보고된 합계를 구성 항목에서 다시 더하고, (2) 1위와의 차이를 계산하고, (3) 본문 서술과 표를 대조했습니다.

## 3. 본문과 표의 일관성

1. **"네 범주에서 완전 일치 (1.00)"**: 표 5에서 Newton, Mass, Fluid, Gravity는 1.00입니다. Penetration은 0.94로, 본문 §5.1.4 문장은 네 범주를 명시하지만 초록과 서론에는 이 제한이 빠져 있습니다. 표와 모순은 아니지만 서술이 선택적입니다.
2. **"Common-sense 격차는 낮은 해상도 때문"** (§5.1.4): 표 5에서 Frame 0.87, Temp 0.85는 Veo3(0.98, 0.95), Cosmos(1.00, 0.94)보다 낮습니다. 해상도 실험이 없으므로 원인은 검증되지 않았습니다.
3. **PBench "Aesthetic과 Imaging이 낮다"** (§5.1.3): Aes 0.455는 기준선 중 최저(Sora2 0.487, Cosmos 0.470보다 낮음)이고, Img 0.649는 Veo3 0.698보다 낮습니다. 역시 해상도 설명은 검증되지 않았습니다.
4. **EWMBench "Logics 최고"**: 1.0000은 Wan2.6, Kling26과 공동 1위입니다. 본문 "top performance in logic constraint satisfaction"은 공동 1위를 명시하지 않습니다.
5. **EWMBench Diversity**: Ours 0.0114는 LVP 0.0093보다 높지만 Cosmos 0.0803, Vidar 0.0653보다 낮습니다. 본문은 다양성을 언급하지 않습니다.
6. **DreamGen Bench**: GR1-Object IF 1위(0.878)는 본문과 일치합니다. 그러나 GR1-Env IF에서는 GigaWorld(0.933)가 가장 높다는 점은 빠져 있습니다.
7. **WMB 350 인스턴스 대 PBench, DreamGen**: 샘플 수가 다른 벤치마크의 점수를 같은 "우위" 문장으로 묶고 있습니다.

## 4. 학습과 평가 설정의 정보 부족 (재계산 불가 항목)

- 학습 스텝, 배치, 학습률, GPU 수, 총 학습 시간: 없음.
- 생성 해상도, 프레임 수, 샘플링 스텝, CFG 값: 없음(PBench 본문에 "낮은 출력 해상도"라고만 적음).
- 기준선의 생성 설정(해상도, 길이, 샘플러, 시드): 없음. 표는 기준선마다 같은 조건이라고 명시하지 않습니다.
- 평가 판정기: DreamGen IF는 Qwen2.5-VL, PBench Domain은 Qwen2.5-VL QA 기반입니다(§5.1.2–3). 판정기가 Qwen 계열이므로 자체 모델에 유리할 수 있습니다. 판정기를 바꾼 대조 실험이 없습니다.

## 5. 결론

- 합계와 순위 주장 대부분은 보고된 항목으로 다시 계산해도 맞습니다. 예외는 **EWMBench LTX-2 행 1건**입니다.
- 가장 가까운 경쟁자와의 차이가 0.002(PBench)인 주장은 근거가 약합니다.
- 통계적 유의성은 샘플 수와 분산이 없어 판단할 수 없습니다. 따라서 "1위"는 점수상의 순서일 뿐, 신뢰할 수 있는 우위로 쓰면 안 됩니다.
- 로봇 제어 성능은 이 수치에서 나오지 않습니다.

## 6. 재현하지 않은 것

- 모델 학습, 샘플 생성, 공식 평가 스크립트 실행은 하지 않았습니다. 코드와 가중치가 공개되지 않았습니다(02 §4).
- CPU 토이 실험은 하지 않았습니다. 논문 핵심 주장(인덱스 기반 다중 구간 조건)을 CPU에서 검사할 만한 작은 모델 설정이 논문에 없어서, 억지로 만들지 않았습니다.
