## 2. 실물 (Table V 없음, 본문과 그림 값)

논문은 실물 결과를 과제당 50회로 보고합니다. Lift Pot은 전체 성공만, Close Marker와 Plate Handover는 전체 성공과 절반 성공을 함께 씁니다. 절반 성공은 저자가 과제마다 정의한 중간 단계입니다(Close: 두 물체 파지 후 삽입 실패, Plate: 들어 올린 후 전달 실패).

| 과제 | 기준 전체 | UVT 전체 | 기준 절반 | UVT 절반 | 기준 점수 | UVT 점수 | Fisher p (전체) | Holm p (전체, 3개) | Mann–Whitney p (점수) |
|---|---|---|---|---|---|---|---|---|---|
| Lift Pot | 19/50 (38%) | 27/50 (54%) | — | — | 38% | 54% | 0.16 | 0.32 | — (전체만) |
| Close Marker | 0/50 (0%) | 5/50 (10%) | 0 | 28 | 0% | 38% | 0.056 | 0.17 | 5e-12 |
| Plate Handover | 7/50 (14%) | 12/50 (24%) | 4 | 16 | 18% | 40% | 0.31 | 0.32 | 0.0019 |

Wilson 95% 구간(전체 성공): Lift Pot 기준 26–52%, UVT 40–67%. Close Marker 기준 0–7%, UVT 4–21%. Plate 기준 7–26%, UVT 14–37%.

**다중 과제 검정:** Mantel–Haenszel 공통 오즈비(UVT 대 기준)는 약 2.28입니다(연속성 보정 카이제곱 6.36, p = 0.012). 이것은 세 과제의 전체 성공을 같은 오즈비로 본다는 가정이 필요합니다. 과제마다 난이도가 다르므로 이 p값은 참고용입니다. 풀링한 단순 Fisher(26/150 대 44/150)는 p = 0.020입니다.

**검출력:** 과제당 50회, 두 팔, 양측 5%, 검출력 80%에서 최소 검출 차이(MDE)는 기준 성공률 20%에서 22pp, 40%에서 27pp, 50%에서 28pp입니다(`table_check.py`의 근사식). 논문의 과제별 차이(10–16pp, 전체 성공 기준)는 모두 이 MDE보다 작습니다. 즉 **과제 하나로는 효과가 있어도 검출하기 어려운 설계**입니다.

**해석:**
1. 과제별 전체 성공 차이는 어느 것도 Holm 보정 후 유의하지 않습니다. 논문 본문의 "substantially improves grasping reliability"는 과제별로 과장된 표현입니다.
2. 점수(절반 성공 포함)의 Mann–Whitney 검정은 Close Marker와 Plate에서 유의합니다. 그러나 이 검정은 **저자가 절반 성공을 사후에 정의한 것**에 의존합니다. Lift Pot에는 점수가 없고, 절반 성공 정의가 바뀌면 결론이 바뀔 수 있습니다(연구자 자유도).
3. 전체 성공만 보면 세 과제 CMH에서 p = 0.012로 유의하지만, 과제 수와 샘플 수가 작고 한 번의 실험(시드 1개, 한 로봇)입니다.
4. 시행 간 상관(같은 물체 배치, 같은 시간대의 하드웨어 상태)은 고려하지 않았습니다.

**판정:** "실물 개선"은 **방향은 일관되지만 과제별로 통계적으로 확인되지 않습니다.** 합산 검정은 시험 설계(과제 묶음, 절반 성공 정의)에 따라 달라집니다.

## 3. 유도 (정밀도 가중 PoE)

**(a) 융합 평균은 볼록 결합입니다.** 행동과 LAM 각각의 정밀도 T_a = α_a/σ_a², T_z = α_z/σ_z²에 대해

μ_u = (T_a μ_a + T_z μ_z)/(T_a + T_z) = w μ_a + (1 − w) μ_z, 여기서 w = T_a/(T_a + T_z).

따라서 α를 같은 배수로 키워도 w는 바뀌지 않습니다(α의 절대 크기는 의미가 없고 비율 α_a/α_z만 의미가 있음).

**(b) 초기 가중치.** 코드의 초기값(로그분산 −2와 +1, α = 1)에서 σ_a² = e^{−2} ≈ 0.135, σ_z² = e ≈ 2.718이므로 w = 7.39/(7.39 + 0.368) ≈ 0.953입니다. 학습 전의 목표는 행동 평균 95%와 동역학 평균 5%의 혼합입니다. 학습 후 w는 보고되지 않았습니다.

**(c) 동역학 정보의 두 경로.** 동역학 정보가 u에 들어가는 길은 두 가지입니다.
- 경로 1: PoE 가중치 (1 − w). 초기에는 작습니다.
- 경로 2: LAM 디코더 손실 L_DYN. u에서 z를 복원하도록 강제하므로, w가 작아도 u의 방향이 z 정보를 담게 됩니다. 이 경로의 크기는 λ_z(코드에서 0.5)에 따라 달라집니다.
따라서 "동역학 신호의 효과"를 보려면 경로 2를 끊는 대조(CE 제거)가 필요합니다.

**(d) KL 항.** 융합 후 분포 N(μ_u, σ_u²)에 대한 KL은 표준 VAE의 닫힌 형태를 씁니다. β = 0.01이므로 목표의 분산 정규화는 약합니다. 논문의 가중치 1(β 없음)과 다릅니다(`04` D3).

**(e) 목표 공간의 스케일.** L1 행동 손실은 56차원 평균이고 CE는 4개 코드 평균입니다. 두 항의 상대 크기는 λ_z에 의해 정해집니다. 논문의 식처럼 합으로 쓰면 행동 항이 56배 커지므로, 어느 쪽인지에 따라 동역학의 상대 기여가 크게 달라집니다.

## 5. 계산량과 데이터 공평성

- 논문은 "추가 데이터와 연산 없음"을 주장합니다. 그러나 (a) LAM 사전학습(외부 영상 데이터와 GPU 시간)은 계산에 빠져 있습니다. (b) MVAE 학습과 LAM 추론, 목표 사전계산은 추가 단계입니다. 이것들은 크지 않을 것으로 보이지만(MVAE 약 31만 파라미터, `04` §8), 논문이 수치로 밝히지 않았습니다. (c) 기준 헤드와 UVT 헤드의 파라미터 수 비교가 없습니다. 공식 코드의 UVT 헤드는 잔차 블록이 24개인 MLP입니다(`04` D16). 기준 회귀 헤드와 크기가 같은지 확인되지 않았습니다.
- 학습 예산은 같은 스텝 수와 같은 배치로 맞췄다고 합니다(§IV-A-d). 그러나 코드에서 VLA 학습은 시드를 고정하지 않으므로, 같은 설정을 두 번 돌려도 다른 결과가 나올 수 있습니다(`04` D15).
- 논문은 실물에서 "같은 파인튜닝 예산"을 말합니다(§IV-D). 그러나 실물 기준선의 학습 스텝과 데이터 양(과제당 시연 30회)은 같지만, LAM 사전학습 데이터가 실물 과제와 겹치는지는 밝히지 않았습니다.

## 6. 선형 toy: 공동 목표가 행동 정확도를 올리는 조건

### 6.1 설정

- x ∈ R^20, 행동 신호 a* = W x (순위 q = 4), 관측 행동 a = a* + σ_a ε (σ_a = 1, ε는 x와 무관한 운동 잡음), 행동 차원 k = 12.
- 동역학 코드 d = √ρ S x + √(1−ρ) ξ, S는 행동 신호와 같은 부분공간의 단위분산 사상, m = 6. 따라서 R²(d | x) = ρ.
- 목표 세 가지(모두 절편 있는 선형 OLS로 x → 목표를 맞춤): (F) 행동 전체(압축 없음), (A_r) 행동만 PCA r차원, (J_r) [행동; 동역학]을 블록 스케일링 후 PCA r차원. 디코더는 PCA 사영의 전치(고정)입니다. 논문은 디코더를 학습하지만 선형 toy에서는 같은 구조로 둡니다.
- 평가: 테스트 x 4000개에서 ‖â − a*‖²의 평균. 시드 30개.
- 같은 시드에서 x와 ε와 ξ는 모든 ρ에서 같습니다. 따라서 **동역학 고유 이득 = MSE(J_r, ρ = 0) − MSE(J_r, ρ)**는 "같은 차원의 예측 불가능한 블록"과의 짝비교입니다. 이 값이 목표 구성 효과(잡음 블록이 주는 효과)를 뺀 순수 동역학 효과입니다.

### 6.2 결과 (선택)

| n | ρ | F MSE | r = 2: A−J / 동역학 고유 | r = 4: A−J / 동역학 고유 | r = 6: A−J / 동역학 고유 |
|---|---|---|---|---|---|
| 30 | 0 | 2.71 | −0.065 / 0 | +0.077 / 0 | +0.373 / 0 |
| 30 | 0.95 | 2.71 | +0.234 / +0.298 | +0.630 / +0.553 | +0.452 / +0.079 |
| 60 | 0 | 0.55 | −0.016 / 0 | −0.067 / 0 | +0.061 / 0 |
| 60 | 0.95 | 0.55 | −0.005 / +0.011 | +0.101 / +0.168 | +0.084 / +0.023 |
| 200 | 0 | 0.118 | −0.001 / 0 | −0.049 / 0 | +0.001 / 0 |
| 200 | 0.95 | 0.118 | −0.064 / −0.063 | +0.016 / +0.065 | +0.014 / +0.013 |

(A−J는 A 대 J의 MSE 차이로 양수면 J가 좋음. 표준오차는 `uvt_toy_results.json`에 있음. 중앙값 0.008, 최대 0.054. r = 1, 3과 n = 30의 ρ = 0.25, 0.5는 생략)

**검증:**
- r = k + m(압축 없음)에서 J의 행동 예측은 F와 같습니다(최대 차이 3×10^-14). 선형 OLS는 목표를 가역 선형 변환해도 예측이 같으므로 **압축이 없으면 보조 목표는 아무 효과가 없습니다.** 따라서 논문 같은 이득은 전적으로 병목과 디코더에서 나와야 합니다.

**결과 해석:**
1. **동역학 고유 이득은 r이 신호 차원(4) 이상일 때 양수입니다**(n = 60, 200). r < 4에서는 n = 200에서 음수입니다. 즉 병목이 신호보다 좁으면 동역학 방향이 신호 방향을 밀어냅니다.
2. **데이터가 적으면(n = 30) r에 상관없이 동역학이 도움이 됩니다.** 보조 목표가 정규화 역할을 하는 것으로 보입니다.
3. **목표 구성 효과가 동역학 효과와 같은 크기일 수 있습니다.** n = 30, r = 6에서 ρ = 0(순수 잡음 블록)의 A−J는 +0.373입니다. 동역학 고유 이득(+0.079)보다 훨씬 큽니다. 즉 "32차원 목표가 더 낫다"는 관찰만으로는 동역학 정보 때문인지 목표 구성 때문인지 구분되지 않습니다. 잡음 블록 대조가 필수입니다.
4. **예측도 ρ의 효과는 단조적입니다.** 같은 r과 n에서 ρ가 커질수록 동역학 고유 이득이 커집니다(r = 4, n = 60: 0.128 → 0.168).

### 6.3 toy의 한계

- 선형 모형이고 디코더를 학습하지 않았습니다. 논문의 MLP 디코더와 학습된 디코더는 다른 결과를 낼 수 있습니다.
- 동역학 신호가 행동 신호와 같은 부분공간에 있다고 가정했습니다(S가 W의 행공간 안). 동역학이 행동과 직교하면 이득이 사라지거나 음수가 될 수 있는데, 이 경우는 테스트하지 않았습니다.
- LAM 코드는 이산 16진 코드 4개인데, toy는 연속 벡터 6차원으로 대체했습니다.
- 블록 스케일은 "평균 분산 1"로 맞췄습니다. 논문은 학습된 α로 블록 가중치를 정하므로 최적 스케일이 다를 수 있습니다.

**toy가 말하는 것:** 공동 목표가 도움이 되는 조건은 (i) 병목이 신호 차원 이상이고, (ii) 동역학이 관측으로부터 예측 가능하며, (iii) 데이터가 충분할 때입니다. 그러나 이 조건은 선형 toy의 결과입니다. 실제 LIBERO에서 이것이 맞는지는 행동 전용 32차원 대조로만 확인할 수 있습니다.
