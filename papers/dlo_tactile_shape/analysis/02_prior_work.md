# 02. 선행연구, 공식 코드, 이 저장소의 관련 분석

## 1. 선행연구 계보 (논문 참고문헌 기준)

논문이 직접 인용한 흐름을 세 갈래로 나눴습니다. 번호는 논문의 참고문헌 번호입니다.

**(a) DLO 형상 추정: 시각과 점군.**
- 점군 등록과 물리 시뮬레이션 결합 [5] (Tang 외, 2017).
- 단일 프레임의 가려진 점군에서 3D 상태 학습 [6] (Lv 외, 2023), 분할에서 재구성 [7] (2024), 부분 관측에서 생성 모델로 3D 상태 추정 [8] (Tang 외, 2026).
- 가림과 움직임 일관성을 쓰는 추적 [9] (TrackDLO, 2023).

**(b) 힘과 토크 기반 추정: 논문이 가장 가깝다고 보는 계열.**
- Bretl과 McCarthy [10] (2014): 키르히호프 탄성 막대의 평형 구성 공간은 6차원 매끄러운 다양체라는 이론적 바탕.
- Mishani와 Sintov [11] (2022): F/T 센서만으로 실시간 형상 추정과 제어(저자 소속 그룹의 선행 연구).
- Mishani와 Sintov [12] (2023): 학습 기반 와이어 형상 추정과 계획.
- 논문의 비판: 해석 모델은 재료 불균일과 제조 편차를 다루지 못하고, 고정 장착과 직선 이완 상태를 가정합니다.

**(c) 촉각 센서와 케이블.**
- 광학 촉각 센서: GelSight [13], DIGIT [14], AllSight [15] (저자 그룹 Azulay 외, 2024).
- 케이블과 촉각: 촉각 반응 그리퍼로 케이블 조작 [17] (She 외, 2021), 촉각 기반 배선 조립 [18] (Wilson 외, 2023), 손가락 촉각으로 in-hand 추종 [19] (Yu 외, 2024), 촉각으로 파지한 부분의 형상 재구성 [20] (Monguzzi 외, 2023).
- 촉각 표현 학습: Sparsh [21] (Higuera 외, CoRL 2024), 이 논문의 인코더 기반입니다.
- 물리 손실의 바탕: 이산 탄성 막대(DER) [22] (Bergou 외, 2008). 이 논문의 `L_weighted`는 DER의 접선, 길이, 곡률 이항 벡터를 쓴 지도 학습 손실입니다.
- 그래프 동역학으로 DLO 형상 제어 [23] (Gu 외, 2025).

**논문이 놓은 자리.** 시각을 쓰지 않는 전역 형상 추정입니다. 논문은 촉각 기반 DLO 추정이 광학 촉각 센서로 접촉 바깥의 전역 형상까지 확장된 첫 사례라고 주장합니다(§I). 이 주장은 참고문헌 검색으로 검증하지 않았습니다. 기여 범위는 "저자들이 아는 한"이라는 단서가 붙어 있습니다.

## 2. 가까운 대안과 비교 기준선

| 대안 | 논문의 비교 | 비고 |
|---|---|---|
| 자세만 쓰는 MLP | Pose-Only, 55 mm | 하한선 |
| 자세와 접촉 방향 | Pose + Direction, 50.6 mm | 촉각 방향을 규칙 기반으로 추출 |
| 무작위 초기화 ResNet-18 교차 주의 | 36.0 mm | 사전학습 Sparsh 대신 일반 시각 특징 |
| 제안 모델에서 B-spline 제거 | 35.0 mm | 출력이 K개 정점 직접 |
| 제안 모델에서 L_weighted 제거 | 37.0 mm | 위치와 Chamfer만 |

논문에 없는 대안: DER 해석 추정(논문은 경계 조건이 관측되지 않아 부적합하다고 씀), 시각 기반 DLO 추적(같은 실험 세팅이 없어 비교하지 않음), 저자 그룹의 F/T 방법 [11][12]과의 직접 비교(없음).

**라이선스 함의.** 공식 저장소의 MIT는 저장소 자체 코드에만 적용됩니다. 사전학습 Sparsh 가중치는 비상업 조건이라서 상업적 이용은 Sparsh 조건의 제약을 받습니다(저장소 README의 License 절). 이 점은 재사용 판단에 중요합니다.

**인용 메타데이터.** `CITATION.cff`의 상태는 `submitted`이고 학회와 DOI는 없습니다. 저장소 README는 "논문은 심사 중"이라고 씁니다.
