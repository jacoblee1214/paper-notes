## 2. 가까운 대안과 차이

- **PointWorld [18].** 3D 점 흐름으로 대규모 데이터에서 학습합니다. 이 논문은 "사람과 여러 손을 같은 파티클 행동 공간에 넣는 것"을 차별점으로 씁니다(v3 II-B 마지막 문장). 두 논문은 같은 주제(점 기반 세계 모델)지만 행동 표현과 데이터가 다릅니다. 직접 비교 실험은 없습니다.
- **Hong et al. [17].** 사람–물체 파티클 모델을 정책 탐색에만 쓰고, 그 정확도가 직접 제어에는 부족했다고 v1에서 적었습니다(v1 II-B). v3는 같은 문장을 줄였습니다.
- **Ai et al. [3] 스케일링.** 이 논문 Q1의 설계 근거입니다. 다만 보행 정책 학습과 달리 여기서는 세계 모델의 **예측 오차**를 봅니다.
- **Point Transformer [58].** 같은 입출력을 쓰는 가장 가까운 대조군입니다. 이 논문에서 PT는 GNN보다 구현체 수 증가에 덜 반응하고, 저자는 그 이유를 GNN의 귀납 편향으로 봅니다(IV-B).

## 3. 이 저장소의 다른 논문과의 관계

이 논문의 핵심(교차 손 전이, 손 파티클 표현, 세계 모델 + MPC)과 같은 축에 있는 폴더입니다. 각 README 첫 단락을 기준으로 정리했습니다. 수치를 이 논문과 직접 비교한 것은 아닙니다.

| 폴더 | 무엇을 하나 | 이 논문과의 관계 |
|---|---|---|
| `flashdexretarget/` | 사람 손 시연 → 로봇손(XHand, Sharpa Wave) 궤적 리타겟팅(강화학습 정책) | 교차 손 전이의 **다른 해법**: 리타겟팅 대 이 논문의 "행동을 파티클 변위로 바꿔 세계 모델에 그대로 넣기". 이 논문은 리타겟팅을 하지 않는다고 명시(v3 I절) |
| `gnr/` | 리타겟팅 궤적을 기준으로 잔차를 flow matching으로 생성 (Tesollo DG-5F) | 같은 문제(사람 → 로봇손)를 생성 모델로 풀이. 이 논문 입장에서는 "리타겟팅 + 정책" 기준선의 후보 |
| `chord/` | 사람 접촉점과 법선에서 마찰원뿔 기반 보상으로 다지 손 조작 RL | 접촉 기하를 명시적으로 쓰는 방법. 이 논문의 "파티클이 접촉 기하를 담는다"와 대비 |
| `lightning_grasp/`, `mana/` | 손의 접촉 가능 집합(BVH), 절차적 파지 키프레임으로 파지·도구 조작 데이터 생성 | 파지 데이터 생성. 이 논문의 무작위 상호작용 데이터 수집과 대비되는 "구조화된 데이터" |
| `eigendexplore/` | 리타겟된 PCA 방향을 행동이 아니라 탐색 잡음에 넣기 | 사람 동작의 저차원 구조를 쓴다는 점이 이 논문의 모션 프리미티브(III-D, [12])와 가까움 |
| `openwam/`, `agentic_wam/` | 영상·행동 결합 World-Action Model | 세계 모델의 다른 표현(영상 대 파티클). 교차 구현체 주장은 없음 |
| `dexpolicy/` | ViViDex 강화학습 탐색 잡음 스케줄 | 이 논문과 직접 관계는 약함. 사람 영상 기반 손 정책의 하위 기법 |

## 5. 가장 가까운 대안을 고르는 기준

- 교차 손 **행동 전이**: 리타겟팅 + 정책(`flashdexretarget/`, `gnr/`), 이 논문의 "파티클 세계 모델 + MPC". 같은 목적에 방법이 다릅니다.
- 세계 모델 **표현**: 파티클(이 논문, PointWorld, RoboPack), 영상(`openwam/`, `agentic_wam/`). 교차 구현체 전이를 주장하는 것은 파티클 쪽뿐입니다.
- 기준선을 고르려면 이 논문에 없는 항목(리타겟팅 + 정책, 손별 모델의 데이터 맞춤)을 직접 구성해야 합니다. 이 점은 `03_analysis.md`에서 다룹니다.
