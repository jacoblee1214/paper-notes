## 2. 불일치와 주의할 점

1. **Fig. 3과 Table 3의 지연이 다른 측정입니다.** Fig. 3의 종합 속도비 Fast 4.21×(393.83 → 93.51 ms), Faster 3.11×(283.65 → 91.34 ms), Joint 3.06×(663.53 → 216.65 ms)는 Table 3 기반 값(4.28×, 3.13×, 3.13×)과 다릅니다. 측정 프로토콜(Fig. 3는 30회, 표는 평가 로그)이 다른 것으로 보입니다. 본문은 둘을 구분해 적지 않습니다.
2. **성공률 차이는 대부분 검출 한계 안입니다.** 아래 §3.
3. **Joint-WAM LIBERO 평균은 Vanilla보다 낮습니다.** 98.00 대 98.35 (−0.35 pp). 본문은 "comparable"이라고 씁니다. 맞는 표현이지만 "약간 낮음"을 밝히지는 않았습니다.
4. **Vanilla보다 높은 정확도의 해석.** 표 6에서 ε = 10⁻³(가장 엄격)에서도 Joint 66.73, Fast 50.63, Faster 74.78로 세 모델이 모두 Vanilla(66.43, 50.17, 74.52)보다 높습니다. ε가 0에 가까워지면 Euler 정확해에 가까워져야 하는데, 그 차이가 나머지 오차인지 시드 변동인지 본문은 구분하지 않습니다. 시드 변동은 보고하지 않았습니다.

## 3. 신뢰구간과 검정

## 4. 제거 실험과 기준선의 관계

Table 4의 "neither" 행 = FlowCast 행(§1). 따라서 제거 실험의 분해는 "FlowCast에서 출발해 RAVS와 TSAV를 더했을 때의 변화"입니다. 이 해석은 맞습니다. 다만 FlowCast 구현이 원저자 코드인지 저자 재구현인지는 적혀 있지 않습니다. 재구현이라면 FlowCast의 성능 자체가 과소평가되었을 수 있습니다.

TSAV 단독과 RAVS 단독의 지연 변화(RAVS는 거의 0, TSAV는 −7–11%)는 기여가 서로 다른 방향이라는 것을 보여 줍니다. 그러나 두 구성 요소 중 하나만 쓴 경우의 정확도 이득(+1.05 ~ +1.52 pp)은 §3의 검출 한계(약 1.2–1.4 pp) 안에 있습니다. 제거 실험의 정확도 차이는 검출되지 않았다고 보는 것이 맞습니다.

## 5. 메커니즘 점검: 토이 흐름 모델

`analysis/toy_speculative.py`: 16차원 상태, 은닉 64, 고정 난수 MLP 속도장, Shift-5 스케줄, N = 10, 창 w = 10, 20 시드. 호출 수는 배치 검증을 1회로 셉니다.

| 방식 | ε | 평균 최종 오차 | 평균 호출 수 |
|---|---|---|---|
| 균일 MSE | 10⁻³ | 0.00147 | 9.2 |
| 균일 MSE | 10⁻² | 0.0303 | 6.7 |
| 균일 MSE | 5×10⁻² | 0.150 | 4.6 |
| TSAV | 10⁻³ | 0.00828 | 7.7 |
| TSAV | 10⁻² | 0.0675 | 5.05 |
| TSAV | 5×10⁻² | 0.177 | 3.7 |

같은 ε에서 TSAV는 호출을 더 아끼지만 오차는 더 큽니다. 같은 호출 수에서 비교하면 결과가 다릅니다. 호출 약 7–8에서 TSAV(ε=10⁻³, 0.0083, 7.7회)는 균일(ε=10⁻², 0.0303, 6.7회)보다 오차가 작습니다. 호출 약 5에서는 TSAV(ε=10⁻², 0.0675, 5.05회)가 균일(ε=5×10⁻², 0.150, 4.6회)보다 작습니다. 즉 이 토이에서 TSAV는 **같은 계산량 대비 오차 경계를 개선하는 방향**입니다(그림 `report/figures/own_toy_frontier.png`). 다만 한 가지 모델과 한 가지 스케줄, 20 시드의 결과입니다. 이것이 LIBERO에서도 성립한다는 증거는 아닙니다.

토이로 확인된 것: (a) 스케줄 불균일에서 가중 검증이 균일 검증보다 같은 계산량에서 유리할 수 있다는 점. 확인되지 않은 것: 정리 4.5의 상수, Lipschitz 가정의 성립, 실제 WAM의 속도장 특성.
