## 2. 방법 (§3, 부록 A–E)

**학습 루프 (§3.1, Fig 2, Algorithm A.1).** 세 단계를 한 루프에서 번갈아 한다. (1) 현재 정책이 시뮬레이터에서 전이를 모아 고정 크기 버퍼 B에 넣는다. (2) world model을 버퍼의 k=8 스텝 창에 맞춘다. (3) 고정된 world model 위에서 H=32 스텝 상상 롤아웃을 만들고, 그 반환을 정책에 BPTT로 역전파한다. 롤아웃의 시작 상태는 버퍼에서 뽑는다(Dyna 방식).

**world model (§3.2, 식 1).**

- 동역학 ŝ_{t+1} = f_ω(ŝ_t, a_t, ξ), 보상 r̂ = r_ω(·), 관측 ō = g_ω(·), 종료 d̂ = d_ω(·). 각 head는 학습되거나 해석적으로 계산됩니다(§3.2 본문). ξ는 에피소드별 시뮬레이터 문맥(마찰, 관절 보정 오프셋, 몸통 질량중심 오프셋)입니다.
- 손실 식 (1): k 스텝 자기회귀 창에서 상태 제곱오차 + 보상 제곱오차 + 관측 제곱오차 + 종료 BCE의 합. 해석적 head에는 손실 항이 없습니다.
- world model은 결정론적입니다. 시뮬레이터의 무작위성은 알려진 출처이므로 ξ와 센서 잡음 η_t로 분리합니다.

**정책 기울기 (§3.3, 식 2, 3).**

- 목적 식 (2): 상상 롤아웃의 할인 반환 Σ_t γ^t ĉ_t r̂_{t+1} + γ^H ĉ_H V_ψ(ŝ_H, g_H, ξ). ĉ는 생존 가중치로, 종료 확률 d̂로 미분 가능하게 만듭니다.
- 기울기: ∇_θ Ĵ는 world model의 자코비안으로 H 스텝을 통과합니다(BPTT). 저자는 PPO의 우도비 추정량보다 "분산이 훨씬 작다"고 주장합니다(§3.3 본문, 이 주장은 `03` §2의 토이 S로 확인).
- 비평가 V_ψ는 상상 궤적 위의 GAE 목표(식 3)로 학습되고, 목표 네트워크(EMA)는 없습니다. 비평가가 H 바깥의 반환을 맡아서 H=16–32로도 학습이 됩니다(§4.3, Fig 4bc).

**모션 추적 보상과 종료 (부록 A).** BeyondMimic의 추적 보상(Table A.2)에서 자기충돌 항을 빼고, 관절 한계 가중치를 −10에서 −2로 낮춥니다. 종료 조건은 루트 높이 편차 |e_z| > 0.25 m 또는 기울기 오차 e_tilt > 0.8입니다. e_tilt = 0.8은 약 78.5°에 해당합니다(계산은 `analysis/recompute.py`). 손끝 편차 종료는 없습니다.

**데이터와 설정 (부록 D, E).** BONES-SEED 공개 부분(G1 리타게팅)에서 142,220개 클립을 이름 필터(12,553개 제외)와 실현 가능성 필터(153개 제외)로 걸러 129,514개를 씁니다(Table A.7, 필터 기준은 부록 E 본문). 시뮬레이터는 MuJoCo Warp(GPU), 환경당 4,096개, 학습 320,000 반복, 갱신 대 데이터 비율 0.4(Table A.5).

## 4. 한계와 저자가 밝힌 것 (§6)

- 여러 인터페이스 학습은 덜 연구됨. 속도 인코더 실험은 동시 학습이 필요한지 모른다고 저자가 인정합니다.
- 학습 데이터는 시뮬레이터 전이뿐입니다. 실로봇 데이터로 world model을 고치지 않았습니다.
- 평지만 다룹니다. 지형과 물체 상호작용은 진행 중입니다.

저자가 쓰지 않은 한계는 `analysis/03_analysis.md`와 `analysis/04_code_verification.md`에서 다룹니다. 주요 항목은 다음과 같습니다. 단일 시드, 기준선을 재학습하지 않은 비교, 학습 데이터(264 h 대 611 h)와 평가 집합이 같은 모션 집합인 점, 평가 종료 규칙이 SONIC 자체 규칙과 다른 점, 평가 물리가 도메인 무작위화 없이 공칭인 점입니다.

## 5. 본문 안의 불일치와 확인이 필요한 곳

1. **하드웨어 표기.** §4 첫 문단은 "모든 보고 비용은 H100에서 측정했다"고 하지만, SONIC 비용은 128 L40 GPU 7일의 보고값입니다(§4.1 Compute accounting은 이를 밝힘). 두 문장을 같이 읽으면 측정 대상이 헷갈립니다.
2. **시드 수.** §4 본문은 "여러 랜덤 시드를 돌렸고 학습이 매우 안정적이었다"고 하면서 그림에 시드 변동을 싣지 않는다고 합니다. 속도 실험(G.2)은 "정책당 시드 1개"라고 씁니다. 주 결과가 몇 개 시드인지 본문에 없습니다.
3. **Fig 3(b) 목표 반환.** 목표 반환 값이 캡션과 본문에 없습니다. Fig 4의 0.82와 같은지 Fig 3a의 0.90과 같은지 알 수 없습니다.
4. **Fig 3(c)의 점 수.** 1, 7, 40, 264 h 네 점이고, 각 점은 단일 실행입니다. "안정적"이라는 주장은 네 점과 0.007–0.011 범위로 뒷받침됩니다.
5. **world model 헤드 설명.** §3.2 본문은 d_ω를 "학습되거나 해석적"이라고 씁니다. 공개 코드는 보상과 종료 확률을 해석적으로 계산합니다(`analysis/04_code_verification.md` D3).
6. **실패 판정 규칙.** F.1은 같은 평가에서 SuperMimic의 학습 종료 규칙으로 두 정책을 모두 판정한다고 씁니다. SONIC 자체 규칙은 높이 편차만 보고 방향을 보지 않습니다(F.1 마지막 문장). 어느 쪽이든 한쪽에 불리할 수 있습니다.
7. **그림 1과 본문의 GPU 종류.** 그림 1 캡션은 "128 L40 GPUs"이고 본문도 같습니다. 문제 없지만, 비교 대상이 SONIC 보고값이라는 점을 그림 1만 봐서는 알 수 없습니다.
8. **표 A.5의 2-GPU 학습률.** "2 × 2 × 10⁻⁴"으로 적혀 있는데, 기호가 √2인지 2인지 PDF 추출로 확정할 수 없습니다(§7 참고).
9. **그림 4(a) 단일 실행.** PPO-Sim 8 GPU의 최종 반환 0.72와 SuperMimic 0.82의 차이는 시드 1개의 차이입니다.
10. **Fig 5(b)의 "64배".** 상상 스텝 수 기준입니다. PPO-WM 배치 크기(16k×32)와 SuperMimic 배치(4096)의 한 스텝 계산량이 다르므로 계산량 비율로 읽으면 안 됩니다.

## 6. 용어와 기호

- **BPTT(시간 역전파)**: 상상 롤아웃을 world model 자코비안으로 미분. 본문의 "analytic gradient"와 같은 뜻입니다.
- **ĉ_t**: 생존 가중치, c_{t+1} = c_t (1 − d̂_{t+1}).
- **ξ**: 에피소드 시뮬레이터 문맥(도메인 무작위화 값). world model 입력이지만 정책 입력은 아닙니다.
- **정규화 반환**: 에피소드 보상 합을 가능한 최댓값으로 나눈 값(§4 서두).

## 7. v1에서 v2로 바뀐 점

`paper/paper_v1.txt`와 v2의 텍스트를 문장 단위로 비교했습니다. 수치(25, 179, 0.82, 0.007–0.011, 650/15, 표 A.8)는 바뀌지 않았습니다.

- **관련 연구 문단.** v1의 "학습된 미분 가능 동역학" 문단에 있던 문장("SuperMimic learns its surrogate ... retaining compatibility with standard rigid-body simulators")은 v2에서 빠졌습니다. 대신 v2는 DMO [21]를 추가해 "궤적은 시뮬레이터에서 굴리고 학습 모델을 통해 미분한다"는 방식과 비교합니다. DMO가 매 업데이트마다 새 시뮬레이터 롤아웃을 필요로 하고 과제마다 하나의 정책을 학습한다는 차이를 적습니다.
- **참고문헌 번호.** DMO가 들어가면서 [21] 이후 번호가 한 칸씩 밀렸습니다. 본문의 인용도 같이 바뀌었습니다(RWM [21]→[22], Dyna [23, 24]→[24, 25], GAE [25]→[26], MuJoCo [26]→[27], BONES-SEED [27]→[28], LAFAN1 [28]→[29]).
- **감사의 말.** v2에 Zhongyu Li가 추가되었습니다.
- **그 밖의 차이.** 그림 1 캡션 머리말(arXiv 판 표기)과 일부 줄바꿈 차이뿐입니다. 본문 문장 자체는 같습니다.

v2에서 실험 결과를 바꾸거나 새 실험을 넣은 흔적은 찾지 못했습니다. 다만 그림과 표의 데이터는 텍스트 추출로 비교한 것이므로, 그림 자체의 수치는 비교하지 못했습니다.
