# 03. 표 재계산과 일관성 검사 (PhysTwin)

재현은 하지 않았습니다. 학습, 시뮬레이션, 기준선 실행은 하지 않았고 토이도 만들지 않았습니다. 논문이 주는 것은 **평균 표**뿐이므로 이 문서의 검사는 세 가지입니다. (a) 보고된 값끼리 맞는지, (b) 평균 차이의 크기, (c) 시나리오 수 n = 22를 쓴 **유의성 역산**(얼마나 큰 시나리오별 SD까지 p < 0.05를 허용하는지). 계산은 `analysis/recompute.py`(numpy, scipy, 1초 미만)에서 하고 결과는 `analysis/recompute_results.json`에 있습니다. 표 값은 `paper/paper.txt`에서 옮겼습니다.

시나리오 수 22와 분할 규칙은 공개 저장소의 정적 읽기로 확인했습니다(`repo/data_config.csv` 22행, `repo/process_data.py` 169–170행).

## 2. 개선량 재계산 (표 1, 표 2)

감소율(%)은 낮을수록 좋은 CD, 추적, LPIPS에 적용. IoU는 %p, PSNR은 dB, SSIM은 절대 차이.

| 과제 · 기준선 | CD | 추적 | IoU | PSNR | SSIM | LPIPS |
|---|---|---|---|---|---|---|
| 재구성 · GS-Dynamics | −64.3% | −59.1% | +12.3 | +1.95 | +0.005 | −34.6% |
| 재구성 · Spring-Gaus | −87.8% | −82.0% | +26.8 | +4.77 | +0.017 | −66.7% |
| 미래 예측 · GS-Dynamics | −70.7% | −68.6% | +22.7 | +3.08 | +0.017 | −43.3% |
| 미래 예측 · Spring-Gaus | −80.6% | −76.6% | +26.1 | +3.13 | +0.017 | −51.3% |
| 처음 보는 상호작용 · GS-Dynamics | −55.2% | −52.6% | +8.78 | +1.15 | +0.004 | −29.9% |

- **기하와 추적 지표의 개선은 크다**(CD와 추적 50% 이상). 2D 지표는 PSNR 1–5 dB 정도로 차이가 있으나, SSIM은 0.004–0.017로 작음.
- **오차가 커지는 정도:** PhysTwin의 CD는 재구성 0.005에서 미래 예측 0.012로 **2.4배**, 추적 오차는 **2.4배**. LPIPS는 1.6배. 미래 예측에서 정확도가 떨어지는 정도는 지표마다 다릅니다.
- **표 3 ablation (full 대비 오차 증가):** 0차만 쓰면 재구성 CD +40%, 미래 CD +17%. 1차만 쓰면 재구성 CD +60%, 미래 CD +58%, 미래 추적 +55%. 두 단계가 함께 필요하다는 주장과 맞지만, 1차만 쓴 변형의 재구성 추적 오차(0.012)는 0차만 쓴 것(0.012)과 같음.

## 3. 유의성 검사 (n = 22)

논문은 시나리오별 값을 주지 않으므로 **신뢰구간과 p값은 계산할 수 없습니다.** 대신 두 가지를 계산했습니다.

### 3.1 부호 검정

시나리오별 승패가 없으므로, 22쌍에서 이긴 횟수 k가 있을 때 양측 이항 검정 p < 0.05가 되는 최소 k는 **17**입니다. 22쌍 모두 이기면 p = 4.8 × 10⁻⁷입니다. 승패 표가 있으면 바로 확인할 수 있습니다.

### 3.2 허용되는 시나리오별 SD 상한

쌍체 t검정(df = 21, t_crit = 2.080)에서 평균 차이 d가 p < 0.05가 되려면 쌍별 차이의 SD ≤ d·√22 / 2.080 = 2.26 d 여야 합니다. 이 상한을 기준선 평균으로 나눈 값으로 "얼마나 관대한 조건인지"를 봅니다.

| 과제 · 지표 (vs GS-Dynamics) | 평균 차이 | SD 상한 | 기준선 평균 대비 |
|---|---|---|---|
| 재구성 CD | 0.009 | 0.020 | 145% |
| 재구성 추적 | 0.013 | 0.029 | 133% |
| 재구성 IoU | 12.3 | 27.7 | 39% |
| 재구성 PSNR | 1.95 dB | 4.41 dB | 17% |
| 재구성 SSIM | 0.005 | 0.011 | **1.2%** |
| 재구성 LPIPS | 0.018 | 0.041 | 78% |
| 미래 CD | 0.029 | 0.065 | 160% |
| 미래 추적 | 0.048 | 0.108 | 155% |
| 미래 IoU | 22.7 | 51.2 | 103% |
| 미래 PSNR | 3.08 dB | 6.94 dB | 31% |
| 미래 SSIM | 0.017 | 0.038 | 4% |
| 미래 LPIPS | 0.042 | 0.095 | 98% |
| 처음 보는 상호작용 CD | 0.016 | 0.036 | 124% |
| 처음 보는 상호작용 SSIM | 0.004 | 0.009 | **1.0%** |

그림 `report/figures/own_sd_threshold.png`에 같은 내용을 그렸습니다(파란색 = 상한이 기준선 평균의 50% 이상, 주황색 = 50% 미만).

**해석:**
- **CD와 추적 오차:** 시나리오별 SD가 기준선 평균 정도(1배)까지여도 유의할 수 있어 **가능성이 큼.** 다만 SD가 얼마인지는 모름.
- **SSIM:** 상한이 기준선 평균의 1% 안팎입니다. 시나리오 사이 SSIM의 SD가 이보다 작다고 보기 어려우므로, **SSIM 차이는 유의하지 않을 가능성이 큼.** 논문의 "모든 지표에서 일관되게" 주장에서 가장 약한 부분입니다.
- **PSNR과 IoU:** 상한이 평균의 17–39%(재구성)라 시나리오 차이가 커 보이면 유의하지 않을 수 있음.

### 3.3 신뢰구간

계산 불가입니다. 시나리오별 값, SD, 실패 사례 수가 모두 논문에 없습니다. 저자에게 **시나리오별 표(22행, 각 지표)** 를 요청하면 쌍체 검정과 신뢰구간을 바로 계산할 수 있습니다.

## 4. 시험 규모

- **객체 시나리오:** 22개(공개 저장소 `data_config.csv` 확인). 논문과 일치.
- **처음 보는 상호작용:** 쌍 11개 × 방향 2 = 22회(논문 부록 C). 원래 상호작용에서 학습하므로 **독립 표본이 아님**(같은 물체의 두 동작). 그러므로 22를 독립 표본 수로 쓰면 검정이 과하게 강해질 수 있음.
- **테스트 프레임:** 영상 1–10초, 30 FPS(config) → 시나리오당 전체 30–300프레임, 테스트 30% = **약 9–90프레임**. 시나리오 안에서 프레임은 강하게 상관되어 있으므로, 프레임 수로 표본 크기를 키우면 안 됨.
- **추적 점:** 영상마다 9개(논문 §5.1). 시나리오당 평가에 쓰이는 점은 9개뿐이고, 추적 오차의 표본 크기는 작음.
- **카메라:** 3대 RealSense D455(논문). 2D 평가는 1대(코드 확인, `04` D11).

## 5. 값의 자릿수와 단위

- 표 1의 CD와 추적 오차는 **단위가 없음.** 물체 좌표가 미터라면 CD 0.005는 5 mm. 논문에 명시가 없으므로 추정임.
- PSNR은 dB, SSIM과 LPIPS는 무차원, IoU는 %.
- 표 2의 IoU 72.18은 다른 표와 자릿수가 달라 옮겨 적을 때 생긴 것으로 보임(V2).

## 6. 결론

1. 논문 표는 **내부적으로 맞습니다**(V1, V4). 재계산에서 틀린 값은 찾지 못했습니다.
2. **기하와 추적 지표의 평균 개선은 크다**(CD 55–71%, 추적 53–69%). 이 차이는 시나리오 SD가 평균 수준이라도 유의할 수 있습니다.
3. **SSIM의 차이(0.004–0.017)는 유의하다고 볼 근거가 없습니다.** 본문의 "모든 지표에서 일관되게"는 과장입니다.
4. **신뢰구간과 p값은 시나리오별 표 없이는 말할 수 없습니다.** 논문 표 1의 Spring-Gaus 값은 성공 사례만이므로 비교가 불균형합니다.
5. 22개 시나리오 중 **9개(천 8, 상자 1)에는 완성된 형상이 없습니다**(`04` D6). 평균을 이 두 집단으로 나눠 보고하지 않았으므로, 기하 주장의 범위가 명확하지 않습니다.
