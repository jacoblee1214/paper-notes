# 03. 재계산, 일관성 검사, 토이

## 0. 방법과 범위

- **재계산.** `analysis/recompute.py`가 공식 저장소(`repo/`)의 CSV와 JSON을 읽어 논문 표 2, 3, 5, 6, 7, 8과 그림 3을 다시 계산합니다. 결과는 `analysis/recompute_results.json`입니다(약 3초, CPU 단일 프로세스).
- **공식 코드는 실행하지 않았습니다.** `statistical_significance/code/*.py`, `analysis/run_analysis.py`, `scripts/recompute_claims.py`는 읽기만 했습니다. 모든 계산은 이 저장소의 스크립트로 다시 했습니다.
- **토이.** `analysis/toy_rank_flip.py`(약 1초)와 `analysis/toy_envelope.py`(약 1초)는 numpy와 scipy만 씁니다. 그래프는 `analysis/plot_figures.py`가 `report/figures/own_*.png`로 저장합니다.
- **환경.** Apple M4 Pro, Anaconda Python 3.12, numpy 1.26.4, scipy 1.13.1. `python3 -I`로 실행했습니다.
- **판정 기준.** 재계산 값이 논문 값과 소수 셋째 자리(표 5는 pp 둘째 자리)까지 같으면 "일치", 아니면 "불일치"입니다.

### 2.3 부록 C 검산 (집계 판정 경계)

- **필요 기준(하한 봉투, 닫힌 형식).** 각 행의 `necessary_count_delta`를 Qlo(L; T, S) = r − r²/S (L = qS + r), 기각 조건 L > z√(S/(S−1) Q)로 다시 계산했습니다. **1,318행 중 1,318행 일치**입니다(나머지 31행은 "unknown"이라 비교하지 않았습니다).
- **충분 기준(상한 봉투), T = 1, R = 1.** RoboCasa와 RoboTwin 2.0은 과제 1개의 이진 결과입니다. Qhi = min(a+b, 2S−a−b) − (b−a)²/S(부록 C.4의 닫힌 형식)로 `sufficient_count_delta`를 다시 계산했습니다. **43행 중 43행 일치**입니다. T > 1(LIBERO, SimplerEnv)과 R = 5(CALVIN)의 상한은 DP가 필요해서 다시 계산하지 않았습니다.
- **범주 규칙.** 각 행의 범주가 (보고 격차, count_delta, 두 기준)에서 규칙대로 나오는지 확인했습니다. **1,349행 중 불일치 0행**입니다.
- **봉투 토이 (`analysis/toy_envelope.py`).** T = 2, S = 4와 S = 5의 이진 결과표를 모두 열거했습니다(과제마다 가능한 결과 조합 4^S개를 과제 두 개에 대해 모두 결합). 각 (A, B)쌍에서 Q의 최소값은 Qlo와, 최대값은 DP 상한 Qhi와 정확히 같습니다(최대 오차 2.2e−16). 기각 분류(모든 표 기각, 어떤 표는 기각, 기각 없음)도 36 + 55쌍 모두 맞습니다. 독립 표본 Qind도 20,000 무작위 쌍에서 [Qlo, Qhi] 밖으로 나가지 않았습니다.
- **결론.** 논문의 집계 판정 경계식은 맞습니다. 문제는 공식 입력(v1과 릴리스의 범주)에 있습니다.

## 3. 순위와 상관

### 3.1 CALVIN 세 정책: 재표본은 순위를 바꾸지 않는다

- 보정 ATC 순서(X-VLA > GR-1 > RoboFlamingo)와 재표본 ATC 순서가 같습니다. Kendall τ = 1.0.
- 해석: 블록 포즈 재표본은 수준을 낮추지만 정책 간 순위를 뒤집지 않았습니다. 그래서 논문이 말하는 "모든 정책이 떨어진다"는 점수 수준의 문제이고, 순위 기반 비교는 이 실험으로는 흔들리지 않습니다. 정책 세 개뿐이라 통계적으로는 약합니다.

### 3.2 LIBERO 네 스위트: 프로브와 OpenVLA의 난이도 순서

- 프로브(99.0, 100.0, 98.8, 92.4)와 OpenVLA(84.7, 88.4, 79.2, 53.7)의 스위트 순서는 같습니다(Object > Spatial > Goal > Long). Kendall τ = 1.0, Spearman ρ = 1.0.
- 해석: 스위트 간 난이도 순서는 프로브와 OpenVLA가 공유합니다. 점 네 개라 검정력은 없습니다. 이는 스위트 난이도가 능력보다 과제 구조를 반영한다는 논문 주장과 맞지만, 이 자료로 증명되지는 않습니다.

## 4. 토이 1: 순위가 시도 수와 과제 재표본에서 얼마나 뒤집히는가

### 4.1 설정 (우리가 만든 모형, 실제 LIBERO 정책이 아님)

- 과제 T = 10개(LIBERO 한 스위트의 구조), 과제당 시도 S ∈ {50, 100, 500}.
- 정책 A의 과제별 성공률 p_At ~ Beta(평균 0.90, 집중도 κ = 10). 정책 B는 p_Bt = p_At + δ, δ ∈ {0, 0.8, 2, 3, 5, 10}pp. 과제 간 이질성이 있습니다.
- 4,000회 반복. 세 설계를 비교합니다.
  - **독립:** 두 정책이 서로 다른 초기 상태에서 평가됩니다.
  - **짝지음(φ = 0.2):** 같은 초기 상태 난수를 공유하지만, 시도의 20%에서는 B의 결과를 독립으로 뽑습니다. 주변 성공률은 그대로입니다. φ는 가정입니다. 이 값은 공개 데이터(§1.4)의 불일치 3.5%와 맞아떨어지도록 정했습니다(모형에서 시도 불일치 3.7%).
  - **짝지음 상한:** 단조 결합(같은 난수, B ≥ A). 불일치는 격차만큼만 생기므로 **낙관적 상한**입니다.
  - **과제 5/10 부분집합:** 독립 자료에서 과제 5개를 무작위로 골라 평균을 냅니다.
- **뒤집힘 확률.** 참 격차 부호와 관측 부호가 다를 확률입니다(동점은 절반). δ = 0일 때 값은 "차이가 있다고 보이는 비율"입니다.

### 4.3 해석

1. **0.8pp 차이는 과제당 50회 독립 설계에서 동전 던지기에 가깝습니다(뒤집힘 34%).** LIBERO 최고 보고치 차이(+0.7–0.8pp, 표 1)가 이 수준입니다. 시도를 100회로 늘려도 28%, 500회여야 8%입니다.
2. **짝지으면 크게 좋아지지만, 실제 효과는 불일치 비율에 달려 있습니다.** φ = 0.2에서 0.8pp의 뒤집힘은 18%입니다. 상한(불일치 없음)은 1%인데, 실제로는 불일치가 있으므로 이 값은 참고만 합니다.
3. **과제 부분집합은 벤치마크 자체를 흔듭니다.** 같은 시도 자료라도 과제 5개만 쓰면 0.8pp에서 38%, 2pp에서 22%가 뒤집힙니다(독립 전체 과제 대비 더 나쁨). 벤치마크의 과제 구성이 순위를 결정한다는 뜻입니다.
4. **0 격차에서도 "차이가 있다"는 결과가 96%입니다(독립, 50회).** 같은 정책을 두 번 평가해도 ±로 가리기 어렵습니다.
5. **이 결과가 말하지 않는 것.** 정책 간 격차가 과제마다 다르거나(이질적 효과), 시드 변동이 있거나, 성공률이 0.9에서 멀어지면 수치가 달라집니다. 학습 시드는 모형에 없습니다(§5).

## 5. 이 분석이 답하지 못한 것

- **학습 시드 변동.** 논문도 이 저장소도 같은 방법을 여러 학습 시드로 재학습하지 않았습니다. 체크포인트 1개에서 나온 점수의 차이는 시드 변동을 포함하지 않습니다. 정책당 학습 실행이 한 번이면 시행을 늘려도 학습 효과가 평균되지 않습니다. 같은 구조의 문제를 우리의 다른 평가 분석에서도 토이로 확인했습니다. 이 논문의 설계도 같은 한계를 가집니다.
- **체크포인트 선택.** 최고 체크포인트를 시험 세트에서 고르면 LIBERO에서 평균 2.5pp가 부풀려집니다(표 2). 이 값은 논문이 인정합니다.
- **다중 비교.** 그림 3의 1,067개 비교를 행마다 판정하며, 보정을 하지 않습니다. 같은 벤치마크 안에서 여러 비교를 골라 보고할 때 거짓 양성이 늘 수 있습니다.
- **프로토콜 이질성.** 이전 SOTA는 새 논문이 보고한 값입니다. 스텝 제한, 체크포인트 선택, 시도 수가 다릅니다(표 4 캡션이 SimplerEnv 보정과 보고치의 차이를 인정합니다).
- **CALVIN ABC→D 매니페스트.** 저장소 CLAIMS는 ABC→D 3.242의 완전한 공식 매니페스트가 없다고 적습니다(`no_full_official_artifact_manifest`). 표 1의 ABC→D 셀은 다른 셀보다 근거가 약합니다.

## 6. 결론 (재계산 관점)

- 논문 표 2, 3, 5, 6, 7, 8과 LIBERO 쌍 불일치는 공개 파일로 재현됩니다. 값은 모두 맞습니다.
- 그림 3의 LIBERO 헤드라인(19.8%)은 v1 입력에 기댑니다. 공개 릴리스는 18.3%이며, 차이는 0 격차 동점 처리와 소수의 범주 변경에서 나옵니다.
- 0.8pp 수준의 차이는 이 설계(과제당 50회)로 순위를 정할 수 없습니다. 쌍 설계와 과제 전체 사용이 필요합니다.
