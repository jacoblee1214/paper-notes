## 1. 문제와 주장

시연 데이터가 적을 때 시각 기반 모방학습은 일반화가 약합니다. 저자들은 2D 이미지 대신 **희소한 점군(point cloud)**을 쓰고, 작은 MLP 인코더로 64차원 3D 표현을 만든 뒤, 확산 정책(Diffusion Policy)의 조건으로 넣는 DP3를 제안합니다. 주장은 네 가지입니다(서론 기여 1–4).

1. 적은 시연(대부분 10회)으로 72개 시뮬레이션 과제에서 성공률이 높다. 2D Diffusion Policy 대비 상대 향상 24.2%.
2. 여러 과제 (시뮬 7개 영역, 실로봇 4개)에서 일반화한다.
3. 점군 표현과 간단한 인코더가 깊이, RGB-D, 복셀, PointNet++, PointNeXt, Point Transformer보다 낫다.
4. 실로봇에서 안전 위반이 드물다(부록 D, 표 XIV).

## 2. 방법

**입력.** 단일 시점 카메라(시뮬과 실로봇 모두)에서 84×84 깊이 영상을 얻고, 카메라 외부·내부 파라미터로 점군으로 바꿉니다. 색은 쓰지 않습니다(외형 일반화를 위해). 작업공간 상자로 자르고(crop), 최원점 샘플링(FPS)으로 512 또는 1024점을 남깁니다(§III-B).

**인코더.** 점마다 3층 MLP (3→64→128→256, 각 층 LayerNorm과 ReLU), 점 축 max-pooling, 투영층(256→64)과 LayerNorm입니다(§III-B, 부록 A의 PyTorch 코드). 로봇 상태(자세)는 별도 MLP로 64차원이 되고, 두 벡터를 이어 128차원 조건을 만듭니다(부록 A).

**결정부.** 합성곱 1D U-Net 기반 Diffusion Policy [10]를 씁니다. DDIM 스케줄러, 학습 100단계와 추론 10단계, 샘플 예측(sample prediction, ε 예측 아님)을 씁니다(§III-C, 식 1–2). 부록 A는 예측 지평 H=4, 관측 Nobs=2, 실행 Nact=3을 씁니다.

**학습.** 배치 128, 시뮬 3000 에폭 (MetaWorld는 1000 에폭), 실로봇 3000 에폭입니다(§III-C). 옵티마이저, 학습률, EMA는 논문에 없습니다(`04` D3).

## 3. 실험 설계

**시뮬레이션 (72 과제, 7 영역, 표 III).** Adroit 3, Bi-DexHands 6, DexArt 4, DexDeform 6, DexMV 2, HORA 1, MetaWorld 50(Easy 28, Medium 11, Hard 6, Very Hard 5)입니다. 시연 수는 대부분 10회이고, DexArt와 HORA는 100회입니다. 시연은 RL 전문가(VRL3, PPO), MetaWorld는 스크립트 정책, DexDeform은 사람 원격조작으로 만들었습니다(§IV-A). 전문가 성공률은 부록 Table XIX에 있습니다.

**평가 지표.** 시드 3개(0, 1, 2)로 학습하고, 200 에폭마다 20 에피소드를 평가합니다. 각 시드에서 평가 점수 가운데 **상위 5개의 평균**을 과제 성공률로 씁니다. 평균과 표준편차는 시드 3개로 냅니다(§IV-A). 이 방식은 학습 중 평가 점수를 골라 쓰므로 낙관적으로 치우칩니다. 기준선도 같은 방식이라 비교는 공정하지만, 절대 수치는 과대평가될 수 있습니다(`04` D5).

**기준선.** 2D 이미지 Diffusion Policy(주 기준선), IBC, BCRNN과 그 3D 변형(10 과제에서만)입니다(§IV-A, 표 II).

**실로봇 (4 과제, 표 III·VIII).** Franka 팔과 평행 그리퍼(Pour), Allegro 손(Roll-Up, Dumpling, Drill)입니다. RealSense L515 한 대를 씁니다. 시연은 과제당 40회(원격조작), 평가는 과제당 10회입니다. 기준선은 이미지 DP와 깊이 DP입니다(§V-A).

**일반화 실험 (§V-C).** 공간(Pour, 새 위치 5곳), 외형(Drill, 색 5종), 물체(Drill, 5종), 시점(Roll-Up, 3시점), 어수선한 장면(표 XIII)입니다. 대부분 시도 수가 5회 이하입니다.

## 4. 결과 요약

| 항목 | 논문 수치 | 출처 |

재계산한 결과는 `03`에 있습니다. 요지는 다음과 같습니다. 72 과제 평균 차이 14.5 pp는 과제 단위 부트스트랩 95% 구간이 [10.4, 19.1]이고, Wilcoxon p = 2×10⁻⁹입니다. 과제 52개에서 DP3가 높고 4개에서 DP가 높습니다. 실로봇 전체 차이 (34/40 대 14/40)는 Fisher p = 9×10⁻⁶입니다. 반면 본문 기술 몇 개(90% 이상 과제 수, 10% 미만 과제 수, Simple DP3의 정확도)는 표와 맞지 않습니다.

## 5. 절제 실험

6개 과제(Hammer, Door, Pen, Assembly, Disassemble, Stick-Push)에서 시행했습니다.

- **3D 표현 (표 IV).** 점군 78.3, 깊이 32.0, RGB-D 34.7, 복셀 32.3, 이미지 40.7, 상태 오라클 76.8. 점군이 깊이·RGB-D·복셀보다 높습니다. 다만 "이미지" 열은 표 II의 DP 값(Hammer 48, Door 50, Pen 25)과 같고 표 XVIII의 DP 값(45, 37, 13)과는 다릅니다(`03` §4).
- **점 인코더 (표 V).** DP3 인코더 78.3, PointNet 15.7, PointNet++ 2.2, PointNeXt 2.3, Point Transformer 1.0, 사전학습 PointNet++ 6.8, 사전학습 PointNeXt 8.8입니다. PointNet++, PointNeXt, Point Transformer는 여섯 과제 가운데 다섯 과제에서 0%입니다. 원인 설명은 없습니다. 인코더 자체의 한계라기보다 학습 설정의 불일치일 가능성이 있어 해석에 주의가 필요합니다(`03` C17).
- **PointNet 개조 (표 VI).** T-Net과 BatchNorm을 빼면 PointNet 평균이 72.5로 오릅니다. 이후 "차원을 줄여도 거의 같다"(72.5 → 72.3)는 결론을 냅니다.
- **설계 선택 (표 VII).** 자르기(cropping)를 빼면 78.3에서 45.3으로 떨어집니다. 색을 넣으면 72.0으로 떨어집니다. 샘플 예측은 수렴을 빠르게 합니다(그림 7).
- **지평 (표 XV).** H=16, Nact=8로 바꾸면 DP3는 78.2, DP는 33.0입니다. 짧은 지평(40.7)보다 DP가 낮아집니다. 이 표의 "long horizon" 설정이 공식 저장소의 기본값과 같습니다(`04` D1).

## 6. 한계와 논문이 스스로 밝힌 것

논문 결론부 "Limitations"는 두 가지입니다. (1) 제어에 가장 좋은 3D 표현은 아직 찾지 못했다, (2) 매우 긴 지평의 과제는 다루지 않았다입니다. 이 밖에 저희가 본 한계는 다음과 같습니다.

- 학습률, 옵티마이저, EMA, 웜업, 가중치 감쇠가 본문과 부록에 없습니다(`04` D3).
- 자르기 상자 경계, 실로봇 전처리(작업공간 자르기 범위)가 논문에 없습니다. 공식 코드에는 환경별 상자 경계가 하드코딩되어 있습니다(`04` D7).
- 카메라 시점 변화는 점군을 사람이 수동으로 옮겨 처리했습니다(§V-C). 시점 일반화 주장은 이 수동 처리에 기댑니다.
- 실로봇 과제는 과제당 시도가 10회이고, 일반화 실험은 3–5회입니다. 표본이 작아 신뢰구간이 넓습니다(`03` §3–§4).
- 안전 위반률은 분모(시도 수)를 밝히지 않았습니다(`03` C13).
