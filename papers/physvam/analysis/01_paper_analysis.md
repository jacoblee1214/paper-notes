## 1. 한 문단 요약

동적 물체 조작에서 로봇은 물체가 움직이는 동안 행동을 정해야 합니다. 이 논문은 미래 장면을 영상으로 그리는 대신, 현재 행동이 **미래 작업 진행도(task progress)에 어떤 영향을 줄지**를 여러 지평 h = {4, 8, 16, 32}에서 예측하는 방식(PhysVAM)을 제안합니다. 입력은 세 시점 영상, 고유감각, 언어 지시, 최근 4프레임의 물체 위치와 로봇 행동 이력입니다. 두 확산 트랜스포머가 함께 학습됩니다. ActionDiT(약 1B)는 32스텝 행동 청크를 만들고, 더 작은 ValueDiT는 지평별 가치 질의 특징을 냅니다. 가치 특징은 ActionDiT의 세 층에 게이트된 교차 주의로 들어갑니다. 가치 목표는 성공과 실패 결과에 시간 감쇠를 곱한 식 (3)으로 만듭니다. 시뮬레이션(동적 장면 10개, 시드 3개, 장면당 20회)에서 평균 성공률은 58.83%이고 원래 기준선 PUMA는 31.83%입니다. 실로봇(AgileX PiPER, 3 장면, 과제당 20회)에서는 64.17%로 PUMA(36.67%)보다 높습니다.

## 2. 문제 설정과 방법

### 2.1 정책 식 (§3.1, 식 1)

- $A_t = \pi_{\theta,\phi}(O_t, \ell, s_t, H^o_t, H^a_t)$, 행동 청크 길이 $S_a = 32$입니다(식 1).
- $H^o_t = [p_{t-4}, \ldots, p_{t-1}]$는 3차원 위치 4개입니다. 속도는 2차 정확도 유한차분으로 구해 6차원 물체 운동 상태를 만듭니다(§3.2).
- $H^a_t = \{a_{t-L}, \ldots, a_{t-1}\}$, $L = 4$는 최근 로봇 행동 이력입니다(§3.2).

### 2.2 가치 목표 (§3.3, 식 2–4)

- 에피소드 길이 $T_e$에서 결과 $c(e) \in \{+1, -1\}$, 시간 앵커 $H_k = \max(1, \lceil kT_e/K \rceil)$, $K = 4$입니다(식 2).
- 식 (3): $V_t = \frac{c(e)}{K}\sum_k \exp(-[H_k - 1 - t]_+ / \tau)$, $\tau = 16$(부록 A.2)입니다. 목표는 $[-1, 1]$에 있고 $V_{T_e-1} = c(e)$를 만족합니다(검사 V1, `03` §3).
- 식 (4): 지평 $h \in \{4, 8, 16, 32\}$의 목표는 $V_{\min(t+h, T_e-1)}$입니다. 끝을 넘는 지평은 종료 값을 씁니다(검사 V2).

### 2.3 모델 구조 (§3.1, §3.3, 부록 A.2, 그림 2)

- **ValueDiT**: 12층, 은닉 512, 지평별 학습 질의 $q_h$, 4 디노이징 스텝입니다.
- **ActionDiT**: 30층, 은닉 1024, 1B 파라미터, 10 디노이징 스텝입니다. 백본은 Wan2.2-TI2V-5B에서 "adapted"된 가중치로 초기화하고 Fast-WAM(`02` §1)을 따릅니다.
- **주입**: ValueDiT의 4, 8, 12층 질의 특징을 ActionDiT의 9, 19, 27층에 게이트된 교차 주의로 넣습니다. 식 (7)의 게이트 $G_j$는 토큰과 채널마다 값을 냅니다(부록 A.2).
- **손실**: $L = L_{action} + \lambda_V L_{value}$, $L_{value} = L^{FM}_V + L_{reg}$, $\lambda_V = 0.1$입니다(식 6, 8). 성공 궤적은 두 손실을 모두 학습하고 실패 궤적은 가치 손실만 학습합니다(§3.3, Algorithm 1).
- **추론**: 가치 예측은 에피소드 라벨 없이 관측에서 계산합니다. 비동기 청크 생성으로 0.322 s/청크를 보고합니다(RTX 5090, 부록 A.2).

### 2.4 설계상 특징

- 미래 영상을 만들지 않습니다. 미래 "작업 진행도"의 시간 구조를 지도 신호로 씁니다(§1, Fig. 1A).
- 가치 표현은 스칼라나 이진 표시보다 잠재 특징으로 주입합니다(§4.3, Table 2b).
- 학습 목표 $V_t$는 에피소드 결과와 시간만으로 정해집니다. 상호작용 정보가 식에 직접 들어가지 않습니다(§3.3). 이 점은 `04`의 C16–C18에서 다룹니다.

## 3. 실험 (§4, 부록 B)

### 3.1 시뮬레이션 설정 (§4.1)

- DOM(DynamicVLA, arXiv:2601.22153)의 폐루프 반응성 설정을 가져와 물체 10개(구형, 타원형, 불규칙, 원기둥, 병, 컵)로 장면을 다시 만들었습니다.
- 속도 분포: Can, D-Bottle, W-Bottle, Egg, Cup은 $v \ge 0.4$ m/s이고 나머지는 $0.2 \le v < 0.4$ m/s입니다.
- 데이터: 성공 12K, 실패 10K 궤적입니다. 실패 궤적은 PUMA, DynamicVLA, FastWAM의 롤아웃에서 모았습니다. 장면마다 성공과 실패 각각 1K 이상입니다.
- 평가: 장면당 20회, 시드 3개입니다(§4.1). 표는 평균 ± SD를 보고합니다.
- 기준선: FastWAM, InternVLA-A1.5, DynamicWAM, DynamicVLA, PUMA입니다. "공식 코드와 공개 가중치로 미세조정했다"고 씁니다(§4.1). 각 기준선이 같은 데이터셋을 썼는지는 본문에 없습니다.

## 4. 읽으면서 확인한 것과 빠진 것

### 4.1 본문 수치의 빈칸

1. **시드 결과와 SD 정의.** 표 1–3과 5의 ±는 시드 3개의 SD로 보입니다. 정수 시도 횟수로 맞춰 보면 모집단 SD(ddof = 0)와 맞는 해가 모든 검사 셀에 있고, 표본 SD와 맞는 해는 없습니다(`03` §1.4). 표본 SD로 읽으면 값이 약 22% 커집니다.
2. **실로봇에는 시드와 SD가 없습니다.** 과제당 20회 한 번 실행입니다.
3. **시뮬 관측의 출처.** 시뮬레이션에서 물체 위치 이력이 시뮬 상태를 그대로 쓰는지 추정 결과인지 본문에 없습니다. 실로봇은 FoundationPose를 씁니다. 시뮬 결과가 실제 추정 오차를 반영하지 않을 수 있습니다.
4. **기준선 데이터와 학습 예산.** 세 방법 모두 같은 12K + 10K 궤적으로 학습했는지 본문에 없습니다. 기준선은 "공식 코드"로 미세조정했다고만 씁니다.
5. **가치 목표가 가치 모델 자체로 재가중됩니다.** B.2의 ValueDiT는 같은 학습 데이터로 학습된 모델입니다. 학습 샘플에 대한 평가라서 가중치가 훈련 데이터에 맞춰질 수 있습니다.

### 4.2 표와 본문의 작은 불일치

- 표 3의 "Without Robot Motion History" 시간은 8.87 ± 0.04이고 표 7은 8.86 ± 0.04입니다(0.01 s 차이, `03` §2).
- 표 2의 "Without Value Branch"와 표 3의 "Without Object Motion History"는 시간이 모두 9.65 ± 0.02입니다. 표 2의 "Current-Value Prediction"과 "Scalar Conditioning"도 모두 9.02 ± 0.16입니다. 우연일 수도, 복사 오류일 수도 있습니다. 확인할 방법은 없습니다.
- 초록의 "27.0 and 27.5 percentage points over the strongest baselines"는 원래 기준선(PUMA) 대비입니다. 증강 기준선 PUMA+(41.50)와 비교하면 시뮬 차이는 17.33입니다(§4.2의 "strongest original baseline"). 초록에는 이 단서가 없습니다(`04` C5).
- 부록 B.5의 표 6, 7 평균은 표 2, 3과 모두 일치합니다(`03` §2).

### 4.3 해석 한계 (저자가 밝힌 것과 밝히지 않은 것)

- 저자는 "오프라인 궤적 감독에 의존한다"(§5)고 씁니다. 온라인 RL이나 복구 학습은 future work입니다.
- 시간 지표는 성공, 시간 초과, 물체 낙하로 끝난 모든 시행을 포함합니다(§4.1). 낙하가 빨리 끝나면 평균 시간이 줄 수 있습니다. "효율" 주장은 성공률과 분리되지 않습니다(`04` C4).
- 가치 목표는 $c(e)$와 시간으로만 정해집니다. "가치가 상호작용에 반응한다"는 것은 학습 예측이 목표에 없는 변화를 보인다는 뜻입니다(§B.1). 이 주장의 근거는 쌍체 차이입니다. 목표 쪽 차이도 시점 위치에 따라 0.005에서 0.35까지 달라집니다(검사 V3, `03` §3).

## 5. 관련 연구 위치 (요약)

- **시각 미래 모델링**: 미래 영상(Fast-WAM, DynamicWAM), 시각 특징 예측(PUMA, VLA-JEPA)입니다. PhysVAM은 이들과 달리 작업 진행도 값을 예측합니다(§2).
- **가치 모델**: π0.6*(Physical Intelligence), ViVa, WCM, RISE, WVM 같은 과정 가치 모델을 인용합니다. 이들은 주로 현재 값을 평가하고 정책 개선에 씁니다.
- **동적 조작**: DynamicVLA(DOM 벤치마크), PUMA(광흐름과 미래 물체 상태), DynamicWAM(광흐름과 운동학 단서)이 직접 비교 대상입니다.

자세한 계보와 저장소 연결은 `02_prior_work.md`에 있습니다.
