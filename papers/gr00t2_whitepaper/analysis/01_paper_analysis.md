# 01. GR00T 2 백서 분석: 초록에서 실험까지

*GR00T 2: Scaling Robot Foundation Models for Generalization, Dexterity, and Adaptation* (NVIDIA, 2026년 11월, arXiv 없음, 135쪽).
원문은 `paper/paper.pdf`(23.5 MB, 저작권 표기 "© 2026 NVIDIA. All rights reserved.")이고, 인용은 백서의 절(Sec.), 표(Tab.), 그림(Fig.) 번호로 합니다. 백서 본문은 `paper/paper.txt`에서 확인했습니다.

## 1. 한 문장 요약

GR00T 2는 **비디오 확산 트랜스포머(Cosmos-Predict2.5-2B)를 그대로 가져와, 미래 영상과 로봇 행동을 한 시퀀스에서 함께 flow matching으로 예측하는 세계-행동 모델(world-action model, WAM)**입니다. 사람 영상(Human-1M 402k 시간), UMI 기구 시연(10k 시간), 원격조작 데이터(23.5k 시간)를 한 모델에 섞어 사전학습하고, 실물 강화학습과 프론티어 에이전트 연동을 더했습니다(Sec. 1, Sec. 2).

## 2. 초록(서론)의 주장 네 가지

백서의 서론(Sec. 1)은 네 가지 진전을 내세웁니다.

1. **초기 성능:** 여러 조작 과제에서 바로 쓸 만하다. 근거는 Tab. 1(YAM 장기 과제 6개, Dexter 장기 과제 7개)과 Tab. 2–3(제로샷 평가).
2. **빠른 적응:** 처음 보는 과제를 몇 번의 시연으로 익힌다. 근거는 Fig. 2(Dexter-50 제로샷 40%, 1회 시연 71%, 5회 95%)와 Sec. 3.1.
3. **X-적응(교차 적응):** 사람 영상, UMI, 글러브 시연으로 로봇 원격조작 없이 새 기술을 배운다. 근거는 Sec. 3.2와 App. B.
4. **에이전트 제어:** 추론 모델(프론티어 에이전트)이 GR00T 2를 도구처럼 호출해 긴 과제를 조합하고 복구한다. 근거는 Sec. 3.4, App. G.

추가로 **GR00T 2 Turbo**(더 작은 시각 잠재 표현을 쓰는 변형)를 소개하고, 휴머노이드 전신 제어에 쓴다(Sec. 2, Sec. 3.5).

## 3. 방법

### 3.1 구조 (Sec. 2 "Architecture")

| 구성 요소 | 백서의 설명 | 비고 |
|---|---|---|
| 백본 | Cosmos-Predict2.5-2B, "video diffusion transformer", 2B 파라미터 한 개 | 시각·행동·상태 토큰을 한 시퀀스에 넣음 |
| 영상 인코더 | Wan 2.1 VAE, 동결. 시간 4배, 공간 8배 압축 | 카메라 한 대 224×320, 프레임당 280 토큰 |
| 언어 | Cosmos-Reason1 VLM, 동결. 교차 주의로 읽음 | 크기는 백서에 없음 |
| 상태·행동 | 임베디드먼트별 작은 MLP 입출력 | 행동은 "노이즈가 섞인 행동 청크"로 입력 |
| 학습 목표 | flow matching, 영상과 행동에 각각 손실 | 사람 영상은 손 자세 궤적을 행동 감독으로 씀(Sec. 4.1) |
| 추론 | 영상 1–2 단계, 행동 2–4 단계 데노이징 | "2v4a" 같은 표기(Tab. 27 주석) |
| 입력 | 0.8초 이력, 5 fps, 카메라 최대 4대 | 머리 1대 + 손목 2대가 전형 (Sec. 2) |

Turbo는 같은 2B 트랜스포머에 Wan 2.2 VAE(공간 16배)를 써서 시각 토큰을 줄인 변형입니다(Sec. 2). 백서가 밝힌 Turbo 구조 차이는 VAE 하나와 입출력 투영뿐입니다.

### 3.2 학습 단계 (Sec. 4.1)

- **1단계 단일 시점 영상 사전학습:** 한 카메라 시점만으로 미래 영상을 예측해 물리 동역학 사전 지식을 얻습니다.
- **2단계 다시점 영상-행동 공동 학습:** 임베디드먼트별 상태·행동 모듈을 붙이고, 사람 영상은 손 자세를 행동 대리 감독으로 씁니다.
- **3단계 로봇 가중 공동 학습:** YAM과 손 로봇 데이터의 비중을 높입니다.
- **사후학습:** SFT 뒤 실물 GRPO 변형(CPS 샘플링, 자기 모방)과 잔차 RL을 적용합니다(Sec. 3.3). 시뮬레이션 RL은 DreamDojo 세계 모델을 씁니다(Sec. F.5).
- 레시피 기저는 "AutoRL"이라는 연구 에이전트가 시뮬레이션에서 약 35일 동안 찾았다고 합니다(Sec. 4.1, F.2).

### 3.3 데이터 (Sec. 4.2, App. C)

| 출처 | 규모 (백서) | 역할 |
|---|---|---|
| Human-1M 필터 사람 영상 | 402,730 시간, 약 1,375만 에피소드 | 행동 없는 영상 학습 + 손 자세 감독 |
| 스튜디오 사람 영상 | 3,000 시간 | 로봇과 맞춘 시점, 같은 속도 |
| UMI-10K (손에 든 그리퍼) | 10,184 시간, 94.2만 에피소드 | 로봇 행동 표현으로 바뀐 시연 |
| 원격조작 | 23.5k 시간, 116만 에피소드 | YAM 18.7k, Sharpa 2.9k, Wuji 1.3k, G1 275 시간, DROID 350 시간 (Tab. 11) |

Tab. 11의 샘플 비중은 YAM 51.2%, ABC-130k 10.4%, Sharpa 20.6%, Wuji 14.0%, G1 1.3%, DROID 2.5%로 시간 비중과 다릅니다. 즉 샘플링 가중치로 균형을 맞춘 것입니다. 주석은 Flora(자체 데이터 엔진)가 달았고, WGO-Bench 시간 분할 F1 50.3으로 GPT-6 Astra(46.0)보다 높다고 보고합니다(Sec. 4.2.4).

### 3.4 학습 인프라 (Sec. 4.7, App. K)

- 사전학습은 **GB300 NVL72 1,024장**에서 했습니다. 전체 클러스터는 2,016장입니다(Sec. 4.7.1, K.2.1).
- DeepSpeed ZeRO-2, BF16, GPU당 배치 16. 총 학습 스텝, 소요 시간, 총 GPU 시간은 **보고하지 않습니다.** MFU·OFU 수치도 없습니다.
- 데이터 로더는 LanceDS 형식으로 25개 저장소, 1,560만 에피소드, 462억 시간 단계를 읽고, 1,024장에서 약 12,000 샘플 창/초를 공급했다고 합니다(Tab. 35).

## 4. 실험과 평가

### 4.1 실물 평가 설계

백서는 두 종류의 평가를 씁니다.

- **고정 과제 표(Tab. 1–6):** 과제마다 시도를 적게(대개 10–20회) 하고 성공률과 진행률을 보고합니다. Tab. 1a(YAM 장기 6개, 과제당 최대 20회), Tab. 1b(Dexter 장기 7개, 시도 수 미기재), Tab. 2(YAM V2 제로샷, 시도 수가 과제·모델마다 다름), Tab. 3(Dexter 제로샷 71과제 × 3회).
- **블라인드 A/B 아레나(Sec. 4.3, App. D):** 같은 장면에서 체크포인트 2–4개를 무작위 순서로 돌리고, 작업자가 순위를 매깁니다. Bradley-Terry Elo를 쌍 부트스트랩(과제 단위 재표본)으로 구간 추정합니다. 공개 데이터는 없고 표 12와 13의 집계만 있습니다.

### 4.3 시뮬레이션과 실물의 관계

- 25개 YAM 과제에서 14개 체크포인트의 시뮬레이션 성능과 실물 성능의 Pearson 상관은 진행률 0.93, 성공률 0.92, Elo 0.93입니다(Sec. 4.5.2).
- 사람 영상 데이터 비율을 바꾼 실험(Fig. 10)은 실물 72과제(과제당 3회)에서 측정했습니다.

### 4.4 에이전트 실험 (Sec. 3.4, App. G)

- 에이전트(System 2)가 계획과 검증을 맡고, GR00T 2를 도구로 호출합니다.
- 실물 장기 조립 3개는 "사람이 부품을 무작위로 쏟은" 시작 상태에서 100회씩 평가했습니다(Fig. 7). 사람이 도운 시도는 실패로 셉니다.
- 시뮬레이션 리더보드에서는 개발 시드(15–30)로 실행기를 고르고 시험 시드(50)로 보고합니다(App. G.1).

## 5. 한계 (백서가 스스로 밝힌 것)

백서 결론(Sec. 5)은 다음 열린 문제를 적습니다.

- **예측 대상:** 미래 영상의 어떤 부분을 예측해야 하는지 모릅니다. Turbo는 잠재 격자가 4배 작은데 Dexter 장기 과제 성공률이 68.6%에서 34.3%로 떨어졌습니다(Sec. 5).
- **확장 법칙:** 모델 크기, 데이터, 계산량에 따른 WAM의 확장 법칙을 모른다고 합니다.
- **평가:** 실물 성공률은 이항 추정이라 "95%와 99%를 가르려면 과제당 약 285회"가 필요하다고 씁니다(Sec. 5, 각주 1). 백서의 과제당 20회로는 큰 차이만 잡힙니다.
- **재현성:** 상시 평가는 "블라인드 A/B"로 바꿨다고 하지만, 원자료와 학습 설정(스텝 수, 학습률 등 상당 부분)은 공개되지 않았습니다.
