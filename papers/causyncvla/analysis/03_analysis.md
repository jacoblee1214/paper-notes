# 03. 재계산, 일관성 검사, 주장 판정

재계산 스크립트는 `analysis/recompute.py`(numpy, scipy, 수 초)이고 결과는 `analysis/recompute_results.json`입니다. 입력은 논문 본문과 표의 값을 옮겨 적은 것이며, 외부 데이터·가중치는 쓰지 않았습니다. 그래프는 `analysis/plot_figures.py`로 만듭니다.

**범위와 가정.** 재현 실험은 하지 않았습니다. 학습, 평가, 공식 코드 실행, 가중치 다운로드 모두 하지 않았습니다. 대신 논문이 공개한 개수로 합계, 비율, 검정을 다시 계산합니다.

- 쌍체 검정(McNemar)은 Table 10의 wins/losses(w, l)가 있는 네 비교에만 쓸 수 있습니다. 그 밖의 쌍 비교(native 469 대 456, LIBERO-Plus 2,019 대 1,967)는 쌍 개수가 공개되지 않아 비쌍 검정으로 근사하고 표시했습니다.
- 실로봇 시행은 장면을 다시 놓은 비쌍 시행이므로 비쌍 검정(Fisher, 카이제곱)이 맞습니다. 과제 층화는 Cochran–Mantel–Haenszel으로 봅니다.
- Table 2(20 Hz 시간 고정, 100 starts)도 쌍 결과가 없으므로 비쌍 검정입니다.

## 1. 재계산과 검정

### 1.1 LIBERO-10 native (Table 1, Table 9)

| 항목 | 값 |
|---|---|
| CauSyncVLA | 469/500 = 93.80%, Wilson 95% 91.33–95.60% (논문과 일치) |
| π0.5 10-step | 456/500 = 91.20%, Wilson 95% 88.39–93.38% (논문과 일치) |
| 차이 | +2.6 pp (13 starts), Newcombe 95% −0.7 ~ +5.9 pp |
| 비쌍 Fisher p | 0.149 (카이제곱 0.119) |
| 과제별 합 | Table 9 합 456, 469로 맞음. 가장 큰 차이는 두 모카 포트 과제 29→38 (+9) |

**쌍 검정 불가.** 같은 500 starts를 썼으므로 쌍체 검정이 맞습니다. 그러나 논문은 쌍체 불일치 개수(w, l)를 native 비교에 공개하지 않았습니다. w − l = 13만 알 수 있습니다. 따라서 p 값은 l에 따라 달라집니다.

| 상대만 성공한 starts l | 0 | 5 | 10 | 20 | 40 | 80 |
|---|---|---|---|---|---|---|
| 정확 McNemar p (w = l + 13) | 0.00024 | 0.011 | 0.035 | 0.098 | 0.21 | 0.36 |

즉 "93.8 대 91.2는 유의하다"는 주장은 **쌍 정보가 있어야 판정**됩니다. 논문은 이 비교에 검정을 하지 않았습니다.

**선택 편향.** 같은 500 starts(Fig. 8b, "native success on 500 fixed initial states")에서 학습 예산 3개를 비교했습니다. 6k 93.4%, 12k 93.8%, 18k 93.0%입니다. 12k를 골랐습니다. 이 선택은 시험 세트에서 이뤄졌고, 보고하는 수치도 같은 시험 세트입니다. 차이는 2–4 starts이므로 결론을 바꾸지는 않지만, 헤드라인 수치는 낙관적입니다. 논문도 §B.5에서 "uncertainty conditional on that selection"이라고 적었습니다.

### 1.3 실로봇 FR3 (Table 6, §C.9)

| 항목 | CauSyncVLA | π0.5 10-step |
|---|---|---|
| 쌓기 | 19/23 (82.61%) | 17/23 (73.91%) |
| 놓기 | 22/23 (95.65%) | 16/23 (69.57%) |
| 분류 | 19/23 (82.61%) | 17/23 (73.91%) |
| 합계 | 60/69 = 86.96%, Wilson 77.03–92.98% (논문 일치) | 50/69 = 72.46%, Wilson 60.95–81.61% (논문 일치) |

- 합계 차이 +14.5 pp, Newcombe 95% 구간 +1.0 ~ +27.5 pp.
- **비쌍 Fisher 정확 검정 p = 0.056**(유의하지 않음). 카이제곱 p = 0.034. 과제 층화 CMH 카이제곱 4.40, **p = 0.036**.
- 과제별 Fisher p: 쌓기 0.72, 놓기 0.047, 분류 0.72. 놓기 과제 하나만 0.05 아래입니다.
- **민감도.** CauSyncVLA 성공 1건을 실패로 바꾸면 카이제곱 p가 0.05를 넘습니다(최소 1건). Fisher p는 이미 0.05를 넘어 있습니다.
- **운영 차이.** 실행 오류가 있었던 시행은 π0.5 15회, CauSyncVLA 5회입니다(§C.9). 운영자 판정이 결과를 정했습니다. 오류 처리 규칙이 두 팔에 같지 않으면 결과가 흔들릴 수 있습니다.
- **구조 차이.** 시행은 컨트롤러 블록으로 모았고, 쌍을 맞추지 않았습니다(§C.9). 블록 순서가 장면 조건과 섞여 있을 수 있습니다.
- 쌓기 과제는 업데이터 학습에 쓰였고, 놓기와 분류는 학습에서 뺐습니다(§4.1, §C.9). 결과가 학습 과제에서 더 좋은지 판단하려면 과제별 시행이 더 필요합니다.

## 2. 지연과 처리량 분해 (Table 16, Table 2)

| 계산 | 값 | 출처 |
|---|---|---|
| 10-step 대 공유 GPU 빠른 경로 | 60.01 / 11.91 = **5.04×** | Table 16 (초록의 수치) |
| = 흐름 단계 10→1 (60.01/36.00) | **1.67×** | Table 16 |
| × 시각 인코딩 제거 (36.00/11.91) | **3.02×** | Table 16 |
| 곱 검산 | 1.67 × 3.02 = 5.04 (일치) | 재계산 |
| 10-step 대 분리 빠른 경로 | 60.01 / 4.79 = **12.53×** (논문 12.52×, 반올림) | Table 16 |
| 20 Hz 단일 GPU 재계획 비 | 3.28 / 2.57 = **1.28×** | Table 2 |

- 5.04×는 모델 단독 지연의 비입니다. 기준선의 60.01 ms에는 매 호출의 시각 인코딩이 들어 있습니다. CauSync 공유 값(11.91 ms)은 시각 인코딩을 다른 스트림에서 계속 돌린 뒤의 빠른 경로입니다. 논문도 §B.4에서 "removing visual encoding from the fast path accounts for the remaining reduction"이라고 적었습니다.
- 실행 전체(관측 전송, 렌더링, 실행기 가드 포함)에서는 1.28배입니다. 같은 시스템의 응답 지연은 2.13배입니다.
- 결론: 빠른 흐름의 **계산 구조**(시각 인코딩 분리 + 한 스텝)는 큰 차이를 만듭니다. 그러나 "추론 처리량 5.04배"는 실행 전체 처리량으로 읽으면 안 됩니다.

## 6. 재계산하지 못한 것

- 쌍 결과(성공 여부별 starts 목록)가 없어 native 비교와 LIBERO-Plus 비교의 정확한 쌍 검정을 할 수 없습니다.
- Table 4와 14의 경계 뒤집힘은 비율만 있습니다. 쌍 구간(Table 14 부트스트랩)의 값 자체는 재계산하지 않았습니다.
- 실로봇 시간 지표(Table 19, 20)는 중앙값과 사분위 자료가 없어 재계산하지 않았습니다.
- 토이(2-링크 등)는 만들지 않았습니다. 핵심 주장은 논문이 공개한 쌍체 개수로 검정할 수 있어서, 토이로 확인할 우선순위가 낮다고 판단했습니다.
