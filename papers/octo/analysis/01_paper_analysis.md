## 1. 문제 설정

로봇 학습은 로봇과 과제마다 데이터를 새로 모아야 해서 일반화가 약합니다. 논문은 Open X-Embodiment(RT-X, 2023)의 OXE 데이터(약 150만 에피소드 중 80만 선별)로 사전학습한 **범용 로봇 정책(generalist robot policy, GRP)** Octo를 제안합니다. 목표는 세 가지입니다(§IV 도입부).

1. 사전학습 정책이 여러 로봇을 **추가 학습 없이** 제어하는가(zero-shot).
2. 새 환경과 과제에 **적은 데이터로 미세조정**하면 처음부터 학습하거나 사전학습 시각 표현(VC-1)을 쓰는 것보다 나은가.
3. 설계 선택(구조, 데이터, 목적함수, 규모)에 무엇이 중요한가.

기여는 (i) 800k 궤적으로 학습한 transformer 정책, (ii) 관측과 과제 토큰을 바꿔 끼울 수 있는 구조, (iii) 체크포인트와 학습·미세조정 코드의 공개입니다(§I, §III-E).

## 2. 방법 (§III)

### 2.1 구조 (§III-A, 그림 2)

- **토크나이저:** 언어는 `t5-base`(111M, 동결)로 16개 토큰을 만듭니다(부록 D). 이미지는 얕은 CNN 스템으로 16×16 패치를 나눕니다. 3인칭 카메라(256×256)는 256개 토큰, 손목 카메라(128×128)는 64개 토큰입니다(부록 D).
- **Transformer 백본:** 과제 토큰과 관측 토큰을 한 시퀀스로 두고, 블록 단위 마스크로 관측 토큰은 같은 시점과 이전 시점, 그리고 과제 토큰만 봅니다(§III-A). 읽기 토큰(readout token)은 앞선 토큰을 보지만 다른 토큰에게 보이지 않습니다. 그래서 읽기 토큰은 출력만 읽고 내부 표현을 바꾸지 않습니다.
- **크기:** Octo-Small(27M, ViT-S 크기), Octo-Base(93M, ViT-B 크기). 표 V 값은 코드의 `vit_s`, `vit_b` 설정과 맞습니다(`04` D12).
- **확산 헤드:** 읽기 토큰 임베딩에 3층 잔차 MLP(은닉 256, 층 정규화)를 두고, DDPM 목적함수와 코사인 스케줄로 20단계 잡음 제거를 합니다(식 1, 부록 D). 트랜스포머는 관측당 한 번만 통과하고 나머지 잡음 제거는 작은 헤드 안에서 합니다(§III-C).
- **행동 청크:** 사전학습 설정에서 한 번에 4개 행동을 예측합니다(`04` D3). 본문에는 숫자가 없고 부록 E는 "행동 청크"의 효과만 말합니다.
- **관측 이력:** 두 프레임을 씁니다(§IV-D, 부록 E).

### 2.2 학습 데이터 (§III-B, 부록 C, 표 III)

- 25개 OXE 데이터셋(이미지 관측, 델타 엔드이펙터 제어, 다양한 행동)을 골랐습니다. 이 과정에서 이미지가 없는 데이터, 절대 그리퍼 제어가 아닌 데이터, 해상도가 낮은 데이터를 뺐습니다.
- 표 III의 비율은 Fractal 17.0%, Kuka 17.0%, Bridge 17.0%부터 DLR EDAN 0.1%까지입니다. 합계는 99.75%이고, 반올림 때문에 이 차이는 자연스럽습니다(`03` §4).
- 그리퍼 행동은 "열림 = +1, 닫힘 = 0"으로 맞췄습니다. 관측 카메라가 없는 채널은 0으로 채웠습니다.
- 목표 영상 학습은 hindsight relabeling으로 같은 궤적의 나중 상태를 목표로 씁니다. 언어 지시는 학습 예시마다 0으로 가려 두 조건을 모두 학습합니다(§III-B).
- 본문은 "데이터의 27%에 손목 카메라가 있고 56%에 언어 주석이 있다"고 씁니다(§V). 표 III에는 이 정보가 없어서 재계산할 수 없습니다(`03` §4의 한계).

### 2.3 학습 목적함수 (§III-C, 식 1)

- 행동 분포를 확산 모델로 학습합니다. MSE 헤드와 이산화 헤드(RT-1식 256칸)보다 낫다고 표 II(표 VI)로 보입니다. 부록 E는 MSE 헤드가 "머뭇거리는" 정책을, 이산화 헤드가 정확도를 떨어뜨린다고 적습니다.
- 미세조정은 전체 모델을 같은 목적함수로 갱신합니다(동결하지 않음, §IV-D).

### 2.4 학습 설정 (§IV-D, 부록 D, 표 IV)

- AdamW, 최대 학습률 3e-4, 2000 워밍업 스텝, 역제곱근 감쇠, 가중치 감쇠 0.1, 기울기 클리핑 1.0.
- 사전학습: 300k 스텝, **배치 2048**, TPU v4-128에서 14시간(부록 D). 공개 설정의 배치는 512입니다(`04` D1).
- 미세조정: 약 100개 시연, 50k 스텝, 코사인 감쇠와 선형 워밍업, 한 번의 A5000(24 GB)에서 약 5시간(§IV-D).

## 3. 실험 (§IV)

### 3.1 평가 설정 (그림 4, 부록 F)

9개 로봇 환경 4개 기관이고, 그중 3개(WidowX BridgeV2, UR5, RT-1 Robot)는 사전학습 데이터 안에서 zero-shot으로 평가합니다. 나머지 6개는 미세조정 평가입니다(표 I의 Berkeley Insertion, Stanford Coffee, CMU Baking, Berkeley Pick-Up, Berkeley Coke, Berkeley Bimanual).

### 3.2 Zero-shot 다중 로봇 제어 (§IV-A, 그림 5)

- 기준선: RT-1-X(35M), RT-2-X(55B). 논문은 "Octo가 RT-1-X보다 평균 29% 높다"고 씁니다(그림 5 수치 없음).
- 목표 이미지 조건이 언어 조건보다 "25% 높다"고 씁니다(WidowX).
- **재계산 불가:** 그림 5와 그림 6에 수치 표기가 없어서 이 주장은 검증하지 못했습니다(`03` §5).

### 3.3 데이터 효율 미세조정 (§IV-B, 표 I)

| 도메인 | 스크래치 (ResNet+Transformer) | VC-1 | Octo |
|---|---|---|---|
| Berkeley Insertion* | 10 | 5 | **70** |
| Stanford Coffee | 45 | 0 | **75** |
| CMU Baking | 25 | 30 | **50** |
| Berkeley Pick-Up† | 0 | 0 | **60** |
| Berkeley Coke | 20 | 10 | **100** |
| Berkeley Bimanual† | 20 | 50 | **80** |
| 평균 | 20 | 15 | **72** |

- 본문은 "6개 설정 평균에서 다음으로 좋은 기준선보다 **52%** 높다"고 씁니다. 평균 차이는 **52.5 %p**(72.5 − 20)입니다. "52%"는 상대 비율이 아니고 **백분율 포인트**입니다. 상대 비율로 쓰면 약 260%입니다(`03` §2, V1).
- 각 도메인 20회입니다(표 I 캡션). 다만 부록 F는 Bimanual을 10회라고 씁니다(V3).

### 3.4 설계 선택 (§IV-C, 표 II = 표 VI, 부록 E)

WidowX 4개 과제(언어 2개, 목표 이미지 2개) × 10회 = 40회.

| 조건 | 평균 (보고) | 40회 합산 |
|---|---|---|
| Octo-Small | 83 | 33/40 |
| RT-X 데이터 혼합 | 60 | 24/40 |
| ResNet+Transformer | 70 | 28/40 |
| Bridge 단일 데이터 | 43 | 17/40 |
| MSE 헤드 | 35 | 14/40 |
| 이산화 헤드 | 18 | 7/40 |

- 확산 헤드 대 MSE·이산화 차이와 Bridge 단일 데이터 차이는 크고 유의합니다(`03` §3).
- **ViT 대 ResNet은 유의하지 않습니다.** 33/40 대 28/40, Fisher p = 0.29입니다. 논문이 "ViT 구조가 낫다"고 하는 근거는 이 표만으로는 약합니다(`03` §3).
- 데이터 혼합의 차이(RT-X 혼합 대 Octo 혼합)는 p = 0.047로 경계선입니다.
- 모든 조건에서 과제 단위 10회의 편차를 합산했습니다. 과제 차이를 보정하지 않은 값입니다.

### 3.5 규모와 일반화 (그림 6, 표 VII)

- 그림 6: Octo-Tiny(10M), Small(27M), Base(93M) 비교. Tiny는 본문에만 있고 표 V와 공개 설정에는 없습니다(`04` D13).
- 표 VII(WidowX, 과제당 10회):

| 범주 | 과제 | 성공 | 평균 |
|---|---|---|---|
| 학습 분포 | 당근·접시, 가지 항아리 | 80, 90 | 85 |
| 새 물체 | 빵·접시, 숟가락·장갑 | 70, 90 | 80 |
| 새 환경 | 버섯·항아리, 숟가락·천 | 20, 60 | 40 |
| 새 기술 | 컵 세우기, 블록 끼우기 | 10, 0 | 5 |

- 새 기술 범주는 학습 분포와 구별됩니다(Fisher p ≈ 4×10⁻⁷, 표 VII 행 17/20 대 1/20). 이것은 논문 본문의 "기술 일반화가 약하다"와 맞습니다.

## 4. 한계와 논문이 스스로 말한 것 (§V)

- 손목 카메라 정보를 잘 처리하지 못합니다. 미세조정에서 3인칭만 쓰는 편이 결과가 더 좋을 때가 있습니다.
- 언어 조건과 목표 이미지 조건의 차이가 큽니다. 학습 데이터에 언어 주석이 56%뿐입니다.
- 최적 시연만 씁니다. 실패 데이터와 온라인 상호작용은 쓰지 않습니다.
- 이동 로봇은 다루지 않았습니다.
- 데이터 혼합의 최적 선택은 연구하지 않았습니다(§V, 부록 C).

## 6. 재현과 게시 판단

- 공식 코드는 JAX이고 MIT 라이선스입니다. 체크포인트는 공개되어 있습니다(HF `rail-berkeley/octo-small-1.5` 등, README 기준).
- 논문 결과를 재현하려면 TPU 또는 대형 GPU 기기, 80만 에피소드의 OXE 데이터, 실로봇 또는 WidowX 설정이 필요합니다. 맥(M4 Pro, CUDA 없음)에서는 사전학습과 미세조정 재현이 불가능합니다. 구현 가능성과 판정은 `04` §4와 `README.md`에 있습니다.
