## 4. 기반 정책 비교(그림 5, 표 2)와 촉각 표현(그림 6)

**그림 5와 4.2절 (K1, K2).** 증감 라벨(+60, +60, +55, +40, +60)은 전/후 값으로 모두 다시 계산됩니다. 그러나 4.2절 본문은 ACT 초기 20%, π0.5 초기 20%인데 그림 5와 표 2는 ACT 25%, π0.5 15%입니다. 둘 다 5%의 배수라 20회 평가에서는 모두 가능한 값이라, 어느 쪽이 맞는지는 논문만으로 정할 수 없습니다. 증감은 그림 기준 +55, +60이고 본문 기준이면 +60, +55로 바뀝니다. 전/후 Fisher p: π0.5 3.3e-4, DP 2.4e-4, ACT 1.2e-3, 원격조작 flow 0.014, 인간 flow 4.5e-5. "15–50% → 75–100%"는 그림 5 값의 최솟값·최댓값과 일치합니다.

**표 2 (V10).** 같은 백본의 가장 센 모방 기준선과 비교하면:

| 비교 | 차이 | Newcombe 95% | Fisher p |

**원격조작 flow 대 인간 flow.** 후 성공률 90% 대 100%(18/20 대 20/20)는 p = 0.49입니다. 본문 "human flow policy achieves the highest performance"는 방향은 맞지만 이 크기로는 구분되지 않습니다.

**그림 6 (그림 판독, 20회 가정).** Peg-in-Hole 기반 40%에서 AnyTouch2, Sparsh, 마커 100%, T3 90%(AnyTouch2와 T3 p = 0.49). Charger 기반 10%에서 AnyTouch2, 마커 100%, Sparsh 80%, T3 70%. AnyTouch2 대 T3 p = 0.020, 대 Sparsh p = 0.106, 대 마커 p = 1.0. 모든 표현이 기반 대비 p < 0.003입니다. 본문 "T3와 Sparsh가 Charger에서 AnyTouch2보다 나쁘다"는 점추정으로는 맞고 Sparsh는 구분되지 않습니다. "마커와 AnyTouch2는 비슷하다"는 둘 다 100%라 맞습니다.

## 5. 예산과 시간 산술 (V12, V15, V16)

- 10 Hz, 에피소드 최대 300 스텝(30초). 웜스타트 12분은 최대 7,200 스텝, 최소 24개 최대 길이 에피소드에 해당합니다. Peg의 온라인 38분은 최대 22,800 스텝입니다. 재생 버퍼는 1e4 전이이므로 웜스타트 최대 전이(7,200)에 ControlTac의 합성(궤적당 2개 추가)을 더하면 버퍼 용량을 넘을 수 있습니다. 버퍼 교체 규칙은 적혀 있지 않습니다.
- 잔차 크기 스케줄(0.05 → 0.10 → 0.15, 500 온라인 스텝 간격)은 1,000 스텝(10 Hz에서 100초)이면 최댓값 0.15에 닿습니다. 이는 Peg 온라인 구간의 4.4%이며, 이후 학습 대부분이 0.15에서 진행된다는 뜻입니다. 본문의 "gradually increased"와 부록 A.5의 "scheduled residual scale"는 이 간격을 "500 온라인 스텝"으로만 적어서, 한 단계의 길이가 에피소드 하나보다 짧습니다(K4).
- 체크포인트 평가: Peg은 0분 20회 + 5개 체크포인트 × 10회 + 최종 20회 평가가 있습니다(그림 4의 표시 지점 기준). 이 시행이 훈련 시간 50분에 들어가는지 적혀 있지 않습니다.
- **10회 체크포인트의 표준오차는 최대 15.8점**(p = 0.5)입니다. 그림 4의 Ours Peg 곡선(그림 판독 40, 30, 30, 50, 90, 90, 100)과 Box 곡선(70 → 80 사이의 오르내림)은 이 크기의 평가 잡음을 포함합니다.
- **검정력(Fisher 정확, 양측 0.05, 각 20회).** 85 대 35는 0.88이지만, 80 대 60은 0.19, 90 대 65는 0.36, 75 대 45는 0.38입니다. 80% 검정력에는 각각 약 90회, 50회, 50회가 필요합니다. 표 2의 백본별 20–30점 차이는 20회 평가로는 검출되기 어려운 크기입니다.

## 6. 보상 산술 (V13)

- 가중치 합 3.5로 나누므로 모든 양의 항이 1이면 최댓값 1입니다. 그러나 접근 보상은 초기 물체 중심까지의 거리(d_max = 0.15 m)로 정의되어, 파지 후 운반하면 0이 됩니다(본문은 "before grasping, reach; after grasping, flow"라고 쓰지만 식 (20)은 항상 합산). 파지 후 접근 항이 0이면 최댓값은 (0.5 + 2.0)/3.5 = 0.714입니다. 종료 성공 보상 1은 별도입니다. 읽는 방식에 따라 "최대 1"이 도달 가능한지가 달라집니다.
- 식 (23)의 ℓ_t 범위가 본문 {0..L}이면 ℓ = L에서 flow 보상이 1 + 1/30 = 1.033으로 [0, 1] 정규화를 넘습니다. 부록은 {0..L−1}로 쓰며 이 경우 최대 1입니다(K5).
- 안전 벌점: 본문은 "large negative reward", 표 4는 범위 [−1, 0], A.6은 "종료하고 리셋"입니다. 값의 크기는 읽는 곳마다 표현이 다릅니다.
- d_flow는 변환 차이의 2-노름(식 22)이고 d_max = 0.05, ε_flow = 0.03인데, 병진(m)과 회전(rad)을 어떻게 한 노름으로 묶는지 단위 설명이 없습니다.

## 7. 절제 끝점 (V17, 그림 15–18 판독, 50분, 10회 가정)

Ours 100%(10/10)에 대한 Fisher p:

| 그림 | 설정 | 끝점 | p |
|---|---|---|---|
| 15 | No Reaching Reward / No dense reward / No Flow Reward / No tactile reward | 80 / 70 / 70 / 90 | 0.47 / 0.21 / 0.21 / 1.0 |
| 16 | ACT + Ours / Keypoints + per-step / ACT + per-step / No gating / Visual-Tactile | 50 / 90 / 30 / 80 / 40 | 0.033 / 1.0 / 0.003 / 0.47 / 0.011 |
| 17 | w/o optimization (PLD*) / w/o ControlTac / w/o critic loss / w/o reconstruction loss | 60 / 80 / 90 / 90 | 0.087 / 0.47 / 1.0 / 1.0 |
| 18 | No Scheduler / No Action Scale / Action Scale = 0.5 | 90 / 50 / 70 | 1.0 / 0.033 / 0.21 |

- 16개 중 4개만 0.05 아래이고, 그중 부품 제거는 "No Action Scale" 하나입니다. 나머지는 대안 설계(ACT + per-step, Visual-Tactile)입니다. 본문 "removing any component … leads to slower learning and lower final performance"는 16개 중 14개가 Ours 이하라는 방향성에서는 맞고, 단일 부품의 필요성은 이 크기로 확정되지 않습니다.
- "w/o optimization (PLD*)" 60%는 그림 4 Peg의 PLD* 끝점(그림 판독 60)과 같은 곡선으로 보입니다. 이 한 점(p = 0.087)이 핵심 설계(웜스타트 최적화)의 가장 직접적인 절제이고, 표 1(20회)의 PLD* 65% 대 100%(p = 0.008)가 더 강한 근거입니다.
- K6: 그림 16의 "ACT + Ours" 50%는 그림 5와 표 2의 Ours(ACT) 80%와 값이 다릅니다. 정의(per-step 키포인트 대 궤적 키포인트, 조건)가 달라 보이나 본문이 구분해 설명하지 않습니다.

## 8. 표 5 부드러움 (V14)

M-SPARC와 M-LDLJ는 본문 문장과 표가 일치합니다. 해석 시 주의: (1) 성공한 롤아웃의 평균이고 롤아웃 수가 없습니다. (2) 인간 시연은 사람 손으로 물체를 옮기고, 원격조작 시연은 Quest 손 추적을 로봇 말단으로 옮겨 로봇이 움직이므로 수집 장치가 다릅니다. (3) LDLJ 차이 1.67(시연)은 무차원 저크 비용 약 5.3배, 정책에서 3.60은 약 36.6배입니다. 정책이 시연보다 인간 쪽은 약간 부드러워지고(SPARC +0.23, LDLJ +0.74), 원격조작 쪽은 더 거칠어집니다(−2.20, −1.19). 본문의 "teleoperation data is less suitable"는 이 지표의 방향과 일치하지만, 성공률로 확인한 것은 그림 5의 원격조작 flow 90% 대 인간 flow 100%(p = 0.49)뿐입니다.
