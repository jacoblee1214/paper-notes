### V8. 실패 롤아웃을 쓴 과제 범위

4.2절은 "∼30 failure rollouts per cube task"라고 씁니다. 큐브 과제는 Stack Cubes와 Pick Cubes로 읽히는데, 표 2의 실패 추가 열에서 큐브가 아닌 세 과제도 값이 달라집니다(Hand-over −5, Stack Bowls +15, Pour +10). 실패 롤아웃이 큐브 과제에만 있었다면 이 변화는 실패 데이터가 아닌 요인(추가 학습 단계, 반복 변동)에서 온 크기가 되고, 칸 하나의 변동이 ±15 포인트에 이른다는 뜻입니다. 큐브가 아닌 과제에도 실패 롤아웃이 있었는지는 논문에서 확인되지 않아 저자 확인이 필요합니다.

## 3. 식 (6), 그림 6–7, 표 4·7·8

### V9. 식 (6)을 λ_fail = 1로 쓸 때 (산수)

식 (6)의 실패 목표는 clip(p_{t+H} − λ_fail · 1_fail, 0, 1)이고, 3.3절은 λ_fail = 1, p_t = t/T로 둡니다. 실패 표시가 켜진 창에서 p_{t+H} ≤ 1이므로 p − 1 ≤ 0이고, 0~1로 자르면 **p < 1인 모든 창에서 목표가 0**입니다. 3.3절의 "이 목표는 시간 진행을 보존한다"는 설명은 λ_fail < 1일 때 성립하고, λ_fail = 1에서는 실패 창의 목표가 상수입니다(`report/figures/own_value_target.png`).

- 그림 2(b)의 실패 막대는 진행도가 0에서 1 − λ로 끝나게 그려져 있어 식 (6)의 뺄셈과 읽는 방법이 조금 다릅니다. 부록 H는 "predicted values are unclipped in this visualization"이라 하여 히트맵의 값이 음수를 가질 수 있다고 씁니다. 즉 학습 목표의 자르기 여부와 시각화의 자르기 여부가 따로 서술됩니다.
- 공개 코드는 다른 식을 씁니다(시간 잔여에 +1, 자르기 없음에 가까움). 자세한 차이는 `04` D3, D4입니다.

### V11. 그림 7, 후보 수와 지연 (그림 판독 값)

| N | 상대 완료율 | 지연 (ms) |
|---|---|---|
| 1 | 0.80 | 약 370 |
| 2 | 0.89 | 약 815 |
| 4 | 1.00 | 약 925 |
| 8 | 0.945 | 약 1,270 |

- 완료율은 N = 4에서 가장 높고 N = 8에서 낮아집니다. 본문 "Larger candidate sets provide a smaller gain"은 "이득이 작다"로 쓰지만 읽은 값은 감소입니다.
- "상대" 완료율의 기준(N = 4를 1.0으로 정규화한 것으로 보임), 과제 이름, 시행 수가 없고 "a long-horizon grasping task"라고만 쓰여 있습니다. 표 2·3의 N = 4 이득(+3, +5 포인트)에 비해 N = 1 → 4의 상대 이득이 25%로 보입니다. 다른 과제와 지표입니다.
- **표 7의 380 ms는 행동만 내는 N = 1 지연과 맞고(그림 7 판독 약 370 ms), 점수화 N = 4의 지연은 약 925 ms로 읽혀 380 ms의 약 2.4배입니다.** "Motus보다 약 3배 빠르다"(1,220 / 380 = 3.21)는 행동만 쓸 때입니다. 점수화를 쓴 92% 결과의 지연으로는 Motus 대비 약 1.3배입니다(판독 값 기준).

## 5. 교란 요인과 빠진 대조

1. **학습 단계 수:** 알고리즘 2는 성공 학습 후 D_s ∪ D_f로 "계속 학습"합니다. 성공 데이터만으로 같은 단계를 더 학습한 대조군이 본문에 없어, 실패 데이터 효과와 추가 학습의 효과가 분리되지 않습니다.
2. **실패 데이터의 분포:** 실패는 초기 정책의 롤아웃이라 이후 평가에서 방문할 상태 분포를 더 많이 포함합니다. 성공 시연에 같은 정책의 성공 롤아웃을 섞은 대조가 없습니다.
3. **다른 실패 활용법:** 실패를 가치만, 영상만, 가중 모방에 쓰는 비교가 없습니다. 있는 대조는 모방에 그대로 쓰는 경우(63)뿐입니다.
4. **통계 단위:** 시드와 모델 학습 반복이 하나로 보이고, 실로봇 칸은 20회입니다.
5. **"미학습 변형"의 범위:** 본 과제와 같은 과제에서 색, 모양, 지시를 바꾼 세 개입니다(부록 B). 새 과제로의 일반화와는 다릅니다.
