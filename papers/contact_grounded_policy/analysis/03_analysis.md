# 03. 추가 검증 (MuJoCo 다지 손)

이 파일은 `03_derivations.md`(유도와 3-DoF toy)를 보완하는 추가 검증만 담습니다. 번호는 `03_derivations.md`의 절과 겹치지 않도록 이 파일 안에서 따로 매깁니다.

## 추가 검증 (2026-11-11)

### 추가 검증 1. 다지 손 MuJoCo 시뮬에서 매핑 실험 (Table III식)

**목적.** `03_derivations.md` §3의 3-DoF toy를 다지 손으로 옮겨, 실제 접촉 시뮬레이션에서도 (1) 상태+촉각 잔차 형식이 절대 형식보다 낫고, (2) 해석식 대비 학습 모델의 격차가 얼마인지, (3) 손끝 촉각만 있을 때 식별이 얼마나 무너지는지 봅니다.

**설정.** `analysis/extra_mujoco_mapping.py` (MuJoCo 4.0.0, torch CPU 4스레드, 시드 3, 약 98초).
- 손: 손가락 3개를 손바닥 반지름 5 cm 원 위에 120° 간격으로 놓고, 손가락마다 관절 3개(수직축 경첩), 링크 길이 5 / 4.5 / 4 cm입니다. 관절은 위치 액추에이터(kp = 2 N·m/rad, 속도 이득 0)로 구동하고 관절 감쇠 0.5로 정착시킵니다. 중력은 끕니다(수평 평면 손이라 중력항이 없습니다). 접촉 마찰은 0입니다.
- 물체: 원점에 고정된 구(반지름 3–5 cm). 반지름은 샘플마다 바뀝니다. 실제 로봇 손을 모델링한 것이 아니며, 공개 손 모델은 쓰지 않았습니다.
- 샘플: 목표 자세 a를 절반은 파지형(1.0–1.4 rad 부근, 잡음 0.1 rad), 절반은 자유 운동형(−0.2–1.2 rad)으로 뽑습니다. 접촉 전에 물체가 손과 겹친 시작 상태는 버립니다. 정착 5 s 뒤 최근 0.5 s 동안 관절 드리프트가 2×10⁻⁴ rad 이하인 샘플만 채택합니다. 채택 10,000개, 기각 1,008개입니다. 채택 샘플 중 접촉이 있는 비율은 6.2%입니다. **접촉이 드물어서 결과는 주로 자유 샘플의 평균에 가깝다는 점을 먼저 밝힙니다.**
- 평형식: 정착 상태에서 kp(a − q) + Jᵀf = 0이므로 해석식은 a = q − Kp⁻¹Jᵀf입니다. 접촉력은 MuJoCo의 mj_contactForce로 얻고, 부호는 finger가 geom2일 때 +Rᵀf로 정했습니다. 모든 손가락 접촉에 대한 Jᵀf가 솔버의 제약력 qfrc_constraint와 맞는지 확인했고, 최대 차이는 4.6×10⁻⁶입니다.
- 촉각 proxy: 링크별 접촉력의 세계 좌표 3성분(9 링크 × 3 = 27값). 손끝만 쓰는 조건은 원위 링크 3개(9값)만 씁니다.
- 학습: MLP 2층 128폭, Adam 1e-3, 배치 128, 100 epoch, L1 손실. 1:1 학습·검증 분할, 시드 3개(평균 ± 표준편차). 단위는 ×10⁻³ rad입니다.

**결과.** 검증 MAE (×10⁻³ rad, 시드 3개 평균 ± 표준편차).

| 모델 | MAE |
|---|---|
| a = q (잔차 0) | 0.478 |
| 해석식, 모든 링크 | 0.248 |
| 해석식, 손끝 링크만 | 0.262 |
| 상태만, 잔차 | 0.478 ± 0.000 |
| 촉각만, 잔차 | 0.237 ± 0.004 |
| 상태+촉각, 잔차 | 0.237 ± 0.002 |
| 상태+촉각, 잔차, 손끝만 | 0.235 ± 0.001 |
| 상태+촉각, 절대 | 8.81 ± 0.72 |
| 촉각만, 절대 | 346.9 ± 0.8 |

**결론.**
- 잔차 형식이 절대 형식보다 훨씬 낫습니다(0.237 대 8.81). 촉각만 있을 때도 같습니다(0.237 대 346.9). `03_derivations.md` §3의 toy 방향과 같습니다.
- 상태만(잔차)은 잔차 0 기준선과 같습니다. 이 손 설정에서 자세만으로는 접촉을 알 수 없고, 촉각이 정보를 줍니다.
- **해석식과 학습 모델의 격차는 측정되지 않았습니다.** 해석식의 오차(0.248)가 이미 정착 드리프트 바닥(약 0.24 × 10⁻³ rad, 최근 0.5 s 드리프트 허용치 2×10⁻⁴ rad에서 온 것)입니다. 학습 모델(0.237)도 같은 바닥에 있어, 숫자 차이는 의미가 없습니다. 정착 정밀도를 더 높이면 바닥이 낮아지지만, 이번 실행에서는 시간 제약 때문에 그렇게 하지 않았습니다.
- 손끝만 감지해도 손실이 없었습니다(0.235 대 0.237). 이 결과는 손끝 식별 한계를 **반박하지도 확인하지도 못합니다.** 접촉 샘플 중 근위 링크 접촉은 76개, 원위(손끝) 링크 접촉은 51개였고, 가운데 링크 접촉은 0개였습니다. 접촉이 드물고 기하가 제한되어 있어서입니다.

**한계.** 접촉 샘플 6.2%(채택 10,000개 중), 정착 드리프트 바닥, 중력과 마찰 0, 물체 고정, 손 모델은 자체 작성한 3손가락 평면 손입니다. 논문 Table III는 다른 손과 시뮬레이터 단위이므로 숫자를 직접 비교하지 않습니다.

### 추가 검증 2. 소형 상태·촉각 확산 모델과 visuomotor·visuotactile 확산 정책의 저차원 비교

**목적.** 상태와 촉각의 미래 청크를 확산으로 만든 뒤 매핑으로 행동을 얻는 구조(CGP)가, 행동 청크를 직접 확산하는 정책(DP)보다 나은지 저차원 과제에서 봅니다. 이미지는 쓰지 않습니다.

**설정.** `analysis/extra_cgp_vs_dp.py` (torch CPU 4스레드, 시드 3, 약 57초). 추가 검증 1과 같은 MuJoCo 손을 씁니다.
- 데이터: 목표 자세로 0.04 s 간격 48 스텝 추적하는 궤적을 학습 400개, 시험 100개 뽑습니다. 절반은 파지형(1.2–1.4 rad), 절반은 자유형입니다. 물체 반지름은 4–6 cm입니다. 학습 창 16,400개, 시험 창 4,100개, 촉각이 있는 창은 시험 기준 7.3%입니다.
- 촉각 proxy: 접촉 법선 방향으로 κ × 침투량(κ = 2000 N/m)입니다. 솔버의 법선력은 쓰지 않았습니다. 침투가 있는 파지 접촉에서 솔버 힘이 발산했기 때문입니다(중간 시도에서 샘플의 절반 이상). 그래서 이 촉각은 센서 모델이며 물리 힘이 아닙니다.
- 모델(모두 DDPM 20 스텝, 3층 MLP 256폭, 학습 3000 스텝, 배치 256, 8스텝 청크):
  - DP 시각운동: 관절과 물체 반지름으로부터 행동 청크를 예측합니다.
  - DP 시각촉각: 같은 입력에 현재 촉각을 더합니다.
  - CGP: 현재 관절과 반지름으로부터 미래 8스텝의 (관절, 촉각)을 확산하고, 각 쌍을 잔차 매핑 MLP(같은 학습 궤적에서 학습)로 행동에 옮깁니다.
- 기준값: 매핑에 참 미래 (관절, 촉각)을 넣은 값입니다. 매핑 자체의 오차 상한을 보려는 오라클이며 방법이 아닙니다.
- 평가: 시험 창의 행동 청크 평균 절대 오차(×10⁻³ rad). 개루프 평가입니다.

**결과.** 시드 3개 평균 ± 표준편차.

| 모델 | MAE (×10⁻³ rad) |
|---|---|
| DP 시각운동 | 320.4 ± 12.4 |
| DP 시각촉각 | 312.2 ± 10.1 |
| CGP (확산 미래 + 매핑) | 894.7 ± 39.5 |
| 매핑에 참 미래 입력 (오라클) | 44.1 ± 3.2 |

**결론.**
- 이 소규모 설정에서 CGP는 DP보다 나쁩니다(894.7 대 312–320). 논문 방향과 반대입니다.
- 원인은 매핑이 아니라 미래 (관절, 촉각) 확산입니다. 참 미래를 주면 매핑 오차는 44.1로 DP의 1/7 수준입니다. 확산 모델이 288차원 미래를 학습 3000 스텝으로 맞추지 못했습니다. 촉각 채널은 대부분 0이고 접촉 창이 7%뿐이라 특히 어렵습니다.
- 촉각 입력의 이득은 DP에서도 작습니다(320.4 대 312.2, 표준편차 안). 논문 Table II에서 촉각 관측만의 이득이 작은 것과 같은 방향입니다.

**한계.** 개루프 청크 오차만 봤고 폐루프 성공률은 없습니다. 이미지가 없습니다. 학습은 3000 스텝으로 짧습니다. 시드 3개입니다. 매핑은 준정적 식이 아니라 동적 추적 데이터에 학습했습니다(오라클 오차 44가 이 차이를 포함합니다). 촉각 proxy는 침투 기반 센서 모델입니다. 확산 모델의 크기와 학습량을 늘리면 결과가 달라질 수 있으며, 그 조건은 시험하지 않았습니다.

## 추가 검증 (2026-11-14): 16자유도 손(Allegro)에서 매핑 실험

**목적.** 2026-11-11 검증(3손가락 평면 손)에서 해석식과 학습 모델의 격차가 정착 드리프트 바닥(약 0.24 × 10⁻³ rad)에 묻혀 판정되지 않았고, 접촉 샘플이 6%뿐이라 손끝 감지의 한계도 보지 못했다. 이번에는 (1) 정착 조건을 고쳐 바닥을 낮추고, (2) 공개 손 모델로 옮겨 접촉 비율을 높인 뒤, Table III식 비교(잔차·절대, 상태·촉각, 잔차 0 기준선, 해석식, 손끝만 감지)를 다시 했다.

**설정.** `analysis/extra_allegro_mapping.py` → `analysis/extra_allegro_mapping_results.json`. CPU, 스레드 4, 시드 3, 실행 163 s.
- 손: `google-deepmind/mujoco_menagerie`의 `wonik_allegro`(Allegro Hand v3 MJCF). commit `370c4396…`, BSD-3-Clause, 2.5 MB 폴더를 `contact_grounded_policy/data/menagerie/`에 sparse clone으로 받았다. `data/`는 `.gitignore`에 넣었고 저장소에는 없다. 손가락 4개(검지·중지·약지·엄지), 관절 16개.
- 손 설정 변경: 중력 0, 관절 위치 액추에이터 kp = 5 N·m/rad(속도 이득 0), 관절 감쇠 0.5, 적분기 implicitfast, 마찰 0(마찰이 있으면 손가락이 구에 걸려 미끄러지며 정착이 수렴하지 않았다는 짧은 실행 확인), 손 자기 접촉 끔(접촉은 손–물체만).
- 물체: 원점 근처 고정 구(반지름 2.5–4 cm), 중심은 손끝 평균 위치에서 ±1.2 cm 흔든다.
- 샘플: 에피소드마다 손을 열린 자세에서 시작해 물체를 놓고, 목표 자세를 최대 4번 바꿔 가며(파지형 60%, 자유형 40%) 각 목표를 정착시킨다. 정착은 1.8 s 뒤 최근 0.4 s 동안 관절 드리프트가 2 × 10⁻⁵ rad 이하인 경우만 채택한다. 채택 6,000개. 기각 에피소드가 많다(15,553; 드리프트 기준이 엄격해서).
- 평형식: 정착 상태에서 kp(a − q) = Jᵀf_contact이므로 a = q − Jᵀf/kp. 접촉력은 `mj_contactForce`, 부호와 야코비안은 솔버 제약력과 맞췄다(관절 한계 행이 없는 샘플에서 최대 차이 2.7 × 10⁻¹⁵ N·m).
- 촉각 proxy: 링크별 접촉력의 세계 좌표 3성분. 관절이 있는 링크 16개 × 3 = 48값. 손끝만 쓰는 조건은 손가락마다 원위 링크 1개(4 × 3 = 12값). 손바닥 접촉은 관절이 없어서 쓰지 않는다.
- 평가: 검증 3000개(1:1 분할), 접촉 샘플 2485개, 그중 근위·중위 링크 접촉이 있는 샘플 2257개. MLP는 2층 128폭, Adam 1e-3, L1, 60 epoch. 타깃은 평균과 표준편차로 정규화했다. 단위는 ×10⁻³ rad.

**결과.** 검증 MAE (×10⁻³ rad, 시드 3개 평균 ± 표준편차). 열은 전체 검증, 접촉 샘플, 근위·중위 접촉이 있는 샘플.

| 모델 | 전체 | 접촉 | 근위·중위 접촉 |
|---|---|---|---|
| a = q (잔차 0) | 19.84 | 23.95 | 25.20 |
| 해석식, 모든 링크 | 0.106 | 0.128 | 0.139 |
| 상태 + 촉각, 잔차 | 2.39 ± 0.01 | 2.81 ± 0.00 | 2.82 ± 0.01 |
| 촉각만, 잔차 | 2.49 ± 0.01 | 2.96 ± 0.01 | 2.99 ± 0.01 |
| 상태만, 잔차 | 14.90 ± 0.06 | 17.16 ± 0.07 | 17.60 ± 0.09 |
| 상태 + 촉각, 절대 | 22.78 ± 0.75 | 23.27 ± 0.70 | 22.99 ± 0.72 |
| 상태 + 촉각, 잔차, 손끝만 | 11.81 ± 0.01 | 13.72 ± 0.02 | 14.49 ± 0.05 |

자유 공간(접촉 없음) 샘플에서 해석식의 오차는 6.7 × 10⁻⁶이다. 이것이 정착 바닥이다. 이전 검증의 0.24보다 약 35배 낮다.

**결론.**
- 해석식은 이 손에서 정확하다. 접촉 샘플 기준 0.13 × 10⁻³ rad이고, 바닥(6.7 × 10⁻⁶)보다 높지만 MLP 격차를 판정하기에는 충분히 낮다.
- 학습한 매핑(상태 + 촉각, 잔차)은 해석식보다 약 20배 나쁘다(2.8 대 0.13). 이 학습 규모(학습 3000 샘플, 60 epoch)에서 MLP는 해석식을 따라잡지 못했다. 격차는 측정되었다. 학습 규모를 늘리면 줄어들 수 있으나 이번 실행에서는 시험하지 않았다.
- 잔차 형식은 절대 형식보다 훨씬 낫다(2.39 대 22.8). 촉각만 있어도 같다(2.49). 상태만 있으면 잔차 0 기준선보다 약간 낫다(14.9 대 19.8). 이는 접촉 정보가 촉각에 있다는 뜻이다.
- **손끝만 감지하면 식별이 무너진다.** 전체 손실은 2.4에서 11.8로 약 5배 늘었고, 근위·중위 접촉 샘플에서는 14.5이다. 손끝 접촉만 있는 샘플(접촉 샘플의 9%)에서는 6.1로, 전체 감지 모델의 같은 부분집합(2.7)보다 2배 이상 나쁘다. 손끝 감지가 근위·중위 접촉 정보를 대신하지 못한다는 것이 이 모형에서 확인된다. 접촉 위치가 손끝 밖일 때의 식별 한계라고 해석한다.

**한계.**
- 손은 공개 모델이지만 물체는 고정 구 하나이고, 마찰은 0이며, 중력도 0이다. 실제 물체와 접촉 마찰·미끄럼은 포함하지 않았다.
- 정착은 준정적이라고 가정했다. 드리프트 기준을 넘지 못해 기각된 에피소드가 많다(15,553).
- 촉각은 센서 모델(접촉력의 세계 좌표 합)이다. 실물 촉각 센서의 응답, 잡음, 해상도는 다루지 않았다.
- 논문 Table III의 값은 다른 손·시뮬레이터이므로 숫자를 비교하지 않는다. 비교하는 것은 경향(잔차 대 절대, 손끝만 감지의 손실)뿐이다.
- MLP 학습량이 적다. 해석식 격차가 학습량 때문인지 입력 표현 때문인지는 구분하지 않았다.

## 추가 검증 (2026-11-14): 확산 학습량 3배에서 CGP 대 DP

**목적.** 2026-11-11 검증 2에서 CGP가 DP보다 나빴고, 원인이 매핑이 아니라 미래 (관절, 촉각) 확산이라고 봤다. 남겨 둔 조건은 "학습량과 모델 크기를 늘리면 결과가 달라지는가"였다. 이번에는 확산 학습 스텝과 매핑 학습 스텝을 3000에서 9000으로 늘려 같은 비교를 다시 했다.

**설정.** `analysis/extra_cgp_vs_dp_long.py` → `analysis/extra_cgp_vs_dp_long_results.json`. 2026-11-11 스크립트(`extra_cgp_vs_dp.py`)와 데이터·모델 구조·평가가 같고, 학습 스텝만 바꿨다(확산 9000, 매핑 9000, 배치 256). CPU, 스레드 4, 시드 3, 실행 159 s.

**결론.**
