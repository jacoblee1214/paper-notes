# TLA 수치 재계산과 일관성 검사

재계산 스크립트는 `analysis/recompute.py`(표준 라이브러리, 수 초), 결과는 `analysis/recompute_results.json`입니다. 그래프는 `analysis/plot_figures.py`가 `report/figures/own_*.png`로 그립니다. 분석일 2026-11-22.

**이 문서의 한계를 먼저 적습니다.** 논문은 방법마다 학습 한 번(단일 시드)만 보고합니다. 여기의 검정은 **시도 횟수에서 생기는 표본 오차만** 반영합니다. 학습 실행 사이의 차이는 반영하지 않으므로, 아래 p값은 "이 모델 한 개가 이 조건에서 보인 차이가 시도 잡음으로 설명되는가"에 대한 답입니다. 같은 방법을 여러 번 학습했을 때도 같은 차이가 날지는 답하지 못합니다.

## 0. 가정

| 항목 | 가정 | 근거 |
|---|---|---|
| 표 III, IV의 Suc | 50회 시도의 성공률(%) | 본문 "각 과제 50회 반복"(§V-D). 저널본은 "average success rate"라고 씀 |
| 표 III "Total" | 세 간격의 평균 (칸당 50회씩 합 150회) | V1에서 확인 |
| 표 I GCR 표본 | 단일 페그 시험셋 2k | §V-B "test set 2k"; GCR 정의에 쓰인 샘플 수는 논문에 명시 없음 |
| 표 II ID GCR 표본 | 4k (정사각·삼각 평가) | §V-C |
| 검정 | 두 비율 비교. 횟수가 정수면 양측 Fisher 정확 검정, 아니면 합동 z 검정 | |
| 구간 | Wilson 95% | |

## 1. 시뮬레이션 성공률 (표 III, 표 IV)

### 1.1 간격별 (표 III, 칸당 50회 가정)

| 비교 | 차이 (%p) | Fisher p | 판정 |
|---|---|---|---|
| SP-TLA 대 DP, 2.0 mm | 38 | 7e-6 | 확실 |
| MP-TLA 대 DP, 2.0 mm | 36 | 4e-5 | 확실 |
| SP-TLA 대 BC, 2.0 mm | 52 | 8e-9 | 확실 |
| SP-TLA 대 DP, 1.6 mm | 51 | 4e-8 (z 근사) | 확실 |
| MP-TLA 대 DP, 1.6 mm | 43 | 7e-6 (z 근사) | 확실 (DP 칸이 정수가 아님, `V2`) |
| SP-TLA 대 BC, 1.6 mm | 62 | 6e-11 | 확실 |
| SP-TLA 대 DP, 1.0 mm | 54 | 9e-8 | 확실 |
| MP-TLA 대 DP, 1.0 mm | 70 | 7e-13 | 확실 |
| SP-TLA 대 BC, 1.0 mm | 56 | 3e-8 | 확실 |
| SP-TLA 대 DP, 합계 (150회) | 48 | 1e-18 | 확실 |
| MP-TLA 대 DP, 합계 (150회) | 50 | 1e-20 | 확실 |
| SP-TLA 대 MP-TLA, 1.0 mm | −16 | 0.066 | 구별 안 됨 |
| SP-TLA 대 MP-TLA, 1.6 mm | +8 | 0.32 | 구별 안 됨 |
| SP-TLA 대 MP-TLA, 합계 | −2 | 0.71 | 구별 안 됨 |

**해석:** 기준선(BC, DP)보다 TLA가 나은 것은 시도 잡음으로 설명되지 않습니다. 단, 한 번 학습한 모델 두 개씩의 비교입니다. 두 TLA 변형 사이에는 차이가 확인되지 않습니다. 특히 "MP-TLA가 SP-TLA보다 낫다"는 여러 칸에서 확인되지 않습니다(위 표 마지막 세 줄).

### 1.2 페그별 (표 IV, 칸당 50회 가정)

| 페그 | SP-TLA | MP-TLA | 최고 기준선 | MP-TLA 대 최고 기준선 (Fisher p) | SP-TLA 대 BC (Fisher p) |
|---|---|---|---|---|---|
| 정사각 (ID) | 96 | 94 | 60 (BC, DP) | 8e-5 | 36 %p (p = 2e-5) |
| 삼각 (ID) | 76 | 92 | 84 (BC) | **0.36** | **−8 %p (p = 0.45)** |
| 원형 (OOD) | 92 | 94 | 62 (BC) | 2e-4 | 30 %p (p = 6e-4) |
| 육각 (OOD) | 90 | 96 | 66 (BC) | 2e-4 | 24 %p (p = 0.007) |

- **삼각형 ID에서 MP-TLA와 BC의 차이는 유의하지 않습니다**(p = 0.36). 삼각형에서 SP-TLA는 BC보다 낮습니다(p = 0.45, 방향 역전). 본문의 "두 TLA 모두 기준선보다 낫다"는 이 칸에서 성립하지 않습니다.
- **OOD에서 MP-TLA가 SP-TLA보다 낫다는 본문 주장**(§V-D)은 확인되지 않습니다. 원형 94 대 92, 육각 96 대 90으로 방향은 맞지만, 육각 p = 0.44, 원형 p = 1.0입니다. 이 두 비교는 `recompute.py`에 넣지 않고 같은 함수로 따로 확인한 값입니다.

## 2. 행동 정확도 (표 I, 표 II)

### 2.1 표 I (단일 페그, GCR 표본 2k 가정)

| 방법 | GCR (%) | Wilson 95% (%) |
|---|---|---|
| BC | 10.4 | 9.1–11.8 |
| DP | 8.5 | 7.4–9.8 |
| SP-TLA | 12.5 | 11.1–14.0 |

- SP-TLA 대 BC: 차이 2.1%p, 합동 z = 2.09, p = 0.037 (Fisher 0.042). **가정한 표본 2k에서 간신히 0.05 아래입니다.**
- SP-TLA 대 DP: 차이 4.0%p, p < 0.001.
- **단일 페그의 GCR 절대값은 8–13%입니다.** 세 방법 모두 행동의 대부분이 틀립니다. 이 지표에서 "정확하다"고 말하기는 어렵습니다.

L1 (표 I): x 감소율 78.6% (0.079 대 0.370, 본문 78%와 맞음, `V3`). y 감소율 59.6% (0.122 대 0.302, BC 기준), rz 감소율 15.6% (0.173 대 0.205, BC 기준). **rz에서는 차이가 작습니다.**

### 2.2 표 II (다중 페그, ID 4k 가정)

| 방법 | GCR ID (%) | L1 x, y, rz (ID) | L1 x, y, rz (OOD) |
|---|---|---|---|
| BC | 18.4 | 0.260, 0.655, 0.186 | 0.286, 0.722, 0.246 |
| DP | 7.4 | 0.371, 0.348, 0.480 | 0.386, 0.369, 0.544 |
| MP-TLA | 18.4 | 0.102, 0.114, 0.135 | 0.121, 0.102, 0.184 |

- MP-TLA 대 DP: GCR 차이 11.0%p, p < 1e-10 (가정 4k).
- **MP-TLA 대 BC: GCR 차이 0.** BC와 같은 GCR입니다. 논문의 "가장 정확하다"는 L1에서만 맞습니다.
- L1 감소율 (최고 기준선 대비, ID): x 60.8%, y 67.2%, rz 27.4%. OOD: x 57.7%, y 72.4%, rz 25.2%.
- L1은 표본 수 없이 평균만 있어 검정하지 못합니다. 같은 표본 4k에서 L1 차이의 표준오차를 알 수 없으므로, L1 차이가 유의한지는 **이 표에서 판정할 수 없습니다**.

## 4. 실험 설계 관찰

- **언어 조건의 효과는 분리되지 않았습니다.** BC(ResNet-50)와 TLA(Qwen2-VL 7B)는 백본, 입력 토큰, 출력 형식, 학습 방식이 모두 다릅니다. 같은 백본을 텍스트 없이 쓴 대조가 없어 "언어 기반"의 효과를 말할 수 없습니다.
- **라벨은 시뮬레이터의 정답 자세 오차에서 계산됩니다** (식 1–3). 기준선과 TLA가 같은 라벨을 맞추는지만 비교하며, 실제 최적 행동과의 비교가 아닙니다.
- **시도 수 대비 조건이 많습니다.** 표 III의 칸은 50회입니다. 본문 "2.0 mm에서 96%"는 48/50입니다. 이 정도의 표본으로 "85% 이상"을 주장하려면 하한 구간을 보고해야 합니다. 예: SP-TLA 2.0 mm의 Wilson 하한은 86.5%입니다.
- **저널 게재본은 실로봇 시도를 20회씩 합니다** (표 5, 6). v1에는 없으므로 이 분석에서는 검정하지 않았습니다. 20회에서는 80%의 Wilson 95% 구간이 약 58–92%로 넓습니다.

## 5. 이 분석이 말하지 않는 것

- 학습을 여러 번 했을 때 같은 차이가 나는지.
- 실로봇 성공률 (v1에 없음).
- L1의 절대 크기가 로봇에서 얼마나 중요한지 (단위 s가 없음).
- 저널 게재본의 실로봇 결과 (별도 판본, 이 분석의 대상이 아님).
