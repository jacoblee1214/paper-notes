# LingBot-VA 논문 분석 (arXiv:2601.21998)

*Causal World Modeling for Robot Control* (Lin Li, Qihang Zhang 외 10인, Robbyant/Ant Group, 칭화·HKUST 등). 분석 대상은 **arXiv v2 (2026-03-22)**이고, v1(2026-01-29)과 본문 수치는 같습니다. 차이는 `§버전 차이`에 정리했습니다. 분석일 2026-11-20.

## 1. 한 줄 요약

영상 생성 백본(Wan2.2-5B)에 행동 토큰을 같은 시퀀스에 끼워 넣고, 프레임 chunk 단위로 **인과적(block-causal) 자기회귀**로 미래 영상과 행동을 함께 생성합니다. 실행 후 실제 관측으로 영상 KV 캐시를 갈아 끼우는 **폐루프**와, 행동 추론과 실행을 겹치는 **비동기 추론**을 더했습니다. RoboTwin 2.0 50과제 평균 92.9(Easy)과 LIBERO 평균 98.5를 보고합니다.

## 2. 문제 설정과 주장 (§1, §3.1–3.2)

- 기존 VLA는 `a_t ~ π(·|o_t)`를 직접 학습합니다. 저자들은 시각 동역학과 운동 제어가 한 신호에 얽힌다고 봅니다 (§1, 식 (5)).
- 대안으로 `o_{t+1} ~ p(·|o_≤t)`를 먼저 학습하고, 역동역학 `a_t ~ g(·|o_t, o_{t+1})`로 행동을 복원합니다 (식 (6)).
- 세 가지 한계를 듭니다: 반응 간극(chunk 단위 개방 루프), 긴 기억 부족, 양방향 어텐션의 인과성 위반 (§1, §3.2). 해결책은 자기회귀 + KV 캐시 + 인과 마스크입니다.

## 3. 방법 (§3.2–3.4)

| 구성 | 논문 설명 | 위치 |
|---|---|---|
| 자기회귀 목표 | 식 (7): `o_{t+1:t+K} ~ p(·|o_≤t)`, chunk 안은 병렬(양방향), chunk 사이는 인과 | §3.2 |
| 행동 조건 | 식 (8): `z_{t+1:t+K} ~ p(·|z_≤t, a_<t)` | §3.2 |
| 역동역학 | 식 (9): `a_{t:t+K-1} ~ g(·|ẑ_{t+1:t+K}, z_≤t, a_<t)` | §3.2 |
| 구조 | 영상 스트림(Wan2.2-5B 초기화, 폭 d_v=3072)과 행동 스트림(같은 깊이, 폭 d_a=768), MoT로 연결 | §3.3, §4.2 |
| 시퀀스 | 영상 프레임을 τ=4로 솎아내고, 프레임마다 τ개 행동을 붙임 | §3.3 |
| 학습 목표 | 식 (11) `L_dyn`, 식 (12) `L_inv`, `L = L_dyn + λL_inv`, λ=1 | §3.3 |
| 잡음 증강 | 식 (10): 확률 0.5로 history를 `s_aug ∈ [0.5,1]`로 섞음 | §3.3 |
| 추론 | KV 캐시(Alg. 1), 영상은 s=0.5(Alg. 1) 또는 3 Euler 단계로 s=0.6까지(§4.2) | §3.4, §4.2 |
| 비동기 | 실행 중 다음 chunk를 미리 계산, 낡은 예측 대신 FDM으로 실제 관측에 맞춤(Alg. 2, Fig. 4) | §3.4 |
| FDM 손실 | 식 (13) `L_fdm` (후학습 때 추가) | §3.4 |

핵심 설계는 세 가지로 보입니다. (i) 행동 토큰과 영상 토큰을 한 인과 시퀀스에 두는 것, (ii) 학습 때 실제 관측을 조건으로 쓰는 교사 강요(teacher forcing)와 추론 때 실제 관측으로 KV 캐시를 갱신하는 폐루프, (iii) 잡음 섞인 영상 history에서도 행동을 복원하도록 학습해 영상 생성을 덜 하고 행동을 내는 것입니다.

## 4. 데이터와 학습 설정 (§4.1–4.2)

- 사전학습: 여섯 공개 데이터(AgiBot, RoboMind, InternData-A1, OXE OpenVLA 부분집합, UMI 계열, RoboCOIN), 약 16K 시간, 1.4T 토큰. AdamW, 최대 lr 1e-4, wd 0.01, bf16. 사전학습 코드는 저장소에 없습니다 (`04` D20).
- 행동 표현: 양팔 각각 EEF 7(위치와 쿼터니언) + 관절 7(최대) + 그리퍼 1, 합 30차원. 부족한 차원은 0으로 채움 (§4.1).
- 정규화: 분위수(q01, q99)로 [-1, 1].
- 사후학습: 과제당 50회 시연, 3K 스텝, lr 1e-5 (§4.2). 실세계는 500 스텝, lr 1e-4, 길이 150,000 (§4.3.1).
- 추론 설정(§4.2): 영상 CFG 5.0, 행동 CFG 1.0, 영상 3 Euler 단계(s=0.6), 행동 10 단계.

## 5. 실험 결과 (§4.3–4.5)

### 5.1 RoboTwin 2.0 (표 1, 표 S1)

- 학습: 깨끗한 장면 2,500회 + 무작위 장면 25,000회(과제당 500회), 50K 스텝, lr 1e-5, 영상 12.5Hz (§4.3.2).
- 결과 (Easy / Hard, 50과제 평균): LingBot-VA 92.9 / 91.6, Motus 88.7 / 87.0, π0.5 82.7 / 76.8, π0 65.9 / 58.4, X-VLA 72.9 / 72.8.
- horizon 3 과제에서 격차가 커진다고 주장합니다 (Easy +8.2, Hard +9.1).
- 주의: π0, π0.5, X-VLA, Motus의 수치는 Motus 논문에서 가져왔습니다 (표 1 주석). 같은 학습 조건인지는 확인하지 못했습니다.

### 5.2 LIBERO (표 2)

- 4개 스위트 각 3시드 × 500회 = 1500회, 평균 98.5 (Spatial 98.5±0.3, Object 99.6±0.3, Goal 97.2±0.2, Long 98.5±0.5).
- "새 최고 성능"으로 주장하지만 Object 99.6은 CronusVLA와 같고(표 2), Avg 98.5는 X-VLA 98.1보다 높습니다.
- 공개 저장소의 평가 스크립트와 체크포인트는 LIBERO-Long만 다룹니다 (`04` D13).

### 5.3 실세계 6과제 (그림 5, 표 S2–S7)

- 과제: Make Breakfast(10단계), Pick Screws(5), Fold Clothes(6), Unpack Delivery(5), Insert Tubes(6), Fold Pants(3). 과제당 시도 20회, 두 방법을 번갈아 실행 (부록 A).
- 표기된 성공률(LingBot-VA / π0.5): 75/70, 70/50, 35/30, 65/25, 40/30, 70/30 (%). 진행 점수: 97.0/73.0, 82.5/74.0, 48.8/62.9, 84.5/73.0, 85.8/79.2, 76.7/30.0.
- 본문은 "모든 과제와 두 지표에서 SOTA"라고 씁니다. 그러나 Fold Clothes 진행 점수는 48.8로 π0.5 62.9보다 낮습니다.
- 부록 규칙("모든 단계 완료 = 최대 점수일 때만 성공")을 적용하면 표기된 성공 수와 맞지 않는 시도가 여러 개 있습니다 (`03` §4). 규칙으로 다시 세면 LingBot-VA의 성공률은 65, 35, 25, 60, 40, 70%입니다.

### 5.4 분석 실험

- 데이터 효율(그림 8): 10회 시연에서 π0.5보다 진행 점수가 높다고 주장합니다 (실세계 Make Breakfast +15.6%p, RoboTwin Easy +10.3%p). 그림 수치는 텍스트에 없어 읽기 근사입니다.
- 시간 기억(그림 9): Wipe Plate(6회 닦기)와 Search Box(반대편 상자 재방문 방지). 실제 수치는 그림에 있고 본문에 표가 없습니다.
- 일반화(그림 10): 새 물체와 새 위치. 정성적 예시 위주입니다.
- 소거(표 3): RoboTwin Easy 기준 LingBot-VA 92.9, FDM 비동기 90.4, 단순 비동기 74.3, WAN 초기화 80.6.
- 초기화(그림 7): 무작위 초기화는 기울기 노름이 커서 불안정합니다. 정성 그래프입니다.

## 7. 읽으면서 찾은 것 (세부는 `03`, `04`)

1. 부록 실세계 표의 성공 열은 부록의 성공 규칙과 맞지 않습니다. 표 6개 중 5개 과제에서 LingBot-VA 또는 π0.5의 성공 수가 달라집니다 (`03` §4).
2. 소거 실험의 "비동기 2배 빠름"을 뒷받침하는 지연 측정값이 본문에 없습니다.
3. 공개 코드는 "shared backbone" 버전입니다. 논문 식 (§3.3)의 분리된 MoT(d_a=768)는 공개 `model.py`에 없습니다 (`04` D3).
4. 학습 코드에 FDM 손실(식 13)이 없고, 공개 평가 클라이언트는 동기 방식입니다 (`04` D11).
5. 본문 텍스트의 RoboTwin 수치가 서로 다릅니다: 결론 92.0, 본문 92.10(Easy)과 91.12(Hard, 표 3 문단), 표 1 92.9 / 91.6 (`03` §5).
