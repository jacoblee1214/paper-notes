## 2. 논문의 선행 계보

논문 §2와 참고문헌 기준으로 정리했습니다. 원문 번호를 씁니다.

| 묶음 | 대표 문헌 (논문 번호) | 이 논문의 위치 |
|---|---|---|
| 손 조작 VLA의 기반 | Diffusion Policy [2], π0 [21], π0.5 [76], VITRA [73] | 기준선은 π0.5와 VITRA. 행동 전문가는 DiT (Peebles & Xie [74]) |
| 사람 영상으로 사전학습 | VITRA-1M [73], HOI4D [9], Ego-Exo4D [66], HOT3D [70] | OmniShare는 장갑과 촉각을 더해 kinematic supervision을 씀 |
| 웨어러블/VR 사람 시연 | 장갑 원격조작 [11], [43], [10] | 장갑은 29개 엔코더와 촉각 배열 (§3.1.2) |
| 사람-로봇 정렬 | 시뮬 리타게팅 [15], [16], 사람 개입 [45], 정렬 미세조정 [46]–[48] | JAAS는 "정렬을 학습 전에 고정한 슬롯"으로 해결 |

| 다지 손 조작 | RL 데모 [1], 시뮬 RL [52]–[55], 원격조작 [1], [3] | 대부분 손 종류별 정책 |
| 손 행동 공통 표현 | GigaHands [71], ARCTIC [67], OakInk2 [69], TACO [68], AssemblyHands [65] | Table 1 비교. 본문은 "Dense" 라벨 (GigaHands와 OmniShare) |

**새로움의 위치.** 논문 스스로 말하는 새로움은 세 가지입니다. (1) 사람 장갑 데이터를 로봇 학습 데이터와 같은 VLA 사전학습에 넣는 규모, (2) JAAS라는 슬롯 기반 공통 행동, (3) GRL을 VLA 인지 토큰에 붙이는 방식. 비교 대상은 π0.5와 VITRA 두 개뿐입니다.

## 4. 근거와 한계

- 논문 주장의 선행연구 계보는 원문 번호로 적었습니다. 참고문헌의 각 항목 내용은 논문 텍스트에서만 확인했고, 원 논문을 열어 대조하지는 않았습니다.
- 관련 저장소의 수치는 각 폴더 분석 문서에서 가져왔고, 이번에 다시 계산하지 않았습니다.
