# Ego2X 주장 검증 (공식 코드 없음)

공식 코드와 데이터가 공개되지 않았습니다(`02_prior_work.md` §2). 그래서 `repo/` 클론, 코드 대조(D1–Dn)는 하지 않았고, **논문 주장 C1–C12를 본문 내부 일관성과 재계산으로 검증**했습니다. 재계산 근거는 `03_analysis.md`입니다. 판정은 다음 기준을 씁니다.

- **재현됨**: 보고 수치를 재계산하거나 본문 내부 값과 맞춘 결과가 일치함.
- **부분**: 방향은 맞지만 범위, 기준선, 선별이 주장보다 좁음.
- **원자료 필요**: 원자료가 없어 확인할 수 없음.
- **불일치**: 보고된 값끼리 또는 값과 쌍 수가 맞지 않음.

## 2. 추가 확인 사항
- **"첫 시도" 주장** (§1, §5): 검색 범위 안에서 반증하지 못했습니다. 주장의 범위를 확인할 수 없음을 적습니다.
- **"26.5%"** (결론부): 실제로는 percentage point입니다. 상대 향상으로 읽으면 65.4%입니다.
- **깊이 보정이 순환을 끊는다는 설계 주장** (§1, §3.3.1): 같은 표의 "1-DoF unbounded L2, 3-DoF, 6-DoF 적합은 발산 (+32.7 ~ +43.6 mm)" 보고가 뒷받침합니다. 이는 본문 내부 근거이며 외부 재현은 없습니다.

## 4. 구현 가능성 판정

**판정: 이 맥(Apple M4 Pro, 약 24 GiB 통합 메모리, MPS, CUDA 없음)에서 Ego2X 전체 재현은 불가능합니다.** 공식 코드도 프로젝트 페이지도 없고, 단안 영상 파이프라인은 여러 대형 모델(SAM 3, SAM 3D, FoundationPose, WiLoR, EgoHand, ProPainter, X-VLA 등)을 GPU에서 돌려야 합니다. RoboTwin 2.0 물리 검증은 시뮬레이터 설치와 자산이 필요하며, 이 맥에서 설치 가능 여부는 확인하지 않았습니다.

| 구성 요소 | 이 맥에서 가능한가 | 필요 자원 | 판정 |
|---|---|---|---|
| CORE 기록 스키마(식 1)와 등급 규칙 | 가능 | Python, numpy | 시작 가능 |
| 깊이 보정 Cauchy 목적함수(식 4)와 1-DoF 탐색 | 가능 (소규모) | numpy, 합성 광선 데이터 | 시작 가능 |
| 접촉 기반 IK(식 5)의 축소판 | 조건부 | 2–3링크 토이로는 가능. 실제 손 URDF는 필요 | 조건부 |
| 가림 제거와 피부 제거(식 6) | 조건부 | 영상과 분할 마스크 (SAM 3 등 GPU 모델 필요) | 조건부 (GPU 필요) |
| 단안 손·물체 추정 파이프라인 | 불가 | 여러 GPU 모델, 대규모 영상 | 불가 |
| HOT3D·EgoDex 평가 재현 | 불가 (데이터 다운로드, 추정기 실행) | 대용량 데이터, GPU | 불가 |
| RoboTwin 2.0 물리 검증과 X-VLA 사후 학습 | 불가 | 시뮬레이터, GPU 학습 | 불가 |
| 재계산 (표 7 쌍 검정, Wilson, 상대 변화) | 가능 | 수 초 | 완료 (`03`) |

**노력 추정 (측정 없음).**
- CORE 스키마와 깊이 보정 토이: 1–2주.
- 접촉 IK 축소판: 2–4주 (로봇 URDF와 손 모델 준비 포함).
- 전체 파이프라인: 수 개월 규모. GPU 자원과 여러 외부 모델의 설치가 병목입니다.

1. 초록의 33.7%가 HaWoR 6클립 결과인지, EgoHand 결과를 함께 낸 이유는 무엇인지.

4. 공동 학습의 3시드 원자료와 HuRo의 학습 설정.
