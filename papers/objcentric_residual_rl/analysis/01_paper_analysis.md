# 01. 논문 분석: Object-Centric Residual RL

*Object-Centric Residual RL for Zero-Shot Sim-to-Real VLA Enhancement* (Kinam Kim, Namiko Saito, Heecheol Kim, Katsushi Ikeuchi, Jaegul Choo, Yasuyuki Matsushita; KAIST, Microsoft Research Asia - Tokyo, The University of Tokyo). arXiv:2606.18953 v1 (2026-06-17 제출). CoRL 2026 포스터.

분석 대상은 **arXiv v1 하나**입니다. abs 페이지의 제출 이력에 v2가 없습니다(2026-11-15 확인). 원문은 `paper/paper.pdf`(19쪽, 16.5 MB)이고, 본문은 8쪽, 참고문헌은 9–11쪽, 부록(A.1–A.11)은 12–19쪽입니다. 논문 번호는 원문의 절과 표, 식 번호를 그대로 씁니다.

## 1. 한눈에 보기

- **문제.** 모방학습으로 만든 VLA는 작은 실행 오차가 쌓여 학습 분포 밖 상태에 들어갑니다. 잔차 RL은 동결한 VLA 위에 보정 정책을 얹는 방법이지만, 시뮬레이션에서 학습한 잔차를 실로봇에 옮기기 어렵습니다(§1).
- **세 가지 실패 방식(논문 정리).** 특권 상태 기반 잔차는 배포 때 증류가 필요하고, 이미지 기반 잔차는 시각 격차가 크고, 실로봇 잔차 RL은 비용과 안전 문제가 있습니다(§1).
- **제안.** 잔차의 관측을 **6자유도 물체 포즈, 고유감각, 기반 VLA 행동**으로 둡니다(Eq. 2). 이 세 값은 시뮬레이션과 실로봇에서 같은 방식으로 얻을 수 있다고 주장합니다(§3.2). 시뮬레이션의 VLA 짝은 같은 원격조작 행동을 MuJoCo에서 재생해 만듭니다(§3.1).
- **결과.** Franka FR3, 과제 5개, 과제당 20회. 실로봇 평균 성공률 **42%(기반) → 76%(기반 + 잔차)**(Table 1). 시뮬레이션은 3 시드 평균 7.6/20 → 17.2/20입니다.
- **부가 주장.** 잔차가 수정한 실로봇 롤아웃으로 기반 VLA를 SFT하면 성공률이 올라갑니다(§3.4, §5.4, Fig. 6c, 6d).

## 2. 방법 (§3, 부록 A.4–A.6)

### 2.1 세 단계

1. **Stage 1: 짝 VLA.** 실로봇 시연(과제당 30회)으로 `π_VLA^real`을 학습합니다. 같은 행동을 MuJoCo에서 재생해 `π_VLA^sim`을 학습합니다(§3.1, §4). 기반 모델은 GR00T-N1.5입니다[8].
2. **Stage 2: 잔차 RL.** 시뮬레이션에서 `π_res^sim`을 학습합니다. 관측은 Eq. (2)입니다.
   `s_t = [s_t^obj, s_t^prop, a_t^base]`
   행동은 Eq. (1)의 `a_t = a_t^base ⊕ π_res^sim(s_t)`입니다. 위치와 그리퍼는 더하고, 회전은 사원수 곱으로 합칩니다.
3. **Stage 3: 실로봇 배포.** `π_VLA^real`과 `π_res^sim`을 둘 다 고정하고 실행합니다. 포즈 추정기의 추적 신뢰도 `c_t`가 `τ_c = 0.5`보다 낮으면 포즈를 0으로 둡니다(§3.3, Alg. 2).

### 2.2 기반 행동 (Eq. 6)

VLA는 H = 16 스텝 행동 조각을 내고, 잔차는 매 스텝 마지막 조각에서 현재 기반 행동을 읽습니다. 잔차는 VLA의 이미지를 보지 않습니다. 그래서 시뮬레이션을 시각적으로 사실적으로 만들 필요가 없습니다(§3.1, §3.2).

### 2.3 관측 격차에 대한 가정 (Eq. 3, §3.2)

논문은 전이 조건을 `s^real = s^sim + η`, `η ~ P_η`로 씁니다. 그리고 세 성분에 대해 이렇게 주장합니다.

- 고유감각: 두 영역에서 같은 값이라서 η ≈ 0
- 기반 행동: 같은 시연으로 학습한 두 VLA의 출력이 가까워서 η ≈ 0
- 물체 포즈: FoundationPose[20]와 SAM2[21]로 추정하며, 유일하게 η가 0이 아닌 성분

포즈 오차는 두 방식으로 다룹니다. 첫째, 위치에 `U(-σ̃_p, σ̃_p)` 잡음(σ_p^max = 5 mm), 방향에 작은 회전 잡음(σ_q^max = 0.1 rad)을 매 스텝 더합니다(Eq. 4, A.6). 둘째, 확률 ρ_drop = 0.1로 포즈 벡터 전체를 0으로 둡니다(Eq. 5).

### 2.4 학습 세부 (§3.2, A.1, A.5, Table 3, Table 5)

- 알고리즘: TD3[38]. 잔차는 2층 MLP(액터 512, 크리틱 1024)입니다.
- 보상: 과제마다 단계형 밀집 보상 4단계(Table 3, 예: Lift는 Reach → Grasp → Lift). **보상 식은 없습니다.**
- Table 5: 과제마다 액터 학습률(1e-5 또는 3e-4), L2 정규화(0–1.0), 할인율(0.95 또는 0.99), 오프라인 비율(0.3–0.75), 최대 에피소드 길이(300 또는 500)가 다릅니다. **과제별로 다르게 조정했는데 그 방법은 보고되지 않았습니다.**
- 학습 스텝 수는 Fig. 4의 x축(약 50k)에서만 읽을 수 있고, 본문에 숫자가 없습니다.

### 2.5 시뮬레이션 (§4, A.2, Table 4)

- MuJoCo[39]. 물체 치수와 질량은 실물 측정값을 씁니다(Table 4). 그리퍼, 테이블 높이, 카메라 위치는 맞추지 않아도 된다고 씁니다.
- 학습 시 물체의 초기 위치와 자세를 작업 공간에서 무작위로 바꿉니다(A.2).
- 실제 장면과 비슷하게 그린 렌더링(A.3)은 이미지 기반 베이스라인에만 씁니다. 메인 방법에는 필요 없습니다.
- FR3 로봇 모델의 출처, 제어 주파수, 접촉 솔버 설정은 본문과 부록에 없습니다.

## 5. 주장과 실험의 틈

이 절은 본문 서술이 표와 그림에서 얼마나 확인되는지를 봅니다. 통계 재계산은 `03`, 주장별 판정은 `04`에 있습니다.

### 5.1 실로봇 전이: 방향은 맞지만 과제당 시도가 적음

- 42% → 76%(100회 합계)는 통계적으로 명확합니다. Fisher p ≈ 1.6e-6이고, 차이의 95% 구간은 21–46%p입니다(`03` §1).
- 과제별로는 5개 모두 올랐지만, Stand Cup Up은 5/20 → 8/20(p = 0.50)입니다. 부호 검정(5/5 양수)의 양측 p는 0.0625입니다.
- 과제당 시도가 20회라 과제별 차이의 신뢰구간이 넓습니다. 한 번의 실행에서 얻은 결과이고 시드 반복은 실로봇에 없습니다.

### 5.2 절제: 포즈 탈락은 효과가 보이지만 잡음 주입은 확인되지 않음

- 포즈 탈락을 뺀 설정은 76 → 58(−18, p = 0.010)로 떨어집니다. 두 장치를 모두 뺀 설정은 52(−24, p = 0.0007)입니다.
- 잡음 주입을 뺀 설정은 69(−7, p = 0.34)입니다. 본문의 "잡음 주입은 허용 오차가 좁은 과제에 도움이 된다"는 서술은 이 표로는 확인되지 않습니다. 특히 Close(20/20)는 변화가 없습니다.
- 본문은 "combined training yields the strongest transfer"라고 쓰지만, 두 설정의 차이가 있다는 근거는 p = 0.34입니다.

### 5.3 관측 공간: 차이는 크지만 베이스라인 구현이 다름

- Ours 76 대 이미지 기반 47, 증류 46은 p < 0.0001입니다. 차이는 크지만, 두 베이스라인은 별도의 학습 파이프라인(시각적으로 사실적인 렌더링, 증류 단계)을 씁니다. 관측 차이만 분리한 대조가 아닙니다.
- Close Drawer는 증류 기반이 20/20으로 Ours와 같습니다. 증류 손실은 과제에 따라 다르다는 뜻입니다.

### 5.4 "시뮬레이션과 실로봇의 실패가 같다" (A.7)

- 기반 정책은 시뮬레이션에서 평균 38%(7.6/20), 실로봇에서 42%입니다. 평균은 가깝지만 과제별 차이는 큽니다. Lift는 21.5%(시뮬)와 35%(실), Close는 56.5%와 70%입니다.
- 과제별 기반 성공률의 상관은 r = 0.71(p = 0.18, n = 5)입니다. 잔차 이득의 상관은 r = 0.38(p = 0.53)입니다. 과제 5개로는 두 상관 모두 판단할 수 없습니다.
- "같은 실패 분포"라는 주장은 실패 유형(Table 6)을 정성적으로 보여 줄 뿐입니다. 실패 빈도를 정량으로 맞춘 검증은 없습니다.

### 5.5 "η ≈ 0"과 포즈 잡음의 크기 (§3.2, A.6)

- 고유감각과 기반 행동이 η ≈ 0이라는 주장은 측정하지 않았습니다. 같은 행동 데이터로 학습해도 시뮬레이션의 접촉 동역학과 실로봇의 컨트롤러 추종 오차는 다릅니다. 논문도 §7에서 "동역학 격차(접촉 마찰, 그리퍼 순응)는 해결하지 못한다"고 인정합니다.
- 포즈 잡음 5 mm, 0.1 rad는 깊이 카메라 오차(RealSense D435, 1 m에서 2.5–5 mm)와 FoundationPose의 방향 흔들림을 근거로 골랐습니다(A.6). 실제 추정기의 오차 분포는 측정하지 않았습니다.
- A.11의 실패 사례(포즈 드리프트, 가림, 잘못된 물체)는 독립 잡음과 다릅니다. 드리프트는 시간에 걸친 상관이 있고, 잘못된 물체는 큰 이상치입니다. 이런 실패는 신뢰도 게이트를 통과한다고 논문도 씁니다(A.11).

### 5.6 본문 서술과 수치의 차이

- "roughly doubles"(A.8): 실로봇 9 → 16은 1.8배, 시뮬레이션 7 → 17은 2.4배입니다.
- "the residual learns to stay near zero when the base is correct"(A.8): 잔차 크기를 보고하지 않아서 확인되지 않습니다.
- "consistently improve"(§3.2, §5.1): 실로봇 Stand Cup Up 증가는 3회입니다(5.1 참조).

### 5.7 SFT 자기 개선 (§3.4, §5.4, Fig. 6c, 6d)

- 세 막대의 시도 수, 롤아웃 수, 시드 수가 없습니다. 47%와 59%의 차이에 대해 유의성을 말할 수 없습니다. n = 100을 가정해도 p ≈ 0.12로 유의하지 않습니다(`03` §4).
- 어떤 과제의 롤아웃을 얼마나 합쳐 학습했는지도 없습니다. 재현에 필요한 정보가 빠져 있습니다.

## 6. 논문이 밝힌 한계 (§7)

1. 포즈 추적(FoundationPose + SAM2)은 심한 가림이나 혼잡에서 실패합니다. 메모리 기반 추정이 완화책이라고 씁니다.
2. 대상 물체를 손으로 지정합니다. 열린 환경에서는 자동 식별이 필요합니다.
3. 포즈 관측은 시각 격차를 없애지만 동역학 격차(마찰, 순응)는 남습니다. 접촉이 많은 과제에서 보정이 부정확할 수 있습니다.
4. 잔차는 작은 편차만 고칠 수 있고, 기반 VLA의 학습 분포 밖 상태에서는 복구하지 못합니다.
5. 서브밀리미터 정밀도나 아주 작은 물체는 현재 포즈 추정의 정확도를 넘을 수 있습니다.

논문이 말하지 않은 한계는 `04` §5에 정리했습니다. 특히 실로봇 시도 수, 시드 반복, 기준선의 구현 차이입니다.
