# 01. 논문 분석: F2F-AP (arXiv:2604.02408)

*F2F-AP: Flow-to-Future Asynchronous Policy for Real-time Dynamic Manipulation* (Haoyu Wei, Xiuwei Xu, Ziyang Cheng, Hang Yin, Angyuan Ma, Jie Zhou, Jiwen Lu, Bingyao Yu; 칭화대 자동화학과, 베이징 구현 지능 시스템 핵심 연구실, 구현 지능·로보틱스 연구원). 분석 대상은 **arXiv v4 (2026-10-15, 18쪽)**입니다. 쪽·절·표 번호는 이 판 기준입니다. 분석일 2026-11-22.

## 0. 한 줄 요약과 위치

비동기 추론에서 정책이 보는 영상은 지연 때문에 낡습니다. 이 논문은 지난 6프레임에서 물체의 **희소 점 흐름(4점)**을 예측해 현재 영상 위에 그려 넣고, 그 "흐름이 그려진 영상"을 미래 관측 대용으로 정책(Diffusion Policy, UMI 구조)에 넣습니다. 로봇 상태도 지연 H만큼 앞선 값을 쓰고, 정책 인코더 특징이 실제 미래 영상의 특징과 가까워지도록 CLIP식 대조 손실을 겁니다. 학회는 **CoRL 2026 포스터**(공식 채택 목록 확인, `analysis/02_prior_work.md` §5)입니다.

| 항목 | 내용 |
|---|---|
| 입력 | 지난 6프레임 RGB(어안 GoPro, 0.1 s 간격), 지연 H 뒤의 로봇 상태 s_{t+H} |
| 중간 표현 | 4개 점의 시작 위치와 H 뒤 변위(흐름), 56×56 히트맵 |
| 정책 | CLIP ViT-B/16 인코더 + 1D 조건부 U-Net, DDIM 16단계 (UMI와 같은 구조) |
| 학습 데이터 | 과제당 100–200개 시연, "총 영상 약 10분"(부록 B.1) |
| 평가 | UR5e(고정 팔)와 Go2 + Saber 팔(사족 이동 조작기), 실로봇 7개 과제, 설정당 10 또는 20회 |
| 지연 | Δo ≈ 125 ms, Δi ≈ 200 ms, Δc < 50 ms, δt = 0.1 s, H = 4 (§4.1) |

## 1. 문제와 기여 (초록, §1, §3.1)

- **문제 1:** 청크 행동이 추론 시작 시각 기준이라 지연 H 동안 앞쪽 행동이 낡습니다(버려야 함). **문제 2:** 지연이 누적되어 정책이 환경보다 계속 뒤처집니다(§1).
- **VLASH(미래 상태)의 한계:** 상태는 s_{t+H}인데 영상은 o_t라서 입력끼리 시간이 어긋납니다(§3.1). π(a_{t+H:t+H+n} | s_{t+H}, o_t).
- **제안:** π(a_{t+H:t+H+n} | s_{t+H}, ô_{t+H}). ô는 예측 흐름을 현재 영상에 그려 만든 합성 미래 관측입니다(식 2). 영상 생성 모델(HunyuanVideo, CogVideoX, Wan)은 생성에 수 초가 걸려 쓸 수 없다고 봅니다(§3.2).
- **기여 세 가지:** (i) 히트맵 기반 흐름 예측기, (ii) 흐름 대조 학습, (iii) 지연을 명시적으로 모델링한 H = ⌈Δtotal/δt⌉와 행동 큐 실행(§3.4).

## 2. 방법 (§3, 부록 B–D)

### 2.1 지연 분해와 H (§3.1, §3.4, 그림 2)

- Δtotal = Δo + Δi + Δc. 측정값은 125 + 200 + <50 ms이고 δt = 0.1 s라서 H = ⌈Δtotal/δt⌉ = 4입니다(§4.1, 재계산 V7: 0.3 < Δtotal ≤ 0.4이면 H = 4).
- 행동 덩어리는 실행 시점에 맞춰 나오므로 앞부분을 버리거나 행동 융합(RTC식)을 하지 않고 큐에 쌓아 시각표대로 실행합니다(§3.4).

### 2.2 Flow2Future 모듈 (§3.2, 식 1–2, 부록 B–C)

- **입력:** V ∈ R^{6×224×224×3}, 16×16 패치, D = 384, 학습형 2D 공간 + 1D 시간 사인 위치 임베딩, 8층 BERT형 인코더(8 헤드, MLP 1536, Pre-Norm, GELU)(부록 C.2).
- **디코더:** 현재 프레임과 과거 프레임 특징 사이 반경 r = 2 국소 상관 볼륨 → 합성곱 + 전치 합성곱으로 56×56 확률 히트맵 → 점 추출 → 점 특징과 상관에서 오프셋과 흐름 회귀(부록 C.2). 식 (1)은 "소프트 샘플링 S(H(Zv))로 거친 시작점 + 오프셋 + 변위"라고 쓰지만, 부록 C.2는 "weighted K-Means로 키포인트 추출"이라고 씁니다(두 서술이 다릅니다. 공식 코드는 K-Means 쪽, `04` D8).
- **히트맵을 쓰는 이유(부록 C.1):** 정답 점의 색인에 물리적 의미가 없어서 일대일 손실이나 헝가리안 손실을 쓰면 평균 흐름으로 수렴한다는 설명입니다. 이 붕괴를 보여 주는 실험은 없고 "w/o Heatmap" 절제(5/20)만 있습니다(`03` C14).
- **정답 흐름 만들기(부록 B.2, 알고리즘 1):** 사람이 첫 프레임에 상자를 그리고 SAM으로 마스크를 추적, K-Means(K = 4)로 점을 뽑고 이전 프레임 중심으로 초기화해 시간 일관성을 확보, 변위는 H 스텝 뒤 점 위치 차이.
- **가림 처리(부록 B.3):** 그리퍼 없는 영상을 따로 같은 양 모아 깨끗한 정답 흐름을 얻고, 분리해 둔 그리퍼 마스크를 무작위로 덧씌워 UMI 촬영을 흉내 낸 학습 영상을 합성합니다.
- **그리기(식 2, 부록 E.3):** 흐름 벡터를 크기·방향에 따라 색을 입혀 현재 영상 위에 그립니다. 점 4개, 선 두께 5픽셀(부록 E.3).

### 2.3 흐름 대조 학습 (§3.3, 식 3, 부록 E.4)

- 예측(흐름이 그려진) 영상과 실제 미래 영상을 **공유 인코더 E_θ**와 **서로 다른 두 투영기**로 잠재 공간에 보내고, 코사인 유사도로 대칭 InfoNCE를 계산합니다. L = ½[ℓ(z^p, z^g) + ℓ(z^g, z^p)].
- 이웃 프레임은 서로 매우 비슷하므로 시간 마스크 M_{i,k} = 𝟙(d(i,k) = 0 ∨ d(i,k) ≥ τ_d)로 가까운 부정 예를 지웁니다. τ_d와 온도 τ, 손실 가중치는 본문·부록에 값이 없습니다(공식 코드의 값은 `04` D6).
- 부록 E.4: 연속 48개 샘플(0.1 s 간격)의 "흐름 영상 특징 대 실제 영상 특징" 코사인 유사도 히트맵에서 최대 유사도가 같은 시각이 아니라 예상 오프셋(H) 쪽에 있다고 보입니다(그림 11). 정성 결과 한 장입니다.

### 2.4 정책과 학습 (§3.4, 부록 C.3, D)

- 정책은 UMI 구조: CLIP 사전학습 ViT-B 인코더 + 1D 조건부 U-Net, 관측 지평선 T_obs = 2, 예측기 입력 T_pred = 6(관측 지평선 각 시점마다 동결된 F2F가 흐름을 그려 줌), DDIM 16단계.
- 예측기 학습: 4090 8장, Adam, 배치 32, 학습률 1e-4, 코사인 + 5 에폭 워밍업, 혼합 정밀도, 마스크된 패치 복원 보조 손실(부록 D.1).
- 정책 학습: AdamW, 배치 32, 학습률 3e-4(비전 백본 3e-5), 2000 스텝 워밍업, 소음 제거 손실 + 흐름 대조 손실(부록 D.1).
- 추론: RTX 3090, 5 Hz. 사족 로봇의 전신 제어기는 Jetson Orin(부록 D.2).

### 3.4 정성 결과 (부록 E)

- 실패 유형 4가지: 물체 미끄러짐, 시스템 불안정(전신 제어기 때문에 자세 변화로 넘어짐), 타이밍 불일치(그리퍼 동작 오차가 협소한 창에서 주된 실패 원인), 공간 정렬 실패(그림 8, E.2).
- 비교 실패 모드(그림 9): 단순 비동기는 같은 위치를 계속 놓치며 재시도, VLASH는 정지 위치를 앞서 예측하지 못해 지나침(E.1). 세 방법은 같은 추론 주파수에서 평가했다고 씁니다(`04` D4).

## 4. 한계 (§5)

저자 서술 한계 세 가지: (1) 지연 변동이 크면 고정 지평선 H가 맞지 않음, 다중 지평선 흐름 예측이 필요. (2) 과제별 흐름 예측기라서 범용 모델로 확장하려면 과제 조건 흐름 예측기가 필요. (3) 2D 픽셀 공간이라 3D 입력으로 확장해야 함.

저자가 쓰지 않은 한계(분석 결과):
- 흐름 예측 정확도(끝점 오차 등)를 한 번도 정량 보고하지 않습니다. 모든 이득이 "예측이 맞아서"라는 가정에 놓여 있습니다(`03` C16).
- 시도 수가 설정당 10–20회이고 모델은 설정당 한 번 학습한 결과로 보입니다. 과제 안의 비교는 대부분 통계적으로 구분되지 않고, 과제를 합친 합산에서만 뚜렷합니다(`03` §1).
- 단일 물체 4점 흐름이라 여러 물체, 그리퍼가 물체를 가리는 단계, 비강체에 대한 일반성은 시험되지 않았습니다(정성 서술 부록 B.3).
- 사족 로봇 결과는 공개 코드가 없어 확인할 수 없습니다(`04` D1).

## 6. 주장과 근거의 간격 (요약, 상세는 `03` §4)

1. 과제 합산에서 F2F-AP 우위는 확실하지만(MH p ≤ 3.2e-6), 과제별 비교는 28개 중 14개만 p < 0.05이고 28개 Holm 보정 후 0개입니다(`03` V2, V3).
