# 03. 보고 수치 재계산과 일관성 검사

재계산 스크립트는 `analysis/recompute.py`이고, 결과는 `analysis/recompute_results.json`입니다. 표 2–6의 값은 논문 v3에서 옮겼습니다. 이 논문은 **학습 실행 한 번의 평균 거리**만 보고하므로, 신뢰구간과 유의성 검정은 원자료 없이는 계산할 수 없습니다. 이 점을 §4에서 다룹니다. 재학습과 재현은 하지 않았습니다(사용자 지시).

### 1.1 "약 15%"의 세부

K=1 평균 거리에서 BC 우위(1 − BC/다른 모델):

- Dec+BC 대 Dec+DDPM: 15.1%
- Dec+BC 대 Dec+FM: 13.5%
- EncDec+BC 대 EncDec+DDPM: 15.4%
- EncDec+BC 대 EncDec+FM: 13.7%

차이는 ~1.5%p로 작습니다. 단일 실행이므로 이 차이가 학습 잡음보다 큰지는 알 수 없습니다.

### 1.2 "34%"의 어떤 비교인가

EncDec+FM의 K=10 값을 K=1 기준 여러 모델과 비교하면 다음과 같습니다.

| 비교 | 평균 | 최종 |
|---|---|---|
| 대 Dec+BC | 15.6% | **33.9%** |
| 대 EncDec+BC | 13.6% | 31.7% |
| 대 Dec+DDPM | 28.3% | 42.3% |
| 대 Dec+FM | 26.9% | 42.3% |
| 대 EncDec+DDPM | 26.9% | 42.3% |

"34%"는 **최종 거리, 결정론적 Dec+BC 대비, K=10**에만 맞습니다. 평균 거리로 읽으면 15.6%이고, 가장 큰 값은 42.3%입니다. 본문은 기준과 지표를 밝히지 않았습니다.

### 1.3 목표 이미지 비교

표 4의 "Dec+BC"(0.045/0.062)는 **궤적 예측**에서의 값입니다. "Dec+BC w/ goal"(0.035/0.029)은 **역동역학**(끝 관측 포함)에서의 값입니다. 목표 이미지는 추가 정보이므로, 이 개선은 모델 개선이라기보다 문제 설정의 차이입니다. 본문도 "기준 점수를 얻는다"고 쓰지만, 이 점을 한 번 더 강조하는 것이 맞습니다.

## 3. Best-of-K 개선량

| 모델 | 평균 K=1→10 | 최종 K=1→10 |
|---|---|---|
| Dec+DDPM | 22.6% | 38.0% |
| Dec+FM | 23.1% | 39.4% |
| EncDec+DDPM | 25.0% | 39.4% |
| EncDec+FM | 25.5% | 41.4% |

확률 모델은 K를 늘릴수록 최선 샘플이 정답에 가까워집니다. 최종 거리의 개선이 평균보다 큽니다. 이는 긴 청크 끝에서 모드가 더 많이 갈라진다는 해석과 맞습니다. 다만 K=10은 평가 비용을 10배 늘리므로, 실제 배치에서는 "단일 샘플 대 최선 샘플"의 차이를 따로 봐야 합니다.

## 4. 불확실성: 무엇을 계산할 수 없는가

- **원자료가 없습니다.** 샘플별 거리나 시드별 결과가 없어서 표준오차와 신뢰구간을 계산할 수 없습니다.
- **시드 수가 0명입니다(보고 없음).** 학습 잡음은 보통 평가 잡음보다 큽니다. 표 2의 격차(0.003–0.01 m)는 이 잡음보다 작을 수 있습니다.
- **가정 아래 민감도.** 테스트 에피소드 수를 338,000 × 1% ≈ 3,380로 두고, 에피소드 단위 독립과 거리 표준편차 σ를 가정하면 (스크립트 `sensitivity`):

| σ 가정 (m) | 평균의 표준오차 | 80% 검출력 최소 차이 (양측 5%) |
|---|---|---|
| 0.02 | 0.00034 | 0.0014 |
| 0.03 | 0.00052 | 0.0020 |
| 0.05 | 0.00086 | 0.0034 |

이 값들은 **테스트 분할 잡음만** 본 것입니다. 실제로는 시드 잡음이 더 크고, σ도 모릅니다. 표 2의 EncDec+FM과 Dec+DDPM(K=10)의 평균 차이는 0.003 m입니다. 테스트 분할 잡음만 보면 검출될 수 있지만, 학습 잡음을 넣으면 판단할 수 없습니다. 이 결론은 "단일 실행이라서 모델 순위를 확정할 수 없다"입니다.

## 5. 데이터셋 통계 일관성

| 항목 | 계산 | 결과 |
|---|---|---|
| 분할 시간 합 | 725 + 7 + 97 | 829 h (초록과 일치) |
| 테스트 비율 | 7 / (725 + 7) | 0.96% ("1%" 주장과 대략 일치) |
| 프레임 수 | 829 h × 3600 × 30 | 89.5 M (본문 90 M과 일치) |
| 평균 에피소드 길이 | 829 h / 338,000 | 8.8 s |

| 저장 용량 | 저장소 zip 합 5×300 + 16 + 200 | 1,716 GB ≈ 1.7 TB, 본문 2.0 TB와 다름 |

저장 용량 차이는 zip 압축 대 디스크 해제 크기 차이일 수 있습니다. 확인은 하지 못했습니다(다운로드 금지).
