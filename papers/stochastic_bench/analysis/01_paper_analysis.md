# 01. 논문 분석: Benchmarking Real-World Robotic Manipulation through Stochastic Challenges (arXiv:2611.12804)

*Gläßer, Şikaroğlu, Kupyn, Pollefeys, Bauer, Blum* (University of Bonn, Lamarr Institute, ETH Zürich, Microsoft). CoRL 2026 포스터. 분석 대상은 **arXiv v1 하나**(2026-11-09 제출, v2 없음)입니다. 쪽 번호와 절·표 번호는 이 v1 PDF 기준입니다.

## 0. 한눈에 보기

- **무엇을 주장하나.** 평가용 장면 집합을 고정하지 않고 장면을 뽑는 **분포**를 표준화합니다(stochastic challenge). 연구실마다 시드로 장면을 다시 짓고 자기 로봇으로 시도하며, 성공률을 시드에 걸쳐 평균합니다(§1, §3.1).
- **통계 틀.** 성공률 추정의 분산을 시드 간 분산 σ²_seed와 시도 잡음 B/J로 나눕니다(§3.2, 부록 B). 로봇 둘을 독립 시드로 비교할 때 필요한 시드 수는 식 (1), 시드 일부(비율 p)를 공유하면 식 (3)입니다.
- **벤치마크.** IKEA KALLAX 선반 3×4 격자에 문·서랍 삽입물을 무작위로 끼우는 생성기와 웹 사이트(KLX Benchmark)입니다(§4).
- **실험.** Hello Robot Stretch 3와 Boston Dynamics Spot을 서로 다른 두 연구실에서 돌려 문 열기·서랍 열기를 비교합니다. 시도는 총 568회, 시드는 로봇·과제당 6–8개입니다(§5.1).
- **핵심 수치 (표 2).** 문: Spot 0.711 대 Stretch 0.180(차이 0.531, 검출 한계 0.333). 서랍: 0.879 대 0.635(차이 0.244, 검출 한계 0.232). 서랍은 경계 근처라고 저자도 적습니다(§5.3).
- **우리 재계산 요약.** 표 2의 한계값과 본문 Welch 구간은 서로 정확히 맞습니다(`03` V3). 그러나 서랍의 Welch 자유도 12.9는 보고된 시드 수(6, 8)로는 만들 수 없습니다(상한 12, `03` V4). 서랍의 "구분 가능"은 z 분위수 대신 t 분위수를 쓰면 뒤집힙니다(`03` V5). 시드 공유 이득은 두 로봇의 시드 난이도가 완전히 같다고 가정한 값입니다(`03` V6). 자세한 내용은 `03`과 `04`에 있습니다.
- **코드.** 벤치마크 생성기와 서버 코드는 공개되어 있지 않습니다. 프로젝트 페이지 저장소는 정적 HTML뿐입니다(`02` §4).

## 1. 문제 설정 (§1, §2)

- 조작은 상호작용 과제라 정적 데이터셋으로 평가할 수 없고, 시뮬레이션은 물리 격차가 있으며, 고정 물체 집합(YCB)은 과적합 위험이 있다고 봅니다(§1).
- 분산 실물 벤치마크인 RoboArena [3]은 로봇 구성을, ManipulationNet [4]은 과제를 표준화하고 둘 다 탁상 과제에 머뭅니다(§1). 논문은 휴머노이드, 바퀴형 모바일 매니퓰레이터, 사족 로봇 같은 서로 다른 플랫폼을 실제 장면에서 비교하는 것을 목표로 합니다(§1).
- 제안의 요지: "누구나 시드로 어떤 장면이든 재구성할 수 있지만 참가자는 전체 장면의 작은 일부만 보고, 정답을 미리 알 수 없다. 데이터셋 벤치마크의 숨겨진 테스트 셋과 비슷하다"(§1, p.2). 같은 분포에서 뽑은 표본이면 플랫폼과 소프트웨어가 달라도 신뢰 수준을 정해 비교할 수 있다는 것이 저자 가설입니다.

## 2. 방법: 통계 틀 (§3, 부록 A–D)

### 2.1 점수 (§3.1, 부록 A)

- 시드 s가 장면 하나를 정하고, 장면마다 과제 Ms개가 있습니다. 과제 i를 J번 시도해 성공 Y ∈ {0, 1}을 얻고 Bernoulli(p_Rsi)로 모형화합니다. 시도 사이에 소프트웨어와 과제 상태를 초기화해 독립 가정을 "근사"합니다(§3.1).
- 3단 평균: p̂_Rsi = (1/J)ΣY, θ̂_Rs = (1/Ms)Σp̂_Rsi, μ̂_R = (1/K)Σθ̂_Rs. 과제를 먼저 평균하므로 과제가 많은 장면이나 더 자주 시도한 과제가 평균을 지배하지 않습니다(§3.1). 그래서 표 2의 성공률은 시도를 합산한 비율이 아니라 시드 평균입니다(`03` V1).
- p(s)는 균일, 즉 모든 장면이 같은 확률로 뽑힌다고 가정합니다(§3.1).

### 2.2 분산 두 가지 (§3.2, 부록 B)

- 전체 분산 법칙으로 V_R(J) = σ²_seed,R + B_R/J. 여기서 B_R = E_S[(1/Ms²)Σp(1−p)]입니다. 벤치마크 평균의 분산은 V_R(J)/K입니다.
- 결론: J → ∞여도 σ²_seed/K는 남습니다. 이 바닥은 시드 수 K로만 줄일 수 있습니다(§3.2). 이 서술은 전체 분산 법칙의 직접적인 결과이고 맞습니다.

### 2.3 필요 시드 수와 비교 (§3.3, §3.4, 부록 C)

- 한 로봇의 신뢰구간 반폭 h = z_{1−α/2}√(V/K), 정밀도 ε에는 K ≥ z²V/ε²(§3.3).
- 두 로봇을 독립 시드로 비교: Var(Δ̂) = 2V/K, 필요 시드 수 **K ≥ 2(z_{1−α/2} + z_{1−β})²(σ²_seed + B/J)/δ²** (식 1). 하한 K ≥ 2(z+z)²σ²_seed/δ²는 J로 줄일 수 없습니다.
- 같은 시드를 쓰면 시드 난이도가 쌍별 차이에서 상쇄됩니다. 시드 공유 비율 p에 대해 **Var(Δ̂) = 2[(1−p)σ²_seed + B/J]/K** (식 2), K ≥ 2(z+z)²[(1−p)σ²_seed + B/J]/δ² (식 3). p = 1이면 시도 잡음만 남습니다.
- 부록 C의 쌍체 모형은 θ̂_As = μ_A + a_s + ε_As, θ̂_Bs = μ_B + a_s + ε_Bs로, **같은 시드 난이도 효과 a_s가 두 로봇에 똑같이** 들어간다고 가정합니다. §3.5도 "공통 난이도 효과는 쌍체 비교에서만 가정한다"고 적습니다. 이 가정(두 로봇의 시드 난이도 상관 ρ = 1)이 식 (2)의 (1−p) 인수를 만듭니다. 우리는 ρ < 1일 때 인수가 (1−pρ)가 됨을 확인했습니다(`03` V6).
- 혼합 설계 식은 부록 C에서 "덧셈 근사"라고 부르지만, 공유 시드와 비공유 시드의 분산을 비율로 합산하면 위 모형 아래에서 정확히 같은 식이 나옵니다(우리 유도, `03` §6).

### 2.4 가정 (§3.5)

독립 시드 표집, 시도의 독립 Bernoulli 근사(초기화로 근사), 시드 난이도는 로봇별 σ²_seed,R로 포착, 공통 난이도는 쌍체에서만, 시드 수준 점수의 정규 근사, 선택적 보고를 막는 중앙 서비스(웹)가 필요합니다.

### 2.5 부록 D 확장

과제 유형별 층화(문, 위 서랍, 아래 서랍), 시도 수준 로지스틱 혼합효과 모형(고정효과 로봇·과제·상호작용, 시드와 시드 내 과제의 임의효과), 사전에 정한 동등성 한계 δ_eq에 대한 신뢰구간 기반 동등성 검정입니다. "헤드라인 비교의 강건성 점검으로 쓴다"고 쓰지만 **본문과 부록 어디에도 모형 적합 결과가 없습니다**(`04` C14).

## 3. KALLAX 벤치마크 (§4)

- **생성기.** 3×4 격자에서 빈 위치를 비복원으로 균일 선택합니다. 빈 비율 0.5는 빈 위치 6개입니다. 남은 위치에 최대 82종의 KALLAX 호환 삽입물(문, 서랍 포함)을 배정하며, 평가한 구성의 문 삽입물은 서랍 삽입물의 약 2.5배이고 서랍 삽입물 하나는 서랍 두 개입니다. 물체 찾기 과제는 YCB 79개에서 뽑습니다(§4).
- **과제.** Open(문·서랍을 목표 상태까지 열기), Pick(지정 물체 꺼내기), Place/Move(물체를 목표 칸으로 옮기기). 논문 실험은 Open만 씁니다(§4, §5.1).
- **웹 인터페이스.** 구성(시드) 생성, 조립 설명과 물체 목록, 과제 인스턴스 내보내기, 결과 기록. 기록은 "투명성을 높이고 선택적 보고를 막기 위한" 것입니다(§4).
- **성공 판정.** 부분 열림, 놓침 등 모호한 실패는 기준이 필요하며 이 연구는 기록과 사람 검토로 확인했습니다. VLM 기반 자동 검증은 장기 과제입니다(§4). 열림 기준은 문·서랍 모두 10 cm 이상입니다(§5.1).
- **프로젝트 페이지의 추가 서술** (논문에는 없음): 빈 칸은 "확률 0.5로 비워 둔다", 새 시드는 이전 시드의 결과를 제출해야 받을 수 있다(`04` C11, C12).

## 4. 실험 (§5)

### 4.1 설정 (§5.1)

- 로봇과 스택: Stretch 3는 Stretch-Compose [25], Spot은 SpotLight [27] 기반 스택입니다. 두 스택은 Spot-Compose [26]에서 갈라진 "다르지만 관련된" 자율 스택입니다. 환경 추론, 손잡이와 물체 인식, 위치나 자연어 목표를 받는 이동·조작 기능을 가집니다.
- 공유 시드 실험에서는 **연구자 한 명**이 두 연구실의 장면을 모두 지었습니다. 재구성 팀에 따른 변동은 통제했지만 측정하지 않았습니다(§5.1, §6).
- 시도 수와 시드 수: 문은 Spot 62회·6시드, Stretch 130회·7시드, 서랍은 Spot 88회·6시드, Stretch 288회·8시드. 합계 568회. Spot은 약 150회를 한 사람이 사흘에 걸쳐 수행했습니다(§5.1).
- 성공 기준: 문이나 서랍을 10 cm 이상 열기. 부분 성공은 실패(표 2 캡션).

### 4.2 변동 분석 (§5.2, 표 1)

| 시드 집합 | 서랍 Spot | 서랍 Stretch | 문 Spot | 문 Stretch |
|---|---|---|---|---|
| same seeds | 92.7 | 58.1 | 86.3 | 12.8 |
| subset 1 | 65.0 | 61.9 | 66.7 | 16.8 |
| subset 2 | 100.0 | 51.3 | 75.0 | 20.2 |
| subset 3 | 87.5 | 70.7 | 100.0 | 30.0 |

- 본문 해석: 무작위 부분집합 추정은 시드 변동이 크고(특히 Spot), "서랍 Spot subset 1 대 Stretch subset 3"처럼 작은 표본의 잡음이 순위를 뒤집을 수 있습니다(§5.2).
- 부분집합의 크기, 겹침, 표 2 값과의 관계는 적혀 있지 않습니다(`03` V8).

### 4.3 검출 가능 한계 (§5.3, 표 2)

- 파일럿 설정 α = 0.10, 검정력 80%라서 z_{1−α/2} + z_{1−β} ≈ 2.49입니다. δ_min,t = 2.49·SE_t, SE_t = √(V̂_Spot,t/K_Spot,t + V̂_Stretch,t/K_Stretch,t)입니다.
- 표 2: 문 0.7109 / 0.1802 / 차이 0.5307 / 한계 0.333 / "distinguishable", p = 0.5 혼합 한계 0.256. 서랍 0.8792 / 0.6352 / 0.2439 / 0.232 / "distinguishable", 혼합 한계 0.183.
- 보조 불확실성: Welch 95% 구간(Spot − Stretch) 문 23.4–82.8점(ν = 10.4), 서랍 4.2–44.6점(ν = 12.9).
- 해석: 서랍은 결정 경계에 가깝고, 한계를 절반으로 줄이려면 시드가 약 4배 필요합니다. 혼합 설계(p = 0.5)는 한계를 33.3 → 25.6(문), 23.2 → 18.3(서랍)점으로 줄입니다. 두 설계 모두 같은 질적 결론을 줍니다.

## 5. 한계 (논문 §6)와 우리가 더한 점

- **논문이 인정하는 한계.** 작은 차이를 가르려면 시도가 많이 필요, 재구성 팀 간 변동 미측정, 성공 보고의 정직성에 의존(영상 업로드와 VLM 검증이 후보).
- **우리가 더한 점** (근거는 `03`, `04`):
  1. 로봇, 연구실, 소프트웨어 스택이 완전히 겹칩니다. 한 로봇의 차이를 구현이나 연구실 탓으로 나눌 수 없습니다. 벤치마크가 "시스템 전체"를 비교한다는 목적에는 맞지만 "구현체 간 비교의 검증"은 아닙니다.
  2. 시드가 6–8개라서 분산 추정이 불안정합니다. 시드 6개의 분산 추정은 95% 구간이 0.39–6.0배입니다(`03` V10). 계획용 K가 같은 비율로 흔들립니다.
  3. 시드 공유 이득은 ρ = 1 가정에 의존하며 논문 데이터(같은 시드 행)로 ρ를 추정하지 않았습니다(`03` V6).
  4. 정규 근사 규칙은 시드가 적을 때 서랍 판정을 뒤집을 수 있습니다(`03` V5, 토이).
