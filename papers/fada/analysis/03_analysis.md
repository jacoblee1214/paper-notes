# 03. 재계산, 일관성 검사, 주장 판정

원문 수치는 `01_paper_analysis.md`의 표를 따릅니다. 재계산은 `analysis/recompute.py`(수 초, CPU)가 하며 결과는 `analysis/recompute_results.json`입니다. 그래프는 `analysis/plot_figures.py`가 그립니다.

## 0. 가정과 방법

논문에는 "±"의 정의와 일부 시도 수가 없습니다. 아래 가정을 씁니다. 가정이 틀리면 p 값이 바뀝니다.

- **"±"는 표준편차(SD)로 읽습니다.** 표준 오차(SE)라면 검정이 훨씬 강해집니다. 논문은 어느 쪽인지 적지 않았습니다 (V-가정 1).
- **시도 수 n.** 실로봇 표 1은 본문대로 5회입니다. 시뮬 표 2는 "20 randomized-command trials"(§5.6)에서 가져와 20으로 둡니다. 표 5는 본문과 캡션이 다릅니다. 캡션의 5 시드를 씁니다 (K9). 표 8은 표 2와 같은 20으로 둡니다. 표 9는 1024 병렬 환경입니다. 그림 8은 n = 10입니다.
- **성공률**은 Fisher 정확검정(양측)입니다. **평균**은 Welch t 검정(양측)입니다. 여러 과제를 한꺼번에 볼 때는 Holm 보정을 따로 적습니다.
- 표 3과 표 4는 분산이 없습니다. 유의성을 판정할 수 없습니다.

## 1. 재계산 결과

### 1.1 실로봇 성공률 (표 1, n = 5)

| 비교 | 관측 | Fisher p |
|---|---|---|
| G1 Slope: FADA 대 FADA-zs | 4/5 대 1/5 | 0.21 |
| G1 Slope: FADA 대 TF–DAgger | 4/5 대 0/5 | 0.048 |
| T1 Basket: FADA 대 FADA-zs | 5/5 대 1/5 | 0.048 |
| T1 Basket: FADA 대 TF–DAgger | 5/5 대 0/5 | 0.008 |
| 두 과제 합산: FADA 대 FADA-zs | 9/10 대 2/10 | 0.006 (두 과제 확률이 같다고 가정한 참고값) |

해석: 5회로는 "제로샷 대비 개선"을 확실히 보이기 어렵습니다. 4/5 대 1/5는 p = 0.21입니다. 0/5 기준선과 비교하면 p < 0.05에 들어갑니다. 저자가 말하는 "TF–DAgger는 두 과제 모두 실패"는 확실합니다.

### 1.2 실로봇 정규화 오차 (표 1, n = 5, SD 가정)

| 과제 | 제로샷 대비 감소 | Welch p (대 FADA-zs) | TF–DAgger 대비 감소 |
|---|---|---|---|
| G1 Loco + Payload (Ēv) | 38.2% | 0.20 | 20.3% |
| G1 Kungfu (Ēmpjpe) | 27.1% | 0.0008 | 14.0% |
| T1 Loco + Payload (Ēv) | 17.0% | 0.0001 | 13.4% |

- 세 과제 평균: 제로샷 대비 **27.4%**, TF–DAgger 대비 **15.9%**. 본문 수치와 일치합니다.
- G1 부하 과제는 FADA-zs의 SD가 0.711로 커서 p = 0.20입니다. 방향은 같지만 통계적으로 약합니다.

### 1.3 시뮬 전이 (표 2, MuJoCo 열, n = 20 가정)

| 과제 | 제로샷 대비 감소 | p (대 FADA-zs) | p (대 TF–DAgger) |
|---|---|---|---|
| G1 Slope | 15.4% | 0.14 | 0.08 |
| G1 Kungfu | 25.7% | < 0.001 | < 0.001 |
| T1 Loco + Payload | 15.1% | 0.001 | 0.013 |
| T1 Slope | 11.6% | 0.17 | 0.23 |
| T1 Falcon | 60.6% | < 0.001 | < 0.001 |

- **Holm 보정 (5개 과제, 대 FADA-zs):** 세 과제(Falcon, Kungfu, T1 Loco)만 α = 0.05를 넘습니다. G1 Slope와 T1 Slope는 넘지 않습니다.
- **평균 감소 (K3):** 본문 "24.7%"는 **합계의 비율**(1 − Σ FADA / Σ FADA-zs)과 일치합니다. 과제별 감소율의 산술 평균은 25.7%입니다. TF–DAgger 대비 26.8%는 두 정의가 같습니다.

### 1.4 TF–CoPred-ft 대 TF–CoPred-zs (표 2, n = 20 가정)

다섯 과제 모두 나빠졌습니다. 유의성은 G1 Slope(p < 0.001), G1 Kungfu(p < 0.001), T1 부하(p < 0.001), T1 Falcon(p = 0.023)에서 확인되고, T1 Slope는 p = 0.14입니다. 방향은 확실합니다.

### 1.5 페이로드 스윕 (표 3, 분산 없음)

FADA@10 kg가 5 kg와 15 kg에서 얻는 개선은 FADA 적응 개선의 **90.9%**와 **89.9%**입니다. 본문 "약 90%"와 일치합니다. 단일 실행이므로 유의성은 판정할 수 없습니다.

### 1.6 예측 지평 (표 4, 분산 없음)

K = 1에서 K = 6으로 가면 G1 Ēmpjpe는 17.0%, T1 Ēv는 18.7% 줄어듭니다. 본문 "약 18%"는 T1에 맞고 G1에는 약간 후합니다 (K6).

### 1.7 LoRA 대 전체 IDM 미세조정 (표 5, n = 5 시드)

| 과제 | LoRA 대 전체 (p) | LoRA 대 제로샷 (p) | 전체 대 제로샷 (p) |
|---|---|---|---|
| G1 Slope | 0.31 | 0.47 | 0.71 |
| T1 Loco | 0.15 | 0.12 | 0.50 |
| T1 Slope | 0.031 | 0.51 | 0.17 |

- LoRA가 세 과제에서 가장 낮은 평균을 보이는 것은 맞습니다. 그러나 LoRA가 **제로샷을 유의하게 낫게 하지는 않습니다**(p = 0.12–0.51).
- "전체 IDM 미세조정은 제로샷보다 나빠진다"는 본문 주장은 방향만 맞습니다. 세 과제 모두 p = 0.17–0.71입니다 (C9).

### 1.8 제로샷 절제 (그림 8, n = 10)

| 비교 | 관측 | Fisher p |
|---|---|---|
| FADA 대 −B (행동 덩이 전체 맞춤) | 10/10 대 4/10 | 0.011 |
| FADA 대 −A (플래너 관측 회귀) | 10/10 대 7/10 | 0.21 |
| FADA 대 −A·B | 10/10 대 1/10 | < 0.001 |
| −B 대 −A | 4/10 대 7/10 | 0.37 |

−B의 하락은 유의합니다. −A의 하락(10 → 7)은 방향만 있고 통계적으로 확인되지 않습니다 (C11).

### 1.9 구조 절제 (표 8, n = 20 가정)

- TTT 대 MMM: p < 0.001. TTT 대 MTM: p = 0.001. **TTT 대 TTM: p = 0.11.**
- 본문 "MLP로 바꿀수록 단조롭게 약해진다"는 양 끝과 MTM 쌍은 맞지만, 인접한 TTM–TTT는 유의하지 않습니다.
- 열 정규화 기준은 MMM = 1.000입니다. 그래서 "소스 평가에서 거의 같다"는 주장은 MMM 대비 약 4%의 차이에 기대고 있습니다. 절대값이 없습니다 (K10).

### 1.10 같은 시뮬레이터 이동 (표 9, 1024 환경)

FADA의 감소율은 G1 부하 18.9%, T1 Slope 4.5%, T1 부하 7.8%입니다. 1024 환경의 p 값은 0에 가깝지만, 환경은 독립 시도가 아니므로 p 값은 의미가 약합니다. 효과 크기가 작은 과제(T1 Slope 4.5%)가 있다는 점을 봐야 합니다.

### 1.11 팔 실험 (§5.7, 그림 12)

- 일관성 격차 감소: (0.079 − 0.037) / 0.079 = **53.2%**. 본문 "약 54%"와 차이는 반올림 수준입니다 (K7).
- 플래너 RMSE 변화: 0.052 / 0.049 − 1 = **6.1%**. 본문 "7%"와 차이는 반올림 수준입니다 (K7).
- 말단 추종 오차 24%와 플래너 RMSE 39%는 그림에만 있어 확인할 수 없습니다.

## 4. 해석의 한계

- **n = 5 실로봇.** 5회로는 과제당 효과를 세밀하게 나누기 어렵습니다. 저자도 본문에서 "평균 5회"라고 씁니다.
- **n = 20 시뮬.** 한 명령 시도 집합의 분산을 쓴 것입니다. 명령을 바꾸면 결과가 달라질 수 있습니다.
- **플래너 동결의 해석.** 플래너 RMSE가 적응 후 39% 줄었는데 플래너 가중치는 얼려 있습니다. 저자는 IDM이 플래너의 예측 쪽으로 로봇을 옮긴 것으로 읽습니다. 이 해석은 플래너가 실제 행동을 예측하는 능력을 잃지 않았다는 증거가 필요합니다. 그림으로만 보여 줍니다.
- **적응 데이터와 평가 데이터의 분리.** 목표 롤아웃은 한 번 수집해 적응에 쓴다고만 적혀 있습니다(B.3). 평가 윈도가 적응 데이터와 겹치는지, IDM 손실이 어느 쪽 데이터에서 계산됐는지는 본문에서 확인할 수 없습니다. 이 점이 C7의 해석을 약하게 합니다.
- **적응 800 스텝과 배치 4096.** 목표 데이터가 약 6000 윈도라면 800 × 4096 = 3.3백만 샘플 추출은 같은 윈도를 수백 번 되풀이하는 것입니다. 논문은 과적합 여부를 보고하지 않습니다. 다만 표 5에서 전체 미세조정이 나빠진 것이 이와 관련될 수 있습니다.

## 5. 토이 검증 (미실시)

선택 사항입니다. 이 분석에서는 실행하지 않았습니다. 이유: 논문의 중심 주장 C14(플래너 동결 대 전체 적응)를 확인하려면 두 대조를 가진 토이가 필요한데, 이는 별도 실험 설계와 사용자 확인이 필요한 재현 작업입니다. 재현 계획은 사용자 확인 후 정합니다.

## 6. 버전 차이의 수치 영향

v1과 v2는 표 1, 2, 4, 5, 8의 셀 값과 본문 수치가 같습니다 (`01` §0). 새 수치는 표 3(페이로드 스윕)과 표 9(같은 시뮬레이터)입니다. 재계산 결과에 영향을 준 변화는 없습니다.
