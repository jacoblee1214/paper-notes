# 03. 수치 재계산과 일관성 검사

재현(학습·롤아웃)은 하지 않았습니다. 논문 표 3, 4, 5, 9, 10, 11과 본문 수치를 옮겨 다시 계산했고(`analysis/recompute.py`, 수 초, 결과 `recompute_results.json`), 프로젝트 페이지가 공개한 **셀 단위 시뮬레이션 결과**(과제 x 레벨 x 모델 x 규모, 모델당 SR·Sub-SR)와 Appendix C 수치로 표 3과 레벨별 수치를 처음부터 다시 만들었습니다. 검사 번호는 V1부터이고 `recompute.py`의 출력 구획과 같습니다. 판정은 §7에 C1–C14로 모았습니다.

시도 수 가정(논문 부록 B.2, F): 시뮬 쌍당 10회, 실제 쌍당 5회, 5과제 x 4레벨 = 20쌍, 규모 3개. 그래서 시뮬 모델당 한 설정(규모 평균) 200회가 아니라 규모별 200회 x 3 = 600회, 실제는 규모별 100회 x 3 = 300회, 레벨별(표 5)은 5과제 x 5회 x 3규모 = 75회입니다. 아래 p값은 시도가 독립이라는 가정이라 같은 과제·같은 모델 반복 때문에 실제로는 더 큽니다(낙관적 하한).

## 5. 자동 지표와 사람 판정의 일치 (V9, 부록 C.7)

프로젝트 페이지 `figdata.js`가 변형 x 설정 60점(자동 SR 대 사람 SR, Sub-SR 대 Q)을 공개합니다.

- 재계산 Pearson r: **SR 대 SR_human 0.956, Sub-SR 대 Q 0.952**(사이트가 적은 "variant x regime" 상관과 같음). **논문 본문은 "r = 0.858, 0.861"**이라 쓰며 이 값은 60점으로 재현되지 않습니다. 사이트의 "+ level" 상관(0.867, 0.874)과도 다릅니다. 어떤 셀 집합의 상관인지 논문에서 정의되지 않았습니다.
- zero-shot 15점이 대부분 (0, 0 근처)에 몰려 상관을 키웁니다. ZS를 빼면 r = 0.93, 0.91, Spearman 0.91.
- 가장 큰 불일치: RDT-1B Scr 자동 0.35 대 사람 0.00, RDT-1B Seen 0.43 대 0.12. ZS 15점 중 12점은 사람 SR이 정확히 0인데 자동 SR은 0.02–0.13입니다(예: π0.5 자동 0.092 대 사람 0.000). 사람 판정은 "SUCCESS만"을 세는 더 엄격한 기준이라 약한 정책에서 체계적으로 낮습니다. 자동 SR ≥ 사람 SR은 60점 중 37점입니다(사람 SR이 더 높은 점 23개).
- 사람 SR의 값(예: 0.0769, 0.0714, 0.0833, 0.5606)은 분모가 작음을 시사합니다(0.0769 = 1/13, 0.0714 = 1/14, 0.5606 = 37/66 등 최소 분모 가능). 분모의 하한만 알 수 있고 실제 판정 수는 알 수 없습니다. 보고된 36,000 판정 대비 매우 작은 분모가 쓰였을 가능성이 있어 V6의 판정 횟수 문제와 함께 확인이 필요합니다.
- 사람 seen SR 레벨별(그림 13b 데이터): 0.58/0.53/0.46/0.65, Q 7.25/6.98/6.70/7.46. 자동(0.62/0.57/0.48/0.63)과 같은 L2 하락·L3 반등 모양입니다. 두 채널이 시뮬에서 같은 구조를 보인다는 주장은 지지됩니다.

## 6. Scr는 규모 표지별 실행 중 최솟값이다 (V10, V12)

프로젝트 페이지 `sim-detail-data.js` 머리말은 Scr 값이 "규모별 값 중 **최솟값**(MIN over the scales present)이며 `all_summary.json`의 unseen_scratch_flat을 정확히 재현한다"고 적습니다. 공개된 원 기록(`all_master_records.csv`, 3,440행 = 셀 단위 SR, 에피소드 10개씩)으로 직접 확인했습니다.

- **Scr 실행 수가 모델마다 다릅니다.** UniSkill, XSkill, ACT 3종, DP 3종, VQ-BeT 3종(11변형)은 규모 표지 15/30/45의 **3회 기록**이 있고, GR00T, π0.5, RDT-1B는 **1회**(15 표지), OpenVLA는 **1회**(45 표지)뿐입니다. 3회 기록이 있는 변형은 표 3의 Scr 열이 셀별 **최솟값**과 일치하고(V8), 1회뿐인 변형은 그 값 그대로입니다. 논문 본문은 이를 말하지 않습니다.
- **3회 평균을 쓰면 Δ(P+FT − Scr)가 줄어듭니다.** 변형별 (최솟값 → 평균, Δ 최솟값 → Δ 평균): ACT/DINOv2 0.755 → 0.803, +0.088 → **+0.040**; ACT/SigLIP2 0.650 → 0.740, +0.148 → +0.058; ACT/VideoMAE 0.630 → 0.735, +0.187 → +0.082; DP/DINOv2 0.130 → 0.210, +0.412 → +0.332; XSkill 0.350 → 0.420, +0.377 → +0.307; UniSkill 0.265 → 0.337, +0.323 → +0.252; VQ-BeT/DINOv2 0.350 → 0.437, −0.122 → **−0.208**; VQ-BeT/SigLIP2 0.255 → 0.422, −0.083 → **−0.250**; VQ-BeT/VideoMAE 0.135 → 0.273, +0.013 → **−0.125**.
- 따라서 "P+FT가 Scr를 이기는 변형 12/15"(§4.3)는 **Scr를 3회 중 최솟값으로 잡은 변형(11개)과 1회 값인 변형(4개)을 섞은 비교**입니다. 3회 평균으로 바꾸면 ACT/DINOv2의 이득은 +0.04로 줄고 VQ-BeT/VideoMAE는 음수가 되어, 이기는 변형은 11개로 줄어듭니다. 또 VLA(1회)와 VA·스킬(3회 최솟값) 사이에서 처리 방식이 달라 Δ 크기를 계열 간에 비교하기 어렵습니다.
- 3회 실행이 같은 설정의 재실행(시드)인지, 규모 표지에 따라 사전학습 IDM 등 다른 구성인지는 기록에 없습니다(UniSkill은 IDM 체크포인트가 규모 표지마다 다름, `04` D14).
- 이항 모형(V10, 셀당 10회, 참 성공률 p)로 보면 셀별 3회 최솟값의 기댓값은 p = 0.3에서 0.18, p = 0.5에서 0.37, p = 0.8에서 0.69로 참값보다 낮아집니다. 위 실측 차이(0.05–0.17)와 같은 크기입니다.
- **Sub-SR은 정의와 다른 연속값입니다(V12).** 논문 B.3은 하위 단계 완료 개수(M개 중 m_e개)의 비율이라 에피소드 평균이 작은 분모의 유리수여야 합니다. 공개 기록의 SubSR는 2,767개의 서로 다른 값(예: 0.000434, 0.7370077)이고 10 x M 배가 정수인 행은 M과 상관없이 18.9%(전부 0 또는 1인 셀)뿐입니다. 피크 보상 평균을 쓴다는 코드(`04` D9)와 일치합니다.
- **PourKettle L2는 모든 기록에서 SR 0입니다(V12).** `L2_TwoRobotPourKettle-v1` 행은 ZS 45, P+FT 45, Scr 37행 모두 SR 최댓값이 0.0입니다.

## 8. 이 분석의 한계

- 원자료(롤아웃 단위 성공 여부)가 없어 시도 독립 가정의 p값만 계산했습니다. 같은 모델·과제·초기 조건이 반복되므로 실제 불확실성은 더 큽니다.
- 프로젝트 페이지의 JS와 `all_master_records.csv`는 논문 표 3과 일치했지만, 에피소드 단위(성공/실패 0과 1) 기록은 아니고 셀당 10회의 SR과 Sub-SR 평균입니다. 실제 로봇 롤아웃 기록은 공개되지 않았습니다.
