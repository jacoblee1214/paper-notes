## 1. 한 줄 요약

모션 캡처 기준 동작을 흉내 내는 강화학습 정책이 PD 제어기의 강성, 감쇠, 목표 위치를 매 10 ms마다 바꿉니다. 정책은 힘판 측정을 보지 않고 **모션만** 입력받지만, 학습 중 측정 GRF와 CoP로 보상을 주어 지면 반력을 맞추도록 합니다. 129명, 6개 활동에서 고정 이득 PD, 토크, 근육 행동 공간과 PHC, SimPoE보다 힘과 관절각 정확도가 높다고 주장합니다.

## 2. 구조 (절과 식)

### 2.1 문제 설정 (§1–2)
- 같은 동작이라도 제어기가 다르면 접촉력이 다릅니다. 힘판 데이터는 실험실에만 있습니다.
- 물리 기반 모방은 동역학 일관성을 주지만, 고정 이득 PD를 쓰면 측정 힘과 어긋날 수 있습니다 (§1, 참고문헌 Peng & Van De Panne, 2017).
- 관련 연구는 SimPoE(Yuan et al., 2021), ReGAIL, Neural PhysCap, OSDCap, Le et al. (2026)을 가깝다고 봅니다. 저자들은 "힘 측정에 맞춘 관절별 임피던스 학습"을 처음이라고 주장합니다 (§2, 기여 2의 "첫 번째" 주장은 C 항목에서 다룹니다).

### 2.2 행동 공간의 한계 (§3.1)
- 식 (2): PD 토크 τ̂ = k_p ∘ (q*_{t+1} + αδq − q) + k_d ∘ (q̇*_{t+1} − q̇), ±τ_lim으로 제한.
- 식 (3): 이득을 기준값 곱하기 지수 잔차로 표현. k_p = k⁰_p ∘ exp(s_p Δk_p), k_d = k⁰_d ∘ exp(s_d Δk_d).
- **명제 1 (힘 권한, Bound 1)**: 기준 상태에서 k_p ≥ max_t |τ*(t)| / α. 이 아래에서는 고정 이득 정책이 힘과 관절각 중 하나를 포기합니다 (식 4).
- **명제 2 (피드백 안정, Bound 2)**: 이산 시간 PD 오차 동역학의 Jury 조건은 0 < k_d < 2I/h, 0 < k_p < 4I/h² − 2k_d/h (식 5, 부록 A.2.1 식 10–11). 감쇠 상한은 접촉 중에는 몸 전체 관성, 공중에서는 발 관성이 정합니다.
- **Remark 1**: 접촉에서는 강성이 필요하고 공중에서는 감쇠를 낮춰야 합니다. 고정 이득은 한쪽 단계를 택해야 합니다.
- 단일 관절 검증(부록 A.2.1, Table 6): 질량 1.5 kg, 길이 0.2 m 막대. I = 0.020 kg·m²이므로 2I/h = 20 Nm·s/rad, k⁰_p = 32 Nm/rad입니다. 이 값은 재계산과 일치합니다.

### 2.3 방법 (§3.2)
- **행동**: a_t = (Δk_p, Δk_d, δq) ∈ [−1,1]^{3m}, m = 15 관절. 행동 차원은 15에서 45로 늘어납니다. 정책은 100 Hz, 물리는 2 ms 간격입니다.
- **지연 (식 6)**: 이득 변화를 1차 지연으로 완만하게 함, T_act = 50 ms.
- **관성 기준 이득 (식 7)**: k⁰_p = I_jj ∘ ω_n², k⁰_d = 2ζ ∘ I_jj ∘ ω_n. 같은 배율이면 몸이 달라도 닫힌 루프 고유 진동수와 감쇠비가 같아지는 것이 핵심 아이디어입니다.
- **GRF 추정기**: 기준 운동학에서 발 GRF를 추정하는 물리 사전 분포(CoM 동역학) + 잔차 앙상블 (K = 3). 학습 클립에 맞춰 분할마다 한 번 고정합니다. 활동 평균 수직 GRF 상관은 시드 분할 0.979, 미경험 0.943입니다 (부록 A.2.2, 본문 §3.2).
- **관측**: 215차원 (Table 7). 고유감각, 접촉 상태, 10/50/250 ms 앞 기준 오프셋, 추정 GRF, 발 위치. 측정 힘판 신호는 들어가지 않습니다 (§3.2 "plate-free inference").
- **보상 (식 8–9)**: r = r^kin + w_grf r^grf + 0.25 r^shear + 0.15 r^ee, w_grf는 0.25에서 0.5로 선형 증가. r^grf는 발별 힘 오차를 하중으로 정규화하고 CoP 오차를 더합니다 (α_grf = 4).
- **학습**: PPO, 2×10⁹ 스텝, 8,192 병렬 환경, MLP [512, 256, 128] SiLU, MuJoCo Warp. 주체 식별자나 신체 치수 입력은 없습니다.
- **비대칭 학습**: 학습 중 측정 GRF가 있는 critic과 측정 GRF를 맞히는 보조 머리가 있지만 추론에서는 버립니다.

### 2.4 데이터와 모델 (§3, 부록 A.1)
- 9개 공개 데이터셋(AddBiomechanics 8개 + Scherpereel et al. 2023), 129명, 972 시행, 8,493 클립, 20.2 h (Table 3). 계산 확인: 프레임 합 7,272,049, 100 Hz 기준 20.2 h. 기록 144명 중 15명 제외.
- 활동: 걷기, 달리기, 서기, 측면 움직임, 굽힘(flexion), 점프. 학습 클립의 16.2%가 비주기 활동(측면, 굽힘, 점프)입니다.
- 시뮬레이션 모델: 팔 없는 Rajagopal 모델(31 좌표, 15 구동 관절), 대상자별 MuJoCo 변환(MyoConverter), 발당 접촉 구 8개.
- 평가 세 가지: seen(모든 피험자의 보류 클립, 1,697 클립), unseen(22명 보류, 학습 107명, 1,365 클립), LOAO(활동 하나 보류, 4,112 클립). 표준편차는 시드 5개입니다.

### 2.5 기준선 (§3.2)
Fixed-PD(관성 기준 고정 이득), Torque(τ̂ = τ_scale ∘ a), Muscle(80 Hill형 근육 자극), GaitDynamics(회귀기, 시뮬 없음, 힘 정확도 참조용), PHC(Luo et al., 2023), SimPoE(Yuan et al., 2021). 강화학습 기준선은 같은 데이터, 물리, 보상(힘 보상 포함)으로 맞췄지만 PHC와 SimPoE는 원 구현과 최대한 맞춘 재구현입니다.

## 4. 논문이 스스로 밝힌 한계 (§5, 부록)

- 비주기 활동(측면, 굽힘, 점프)과 팔 없는 모델에서 모든 방법이 나쁩니다.
- GaitDynamics는 수직 힘 상관이 가장 높지만 CoP가 발 밖이고 비행 중 힘이 있습니다 (부록 A.3.7). 그러나 측면 CoP 위반은 0.2%로 낮습니다.
- 추정기와 기준 미리보기는 최대 400 ms의 미래 기준 동작을 씁니다 (§5). 실시간 로봇 적용에는 인과성이 없습니다.
- 하드웨어 모터 구동기, 마찰, 토크 한계는 시뮬레이션에서 빠졌습니다 (§5, 부록 A.3.3).
- SimPoE는 상체 골반에 잔여 외력을 줘서 생존율을 얻습니다. 이 외력을 빼면 생존율이 85, 80, 56%로 떨어집니다 (Table 19, 본문 §4.4).

## 5. 주장과 근거의 간격 (요약)

자세한 판정은 `04_claim_verification.md`의 C 항목에 있습니다.

- **확인됨**: 평균 행의 통계적 우위 (IM 대 Fixed-PD, 시드 5개 Welch, Holm 보정 후 전부 p < 0.05), 짝 맞춘 적분 방식 비교의 대부분, 관성 기준 이득이 몸마다 같은 동역학을 준다는 식 (7) 논리, 단일 관절 경계 수치(식 5, Table 6).
- **부분 확인**: "모든 적분 방식에서 우위" (생존율은 짝 맞춘 2배 안정 PD 한 칸에서 짐), "힘 측정 없이 추론" (학습 중에는 측정 힘을 씀, 추론 시에는 기준 동작의 미래 값을 씀).
- **확인 불가 또는 틀림**: 공식 코드와 체크포인트 공개 (아직 없음), 학습 임피던스의 활동 판별 92.5% (수치 원자료 없음), G1 안정 PD에서 우위 1.4점 (통계적으로 구분 안 됨, p ≈ 0.6), 본문 §4.2의 "약 35점 손실" 기준 혼동 (`03` V7).
