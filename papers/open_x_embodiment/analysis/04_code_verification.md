# 04. 공식 코드와 논문 대조 (정적 읽기)

대상: `repo/` (google-deepmind/open_x_embodiment, 커밋 `9eeb68b`, 2025-11-05, 얕은 복제). 파일: `models/rt1.py`, `models/rt1_inference_example.py`, `models/token_learner.py`, `models/efficientnet.py`, `models/film_conditioning.py`, `colabs/*.ipynb` 3개, `README.md`.

**규칙:** 코드를 실행하거나 import하거나 설치하지 않았습니다. 읽기만 했습니다. 복제본은 신뢰하지 않는 데이터로 취급했습니다. 콜랩의 셀 소스만 JSON에서 꺼내 읽었습니다.

**공개 범위:** 공식 코드는 RT-1-X 모델 정의와 추론, 데이터 콜랩, 학습 예제 콜랩뿐입니다. **RT-2-X의 코드와 가중치는 없습니다.** 따라서 표 I, 표 II의 RT-2-X 수치는 공개 아티팩트로 검증할 수 없습니다.

## 2. 차이 목록 (D1–D10)

**D1. 어휘 크기: 논문 256, 공개 추론 예제 512.**
`rt1_inference_example.py`의 `main()`은 `vocab_size = 512`, `layer_size = 256`으로 RT-1-X를 만듭니다. 클래스 기본값은 256이고 층 너비는 128입니다. 공개 체크포인트가 어떤 설정으로 학습되었는지는 문서에 없습니다. 예제의 설정을 논문 설정으로 볼 수 없습니다.

**D2. 모델 크기와 설정 대응.**
논문은 RT-1을 35M으로 씁니다. 공개 코드는 두 가지 설정(128, 256)을 보여 주며, 어느 쪽이 35M인지는 밝히지 않습니다. 파라미터 수는 실행 없이 확정할 수 없습니다(확인 불가).

**D3. 행동 토큰 수: 논문 8, 코드 11.**
`tokenize_action`은 종료 신호 1개, `world_vector`, `rotation_delta`, `gripper_closedness_action`, `base_displacement_vertical_rotation`, `base_displacement_vector`를 토큰화합니다. 모바일 기저 이동 토큰이 3개(수직 회전 1, 벡터 2) 더 있습니다. 논문 IV-B는 "eight dimensions"라고 씁니다. 기저 토큰을 어떻게 채우는지(0으로 두는지)는 추론 예제에서 확인하지 못했습니다.

**D4. 행동 정규화 범위.**
논문 IV-A는 "normalize each dataset's actions prior to discretization"이라고만 씁니다. 공개 코드에서 확인되는 범위는 여러 가지입니다.
- 추론 예제 RT-1-X: `world_vector_range=(-2.0, 2.0)` (주석에 "RT-1-X uses (-2.0, 2.0) instead of (-1.0, 1.0)").
- 클래스 기본: `(-1.0, 1.0)`.
- 학습 예제 `bridge_map_action`: world_vector ±0.05를 ±1.75로, rotation_delta ±0.25를 ±1.4로 선형 변환(안전 여유 0.01). 이 상수는 `rt1_eval` 저장소의 주석을 따른다고 적혀 있습니다.
- 학습 예제 `taco_play`: 차원별 하한과 상한 상수.
정규화 상수가 논문에 없으므로 논문 수치를 재현하려면 공개 코드의 상수를 가정해야 합니다.

**D5. 입력 해상도.** 논문은 "resize it to a common resolution"이라고만 씁니다. 추론 예제는 300 × 300입니다. 논문에서 수치를 확인할 수 없어 기록만 합니다.

**D6. 혼합 출처: 논문 12, 학습 예제 10.**
학습 예제의 `DATASET_NAME_TO_WEIGHTS`에는 `kuka`(20)와 `language_table`(30)이 주석 처리되어 있고, 데이터 맵 정의에도 "TODO: (add Qt-Opt)", "TODO: (add Language Table)"이 있습니다. 논문 IV-C의 12개 출처 중 QT-Opt와 Language Table이 빠집니다. 두 데이터셋은 스프레드시트에서 혼합의 90%입니다(03 V6). 예제는 논문 혼합의 축약본이 아닙니다.

**D7. 혼합 가중치.** 논문에는 없습니다. 학습 예제 가중치(활성 10개, 합 273)를 계산하면 RT-1 데이터 54.9%, Bridge 18.3%, Jaco 7.3%, Cable 7.3%입니다(03 V7b). 주석에 "for example"이라고 되어 있어 논문 가중치의 근거가 되지 않습니다. 논문이 어떤 가중치를 썼는지는 확인할 수 없습니다.

**D8. 학습 설정.** 논문에 스텝 수, 배치, 학습률, 하드웨어, 시드가 없습니다. 공식 콜랩 예제는 Adam(lr 1e-4, eps 1e-7), 배치 6, 1,000 스텝을 씁니다. 예제 주석은 실제 학습은 "> 1M" 스텝이어야 한다고 적습니다. 학습 루프와 체크포인트 저장은 저장소에 없고 예제 콜랩에만 있습니다.

**D9. 프레임워크.** 논문은 프레임워크를 밝히지 않습니다. 공개 모델은 JAX/Flax(`rt1.py`, `film_conditioning.py`), 데이터 파이프라인은 TF/RLDS/reverb입니다. 우리 재구현은 CLAUDE.md의 기본 PyTorch를 따르면 됩니다(구현 차이 기록).

**D10. 데이터셋 목록 수.** 콜랩 `DATASETS`는 53개 이름입니다. 논문과 스프레드시트 v1.0은 60개입니다. 콜랩이 시각화 전용 부분 목록인지 오래된 목록인지는 확인할 수 없습니다.

**일치 항목 (E1–E4):** 이력 15장, 81 이미지 토큰, 단일 카메라, 균등 이산화는 논문과 코드가 맞습니다. 논문의 구조 설명(FiLM, EfficientNet, 디코더 전용 Transformer)도 `rt1.py`와 `film_conditioning.py`에서 확인했습니다.

## 3. 공개 아티팩트로 검증할 수 있는 것과 없는 것

| 주장 | 검증 가능 여부 |
|---|---|
| RT-1-X 구조와 추론 | 가능 (정적 확인, 실행하면 더 확인) |
| RT-1-X 체크포인트 성능 | 불가 (체크포인트 미다운로드, 평가 프로토콜 없음) |
| RT-2-X 55B 모든 수치 | 불가 (코드와 가중치 없음) |
| 혼합 구성과 가중치 | 부분 (예제 가중치만 있고 논문 가중치 없음) |
| 실로봇 평가 (3600회) | 불가 (평가 코드 없음, 실로봇 필요) |

## 4. 구현 가능성 판정

**이 맥(Apple M4 Pro, 약 24 GiB 통합 메모리, MPS, CUDA 없음)에서의 판정입니다.**

**판정: 전체 재현은 불가능합니다. 부분 재현은 조건부로 가능합니다.**

| 단계 | 가능 여부 | 근거 | 노력 (추정) |
|---|---|---|---|
| 표·그림 재계산 (이 분석) | 가능 (완료) | 보고값과 스프레드시트만 씀 | 완료 |
| 공개 체크포인트 추론 (RT-1-X 35M 급) | **조건부** | JAX/TF 설치와 체크포인트 다운로드가 필요. 공식 코드 실행과 새 가상환경은 사용자 승인 필요. 메모리는 충분 | 1–2일 (추정). 체크포인트 크기는 확인 전 |
| 공개 데이터의 오프라인 행동 예측 검사 | **조건부** | 작은 데이터셋만 가능 (스프레드시트 기준 Austin VIOLA 10.4 GB, NYU VINN 7.12 GB). Bridge 387 GB, Language Table 399 GB, QT-Opt 778 GB는 다운로드 자체가 부담 | 데이터 1개당 수시간 + 다운로드 (추정) |
| RT-1 구조를 PyTorch로 옮겨 MPS에서 소규모 미세조정 | **조건부 (무거움)** | 공식 코드는 JAX. MPS 학습은 경로가 불안정할 수 있음. 한 데이터셋 소규모 미세조정은 CPU/MPS에서 가능성은 있으나 시간이 큼 | 1–2주 (추정) |
| 혼합 학습 (12 출처, 1.13M 에피소드, 2.0 TB) | **불가** | 데이터 다운로드 2.0 TB 이상, 학습은 TPU/GPU 클러스터 전제 (논문 설정도 미공개) | — |
| RT-2-X 55B 학습과 평가 | **불가** | 코드와 가중치 없음, 55B 규모 | — |
| Bridge 제외 등 표 II 어블레이션 | **불가** | 학습 여러 번 + 실로봇 평가 | — |
| 실로봇 평가 (3600회) | **불가** | 로봇 여러 대와 실험실 필요 | — |

**권장:** 이 논문은 "방향"을 확인하는 가치가 있지만, 맥에서 할 수 있는 최선은 공개 RT-1-X 추론 검사와 혼합 가중치 민감도 분석입니다. 학습 재현은 사용자 판단과 외부 자원이 필요합니다.
