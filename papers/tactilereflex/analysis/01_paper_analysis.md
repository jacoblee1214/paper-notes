## 1. 문제 설정

얇은 일회용 플라스틱 컵(3.5–5 g, 벽 0.3–0.5 mm)은 미끄럼을 막는 힘과 찌그러뜨리는 힘의 차이가 좁습니다(§I). 물을 붓는 동작은 액체가 이동하면서 중력 토크를 계속 바꾸므로 고정 effort로는 버티기 어렵습니다. 저자들은 세 가지 능력을 요구합니다(§I).

1. 미끄럼을 실시간으로 억제한다.
2. 하중이 줄면 effort를 낮춰 과파지를 막는다.
3. 접촉력에 하드한 안전 상한을 둔다.

기존 접근의 한계로 저자들은 세 가지를 듭니다. 힘·토크 센서는 장착 순응과 보정 문제가 있고, 비전 촉각은 이진 슬립 분류나 end-to-end 정책의 입력으로만 쓰이며, VLA는 힘 조절을 학습된 정책에 맡깁니다(§I, §II).

## 2. 방법

### 2.1 촉각 영상 처리 (§IV-A)

- 입력: MC-Tac 센서 두 대(좌·우 손가락), 640×480 회색조 영상. 노출과 화이트 밸런스는 고정(§III-A).
- 차이 영상: ΔI_t(u) = I_t(u) − I_ref(u) (식 1). 임계값 τ = P98(ΔI)로 자르고 모폴로지 열림(opening)을 적용해 접촉 마스크를 만듭니다. 접촉 화소가 N_min보다 적으면 비접촉입니다.
- 가중치 W = ΔI^γ, γ = 1.5 (식 2).
- 세 가지 지표(센서별):
  - **Fn (식 3):** 가중치 합 / (HW). 무차원 접촉 강도이며 뉴턴이 아니라고 명시합니다.
  - **CoP (식 4–5):** 가중치 중심 C_t^s. 양쪽 접촉이 모두 있을 때만 세로 성분 평균 Ĉ_y를 계산합니다.
  - **Sy (식 6):** Farnebäck 광흐름(연속 두 프레임)의 접촉 영역 세로 성분 median(v_y). 식에는 절댓값이 없습니다.
- 지수 이동평균 EMA(α = 0.3)는 R1과 R3에서만 씁니다. R2(미끄럼)는 원시 Sy를 씁니다(Table I).

### 2.2 상태 기계와 세 채널 (§IV-B, Alg. 1)

상태는 Idle → Closing → Holding 순서입니다. Closing은 effort를 고정(e_init)하고 위치만 줄이다가, min(Fn_raw,L, Fn_raw,R) ≥ Fstop이 되면 Holding으로 넘어갑니다. 세 채널은 Holding에서만 작동합니다.

| 채널 | 신호 | 조건 | 동작 (논문 식) |
|---|---|---|---|
| R1 Force-protect (최우선) | EMA Fn_max | > Flim | effort −Δe_prot, 위치 +Δp_prot (식 7–8) |
| R2 Anti-slip | 원시 Sy (접촉 게이트) | ≥ θs (한쪽이라도) | effort +Δe_slip, 위치 −Δp_slip, 누적 ≤ Δp_max (식 9–11) |
| R3 Weight-adaptive release | EMA Sy_max, ΔCoP_y | 양쪽 접촉, ΔC_y < θc, Sy_max < θq | effort −Δe_rel, 위치 +Δp_rel (식 12–13) |

- R2와 R3는 상호 배타입니다. R1은 두 채널 뒤에 독립적으로 평가되며, R2와 함께 떠도 순효과가 감소이도록 Δe_prot > Δe_slip을 둡니다(§IV-B).
- CoP 기준선 C̄_y는 매 Holding 프레임마다 α_bg = 0.02로, 릴리스 때는 α_rel = 0.3으로 갱신합니다.
- **증분 값(Δe, Δp)은 본문에 없습니다.** 저장소 코드에서 읽은 값은 `04` §2를 보십시오.

### 2.3 임계값 (§IV-C, Table II)

논문은 "모든 임계값을 ∼2분 정지 보유-풀기 보정의 노이즈 통계에서 유도한다"고 주장합니다. 본문이 적은 규칙은 다음과 같습니다.

- τ = P98(ΔI) (노이즈 바닥)
- θq = P95(Sy_raw) (정지 상태 잡음 상위)
- Flim = P99.9(Fn_raw)
- θs: P99.9(Sy_noise) ≤ θs ≤ 관측된 최소 슬립 (100% TPR, 0% FPR을 같이 만족하는 구간)
- θc: 수동 하중 감소 이벤트에서 얻음
- Fstop, γ, α: 고정 상수 (Table II에서 Fstop은 "재료 의존")

Table II의 값은 θs 0.20(공통), θq 0.12/0.10, θc −10.0/−3.5 px, Flim 45/100, Fstop 1.3/5.5입니다. "모든 임계값이 노이즈에서 나온다"는 주장이 실제로 어디까지 성립하는지는 `03` §4에서 따로 봅니다.

## 3. 실험 (§V)

| 단계 | 내용 | 규모 | 논문의 주장 |
|---|---|---|---|
| Phase 1 | 임계값 보정과 신호 검증. 연한 컵과 강성 계량컵 | 19회, 약 20,000 프레임 | 노이즈 바닥이 재료에 둔감. θs는 보편 (100% TPR, 0% FPR) |
| Phase 2 | 채널 절제 A/B/C/D (연한 컵만) | 구성당 N = 5 | D만 5/5 성공. 나머지 최대 1/5 |
| Phase 3 | 붓기 (45 ml, 90 ml), 반사 끔 대 켬 | 조건당 N = 5 | 반사 끔 0/10, 켬 9/10 |

**Phase 1 (Table III, IV):** 정지 보유 프레임 6,477개에서 Sy P95는 연한 컵 0.08–0.11, 강성 컵 약 0.08입니다. 슬립 최소 피크는 연한 0.429, 강성 0.204이고, 분리비 SNR은 3.8배와 2.4배입니다. 강성 컵 밀기 45회의 Sy 피크는 0.201–1.45입니다. 논문은 이것을 θs의 "교차검증"이라고 부릅니다(`03` §4.2에서 다룹니다).

**Phase 2 (Table V):** 연한 컵에 "잡기 → 들기 → 당기기 → 누르고 풀기 → 옆으로 밀기"를 순서대로 합니다. 구성 A(Sy만)는 effort가 emax = 5000까지 올라가 머물고 0/5 성공합니다. B(Sy + 보호)는 톱니 모양으로 흔들려 0/5입니다. C(Sy + 해제)는 1/5입니다. D(전체)는 5/5이고, 최종 Fn 피크는 67.3 ± 6.6입니다. 낙하는 네 구성 모두 0/20입니다.

**Phase 3 (Table VI):** 키네스테틱 교시로 얻은 궤적(들기 → 기울이기 → 붓기 → 복귀)을 재생합니다. 반사 끔은 파지 단계에서 정착한 effort와 위치를 고정합니다. 반사 켬은 같은 궤적에서 effort를 실시간으로 조정합니다. 슬립 비율은 끔 42% → 켬 35%(45 ml), 끔 63% → 켬 42%(90 ml)입니다. 성공은 끔 0/10, 켬 9/10(45 ml 5/5, 90 ml 4/5)입니다.

## 4. 저자들이 밝힌 한계 (§VI)

- 그리퍼 중심 범위이며, 회색조 영상만 씁니다(조명 강건성과 효율을 위해 RGB 정보를 버렸다고 씀).
- 재료 범위가 좁습니다(연한 컵 하나와 강성 계량컵 하나).
- VLA와의 통합은 "향후 과제"입니다. 논문에 VLA 실험은 없습니다. 안전층 역할은 궤적 재생과 원격조작 데이터 수집을 근거로 주장합니다.

논문이 명시하지 않은 한계는 `03`, `04`에서 정리합니다. 가장 중요한 것은 (1) Table V와 VI의 표본 수(5), (2) 단일 물체, (3) 붓기 대조군이 고정 effort 1200이라 반사 켬(최대 5000)과 평균 힘이 다르다는 점, (4) Sy 정의와 프레임 간격에 따라 임계값의 단위가 달라진다는 점입니다.

## 5. 재사용 가능한 점과 주의할 점 (요약)

- **재사용 가능:** 세 개의 이미지 지표(Sy, Fn, CoP)를 우선순위 채널로 묶는 구조, 채널 간 배타성과 증분 불변식(Δe_prot > Δe_slip), 보정을 짧게 반복해 임계값을 재유도하는 절차.
- **주의:** 노이즈에서 유도된다는 주장은 일부만 성립합니다. 논문에 있는 Sy 정의가 저장소 두 커밋 사이에서 바뀌었습니다(`04` D1). 절제와 붓기 결과는 N = 5이고 물체 하나입니다.
