## 2. 관절 정확도 (Fig. 9, 본문 수치 재계산)

원자료(샘플별 오차)가 없어서 본문 수치로만 계산할 수 있습니다. 그래프는 `report/figures/joint_accuracy.png`입니다.

| 방식 | MAE (°) | RMSE (°) | MaxAE (°) | RMSE/MAE | MaxAE/RMSE | MAE/시험 범위 (%) |
|---|---|---|---|---|---|---|
| Type I 축-슬리브 (0–90°) | 0.535 | 0.708 | 2.383 | 1.323 | 3.366 | 0.59 |
| Type II 축-베어링 (0–90°) | 0.387 | 0.461 | 1.262 | 1.191 | 2.738 | 0.43 |
| Type III 호형 슬롯 (0–75°) | 0.377 | 0.462 | 1.368 | 1.225 | 2.961 | 0.50 |

- 세 방식 모두 MAE가 1° 아래이고 MaxAE가 2.4° 아래라는 본문 주장은 수치와 맞습니다.
- 오차 차이 검정: 방식 사이 MAE 차이는 Type I 대 II가 0.148°, Type II 대 III가 0.010°입니다. 왕복 5회 한 장치의 값이라서 원자료 없이는 표준오차를 알 수 없고, **유의성 검정은 할 수 없습니다.** 가능한 것은 정성 판단뿐입니다. Type II와 III는 구분되지 않고, Type I만 다를 가능성이 있습니다.
- RMSE/MAE: 0 평균 정규분포에서는 √(π/2) = 1.253입니다. Type I의 1.323은 정규분포보다 꼬리가 두껍거나 편향이 있다는 뜻입니다. Type II와 III는 1.19–1.23으로 정규분포에 가깝습니다. 편향 여부는 부호가 있는 오차 평균이 있어야 알 수 있습니다.
- 서보 기준의 한계: 기준은 Dynamixel XC330입니다(논문 §6.2.1). 서보 자체의 기준 오차와 장착 편심은 보고하지 않았습니다.

### 2.1 분해능 바닥과 전달비 (외부 데이터시트 값, 논문 미기재)

AS5600L이 12비트라고 가정하면(데이터시트 값, 논문에는 없고 검증하지 않음) 분해능은 360°/4096 = 0.0879°입니다. 7.4:1 전달비에서는 관절 환산 분해능이 0.0879/7.4 = **0.0119°**입니다.

- 그런데 세 방식의 MAE는 0.377–0.535°로 분해능 바닥보다 30배 이상 큽니다. 따라서 **측정 오차는 분해능이 지배하지 않습니다.** 기계 유격, 조립 편심, 기준 서보 오차가 더 큰 원인일 가능성이 높습니다(추정).
- 논문 §6.2.1은 Type III의 전달비가 "유효 분해능을 높여 Type II와 비슷한 정확도를 준다"고 설명합니다. 수치로는 Type III의 분해능이 Type II보다 높은 것은 맞지만, 분해능이 오차 크기를 정하지 않으므로 이 설명은 MAE 차이를 설명하지 못합니다.
- Type I가 가장 큰 오차를 보이는 이유를 "기어 전달" 때문이라고 하는데, Type III도 기어를 쓰면서 Type I만큼 큰 오차를 보이지 않으므로 기어가 주원인이라는 근거는 약합니다.

## 3. 판독 시간 예산 (§5.3, 부록 D)

- 2048 taxel × 120 Hz = 245,760 샘플/s. 12비트 기준 **2.95 Mbit/s**입니다. SPI 한 개로 옮길 수 있는 대역 안입니다(STM32F411의 SPI 최대 속도는 확인하지 않음).

- 결론: 대역은 충분합니다. 120 Hz의 실제 달성 여부는 정착 시간과 동기화 지터 측정이 있어야 확인됩니다(논문에 없음).

## 6. 유도

### 6.1 히스테리시스 출력의 힘 편향 (토이 B 검산)

출력 s = F^b (b = 0.7), 언로딩에서 s × (1 − h)인 경우, 보정 곡선 F̂ = s^{1/b}를 쓰면

  F̂/F = (1 − h)^{1/b}

입니다. h = 0.10이면 (0.9)^{1/0.7} − 1 = **−13.97%**입니다. 토이의 2.5 N 근처 언로딩 평균 편향은 −0.3493 N이고 2.5 N으로 나누면 −13.97%이므로 **닫힌 식과 정확히 맞습니다.**

### 6.2 곱셈 드리프트의 힘 편향

s가 (1 + k·t)로 곱해지면 F̂/F = (1 + k t)^{1/b}. 분당 1%(k = 0.01), 10분 후이면 (1.1)^{1/0.7} − 1 = **+14.6%**입니다. 토이의 10분 세션 끝 오차와 맞습니다.

### 6.3 히스테리시스와 드리프트의 상쇄

언로딩 구간 편향은 음수(힘을 적게 읽음), 드리프트는 양수(힘을 많이 읽음)입니다. 그래서 h = 0.10에 k = 0.01을 함께 넣으면 RMSE가 **4.86%**로, 히스테리시스만 있을 때(5.70%)보다 줄어듭니다. **세션 RMSE 하나로는 두 원인을 나눌 수 없습니다.** 힘 보정 검증은 상승과 하강을 따로 보고, 드리프트는 무부하 기준점으로 따로 재야 합니다.

### 6.4 접촉 항의 선형화 (토이 C 검산)

접촉 프레임에서 목적함수 ||δq||² + λ(z_h + Jδq)² (J = ∂z/∂q, 1×3)를 최소화하면

  δq* = −λ z_h Jᵀ / (1 + λ‖J‖²),  z_after = z_h / (1 + λ‖J‖²),  ‖δq*‖ = λ|z_h|‖J‖ / (1 + λ‖J‖²)

입니다. λ → ∞이면 ‖δq*‖ → |z_h| / ‖J‖입니다. 즉 **접촉 가중치를 아무리 키워도 관절이 움직이는 양은 표면까지 가는 최소 거리 |z_h|/‖J‖에서 멈춥니다.** 접촉 가중치는 잔차를 1/(λ‖J‖²)만큼 줄이고, 그 대가로 관절 편차가 생깁니다.

토이 C의 접촉 프레임에서 선형식과 시뮬레이션을 대조하면 다음과 같습니다(`retarget_results.json`의 `linear_check`).

| λ | 예측 중앙값 (mm) | 시뮬 중앙값 (mm) | 예측 90분위 (mm) | 시뮬 90분위 (mm) |
|---|---|---|---|---|
| 1 | 0.0147 | 0.015 | 0.162 | 0.159 |
| 10 | 0.0015 | 0.002 | 0.017 | 0.017 |
| 100 | 0.0001 | 0.000 | 0.0017 | 0.002 |

관절 이동 한계 |z_h|/‖J‖의 중앙값은 0.696°이고, λ = 100의 시뮬 접촉 프레임 관절 편차 중앙값은 0.697°입니다. 선형식과 토이가 맞습니다.

## 7. 토이 B: 히스테리시스와 드리프트가 힘 추정에 주는 오차 (`analysis/hysteresis_toy.py`)

**설정 (가정):** 삼각파 0 → 5 N → 0, 한 주기 20 s, 30주기(약 10분), 120 Hz. 출력 s = F^0.7, 언로딩에 (1 − h), 드리프트 (1 + k·t/60). 보정은 깨끗한 로딩 곡선 1회로 log s = a + b log F를 맞춘 역변환. 논문에는 힘 보정이 없습니다(§8). 이 토이는 "보정 없이 법선 힘 크기를 읽을 때" 생기는 오차의 규모입니다.

| h \ 드리프트 (%/min) | 0 | 0.5 | 1.0 | 2.0 |
|---|---|---|---|---|
| 0 | 0.00% | 2.40% | 4.84% | 9.82% |
| 0.05 | 2.88% | 2.40% | 3.76% | 8.11% |
| 0.10 | 5.70% | 4.79% | 4.86% | 7.55% |
| 0.20 | 11.14% | 10.22% | 9.67% | 9.98% |

값은 RMSE / Fmax(5 N) 백분율입니다. 최대 절댓값 오차는 h = 0.10, k = 0에서 0.70 N, h = 0.20에서 1.36 N입니다.

그래프: `report/figures/hysteresis.png`.

- 히스테리시스 10%만 있어도 힘 RMSE가 5.7%입니다. 힘의 정확도를 주장하려면 히스테리시스 폭을 먼저 재야 합니다.
- 드리프트 1%/min이면 10분 뒤 최대 오차가 15%입니다(6.2). 보정은 짧은 시간 안에만 유효합니다.
- 6.3에서 보았듯이, 상쇄 때문에 RMSE가 줄 수 있습니다. 표의 0.10/1.0 칸이 0.10/0 칸보다 작은 것이 그 예입니다.
- 이 토이는 촉각 셀의 실제 물리를 모델링하지 않습니다. 실제 히스테리시스 형태(속도 의존, 피로)는 측정해야 합니다.

## 8. 토이 C: 접촉 라벨을 관절 공간 리타게팅에 넣었을 때 (`analysis/retarget_contact_toy.py`)

**설정 (가정):** 평면 3관절 손가락, 사람 링크 (4.5, 2.8, 2.0) cm, 로봇 링크는 사람의 (1.08, 0.95, 1.05)배. 사람 손끝은 책상 위 2D 곡선을 따르고, z < 0.3 cm인 프레임(약 33%)을 접촉으로 봅니다. 사람 관절은 사람 링크로 IK합니다(최대 오차 0 mm). 로봇은 목적함수 ||q − q_h||² + λ c̃ z(q)²를 프레임마다 Gauss-Newton으로 풉니다. c̃는 접촉 라벨이고, ε의 확률로 뒤집습니다. 관통 기준은 z < −0.01 mm입니다.

|---|---|---|---|---|---|---|
| 0 | 0 | 0.985 | 2.904 | 1.00 | 0 | 0 |
| 1 | 0 | 0.015 | 0.159 | 0.61 | 0.686 | 0 |
| 10 | 0 | 0.002 | 0.017 | 0.41 | 0.696 | 0 |
| 100 | 0 | 0.000 | 0.002 | 0.00 | 0.697 | 0 |
| 0 | 10% | 0.985 | 2.904 | 1.00 | 0 | 0 |
| 1 | 10% | 0.089 | 0.164 | 0.65 | 0.616 | 0 |
| 10 | 10% | 0.010 | 0.381 | 0.50 | 0.638 | 2.295 |
| 100 | 10% | 0.001 | 0.002 | 0.10 | 0.639 | 2.647 |

그래프: `report/figures/retarget.png`.

- 접촉 라벨이 정확하면 λ를 10–100으로 두는 것만으로 접촉 높이 중앙값이 0.99 mm에서 0.002 mm 수준으로 떨어지고, 관절 편차는 0.7°에서 멈춥니다. 이 값이 6.4의 식과 맞습니다.
- 라벨이 10% 틀리면 비접촉 프레임에서 관절 편차 90분위가 2.3–2.6°로 커집니다. **라벨 오류의 비용은 접촉 가중치와 함께 커집니다.** λ가 클수록 잘못된 라벨을 강하게 따라갑니다.
- 관통 비율은 λ = 1, 10에서 여전히 0.4–0.6입니다. 관통 기준 0.01 mm가 너무 엄격하고, 약한 가중치로는 완전히 막지 못합니다. 이 점은 실사용에서 λ를 고를 때 관통 기준을 함께 정해야 한다는 뜻입니다.
- 한계: 평면 3관절, 링크 차이 8% 이하, 접촉 프레임 33%, 관절 복사 목적. 실제 손의 3D 관절(엄지 6자유도, 관절 간 결합)과 물체의 기하는 들어 있지 않습니다. 관절 편차의 크기는 링크 차이에 따라 달라질 것입니다. 링크 차이를 키운 실험은 하지 않았습니다.
