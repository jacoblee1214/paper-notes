## 1. 한 줄 요약

World-Action Model(WAM)에 **객체 마스크를 입력과 출력 양쪽에** 넣습니다. 첫 프레임 목표 마스크를 조건으로 주고(공간 앵커), 미래 RGB와 함께 미래 마스크도 예측하게 합니다(의미 감독). 마스크를 RGB처럼 렌더링해 같은 비디오 VAE로 인코딩하고 RGB 잠재와 채널 방향으로 이어 붙이므로, 사전학습된 Wan 2.2 백본에서 패치 임베딩과 출력 헤드의 채널만 늘리면 됩니다(§3.1).

## 2. 방법

### 2.1 구성 (§3, 그림 2)

| 요소 | 내용 | 출처 |
|---|---|---|
| 백본 | Wan 2.2 (TI2V 5B로 보임, 코드 `Wan2.2-TI2V-5B`), 비디오 VAE는 동결 | §3 Overview, §3.3 |
| 입력 | 현재 RGB `I0`, 고유감각 `s0`, 언어 `ℓ`(T5, 동결, 교차 어텐션), 선택적 첫 프레임 마스크 `M0` | 식 1 |
| 출력 | 행동 청크 `a_{1:K}`, 미래 RGB `I_{1:T}`, 미래 마스크 `M_{1:T}` (T = 8) | 식 1, §3.3 |
| 마스크 표현 | 고정 색 팔레트의 3채널 이미지로 렌더링 → 같은 VAE로 인코딩 → `z = [z_v ; z_m] ∈ R^{2C×L×H'×W'}` | §3.1, 식 2 |
| 채널 확장 | 패치 임베딩 C → 2C (새 채널은 0 초기화), 출력 헤드도 C → 2C | §3.1 |
| 행동 분기 | 가벼운 MoT 행동 전문가. 비디오 토큰과 결합 어텐션 (비디오는 행동을 보지 못하고 행동은 둘 다 봄) | §3.3, 그림 2b |
| 마스크 드롭아웃 | 학습 중 확률 0.5로 `M0`을 0 텐서로 교체해 마스크 있음/없음을 한 모델이 처리 | §3.2 |
| 손실 | `L = L_video + L_mask + L_act` (식 3). 시각 타임스텝 `τ_v`는 RGB와 마스크가 공유, 행동 `τ_a`는 독립 | §3.3 |
| 추론 | 첫 프레임 마스크는 SAM 3으로 에피소드 시작에 한 번 생성. 부분 디노이징: RGB-마스크 스트림에 1스텝만 적용하고 그 KV 캐시로 행동 생성 | §3.2, §3.3, 그림 2c |
| 해상도 | 384 × 320 ("T-shape"), 예측 지평 T = 8 | §3.3 |

### 2.2 핵심 주장 두 가지

1. **미래 마스크 예측은 의미 정규화입니다.** RGB 복원은 모든 영역을 같게 다루므로, 마스크 예측이 과제 관련 영역으로 어텐션을 모읍니다(서론, 표 1 오른쪽 어텐션 그림). 마스크 프롬프트가 없어도(LIBERO) 성능이 오른다고 주장합니다.
2. **첫 프레임 마스크는 언어 모호성을 푸는 앵커입니다.** 세 개의 비슷한 그릇 중 하나를 고르는 식의 과제에서, 마스크 프롬프트가 텍스트 좌표 프롬프트보다 훨씬 낫다고 주장합니다. 특히 "미래 마스크 예측이 있어야 프롬프트가 쓰인다"(Q2)가 핵심 절제입니다.

(WorldVLA, GR00T-N1, π0 행은 생략. 전체는 표 1.) 이 실험은 마스크 프롬프트 없이 미래 마스크 예측만 쓴 설정입니다(§4, "even without test-time visual prompts"). 평가 횟수는 논문에 없습니다(`03` V2는 스위트당 500회를 가정).

### 3.2 RoboTwin 2.0 (표 2)

과제 여섯 개(Hammer, Bell, Card, Burger, Stand, Shoe), 과제당 500개 무작위화 에피소드로 학습합니다(표 2 캡션). π0 72.8, FastWAM 87.7, Ours(RGB만) 87.3, Ours(마스크만) 88.8, **Ours 92.2**. 과제 이름은 줄임말이고 평가 횟수와 학습 방식(과제별 또는 통합)은 적혀 있지 않습니다.

### 3.3 실로봇 (§4.1, 부록 A)

듀얼암 Xtrainer, 헤드 D455와 손목 D405. 과제 8개: 1–4는 language-clear, 5–8은 language-ambiguous. 과제당 평균 100개 시연을 수집합니다.

- **Language-clear (표 3, 과제당 100회):** π0 55.8, π0.5 72.3, FastWAM 79.0, Ours(RGB만) 79.3, **Ours 84.3**.
- **Language-ambiguous (표 5, 과제당 60회, 4 설정 × 4 과제):** 분포 내 92.9, 방해물 90.4, 새 물체 74.6, 조명 81.7, 전체 **84.9**. 기준선은 π0-mask 51.7, π0-coord 32.6, FastWAM-coord 17.4(그림 4). "가장 강한 기준선보다 33.2% 높다"는 서론 문장은 π0-mask 대비 포인트 차이입니다.
- **절제 (표 4):** 마스크 프롬프트만 주고 미래 마스크 예측을 뺀 Ours-no-pred 21.6, 좌표 텍스트를 쓴 Ours-coord 18.2, Ours 84.9.
- **마스크 잡음 강건성 (부록 B.2, 그림 8):** 과제 5와 8에서 SAM3 마스크를 침식, 팽창, 이동, 드롭아웃으로 훼손해 평가합니다. 중간 정도 훼손에서는 하락이 작고, 큰 이동(IoU 0.1)에서 크게 떨어집니다.
- **주석 파이프라인 (부록 B.1):** 에피소드의 91%는 사람 수정이 필요 없고, 50개 에피소드 주석에 약 3분이 걸린다고 적습니다.

### 3.4 부록 C의 음의 결과 (수치 없음)

마스크를 이진 다운샘플링하거나 별도 3D CNN으로 인코딩하는 설계, ControlNet식 주입, VLA 기준선의 0 초기화 게이트 융합은 "더 나빴다" 또는 "마스크를 거의 쓰지 않았다"고 서술합니다. 비교 수치는 없습니다.

## 4. 한계 (§6, 저자 서술)

마스크 감독과 배포 시 분할 프롬프트에 의존하며, 복잡한 실환경에서 신뢰할 수 있는 마스크 추출이 자동화되지 않았다고 적습니다. 대규모 RGB-마스크-행동 사전학습은 계산 제약으로 미뤘습니다.

## 5. 이 분석이 본 것 (요약, 근거는 `03`, `04`)

- **표 평균은 모두 맞습니다.** 표 1, 2, 3, 5와 그림 4의 평균은 칸 값에서 재계산되고, 퍼센트는 정수 성공 횟수로 복원됩니다(`03` V1, V3, V5, V7, V8).
- **RGB 예측만 하는 변형은 FastWAM과 구분되지 않습니다.** RoboTwin 87.3 대 87.7(p = 0.93), 실로봇 79.3 대 79.0입니다. 따라서 구조 차이보다 마스크 스트림의 기여가 이득의 출처입니다(`03` V4, V6).
- **마스크 예측의 이득은 크기가 맥락마다 다릅니다.** LIBERO +1.1 (Fisher p = 0.03, 스위트당 500회 가정), RoboTwin +4.8(6과제 모두 상승, 부호 검정 p = 0.031), 실로봇 language-clear +5.0(p = 0.08)입니다. 개별 과제 단위 차이는 모두 p > 0.3입니다(`03` V2, V4, V6).
- **language-ambiguous의 큰 격차(84.9 대 51.7)는 확실하지만 해석에 주의가 필요합니다.** 기준선이 저자 설계의 π0-mask와 좌표 텍스트 변형이고, 프롬프트 없이 학습한 WAM에 마스크만 더한 대조(Ours-no-pred 21.6)가 π0-mask(51.7)보다 낮습니다. 마스크 정보의 유무보다 이 주입 경로가 마스크를 쓰도록 학습되었는지가 결과를 가르는 것으로 보입니다(`03` V9, C5).
- **그림 8의 시행 수 서술(20회)과 그림에서 읽은 값(60분의 정수)이 맞지 않습니다.** 60회 기준이면 모든 값이 설명됩니다(`03` V11, K3).
- **공식 코드와의 차이:** 마스크 드롭아웃 0.5가 공개 학습 설정에서 꺼져 있고(보존 확률 1.0), 손실에 마스크 가중치 0.5가 있으며, RoboTwin 코드가 없습니다(`04` D1, D2, D9).
