# 04. 주장 검증과 구현 가능성

공식 코드가 없어서(`02_prior_work.md` §4) 논문 대 코드 대조 대신 **논문 주장을 표·그림 수치로 다시 확인**합니다. 근거 번호 V는 `03_analysis.md`, 그림과 절은 논문 기준입니다. 판정 표현은 "확인됨 / 부분 확인 / 이 자료로는 확인 안 됨 / 반증 아님"으로 씁니다. "확인 안 됨"은 틀렸다는 뜻이 아니라 시행 수나 설계가 그 서술을 뒷받침하기에 부족하다는 뜻입니다.

## 2. 내부 일관성 검사 (K1–K9)

| 번호 | 위치 | 관찰 | 영향 |

## 4. 구현 가능성 판정

**판정 (이 맥: Apple M4 Pro, 약 24 GiB 통합 메모리, MPS, CUDA 없음)**

**논문 방법의 소규모 재구현은 가능하고, 논문 결과의 재현은 불가능합니다.**

| 단계 | 판정 | 이유와 노력 |
|---|---|---|
| 풀 π0.7 학습 또는 미세조정 (5B VLA) | 불가 | 가중치와 코드가 공개되지 않았고(M9), 학습 데이터와 하드웨어 규모가 비공개(M1, M2). 5B bf16 가중치만 약 10 GB이고 학습 상태까지 더하면 이 맥의 메모리를 넘음 |
| 세계 모델 재현 (BAGEL 14B) | 불가 | 14B bf16 가중치만 약 28 GB로 24 GiB 초과. 논문도 8비트 양자화와 4×H100으로 서비스(부록 D) |
| 공개 가중치 추론 | 불가 | π0.7 가중치 공개 안 됨. 제3자 저장소 두 곳은 회사 파트너 API 접근을 언급(미확인) |
| 실로봇 재현 (UR5e, 모바일 양팔 등) | 불가 | 로봇과 데이터 필요 |
| **프롬프트 확장 학습 방식의 소규모 재구현** | **가능** | 작은 백본(SmolVLA급 또는 작은 트랜스포머)에 메타데이터 토큰, 구성요소별 드롭아웃, 블록 인과 마스크, 선형 상태 사영, 학습 시점 RTC를 넣는 PyTorch 코드 약 600–900줄, 1–2주(추정). MPS와 CPU에서 합성 데이터 또는 MuJoCo 소형 과제로 가능 |
| 마스크, 드롭아웃, CFG 수식의 단위 시험 | 가능 | 수 시간. 장난감은 `analysis/toy_metadata.py`로 이미 돌림 |
| 그림 수치 재계산 | 완료 | `analysis/recompute.py` |
