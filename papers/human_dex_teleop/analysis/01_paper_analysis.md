## 1. 문제와 주장

**문제.** 사람은 한 손 안에서 물체를 돌리고 잡는 방식을 바꾸고 손가락을 번갈아 움직여(finger gaiting) 도구를 씁니다. 기존 텔레옵은 (a) 사람 손 관절을 로봇 관절로 옮기는 **운동학 리타게팅**(DexPilot, AnyTeleop 등)이라 접촉력과 물체 관성을 무시해 물체를 떨어뜨리고, (b) DexGen([13])은 시뮬레이션에서 만든 파지 전이를 학습 목표로 쓰는 **생성형 행동 사전분포**라 물리적으로 맞지 않을 수 있고 폐루프에서 오차가 누적된다고 지적합니다(1절, 2절).

**주장.** 조작자가 손끝 위치와 물체 자세를 목표로 주고(hand-object co-tracking), 시뮬레이션에서 RL로 학습한 저수준 제어기가 접촉 동역학을 맡습니다. 세 가지가 핵심입니다(1절).

1. **연속 부분목표(consecutive subgoal) co-tracking:** 사람 참조 궤적을 프레임별로 따라가지 않고, 일정하지 않은 간격으로 뽑은 부분목표를 순서대로 도달하게 학습합니다. 희소 목표 도달 보상과 밀집 추적 보상을 섞은 하이브리드 보상(식 2)입니다.
2. **기하 인식 리타게팅:** MoCap으로 잰 사람 손-물체 궤적을 로봇 손으로 옮길 때 물체 메시의 SDF로 접촉 인력과 관통 벌칙을 넣는 2단계 최적화(식 4).
3. **무작위 행동 마스킹(random action masking)과 도메인 무작위화**로 제로샷 sim-to-real.

**결과 요약.** SharpaWave(22자유도, 5손가락) 7개 과제에서 평균 SR 75.2%, TP 87.1%(표 1). 기준선(DexRT, GeoRT, DexGen)은 평균 SR 5.7%, 0%, 0%. LeapHand(16자유도, 4손가락)에서도 같은 파이프라인이 동작(표 2). 수집한 시연 50개로 확산 정책을 학습해 3개 과제를 자율 수행(표 3).

## 2. 방법 (3절, 부록 C)

### 2.1 문제 정식화 (3절 서두)

모든 양은 손목 프레임에서 표현합니다. 팔은 사람 손목 자세를 IK로 따라갑니다. 정책은 a_t = π_θ(o_t, g_t)이고 g_t = (p̂_tip, T̂_obj)는 목표 손끝 위치(N_f × 3)와 목표 물체 자세(SE(3))입니다. 텔레옵 중에는 MoCap이 실시간으로 잰 사람 손끝과 물체 자세가 g_t가 됩니다.

### 2.2 연속 부분목표와 도달 판정 (식 1, 3.1절, 부록 C.2, C.4)

- 오차: 손끝 e_f = ‖p_tip,f − p̂_tip,f‖₂, 물체 위치 e_pos = ‖x − x̂‖₂, 물체 회전 e_rot = ‖Log(R̂ᵀR)‖₂ (식 1).
- 도달: N_stay 연속 프레임 동안 max_f e_f < ε_tip, e_pos < ε_pos, e_rot < ε_rot. 표 8의 값은 ε_pos = 1 cm, ε_tip = 3 cm, ε_rot = 10°, N_stay ~ U{5, 15}(도달할 때마다 재추출).
- 다음 부분목표: 확률 0.9로 같은 궤적의 k + Δk(범위는 커리큘럼으로 확장), 확률 0.1로 같은 물체의 다른 궤적에서 같은 프레임 번호를 고르는 **교차 궤적 전환**(식 9, "Any2Any").
- 실패 종료: 속도 한계, 물체 위치 오차 15 cm 초과, 또는 허용 밖 프레임이 n_max = η_fail·|Δk|를 넘을 때(η_fail = 1.5, 교차 궤적 직후는 300프레임 고정). 종료 뒤에는 참조 상태 초기화(RSI)로 궤적 앞 90% 안의 임의 프레임에서 시작합니다.

### 2.3 보상 (식 2, 3, 5–8, 표 8)


```
r_t = 1_reach(t) · w_step(t) · r_score(t) + α_dense · r_dense(t) − c_time
```


- r_score = α_s [ w_tip Σ_f ρ_f + w_obj (ρ_pos + ρ_rot) ], ρ = exp(−β e) (식 6, 7). α_s = 1.5, w_tip = 0.5, w_obj = 2.0. 손가락 5개면 최댓값은 1.5 × (2.5 + 4.0) = 9.75입니다(`03` V11).
- w_step: 궤적 안 전환은 |Δk| + 5, 교차 궤적 전환은 100. 큰 점프일수록 큰 보상입니다.
- r_dense: 손끝 5개와 MCP·근위 관절 평균에 지수 커널, 물체 항은 (1 − σ_t)로 가중 (식 8). α_dense = 0.1.
- c_time = 0.1.
- 본문 식 3은 α_s를 쓰지 않고 가중치를 w_f, w_pos, w_rot로 적었고, 부록 식 6은 α_s와 w^s로 다시 씁니다. 값은 부록 표 8에만 있습니다.

### 2.4 관측과 행동 (부록 C.1, 표 7)

- 관측 차원: SharpaWave 142, LeapHand 112(항목 합이 일치합니다, `03` V11). 관절 속도와 접촉력은 **의도적으로 제외**했고, 중력 방향은 손목 프레임에서 유일한 세계 기준 단서입니다. 촉각은 없습니다.
- 행동: HORA식 잔차 관절 목표에 소프트 데드존 deadzone_τ(a) = sign(a)·max(|a| − τ, 0), α_a = 0.1, τ = 0.1. 0을 정확히 내기 어려운 가우시안 정책에 "가만히 있기" 구간을 줍니다.

### 2.5 커리큘럼 (3.1절, 부록 C.3)

- 본문은 **세 축**(중력 감소 → 완전 중력, 추적 허용오차 완화 → 엄격, 부분목표 간격 작음 → 큼)이라고 쓰고, 부록은 **네 노브**(부분목표 간격 상한 40 → 80프레임, 행동 마스킹 지속 1 → 10프레임, 밀집 물체 보상 가중 (1 − σ_t), 중력 0 → −9.8 m/s²)를 적습니다. 허용오차 완화 일정은 부록 목록에 없습니다(`03` K5).
- σ_t는 1에서 σ_min = 0.7까지 T_σ = 25,600 환경 프레임(환경당)에 걸쳐 선형으로 줄고, 상한은 3차식으로 확장합니다. 중력은 환경당 32 K 프레임에 걸쳐 선형.

### 2.6 무작위 행동 마스킹 (3.1절, 부록 C.8)

각 스텝에서 마스크가 켜져 있지 않으면 확률 p_mask = 0.15로 새 마스크를 뽑습니다. 관절 3개를 비복원 추출하고 지속 시간 d ~ U{1, d_max} 동안 그 관절들의 실행 행동을 직전 명령으로 고정합니다: ã_t = m_t ⊙ a_t + (1 − m_t) ⊙ ã_(t−1). 의도는 "일부 관절이 낡은 명령을 유지해도 성공"하도록 하는 행동 공간 정규화입니다.

### 2.7 sim-to-real와 학습 설정 (3.1절, 부록 C.7, C.9, 표 9, 10)

- 도메인 무작위화(표 9): 손 질량 ×U[0.9,1.2], 마찰 U[1,4], Kp·Kd ×U[0.8,1.2], 물체 질량 ×U[0.5,2], 마찰 U[0.5,4], 메시 스케일 ×U[0.95,1.05], 물체에 가하는 외력(Visual Dexterity 방식), 관측 잡음(관절 σ=0.1, 손끝·물체 위치 ±5 mm, 자세 ±2°), 관측 지연(큐 2프레임), 초기 손목 방향 ±30°.
- Isaac Gym, SAPG(블록 6개), LSTM 512 + MLP [512,1024,1024,512,512], 4 × RTX 5090에서 약 62,400 환경, 약 10¹⁰ 환경 스텝, 약 1일(C.9, 표 10). 물체 하나당 참조 궤적 150개 × 20 s = 약 50분(C.6).

### 2.8 기하 인식 리타게팅 (3.2절, 식 4, 부록 C.5)


```
q*(1:T) = argmin_q Σ_t [ L_vec(t) + λ_surf L_surf(t) + λ_pen L_pen(t) + λ_col L_col(t) ] + λ_smooth L_smooth
```


1단계는 벡터 리타게팅(Adam, lr 10⁻³, 6,000회), 2단계는 SDF 기반 표면 인력(임계 τ_surf 안의 손 표면점을 물체 표면으로), 관통 벌칙, 손가락 간 구-구 자기충돌, cuRobo 평활 에너지(Adam, lr 3×10⁻³, 160회, 기울기 노름 1.0 클립). λ_surf = 10, λ_pen = 2, λ_col = 10, λ_smooth = 0.1. τ_surf는 "2"로만 적혀 있고 단위가 없습니다(`03` K13).

### 2.9 텔레옵 배치 (3.3절, 부록 B.3)

NOKOV 광학 MoCap이 30 Hz로 손목, 손끝(실시간용 간이 장갑), 물체 6D 자세를 줍니다. 파지 전 접근과 첫 접촉은 **운동학 벡터 리타게팅**이 맡고, 안정 접촉이 생기면 **조작자가 co-tracking 정책으로 전환**합니다(3.3절, B.3.2). 전환 방법(버튼 등)은 적혀 있지 않습니다.

## 3. 실험 (4절, 부록 A)

### 3.1 설정 (4.1절, 4.2절, 부록 B, D)

- 로봇: Franka FR3 + SharpaWave(5손가락, 22자유도) 또는 LeapHand(4손가락, 16자유도). 모든 텔레옵 평가는 30 Hz.
- 과제 7개(그림 3, 부록 B.1): 재배향 3개(Cylinder, Cuboid, Bunny; 3단계씩)와 도구 사용 4개(HammerUse 7단계, BrushSweep 7단계, ScrewdriverUse 5단계, BulbReplace 6단계). 물체는 마찰을 위해 의료용 붕대 테이프를 감았습니다(B.1).
- 지표: **SR** = 모든 단계를 마친 시행 비율, **TP** = 시행별 (마친 단계 수 / 전체 단계 수)의 평균. 과제·방법당 **15회**(4.2절).
- 기준선(부록 D): DexRT(dex-retargeting, 운동학), GeoRT(신경 리타게팅, 공식 구현), DexGen(**공식 구현이 없어 재구현**; 핵심 중간 단계인 AnyGrasp-to-AnyGrasp RL 정책을 TeleDexter의 co-tracking 제어기로 **대체**해 시뮬 롤아웃을 만들고 이후 확산 사전분포 학습·배치는 원 논문을 따름), SimToolReal(공식 구현으로 FR3 + SharpaWave에서 재학습; 텔레옵이 아니라 추론 시 사람 참조 동작이 필요한 방법; 도구별 정책 †, 전 도구 단일 정책 ‡, 세 과제만).

### 3.3 자율 정책: 텔레옵에서 자율로 (4.3절, 표 3, 부록 B.2, E)

과제 3개(BulbInstall 4단계, HammerDriver 3단계, BrushForward 3단계)에서 시연 50개로 Conv-UNet 확산 정책(DINOv2 ViT-S/14 고정 인코더 2개, 관측 2프레임, 행동 청크 16, DDIM 16스텝)을 학습하고 15회 평가합니다. 단계별 성공: BulbInstall 13/15 → 12/13 → 8/12 → 7/8 (SR 46.7%), HammerDriver 15/15 → 15/15 → 11/15 (73.3%), BrushForward 7/15 → 7/7 → 6/7 (40.0%). HammerDriver는 텔레옵 HammerUse보다 큰 못과 폼 표적을 쓰는 단순화 과제입니다(B.2). 비교 대상은 없습니다. "기존 텔레옵으로는 같은 데이터를 모을 수 없다"는 것이 이유로 적혀 있습니다(4.3절).

### 3.4 절제 (4.4절, 표 4, 5, 부록 A.2)

- **표 4 (시뮬, 보류 참조 동작 3개 물체):** 연속 부분목표 학습 대 밀집 프레임 추적. 밀집 평가(참조가 매 스텝 진행)에서 에피소드 길이 Cuboid 378.6 대 115.8, Hammer 376.9 대 131.2, Screwdriver 373.2 대 88.7. 희소 평가(목표 도달 후 진행)에서 도달 부분목표 수 32.6 대 2.6, 186.6 대 2.7, 178.5 대 2.7.
- **표 5 (실로봇, SR / TP):** 행동 마스킹 있음 대 없음. HammerUse 66.7 / 86.7 대 33.3 / 57.1, ScrewdriverUse 73.3 / 86.7 대 0.0 / 36.0, CuboidReorient 80.0 / 86.7 대 26.7 / 51.1.
- **그림 5 (Hammer, 학습 곡선):** 커리큘럼 없음과 SAPG 대신 PPO가 보상과 연속 성공에서 모두 낮음. 곡선의 끝값은 `03` V12.

### 3.5 부록 A.1: any-to-any 재위치 시험 (LeapHand, 표 6)

참조 집합의 모든 프레임을 목표 풀로 삼아, 직전 목표에 도달할 때마다 새 목표를 뽑아 이어서 줍니다. 도달 기준은 물체 위치 오차 2 cm 미만, 회전 오차 20° 미만. 시행은 물체 이탈 또는 20초 동안 목표 미도달 시 종료. 15회: Cylinder 연속 성공 평균 41.1, 목표당 성공률 97.6%. Cuboid 12.1, 92.3%.

### 3.6 부록 A.4: 실패 유형 (그림 7)

(1) 상호작용 교란(못 치기 같은 충격으로 손 안 자세가 바뀜), (2) 접촉 전환 걸림(올라가야 할 손가락이 물체에 끼어 물체가 튕겨 나감, BunnyReorient에서 가장 잦음), (3) 추적 정체(재파지가 실패해 진전이 없음; 촉각이 없기 때문이라고 귀속). 실패 유형별 횟수는 보고되지 않았습니다.

## 4. 한계 (6절)와 이 분석이 본 한계

**저자가 적은 한계(6절).** 물체별 제어기(새 물체마다 사람 시연 수집과 학습 필요), MoCap 의존(손과 물체 자세).

**이 분석이 본 점(자세한 근거는 `03`, `04`).**
- 시행 수는 칸당 15회라 Wilson 95% 구간이 대략 ±20 %p입니다. 격차가 큰 칸(80 대 0)은 확실하지만 최고 기준선이 SimToolReal인 Hammer, Brush 칸은 Fisher p가 0.025, 0.027이고 Holm 보정 후 0.051입니다(`03` V5).
- 조작자 수, 시행 순서, 시도 간 독립성(물체 재배치, 장갑 재보정)은 적혀 있지 않습니다.
- "human-level"은 사람과의 직접 비교(성공률, 소요 시간, 지연)로 측정하지 않았습니다(`04` C2).
- 행동 마스킹 외의 sim-to-real 요소(도메인 무작위화, 지연, 외력)와 기하 인식 리타게팅은 절제하지 않았습니다(`04` C6, C7).
- DexGen 기준선은 TeleDexter의 제어기로 시뮬 롤아웃을 만든 재구현이라 원 시스템과 같다고 볼 수 없습니다(`04` C12).
- 학습·평가에 쓰는 시뮬 제어 주파수, PD 이득, 시뮬 손 모델 파일은 논문에 없습니다(`04` §4).
