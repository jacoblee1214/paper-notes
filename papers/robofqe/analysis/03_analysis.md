- **실로봇 표의 "가장 낮은 ARE"는 검정되지 않습니다.** RoboFQE 7.5 ± 5.0 대 Ctrl-World 10.3 ± 10.2는 Welch p = 0.37입니다. 표기와 본문의 "±" 정의가 서로 다릅니다(§1.4).
- **백분율 세 개는 표기된 표본 수와 맞지 않습니다.** LRM 정확도 83.3%(n = 250)와 정책 성공률 58.5%(n = 300)는 정수 성공 수로 만들 수 없습니다(§1.4).
- **라벨 오류는 주로 절대값을 흔듭니다.** LIBERO에서 정확도 97.4%의 대칭 오류는 할인 반환을 평균 약 −1.6–2.4% 끌어내리고 순위는 그대로 둡니다. 실로봇(γ = 1)에서 83.3%의 대칭 오류는 평균 상대 오차 약 11.6%를 만들어 보고된 7.5%보다 큽니다. 실제 오류가 대칭이 아니거나 목표 정책 롤아웃에서 다르다는 뜻입니다(토이 2, §4).

## 1. 재계산과 일관성 검사

### 1.1 표 1: ARE와 MSE

Jensen 부등식에 따라 같은 V^π와 같은 추정치 집합에서 평균 |e|/V ≤ sqrt(평균 e²)/V 입니다. 보고된 ARE가 이 상한보다 크면 기준값이나 정의가 다릅니다. V는 캡션 값(Spatial 0.237, Object 0.166, Goal 0.246, Long 0.029)을 썼습니다.

| 방법 | 과제 | 보고 ARE (%) | RMS 상한 (%) | 판정 |
|---|---|---|---|---|
| RoboFQE | 네 과제 전부 | 3.40 / 4.56 / 2.34 / 5.63 | 3.40 / 4.56 / 2.34 / 7.07 (Long) | 맞음 |
| RoboFQE-scratch | Spatial | 9.35 | 9.12 | **상한 초과 (0.2pp)** |
| WorldGym | Long | 69.18 | 68.75 | **상한 초과** |
| Cosmos 2.5-AC | Long | 54.37 | 50.74 | **상한 초과 (3.6pp)** |
| Ctrl-World | Long | 58.75 | 56.17 | **상한 초과 (2.6pp)** |

- Long의 V는 0.029로 두 자리입니다. 반올림(±0.0005)을 고려해도 Cosmos·Ctrl-World 셀의 초과는 남습니다.
- RoboFQE 행 네 개는 모두 상한 안에 있고, Spatial, Object, Goal은 상한과 거의 같습니다. ARE가 상한과 같다는 것은 오차 크기가 시드마다 거의 같다는 뜻입니다. 그러면 "±"의 부트스트랩 구간이 무엇을 리샘플링했는지가 중요해집니다(논문에 없음).
- **표 5(데모만)** 의 세 행도 상한을 넘습니다. Spatial 19.22 대 상한 16.84, Object 29.05 대 27.79, Goal 23.07 대 22.21입니다. Long(30.85 대 30.94)만 맞습니다. 표 5는 "단일 학습 실행"이라고 적혀 있어서 MSE와 ARE가 다른 실행에서 나왔을 가능성이 있습니다.

## 3. 토이 1: 정답 노이즈의 바닥과 순위 천장

`analysis/toy_gt_noise.py` (numpy, 1초 미만). 정답 V = γ^(T−1)의 평균입니다. 성공은 Bernoulli(SR), 성공 시점은 정규분포(평균 μ, 표준편차 c·μ)를 자른 분포입니다. μ는 V/SR이 맞도록 정했습니다. c = 0.15, 0.25, 0.35를 씁니다. 정답은 200 궤적입니다. **성공 시점 분포는 가정이며 논문에 없습니다.**

**(a) 정답 추정의 상대 표준오차와 ARE 바닥(평균 절대 오차 = 0.80 SE/V)**

| 과제 | c = 0.15 (SE / 바닥) | c = 0.25 | c = 0.35 | 보고 RoboFQE ARE |
|---|---|---|---|---|
| Spatial | 3.4% / 2.7% | 4.0% / 3.2% | 4.8% / 3.9% | 3.40% |
| Object | 4.0% / 3.2% | 4.9% / 3.9% | 6.1% / 4.9% | 4.56% |
| Goal | 4.1% / 3.3% | 4.6% / 3.7% | 5.2% / 4.2% | 2.34% |
| Long | 9.4% / 7.5% | 12.3% / 9.8% | 17.3% / 13.8% | 5.63% |

- 몬테카를로(4000 반복)로 확인한 표준오차는 해석식과 대부분 0.1pp 안에서 맞습니다. Long c = 0.35만 1.3pp 차이가 납니다.
- **해석:** Spatial과 Object는 보고된 ARE가 정답 노이즈 바닥과 같은 크기입니다. 즉 RoboFQE가 정답과 얼마나 다른지 구분할 수 없습니다. Long은 보고 ARE 5.63%가 가장 낙관적인 c = 0.15의 바닥 7.5%보다도 낮습니다. 그러므로 Long의 "5.6% 오차"는 정답 기준으로 0과 구분되지 않습니다. 그래도 세계모델의 50–70%와는 차이가 크므로, 비교 결론은 유지됩니다.

**(b) 순위 천장:** 체크포인트 네 개의 SR 간격을 세 가지로 두고, 정답 노이즈가 있는 순위와 참값 순위의 상관 중앙값을 봤습니다(c = 0.25).

| 과제 | 좁음 (0.84–0.73) | 중간 (0.84–0.30) | 넓음 (0.90–0.05) | 좁은 쌍의 순서 맞힘 확률 |
|---|---|---|---|---|
| Spatial | 0.88 | 0.99 | 1.00 | 0.72 |
| Object | 0.86 | 0.99 | 1.00 | 0.70 |
| Goal | 0.89 | 0.99 | 1.00 | 0.73 |
| Long | 0.74 | 0.99 | 1.00 | 0.64 |

- SR이 3–4pp 차이나는 정책은 정답 200 궤적으로 순서를 맞힐 확률이 약 70%입니다. 그러면 **어떤 방법도 정답과 상관 0.88 이상을 얻을 수 없습니다.** RoboFQE의 0.88–0.96이 이 천장보다 높으면 SR 간격이 큰 정책 집합이었다는 뜻이고, 낮으면 방법의 한계입니다. 논문의 SR 간격을 모르므로 판정할 수 없습니다(그림 `own_rank_toy.png`).
- 순위 집합의 간격이 넓으면 천장은 거의 1이라서 순위 상관은 방법을 가릴 만큼 민감합니다.

## 4. 토이 2: LRM 라벨 오류가 할인 반환을 바꾸는 방식

`analysis/toy_label_noise.py` (numpy, 1초 미만). FQE가 잘 맞았다고 가정하면 추정 목표는 E[γ^(T−1) r̂]입니다. 라벨은 성공 궤적에서 TPR, 실패 궤적(H에서 종료)에서 1 − TNR로 1이 됩니다. 닫힌 형태는 다음과 같습니다.

V̂ = TPR·V + (1 − TNR)·γ^(H−1)·(1 − SR)

몬테카를로(정책당 40만 궤적)와 닫힌 형태는 상대 편향 기준 0.05%p 이내로 맞습니다. 과제별로 H와 할인 평균만 바꾸고, 정책 SR은 공통 집합(0.84–0.30)을 썼습니다. Long의 실제 SR은 0.43이라 이 부분은 근사입니다.

**(a) LIBERO, 대칭 오류(TPR = TNR = 정확도), 정책 4개 평균 상대 편향**

| 과제 | 정확도 97.4% | 정확도 90% |
|---|---|---|
| Spatial | −1.7% | −6.3% |
| Object | −1.9% | −7.3% |
| Goal | −2.2% | −8.6% |
| Long | −2.4% | −9.2% |

- 네 과제 모두 Kendall 순위 상관이 1입니다. 거짓 양성의 가중치 γ^(H−1)(1 − SR)은 Spatial에서 0.018 (SR 0.84) – 0.078 (SR 0.30), Long에서 0.003 안팎이라서 실패가 성공으로 잘못 잡혀도 값에 거의 안 들어갑니다. 대칭 오류의 주된 효과는 **음의 방향 편향**입니다.
- 논문은 부호가 있는 편향을 보고하지 않습니다. ARE와 MSE만 있어서 편향의 부호를 알 수 없습니다.
- **"최소 손실" 주장과의 관계:** 초록은 학습된 성공 주석이 "정확도를 약간만 떨어뜨린다"고 씁니다. 그러나 v2 본문에는 LRM 라벨과 정답 라벨을 나란히 둔 RoboFQE 표가 없습니다. 코드에는 `--rollout-reward-key sim_rewards`가 있어 이 비교가 가능하지만, 결과는 논문에 없습니다.

**(b) 실로봇(γ = 1, SR 58.5 / 81.0 / 33.0%), 대칭 83.3%**

| 정책 | V̂ − V (pp) | 상대 오차 |
|---|---|---|
| SR 58.5% | −2.8 | 4.9% |
| SR 81.0% | −10.4 | 12.8% |
| SR 33.0% | +5.7 | 17.2% |
| 평균 | | **11.6%** |

- 보고된 RoboFQE ARE 평균은 7.5 ± 5.0%입니다. 대칭 오류만으로도 11.6%가 나오므로, 실제 오류가 대칭이 아니거나 목표 정책의 롤아웃에서는 정확도가 다르다고 볼 수 있습니다. 이 토이로 어느 쪽인지는 가릴 수 없습니다. 목표 정책 롤아웃에서 클래스별 정확도를 재야 합니다.
- **정책 의존 오류:** 33% 정책의 실패만 자주 성공으로 본다고 하면(FPR 0.30, 나머지 0.05) 그 정책의 상대 오차는 56%가 되지만 **순위는 유지됩니다.** 실로봇에서는 값이 틀려도 순위는 잘 남습니다.
- **비대칭 오류(LIBERO Spatial):** TPR 0.75, TNR 0.99에서는 편향이 −2 ~ −6pp, TPR 0.99, TNR 0.75에서는 +0.2 ~ +1.8pp입니다. 순위는 모두 유지됩니다.
- **결론:** 라벨 오류의 주된 효과는 절대값 편향입니다. 순위는 거짓 양성 가중치가 작은 LIBERO에서 안정적이고, 실로봇에서도 큰 차이가 있을 때만 흔들립니다. 그러나 **절대값이 중요한 배포 결정**에서는 편향이 상당합니다(논문 5절도 같은 점을 말합니다).

## 5. 한계와 가정

- 토이는 정책의 행동, 상태, 이미지를 모형화하지 않습니다. FQE의 함수 근사 오차, 궤적 커버리지, 정책 간 상태 분포 차이는 빠져 있습니다. 토이 결과를 RoboFQE의 실제 수치로 옮기면 안 됩니다.
- 성공 시점 분포(정규, 변동계수 0.15–0.35)는 가정입니다. 실제 분포가 더 치우쳐 있으면 정답 노이즈가 달라집니다.
- 정답 궤적 수 200은 논문 4.1의 LIBERO 설정입니다. CALVIN과 실로봇 정답 수는 §1.3–1.4에서 따로 다뤘습니다.
- MPS 속도(§6)는 인코더 한 번의 순전파와 역전파만 측정했습니다. 정책 순전파, 데이터 로딩, 평가는 빠져 있어 실제 시간은 더 깁니다.
