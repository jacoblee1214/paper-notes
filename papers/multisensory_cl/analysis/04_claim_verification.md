# 04. 주장 검증과 구현 가능성

공식 코드가 없어 논문 ↔ 코드 대조(D 항목) 대신, 논문의 주장을 표·본문 수치로 다시 확인했습니다(C1–C18). 재계산 결과는 `03`의 V 항목입니다.

## 1. 코드와 데이터 상태 (2026-11-24 확인)

- 프로젝트 페이지의 "Code" 링크는 `github.com/jadenvc/multisensory_wm`(README에 "Code to be released" 한 줄, 마지막 커밋 2026-07-02)을 가리킵니다. 모델 코드, 체크포인트, 데이터셋 링크는 프로젝트 페이지와 README에서 찾지 못했습니다(`02` §2).
- 같은 계정의 `multisensory-world-model`은 LingBot-VA 기반 저장소로 보이며, 논문이 쓰는 UVA/MAR 구현과의 관계는 확인하지 못했습니다. 읽거나 실행하지 않았습니다.
- 그래서 이 문서는 코드 대조가 아니라 주장 검증입니다. 아래 판정은 "논문에 실린 정보로 확인 가능한 범위"입니다.

## 2. 주장 검증 (C1–C18)

판정 표기: 지지(수치와 방향이 맞고 이 시행 수로 구분됨) / 방향만(방향은 맞으나 시행 수로 구분 안 됨) / 조건부(교란이나 정보 부족) / 확인 불가 / 불일치.

| ID | 주장(위치) | 확인한 것 | 판정 |
|---|---|---|---|
| C1 | 접촉이 많은 미세조정 과제에서 잘 동작(초록, §4.2) | 전진 합산 80% 대 No F/T 53.8%, No Pretrain 47.5%(`03` V11, p 0.005–0.031). 과제별로는 페그 대 No Pretrain(p = 0.021)만 단독으로 구분되고 닦기·페그 대 No F/T는 경계 또는 비유의(V9) | 방향만 (합산은 지지) |
| C2 | 사전학습 과제에서도 성능 향상, "+17.5% success"(그림 1, 초록) | 산술은 맞음(72.5 − 55). 합산 95% 구간 [-3.5, +36.5] %p, p = 0.16. 과제별 p 0.11–1.0(V9, V11) | 방향만 |
| C3 | "적은 다중 감각 데이터가 미세조정 분포 밖의 일반 능력을 높인다"(초록) | 후진 평가의 닦기, 페그와 가까운 과제 데이터가 미세조정에 들어 있음: 미세조정에 닦기(vase) 160, 페그 144 에피소드, 사전학습의 닦기·페그 192–278 에피소드(`03` V5). "해당 과제 데이터를 더하지 않았다"는 문장은 문자 그대로는 맞으나 관련 과제 데이터는 더해짐. 보상 제어를 켜고 끄는 분리도 후진 평가에는 없음(V14) | 조건부 (F/T 효과와 관련 데이터 효과가 분리되지 않음) |
| C4 | 경험 재생이 망각을 막는다(§4.3) | No ER 닦기 0.5/15, 페그 2/15, 합산 +52.5 %p [31.2, 67.3]. Holm 보정 후에도 닦기는 0.002. 단 No ER는 "원 데이터를 전혀 안 쓰는" 극단 기준선이고 재생 비율을 바꾼 비교는 없음 | 지지 (효과 방향·크기 분명, 비율 민감도는 미확인) |
| C5 | 교차 모달 F/T 예측이 사전학습 과제로 일반화(§4.1, 그림 4·5) | 오차 8.42(그림 판독 값). 영 예측·직전 값 유지 같은 기준선, 반복 실행 분산, 평가 궤적 수가 없고 N과 Nm이 섞인 노름임(V7, `03` §3-5). 그림 5는 사례 3개(실패 사례 2개 명시) | 조건부 (기준 없는 단일 수치) |
| C6 | 초기+후기 융합, 비디오 예측, 경험 재생이 각각 중요(§4.1 Takeaway) | 7개 절제 모두 MuSe(8.42)보다 오차가 큼(+17.6% ~ +47.0%). 단일 실행으로 보이고(시드 미기재) 융합 변형 4개는 11.52–12.06으로 순서를 가리기 어려움(V7, `03` §3-6) | 방향만 |
| C7 | DP 기준선이 미래 영상 예측의 역할을 분리(표 2, 부록 6.2) | 표 2는 "Img. pred."만 다른 것으로 적지만, 본문은 DP가 "late fusion 없음"이라고도 씀. DP의 백본과 구조는 부록 6.2에 상세 기재가 없어(MAR-Large 기반인지 불명), 영상 예측 외 요인이 함께 달라졌을 가능성을 배제할 수 없음. 영상 예측의 기여로 분리되었다고 보기는 어려움 | 조건부 |
| C8 | "No VP"가 미래 영상 예측 제거를 뜻함(§4.1, 부록 6.3) | 부록 6.3은 "no-video-prediction baseline은 정책 모드만으로 학습"이라고 씀. 영상 손실 제거와 함께 다섯 모드 중 네 모드(영상 생성, 순·역동역학, 완전 동역학)가 빠짐. "미세조정에서만 제거" 변형은 v2 그림에만 있음(`01` §0) | 조건부 |
| C9 | F/T 예측이 적응 강성에 쓰여 성능을 높임(부록 6.1, 표 1) | 닦기 11.5 대 8, 페그 13 대 11. p 0.25–0.65(V10). 닦기에서 보상 제어를 끄면 No Pretrain과 같아짐(8 대 8) | 방향만 |
| C10 | 사전학습이 변형 일반화를 높임(§4.2) | 전진 MuSe 대 No Pretrain 합산 +32.5 %p [11.5, 49.9]. 단 No Pretrain은 434 에피소드만으로 학습하므로 "사전학습 효과"에 데이터 양(1,271 에피소드)이 포함됨 | 지지 (해석은 데이터 양과 함께) |
| C11 | F/T 미세조정이 집어 놓기 성능을 떨어뜨리지 않음(§4.2) | 7.5/10 대 7.5/10(No F/T)로 같음. n = 10, 구분 불가이므로 "하락이 관측되지 않았음"이 정확한 표현(V9) | 지지 (하락 없음의 증거는 약함) |
| C12 | DP는 미세조정에서는 강하나 후진 전이에서 크게 떨어짐(부록 6.2, 표 3·4) | 전진 합산 26 대 32(p = 0.21), 후진 합산 17.5 대 29(p 0.012–0.023)(V11). DP 후진 닦기 6.5, 페그 5는 Pretraining Only 8.5, 8보다 낮음 | 지지 (후진), 방향만 (전진) |
| C13 | 그림 3, 그림 1의 막대 값이 표와 일치 | 18개 막대 중 17개 일치. 그림 3 전진 페그 MuSe 93%는 표의 13/15(86.7%)와 불일치(v1은 87%). 그림 1 합산 80%는 표와 일치(V3, V4) | 불일치 1건 (저자 확인 필요) |
| C14 | 보고된 본문 수치가 그림 4와 일치(§4.1) | Linear 11.518은 그림의 No Late(11.52)와 일치하고 그림의 Linear는 11.80. 나머지 5개 값 일치(V7) | 불일치 1건 (저자 확인 필요) |
| C15 | "다중 감각" 연속 학습 프레임워크(제목, 초록) | 실험은 힘-토크 한 모달리티, 손가락 센서 두 개, 로봇 한 대, 과제군 세 개. 논문 §5도 촉각·오디오·깊이는 향후 과제라고 밝힘 | 조건부 (범위가 F/T 사례로 한정) |
| C16 | 평가가 비교 가능한 조건 | 종료 조건(20 N, 6 Nm)을 모든 방법에 적용하는지, 기준선(No F/T, Pretraining Only)이 어떤 저수준 제어(강성)로 실행되는지 본문에 없음. No F/T는 F/T 예측이 없어 적응 보상 제어를 쓸 수 없는 것으로 읽힘(§3.5, 부록 6.1) | 확인 불가 (제어 조건 미기재) |
| C17 | 시행 수와 평가 방식 | 과제당 10–15, 부분 점수(>50%, >90% 제거 등). 시행 순서, 맹검 여부, 시드/체크포인트 수, 초기 조건이 방법 간 같은지는 미기재(부록 6.5) | 확인 불가 |
| C18 | 재현에 필요한 학습 정보 | 손실 가중치 λ_a, λ_o, λ_{n+1}, 총 학습 스텝, 시드, 재생 샘플링(균등 합집합 기준 74.5%), F/T 정규화, 어댑터 삽입 블록 수 d, 강성 복원 함수와 필터 길이, 평가 에피소드 선택 기준이 본문에 없음. 기재된 것: 최적화기, 학습률, 배치 40, GPU 8장, 토큰 구조(부록 6.3, 6.4) | 확인 불가 (정보 부족) |

## 3. 재현에 비어 있는 정보

- 데이터: UMI-FT로 모은 사전학습 1,271, 미세조정 434 에피소드의 공개 링크가 없습니다. 하드웨어(UR5e, WSG50, CoinFT 2개, iPhone)가 필요합니다.
- 코드: 공식 코드 없음. 백본 UVA(MIT), MAR(MIT), ACP(MIT), UMI-FT(MIT)는 공개되어 있어 일부를 조합할 수 있지만, MuSe 고유의 F/T 인코더·어댑터·마스킹·모드 샘플링 코드는 공개본이 없습니다.
- 학습 설정: 위 C18의 공백.
- 라이선스: MuSe 코드 저장소는 없고 `jadenvc/multisensory_wm`은 라이선스 파일이 없습니다(`02` §2).

## 4. 구현할 수 있는지 (이 맥: Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)

**판정: 논문의 결과를 재현하는 것은 이 맥에서 불가능합니다. 재계산(완료)과 구조 개념의 축소판 토이는 가능합니다.**

| 수준 | 판정 | 근거 |
|---|---|---|
| 실로봇 결과(표 1, 3, 4) | 불가 | UR5e + WSG50 + UMI-FT + iPhone, 평가 시행 수백 회, 데이터 비공개 |
| MuSe 학습(MAR-Large 479M, 8 × RTX Pro 6000, 배치 40) | 불가 | CUDA 전제의 대형 확산 모델. 이 맥에서 MPS로도 메모리·속도가 맞지 않음. 학습 스텝 수 미기재 |
| 공식 코드 사용 | 불가 | 코드 없음 |
| UVA 공식 코드(MIT) 위에 F/T 경로를 직접 구현해 소규모 합성 데이터로 돌리기 | 조건부 | UVA 코드 다운로드·설치·실행 승인이 필요하고, 사전학습 가중치(대형)와 CUDA 가정 수정이 필요해 실질 이득이 작음 |
| 재계산(표, 그림 라벨, 검정) | 가능, 완료 | `analysis/recompute.py` (수 초, numpy/scipy) |
| 구조 개념의 토이: 영 초기화 어댑터 + 모달리티 마스크 토큰 + 경험 재생을 작은 MLP/트랜스포머와 합성 F/T 과제로 | 가능 | torch(설치됨, CPU 또는 MPS)로 분 단위. 단 실제 모델과 거리가 멀어 논문 수치의 검증은 아님 |

노력 추정(측정 전, 추정): 합성 토이 3–5일. UVA 코드 위 F/T 경로 구현과 소규모 사전학습·미세조정은 승인과 GPU가 있다면 3–4주. 논문과 같은 데이터 수집과 평가까지는 장비와 수 개월이 필요합니다.
