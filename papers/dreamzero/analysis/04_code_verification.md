## 0. 범위와 방법

- **대상:** `github.com/dreamzero0/dreamzero`, HEAD `ab790c1` (2026-04-19), 얕은 복제 `dreamzero/repo/` (정적 읽기 전용).
- **했던 것:** README, LICENSE, COPYRIGHT, 학습 스크립트 `scripts/train/*.sh`, 행동 헤드 `groot/vla/model/dreamzero/action_head/wan_flow_matching_action_tf.py`와 설정 yaml, 서버 `socket_test_optimized_AR.py`, 빌드 스크립트 `scripts/inference/build_trt_engine.py`. 체크포인트의 `config.json`(약 3–4 KB), 모델 카드 README(약 3 KB)만 받았습니다(HuggingFace raw 파일).
- **하지 않은 것:** 코드 실행, import, 설치(`pip install`, `uv sync`), 가중치와 데이터 다운로드, API 호출.

- **공개 자료에서 보이는 학습 규모:** DROID 체크포인트의 `config.json`의 `resume_path` 값은 `AR_full_droid_relative_steps100000_gpus128_bs128_per_device1_wrist_all`입니다. 파일 이름에 적힌 값이라 확인된 사실은 아니지만, 사전학습이 128 GPU, 전역 배치 128, 100K 스텝이었음을 시사합니다. 논문은 GPU 수를 밝히지 않았습니다.

## 4. 구현 가능성 판정 (이 맥)

**결론: 이 맥(Apple M4 Pro, 통합 메모리 약 24 GiB, MPS, CUDA 없음)에서 DreamZero 14B를 학습하거나 추론하는 것은 불가능합니다. 축소한 구조 재구현(작은 모델과 합성 데이터)은 조건부로 가능합니다.**

판정표:

| 작업 | 판정 | 근거 |
|---|---|---|
| 공식 14B 추론 (480P, 7 Hz) | **불가** | 메모리: 가중치 BF16 약 26.1 GiB > 24 GiB. int4 가중치 약 6.5 GiB에 KV 캐시 한 분기 약 9.5 GiB를 더하면 약 16 GiB, 두 분기면 약 25.5 GiB (`03` §4). 속도: 청크 하나에 수십 초에서 수 분 (가정 처리량 5–10 TF/s, 측정 아님). CUDA 전용 경로(flash-attn, cuDNN SDPA, torch.compile의 GPU 그래프, TRT, NVFP4)가 필요 |
| 공식 코드 실행 (DROID API 또는 로컬 서버) | **불가** | CUDA 12.9 이상, flash-attn 빌드, GB200 또는 H100 2장 필요 (README). 이 맥에서는 설치와 실행 모두 안 됨 |
| 공식 체크포인트 후학습 (LoRA, 5000 스텝) | **불가** | 14B 가중치 로드와 역전파 메모리 부족. CUDA 필요 |
| 사전학습 재현 (100K 스텝, 배치 128, 500시간) | **불가** | 데이터 없음 (AgiBot 공개 안 됨), 계산량 GPU 128장 규모 추정 |
| 행동 헤드 구조를 작은 DiT로 재구현 (영상 16×16, 2–4 M 파라미터, 합성 로봇 데이터) | **조건부 가능** | MPS 또는 CPU에서 학습 가능한 크기. 구현 요소: (1) 영상·행동 공동 흐름 정합 손실 (식 3), (2) 청크 단위 블록 마스크 (그림 14), (3) KV 캐시 추론과 실제 관측 주입, (4) Flash형 시점 샘플러 (D5), (5) DiT 캐시 마스크 (D3). 재현 대상은 설계 논리이며 논문 수치는 재현하지 않음 |
| DiT 캐시 규칙과 Flash 시점 샘플러를 토이로 검증 | **가능** (이미 수행) | `analysis/toy_dit_cache.py`, `analysis/toy_decoupled_noise.py` (`03` §5) |

**노력 추정 (축소 재구현).** 사람이 PyTorch로 짜는 기준으로 약 3–5일. 단위 테스트(마스크 모양, 흐름 정합 목표, KV 캐시 일치, 단계 수 계산)를 포함하고, 합성 데이터 생성과 학습 스크립트까지입니다. 14B 포팅은 추가로 GPU 환경이 필요하므로 이 맥에서는 범위 밖입니다.

**구현을 막는 것 가장 큰 세 가지.** (1) 추론 메모리와 속도 (14B), (2) 학습 데이터 비공개 (AgiBot), (3) 공개 기본 설정과 논문 설정의 차이 (D3, D5, D6, D8, D9, D11). 이 셋은 맥에서 해결되지 않습니다.
