# 03 수치 재계산과 일관성 점검

재계산 스크립트: `analysis/recompute.py` (표준 라이브러리만 사용, CPU 몇 초). 결과: `analysis/recompute_results.json`.
모델 학습·추론은 하지 않았습니다. 논문 Table 1·2의 보고 수치만 사용했습니다.

## 1. 성공률 재계산 (Table 2, n = 40)

| 과제 | Ours | 95% Wilson CI | DP | 95% Wilson CI | 차이 (pp) | Fisher 정확 검정 (양측) |
|---|---|---|---|---|---|---|
| Rotation | 37/40 = 92.5% | 80.1–97.4 | 22/40 = 55.0% | 39.8–69.3 | +37.5 | p = 2.4e-4 |
| Scooping | 34/40 = 85.0% | 70.9–92.9 | 22/40 = 55.0% | 39.8–69.3 | +30.0 | p = 6.6e-3 |
| Sweeping | 37/40 = 92.5% | 80.1–97.4 | 5/40 = 12.5% | 5.5–26.1 | +80.0 | p = 1.4e-13 |

해석:
- 세 과제 모두 두 방법의 차이가 통계적으로 뚜렷합니다. 다만 과제마다 시도 수가 40이라서 CI 폭이 넓습니다 (Rotation의 Ours 하한 80%).
- Scooping은 CI가 많이 겹칩니다 (Ours 하한 70.9%, DP 상한 69.3%). "크게 낫다"는 주장은 방향은 맞지만 차이의 크기는 ±15pp 안팎으로 불확실합니다.
- 각 과제는 같은 물체 집합 하나로 40회를 돌린 결과이므로, 물체 간 분산이나 시도 간 상관은 반영되지 않습니다. 이 CI는 시도를 독립으로 본 하한입니다.

## 2. Push-Shape (Table 2, n = 32)

- 보고된 값은 평균 mIoU(0.731 vs 0.550)와 평균 회전 오차(8.0° vs 48.2°)뿐입니다. 시도별 값이 없어서 CI와 검정을 계산할 수 없습니다.
- 본문은 "significantly higher mIoU"라고 쓰지만, 유의성 검정 결과는 없습니다. 이 문장은 근거가 부족합니다.

- Diffusion Policy 기준선의 인용 번호: Table 2는 Diffusion Policy를 [2]로 인용합니다 (Push-T 과제도 [2]). 논문 내 인용 일관성은 맞습니다.
- Figure 8 (데모 수 실험)은 그림으로만 있고 숫자가 본문에 없어서 재계산할 수 없습니다.

## 4. 실제 재현 없이 말할 수 있는 것

- 보고된 카운트가 맞다면 "Ours가 세 과제에서 DP보다 높다"는 결론은 Fisher 검정 기준으로 유의합니다.
- 하지만 40회 한 번의 실험, 물체 10–17개, 시도 간 상관을 무시한 CI이므로, 일반화 성능을 정량적으로 주장하기에는 표본이 작습니다.
- 이 점검은 보고 수치의 내부 일관성만 확인합니다. 실제 장비와 데이터로 재현했을 때 같은 숫자가 나오는지는 확인하지 않았습니다 (재현은 하지 않기로 함).
