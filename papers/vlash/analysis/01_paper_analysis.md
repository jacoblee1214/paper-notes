# 01. 논문 분석: VLASH (arXiv:2512.01031 v2)

*VLASH: Real-Time VLAs via Future-State-Aware Asynchronous Inference* (Jiaming Tang, Yufei Sun 외, Song Han; MIT, NVIDIA 외). 분석 대상은 **v2(2026-07-26)** 하나이고, v1(2025-11-30)과의 차이는 §6에 정리했습니다. v2는 IEEE 학회 양식(10쪽)이지만 arXiv comments, 프로젝트 페이지, 공식 목록 어디에도 학회 표기가 없습니다(`02` §5). 절·표 번호는 v2 기준이고, 로마자 절 번호(I–VI)와 부록(Appendix I–III)을 그대로 씁니다. 라벨 V1–V9는 `03`의 검사, D1–D14는 `04`의 코드 대조입니다.

## 1. 한 장 요약

| 항목 | 내용 |
|---|---|
| 문제 | 동기 추론은 추론 중에 로봇이 멈추고(stall) 반응이 늦다. 비동기 추론은 추론 중에도 이전 청크를 실행하지만, 예측 구간 [t, t+K)와 실제 실행 구간 [t+Δ, t+Δ+K)가 어긋난다(§III c, 그림 2). |
| 방법 | (1) 추론 시작 시점의 상태 대신 **실행 시작 시점의 상태** s_{t+Δ}를 입력한다. 이미 실행이 확정된 행동 a_{t:t+Δ-1}로 상태를 굴린다(델타 행동은 누적, 절대 행동은 마지막 행동)(§IV-A, 그림 3). (2) 파인튜닝에서 오프셋 δ ∈ {0..Δmax}를 뽑아 (o_t, s_{t+δ}) → a_{t+δ:t+δ+H-1}로 학습한다(§IV-B). (3) 한 관측에 모든 오프셋을 한 시퀀스로 묶고 블록 희소 어텐션으로 관측 토큰을 한 번만 인코딩한다(§IV-C, 그림 4). (4) 인접 행동 q개를 합쳐 더 빨리 움직인다(행동 양자화, §IV-D, 그림 5). |
| 주장 | 반응 지연 최대 11.8배 감소(표 II), 비동기 기준선 대비 정확도 우위(그림 6–8), 양자화로 1.5–2.0배 완료 속도, π0.5의 핑퐁 랠리와 두더지 잡기(표 III), 파인튜닝 스텝당 3.26배(표 IV). |
| 코드 | https://github.com/mit-han-lab/vlash (Apache-2.0, 별 525, 2026-04-22 최신). 논문의 LIBERO와 Kinetix 평가는 별도 가지(`sim/libero`, `sim/kinetix`)에 있고 main에는 π0/π0.5 학습·실로봇 추론만 있습니다(`04` §1). |

## 2. 방법 상세

**기호.** 정책 π_θ(A_t | o_t, s_t), 예측 지평 H(청크 길이), 실행 지평 K ≤ H, 지연 Δ(제어 스텝 단위)(§III a–c).

**미래 상태 인지(§IV-A).** 추론 시작 시 상태가 s_1이고 이전 청크의 남은 행동이 a_1, a_2이면 s_3 = s_1 + a_1 + a_2를 정책에 넣는다. 환경 관측 o_1은 그대로 쓰므로 **상태만 미래이고 영상은 과거**입니다. 저자들은 이를 "사람이 지연된 시각 입력에 내부 신체 상태를 더해 반응한다"는 비유로 설명합니다.

**오프셋 증강(§IV-B).** (i) 상태와 행동을 같이 δ만큼 민다. (ii) 관측 o_t는 고정한다. 같은 영상에 다른 정답 행동이 대응하므로 모델이 상태 입력을 쓰도록 강제된다는 논리입니다. 배포 시에는 "측정된 추론 지연 Δ보다 큰 최소 δ"를 고릅니다. v2는 "현재 VLA는 로봇 상태를 덜 쓴다"고 주장하지만, v1에 있던 근거(상태 없는 파인튜닝이 LIBERO에서 더 높음)는 v2 표 I에서 빠졌습니다(§6, `03` V7).

**공유 관측 학습(§IV-C).** π0.5는 두 영상과 언어가 약 600토큰, 상태와 행동 청크 하나가 약 50토큰이라서, N_δ = 5개 오프셋을 묶으면 650 → 850토큰(+31%)에 학습 궤적 수가 5배라고 합니다(850/650 = 1.308, `03` V5). 같은 유효 배치에서 효율이 오릅니다. 부록 III은 π0.5가 상태를 언어 프롬프트의 텍스트 토큰으로 받아서 상태 투영층을 더하는 것이 "선택 사항이지만 부드러움을 높인다"고 쓰는데, 공식 코드에서는 공유 관측 경로가 이 투영을 **요구**합니다(`04` D4).

**행동 양자화(§IV-D).** 델타 행동은 합산, 비정수 q는 선형 보간으로 재표본합니다. "task-dependent q"를 고릅니다.

## 4. 주장과 증거의 틈

1. **"지연이 있어도 동기 수준 정확도"(§V-A 2).** LIBERO의 지연은 실제 비동기 실행이 아니라 **영상을 지연 스텝만큼 과거 것으로 바꾸고 상태는 현재의 진짜 상태를 넣는** 시뮬레이션입니다(`04` D1, 공식 평가 스크립트 `sim/libero`). 롤아웃된 상태가 아니라 정답 상태이므로, 방법의 핵심인 "상태 굴림의 오차"가 이 실험에서는 시험되지 않습니다. 논문 본문은 이 설정을 설명하지 않습니다.
2. **실로봇 우위(§V-B 1).** 그림 7의 9개 설정 모두에서 VLASH가 Sync보다 높고(부호 검정 p = 0.004), 시도 단위 z 검정(군집 무시, 반보수)으로 대 Sync는 Stacking q = 1.5(z = 2.45)만 2를 넘고, 최대 경쟁 기준선 대비는 9개 모두 |z| ≤ 1.5입니다(`03` V6). 시도가 롤아웃 안에서 독립이 아니므로 실제 불확실성은 더 큽니다. 방향은 일관되지만 개별 설정은 입증되지 않았습니다.
3. **"성공률 = 성공 수 / 전체 시도 수".** 막대마다 분모가 22–56으로 다르고(`03` V6, `own_fig7_denominators.png`), 난이도가 이질적이면 이 지표는 시도당 평균 성공 확률보다 낮게 나오고 이항 에러바 구간이 95%에 못 미칩니다(토이 1, `03` §5).
4. **"1.5–2.0배 완료 속도"(초록, §V-B 1 b).** v2에는 완료 시간 측정이 없습니다. "q배 속도 향상이 정확도가 유지되면 성립한다"는 서술입니다. v1은 실측 완료 시간을 보고했고(2.03×) v2는 그 그림을 뺐습니다(§6).
5. **"11.8배 반응 지연 감소".** 식 D + 2L의 계산값이고 H100에서의 값입니다. RTX 5090은 9.5배, 동기 쪽을 K = 25 대신 짧게 잡으면 크게 줄어듭니다(`03` V3, `own_latency_k.png`).
6. **상태 굴림 = 마지막 행동(절대 행동).** 추종 지연이 큰 시스템에서는 마지막 명령이 실제 미래 상태와 크게 다릅니다(토이 2, `03` §6). 핑퐁처럼 빠른 동작에서 중요한 가정인데 논문은 추종 오차를 보고하지 않습니다.
7. **파인튜닝 3.26배.** 스텝당 시간비는 토큰 수비(10,400 / 3,200 = 3.25)와 같고, VLASH는 스텝당 고유 관측이 4배 적어서 같은 스텝 수에서 더 늦게 수렴합니다. 정확도 기준 시간비는 최대 2.2배(`03` V5).
8. **Kinetix.** 미래 상태를 시뮬레이터 롤아웃으로 얻으므로 알려진 동역학을 쓰는 오라클에 가깝습니다. 실로봇 경로(행동을 상태로 사용)와 다릅니다. 코드는 서브모듈(`Sakits/vlash-kinetix`)이라 받아 읽지 않았습니다(`04` D12).

## 5. 한계 (저자 서술과 우리가 본 것)

- 저자: GR00T N1.6은 q ≥ 1.5에서 성공률이 낮아 q = 1만 보고(그림 8 캡션). π0.5의 상태 투영층은 선택 사항이라고만 씀(부록 III).
- 우리: 시드 1개(공식 이슈 #22 답변, "single seed"), 신뢰구간 없음, 에피소드 수 미기재, Naive·RTC는 LIBERO에서 빠짐, SmolVLA 실로봇 없음, 평가 설정(Δmax, 오프셋 샘플링)이 표마다 다름(`04` D6–D8).
- 공식 이슈 #22는 표 I의 LIBERO-Spatial을 재현하려다 mujoco 3.6.0에서 지연 4가 74.8%, 3.3.7에서 86.2%로 크게 달라졌다고 보고했고, 저자는 MuJoCo 버전에 민감하다고 답했습니다(2026-04-08–10). 표 I의 지연 3–4 결과가 시뮬레이터 버전에 민감하다는 뜻입니다(`04` D9).
