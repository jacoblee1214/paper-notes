## 1. 한 문단 요약

확산 정책이 작업 공간(task space)에서 낸 출력(파지, 경유점, 궤적)은 데이터 분포에는 맞아도 특정 로봇에서는 도달 불가, 충돌, 추종 불가일 수 있습니다. 이 논문은 DDIM의 역방향 갱신에서 **확률적 섭동 σ_k ω를 최적화 변수 σ_k δ_k로 바꾸고**, δ_k의 크기를 규제하면서 실행 가능성 비용 J를 최소화하는 문제를 풀어, 확산 모델을 다시 학습하지 않고 제약을 부과합니다. 파지(손가락 5개 XHand, Franka와 Dynaarm 두 팔)와 이미지 조건 조작(서랍 열기, 집어서 놓기)에서 투영 안내와 기울기 안내보다 과제 성공률을 높였다고 보고합니다. 실로봇은 Franka와 XHand의 파지 일부만 정성 보고합니다.

## 2. 방법

### 2.1 핵심 아이디어: DDIM 갱신의 분해 (3절, 4.1절)

DDIM 역방향 갱신은 결정적 평균 μ_θ(x_k, k)와 섭동 σ_k ω로 나뉩니다 (식 2). 논문은 ω를 최적화 변수 δ_k로 바꿉니다 (식 3).

x_{k-1} = μ_θ(x_k, k) + σ_k δ_k

전체 문제는 식 (4)입니다.

- 목적: ½ Σ_{k=1..K} ‖δ_k‖² + Σ_{k=0..K} β_k J(x_k)
- 제약: 역방향 등식 x_{k-1} = μ_θ + σ_k δ_k, 종단 x_0 ∈ X_target = {J(x) ≤ ε_tol}, 시작 x_K ∈ X_init (기본은 R^d).
- 변수: x_K와 {δ_k}. 즉 **초기 잡음 자체도 최적화 변수**입니다.
- β_k는 "데이터 다양체에 가까운 단계에서만" 비용을 켜려고 키웁니다 (4.1절 끝).

부록 8.2는 이를 MAP으로 해석합니다. ½‖δ_k‖²는 δ_k ∼ N(0, I)의 음의 로그 밀도이고 β_k J는 볼츠만 유사 가능도입니다. 식 (20)은 식 (4)를 "x_K에 대한 사전항과 x_0의 우도항을 종단 제약으로 바꾼 것을 제외하고" 되찾습니다. 아래 `03` §5와 `04`는 이 두 가지 차이를 따집니다.

### 2.2 비용 J의 세 가지 구현 (4.2절)

| 이름 | 식 | 내용 |
|---|---|---|
| 도달 가능성 J_IK | 식 (5)–(6) | X_IK까지의 거리. 구현에서는 학습한 대리 신경망 Ĵ_IK (부록 8.5.0) |
| 충돌 J_coll | 식 (7), 부록 식 (39) | 서명 거리 함수(SDF) 기반 안전 여유 d_safe의 제곱 벌점. 부록은 제곱 없는 형태 max(0, s + d_safe)를 쓰고 d_safe = 5 cm |
| 제어기 수준 실행 가능성 J_dyn | 식 (8), 부록 식 (23)–(24) | 기준 궤적 x와 닫힌 고리 궤적 φ(x; q0; κ)의 차이. 제어기 오프셋 o를 최적화한 J*_dyn을 실제 신호로 씀 |

식 (7)(본문)은 max(0, d_safe − s(r_n))²이고 식 (39)(부록)는 max(0, s(x) + d_safe)입니다. 부호 규약과 제곱 여부가 서로 다릅니다. 본문은 s > 0이 자유 공간이라고 쓰므로 부록 식은 s + d_safe가 아니라 d_safe − s가 되어야 같은 뜻입니다. 식 (7)과 식 (39)가 같은 비용인지는 논문에서 확인되지 않습니다 (`04` C14).

### 2.3 해법 세 가지 (5절 도입, 부록 8.5.2)

| 변형 | 사용처 | 설정 |
|---|---|---|
| IPOPT (엄밀한 종단 제약) | 파지 | 최대 45회 반복, ε_IK = 0.01, −1 ≤ x_K ≤ 1, −1 ≤ δ_k ≤ 1, λ_δ = λ_IK = 1 (식 25–27) |
| Theseus 비선형 최소제곱 완화 | 파지 | Levenberg–Marquardt 15회. 가중치 10, 50, 1, 100, 1, 10, 10 (식 28–35). 종단·경로 힌지 허용오차 0.005 |
| L-BFGS 직접 슈팅 | 시각운동 | z = [x_T, 잡음 전부, o]를 한꺼번에 최적화. lr 0.1, 반복 ≤ 10, 클로저 호출 ≤ 5, 이력 10, strong-Wolfe, 바깥 단계 1회 |

IPOPT와 Theseus는 비용 항 J_IK를 모든 단계 k = 0..K에 둡니다 (식 27, 33). 본문 4.1절은 "β_k를 키워서 후반 단계에만" 비용을 켠다고 쓰지만, 부록 8.5.2는 "최적화 안내 방법(IPOPT, Theseus)은 상수 스케줄러를 쓴다"고 적습니다. 두 서술이 같은 설정인지는 논문만으로 알 수 없습니다.

### 2.4 대리 모델과 롤아웃 모델

- **도달 가능성 대리망 (부록 8.5.0, 알고리즘 1, 표 4):** 입력 [위치 3, 6D 회전 6]. 폭 256의 은닉 블록 둘, 머리 셋(관절 q̂, 도달성 Ĵ_IK ≥ 0 softplus, 자세 보정 Δp). 약 2.2×10⁵ 파라미터. 임베디먼트마다 기준 IK 해법으로 라벨을 붙인 목표 10⁵개(검증 2×10³개)로 학습합니다. 위치는 [−2, 2]³ m 상자에서 균일 추출합니다.
- **닫힌 고리 롤아웃 (부록 8.5.1):** 감쇠 최소제곱(DLS, λ = 0.05) 자코비안 갱신, 관절 속도·토크 한계에 의한 증분 상한, PD 지연 계수 α_eff, 관절 한계 클리핑. 중력 보상은 되먹임이 아니라 전방 토크로 가정합니다. J_dyn은 위치 오차와 세 키포인트(0.15 m)의 방향 오차를 시간 가중 c_t = t + 1로 합합니다 (식 23).
- **제어기 오프셋 (식 24):** J_dyn을 그대로 안내 신호로 쓰면 "빠른 동작을 줄이는 것"이 비용을 가장 쉽게 낮추는 길이 됩니다. 그래서 경계가 있는 전방 명령 오프셋 o ∈ B를 먼저 최적화하고 남는 추종 오차만 비용으로 씁니다.

### 3.5 실로봇: 8.7.1절

Franka + XHand로 기울기 안내와 IPOPT를 Floor, Walls, Clutter, Tunnels에서 비교하되 물체는 컵과 양념통 둘입니다. Floor는 방법·물체 쌍마다 파지 3개, 나머지는 5개를 생성하고 "하드웨어 파이프라인이 실행할 수 있는 후보"만 시행했습니다. 접근 동작은 cuRobo가 계획합니다. 성공 횟수나 표는 없고 그림 8과 보충 영상으로 정성 보고합니다(저자도 "초기 증거"로 해석).

## 4. 저자가 밝힌 한계 (6절)

1. 제약 NLP는 샘플당 시간이 길어 기울기 안내보다 느립니다. Theseus와 L-BFGS는 시간을 줄이지만 하드 제약을 소프트 벌점으로 바꿉니다.
2. 문제 (4)는 비볼록이라 전역 최적성이나 실행 가능성 보장이 없고 "조건이 나쁜 사례에서 가끔 수렴 실패"를 관찰했습니다.
3. 주 평가는 시뮬레이션이고 하드웨어는 예비 실험입니다.
4. J_dyn은 Cartesian 임피던스 제어기와 운동학 롤아웃을 가정합니다. MPC나 미분 가능 물리 시뮬레이터(Newton)는 향후 과제입니다.

## 5. 논문에 없는 값과 해석이 갈리는 곳 (공란 목록)

| 항목 | 상태 | 영향 |
|---|---|---|
| 확산 단계 수 K, 노이즈 스케줄(ᾱ_k), η | 본문과 부록에 없음 | σ_k는 식 (11)(η = 1)로 주어짐. ᾱ_0 = 1이면 σ_1 = 0 (`03` §5) |
| β_k의 구체 스케줄 (4.1절의 "키운다") 대 부록의 "상수 스케줄러" | 두 서술이 따로 있음 | 어느 쪽이 보고된 결과인지 불명 |
| X_init 상자 제약 −1 ≤ x_K ≤ 1 (식 25)과 기본 X_init = R^d (4.1절) | 정규화 공간이 불명 | N(0, I)에서 뽑은 x_K가 상자에 들어갈 확률 (`03` §5) |
| SR(1)의 단위 | 5.1절은 "(물체, 자세)별", 부록 8.6은 "파지별, 세 축 중 한 축 이상", 그림 6은 "자세별 SR(1)과 파지별 SR_all" | 표 1의 시행 수 n이 150인지 1200인지 (`03` §1) |
| 표 5의 시행 수 | 캡션은 "4 물체 × 파지 10개"(40) | 보고 값은 1/160 격자 (`03` §3) |
| 시각운동 "4회 실행"의 의미 | 시드인지, 환경 무작위화인지 불명. 같은 100 환경을 반복하는지 불명 | 표준편차의 해석 |
| L-BFGS 안내의 목적함수 | J*_dyn 외에 ‖δ‖² 규제를 넣었는지, 가중치는 얼마인지 없음 | 식 (4)의 "최소 섭동" 성격이 이 변형에 적용되는지 |
| 초기 추정값(IPOPT, L-BFGS) | 무작위 표본에서 시작하는지, δ = 0에서 시작하는지 없음 | 결과 다양성 |
| 하이퍼파라미터 선택 | 기울기 안내의 g, 스케줄은 "여러 개를 시험해 최고를 보고". 시험 수와 선택 기준(평가 집합 여부) 미기재 | 기준선 조정의 공정성 |
| 하드웨어 시행 수와 성공 수 | 없음 | 정량 비교 불가 |
