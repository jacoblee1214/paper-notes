- 16개 행의 평균 열을 네 스위트 평균으로 다시 계산했습니다(반올림 0.05 허용). **15개 행이 일치하고 EO1 하나만 어긋납니다.** EO1: (99.7 + 99.8 + 99.2 + 94.8)/4 = **98.375**인데 표는 98.2입니다(0.175 차이, 인용한 원 논문 값을 그대로 옮긴 것으로 보임).

### V5. 표 6 (LIBERO 5-shot, 단일 과제 스위트)

- 행 평균 검산에서 **불일치 두 곳**: (a) "Und+ViT 동결 / 사람 중심 사전학습" 행의 L-Object 이득이 +34.4로 적혀 있는데 84.2 − 50.0 = 34.2입니다(기준선이 49.8이면 맞음). ### V9. 시도 수 시나리오별 검정 (실로봇)

시도 수가 없으므로 "범주당 N회"로 가정하고 막대 라벨이 N회 중 성공 횟수라고 두었습니다(독립). 네 범주를 합산한 Fisher p:

| 범주당 N | 전문가 대 π0.5 | 범용 대 π0.5 | 범용 대 무사전학습 범용 | 전문가 대 범용 | 범용 대 (MPG+UAC 제거) |
|---|---|---|---|---|---|
| 20 (합 80) | 0.077 | 0.15 | 4.7×10⁻⁴ | 0.87 | 0.0043 |
| 40 (합 160) | 0.0089 | 0.032 | 4.1×10⁻⁷ | 0.73 | 3.2×10⁻⁵ |
| 80 (합 320) | 1.6×10⁻⁴ | 0.0018 | 4.4×10⁻¹³ | 0.56 | 2.5×10⁻⁹ |

- **사전학습 효과(범용 대 무사전학습 범용, 전문가 대 무사전학습 전문가)는 N = 20에서도 합산 p < 0.005로 확실합니다.** 격차가 15–35%p로 크기 때문입니다.
- **π0.5 대비 우위는 N = 20에서는 합산해도 유의하지 않고(전문가 p = 0.077, 범용 p = 0.15), N = 40 이상에서야 유의합니다.** 범주별 개별 검정은 N = 80에서도 대부분 p > 0.05입니다(예: 장기 전문가 대 π0.5 p = 0.081). 본문의 "significantly outperform π0.5"는 시도 수가 밝혀지지 않는 한 검증할 수 없고, 가장 작은 격자(N = 20)에서는 성립하지 않습니다.
- 전문가 대 범용 차이는 어느 N에서도 유의하지 않습니다(p ≥ 0.38). 범용이 전문가에 가깝다는 서술은 이 정도 검출력에서 "차이를 못 찾았다"입니다.
- N = 20에서 범주 하나의 검출 가능 최소 차이는 약 44%p, N = 80에서도 약 22%p입니다. 범주별 15%p 격차는 어느 시나리오에서도 개별로 확정되지 않습니다.
- 그림: `report/figures/own_real_power.png`.

### V10. "비영(non-zero) 제로샷 성공" (§7.1.2)

본문은 Adam-U에서 시연이 없는 과제-로봇 쌍에서 "비영 성공률"을 보였다고만 쓰고 수치가 없습니다. 참고로 진짜 성공률이 5%일 때 20회 중 1회 이상 성공이 관측될 확률은 64%, 10%면 88%입니다. 20회 중 1회 성공의 Wilson 95% 구간은 0.9–23.6%이고, 0회라도 상한은 13.9%입니다. 따라서 "비영"이라는 표현은 매우 낮은 성공률 아래서도 쉽게 나오며 성공 횟수와 시도 수 없이는 "과제 일관적 다단계 동작"의 정성 서술에 가깝습니다 (C5).

### V11. 표 2 자유도

G1+O6 26 = 2×7 + 2×6, FR3+Inspire 13 = 7 + 6, SO-101 6 = 5 + 그리퍼 1은 맞습니다. Adam-U 31 = 2×7 팔 + 머리 2 + 허리 3 + 2×6 손도 맞고 공식 문서의 슬롯(머리 2, 허리 3)과 일치합니다. D1의 14는 구성을 알 수 없습니다.

### V13. MPG 게이트 장난감 (CPU, 수 초, 식 14–15)

`recompute.py`의 V13 구간은 공식 코드의 SlicedWassersteinDistance와 같은 계산(배치와 토큰을 펴서 정렬)을 numpy로 쓴 것입니다(d = 1024, 토큰 80, M = 32 방향, 20 시드).

- **앵커 Z̄를 관측 길이로 방송하면 정렬이 의미가 없어집니다.** y쪽 투영값이 모두 같은 상수이므로 정렬해도 그대로이고, SWD는 각 토큰과 앵커의 **평균 제곱 유클리드 거리 ÷ 차원**과 같아집니다. 닫힌 식 1.0635 대 코드 방식 20시드 평균 1.0596(표준편차 0.020)로 일치합니다.
- LayerNorm 뒤 특징은 ‖h‖² = d이므로 D = 1 + c − 2ρ̄(c = ‖z‖²/d ∈ [0, 1], ρ̄ = 평균 코사인 정렬)이고 **0 ≤ D ≤ 4**입니다. 따라서 g = exp(−D/τ)는 τ = 1에서 [0.018, 1], τ = 2에서 [0.135, 1] 안에 있습니다.
- **특징의 크기를 0.1배, 10배로 바꿔도 D는 1.0625, 1.0635로 사실상 불변입니다.** LayerNorm이 크기를 지우므로, 조명이나 시점 변화가 특징 크기만 바꾸는 방향의 분포 이동은 게이트에 보이지 않습니다. 반응하는 것은 앵커와의 방향 정렬뿐입니다.
- 정렬 ρ = 0 → 0.8에서 g는 0.14 → 0.67(τ = 1) 또는 0.37 → 0.82(τ = 2)로 변합니다. 앵커가 16개 독립 토큰의 평균(c ≈ 0.06)이고 무관한 특징일 때 D ≈ 1.06, g ≈ 0.35(τ = 1), 0.59(τ = 2)입니다.
- 이것은 코드의 계산을 단순화된 가우시안 특징에 적용한 장난감이며, 실제 학습된 특징에서 g가 어떻게 분포하는지는 모릅니다. 논문에는 g의 분포나 분포 이동 아래의 g 값이 없으므로 "분포 밖에서 g가 작아진다"(§5.3.2)는 주장은 이 폴더에서 확인되지 않은 채 남습니다 (C11).
- 그림: `report/figures/own_mpg_gate.png`.
