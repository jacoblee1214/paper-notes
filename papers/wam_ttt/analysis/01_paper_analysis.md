## 1. 한 문장 요약

사전학습된 World-Action Model(LDA 백본)의 **비디오 전문가 블록에 TTT(고속 가중치) 잔차 가지를 붙이고**, 사람-로봇 쌍 데이터로 메타 학습(안쪽 SGD 한 단계 + 바깥쪽 역전파)한 뒤, 배포 시에는 **행동 라벨 없는 사람 영상 몇 개로 고속 가중치만 한 단계 갱신**해 로봇 행동을 사람 시연 쪽으로 이끈다는 논문입니다(초록, 그림 1·2, §3). 실로봇 세 기체, 아홉 과제에서 새 가정집(New) 평균 진행도가 LDA 32.5%에서 46.2%로, 사람 영상을 문맥으로 넣는 WAM-ICL은 7.1%라고 보고합니다(표 1).

## 2. 방법

### 2.1 구조 (§3.1, 식 1–2, 표 B.1)

- 백본은 LDA [23]입니다. Qwen3-VL-4B-Instruct VLM이 조건을 만들고, 16블록 MMDiT(은닉 1536, 헤드 32)에 비디오 전문가와 행동 전문가가 결합 어텐션으로 연결됩니다(표 B.1). LDA 공개 README는 비디오 쪽 토큰이 DINOv3-ViT-S 특징이고 픽셀이 아니라고 설명합니다(`02` §2).
- **TTT 잔차**(식 1): z^(ℓ+1) = ẑ^(ℓ+1) + ΔzTTT^(ℓ), 행동 스트림 x^(ℓ+1) = x̂^(ℓ+1)는 그대로. 즉 TTT 가지는 비디오 스트림에만 더해지고, 행동 전문가는 결합 어텐션을 통해 간접적으로 영향을 받습니다.
- **읽기**(식 2): ΔzTTT = θO f_W(θQ(z)). f_W는 작은 MLP(헤드 차원 d = 48, 은닉 폭 128, 표 B.1)이고 W는 고속 가중치입니다. 은닉 1536 / 헤드 32 = 48로 표 B.1의 d와 맞습니다.
- 본문에 **없는 것**: TTT 가지를 붙인 블록의 수와 위치, f_W의 활성화(SwiGLU인지 GELU인지), 헤드마다 따로인지 공유인지, 고속 가중치의 총 파라미터 수. 인용한 Spatial-TTT [52]의 층 구현은 per-token 학습률, 채널별 L2 정규화, 선택적 Muon을 쓰는데(공개 코드의 `ttt_operation.py`), WAM-TTT가 같은 방식인지는 본문에 없습니다.

### 2.2 사람-로봇 메타 학습 (§3.2, 식 3–6, 알고리즘 A.1)

1. **짝 데이터와 위상 정렬.** 같은 과제의 로봇 에피소드(길이 T_r)와 사람 에피소드(길이 T_h)를 로봇 시각 t마다 정규화 위상 ϕ = t/T_r로 맞추고 가장 가까운 사람 프레임을 고릅니다(선형 시간 정렬, 오프라인).
2. **KV 재구성 손실**(식 3): 사람 토큰에서 K_h = θK(h), V_h = θV(h)를 만들고 L_KVM = (1/(B L_h d)) ‖f_W(K_h) − V_h‖²를 층마다 계산합니다.
3. **안쪽 루프**(식 4–5): 사람 클립 u_h에서 L_adapt = L_vg^human + λ Σ_ℓ L_KVM^(ℓ)를 SGD로 N회 최소화합니다. **N = 1, η = 0.1, λ = 0.04**(표 B.1). 초기값은 학습되는 W_init입니다.
4. **바깥 루프**(식 6, v3): 갱신된 W_N을 로봇 질의 Q_r로 읽어 로봇 쪽 WAM 손실(비디오 확산 + 행동 확산)과 λΣL_KVM(W_N)을 최소화하고, **WAM 전체 파라미터, TTT 슬로우 투영 θ{K,V,Q,O}, W_init**을 함께 학습합니다. 안쪽 갱신을 통해 역전파합니다(2차 미분).
5. 규모: AdamW, LR 1e-4(DiT 행동 헤드)/1e-5(VLM 인터페이스), 100k 스텝, 전체 배치 128, 8×H800, DeepSpeed ZeRO-2(표 B.1). 짝 데이터는 로봇+사람 2,286 에피소드(Unitree G1 600, Galbot gripper 544, Galbot sharpa 1,142, 부록 B).

메타 학습에서 WAM 자체도 학습된다는 점이 중요합니다. "고정된 WAM"은 **배포 시점**에만 맞는 말이고, 메타 학습의 결과물은 LDA와 다른 가중치입니다(WAM-Cotrain과 같은 데이터를 쓰는 별개 모델).

### 2.3 시험 시 학습 (§3.3, 식 7–9)

- WAM, 슬로우 투영, W_init은 얼리고 **비디오 쪽 고속 가중치만** 갱신합니다. 입력은 대상 영역의 행동 없는 사람 영상 소수(B_h). 비디오 생성 모드로 L_TTT = mean_u [L_vg + λΣL_KVM]을 구하고 W_{i+1} = W_i − η∇L_TTT. **N = 1, η = 0.01**(표 B.1).
- 갱신된 W_N은 로봇 롤아웃 내내 고정이며, 행동은 p(a_{t:t+k} | o_t, g; W_N)에서 뽑습니다(식 9).
- **메타 학습의 η(0.1)와 시험 시 η(0.01)가 10배 다릅니다.** 본문은 "같은 목적 형태"와 "같은 단계 예산"을 강조하지만 학습률이 다르다는 점은 표 B.1에만 있습니다.

### 2.4 부록 A의 이론적 설명

- 선형 f_W(x) = Wx이면 식 3의 최소해는 W* = V_h^T K_h (K_h^T K_h)^{-1}(식 A.2), K^T K ≈ (L_h/d) I(등방)이면 W* ∝ Σ v_i k_i^T(헤비안, 식 A.3), 질의 읽기는 선형 어텐션 Σ (k_i^T q) v_i(식 A.4)입니다.
- 논문은 이 등식이 **선형 특수 경우에서만 정확히 성립**하고, 비선형 MLP는 "같은 훈련 목표를 따르지만 닫힌 해 분해는 학습된 어텐션 유사 읽기로 대체된다"고 적습니다. 이 분석의 토이(`03` §8)가 이 부분을 점검합니다.

## 4. 한계

**논문이 쓴 것** (§5): (1) 짝 데이터의 위상 분포가 어긋나면 안쪽 적응 신호가 나빠지고 손실이 이를 알리지 않습니다. (2) 적응은 고속 가중치 표현력과 메타 학습 때 고정된 슬로우 투영에 묶이고, 배포 과제가 메타 학습 짝 분포에서 멀수록 약해집니다. 경계는 실험으로 보지 않았습니다. (3) 입력은 일인칭 RGB뿐이며 손 포즈, 접촉, 3D 단서는 쓰지 않습니다.
