# 03. 재계산, 일관성 검사, 토이 검증

이 문서는 논문 표 값을 다시 계산하고, 표끼리와 본문 문장을 맞춰 보고, 변환 식을 수치로 확인합니다. 재현 실험(학습, 시뮬레이션 데이터 생성)은 하지 않았습니다.

- 재계산 스크립트: `analysis/recompute.py` → `analysis/recompute_results.json` (1초 미만)
- 토이 V1: `analysis/toy_transform_check.py` → `analysis/toy_transform_check_results.json` (1초 미만)
- 가정: 표의 "±"는 3개 시드의 표본 표준편차(n = 3)로 봅니다. 논문이 정의하지 않았습니다. 시뮬 성공률은 롤아웃 50회 평가입니다(부록 O). 체크포인트 수는 모릅니다.

## 0. 요약

- **실로봇 결과의 주요 차이는 통계적으로 확실합니다.** Stack BC-RNN 36%(18/50)와 확산 정책 76%(38/50)는 Fisher p = 1.1 × 10⁻⁴입니다. 다만 신뢰구간은 넓습니다(24–50%, 63–86%).
- **시뮬 보고값의 ±는 평가 한 번의 표본 잡음보다 작습니다.** 36개 셀 중 29개(81%)에서 보고된 SD가 롤아웃 50회의 이항 표준오차보다 작습니다. 체크포인트 최댓값을 보고한 것과 함께 생각해야 합니다.
- **"로봇 팔 간 비슷하다"는 주장은 부분만 맞습니다.** D0에서 범위(80–91%)는 맞지만 IIWA와 Panda의 차이(10.7 %p)는 p = 0.03입니다. D1 Square에서 IIWA는 Panda보다 25.3 %p 낮습니다(p = 0.0008).
- **표끼리 일치는 31개 검사 중 30개가 맞습니다.** 틀린 한 곳은 Mobile Kitchen의 저차원 원천 값(본문 2.7%, 표 Q.1 6.7%)입니다.
- **본문 6.3의 예시는 저차원 값을 이미지 값처럼 씁니다.** 과제 이름도 맞지 않습니다("Object Cleanup" ↔ 표의 "Mug Cleanup").
- **변환 식은 맞습니다.** 무작위 1000 사례에서 상대 자세 보존 오차는 2 × 10⁻¹⁵입니다. 곱하는 순서를 바꾸면 모든 사례에서 깨집니다(V1).
- **"18개 과제, 50K 이상"은 본문 표로 확인할 수 없습니다.** 표 P.1은 16개 과제, 36개 변형이고 1000개씩 36,000개입니다.

## 1. 재계산

### 1.1 실로봇 (본문 6.4, 부록 H)

마지막 체크포인트를 평가 50회 했으므로 체크포인트 선택 편향은 없습니다.

| 항목 | 값 | Wilson 95% | 비고 |
|---|---|---|---|
| Stack DGR | 200/243 = 82.3% | 77.0–86.6 | 본문 82.3% 일치 |
| Coffee DGR | 100/192 = 52.1% | 45.0–59.0 | 본문 52.1% 일치 |
| Stack BC-RNN | 18/50 = 36% | 24.1–49.9 | 본문 36% |
| Stack 확산 정책 | 38/50 = 76% | 62.6–85.7 | 부록 H, 76% |
| Stack 원천 10개 | 0/50 | 0.0–7.1 | 본문 0% |
| Coffee 정책 | 7/50 = 14% | 7.0–26.2 | 본문 14% |
| Coffee 삽입 | 10/50 = 20% | 11.2–33.0 | 본문 "삽입 20%" |
| Coffee 파지 | 30/50 = 60% | 46.2–72.4 | 본문 "파지 60%" |

- BC-RNN 대 확산 정책(Stack): Fisher 양측 p = 1.1 × 10⁻⁴ (18/50 대 38/50).
- BC-RNN 대 원천(Stack): p = 1.2 × 10⁻⁶ (18/50 대 0/50). Coffee 정책 대 원천: p = 0.012 (7/50 대 0/50).
- 확산 정책과 BC-RNN의 차이를 80% 검정력으로 보려면 팔당 약 23회면 충분합니다. 50회는 큰 차이에 충분하지만, 본문 Coffee나 Stack 원천과의 작은 차이는 확인하기 어렵습니다.
- **결론:** 실로봇에서 "생성 데이터는 원천보다 낫다"는 결론은 확실합니다. 정책 간 세부 차이(예: 확산 정책 대 BC-RNN의 크기)는 평가 한 번의 신뢰구간 안에서 해석해야 합니다.
- 이 분석은 본문 값의 재계산일 뿐입니다. 실로봇 실험 자체는 재현하지 않았습니다.

### 1.2 시뮬레이션 평균과 ±

- 보고된 SD의 중앙값은 2.5 %p입니다. 롤아웃 50회로 평가 한 번을 했을 때 이항 표준오차의 중앙값은 5.8 %p입니다(성공률 평균별로 계산, `recompute_results.json`의 `binomial_vs_reported_sd`).
- 36개 셀 중 29개(81%)에서 보고된 SD가 평가 한 번의 표준오차보다 작습니다. 세 시드의 평균은 평가 잡음이 줄어든 값이어야 하므로, 보고된 SD가 평가 잡음을 다 담지 못한다는 뜻입니다.
- 이 불일치는 두 가지로 설명할 수 있습니다. (a) 최대 체크포인트를 고르면 각 시드 값이 위로 치우치고, 그 변동이 SD를 작게 만듭니다. (b) "±"가 시드 간 최댓값의 SD라서 롤아웃 잡음을 담지 않습니다. 논문에서 어느 쪽인지 알 수 없습니다.
- **판정:** 시뮬 표의 평균 차이 대부분(예: 원천 대 D0)은 이 문제와 상관없이 큽니다. 하지만 10 %p 안팎의 차이(로봇 팔, 조작자, 원천 선택)는 체크포인트 선택과 ± 정의에 따라 바뀔 수 있습니다.
- 가정(±는 SD, n = 3)에 따른 주요 Welch 검정 결과는 아래와 같습니다. 차이가 크면 가정이 틀려도 결론이 같습니다.
  - Square D0 원천 대 D0: 11.3 대 90.7, p = 1.3 × 10⁻⁵.
  - Threading D0 원천 대 D0: 19.3 대 98.0, p = 7.0 × 10⁻⁵.

### 1.3 로봇 팔 전이 (표 F.2, 이미지 기반)

Panda와 각 로봇의 Welch 검정(n = 3 가정). 차이는 Panda에서 뺀 값입니다.

| 셀 | Sawyer | IIWA | UR5e |
|---|---|---|---|
| Square D0 | +4.7, p = 0.03 | +10.7, p = 0.03 | +6.0, p = 0.02 |
| Square D1 | +12.6, p = 0.008 | +25.3, p = 0.0008 | +17.3, p = 0.006 |
| Threading D0 | +9.3, p = 0.16 | +4.0, p = 0.16 | +6.7, p = 0.007 |
| Threading D1 | +10.0, p = 0.025 | +11.4, p = 0.022 | 0.0 |

- 본문은 "Square D0 80–91%, Threading D0 89–98%"라고 씁니다. 범위는 맞습니다(표 F.2 확인).
- 그러나 "remarkably similar"는 과장입니다. 여러 셀에서 Panda와의 차이가 p < 0.05이고, 특히 Square D1에서 IIWA는 25 %p 낮습니다. 본문과 부록 F는 이 D1 차이를 설명하지 않습니다.
- 데이터 생성률도 팔마다 큽니다. Square D0은 37.7%(IIWA)에서 73.7%(Panda)입니다. 표 F.1로 확인했습니다.

### 1.4 절제와 잡음 (표 N.1, N.2)

- 잡음 제거(σ = 0): Square D0 SR 72.0 대 90.7, 차이 18.7 %p, p = 0.003. Threading D0 저차원은 69.3 대 97.3, 차이 28.0 %p, p < 10⁻⁵. 본문 "최대 30%(저차원), 40%(이미지)"는 관측 최댓값 28.0과 38.7에 해당합니다.
- 잡음 제거의 DGR 증가: Threading D0 51.0 → 84.5 (+33.5 %p). 본문 "33%"와 일치합니다.
- 재생 + 잡음(원천 10개를 같은 잡음으로 재생): Square D0 SR 42.0 대 MimicGen 90.7 (p < 10⁻⁵), Threading D0 74.0 대 98.0 (p = 0.002). 원천을 새 장면에 옮기는 효과가 재생만으로는 나오지 않는다는 주장을 뒷받침합니다.
- 최근접 이웃 선택 제거(표 N.2): Square D0 DGR 73.7 → 36.7. 저차원 SR은 98.0 대 94.7, 차이 3.3 %p, p = 0.14. 생성률은 크게 떨어지고 정책 성능 차이는 작다는 본문 주장과 맞습니다.

### 1.5 더 다양한 원천 데모 (표 S.1)

- Square: 원천 D2의 저차원 SR은 D0 80.7 → 84.7(D1), 58.7 → 60.7(D2)로 차이가 작습니다(p = 0.17, D1 기준).
- **Three Piece Assembly:** 원천 D2에서 D0 저차원 SR은 74.7 → 62.0입니다. 차이 12.7 %p, p = 0.03입니다. 본문 "정책 성공률은 비슷하다"는 이 셀에서 과장입니다.

### 1.6 객체 전이 (표 G.1)

- O1(한 머그)은 D0 대비 90.7 대 80.0(+10.7 %p, p = 0.049). O2(12개 머그)는 75.3 대 80.0(−4.7 %p, p = 0.32).
- O2가 D0보다 낮은 것은 본문과 맞습니다. 다만 "머그 12개로 일반화"라는 주장은 평균 차이가 작다는 근거로 씁니다.

### 1.7 조작자와 원천 품질 (표 I.1, I.2)

- 표 I.1 조작자 A 대 B(이미지): 최대 편차 17.4 %p(Stack Three D1, 86.7 대 69.3). 저차원 최대 9.3 %p. 본문 "0–17%"와 맞습니다.
- 표 I.2 Square 최선/보통/최악(이미지 D1): 73.3, 64.0, 59.3. 최선 대 최악은 14.0 %p, p = 0.006입니다. 본문 "매우 비슷하다"는 이 셀에서 과장입니다. 최선 대 보통은 p = 0.14입니다.

## 3. 토이 V1: 변환 식 확인

`analysis/toy_transform_check.py`는 무작위 SE(3) 자세 1000개 사례에서 다음을 확인합니다.

- 식 C'_t = O'_0 (O_0)⁻¹ C_t(부록 M)이 객체 좌표계 상대 자세를 보존합니다. 최대 오차 1.7 × 10⁻¹⁵.
- 공식 코드 `transform_source_data_segment_using_object_pose`의 두 단계 계산(`pose_in_A_to_pose_in_B`를 두 번)은 논문 식과 같습니다. 최대 차이 3.3 × 10⁻¹⁶. 이 검사는 저장소 함수를 실행하지 않고, 함수의 연산을 읽고 옮겨 쓴 것입니다.
- 음성 대조: 곱하는 순서를 바꾸면(O⁻¹ O' C) 1000 사례 모두 오차가 10⁻⁶을 넘습니다(중앙값 1.6).

**판정:** 변환 식과 구현의 연산 순서는 맞습니다. 이 토이는 이 식이 옳다는 것만 확인합니다. 데이터 품질, 보간 충돌, 성공 판정은 확인하지 않았습니다.
