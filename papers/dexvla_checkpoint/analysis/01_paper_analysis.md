## 1. 문제 설정

VLA(π0.5 등)는 두 손가락 그리퍼 데이터로 사전학습되어 있어 16자유도 LEAP 손 같은 다지 손에 옮기려면 미세조정이 필요합니다. 그런데 다지 손의 원격조작 데이터는 비싸서 시연이 몇 개뿐입니다(§1, [6, 12, 30]).

기존 연구는 미세조정 방법(어떤 파라미터를 얼리는지, LoRA를 쓰는지)을 SFT 롤아웃 성공률이 가장 높은 체크포인트로 평가했습니다(§1, §2, [10, 17, 18]). 저자들은 이 평가가 잘못됐다고 봅니다. SFT 뒤에 **잠재 잡음 조종(DSRL)**을 붙이면, SFT 체크포인트는 초기값일 뿐이고 중요한 것은 얼린 모델의 잡음 공간에 성공 영역이 있는지라는 입장입니다(§1).

## 2. 방법

**π0.5 구조 (§3.1, 부록 A).** PaliGemma 백본(SigLIP 시각 인코더, 멀티모달 프로젝터, Gemma LM)과 흐름 정합(flow matching) 액션 전문가로 이루어집니다. 액션 청크는 H = 32, 액션 차원은 32(짧으면 0 패딩)입니다. 새 구현체의 상태는 LM을 거치고, 액션은 전문가의 선형 투영을 거칩니다.

**다섯 가지 SFT 레시피 (§3.2, 표 1).** 두 축, 즉 어떤 파라미터를 학습하는지(H1: LM, H2: 시각 인코더)와 전체 학습 대 LoRA(H3, H4)를 조합합니다.

| 레시피 | 학습 파라미터 (전체 3.24B 대비) | 학습률 |
|---|---|---|
| EXPERT-ONLY | 전문가 어텐션·MLP·adaRMS, 시간 MLP, 액션 투영: 430M (13.3%) | 2.5e-5 |
| FROZEN-LM | EXPERT-ONLY + SigLIP + 멀티모달 프로젝터: 845M (26.1%) | 2.5e-5 |
| FULL-FT | 전부: 3.24B (100%) | 2.5e-5 |
| LORA | LM·전문가에 r=32 LoRA, SigLIP·프로젝터·액션 투영 전체: 468M (14.4%) | 2.5e-4 (LoRA), 2.5e-5 (전체) |
| LORA-LM | FROZEN-LM에서 LM에만 r=32 LoRA: 887M (27.4%) | 2.5e-4 (LoRA), 2.5e-5 (전체) |

**DSRL (§3.3, 부록 C, 표 4).** 대형 청크 변형을 씁니다. 행위자(actor)는 32차원 벡터 w ∈ [−1, 1]^32 하나를 출력하고 H = 32 위치에 반복해 A0로 씁니다. 동결된 π0.5가 청크를 디코딩하고, 첫 16개 액션을 실행합니다. SAC 학습, 실행당 500k 환경 스텝 예산, 3개 RL 시드입니다. 이 설정은 모든 레시피·체크포인트·과제에서 같습니다.

**체크포인트 선택 (§3.3).** 레시피마다 과제별로 체크포인트 4개를 골라 SFT 시점의 성공률과 DSRL 후 성공률을 같이 기록합니다. Screw는 2k/4k/8k/16k, Coffee는 4k/8k/14k/18k 스텝입니다.

**평가 (§3.3, 부록 D).** 과제마다 물체 위치 하나를 바꿉니다. DSRL은 학습 placement 2개에서 학습하고, 추가 placement 2개는 학습 범위 밖입니다. 사전 RL 성공률은 i.i.d. 잡음과 반복 잡음 두 가지로 측정하며, 반복 잡음을 "기본" 값으로 씁니다(DSRL이 보는 공간과 맞기 때문).

## 4. 결과

**표 5 (원문 p.11)의 핵심:**

- EXPERT-ONLY는 학습 배치에서 DSRL 후 두 과제 모두 95–100%입니다. 추가 배치(Screw 2k~16k: 98, 73, 88, 45 / Coffee: 94, 87, 83, 90)에서도 평균이 가장 높습니다.
- SCREW LIGHTBULB 8k: EXPERT-ONLY 학습 100%, 추가 88%. 다른 레시피는 학습 0–33%, 추가 0%입니다.
- LoRA 18k는 Coffee 반복 잡음 사전 RL 성공률 76%로 전체 최고지만, DSRL 후 학습 55%, 추가 7%입니다.
- SFT 체크포인트 선택에 관한 주장은 §4 "SFT-time success is a poor predictor" 문단에 있습니다. 상관 계산은 `03_analysis.md` §4에 있습니다.

**그림 (원문 Fig. 1–5):** Fig. 1은 과제 설정, Fig. 2는 체크포인트별 사전·사후 성공률, Fig. 3은 DSRL 학습 곡선, Fig. 4는 두 잡음 분포의 SFT 시점 성공률, Fig. 5는 Screw 2k 체크포인트가 손바닥으로 밸브를 돌리는 장면입니다. Fig. 5는 "시뮬 악용"의 질적 증거입니다.

## 5. 한계 (논문 §5 및 본 검토)

논문이 밝힌 한계:
1. 레시피당 SFT 1회 (부록 B). RL 시드 3개는 변동을 보여 주지만 SFT 변동은 보여 주지 않습니다.
2. 시뮬레이션만 있습니다. Screw 2k 체크포인트는 시뮬 성공 조건을 악용합니다(Fig. 5).
3. SFT 성공률이 조종 결과를 예측하지 않습니다. 오프라인 지표가 다음 단계로 제시됩니다.

본 검토에서 보인 것:
- 두 과제, 과제당 물체 위치 하나, 시뮬 전용이라 일반화 범위가 좁습니다.
- 과제 두 개에서 레시피 간 차이를 보려면 시드를 여러 번 돌려야 하는데 그렇게 하지 않았습니다.
- 레시피 간 비교에 검정이 없습니다. 사전·사후 차이를 p값으로 보고한 곳은 없습니다.
- 고려하지 않은 교란: EXPERT-ONLY와 FROZEN-LM의 차이는 시각 인코더 학습 하나뿐이지만, LoRA 계열은 학습률이 10배 다릅니다(표 1, 부록 B). "LoRA가 덜 조종 가능하다"는 결론에는 학습률 차이가 섞여 있을 수 있습니다.

## 7. 핵심 주장 요약

1. SFT 성공률과 DSRL 후 성공률은 과제에 따라 상관이 다릅니다 (Coffee는 음, Screw 반복 잡음은 양).
2. VLM을 얼리고 액션 전문가만 학습하면 조종 가능성이 가장 높습니다.
3. LoRA는 조종 가능성이 가장 낮습니다(추가 평가 기준).
4. 권고: VLM 동결, 전문가 완전 학습, SFT 롤아웃 성공률로 체크포인트를 고르지 않음.
