# 03. 수치 재계산과 일관성 검사: TacBridge (arXiv:2611.20939)

원자료(샘플별 점수, 시드별 결과)는 공개되지 않았습니다. 그래서 이 문서는 **논문에 적힌 평균과 표본 수로 계산할 수 있는 것**만 다룹니다. 계산은 `analysis/recompute.py`로 하며 결과는 `analysis/recompute_results.json`에 있습니다 (표준 라이브러리만 사용, 수 초).

재현 실험은 하지 않았습니다. 학습과 실행이 필요한 검증은 이 문서의 범위 밖으로 두었습니다.

## 2. 표 II: 번역과 재구성

- **재구성 대비 차이 (본문 확인):** 동일 센서 PSNR 33.38 − 30.69 = **2.69 dB**, cPSNR 28.98 − 26.46 = **2.52 dB** (AnyTouch 대비). 본문 2.69와 2.52 일치.
- **교차 센서 차이 (본문 확인):** PSNR 33.23 − 30.52 = **2.71 dB**, cPSNR 28.83 − 26.30 = **2.53 dB**, ∆cPSNR 11.93 − 10.30 = **1.63 dB**, rFID-r 63.5 → 58.3. 본문과 일치.
- **동일 센서와 교차 센서 격차:** PSNR 33.38 − 33.23 = 0.15, cPSNR 28.98 − 28.83 = 0.15. 본문 "0.15 dB"와 일치.
- **rFID-r:** 동일 센서 65.8 → 60.1 (AnyTouch 대비), 교차 센서 63.5 → 58.3. 본문과 일치.

**표본 단위 문제:** 15,552쌍은 216개 접촉을 9개 센서 외형으로 렌더링한 뒤 만든 **순서쌍** 수입니다. 9 × 8 = 72 순서쌍이 접촉 하나마다 생기므로 216 × 72 = 15,552로 맞습니다. 그러므로 **독립 단위는 접촉 216개**이고, 쌍 15,552개를 독립 표본으로 세면 검정력이 과대평가됩니다. 접촉 단위 분산은 논문에 없어 p값은 계산하지 못했습니다.

**시드 문제:** Table II에 시드 수나 표준편차가 없습니다. 즉 학습 무작위성에 따른 차이를 알 수 없습니다. 2.5 dB 격차는 시드 간 흔들림보다 클 가능성이 높지만, 증명할 자료가 없습니다.

## 3. 표 III: 직물 분류와 OOD 검정력

### 3.1 표본 구조 검산

- 직물 50개 × 접촉 325 = 16,250장 (본문 일치).
- ID 분할: 224 학습 + 101 시험 = 325 (본문 일치).
- OOD 분할: 45 학습 직물 + 5 시험 직물 = 50 (본문 일치).

### 3.2 OOD 격차의 검정력 (핵심)

속성 정확도는 **직물 단위로 묶여 있습니다.** 같은 직물의 325장은 모두 같은 24개 속성 벡터를 가집니다 (§IV-D). 그러니 장 수(1,625장)가 아니라 **시험 직물 수 5**가 독립 단위입니다.

격차 2.8 pp (73.0 − 70.2)를 쌍체 t 검정 근사로 보면 (자유도 4, t = 2.776):

| 직물 간 표준편차 s (pp) | 95% 반폭 (pp) = 2.776 × s / √5 | 격차 2.8이 p < 0.05가 되는 s의 상한 |
|---|---|---|
| 1.0 | 1.24 | |
| 2.0 | 2.48 | |
| 4.0 | 4.97 | |
| 6.0 | 7.45 | |

- **p < 0.05가 되려면 직물 간 쌍체 차이의 표준편차가 약 2.3 pp 이하여야 합니다.** 직물 분류 정확도가 직물마다 몇 pp씩 흔들린다고 가정하면, 2.8 pp 격차는 유의하지 않습니다.
- 이 계산은 **추정**입니다. 직물별 점수 분산이 필요하지만 논문에 없습니다. 어떤 값을 쓰든 "5개 직물로는 2–3 pp 격차를 구별하기 어렵다"는 결론은 같습니다.
- **ID 분할의 1.0 pp 격차:** 시험 직물 수를 50으로 가정해 (직물 수는 논문에 명시되지 않음) 계산하면 p < 0.05에 필요한 s 상한은 약 3.5 pp입니다. 가정이 맞더라도 격차가 작아 방향만 말할 수 있습니다.

### 3.3 어텐티브 풀링

본문은 "어텐티브 풀링이 74.2%와 99.0%로 더 좋다"고 씁니다. 두 헤드를 같은 시험 직물에서 비교한 것이므로 선택 편향이 있습니다. 하이퍼파라미터는 "held-out training fabrics"로 골랐다고 적혀 있어 시험 직물을 쓰지 않았다는 것은 맞습니다 (§IV-D).

## 5. 해석

1. **Table II의 격차는 크지만 시드와 접촉 단위 분산이 없어 검정할 수 없습니다.** 가장 강한 결과이지만 가장 근거가 얕게 보고되어 있습니다.
2. **Table I의 "9/11"은 셈 방식에 따라 달라집니다.** 패널 B 4개는 이긴 폭이 커서 나머지 7개 중 5개만 이긴 것을 가리는 효과가 있습니다. 승리 수를 세는 대신 다중 비교 없이 개별 열의 차이를 보는 편이 낫습니다. 이 표는 시드와 샘플 수가 없어 그 보정도 할 수 없습니다.
3. **Table III의 "실로봇 일반화" 주장은 5 직물 기준으로는 약합니다.** 본문 "the gains on unseen fabrics demonstrate that the learned representation generalises" (§IV-D)는 과장입니다. 방향은 맞지만 구별 가능한 증거는 아닙니다.

## 6. 검사하지 않은 것

- 원자료가 없어 Table I의 TAG, Cloth, Sparsh 지표의 신뢰구간은 만들 수 없습니다.
- 기준선 재학습은 하지 않았습니다. 논문에 설정이 없고 학습은 이 맥에서 하지 않기로 했습니다.
- 번역 품질의 인간 평가는 논문에 없어 판단하지 않았습니다.
