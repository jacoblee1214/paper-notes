# 01. 논문 분석: DINO-WM

*DINO-WM: World Models on Pre-trained Visual Features enable Zero-shot Planning* (Gaoyue Zhou, Hengkai Pan, Yann LeCun, Lerrel Pinto; NYU Courant, Meta-FAIR). arXiv:2411.04983. 분석 대상은 **arXiv v2 (2025-02-01)**이며, 학회 게재본은 **ICML 2025 포스터**(PMLR v267)입니다. 원문은 `paper/paper.pdf`(21쪽, `pdftotext` 결과 `paper/paper.txt`, 비정렬 추출 `paper/plain.txt`)입니다.

## 0. 버전과 차이

| 항목 | v1 (2024-11-07) | v2 (2025-02-01, 분석 기준) |
|---|---|---|
| 환경 수 | "five control environments" (PointMaze, PushT, Wall, Rope, Granular) | "six" (Maze, Wall, **Reach**, PushT, Rope, Granular). Maze는 v1의 PointMaze 이름 변경 |
| Table 1 PushT, DreamerV3 SR | **0.04** | **0.30** (값 변경, 설명 없음) |
| Table 1 Reach | 없음 | IRIS 0.18, DreamerV3 0.64, TD-MPC2 0.00, Ours 0.92 (추가) |
| Table 4 | LPIPS와 SSIM 함께 | LPIPS만 본문, SSIM은 부록 A.7로 이동 |
| 초록 주장 | 같은 방향 (LPIPS 56%, 과제 45%) | 같은 두 수치를 유지. 정의는 적지 않음 |
| 본문 표 참조 | "Table 3" | 일반화 절에서 "From Table 5"로 적힘 (표 번호 오류, K3) |

- v2의 핵심 변화는 **환경 확장과 PushT DreamerV3 값의 변경**입니다. PushT에서 DreamerV3 SR이 0.04에서 0.30으로 올랐는데 설명이 없습니다. 이 값 하나 때문에 PushT에서 Ours와 DreamerV3의 차이가 v1의 0.86(0.90 − 0.04)에서 v2의 0.60(0.90 − 0.30)으로 줄었습니다. Ours의 값(0.90)은 두 버전이 같습니다.
- 두 버전 모두 시드 반복과 오차 막대가 없습니다(§3 참조).
- ICML 2025 게재본의 세부(부록 번호, 표 번호)는 이 분석에서 대조하지 않았습니다. 분석 기준은 arXiv v2 PDF입니다.

## 1. 문제 설정과 주장

- **문제:** 시각 기반 로봇 제어에서 세계 모델(world model)을 **오프라인 궤적**으로 학습하고, **테스트 시점에 행동을 최적화**해 **작업에 무관하게(task-agnostic)** 목표 관측에 도달하게 한다(§1, §3).
- **주장 셋:** (1) 오프라인 궤적으로 학습 가능, (2) 테스트 시 행동 최적화 지원, (3) 작업 무관 추론. 보상, 전문가 시연, 역모델 없이 6개 환경에서 제로샷 계획이 된다고 주장합니다(초록).
- **핵심 아이디어:** 픽셀을 재구성하지 않고, 동결된 **DINOv2 패치 특징**(`dinov2_vits14`)의 시간 예측을 학습합니다. 계획은 목표 이미지의 패치 특징과 예측 특징의 MSE를 최소화하는 행동열 탐색입니다(§3.2, 식 4).
- **두 가지 주장의 강도:** 초록의 "outperforming prior state-of-the-art" 주장은 Table 1과 Table 3에서 대부분 지지됩니다(§03 참조). "zero-shot"과 "task-agnostic"은 같은 환경 안에서 목표 이미지만 바꾸는 설정이라서, 보상이나 작업 종류가 바뀌는 경우의 일반성은 보이지 않습니다.

## 2. 방법 (§3, 부록 A.5, A.9)

| 구성 요소 | 내용 | 근거 |
|---|---|---|
| 관측 모델 `enc` | DINOv2 (`dinov2_vits14`, 패치 토큰 384차원). **동결** | §3.1.1, 부록 A.9 |
| 전이 모델 `p_θ` | 인과 마스크가 있는 ViT, 토큰화 층 제거 (디코더 전용 트랜스포머). 프레임 단위 인과 | §3.1.2 |
| 행동 인코더 | MLP로 행동을 저차원으로 올려 모든 패치 토큰에 이어 붙임 (행동 임베딩 차원 10) | §3.1.2, 표 12 |
| 고유감각 | 있을 때만 관측 잠재에 이어 붙임 | §3.1.2 |
| 디코더 `q_θ` | 전치 합성곱, 픽셀 재구성 MSE. **전이 모델과 독립 학습** (손실 전달 없음) | §3.1.3, 식 2, 부록 A.4.3 |
| 전이 학습 | 교사 강요, 길이 H+1 조각, 잠재 MSE 손실 | §3.1, 식 1 |
| 계획 목적 | 마지막 예측 잠재와 목표 잠재의 MSE (식 4) | §3.2, 부록 A.5.1 |
| 계획 알고리즘 | MPC + CEM (기본), 경사하강(GD)은 비교 대상 | 부록 A.5 |

- **ViT 규모:** 깊이 6, 헤드 16, MLP 2048, 약 19M 파라미터 (부록 A.9). 이 수치는 저장소 설정만으로는 확인되지 않습니다(`04` D11).
- **학습 설정 (표 12):** AdamW, 디코더 lr 3e-4, 전이 lr 5e-5 (본문 표 기준), 행동 인코더 lr 5e-4, 100 에폭, 배치 32, 이미지 224. 같은 설정을 모든 환경에 씁니다.
- **환경별 데이터 (표 11, 발췌):** PointMaze 2,000궤적, Reacher 3,000, PushT 18,500, PushObj 20,000, Wall 1,920, WallRandom 10,240, Rope 1,000, Granular 1,000. 데이터는 무작위 행동으로 만든 궤적입니다(부록 A.1).

## 3. 실험과 결과 (§4, 부록)

### 3.1 설정
- **평가:** 목표는 무작위 샘플 상태입니다. Maze, Reach, PushT, Wall은 시작과 목표 50쌍으로 성공률(SR), Rope와 Granular는 10개 인스턴스로 Chamfer 거리(CD)를 씁니다(§4.3).
- **기준선:** IRIS (토큰 세계 모델), DreamerV3 (잠재 세계 모델 + 행위자-비평가), TD-MPC2 (보상 신호 사용), AVDC (확산 영상 생성, 부록 A.6). 기준선은 **보상이나 작업 정보 없이** 같은 오프라인 데이터로 학습했다고 적혀 있습니다(§4.2).
- **인코더 비교 (§4.4):** R3M, ImageNet ResNet-18, DINO CLS(전역 토큰).

### 3.2 주요 수치 (보고값 그대로, 재계산은 `03`)

**표 1 (계획 성능, v2).** SR은 n=50, CD는 n=10.

| 방법 | Maze SR | Wall SR | Reach SR | PushT SR | Rope CD↓ | Granular CD↓ |
|---|---|---|---|---|---|---|
| IRIS | 0.74 | 0.04 | 0.18 | 0.32 | 1.11 | 0.37 |
| DreamerV3 | 1.00 | 1.00 | 0.64 | 0.30 | 2.49 | 1.05 |
| TD-MPC2 | 0.00 | 0.00 | 0.00 | 0.00 | 2.52 | 1.21 |
| **Ours** | **0.98** | **0.96** | **0.92** | **0.90** | **0.41** | **0.26** |

- 쉬운 환경(Maze, Wall)에서는 DreamerV3와 같은 수준이고, 조작 환경에서 차이가 큽니다. 논문도 이 점을 씁니다(§4.3).

**표 2 (인코더 비교).** Ours는 DINO 패치. 값은 SR(Maze, Wall, Reach, PushT)과 CD(Rope, Granular)입니다.
- R3M: 0.94, 0.34, 0.40, 0.42 / CD 1.13, 0.95
- ResNet: 0.98, 0.12, 0.06, 0.20 / CD 1.08, 0.90
- DINO CLS: 0.96, 0.58, 0.60, 0.44 / CD 0.84, 0.79
- **DINO Patch (Ours): 0.98, 0.96, 0.92, 0.90 / CD 0.41, 0.26**
- 논문은 "패치 기반 표현이 공간 정보를 보존한다"고 해석합니다(§4.4). Wall, Reach, PushT에서 CLS 대비 차이가 크고 Maze에서는 차이가 없습니다.

**표 3 (분포 밖 구성).** 훈련과 다른 벽 위치(WallRandom), 4개 물체 모양만 학습한 PushObj, 입자 수가 다른 GranularRandom.
- WallRandom SR: IRIS 0.06, DreamerV3 0.76, R3M 0.40, ResNet 0.40, DINO CLS 0.64, **Ours 0.82**
- PushObj SR: IRIS 0.14, DreamerV3 0.18, R3M 0.16, ResNet 0.14, DINO CLS 0.18, **Ours 0.34**
- GranularRandom CD: IRIS 0.86, DreamerV3 1.53, R3M 1.12, ResNet 0.98, DINO CLS 1.36, **Ours 0.63**
- 논문은 WallRandom에서 "significantly better"라고 씁니다(§4.5). 그러나 DreamerV3 대비 차이는 p ≈ 0.6으로 통계적으로 구분되지 않습니다(`03` §2).

**표 4 (예측 품질, LPIPS, 낮을수록 좋음).** 값 순서: R3M, ResNet, DINO CLS, AVDC, Ours.
- PushT: 0.045, 0.063, 0.039, 0.046, **0.007**
- Wall: 0.008, 0.002, 0.004, 0.030, **0.0016**
- Rope: 0.023, 0.025, 0.029, 0.060, **0.009**
- Granular: 0.080, 0.080, 0.086, 0.106, **0.035**
- 초록의 "LPIPS 56%"는 Granular에서 최선 기준선(0.080)보다 56% 낮다는 뜻으로 맞습니다.

**표 5 (데이터 크기, PushT).** 궤적 200, 1000, 5000, 10000, 18500개에서 SR은 0.08, 0.48, 0.72, 0.88, 0.92. SSIM과 LPIPS도 같은 방향으로 좋아집니다. 논문은 "scaling laws"라고 부르지만 데이터 크기 축 하나의 5점 관찰입니다.

**표 6 (인과 마스크 절제, PushT).** 텍스트에 따라 h=1에서 두 설정이 같아야 합니다. 본문 추출상 배치는 w/o mask: 0.76, 0.36, 0.08 / with mask: 0.76, 0.88, 0.92로 읽힙니다(열 h=1, 2, 3 추정, 원문 그림으로 재확인 필요). 인과 마스크가 긴 이력에서 미래 누수를 막는다는 해석과 맞습니다.

**표 7 (디코더 손실 절제, PushT).** 디코더 손실을 전이에 전달하지 않은 경우 0.92, 전달한 경우 0.80입니다. 본문 표 1의 PushT(0.90)와 값이 다릅니다(`03` K4).

**표 10 (추론 시간, A6000 GPU).** 배치 32 추론 0.014 s, 시뮬레이션 한 단계 3.0 s, CEM 계획(100 샘플 × 10 반복) 53 s. 논문은 "deformable 환경에서 빠르다"고 씁니다. 시뮬레이션과 비교한 계획 시간은 명시되지만 Mac 기준 시간은 없습니다.

### 3.3 한계 (§5, 저자 서술)
1. 충분한 상태-행동 범위를 가진 오프라인 데이터가 필요합니다. 복잡한 환경에서는 얻기 어렵습니다.
2. 행동 라벨이 필요합니다. 인터넷 영상처럼 행동 없는 데이터에는 적용하지 않습니다.
3. 계획은 행동 공간에서 합니다. 계층적 제어와의 결합은 향후 과제입니다.

## 4. 분석자의 관찰 (주장과 근거의 간격)

- **시드와 분산:** 본문과 부록 어디에도 시드 반복, 표준편차, 신뢰 구간이 없습니다. SR은 시도 50회로 계산했을 뿐이고, CD는 10개 인스턴스 평균만 있습니다. 학습 실행을 여러 번 했는지 알 수 없습니다.
- **"45% 평균 개선"의 정의가 없습니다.** Rope와 Granular CD 감소율의 평균은 46.4%로 가깝지만, 같은 계산이라고 확정할 근거가 없습니다(`03` §3).
- **기준선 조정:** IRIS, DreamerV3, TD-MPC2는 같은 데이터로 학습했지만 하이퍼파라미터 조정 범위는 적혀 있지 않습니다. 이 점은 기준선 공정성 판단을 제한합니다.
- **AVDC 비교 (§4.6):** 확산 기반 AVDC와 비교한 정성 결과가 중심이고, 정량 비교(부록 A.6)는 행동 조건 변형에 한정됩니다.
- **환경 이름과 설정:** Table 11의 H와 frameskip 값은 저장소 설정 파일만으로 대응을 확인하지 못했습니다(`04` D8).
