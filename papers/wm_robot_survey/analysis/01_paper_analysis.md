## 1. 한 문단 요약

서베이는 로봇 학습에서 세계 모델(world model)이 정책, 시뮬레이터, 평가, 데이터 생성에 어떻게 쓰이는지를 정리합니다. 중심 질문은 "예측 모델이 실제 로봇 행동 성능을 올리는가"입니다. 논문은 세계 모델을 "행동에 조건부인 상태 전이 모델"로 정의하고, 영상 생성 모델을 주로 다룹니다(§2.1). 분류는 두 축입니다. 첫째는 정책과 세계 모델의 결합 방식(§3: IDM형, 단일 백본, MoE/MoT, 통합 VLA, 잠재 공간)이고, 둘째는 시뮬레이터로서의 역할(§4: 강화학습, 평가)입니다. 로봇 영상 생성(§5), 내비게이션과 자율주행(§6), 벤치마크·데이터셋·결과 표(§7), 열린 과제(§8)가 이어집니다.

## 3. 주장과 근거

1. **주장:** 세계 모델은 정책의 보조 예측기에서 학습 루프의 핵심 부품으로 바뀌고 있습니다(§1, Figure 2). **근거:** 연도별 계보 도식과 인용 목록입니다. 도식은 "추세"이지 정량 근거가 아닙니다. 논문도 "dominant directions, not strictly sequential"이라고 적습니다.
2. **주장:** 고성능은 여러 결합 방식에서 나오므로 사실적 영상 생성은 필수가 아닙니다(§7.3). **근거:** 표 5·6의 방법 여럿. 다만 벤치마크와 실행 조건이 서로 달라서(논문도 "less suitable for strict ranking"이라고 인정) 이 결론은 약합니다.
3. **주장:** LIBERO에서 Goal과 Long 과제가 Spatial과 Object보다 어렵습니다(§7.3). **근거:** 표 5. 재계산으로 확인했습니다(03 §3). 평균 Long − Spatial은 −3.93 %p이고 15행 중 13행에서 하락합니다.
4. **주장:** 세계 모델은 실제 로봇 행동을 측정 가능하게 개선합니다(§7.3 첫 문장). **근거:** 표의 방법들 대부분의 자기 보고 수치입니다. 독립 재현은 없습니다.
5. **주장:** 정책 성능의 상관, 평가 지표의 통일이 부족합니다(§7.3, §8.6). **근거:** 문헌 관찰입니다. 이 주장은 검증 대상으로 적절하고 논문도 과제로 인정합니다.

## 4. 강점

- 분류가 명확합니다. Table 1은 "미래 생성 방식(추론 시점)", "백본(VGM 또는 UMM 또는 MLLM)", "결합 방식"의 세 열로 방법을 나눕니다. 같은 열 기준으로 비교할 수 있어서 쓸모가 있습니다.
- 표 5·6은 방법별 값을 정리했고, 빈 칸을 "–"로 명시했습니다. 재계산이 가능한 형태입니다.
- 열린 과제 목록(§8)이 구체적입니다.

## 5. 약점

- 정량 근거가 표 5·6에 몰려 있습니다. 나머지 본문은 대부분 정성적입니다.
- 표 5·6의 값은 각 원논문에서 가져온 자기 보고 수치입니다. 시행 횟수, 시드, 평가 설정을 통일하지 않았습니다.
- 분류 경계에 일관성 문제가 있습니다(03 §4). Motus와 LingBot-VA는 표마다 다른 칸에 있습니다.
- 인용 이름 오류가 하나 확인되었습니다. Table 1의 GE-Act 저자가 Bharadhwaj로 적혀 있지만, 본문에서는 Liao로 적혀 있습니다(03 §4). WorldVLA의 참고문헌 항목은 없고 RynnVLA-002 항목으로 대체되어 있습니다.
- 빠진 계보가 있습니다. GR00T 계열(NVIDIA), DreamerV3·PlaNet 계열의 잠재 동역학, Diffusion Forcing과 Self-Forcing 같은 자기회귀 영상 생성이 참고문헌에 없습니다(03 §2).

## 6. 세계 모델 개념 정의에 대한 메모

§2.1의 정의는 "행동에 조건부인 예측"입니다. 식 (1)에서 행동은 저수준 명령 a와 고수준 언어·목표 l을 함께 포함합니다. 이 정의에 따르면 단순한 생성 영상은 세계 모델이 아닙니다. 그러나 논문은 그 뒤 대부분의 예시에서 영상 생성 모델을 세계 모델로 취급합니다(§2.1.2). 정의와 적용 사이에 간극이 있습니다. 이 간극은 서베이 전체의 분류 기준이 흔들리는 원인입니다.
