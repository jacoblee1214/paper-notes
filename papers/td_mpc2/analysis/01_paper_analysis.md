## 1. 한 문단 요약

TD-MPC2는 TD-MPC의 잠재 공간 계획 방식을 유지하면서, 디코더 없이 **보상, 가치, 정책 사전 분포**만으로 학습하는 암묵적 세계 모델을 씁니다. 학습 안정성은 SimNorm(잠재 상태를 여러 단순형으로 softmax 정규화), 로그 변환 공간의 이산 회귀(two-hot 교차 엔트로피), Q 함수 앙상블과 드롭아웃, LayerNorm과 Mish로 확보합니다. 하이퍼파라미터는 과제와 무관하게 하나로 고정합니다(표 8). 104개 연속 제어 과제(DMControl 39, Meta-World 50, ManiSkill2 5, MyoSuite 10)에서 SAC, DreamerV3, TD-MPC를 이기고, 같은 설정으로 1M–317M 파라미터의 다과제 세계 모델을 80과제(545M 전이)에 학습해 점수가 모델 크기에 따라 오릅니다(그림 7, 표 1). 여기에 소량 미세조정(20k 단계)에서 처음부터 학습보다 약 2배의 점수를 보고합니다(그림 8).

## 2. 문제 설정과 방법

### 2.1 문제 설정 (§2, 식 1)

무한 지평 MDP (S, A, T, R, γ)를 가정합니다. 세계 모델로 행동 열을 H 단계 굴려 보고, 그 뒤의 가치를 Q로 잇는 MPC 목표(식 1)를 씁니다. 저자는 식 1의 해가 "지역 최적"이라고 적고, 이를 학습된 terminal value로 H 밖의 반환을 더해 고칩니다(식 6).

### 2.2 구성 요소 (§3.1, 식 2)

다섯 모듈이 모두 MLP입니다. 인코더 h(s, e), 잠재 동역학 d(z, a, e), 보상 R(z, a, e), terminal value Q(z, a, e), 정책 사전 분포 p(z, e). e는 과제 임베딩입니다.

- 디코더가 없습니다. 관측을 재구성하지 않고, 잠재 예측 \(\|z_t - \mathrm{sg}(h(s'_t))\|\)(joint-embedding), 보상, TD 목표로만 학습합니다(식 3).
- 보상과 가치는 log 변환 공간(symlog)에서 101개 bin의 soft two-hot 교차 엔트로피로 회귀합니다. 과제마다 보상 크기가 달라도 손실 크기가 같아지게 하려는 설계입니다(§3.1, 부록 A).
- 목표 Q̄는 Q의 EMA이고, TD 목표는 무작위로 고른 두 Q̄의 최솟값입니다(§3.1). Q는 5개이고 드롭아웃 1%를 첫 선형층 뒤에 둡니다(부록 A, 표 8).

### 2.3 정책 사전 분포 (§3.1, 식 4)

정책 p는 최대 엔트로피 목표(식 4)로 학습합니다. 그래디언트는 p에만 흐릅니다. Q 값 크기가 과제마다 달라서 Q를 이동 통계(5%, 95% 백분위 차이)로 나눕니다. 그래서 αQ의 α는 고정 1이고, 엔트로피 계수 β = 1e-4가 됩니다(부록 H, 표 8). 논문 본문은 "α를 이동 통계로 조정한다"고 쓰는데, 구현은 Q를 이동 통계로 나누는 방식이고 두 설명은 같은 목표입니다(`04` §2에서 확인).

### 2.4 SimNorm (§3.1, 식 5, 부록 H)

잠재 상태 z를 V차원 그룹 L개로 나누고 각 그룹에 softmax를 씁니다. 부록 H는 V = 8이고 온도 τ = 1이라고 씁니다. 저자는 이것이 희소성을 주면서 제약을 강하게 걸지 않는다고 설명하고, 학습 안정성에 "essential"이라고 씁니다. 제거 실험은 그림 9에 있습니다.

### 2.5 계획 (§3.2, 식 6)

MPPI를 쓰는 샘플 기반 최적화입니다. 샘플 512개, 반복 6회(행동 차원 20 이상이면 +2), 엘리트 64개, 정책 사전 샘플 24개, 호라이즌 3, 온도 0.5, 표준편차 범위 [0.05, 2]가 표 8에 있습니다. 운동량은 쓰지 않습니다(부록 A). 논문은 실행하는 첫 행동을 N(µ*_t, σ*_t)에서 샘플링한다고 씁니다. 구현 대조는 `04` D4입니다.

### 2.6 다과제 학습 (§3.3, 부록 H, 표 9)

- **과제 임베딩:** 학습 가능한 96차원 임베딩을 다섯 구성 요소 모두에 줍니다. 노름은 1 이하로 제한합니다(§3.3).
- **관측과 행동 공간이 다른 과제:** 입출력을 최댓값 차원으로 0 패딩하고, 계획과 정책의 무효 행동 차원을 마스킹합니다(§3.3).
- **모델 크기:** 표 9의 다섯 구성(1M, 5M, 19M, 48M, 317M)은 인코더 차원, MLP 차원, 잠재 차원, 인코더 층 수, Q 개수만 바꿉니다. 나머지 설정은 그대로입니다.
- **데이터:** 240개 단일 과제 에이전트의 재생 버퍼에서 모은 545M 전이 (80과제). 30과제 부분집합은 345M 전이입니다(§4.1).
- **할인율과 시드 단계 (부록 H, 식 7–8):** γ = clip(1 − 5/T, [0.95, 0.995]), 시드 단계 S = max(5T, 1000). T는 행동 반복 뒤의 에피소드 길이입니다. DMControl(T = 500)은 γ = 0.99입니다.

## 3. 실험 결과

### 3.1 단일 과제 온라인 RL (§4.1, 그림 4, 부록 D)

- 기준선: SAC(모델 없음), DreamerV3(S 크기, 약 20M, UTD 512), TD-MPC(1M, 과제별 하이퍼파라미터). TD-MPC2는 과제 공통 하이퍼파라미터, UTD 1, 배치 256, 5M 파라미터입니다(§4, 부록 H).
- 결과: 4개 도메인 모두에서 TD-MPC2가 앞섭니다. MyoSuite는 TD-MPC2를 이전에 돌리지 않았는데 이번에 처음 보고합니다(§4.1).
- 불안정성: TD-MPC는 일부 과제에서 기울기가 폭발해 발산합니다. 그림 12는 Walker Stand와 Walker Walk를, 그림 21은 기울기 노름을 보여 줍니다. DreamerV3는 Dog 과제에서 수치 불안정이 있다고 씁니다(§4.1).
- 통계: 그림 4는 "3 seeds, mean and 95% CI"라고만 씁니다. 구간 계산 방법은 없습니다. 공개된 학습 곡선 파일로 다시 계산한 결과는 `03` §1–§2입니다.

### 3.2 고차원 과제 (§4.1, 그림 5, 6)

- Humanoid와 Dog: 그림 5 설명은 Humanoid A = 21이고 표 2는 24입니다(`03` K3). Dog는 A = 38입니다. SAC와 DreamerV3는 Dog에서 수치 불안정, Humanoid에서 데이터 효율이 떨어진다고 씁니다. TD-MPC2는 14M 단계까지 돌렸습니다(표 2 설명).
- 물체 조작 (ManiSkill2, 그림 6): Pick YCB(74개 물체)는 TD-MPC2만 높은 성공률을 보입니다. 어려운 과제에서 차이가 가장 크다고 씁니다.

### 3.3 다과제 확장 (§4.1, 그림 7, 표 1, 부록 K, 그림 22)

- 모델 1M, 5M, 19M, 48M, 317M을 80과제(MW 50 + DMC 30)에서 학습했습니다. 배치는 1024로 늘렸고 나머지는 그대로입니다.
- 정규화 점수는 DMControl의 반환(0–1000을 0–100)과 Meta-World 성공률의 평균이라고 정의합니다. 여러 도메인을 어떻게 묶는지는 명시하지 않습니다.
- 표 1 값(80과제): 1M 16.0, 5M 49.5, 19M 57.1, 48M 68.0, 317M 70.6. GPU일은 3.7, 4.2, 5.3, 12, 33(RTX 3090)입니다.
- 저자는 점수가 "log 파라미터에 선형으로 늘어나 보인다"고 쓰면서 scaling law는 세우지 않습니다. 317M은 "아직 포화되지 않았다"고 씁니다. 이 두 주장은 `03` §2에서 다시 봅니다.
- 과제 임베딩의 t-SNE(그림 7 오른쪽)에서는 같은 몸체·물체를 쓰는 과제가 가깝습니다. 저자는 이것이 목표(걷기, 달리기)보다 동역학을 따른다고 해석합니다.

### 3.4 미세조정 (§4.1, 그림 8, 부록 E, 표 7)

19M 모델을 70과제에 학습하고, 새 과제 10개(각 도메인 5개)에 온라인으로 20k 단계 미세조정했습니다. 점수 47.0 대 처음부터 24.0입니다(그림 8). 저자는 "2배"라고 씁니다. 새 과제의 임베딩은 의미상 가까운 원본 과제의 것으로 초기화합니다(표 7). 다른 초기화는 시험하지 않았습니다.

### 3.5 절제 (§4.1, 그림 9, 부록 F, G)

- 세 어려운 과제(Dog Run, Humanoid Walk, Pick YCB)와 19M 80과제에서 정책 구조, 정규화(없음, SimNorm, LN+SimNorm), 회귀 방식(연속 대 이산), Q 개수(2, 5, 10)를 바꿉니다.
- 본문은 "모든 설계 선택이 기여한다"고 씁니다. 막대 값은 그림에서만 읽을 수 있고 표로 주지 않습니다.
- 부록 F의 과제 임베딩 정규화 제거: 19M 80과제에서 54.2 대 46.6(그림 18).

### 3.6 시각 입력 (§4.1, 그림 10, 부록 H)

인코더만 4층 합성곱으로 바꾸고(64×64, random shift), 10개 DMControl 과제에서 DrQ-v2와 DreamerV3와 비슷하다고 씁니다. 기준선 학습 곡선은 논문에 있지만, 공개 저장소에는 TD-MPC2의 시각 결과 12과제만 있습니다(`03` §4).

### 3.7 테스트 시 정규화 (부록 J, 표 10)

계획의 목표에 Q 앙상블의 "평균 × 표준편차"에 비례하는 패널티를 더합니다(식 9–12). 계수 c는 과제에 무관하게 하나로 둡니다. 19M 80과제 점수: 정규화 없음 56.54, c = 0.001 58.14, c = 0.01 62.01, c = 0.1 44.13. 저자는 본 실험에 쓰지 않았다고 명시합니다. 시드 수와 구간은 없습니다.

### 3.8 이산 행동 공간 (부록 I)

실험 없이 한계로만 씁니다. 계획기가 MPC라서 이산 행동에는 MCTS 같은 계획기가 필요하다고 논의합니다.

## 6. 재현 대상으로 본 논문의 쟁점

1. **정책 사전 분포와 계획의 분담.** 계획만으로 충분한지, 정책 사전 분포가 얼마나 기여하는지는 그림 9에서 묶여 있습니다. 샘플 24개의 사전 분포 궤적과 512개의 MPPI 샘플 중 무엇이 성능을 만드는지는 분리되지 않았습니다.
2. **다과제 점수의 해석.** 80과제 점수는 DMControl 반환과 성공률을 섞습니다. 과제별 실패가 평균에 묻히기 쉽습니다.
3. **재현 비용.** 표 1의 GPU일은 317M 모델 한 번의 학습입니다. 이 맥에서는 다과제 학습을 할 수 없습니다(`04` §4).
