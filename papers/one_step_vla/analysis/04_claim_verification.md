## 4. 구현 가능성 판정

**판정: 구현할 수 있습니다 (수학과 평가 프로토콜), 재현은 이 맥에서 불가합니다.**

| 항목 | 이 맥 (Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음) | 판정 |
|---|---|---|
| 표 재계산, 검정 재구현 | 완료 (`table_check.py`) | 가능 |
| 정확한 속도장 토이 (1차원, 두 모드) | 완료 (`toy_one_step_gmm.py`, 약 1분) | 가능 |
| 다차원, 여러 모드 토이 (numpy) | 가능, 수 분 | 가능 |
| 소형 흐름 정책 (torch, MPS) 학습과 1-step 대 10-step 비교 | MPS에서 가능 규모(수백만 파라미터). torch 설치 승인 필요 | 조건부 |
| 체크포인트 추론 지연 (1 스텝 대 10 스텝) | A100 측정과 조건이 다름. 체크포인트 다운로드 필요(승인 필요) | 조건부 |
| LIBERO 시뮬레이터 평가 (SmolVLA, FLOWER 등) | 시뮬레이터와 CUDA 학습 환경 필요 | 불가 |
| 실로봇 재현 | Franka와 실험실 필요 | 불가 |
| 공식 코드 | 공개되지 않은 것으로 판단 | 해당 없음 |

**구현 노력 (추정).** 한 스텝 짝 평가 파이프라인(모델 로드, 같은 시드로 두 스텝 설정 실행, 불일치쌍 기록)은 PyTorch로 300–500줄, 3–5일입니다. 실제 VLA에 적용하려면 GPU 1장 이상이 필요하고, 중형 VLA 한 개의 LIBERO 평가에는 수 시간에서 하루가 걸릴 것으로 보입니다(추정, 검증 안 됨).

**권장.** 이 저장소에서는 (1) 표 재계산과 토이 확장, (2) 짝 평가 로그 설계(D7 참고)까지 CPU로 진행합니다. 체크포인트 평가는 GPU 자원이 생기면 별도 단계로 진행합니다.
