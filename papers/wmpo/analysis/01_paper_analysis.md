## 1. 한 문단 요약

VLA 정책을 **픽셀 공간의 행동 조건부 비디오 세계모델** 안에서 GRPO로 강화학습하는 방법입니다. 세계모델은 OXE로 사전학습한 뒤, 정책 자신이 수집한 실제 궤적(P = 128 또는 1280)으로 **정책 행동 정렬**(policy behavior alignment)을 합니다. 궤적은 클립 단위 자기회귀 생성으로 끝까지 만들고, VideoMAE 기반의 이진 보상 모델이 성공 여부를 판정합니다. 기저 정책은 OpenVLA-OFT를 전문가 시연 300개(시뮬)나 200개(실세계)로 미세조정한 것입니다. 저자들은 MimicGen 시뮬 4개 과제 평균에서 GRPO와 DPO를 이기고(P = 1280에서 57.6 대 37.1 / 42.4), 과제 변형 세 종류에서 일반화를 보였으며, 실세계 1개 과제에서 base 53%, DPO 60%, WMPO 70%를 보고합니다.

## 2. 방법 (§3, 식 1–5, Algorithm 1)

- **문제 설정 (§3.1).** 상태는 이미지 시퀀스와 언어 지시, 행동은 길이 K = 8의 행동 청크(7자유도, 각 자유도를 256 구간으로 이산화). 보상은 궤적 단위 이진값 R_ψ(τ) ∈ {0, 1}. 목적은 식 (1) max E[R_ψ(τ)].
- **세계모델 (§3.2, 식 2).** 조건 프레임 c = 4개와 행동 청크로 다음 K = 8 프레임을 생성합니다. 기반은 OpenSora의 video diffusion이고, 3D VAE를 SDXL의 2D VAE로 바꿉니다. 이 선택의 근거는 "시간 왜곡 방지"입니다. 두 가지 장치가 더 있습니다.
  - **노이즈 프레임 조건화:** 학습 시 조건 프레임에 확산 노이즈 50/1000을 넣습니다 (본문 §3.2).
  - **프레임 단위 행동 제어:** AdaLN을 프레임마다 적용해 행동 신호와 timestep을 주입합니다. 각 행동 a_i에서 MLP가 γ, β, α 세 계수를 만듭니다 (본문 §3.2 업데이트 식).
- **정책 행동 정렬 (§3.2).** OXE에서 사전학습한 뒤, 정책이 낸 실제 궤적으로 미세조정합니다. 이유는 OXE가 성공 궤적 위주라 실패 분포가 빈약하다는 점입니다. 이 단계가 WMPO의 핵심 주장 중 하나입니다 (§1 서론의 첫 번째 혁신).
- **보상 모델 (§3.3).** VideoMAE 인코더와 선형 헤드. 길이 L = 8 클립에 BCE 손실을 씁니다. 양성은 성공 궤적의 마지막 클립, 음성은 성공 궤적의 중간 클립과 실패 궤적의 임의 클립입니다. 추론은 stride s 슬라이딩 윈도우로 클립 확률을 얻고, 어느 클립이든 임계값 τ_thr을 넘으면 성공으로 봅니다. τ_thr은 "검증 실험으로 선택"한다고만 적혀 있고 값과 절차는 없습니다.
- **온폴리시 GRPO (§3.4, 식 3–5, Algorithm 1).** 실제 환경에서 뽑은 초기 프레임 I_0:c마다 G = 8개의 상상 궤적을 현재 정책으로 생성합니다. 보상 모델로 점수를 매기고, 그룹 안이 전부 성공이거나 전부 실패이면 버리는 **동적 샘플링**(DAPO 식)을 씁니다. KL 항은 없앱니다(참조 모델 불필요). 식 (4)는 클리핑 비율 ε_low = 0.2, ε_high = 0.28, 식 (5)는 궤적 단위 정규화 advantage입니다.

**구현 세부 (부록 A, B, 표 3–4).** 기저 SFT는 H100 8장, 세계모델 사전학습은 12M 스텝, 미세조정은 3M 스텝, 정책 최적화와 세계모델 학습은 H100 32장입니다. GRPO 하이퍼파라미터는 표 4: 학습률 5e-6, 배치 64, 그룹 G = 8, 미니배치 128, ε_low = 0.20, ε_high = 0.28, 온도 1.6. 부록 B는 GRPO 기준선이 배치 8과 64 중 **성능이 더 좋은 쪽을 골라 보고**한다고 씁니다.

## 5. 주장과 근거의 간격 (요약)

- **표 1의 우위**는 숫자로 확인됩니다. 평균 차이와 산술은 맞습니다. 그러나 **비교 조건이 같지 않습니다.** 기준선 GRPO는 실제 환경에서만 학습하고, WMPO는 실제 궤적을 세계모델 학습에만 쓰고 정책 최적화는 상상 궤적으로 합니다. 세계모델 쪽 계산 비용과 상상 궤적 수는 보고되지 않았습니다. 세부는 `03` §1, §5, `04` D6.
- **"온폴리시가 오프폴리시보다 낫다"**는 GRPO 대 DPO 비교로 뒷받침되지만, DPO는 세 가지 점에서 다른 조건입니다 (정적 데이터, 쌍 구성, 배치 설정). 설계 교란이 큽니다 (`03` C5).
- **보상 모델의 F1 > 0.95**는 숫자 한 개뿐이고 검증 데이터와 임계값 선택이 빠져 있습니다. 공식 코드는 과제마다 다른 임계값(0.62–0.96)을 씁니다 (`04` D1, D2). 이 주장은 확인하지 못했습니다.
- **자가 교정과 빠른 궤적**은 정성 그림과 길이 비율로만 뒷받침됩니다. 반복 횟수, 통계, 실패 분류는 없습니다 (`03` C6).
- **"처음으로 세계모델의 실현 가능성을 확인했다"**(§2 World Models)는 본문이 [32] World4RL을 같은 절에서 인용하면서 쓴 표현입니다. 범위를 좁혀야 맞는 주장입니다 (`03` C7).
- **실세계 우위**는 시행 30회입니다. 70% 대 60% (p = 0.59), 70% 대 53% (p = 0.29)로 유의하지 않습니다 (`03` §3).
