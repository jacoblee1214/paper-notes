## 0. 한 줄 요약

생성 모델(플로우 매칭)의 출발점을 가우시안 잡음 대신 로봇의 최근 상태 이력으로 바꾸면, 전달 비용과 직진성이 좋아지고 추론 단계 수(NFE)를 10으로 줄여도 Robomimic 성공률이 CFM과 비슷하다는 주장입니다. 다만 이 논문이 보인 효과 중 상당 부분은 **데이터 쌍의 시간 간격(d = 14)과 행동 정규화**에서 나오고, 공개된 샘플러에서 결정적 ODE는 사실상 **조건부 평균(회귀)** 을 출력합니다(`03` §6, §7).

## 1. 문제 설정과 동기 (Sec. I, II)

- 표준 확산·플로우 정책은 가우시안 잡음 `x0 ~ N(0, I)`에서 행동 청크 `x1`로 가는 흐름을 학습합니다(Sec. I, Fig. 1). 논문은 이 원천이 "정보 없는 사전분포"라서 긴 곡선 경로와 많은 적분 단계를 낳는다고 봅니다(Sec. I, II-A).
- 관련 연구로 CFM(Sec. II-B)과 OT-CFM, Schrödinger bridge를 다루고, 데이터 의존 결합(Sec. II-C)으로 Streaming Flow Policy(이전 행동에서 출발), VITA(잠재 시각 표현 원천), Trajectory Flow Matching(관측 이력 조건, 이중 네트워크)을 비교합니다. 논문의 차별점은 **학습된 두 번째 네트워크 없이** 이력 그 자체를 원천으로 쓰는 것입니다.
- 이론적 틀은 Chen et al.(ICML 2024, [7])의 확률적 보간(stochastic interpolant)을 따릅니다. 원천을 점질량 `δ(x0)`로 두는 "점에서 분포로" 수송입니다.

## 2. 방법 (Sec. III)

### 2.1 원천과 목표 (Sec. III-A)

- 상태 공간과 행동 공간을 같은 표현(관절 위치 또는 말단 자세)으로 둡니다(식 없음, 강한 가정).
- 시각 `t`에서 **원천** `x0 = s[t−H+1 : t]`(상태 이력), **목표** `x1 = s[t−H+1+d : t+d]`(d시점 뒤로 밀린 "미래 행동" 청크), `1 ≤ d ≤ H`. `d < H`면 두 열이 겹칩니다(Sec. III-A).
- 실험 설정은 H = 16, d = 14, 겹침 2(학위논문 부록 A.1). 실물은 겹침 2, 관측 창 2(Sec. IV-E).

### 2.2 학습 (Sec. III-C, Alg. 1, 식 1–3)

- 보간(식 1): `xλ = (1−λ)x0 + λx1 + ε(1−λ)wλ`, `λ ~ U(0,1)`, `ε`는 학습 잡음 계수. 선형 보간을 골랐다고 명시합니다.
- 드리프트 목표(식 2–3): `u_λ = (x1 − x0) − ε√λ z`, 손실 `L = E‖b_θ(xλ, x0, λ, c) − u_λ‖²`. 확률 미분 방정식은 식 2입니다.
- 관측 조건 `c`는 ResNet-18 + Spatial Softmax + FiLM으로 넣습니다(Sec. III-D). 드리프트 네트워크는 1D U-Net입니다.

### 2.3 추론 (Sec. III-E, Alg. 2, 식 4–6)

- 점수(식 4–5): `∇x log p_λ(x|x0) = [λ u_λ − (x − x0)] / (ε² λ(1−λ))`. 조건부 가우시안 구조에서 닫힌 식입니다. **이 식은 코드의 `compute_score`와 수치로 일치합니다(`03` §7, 최대 차이 2e-9).**
- 추론 SDE(식 6): `dx = [u_λ + (g_λ² − γ_λ²)/2 · ∇log p] dλ + g_λ dw`. `g_λ = 0`이면 결정적 흐름(ODE), `g_λ > 0`이면 확률적 샘플링입니다.
- 논문은 결정적 샘플링을 주 방식으로 씁니다(Sec. IV-C). 실물은 10 Euler 단계, 청크 16개 예측·8개 실행(수신 지평, Sec. III-E 끝, Sec. IV-E).

### 2.4 논문이 제시한 핵심 논리

1. 원천이 목표에 가까우면 전달 거리가 짧다(Sec. III-B, 식 없이 서술).
2. 같은 가정에서 `J_temporal < J_indep`이다. `J_indep = 2HD`, `J_temporal = 2HD − 2E[x1ᵀx0]`(Sec. III-B). 이 유도는 **각 차원이 분산 1로 표준화되었다**고 가정합니다(§5 `03` 참조).
3. 짧고 직선인 흐름이면 적은 단계로 적분할 수 있다(Sec. IV-A, IV-B).

## 3. 실험 (Sec. IV)

### 3.1 시뮬레이션 (Sec. IV-A, Table I)

- 과제 5개(Lift, Can, Square, Transport, Tool Hang), 데이터 ph(숙련 사람)와 mh(여러 사람, Tool Hang 제외).
- 기준선: Diffusion Policy(DDPM, 255M, 100 NFE)와 CFM(255M, 10 NFE). 제안법은 17M 파라미터(U-Net [256, 512]).
- 평가: 체크포인트당 50회, 시드 3개, 50 epoch마다 평가. **Max는 학습 전체 최댓값, Average는 마지막 10개 체크포인트 평균**(Table I 캡션).
- 학습: 배치 128, 1500 epoch, A100 1장. 추론 지연은 RTX 4080(Table I).

**Table I 요지(성공률 Max/Average):**

| 과제 | 제안법 Average | DP Average | CFM Average |
|---|---|---|---|
| Lift ph / mh | 1.00 / 0.99 | 1.00 / 1.00 | 1.00 / 0.99 |
| Can ph / mh | 0.98 / 0.98 | 0.97 / 0.96 | 0.98 / 0.95 |
| Square ph / mh | 0.96 / 0.83 | 0.91 / 0.87 | 0.91 / 0.78 |
| Transport ph / mh | 0.91 / 0.76 | 0.89 / 0.73 | 0.91 / 0.54 |
| Tool Hang ph | 0.69 | 0.71 | 0.70 |
| NFE / 지연(ms) | 10 / 19.1 | 100 / 615.6 | 10 / 63.5 |

- 논문은 "outperforming on Can mh, Square ph, Transport mh, underperforming on Square mh and Tool Hang ph"라고 씁니다(Sec. IV-A). 재계산 결과 차이는 대부분 구간 안에 있고, 통계적으로 남는 것은 Transport mh의 CFM 대비 차이뿐입니다(`03` §1).

### 3.2 전달 비용 (Sec. IV-B, Table II, 식 7–8)

- 식 7: `J(τ) = Σ_k (‖p_{k+1} − p_k‖² + r·θ(R_k, R_{k+1}))`, `r = 0.1 m`. 식 8: `J(τ) / (‖p_K − p_0‖² + r·θ(R_0, R_K))`.

**Table II (Square ph, 50 에피소드):**

| 방법 | 전달 비용 | 직진성 비율 |
|---|---|---|
| Diffusion Policy | 189.99 | 20.61 |
| CFM | 10.00 | 1.08 |
| 제안법 | 1.21 | 1.02 |

- 논문은 "nearly an order of magnitude"라고 씁니다. CFM 대비 8.3배, DP 대비 157배입니다. 두 방법 모두 `N(0, I)` 원천이라 결합 비용은 같은데도 DP와 CFM의 차이가 19배입니다. 그 차이는 샘플러(100단계 DDPM 대 10단계 ODE)와 측정 방식에서 옵니다(`03` §4, §8).
- 직진성 1.02 대 1.08(CFM)은 학위논문 표 5.4의 SD(0.03, n = 100)로 보면 통계적으로는 구별되지만(Welch p ≈ 1e-38) 차이가 7%입니다(`03` §1.4).

### 3.3 추론 단계 수와 잡음 (Sec. IV-A 끝, IV-C, Fig. 3)

- Fig. 3 왼쪽(Tool Hang ph): 제안법은 NFE 1에서 약 0.6, CFM도 약 0.56, DP는 32 NFE 미만에서 0입니다. 10 NFE 이상에서 세 방법이 비슷해집니다.
- Fig. 3 오른쪽: 추론 SDE 계수 ε를 올리면 성공률 곡선이 오른쪽으로 밀립니다. ε = 0은 2–4 단계에서 높은 성공률, ε = 1.0은 8–16 단계가 필요합니다. 결정적 ODE를 쓰는 근거입니다.
- 학습 잡음 `ε` 값은 본문에 없습니다(학위논문: ε = 1.0으로 고정, 부록에서 ε = 0.1일 때 NFE 1 성공률 0.34, ε = 1.0일 때 0.89, 표 5.1 본문 설명).

### 3.4 데이터 효율 (Sec. IV-D, Fig. 4)

- Square ph에서 데이터 수 40–200을 바꾼 곡선 하나. 제안법이 DP보다 모든 구간에서 높다고 씁니다. 시드 수, 오차 막대, 평가 횟수가 없습니다. 그림에서 읽으면 40개일 때 0.51 대 0.44, 200개일 때 0.995 대 0.98입니다(읽은 값, 그림 기준).

### 3.5 실물 (Sec. IV-E, F)

- 양팔 원격조작 장치, 7자유도 Barrett WAM 추종기, BarrettHand. 10 Hz 제어, 두 카메라.
- 과제: 머그를 집어 나무 못에 걸기. 시연 150개. **20회 평가, 10/20 성공(50%), 집기 19/20(95%).** 실패는 정렬 단계에서 깊이를 덜 밀어 넣는 것이었습니다.
- **비교 기준선이 없습니다.** DP나 CFM을 같은 실물 과제에 돌리지 않았습니다.

## 4. 결론과 한계 (Sec. V)

논문이 스스로 밝힌 한계:
- 원천이 현재 관측에 묶이므로 **초기화 품질에 민감합니다.** 원천의 잡음이 크면 생성 궤적이 치우칩니다(Sec. V).
- 미래 연구: 현재 속도로 원천을 앞으로 밀기, 힘·토크 제어, 키포인트 표현.
- "이력 초기화가 다중 모드를 분리하는지, 행동의 다양성을 보존하는지"는 **연구 과제로 남겨 둡니다**(Sec. V 첫 문단).

## 6. 논문 안에서 찾은 불일치와 빠진 정보

1. **식 7·8의 정의와 Table II 수치가 맞지 않습니다.** 식은 스텝 거리의 제곱 합과 끝점 거리의 제곱을 씁니다. 10단계 직선 경로에서 이 식은 1/10을 줍니다. 그런데 표의 직진성은 1.02, 1.08입니다. 공개 코드는 거리의 **합(제곱 없음)** 과 회전 각을 쓰고 끝점 거리로 나눕니다(`04` D8). 표 수치는 코드 정의와 맞습니다.
2. **원천과 목표의 시간 정렬이 식과 그림에서 다르게 읽힙니다.** 식 본문은 `x1 = s[t−H+1+d : t+d]`(상태)라고 쓰고, 그림 2는 원천을 `s_{t−1}`(한 상태)라고 씁니다. 코드는 원천 `s[t−15 : t]`(16개 상태)와 목표 `a[t−1 : t+14]`(16개 행동)를 인덱스 순서대로 짝짓습니다(`04` D2).
3. **같은 인덱스의 원천과 목표는 14 스텝 떨어진 시점입니다.** 그래서 전달 거리는 "14 스텝 동안의 움직임"입니다. 중복(겹침 2)은 시간으로는 같은 값이지만, 흐름이 학습하는 쌍은 인덱스 기준이므로 실제 이동량은 d에 의해 정해집니다(`03` §2, §8).
4. **실물의 결합 표현이 상태-행동 동등 가정에 맞지 않습니다.** 결합은 "관절 위치와 그리퍼 속도"(Sec. IV-E)라고 씁니다. 그리퍼 속도는 상태가 아니라 파생량입니다. 학위논문에도 같은 문장이 있습니다.
5. **실물 제어 코드는 저장소에 없습니다.** `real_world/` 폴더에는 비디오 기록기만 있습니다. 500 Hz 보간(학위논문 5.2절)도 공개되지 않았습니다.
6. **학습 epoch 불일치.** 논문과 학위논문은 1500, 저장소 기본 설정은 4500입니다(`04` D6).
7. **평가 횟수 불일치.** 논문은 체크포인트당 50회, `eval.py`는 100회입니다. 학습 중 롤아웃은 50회입니다.
8. **추론 설정 불일치.** 논문 표의 NFE 10은 결정적 ODE입니다. 공개 `eval.py`는 추론 SDE 계수를 1.0으로, 단계 수를 100으로 덮어씁니다(`04` D5).
9. **정규화 가정.** 분석 식은 분산 1을 쓰고, 코드는 [−1, 1] 범위 정규화를 씁니다(`03` §2).
10. **ε 값이 본문 주 결과에 없습니다.** 학위논문만 1.0을 적습니다.
11. **Fig. 2의 원천 표기**가 본문과 다릅니다(위 2번).
12. **원천 밀기 제안과 실물 평가 부족.** 실물 한 과제, 20회, 기준선 없음.

## 7. 용어

- 원천(source) x0: 이력, 확률 과정의 출발 분포. 여기서는 점질량.
- 목표(target) x1: 미래 행동 청크(인덱스 순서로 d만큼 밀림).
- 드리프트 b_θ: 신경망이 예측하는 `E[ẋ | xλ, x0, c]`.
- 결정적 ODE: 추론 SDE 계수 g = 0. 논문 식 6의 보정항은 g = 0에서도 남습니다(`03` §6).
- NFE: 드리프트 신경망 호출 수. 여기서는 적분 단계 수와 같습니다(Euler 1단계 = NFE 1).
