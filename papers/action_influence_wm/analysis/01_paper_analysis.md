## 1. 한 줄 요약

전문가 시연으로 학습한 행동 조건부 비디오 세계모델은 행동 명령을 무시하고 "그럴듯한 전문가식 미래"를 내놓습니다. 저자들은 원인을 **학습 데이터의 행동 영향(action influence)이 낮은 것**으로 보고, 데이터의 조건부 상호정보를 늘리는 능동 수집 알고리즘 **AIM**을 제안합니다. 3k 전문가 시연에 AIM 에피소드 500개를 더하면 Push-T에서 end-effector(EE) 재현율이 전문가 300k로 학습한 모델과 같아진다는 결과를 "데이터 85배 절감"으로 보고합니다(초록, §4.2, 그림 5).

## 2. 방법

### 2.1 행동 영향 지표 (식 1, §3.1)

설명된 행동 정보(explained action information)는 모델이 행동을 알 때와 모를 때의 예측 오차 차이입니다.

Î(ρ_eval, π_eval) = E_{d_eval(s,a)} [ KL(p(·|s,a) ‖ p̂_{θ,π_eval}(·|s)) − KL(p(·|s,a) ‖ p̂_θ(·|s,a)) ]

p̂_{θ,π_eval}(s'|s)는 모델의 예측을 평가 정책 π_eval로 평균한 것입니다. 이 값이 크면 모델이 행동을 쓴다는 뜻이고, 저자들은 이를 행동 충실도의 대리 지표로 씁니다(§3.1). 부록 A.1 식 (A.1)에 따라 Î = E[log p̂_θ(s'|s,a) − log p̂_{θ,π}(s'|s)]입니다. 이 값은 음수가 될 수 있습니다(`03` T1).

### 2.2 정리 1: 데이터의 조건부 상호정보가 상한 (식 2, 부록 A.1)

Î(ρ, π) ≤ I(ρ, π) := E_ρπ[KL(p(·|s,a) ‖ p_π(·|s))] = I(A; S'|S).

증명은 두 정보의 차이를 베이즈 규칙으로 쓰면 I − Î = E[KL(q_π ‖ q̂_π)] ≥ 0이 되는 것입니다(식 A.3–A.5). 이 유도를 따라가 보면 단계마다 맞습니다(`03` §5).

범위를 꼭 짚어야 합니다. 식 (2)의 ρ, π는 **같은 분포 하나**이고, 우변 I(ρ, π)는 그 분포 아래 참 전이 p의 성질입니다. 학습 데이터는 식 어디에도 들어가지 않습니다. 따라서 "데이터가 상한을 준다"는 말은 평가 분포를 데이터 분포로 놓았을 때(식 (A.5) 아래 문장 "over the dataset")에만 정리의 직접 결과입니다. 초록과 서론의 "any model trained on that data can express"는 이보다 넓은 서술이며, §3.2는 "추가 귀납 편향이 없다면" 조건을 한 문장으로 밝힙니다(`03` T1, `04` C1–C2).

### 2.3 문맥 밴딧과 AIM 보상 (식 3–5, §3.2–3.3)

평가 상태 분포 ρ_eval에서 I(ρ_eval, π)를 최대화하는 문맥 밴딧(식 3)을 정의하고, 이것이 **한 단계 empowerment** 목적과 같다고 밝힙니다. 실제로는 ρ_eval과 참 전이에서 표본을 얻을 수 없으므로 리플레이 버퍼 d_k, β_k로 쓴 보상을 씁니다.

r_AIM(s,a,s') = log q_k(a|s,s') − log β_k(a|s) + log ρ_eval(s) − log d_k(s)   (식 4)

앞 두 항은 점별 상호정보(r_MI), 뒤 두 항은 상태 커버리지(r_cov)입니다. **정리 2** (식 5–6)는 π*_k(a|s) ∝ β_k(a|s) exp(E_{s'}[r_AIM])이 Barber–Agakov 하한의 최적해이고 β_k ≠ π*_k이면 I(ρ, π*_k) > I(ρ, β_k)라는 주장입니다(증명 A.2–A.3). 증명 구조는 맞습니다. 다만 r_cov는 상태만의 함수라 상태별 정책 π*(a|s)에 영향을 주지 않고(A.14에서 상수로 소거), 정리가 보증하는 것은 정확한 q_k를 쓴 한 단계 정책 개선입니다(`03` T2, K11).

### 2.4 실용 구현 (§3.4, 부록 C, 알고리즘 1–2)

| 구성 | 내용 | 출처 |
|---|---|---|
| 밀도 추정 | q̂(a\|s,s'), β̂(a\|s), d̂(s)를 flow matching 모델로 학습. 우도는 FFJORD-Hutchinson 추정기를 학습 시간 자기 증류로 상각 | §3.4 |
| 반복 | 리플레이 D_k로 밀도 모델을 다시 맞추고(체크포인트는 held-out 우도로 선택) 보상을 붙인 뒤, IQL 비평가 + AWR로 확산 정책을 추출하고 B_k = 100 궤적을 수집 | 알고리즘 1–2 |
| 보상 정규화 | 각 항을 z-점수로 표준화해 r̂ = z(log q̂ − log β̂) − z(log d̂) (식 C.2). AWR 가중치는 [0, 100]으로 자름 | §3.4, 부록 C |
| ρ_eval | 평가 분포를 모르므로 목표 상태 공간 위 균등분포로 둠 | §3.4 |
| 정책 하이퍼파라미터 | IQL expectile 0.7, γ = 0.99, AWR 역온도 0.1, 가중치 클립 [0, 100], AWR 워밍업 20k + 5k 램프, 학습 스텝 BC 100k / IQL+AWR 50k, 배치 256 | 표 3 |
| 밀도 모델 하이퍼파라미터 | **본문과 부록 표에 없음.** 구조, 크기, 학습 스텝, 발산 헤드 정보가 보이지 않음 | (K10) |

이론과 구현 사이의 간격은 논문이 직접 밝힙니다. 순차 RL 근사는 문맥 밴딧의 개선을 보증하지 않으며(§5 한계), z-점수는 "보상 항의 거듭제곱 가중치와 더 좁은 신뢰 영역"으로 해석됩니다(부록 C). 정리 2의 라그랑주 승수 η = 1 등가성은 z-점수 이후에는 적용되지 않는 것으로 읽힙니다.

## 3. 실험 설정 (§4, 부록 D–E)

| 항목 | 내용 |
|---|---|
| 환경 | **Four Rooms**(완전 관측, 결정적, 이산 행동 6, 레이아웃 5개를 모든 상태-행동 쌍으로 평가), **Push-T**(ManiSkill3, 픽셀, 연속 행동 6차원) |
| 세계모델 | Four Rooms: DiT 흐름 정합 (97.8M). Push-T: DreamerV4 유사 잠재 Diffusion Forcing (44.5M), 144×144 SD-VAE 잠재, 128 Euler 스텝 (표 5). §4.3과 사람 평가는 256×256 |
| 학습 | 사전학습 없이 처음부터. **데이터셋/규모/해상도마다 모델 하나**(부록 E) |
| 지표 | Four Rooms: 최대우도 상태 매칭 시뮬 충실도. Push-T: end-effector 마스크 픽셀 재현율(임계값 = 범위의 10%), §4.3은 Tee 재현율과 Joint = 변환별 min(EE, Tee) |
| 평가 분포 | BC 확산 정책 롤아웃(on-policy), Push Away(Tee를 목표에서 멀리 미는 PPO), BC-Failure(BC와 Push Away를 3:1로 기하 분포 전환) |
| 평가 크기 | 분포마다 정책 롤아웃 100개 × 추론 시드 3개, 궤적과 시드 부트스트랩 10,000회. 지평 H = 10(그림 5–6), H = 33(표 1) |
| 사람 평가 | 아레나 A/B, Bradley–Terry Elo, 1545 비교, 평가자 20명 |
| 기준 데이터 | PPO 전문가(3005 궤적 ≈ 1.1×10^5 전이), 균등 랜덤, 랜덤 워크, 복구(Recovery: 랜덤 워크와 PPO를 기하 분포로 번갈아) |
| 탐험 기준선 | DIAYN, DADS, ICM, METRA. SAC 백본으로 **31차원 시뮬 상태**에서 학습(EE와 Tee 포즈 일부만 보상에 사용), 라운드마다 2×10^5 갱신 후 100 궤적 수집, 5라운드(부록 E, 표 6) |

AIM은 픽셀(SD-VAE 잠재)로, 탐험 기준선은 시뮬 상태로 돌아갑니다. 그림 5 범례도 "Push-T (sim-privileged)"와 "Push-T (visual-only)"를 구분합니다. 부록 H는 기준선이 픽셀만으로는 탐험하지 못했다고 설명합니다(K3).

## 4. 결과

### 4.1 상호정보와 제어 가능성 (§4.1, 그림 3, 6)

세계모델 68개(Push-T 8 규모 × 4 전략 + Four Rooms 9 규모 × 4 전략, 산술 일치)를 학습해, Four Rooms에서 모델이 설명한 행동 영향과 시뮬 충실도의 상관을 r = 0.979(95% CI [0.96, 0.99])로 보고합니다(그림 3). 사이트 기록 데이터의 36점으로 r = 0.9787, Fisher 구간 [0.958, 0.989]가 다시 나옵니다(`03` V5). 그림 3의 가로축은 **세계모델의 Î**이지 데이터의 I가 아닙니다(`03` K2).

그림 6은 수동 수집의 규모 곡선입니다. Four Rooms에서는 균등 랜덤이 1.2k부터 99%로 평평합니다. Push-T BC 평가에서 PPO 전문가 곡선은 1.5k에서 약 20%, 150k와 300k에서 약 32.3%이고(그림 판독 값), 랜덤 워크와 균등 랜덤은 4.7k 궤적에서 38–39%입니다(그림 판독 값, `03` V7).

### 4.2 능동 수집 (§4.2, 그림 5)

3k 전문가에 100 에피소드씩 Four Rooms 4라운드, Push-T 5라운드를 더합니다(`03` V6).

| 평가 | 3k 전문가 | AIM 500 | 300k 전문가 | 근거 |
|---|---|---|---|---|
| Push-T BC, EE 재현율(H=10) | 20.35 | 32.54 | 32.33 | 사이트 JSON, 그림 5 |
| Push-T Push Away, EE 재현율(H=10) | 18.25 | 28.16 | 41.69 | 사이트 JSON, 그림 5 |

균등 랜덤, 랜덤 워크, 복구와 탐험 기준선 네 가지(DADS, DIAYN, ICM, METRA)는 모두 BC 평가에서 500 에피소드 뒤 값이 3k 전문가 값(20.35) 이하입니다(사이트 JSON, `03` V6). Four Rooms에서는 균등 랜덤이 98%로 AIM(약 83%)보다 높고, 저자들도 "예상대로 랜덤이 가장 강하다"고 씁니다(§4.2).

## 5. 저자가 밝힌 한계 (§5)

- 밀도 보상 모델을 여러 번 다시 학습하는 구현 복잡도와 계산량. 재추정이 줄어도 된다는 절제가 있고, 학습된 보상을 오프라인 필터로도 쓸 수 있다고 제안.
- 순차 RL 근사가 문맥 밴딧의 개선을 보증하지 않음.
- 사후 학습(post-training)이 데이터 효율에 주는 영향은 다루지 않음.
- 시뮬레이션 개념 증명이며, 범용 모델의 지속 개선으로 옮기는 것은 앞으로의 일.
