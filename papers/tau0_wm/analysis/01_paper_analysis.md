## 1. 문제와 주장

- **문제 (I절):** 로봇 조작은 행동이 일으킬 결과를 예측하면서 실행 가능한 행동을 만들어야 합니다. 로봇 시연은 행동 라벨이 있지만 좁고 비싸며, 영상은 넓지만 행동 라벨이 없습니다.
- **핵심 아이디어:** 미래 관측, 로봇 행동, 과제 진행을 한 예측 모델 안에 두고, 각 데이터 소스가 자기가 가진 신호만 감독하게 합니다("modality-specific supervision masks", III절 d).
- **기여 세 가지 (I절 끝):** (1) 정책 학습과 행동 조건 시뮬레이션이 예측 표현을 공유하는 τ0-WM, (2) 이질적 데이터를 감독 마스크로 합치는 방법, (3) 제안-평가-수정(proposal-evaluation-revision) 형태의 테스트 시간 계산.
- **주장 목록:**

| ID | 주장 | 위치 |
|---|---|---|
| C1 | VAM이 네 가지 긴 과제에서 π0.5, Fast-WAM보다 평균 성공률이 높다 (0.64 대 0.44, 0.20) | VII-A, 그림 4a |
| C2 | VAM은 여러 로봇(AGIBOT-G01, ARX, 이중 Franka)에서 잘 확장된다 | VII-A 끝 |

## 2. 방법

### 2.1 두 인터페이스 (그림 1, 2)

- **VAM (Video Action Model, IV절).** 입력은 다시점 관측 `o_t`, 언어 `p`, 로봇 상태 `s_t`이고, 출력은 미래 영상 잠재 `ẑ_{t+1:t+Hv}`와 행동 덩어리 `â_{t:t+Ha−1}`입니다(식 1). Wan2.2-TI2V-5B에서 초기화합니다. Wan VAE로 시점별 잠재를 만들어 가로로 이어 붙이고, 현재 관측 잠재는 깨끗한 문맥으로 두고 미래 잠재 칸만 잡음을 넣어 영상 DiT(5B)가 노이즈 제거합니다. 행동 가지는 0.5B DiT 스타일 디코더이며 같은 층에서 영상 중간 특징에 cross-attention으로 붙습니다. 합계 5.5B.
- **손실 (식 2).** 영상과 행동 둘 다 flow matching이고 `L_VAM = E[λz‖f_z − v_z‖² + λa‖f_a − v_a‖²]`, 모든 실험에서 `λz = λa = 1`. 영상 가지와 행동 가지는 각자의 잡음 수준(`u_z`, `u_a`)을 씁니다. 데이터 소스별 감독 마스크로 없는 항을 끕니다.
- **ACVS (Action-Conditioned Video Simulator, V절).** VAM과 같은 Wan VAE와 영상 백본을 쓰되 행동 가지는 빼고, 후보 행동 `ā`를 깨끗한 조건으로 주어 미래 영상 잠재와 밀집 보상 `r̂`을 예측합니다(식 3). 행동 조건은 Cosmos의 방식을 따라, 미래 잠재 칸마다 행동 묶음 `b_ℓ`을 MLP 두 개로 사영해 시간 임베딩과 AdaLN 변조에 더합니다(식 4). 보상 헤드는 "Optional Reward Expert 0.5B"로 그림 2(b)에 표시됩니다.
- **보상 라벨 (V-C).** 과제를 하위 과제로 나누고 하위 과제 단위로 진행 라벨을 붙인 뒤, 각 하위 과제 구간 안에서 몬테카를로 전파로 프레임별 보상을 만듭니다. 실패한 하위 과제 구간은 궤적 전체에 음의 보상을 줍니다. 실패·복구가 많은 궤적을 시뮬레이터 학습에 더합니다.
- **ACVS 손실 (식 5).** 영상과 보상에 flow matching, `λz = λr = 1`.

### 2.2 테스트 시간 계산 (VI절, 알고리즘 1, 2)

1. VAM에서 후보 `N`개(`N = 4`가 기본, VII-B)를 샘플합니다.
2. 후보마다 **RCS**(Re-denoising Consistency Score)를 계산합니다. `K`개의 흐름 시각을 무작위로 골라 후보 행동에 학습 때와 같은 방식으로 잡음을 다시 넣고, VAM의 행동 속도장 오차를 평균해 `E_RCS`를 얻고 `S_RCS = −E_RCS`(식 6)로 두어 `i* = argmax S_RCS`(식 7)를 고릅니다. 논문은 이것을 "가벼운 분포 필터"라고 부릅니다.
3. `S_RCS^{(i*)} ≥ γ`이면 그 후보를 실행합니다(알고리즘 1, 식 8의 부정). 아니면 ACVS로 모든 후보의 상상 롤아웃과 보상을 만들고(식 9), 롤아웃 값 `J^{(i)} = max_q r̂_{t+q}`(식 10)가 가장 큰 후보 `j*`를 고릅니다(식 11).
4. **LAR** (Low-quality Action Rectification, 알고리즘 2): 고른 롤아웃 잠재 `ẑ^{(j*)}`를 추가 미래 조건으로 VAM에 다시 질의해 정제된 행동 덩어리 `ã`를 얻습니다.
- `K`, `γ`, 메모리 길이 `M`, `Hv`, `Ha`, 샘플러 단계 수는 논문에 값이 없습니다(`04` D 항목에서 코드 값과 비교).

### 2.3 데이터 (III절, 그림 1)

| 소스 | 시간 | 비율 | 감독 |
|---|---|---|---|

롤아웃·실패 궤적의 양은 논문에 없습니다. 27.3K h의 합계 구성에 포함되는지도 III절은 세 소스만 합산해 27.3K라고 씁니다(`03` V1).

### 2.4 학습과 배포 (부록 A, B)

- 두 단계: 27.3K h 사전학습(전역 배치 12,288), 과제 사후학습(전역 배치 384). AdamW, 학습률 5×10⁻⁵, 모든 임베디먼트·과제에 같은 최적화 하이퍼파라미터.
- 배포: 행동 덩어리 길이 30으로 수평선 후퇴 제어. RTX 5090 한 장. 질의당 약 220 ms, 텍스트 표현 캐시로 180 ms, 층별 `torch.compile`과 KV 캐시 등으로 140 ms. 본문 결과는 `torch.compile` 없이 얻었다고 적었습니다.
- 사전학습에 쓴 연산량, 학습 스텝 수, GPU 수는 논문에 없습니다.
