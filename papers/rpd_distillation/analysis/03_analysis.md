## 4. 유도

### 4.1 기호와 코드 대응

- 행동 a ∈ R^d, d = 7 (ΔEE 6 + 그리퍼). 정책 평균 μ_θ(s), 로그 표준편차 ℓ 상태 독립, σ = exp(ℓ).
- 교사 샘플 ā(s) ~ π_VLA(·|s). 논문 식 (5)의 기댓값 m(s) = E[ā|s].
- 코드의 PPO 손실 `pg_loss` = −min(...)의 평균 (최소화 방향). 코드의 MSE 항 `l_ppd` = `F.mse_loss(means, p.mean)` = (1/(Bd)) Σ_i Σ_k (μ_ik − ā_ik)².
- 코드 전체 손실: `loss = pg_loss + v_coef·v_loss + λ·l_ppd` (`ent_coef = 0`). 최대화 형태로 쓰면 J_RPD = J_clip − λ·ℓ_MSE입니다.

### 4.2 결합 손실의 기울기

J_clip의 기울기는 PPO 표준입니다. MSE 항의 기울기는 다음과 같습니다.

∇_θ ℓ_MSE = (2/(Bd)) Σ_i (μ_θ(s_i) − ā_i)ᵀ ∇_θ μ_θ(s_i)

따라서 ∇_θ J_RPD = ∇_θ J_clip − (2λ/d) · E_s[(μ_θ(s) − ā)ᵀ ∇_θ μ_θ(s)].

- 로그 표준편차 ℓ은 MSE 항에 들어가지 않습니다. 따라서 RPD는 분산을 줄이라고 요구하지 않습니다. 분산이 바뀌는 것은 PPO 항 때문입니다.
- 논문 식 (3)의 가중치 1은 코드에서 `λ = 1`인 상수입니다(`04` D1). 코드의 MSE는 원소 평균(÷d)이므로, 식 (5)를 합 형태로 쓰면 가중치가 λ/d = 1/7입니다. 논문은 이 정규화를 밝히지 않습니다(`04` D2).

### 4.3 단일 교사 샘플의 편향

교사 샘플 하나로 추정해도 기울기의 기댓값은 바뀌지 않습니다. 교사 분포에 대해

E_ā[(μ − ā)²] = (μ − m)² + Var(ā)

이고 Var(ā)는 θ와 무관합니다. 따라서 ∇_θ E_ā[(μ−ā)²] = 2(μ−m)∇_θμ이고, 단일 샘플 추정의 기댓값도 같습니다. 단일 샘플은 편향이 아니라 분산을 더합니다. 이 점은 논문의 "상태당 한 샘플이면 충분하다"(§III-A)와 맞습니다.

한 가지 단서: 코드는 같은 상태를 에폭마다 다시 질의하므로(`04` D3) 교사 샘플은 에폭마다 새로 뽑힙니다(Octo는 확률적 샘플링, OpenVLA는 결정적 생성). 위 기댓값 논리는 여전히 성립하고, 질의 횟수만 늘어납니다.

### 4.4 가우시안 BC와의 관계

고정 σ의 가우시안 최대우도 손실은 (1/(2σ²))‖μ − a‖² + 상수입니다. 따라서 코드의 MSE 항은 **고정 σ 가우시안 BC와 같고, σ² = d/(2λ)입니다.** λ = 1, d = 7에서 σ² = 3.5, σ ≈ 1.9입니다. 행동 범위가 대략 [-1, 1]인 것을 생각하면 이 BC는 매우 느슨합니다. 식 (5)를 합 형태로 쓰면 σ² = 0.5, σ ≈ 0.7이 되어 더 강합니다. 두 해석 중 무엇이 코드인지는 `04` D2가 확정합니다(코드는 원소 평균).

RPD-BC(식 2)는 σ를 학습하므로 σ가 줄어드는 방향으로 움직입니다. 논문의 "분산 항이 표준편차를 줄여 교사에 과적합한다"(§IV-A)는 설명은 이 차이와 맞습니다. 기울기 수준에서 확인하지는 않았습니다.

### 4.5 고정점 편향

RL 목적을 평균 공간에서 국소 이차 근사합니다.

J_clip(μ) ≈ −(κ/2)(μ − μ*)²

여기서 μ*는 RL 최적 평균이고 κ > 0는 곡률입니다. 교사 항의 유효 가중치를 λ_e = λ/d (코드 기준)로 두면, 정지점은

κ(μ* − μ) − 2λ_e(μ − t̄) = 0 ⟹ μ_fix = (κμ* + 2λ_e t̄)/(κ + 2λ_e)

이고 편향은

μ_fix − μ* = [2λ_e/(κ + 2λ_e)] · (t̄ − μ*)

입니다. 여기서 t̄ = E[ā|s].

- **상수 λ:** 편향 비율 w = 2λ_e/(κ + 2λ_e)는 λ가 클수록, κ가 작을수록 커집니다. 교사가 최적 (t̄ = μ*)이면 편향 0입니다. 교사가 틀리면 편향은 w(t̄ − μ*)에 비례합니다.
- **감쇠 λ(t) → 0:** 정지점 편향은 0으로 갑니다. 다만 수렴 속도는 λ(t)의 시간 척도에 달려 있습니다(§5 토이).
- **κ는 식에 없는 값입니다.** 논문의 정규화 advantage (`norm_adv = True`)를 쓰면 κ의 단위는 기울기 스케일에 따라 달라집니다. 따라서 "λ = 1이 얼마나 강한가"는 이 논문만으로 정할 수 없습니다. κ를 재려면 PPO 항과 MSE 항의 기울기 노름을 기록해야 합니다.

### 4.6 교사 질의 수와 비용

코드 설정 (`train.py`, `ppo_rgb_rpd.py`): num_envs = 128, num_steps = 50 → 배치 6400, num_minibatches = 48 → 미니배치 133, update_epochs = 8, total_timesteps = 3×10^7.

- 반복 수 = 3×10^7 // 6400 = 4687
- 반복당 교사 호출 = 8 에폭 × 49 미니배치 = 392 (마지막 미니배치는 16개)
- 반복당 교사 이미지 = 8 × 6400 = 51,200 → **환경 스텝 1개당 8개**
- 총 호출 = 1,837,304 (Octo는 배치 호출), 총 이미지 = 약 2.4×10^8 (OpenVLA는 이미지마다 순차 추론)
- 호출당 입력 전송 = 133 × 256×256×3 바이트 ≈ 26 MB

논문은 "상태당 한 샘플"이라고 쓰지만, 같은 상태를 에폭마다 다시 질의하므로 **스텝당 질의는 8배**입니다. 샘플 효율을 환경 스텝으로만 재면 이 비용이 빠집니다. 조기 종료(target KL 0.2)가 걸리면 줄어들지만 코드에 근거가 없습니다. 이 계산은 `python3 -I`로 확인했습니다.

### 4.7 탐색 관점의 해석

RPD 항은 μ를 t̄ 쪽으로 끌어당기는 결정적 항입니다. 학습 초기에 RL 신호가 없거나 약하면(희소 보상에서 성공이 없으면) 이 항이 사실상 유일한 기울기입니다. 이것이 논문의 속도 향상과 희소 보상 결과를 설명하는 기본 메커니즘입니다. 반대로 RL 신호가 충분해지면 교사 항은 편향만 더합니다. 논문은 이 두 단계를 나누어 보고하지 않습니다.

## 5. 토이 (CPU numpy)

설정: 1차원 행동, 정책 a ~ N(μ, 0.3²), a* = 1, 배치 32, 반복 800, 시드 30, η = 0.1, μ₀ = -1. 교사는 좋은 교사(t = 1), 편향 교사(t = 1.4, 같은 방향), 반대 교사(t = -2), 잡음·무편향 교사(N(1, 1²)), 무관한 교사(N(0, 1²))입니다. 보상은 dense -(a-a*)²와 sparse 1{|a-a*| < 0.1}입니다. 스케줄은 상수, 선형(T/2에서 0), 코사인(`0.5cos(πt/T) + 0.5`)입니다.

### 5.1 고정점 편향 검증 (dense, 상수 λ)

| 교사 | λ | 시뮬 편향 | 이론 λ/(1+λ)·(t̄ − a*) |
|---|---|---|---|
| 편향 교사 | 1 | +0.204 | +0.200 |
| 반대 교사 | 1 | -1.525 | -1.500 |
| 무관한 교사 | 1 | -0.507 | -0.500 |
| 좋은 교사 | 1 | +0.001 | 0 |
| 잡음 무편향 | 1 | +0.001 | 0 |

이론식 μ_fix = (a* + λt̄)/(1+λ)가 시뮬레이션과 0.01 이내로 맞습니다(κ = 2, λ_e = λ인 1차원 모델). 이 토이에서는 λ_e = λ이므로 d 정규화 문제가 없습니다.

### 5.2 학습 속도와 스케줄 (dense)

0.1 근처에 도달한 반복 중앙값:

| 교사 | 스케줄 | λ = 0 | λ = 0.3 | λ = 1 | λ = 3 |
|---|---|---|---|---|---|
| 편향 | 상수 | 13 | 8 | 3 | 800 (미도달) |
| 편향 | 코사인 | 13 | 8 | 3 | 582 |
| 무관 | 상수 | 14 | 800 | 800 | 800 |
| 무관 | 선형 | 14 | 174 | 344 | 388 |
| 무관 | 코사인 | 14 | 360 | 595 | 691 |
| 반대 | 상수 | 13 | 800 | 800 | 800 |

- 교사가 좋거나 편향되어 같은 방향이면 λ가 클수록 빠릅니다. 다만 λ = 3에서 편향 교사가 800까지 도달하지 못하는 것은 편향 0.30이 0.1 창 밖에 머물기 때문입니다.
- 무관하거나 반대인 교사에서 상수 λ는 학습을 막습니다. 감쇠 스케줄은 편향을 없애고 도달을 되찾지만 느립니다.
- 이 토이의 λ 척도는 κ = 2인 dense 보상에 맞춰져 있습니다. 실제 RPD의 λ 의미는 §4.5와 같이 κ에 따라 달라지므로 값을 옮기면 안 됩니다.

### 5.3 희소 보상 (상수 λ, 최종 성공 확률 P(|a-a*| < 0.1))

| 교사 | λ = 0 | λ = 0.1 | λ = 1 | λ = 3 |
|---|---|---|---|---|
| 좋은 | 0.00 | 0.26 | 0.26 | 0.26 |
| 편향 (+0.4) | 0.00 | 0.26 | 0.21 | 0.15 |
| 반대 | 0.00 | 0.00 | 0.00 | 0.00 |
| 무관 | 0.00 | 0.25 | 0.00 | 0.00 |
| 잡음 무편향 | 0.00 | 0.26 | 0.26 | 0.26 |

- **교사가 없으면 희소 보상 학습은 전혀 되지 않습니다**(λ = 0, 800 반복 내 성공 0). 교사의 탐색 기여가 가장 분명한 부분입니다.
- 편향 교사는 λ가 클수록 최종 성공 확률이 떨어집니다. 같은 방향이어도 고정점 편향이 0.1 창을 벗어나기 때문입니다.
- 무관한 교사는 λ = 0.1에서만 성공하고, λ가 커지면 교사 편향이 학습을 막습니다.

### 5.4 무관한 교사 대조가 보여 주는 것

논문에 없는 대조입니다. 무관한 교사(평균 0, 잡음 1)는 상수 λ에서 편향(-0.5 at λ = 1)을 만들고 학습을 막습니다. 잡음만 있고 편향이 없는 교사는 편향 없이 탐색만 돕습니다. 그러므로 "교사 행동이 탐색 방향을 준다"는 해석이 맞으려면, 교사의 **평균**이 과제 목표와 맞아야 합니다. 논문의 "낮은 성공률에서도 방향을 준다"(§IV-D)는 교사 평균이 맞는 경우에 한정될 때만 성립합니다. 이 점은 이 토이로 확인되었고, 논문에서는 검증되지 않았습니다.

## 6. 이 분석이 말하지 않는 것

- 논문의 실제 PPO와 RPD 곡선 재현: 실행하지 않았습니다.
- κ와 실제 기울기 비율: 값을 모릅니다. §4.5의 w는 식으로만 주어집니다.
- 교사 분산과 시드 분산의 분리: 데이터가 없습니다.
- 토이의 λ 척도가 실제 PPO의 λ 척도와 같다는 주장: 근거가 없습니다.
- 벽시계 시간: 측정하지 않았습니다.
