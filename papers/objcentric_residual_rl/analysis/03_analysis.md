# 03. 수치 재계산, 통계 검정, 토이 검증

논문 수치를 다시 셈하고, 주장별 통계를 검정했습니다. 원자료(시도별 결과)는 없으므로 표 값에서만 계산했습니다. 실행은 CPU에서 수 초 안에 끝납니다.

- `analysis/recompute.py` → `analysis/recompute_results.json` (표 1, 2, 7과 그림 6의 막대 라벨)
- `analysis/toy_pose_residual.py` → `analysis/toy_pose_residual_results.json` (토이 C, numpy, 약 2.5분)
- `analysis/plot_figures.py` → `report/figures/own_*.png` (우리가 그린 그래프 세 장)

가정은 두 가지입니다. 실로봇의 과제당 20회는 서로 독립이라고 봅니다. 논문에는 같은 과제 안의 상관이나 시도 순서가 없습니다. 시뮬레이션의 "±"는 3 시드의 표본 표준편차(ddof = 1)로 봅니다. 논문에 정의가 없습니다.

## 1. 실로봇 성공률 재계산 (표 1)

### 1.1 주장 C1: 42% → 76% (100회 합계)

| 조건 | 성공 | 95% Wilson 구간 |
|---|---|---|
| 기반 VLA | 42/100 | 32.8% – 51.8% |
| 기반 + 잔차 | 76/100 | 66.8% – 83.3% |

- 차이 +34%p, Newcombe 95% 구간 [20.5, 45.8]%p.
- 양측 Fisher 정확검정 p = 1.6 × 10⁻⁶.
- 결론: **차이는 통계적으로 명확합니다.** 다만 시도가 과제 5개 × 20회에 묶여 있어 독립 가정이 완전히 성립하지 않을 수 있습니다. 이 점은 1.2에서 다룹니다.

### 1.2 과제별과 부호 검정

| 과제 | 기반 | +잔차 | 차이 | Newcombe 95% (차이) | Fisher p |
|---|---|---|---|---|---|
| Cube Lift | 7/20 | 17/20 | +10 | [0.20, 0.70] | 0.0031 |
| Pick-and-Place | 9/20 | 16/20 | +7 | [0.05, 0.58] | 0.048 |
| Stack Cube | 7/20 | 15/20 | +8 | [0.09, 0.62] | 0.025 |
| Close Drawer | 14/20 | 20/20 | +6 | [0.08, 0.52] | 0.020 |
| Stand Cup Up | 5/20 | 8/20 | +3 | [−0.13, 0.40] | 0.50 |

- 5개 과제가 모두 양의 차이입니다. 부호 검정의 양측 p = 0.0625입니다(과제 5개로는 최소 가능 p가 0.0625라서 더 강하게 말할 수 없습니다).
- Stand Cup Up만 구간이 0을 포함합니다. 나머지 네 과제는 p가 0.05 미만입니다. 다만 과제 5개의 다중 비교를 Holm으로 보정하면 Cube Lift(0.0031 × 5 = 0.016)만 남고, Close Drawer(0.0202 × 4 = 0.081)와 Stack Cube, Pick-and-Place는 유의하지 않습니다.

### 1.3 시도 수 계획

정규 근사, 양측 α = 0.05, 검정력 80%, 팔당 시도 수:

| 차이 | 팔당 시도 |
|---|---|
| 0.35 → 0.75 | 24 |
| 0.42 → 0.76 (논문 전체) | 32 |
| 0.50 → 0.90 | 20 |

과제당 20회는 과제 하나의 차이를 확실히 보기에 부족합니다. 과제별 차이를 주장하려면 과제당 약 25–30회가 필요합니다.

## 2. 절제와 관측 공간 (표 2)

합계는 실로봇 100회 기준입니다(과제당 20회 × 5).

| 설정 | 성공 | 차이 (Ours 대비) | Newcombe 95% | Fisher p (Ours 대비) |
|---|---|---|---|---|
| Ours | 76 | - | - | - |
| (a) 잡음 주입 제외 | 69 | −7 | [−0.05, 0.19] | 0.34 |
| (a) 포즈 탈락 제외 | 58 | −18 | [0.05, 0.30] | 0.010 |

| (b) 증류 기반 | 46 | −30 | [0.17, 0.42] | 0.00002 |
| (b) 이미지 기반 | 47 | −29 | [0.16, 0.41] | 0.00004 |

- **포즈 탈락이 기여합니다**(p = 0.010). **잡음 주입의 기여는 확인되지 않습니다**(p = 0.34). 본문 "noise injection helps tight-tolerance tasks"는 Close(20/20 변화 없음)와 Stand(8/20 변화 없음)를 보면 과제 수준에서도 근거가 약합니다.

- 이 대조는 관측만 바꾼 설계가 아닙니다. 증류와 이미지 베이스라인은 별도의 학습 파이프라인을 씁니다(`01` §5.3). 차이가 "관측 공간" 때문이라고 말하려면 학습 예산과 구조를 맞춘 추가 대조가 필요합니다.

## 3. 토이 C: 포즈 오차가 잔차를 어디서 깨뜨리는가

### 3.1 설계

- 2차원 점 그리퍼, 물체 위치 o ∈ [−0.1, 0.1]², 한 스텝 최대 2 cm, 60 스텝, 성공은 마지막 스텝에서 |o − x| < 1 cm입니다.
- **기반 정책**: 자기 방식으로 물체를 보고 `o_v = o + e_v`, `e_v ~ N(0, 2 cm²)`(에피소드마다 고정)를 씁니다. `a = clip(0.5 (o_v − x))`. 포즈 입력과 독립인 오차입니다.
- **잔차**: 2층 MLP(은닉 16, tanh), 입력은 `[o_hat, x, a_base]`, 출력은 `0.02 tanh(·)`입니다. 드롭아웃이면 `o_hat = (0, 0)`입니다(논문 식 5의 "포즈 벡터 0").
- **학습**: 진화 전략(antithetic, 인구 128, 800 세대, 에피소드 32). 세 설정을 학습했습니다. 증강 없음, 논문식 증강(스텝마다 iid N(0, 5 mm²) + 드롭아웃 0.1), 논문식 증강 + 에피소드 편향 N(0, 1 cm²).
- **평가**: 1000 에피소드, 고정 시드, 요인 하나씩 변경.

처음 설계에서는 `a_base`를 참 물체 위치로 계산했습니다. 그러면 잔차가 `a_base`에서 물체 위치를 읽어 포즈 잡음을 우회했고, 모든 조건이 성공률 1.0이 나왔습니다. 이것은 누설이라서 버리고 위의 설계로 바꿨습니다.

### 3.2 결과

| 정책 / 조건 | 0 | 중간 | 최대 |
|---|---|---|---|
| 기반 정책만 (잡음 없음) | 0.142 | - | - |
| 해석해 상한 (깨끗한 포즈, 잔차 = 0.5(o − x) − a_base) | 1.000 | - | - |
| 해석해, 에피소드 편향 σ_β = 1 cm | 0.404 | - | - |
| 학습: 증강 없음, iid σ 0 → 2 cm | 0.545 | 0.371 (1 cm) | 0.262 |
| 학습: 증강 없음, 편향 σ_β 0 → 2 cm | 0.545 | 0.376 (1 cm) | 0.238 |
| 학습: 증강 없음, 드롭아웃 0 → 0.3 | 0.545 | 0.498 (0.1) | 0.368 |
| 학습: 논문식 증강, iid σ 0 → 2 cm | 0.400 | 0.310 (1 cm) | 0.228 |
| 학습: 논문식 증강, 편향 σ_β 0 → 2 cm | 0.400 | 0.282 (1 cm) | 0.190 |
| 학습: 증강 + 편향 1 cm, 편향 σ_β 0 → 2 cm | 0.354 | 0.276 (1 cm) | 0.206 |

(학습 조건 행의 중간 열은 해당 축의 중간 값입니다. 1000 에피소드의 Wilson 95% 반폭은 최대 약 ±3%p입니다.)

### 3.3 해석

1. **편향의 절벽은 이론과 맞습니다.** 잔차가 포즈를 믿고 물체 위치 o + β로 간다면, 최종 오차는 |β|입니다. 2차원 정규 분포에서 P(|β| < 1 cm) = 1 − exp(−1/2) ≈ 0.393입니다. 해석해 결과 0.404와 맞습니다. 즉 **포즈에 상수 편향이 있으면 어떤 잔차도 허용 오차 밖으로 못 고칩니다.** 논문의 독립 잡음 모델(§3.2, A.6)은 이 실패를 드러내지 않습니다.
2. **학습된 잔차는 덜 학습되었습니다.** 깨끗한 포즈에서도 0.55 또는 0.40이고, 상한 1.0에 못 미칩니다. 그래서 증강이 성능을 낮추는지, 학습이 부족한지를 이 토이로 구별할 수 없습니다. 증강을 넣은 쪽이 깨끗한 포즈에서 0.40으로 낮은 것은 이 학습 예산에서 나타난 현상일 뿐입니다.
3. **그래도 방향은 있습니다.** 세 학습 설정 모두 포즈 잡음, 편향, 드롭아웃이 커질수록 성공률이 떨어집니다. 증강 없음 설정도 iid 2 cm에서 0.26으로 떨어집니다. 논문식 증강이 이 범위의 iid 잡음에 강건하다는 근거는 나오지 않았습니다.
4. **논문의 "로봇 실패" 모드와 맞닿는 지점:** 실제 실패(A.11)는 드리프트와 잘못된 물체입니다. 토이의 편향은 드리프트의 가장 단순한 형태입니다. 이 결과는 "추정기 오차의 상관 구조가 설계 변수"라는 것을 보여 줍니다.

### 3.4 한계

- 2차원 점 모델이고 접촉이 없습니다. 손가락 접촉이나 동역학 격차는 없습니다.
- 학습은 설정마다 한 번(고정 시드 1, 2, 3)입니다. 시드 반복이 없어서 설정 차이의 분산을 알 수 없습니다.
- 진화 전략의 수렴이 부족합니다. 학습된 정책의 결론은 방향만 봅니다. 수치는 과제 전이를 예측하지 않습니다.
- 편향 절벽과 해석해 상한은 학습 방식과 무관한 결과라서 가장 믿을 만합니다.

### 4.5 기타 점검

- 본문 Table 5의 과제별 하이퍼파라미터(학습률 1e-5 대 3e-4, 할인율 0.95 대 0.99, L2 0 대 1.0)는 과제마다 다르고, 선택 방법이 없습니다. 재현할 때 과제별 탐색 예산을 따로 기록해야 합니다.
- 포즈 잡음 σ_p^max = 5 mm는 깊이 카메라 오차에 근거합니다(A.6). FoundationPose의 실측 오차 분포는 논문에 없습니다.
- 잔차 추론 0.06 ms(GPU)와 VLA 140 ms는 계산 비용이 작다는 주장을 뒷받침합니다. 실제 제어 주파수와 포즈 추적의 지연(18 ms, 비동기)이 제어 루프에 주는 영향은 측정하지 않았습니다.
