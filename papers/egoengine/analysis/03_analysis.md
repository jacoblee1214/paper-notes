# 03. 재계산과 일관성 검사

이 문서는 논문 표의 보고 값으로 평균, 구간, 검정을 다시 계산하고 표와 본문, 표끼리 맞는지 확인합니다. 재현 실험은 하지 않았습니다. 모든 계산은 `analysis/recompute.py`(수 초, scipy)이고 결과는 `analysis/recompute_results.json`입니다. 그래프는 `analysis/plot_figures.py`가 그립니다.

## 0. 시도 수(N)는 논문에 없다: 추정 방식

논문은 실로봇 시도 수, 시뮬 시도 수, 시드 수를 적지 않았습니다. 그래서 보고 값이 k/N으로 맞아떨어지는 N을 찾았습니다. 이것은 **추정**입니다.

- **표 3 (실로봇, 4 과제):** 보고 값 0.00–0.80이 모두 0.05의 배수입니다. 맞는 N은 20과 40뿐입니다 (`t3_denominator_candidates`). 이 문서는 **N = 20**을 씁니다. 표 4와도 맞습니다. 4 과제 x 20 = 80에서 0.025, 0.05, 0.425, 0.5125가 보고 값(0.03, 0.05, 0.43, 0.51)으로 반올림됩니다.
- **표 2 (시뮬):** TACO의 SR 0.17, 0.25, 0.83은 N = 12 또는 N = 64와 맞습니다. 본문의 "16쌍"으로는 0.17을 만들 수 없습니다. 16쌍에 쌍당 4회를 돌렸다면 N = 64일 수 있습니다 (V8). Aria의 SR 0.10, 0.20, 0.90은 N = 10 또는 20이고, Fig. 5의 "20 Aria demos"와 맞춰 N = 20으로 봅니다.

따라서 아래의 구간과 p 값은 모두 **추정 N에 조건부**입니다.

## 1. 재계산

### 1.1 실로봇 과제 성공률 (표 3, N = 20 추정)

Wilson 95% 구간과 EgoEngine 대 실로봇 Fisher 정확 검정(양측)입니다.

| 과제 | EgoEngine | 실로봇 teleop | 차이 (EgoEngine − 실로봇) | Fisher p | 판정 |
|---|---|---|---|---|---|
| Mustard | 8/20 = 0.40 [0.22, 0.61] | 16/20 = 0.80 [0.58, 0.92] | −0.40 | 0.022 | 실로봇이 더 높음 |
| Drawer | 7/20 = 0.35 [0.18, 0.57] | 16/20 = 0.80 [0.58, 0.92] | −0.45 | 0.010 | 실로봇이 더 높음 |
| Flower | 14/20 = 0.70 [0.48, 0.85] | 14/20 = 0.70 [0.48, 0.85] | 0.00 | 1.00 | 같음 |
| Hammer | 12/20 = 0.60 [0.39, 0.78] | 5/20 = 0.25 [0.11, 0.47] | +0.35 | 0.054 | 경계 (유의하지 않음) |
| 4 과제 합계 | 41/80 = 0.51 [0.40, 0.62] | 51/80 = 0.64 [0.53, 0.73] | −0.13 | 0.15 | 합계 차이는 유의하지 않음 |

- **V1. 본문의 "2 of 4 과제에서 같거나 더 높다" (§4.4):** 방향은 맞습니다. 하지만 Hammer의 우위는 p = 0.054로 경계입니다. 과제별 시도 수가 20이면 차이 0.35를 80%로 잡으려면 기준 0.5에서 0.4 이상이 필요합니다 (정규 근사, 아래 V2). Flower는 같은 값입니다.
- **V2. 검출력:** 기준 0.5 쌍 비교에서 차이 0.20, 0.30, 0.35, 0.40을 검출할 확률은 각각 약 0.25, 0.51, 0.67, 0.81입니다 (정규 근사, 두 비율, 양측 0.05, n = 20). 그래서 과제당 20회로는 차이 0.2–0.3 수준의 우위나 열세를 가리기 어렵습니다.
- **V3. 사람 영상과 Phantom 대 EgoEngine (합계):** 사람 영상 2/80, Phantom 1/80 대 EgoEngine 41/80입니다. Fisher p < 10⁻¹². 실로봇 없이 시각 변환만으로는 과제가 거의 안 된다는 주장은 강하게 지지됩니다.

### 1.2 어블레이션 (표 4, 4 과제 합계 80회 추정)

| 비교 | 성공 수 | Fisher p (양측) |
|---|---|---|
| 전체 EgoEngine 대 시각 분기만 | 41 vs 4 | 2.6 × 10⁻¹¹ |
| 전체 EgoEngine 대 행동 분기만 | 41 vs 34 | 0.34 |
| 전체 EgoEngine 대 사람 영상 | 41 vs 2 | 3.5 × 10⁻¹³ |

- **V4. 행동 분기가 핵심이라는 주장 (§4.4):** 시각 분기만 쓰면 0.05로 떨어지고 행동 분기만 쓰면 0.43입니다. 행동 분기가 주된 요인이라는 방향은 맞습니다.
- **V5. 시각 분기의 기여 (§4.4):** 행동 분기만 쓴 것과 전체의 차이는 0.08이고 p = 0.34입니다. 본문은 "작은 감소"라고 씁니다. 이 차이는 이 표로는 확정하지 못합니다. 논문의 "시각 분기가 추가 이득을 준다"는 서술은 방향만 말할 수 있습니다.

### 1.3 시뮬레이션 (표 2)

| 항목 | TACO | Aria |
|---|---|---|
| EgoEngine SR | 0.83 | 0.90 |
| H2S2R (RL) SR | 0.83 | 0.90 |
| 두 SR 차이 | 0 | 0 |
| Cost: H2S2R 대 EgoEngine | 73,675 대 34,842 (**52.7% 감소**) | 20,237 대 16,560 (**18.2% 감소**) |
| Cost: Spider(MPC) 대 EgoEngine | 7,923 대 34,842 (EgoEngine이 4.4배) | 4,382 대 16,560 (3.8배) |

- **V6. "성능은 같고 비용이 줄었다"는 해석:** 성공률은 두 데이터셋에서 RL과 같습니다. 개선은 비용입니다. 본문 §4.3의 "generation cost를 줄인다"와 맞습니다. 다만 Aria의 스텝 기준 절감은 18%이고, 본문 22%는 벽시계 기준입니다 (V7).
- **V7. 처리량 22.0%:** 2.88/2.36 − 1 = 22.03%로 맞습니다. 이것은 RTX 4090 한 대에서 **한 번 측정**한 벽시계 처리량입니다. 시드와 반복이 없어서 신뢰구간을 쓸 수 없습니다. 스텝 기준 Cost 표와 측정 단위가 다릅니다.
- **V8. 시뮬 SR의 시도 수:** TACO 16쌍에서 0.17을 만들 수 없습니다 (§0 참조). 쌍당 시도 수가 보고되어야 합니다.
- **V9. Cost의 정의:** Mink의 Cost 1.00은 정의상 값입니다 (재실행 없이 궤적을 그대로 쓰는 경우). 이 값을 다른 방법과 같은 척도로 비교하는 것은 맞지 않습니다.

### 1.4 시각 충실도 (표 1)

| 인코더 | EgoEngine 대 Phantom 차이 |
|---|---|
| ResNet18 | 614.7 대 620.0 (−0.85%) |
| VGG16 | 644.2 대 650.8 (−1.01%) |
| DINOv2 | 473.1 대 470.6 (+0.53%) |

- **V10. 주장 "FD를 줄였다":** ResNet18과 VGG16에서 1% 안팎입니다. 시료 수, 특징 개수, 부트스트랩 구간이 없으므로 이 차이가 의미 있는지 말할 수 없습니다. DINOv2에서는 Phantom이 조금 낫습니다. 본문은 "matches"라고 씁니다. 근소하게 다른 값을 같다고 보는 것은 약한 표현입니다.
- **V11. EgoMimic의 FD:** ResNet18에서 830.5로 사람 영상 764.5보다 나쁩니다. 마스크만 씌운 영상이 사람 영상보다 로봇 특징 분포와 더 멀다는 뜻입니다. 본문에서 이 점은 언급하지 않습니다.

## 4. 토이 검증을 하지 않은 이유

- 중심 주장 C2 (행동 분기가 핵심)와 C6 (비용)은 GPU 기반 MuJoCo Warp 학습과 시뮬 스텝 카운터에 의존합니다. CPU 토이로 같은 조건을 흉내 내면 논문과 다른 실험이 됩니다.
- C1과 C4는 실로봇 시도가 필요합니다.
- 그래서 이 저장소의 원칙(재현은 묻고 시작, GPU 재현 금지)에 따라 토이를 만들지 않았습니다. 재계산과 검정이 이 논문에서 할 수 있는 최대입니다.
