- **코드 상태 (2026-10-28):** AlphaNIST 공식 코드는 공개되지 않았습니다("심사·수정 기간 뒤 공개 예정", Sec. I). `alpha-nist` 조직에는 웹사이트 저장소만 있습니다. SGS 페이지도 "Code (coming soon)"입니다. 그래서 논문 ↔ 코드 대조 대신 아래 세 가지를 했습니다.

## 3. 자료 정합성 요약

- **맞는 것:** 39.3배 산술, 그림 5(a)와 5(b)의 정합(판독 ±0.7%p), 그림 6의 25K 값과 그림 5(b)의 세 막대, 본문의 dense 칸 값(45.0%, 93.6%), 그림 7의 본문 수치, Fig. 3 차원, OmniReset 계수의 실효값(0.01).

  - 그림 5(b) 분리 dense 막대의 checkpoint(C3).
  - 39.3배의 비교 기준(C2).
  - "17.8 ± 0.010%"(C6).
  - SGS의 보상 서술(C13)과 샘플링 식(C15).
  - dense 비교군과 OmniReset 보상의 구조 차이(C14).

## 4. 구현할 수 있는가

### 4.1 공식 코드를 그대로 쓰는 경우
**지금은 불가능합니다.** 코드가 공개되지 않았습니다. 공개되더라도 논문 규모는 64K 환경 = GPU 16장 × 약 26시간(410 GPU-h)이고, 256K = GPU 64장입니다. Isaac Lab(Linux, NVIDIA GPU)이 필요해 이 맥에서는 돌릴 수 없습니다.

### 4.2 독립 MuJoCo 구현(suniique/assembly-nist)을 쓰는 경우
- **장점:** MIT 라이선스이고 사전학습 checkpoint 5개(2.5K–12.5K iteration, 54 MB)가 있습니다. 시작 상태별 성공률을 보고하고, CPU 시뮬레이션(MuJoCo)이라 CUDA가 필요 없습니다.
- **평가:** 16 CPU 코어로 3,200 episode에 약 1시간입니다(README).
- **학습:** 기준 실행은 GPU learner 1장 + CPU worker 960개(약 30 노드) × 약 26시간입니다. README는 한 대에서 512 환경으로 작게 돌리는 방법도 적어 두었습니다.
- **이 맥의 장애물:** 접촉 플러그인(나사산·커넥터 SDF)이 x86-64 전용 빌드(`-mf16c`)라 Apple Silicon에서는 그대로 빌드되지 않습니다. half-precision 변환 부분을 ARM용으로 고쳐야 합니다(미확인). mujoco와 torch 설치도 필요합니다.
- **판단:** 사전학습 정책 평가는 **조건부 가능**합니다(플러그인 이식 + 설치 승인 필요, 맥 CPU 코어 수만큼 느림). 학습 재현은 이 맥 한 대로는 현실적이지 않습니다.

### 4.3 이 맥에서 바로 할 수 있는 것
| 작업 | 가능 여부 |
|---|---|
| 수치 재계산, 그림 판독, 샘플러·보상 toy | ✅ 완료 (numpy, 설치 없음) |
| SGS 커널과 식 4를 작은 학습 toy(예: 다중 과제 bandit, 사슬 MDP 묶음)에 넣어 비교 | ✅ 설치 없이 가능 |
| 독립 구현의 사전학습 checkpoint 평가 | 조건부 (플러그인 ARM 이식, mujoco·torch 설치) |
| Isaac Lab 기반 학습 | ❌ (CUDA 필요) |

### 4.4 아이디어를 다른 환경에 다시 구현하는 경우
| 구성 요소 | 난이도 | 메모 |
|---|---|---|
| 이진 보상 + 제어 비용 + 성공 시 종료 | 낮음 | 성공 판정(1 mm)만 정확하면 됩니다 |
| Beta 샘플러 | 낮음 | 수십 줄입니다. ε_q, L, 커널 지수를 명시하고 프런티어 비율을 기록해야 합니다 |
| reset bank(놓인 부품 ~ 부분 조립) | 중간 | 과제마다 유효한 중간 상태를 만드는 것이 일입니다(조립 역순, 파지 샘플링). OmniReset 코드(UWLab)가 참고가 됩니다 |
| 점군 관측 + SimBa actor·critic | 중간 | Fig. 3 구조는 명확하지만 n_pts와 이력 길이는 정해야 합니다 |
| 나사산·기어 접촉 시뮬레이션 | 높음 | 성능을 좌우합니다. 독립 구현도 접촉 수정 전에는 너트 성공률이 0%였습니다 |
| 수만 환경 규모 PPO | 높음 | 이진 보상의 이득은 규모에 크게 의존합니다(1K 38.6% → 8K 86.9%, 그림 7). 작은 규모로는 결과가 재현되지 않을 수 있습니다 |

**요약:** 알고리즘 자체(이진 보상 + reset bank + Beta 샘플링 + PPO)는 단순해서 재구현이 쉽습니다. 이미 독립 구현이 공개되어 비슷한 성공률을 보고했습니다. 어려운 부분은 정밀 접촉 시뮬레이션과 대규모 병렬 계산입니다. 이 맥에서는 샘플러·보상 설계를 toy로 검증하는 단계까지가 현실적이고, 정책 평가는 독립 구현의 플러그인을 ARM으로 옮겨야 가능합니다.
