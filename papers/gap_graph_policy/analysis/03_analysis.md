# 03. 수치 재계산, 일관성 검사, 토이 실험

모든 재계산은 `analysis/recompute.py`(수 초, 결과 `recompute_results.json`)에서 나옵니다. 토이는 `analysis/toy_accept_rule.py`(수 초)입니다. 논문 표·본문과 값이 달라 보이는 곳은 "무엇과 무엇이 다른지"로 적었고, 원인은 가능성으로만 씁니다. 저자 확인이 필요한 항목은 그렇게 표시했습니다.

## 0. 가정

- **표 1:** 칸당 task instance 100개(§5.2, 표 1 캡션). 이 시행 수는 논문에 있습니다.
- **표 3의 성공률:** 칸당 100개로 가정했습니다(논문에 시행 수 없음, "시행 수 100 가정").
- **그림 2, 3의 값**은 PDF를 300 dpi로 렌더링해 읽은 값입니다(그림 판독 값, 약 ±1 %p, 주기 시간은 ±1–2%).
- **표 2의 Pack Grocery Items (28/30, 10/30):** 6개 물건 × 5회 시행으로 읽을 수 있습니다. 물건 단위 시행이면 같은 시행 안의 물건이 서로 독립이 아닐 수 있어 Wilson·Fisher 구간이 좁게 나옵니다. 아래 값은 30개 독립 시행을 가정한 것입니다.
- 검정은 두 비율의 Fisher 정확 검정(양측), 구간은 Wilson 95%입니다. 칸 수가 많아도 다중 비교 보정은 하지 않았습니다(보정하면 p가 더 커집니다).

## 2. 토이 T1: 갱신 채택 규칙의 잡음 (`analysis/toy_accept_rule.py`)

**목적.** §4.2는 "새 task instance 100개에서 성공률이나 주기 시간이 떨어지는 갱신은 거부"한다고 씁니다. 이 규칙이 100개의 표본 잡음에서 얼마나 틀리게 채택하는지 계산합니다. 논문은 비교가 같은 100개에서의 쌍체인지 독립 측정인지 적지 않아 둘을 모두 계산했습니다.

**가정.** 후보 성공률 p + d(실제 효과 d), 인스턴스는 독립 베르누이이고, 측정 성공률(후보) ≥ 측정 성공률(현재)이면 채택합니다. 쌍체는 같은 난이도 난수를 공유하는 이상화(공통 난수)라 실제보다 유리한 상한입니다. 실제 갱신 효과 분포는 논문에 없어 N(−0.01, 0.06)과 N(0, 0.03)을 가정했습니다(가정).

| 현재 성공률 | 측정 방식 | d = −0.05 | d = −0.03 | d = −0.01 | d = 0 | d = +0.02 |
|---|---|---|---|---|---|---|
| 0.9 | 독립 100개씩 | 16.5% | 28.8% | 45.4% | 54.8% | 73.3% |
| 0.9 | 쌍체(상한) | 0.6% | 4.6% | 36.3% | 100%(동률 채택) | 100% |
| 0.5 | 독립 100개씩 | 25.9% | 35.7% | 46.7% | 52.2% | 63.3% |

- 독립 측정이면 성공률을 3 %p 떨어뜨리는 갱신이 p = 0.9에서 약 29%, 5 %p 떨어뜨리는 갱신이 약 17% 채택됩니다. 성공률 0.9 근처에서는 100개 표본의 표준편차가 약 3 %p라 작은 후퇴를 걸러내지 못합니다.
- 10번 반복 루프(`loop_K10`)에서 평균 4.7–6.2번이 채택되고, 독립 측정에서는 마지막 채택 갱신의 측정 성공률이 실제 값보다 0.4–2.2 %p 높습니다(예: 시작 0.3, 독립: 측정 0.433 대 실제 0.412). 쌍체에서는 거의 같습니다(0.485 대 0.484).
- **해석.** 이 계산은 논문의 결과가 틀렸다는 근거가 아닙니다. 그림 2, 3의 곡선은 반복마다 새 표본의 측정값이라 선택 편향이 작고(그림 2는 단조가 아니어서 선택된 최댓값을 그린 것도 아닙니다), 큰 이득(30% → 94%)은 이 잡음보다 훨씬 큽니다. 다만 성공률이 이미 0.95를 넘는 구간(그림 3의 후반 반복, 표 3의 0.97)에서는 채택 규칙의 비교 방식과 임계값이 최종 값에 영향을 줄 수 있어, 방식을 명시하는 것이 재현에 필요합니다.
- 한계: 토이의 갱신 효과 분포와 성공 모형은 임의의 가정이고, 실제 그래프 편집의 효과 분포와 인스턴스 간 상관은 알려져 있지 않습니다.
