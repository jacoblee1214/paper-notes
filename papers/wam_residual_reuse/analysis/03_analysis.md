## 2. 주요 대비 (V1, V2)

Table 1의 100상태 쌍체 대비를 불일치 개수에서 다시 계산했습니다(`a_only`, `b_only`는 저장소 `primary_contrasts`).

| 대비 | 성공률 A / B | 불일치 (A 전용 / B 전용) | 정확 McNemar p | Holm p |
|---|---|---|---|---|
| IDM 2스텝 대 10스텝 | 95 / 95 | 2 / 2 | 1.00 | 1.00 |
| IDM 2스텝 대 τ=8 캐시 | 95 / 63 | 35 / 3 | 6.7 × 10⁻⁸ | 7.3 × 10⁻⁷ |
| IDM 2스텝 대 감쇠 τ=8 | 95 / 81 | 17 / 3 | 0.0026 | 0.023 |
| IDM 감쇠 대 τ=8 | 81 / 63 | 25 / 7 | 0.0021 | 0.021 |
| IDM 2스텝 대 τ=2 캐시 | 95 / 97 | 2 / 4 | 0.69 | 1.00 |
| 원본 2스텝 대 10스텝 | 96 / 95 | 2 / 1 | 1.00 | 1.00 |
| 원본 1스텝 대 10스텝 | 93 / 95 | 1 / 3 | 0.62 | 1.00 |

- 11개 대비 모두 저장소 p와 소수점 여섯 자리까지 같습니다. 보정 후 유의한 것은 τ=8 캐시와 감쇠 캐시 대비(IDM)뿐이라는 논문 서술과 맞습니다.
- **Holm 보정의 순서**: 가장 작은 p(6.7e-8)에 11을 곱하고, 둘째 p(0.0021)에 10을 곱하는 식으로 계산합니다. 논문 Table A1 값과 같습니다.

## 3. 비열등 구간 (V3, 미검증)

논문은 "2스텝 대 10스텝, IDM 100상태 90% Tango 구간 [−4.1, 4.1]"을 씁니다. 이 구간은 3점 마진에서는 실패하고 5점에서는 성공한다는 주장의 근거입니다. 저장소 값을 인용했으나, 우리 독립 구현이 맞지 않아 이 주장은 **미검증**입니다. 500상태 IDM 구간 [−1.4, 1.8]도 원자료가 없어 확인하지 못했습니다.

## 4. 식 (1)과 캐시 비율 (V4)

`share(s, m, K=10) = 1 − s·u/(1+(s−1)·u)`, `u = 1 − m/10`. 논문 Table A2의 값과 비교했습니다.

- s=1, 8캐시 → 80.0 (논문 80). s=5, 8캐시 → 44.4 (44). s=3, 8캐시 → 57.1 (57). s=3, 9캐시 → 75.0 (75). s=5, 9캐시 → 64.3 (64). s=2, 7캐시 → 53.8 (54), 9캐시 → 81.8 (82).
- 같은 식은 저장소 `probes/fw_libero.py`의 `cached_path_fraction`과 같습니다(04 D1).
- **해석**: 식 (1)에서 큰 s는 높은 노이즈 쪽 스텝을 조밀하게 두므로, 같은 "스텝 개수"도 경로를 적게 덮습니다. 이것이 논문이 "스텝 세는 규칙은 샘플러에 따라 뜻이 바뀐다"고 말하는 이유입니다. 계산상 맞습니다.

## 5. 지연과 복합 캐시 (V5, V8)

**고정비와 상한.** 1–10스텝 최소제곱 적합(Table 1 기기)은 F = 66.7 ms, a = 13.51 ms, F/a = 4.93입니다. 원본은 4.83. 2스텝 호출에서 고정비 비중 F/(F+2a) = 70.8%입니다.

**복합 캐시(스텝 0만 캐시, τ=4)의 절감 상한.** 4번 중 3번에서 한 스텝을 건너뛰므로 `0.75a / (F/a + 2)`입니다.

| 기기 | F/a | 상한 | 논문 |
|---|---|---|---|
| Table 1 기기 (IDM) | 4.93 | 10.9% | 11% |
| follow-up 기기 (2스텝과 10스텝 적합) | 3.39 | 13.9% | 14% |
| CUDA 그래프 | 10.08 | 6.2% | 6% |
| τ → ∞ 극한 | - | 14.6–18.5% | 15–19% |

모두 맞습니다. 다만 이 계산은 "캐시 스텝의 비용이 0"이라고 가정한 상한입니다(§3 논문 자체도 그렇게 씀).

## 8. 기타 일관성

- 본문 "2스텝 94 ms, 10스텝 202 ms"와 초록 "202 → 92 ms"는 같은 기기에서 나온 값이고, 초록은 원본 체크포인트를 고릅니다(01 §4-6).
- "τ=2 캐시 재사용 호출 100 ms 대 2스텝 94 ms"는 저장소 `reuse_mean` 100.9 대 `ep_mean` 93.9와 맞습니다.
- 지연 실험의 "2스텝 대 10스텝 동기 루프 1.18배(594 대 702 ms)"는 702/594 = 1.18로 맞습니다.
- Table 1의 τ=8 캐시 평균 116 ms(IDM)와 120 ms(원본)는 저장소 `ep_mean` 115.7과 119.9와 맞습니다.
- 확인하지 못한 주장: 잔차 드리프트 56–66%, 65%, 85–97%(A.9)는 원자료가 필요해서 미검증입니다.

## 9. 정리

재계산 범위에서 논문 수치는 대부분 맞습니다. 불일치를 찾지 못했다는 뜻이 아니라, 우리가 확인한 범위에서는 맞다는 뜻입니다. 확인하지 못한 것은 (a) Tango 구간 (V3), (b) 500상태 결과, (c) 드리프트 수치, (d) 원본 쪽 80% 재샘플 값과 고정 값의 짝짓기(§01 §4-1)입니다.
