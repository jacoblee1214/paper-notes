# 01. 논문 분석: RL Token (arXiv:2604.23073)

> 대상: *RL Token: Bootstrapping Online RL with Vision-Language-Action Models*, Charles Xu, Jost Tobias Springenberg, Michael Equi, Ali Amin, Adnan Esmail, Sergey Levine, Liyiming Ke (Physical Intelligence).
> 원문: `paper/paper.pdf`(v2), 텍스트 `paper/paper.txt`. 인용은 절·식·그림·표 번호로 합니다. 페이지 번호는 v2 PDF의 13쪽 기준입니다.
> 학회: CoRL 2026 구두 발표(세션 O4). `conferences/corl2026/papers.json`에서 `presentation: oral`, `also_poster: true`, `in_official: true` 확인.

## 1. 한 문단 요약

사전학습 VLA(π0.6, VLM SigLIP 400M + Gemma 4B, 액션 엑스퍼트 860M, 그림 2 캡션)에 작은 인코더-디코더 트랜스포머를 붙여, VLA 내부 임베딩을 **2048차원 RL token** 하나로 압축합니다(식 (1)–(2)). VLA와 RL token은 얼린 뒤, 그 위에 **작은 actor-critic**(MLP 2–3층, 은닉 256 또는 512)을 올려 실로봇에서 오프폴리시 온라인 RL을 돌립니다. actor는 VLA가 낸 기준 행동 청크 ã를 입력으로 받고, β‖a−ã‖²로 기준에 묶입니다(식 (4)–(5)). 나사 설치, 지퍼 타이, 이더넷, 충전기 4과제의 **가장 정밀한 구간**에만 RL을 적용하며, 보고된 개선은 그 구간의 속도(최대 3배)와 성공률(예: 나사 20%→65%)입니다.

## 2. 문제 설정과 기여

- **문제:** 정밀 과제에서 VLA는 느리고(접근·후퇴·재시도 반복), 작은 실수가 실패로 이어집니다(§I). 전체 VLA를 온라인 RL로 고치는 것은 계산·샘플 비용이 커서 수 시간 안에 안 됩니다(§IV 도입부). 작은 모델로 RL을 하면 빠르지만 VLA의 일반화를 잃습니다(§I).
- **기여 (§I, §VII):** (1) VLA가 노출하는 "RL token"이라는 압축 읽기 표현, (2) 그 위의 경량 actor-critic과 기준 행동에 묶는 정규화, (3) 4과제 실로봇 실험. 저자가 말하는 핵심 설계는 세 가지입니다. RL token으로 상태를 압축하는 것, 청크 단위 행동(VLA의 행동 인터페이스와 맞춤, §II 세 번째 차이점), 잔차나 잠재 노이즈가 아니라 기준 행동을 직접 조건으로 주는 것(§II).

## 3. 방법

### 3.1 RL token 만들기 (§IV-A, 식 (1)–(2), 그림 2)

- VLA의 마지막 층 임베딩 z = f(s, ℓ; θ_vla), z₁:M (M≈ VLA 토큰 수). 학습 가능한 <rl> 임베딩 e_rl을 붙여 인코더 g_ϕ에 넣고, 마지막 위치 출력을 z_rl로 씁니다(식 (1)). 그림 2에 따르면 z_rl은 1×2048입니다.
- 디코더 d_ϕ와 선형 투영 h_ϕ가 z_rl과 이전 토큰으로 z̄ᵢ(stop-gradient)를 자기회귀 재구성합니다(식 (2)). 재구성 손실 L_ro를 시연 데이터 D에서 최소화합니다.
- 학습: VLA는 기본적으로 얼린 상태에서 ϕ만 학습합니다. α>0이면 VLA를 SFT로 함께 조정하고, 알고리즘 1의 3줄이 L_ro + αL_vla를 최소화합니다. 적응 단계는 과제당 2,000–10,000 그래디언트 스텝(부록 B)입니다.
- 해석: 재구성 병목이 "과제에 필요한 정보를 남긴다"는 근거입니다. 그런데 저자들은 RL token이 어떤 정보를 얼마나 담는지 직접 검사하지 않습니다. 근거는 ResNet-10으로 바꿨을 때 처리량이 50% 떨어진다는 ablation(Q3, 그림 7)뿐입니다.

### 3.2 RL token 위의 actor-critic (§IV-B, 식 (3)–(5))

- **입력:** x = (z_rl, s_p). s_p는 과제별 고유수용감각(관절 위치 또는 말단 자세, 부록 B).
- **Critic (식 (3)):** 청크 전이 (x, a₁:C, x′)에 대한 TD 목표를 씁니다. 목표 Q̂는 C단계 할인 보상과 γ^C·Q′(x′, a′)의 합입니다. 부록 B에 따라 TD3식 2개 Q의 최솟값을 씁니다. 식 (3)의 기호 γ, 목표 네트워크 ψ′는 본문에 있습니다.
- **Actor (식 (4)):** π_θ(a₁:C | x, ã₁:C) = N(μ_θ(x, ã), σ²I). σ는 고정된 작은 값(부록 B), 청크 길이 C=10(부록 B), 제어 주기 50 Hz, 행동 14차원이므로 청크는 140차원입니다.
- **Actor 목표 (식 (5)):** L_π(θ) = E[−Q_ψ(x, a) + β‖a−ã‖²], a ∼ π_θ, ã ∼ π_vla. 저자들은 β의 값을 본문에 쓰지 않습니다. 부록 B도 β를 주지 않습니다.
- **기준 행동 드롭아웃 (§IV-B 마지막 문단):** 배치 일부에서 ã를 0으로 바꿉니다. 부록 B는 50%라고 합니다. 목적은 actor가 ã를 그냥 베끼는 것을 막는 것입니다.

### 3.3 전체 루프 (§V, 알고리즘 1, 그림 3)

- **워밍업:** 기준 VLA로 N_warm 환경 스텝을 굴려 버퍼 B를 채웁니다(값은 본문에 없음).
- **롤아웃:** 청크 경계마다 VLA가 ã를 내고, actor가 a를 냅니다. 사람은 개입해 행동을 덮어쓸 수 있습니다. 개입 행동은 기준 자리에 저장됩니다(§V "Rollout").
- **저장 스트라이드:** 중간 시점까지 2스텝 간격으로 전이를 저장합니다. 부록 B에 따르면 1초에 약 25개 샘플이 생깁니다.
- **업데이트:** 버퍼에서 샘플링한 배치로 critic 2번, actor 1번을 갱신합니다(§V "Update"). 또 UTD(update-to-data) 비율 5를 씁니다. 두 설명이 같은 것인지 본문만으로는 확정할 수 없습니다. 알고리즘 1의 내부 루프 G는 "환경 스텝당"이 아니라 "청크 경계당"으로 읽힙니다. 이 모호함은 `03` §3의 샘플 산술에서 두 해석으로 나눠 계산합니다.
- **임계 구간 집중 (§V "Targeted improvement"):** 에피소드는 기준 정책으로 시작합니다. 사람이 중요한 시점에 RL로 넘깁니다. 성공·실패 신호도 사람이 줍니다. 테스트 때는 VLA를 짧게 더 미세조정해 전환 시점을 예측하게 합니다(사람 개입을 레이블로 씀).

## 6. 제거 실험 (Q3, 그림 7–8)

- 그림 7(처리량, 이더넷): 15분 시점에 RL ≈ 400, w/o Pass-Through ≈ 397, w/o RL token ≈ 157, w/o Chunk ≈ 128, w/o BC ≈ 0. 기준 정책은 약 148.
- 그림 8(성공률, 이더넷): 5분 시점 RL 약 0.94, w/o Chunk 약 0.86, w/o RL token 약 0.60, w/o Pass-Through 약 0.57. 15분 시점에는 w/o Pass-Through가 RL과 같이 1.0에 닿습니다.
- **해석 주의:** 제거 실험은 과제 하나(이더넷)에서, 점 4개(0·5·10·15분)로 그렸습니다. 시드 수와 신뢰구간은 없습니다. 저자들이 "best final performance"라고 쓴 w/o Pass-Through는 최종값에서 RL과 차이가 없습니다. 차이는 학습 속도와 실패 횟수에만 있습니다(그림 7 캡션, Q3). 따라서 "기준 행동 전달이 필수"라는 강한 주장은 과제 하나의 학습 곡선에서만 나온 것입니다.
- w/o BC Regularizer는 15분 내내 0입니다. β=0에서는 actor가 Q만 따라가다가 실패합니다(§VI-C Q3).

## 7. 질적 발견 (Q4, 그림 9)

- 이더넷에서 기준 정책은 접근·후퇴·재시도를 반복합니다. RL 정책은 한 번에 접근해 밀어 넣고, 실패해도 가볍게 흔들어 컴플라이언스를 씁니다.
- 이 행동은 시연에 없었고 온라인 탐색에서 나왔다고 저자들이 주장합니다(§VI-C Q4).
- 근거는 그림 9의 분포와 질적 영상 설명뿐입니다. 영상은 본 PDF에 없습니다.

## 8. 한계 (저자 명시 + 읽으며 찾은 것)

**저자가 말한 것 (§VII):** 보상 신호, 개입 수정, RL과 기준 정책 사이 전환에 사람 개입이 필요합니다. 보상 모델과 진행률 예측으로 줄이는 것은 향후 과제입니다.

**읽으며 찾은 것:**
- 과제 4개, 기반 VLA 1개(π0.6). 다른 로봇이나 다른 VLA에서의 일반성 검증은 없습니다. 로봇 플랫폼 사양은 본문에 자세히 없습니다(그리퍼 설계는 감사의 말에 언급).
- 임계 구간만 RL합니다. 전체 과제는 2과제에서만 평가하고, 그중에서도 조건이 더 어렵습니다.
- 학습 시간, 컴퓨트 사양(GPU 종류·시간)이 없습니다. "몇 분에서 몇 시간"이라는 주장은 로봇 시간만 셉니다. 사람의 시간(개입, 리셋, 레이블)은 포함되지 않습니다.
- 재현에 필요한 세부값(β, σ, N_warm, G, 워밍업 길이, 기준 VLA 미세조정 스텝의 과제별 값)이 본문과 부록에 없습니다.
- 처리량에서 "성공 수"와 "속도"가 섞입니다. 처리량 비(6–7배)는 성공률 증가와 속도 증가가 함께 든 값이라 "3배 속도"와 직접 같지 않습니다(`03` §2).
- HIL-SERL은 50 Hz 설정을 맞추지 못해 실패했다고 적혀 있습니다(부록 C). 기준선이 약하게 튜닝됐을 가능성이 있습니다. 이 점은 저자가 밝힌 것이고, 튜닝 조건은 확인할 수 없습니다.
- 그림 9의 이더넷 기준 중앙값 228스텝(4.6초)은 본문이 말하는 임계 구간 "250–1,000스텝(5–20초)"보다 짧습니다. 과제 설명과 실제 구간 길이가 어긋나는 부분입니다.
