## 1. Abstract (한 줄 요약과 주장)

**한 줄 요약:** 로봇손 손끝 밑에 6축 힘·토크 센서를 달고 사람이 손가락을 직접 잡고 움직이는 kinesthetic 시연을 받은 뒤, 측정한 접촉력만큼 관측 위치를 물체 쪽으로 밀어 넣은 **force-informed 위치 목표** x_f = x_o + k_f f를 행동으로 씁니다. 임피던스 제어로 이 목표를 추종하면 시연의 힘이 재현됩니다.

논문이 내세우는 기여는 두 가지입니다(Sec. I).

1. kinesthetic 시연에서 측정한 접촉력으로 force-informed 행동을 뽑는 데이터 수집 방법 DexForce. 이 행동으로 학습한 정책은 6개 과제 평균 76%이고, 관측 위치를 그대로 행동으로 쓰면 거의 0%입니다.
2. 정책 관측에 힘 정보를 넣는 절제 실험. 힘 관측은 성능을 해치지 않으며, 정밀성과 협응이 필요한 과제(AirPods 열기, 너트 풀기)에서 가장 크게 돕는다고 주장합니다.

## 2. Method

### 2.1 전체 구조 (Fig. 1–3)

```
Stage 1  kinesthetic 시연: 사람이 손끝 센서 위쪽을 잡고 두 손가락(엄지·검지)으로 과제를 수행
         기록 = 손끝 관측 위치 x_o,1..T, 접촉력 f_1..T (CoinFT, 손가락마다 6축)
         → force-informed 목표 x_f,t = x_o,t + k_f f_t   (식 3, k_f = 0.0045)
Stage 2  재생: 로봇이 x_f,1..T를 데카르트 임피던스 제어(식 1–2)로 추종
         기록 = 새 관측 위치 x*_o, 접촉력 f*, 모멘트 m*, 손목 카메라 영상 I (사람 손이 없는 장면)
학습     Diffusion Policy: 관측 = ResNet18 영상 특징 + 손가락별 f*, m* (proprioception 없음)
         출력 = x_f (force-informed 목표) → 같은 임피던스 제어기로 실행
```

### 2.2 임피던스 제어 (식 1–2)

손가락 하나의 데카르트 제어력은 F = k_p (x_d − x_c) − k_v ẋ_c(식 1)이고, 관절 토크 τ = Jᵀ F + g(식 2)로 명령합니다. 자유 공간에서 목표 궤적을 따라가도록 이득을 맞췄고 **k_p = 310, k_v = 2**입니다(v2에서 처음 보고된 값, 단위 표기 없음. N/m, N·s/m로 읽음).

### 2.3 force-informed 목표 (식 3)

식 1의 첫 항을 스프링으로 보고, 준정적 운동을 가정해 같은 모델로 목표를 계산합니다.

```
x_f = x_o + k_f f      (f: 손가락이 물체에 가한 힘, k_f: 손으로 맞춘 스칼라 "강성 계수")
```

시연 중 사람이 손끝으로 면을 세게 누르든 약하게 누르든, 관측 위치 x_o는 같습니다(Fig. 2). 그래서 x_o를 그대로 재생하면 힘이 재현되지 않습니다. x_f는 힘이 클수록 면 안쪽으로 더 들어가 있어서, 임피던스로 추종하면 그만큼 밀어 줍니다. 저자들은 식 3이 연한 접촉과 마찰을 모델링하지 않지만 많은 과제에서 충분했다고 씁니다. 모든 과제에서 **k_f = 0.0045**를 썼습니다.

**우리 계산:** 식 1과 식 3을 함께 쓰면, 강체 접촉에서 재생 힘은 시연 힘의 k_p·k_f = 310 × 0.0045 = **1.40배**입니다. 시연 힘을 그대로 재현하는 값은 k_f = 1/k_p = 0.0032입니다. v1은 K_f = (1/220)·I₃라고 썼는데, 이는 강성 220의 역수 꼴입니다(`03` §1).

### 2.4 정책 학습

CNN 기반 Diffusion Policy를 씁니다. 관측 지평 2, 행동 예측 16, 실행 8, 1000 epoch이고, 30 Hz로 기록해 10 Hz로 내려 학습합니다. 영상은 128²이고 grasp battery만 256²입니다. 관측에는 영상 특징과 Stage 2의 손가락별 힘·모멘트가 들어가고 **손가락 위치(proprioception)는 넣지 않습니다.** v1에는 proprioception을 넣으면 성능이 크게 떨어진다는 절제(v1 Fig. 9)가 있었는데, v2에서는 빠졌습니다(§4.2-3).

### 2.5 하드웨어 (Fig. 6)

Allegro Hand, 손목 RealSense D435(어안렌즈를 달아 손 작업공간 전체를 봄), 엄지와 검지 밑의 CoinFT 6축 힘·토크 센서 2개입니다. 사람이 편하게 시연할 수 있는 손가락이 두 개까지라서, 과제는 한 손가락(외부 접촉 활용)이나 두 손가락입니다.

## 3. Experiments

### 3.1 과제와 평가 (Fig. 4–5)

| 과제 | 내용 | 시연 수 | 부분 성공 기준 |
|---|---|---|---|
| slide cube | 한 손가락으로 큐브를 레일 위 목표 구역까지 밀기 | 80 | 없음 |
| reorient smiley | 한 손가락으로 육각 블록을 바로 세우기 | 60 | 뒤집었지만 방향이 틀림 |
| open AirPods | 두 손가락으로 케이스 열기 | 150 | 일부만 열림 |
| grasp battery | 얇은 카메라 배터리 집기 | 110 | 들었지만 못 잡음 |
| unscrew nut | 너트를 풀어 들기 | 80 | 풀었지만 떨어뜨림 |
| flip box | 상자를 옆으로 세우기 | 70 | 세웠지만 자립 못 함 |

시연은 합쳐 550개입니다. 과제마다 같은 무작위 초기 배치 30개로 모든 정책을 평가합니다. OOD는 unscrew nut(너트가 360–900° 더 감김)과 flip box(100 g 더 무거움) 두 가지입니다.

### 3.2 Q1: force-informed 행동이 필요한가 (Fig. 7)

| 과제 | force-informed (성공/부분/실패) | 관측 위치 (성공/부분/실패) |
|---|---|---|
| slide cube | 27 / 0 / 3 | 1 / 0 / 29 |
| reorient smiley | 25 / 4 / 1 | 0 / 2 / 28 |
| open AirPods | 17 / 8 / 5 | 0 / 0 / 30 |
| grasp battery | 22 / 3 / 5 | 0 / 0 / 30 |
| unscrew nut | 26 / 4 / 0 | 0 / 23 / 7 |
| flip box | 20 / 3 / 7 | 0 / 1 / 29 |

- 성공 137/180 = **76.1%**로 "평균 76%"가 맞습니다. 관측 위치는 1/180입니다. 과제마다 Fisher p ≤ 10⁻⁶ 수준입니다(`04` C1).
- **관측 위치 기준선은 원리상 실패하게 되어 있습니다.** 손끝이 이미 x_o에 닿아 있으므로, x_d = x_o로 두면 임피던스 제어가 내는 힘은 거의 0입니다. 그래서 이 비교는 식 3이 필요하다는 것을 보여 주지만, 다른 데이터 수집 방법(텔레옵, 힘 기반 기준선)과의 비교는 아닙니다. 연한 접촉에서는 x_o 안에 이미 변형이 들어 있어서 일부 힘이 남습니다(`03` §3).
- unscrew nut에서 관측 위치 정책이 23/30 부분 성공(풀기는 함)인 것은, 너트 모서리를 밀어서 돌리는 데는 큰 힘이 필요 없고 쥐어서 드는 데 필요하다는 저자 해석과 맞습니다.

### 3.3 Q2: 힘을 관측에 넣으면 (Fig. 8)

모든 정책은 force-informed 목표로 학습했고, 관측만 바꿨습니다. Fig. 7의 force-informed 정책과 Fig. 8의 RGB, F/T 정책은 여섯 과제 모두 같은 숫자라서, 같은 평가를 두 그림에 썼습니다.

| 과제 | RGB, F/T | RGB only | RGB, 0/1 | F/T vs RGB-only Fisher p |
|---|---|---|---|---|
| open AirPods | 17 | 1 | 1 | 8×10⁻⁶ * |
| unscrew nut | 26 | 11 | 16 | 1.4×10⁻⁴ * |
| slide cube | 27 | 17 | 15 | 0.0074 * |
| grasp battery | 22 | 17 | 10 | 0.28 |
| reorient smiley | 25 | 20 | 14 | 0.23 |
| flip box | 20 | 19 | 18 | 1.00 |
| flip box OOD | 13 | 8 | 8 | 0.28 |
| unscrew nut OOD | 15 | 11 | 15 | 0.43 |

(30회 중 성공 수, 우리 재계산)

- 화살표의 상대 변화율 16개(+1600%, +136%, +58.8% 등)는 모두 성공 수의 비율로 재현됩니다. * 표시 세 개는 Fisher 검정(v2)과 v1의 two-proportion z-test 모두에서 같고, Holm 보정 후에도 유지됩니다(`04` C2–C3).
- **"힘 관측은 해치지 않는다"는 점추정 기준입니다.** 8개 비교 모두 F/T가 RGB-only 이상이지만(부호 검정 p = 0.004), 과제별로 유의한 것은 3개뿐입니다. flip box는 20 대 19입니다.
- **"이진 접촉(0/1)은 RGB-only와 같거나 나쁘다"는 일부만 맞습니다.** 8개 중 나쁨 4, 같음 2, **나음 2**(unscrew nut 16 대 11, unscrew nut OOD 15 대 11)입니다. 6축 힘(F/T)이 이진 접촉보다 낫다는 것은 6개 과제 모두에서 맞습니다.
- OOD에서 RGB, F/T는 13/30, 15/30으로 "약 50%"는 43–50%입니다.

### 3.4 Q3: k_f에 얼마나 민감한가 (Fig. 9)

과제마다 시연 5개를 골라, k_f를 0.0045에서 시작해 0.0001씩 올리고 내리며 재생이 실패할 때까지 반복했습니다(상한 0.025). 막대는 성공한 k_f 범위의 평균 최솟값–최댓값이고, 오차 막대는 표준편차입니다.

| 과제 | k_f 범위 (판독) | 힘 배율 G = k_p·k_f | 최대/최소 비 |
|---|---|---|---|
| unscrew nut | 0.0018–0.0076 | 0.55–2.37× | 4.3 |
| open AirPods | 0.0021–0.0111 | 0.66–3.43× | 5.2 |
| slide cube | 0.0026–0.0118 | 0.82–3.66× | 4.5 |
| reorient smiley | 0.0010–0.0145 | 0.32–4.49× | 13.9 |
| grasp battery | 0.0006–0.0158 | 0.17–4.91×, 상한 절단 | 28.8 이상 |
| flip box | 0.0008–0.0216 | 0.24–6.69×, 상한 절단 | 27.3 이상 |

(픽셀 판독 오차 ±0.00012, 빨간 기준선 0.0045를 0.00458로 읽어 검증. `analysis/fig_digitize.py`)

- 저자 결론 세 가지 가운데 "k_f를 과제마다 맞출 필요가 없다"와 "0.0045가 모든 범위 안에 있다"는 판독값으로 확인됩니다.
- **힘 배율로 바꾸면 해석이 선명해집니다.** 가장 민감한 unscrew nut도 시연 힘의 0.55–2.4배를 허용합니다. 과제가 요구하는 것은 "정확한 힘"이 아니라 "4배 정도 폭 안의 힘"입니다. 힘을 그대로 재현하는 G = 1은 여섯 과제 모두 범위 안에 있습니다(`03` §2).
- 범위가 좁은 세 과제(nut, AirPods, slide)가 힘 관측 이득이 큰 세 과제와 같다는 관찰은, 순위 상관으로 보면 ρ = −0.89(정확 순열 p = 0.017, n = 6)라 뒷받침됩니다(`04` C6).
- grasp battery와 flip box는 최댓값의 평균 + SD가 sweep 상한 0.025를 넘습니다. 일부 시연이 상한에 걸린 절단값이라 실제 범위는 더 넓습니다.

## 4. Limitations

### 4.1 저자가 밝힌 한계
DexForce는 대규모 데이터 수집에는 맞지 않을 수 있다고 씁니다. 사람이 동시에 다룰 수 있는 손가락이 두 개뿐이고, 식 3은 연한 접촉과 마찰을 모델링하지 않습니다. 향후 과제로, 손 전체를 쓰면서 직접 촉각 피드백을 주는 다른 시연 방식을 들었습니다.

### 4.2 분석하면서 추가로 발견한 한계와 의문점
1. **k_f와 k_p가 스프링 모델과 맞지 않습니다.** 논문은 식 3을 "식 1과 같은 스프링 모델"로 정당화하지만, 보고된 값으로는 재생 힘이 시연 힘의 1.40배입니다(강체 접촉). 손으로 맞춘 값이라 틀린 것은 아니지만, 식 3의 근거(같은 스프링)와 실제 설정(1.4배 증폭) 사이를 설명하지 않습니다. v1의 1/220은 다른 강성에서 정한 값일 가능성이 있습니다(가설, `03` §1).
2. **기준선이 하나뿐이고, 원리상 실패하는 기준선입니다.** 관측 위치를 그대로 쓰면 임피던스 제어가 힘을 거의 내지 않습니다. 텔레옵이나 리타겟 데이터, 또는 compliance를 함께 학습하는 방법(인용한 Adaptive Compliance Policy[32])과의 비교는 없습니다.
3. **v2에서 proprioception 절제가 빠졌습니다.** v1 Fig. 9에서는 proprioception을 넣으면 AirPods 17 → 7, unscrew nut 26 → 8(Fisher p = 5×10⁻⁶)로 크게 떨어졌고, 저자들은 이를 causal confusion으로 설명하며 관측에서 뺐습니다. v2는 관측에 proprioception이 없다는 사실만 남기고 이유와 결과를 지웠습니다. 재구현할 때 가장 놓치기 쉬운 설계 선택입니다(`04` §2).
4. **Stage 2 재생의 수율이 보고되지 않았습니다.** 재생이 실패한 시연을 버렸는지, 몇 개를 버렸는지 알 수 없습니다. 데이터 수집 비용과 선별 편향에 영향을 줍니다.
5. **통계는 과제당 30회, 단일 학습 실행입니다.** 힘 관측의 이득이 유의한 과제는 6개 중 3개입니다. "never hurts"는 점추정입니다.
6. **k_f sweep의 비용이 큽니다.** 0.0001 간격으로 위아래 실패까지 재생하면, 평균 범위로 추정해 과제당 시연 5개 × 61–210회, 합계 약 3,700회의 실물 재생이 필요합니다(우리 추정, `04` C7). 시간이나 실제 시도 횟수는 보고되지 않았습니다.
7. **접촉 위치와 모멘트를 목표 계산에 쓰지 않습니다.** 센서가 손끝 밑에 있어서 모멘트로 접촉점을 추정할 수 있는데, 식 3은 힘 벡터만 씁니다. 모멘트는 정책 관측에만 들어갑니다.
8. **코드와 데이터가 공개되지 않았습니다.** 하드웨어 부품 자료만 있습니다.
