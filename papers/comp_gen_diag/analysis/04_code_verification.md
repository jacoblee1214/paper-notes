### 2.1 논문 주장의 코드 쪽 확인

- **손실 정의.** 흐름 매칭 손실은 선형 경로 `x_t = (1 − t)x_0 + t x_1`, 목표 속도 `x_1 − x_0`, 평균 제곱 오차입니다(`algorithms/flow_matching.py`). 논문의 "flow-matching loss"와 같습니다. 기본 GaussianPath, 최적수송 정규화 필드(`ot_reg`) 등은 설정 필드로 있으나 프리셋은 `linear` 경로를 씁니다.
- **지시 토큰이 범주형 ID.** 지시는 슬롯별 임베딩 표(어휘 4)입니다. 새 조합은 "임베딩 3개의 낯선 결합"이지 낯선 문장이 아닙니다. 따라서 이 코드로 얻은 결과는 언어 지시를 쓰는 VLA의 조합 일반화와는 직접 연결되지 않습니다. 논문의 한계 절도 VLA로의 확장을 후속 과제로 둡니다.
- **ID/OOD 분할 규칙.** 코드는 방문한 학습 과제와 분할이 일치하지 않으면 거부하도록 만들어 평가 라벨을 보호합니다. 이 보호가 사전학습 기준 OOD(그림 6)를 막는 점이 D6입니다.
- **2S-PP 성공 정의.** `EpisodeProgress.update`: `infer_cont0`에서 첫 배치는 c2가 아닌 어떤 컨테이너든 허용하고, o1이 c2에 들어가면 위반을 래치하며, 최종 성공은 `stage1_done and not violation`입니다. 논문의 "c1 ≠ c2를 만족하는 어떤 첫 배치도 허용"과 일치합니다. 평가는 시도마다 시뮬레이터의 첫 목표 컨테이너를 유효한 세 값에 순환 배정합니다(25회 기준 9/8/8회).

## 3. 저자 감사 문서의 요지

`docs/validation/paper-release-audit.md`가 스스로 적은 남은 일입니다(저장소 내용이며, 위의 D에 반영함).

- PP/PPP 커버리지 스윕: 정확한 과제 설계 추출, 고정 시연 배분, 시드 목록, 전체 실행 행렬, 결과가 공개되어야 함. `example_*` 프리셋은 일부만.
- 본 쌍 수별 성공, 과제별 히트맵, 그림 생성: 추가 필요.
- 희소 사전학습과 파인튜닝: 대각→전체/직교 행렬, B6/B8/B16 사전학습, 처음부터 학습 대조, 16/32시연 직교 대조 추가 필요. 사전학습 기준 분할 필요.
- 36과제 평가 집합: 별도 구현 필요 (48과제와 혼용 금지).
- 위반율 조건부 정의, 첫 배치 이벤트 기록, 분모와 분자 수 기록 필요.
- 오프라인 손실 1,000개 의미 정의 필요.
- 사람 시연(Isaac Lab) 환경과 데이터 또는 범위 제외 명시.
- 체크포인트, 결과 JSON/CSV, 평가 명령 공개. 코드 라이선스 선택.
- 데이터셋 3개 리비전은 "관찰된 리비전이지 논문 데이터 버전으로 인증된 것이 아님". 옛 파일럿의 PPP 풀은 63과제, 이후 기준선은 64과제로 기록.
