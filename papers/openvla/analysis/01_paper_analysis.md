## 1. 문제와 주장

- **문제.** 로봇 정책은 학습 데이터 밖의 물체, 배경, 지시문에 약합니다. 인터넷 규모로 사전학습된 VLM을 로봇 행동 생성에 쓰는 VLA는 RT-2-X(55B, 닫힌 모델)가 최신이지만, 공개되지 않아 채택이 어렵고 새 로봇에 맞춘 효율적인 미세조정 방법도 충분히 연구되지 않았습니다(Abstract, §1).
- **주장 세 가지.** (1) 970k 에피소드(OXE 큐레이션)로 학습한 7B 모델 OpenVLA가 BridgeData V2 WidowX 17과제와 Google 로봇 12과제, 합계 29과제에서 RT-2-X보다 절대 성공률 16.5%p 높다. (2) 10–150회 시연으로 새 로봇에 미세조정하면 Diffusion Policy보다 평균이 20.4%p 높다. (3) LoRA와 양자화로 소비자 GPU에서 미세조정과 추론이 가능하고 성공률 손실이 없다(§5.3, 5.4).
- **기여.** 모델 가중치, 미세조정 노트북, PyTorch 학습 코드(RLDS 데이터 파이프라인 포함), HuggingFace 연동(§1 마지막 문단).

## 2. 방법

### 2.1 모델 구조 (§3.1, 그림 2)

- **백본.** Prismatic-7B VLM. 시각 인코더 두 개(SigLIP와 DINOv2)의 패치 특징을 채널 방향으로 이어 붙이고(약 600M), 2층 MLP 프로젝터로 Llama 2 7B의 임베딩 공간에 맞춥니다.
- **행동 출력.** 연속 행동을 256개 빈으로 이산화하고, Llama 어휘에서 가장 적게 쓰는 마지막 256개 토큰을 덮어씁니다(§3.2). 학습은 행동 토큰의 교차 엔트로피만 계산하는 다음 토큰 예측입니다.
- **입력.** 단일 시점 RGB 이미지 한 장과 지시문 한 문장(§6의 한계로 명시). 해상도 224×224.

### 2.2 행동 토큰화 (§3.2)

- 각 행동 차원을 학습 데이터의 1st–99th 분위수 구간으로 정규화한 뒤 256개 균일 빈으로 나눕니다. 최소-최대 대신 분위수를 쓰면 이상치가 빈 간격을 넓히지 않습니다(§3.2).
- Llama 토크나이저는 새 토큰 100개만 예약하므로 256개가 모자랍니다. 그래서 "마지막 256 토큰 덮어쓰기"를 택했습니다(Brohan et al. 방식, §3.2).

### 2.3 데이터 (§3.3, 부록 A, 표 3)

- OXE 전체(70개 이상 데이터셋, 2M 궤적 이상)에서 3인칭 카메라가 있고 단일 팔 엔드 이펙터 제어인 조작 데이터만 씁니다. 가중치는 Octo의 혼합을 따르고, 학습 후반에는 DROID를 빼는 일정을 택했습니다(§3.3, 표 3 각주 6).
- 표 3의 비율(Fractal 12.7%, Kuka 12.7%, Bridge 13.3%, DROID 10.0% 등)이 최종 학습의 샘플링 비율입니다. 재현은 `04` D4–D5에서 다룹니다.

### 2.4 설계 결정 (§3.4, 부록 D)

- **백본 선택.** IDEFICS-1, LLaVA, Prismatic을 BridgeData V2 소규모 실험으로 비교했습니다. LLaVA는 IDEFICS보다 다중 객체 언어 근거화에서 35%p 높았고, Prismatic은 LLaVA보다 약 10%p 높았습니다(§3.4). 이 수치는 소규모 실험이라 논문에 표로 실리지 않았습니다.
- **해상도.** 224와 384의 성능 차이가 없었고 384는 학습이 3배 걸려 224를 택했습니다(§3.4).
- **시각 인코더 미동결.** 일반 VLM 관행과 달리 인코더를 미세조정하는 것이 필수였다고 씁니다(§3.4, 부록 D.3, 표 10).
- **학습 길이.** 27 epochs를 돕니다. 실로봇 성능이 행동 토큰 정확도 95%를 넘을 때까지 계속 올랐다고 씁니다(§3.4).
- **학습률.** 고정 2e-5, 워밍업 없음(§3.4).

### 2.5 인프라 (§3.5)

- 64 × A100, 14일, 21,500 A100-시간, 배치 2048. 추론은 bfloat16에서 15 GB, RTX 4090에서 약 6 Hz(컴파일과 추측 디코딩 없음)라고 씁니다. 6 Hz는 본문 값이고, 이 분석에서는 측정하지 않았습니다.
- 원격 추론 서버를 공개 코드에 넣었습니다(§3.5, §4).

## 3. 실험과 수치

공통 설계: 모든 방법을 같은 과제와 같은 초기 상태에서 평가하는 A/B 평가입니다(§5.1). 표 4와 6의 부분 점수(0.5)를 허용합니다.

### 3.1 BridgeData V2 WidowX (§5.1, 그림 3, 표 4)

- 17과제 × 10회 = 170회. 과제는 시각 일반화 5, 움직임 2(높이 변화 포함), 물리 3, 의미 4, 언어 근거화 3으로 나뉩니다(표 4 범주).
- 평균 성공률: OpenVLA 70.6 ± 3.2%, RT-2-X 50.6 ± 3.5%, Octo 20.0 ± 2.6%, RT-1-X 18.5 ± 2.7%.
- 논문 해석: RT-2-X는 의미 일반화에서 OpenVLA보다 높습니다(38.8 대 36.2%, 재계산). 나머지 범주에서는 OpenVLA가 높거나 비슷합니다.
- 부록 C: BridgeData 원본의 첫 전이가 모두 0 행동이라, 학습 시 첫 전이를 뺐습니다. RT-2-X는 이 전처리 없이 학습되어 정지 현상이 나타났고, 이 전처리 차이도 격차의 원인으로 꼽습니다.

### 3.2 Google 로봇 (§5.1, 그림 4, 표 6)

- 12과제 × 5회 = 60회(in-distribution 5과제, OOD 7과제).
- 평균: OpenVLA 85.0 ± 4.6%, RT-2-X 78.3 ± 5.4%, RT-1-X 33.3 ± 6.1%, Octo 26.7 ± 5.8%. 논문은 OpenVLA와 RT-2-X가 "비슷하다"고 씁니다.

### 3.3 Franka 미세조정 (§5.2, 그림 5, 표 7, 부록 B.3)

- 테이블탑 6과제 + DROID 1과제, 시연 10–150회. 테이블탑 99회, DROID 30회 = 129회.
- 테이블탑 평균(시도 가중): OpenVLA 67.2 ± 4.0%, DP 48.5 ± 4.9%, DP(matched) 43.4 ± 4.7%, Octo 43.4 ± 4.4%, OpenVLA 처음부터 43.4 ± 4.6%.
- DROID 평균: OpenVLA 58.3 ± 7.2%, Octo 38.3 ± 8.5%, DP 35.0 ± 8.0%.
- 논문 해석: 단일 지시 과제(당근 넣기, 옥수수 붓기)는 DP가 강하고, 다중 지시 과제는 OpenVLA와 Octo가 강합니다. 초록의 "20.4%p"는 이 표의 어떤 집계와도 맞지 않습니다(`03` §2).

### 3.4 파라미터 효율 미세조정 (§5.3, 표 1, 표 8)

- 테이블탑 두 과제(당근, 판 위로 옮기기), 33회.
- 전체 미세조정 69.7%, LoRA r=32 68.2%(학습 파라미터 1.36%), r=64 68.2%, 샌드위치 62.1%, 비전 동결 47.0%, 마지막 층만 30.3%.
- 논문 해석: 마지막 층 또는 비전 동결은 나쁘고, 샌드위치와 LoRA는 전체 미세조정과 비슷합니다. LoRA는 A100 한 장에서 10–15시간이라 전체 미세조정(8장 5–15시간)보다 약 8배 적은 계산이라고 씁니다.

### 3.5 양자화 추론 (§5.4, 표 2, 표 5, 표 11)

- 8과제 × 10회 = 80회, 비차단(5 Hz 비차단 제어) 기준.
- bfloat16 71.3 ± 4.8%, int8 58.1 ± 5.1%, int4 71.9 ± 4.7%. int8의 감소는 추론 속도(A5000에서 1.2 Hz) 때문이라고 설명합니다.
- 부록 D.4(표 11, 차단 제어): bfloat16 70.0, int8 74.4, int4 68.8. 차단 제어에서 int8의 감소가 사라져 속도 가설을 지지한다고 씁니다.

### 3.6 절제 (부록 D, 표 9, 표 10)

- **OpenX 사전학습 (D.1).** 같은 Prismatic VLM을 BridgeData만으로 미세조정하면 OpenVLA 76.3%에서 45.6%로 떨어집니다(8과제 × 10회).
- **DINOv2 추가 (D.2).** SigLIP만 쓰면 40.6%입니다. 논문은 5%p 감소이며 OpenX만큼 크지 않다고 씁니다.
- **시각 인코더 동결 (D.3, 표 10).** SigLIP와 LLaVA 두 백본에서 동결 대 미세조정. 논문 문장: 같은 조건에서 미세조정 80.0% 대 동결 46.7%.

### 3.7 LIBERO 시뮬레이션 (부록 E, 표 12)

- 네 스위트 × 3 시드 × 500회 = 스위트당 1,500회. OpenVLA 미세조정 평균 76.5%, Octo 75.1%, DP 72.4%.
- 순위 평균: OpenVLA 1.5, Octo 2.0, DP 2.5. 논문은 격차가 실로봇보다 작다고 씁니다(domain gap).

## 4. 한계 (논문 §6과 우리 관찰)

논문 §6이 드는 한계:

1. 단일 이미지 입력만 씁니다. 고유감각, 다중 시점, 관측 이력이 없습니다.
2. 추론 속도가 느려 ALOHA 같은 50 Hz 제어에 맞지 않습니다. 행동 청킹이 없습니다.
3. 신뢰도가 90% 아래입니다("typically achieving <90% success rate").
4. 큰 VLM, 공동학습, 시각 특징 선택 같은 설계 질문은 계산 제약으로 다루지 못했습니다.

이 분석에서 추가로 본 한계:

5. **최종 모델 설정이 공개 코드와 다릅니다.** DROID 일정과 학습 길이(D3, D4).
6. **표 1·2(PEFT, 양자화)는 최종 모델이 아니라 v0.1(Octo 혼합, SigLIP 단일 인코더) 모델입니다**(§5.3 각주 4). 결과를 공개 flagship으로 옮길 때 주의가 필요합니다.
7. **통계 검정력이 낮습니다.** 과제당 5–10회이고, 실로봇 Franka 표 8은 33회입니다. 차이가 작은 비교(Google, 양자화 4-bit, LoRA 대 전체)는 "차이 없음"을 증명하지 못합니다(`03` §3).
8. **보고된 평균이 판본과 표 사이에서 흔들립니다.** 같은 bfloat16 정책이 76.3%(표 4와 9), 71.3%(표 2와 5), 70.0%(표 11)로 나옵니다(`03` §4 C18).

## 5. 읽을 때 주의할 점

- 표 4, 6, 7은 평균 옆의 ± 값이 어떤 공식인지 논문이 밝히지 않습니다. 재계산 결과 n=170 이항 표준오차보다 8–15% 작습니다(`03` §2).
- "29과제 16.5%p"는 시도 가중 평균입니다. 과제 가중으로 계산하면 14.5%p입니다(`03` §2.2).
- 인용 시 판본(v3)과 표 번호를 함께 적습니다. 본문 번호는 v1과 v3에서 다릅니다(v1 표 5 = v3 표 6 등).
