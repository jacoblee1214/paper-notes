## 3. 재현에 필요한데 논문에 없는 것

- **특권 입력의 정의:** 그림 2는 특권 인코더 입력을 질량, 무게중심, 마찰, 자세, 모터 세기로 그리고, 그림 3과 §4.2는 잡음 낀 물체 자세와 형상만 적습니다(`03` K14). PTLD 교사가 실제 셀에서 받는 입력이 후자라고 읽히지만 한 줄 명시가 없습니다.
- **시뮬레이션:** 병렬 환경 수, 총 스텝, GPU 종류와 학습 시간, PPO 하이퍼파라미터, c_latent와 L_latent의 노름, 잠재 차원(회전 정책), 관측 잡음 모델, 도메인 랜덤화 범위(RMA [11] 설정을 따른다고만 함, §5.1).
- **촉각 증류:** 인코더 층 수·채널 수, 배치·에폭, 손실 가중치, 증강, 학습 곡선, DAgger 혼합 비율(β), 각 반복의 데이터 크기와 선택 규칙.
- **실제 로봇:** 제어기 이득, 정책 출력의 변환, 촉각 필터링(기준 신호 차감만 적힘), 마커·FoundationPose 잡음 수준과 지연, 안전 종료 조건, 에피소드 상한(그림 6의 120 s 외).
- **평가:** 물체별·방향별 시행 수, 평가 물체 목록, ± 의 정의, 표 1–3의 시행 수, 시드.

## 4. 구현할 수 있는지 (이 맥: Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)

**판정: 논문 시스템의 구현과 재현은 이 맥에서 불가능합니다. 방법의 부품 일부와 소형 장난감 검증은 이 맥에서 가능합니다.**

| 구성 | 이 맥에서 | 필요한 것 |
|---|---|---|
| 보고 수치 재계산 (표 1–4, 그림 6 판독) | **완료** | numpy, scipy (`analysis/recompute.py`) |
| 시뮬 RL (AAC + L_latent, 손 안 회전·재배향) | **불가** | IsaacGym(논문 [57])은 NVIDIA GPU(CUDA) 전제이고 관련 IsaacGymEnvs 저장소는 보관(archived) 상태. 병렬 수천 환경 학습. CPU MuJoCo로 옮기는 재구현은 가능하나 표본 효율 때문에 며칠–주 규모로 보임(추정, 측정 전) |
| 촉각 인코더(1D conv + MLP, 트랜스포머) 학습 | **코드는 가능, 데이터가 없어 불가** | 입력 368×6 × 50스텝, 학습 대상 약 180분 × 100 Hz ≈ 108만 스텝 (원시 프레임만 저장해도 fp32 약 9.5 GB). 공개 데이터 없음 |
| L_latent 손실 구현과 작은 비대칭 액터-크리틱 장난감 | **가능** | torch(이 맥의 CPU/MPS), 수 분 (아래 제안) |
| 특권 센서 셀 (카메라 4대, ArUco, GTSAM PGO) | **불가** | RealSense D435 4대, 보정, 마커, 물체 |
| 실로봇 평가 | **불가** | Franka Panda, Allegro 손, Xela uSkin 18패드(368 센서), ROS2 |

- **노력 추정(측정 전):** 손실과 인코더 구현은 며칠, 단일 단계 AAC 시뮬 정책은 HORA류 코드를 기반으로 한 기준으로 1–2주, 실제 셀 구축과 증류 데이터 수집·평가(정책당 약 180분 데이터)는 하드웨어가 있다는 전제에서 수주입니다.
- **의존 자원 요약:** GPU(시뮬 학습), 로봇 셀과 촉각 센서(증류 데이터), 공식 코드와 데이터 공개 여부. 이 셋 중 이 맥에서 얻을 수 있는 것은 없습니다.
- 재현 실험은 하지 않았습니다. 장난감 검증은 제안만 합니다.

## 5. 제안: 이 맥에서 할 수 있는 작은 검증 (미실행)

- **장난감 1: 증류.** 숨은 상태(예: 물체 각도)를 특권 센서가 정확히 주고, 촉각 대용 센서가 접촉 상태에서만 부분 정보를 주는 1차원 회전 환경에서 (1) 고유수용만, (2) 고유수용 + 촉각 대용, 학생이 특권 잠재를 MSE로 따라가는 증류 효과를 DAgger 0회·1회·3회로 비교. 목적은 C3·C14·C7의 구조 시험이며 논문 수치의 재현이 아닙니다. 2분 이내 torch CPU.
- **장난감 2: 홀짝·정수 정합성 도구.** 표 4와 같은 ±표기를 n별로 검사하는 `analysis/recompute.py`의 함수는 이미 있습니다. 저자 원자료가 나오면 같은 틀로 순위 검정과 부트스트랩을 할 수 있습니다.
