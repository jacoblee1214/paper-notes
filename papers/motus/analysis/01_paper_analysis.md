## 1. 질문

로봇 기반 모델은 지금 다섯 가지 분포를 따로 학습합니다 (§1, §3 원문): VLA `p(a_{t+1:t+k}|o_t,ℓ)`, WM `p(o_{t+1:t+k}|o_t,a_{t+1:t+k})`, IDM `p(a|o_{t:t+k})`, VGM `p(o|o_t,ℓ)`, 영상-행동 결합 예측 `p(o,a|o_t,ℓ)`. 저자들의 질문은 두 가지입니다 (§3, Challenge 1·2).

1. 이 다섯 가지를 **하나의 생성 모델**로 묶을 수 있는가. UWM [64]은 처음부터 학습하거나 작은 사전학습 모델을 써서 VLM의 시각-언어 이해와 VGM의 물리 사전지식이 빠진다고 봅니다.
2. 행동 라벨이 없는 인터넷 영상과 사람 시연 영상을 행동 전문가 사전학습에 쓸 수 있는가. 로봇마다 행동 공간이 달라서 직접 쓸 수 없습니다.

## 2. 방법

### 2.1 구조: 세 전문가 + Tri-model Joint Attention (§4.1, Fig. 1)

- **영상 생성 전문가**: Wan 2.2 5B (VGM). 원래 Wan의 self-attention 문맥을 확장해 세 전문가의 토큰이 함께 주의를 받습니다.
- **행동 전문가**: 같은 깊이(30층)의 Transformer 블록. AdaLN으로 rectified-flow 시간을 주입합니다 (Table 11: hidden 1024, 641.5M).
- **이해 전문가**: Qwen3-VL-2B의 마지막 층 토큰을 입력으로 받는 블록 (hidden 512, 253.5M). VLM 본체는 Stage 2에서 동결합니다 (Table 1, 공식 설정 `frozen: true`).
- 세 전문가의 multi-head self-attention 층을 이어 붙인 것을 "Tri-model Joint Attention"이라 부릅니다. 전문가마다 FFN과 정규화는 따로 둡니다. 총 약 8B 파라미터 (Table 11).

### 2.2 UniDiffuser형 스케줄러 (§3, §4.1, Supp. §7, Alg. 1–6)

영상 시간 τ_o와 행동 시간 τ_a를 **독립적으로** 샘플합니다 (Alg. 1, 식 `l_action`, `l_obs`). 추론 때 두 시간을 어떻게 고르느냐에 따라 같은 모델이 다른 모드가 됩니다.

| 모드 | 깨끗하게 두는 것 | 복원하는 것 | 원문 |
|---|---|---|---|
| WM | 행동 (τ_a=0) | 영상 | Alg. 3 |
| IDM | 영상 (τ_o=0) | 행동 | Alg. 4 |
| VGM | 행동 노이즈 유지 | 영상 | Alg. 2 |
| VLA | 영상 노이즈 유지 | 행동 | Alg. 5 |
| 결합 예측 | 둘 다 노이즈에서 복원 | 영상+행동 | Alg. 6 |

### 2.3 Action-Dense Video-Sparse 예측 (§4.1, Fig. 2)

영상 프레임은 행동보다 드물게 샘플합니다. 원문은 "예: 영상 프레임 속도를 행동의 1/6로" 라고 씁니다. 토큰 수를 맞추려는 목적입니다 (영상 토큰이 많아 행동 토큰이 묻히는 문제를 줄임).

### 2.4 잠재 행동 (§4.2, Fig. 3)

1. DPFlow [33]로 광학 흐름을 계산하고 RGB 이미지로 바꿉니다.
2. DC-AE [13] 기반 변분 오토인코더가 흐름을 512차원 토큰 4개로 압축합니다. 이를 가벼운 인코더로 **14차원 잠재 행동**으로 투영합니다 (로봇 행동 차원 14와 맞춤).
3. 학습 손실 식 (2): `L = L_recon + λ_a ||a_real − a_pred||² + β L_KL` (λ_a=1.0, β=1e-6, Table 11).
4. 데이터의 90%는 라벨 없이 재구성만, 10%는 약한 행동 지도(작업 무관 데이터 포함)를 씁니다 (§4.2).

### 2.5 학습 파이프라인과 데이터 피라미드 (§4.3, Table 1, Table 12, Fig. 4)

| 단계 | 데이터 (피라미드 층) | 학습 대상 |
|---|---|---|
| Stage 1 영상 학습 | 1 웹(사전학습 VGM·VLM), 2 사람 영상, 3 합성, 5 다로봇 | VGM만 |
| Stage 2 잠재 행동 사전학습 | 2, 3, 4 작업 무관 (AnyPos 방식, Curobo로 수집), 5 | Motus 전체 (VLM 동결) |
| Stage 3 대상 로봇 SFT | 6 대상 로봇 궤적 | Motus 전체 (행동 라벨) |

Table 12 데이터 크기: Egodex 230,949 (사람), AgiBot 728,209, RDT 6,083, RoboMind 9,589 + 7,272, **RoboTwin 27,500 (Level 3, 합성)**, 작업 무관 1,000, 자체 수집 2,000. 학습 설정은 Table 13 (배치 256, AdamW, GPU 시간 약 8000 / 10000 / 400).

## 3. 실험

### 3.1 RoboTwin 2.0 시뮬레이션 (§5.2, Table 2, Table 14, Fig. 6)

- 50개 과제, 청정(clean)과 무작위화(randomized) 두 설정, 과제당 100회 실행 (§5.2).
- 학습: 청정 과제당 50개(2500개) + 무작위화 과제당 500개(25000개)를 **하나의 다중 과제 모델**로 학습. 모든 모델을 RoboTwin 데이터에서 40k 스텝 미세조정 (§5.2).
- Table 14 평균 (재계산 일치): π0.5 42.98 / 43.84, X-VLA 72.8 / 72.84, Motus 88.66 / 87.02 (clean / randomized).

### 3.2 실세계 (§5.3, Table 3–5, Fig. 5)

- 두 플랫폼: AC-One, Agilex-Aloha-2 (양팔). 과제는 14개입니다 (표 3 기준 AC-One 9개, Agilex-Aloha-2 5개).
- 과제당 학습 궤적 100개, 다과제 공동 학습, 부분 성공률 (subtask 점수 합).
- 비교 대상은 π0.5와 w/o Pretrain (처음부터 학습) 뿐입니다. X-VLA는 실세계에 없습니다.
- 평균: AC-One π0.5 14.79 → Motus 63.22 (+48.43 점), Agilex π0.5 48.60 → Motus 59.30 (+10.70 점). 초록의 "+11~48%"는 이 **절대 점수 차**입니다 (상대 증가율이 아님).

### 3.3 절제 (§5.4, Fig. 6)

RoboTwin randomized 평균: w/o Pretrain 77.00 → Stage 1만 81.86 → Stage 2 포함 87.02. 청정은 77.56 → 82.26 → 88.66.

### 3.4 부가 평가 (부록 §8)

- LIBERO-Long (Table 9): Motus 97.6, X-VLA 97.6, OpenVLA-OFT 94.5 (**LIBERO-Long 10개 과제만**).
- VLABench (Table 10): 3과제 × 2 트랙, 단일 모델 미세조정.
- 모드별 성능: IDM 행동 MSE 0.014 (Table 7, ResNet18+MLP 0.044, DINOv2+MLP 0.122), VLA 모드 83.90, 결합 모드 87.02 (Table 8), 세계 모델 생성 FID 11.2, FVD 61.2 (Table 6).

## 4. 강점

1. **하나의 모델로 다섯 모드**라는 설계 주장이 구체적입니다. 모드마다 알고리즘 표(Alg. 2–6)가 있고, 독립 타임스텝이 왜 필요한지(§3, UniDiffuser 계열)를 설명합니다.
2. 절제가 단계별로 있습니다 (Fig. 6, 표 4–5). 사전학습이 실제로 도움이 된다는 증거가 청정·무작위 설정에서 같은 방향입니다.
3. 실세계 과제가 긴 호흡(접기, 커피 내리기, 원두 갈기)이고, 부분 점수 기준을 밝혔습니다.
4. 공식 코드(Apache-2.0)와 체크포인트가 공개되어 있습니다 (§ `04_code_verification.md`).

## 5. 약점과 확인이 필요한 점

1. **비교 공정성.** Stage 2 사전학습 데이터에 RoboTwin 27,500개가 들어 있습니다 (Table 12 Level 3, 공식 `configs/latent_action.yaml`의 `robotwin2_copy/clean`, `randomized`). 반면 π0.5와 X-VLA는 RoboTwin으로 40k 스텝 미세조정만 받습니다 (§5.2). 같은 벤치마크 분포에서 사전학습한 모델과 그렇지 않은 모델을 비교하는 셈입니다. 논문은 이 차이를 언급하지 않습니다.
2. **헤드라인 수치.** 초록과 서론은 "+45% over π0.5"라고 씁니다. Table 14 재계산으로 청정 차이는 +45.68점, 무작위화 차이는 **+43.18점**입니다. 공식 README는 "87.02% ... +45% over π0.5"로 무작위화 수치에 45%를 붙입니다. 무작위화 기준으로는 45%가 아닙니다.
3. **Table 2의 오기.** Table 2의 w/o Pretrain 청정 평균 72.8과 Stage 1 청정 평균 82.86은 Table 14와 Fig. 6의 77.56, 82.26과 다릅니다. 본문과 그림은 Table 14 쪽과 맞습니다. X-VLA 청정 평균도 재계산 72.88 대 보고 72.80입니다 (`analysis/recompute_results.json`).
4. **통계 보고 없음.** 실험마다 한 번 학습한 결과인지, 시드 반복이 있는지 적지 않습니다. 과제 간 쌍체 검정, 신뢰구간도 없습니다. 재계산 결과 (`03_analysis.md`)는 Stage 2 효과가 무작위화 기준에서 과제 쌍체 t 검정으로는 p=0.047이지만 Wilcoxon p=0.14, 부호 검정 p=0.88입니다. 즉 "사전학습 효과 확실"이라고 하기 어렵습니다.
5. **실세계 표본.** 과제당 시행 수가 표에 없습니다. 부록 Table 4–5의 부분 점수 합을 더하면 각 10회입니다. 실세계 14개 과제 중 2개만 subtask 분포를 줍니다. 10회 시행으로 본 부분 점수 차이는 Agilex Get Water에서 Mann-Whitney p=0.001, AC-One Put Bread에서 p=0.26입니다.
6. **토큰 균형 주장.** §4.1은 "영상 토큰과 행동 토큰 수가 균형을 이룬다"고 씁니다. 공식 설정에서 계산하면 영상 토큰은 약 360개(잠재 프레임 3개 × 120), 행동 토큰은 실세계 48+5, RoboTwin 16+5입니다 (`04_code_verification.md` D5). 균형이 아니라 영상 쪽이 7배에서 22배 많습니다.
7. **한계 절이 없습니다.** §6 "Conclusion and Limitations"에는 향후 과제만 있습니다. 실패 사례, 계산 비용(GPU 시간 약 1.8만 시간, Table 13), 학습 데이터의 편향에 대한 언급이 없습니다.
8. **비교 대상 부족.** 실세계는 π0.5 하나입니다. X-VLA, GR00T 등과 실세계 비교가 없습니다.
