# 04. 코드 대조와 구현 가능성

## 0. 범위와 방법

- **대상 코드:** [EthanRath/cosmos-predict2.5](https://github.com/EthanRath/cosmos-predict2.5)의 `gamma-branch`, 커밋 `8a924ea` (2026-06-16, 앞선 브랜치). nvidia-cosmos/cosmos-predict2.5의 포크이고 Apache-2.0입니다. 논문과 arXiv가 이 저장소를 링크하지 않으므로 "저자 계정으로 보이는 공개 포크"로 다룹니다(`02` §2). README와 설명이 없고 커밋 메시지도 "y", "attack updates" 같은 짧은 문구입니다.
- **방법:** 얕은 clone(스크립트, 월드 모델 수정 4개 파일, 실험 설정)을 **정적으로만** 읽었습니다. 코드는 실행, import, 설치하지 않았습니다. clone 내용은 신뢰하지 않는 데이터로 다뤘습니다.
- **범위:** 이 포크는 **VPH(텍스트 조건 월드 모델 공격)** 쪽입니다. VTH(DINO-WM 공격, PPO 학습, 표 5의 r2Dreamer, 그림 4·5)의 코드는 이 저장소에도, 같은 계정의 다른 저장소에도 없습니다(`02` §2).
- 브랜치가 여럿이고(`wm-poison-modifications` 04-10, `delta` 04-06, `ethan` 05-12, `gamma-branch` 06-16) 논문 v2의 표 1 값은 10월에 바뀌었으므로, 이 코드가 어느 값을 만든 것인지는 정해지지 않습니다(D12).

## 3. 정리

- 공개된 부분은 **공격 최적화의 입구**(손실, 프롬프트 변형, 인자)이고, LAB PGD 루프와 평가, 데이터는 빠져 있습니다. 코드로 확인되는 것은 "논문의 손실 종류와 주요 하이퍼파라미터가 이 포크의 호출 인자와 일치한다" 수준입니다.
- 식과 서술이 다른 곳(K1)에서 코드 기본값은 서술 쪽(원본 잠재 기준)입니다. 식 3 정정이 필요한 쪽은 논문 표기입니다.
- 논문 표 2의 수치(400 스텝, 프레임 10, 5이미지)와 코드의 권장 명령(300 스텝, 잠재 9, 10이미지)은 대응이 정해져 있지 않습니다. 저자 확인이 필요합니다.
- VTH 쪽은 코드로 점검할 수 없어서 `03`의 수치 재계산과 주장 판정이 유일한 확인입니다.

## 4. 구현할 수 있는가 (Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)

**판정: 논문 수치의 재현은 불가능합니다. 핵심 아이디어(행동 조건 월드 모델 + 백도어 PPO)의 축소판 재구현은 가능하고, 텍스트 조건 월드 모델 공격(VPH)은 이 맥에서 할 수 없습니다.**

| 수준 | 판정 | 근거 |
|---|---|---|
| 표 1 재현 (Cosmos-Predict2.5 2B 미세조정 + PGD 공격 + 수동 라벨) | **불가** | 공식 코드가 Linux, NVIDIA Ampere 이상, CUDA를 전제. 저자도 공격 최적화에 96GB GPU를 썼고(A.3) LIBERO 미세조정 데이터와 새 장면, 자산이 공개되지 않음. 수동 영상 판정(공격 영상 약 720개, 무공격 포함 시 더 많음, 시행 수 20 가정) |
| 그림 5 재현 (Cosmos AC에 VTH) | **불가** | 같은 이유. 코드 없음 |
| 그림 4 재현 (DINO-WM Single Wall + PPO) | **조건부, 코드 재작성 필요** | VTH와 PPO 래퍼 코드가 없음. DINO-WM 코드(MIT)와 체크포인트(약 5억 파라미터)는 있으나 다운로드 승인이 필요하고 CUDA 하드코딩이 있을 수 있음. 학습 약 38만 스텝 × 5시드 × 2묶음 |
| 표 5 재현 (r2Dreamer) | **불가** | 코드 없음, r2Dreamer 참고문헌 없음 |
| 위협 모델의 축소판 (작은 행동 조건 잠재 월드 모델 + 입력 섭동 + 월드 모델 안 PPO, 2차원 벽 환경) | **가능** | torch(MPS/CPU)와 numpy로 충분. 새 패키지 설치 불필요 |
| 표 1·4·5 수치 재계산, 문서 일관성 | **완료** | `03` |

**노력 추정 (측정 전, 근거 없는 추정):** 축소판 월드 모델과 식 4·5 공격, 월드 모델 안 PPO는 1–2주. DINO-WM 공식 체크포인트로 VTH 공격과 PPO를 맞추려면 3–5주(래퍼, 보상, 공격 구현, 다운로드). Cosmos 기반 VPH는 GPU 환경에서 설정 1–2주와 공격 시행당 수 분–수십 분이지만 이 맥에서는 대상이 아님.
