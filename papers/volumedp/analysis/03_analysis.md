## 2. 실물 실험 (Table V, 과제당 n = 20)

| 과제 | DP | Ours | 차이 | Fisher 양측 p | Holm 보정 | DP Wilson 95% | Ours Wilson 95% |
|---|---|---|---|---|---|---|---|
| Placing Bowl | 16 | 17 | +1 | 1.000 | 1.000 | [0.58, 0.92] | [0.64, 0.95] |
| Microwave | 12 | 15 | +3 | 0.501 | 1.000 | [0.39, 0.78] | [0.53, 0.89] |
| Door Opening | 13 | 17 | +4 | 0.273 | 0.820 | [0.43, 0.82] | [0.64, 0.95] |
| Nut onto Screw | 5 | 12 | +7 | 0.054 | 0.214 | [0.11, 0.47] | [0.39, 0.78] |
| **합계** | **46/80** | **61/80** | +15 | **0.0183** (Fisher, 과제 무시) | — | [0.47, 0.68] | [0.66, 0.84] |

**Mantel-Haenszel 층화 검정(과제를 층으로):** 공통 오즈비 2.60, χ² = 3.54, **양측 p = 0.060**.

**해석.**
- 원문 본문과 `temporal_policy`의 교훈처럼, 과제를 무시한 합산 Fisher 검정(p = 0.018)은 과제별 차이를 하나로 합칩니다. 과제 층화 검정(MH)은 p = 0.060이라 **5% 수준에서 유의하지 않습니다**.
- 과제별로는 Holm 보정 후 아무 과제도 유의하지 않습니다(최소 0.214).
- 따라서 "실물에서 유의하게 우월하다"는 주장은 합산 검정에만 의존합니다. 층화를 고려하면 방향은 일관되지만 강한 증거는 아닙니다.
- Wilson 구간은 과제별로 크게 겹칩니다(예: Microwave는 DP [0.39, 0.78], 제안 [0.53, 0.89]이고 [0.53, 0.78]에서 겹침).

- 과제당 n = 20은 검정력이 매우 낮습니다. 관측된 19포인트 차이를 참값으로 믿더라도 합산에서 팔당 약 98회가 필요합니다. 실물 비교는 **과제별 검정으로는 결론을 내릴 수 없습니다.**
- 관측 차이는 참값보다 과대 추정되기 쉽습니다(선택 편향). 10포인트 차이를 가정하면 팔당 367회가 필요합니다.
- 실물 시험은 시행 간 독립, 같은 초기 배치 분포, 같은 시험자 조건을 가정합니다. 이 가정은 원문에 적혀 있지 않습니다.

## 4. LIBERO (Table I)

± 값의 정의가 없습니다. 두 경우로 나누어 봅니다.

- **±를 3 시드의 SD로 가정:** Welch 검정 결과는 Spatial t = 12.1, p = 0.0004 / Object t = 6.0, p = 0.004 / Goal t = 22.1, p < 0.001 / Long t = 21.2, p = 0.0001. 모두 유의합니다.
- **±를 SE로 가정:** SD = SE × √3이므로 분산이 3배 커집니다. 이 경우에도 Goal과 Long은 유의할 가능성이 높지만, Spatial과 Object는 재확인이 필요합니다. 계산은 하지 않았습니다.

**핵심 한계:** 유의성은 Ours 대 DP 행의 값이 **같은 조건에서 나온 두 독립 측정**이라는 전제 위에서만 의미가 있습니다. DP 행의 출처가 불명확하므로(`02` §2) 이 검정은 "같은 레시피로 재실행한 DP와의 차이"가 아니라 "인용값과의 차이"를 검정하는 셈입니다.

## 6. 토이: 관측 표현 비교 (`analysis/volumedp_toy.py`)

**설정 (단순화, 실제 로봇 아님).** 목표 큐브(한 변 0.1)의 높이 z를 정책이 맞힙니다. 카메라는 위에서 내려다보는 직교 카메라이고, 가림판은 확률 p로 목표 위에 놓입니다. 표현 세 가지를 비교합니다.
- (A) 2D 투영 8×8 xy 점유 격자 (깊이 없음)
- (B) 8×8×8 복셀 점유, 카메라에서 처음 보이는 표면만 (깊이 있음)
- (C) 보이는 표면 32점의 평균·최소·최대와 가림 신호 (깊이 있음, 순서 불변)

정책 근사는 선형 최소제곱과 kNN(k = 5)입니다. 평가는 테스트 RMSE(z 단위, 장면 공간 [0,1])입니다. 학습 1,500, 테스트 500, 시드 0.

| 설정 | 평균 예측 | 2D 선형 | 2D kNN | 복셀 선형 | 복셀 kNN | 점 요약 선형 | 점 요약 kNN |
|---|---|---|---|---|---|---|---|
| 가림 없음 | 0.296 | 0.306 | 0.325 | 0.066 | 0.177 | **0.000** | 0.024 |
| 가림 확률 0.5 | 0.279 | 0.288 | 0.310 | 0.235 | 0.273 | 0.120 | 0.132 |
| 가림 확률 1.0 | 0.295 | 0.301 | 0.322 | 0.246 | 0.321 | 0.178 | 0.181 |

**읽는 법.**
- 2D 투영은 깊이가 없으므로 어떤 정책도 평균 수준을 넘지 못합니다(가림 없음에서 0.31대 0.30). 깊이가 관측에 들어가면 z를 맞힐 수 있습니다.
- 가림이 없을 때 깊이를 담는 표현(복셀, 점 집합)이 z를 맞힙니다. 점 집합 선형 0.000은 **구성상의 누출**입니다. 보이는 윗면 점의 평균 z가 목표 z + 0.05로 정해져 있어서 선형 모델이 정확히 복원합니다. 학습된 표현의 이득으로 읽으면 안 됩니다.
- 가림이 있을 때는 깊이 표현도 오차가 크게 늘어납니다. 가려진 목표의 z는 어떤 표현에서도 관측되지 않기 때문입니다. 이 토이에서 볼륨이 도움이 되는 조건은 **목표 표면이 일부라도 보이고 그 깊이가 정책 출력에 필요한 경우**입니다.
- **결론(토이 수준):** 볼륨이나 점 표현의 이득은 깊이 정보가 관측에 들어가는 것에서 옵니다. RGB에서 깊이를 만들 수 있는지(VolumeDP의 주장)는 이 토이로 판단할 수 없습니다. 실제 RGB 리프팅의 깊이 복원 품질은 원문에 없습니다.

## 7. 공정성: DP 기준선이 같은 레시피인지

원문에서 확인할 수 있는 것과 없는 것입니다.

| 항목 | 확인 | 근거 |
|---|---|---|
| BC 행이 인용인지 | 확인 (인용 일치) | `02` §2, [32] 표 |
| DiT 행이 자체 실행인지 | 원문 별표 | Table I |
| DP 행(LIBERO)이 자체 실행인지 | **확인 불가** | 별표 없음. [32]와 불일치. 출처 불명 |
| DP 행(ManiSkill, LIBERO-Plus)이 자체 실행인지 | 원문 별표 | Table II, III |
| 시연 수 (LIBERO 50, ManiSkill 평균 150) | 원문 명시 | §IV-A |
| 학습 epoch, 배치, 학습률 | **기준선별 명시 없음** | §IV-A의 "uniformly trained" 한 문장뿐 |
| 샘플러 (denoising 100 단계) | 명시 | §IV-A |
| 입력 해상도 (256×256), 프레임 (t, t−1) | 명시 | §IV-A |
| DP 디코더 크기 대 제안 디코더 크기 | **명시 없음** | 파라미터 수 미보고 |

**결론.** LIBERO에서 DP 행이 같은 레시피로 재실행되었다는 증거는 없습니다. 인용값이라면 학습 조건이 다를 수 있고, 이것이 +16.4%p의 가장 큰 불확실성입니다. ManiSkill 행은 자체 실행이므로 이 축은 상대적으로 더 공정하게 볼 수 있습니다. 다만 ManiSkill DP와 제안 방법의 파라미터 수와 epoch는 여전히 빠져 있습니다.

## 8. 승격 조건 판정: "LIBERO DP 기준선이 같은 레시피로 재학습되었는가?"

**판정: 해결되지 않았습니다. 원문과 공개 코드로는 공정성을 확인할 수 없습니다.**

근거:
1. DP 행에 자체 실행 표시가 없고, 캡션 규칙("*는 자체 구현")에 따르면 인용값입니다.
2. 인용 출처로 보이는 [32]에는 같은 DP 수치가 없습니다(Long 한 셀 78.0, 본 논문 50.5와 다름).
3. 공개 코드는 ManiSkill 포크이며 LIBERO 코드가 없습니다. 프로젝트 페이지의 LIBERO 코드 링크는 404입니다.
4. 따라서 "같은 시연 수, 같은 epoch, 같은 샘플러"는 검증할 수 없습니다.

**이 판정이 바꾸는 것:** LIBERO의 +16.4%p는 "재학습 비교"가 아니라 "인용값 대 자체 측정"으로 읽어야 합니다. ManiSkill 결과(+19.3%p, 자체 실행)와 LIBERO-Plus 결과(+21.3%p, 자체 실행)가 더 믿을 만한 비교입니다. 다만 LIBERO-Plus 평균에도 0.5포인트 계산 불일치가 있습니다(§1).

**재확인 방법(재현 시 수행할 일, 실행하지 않음):** 공개 ManiSkill 포크에서 DP 기준선을 같은 시연·epoch·샘플러로 학습해 보는 것입니다. 그러나 LIBERO에는 코드가 없어 같은 실험은 불가능합니다.
## 9. 컴퓨트 비용 추정 (원문 미보고, 계산으로만 추정)

- 볼륨 40×40×40×32 = 2,048,000 값. fp32 기준 약 8.2 MB 활성화 메모리 per 샘플, 프레임 2장이면 2배 가까이 됩니다. 이는 중간 텐서이며 학습 배치에 곱해집니다.
- deformable 샘플링은 복셀 64,000개 × 샘플점 수 × 헤드 수 만큼의 바이리니어 보간입니다. 실제 시간은 구현에 따라 다릅니다.
- 토큰 축약(N = 200)으로 디코더 입력은 202개 토큰입니다. DiT-Block 디코더와 같은 크기의 어텐션 비용이 남습니다.
- 원문에는 파라미터 수, FLOPs, 지연이 없습니다. "computation 크게 축소" 주장은 **검증되지 않았습니다.**
