## 1. 한눈에

**한 줄 요약.** 12자유도 손가락 제어를 "손 기술(hand skill)"로 묶어 얼려 두고, 그 위에서 팔 6D 증분 + 기술 활성 강도 α ∈ [0,1]만 학습하는 계층 구조를 만들어, 실로봇 RL(RLPD 기반 HIL-SERL 계열)을 6개 과제 · 2종 손에서 과제당 20–60분 온라인 학습으로 평균 98.3% 성공에 올렸다는 연구입니다(Abstract, 표 1).

| 구성 | 한 일 | 절 |
|---|---|---|
| ① 손 기술 | 직접 교시(kinesthetic) 참조 자세 θ_ref + SAC 잔차 δθ (식 1). 보상은 추종 + 손끝 힘 + 희소 성공 (식 3) | 3.1–3.2 |
| ② 조정 정책 | RLPD 위에서 π_coord(s) → [Δx ∈ R⁶, α ∈ [0,1]], 손 명령 θ_hand = α θ_skill + (1−α) θ_reset (식 2) | 3.1, 3.3 |
| ③ DMP 증강 | 기준 시연 1개에서 Cartesian DMP로 시작 자세만 무작위화한 롤아웃 100개 = 오프라인 데이터 | 3.3, 부록 A |
| ④ 다중 헤드 비평가 | Q_nav는 과제 보상, Q_mod는 활성 보상(식 4)을 따로 TD. Q̂ = Q_nav + Q_mod, 행동 성분별 정지 기울기 | 3.3, 식 5 |
| ⑤ IAW | 사람 개입 a_I와 정책 행동의 가치 차(식 7)를 z-정규화 후 시그모이드(식 8)로 가중한 모방 손실 | 3.3 |
| ⑥ 개입 인터페이스 | 팔은 Gello로 상대 SE(3) 개입, 손은 버튼 한 번으로 얼린 손 기술을 실행 | 3.3 |

## 2. 방법

### 2.1 문제 설정 (3.1절)

관측 s_t = (I_t, q_t, f_t): 손목·외부 RGB, 팔-손 고유감각, 손끝 접촉력. 손 기술 정책 π_skill(s_t, θ_ref,t)은 참조 손 자세에 잔차를 더합니다: θ_skill = θ_ref + λ_res δθ (식 1, δθ ∈ R¹², "λ_res는 잔차 탐색을 제한"). 조정 정책은 [Δx_t, α_t]를 내고 손 명령은 θ_hand = α θ_skill + (1−α) θ_reset (식 2)입니다. 실행되는 것은 (Δx_t, θ_hand)입니다.

### 2.2 손 기술 학습 (3.2절, 부록 C.1)

- 직접 교시: 사람이 로봇 손을 잡고 움직이는 인터페이스(참고문헌 [38] KineDex)로 θ_ref 궤적과 손끝 힘 변화, 손가락별 힘 상한 F_max를 기록합니다. 기준 궤적 1개를 기록하는 데 "과제당 5분 미만"입니다(부록 C.1).
- 접촉 회복: 측정 접촉이 기대와 크게 다르면 참조를 "가장 최근의 접촉 일치 상태"로 되감습니다(reference rewind). 판정 기준과 되감기 규칙은 수치로 주어지지 않습니다.
- 보상(식 3): r = −ω_track‖θ_cur − θ_ref‖² + ω_force Σᵢ min(‖f‖, F_max⁽ⁱ⁾) + 1[성공] R_skill. 성공은 "운영자 라벨"입니다.
- 학습: 실제 로봇에서 SAC, 리플레이는 교시 시연으로 초기화. 비평가는 실제 실행된 θ_skill로 학습합니다. 수렴하면 얼려서 (i) 조정 정책의 기본 동작과 (ii) 사람 개입 인터페이스로 씁니다.

### 2.3 조정 정책 (3.3절, 부록 A, C)

- 보상: 과제 완료 이진 분류기(ResNet-10 특징, 손끝 힘, 관절 토크 입력)가 R_task ∈ {0,1}을 냅니다. 분류기 정확도 95%(표 4). 활성 보상 r_mod는 α > τ일 때 R_task = 1이면 r_bonus, 0이면 r_penalty(< 0), 그 밖에는 0입니다(식 4).
- 다중 헤드 비평가: 한 Q로 R_task + r_mod를 배우면 초기에 활성 시도가 대부분 실패해 페널티가 누적되어 "활성을 회피"한다고 설명합니다. 그래서 Q_nav(목표 R_task)와 Q_mod(목표 r_mod)를 따로 TD 학습하고(식 5), 액터에는 Q̂ = Q_nav + Q_mod를 씁니다. 액터 최적화에서 Q_nav는 α 방향 기울기를 막고 Q_mod는 Δx 방향 기울기를 막습니다.
- 오프라인 사전학습: 기준 시연 1개(팔 궤적 + 활성 스케줄, Gello)에서 Cartesian DMP(식 9–11)를 맞추고 목표를 고정한 채 시작 자세를 작업 공간에서 무작위화해 실제 로봇에서 실행합니다. 팔 라벨은 Δx = clip(x*_{t+1} − x_t, −1, 1)(식 12), α는 과제 진행도로 시연에 맞춥니다. 손은 α > τ일 때만 얼린 π_skill이 움직입니다. 사전학습 손실은 SAC + 전역 BC 항 λ_gbc ‖ā_π − a_dmp‖²(식 6, λ_gbc = 0.5).
- 온라인 미세조정: 롤아웃과 개입 구간을 RLPD 리플레이에 쌓고 IAW 항을 액터 손실에 더합니다. A_I(s) = min_i Q̂_ϕ̄,i(s, a_I) − min_i Q̂_ϕ̄,i(s, ā_π(s)) (식 7), w = σ(Norm(A_I)/τ_I), L_IAW = E[w ‖ā_π − a_I‖²] (식 8), 총 액터 손실 L_SAC + λ_I L_IAW (λ_I = 0.1).

## 4. 이 글이 확인한 것과 남는 질문 (요약)

1. **표 1의 산술은 모두 맞습니다.** 열 평균 8개, 표 5·표 6과의 일치, 본문의 인용 숫자가 일치합니다(`03` V1–V2, K1–K5).
2. **HiFun 대 기준선 격차는 통계적으로 크고 확실합니다.** 과제별 Fisher p ≤ 2.4e-9(시행 수 50 가정). 평균 98.3%는 295/300, Wilson 95% 구간 96.2–99.3% (`03` V4–V5).
3. **"한 시간 온라인 학습"은 조정 정책 미세조정 시간만 셉니다.** 손 기술 잔차 RL 시간, 기준 시연(Gello), 교시는 표에 없습니다. 표에 적힌 항목 합은 과제 평균 73.75분(분류기 8.75 + DMP 18.8 + 온라인 46.2)입니다(`03` V15).
4. **절제 표의 시행 수가 없어서 단일 헤드 효과(100 → 85)는 n에 따라 p = 0.23(20회)에서 0.012(50회)까지 갑니다.** 드릴 비트(100 → 75)는 0.047–0.0002입니다. IAW 항(100 → 60, 40)은 두 가정 모두 유의합니다(`03` V6).
5. **"DMP가 약 4배 적은 시간"은 100개 대 200개 롤아웃 비교입니다.** 궤적당으로 환산하면 1.9–2.3배입니다(`03` V7).
6. **IAW 가중치 분리 그림은 식 7의 정의가 만드는 방향을 보여 줍니다.** 가치가 낮은 상태에서 높은 가중이 나오는 것은 A_I 정의의 결과여서 별도 근거가 되기 어렵습니다(`04` C8).
7. **코드가 공개 확인되지 않아 논문 수치와 코드 대조는 하지 못했습니다.** 재현에 필요한 값 다수가 본문에 없습니다(`04` §3).

## 5. 저자가 적은 한계와 해석 (6절)

저자는 (a) 학습된 손 기술 밖의 접촉 행동은 실패할 수 있고, (b) 저수준 실행에 초점을 두며 개방형 계획이나 언어 조건 일반화는 다루지 않고, (c) VLA·세계 모델과 결합은 향후 과제라고 씁니다. 추가로 본문에서 읽히는 범위 제한은 다음과 같습니다.

- 평가는 "학습 작업 공간 안에서 반복 실행의 정확도"입니다(B.3: "zero-shot 작업 공간 일반화가 아님").
- 과제마다 손 기술을 따로 학습·교시합니다. 여러 과제를 한 정책으로 쓰는 것은 영상 한 개(프로젝트 페이지)만 있고 수치는 없습니다.
- 과제 완료 판정이 분류기(정확도 95%)인지 사람인지 평가 단계에서 밝히지 않았습니다(`03` K12).
