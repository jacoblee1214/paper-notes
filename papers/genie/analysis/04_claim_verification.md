# 04. 주장 대조와 구현 가능성

## 0. 대상과 방법

**공식 코드가 없습니다**(`02` §2). 그래서 `04_code_verification.md` 대신 이 문서에서 논문 주장을 하나씩 대조합니다(C1–C14).

- 방법: 표 수치와 산술 주장은 `03`의 재계산(V 항목)으로 확인했습니다. 정성 주장(그림)은 **확인할 수 없음**으로 표시했습니다. 재현은 하지 않았습니다.
- 판정 기준: **확인됨**(재계산이나 산술로 맞음), **부분**(방향은 맞으나 조건이 빠짐), **확인 불가**(논문에 근거 수치가 없거나 그림에만 있음), **불일치**.

## 1. 라이선스와 공개 범위

- **arXiv 라이선스:** abs 페이지의 "view license" 링크는 `http://arxiv.org/licenses/nonexclusive-distrib/1.0/`입니다(2026-11-22 확인). CC BY 4.0이 **아닙니다**. 이 라이선스는 arXiv에 배포할 권리만 주며, 재배포나 2차 저작을 허락하지 않습니다.
- **PDF 표기:** 첫 쪽 하단에 "© 2024 Google DeepMind. All rights reserved"가 있고, 쪽마다 "Proprietary + Confidential"이 찍혀 있습니다(`paper/paper.txt`). ICML 판본의 저작권 문구는 "Copyright 2024 by the author(s)"입니다(`01` §0.1).
- **결론:** 공개본에 **논문 그림을 넣지 않습니다.** 텍스트 인용은 짧게 쓰고 출처(저자, 연도, arXiv:2402.15391, 절·표 번호)를 붙입니다. 공개본의 그래프는 우리가 표 점 값으로 다시 그린 것입니다.
- **코드 라이선스(커뮤니티 구현):** myscience/open-genie MIT, FLAIROx/jafar Apache-2.0, alexcbb 저장소 MIT, kyegomez/Genie MIT(GitHub API). 이 저장소에 코드를 가져오지 않았습니다.

## 3. 축소판 재현 설정 검토 (부록 F)

저자는 "단일 중간급 TPU/GPU에서 1주 이내" 재현 가능한 CoinRun 예를 제시합니다. 설정을 정리하면 다음과 같습니다.

| 항목 | 설정 (부록) | 비고 |
|---|---|---|
| 환경 | Procgen CoinRun, hard 모드 (F.1) | Procgen 설치 필요 |
| 데이터 | 무작위 정책, 행동 반복 없음, 시드 0–10,000, 시드당 1,000 스텝, 총 1,000만 전이 (F.1) | 공식 환경 실행 필요 |
| 토크나이저 | 인코더 8층, 디코더 8층, d 512, 헤드 8, 패치 4, 코드 1024, 임베딩 32 (표 15) | 배치 48 × 16 프레임, 300k 스텝, 단일 TPU 3일 (F.2) |
| LAM | 인코더와 디코더 8층, d 512, 헤드 8, 코드 6, 임베딩 32 (표 16) | 본 모델 8개 대비 코드 6개. 패치 크기는 표에 없음 |
| 동역학 | 12층, d 512, 헤드 8, MaskGIT 25 스텝, 온도 1.0 (표 17) | 본 모델 온도 2 |
| 공동 학습 | 배치 36 × 16 프레임 = 576 이미지, 200k 스텝 (F.3) | 시간 미기재, 16 GB 메모리 전제 |
| 해상도 | 미기재 | K12 |

설정은 충분히 구체적입니다. 빠진 것은 해상도와 시간입니다. 그래서 1주 이내 주장은 확인할 수 없습니다(C11).

## 4. 구현 가능성 (이 맥)

이 맥의 자원은 Apple M4 Pro, 약 24 GiB 통합 메모리, MPS, CUDA 없음입니다(저장소의 기기 메모 기준).

**판정: 전체 Genie는 구현·재현할 수 없습니다. 맥에서 가능한 것은 구조 재구현의 소형 토이와, 승인 후 CoinRun 축소판의 짧은 측정뿐입니다.**

| 대상 | 필요 자원 | 맥에서 | 근거 |
|---|---|---|---|
| 전체 Genie (11B, 942B 토큰) | 256 TPU급 학습, 비공개 데이터·가중치, 공식 코드 없음 | **불가** | `01` §5, 표 12, `02` §2 |
| 공개 커뮤니티 구현 실행 (PyTorch, JAX) | 저장소 클론, 설치 (새 패키지 승인 필요), 공식이 아님 | **조건부** (설치 승인 후 소형 설정 한 번) | `02` §2 |
| CoinRun 축소판 (App F) | Procgen 설치 (승인), 공식 환경 실행으로 데이터 생성 (승인), 16 GB급 학습 3일 이상 (추정) | **조건부** (MPS에서 짧은 측정 전에는 판단 불가. 메모리는 24 GiB에 들어갈 것으로 추정하나 측정 전) | 04 §3, 표 15–17 |
| 합성 격자 영상으로 LAM 토이 | numpy 또는 torch (직접 작성) | **가능** | 직접 짠 코드는 재현 승인 범위 안 (저장소 재현 규칙) |

**노력 추정 (측정 전):** 합성 토이 LAM 1–2일. CoinRun 축소판은 설치, 데이터 생성, MPS 포팅, 짧은 학습 측정까지 2–4주로 봅니다. 이 숫자는 측정 전 추정입니다.
