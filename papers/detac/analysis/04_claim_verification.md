# 04. 주장 검증과 구현 가능성: DeTac

공식 코드와 프로젝트 페이지를 찾지 못해(`analysis/02_prior_work.md` §4) 논문 ↔ 코드 대조 대신, 논문 안의 주장 C1–C12를 표·식·본문으로 검증합니다. 검증은 표 재계산(`analysis/03_analysis.md`의 V 라벨), 식의 정합성 읽기, 측정 구성 확인으로 했고 실행한 실험은 구조의 속도 측정뿐입니다. 서술의 주어는 논문과 표이며, "확인 불가"는 "논문에 정보가 없다"는 뜻입니다.

## 1. 주장별 판정

판정: 성립 = 표·식과 일치, 조건부 = 일치하나 비교 조건·표본 때문에 해석에 단서, 불명 = 논문 정보로 가를 수 없음.

| 번호 | 주장(위치) | 확인 | 판정 |
|---|---|---|---|
| C1 | 전체 모델이 모든 지표에서 최고(4.2절, 표 1) | 8개 열 모두 최고(`03` V3). 일부 열의 차이는 PSNR 0.04 dB, SSIM 0.002 | 성립, 좁은 격차 열은 조건부 |
| C2 | TacDiff 대비 PSNR 7 dB 이상(1절 기여) | 7.93 / 7.67 dB(`03` V2). TacDiff는 합성 데이터, 회귀 기준선은 같은 쌍 데이터로 학습. 후자 대비 0.04–0.89 dB | 조건부 |
| C3 | 회귀 기준선은 지각·분포 유사도가 더 나쁘다(4.2절) | FID 104–112 대 DeTac 17–20, KID도 같은 방향(`03` V12). PSNR·SSIM은 근접 | 성립(FID, KID) |

| C7 | L_con이 마커 추출에 필수적인 지침을 준다(4.3절 "indispensable") | L_con 제거 MCLE +9.2%, L_sur 제거 +10.1%(`03` V6). 시드가 하나이고 L_sur의 마커 분기 경로가 간접이라 두 값의 우열을 가를 수 없음 | 불명 |

| C9 | 힘 추정이 가장 정확(표 3) | 0.089 N 대 UVTac 0.119 N, 혼합 0.202 N(`03` V7). 시험 크기, 힘 범위, 성분 정의, 반복이 없음 | 조건부 |

## 2. 식과 정의 읽기

| 번호 | 항목 | 읽은 내용 |
|---|---|---|
| E1 | 식 2–5 | 표준 DDPM(전방 q, ε 예측, x̂₀ 복원, σ_t² = (1−ᾱ_{t−1})β_t/(1−ᾱ_t))과 같은 형태로 일관됨 |
| E2 | 식 4와 보조 손실 | L_sur, L_con은 한 번의 노이즈 예측으로 만든 x̂₀로 계산합니다. 큰 t에서는 x̂₀가 흐려지므로 t에 따른 가중이나 t 제한이 있는지 논문에 없음 |
| E3 | 식 7 | 이진화 I(Î_mar > τ)는 미분되지 않아 L_sur의 gradient는 음영 분기로만 흐름. 마커 분기에는 I_chg(식 9) 경로로만 영향 |
| E4 | 식 8 | 분모 ‖R_mar‖₁ + δ가 고리 픽셀 수(RGB 방송 전 기준인지 후 기준인지 불명)로 정규화. 반경 r = 2픽셀이라 고리 폭이 픽셀 단위에서 정해지며, 입력 해상도와 마커 크기에 따라 의미가 달라짐 |
| E5 | 식 9, 10 | I_chg는 복원 전후 차이의 공간 최대값 정규화입니다. 차이는 마커 위치뿐 아니라 함입 흔적 주변과 조명 차이에서도 생기므로, L_con이 Î_mar를 I_chg에 맞추는 방향이 마커 마스크를 넓게 만드는지는 논문에 분석이 없음 |
| E6 | gradient 흐름 | L_con이 Î_sha 쪽으로도 역전파되는지(stop-gradient) 논문에 없음. "상호 감독"(mutual supervision)이 양방향 gradient를 뜻하는지 확인 필요 |
| E7 | 부록 A.1 | 잔차 블록 22개는 8 + 2 + 12로 일치(`03` V13). 해상도, 시간 임베딩, 어텐션 유무는 없음 |

## 3. 정보가 없어 재구현에 필요한 값

입력 해상도, 마커 개수·배치, 이진화 문턱 τ, 팽창이 쓰는 구조 요소, ε와 δ, 샘플링 단계 수와 시간, 데이터 증강의 확률과 범위, SAM의 버전과 프롬프트 수, FID·KID를 계산한 특징망과 표본 구성, 힘 추정망 구조와 학습·시험 분할, 광도 스테레오 보정, 시드와 반복 횟수. 데이터셋과 코드의 공개 계획도 본문에 없습니다.

## 4. 구현할 수 있는지 (판정)

**이 맥(Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)에서 논문 수치의 재현은 불가능합니다. 알고리즘 부분만 합성 데이터로 구현하는 축소판은 가능합니다.**

| 경로 | 이 맥에서 | 근거 |
|---|---|---|
| 모델(24 M 가정, 22 잔차 블록) 구현과 학습 | 가능(데이터가 있을 때) | 랜덤 가중치 측정으로 128×128 기준 300 epoch 약 5.6 h, 256×256 약 20.5 h(MPS, 추정, `03` 6절). 해상도는 가정 |
| 추론(DDPM T = 1000) | 가능, 느림 | MPS 한 장당 15–56 s(가정 해상도) |
| 논문의 쌍 데이터 | **불가** | 데이터셋 공개 여부를 확인하지 못함. 재수집에는 MC-Tac(BSD-3 하드웨어), 3D 프린팅 외피·패드(핀 20개, 질감 유닛 54종), 마커 제작, 사람의 점 주석, SAM 3.x 가중치(라이선스 NOASSERTION)가 필요 |
| 마커 pseudo GT | 불가(SAM 가중치 다운로드 필요, 승인 전) | 3.3절 |
| 표 3, 4, A1(힘, 표면, 직물) | **불가** | 로봇 팔, 6축 힘센서, 마커 없는 센서, 분류망 데이터가 필요 |
| 교차 센서(그림 7) | 불가 | 다른 센서 하드웨어 필요 |
| 축소판: 합성 음영 + 합성 마커로 두 분기와 L_sur, L_con을 구현해 절제(균일 가중 L1 대조 포함) | 가능(CPU/MPS, 새 설치 없음) | torch가 이미 설치됨. 단 합성 마커는 함입 흔적을 별도로 모델링해야 의미가 있음 |

- **노력(추정):** 축소판 구현과 절제 1–2주. 논문과 같은 쌍 데이터를 새로 모으는 전체 재현은 하드웨어 제작과 수집, 라벨링으로 1–3개월 이상입니다.
- **라이선스 메모:** 하드웨어(MC-Tac)는 BSD-3-Clause입니다. 논문 데이터와 코드의 라이선스는 공개되지 않아 알 수 없습니다.

## 5. 저자에게 묻고 싶은 것

1. 표 1의 TacDiff 확대 마스크 변형은 어떤 마스크 크기와 학습 데이터로 만들었나요. TacDiff만 4지표가 모두 나빠진 이유가 있나요(C5).
2. 입력 해상도, 마커 수, τ, 샘플링 단계 수는 얼마인가요(3절).
3. L_con의 gradient는 음영 분기로도 흐르나요. 보조 손실을 계산하는 t의 범위가 있나요(E2, E6).
4. 표 1–3의 시드 수나 반복이 있나요. 표 1의 FID는 몇 장으로 계산했나요(`03` V1).
5. MCLE의 정답 중심은 SAM pseudo GT와 같은 절차인가요. UVTac와 SAM 3.1은 혼합 이미지에 어떻게 적용했나요(C6).
6. 표 3·4의 시험 표본 수, 힘 범위, 성분별 오차를 알 수 있나요(C9, C10).
7. 표 A1의 분류 범주 수와 시행 독립성, 혼합 이미지 직물 A의 16.7%의 원인은 무엇인가요(C11).
8. 데이터셋과 코드의 공개 계획이 있나요.
