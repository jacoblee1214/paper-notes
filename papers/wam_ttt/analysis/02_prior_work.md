# 02. 선행연구와 자료: WAM-TTT (arXiv:2607.06988)

계보는 논문 §2와 참고문헌에서 가져왔고, 논문이 말하지 않은 연결은 "분석"으로 표시했습니다. 외부 논문의 내용은 arXiv 초록(2026-11-26 확인)과 공개 README만 근거로 썼습니다.

분석: 이 논문의 새로운 부분은 (1) 사람 영상을 "행동 없는 키-값 기억"으로 쓰는 시험 시 갱신, (2) 짝 사람-로봇 데이터로 그 기억의 읽기 경로를 메타 학습하는 두 단계 구성, (3) 위상 정렬(선형 시간 정렬)로 짝을 맺는 것입니다. TTT 층 자체와 LDA 백본, 사람 영상 ICL의 아이디어는 기존 연구에서 왔습니다.

## 4. 가까운 대안과 차이

| 대안 | 사람 영상을 쓰는 방식 | WAM-TTT와의 차이 |
|---|---|---|
| WAM-Cotrain (이 논문의 기준선) | 짝 사람 영상으로 WAM을 공동 학습 | 배포 시 적응이 없음. 메타 학습 데이터는 같음 |
| WAM-ICL / LingBot-style ICL | 사람 영상을 문맥 토큰으로 입력 | 문맥 길이가 영상 수에 따라 늘어남. 이 논문 설정에서는 메타 학습만으로 조건화를 배워 약함(v3 본문 설명) |
| MimicDroid [18] | 사람 놀이 영상으로 ICL 정책을 학습 | WAM 없이 정책 자체가 ICL. 논문은 비교하지 않음 |
| EgoScale [10] 등 사전학습형 | 대규모 일인칭 사람 데이터로 정책 사전학습 | 시험 시 사람 영상이 없음 (논문에서 재구현) |
| UniSkill, XSkill [12, 3] | 사전학습된 스킬 잠재 | 표 2에서 "메타 학습만으로 삽입"한 변형 |
| 행동 의사 라벨 방식 [7, 10] | 손 포즈 추정 후 재타깃, 행동 감독 | 부록 E.6이 "나쁘다"고 보고 (표 E.3) |
| LoRA 적응 (표 3) | 같은 정보를 저랭크 가중치 갱신으로 | 표 3 Swap Place에서 0.0 |

## 5. 읽으면서 확인할 것 (선행연구 관점)

1. 고속 가중치 f_W가 **Spatial-TTT의 층과 같은 연산**(SwiGLU, per-token lr, L2 정규화)인지, 식 3의 MSE 갱신인지가 본문에서 정해지지 않습니다. 갱신 규모가 다르게 해석됩니다(`03` §8).
2. "행동 없는 사람 영상은 안전하다"는 서술과 달리 메타 학습의 **짝 사람 영상이 평가 가정집에서 찍힙니다**(부록 B). WAM-ICL은 같은 사람 영상을 문맥으로 받는다고 서술되지만(§4.4) 문맥에 들어가는 영상 수와 프레임 수는 본문에 없습니다(`04` §3).
3. MimicDroid, LingBot-VA 2.0 같은 사람 영상 ICL 기준선은 "스타일" 변형만 비교했습니다(§4.2). 원 시스템과의 비교는 없습니다.
