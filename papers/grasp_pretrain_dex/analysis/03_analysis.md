# 03. 수치 재계산과 주장 검사

이 문서는 논문 표의 값을 옮겨 다시 계산한 결과입니다. 재현 실험은 하지 않았습니다. 계산은 `analysis/recompute.py`(numpy, scipy, 수 초)이고, 결과는 `analysis/recompute_results.json`에 있습니다. 그래프는 `analysis/plot_figures.py`로 그렸습니다.

**계산 가정.** 시뮬레이션 셀은 500 에피소드의 성공 비율로 보았습니다. 과제 6개의 평균은 과제를 독립으로 보고 셀 분산만 반영했습니다. 실로봇 셀은 과제당 18회입니다. 시드 간 분산은 논문이 보고하지 않아 어떤 구간에도 들어 있지 않습니다. 따라서 아래의 "95% 구간"은 모두 **샘플링 오차만**입니다.

## 1. 표 값의 재계산

### 1.1 표 1 평균 (시뮬레이션, 6과제 평균)

| 방법 | 20 시연 (재계산 / 보고) | 50 시연 | 100 시연 |
|---|---|---|---|
| DP | 1.03 / 1.0 | 1.77 / 1.8 | 2.33 / 2.3 |
| DP3 | 2.40 / 2.4 | 8.40 / 8.4 | 19.00 / 19.1 |
| DP3-PT | 10.03 / 10.1 | 22.23 / 22.3 | 29.70 / 29.7 |
| GraspXL-PT | 12.97 / 13.0 | 37.97 / 37.8 | 48.70 / 48.7 |
| HP-Scratch | 38.63 / 38.7 | 48.90 / 48.9 | 57.93 / 58.0 |
| Ours | 45.37 / 45.4 | 60.27 / 60.3 | 64.47 / 64.6 |

- 최대 차이는 0.167pp(GraspXL-PT, 50 시연)입니다. 대부분은 반올림 범위 안이지만, 0.1을 넘는 셀이 몇 개 있어 셀 원값과 평균 계산 방식이 완전히 같지 않을 수 있습니다. **판정: 대체로 일치, 소수 첫째 자리의 작은 불일치 있음.**

### 1.2 표 4 실로봇 (과제 3개, 과제당 18회, 풀링 54회)

| 방법 | 잡기 (k/54, %) | 정렬 | 작동 (=전체) | 작동 Wilson 95% |
|---|---|---|---|---|
| DP3 | 21 (38.9) | 11 (20.4) | 4 (7.4) | [2.9, 17.6] |
| HP-Scratch | 33 (61.1) | 23 (42.6) | 14 (25.9) | [16.1, 38.9] |

- 보고된 평균 열(38.9/20.4/7.4, 61.1/42.6/25.9, 77.8/66.6/40.7)과 일치합니다(정렬 66.7과 66.6은 반올림 차이).
- 원데이터는 표 4의 과제별 백분율을 18회 기준 횟수로 바꿔 쓴 것입니다. 모든 셀이 정수 횟수로 떨어지는 것을 코드에서 확인했습니다.

## 3. 해석 메모

1. **사전학습의 효과는 있어 보입니다.** 같은 구조에서 사전학습만 뺀 HP-Scratch 대비 6.5–11.4pp입니다(C5, C6). 이 차이는 샘플링 구간보다 크지만, 시드 간 분산이 빠져 있어 확실하다고 하기는 이릅니다. 시드 3개 이상의 학습 반복이 있어야 합니다.
2. **실로봇 결과는 방향이 맞고 크기는 불확실합니다.** DP3 대비는 확실합니다(C13). HP-Scratch 대비는 유의하지 않습니다(C14). 논문 본문이 두 비교를 같은 강도로 쓴 것은 과장입니다.
3. **오라클이 더 낮은 이유가 궁금합니다.** 오라클은 시연의 정답 부목표를 쓰는데도 Ours보다 평균 6–8pp 낮습니다(C19). 논문은 오라클이 "깨지기 쉽다"고 설명합니다(부록 D.3). 다만 저수준 정책은 학습할 때 정답 부목표를 썼습니다(§5.1). 즉 학습-추론 불일치를 고수준 예측이 어떻게 줄이는지에 대한 설명이 없습니다. 임계값(전환 기준)에 따라 오라클 성능이 크게 바뀔 수 있어 이 비교는 확인이 필요합니다.
4. **셀 잡음은 1–2pp 수준입니다.** 같은 방법이 예산을 늘렸을 때 떨어지는 셀이 있습니다(C4). 500 에피소드라도 셀 하나의 표준오차는 약 2pp입니다. 셀 단위 주장은 3pp 이내의 차이로는 읽지 않는 편이 안전합니다.
5. **표본 설계.** 시뮬레이션은 500회로 충분하지만, 실로봇은 과제당 18회로 너무 작습니다. 두 방법 사이에서 20pp 차이를 확인하려면 약 97회가 필요합니다(C16).

## 4. 재계산에서 제외한 것

- 그림 5(스테이플러 샘플 효율)와 그림 9(인코더 전이)는 값이 표로 주어지지 않아 읽지 않았습니다.
- 그림 10(5점 대 16점 키포인트)도 표가 없어 Cond-16이 낫다는 본문 주장만 확인했습니다. 부록 D.1 본문은 3개 과제에서 16점이 낫다고 씁니다.
- 실로봇 세 과제 이미지와 정책 시각화(그림 6, 12–14)는 확인하지 않았습니다.

## 5. 이 문서의 한계

- 표 값은 `pdftotext -layout`으로 옮겼습니다. 한 행을 잘못 옮기면 과제 순서가 바뀌므로, 옮긴 뒤 과제 순서대로 재배열하고 평균으로 검산했습니다. 이 과정에서 과제 5와 6(스테이플러, 펜)의 열 순서를 한 번 잘못 옮겼다가 고쳤습니다. 현재 값은 원문 행과 대조해 맞춘 것입니다.
- 검정은 셀 독립과 과제 독립을 가정합니다. 시드 분산은 빠져 있습니다.
- 논문 v1의 실로봇 표(v1 표 2)와 v2의 표 4의 값 비교는 하지 않았습니다. v1 텍스트에서 이 표 값을 대조하지 않았습니다.
