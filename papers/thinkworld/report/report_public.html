핵심 요약

  1. 무엇을 하는가: Qwen3-VL-2B VLM이 1초 손목 움직임 토큰(CoD)을 생성하고, CoD로 1초 뒤 DINOv3 특징을 예측하게 학습한다. 그다음 예측과 실제 미래의 일치로 CoD를 GRPO로 강화한다. 배포 때는 CoD도 예측도 쓰지 않으므로 구조는 Qwen3-VL + MolmoAct2 action expert VLA와 같다.
  2. 실물 결과는 크고 유의하다: 112/120 대 72/120(MolmoAct2), Fisher p = 6×10⁻¹⁰. 다만 학습 seed는 1개이고, "ID에서는 비슷하다"는 서술과 달리 ID에서도 60/60 대 47/60으로 앞선다. 컵 걸기에서는 기준선이 OOD에서 오히려 오른다.
  3. 이득의 대부분은 미래 예측 보조 손실이다: Table 3의 총 이득 15.5%p 중 미래 예측이 63%, CoD가 26%, 제목의 핵심인 RL은 8%(+1.3%p)다.
  4. "레이블 없는 영상" 주장은 좁혀 읽어야 한다: 학습에 쓴 사람 영상 1,880시간은 손목 자세 주석을 CoD 정답으로 쓴다. 주석 없는 영상의 효과는 정성 사례(기술 조합)뿐이다.
  5. RL 보상의 신호 폭이 작다: Eq. 6으로 환산한 "CoD 있음 대 없음" 보상 차이는 약 0.03이고, 형식 오류 벌칙(0.05)이 그보다 크다. 그룹에 형식 오류가 하나 섞이면 정상 후보의 advantage 폭이 19–49%로 줄어든다.
  6. 시뮬레이션 표는 공개 리더보드와 맞는다: LIBERO-PRO 기준선 값은 공식 리더보드와 0.05%p 안에서 일치하고, LIBERO-Plus Avg는 과제 수 가중 평균으로 재현된다. LIBERO 1위는 VLA-JEPA와 0.05%p 차이이고, 가장 가까운 기준선 MolmoAct2-LIBERO가 표에 없다.
  7. 구현 가능성: 코드·가중치가 없어 공식 재현은 불가능하다(H100 128장 규모). 구성 요소는 모두 공개되어 있어 아이디어 재구현은 가능하고, 가장 싼 경로는 기존 VLA에 미래 DINO 특징 예측 보조 손실을 붙이는 것이다.

1. Abstract (한 줄 요약과 주장)

한 줄 요약: VLA의 VLM이 행동 전에 **사람과 로봇이 공유하는 이산 손목 움직임 토큰(Chain-of-Dynamics, CoD)**을 생성하고, 그 CoD가 1초 뒤 장면(DINOv3 특징)을 어떻게 바꿀지 예측하도록 학습합니다. 그다음 예측한 미래와 실제 미래가 잘 맞는 CoD에 보상을 주는 GRPO로 VLM을 강화합니다. 배포할 때는 CoD도 미래 예측도 쓰지 않습니다.

저자들이 내세우는 기여는 세 가지입니다(Sec. 1).

  1. 사람과 로봇에 공통인 VLM 고유의 행동 추론 인터페이스(CoD)와 내부 세계 상상(world imagination)을 결합한 VLA 학습 틀입니다.
  2. **결과에 근거한 RL(consequence-grounded RL)**입니다. 관찰된 미래와의 일치로 CoD에 보상을 주므로, 행동 레이블이 없는 영상에서도 추론이 개선된다고 주장합니다.
  3. 행동 레이블이 없는 사람 영상을 늘리면 성능이 오르고, 사람 영상만으로 보여 준 과제 순서를 로봇이 원자 기술을 조합해 수행한다고 보고합니다.

2.2 Chain-of-Dynamics (Sec. 3.2, 부록 A.2)

  • 움직임 표현: 로봇 궤적과 사람 손 궤적을 모두 정규화된 delta 엔드이펙터로 바꿉니다. 손 하나는 6D, 두 손은 12D(위치는 m, 회전은 rotation vector)이고, 그리퍼 상태는 뺍니다. 정규화 스케일은 0.3448 m와 0.9119 rad입니다.
  • 좌표계: 로봇은 베이스 좌표계, 사람은 중력 정렬 + 행위자 yaw를 따르는 좌표계입니다. 사람과 로봇의 기구학 대응은 가정하지 않습니다.
  • 토큰화: 1초 구간을 FAST 토크나이저[57]로 어휘 2,048의 이산 토큰열 c*로 바꿉니다. VLM은 이것을 autoregressive로 생성합니다(L_CoD).
  • 실행: CoD 토큰은 실행되지 않습니다. 별도의 action expert가 실행 행동을 냅니다.

2.3 CoD 조건부 미래 상상 (Eq. 1–2, 5)

CoD 뒤에 학습 가능한 미래 질의 q_{t+Δ}를 붙입니다. 질의는 VLM을 거쳐 q̃가 되고, 가벼운 decoder가 이것을 동결된 DINOv3 특징 공간의 z_{t+Δ}로 바꿉니다(Eq. 1). 표적은 Δ = 1초 뒤 주 카메라 프레임의 DINOv3 특징 z*입니다(±50 ms 안에 프레임이 없으면 손실에서 뺌).

L_SFT = L_CoD + λ_future · L_future                                  (Eq. 2, λ_future = 3)
dist(z, z*) = (1/|V|) Σ_p [ 1 − cos(z_p, z*_p) + λ_SL1 · SmoothL1_β(z_p, z*_p) ]   (Eq. 5, β = 0.01)

학습 때 미래 예측은 **정답 CoD(teacher forcing)**에 조건화됩니다.

2.4 세계 상상 보상 RL (Sec. 3.3, Eq. 3–4, 6, 부록 A.6)

같은 맥락에서 CoD 후보 K = 4개를 뽑고, 각 후보로 예측한 미래를 실제 미래와 비교해 보상을 줍니다.

sim(z, z*) = ½ [ (1/|V|) Σ_p s_p  +  Σ_p w_p s_p / Σ_p w_p ],   s_p = cos(z_p, z*_p)          (Eq. 6)
w_p = 0.2 (변화량 ≤ 중앙값) → 선형 증가 → 1 (≥ 90분위),  변화량 = 현재→관찰 미래의 DINO 특징 변화
L_RL = 0.999 · L_GRPO(r_world) + 0.001 · L_replay                                            (Eq. 4)
  • 형식 오류: 형식이 깨진 CoD는 그룹 최저 유사도보다 0.05 낮은 보상을 받습니다.
  • advantage: 4개 후보 그룹 안에서 표준화하고, 다시 배치 전체에서 표준화합니다. 후보의 advantage는 그 후보의 모든 토큰이 공유합니다.
  • 최적화 설정: 토큰 단위 importance ratio를 [0.8, 1.28]로 자르고, KL 계수는 0.04, 학습률은 10⁻⁶입니다.
  • 고정 부분: RL 동안 미래 projector와 action expert는 고정입니다.

2.5 배포

Action SFT와 추론은 빈 <think></think>를 씁니다. 배포된 정책은 CoD도 미래 예측도 생성하지 않으므로, 구조상 Qwen3-VL + MolmoAct2 action expert VLA와 같습니다. CoD, 미래 예측, RL은 모두 VLM 가중치를 바꾸는 학습 신호로만 작동합니다(부록 C.5).

4. Limitations

4.1 저자가 밝힌 한계 (부록 D)

학습 seed가 하나라서 보고된 신뢰구간은 평가 변동만 반영합니다. 지연 시간은 하드웨어와 입력 설정에 따라 달라집니다. 재현성을 위해 시행 분모, 초기화, 학습 설정, 하드웨어를 적었다고 밝힙니다.

4.2 분석하면서 추가로 발견한 한계와 의문점

  1. "행동 레이블 없는 영상"으로 학습한다는 핵심 주장이 대규모로 시험되지 않았습니다.
    • 학습에 쓴 사람 데이터(EgoDex, EgoVerse)는 모두 손목 자세 주석이 있고, 이것이 CoD 정답 토큰이 됩니다(Table 4). RL 데이터도 "Robot + human motion"입니다(Table 5).
    • 그런데 프로젝트 페이지는 "44% egocentric human video, no action labels"라고 씁니다. 주석이 없는 것은 로봇 행동이고, 손 자세 주석은 있습니다.
    • 진짜로 주석 없는 영상을 쓴 것은 실물 기술 조합 사후학습(미래 예측 손실만)뿐이고, 결과는 정성 사례입니다.
  2. 배포 시점의 "추론"은 없습니다. CoD와 미래 예측은 학습 신호입니다. 따라서 성능 이득은 "추론"보다 표현 학습(보조 손실 + 데이터)의 효과로 읽는 편이 정확합니다. Table 3에서 이득의 63%가 미래 예측 보조 손실 하나에서 나옵니다.
  3. RL 보상의 신호 폭이 작고, 자기 모델에 기대어 있습니다.
    • 보상은 모델 자신의 미래 예측(동결 projector + 갱신되는 VLM)과 실제 미래의 일치도입니다.
    • Eq. 6의 순위 가중치는 상위 10% 변화 패치에 보상의 17%만 줍니다.
    • CoD가 바꾸는 보상 폭은 약 0.03으로, 형식 오류 벌칙 0.05보다 작습니다(03 §2–3).
    • RL의 기여도 Table 3에서 +1.3%p입니다.
  4. 비교 대상 구성이 고르지 않습니다.
    • 실물 비교는 MolmoAct2, LIBERO 비교는 MolmoAct(이전 버전)입니다.
    • LIBERO-PRO의 MolmoAct 평균은 Environment가 없어 축 4개 평균입니다.
    • LIBERO-Plus는 "공개 결과가 있는 방법만"이라면서 공식 리더보드의 π0(53.6), RIPT-VLA(68.4) 등을 뺐습니다. 다만 넣어도 순위는 바뀌지 않습니다.
  5. ID 성능부터 다릅니다. 실물 로봇에서 ThinkWorld는 ID 60/60이고 기준선은 29–47/60입니다. 같은 사전학습 규모를 맞춘 기준선이 없어서, 일반화 이득과 기본 성능 이득을 구분할 수 없습니다.
  6. 재현 수단이 없습니다. 코드와 가중치가 없습니다. 학습에는 H100 128장(SFT), 64장(RL, YAM 적응)이 들고, 실험실 실물 데이터와 데이터 표집 가중치는 공개되지 않았습니다.
  7. 사소한 수치 차이가 있습니다. Table 1의 MolmoAct LIBERO 평균은 suite 값에서 86.8로 계산되는데 86.6으로 적혀 있습니다. VLA-JEPA LIBERO-PRO 평균은 48.58인데 48.5로 적혀 있습니다(재현값 표시 †).

2. 세계 상상 보상(Eq. 6)의 신호 폭

2.1 가중치는 순위만의 함수

w_p는 변화량이 중앙값 이하면 0.2, 90분위에서 1이고 그 사이는 선형입니다. 변화량의 크기와 관계없이 패치 순위로만 정해집니다. 그래서 196 패치에서 각 구간이 받는 몫은 변화량 분포와 무관하게 거의 같습니다. lognormal, uniform, exponential 분포로 각각 2,000번 표본을 뽑아 확인했습니다(R1).

패치 구간 motion 가중 항에서의 몫 Eq. 6 전체에서의 몫 균등 평균이라면
변화 상위 10% 22–25% 17.4% 10%
변화 상위 25% 52–53% 39.0% 25%
변화 하위 50% 23–26% 37.8% 50%

Eq. 6의 절반은 균등 평균입니다. 그래서 움직임이 거의 없는 하위 절반의 패치가 여전히 보상의 38%를 차지합니다.

2.2 CoD가 바꾸는 보상 차이

Table 2의 차이를 보상 단위로 환산합니다(R2). 가정은 두 가지입니다.

  • Table 2의 "상위 25% 움직임 패치"는 보상 가중치와 같은 변화 순위로 고른 것입니다.
  • 각 구간 안에서 코사인 차이는 균일합니다.

전체 패치 차이 Δ_all과 상위 25% 차이 Δ_top에서, 나머지 75% 패치의 차이는 Δ_rest = (Δ_all − 0.25 Δ_top) / 0.75입니다.

비교 Δ_all Δ_top25 Δ_rest Eq. 6 보상 차이
CoD vs Shuffle 0.024 0.071 0.0083 0.033
CoD vs Empty 0.020 0.079 0.0003 0.031
CoD vs CoD off 0.018 0.071 0.0003 0.028

해석:

  • 상위 25% 밖의 패치에서는 CoD가 예측을 거의 바꾸지 못합니다(Δ_rest ≈ 0.0003). 따라서 Eq. 6의 균등 평균 항은 CoD 선택에 거의 둔감하고, 보상의 CoD 의존성은 대부분 motion 가중 항에서 나옵니다.
  • "올바른 CoD를 쓴 경우"와 "CoD가 아예 없는 경우"의 차이가 코사인 0.03입니다. RL에서 비교하는 것은 그보다 비슷한 후보 4개 사이의 차이이므로, 실제 보상 폭은 0.03보다 작을 것으로 봅니다.

3. 형식 오류 벌칙과 그룹 표준화 (R3, R4)

3.1 형식 오류 벌칙이 신호보다 큽니다

형식이 깨진 CoD는 그룹 최저보다 0.05 낮은 보상을 받습니다. 이 값은 §2.2의 "CoD 있음 대 없음" 차이(평균 0.031)의 1.6배입니다. 4개 후보 중 하나가 형식 오류이면, 그룹 표준편차가 이 벌칙에 끌려갑니다. 그 결과 나머지 정상 후보 3개의 advantage 폭이 줄어듭니다(시행 20,000번).

그룹 표준화는 보상 차이가 0.001이든 0.1이든 advantage의 분산을 1로 맞춥니다. 그래서 신호 품질은 오직 잡음 / 후보 간 차이 비율로 정해집니다. 여기서 잡음은 예측 오차, DINO 특징 변동, 프레임 선택 오차 등입니다.

4. 보상이 모델 자신에 기대는 구조

RL 보상의 기준은 실제 실행 결과가 아닙니다. 모델 자신의 미래 예측(동결 projector + 계속 갱신되는 VLM이 만드는 질의 q̃)과 데이터 속 관찰 미래가 얼마나 일치하는지가 기준입니다. 이 구조는 세 가지를 뜻합니다.

  1. 역동역학 추론과 같습니다. "관찰된 미래를 가장 잘 설명하는 CoD"를 고르는 것은, 학습된 순방향 모델을 거꾸로 써서 행동을 추정하는 것과 같습니다. 순방향 모델은 teacher-forcing된 정답 CoD로만 학습되었으므로, 이 추정의 정확도는 순방향 모델의 정확도를 넘을 수 없습니다.
  2. 실제 탐색이 없습니다. 후보 CoD를 실행하지 않고 기록된 영상의 미래와 비교만 합니다. 그래서 오프라인 데이터에 없는 결과는 배울 수 없습니다. 이 방법이 개선할 수 있는 것은 "이미 일어난 일을 더 잘 설명하는 표현"입니다.
  3. 보상 해킹 경로가 있습니다. VLM이 갱신되면 같은 CoD에서도 q̃가 달라집니다. 그래서 CoD를 바꾸지 않고도 예측 질의 쪽 표현이 보상을 바꿀 수 있습니다. GRPO의 기울기는 CoD 토큰 log-prob로만 흐르지만, 같은 VLM 가중치를 공유합니다. KL 0.04, 학습률 10⁻⁶, 2k iteration, replay 0.001이 이 이동을 작게 묶어 두는 장치로 보입니다.

그러나 사람 데이터 두 종의 행동 표현 칸은 "One-second 6D/12D motion tokens"입니다. 손목 자세 주석이 CoD의 정답 토큰으로 쓰인다는 뜻입니다. 따라서 이 1,880시간은 "행동 레이블 없는 영상"이 아니라 손 자세가 주석된 영상입니다. 레이블 없는 영상의 효과를 보려면 같은 사람 영상에서 주석을 지우고 RL·미래 예측 손실만 쓰는 대조가 필요한데, 그런 실험은 없습니다.

Hydra-0 (hydra0/, [45]) 같은 NVIDIA이고 둘 다 "미래 예측"을 쓰지만 용도가 반대입니다. Hydra-0은 action flow에 조건화된 비디오 world model 자체를 시뮬레이터와 평가기로 씁니다. ThinkWorld는 1초 뒤 DINO 특징만 예측하고, 그 예측을 학습 신호로만 쓴 뒤 배포에서 버립니다. Hydra-0 분석에서 본 "평가 기준이 시뮬레이터"라는 문제가 ThinkWorld의 RL 보상에도 비슷하게 있습니다. 보상의 기준이 실제 결과가 아니라 모델 자신의 예측 일치도입니다.
AW-0 (agentic_wam/) AW-0은 코드·미래 영상·행동을 한 MoT에서 함께 denoise하고, 계획(코드)을 추론 때도 생성합니다. ThinkWorld의 CoD는 손목 움직임 토큰이고 추론 때는 생성하지 않습니다. 두 논문 모두 "계획 스트림"의 기여를 ablation으로 주장하므로, AW-0 분석의 "같이 빠지는 것" 점검이 여기에도 적용됩니다. ThinkWorld의 Table 3에서 미래 예측 손실을 더하면 Env +24.6%p인데, 이 손실만 따로 떼어 본 대조(CoD 없이 미래 예측만)는 있습니다. 반면 "CoD는 있고 미래 예측은 없는" 대조는 없습니다.
FlashDexRetarget, Do as I Do (flashdexretarget/, do_as_i_do/) 사람 시연을 로봇 데이터로 바꾸는 명시적 리타겟팅 계열입니다. ThinkWorld가 "자세 추정과 대응이 필요하다"고 비판하는 쪽입니다. ThinkWorld도 사람 손목 자세 주석을 쓰지만 기구학 대응은 하지 않고 공유 토큰 공간에 넣을 뿐입니다. 실행 가능한 로봇 궤적이 필요하면 리타겟팅이, VLM 표현만 바꾸려면 ThinkWorld 방식이 맞습니다.
DexPolicy, GQKAE (dexpolicy/, gqkae/) 둘 다 GRPO의 advantage 설계 문제를 다뤘습니다. DexPolicy는 궤적 전체에 같은 advantage를 주는 구현이었고, GQKAE는 최선 표본 NLL 항이 있었습니다. ThinkWorld도 후보 하나의 advantage를 모든 토큰이 공유하고, 그룹 표준화 뒤 배치 표준화를 합니다. 여기에 형식 오류 벌칙이 보상 폭보다 커서 표준화에 끼치는 영향이 큽니다(03 §3).
