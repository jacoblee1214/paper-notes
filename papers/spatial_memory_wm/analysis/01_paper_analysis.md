## 1. 문제와 주장

자기회귀 영상 세계 모델은 행동(카메라 이동, 텍스트)을 받아 프레임을 한 장씩 만듭니다. 문맥 창이 짧아서, 이미 본 장면을 다시 보면 앞서 만든 내용을 잊고 다른 장면을 만듭니다 (§1 첫 문단). 저자들은 이를 **길이 문제가 아니라 3D 일관성 문제**로 보고, 세 가지 기억을 나눠 씁니다.

- **작업 기억 (working memory):** 최근 생성 프레임. 움직임의 연속성을 담당합니다.
- **공간 기억 (spatial memory):** 생성된 정적 장면을 점군으로 누적한 것. 장면 구조의 장기 일관성을 담당합니다.
- **에피소드 기억 (episodic memory):** 과거의 대표 프레임 몇 장. 세부 시각 정보(질감, 인물 정체)를 담당합니다.

주장은 세 가지입니다 (Abstract, §1, §5).
1. 장기 일관성(재방문 시 같은 장면)이 기준선보다 좋다.
2. 영상 품질(VBench)이 기준선보다 좋다.
3. 문맥 길이(context length)가 늘어난다.

## 2. 방법

### 2.1 세 기억의 구성 (§3.2, Figure 2)

**공간 기억 (§3.2).** 정적 점군을 TSDF 융합으로 누적합니다. 동적 물체는 프레임마다 깊이가 달라서 TSDF 가중 평균에서 낮은 신뢰도로 남고 걸러진다고 설명합니다 (식 (2), 가중치 w_i = 1). 생성 중에는 새 프레임의 정적 점 지도를 **CUT3R**로 온라인 복원하고, TSDF로 동적 부분을 지운 뒤 기존 메모리에 맞춰 합칩니다 (부록 A, 그림 S1).

**작업 기억 (§3.2).** 최근 k+1개 잠재 프레임을 조건으로 넣고, N−k개의 미래 프레임을 생성합니다. 추론에서는 "최근 5개 과거 프레임"을 씁니다 (§4).

**에피소드 기억 (§3.2).** 생성 중에 **새로 드러난 미지 영역의 넓이**를 가시성 마스크로 재고, 임계값을 넘으면 그 프레임을 대표 프레임으로 저장합니다. 이 기준은 본문에 적혀 있지만 임계값 값은 적혀 있지 않습니다.

### 2.2 조건부 생성 구조 (§3.1, §3.3, Figure 2)

- 기반 모델: CogVideoX-5B-I2V (§4). 사전학습 가중치는 DaS에서 가져옵니다.
- 정적 점군 렌더링 (목표 궤적을 따라 그린 영상, 빈 곳은 검정)을 3D VAE로 잠재 공간에 넣고, **DiT 블록 앞 18개를 복사한 조건 DiT**가 처리합니다. 각 출력은 0으로 초기화한 선형층을 거쳐 본 DiT에 더합니다 (ControlNet 방식).
- 원본 영상 토큰의 마지막 5프레임을 목표 토큰과 프레임 축으로 이어 붙입니다 (동적 문맥).
- 에피소드 프레임은 같은 3D VAE로 인코딩해 참조 토큰으로 쓰고, **역사 교차 주의**(영상 토큰이 질의, 참조 토큰이 키와 값)를 둡니다.

### 2.3 데이터셋 (§3.4, 부록 A, Figure 3)

MiraData의 원영상을 97프레임 클립으로 자릅니다. 앞 49프레임은 원본(source), 뒤 48프레임은 목표(target)이고 전이 프레임 하나를 공유합니다. MegaSaM으로 카메라와 프레임별 깊이를 얻고, source에는 TSDF 융합으로 동적 영역을 지운 정적 지도를, target 궤적에는 그 지도를 렌더링해 정적 기준을 만듭니다. 행동 문장은 Qwen이 target 프레임에 달아 줍니다. 최종 데이터셋은 **90K 샘플**입니다 (§3.4). 테스트 세트는 학습에 안 쓴 **500개** 시퀀스입니다 (§4).

### 2.4 학습 설정 (§4)

CogVideoX-5B-I2V, 49프레임, 480×720, 6,000 이터레이션, 학습률 2e-5, 미니배치 8, A100 8장. 본문에는 옵티마이저, 스케줄러, 가중치 감쇠, 조건 프레임 드롭아웃 같은 값이 없습니다.

## 3. 실험

### 3.1 평가 지표와 기준선 (§4)

- **뷰 리콜 일관성:** 같은 카메라 자세를 정방향과 역방향 궤적에서 두 번 지나는 쌍을 만들어 PSNR, SSIM, LPIPS를 잽니다 (Table 1 왼쪽).
- **영상 품질:** VBench 여섯 지표 (Table 2).
- **사용자 연구:** 피험자 20명 (영상/3D/4D 생성 경험 1년 이상), 사례 14개, 4개 방법을 1–4 순위로 매긴 AHR (§4.3, Table 1 오른쪽).
- **기준선:** TrajectoryCrafter, DaS (DiffusionAsShader), Wan2.1-Inpainting. 모두 점군이나 포인트 맵 조건을 쓰는 방법입니다.

## 4. 한계 (논문이 스스로 적은 것, §5)

1. TSDF 융합은 카메라 자세가 급격히 바뀌는 궤적에서 부정확합니다. 그림 6은 4D 복원이 실패해 정적 점이 대부분 걸러지는 사례입니다.
2. 장기 드리프트(오차 누적으로 화질 저하)는 다루지 않는다고 적습니다.
3. 에피소드 기억은 "잊은 세부를 되살리는" 역할이고, 시간 창을 늘리는 방법(FramePack [87])과 상보적이라고 씁니다.
4. 딥페이크 위험을 명시합니다 (Societal Impacts).

## 5. 본문에서 확인되지 않는 것 (분석자 판단)

1. **공간 기억의 기여를 직접 재는 절제가 없습니다.** Table 3과 Figure 5 모두 공간 기억을 뺀 조건이 없습니다. 본문은 "각 기억 기제가 품질을 높인다"고 쓰지만 (§4.4), 공간 기억 쪽 근거는 기준선 비교(Table 1)뿐입니다. 기준선은 점군 조건을 쓰는 다른 모델이라 공간 기억 하나만의 효과가 아닙니다.
2. **문맥 길이(context length)를 재지 않습니다.** 초록과 §5는 "context length 개선"을 주장하지만, 몇 프레임 또는 몇 초까지 일관성이 유지되는지 측정한 표나 그림이 없습니다.
3. **통계 정보가 없습니다.** 뷰 리콜과 VBench는 평균만 있고 샘플별 분산, 신뢰구간, 검정이 없습니다. 사용자 연구도 순위 평균만 있습니다 (`03_analysis.md` §1에서 보충).
4. **학습과 추론의 재구성기가 다릅니다.** 데이터 생성은 MegaSaM, 추론 중 생성은 CUT3R입니다 (부록 A). 두 방식의 성능 차이는 "큰 차이가 없다"고만 적혀 있고 수치가 없습니다.
5. **사례 수가 맞지 않습니다.** 사용자 연구는 "14개 사례"이고, 정량 평가는 "500개 테스트 시퀀스"입니다. 두 집합의 관계는 본문에 없습니다.
6. **인용 표기 오류.** 부록 B에 `[86? , 69]`처럼 번호 옆에 `?`가 남은 인용이 있습니다.
7. **시간과 메모리 비용을 재지 않습니다.** 이터레이션마다 CUT3R 상태를 저장하고 점군을 합치는 비용이 있지만 측정값이 없습니다.

## 6. 이 논문의 자리 (요약)

- 같은 계열: 점군과 포인트 맵 조건 기반 카메라 제어 영상 생성 (DaS, TrajectoryCrafter, GEN3C).
- 다른 기억 방식: 과거 프레임을 압축해 문맥을 늘리는 방법 (FramePack, 논문 [87]).
