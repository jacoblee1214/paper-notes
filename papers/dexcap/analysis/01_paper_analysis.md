## 1. 한 문단 요약

DexCap은 손가락을 EMF 장갑(Rokoko)으로, 손목 6-DoF를 장갑 등의 T265 SLAM 카메라로, 장면을 가슴 LiDAR(L515) RGB-D로 기록하는 휴대용 모션캡처 장비입니다(§III-A). DexIL은 이 데이터를 LEAP 손 (4손가락, 16관절) 두 개와 Franka 팔 두 개로 옮기는 방법입니다. 손끝 IK로 관절을 맞추고(§IV-A), 세계 좌표계로 정렬한 점군을 입력으로 하는 point-cloud diffusion policy를 학습합니다(§IV-B). 선택적으로 사람이 발판 페달로 전환하며 정책 실행을 교정하는 mode를 더하고, 교정 궤적을 같은 데이터셋과 섞어 미세조정합니다(§IV-C). 여섯 과제(스펀지, 공, 접시, 상자 포장, 가위, 차 준비)에서 시험했고 (과제당 20회, 포장은 학습 객체 30회와 미학습 객체 45회), 실험 주장은 세 가지 축(인간 데이터만, 미학습 객체, 교정 추가)으로 나뉩니다(§V). 저자가 쓴 핵심 결과는 "인간 데이터 30분만으로 평균 72%", "미학습 객체 40%", "교정 30회 후 가위 45%와 차 준비 25%"입니다.

## 2. 문제 설정과 방법

### 2.1 하드웨어 (§III-A, 부록 A, B)

- **손가락:** Rokoko 장갑. 손끝 자석 센서의 위치를 손 허브 기준으로 잽니다. 60 Hz로 기록합니다(부록 B).
- **손목 6-DoF:** 장갑 등에 붙인 T265 두 대 (SLAM), 가슴 랙에 있는 T265 한 대 (세계 좌표 기준), 가슴 L515 RGB-D. 세 장비는 3D 프린트 랙에서 고정 변환을 가지고 있어 약 10초 (본문) 또는 15초 (부록 B) 안에 보정합니다 (`03` K3).
- **휴대:** Intel NUC 13 Pro (64 GB RAM, 2 TB SSD)와 40000 mAh 배터리, 총 3.96 lb(약 1.8 kg), 연속 수집 최대 40분.
- **비용:** "$4k 이하" (§III-A). 부품 목록은 본문에 없습니다.
- **로봇 쪽:** 같은 L515를 가슴 받침대에 옮겨 쓰고, 손목 T265는 로봇 실행에서 쓰지 않습니다 (보정 모드에만 사용).

### 2.2 리타게팅 (§IV-A, 부록 C)

- **손끝 IK:** 엄지와 나머지 손가락 손끝을 LEAP 손 손끝에 맞추는 IK. 새끼손가락 정보는 IK에서 뺍니다. 손목 6-DoF 초기값으로 IK를 시작합니다. LEAP 손은 인간 손보다 약 50% 큽니다 (§IV-A).
- **상태와 행동:** 상태는 손목 pose와 16 관절 위치 (s_t = (p_t, J_t)), 행동은 다음 상태 a_t = s_{t+1}입니다. 위치 제어입니다.
- **관찰:** RGB-D를 점군으로 바꾸고, 세계 좌표 (SLAM 기준 첫 프레임)로 옮겨 몸통 움직임을 없앱니다. 책상 아래 점은 버립니다. 로봇 손은 순운동학으로 만든 점을 점군에 더합니다 (§IV-B).
- **정렬:** 사람이 키보드 방향키로 점군 위치를 로봇 작업 공간에 맞춥니다. 장소당 1분 이내 (부록 C).

### 2.3 정책 (§IV-B, 부록 E, 표 V–VII)

- **구조:** diffusion policy (DDIM, 학습 100 단계, 추론 10 단계), UNet 채널 [256, 512, 1024], 커널 5, 관찰 지평 3. 행동 지평은 논문 표 VI에 없습니다. 공식 설정은 예측 20, 실행 10입니다 (`04` D4). 배치 16, 학습률 1e-4, 3000 에폭.
- **인코더:** 본문 "Ours (DP-perc)"는 **Perceiver** 인코더입니다 (표 VII 제목은 "DP-prec"으로 씁니다). 비교군은 PointNet (DP-point)과 원 점군 (DP-point-raw)입니다.
- **행동 차원:** 두 팔 (7-DoF) + 두 손 (16-DoF) × d 단계. 그림 4는 "46-dim action space"라고 적습니다. 본문은 팔을 "6-DoF pose"라고 씁니다. 46 = 2 × 7 + 2 × 16이므로 7은 위치 3 + 쿼터니언 4로 보입니다 (`04` D6).
- **데이터 증강:** 점군과 궤적에 무작위 2D 평행 이동.

### 2.4 사람 교정 (§IV-C, 부록 G)

- **잔차 모드:** 사람 손의 변화량 (Δp, ΔJ)을 정책 행동에 더합니다. a'_t = (p_{t+1} + α·Δp, J_{t+1} + β·ΔJ). β < 0.1을 권장합니다. α 값은 본문에 없습니다.
- **텔레옵 모드:** 발판 페달로 전환하면 정책을 끄고 사람 손목 변화를 로봇 손목에 그대로 씁니다. 손끝은 IK로 따릅니다.
- **데이터:** 교정 궤적은 별도 데이터셋 D'에 저장하고, D와 같은 확률로 섞어 미세조정합니다 (IWR 방식 [101]).
- **구현:** 손 데이터를 Redis로 중계하고 로봇 쪽은 델타를 받습니다. 행동 대신 명령 기록을 저장합니다 (부록 G).

## 3. 실험 결과

모든 로봇 실험은 두 팔, LEAP 손 (Franka + LEAP), 제어 20 Hz에서 수행됩니다. 각 조건은 시험 20회입니다 (Packaging은 학습 객체 30회와 미학습 객체 45회, 아래 표 II).

### 3.1 데이터 품질 (Q1, 그림 6–8)

- 그림 6은 점군 위에 사람 손과 리타게팅된 로봇 손을 겹쳐 보여 줍니다. 정량 지표가 없습니다.
- 그림 7은 HaMeR과의 정성 비교입니다. 가림 상황에서 HaMeR이 손을 못 찾거나 손끝을 틀린다고 씁니다. 정량 비교는 없습니다.
- 그림 8은 수집 처리량입니다. 공 수집 과제에서 DexCap이 원격조작보다 3배 빠르다고 씁니다. 그림에 수치가 없고 본문에도 표가 없습니다 (`03` C3).

### 3.2 DexCap 데이터만으로 학습 (Q2, 표 I)

| BC-RNN-img-mask | 0.25 | 0.10 | 0.10 | 0.15 |

- 전체 칸은 세 과제 평균입니다. 모든 칸이 20회 중 정수 개수로 복원됩니다 (`03` K1).
- 이미지 입력은 가림 마스크가 있어야 0이 아닙니다 (DP-img 0%, DP-img-mask 42%).

### 3.3 인코더와 모델 비교 (Q3, 표 I)

- 본문: 점군 입력 > 마스크 이미지 입력 > 원시 이미지, 확산 > MLP (BC-RNN) 순서.
- 본문: Perceiver가 PointNet보다 Plate에서 20%p 높음 (0.70 대 0.50). 이 차이로 Perceiver를 기본값으로 정했습니다.

### 3.4 미학습 객체와 실제 환경 데이터 (Q4, 표 II, Packaging)

|---|---|---|---|---|---|---|
| BC-RNN-img-mask | 0.00 | 0.00 | 0.00 | 0.23 | 0.07 | 0.00 |
| BC-RNN-point | 0.33 | 0.23 | 0.16 | 0.40 | 0.27 | 0.22 |

- 본문: 이미지 기반은 움직이는 카메라 때문에 실패하고, 점군은 세계 좌표 정렬로 안정화된다. 미학습 객체 40%.
- 실패 원인 두 가지를 씁니다: 힘 정보가 없어 상자 덮개를 누르지 못함, 덮개가 가슴 카메라 밖으로 나감.

### 3.5 사람 교정 (Q5, 표 II 오른쪽, 표 III, 표 IV)

- 본문: 교정 30회로 DP-img-mask가 전체 0%에서 33%로 올라갑니다. 저자는 교정 데이터가 고정 카메라에서 얻어져 평가 조건과 맞기 때문이라고 설명합니다.
- 본문: 제안 모델은 교정으로 10%p 올라갑니다 (0.47 → 0.57). 미학습 객체는 거의 변하지 않습니다 (0.40 → 0.42).

### 3.6 어려운 과제 (Q6, 표 III, 표 IV)

- **가위 (표 III):** 데이터만 → 교정 30회 후, Subtask 0 → 9/20 (45%), 전체 0 → 4/20 (20%). 대조군 BC-RNN-point는 교정 후 2/20과 0/20입니다.
- **차 준비 (표 IV):** 데이터만 6/20 (Subtask, 뚜껑 열기 30%) → 교정 후 13/20 (65%). 전체 0 → 5/20 (25%).

## 4. 주장과 근거의 간격 (요약)

자세한 판정은 `03` §4 (C 항목)입니다.

1. **"제안 모델이 최고":** 표 I에서 제안 모델과 DP-point의 차이는 8.3%p, Fisher p = 0.44입니다. 가장 가까운 대안인 DP-point-raw와는 11.7%p, p = 0.25입니다. 통계적으로 지지되지 않습니다. 공 수집 과제에서는 제안 모델이 DP-point-raw (14/20)보다 낮습니다 (12/20).
2. **Perceiver 선택:** Plate에서 14/20 대 10/20, p = 0.33입니다. 선택 근거로는 약합니다.
3. **점군이 이미지보다 낫다:** DP-point 대 DP-img-mask (풀링 38/60 대 25/60), p = 0.03. 지지됩니다. 단 한 시드입니다.
4. **미학습 객체 40%:** 18/45, 95% 구간 약 27–55%. 대조군 BC-RNN-point 7/45와 p = 0.018입니다. 지지됩니다.
5. **교정 효과:** DP-img-mask의 0 → 10/30 (p < 0.001)은 교정 데이터가 추가된 효과이면서 평가 조건과 맞춘 효과가 섞여 있어 원인을 분리하지 못했습니다. 제안 모델의 47 → 57%는 p = 0.61입니다.
6. **속도 3배, 드리프트 차이, 하드웨어 비용:** 수치가 없거나 부분만 있습니다. 드리프트는 방향이 분명합니다. 반복 횟수를 가정하면 n = 3에서 p ≈ 0.05–0.06, n ≥ 5에서 p < 0.01입니다 (`03` §1.6).
