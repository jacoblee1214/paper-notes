# 04. 주장 검증과 구현 가능성

공식 코드가 없어서(`02` §2) 코드 대조(D 항목) 대신 **논문 주장 대 수치와 서술**을 대조합니다(C 항목). 판정은 네 가지입니다. **확인** (수치와 서술이 맞고 표본이 주장을 뒷받침), **부분 확인** (방향은 맞지만 표본이나 정의가 부족), **미확인** (논문에 판정할 정보가 없음), **불일치** (수치나 서술이 어긋남).

## 2. 불일치와 빠진 정보

- **불일치 (사소).** 본문 +31%와 계산 +31.7%(`03` K2). 프로젝트 페이지의 "held-out objects"와 논문의 "held-out recordings"(`03` K5). 초록의 "unseen perturbations"와 표 3의 "sim test"가 같은 집합인지 불분명(`03` K3). 드리프트 5.1 mm가 성공 기준 5 mm를 넘음(`03` K8).
- **인용 (확인 필요).** 영상 생성기 인용(arXiv:2503.20314)이 Wan2.1 보고서 제목을 가리킵니다. 본문은 Wan2.2라고 씁니다(`03` K7).
- **빠진 정보 (재현의 전제).**
  1. 닫힘 힘을 정하는 식(포즈 너머로 얼마나 더 닫는가)과 보정 규칙
  2. 객체 검사 기준과 실패 객체 수
  3. 손 모델 맞춤 최적화(목적 함수, 관절 수, 손가락 한계)
  4. 정책 학습 설정(N0-VTLA 설정 변경 여부, 데이터 양, 시드)
  5. 접촉 예측기 구조와 평가 프레임 수
  6. 기록 선택 기준, 기록 수, 기록 길이, 시도 수
  7. grip 비율의 집계 방식
  8. 섭동 종류와 횟수(35/36의 분모 36의 구성)

## 3. 공식 코드 상태

- 논문과 프로젝트 페이지에 코드 링크가 없습니다. TouchTwin 조직에는 프로젝트 페이지 저장소만 있습니다(`02` §2).
- 따라서 공식 코드와 논문의 설정 차이를 검사할 수 없습니다. 이 검사가 가능해지면 `04_code_verification.md`를 새로 만들어야 합니다.

## 4. 구현 가능성 판정

**판정: 논문 규모의 재현은 이 맥에서 불가능합니다. 방법의 핵심 원리(촉각으로 닫힘 힘을 정해 물리 재생을 만드는 것)는 CPU MuJoCo로 작은 규모 구현이 가능합니다. 단, 논문의 수치를 재현하지는 못합니다.**

이 맥의 조건: Apple M4 Pro, 약 24 GiB 통합 메모리, MPS 사용 가능, CUDA 없음. CPU에서 쓸 수 있는 시뮬레이션 패키지는 MuJoCo 4.0.0과 torch 2.15입니다(로컬 설치 확인).

| 구성 요소 | 이 맥에서 | 필요 자원 | 판정 |
|---|---|---|---|
| 표 재계산과 검정 | 완료 | 없음 | 가능, 완료 |
| 머그 파지 물리 토이 (자체 모델) | 가능 (CPU, MuJoCo) | 자체 머그 모델 | 시작 가능. 논문 수치 재현은 아님 |
| TouchScale 기록 한 개의 시뮬 재생 | 조건부 | TouchScale 데이터 다운로드(500시간, 크기 미확인), 손 추정(WiLoR), 객체 프로그램(코딩 에이전트, LLM 호출) | 조건부 (데이터와 API 호출 승인 필요) |
| 촉각 접촉 예측기 (표 2) | 조건부 | 시뮬 재생 데이터, 구조 미공개 | 불가 (데이터와 구조 미확보) |
| 손 정책 (표 3) | 불가 | GPU 학습, N0-VTLA 설정 미확인 | 불가 |
| Wan2.2 조건부 영상 생성 (표 1) | 불가 | 대형 GPU 모델과 추론 시간 | 불가 (측정하지 않음) |
| 실로봇, 손 로봇 전이 | 불가 | 로봇과 촉각 장갑 | 불가 |

**노력 추정 (측정 전, 추정입니다).**
- 머그 토이로 "포즈 대 촉각 닫힘의 힘 비율"을 보는 것: 1–2일.
- 기록 한 개를 MuJoCo로 재생하고 힘 시계열을 장갑과 비교하는 것: 2–4주. 데이터 준비와 손 모델 맞춤이 대부분입니다.
- 정책과 영상까지 포함한 재현: 해당 없음(불가).

**판정의 근거.** 원리는 MuJoCo에서 구현할 수 있습니다. 그러나 (1) 닫힘 힘을 정하는 식이 공개되지 않았고, (2) 코드가 없고, (3) 정책과 영상은 GPU 전제이며, (4) 데이터가 500시간 규모라서, 논문 수치를 같은 조건에서 재현하는 것은 불가능합니다.
