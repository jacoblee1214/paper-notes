## 3. 검증하지 못한 것과 필요한 정보

1. **학습 시드와 체크포인트 수.** 조건당 학습 실행이 하나로 보입니다. 시드 분산이 없어서 표 2의 차이가 방법 효과인지 학습 운이 섞였는지 가릴 수 없습니다. 가장 큰 공백입니다.
2. **표 3 FR3 열과 그림 6의 시도 출처.** 표 2와 같은 값이 나옵니다. 재사용 여부를 확인해야 합니다.
3. **그림 8 시도별 시간.** 평균 시간의 분산과 실패 처리 방식을 알아야 시간 차이를 검정할 수 있습니다.
4. **배포 쪽 지연과 추적 오차.** 수집과 배포의 제로 갭을 정량으로 말하려면 시간 정렬 오차, 목표 추적 오차, 보정 오차의 크기가 필요합니다.
5. **장갑 매핑의 정확도.** 엔코더 해상도와 선형 매핑 오차가 손 명령에 주는 영향을 모릅니다.
6. **데이터 공개 여부.** "공개 예정"이라고만 적혀 있습니다. 공개되면 학습 재현의 가장 큰 장벽이 낮아집니다.

## 4. 구현 가능성 판정

**판정: 전체 재현은 이 맥에서 불가능합니다. 소프트웨어 부분은 부분적으로 구현할 수 있고, 데이터 공개 전에는 학습을 시작할 수 없습니다.**

이 맥은 Apple M4 Pro, 약 24 GiB 메모리, MPS 사용, CUDA 없음입니다.

| 항목 | 필요 자원 | 이 맥에서 | 판정 |
|---|---|---|---|
| 손 모듈, 장갑, 촉각 센서 제작 | 웜 기어 손 설계, PC 셸, 압저항 촉각, 자기 엔코더 장갑, ESP32-S3 | 설계와 부품 목록이 공개되지 않음 | **불가** |
| 교차 로봇 배포 (FR3, RM65, Adam-U) | 세 로봇, IK와 저수준 컨트롤러 | 로봇 없음 | **불가** |
| 실로봇 과제 8개, 과제당 20회 | 로봇, 시험 공간, 과제 도구와 픽스처, 시간 | 불가 | **불가** |
| 수집 효율 비교 (Fig. 8) | 사람 운영자, AVP와 Manus 장비 | 불가 | **불가** |
| 상대 행동 라벨 생성 (식 2–3, 4.2절 목표) | numpy, scipy | 가능. 토이 검사 완료 (`03` §3) | **시작 가능** (실제 데이터 형식이 필요) |
| ACT 학습 (ResNet-18, 256×256, 200k 스텝, 배치 128) | CUDA GPU 전제. 공식 ACT 코드는 MIT (`tonyzhaozh/act`) | MPS에서 소규모 학습 가능 여부는 측정 전. 전체 학습 시간은 추정 불가 | **조건부** (데이터 공개 후, MPS 시간 측정 후 판정) |
| 촉각 제거 절제 (w/o tactile) | ACT 학습과 같음 | 같음 | **조건부** |
| 통계 재계산과 일관성 검사 | Python | 완료 | 완료 |

**노력 추정 (측정 없음, 추정):**
- 라벨 생성기와 데이터 파이프라인 (상대 행동, 동기화, 촉각 입력)을 자체 구현: 1–2주. 실제 데이터 형식이 공개된 뒤에 가능.
- ACT를 MPS나 GPU에서 학습하는 최소 재현: 공개 데이터가 있으면 수 일 (GPU 여부에 따라 크게 다름).
- 하드웨어 재제작과 로봇 3종 실험: 이 저장소의 범위 밖. 수개월 규모로 추정하지만 근거는 없음.
