- 제목: *WorldVLA: Towards Autoregressive Action World Model*
- 저자: Jun Cen, Chaohui Yu, Hangjie Yuan, Yuming Jiang, Siteng Huang, Jiayan Guo, Xin Li, Yibing Song, Hao Luo, Fan Wang, Deli Zhao, Hao Chen (Alibaba DAMO Academy, Hupan Lab, Zhejiang Univ.)
- 원문: `paper/paper.pdf` (14쪽, 3.5 MB), 텍스트 `paper/paper.txt`. 인용 번호는 원문의 절·표·식 번호를 씁니다.

## 1. 한 문단 요약

WorldVLA는 하나의 자기회귀(autoregressive) Transformer가 **행동 모델(정책)** 과 **세계 모델(다음 프레임 생성)** 을 동시에 하도록 학습합니다. 백본은 Chameleon 7B이고, 이미지·텍스트·행동을 각각 토큰화해 한 어휘(vocabulary) 안에 넣습니다(3.2). 두 역할은 데이터 형식으로 나뉩니다. 행동 모델은 "지시문 + 이미지 2장 → 행동 K개"를, 세계 모델은 "이미지 + 행동 → 다음 이미지"를 학습합니다(3.3). 핵심 기여는 두 가지입니다. 첫째, 두 역할을 섞어 학습하면 행동 성공률과 영상 생성 품질이 각각 좋아진다고 주장합니다(Table 3, Table 4). 둘째, 자기회귀로 행동 여러 개(action chunk)를 만들면 뒤의 행동이 앞 행동의 오류를 물려받는 문제가 생기는데, 이를 막기 위해 **행동 블록 사이 attention을 가리는 마스크**를 제안합니다(3.3 Attention Mask, Fig. 3b).

## 2. 방법 (3장)

| 요소 | 내용 | 근거 |
|---|---|---|
| 백본 | Chameleon 초기화. 이미지 VQ-GAN(압축 16, 코드북 8192), 256×256은 이미지당 256토큰, 512×512는 1024토큰 | 3.2 |
| 행동 토큰화 | 행동 7차원(상대 위치 3, 상대 회전 3, 그리퍼 1)을 차원마다 256 bin으로 이산화. bin 폭은 학습 데이터 범위로 정함 | 3.2 |
| 텍스트 | BPE 65,536 어휘(이미지 8192, 행동 256 포함) | 3.2 |
| 행동 모델 데이터 | `[BOS] text [BOI] image×M [EOI] [BOA] action×K [EOA]`, 손실은 행동 토큰에만 계산 (M=2 입력 이미지, K=5 또는 10) | 3.3, 4.1 |
| 세계 모델 데이터 | `[BOI] image [EOI] [BOA] action [EOA] [BOI] image [EOI]`, 손실은 생성된 이미지 토큰에만 계산 (N=1) | 3.3 |
| 전체 손실 | L = L_action + α·L_world, α = 0.04 | 식 (4) |
| 마스크 | 행동 블록은 이전 행동 블록을 보지 않음. 세계 모델 부분은 일반 causal 마스크 | 3.3, Fig. 3 |

식 (1)–(3)은 행동 정책 π_θ(a_t | o_{t-h:t}, l)과 세계 모델 f_φ(o_t | o_{t-h:t-1}, a_{t-h:t-1})을 하나의 M_ψ로 묶는다는 정의입니다(3.1). 수학적 새 결과는 없고 정의만 있습니다.

## 3. 실험 설정 (4.1)

- 벤치마크: LIBERO Spatial, Object, Goal, Long (LIBERO-90은 사전학습용으로 언급만, 4.1).
- 데이터: 실패 궤적과 no-op 행동 제거(OpenVLA 방식). 세계 모델 평가를 위해 **궤적의 90%를 학습, 10%를 검증**으로 나눕니다(4.1 Datasets). 표 2만 전체 데이터를 학습에 씁니다.
- 평가: 과제당 롤아웃 50회 성공률(SR). 세계 모델은 검증 세트에서 FVD, PSNR, SSIM, LPIPS.
- 기본 설정: 행동 청크 K=10(Long), K=5(나머지 3개), 입력 이미지 2장, 세계 모델 1라운드, α=0.04.
- **보고되지 않은 것:** 옵티마이저, 학습률, 배치 크기, 에포크 수, GPU 수와 학습 시간, 시드 수, 신뢰구간. (코드에는 있음. `04_code_verification.md` 참고.)

## 4. 주요 결과와 해석

### 4.1 벤치마크 (Table 2)
- WorldVLA 256: 평균 79.1, 512: 81.8. OpenVLA(이산 행동 모델, 사전학습 있음): 76.5. OpenVLA-OFT(연속 행동, 사전학습): 95.4.
- 저자들은 "사전학습 없이도 OpenVLA보다 좋다"고 주장합니다(4.2). 그러나 두 값의 차이 2.6pp는 과제당 50회 롤아웃으로는 통계적으로 구별되지 않습니다(`03_analysis.md` §2). 또 OpenVLA 수치는 다른 논문에서 가져온 것이라 학습 조건이 같지 않습니다.
- 해상도 효과(512 > 256)는 Chameleon 사전학습 해상도(512)로 설명합니다(4.2).

### 4.2 세계 모델이 행동을 돕는가 (Table 3, 행 1 대 2, 행 4 대 5)
- 행동 모델만(행 1) 62.8, 세계 모델 데이터 추가(행 2) 67.2 → +4.4pp. 청크 없음 조건.
- 마스크 있는 청크(행 4) 76.6, 마스크+세계 모델(행 5) 78.1 → +1.5pp.
- 두 차이 모두 과제당 50회 기준으로 통계적으로 유의하지 않습니다(p≈0.36, 0.72; `03` §2). 저자 주장은 방향은 맞을 수 있으나 증거는 약합니다.

### 4.3 행동 청크와 마스크 (Table 3 행 3 대 4, Fig. 6)
- 가장 큰 효과입니다. 마스크 없이 청크를 쓰면(행 3) 평균 54.0, 마스크를 쓰면(행 4) 76.6 → +22.6pp. Spatial +45.1pp, Long +32.4pp로 과제별로도 크고 유의합니다(p<0.001; `03` §2).
- 해석은 "뒤 행동이 앞 행동에 과하게 의존해 오차가 쌓인다"입니다(4.2). 이 메커니즘은 Fig. 6의 청크 길이별 곡선으로 뒷받침하지만 **Fig. 6의 수치는 그림에만 있어** 표로 재계산할 수 없습니다.
- 주의: 코드를 보면 마스크는 "행동 블록 간" 차단입니다. 같은 청크 안의 토큰은 여전히 causal입니다(`04` D5). 논문 Fig. 3(b)가 말하는 "병렬 생성"과 정확히 같지 않습니다.

### 4.4 세계 모델의 영상 품질 (Table 4)
- 10프레임: FVD 250.0 → 255.1(행동 세계 모델이 나쁨), PSNR·LPIPS는 근소하게 좋음.
- 50프레임: FVD 718.6 → 674.1(**−6.2%**), PSNR 23.98 → 24.30, LPIPS 15.60 → 15.44.
- 서론(1장)은 "FVD를 10% 줄였다"고 씁니다. **표 4로는 50프레임에서 6.2%가 최대**이고, 10프레임에서는 오히려 늘었습니다. 서론 수치와 표가 맞지 않습니다(`03` §3).

### 4.5 기타 절제(ablation)
- 입력 프레임 수(Table 5): 1·2·4 프레임. 2프레임을 기본값으로 택했다고 씁니다. 표 5의 2프레임 값 84.4는 표 3의 행 4 Goal SR과 같고, 기본 설정(행 5, Goal 85.1, 평균 78.1)과는 맞지 않습니다. 열 이름도 없어서 **어떤 지표인지 확실하지 않습니다**.
- 세계 모델 사전학습(Table 6): "w/o" 행은 표 3 행 1과 같고, "w/" 행(평균 66.8)은 표 3 행 2(평균 67.2)와 과제별 값이 다릅니다(Object 84.0 vs 88.0). 같은 설정인지 설명이 없습니다.
- Fig. 7(행동 세계 모델 대 영상 예측 모델)은 **그림만** 있고 수치가 없어 검증하지 못했습니다.

## 6. 저자들이 밝힌 한계 (5장)
- 이산 이미지 토크나이저의 지각 표현력 한계, 통합 토크나이저 필요.
- 보조 행동 헤드 추가 가능성.
- 데이터·모델 규모 확장은 미래 과제.

논문에 없는 한계 (우리가 보는 것): 실제 로봇 실험 없음, LIBERO 시뮬레이션만, 과제당 50회, 비교 베이스라인이 같은 학습 예산으로 재학습되지 않음(OpenVLA 등은 다른 논문 수치), 학습 비용 미기재.

## 7. 원문 내부 불일치 목록

## 8. 판단
- 아이디어(행동과 영상을 한 자기회귀 모델로 묶기, 행동 블록 마스크)는 명확하고 재사용할 가치가 있습니다.
- 실험 증거는 **마스크 효과(표 3 행 3 대 4)** 만 강합니다. 세계 모델이 행동을 돕는다는 주장과 FVD 개선 주장은 표로 보면 약합니다.
- 재현에 필요한 학습 설정 일부(lr, 배치, 에포크, 손실 정규화)가 논문에 없고 코드에만 있습니다.
