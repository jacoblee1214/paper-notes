1. Abstract와 문제 설정

문제. 사람 영상에는 로봇 행동 레이블이 없고, 로봇끼리도 제어 공간이 다릅니다. 그래서 같은 행동이 embodiment마다 다른 저수준 행동으로 기록됩니다(§1). latent action model(LAM)은 연속 프레임의 변화를 압축한 latent action으로 이 문제를 풀려 하지만, 재구성 정확도만으로는 latent action이 "행동"만 담는다는 보장이 없습니다. 재구성에 도움이 되면 시점이나 장면 외관 같은 도메인 정보도 함께 담깁니다(§1, Nikulin et al. 2025 인용).

주장.

  1. 영상 diffusion 모델의 시공간 특징은 움직임·대응·기하를 이미 담고 있으므로, 여기서 latent action을 직접 읽으면 좋습니다(§1, §2).
  2. 같은 모델의 생성 prior가 외관을 책임지므로, decoder가 첫 프레임과 latent action으로 미래를 재구성하게 하면 latent action은 움직임에 집중하게 됩니다(§3.2).
  3. 그 결과 LARYBench에서 LAM 중 최고 성능을 냈고(Table 1), 짝지은 학습 데이터 없이도 임의 embodiment 간 영상 전이와 사람→로봇 zero-shot 행동 전이가 됩니다(§4.2–4.3).
  4. 압축 코드를 예측 대상으로 하는 정책은 미래 영상을 생성하는 정책(Mimic-Video)보다 성공률이 높고 19.1배 빠릅니다(Table 3).

기여(§1). (i) 영상 diffusion 모델의 시공간 prior와 생성 prior로 범용 latent action을 학습하는 틀, (ii) 짝지은 데이터 없는 영상·행동 전이와 압축 latent 코드를 예측 대상으로 하는 정책.

2. Method

2.1 백본: Cosmos-Predict2.5 (§3.1, Eq. 1)

causal 영상 autoencoder가 클립을 latent frame N개 V = (V₀, …, V_{N−1})로 압축합니다. V₀는 첫 프레임만 담습니다. 이 latent를 공간 패치 토큰으로 나눠 시공간 attention으로 모델링하고, 첫 프레임과 텍스트 등의 조건 c 아래에서 flow matching으로 학습합니다. x_τ = (1 − τ)x + τε, 손실은 ‖v_θ(x_τ, τ; c) − (ε − x)‖²입니다(Eq. 1).

2.2 Encoder: query 토큰으로 latent action 읽기 (§3.2, Eq. 2, Fig. 2)

  • 학습 가능한 query 토큰 q를 영상 토큰 열에 이어 붙여, 백본의 시공간 attention을 함께 통과시킵니다.
  • latent frame V_g마다 query K = 4개(q_g)를 배정하고, 문맥화된 출력이 latent-action 그룹 Q_g가 됩니다. 모든 그룹을 한 번의 forward로 뽑습니다: Q = E_φ(q; V, ℓ) (Eq. 2).
  • ℓ은 언어 지시이고, 백본의 원래 cross-attention으로 encoder에 들어갑니다. decoder에는 텍스트가 들어가지 않습니다. 이 차이는 §4에서 다시 다룹니다.
  • attention 마스크(Fig. 2b): query → 영상은 프레임 causal이라 Q_g는 V_{0:g}만 봅니다. query끼리는 제한이 없습니다.
  • encoder는 사전학습 백본에 rank-16 LoRA를 붙여 학습합니다(백본 가중치는 고정, 부록 A.2).

2.3 Decoder: 생성 재구성과 보조 행동 손실 (§3.2, Eq. 3–4)

  • 같은 백본을 별도 rank-16 LoRA로 decoder로 씁니다. 조건은 V₀와 Q_{0:N−1}이고 텍스트는 넣지 않습니다.
  • 행동 레이블이 있는 클립에서는 고유수용 상태 p₀를 받아 행동 chunk도 함께 decode합니다: V̂, Â = D_θ(Q_{0:N−1}, V₀, p₀) (Eq. 3).
  • decoder 마스크: query는 조건으로만 쓰이고 아무것도 보지 않습니다. 영상 프레임 V_t는 Q_{0:t}를, 행동 chunk A_m은 Q_{0:m}을 보며, 영상과 행동 스트림은 서로를 보지 않습니다.
  • 손실: L = L_video + λ L_action, 행동 레이블이 없는 클립은 λ = 0입니다(Eq. 4). 레이블이 있으면 두 손실의 가중치가 같습니다(부록 A.2).

2.4 전이 (§3.3, Eq. 5, Fig. 3a)

원본 영상에서 고정된 encoder로 Q_src = E_φ(q; V_src, ℓ_src)를 뽑고, 두 가지로 씁니다.

  • 영상 전이: V̂_tgt = D_θ(Q_src, V₀^tgt). 대상 장면의 첫 프레임에 원본 움직임을 입힙니다.
  • 행동 전이: Â_tgt = D_θ(Q_src, p₀^tgt). 대상 로봇의 초기 상태에서 실행할 행동을 decode합니다.

논문은 이 전이 능력이 학습 목표에 없던 창발 성질이라고 설명합니다(§3.3). 추가 학습은 하지 않습니다.

2.5 압축과 정책 (§3.4, Eq. 6–9, 부록 A.3–A.4)

  • 압축(FAE): latent-action 토큰은 개수는 적지만 각 토큰이 백본 폭(2,048차원)을 그대로 가집니다. 논문도 이 때문에 직접 diffusion하기에는 차원이 높다고 적습니다(§3.4). 그래서 encoder를 고정하고 변분 bottleneck으로 토큰마다 2,048 → 32차원으로 줄입니다. 손실은 ‖Q̂ − Q‖² + β KL이고 β = 0.01입니다(Eq. 8–9). encoder는 self-attention 블록 하나, decoder는 6층 transformer, 학습은 50k step입니다. 정책 학습에는 사후 평균 Z = μ_ψ(Q)를 씁니다.
  • 정책: π(Z, A | V₀, ℓ, p₀)(Eq. 6). 같은 영상 백본이 현재 프레임과 지시에서 압축 코드 Z를 생성하고, 별도의 Action DiT가 생성기의 latent-action 특징, 관찰, 지시, 상태를 보고 행동을 생성합니다. 행동 토큰은 latent 특징을 보지만 반대는 아닙니다. 손실은 L_latent + λ L_action이고, 사람 영상은 λ = 0입니다(Eq. 7).
  • 생성기 사전학습: DreamX 사전학습 데이터의 약 1/3로 rank-128 LoRA를 100k step 학습합니다(H200 2장, 배치 60). Action DiT는 따로 사전학습하지 않고 과제별 학습 때 함께 학습합니다(부록 A.4).

3.3 행동 전이 (§4.3, Fig. 6, 부록 B.2)

4. Limitations

논문에는 한계 절이 따로 없습니다. 윤리 절에서 "평가하지 않은 설정에서는 실패할 수 있다"고만 적었습니다. 아래는 이 분석에서 정리한 한계입니다.

  1. 정렬이 왜 생기는지 설명이 없습니다. 재구성 손실은 embodiment마다 다른 latent 좌표계를 허용합니다. 사람 영상에는 행동 손실이 없으므로(λ = 0), 사람과 로봇의 latent가 같은 좌표에 놓일 압력은 (a) 가중치 공유와 (b) 같은 행동이 이미지에서 비슷하게 움직여 보이는 것뿐입니다. toy(03 §1)에서 공유 encoder는 이미지 공간의 움직임이 일치할 때(θ ≈ 0)만 정렬되고, 시점 차이로 움직임이 돌아 보이면 전이 오차가 2(1 − cos θ)로 커졌습니다.
  2. 전이 증거가 쉬운 경우에 몰려 있습니다. Fig. 5(HumanAndRobot)와 Fig. 6(실물)의 사람 영상은 로봇 카메라와 같은 위쪽 시점에서 찍었습니다. 학습 데이터의 사람 영상(EgoDex, EgoVerse)은 1인칭인데, 1인칭 → 3인칭 전이의 정량 평가는 없습니다.
  3. 텍스트 경로가 통제되지 않았습니다. encoder는 지시 ℓ을 받고 decoder는 받지 않습니다(Eq. 2, §3.2). 전이할 때 Q_src에는 원본 지시(예: "Grab red cube and pull to plate")의 의미가 들어갈 수 있고, decoder는 그 의미를 대상 장면에서 실현할 수 있습니다. 빈 지시로 encode하는 ablation이 없어서, 전이 중 어디까지가 움직임이고 어디까지가 과제 의미인지 가를 수 없습니다.
  4. "300× 압축"은 토큰 개수 기준입니다. 각 토큰은 2,048차원이라 프레임당 8,192개 실수이고, VAE latent(프레임당 76,800개로 추정) 대비 9.4배입니다. 진짜 작은 코드는 FAE-32(128개)입니다(03 §3, 04 C7).
  5. LARYBench 비교 조건이 다릅니다. 영상 기반 모델만 중간 프레임을 받았고, DreamX 학습 데이터의 37.4%인 AgiBot이 평가셋 AgiBotWorld-Beta와 같은 출처입니다(학습·평가 분리 여부 미보고).
  6. 정책 실험의 표본과 기준선이 작습니다. 과제 하나, 설정당 10회, 체크포인트 1개입니다. 기준선은 Mimic-Video 하나이고 사전학습 출발점이 다릅니다. 차이는 push에서만 나옵니다.
  7. 재현 정보가 부족합니다. 코드·가중치가 없고, 사전학습 연산량·배치·seed, 행동 레이블 클립 비율, 정책에 쓴 사람 영상 수가 빠져 있습니다(04 §2).
  8. 사소한 표기 문제: VideoWorld2가 참고문헌에 같은 논문으로 두 번(Ren et al. 2026a, 2026b) 들어가 있습니다. LARY-Bench/LARYBench, MolmoAct2-BimanualYAM/MolmoAct-BimanualYAM, reach/approach처럼 같은 대상을 다르게 부릅니다.

1. 재구성만으로 사람·로봇 latent action이 정렬되는가 (toy)

1.1 질문

DreamX가 내세우는 전이(Eq. 5)는 사람 영상에서 뽑은 Q_src를 로봇의 행동 branch로 decode합니다. 이것이 되려면 같은 행동이 사람과 로봇에서 같은 latent 좌표로 가야 합니다. 그런데 학습 손실(Eq. 4)에는 이를 직접 요구하는 항이 없습니다.

  • 재구성 손실은 embodiment마다 latent를 가역 변환해도 값이 같습니다. decoder가 첫 프레임 V₀로 embodiment를 알 수 있으므로, 사람용 좌표계와 로봇용 좌표계를 따로 써도 재구성은 똑같이 잘 됩니다.
  • 행동 보조 손실은 로봇 클립에만 있습니다(사람은 λ = 0). 그래서 로봇 latent만 행동 좌표에 묶입니다.

남는 정렬 압력은 두 가지입니다. (a) encoder 가중치 공유, (b) 같은 행동이 이미지에서 비슷하게 움직여 보이는 것. toy는 이 둘이 각각 얼마나 일을 하는지 봅니다.

1.2 모형

  • 행동 a ∈ ℝ², 영상 공간의 움직임 Δo_e = R_e a + 잡음(8차원).
  • 로봇 렌더러 R_r은 직교 열 2개입니다. 사람 렌더러는 R_h = R_r Q(θ) + η R_⊥ 를 열마다 정규화한 것입니다. θ는 시점 차이 때문에 이미지 평면에서 움직임이 돌아 보이는 각도, η = 0.3은 손이 그리퍼와 다르게 보이는 정도입니다.
  • encoder z = E_e Δo, decoder Δo ≈ D_e z(embodiment별), 로봇 클립에만 행동 head 손실 ‖H z − a‖²(λ = 1, H 공유)를 둡니다. DreamX의 Eq. 3–4를 선형으로 줄인 구조입니다.
  • 조건 세 가지:
    • S: 공유 encoder. 가중치 공유가 유일한 정렬 압력입니다.
    • I: embodiment별 encoder. 강한 비선형 encoder가 입력만 보고 embodiment를 알아보는 경우를 근사합니다.
    • P: embodiment별 encoder에, 짝지은 사람·로봇 클립 5%로 정렬 손실 ‖z_h − z_r‖²(가중치 5)를 더합니다. DreamX가 쓰지 않는 신호입니다.
  • 지표: (1) 탐침 R²: embodiment마다 z → a 선형 회귀를 따로 학습합니다. LARYBench 방식입니다. (2) 전이 오차 ‖H z_h − a‖²/‖a‖²: 사람 latent를 로봇 행동 head로 풀었을 때의 오차입니다. DreamX의 행동 전이(Eq. 5)에 해당합니다.
  • Adam(lr 0.02, weight decay 1e-3) 2,500 step, embodiment당 1,000표본, seed 5개.

1.4 읽기

  1. 공유 encoder는 이미지 공간의 움직임이 일치할 때만 정렬됩니다. S의 전이 오차는 이론값 2(1 − cos θ)를 거의 정확히 따릅니다. 행동 head를 로봇에 맞춰 H E R_r = I로 학습하면 사람 쪽은 H E R_h ≈ Q(θ)가 되고, 등방 행동에서 기대 오차가 ‖Q(θ) − I‖²_F / 2 = 2(1 − cos θ)이기 때문입니다. 사람 전용 방향 R_⊥을 써서 회전을 보정하는 해가 선형 encoder에도 존재하지만, 재구성 손실은 그 해를 고를 이유가 없고 weight decay는 오히려 막습니다.
  2. encoder가 embodiment를 알아볼 수 있으면 정렬은 임의적입니다. I는 θ와 무관하게 오차가 1을 넘습니다. 재구성 손실이 embodiment별 좌표계를 허용한다는 것을 그대로 보여 줍니다. DreamX의 encoder는 2B 백본에 지시문까지 받으므로, 입력만으로 사람인지 로봇인지 쉽게 알 수 있습니다. 실제 모델은 S와 I 사이 어딘가에 있고, 어느 쪽에 가까운지는 사전학습 백본의 귀납 편향에 달려 있습니다.
  3. 짝지은 클립이 조금만 있어도 정렬됩니다. 5%로 θ와 무관하게 전이 오차가 0 근처로 갑니다. 정렬을 만드는 가장 싼 신호입니다.
  4. 탐침 점수는 정렬을 재지 못합니다. 세 조건, 모든 θ에서 사람 쪽 탐침 R²는 1입니다. LARYBench처럼 탐침을 embodiment(벤치마크)마다 따로 학습하면, latent에 정보가 있는지는 재도 같은 좌표에 있는지는 재지 못합니다. Table 1의 높은 점수는 정렬의 근거가 아닙니다.

1.5 DreamX 실험에 대입

  • Fig. 5(HumanAndRobot)와 Fig. 6(실물 행동 전이)의 사람 영상은 로봇과 같은 위쪽 시점에서 찍었습니다. toy로 말하면 θ ≈ 0인 경우입니다. 이 조건에서는 공유 encoder만으로 전이가 되는 것이 자연스럽고, DreamX의 결과와 맞습니다.
  • 학습 데이터의 사람 영상(EgoDex, EgoVerse)은 1인칭입니다. 1인칭 손 움직임을 3인칭 로봇 카메라로 옮기는 경우는 θ가 크고, 실제로는 회전이 아니라 투영까지 바뀝니다. 이 경우의 정량 평가는 논문에 없습니다.
  • 그래서 "짝 데이터 없이 정렬된다"는 결과는 "시점이 맞으면 가중치 공유로 정렬된다" 로 읽는 것이 안전합니다. 시점이 다른 전이에서는 소량의 짝 클립(P)이나 시점 정규화가 필요할 가능성이 큽니다.

1.6 toy의 한계

선형 모형이고, 시점 변화를 이미지 평면 회전으로만 근사했습니다. 실제 영상 diffusion 백본의 사전학습 표현은 시점에 어느 정도 불변인 특징(예: 물체 중심 좌표)을 가질 수 있고, 그렇다면 S보다 나은 정렬이 나올 수 있습니다. toy가 보여 주는 것은 "손실이 정렬을 요구하지 않는다"까지입니다. 실제 정렬 정도는 시점이 다른 짝 데이터(예: 1인칭·3인칭 동시 촬영)로 직접 재야 합니다.

  1. 입력 프레임 수: 회귀 벤치마크는 원래 표본당 프레임 2장입니다. 영상 기반 모델에는 저자들이 원본에서 중간 프레임을 복원해 넣었습니다(부록 B.4). 위 그룹(프레임 2장)과 아래 그룹(영상)의 차이 일부는 입력 정보량 차이입니다.
  2. 특징 크기: DreamX 특징은 latent frame마다 2,048차원 토큰 4개입니다. 탐침은 토큰마다 768차원으로 사영한 뒤 attentive pooling을 하므로, 넓은 특징이 유리할 수 있습니다. 그래서 토큰당 32차원인 FAE-32가 더 공정한 비교 대상입니다. FAE-32도 모든 기준선을 이기므로, 결론의 방향은 유지됩니다.
  3. 데이터 출처 겹침: DreamX 사전학습의 37.4%가 AgiBot이고(Fig. 9), 회귀 평가셋 AgiBotWorld-Beta도 같은 출처입니다. 다만 사전학습에 없는 CALVIN에서 상대 개선이 가장 크므로(−65.1%), 겹침만으로 설명되지는 않습니다.
  4. 텍스트: encoder가 지시문 ℓ을 받는데(Eq. 2), 탐침용 특징을 뽑을 때 무엇을 넣었는지 적혀 있지 않습니다(04 C9).
  5. 정렬 미측정: §1.4대로, 벤치마크마다 따로 학습한 탐침은 embodiment 간 정렬을 재지 못합니다.

추가 검증 1: 비선형 encoder·decoder에서도 공유 encoder의 정렬이 시점 각도에 따라 깨지는가

목적. §1의 선형 결론 세 가지(공유 encoder는 θ ≈ 0에서만 정렬, embodiment별 encoder는 임의적, 짝 클립 5%면 정렬)가 비선형 encoder와 행동 손실에서도 유지되는지 봅니다. 탐침 R²가 정렬을 재지 못한다는 결론도 함께 봅니다.

설정(가정).

  • 행동 a ∈ R², 관측 Δo_e = tanh(R_e φ(a) W + 잡음) ∈ R⁸, φ(a) = [a₁, a₂, a₁a₂, sin a₁]. 로봇 R_r은 직교 열 2개, 사람 R_h = R_r Q(θ) + 0.3 R_⊥(열 정규화).

  • 독립 encoder(I)는 붕괴했습니다. 전이 오차는 θ와 무관하게 4.3으로, 행동 정보가 없는 상태입니다.

  • 재구성 MSE도 정렬 지표가 아닙니다. 세 조건 모두 0.008 근처입니다. 재구성은 복사 기준선보다 낫지만, 행동 정보가 잠재에 있는지와는 별개입니다. 추가 검증 2(03 §5.3)에서 query를 0으로 바꿔도 움직임이 45% 남았던 것과 같은 방향입니다.

한계. 합성 장면 2차원 행동 한 종류, 낮은 해상도, step 600(수렴 전일 수 있음), 시드 3개입니다. 사람과 로봇의 외형이 달라서 S의 실패를 시점 효과로 읽을 수 없습니다. 외형을 같게 두고 시점만 바꾸는 대조, 잠재 분산 하한이나 행동 재구성 항을 넣은 I 조건, 더 긴 학습은 아직 하지 않았습니다. DreamX 백본과 직접 비교할 수 없습니다.

4.3 아이디어 재구현 (CUDA GPU가 있는 경우)

구조 자체는 간단합니다. 공개 백본에 (1) latent frame당 query 4개, (2) Fig. 2b 마스크, (3) encoder·decoder 각각 LoRA, (4) 텍스트 cross-attention 자리에 query 조건, (5) 로봇 클립용 행동 branch를 붙이면 됩니다. 어려운 점은 세 가지입니다.

  1. decoder의 조건 경로: 원래 텍스트 cross-attention이 있던 자리에 query를 넣는지, 영상 토큰 열에 이어 붙이는지(논문은 "temporal sequence를 따라 이어 붙인다", §3.2)에 따라 구현이 달라집니다. 행동 branch의 구조는 적혀 있지 않습니다.
  2. 행동 공간 통일: 로봇 데이터 4종은 행동 공간이 서로 다릅니다. 어떻게 하나의 행동 branch로 학습했는지 설명이 없습니다.
  3. 연산량: 2B 백본, 480 × 640, 최대 29프레임, 78k step이면 H100급 여러 장이 필요할 것으로 추정됩니다. 줄인 해상도와 일부 데이터(Table 4처럼 MolmoAct2·EgoVerse·EgoDex 일부)로 시작하는 것이 현실적입니다.

저자들의 위치 설정(§2)은 이렇습니다. 기존 LAM은 프레임 한 쌍 같은 국소 전이에서 행동 공간을 처음부터 학습하므로, 움직임이 한 step 너머로 어떻게 이어지는지 보지 못하고 외관과 행동이 얽힌다고 봅니다. 영상 prior를 쓰는 LAM(AdaWorld, VideoWorld 2)도 영상 모델은 픽셀이나 rollout을 공급할 뿐이고, 행동 표현은 처음부터 학습한 외부 모듈이 만든다고 봅니다. DreamX는 백본 내부 표현을 직접 읽고, embodiment별 행동 encoder를 쓰지 않는다는 점을 차이로 듭니다.

이 위치 설정에서 빠진 것. 저자들이 인용한 LAOM(Nikulin et al. 2025)의 결론은 "방해 요소가 있으면 latent action 학습에 감독이 필요하다"입니다. DreamX는 이 문제를 "생성 prior가 외관을 맡는다"로 우회한다고 주장하지만, 사람 쪽에는 감독이 전혀 없고 로봇 쪽 행동 손실만 있습니다. 감독 없이 사람·로봇 latent가 같은 좌표에 놓이는 이유는 설명하지 않습니다(03 §1).

3. 이 저장소의 다른 논문과의 관계

논문 관계
ThinkWorld (thinkworld/) 같은 그룹의 짝 논문입니다. 저자 4명(Chaehyun Kim, Jisoo Kim, Seungryong Kim, Fu-En Yang)이 겹치고, 둘 다 양팔 YAM과 MolmoAct2-BimanualYAM, 사람 영상 EgoDex·EgoVerse를 씁니다. 사람·로봇 공통 행동 인터페이스를 푸는 방식이 정반대입니다. ThinkWorld의 Chain-of-Dynamics는 손목 자세 주석에서 만든 명시적 6D/12D 움직임 토큰이라 정렬이 구성상 보장되지만 주석이 필요합니다(ThinkWorld 분석에서 "레이블 없는 사람 영상"이라는 서술이 손 자세 주석을 쓴다는 점을 지적했습니다). DreamX는 주석 없이 latent를 학습하지만 정렬이 보장되지 않습니다(03 §1). 미래 예측 대상도 다릅니다. ThinkWorld는 1초 뒤 DINOv3 특징을, DreamX는 영상 diffusion으로 미래 프레임 자체를 재구성합니다. toy 결과로 보면 두 접근을 합치는 것이 자연스럽습니다. 사람 클립 일부에만 손목 자세 head를 붙여 latent를 고정하면 짝 클립(P 조건)과 같은 정렬 신호가 됩니다.
Hydra-0 (hydra0/) Hydra-0는 행동을 이미지 평면의 점 궤적(action flow) 으로 명시적으로 표현해 Cosmos 계열 영상 world model의 조건으로 씁니다. DreamX는 같은 문제의 암묵적 버전입니다. 학습된 latent가 조건 역할을 합니다. 두 방법 모두 "이미지에서 보이는 움직임"이 공통 인터페이스라는 점은 같고, 그래서 둘 다 시점에 묶입니다. Hydra-0는 배포할 때 URDF·카메라 보정·Isaac Lab 투영이 있어야 하고, DreamX의 행동 전이는 로봇 초기 상태만 있으면 되지만 대응 관계가 보장되지 않습니다. 명시적 track은 시점이 달라도 3D 역투영으로 맞출 수 있다는 장점이 있습니다.
OpenWAM (openwam/) OpenWAM은 영상 prior + 행동 생성(WAM)의 설계를 통제 실험으로 비교했고, 추론 때 미래 영상의 기여는 작고 이득은 학습 때 생긴다는 결과를 냈습니다. DreamX 정책은 이 관찰을 구조로 옮긴 사례입니다. 미래 영상 대신 4 × 32 압축 코드를 생성해 Mimic-Video보다 19.1배 빠릅니다. 다만 DreamX에는 "같은 백본, 예측 대상만 다름" 같은 통제 비교가 없어서(04 C12), OpenWAM 같은 실험이 있어야 "latent 예측 대 영상 예측"을 판단할 수 있습니다. 사람 영상 비중은 OpenWAM 30%(비공개 1인칭), DreamX 21.4%(공개 EgoDex·EgoVerse)입니다.
AW-0 (agentic_wam/) AW-0도 Cosmos-Predict2.5 2B 영상 전문가와 행동 전문가를 MoT로 묶어 함께 denoise합니다. DreamX 정책의 구조(영상 백본이 코드 Z 생성, Action DiT가 그 특징을 단방향으로 읽음)는 AW-0의 영상 → 행동 정보 흐름과 비슷합니다. AW-0 분석에서 "4단계 추론에서 행동이 읽는 미래 영상은 σ ≥ 0.625의 흐린 상태"라고 지적했는데, DreamX는 영상 대신 작은 코드를 생성하는 쪽으로 이 문제를 피합니다. 사전학습 규모도 비슷합니다(AW-0 약 2,900시간, DreamX 2.19k시간).
PaceVLA (pacevla/) PaceVLA는 텔레옵 시연의 느린 속도를 정책이 물려받는 문제를 다룹니다. DreamX의 latent action은 VAE의 시간 압축(latent frame 1개 = 영상 4프레임)에 묶여 있어, 같은 움직임이라도 사람(빠름)과 텔레옵 로봇(느림)에서 latent frame 수와 토큰 내용이 달라집니다. 행동 전이를 open-loop로 실행하면 사람의 속도가 그대로 로봇 명령으로 옮겨질 수 있는데, 논문은 속도·fps 정규화를 다루지 않습니다. 정책 1회 호출 1.47초라는 지연도 PaceVLA가 다루는 실행 속도 문제와 맞닿습니다.
GNR (gnr/) GNR은 사람 손 시연을 로봇 손 궤적으로 명시적으로 리타겟팅합니다. 손 자세를 입력으로, MPC가 푼 궤적을 목표로 조건부 flow 생성기를 학습하고, 후보를 시뮬레이터로 거릅니다. DreamX의 행동 전이는 주석·기구학·물리 검사 없이 latent만으로 하고, 대상은 평행 그리퍼의 거친 움직임(글자 쓰기, 밀기)입니다. 물리적 타당성 검사가 없는 대신 입력 요구가 거의 없습니다. DreamX latent를 "움직임 의도"로, GNR식 시뮬레이터 거르기를 타당성 검사로 쓰는 조합을 생각할 수 있습니다.

DreamX가 위 논문들에 더하는 것

  1. 주석 없는 공통 인터페이스의 실물 시연. ThinkWorld(손목 자세), Hydra-0(점 궤적), GNR(손 자세 + MPC)은 모두 명시적 대응을 씁니다. DreamX는 주석 없이 사람 시연을 로봇 명령으로 옮긴 실물 사례를 보였습니다. 정량 평가가 없고 같은 시점 조건이라는 제약은 있습니다.
  2. 영상 백본 내부를 읽는 latent action. LAM 계열에서 처음으로 사전학습 영상 diffusion의 내부 표현에서 직접 latent action을 뽑았고, LARYBench에서 회귀 오차를 기존 최고 대비 절반 아래로 낮췄습니다.
  3. 정책 지연. 미래 영상 대신 압축 코드를 생성하는 WAM형 정책으로 지연을 28.2초(Mimic-Video)에서 1.5초로 줄였습니다.
  4. 같은 약점. 이 저장소의 다른 논문들처럼 같은 백본에서 한 변수만 바꾼 통제 비교, 시점이 다른 조건, 여러 seed가 없습니다.
