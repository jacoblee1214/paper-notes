게시용 버전: 논문 그림은 라이선스(arXiv 비독점 배포) 때문에 제외했습니다. 원문 https://arxiv.org/abs/1509.02971 · arXiv:1509.02971v6 · ICLR 2016 · Google DeepMind (Lillicrap, Hunt, Pritzel, Heess, Erez, Tassa, Silver, Wierstra) · 공식 코드 없음 · 분석일 2026-10-28 · 논문 그림은 개인 학습용으로만 사용(논문 라이선스가 CC BY 아님)

핵심 요약

  1. 무엇을 했나: DPG actor-critic에 DQN의 재생 버퍼와 soft 표적망(τ = 0.001), 배치 정규화, OU 탐색 잡음을 붙여 연속 행동을 신경망으로 학습했다. 같은 설정으로 MuJoCo 26개 과제와 Torcs를 저차원·픽셀 입력에서 풀었다고 보고한다.
  2. "계획기와 견줄 만하다"는 최고 시드 기준이다: 저차원 평균 정규화 점수는 0.72(계획기의 약 72%)이고, 평균으로 계획기를 넘은 과제는 26개 중 2개다. 최고 시드 기준으로는 10개다.
  3. 표적망 효과는 확실하고, BN 효과는 근거가 약하다: DDPG가 DPG + BN보다 26개 중 25개 과제에서 높다(p = 6×10⁻⁸). 반면 "표적망만" 변형은 표에 없고, Fig. 2에서는 BN 유무가 여러 과제에서 겹친다.
  4. 공식 코드가 없고 재현 정보가 빠져 있다: OU 잡음의 dt가 없어 구현마다 상관 시간이 100배(6 vs 666 step) 다르다. 픽셀 망은 커널·stride가 없어 "43만 파라미터"로 구조를 복원할 수 없다.
  5. 주요 구현은 논문 설정과 다르다: SB3·Spinning Up·TD3 저장소 모두 BN이 없고 τ·배치·잡음이 다르다. TD3 저장소의 "논문 재현" DDPG.py도 main.py로 돌리면 τ 0.005, 배치 256이 된다.
  6. numpy toy(진자, 5개 시드): 표적망을 빼면 0/5, τ를 0.005로만 바꿔도 1/5만 풀었다. 잘 풀린 설정에서도 Q는 평균 +6.7% 과대추정되었다(Fig. 3의 "편향 없음"과 다름).
  7. 구현 가능성: 논문 표 재현은 불가능하다(과제·계획기 비공개). 알고리즘 재구현과 공개 구현 사용은 매우 쉽고, 저차원 MuJoCo 실험은 이 맥(CPU)에서 설치만 승인받으면 할 수 있다.

01. 논문 분석: DDPG (arXiv:1509.02971)

  • 제목: Continuous control with deep reinforcement learning

1. Abstract (한 줄 요약과 주장)

한 줄 요약: DQN을 성공시킨 두 장치(재생 버퍼, 표적망)를 결정적 정책 경사(DPG) actor-critic에 옮기고 배치 정규화를 더해, 연속 행동 공간에서 신경망 정책을 안정적으로 학습했습니다. 하이퍼파라미터 하나로 20개 넘는 물리 과제를 저차원 관측과 픽셀 모두에서 풀었다고 보고합니다.

논문이 내세우는 주장은 네 가지입니다.

  1. 모델 없는 off-policy actor-critic 알고리즘 DDPG를 제시합니다. 연속 행동을 이산화하지 않고 바로 다룹니다.
  2. 같은 구조와 하이퍼파라미터로 cartpole swing-up, 손 조작, 보행, 자동차 주행 등 20개 넘는 과제를 풉니다.
  3. 동역학과 미분을 모두 아는 계획기(iLQG)와 견줄 만한 정책을 찾고, 일부 과제에서는 그보다 낫습니다.
  4. 여러 과제에서 픽셀 입력만으로 끝까지(end-to-end) 학습합니다.

2. Method

2.1 배경: 결정적 정책과 Bellman 식 (Eq. 1–5)

정책이 결정적 μ(s)이면 Bellman 식의 다음 행동 기댓값이 사라집니다.

Q^μ(s_t, a_t) = E_{r_t, s_{t+1} ~ E} [ r(s_t, a_t) + γ Q^μ(s_{t+1}, μ(s_{t+1})) ]     (Eq. 3)

기댓값이 환경에만 걸리므로, 다른 행동 정책 β가 모은 전이로 Q^μ를 off-policy 학습할 수 있습니다. critic은 TD 손실 L = E[(Q(s,a|θ^Q) − y)²], y = r + γ Q(s', μ(s'))로 학습합니다(Eq. 4–5).

2.2 actor 업데이트 (Eq. 6)

연속 공간에서는 매 step argmax_a Q를 풀 수 없으므로 actor μ(s|θ^μ)를 따로 둡니다. 시작 분포 기준 return J를 actor 파라미터로 미분하고 연쇄 법칙을 쓰면 다음과 같습니다.

∇_{θ^μ} J ≈ E_{s ~ ρ^β} [ ∇_a Q(s, a | θ^Q) |_{a = μ(s)} · ∇_{θ^μ} μ(s | θ^μ) ]     (Eq. 6)

Silver et al. (2014)은 이것이 정책 성능의 경사임을 증명했습니다(on-policy 분포 기준). 이 논문은 각주 2에서 상태 방문 분포의 할인을 무시했다고 밝힙니다. 행동 분포 ρ^β에서 기댓값을 취하는 점도 엄밀한 경사가 아닌 근사입니다(03 §1).

2.3 DQN에서 가져온 두 장치와 배치 정규화 (Sec. 3, Algorithm 1)

장치 논문의 동기 방식
재생 버퍼 연속 탐색으로 모은 표본은 i.i.d.가 아니고, 하드웨어 효율에는 minibatch가 필요 크기 10⁶, 가득 차면 오래된 것부터 버림, 매 step 균등 표본
soft 표적망 업데이트하는 Q가 표적 y 계산에도 쓰여 발산하기 쉬움 actor와 critic의 복사본을 두고 θ' ← τθ + (1−τ)θ', τ = 0.001. 두 표적망이 모두 있어야 critic이 발산하지 않았다고 보고
배치 정규화 관측 성분마다 단위(위치, 속도)와 범위가 달라 과제 간 하이퍼파라미터 공유가 어려움 상태 입력, μ의 모든 층, 행동이 합류하기 전 Q의 모든 층에 적용
OU 탐색 잡음 관성이 있는 물리계에서 시간 상관 탐색이 효율적 μ'(s) = μ(s) + N, N은 Ornstein–Uhlenbeck 과정(θ = 0.15, σ = 0.2)

Algorithm 1은 매 환경 step마다 critic과 actor를 한 번씩 업데이트하고 두 표적망을 soft update합니다. 에피소드마다 탐색 과정 N을 새로 시작합니다.

3. Experiments

3.1 과제와 기준선 (Sec. 4, 부록 9절)

  • MuJoCo로 만든 자체 과제입니다. 부록 Table 2에 32개 환경의 차원이 있고, Table 1에는 그중 26개와 Torcs가 실렸습니다. 빠진 6개는 cartpoleParallelTriple, hardCheetahNice, hyqKick, movingGripperRandom, reacherDouble, reacherObstacle입니다(04 C5). cheetah를 빼면 행동은 관절 토크입니다.
  • 점수는 두 기준으로 정규화합니다. 행동 공간에서 균등하게 뽑는 무작위 정책을 0, iLQG 모델 예측 제어기(진짜 동역학과 미분을 씀, 계획 구간 250–600 ms)를 1로 둡니다.
  • 시드 5개입니다. "평균"과 "최고" 점수를 보고하고, 학습은 최대 250만 step입니다.

해석:

  • "계획기와 견줄 만하다"는 최고 시드 기준입니다. 평균으로 계획기를 넘은 과제는 26개 중 2개(blockworld1, hardCheetah)입니다. 최고 시드 기준으로는 10개입니다. 초록과 본문의 "some of the replicas"라는 표현은 정확하지만, 평균 성능은 계획기의 약 72%입니다.
  • 표적망 효과는 분명합니다. 표적망이 없는 DPG + BN(cntrl)보다 DDPG가 평균 기준으로 26개 중 25개 과제에서 높습니다(평균 차이 +0.50, Wilcoxon p = 6×10⁻⁸). 예외는 reacherSingle 하나입니다(1.010 vs 0.981).
  • 픽셀은 대부분 저차원보다 나쁩니다. 평균 기준으로 픽셀이 저차원 이상인 과제는 5개(blockworld3da, cart, movingGripper, reacherSingle, walker2d)뿐이고 평균 차이는 −0.22입니다. "단순한 과제에서는 픽셀도 저차원만큼 빠르다"는 본문 설명과 맞습니다.
  • 시드 간 퍼짐이 큽니다. R_best가 같은 5개 최종 점수의 최댓값이라면, R_best − R_av로부터 시드 표준편차의 하한을 구할 수 있습니다(03 §4). 예를 들어 canada는 0.80 이상, walker2d는 0.49 이상, hardCheetah는 0.38 이상입니다. "robustly solves"는 평균보다 최고 시드에 가까운 표현입니다. 다만 R_best가 학습 중 최고 체크포인트를 뜻한다면 이 하한은 성립하지 않으며, 논문만으로는 어느 쪽인지 알 수 없습니다.
  • Torcs는 평균이 음수입니다(저차원 −393, 픽셀 −402). 최고 시드는 1,840과 1,876입니다. 본문도 "일부 시드만 트랙을 완주했다"고 적었습니다. 또 Torcs는 탐색 잡음을 바꿔서, "모든 과제에 같은 하이퍼파라미터"라는 주장의 예외입니다.

3.3 구성 요소 비교 (Fig. 2)

Fig. 2는 10개 과제에서 네 변형의 학습 곡선을 보입니다: DPG + BN(연회색), + 표적망(진회색), + 표적망 + BN(초록), + 표적망, 픽셀(파랑).

  • 연회색(표적망 없음)은 대부분 과제에서 가장 나쁩니다. "표적망이 결정적"이라는 캡션과 맞습니다.
  • 반면 진회색(표적망만)과 초록(표적망 + BN)은 여러 과제에서 거의 겹칩니다(Cart, Pendulum, Cheetah 등, 그림에서 읽은 판단). Table 1에는 "표적망만" 열이 없어서 배치 정규화의 기여는 수치로 보고되지 않았습니다. "두 장치가 모두 필요하다"(Sec. 4)는 주장에서 BN 쪽 근거는 약합니다.

3.4 Q 추정 정확도 (Fig. 3)

학습 후 Q 추정값과 테스트 에피소드의 실제 return을 비교했습니다. 진자와 cartpole은 대각선 근처이고, cheetah는 추정이 실제보다 크게 위에 있습니다(과대추정). 본문은 "단순 과제에서는 체계적 편향 없이 정확하다"고 해석합니다. 우리 진자 toy에서는 잘 풀린 설정의 시드 15개 중 13개가 과대추정이었고 평균 +6.7%였습니다(03 §5). 단순 과제에서도 편향이 0은 아니라는 뜻입니다. 이후 TD3(Fujimoto et al., 2018)가 이 과대추정을 DDPG의 핵심 약점으로 지목했습니다.

4. Limitations

4.1 저자가 밝힌 한계

비선형 함수 근사 때문에 수렴 보장이 없습니다. 대부분의 모델 없는 방법처럼 학습 에피소드가 많이 필요합니다. 어려운 과제에서는 Q 추정이 부정확합니다.

4.2 분석하면서 추가로 발견한 한계와 의문점

  1. 재현에 필요한 정보가 빠져 있습니다(04 §2). OU 잡음의 dt가 없어서 구현마다 상관 시간이 100배 다릅니다(rllab dt = 1 → 약 6 step, baselines·SB3 dt = 0.01 → 약 666 step). 픽셀 망은 커널과 stride가 없고, 세 층이 같은 설정이라고 가정하면 "43만 파라미터"를 7% 이내로 맞출 수 없습니다(04 C7). 시간 제한 종료 처리, 무작위 시작 step, 평가 방식도 없습니다.
  2. 과제, 정규화 기준, 계획기가 공개되지 않았습니다. 정규화 점수의 0과 1이 모두 비공개 구현에 의존하므로 Table 1을 다른 환경에서 직접 재현할 수 없습니다.
  3. "하이퍼파라미터 하나로 모든 과제"는 보고 방식에 기댄 주장입니다. 평균 점수의 범위가 0.27–1.31로 넓고, 시드 간 퍼짐도 큽니다. 같은 설정이 "돌아간다"는 것과 "안정적으로 잘 푼다"는 것은 다릅니다.
  4. 배치 정규화의 기여가 수치로 분리되지 않았습니다(§3.3). 이후 주요 구현(SB3, Spinning Up, TD3 저장소)은 모두 BN을 빼고도 잘 동작합니다.
  5. 시드 5개, 신뢰구간 없음, 학습 곡선 일부만 공개입니다. Table 1의 "최대 250만 step"도 과제마다 실제 학습 길이가 다를 수 있다는 뜻으로 읽힙니다.
  6. "DQN보다 20배 적은 step"은 단위가 섞인 비교입니다(04 C8). DQN의 5천만은 게임 프레임이고, DQN은 4프레임마다 행동하므로 행동 step으로는 1,250만입니다. 같은 단위로 비교하면 약 5배입니다(DQN 수치는 내 사전 지식이라 원문 확인이 필요합니다).

1. Eq. 6은 무엇의 경사인가

off-policy 목적함수를 행동 분포 ρ^β 위에서 정의하면 J_β(μ) = E_{s~ρ^β}[Q^μ(s, μ(s))]입니다. 이를 미분하면 두 항이 나옵니다.

∇_θ J_β = E_{s~ρ^β} [ ∇_θ μ(s) · ∇_a Q^μ(s, a)|_{a=μ(s)} ]  +  E_{s~ρ^β} [ ∇_θ Q^μ(s, a)|_{a=μ(s)} ]
                    └──── Eq. 6 ────┘                              └─ 정책이 바뀌면 Q^μ 자체가 바뀌는 항 (버림) ─┘

Eq. 6은 두 번째 항을 버린 근사입니다. Silver et al.(2014)의 off-policy 결정적 actor-critic도 같은 근사를 씁니다. 정리가 정확히 성립하는 것은 on-policy 할인 방문 분포 ρ^μ에서인데, DDPG는 재생 버퍼의 분포에서 기댓값을 취하고 각주 2처럼 할인도 무시합니다. 버퍼가 크고 정책이 빨리 바뀔수록 ρ^β와 ρ^μ의 차이가 커집니다. 따라서 "버퍼가 클수록 좋다"는 데이터 효율과, 경사의 편향 사이에 맞교환이 있습니다. 논문은 버퍼 크기를 10⁶ 하나만 씁니다.

해석하면 Eq. 6은 "현재 critic이 보기에 Q가 커지는 방향으로 행동을 민다"는 정책 개선 단계입니다. critic이 틀리면 actor도 그대로 따라갑니다. 과대추정(§5)이 정책 품질로 바로 이어지는 이유입니다.

2. soft 표적망 = 지수이동평균

θ' ← τθ + (1−τ)θ'을 펼치면 θ'k = Σ_j τ(1−τ)^j θ{k−j}이므로, 표적망은 최근 파라미터의 지수이동평균입니다. 반감기는 ln 0.5 / ln(1−τ) 업데이트입니다.

4. 시드 퍼짐의 하한 (Table 1)

5개 값의 평균이 m이고 최댓값이 M이면, 표본 표준편차가 가장 작아지는 경우는 한 값이 M이고 나머지 넷이 m − (M−m)/4로 같을 때입니다. 이때 편차 제곱합은 (M−m)²·(1 + 4/16) = 1.25(M−m)²이므로 다음이 성립합니다.

s ≥ sqrt(1.25 / 4) · (M − m) ≈ 0.559 · (R_best − R_av)

저차원 DDPG에 적용하면 canada 0.80, walker2d 0.49, hardCheetah 0.38, canada2d 0.32 이상입니다. 26개 과제의 중앙값은 0.17입니다. 정규화 점수 범위(0–1)에 비하면 큰 퍼짐입니다. 단, 이 하한은 R_best가 R_av를 만든 같은 5개 최종 점수 중 최댓값일 때만 성립합니다. 논문의 "best observed"가 학습 중 최고 체크포인트라면 하한이 아닙니다.

5. toy: numpy DDPG로 본 장치별 효과

설정: gym Pendulum-v1과 같은 동역학(200 step, 토크 ±2)에서 실행했습니다. 구조와 하이퍼파라미터는 논문 부록을 따랐습니다: ReLU, tanh 출력, 행동은 critic 두 번째 층에 합류, 마지막 층 U(±3e-3), Adam 10⁻⁴/10⁻³, critic L2 10⁻², γ = 0.99, 배치 64. 다만 폭은 64-64로 줄였고 배치 정규화는 넣지 않았습니다. 40,000 step, 시드 5개이고, 논문 설정에서 한 항목씩만 바꿨습니다. 평가는 고정 초기 상태 10개에서 결정적 정책의 return 평균이고, 토크 0 정책은 −1,236입니다.

해석:

  • 표적망 없이는 전혀 배우지 못했습니다. 다섯 시드 모두 토크 0 정책보다 나쁩니다. 수치 발산은 없었지만 정책이 개선되지 않았습니다. 논문의 "target networks are crucial"과 맞습니다.
  • τ는 다른 하이퍼파라미터와 묶여 있습니다. 이 toy에서는 τ = 0.005가 논문 값 0.001보다 크게 나빴고, TD3 논문식 "재조정" 묶음도 5개 중 1개만 풀었습니다. 이것을 "τ = 0.005가 나쁘다"로 일반화하면 안 됩니다. SB3와 TD3 저장소는 τ = 0.005로 MuJoCo를 잘 풀고, 차이는 망 폭(400-300·256-256 vs 64-64), 할인율, 보상 크기에서 올 수 있습니다. 결론은 "τ만 따로 바꾸면 위험하다"입니다.
  • L2, 잡음 종류의 효과는 이 toy에서 구분되지 않습니다(p > 0.1). L2를 빼도 오히려 약간 나았습니다(−151). 가우시안 0.1도 결국 풀지만 −400 기준을 넘는 시점이 늦었습니다(시드별 18–28k step, 논문 설정은 14–20k).
  • OU dt = 0.01은 한 시드가 실패했습니다(−787). 나머지 넷은 풀었습니다. §3에서 본 대로 에피소드 초반 잡음이 거의 없어서 탐색이 약해진 결과로 보입니다. 시드 5개로는 유의하지 않습니다.
  • 잡음이 없어도 5개 중 3개는 풀었습니다. 진자는 초기 상태가 무작위라 탐색 부담이 작습니다. 잡음의 역할을 보기에는 약한 과제입니다.

Q 추정 편향 (Fig. 3 주장 확인): 학습 뒤 Q(s₀, μ(s₀))를 같은 초기 상태에서 1,000 step 굴린 실제 할인 return과 비교했습니다.

  • 논문 설정은 다섯 시드 모두 과대추정이었습니다(+1.4%, +7.4%, +22.3%, +4.0%, +11.7%. Wilcoxon p = 0.06, 5개라 검정력의 한계).
  • 잘 풀린 세 설정(논문, L2 없음, 가우시안)을 합치면 15개 중 13개가 과대추정이고 평균 +6.7%입니다.
  • 진자 같은 단순 과제에서도 체계적 과대추정이 있었습니다. "편향 없이 정확하다"는 Fig. 3의 해석은 이 toy에서는 재현되지 않았습니다. 그림의 축 단위가 "임의"라서 원 논문의 편향 크기를 직접 비교할 수는 없습니다.

toy의 한계: 망이 작고(64-64), BN이 없고, 과제가 하나이며, 시드가 5개입니다. 결론은 "이 설정에서의 경향"으로만 읽어야 합니다. 실행 시간은 다른 작업과 CPU를 나눠 써서 70분이 걸렸습니다. 단독으로 실행하면 몇 분 수준으로 추정합니다(3k step 실측 0.8초에서 환산하면 시드 하나 40k step에 약 15–20초).

2. 차이와 영향 (D1–D9)

# 내용 영향
D1 배치 정규화가 주요 구현에서 모두 빠졌습니다. 논문은 관측 단위 차이를 해결하는 핵심 장치로 소개했지만, SB3·Spinning Up·TD3 저장소에는 없고, baselines는 관측 running 정규화로 대신합니다. 논문 Fig. 2에서도 표적망만 쓴 변형과 BN까지 쓴 변형이 여러 과제에서 겹칩니다(01 §3.3). 오늘날 DDPG는 사실상 "BN 없는 DDPG"입니다. 표적망 대신 정규화로 안정화하려는 CrossQ 계열이 이 질문을 다시 다룹니다.
D2 critic의 행동 합류 위치가 다릅니다. 논문은 두 번째 은닉층에서 합류하고, SB3·Spinning Up·baselines는 입력층에서 상태와 이어 붙입니다. 행동을 늦게 넣으면 첫 층이 상태 특징만 학습합니다. 논문에서는 BN을 행동 합류 전 층에만 적용하기 위한 구조이기도 합니다. 성능 차이는 보고된 적이 없고 이 분석에서도 측정하지 않았습니다.
D3 TD3 저장소의 "논문 재현" DDPG.py도 기본 실행에서는 논문 값이 아닙니다. main.py가 --tau(기본 0.005)와 --batch_size(기본 256)를 모든 정책에 넘기므로, 클래스 기본값(τ 0.001, 배치 64)이 덮어써집니다. 탐색도 가우시안 0.1이고 처음 25,000 step은 무작위입니다. 이 저장소로 "원래 DDPG" 결과를 냈다면 실제 설정이 무엇이었는지 확인해야 합니다. 논문 설정을 원하면 --tau 0.001 --batch_size 64를 명시해야 합니다.
D4 SB3 DDPG는 TD3의 특수 경우입니다(policy_delay=1, n_critics=1, target_noise_clip=0). 표적 정책 평활화 잡음은 0.1로 두지만 clip이 0이라 실제로는 0이 됩니다. 기본 action_noise=None이라 사용자가 잡음을 주지 않으면 탐색 잡음 없이 학습합니다. 비교 실험이 쉬운 대신, 기본값만으로 돌리면 "잡음 없는 DDPG"가 됩니다. toy에서 잡음 없음은 5개 시드 중 2개가 실패했습니다(03 §5).
D5 OU 잡음의 dt가 구현마다 100배 다릅니다. rllab은 dt = 1(dx = θ(μ−x) + σ·ε), baselines와 SB3는 dt = 0.01이 기본입니다. 논문은 θ, σ만 줍니다. 상관 시간이 6 step과 666 step으로 다르고, 에피소드마다 0에서 다시 시작하면 dt 0.01의 잡음은 초반에 거의 0입니다(03 §3). "OU(0.15, 0.2)를 썼다"는 기술만으로는 탐색을 재현할 수 없습니다.
D6 critic L2의 적용 범위가 다릅니다. TD3 저장소는 Adam weight_decay로 bias까지 감쇠합니다. baselines는 출력층을 뺀 은닉 가중치에만 적용합니다. 논문은 "Q에 L2 10⁻²"라고만 적었습니다. toy에서는 L2를 빼도 성능이 비슷하거나 약간 나았습니다(−151 vs −163, p = 0.14). 영향은 작아 보이지만 과제와 보상 크기에 따라 다를 수 있습니다.
D7 마지막 층 초기화(±3×10⁻³)를 PyTorch 구현들이 따르지 않습니다. baselines만 논문과 같습니다. 초기 Q와 행동을 0 근처에 두려는 장치입니다. PyTorch 기본 초기화도 출력이 작은 편이라 영향은 크지 않을 것으로 보이지만 측정하지 않았습니다.
D8 학습 전 무작위 탐색과 시간 제한 처리가 구현마다 다르고, 논문에는 없습니다. TD3 저장소와 Spinning Up은 균등 무작위 행동으로 시작하고 시간 제한 종료에서 bootstrap합니다. 시간 제한을 종료로 취급하면 마지막 상태의 가치가 0으로 학습되어 편향이 생깁니다. 논문이 어느 쪽인지 알 수 없습니다.
D9 논문 본문의 사소한 오류: 배치 정규화가 "unit mean and variance"로 정규화한다고 썼습니다(실제로는 평균 0, 분산 1). 픽셀 마지막 층 초기화 범위 "[3×10⁻⁴, 3×10⁻⁴]"는 음수 부호가 빠졌습니다. μ : S ← A는 화살표 방향이 반대입니다. 재현에는 영향이 없습니다.
