## 1. 한 문단 요약

VideoWorld 2는 VideoWorld(CVPR 2025)의 후속 연구로, 라벨 없는 실제 손동작 튜토리얼 영상에서 **긴 시퀀스 과제 지식**을 배우는 방법입니다. 핵심은 **dLDM**(dynamics-enhanced Latent Dynamics Model)입니다. 기존 LDM이 VQ-VAE 디코더로 프레임을 재구성하면서 잠재 코드가 외형(배경, 질감, 조명)까지 담는 문제를 풀기 위해, 디코더 자리에 사전학습된 영상 확산 모델(VDM, Cosmos-Predict2 DiT 2B)을 둡니다. VQ-VAE는 저해상도 움직임 힌트만 만들고, 외형 생성은 VDM이 맡습니다. 잠재 코드(FSQ 1000개 코드, 프레임당 N=4개 토큰)는 자기회귀 Transformer(Cosmos AR 4B 구조)로 예측해 행동 계획을 만듭니다. 새 Video-CraftBench(종이접기 2개, 블록 쌓기 3개, 약 7시간, 학습·시험 분할)에서 종이접기 7단계 순차 성공률의 마지막 단계가 Craft-only 설정에서 68.8%, OpenX 사전학습 설정에서 72.3%입니다. 같은 단계에서 Craft-only 기준선 최고(Wan 2.2 14B, VideoWorld)는 0.0%, OpenX 설정의 기준선 최고(CoLA)는 40.2%입니다(표 1). CALVIN에서는 OpenX 잠재 사전학습으로 5과제 평균 길이 2.88을 얻었다고 보고합니다(표 2, 비교 대상 LAPA 2.51). 시험 수, 학습 반복 실행, 신뢰 구간은 보고하지 않습니다.

## 2. 문제 설정과 방법

### 2.1 문제 설정 (§3.1)

관찰 공간 X, 행동 공간 A, 영상 생성기 ρ로 구성된 튜플 G = ⟨X, A, ρ⟩를 정의합니다. 다음 프레임 x_{t+1}의 조건부 분포를 학습하고, 이를 정책 π(·|x_{0:t}): X → A로 쓴다는 설정입니다(식 없이 문장으로 정의). 언어 지도 없이 영상만으로 지식을 얻는 것이 목표입니다.

### 2.2 기존 LDM (§3.1, 그림 4 왼쪽)

VideoWorld의 LDM은 MAGVIT v2 방식의 인과 코덱을 씁니다. 길이 T 클립을 특징 f_{0:K}로 바꾸고(K = 1 + ⌊(T−1)/s⌋, s는 시간 스트라이드), N개의 학습 가능한 질의 q로 변화량 z를 뽑은 뒤 양자화합니다. 디코더는 f_0과 양자화된 z로 뒤 프레임을 재구성하고, 목표는 ℓ2 재구성 손실입니다. 논문은 이 잠재 코드가 배경 움직임, 조명, 질감, 카메라 흔들림 같은 외형 정보를 함께 담는다고 봅니다(§3.2).

### 2.3 dLDM (§3.2, 그림 3–4, 부록 A의 알고리즘 1)

- **인코더와 질의:** 기존 LDM과 같습니다. 학습 가능한 질의 N=4개, 시간 스트라이드 4, FSQ 레벨 [8,5,5,5] (코드 1000개), 임베딩 차원 4.
- **디코더 대체:** 재구성 디코더 자리에 사전학습 VDM을 둡니다. 잠재 코드는 투영 층과 **인과적 교차 주의(causal cross-attention)** 로 VDM에 들어갑니다. VDM의 시간 주의도 인과적입니다.
- **저해상도 움직임 힌트:** VQ-VAE 디코더는 잠재 코드에서 움직임이 살아 있는 저해상도 영상을 만들고, 이를 **기울기가 끊긴(gradient-stopped) ControlNet 유사 분기**로 VDM에 넣습니다. 디코더 기울기는 잠재 코드로 흐르지 않습니다(§5.5).
- **두 단계 학습:** 1단계는 재구성 손실만으로 워밍업(2k 반복 스케줄, 표 4)하고, 2단계에서 VDM을 포함해 함께 학습합니다. 학습 가능 파라미터는 AR Transformer, dLDM 자동부호화기, DiT, 투영 층입니다(§5.1).
- **자기회귀 Transformer:** 각 영상의 잠재 코드 {z_k^n}를 평탄화해 다음 토큰을 예측합니다. 조건은 첫 프레임과 과제 지시문입니다(§3.2). 추론에서는 새 환경의 첫 프레임에서 코드를 예측하고, dLDM이 93프레임 단위로 디코딩합니다. 긴 영상은 이전 구간의 마지막 프레임에서 이어 생성합니다(부록 C).

### 2.4 설계 근거와 주장

논문의 중심 주장은 "외형 모델링을 사전학습 VDM에 맡기면 잠재 코드가 과제 관련 동역학에 집중하고, 환경이 바뀌어도 같은 동작의 코드가 정렬된다"입니다(§3.2, 그림 7 UMAP). 이 주장은 §5.5의 절제(표 3a, 3f)와 UMAP 한 장으로 뒷받침합니다.

## 3. 실험 결과

### 3.1 Video-CraftBench (§4, 표 1, 부록 B)

- **데이터:** 손으로 종이접기(비행기, 배), 블록 쌓기(사람, 탑, 말) 5과제의 1인칭 튜토리얼. 약 7시간, 약 9.5k 클립, 인터넷과 직접 촬영. 종이접기는 40–80초, 블록은 20–30초(§4.1). 시험 세트는 약 150개 영상으로, 배경·질감·카메라를 달리했습니다(부록 B).
- **지표:** 종이접기 7단계 순차 성공률. DINOv2-Base 분류기(약 25k 프레임, 시험 정확도 96.1%)가 각 단계 완료를 판정하고, 이전 단계가 모두 성공해야 다음 단계가 성공입니다. 롤아웃은 사례당 3회입니다(§4.2). 블록은 최종 상태만 판정합니다. 시각 품질은 SSIM과 LPIPS입니다.
- **결과 (표 1 요약, 종이접기 7단계 %):**
  - 사전학습 영상 모델을 Craft 텍스트로 미세조정: Wan 2.2 14B 81.2 → 75.0 → 30.4 → 10.6 → 0 → 0 → 0. 4단계 이후 실패합니다.
  - VideoWorld(Craft): 70.3 → … → 6.7 → 0 → 0.
  - **VideoWorld 2(Craft): 97.2 → 95.3 → 90.0 → 83.3 → 81.4 → 74.6 → 68.8.** 블록은 사람 70.0, 탑 81.5, 말 80.9.
  - OpenX 사전학습 포함: VideoWorld 91.7 → … → 31.9, CoLA 83.5 → … → 40.2, **VideoWorld 2 98.2 → … → 72.3** (블록 74.0, 83.0, 85.8).
  - 시각 품질: VideoWorld 2 SSIM 0.770, LPIPS 0.205(Craft). Wan 2.2는 0.719 / 0.237.
- **해석 주의:** 기준선들은 같은 학습 데이터로 한 번 학습했고, 반복 실행이나 분산은 없습니다. 기준선 가운데 LAPA는 긴 시퀀스 디코딩에서 심하게 열화해 N.A.로 표시했습니다. 오차 막대는 없습니다(재계산은 `03` §1).

### 3.2 CALVIN (§5.4, 표 2)

CALVIN은 34개 과제, 5과제 연속 평가(ABCD→D)입니다. 평가 사슬 수는 본문에 없습니다.

- **도메인 내 잠재 사전학습 (10% 데이터 = 2k 궤적):** 잠재 코드를 22k 궤적에서 사전학습한 뒤 2k 정답 행동으로 미세조정합니다. VideoWorld 2 평균 길이 1.87, LAPA 1.49(보고값), 정답 전체 학습 Oracle 2.36(22k 행동 라벨), 10% 학습만 한 Oracle 1.11.
- **교차 도메인 (OpenX 1.3M 사전학습 후 CALVIN 22k 미세조정):** VideoWorld 2 2.88, LAPA 2.51, 영상 다음 토큰 예측 OpenX 사전학습 2.46, 정답 전체 학습 Oracle 2.36.
- **주의:** 행 3(LAPA 10%)의 단계별 값을 더하면 1.63이어서 보고값 1.49와 맞지 않습니다(`03` V1). 행 4 VideoWorld 2 10%도 0.014 차이가 있습니다.

### 3.3 절제 (§5.5, 표 3, 그림 7)

- **VDM 사전 지식 (3a, 행 1 대 2):** 종이접기 0.0 → 30.3, 블록 28.5 → 45.2, LPIPS 0.312 → 0.297. 본문 "약 30% 상승"은 종이접기 열과 맞습니다.
- **디코더 기울기 차단 (3a, 행 2 대 3):** 종이접기 30.3 → 47.3. 본문 "약 20%"는 종이접기 열 기준 17.0포인트입니다.
- **움직임 조건 (3a, 행 3 대 5):** 종이접기 47.3 → 68.8(+21.5), LPIPS 0.275 → 0.205(−0.070). 본문은 "LPIPS 약 0.9"라고 쓰는데 표의 차이와 맞지 않습니다(`03` V4).
- **질의 길이 N (3b):** N=1 41.9, N=2 55.1, N=4 68.8, N=8 65.0. N=4 선택은 표와 맞습니다.
- **상호작용 방식 (3c):** 마지막 행 72.3 / 80.9는 기본 설정 68.8 / 77.5와 다릅니다(`03` V3).
- **코드북 (3d):** 크기 8 20.1, 1000 68.8, 4096 50.4, 64000 29.4. 복잡한 Craft 과제에서는 큰 코드북이 필요하지만 과하면 떨어진다는 본문과 맞습니다.
- **시간 길이 T (3e):** T=2 19.1, T=9 55.4, T=49 65.3, T=93 68.8, T=177 69.0(블록은 76.8로 T=93보다 낮음).
- **VDM 학습 방식 (3f):** 무작위 초기화 0.0(붕괴), 동결 31.7, LoRA 50.9, 전체 미세조정 68.8.

### 3.4 정성 결과와 다른 방법의 실패 (그림 2, 6, 8, 11, 부록 C)

그림 8은 기준선 실패 사례(영상 확산, AdaWorld, VideoWorld 1)를 보입니다. 그림 2와 11은 VideoWorld 2의 생성 영상입니다. 생성 영상에는 손과 종이, 블록 장면이 보이며 대부분 인터넷 튜토리얼 또는 직접 촬영 영상에서 온 것입니다. 정성 결과는 재현할 수 없고, 본문과 부록이 "긴 영상에서 조명과 질감 드리프트가 점진적으로 생긴다"고 적은 한계를 확인하는 데만 씁니다.

## 6. 읽으며 기록한 주의점

1. **본문과 알고리즘이 다릅니다.** 본문 §5.5는 2단계부터 VQ-VAE 디코더 재구성 손실을 버린다고 쓰지만, 알고리즘 1은 `MSE(rec, video) + VDM(...)`을 씁니다. 공식 코드도 재구성 손실을 더합니다(`04` D3).
2. **"70%" 문구의 기준이 불분명합니다.** 초록의 "up to 70% improvement"는 상대 향상인지 절대 포인트인지 정의하지 않았습니다.
3. **참고문헌 번호 오류.** 표 1에서 AdaWorld가 [72](LAPA)로 인용되어 있습니다. 본문은 [24]를 씁니다.
4. **본문 지표 불일치.** "higher SSIM and PSNR"이라고 쓰지만 표에는 SSIM과 LPIPS만 있습니다.
5. **부록 B의 시간 비율 불일치.** 종이접기 "55.3% (5.2 hours)"는 5.2시간 대 전체 7시간 (74.3%)과 맞지 않습니다.
6. **학회 표기 없음.** 제출본(v1)에는 학회 정보가 없습니다. CVPR 2026 채택은 외부 공식 페이지로 확인했습니다(§0).
