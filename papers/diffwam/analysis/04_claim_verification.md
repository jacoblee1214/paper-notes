# DiffWAM 주장 대조와 구현 가능성 (C1–C18)

## 1. 코드 상태와 대조 방식

- **공식 코드 없음.** `github.com/ZGCA-HMI-Lab/DiffWAM`의 최신 커밋 7fc02f7(2026-11-17)에는 README와 그림 한 장뿐입니다. README 전문은 "Code coming soon."입니다(2026-11-22 얕은 복제로 확인, `repo/`). 프로젝트 페이지의 Code 링크도 같은 저장소입니다.
- 따라서 "논문 대 코드" 대조(D1–Dn)는 할 수 없습니다. 대신 **논문 안의 주장을 표, 본문, 부록과 대조하고 외부 자료 근거를 붙였습니다.**
- 저장소 복제는 실행, 설치, import를 하지 않았습니다. 내용은 신뢰하지 않는 자료로 취급했습니다.
- 재계산 근거는 `03_analysis.md`, 설계 설명 누락은 `01_paper_analysis.md` §6에 있습니다.

## 4. 구현 가능성 판정

**판정: 논문 수준의 재현은 이 맥(Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)에서 할 수 없습니다. 개념 검증도 맥의 CPU 범위를 넘습니다.** 근거는 다음과 같습니다.

| 목표 | 이 맥에서 가능? | 이유 |
|---|---|---|
| 공식 학습 (LIBERO, RoboTwin, 실로봇) | **불가** | 약 7B 파라미터 (§4.1). 표 9 학습 하드웨어는 8× A100. 학습 스텝 1.3 × 10^4 – 6.3 × 10^4. MPS 메모리와 CUDA 전제 아래서는 학습 불가 |
| 공식 체크포인트 추론과 평가 | **불가 (현재)** | 코드, 체크포인트, 전처리 스크립트가 모두 미공개 |
| 축소 재구현 (Wan 기반 구조를 수 M 파라미터 규모로) | **조건부** | MPS에서 가능한 규모이나 Wan2.2-5B 구조와 같지 않으므로 논문 값과 비교할 수 없음. 차이 목적의 효과를 판단하려면 LIBERO 등 데이터가 필요 (LIBERO 설치와 데이터 다운로드 승인 필요) |
| 토이 개념 검증 (차이 목적이 표현을 바꾸는지) | **이번에는 하지 않음** | 중심 주장을 CPU 토이로 시험하려면 설계를 임의로 정해야 합니다. 논문 수치 판단에 보탬이 적어 생략했습니다 |
| 공식 코드가 공개된 뒤 추론 검증 | **조건부** | 가중치 다운로드와 설치 승인 필요. 추론 지연과 공식 체크포인트의 LIBERO 평가는 MPS에서 확인 필요 |

**노력 추정 (추정, 측정 전).**
- 공식 코드 없이 재구현: 3–6주 (Wan 계열 비디오 DiT와 VAE, T5 인코더 연결, 세 전문가와 마스크 구현, 흐름 매칭 손실).
- 코드 공개 후 추론 검증: 1–2주 (가중치 용량은 미확인이며 수 GB 이상으로 추정).
- 학습 재현: GPU가 필요해 하지 않습니다.
