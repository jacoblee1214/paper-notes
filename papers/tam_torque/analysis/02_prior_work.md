# 02. 선행연구와 관련 저장소

이 문서는 TAM의 구성 요소가 어디서 왔는지, 가까운 대안이 무엇인지, 공식 코드가 있는지를 정리합니다. 번호는 논문 참고문헌 번호(`paper/paper.txt`의 References)입니다.

## 1. 선행연구 계보 (구성 요소별 출처)

| TAM의 요소 | 출처 (논문 번호) | 관계 |
|---|---|---|
| 목표 불일치를 도메인 무작위화로 흡수 | DR revisited [1] (Xie 2021), Peng 2018 [3], BayesSim [9], OpenAI 2019 [10] | TAM은 이를 정책 밖으로 옮깁니다. 저자는 DR이 "과도하게 보수적인 정책"을 만든다고 봅니다(초록, §1) |
| 로봇 동역학 식별 | Franka 동역학 식별 [2] (Gaz 2019), Swevers 외 [6], Farsoni 외 [5], Ljung [28], Joukov 외 [34] | TAM의 시스템 식별 대안. 온라인 입자 필터 기준선(Online SysID)은 이 계열입니다(부록 C.2) |
| 신경 액추에이터 모델 | Hwangbo 2019 [7] | 액추에이터 모델을 학습합니다. TAM은 같은 물리 모델을 역명령 맵으로 쓰고 잔차만 학습합니다 |
| 맥락 기반 동역학 파라미터 예측 | Dynamics as Prompts [8] | PhysPred 기준선의 영감입니다. 저자가 같은 역명령 파이프라인에 붙여 만들었습니다(부록 C.2) |
| 적응 상태를 정책 안에서 학습 | RMA [13] (Kumar 2021), Deep whole-body [14], RMA for arms [15], UPOSI [12] | TAM의 주된 비교 대상. 정책 재학습이 필요하다는 점을 저자가 한계로 듭니다(§1) |
| 잔차 학습과 행동 변환 | 잔차 강화학습 [39] (Johannink 2019), GAT [35–38], RL2AC [33] | 잔차를 정책 출력 위에 두는 점은 같지만, TAM은 정책 대신 토크 인터페이스에 둡니다(부록 A.4) |
| 적응 제어 | Slotine & Li 1987 [32] | 계산토크 PD 제어와 수동성 증명(부록 G)의 기반 |
| 이력 인코더 | Transformer [16], PatchTST [17], RoPE [43], FiLM [18], DiT [19] | 패치 토큰화와 adaLN은 이 계열을 조합했습니다 |
| 히스토리 분포 이동 보정 | DAgger [20] (Ross 2011) | §3.3의 미세조정. 논문 실험 4.4와 F.1에서 효과를 봅니다 |
| 시뮬레이션과 MPC 도구 | MuJoCo [42], MuJoCo Playground [21], MuJoCo MPC [23], Menagerie [24] | 시뮬레이션 로봇 자산과 MPC 기준선에 쓰입니다 |
| 실로봇 정책 (기준선 정책) | ACT [22] (Zhao 2023), PointNet [44] | flip 정책은 ACT, 상자 밀기 시각은 PointNet 계열입니다 |

**가까운 대안과의 차이.** TAM은 "정책 재학습 없이 정책 아래에 붙인다"와 "1 kHz 토크 보정"을 함께 내세웁니다. 가장 가까운 대안은 RMA입니다. RMA는 정책 안에서 잠재 상태를 쓰므로 정책을 다시 학습해야 합니다. 논문 표 1에서 RMA 위에 TAM을 얹으면 개선이 있지만 통계적으로 확실하지 않습니다(`03` §1).

## 4. 참고: 이 논문의 주장이 기대는 선행 결과

- Franka 동역학 식별 [2]은 자유 운동 데이터에서 파라미터를 식별하는 방법입니다. TAM 부록 B.2는 "페이로드 관성은 식별할 수 있지만 액추에이터 효과와 함께 알려지지 않으면 분리가 어렵다"고 씁니다. 이 주장은 식별 문헌의 일반 결과와 맞습니다.
- DAgger [20]의 필요성은 히스토리 분포 이동입니다. TAM의 보정이 적용되면 히스토리가 바뀌므로 §3.3이 필요합니다. 토이 T1은 같은 효과를 보입니다(`03` §3).
