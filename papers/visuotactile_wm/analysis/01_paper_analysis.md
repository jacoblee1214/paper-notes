## 0. 한 줄 요약

시각 세계 모델(Cosmos 토크나이저 + 12층 트랜스포머)에 Digit 360 촉각 임베딩(Sparsh-X)을 같은 토큰 열로 붙인 **VT-WM**을 학습했다. 같은 데이터, 같은 행동 조건에서 시각만 쓴 **V-WM**과 비교해 (a) 가려진 물체의 궤적 오차(객체 영속성)와 정지 물체의 허위 움직임(인과 준수)을 줄였고, (b) CEM 계획을 실로봇에 zero-shot으로 옮겼을 때 접촉이 많은 과제에서 성공률이 더 높았다. 새 과제 하나를 20회 시연으로 적응시킨 실험도 있다.

## 1. 문제 설정

- 시각만으로는 가려짐, 접촉 여부의 모호함(같은 영상인데 밀리거나 안 밀림) 때문에 세계 모델이 물체 영속성과 운동 법칙을 틀린다(§1 Introduction, Fig. 1, Fig. 5).
- 논문의 주장은 "촉각을 imagination의 입력에 넣으면 예측이 접촉 물리에 맞아진다"입니다. 촉각은 학습 목표(목표 이미지)에는 넣지 않습니다(§3.2.3). 즉 계획 목적함수는 시각 전용이고 촉각은 초기 문맥으로만 쓰입니다.

## 2. 방법 (§3, Fig. 3, 부록 B)

| 구성 | 값 (본문) | 근거 |
|---|---|---|

| 촉각 입력 | Digit 360 4개 각 2 프레임, "최근 0.16 s", Sparsh-X 인코더 (미세조정) | §3.2.2, B.1 |
| 행동 | 30 Hz 델타 상태(위치, 쿼터니언), 손 열림/닫힘 이진값, 5개씩 묶음 | §3.2.2 |
| 예측기 | 12층, 공간·시간 분해 자기 주의와 행동 교차 주의, RoPE | §3.2.1 |
| 손실 | 교사 강요 L1 + 자기회귀 샘플링 L1(H=3–5), 가중치 1:1 | §3.2.2 |
| 최적화 | AdamW(β=0.9, 0.95), wd 0.01, 워밍업 10k, 코사인, 80k 업데이트, lr 3e-4 | B.1 |

- 계획: CEM, 7차원 행동(위치 3, 자세 3, 손 이진), 수평 H=2 s, 입자 36, 반복 10, 엘리트 5, 최대 3회 호출(Algorithm 1). 실행은 개루프.
- V-WM은 같은 데이터와 같은 행동 조건을 쓰고 촉각만 뺀 대조군입니다. V-WM의 파라미터 수와 학습 설정은 논문에 명시되어 있지 않습니다(§5 한계).

## 3. 실험과 결과 (§4)

### 3.1 접촉 인식 (§4.1, Fig. 4–6)

- **객체 영속성** (Fig. 4): CoTracker로 물체 키포인트를 추적하고, 정규화 Fréchet 거리를 V-WM과 VT-WM에서 비교합니다. 5개 과제 평균 약 **33%** 감소(범위 18–47%). 유의 차이는 place fruits(t=4.38, p<0.001), push fruits(t=6.06, p<1e-6), cube stacking(t=2.40, p<0.05).
- **인과 준수** (Fig. 6): 움직이면 안 되는 정지 물체의 키포인트 오차. 평균 약 **29%** 감소. 유의: place fruits(t=3.66), push fruits(t=2.28), wipe cloth(t=2.99). stacking(t=1.75, p=0.09)과 scribble(t=−1.22, p=0.23)은 비유의. scribble은 오히려 악화. 감소율 본문 수치는 place 43.6%, push 16.4%, wipe 66.1%.
- 정성 결과(Fig. 5, 12, 어블레이션 아님): 손을 천 위에서 접촉 없이 움직일 때 V-WM은 천이 움직이고 VT-WM은 정지합니다.

### 3.2 실로봇 zero-shot 계획 (§4.2, Fig. 7 왼쪽)

- 과제 5개(reach button, push fruits, reach & push, wipe cloth, stack cubes), 과제당 **5회** 시행, 성공률.
- reach button 두 모델 모두 100%. VT-WM의 개선폭 본문 표기: push fruits **10%**, reach & push **35%**, wipe cloth **31%**, stack cubes **11%**. "up to 35% higher"는 초록과 결론에도 나옵니다.
- **검증 필요:** 과제당 5회에서 가능한 성공률은 0, 20, 40, 60, 80, 100%뿐입니다. 본문 개선폭 10, 11, 31, 35%는 절대 차이로도, 상대 차이로도 5회 시행에서 나올 수 없습니다(`analysis/recompute.py`, `analysis/recompute_results.json`). 실제 시행 수나 평균 방식이 본문과 다르다는 뜻입니다. 자세히는 `03_analysis.md` §2.

### 3.3 하위 과제 적응 (§4.3, Fig. 7 오른쪽)

- 새 과제 "접시를 식기건조대에 넣기"에 시연 20개를 추가해 VT-WM을 계속 학습. CEM zero-shot 10회 시행, 성공률 **77%**. 실패 모드는 접시를 선반 옆에 두는 정밀도 오차.
- **검증 필요:** 10회 시행에서 77%는 불가능합니다(7.7/10). 시행 수 또는 평균 방식 불일치입니다. 20개 시연 대조군(V-WM 또는 처음부터 학습)이 없어서 "데이터 효율" 주장은 비교로 뒷받침되지 않습니다.

## 4. 본문 주장의 강도 (읽는 법)

- 초록의 "33% better object permanence"와 "29% better compliance"는 **정규화 Fréchet 거리의 상대 감소**입니다. 낮을수록 좋은 거리이므로 "더 좋다"로 옮긴 표현입니다. 수치 의미는 맞지만 단위가 다릅니다.
- 실로봇 결과는 과제당 5회, 개선 폭이 이산 값과 맞지 않는 점과 함께 보면 **방향은 일관, 크기는 불확실**입니다. 통계 검정(이항 등)은 본문에 없습니다.
- 객체 영속성·인과 준수 실험의 샘플 수(롤아웃 개수)와 정확한 df도 본문에 없습니다. 보고된 t, p로 역산하면 df가 대략 30–60 범위와 맞습니다(`03_analysis.md` §1).

## 5. 한계 (논문 §E와 내가 본 것)

논문이 밝힌 한계: 비전 기반 촉각 센서 한 종류(Digit 360)에만 검증, 학습 분포 안의 과제만, 같은 장면과 같은 물체에서만 계획 테스트, CEM 계산량이 커서 개루프 청크 실행.

내가 본 추가 한계:
1. V-WM 대조군의 구조와 파라미터 수 정보가 없습니다. "촉각 추가 효과"인지 "모델 용량이나 미세조정 차이"인지 분리하기 어렵습니다(Sparsh-X만 미세조정, Cosmos는 동결 → 촉각 쪽 파라미터가 더 학습됨).
2. 계획 목표가 시각 전용 ℓ2입니다. 촉각 목표를 쓰지 않으므로 촉각이 계획 점수에 간접적으로만 들어갑니다.
3. 실로봇 시행 수(5, 10)와 개선 수치 불일치(§3.2, §3.3).
4. 부록 B.0.1의 datapoint 정의가 없어 112k와 17k의 1 시연당 값이 다릅니다(903 대 654). 데이터 규모 보고가 불명확합니다.
5. 부록 C는 "action controllability"를 정성 그림으로만 보입니다(Fig. 9–11). 정량 지표가 없습니다.

## 6. 용어와 식 (출처)

- Teacher forcing: L_teacher = Σ_k ‖ŝ_{k+1}−s_{k+1}‖₁ + ‖t̂_{k+1}−t_{k+1}‖₁ (§3.2.2).
- Sampling: L_sampling = Σ_{k=1}^{H} (같은 형식, 샘플된 입력), H=3–5, 기울기 없이 샘플 (§3.2.2).
- 총손실 L = L_teacher + L_sampling (§3.2.2, 같은 가중치).
- 정규화 Fréchet 거리: 키포인트 궤적을 초기 위치 기준으로 옮기고 GT 궤적 길이로 나눔 (§4.1).
