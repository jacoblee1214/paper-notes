# 04. 주장 검증과 구현 가능성 (공개 코드 없음)

공식 코드를 확인하지 못했습니다(2026-11-26 기준, `02` §5). 그래서 논문 ↔ 코드 대조(D 항목) 대신 **논문 안의 주장 C1–C30을 표·절 수치로 재계산하고 서로 대조**했습니다. 근거는 `03_analysis.md`의 V1–V11과 토이 T1입니다. 판정 표현은 다음과 같습니다. **지지**(표와 서술이 맞음), **부분**(일부만 맞거나 범위가 좁음), **방향만**(방향은 맞으나 크기나 유의성이 다름), **확인 불가**(논문 안에서 근거를 찾지 못함), **다름**(표와 서술이 서로 다름). 판정은 논문 비판이며 저자의 의도에 대한 판단이 아닙니다.

## 2. 코드가 공개되면 대조할 항목

코드가 없어서 대조하지 못한 것입니다. 공개되면 다음을 확인하면 논문의 모호한 부분이 풀립니다.

- 동결 VLA의 가중치와 행동 헤드, 토큰 수 N과 차원 d(C17, C21).
- 식 5의 평균 풀링과 식 6, 7의 |S|개 토큰 복원(복제 + 위치 임베딩)이 실제 구현과 같은지(C25).
- 식 4의 τ_u를 구하는 훈련 세트와 적응 중단 구현, 샘플 수와 속도 잡음 σ(표 8).
- 정렬 층의 구조와 학습 데이터(부록 B.7), 팔 패치 제외를 기본으로 켰는지(부록 B.4).
- 시뮬레이션 환경의 시나리오 파라미터(속도, 가속 프로파일), 평가 시드와 롤아웃 수(C20).
- 표 4 컨베이어 과제의 속도와 시행 방식(C9).

## 3. 구현할 수 있는지 (이 맥: Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)

**판정: 논문 수치의 재현은 불가능합니다.** 코드·환경·체크포인트가 공개되어 있지 않고, 7B VLA, 약 9–12 TB(추정) 특징 저장, 8×H100 약 100 GPU-시간, xArm 7과 발사기가 필요합니다. **방법의 핵심 아이디어(운동 조건의 잠재 예측 + 적응 중단)를 작은 모형으로 구현해 시험하는 것은 조건부로 가능합니다.**
