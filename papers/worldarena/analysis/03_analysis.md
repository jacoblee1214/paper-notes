# 03. 수치 재계산과 일관성 검사

재계산 스크립트는 `analysis/recompute.py`(결과 `recompute_results.json`), toy는 `toy_dynamic_gate.py`와 `toy_small_n_corr.py`다. 모두 CPU, numpy와 scipy, 단일 프로세스에서 몇 초 안에 끝난다. 논문에는 영상별 원점수와 사람 평가 원자료가 없다. 따라서 검사는 **논문이 보고한 값끼리** 맞는지를 본다.

## 1. EWMScore 정의 재현 (표 2·3 → 그림 1(a))

논문 §3.4는 EWMScore를 "16개 정규화 지표의 산술 평균 ×100"으로 정의한다. 표 2와 3의 값으로 이것을 계산해 그림 1(a)의 막대 라벨과 비교했다.

- 14개 모델 모두 최대 차이 **0.02**, 평균 절대 차이 0.00 (반올림 수준). 상관 1.000.
- 즉 표 2·3 값은 이미 정규화된 값이고, EWMScore는 그 16개의 단순 평균이다. 가중치 없음.
- 그림 1(a) 막대 라벨은 텍스트 층에서 내림차순으로 옮겼다. 모델 이름과 값을 짝짓는 방식이 맞았다는 것은 위 일치로 간접 확인된다.

결론: 정의와 값이 일관된다. 다만 **EWMScore 계산 코드는 공개 저장소에 없다**(`04` D5).

## 2. 과제 성공률과 통계 (표 4, 5, n = 100 가정)

본문은 과제마다 100회 실행했다고 한다(표 4 캡션). 실데이터 기준선은 과제 1 77%(Wilson 95% [67.8, 84.2]), 과제 2 66%([56.3, 74.5])다.

| 세계 모델 (데이터 엔진) | 과제 1 | 과제 2 | 과제 2 Wilson 95% | 과제 2 vs 66% p (Fisher) |
|---|---|---|---|---|
| Genie Envisioner | 7 | 21 | [14.2, 30.0] | < 0.001 |
| TesserAct | 1 | 35 | [26.4, 44.7] | < 0.001 |
| RoboMaster | 7 | **68** | [58.3, 76.3] | **0.88** |
| Vidar | 13 | 53 | [43.3, 62.5] | 0.084 |
| WoW | 45 | **71** | [61.5, 79.0] | **0.54** |
| Wan 2.2 | 15 | 41 | [31.9, 50.8] | < 0.001 |

- 과제 1은 여섯 모델 모두 실데이터(77%)보다 유의하게 낮다 (p < 0.001, WoW는 p = 6e-6).
- 과제 2에서 RoboMaster(+2pp)와 WoW(+5pp)는 실데이터(66%)보다 높지만 **유의하지 않다**. 본문 §4.2.2의 "RoboMaster와 WoW는 실데이터 학습을 넘는다"는 주장은 이 표본으로 뒷받침되지 않는다.
- 이 검사는 시드 반복 결과가 보고되지 않은 상태에서, 한 번 학습한 값으로 가정한다. 정책 학습의 시드 분산이 빠져 있으므로 실제 차이는 더 불확실하다.

**표 4와 표 5의 TesserAct 행이 같다.** 두 표 모두 TesserAct의 과제 1 = 1%, 과제 2 = 35%다. 다른 다섯 모델은 두 표에서 값이 다르다. 데이터 엔진과 행동 계획은 다른 실험이므로, 이 일치는 우연이거나 복사 오류일 수 있다 (`04` D6). WorldArena 2.0 프로젝트 페이지의 RoboTwin 행에도 TesserAct가 두 역할 모두 1/35로 나온다. 2.0 페이지에서도 같은 값이라 복사 오류라고 단정할 수는 없다.

## 3. 세계 모델 점수와 과제 성능의 상관 (표 4·5, 그림 1(a), 그림 5)

그림 5의 산점도는 데이터 엔진 6개 모델의 점을 표 4의 **두 과제 평균**으로 찍은 것이다 (Genie 14, TesserAct 18, RoboMaster 37.5, Vidar 33, WoW 58, Wan 2.2 28). 행동 계획도 같은 방식으로 맞는다. 그림 5의 점 위치와 재계산 값이 일치했다. 따라서 평균 방식은 논문의 방법과 같다.

| 상관 | 논문 r | 재계산 r | n | p | 5% 임계 |
|---|---|---|---|---|---|
| EWMScore vs 데이터 엔진 (평균) | 0.600 | 0.600 | 6 | 0.21 | 0.811 |
| EWMScore vs 데이터 엔진 과제 1 | — | 0.424 | 6 | — | |
| EWMScore vs 데이터 엔진 과제 2 | — | 0.628 | 6 | — | |
| EWMScore vs 행동 계획 (평균) | 0.360 | 0.360 | 6 | 0.48 | 0.811 |
| EWMScore vs 사람 평가 | 0.825 | (원자료 없음) | 14 (그림 5 점 개수) | < 0.001 (n=14 가정) | |

- 데이터 엔진과 행동 계획의 상관은 6개 점으로 계산했고 둘 다 유의하지 않다.
- 사람 평가 r = 0.825는 그림 5에서 점이 14개로 보여 n = 14로 두었다. 표가 없어 r 자체는 재계산할 수 없다.

**toy: 6개 점의 상관 검정력** (`toy_small_n_corr.py`, Monte Carlo 20,000회)

- n = 6에서 귀무(ρ=0)의 95% 분위수는 |r| = 0.808이다. 해석적 임계 0.811과 맞는다.
- 참 상관이 ρ = 0.7이면 관측 r ≥ 0.600일 확률은 0.69, ρ = 0.8이면 0.84다.
- 즉 **0.600은 "약한 상관"이라는 뜻이 아니라 "6개 점으로는 구분이 안 된다"는 뜻이다.** 참 상관이 강해도 6개 점에서는 r이 0.6 근처로 나오기 쉽다. 논문이 "중간 정도의 상관"이라고 해석한 것은 과하게 읽은 것이다.
- n = 14라면 임계는 0.532이고, ρ = 0.8에서 관측 r ≥ 0.600일 확률은 0.93이다. 모델을 더 많이 넣으면 같은 상관에서도 결론이 더 안정된다.

## 4. 정책 평가자 상관 (그림 4)

그림 4는 정책 5개(10/20/30/50/100% 데이터)에 대한 시뮬레이터 성공률과 세계 모델 성공률의 산점도다. 원자료 표는 없다. 두 가지를 했다.

1. **그림의 점을 눈으로 읽어 재계산.** Ctrl-World 쪽은 r ≈ 0.987, Cosmos 쪽은 r ≈ 0.483이다. 논문 값 0.986과 0.483과 맞는다. 점의 위치는 눈으로 읽은 값(±1 정도)이라 참고용이다.
2. **n = 5 통계.** Ctrl-World r = 0.986은 p = 0.002, 95% 구간 [0.797, 0.999]다. Cosmos r = 0.483은 p = 0.41, 구간 [−0.696, 0.957]이다.
   - 두 상관의 차이: Fisher z = 1.95, p = 0.051 (두 상관이 같은 시뮬레이터 점수를 공유하므로 독립 가정은 근사다).
   - 해석: Ctrl-World가 정책 순위를 따라간다는 증거는 n = 5에서도 꽤 강하다. 그러나 Cosmos와의 차이는 경계선에 있다. 논문의 "Cosmos는 환경 동역학을 잘 모델링하지 못한다"는 해석은 과하다.
   - 코드의 기본 시뮬레이터 점수 5개(28.6, 34.58, 37.78, 43.52, 46.8)는 그림 4의 x축 값과 일치한다.

## 6. 토이 검사

### 6.1 동적 게이트 규칙 차이 (`toy_dynamic_gate.py`)

논문 식 (9)–(13)은 `raw · min(1, Sdyn/γ)`다. 코드는 `dyn <= 0.1213`일 때 `raw · dyn`을 쓴다 (`04` D1).

- raw = 0.90일 때 두 규칙의 최대 차이는 **0.79**다.
- 코드 규칙은 임계에서 **불연속**이다. Sdyn이 0.121에서 0.122로 넘어갈 때 점수가 0.109에서 0.900으로 뛴다.
- 논문 식은 γ에서 연속이다.
- 두 모델 예: 정적 영상 A(raw 0.95, Sdyn 0.10)는 논문 규칙에서 0.783, 코드 규칙에서 0.095다. 움직임 있는 B(raw 0.85, Sdyn 0.13)는 두 규칙에서 모두 0.85다. 두 규칙 모두 정적 영상 A가 움직이는 영상 B보다 낮다는 순서는 같다. 차이는 크기다. 논문 식에서 A와 B의 간격은 0.07이고, 코드 규칙에서는 0.75다. 즉 코드 규칙은 정적 영상 페널티를 훨씬 세게 준다.
- 임계 0.10–0.20 범위를 가상 영상 2,000개에 적용하면 코드 규칙의 평균 점수는 0.60에서 0.35로 움직인다(논문 식은 0.73에서 0.58). 임계 선택이 절대 점수에 강하게 영향을 준다.

따라서 **EWMScore를 구현할 때는 규칙과 임계를 명시하지 않으면 재현되지 않는다.**

### 6.2 소표본 상관 (`toy_small_n_corr.py`)

§3에서 설명했다. 6개 점의 r = 0.600은 유의하지 않고, 데이터 엔진 상관은 방향만 말할 수 있다.

## 7. 한계

- 원자료가 없다. 모든 재계산은 논문 표와 그림 텍스트 층에서 옮긴 값에 기대고 있다. 그림 값은 눈으로 읽은 근사다.
- 시드와 신뢰구간이 없다. 표 4·5의 n = 100은 캡션에서 가정했다.
- 사람 평가 r = 0.825는 n = 14를 그림에서 셈으로 얻었다.
- 게이트 규칙의 γ는 논문에 없다. 코드 값 0.1213으로 계산했다.
