# 03. 수치 재계산과 일관성 검사

대상: arXiv:2410.09309v2의 Table I(물체 뒤집기, 시도 100회)와 Table II(벽 닦기, 시도 16회). 재계산 스크립트는 `analysis/recompute.py`(표준 라이브러리만 사용, 1초 안에 끝남), 결과는 `analysis/recompute_results.json`입니다. 재현 실험은 하지 않았습니다. 표에 적힌 수치만 다시 계산했습니다.

## 1. 원시 횟수 복원

표의 백분율은 시도 수가 20(시나리오당)과 16(벽 닦기 전체)이라 정수 횟수로 바로 바뀝니다. 복원한 횟수와 합계가 모두 맞습니다.

| 방법 | 학습 항목 | unseen | Push&Flip | 고정구 자세 | 불안정 고정구 | 합계 (표의 All) | Wilson 95% |
|---|---|---|---|---|---|---|---|
| ACP | 18/20 | 19/20 | 19/20 | 20/20 | 20/20 | **96/100** | 90.2–98.4 % |
| ACP w.o. FFT | 18/20 | 20/20 | 20/20 | 19/20 | 18/20 | **95/100** | 88.8–97.8 % |
| Compliant | 16/20 | 3/20 | 3/20 | 1/20 | 0/20 | **23/100** | 15.8–32.2 % |
| Stiff | 4/20 | 1/20 | 0/20 | 7/20 | 2/20 | **14/100** | 8.5–22.1 % |

벽 닦기(Table II, 시나리오 Small 5, Large 5, PbC 4, PaC 2):

| 방법 | Small | Large | PbC | PaC | 합계 (표의 All) | Wilson 95% |
|---|---|---|---|---|---|---|
| ACP | 5/5 | 4/5 | 4/4 | 2/2 | **15/16 (93.75%)** | 71.7–98.9 % |
| ACP w.o. FFT | 5/5 | 3/5 | 3/4 | 2/2 | **13/16 (81.25%)** | 57.0–93.4 % |
| Compliant | 3/5 | 1/5 | 1/4 | 2/2 | **7/16 (43.75%)** | 23.1–66.8 % |

Table II의 15개 백분율을 어떤 순서로 묶을지는 pdftotext 출력만으로는 정하기 어렵습니다. 방법별 행으로 읽으면 PbC(4회) 칸의 60%(2.4회)처럼 정수가 되지 않는 값이 나옵니다. 시나리오별 열로 읽으면 모든 값이 시도 수의 정수 배이고 합계가 All과 맞습니다(15, 13, 7). 그래서 열 방향 해석을 채택했습니다.

## 2. 일관성 검사

| 검사 | 결과 |
|---|---|
| Table I 각 행의 시나리오 합 = All × 5 | 통과 (ACP 480/500, ACP w.o. FFT 475/500, Compliant 115/500, Stiff 70/500) |
| Table I 각 셀이 20회의 정수 배수인가 | 통과 (모두 5의 배수) |
| Table II 각 셀이 시나리오 시도 수로 나누어지나 | 통과 (5, 4, 2 시도 기준) |
| Table II 합계 = All × 16 | 통과 (15, 13, 7) |
| 본문 "ACP 96/100 대 w.o. FFT 95/100" | 표와 일치 |
| 본문 "Compliant 대비 50% 이상" | 아래 §3 |
| 본문 "Stiff는 Table II에서 제외" | 표와 일치 (Table II에 Stiff 행 없음) |
| v1 대 v2 표 값 | 같음. 텍스트 대조(`diff`)에서 표 행은 바뀌지 않았습니다. v2에서 바뀐 것은 관련 연구 문장과 참고문헌 번호뿐입니다 |

눈에 띄는 불일치 두 가지:
- **Table I "고정구 자세" 열의 시도 배분이 적혀 있지 않습니다.** 본문은 "두 가지 고정구 자세"라고만 씁니다. 20회를 어떻게 나눴는지(10+10인지 아닌지) 모르므로, 이 열의 세부 해석은 보류합니다.
- **Table II 시도 수가 16인데 본문 시나리오 수(5, 5, 4, 2)와 맞습니다.** 불일치는 아니지만, 16회는 작은 표본입니다.

## 3. "50% 이상 향상" 주장 점검

초록과 서론은 "최신 시각 정책 대비 50% 이상 향상"이라고 씁니다. 표로 확인하면 다음과 같습니다.

| 비교 | 차이 (%p) | 상대 향상 | 표 |
|---|---|---|---|
| 뒤집기: ACP 대 Compliant | 73.0 | +317% | Table I |
| 뒤집기: ACP 대 Stiff | 82.0 | +586% | Table I |
| 벽 닦기: ACP 대 Compliant | **50.0** | +114% | Table II |
| 벽 닦기: ACP 대 ACP w.o. FFT | 12.5 | +15% | Table II |

벽 닦기에서 Compliant 대비 차이는 정확히 50%p입니다. "50% 이상"이라는 표현은 %p로 보면 경계선(= 50)이고, 상대 비율로 보면 훨씬 큽니다. 두 기준이 섞여 있어서 "50% 이상"은 벽 닦기 기준으로는 %p 기준에서 "이상"이 아니라 "같음"입니다. 뒤집기는 어느 기준으로도 충분합니다. 초록은 기준을 밝히지 않으므로, 이 글에서는 "뒤집기는 73%p, 벽 닦기는 50%p 차이"로 나눠 적습니다.

Stiff는 벽 닦기에서 제외되어 있어 벽 닦기에서는 가장 약한 기준선과만 비교할 수 있습니다.

## 4. 통계 검정 (Fisher 정확 검정, 양측)

| 비교 | 차이 (%p) | p값 | 해석 |
|---|---|---|---|
| 뒤집기 ACP 대 Compliant | 73.0 | < 1e-6 | 명확 |
| 뒤집기 ACP 대 Stiff | 82.0 | < 1e-6 | 명확 |
| 뒤집기 ACP 대 ACP w.o. FFT | 1.0 | 1.0 | FFT 효과 없음 |
| 벽 닦기 ACP 대 Compliant | 50.0 | 0.0059 | 16회에서도 유의 |
| 벽 닦기 ACP 대 ACP w.o. FFT | 12.5 | 0.60 | 차이 방향만 있음 |

본문은 "벽 닦기에서 FFT 인코딩이 더 잘 된다"고 씁니다. 13/16 대 15/16은 방향은 맞지만 통계적으로는 구분되지 않습니다(p = 0.60). "FFT 인코딩이 우수하다"는 주장은 이 표본으로는 뒷받침되지 않습니다.

## 5. 한계

- **학습 시드가 하나로 보입니다.** 표에 여러 시드의 평균이나 편차가 없습니다. 위 구간은 시험 시도의 표집 잡음만 반영하며, 학습 자체의 변동은 반영하지 않습니다.
- **구간은 시험 시도 기준입니다.** 같은 로봇과 같은 물체에서 나온 시도들이므로 독립 표본으로 보기 어렵습니다.
- **벽 닦기는 16회입니다.** 95% 구간 폭이 27–30%p라 "ACP가 낫다"는 결론의 크기는 넓은 범위로만 말할 수 있습니다.
- **기준선 구현이 공개 코드에 있는지 확인하지 않았습니다.** Compliant와 Stiff가 같은 코드 경로인지는 정적 읽기로 정하지 못했습니다(`04_code_verification.md` 참조).
