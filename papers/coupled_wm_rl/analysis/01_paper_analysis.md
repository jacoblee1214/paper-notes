## 1. 한 문단 요약

로봇이 실제 환경에서 모은 "놀이(play)" 데이터로 큰 확산 세계모델(global)을 학습하고, 이 세계모델 안에서 정책을 RL로 학습해 실로봇에 영점 이동(zero-shot)으로 배포합니다. 큰 세계모델을 통과한 역전파는 메모리와 시간이 너무 커서, 순전파는 큰 모델이, 역전파의 야코비안은 작은 RSSM(local, DreamerV3식)이 맡는 **분리형 1차 기울기(DMO)** 를 씁니다. Push-T(조작기), Go2 사족 보행 로봇의 Push Cube, G1 휴머노이드의 Grab Box 세 과제에서 PPO, SAC, IQL, ACT(BC)와 비교합니다. 실로봇 시행은 방법마다 10회입니다.

## 2. 문제와 동기 (§1, §2)

- 이동(locomotion)은 병렬 시뮬레이터로 RL이 잘 되지만 조작은 시뮬레이터 구축이 어렵고 sim2real 간극이 큽니다(§1).
- 1차 기울기(FoG) 방법은 PPO·SAC보다 기울기 분산이 낮고 표본 효율이 좋다고 보지만, 세계모델 통과 역전파가 필요해 큰 확산 모델에는 계산이 부담됩니다(§1, §2.2).
- DreamerV4, DIAMOND 같은 확산 세계모델은 영 차수(zeroth-order) 최적화를 쓰며, 확산 표본을 많이 만들어야 해서 비쌉니다(§2.3).
- 그래서 DMO [15](Amigo 외, CoRL 2025)의 "순전파와 역전파 모델 분리"를 시뮬레이터 없이 이미지 공간으로 확장합니다(§1, §3.1).

## 3. 방법

### 3.1 분리형 1차 기울기 (§3.1)

- 정책 기울기는 `∇θ G = Σ γ^t [∂r/∂s · ds_t/dθ + ∂r/∂a · da_t/dθ]`이고, 상태 민감도는 `ds_{t+1}/dθ = ∂f/∂s · ds_t/dθ + ∂f/∂a · da_t/dθ`로 전파됩니다(§3.1).
- DMO는 값(궤적)은 정확한 순전파 모델 `f→`로 만들고, 야코비안은 그 궤적의 다음 상태 `s→_{t+1}`에서 역전파 모델 `f←_φ`로 평가합니다(§3.1).
- 이 논문의 변경: DMO는 시뮬레이터 상태를 두 모델이 공유하지만, 이미지 공간에서는 전역 모델의 상태가 너무 큽니다. Push Cube에서 전역 모델은 최대 96프레임 x 256 토큰 x 폭 16 = 393,216 차원을 조건으로 받아 DMO의 쿼드러페드 상태 68차원의 5,700배 넘는다고 씁니다(§3.4, 재계산 일치: 5,782배, `03` V4). 그래서 두 모델을 **이미지 공간으로 결합**합니다. 전역 모델이 만든 프레임을 디코드해 국소 RSSM의 이미지 인코더로 다시 인코딩하고(둘 다 기울기 없음), 전역 잠재 공간의 야코비안을 국소 잠재 공간의 야코비안으로 근사합니다(§3.4).

### 3.2 전역 세계모델 (§3.2, 표 4)

| 과제 | 모델 | 규모 | 데이터 | 비고 |
|---|---|---|---|---|
| Push-T | DIAMOND 구조 확산, 3 확산 단계, 조건 4프레임 | 4M 파라미터 | 놀이 4시간 | 1 RTX4090, 64x64 |
| Push Cube | DreamerV4식 트랜스포머 잠재 확산 | 1.0B (v3, v2는 1.4B) | 12시간 | 128x128, 4 확산 단계, 문맥 최대 96 |
| G1 Grab Box | 같은 구조, 고유감각을 토크나이저에 추가 | 1.4B | 20.9시간(놀이 16.5 + 표적 수집 4.4) | 256x256, 토크나이저는 SOAR 데이터로 사전학습 |

- shortcut 학습 [32]으로 확산 단계를 줄이고, causal diffusion forcing [33]과 KV 캐시로 실시간 순환 생성을 합니다(§3.2).
- 조건은 Push Cube·G1 모두 `32프레임`으로 시작합니다(부록 A.4, A.5). Push Cube는 32 + 64 = 96이라 표 4의 96과 맞습니다(`03` V4).

### 3.3 전역 보상 모델 (§3.3)

- Push-T: 목표까지의 시간 근접도를 점수로 매기는 대조적 에너지 함수 `fψ(s_t | s_start, s_goal)` [34].
- Push Cube, G1: 프레임이 시연 분포에 속하는지 분류하는 보상 헤드. Push Cube에서는 목표에 도달한 프레임에 높은 라벨(10)을 줍니다. **라벨은 사람이 놀이 중 버튼 입력이나 사후 처리로 붙입니다**(§3.3, §5 한계).

### 3.4 국소 보상·세계모델 (§3.4, 표 4, 부록 A.5)

- DreamerV3 RSSM(순환 상태 1024 또는 4096)이 국소 잠재 동역학과 보상을 함께 학습합니다. 이미지 인코더가 관측을 잠재로 줄이며 **정책 기울기는 인코더로 흐르지 않습니다**.
- 놀이 데이터로 오프라인 사전학습한 뒤, RL 중에도 전역 모델이 만든 궤적으로 계속 미세조정합니다. 에폭마다 모델 갱신은 첫 에폭 10,000회, 이후 64회입니다(알고리즘 1).
- 국소 모델은 1스텝만 정확하면 됩니다. 야코비안을 전역 모델이 만든 정확한 이미지의 인코딩에서 평가하기 때문입니다(§3.4).

### 3.5 정책 목적함수 (부록 A.5, 식 (1)–(3))

- DMO-SAPO: `Lπ(θ) = E[Σ_{h=0}^{H-1} γ^h (R̂φ(l_{h+1}) + α H̃_h) + γ^H V(l_H)]` (식 1). 엔트로피는 `H̃_h = (Ĥ_h + |H̄|)/(2|H̄|)`로 정규화하고 α는 자동 조정합니다.
- 비평가는 10개 앙상블이고 `λ-return`에 회귀합니다(식 2, 3). 목표 네트워크는 쓰지 않고 앙상블 중 무작위 두 개의 최솟값을 씁니다.
- 호라이즌 H = 16, 액터 128개, 감마 0.99, 람다 0.95, 미니배치 1024, 에폭 8, AdamW(0.7, 0.95), 리플레이 10^6(표 4). PPO는 H = 64, 액터 256, 미니배치 4096(표 4).

### 3.6 데이터 수집과 패칭 (§3.5, 부록 A.2)

- 구조 없는 고엔트로피 "놀이" 데이터를 로봇으로 모읍니다. 과제 분할이나 잦은 초기화가 필요 없다는 점이 장점이라고 씁니다(§3.5).
- **세계모델 패칭 두 단계:** (1) VR 헤드셋(Quest 3, Pico)으로 세계모델 안에서 몰입 탐색을 하며 부정확한 영역을 찾아 데이터를 더 모읍니다. (2) RL이 세계모델 또는 보상 모델의 결함을 이용해 인위적으로 높은 반환을 얻는 정책을 찾으면, 그 정책을 **실로봇에 배포해** 표적 데이터를 모으고 미세조정합니다. G1은 7회 반복했고 각 회차는 0.19, 0.55, 0.74, 0.80, 1.00, 0.72, 0.43시간(합 4.43, 보고 4.4)입니다(부록 A.2). 회차마다 3k 업데이트로 미세조정하고 보상 헤드는 새로 초기화합니다.

## 4. 실험

### 4.1 과제 (§4.1)

| 과제 | 로봇 | 행동 | 제어 주기 | 비고 |
|---|---|---|---|---|
| Push-T | Flexiv Rizon-10S | 도구 속도 2차원 | 5 Hz | 4프레임 스택 |
| Ego-Centric Push Cube | Unitree Go2 | 몸체 속도 명령(저수준 RL 보행 정책에 전달) | 5 Hz | 부분 관측, 에피소드 64스텝(DMO) 또는 128(실로봇 PPO) |
| Humanoid Grasp and Lift | Unitree G1 + BrainCo 손 | 22차원 명령(허리 3 + 팔 14 + 그립 2 + 하체 3), 정책은 19차원 증분 출력, 배포는 11 DoF | 10 Hz, 저수준 SONIC 50 Hz | 한쪽 팔 고정 |

### 4.2 기준선과 절제 (§4.2)

- 같은 세계모델·보상·초기 분포에서 학습한 PPO, SAC(세계모델 안에서만 평가), IQL(오프라인, 최고 평가 시점), ACT(BC, Push Cube와 G1만).
- 절제 두 개: **No Diffusion**(순전파와 역전파 모두 DreamerV3 RSSM), **No RSSM Finetuning**.
- 학습 곡선은 "훈련 에피소드의 비할인 보상 합(64스텝, 전역 보상 모델의 프레임별 예측)의 이동 평균"입니다(부록 A.4). **즉 학습 곡선의 보상은 세계모델 안의 학습된 보상 모델이 준 값이며, 실로봇 성공이 아닙니다.** 시드 4개입니다(그림 5, 8 캡션).

### 4.3 결과 (§4.3, 그림 5, 8, 표 1–3)

- **그림 5(집계):** 보상은 과제별로 min-max 정규화하고 표본 수와 시간은 그 과제에서 가장 큰 값으로 나누어 과제 평균을 냅니다. 음영은 **과제 사이의** 표준편차입니다(부록 A.4). 곡선 끝에서 DMO ≈ 0.87, PPO ≈ 0.67, IQL 선 ≈ 0.64(그림 판독 값, `03` V6, V7).
- **그림 8(과제별, 부록 A.4):** Push-T는 DMO 4M 대 PPO 48M 표본, Push Cube와 G1은 DMO 4M 대 PPO 25M(캡션). 그림 판독으로 최종 보상은 DMO 37.6 / 66.7 / 24.6, PPO 32.8 / 37.2 / 18.3, IQL 선 27.0 / 44.4 / 17.8입니다(`03` V5).
- **표 1(Push Cube, 실로봇 N = 10):** 성공률 DMO 90%, BC 60%(목표 바로 앞 도달을 성공으로 정의, 각주), PPO 40%, No Diffusion 0%. 성공 에피소드만으로 낸 스텝 수(DMO 177.2 ± 52.2, BC 371.0 ± 94.0, PPO 173.5 ± 20.3), 직진도(0.520, 0.330, 0.233), 곡률(0.692, 0.761, 1.222).
- **표 2(Push-T, 10회):** DMO 9/10, PPO 1/10(완화 기준 4/10), No Diffusion 0/10.
- **표 3(G1 Grab Box, 10회):** DMO 8/10, BC 7/10, PPO 1/10, No Diffusion 0/10.
- **부록 A.3(G1 세계모델 정확도, 기울기 정렬, 비용):** 64스텝 열린 루프 LPIPS 전역 0.295 대 RSSM 0.425, 퍼짐-오차 비 0.665 대 0.275. 전역 모델 자동미분을 기준으로 한 기울기 코사인 0.52(분리) 대 0.35(분리하지 않은 Dreamer식) 대 0.08(온라인 미세조정 전 국소 모델). 전역 모델 역전파는 단일 상태 16스텝 청크에 45.6 GB, 1.5 s, 분리형은 3.6 GB, 59 ms.
- **부록 A.6, A.8:** 능동 탐색 행동(큐브가 시야 밖일 때 360도 회전), 저수준 보행 정책을 바꿔도 성공(질적), CEM-MPC는 128 병렬 롤아웃에 H200 16장 이상 필요.

## 5. 한계와 증거의 틈

논문이 밝힌 한계(§5): 전역 모델을 처음부터 학습하고(토크나이저 제외), Push Cube·G1 보상은 사람이 라벨링합니다. 놀이 데이터가 물리 상호작용을 넓게 덮어야 합니다.

이 분석에서 추가로 확인한 점(`03`, `04`):

1. **표본 효율은 세계모델이 만든 표본 기준입니다.** 모든 방법이 같은 세계모델과 놀이 데이터를 쓰므로, "PPO 대비 표본 효율"은 실로봇 데이터 소모가 아니라 세계모델 롤아웃 수의 비교입니다(`04` C2).
2. **그림 5의 곡선 끝은 과제별 끝점의 평균이 아니라 최솟값과 맞습니다**(그림 판독 값). DMO의 집계 곡선(끝 0.087 표본, 0.29 시간)은 Push-T의 끝에 해당하고, Push Cube와 G1의 후반 절반은 집계에 들어가지 않은 것으로 보입니다(`03` V6).
3. **시간 효율은 하드웨어가 다른 비교입니다.** 표 4 "Compute (per Seed)"를 과제 순서대로 읽으면 G1에서 DMO 8 H100, PPO 4 H200입니다. GPU 수를 곱하면 PPO ÷ DMO 시간 비가 2.26에서 1.13으로 줄어듭니다(표 셀 위치 가정, `03` V5).
4. **실로봇 비교는 시행 10회, 방법마다 한 정책입니다.** 시드와 어떤 정책을 배포했는지는 쓰여 있지 않습니다. Fisher 검정으로 구분되는 비교는 DMO 대 PPO(Push-T, G1)뿐이고, DMO 대 BC는 구분되지 않습니다(`03` V2).
5. **BC의 성공 정의가 다릅니다.** 표 1의 BC 60%는 "목표 바로 앞 도달"을 성공으로 센 값입니다(각주). v1에서는 같은 BC를 0% 성공으로 썼습니다(§6).
6. **정량 근거가 없는 주장:** 보행 정책 교체에 대한 강건성(그림 12), 능동 탐색의 빈도(그림 11), 패칭 전후 착취 감소(그림 7), "하이퍼파라미터에 강건"(Push Cube 에피소드 길이 64와 128). 모두 질적이거나 한 문장입니다(`04` C11–C14).
7. **"시뮬레이터 없음"의 범위:** 세계모델 학습과 패칭에는 사람이 개입한 실로봇 데이터 수집이 7회(G1) 반복됩니다. 패칭 데이터 4.4시간은 총 데이터 20.9시간의 21%입니다(`03` V4).

## 7. 한 줄 평

"큰 확산 세계모델 안에서 1차 기울기 RL이 가능하다"는 기술적 주장(분리형 기울기)은 설계가 명확하고 부록 A.3의 기울기 정렬과 비용 수치가 방향을 뒷받침합니다. 반면 "PPO 대비 표본·시간 효율"은 세계모델 표본 기준이고 하드웨어가 다른 비교이며, 실로봇 이득은 시행 10회라서 DMO 대 PPO 정도만 구분됩니다.
