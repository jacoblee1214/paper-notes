> **논문:** Wang, Lin, Huang, Lin, Zhang, Wang. *GPT-6-Astra Understands Touch and Outperform Vision–Tactile–Language–Action Models.* arXiv:2610.28457 (2026). Sun Yat-sen University, X-Era AI Lab, PolyU.
> 논문 그림은 라이선스(arXiv 비독점 배포, CC BY 아님) 때문에 싣지 않았습니다. 이 글의 그래프는 논문 표의 수치와 우리 실험 결과로 직접 그렸습니다. 우리 실험은 GPT-6-Astra 대신 Claude Opus 5.5로 했으므로 원문 수치를 재현한 것은 아닙니다.

## 한 줄 요약

파라미터가 고정된 GPT-6-Astra를 단독 정책으로 씁니다. 오프라인에서 같은 모델이 데모 40개를 요약해 텍스트 **Task Skill**과 **촉각 reference**를 만들고, 폐루프에서는 RGB, 양손가락 촉각, 자세를 받아 EEF 목표를 직접 냅니다. 저자들은 UniVTAC 5개 태스크 평균 93.8%, 촉각을 빼면 Insert Hole이 99%에서 31%로 떨어진다는 결과로 "촉각을 이해한다"고 주장합니다.

## 1. 원문 표를 다시 계산했다

![Tab.2 재도식](images/chart_tab2.png)

- **산술은 맞습니다.** Tab.2 평균, Fig.1C 막대 라벨 30개가 모두 일치합니다. baseline 20칸은 출처 논문의 표와 셀 단위로 같습니다. 즉 재실행한 값이 아니라 옮겨 온 값입니다.
- **제목 주장은 데이터와 반대입니다.** 비교 대상 중 VTLA인 N0-VTLA보다 평균이 2.4%p 낮습니다(93.8 대 96.2). "comparable"도 ±5%p 마진에서만 방어됩니다.
- **유일하게 견고한 차이는 열세입니다.** Pull-out Key가 84 대 99이고, Holm 보정 Fisher p = 0.0008입니다.
- **촉각 ablation 99 대 31은 교란되어 있습니다.** 촉각을 빼는 조건에서 촉각 관측, 촉각 reference, Task Skill(재증류)이 함께 바뀌었고, 태스크도 하나뿐입니다. 효과는 확실하지만 무엇 덕분인지는 원문만으로 알 수 없습니다.

## 2. 같은 구조를 재구현해 돌려 봤다

공식 코드가 없어서 증류 → 고정 컨텍스트 → 폐루프 → 평가 → ablation을 잇는 패키지를 직접 만들었습니다(테스트 123개). 그다음 원문 주장의 메커니즘을 세 단계로 떼어 봤습니다.

### 2.1 단일 판단 probe: 좌표만 알려 주면 62% → 92%

UniVTAC 공개 데모 48개를 첫 접촉 장면에서 멈추고, 구멍이 어느 쪽(+x/−x)으로 기울었는지 물었습니다.

![0단계 probe 결과](images/chart_stage0.png)

- reference 두 개가 있으면 촉각으로 100%를 맞힙니다. 그런데 LLM이 아닌 1-NN도 96%입니다. **대조만으로도 되는 수준**입니다.
- reference가 없으면 62%로 다수 클래스 수준입니다. 근거 문장을 보니 병목은 물리 추론이 아니라 **센서 좌표계**였습니다. 데이터로 보정한 센서 장착 정보 다섯 줄을 주자 92%가 되었습니다.
- reference 라벨을 거꾸로 보여 주면, 좌표 정보가 있어도 48개 모두 뒤집힌 라벨을 따릅니다. **reference와 자기 해석이 충돌하면 reference가 이깁니다.**

### 2.2 폐루프 2×2: 촉각 효과는 Skill이 있을 때만

UniVTAC Insert Hole 폐루프에서 Task Skill 유무 × 촉각 유무를 같은 20 seed로 돌렸습니다. 카메라는 뺐습니다.

![2×2 결과](images/chart_2x2.png)

| 조건 | 성공 |
|---|---|
| 촉각 + Skill | **17/20** |
| Skill만 | 7/20 |
| 촉각만 | 12/20 |
| 둘 다 없음 | 9/20 |

- **촉각 효과는 Skill이 있으면 +50%p(McNemar p = 0.0063), 없으면 +15%p(p = 0.25)입니다.** 촉각만 있고 Skill이 없으면, 모델은 측방 이동을 한 번도 시도하지 않았습니다.
- 원문 형태의 비교(촉각+Skill 대 Skill만)는 85 대 35로 원문 99 대 31과 비슷합니다. 하지만 이 차이에는 촉각×Skill 상호작용(+35%p)과, Skill 없이도 되는 지름길이 섞여 있습니다.

![숨은 결정별 성공률](images/chart_2x2_direction.png)

seed에서 숨은 정답 방향을 복원해 보니, 구멍이 −x로 기운 7개 seed는 촉각+Skill만 풀었습니다(6/7, 나머지 0/7). 근거 문장은 증류된 Skill 규칙을 그대로 인용합니다. 그 규칙은 증류 단계에서 같은 모델이 데모 촉각 데이터로 찾아낸 것입니다("양쪽 전단 y가 양수면 −x"). 반대로 촉각 없는 Skill은 데모 다수 방향으로 찍은 뒤, 막힘이 없자 "방향이 맞았다"고 근거 없이 결론 내렸습니다.

### 2.3 반사실 촉각: 단서를 뒤집으면 행동도 뒤집힌다

상관이 아니라 원인인지 보려고, 같은 Skill과 seed에서 **촉각 프레임만 거울 반전**했습니다. 전단 방향만 바뀌고 나머지 물리는 그대로라서, "구멍이 반대쪽으로 기운 세계"와 일관된 관측이 됩니다.

![반사실 촉각 손끝 경로](images/chart_cf_traj.png)

- 첫 측방 이동이 20/20 모두 구멍 반대쪽으로 갔고(원래 20/20 구멍 쪽, p = 1.9×10⁻⁶), 성공은 17/20에서 1/20으로 떨어졌습니다.
- 반대로 가도 하중은 풀립니다. 모델은 그 신호까지 "방향이 맞다"는 증거로 읽었고, 방향을 의심한 근거 문장은 없었습니다.

## 3. 그래서 무엇을 이해했나

- "촉각을 이해한다"는 이 설정에서 **"데모에서 촉각–행동 규칙을 스스로 추출하고, 폐루프에서 그 규칙대로 읽는다"**로 좁혀 쓰는 것이 데이터에 맞습니다. 규칙을 추출한 것 자체는 모델의 능력입니다.
- 다만 **규칙이 틀렸을 때 물리 피드백으로 고치지는 못했습니다.** 센서 장착이 바뀌거나, sim-to-real에서 부호 규약이 다르거나, 데모가 잘못되면 같은 방식으로 실패할 것입니다.
- 비용도 큽니다. 촉각+Skill은 결정당 약 30초(약 0.03 Hz)이고, episode당 출력 토큰은 약 46k입니다. 원문은 비용과 지연을 보고하지 않았습니다.

## 4. 직접 구현할 수 있나

| 경로 | 판단 |
|---|---|
| 원문 수치 재현 | 불가능합니다. GPT-6-Astra, 원문 프롬프트, Task Skill 원문이 없고 공식 코드도 공개되지 않았습니다 |
| 아이디어 재구현 | 해 봤습니다. 다른 모델(Claude Opus 5.5)로 같은 구조를 만들어 UniVTAC 폐루프까지 돌렸습니다 |
| 더 나아가려면 | 원문 조건(카메라 포함)과 나머지 4개 태스크는 Isaac Sim 5.1을 돌릴 NVIDIA GPU 서버와 수백 회의 LLM 호출이 필요합니다 |

## 5. 이 실험의 한계

모델이 원문과 다르고, 카메라를 뺐으며, 태스크 하나에 조건당 20 episode입니다. 그래서 원문 수치를 직접 반박하는 근거는 아닙니다. 대신 원문 실험만으로는 구분할 수 없던 두 가지를 보여 줍니다. 하나는 "증류된 규칙"과 "촉각 관측"이 각각 얼마나 기여하는지이고, 다른 하나는 규칙이 결정의 원인이라는 점입니다.
