## 1. 한 문단 요약

영상 세계 모델(SVD 기반, Ctrl-World 백본)은 RGB만 학습해서 프레임마다 그럴듯하지만 3D로 맞물리지 않는 롤아웃을 만듭니다. 저자들은 두 가지를 냅니다. 첫째, DROID의 다시점 스테레오와 URDF를 써서 로봇 한 대의 모든 에피소드를 묶은 **요인 그래프(factor graph) 보정**으로 DROID-3D(71,100 장면의 메트릭 깊이와 재보정된 외부 카메라 자세)를 만듭니다(§3). 둘째, RGB와 깊이를 **각각 SVD VAE로 인코딩해 잠재 격자에 옆으로 붙이는 공간 타일링**으로 깊이를 같은 U-Net에 공동 예측시키고, 선택적으로 **DPT 점지도 헤드**로 로봇 기준 좌표의 3D 점을 보조 손실로 맞춥니다(§4). 주 결과는 같은 학습 예산에서 깊이를 함께 예측하면 외부 시점 PSNR이 +1.48 dB 오르고(표 2, PM-DPT 기준), 보정은 PointWorld식 장면별 보정보다 중앙값 재투영 오차를 약 23배(외부-외부), 13배(손목-외부) 줄인다는 것입니다(표 1).

## 2. 문제 설정과 방법

### 2.1 DROID-3D 보정 (§3, 식 1–2, 부록 A–B)

- **Stage 1 (§3.1):** 각 카메라 쌍의 스테레오 시차를 S²M² 전역 매칭 네트워크로 메트릭 깊이로 바꿉니다(부록 A.1, 식 A1). 다시점 정합은 RoMa v2의 조밀 대응과 두 단계 번들 조정으로 합니다. 1단계는 외부 두 카메라를 맞추고, 2단계는 손목 카메라 자세를 순운동학과 공장 손-눈 값으로 고정해 외부 쌍 전체를 한 SE(3)로 움직입니다.
- **Stage 2 (§3.2):** 로봇 URDF를 외부 영상에 렌더링해 LoMa-G의 2D–3D 대응으로 로봇 기준 좌표에 묶습니다. 요인 그래프의 변수는 에피소드마다 외부 카메라 보정 두 개(12자유도)와 로봇마다 공유되는 손-눈 보정 6자유도 + 관절 오프셋 7자유도입니다(식 1). 손목 카메라 자세는 식 1로 결정되고 에피소드별 자유도가 없습니다.
- **목적 함수 (식 2):** Cauchy 강건 손실 아래에서 다섯 항(2d, 3d, l, ee, f)을 합하고, 관절 오프셋에는 Tikhonov 항 λq‖δq‖²를 더합니다. 부록 B.4의 값은 c2d = 3σ, c3d = 10 mm, cl = 50 px, cee = 5 px, λ3d = 10⁴, λq = 10⁻², 배포 설정은 "3D 증폭, FM 제외"입니다.
- **계산:** Schur 보완으로 에피소드 블록을 소거해 13×13 전역 풀이로 줄입니다(§3.2). 로봇 그룹당 약 12.5분입니다(부록 B.4). 이 최적화기는 GPU 가속 LM으로 설명되며, **공개 저장소에 없습니다**(`analysis/04_code_verification.md` D9).
- **데이터:** DROID 원본의 71k 궤적 분할을 쓰며, 13개 기관, Franka Panda 28대, 13개 연구실, 71,100 장면입니다(§3.3). 외부 카메라는 ZED 2 두 대, 손목은 ZED Mini입니다.

### 2.2 DepthWorld 구조 (§4.1, 그림 3, 부록 C.1–C.4)

- **입력:** 3대 카메라(외부 2, 손목 1) × 2개 모달리티(RGB, 깊이), 해상도 192×320, 5 Hz, 시간 창 11프레임(과거 6, 미래 5). 과거 프레임은 Ctrl-World처럼 희소하게 뽑습니다(부록 C.7, 설정 `history_idx = [0, 0, -12, -9, -6, -3]`).
- **깊이 전처리 (부록 C.1):** 실제 깊이를 언프로젝션한 뒤 z-버퍼 최소 풀링으로 192×320에 맞추고(쌍선형 보간을 쓰지 않음), 카메라별 95백분위로 자른 뒤(외부 약 3 m, 손목 약 2 m), 로그 변환하고 [0, 1]로 정규화해 세 채널로 복제합니다.
- **공간 타일링 (§4.1):** 각 뷰와 모달리티를 수정하지 않은 SVD VAE로 24×40 잠재로 인코딩합니다. RGB와 깊이를 가로로 붙이고(폭 2·40 = 80), 뷰 3개를 세로로 쌓아 **72×80 잠재 격자 하나**를 만듭니다. U-Net 변경은 위치 임베딩을 넓히는 것뿐입니다.
- **행동 조건:** 프레임별 7차원 엔드이펙터 행동(6자유도 자세 + 그리퍼)을 Ctrl-World와 같은 방식으로 넣습니다(부록 C.6).
- **점지도 헤드 (§4.2, 식 A7–A12):** SVD U-Net의 예측 잠재 x̂0,f의 RGB 절반과 깊이 절반을 뷰마다 8채널로 합쳐 DPT 피라미드(24×40 → 3×5)로 올리고, 로봇 기준 좌표의 XYZ와 신뢰도 logit을 냅니다. 손실은 log 맵 φ 위의 Barron 강건 손실(α = 0.5, c = 0.05)을 DUSt3R식 신뢰도 가중(C = 1 + exp, β = 0.2)으로 씁니다. 상위 5% 잔차를 버리고, EDM 가중치는 min-SNR 상한 5로 자릅니다(부록 C.5). 헤드의 융합 몸통과 회귀기는 VGGT에서 가져옵니다.

### 2.3 학습 (§4.2 끝, 부록 C.6)

- **두 단계:** 1단계 40k 스텝은 λpm = 0으로 공동 잠재 분포만 학습합니다. 2단계 50k 스텝은 DPT 헤드를 붙이고 λpm = 0.005로 전체를 학습합니다. 합계 90k 스텝입니다.
- **설정:** 시작점은 Ctrl-World의 SVD 체크포인트, AdamW 상수 학습률 10⁻⁵, 전역 배치 64, EMA 0.9999, 두 H200 노드에서 약 2일입니다.
- **추론:** 50 디노이징 스텝, CFG 스케일 2(Ctrl-World와 같음), 자기회귀 10청크(약 8.2 s, §5와 부록 D.3).

### 2.4 평가 설계 (§5, 부록 D.1–D.3)

- **보정 평가:** 약 1,000 장면(5개 연구실, 995장면)에서 네 가지 기하 대리 지표(EE, WE, RD, Mask IoU)를 씁니다. 비교 기준은 PointWorld식 장면별 보정이며, 깊이 소스만 S²M²로 바꿨습니다(부록 D.1). 독립 검증으로 ChArUco 보드로 잰 5개 캡처 세트의 실제 자세를 쓰고, REALM 시뮬레이터 50개 구성도 씁니다.
- **세계 모델 평가:** 무작위 에피소드 1% 검증 세트에서 256 궤적을 뽑습니다(부록 D.3). 같은 로봇과 같은 연구실이 학습과 검증에 섞여 있다고 저자가 직접 씁니다. 깊이 지표는 S²M² 깊이를 SVD VAE로 한 번 왕복시킨 참조와 비교합니다(부록 C.8).
- **PointWorld 비교 (부록 D.4):** 두 모델을 같은 256 창(141 + 147)에서 3D 점 궤적으로 바꿔 채점합니다. 추적 점은 CoTracker3로 만든 가짜 정답이고(S²M² 깊이 기반), 로봇 팔 픽셀은 뺐습니다. 공정 비교는 "자기 표현의 하한"에 맞춘 대각선만 씁니다(표 A5).
- **TesserAct 비교 (부록 D.5):** 텍스트 조건 단일 시점 모델을 행동 조건으로 바꿔 같은 에피소드로 50k 스텝 학습했고, 128 샘플로 평가했습니다.

- 교차 뷰 재투영(GT 깊이와 자세로 한 외부 시점을 다른 시점으로 워프): RGB 16.60 → RGB+D 17.60 dB(+1.0 dB), PM-DPT는 +0.05–0.08 dB 더 얻는다고 합니다(§5).

### 3.3 다른 세계 모델과 비교 (§5, 표 A5, 부록 D.4–D.5)

- **PointWorld (표 A5, 공정한 대각선):** 추적 점 ℓ2는 2 s에서 PW 23 mm, DW 31 mm, 8 s에서 PW 56 mm, DW 46 mm입니다. 전체 장면 Chamfer는 2 s에서 둘 다 8 mm, 8 s에서 PW 18 mm, DW 9 mm입니다. 움직이는 점 Chamfer는 2 s에서 PW 21, DW 25, 8 s에서 PW 58, DW 32입니다.
- **TesserAct (부록 D.5):** 50k 스텝에서 외부 PSNR 19.43 dB, AbsRel 0.154입니다. DepthWorld RGB+D는 24.07 dB, 0.074입니다. 저자는 TesserAct의 롤아웃이 40프레임에서 PSNR 16.8로 떨어진다고 보고합니다.

### 3.4 절제 (부록 A–C)

- **깊이 소스 (표 A3, 50k 스텝):** S²M²와 ZED NEURAL은 RGB PSNR이 0.2 dB 안에서 같습니다. ZED ULTRA는 외부 PSNR −1.96 dB, 손목 −1.40 dB이고, 외부 AbsRel이 0.074에서 0.194로 오릅니다(§C.3).
- **통합 방식 (표 A2, 약 70k 스텝):** 공간 타일링이 이중 분기와 채널 확장보다 RGB 세 지표 모두 낫다고 합니다. 이중 분기는 RGB 우선 50k 뒤 20k 추가 학습으로 조건이 다르다고 저자가 씁니다(§C.2).
- **점지도 외부 자세 (표 A4):** 공장 외부 자세로 만든 점지도 목표는 손목 AbsRel 0.233, 보정 자세는 0.220입니다. RGB는 같습니다(§C.4).
- **보정 요인 절제 (표 A1, 약 1,000 장면):** 확장-확장 요인을 빼면 EE가 0.25에서 0.66 px로 나빠지고, 손목 3D 요인이 없으면 WE 변화가 작습니다. 손-눈 보정 δTwrist를 빼면 WE가 1.03에서 2.07 px로 오릅니다.

### 3.5 저자가 한계로 인정한 것 (§5)

- 자기회귀 롤아웃의 노출 편향과 품질 저하가 있습니다. RL 후처리(PersistWorld)가 안정성을 높인다고 인용합니다.
- 손목 깊이 품질은 외부보다 낮습니다(δ1 ≈ 0.82 대 0.94). 빠른 움직임과 자기 가림 때문입니다.
- 점 궤적에서는 PointWorld가 움직이는 물체를 잘 맞추고, 깊이 잠재 표현이 잡음 바닥을 만든다고 부록 D.4에 씁니다.

## 5. 재현에 필요한 정보와 빠진 정보

- **있는 것:** 구조(그림 3, 잠재 72×80), 손실 식(A7–A12), 학습 단계와 스텝 수, 옵티마이저와 학습률, EMA, 배치 크기 64, 추론 스텝 50과 CFG 2, 평가 지표 정의(D.2–D.3), 보정 상수(B.4).
- **빠진 것:** (1) 보정 최적화기의 구현, 공개 저장소에 없습니다. (2) 두 번째 시드와 창별 분산. (3) 배치 64가 GPU 몇 개와 어떤 누적으로 만든 값인지. (4) RGB 기준선의 정확한 잠재 크기와 스텝 수. (5) PM-DPT 헤드 학습의 정확한 시작 체크포인트(공개 README는 40k 시작과 100k 한도를 씀). (6) S²M² 깊이 추론 설정과 스테레오 모델 가중치의 출처. (7) CoTracker3 기반 추적 가짜 정답의 샘플링 설정.
- **재현 난이도:** 학습은 H200 두 노드 약 2일(C.6)입니다. 이 맥에서 학습은 불가능합니다. 추론도 6.1–6.2 GB 체크포인트와 CUDA 기본 경로 때문에 그대로는 어렵습니다(`analysis/04_code_verification.md` §4).
