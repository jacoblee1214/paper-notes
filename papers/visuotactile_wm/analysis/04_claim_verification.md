공식 코드가 확인되지 않아 `04_code_verification.md`를 쓰지 않습니다. 대신 논문 주장과 본문 수치를 대조합니다. 코드는 clone하지 않았고, 실행하거나 설치한 것도 없습니다. 근거는 본문과 `analysis/03_analysis.md`, `analysis/recompute_results.json`입니다.

## 1. 주장 목록과 판정

## 2. 추가로 확인할 내용 (코드 없이 할 수 있는 것)

- V-WM과 VT-WM의 파라미터와 학습 설정 차이를 본문에서 찾을 수 없었습니다(부록 B.1은 VT-WM만 설명). 이 점은 C1–C3 해석에 영향이 큽니다.
- 학습 목표는 시각 잠재 예측 ℓ1입니다. 촉각 잠재의 ℓ1 손실 가중치가 시각과 같아서 촉각이 지배하지 않는다는 근거는 없습니다.

## 3. 검증 불가 항목 (데이터와 코드가 없음)

- 그림 4, 6, 7의 막대 값과 오차 막대.
- 롤아웃 개수, 실로봇 시행 수와 원 성공 수.
- 두 모델의 파라미터 수와 학습 설정(V-WM).
- Sparsh-X 미세조정 효과를 분리한 실험.

## 4. 구현 가능성 판정

**판정: 전체 구현은 이 맥에서 불가능합니다. 개념 검증용 축소판은 가능합니다.**

- 환경: Apple M4 Pro, 약 24 GiB 통합 메모리, MPS 있음, CUDA 없음.
- **불가:** 173M 모델 학습(논문 32 A100, 80k 업데이트), 실로봇 Franka+Allegro+Digit 360 평가, 원 데이터(공개 여부 미확인).
- **조건부:** Cosmos 토크나이저와 Sparsh-X 추론(가중치 다운로드와 라이선스 확인 필요, 승인 전까지 실행 안 함). 추론만 MPS로 가능할 수 있으나 측정 전입니다.
- **가능:** 2D 촉각 접촉 toy로 "촉각 입력이 접촉 상태 예측을 바꾸는가"를 CPU에서 확인(분 단위 예상). 보고 수치 재계산(완료).
- **노력 추정(측정 전):** toy 1–2일, 축소 촉각 예측기 재구현 1–2주, 논문 규모 재구현(코드 미공개) 3–4주 + GPU 학습 기간.
