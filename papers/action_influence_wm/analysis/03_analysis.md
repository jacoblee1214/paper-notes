## 5. 정리의 유도 검토

### 5.1 정리 1 (식 2, 부록 A.1)

단계별로 확인했습니다.

1. 식 (A.1)은 KL 두 개의 차이에서 log p(s'|s,a) 항이 소거되어 E[log p̂_θ(s'|s,a) − log p̂_{θ,π}(s'|s)]가 됩니다. **맞습니다.**
2. 식 (A.4)의 I − Î는 log p − log p_π − log p̂_θ + log p̂_{θ,π}입니다. **맞습니다.**
3. p(s'|s,a)π(a|s) = p_π(s'|s) q_π(a|s,s')를 쓰면 log p − log p_π = log q_π − log π이고, 같은 식을 p̂에 적용하면 log p̂_θ − log p̂_{θ,π} = log q̂_π − log π입니다(q̂ 정의 A.3). 차를 취하면 π가 소거되어 E[log q_π − log q̂_π]입니다. **맞습니다.**
4. 기댓값을 ρ p_π q_π로 바꾸면 KL(q_π‖q̂_π)의 평균이 되고 ≥ 0입니다. **맞습니다.**

결과적으로 I − Î = E_ρ p_π[KL(q_π(·|s,s') ‖ q̂_π(·|s,s'))] ≥ 0 입니다. 두 가지를 덧붙입니다.

- 이 항등식에서 **I는 ρ와 π에서 참 전이로 계산되는 양**입니다. 정책 π를 데이터 수집 정책으로 놓고 ρ를 데이터 상태 분포로 놓으면 I = I_D입니다. 모델이 어떻게 학습되었는지는 식에 없으므로, 같은 부등식이 **학습 데이터와 무관하게** 모든 모델 p̂에 대해 성립합니다.
- 따라서 "데이터가 상한이다"는 말은 **평가 분포를 데이터 분포로 놓을 때**의 읽기입니다. 평가 정책이 다르면 우변은 평가 분포의 I(ρ_eval, π_eval)이고, 데이터의 I_D와 비교할 수 없습니다.

### 5.2 정리 2 (식 5–6, 부록 A.2–A.3)

1. **보조정리 1 (A.6–A.10).** L_k^ρ(π) = E[log q_k − log π]에서 q_k가 β_k의 참 사후분포이면 L_k(β_k) = I(ρ, β_k)이고 L_k(π) ≤ I(ρ, π)입니다. **맞습니다.** (토이 T2에서 2000개 무작위 환경 모두 확인)
2. **A.12.** L_k(π) = E[r_info] − E_ρ KL(π‖β_k), r_info = log q_k − log β_k. E_π[−log π] = −E_π[log β_k] − KL이므로 **맞습니다.**
3. **A.13.** η = 1인 KL 제약 문제의 해는 π* ∝ β exp(E_{s'}[r_info])입니다. **맞습니다.**
4. **A.14.** r_cov = log ρ(s) − log d_k(s)는 **a에 의존하지 않으므로** 상태별 조건부 정책에서 소거됩니다. 따라서 r_AIM의 최적 조건부 정책은 r_info만 쓴 것과 같습니다. 이는 증명이 맞다는 뜻이면서, **정리 2가 r_cov의 역할을 말해 주지 않는다**는 뜻이기도 합니다. r_cov는 정리 밖에서 도입된 설계입니다.
5. **A.15.** I(ρ, π*) − I(ρ, β) ≥ L(π*) − L(β) > 0. 엄밀 부등호는 π* ≠ β에서 L이 π*에서 유일 최대이기 때문입니다. **맞습니다.**

정리가 보증하는 대상은 (a) **정확한 q_k**, (b) 한 단계 정책(문맥 밴딧), (c) 상태 분포 ρ 위의 평균 I입니다. 알고리즘은 (a) 학습한 흐름 밀도 q̂, β̂, d̂, (b) IQL과 AWR 순차 RL, (c) z-점수와 AWR 클립이 들어간 보상(식 C.2)으로 이를 근사합니다. 저자도 "순차 RL 근사는 개선을 보증하지 않는다"고 씁니다(§5).

그림 3은 재현됩니다. 해석상 주의가 둘 있습니다. 첫째, 점 36개는 서로 독립이 아닙니다. 같은 시리즈의 규모들이 한 곡선을 이룹니다. 둘째, 가로축은 사이트 설명대로 "model-explained action influence", 곧 **세계모델의 Î**이고, 세로축 시뮬 충실도는 같은 모델의 모든 상태-행동 쌍에서의 최대우도 상태 일치입니다. 두 양은 모두 "모델이 그 전이를 얼마나 맞히는가"의 함수라서 같은 모델 둘레에서 함께 움직이는 것이 자연스럽고, 데이터의 I_D가 모델의 Î를 제한한다는 정리 1의 서술(데이터 쪽 양)과는 다른 것을 잰 그래프입니다(K2). Uniform Random은 영향 1.097–1.098, 충실도 98.9–99.6%로 거의 한 점입니다.

## 10. 토이

### 10.1 T1: 정리 1의 범위 (`toy_theory.py` A)

환경 s' = s + a + η (η ~ N(0, 0.01²)), 데이터 정책 a = −0.5 s + σ_a ξ. 모델 두 가지(선형 회귀, k-최근접 이웃)를 4000개 표본으로 학습하고 식 (A.1)의 Î를 정확한 구적으로 계산합니다(몬테카를로가 아니라 행동 격자 합). 평가는 (i) 평가 정책 = 데이터 정책, (ii) 다른 학습자 a ~ N(0, 0.5²)입니다. 데이터의 조건부 상호정보는 I_D = ½ log(1 + σ_a²/σ_η²)입니다.

| σ_a | I_D | 선형, (i) 데이터 분포 | 선형, (ii) 다른 학습자 | kNN, (i) | kNN, (ii) |
|---|---|---|---|---|---|
| 0.01 | 0.347 | 0.34 | **3.69** | 0.15 | −1455 |
| 0.03 | 1.151 | 1.16 | **3.90** | 0.70 | −619 |
| 0.1 | 2.308 | 2.32 | **3.92** | 1.60 | −78 |
| 0.3 | 3.402 | 3.37 | 3.92 | 2.14 | −1.1 |
| 1.0 | 4.605 | 4.61 | 3.89 | 2.80 | 1.75 |

(단위 nats. 평가 정책의 참 상호정보 I_eval = 3.91. 표에 없는 σ_a = 0.001, 0.003 행은 선형 모델이 식별되지 않아 (ii)가 −44, −4.7)

- (i) 데이터 분포에서 평가하면 모든 행에서 Î ≤ I_D입니다(+0.01 이내의 표본 오차 포함). **정리 1의 직접 결과가 확인됩니다.** 선형 모델은 σ_a가 클 때 I_D에 거의 붙고(2.32 대 2.31), kNN은 아래에 머뭅니다.
- (ii) 평가 정책이 다르면 **외삽하는 선형 모델의 Î는 I_eval = 3.91에 가깝고 I_D보다 훨씬 큽니다**(σ_a = 0.01에서 3.69 대 0.35). 그래도 항상 참 I_eval 이하입니다(정리 1의 우변). 이는 정리 1이 틀렸다는 것이 아니라 **우변이 평가 분포의 I**라는 읽기가 확인된 것입니다.
- 외삽하지 않는 kNN은 데이터 밖에서 Î가 크게 음수가 되어 "행동을 무시하는 것보다 나쁜" 예측을 합니다. σ_a = 0인 극단(전문가 결정적)에서는 선형 회귀도 (w_s, w_a) = (0.4, −0.2)로 행동 계수 부호가 틀려 Î = −2957이 됩니다. 이는 논문의 "전문가 데이터는 행동을 무시해도 된다"는 현상과 맞는 방향입니다.
- 이 토이의 모델은 데이터 분포 밖으로 **올바르게** 외삽하는 선형 구조를 갖고 있어 이득을 얻은 경우입니다. 현실의 픽셀 세계모델이 이런 외삽을 얼마나 하는지는 논문에서도 "추가 귀납 편향 없이는" 조건으로 열어 둡니다(§3.2).
