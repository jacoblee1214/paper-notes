# 03. 수치 재계산, 일관성 검사, 주장 판정

## 0. 방법과 가정

- 재계산 스크립트: `analysis/recompute.py` (수 초, numpy와 scipy). 결과: `analysis/recompute_results.json`. 재현 실험(학습, 추론)은 하지 않았습니다. 이 문서의 모든 숫자는 논문 원문 값과 저장소 문서 값을 다시 계산한 것입니다.
- **가정 1.** 표의 "±"는 표본 SD(모집단, ddof = 0)입니다. 논문은 정의하지 않았지만 저장소 `engine/metrics.py`가 같은 정의를 씁니다.
- **가정 2.** 단위는 mm입니다. 논문 캡션과 본문이 mm라고 씁니다. 저장소 문서에는 m라고 된 곳도 있습니다(`04` D19).
- **가정 3.** 표 1과 2의 비교는 두 독립 표본의 Welch 검정입니다. 같은 시험 프레임을 쓰므로 짝 검정이 맞지만, 프레임별 짝 정보가 없어 쓸 수 없습니다.
- **핵심 한계.** 시험 프레임 21,853개는 독립 에피소드 4개에서 나왔습니다. 프레임 기준 검정은 표본 독립을 가정하므로 p값이 지나치게 작습니다. 그래서 두 번째 기준으로 **에피소드 수준 임계값**을 씁니다. 에피소드 4개로 짝 t검정(df = 3, 양측 0.05, t = 3.18)을 통과하려면, 에피소드별 차이의 SD가 `2 × |평균 차이| / 3.18`보다 작아야 합니다. 이 값을 "SD 상한"이라 부릅니다. 논문이 에피소드별 값을 주지 않으므로 실제 SD는 알 수 없습니다.

## 1. 재계산

### 1.1 표 1 (RMSE, 평균 ± SD, 시험 프레임 21,853)

| 비교 (제안 − 기준선) | 평균 차이 (mm) | Cohen d | 프레임 기준 Welch p | 에피소드 SD 상한 (mm) |
|---|---:|---:|---:|---:|
| 대 Pose-Only | −24.48 | −1.29 | < 1e-300 | 15.4 |
| 대 Pose + Direction | −20.11 | −0.99 | < 1e-300 | 12.6 |
| 대 ResNet-18 + Cross-Attn | −5.48 | −0.31 | 4e-225 | 3.4 |
| 대 w/o B-spline | −4.49 | −0.28 | 9e-189 | **2.8** |
| 대 w/o L_weighted | −6.48 | −0.35 | 2e-295 | 4.1 |

- 프레임 기준 95% 구간 반폭은 평균당 약 0.2 mm입니다(1.96 × 15.22 / √21853). 그래서 구간은 의미가 거의 없습니다. 실제 불확실성은 에피소드 수준에 있습니다.
- Cohen d는 0.28–1.29입니다. 제안 모델과 가장 가까운 기준선(w/o B-spline)과의 차이는 "작은" 효과입니다.

### 1.2 표 1 (Chamfer)

| 비교 (제안 − 기준선) | 평균 차이 (mm) | Cohen d | 에피소드 SD 상한 (mm) |
|---|---:|---:|---:|
| 대 Pose-Only | −16.71 | −1.04 | 10.5 |
| 대 Pose + Direction | −13.41 | −0.90 | 8.4 |
| 대 ResNet-18 + Cross-Attn | −2.71 | −0.19 | **1.7** |
| 대 w/o B-spline | −2.77 | −0.21 | **1.7** |
| 대 w/o L_weighted | −3.53 | −0.24 | 2.2 |

- 제안 모델이 Chamfer에서도 최저입니다(27.29 mm). 그러나 ResNet과 w/o B-spline과의 차이(2.7–2.8 mm)는 d가 0.2 수준입니다. 에피소드 4개로 확정하려면 에피소드 간 차이의 SD가 1.7 mm 미만이어야 합니다.

### 1.4 규모 변화와 기타 본문 수치

- 유효 길이 500 mm와 580 mm(재학습 없음): 36 mm와 40 mm, 전체 대비 +5.5 mm와 +9.5 mm.
- 에피소드 수: 15/36 = 41.7%(본문 "약 42%" 맞음). 학습 에피소드당 평균 프레임 196,678/36 = 5,463(본문 "약 5,460" 맞음).
- 표 1 지연: 1000/61.5 ms = 16.26 Hz(본문과 표 맞음). 1000/17.6 = 56.82 Hz(ResNet, 맞음).
- 파라미터 차이는 §2의 K2를 보십시오.

## 4. 재현 없이 할 수 있었던 검사와 못 한 검사

- 할 수 있었던 것: 표 재계산, 파라미터 수의 산술 설명(K2), 학습률과 샘플 수의 내부 일관성(K3, K4), 에피소드 수준 상한(§0, §1).
- 하지 않은 것: 토이 실험. 논문의 핵심 주장(촉각 표현의 기여, 물리 손실의 기여)을 CPU 토이로 검증하면 토이 설정이 논문과 달라서 의미가 약합니다. 그래서 생략했습니다(전체 재현은 `04` §4).
- 할 수 없는 것: 에피소드별 오차, 시드 변동, 시험 예측 파일이 공개되지 않아 p값과 구간을 더 정확히 계산할 수 없습니다. 저장소 `experiments/`의 결과 파일도 없습니다(`clone` 기준).
