# ART-Glove 저장소 대조와 주장 검증 (04)

공식 저장소(`linchangyi1/ART-Glove`)가 있습니다. 다만 공개된 것은 **기계 설계 파일, BOM, 조립 가이드**뿐입니다. 전자 회로, 촉각 FPCB, 펌웨어, 캘리브레이션과 기록 도구는 "다음 공개 단계"로 미뤄져 있습니다. 그래서 이 문서는 (1) 공개된 파일이 논문과 맞는지 대조하고(D1–D7), (2) 논문 주장을 수치와 산술로 검증하며(C1–C14), (3) 구현 가능성을 판정합니다(§4).

판정 기준: **재현됨**(산술 또는 표 수치가 맞음), **부분**(방향은 맞으나 근거가 약하거나 조건이 붙음), **확인 불가**(논문과 저장소에 정보가 없음), **불일치**(본문, 표, 저장소가 서로 어긋남).

## 4. 구현 가능성 판정

### 4.1 공식 재현: **부분 가능 (기계만 가능, 센싱은 불가)**
- 기계 쪽: STEP, 3MF, DXF, BOM, 조립 가이드가 있어서 셸, 관절, 기어를 만드는 것은 가능합니다. 다만 가이드는 1–4장에 걸친 단계별 조립과 Type III 공차 조정을 요구하며, 저자도 Type III가 공차에 민감하다고 씁니다(§8).
- 센싱 쪽: 촉각 FPCB, 엔코더 PCB, 판독 PCB, 펌웨어, 캘리브레이션 도구가 공개되지 않았습니다. 촉각과 엔코더 신호를 얻을 수 없으므로 논문의 핵심 결과(C7, C10–C12)는 공식 파일로 재현할 수 없습니다.
- 논문 결과 대부분(Fig. 9–11)을 재현하려면 공개 전자 파일이 필요합니다.

### 4.2 이 맥 (Apple M4 Pro, 통합 메모리 약 24 GiB, MPS, CUDA 없음, torch 미설치)
| 항목 | 판정 |
|---|---|
| 기계 재현 (3D 프린트, 절단, 조립) | **장비 의존.** 3D 프린터, 절단기, 납땜 장비가 있어야 하며, 이 환경에 있는지는 확인하지 않음. 없으면 외주 |
| 전자 재현 (PCB, 엔코더, 판독) | **불가**. PCB 파일 미공개 |
| 펌웨어와 데이터 수집 | **불가**. 코드 미공개 |
| 촉각 정확도 재측정 | **불가**. 장갑 하드웨어 필요 |
| 토이 수준 검증 (numpy, 이 폴더에서 완료) | **가능**. 토이 A–C와 산술 검산 |
| 학습 재현 | **해당 없음**. 논문에 학습 실험 없음. torch 설치 불필요 |

### 4.3 같은 장갑을 새로 만드는 노력
- **높음.** 필요한 설계: (a) 압저항 촉각 FPCB와 행·열 전극 배치 (부록 B를 기준으로 가능, 공정 자료 필요), (b) 엔코더 PCB 5종 또는 동등 회로, (c) 저잡음 행렬 판독 PCB와 STM32 펌웨어 (SPI 대역은 충분, 정착 시간 확인 필요), (d) Type III 호형 슬롯 기구의 공차 조정.
- 가장 큰 어려움은 (a)와 (c)입니다. 판독 회로 설계는 [41] (HIPI, 같은 저자)에 근거가 있지만 그 저장소는 이 조사에서 찾지 못했습니다(02 §2).
- 노력의 정량 추정(시간, 비용)은 하지 않았습니다. 근거가 부족합니다.

### 4.4 하드웨어 요구
- 기계: 3D 프린터 (논문은 PLA 1 mm 셸, BOM은 Bambu Lab H2D 기준, $1,849) 또는 외주, 절단 장비 (Velostat와 TB641 절단, BOM의 $69 절단 키트는 H2D용), 소형 나사와 베어링, E-clip.
- 전자: STM32F411CEU6 보드와 ST-LINK, 엔코더 AS5600L (BOM에 없음, 공개 후 확인), 판독 PCB (미공개), FFC 커넥터 0.5 mm와 1 mm.
- 검증 장비: Dynamixel XC330 서보 (논문 Fig. 9 기준).
- 비용: 가격이 있는 항목 합계 $474.23 (프린터 제외), 프린터를 더하면 $2,323.23. PCB와 촉각 FPCB는 가격 미정입니다.

### 4.5 판정 요약
- **공식 재현: 부분 가능.** 기계 파일은 공개되어 있지만, 촉각과 센싱 재현에 필요한 파일은 공개 전입니다.
- **이 맥에서의 재현: 불가.** 소프트웨어는 공개되지 않았습니다. 토이 수준 검증만 가능합니다.
- **새로 만드는 구현: 가능하지만 노력이 큽니다.** 기계 조립은 중간, 촉각 FPCB와 판독 회로는 높음.
- **가치 판단:** 설계 아이디어(해부학적 정렬 관절, 면 단위 촉각, 접촉 라벨)는 토이로 검증할 수 있고 가치가 있습니다(`03` §5–8). 촉각 힘 보정과 시연 데이터 없이는 로봇 학습 효과를 말할 수 없습니다.
