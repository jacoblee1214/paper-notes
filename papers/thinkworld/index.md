## 한 줄 요약

VLM이 행동 전에 사람과 로봇이 공유하는 **1초 손목 움직임 토큰(Chain-of-Dynamics, CoD)**을 만들고, 그 토큰으로 1초 뒤 장면의 DINOv3 특징을 예측하도록 학습합니다. 그다음 예측과 실제 미래가 잘 맞는 CoD에 보상을 주는 GRPO로 VLM을 강화합니다. 배포할 때는 CoD도 예측도 쓰지 않습니다. 추론 구조는 Qwen3-VL-2B + MolmoAct2 action expert로 된 일반 VLA와 같습니다.


## 1. 실물 결과: 차이는 크지만 ID부터 다르다

YAM 양팔 로봇의 세 과제에서 ThinkWorld는 112/120회를 성공했고, MolmoAct2는 72/120회였습니다(Fisher p = 6×10⁻¹⁰). Table 6의 Macro·Micro와 Fig. 1의 막대값(과제 평균)도 모두 정확히 재현됩니다. 그런데 읽을 때 걸러야 할 점이 세 가지 있습니다.

![실물 로봇 설정별 성공률](images/real_robot_ci.png)

- **"ID에서는 비슷하다"는 서술은 수치와 맞지 않습니다.** ID에서도 60/60 대 47/60입니다(p = 1.2×10⁻⁴). 그래서 OOD 우위를 일반화 능력만의 효과로 떼어 읽기 어렵습니다.
- **컵 걸기에서는 기준선이 OOD에서 오히려 오릅니다.** MolmoAct2는 73% → 93%, LaWAM은 60% → 80%입니다. "기준선이 OOD에서 크게 떨어진다"는 캡션은 이 과제에서 반대입니다.
- **학습 seed는 1개입니다.** 설정별로 보면 MolmoAct2 대비 유의한 곳은 6개 중 3개입니다.

## 2. 이득의 대부분은 미래 예측 보조 손실이다

Table 3은 구성 요소를 하나씩 더한 LIBERO-PRO 결과입니다. 총 이득 15.5%p를 나눠 보면 이렇습니다.

![Table 3 구성 요소별 이득](images/component_gain.png)

| 추가한 것 | 평균 이득 | 몫 |
|---|---|---|
| 이력 프레임 | +0.5 | 3% |
| **1초 뒤 DINO 특징 예측** | **+9.7** | **63%** |
| CoD 토큰 | +4.0 | 26% |
| 세계 상상 RL | +1.3 | 8% |

배포된 정책은 CoD도 예측도 쓰지 않으므로, 이 이득은 "추론"이라기보다 **보조 손실과 데이터로 만든 표현 학습**의 효과로 읽는 편이 정확합니다. 논문 제목의 핵심인 RL은 SFT 반복 수의 1.3%(2k iteration)이고 평균 +1.3%p입니다.

## 3. 보상의 신호 폭이 형식 오류 벌칙보다 작다

부록 A.6의 보상(Eq. 6)은 "전체 패치 평균 코사인"과 "움직인 패치에 가중한 코사인"의 평균입니다. 식을 그대로 옮겨 계산해 봤습니다.

![Eq. 6 가중치와 보상 차이](images/reward_weights.png)

- **가중치가 순위만으로 정해집니다.** 그래서 가장 많이 변한 상위 10% 패치는 보상의 17.4%만 차지하고, 움직임이 거의 없는 하위 절반이 38%를 차지합니다.
- **CoD가 바꾸는 보상 폭은 약 0.03입니다.** Table 2의 차이를 이 보상으로 환산한 값이고, 형식이 깨진 CoD에 주는 벌칙 0.05가 이보다 큽니다.
- **형식 오류가 섞이면 신호가 줄어듭니다.** 4개 후보 중 하나가 형식 오류이면 그룹 표준화 뒤 정상 후보들의 advantage 폭이 19–49%로 줄어듭니다.

RL 이득이 작은 이유와 들어맞는 그림입니다. 다만 실제 형식 오류 비율과 예측 잡음은 공개되지 않아서 가설로 남겨 둡니다.

## 4. "행동 레이블 없는 영상"은 사실 손 자세가 주석된 영상이다

프로젝트 페이지는 학습 데이터 4,276시간 중 "44%가 행동 레이블 없는 사람 영상"이라고 씁니다. 44%는 시간 기준으로 맞습니다. 그러나 논문 Table 4에서 사람 데이터(EgoDex, EgoVerse)의 행동 칸은 "1초 6D/12D 움직임 토큰"입니다. **손목 자세 주석이 CoD의 정답으로 쓰인다**는 뜻입니다. RL 데이터도 같은 원천입니다. 정말로 주석 없이 쓴 사람 영상은 실물 기술 조합 실험뿐인데, 이 결과는 시행 수와 성공률이 없는 정성 사례입니다.

## 5. 시뮬레이션 표는 공개 리더보드와 맞는다


- **LIBERO-PRO:** 기준선 값을 공식 리더보드의 suite별 값과 비교하면 최대 0.05%p 차이로 일치합니다. 평균 1위(55.6 대 π0.5 53.2)는 맞지만, 축별로 보면 Task 1위이고 Object는 6개 방법 중 최하입니다.
- **LIBERO:** 97.25 대 VLA-JEPA 97.2로, 차이가 반올림 하나(0.05%p)입니다.
- **LIBERO-Plus:** Avg는 단순 평균이 아니라 과제 수 가중 평균입니다. 공식 리더보드로 가중치를 추정하면 ThinkWorld의 71.7이 재현됩니다.
- **빠진 기준선이 있습니다.** ThinkWorld는 MolmoAct2의 action expert와 데이터를 쓰는데, LIBERO 비교 대상은 이전 버전 MolmoAct입니다. 공개 체크포인트 MolmoAct2-LIBERO는 표에 없습니다.

## 6. 직접 구현할 수 있나

| 경로 | 판단 | 메모 |
|---|---|---|
| 공식 코드 | 불가 | 코드·가중치 미공개("soon"). 학습 규모는 H100 128장 |
| 노트북(CPU, Apple GPU) | 일부 | 표 재계산과 보상 toy는 완료. 결과 기반 RL의 축소 toy는 numpy로 가능. FAST·DINOv3·LIBERO-PRO 평가는 설치 후 조건부 |
| 아이디어 재구현 | 가능 | Qwen3-VL, MolmoAct2 expert, FAST, DINOv3, LIBERO-PRO/Plus가 모두 공개되어 있음 |

가장 싸고 효과가 큰 재구현 경로는 **기존 VLA에 "1초 뒤 DINO 특징 예측" 보조 손실을 붙이는 것**입니다. 학습 질의를 붙이고 배포 때는 떼므로 추론 지연이 늘지 않습니다. CoD와 RL은 그다음에 더하는 것이 순서로 보입니다.

## 7. 정리

- 실물 성능 차이는 크고 통계적으로 확실하지만, ID 성능부터 다르고 seed가 하나입니다.
- 성능의 대부분은 미래 예측 보조 손실에서 나오고, 제목의 RL 몫은 작습니다.
- "행동 레이블 없는 영상"이라는 핵심 주장은 실제로는 손 자세 주석에 기대고 있습니다.
- 시뮬레이션 표는 공개 리더보드와 맞습니다. 다만 1위 폭이 작고, 가장 가까운 기준선(MolmoAct2-LIBERO)이 빠져 있습니다.
