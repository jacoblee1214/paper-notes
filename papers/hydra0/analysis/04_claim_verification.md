Hydra-0의 모델 코드는 공개되지 않았습니다("Code — coming soon"). 그래서 이번에는 코드 대조 대신 **논문 표, 프로젝트 페이지, 본문 주장**이 서로 맞는지를 검증했습니다. 스크립트는 `analysis/table_check.py`입니다.

## 1. 수치 정합성

| 검증 항목 | 결과 |

## 3. 재현 가능성
- **공개된 것:** 논문, 프로젝트 페이지(영상, 수치표, 미디어 출처 manifest)
- **공개되지 않은 것:** 모델 코드, 가중치, 학습 데이터 전처리 결과, RoboLab 쌍별 성공률
- **재현 비용:** A14B mid-training에 H100 32장으로 5일(40,000 step)이 들었습니다. 개인 단위로는 Wan2.2 TI2V-5B 또는 Cosmos 2B 설정이 현실적인 하한입니다.
- **라이선스:** 논문은 CC BY가 아닙니다(arXiv 비독점 배포, © NVIDIA). 학습 데이터 중 EgoDex는 CC-BY-NC-ND이므로, 공개될 가중치의 라이선스에 영향이 있을 수 있습니다.
