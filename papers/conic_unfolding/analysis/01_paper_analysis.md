## 1. 한 문단 요약

ADMM 기반 원뿔 최적화기 COSMO를 K번 펼쳐 ρ와 α(반복마다)를 작은 MLP(32×32)가 내도록 학습하는 deep unfolding(DU)을 큰 SDP로 확장한 논문입니다. 막히는 곳이 두 군데라고 보고 하나씩 고칩니다. 첫째, 반복마다의 선형계 풀이를 CG로 풀면 역전파가 조밀한 AᵀA 행렬을 만들어 메모리가 O(n²)이므로, 행렬곱만 쓰는 암묵 미분 규칙(식 5–6)으로 O(n + nnz(A))로 줄입니다. 둘째, PSD 투영의 eigh 역전파는 고유값이 겹칠 때 정의되지 않으므로 Daleckii–Krein(DK) 규칙(식 9–10)으로 바꿉니다. 이렇게 7개 문제군(Lyapunov LMI, Max Cut, Lovász ϑ, Robust KF, Robust MPC, 공분산 조종 이중 적분기, 유니사이클)에서 클래스마다 정책과 웜스타트 MLP를 학습하고, 100개 시험 인스턴스에서 절대 허용오차 1e-3에 이르는 반복 수를 비교합니다(표 1). 보고는 최대 약 60배 적은 반복(표 1), 훈련 크기의 10배까지 재학습 없이 전이(표 3), 64개 Lovász ϑ를 GPU에서 한꺼번에 풀면 순차 COSMO.jl보다 14배 빠름(표 2), SCP 안에서 Clarabel보다 성공률과 풀이 시간이 낫다는 것입니다(그림 1, 20 시나리오).

## 2. 문제 설정과 방법

### 2.1 설정 (§2.1–2.2, 식 1–3)

표준형 원뿔 계획 min ½xᵀPx + qᵀx, s.t. Ax + s = b, s ∈ K(식 1)에서 COSMO 한 번 반복은 (3a) 준정부호 KKT 선형계 풀이, (3b)–(3c) 이완, (3d) 원뿔 투영, (3e) 쌍대 갱신입니다. σ = 1e-6으로 고정하고 ρᵏ(행마다)와 αᵏ(스칼라)를 정책 πφ가 내며, K번 펼친 뒤 자기지도 손실(식 13)로 학습합니다.

### 2.2 행렬 없는 암묵 미분 (§2.3, 식 4–6, 그림 2, 부록 B)

COSMO의 간접(indirect) 방식은 ν̃를 소거해 M(ρ)x̃ = ξ, M = P + σI + AᵀD(ρ)A(식 4)를 CG로 풉니다. 손실 L에서 ρ_i에 대한 기울기는 λ̃ᵀ(∂M/∂ρ_i)x̃이고(식 5), Mλ̃ = −∇L의 수반계를 같은 CG로 풀면 ∂M/∂ρ_i = a_i a_iᵀ이므로 ∇ρL = (Aλ̃) ⊙ (Ax̃)(식 6)입니다. ξ(ρ)를 통한 의존은 사용자 정의 층 밖에서 autograd가 처리하고(∇ξL = −λ̃), 합쳐서 "정확한" 기울기가 됩니다. 이 도출은 맞습니다(`analysis/03_analysis.md` V12, 토이 T1 c).

### 2.3 안정한 PSD 투영 (§2.4, 식 7–10, 그림 3·4, 부록 C)

Π(S) = U max(Λ, 0)Uᵀ의 autograd 역전파는 식 8의 F_ij = 1/(λ_j − λ_i)가 고유값이 합쳐지면 발산합니다. 논문은 이것이 공분산 조종의 등방성 목표 S = σ²I 근처에서 "자주" 일어난다고 하고, 투영이 f(x) = max(x, 0)의 주(primary) 행렬 함수라는 점을 써서 Daleckii–Krein 정리로 S̄ = U(L ⊙ (UᵀT̄U))Uᵀ, L_ij = (f(λ_j) − f(λ_i))/(λ_j − λ_i)(같으면 f'(λ_i))를 씁니다(식 9–10). 대안으로 분모 정규화(식 11)와 Newton–Schulz 부호 함수(식 12)를 비교합니다.

### 2.4 정책, 웜스타트, 손실 (§3, 부록 D·E, 식 13)

- **정책:** ρ의 로짓과 α의 로짓에 더해지는 증분을 MLP 둘이 냅니다(ℓ^{k+1} = ℓ^k + Δℓ^k). ρ는 [1e-3, 1e3]로 제한, α = 2σ(ℓ) ∈ (0, 2). ρ-MLP 입력은 (로짓, s_i, y_i, 정규화 r_p,i, log‖r_d‖, δ_p,i, δ_d,i), α-MLP 입력은 (로짓, log‖r_p‖, log‖r_d‖, log‖δ_p‖, log‖δ_d‖)입니다. 마지막 층은 0으로 초기화하고 ρ₀, α₀도 학습합니다. SOC와 PSD 블록은 행별 ρ를 평균내 한 값으로 맞춥니다(rectification).
- **웜스타트:** 변수와 제약 행마다 특징(q_i, P_ii, A의 열 노름과 nnz, b_i, 행 노름과 nnz, 원뿔 종류 one-hot, 전역 문맥 4개)을 받는 64×64 MLP 둘이 (x⁰), (s⁰, y⁰)를 냅니다. 마지막 층은 0 초기화입니다.
- **손실(식 13):** Σ_{k=1..K} log(‖Pxᵏ + q + Aᵀyᵏ‖²/detach(‖Px⁰ + q + Aᵀy⁰‖²) + ‖Axᵏ + sᵏ − b‖²/detach(‖Ax⁰ + s⁰ − b‖²)). 초기 잔차로 나눠 퇴화 해를 막습니다.
- **학습 설정(표 4, 표 5):** Adam, 학습률 1e-3 → 1e-4 코사인, 슈퍼배치 5, 기울기 노름 클립 1.0, 학습 100/검증 20 인스턴스, 클래스별 K와 에폭(Lyapunov 400/30, Max Cut 300/60, Lovász 100/50, KF 100/100, MPC 300/60, DI 150/60, Unicycle 150/60), 정밀도 float64, RTX 4090 한 장, 정책당 10 GPU시간 미만(부록 D). 한 에폭은 5개 슈퍼배치 20번이므로 Adam 갱신은 클래스당 600–2000회입니다(`analysis/03_analysis.md` V9).

### 3.5 그림 1과 부록 H: SCP 안의 학습 COSMO

비선형 유니사이클 공분산 조종 20개 시나리오에서 성공(최대 SCP 잔차 < 1e-3, SCP 반복 20회, 부분문제 풀이당 20 s, 총 400 s)은 학습 16/20, Clarabel 12/20, COSMO 4/20입니다. 둘 다 푼 12개 시나리오에서 학습 COSMO의 중앙값 도달 시간은 27.9 s, Clarabel은 76.7 s이고 12개 모두에서 더 빠르다고 합니다. 부록 H는 실패 양상을 적습니다. 학습 COSMO 실패 4건(시간 한계에 걸린 부분문제, 잔차 정체 0.29와 0.99 등), Clarabel 실패 8건(6–10회 내부 반복 뒤 해 없이 종료 5건, 잔차 정체 3건)이고, Clarabel은 학습 COSMO가 실패한 4개를 모두 함께 실패했습니다. 푼 시나리오에서 2000개 몬테카를로 표본으로 닫힌 루프 공분산 경계를 확인했고, 닫힌 루프 robust MPC 10회 중 9회는 세 solver 모두 수렴합니다.


### 3.6 절제와 그림 5·6 (부록 E)

정책만, 웜스타트만, 둘 다를 COSMO와 잔차 곡선으로 비교한 그림 5의 결론은 "정책이 거의 모든 클래스에서 가장 좋고, 웜스타트는 대체로 개선하되 로봇 MPC에서는 해가 되며, 둘을 함께 학습해도 정책 단독보다 나아지지 않는다"입니다. 그림 6은 학습된 ρ가 제약 종류(등식, 부등식, SOC, PSD)별로 갈라지고 α도 클래스마다 다르다고 보입니다. 두 그림은 수치 표가 없어 다시 계산하지 않았습니다(`03` §5).

### 3.7 핵심 도구 검증 (그림 2, 3, 4)

- **그림 2:** n = 1k–50k 변수(m = n/2, A의 1% 비영, float64, RTX 4090)에서 역전파 피크 메모리와 시간. 직접 방식과 Saravanos 방식은 n ≈ 20–50k에서 24 GB를 넘고, 제안 방식은 50k에서 300 MB 미만입니다.
- **그림 3:** 공분산 조종 SDP(이중 적분기, N = 10)의 실제 ADMM 궤적 100 반복에서 최소 고유값 간격이 10자릿수 넘게 줄고, autograd는 NaN, 분모 정규화는 편향, Newton–Schulz는 간헐 스파이크, DK는 오차 바닥을 유지합니다.
- **그림 4:** n = 40, 군집 고유값(식 14)에서 상대 기울기 오차(왼쪽). 그림 판독 값으로 autograd 약 1e-3, DK 약 2e-5, Newton–Schulz 약 3e-8이고, 분모 정규화는 0.5–1입니다. 오른쪽은 행렬 크기별 시간입니다. 이 값들의 정밀도는 본문과 부록 C에 적혀 있지 않습니다(`03` V13).

## 4. 저자가 한계로 인정한 것 (§4)

PSD 투영의 O(p³) 고유분해는 그대로라 확장성은 블록 수와 제약 수 방향이고 개별 블록 크기 방향이 아닙니다. 정책은 저-중간 정확도(ε ≈ 1e-3)를 겨냥하므로 엄밀한 허용오차에서 Clarabel을 이긴다고 주장하지 않습니다. 문제군마다 정책을 따로 학습합니다(약 100 훈련 문제). SCS 등 다른 ADMM 솔버에 대한 실증과 하드웨어 시험은 하지 않았습니다.

## 5. 주장과 근거의 간격 (요약)

1. **"튜닝된" 상수 기준선의 튜닝 절차가 적혀 있지 않습니다.** 표 1은 "best-tuned"라고 하지만 격자나 목적이 없고, 공식 설정 파일은 모든 클래스에서 기본값(100, 0.1, 0.1, 0.1, α 1.6)만 담습니다(`04` D1). Robust KF의 상수와 적응형이 같은 값(314 [312, 317])이라는 점은 이 열이 초기값에서 움직이지 않은 적응형일 가능성과 맞습니다.
2. **성공이 절반 이하인 열의 중앙값은 성공한 인스턴스만의 값입니다.** Lyapunov 적응형 47/100(중앙값 788)과 DI 적응형 49/100(684)은 실패를 상한 10000으로 세면 중앙값이 10000이어야 합니다(`03` V2). 이 계산 방식은 표 1 캡션에 없고, 공식 벤치마크 도구는 실패를 상한으로 셉니다(`04` D2).
3. **"학습 정책"과 "학습 정책 + 웜스타트".** 표 1 캡션은 정책, 부록 I와 공식 설정은 정책과 웜스타트를 함께 쓰는 학습 COSMO입니다. 그림 5는 정책 단독이 웜스타트 포함보다 대체로 낫거나 같다고 하는데, 표 1에는 정책 단독 열이 없습니다(`04` D4).
4. **SCP 성공률 16/20 대 12/20은 표본이 작습니다.** Fisher p = 0.30, Clarabel이 학습 COSMO의 실패 4건을 모두 함께 실패하므로 짝 검정(정확 McNemar)은 4 대 0에서 p = 0.125입니다. 같은 시간 안에 푼 시나리오 수가 앞서는 것은 그림 1에서 보입니다(`03` V6).
5. **14× 배치 속도비의 기준 시간.** 표 2 B = 64 Lovász COSMO.jl 72.3 s는 같은 논문 표 6의 단일 인스턴스 0.599 s × 64 = 38.3 s의 1.89배입니다. B = 16은 표 6 환산과 1.00배로 맞고, Clarabel은 B = 16, 64 모두 1.01배로 맞습니다. 표 6 환산을 쓰면 B = 64에서 COSMO.jl 대비 약 7.5배입니다(`03` V4).
6. **그림 2의 "n에 선형"과 O(n + nnz(A))는 같은 말이 아닙니다.** 그림 2의 인스턴스(A의 1% 비영, m = n/2)에서 nnz(A) = 0.005n²이므로 nnz 항이 n²로 자랍니다(`03` V8).
7. **절대 허용오차 1e-3은 문제 스케일을 정규화하지 않습니다.** Lyapunov만 Ruiz 평형화 데이터이고 나머지는 원 스케일이라, 같은 ε이 클래스마다 다른 상대 정확도를 뜻합니다(`04` D6).
