# 01. 논문 분석: FACTR 2 (arXiv:2606.12406)

*FACTR 2: Learning External Force Sensing for Commodity Robot Arms Improves Policy Learning*. Steven Oh, Jason Jingzhou Liu, Tony Tao, Philip Han, Kenneth Shaw, Satoshi Funabashi, Ruslan Salakhutdinov, Deepak Pathak (CMU, Waseda). CoRL 2026 구두 발표. 분석 대상은 **arXiv v2**(2026-08-12)이며, 본문 수치는 v1과 같습니다(`README.md` 버전 절).

이 문서는 논문의 주장과 구조를 그대로 정리합니다. 검증은 `03`, 코드 대조는 `04`에 있습니다. 표와 식은 원문 번호로 씁니다.

## 0. 한 문단 요약

접촉이 많은 조작에는 힘 감지가 필요하지만 저가 팔에는 힘 센서가 없습니다. 저자들은 **NEXT**라는 방법을 냅니다. 자유 운동 데이터 10분으로 LSTM을 1분 학습해 "자유 공간에서 필요한 관절 토크"를 예측하고, 측정 토크에서 이 예측을 뺀 잔차를 외부 관절 토크로 씁니다(식 2). 이 외부 토크로 저가 팔에서 힘 피드백 원격조작을 하고, **FIRST**라는 행동 복제 방법으로 접촉 직전과 접촉 구간을 더 자주 뽑아 학습합니다. 다섯 가지 긴 과제에서 힘 인지 기준선보다 과제 진행도가 17% 넘게 높다고 보고합니다.

## 1. 문제 설정과 동기

- 힘 센서는 Franka, Flexiv, KUKA 같은 고가 팔에 주로 있습니다. 말단 힘 센서를 추가하면 팔 값보다 비쌀 수 있다고 씁니다(서론).
- 기존 방법은 전류·토크 기반 잔차를 쓰지만, 마찰·정지 마찰·백래시·이력 현상을 물리 모델로 맞추기 어렵다고 봅니다(§3, 식 1).
- 핵심 주장: 자유 운동 데이터만으로 학습한 시간 이력 모델이 이런 비모델 효과를 흡수하므로, 시스템 식별 없이도 외부 토크를 얻을 수 있습니다(§4).

## 2. 방법

### 2.1 NEXT: 자유 공간 토크 학습 (§4, 식 2–4, 부록 A)

- 식 1: τ_ext = τ_m − τ_f, τ_f = M q̈ + C q̇ + g + τ_other. τ_m은 전류에 토크 상수 K를 곱한 값(§3).
- 식 2: τ̂_f = f_θ(x), τ̂_ext = τ_m − τ̂_f. 입력은 식 3처럼 H 스텝 이력 x_i = [q, q̇, Δq_d] (Δq_d = 명령 위치 − 현재 위치).
- 학습은 접촉이 없는 데이터에서만 합니다. 이때 τ_m이 곧 τ_f이므로 τ_m을 목표로 씁니다(식 4, L2 회귀).
- 모델: 2층 LSTM(은닉 128), 머리 2층 MLP(은닉 256), 드롭아웃 0.1, 무상태 슬라이딩 윈도우(윈도우마다 은닉 상태를 0으로 초기화, 부록 A.1, 표 3).
- 최종 설정: H = 50, 입력 (q, q̇, Δq_d). 부록 A.2 표 4에서 MLP, GRU, LSTM과 H = 10, 25, 50을 비교해 고릅니다.
- 학습 시간: RTX 3090에서 약 1분(§4, 표 3). 추론: 단일 스레드 1.76 ms(i9-10920X, 568 Hz, 부록 A.1). 실행은 100 Hz.
- 데이터: 관절마다 범위를 따라 움직이고, 말단 카테시안 동작, 느린 동작과 빠른 동작을 섞은 10분 자유 운동(부록 A.3, 그림 8).

### 2.2 FIRST: 접촉 단계 기반 재샘플링 (§5, 식 5–7, 부록 D.3–D.5)

- 단계 라벨: 식 6은 접촉 시작 시점 T_onset을 정의하고, 식 7은 접촉 중(C), 접촉 전 F 스텝(PC), 나머지 자유 운동(F)을 나눕니다. "접촉 전 F 스텝"은 **1초**로 설명합니다(§5 본문). F는 제어 주파수로 정하는데 값은 본문에 없습니다.
- 접촉 판정: 점수 f_t = ‖τ̂_ext,t‖_1, 히스테리시스 임계값 T_high와 T_low (값 미공개).
- 샘플링: 단계별 가중치 w_F, w_PC, w_C를 두고 확률 p_t = w(s_t)/Σ w(s_j)로 미니배치를 뽑습니다. 손실은 바꾸지 않습니다(§5).
- 실제 가중치(부록 D.3, 표 8): 대부분 과제 1:5:1, Cap Screwing은 1:3:3. 부록 D.4(그림 12)는 배율 m에 따른 효과를 보여 주며 m = 5 근처가 좋다고 합니다.

### 2.3 원격조작 피드백 (§6.1, 식 8, 부록 A.5)

- 식 8: τ_feedback = K_f,p τ_ext. 두 가지 FACTR 원격조작(Franka 내장 토크 센서, NEXT 추정치)을 비교합니다.
- 사용자 연구: 20명, Franka에서 닦기 과제, 5가지 피드백 조건(없음, DO, PP, FACTR, NEXT). 1–5점 사용 편의 평점과 가한 토크를 잽니다(그림 4). 본문과 그림에 통계 수치는 없습니다.

### 2.4 행동 복제 정책 (§6.2, 부록 B, C)

- 정책: 플로우 매칭 DiT(§6.2, 부록 B, 표 6)와 ACT를 같은 구조에서 씁니다. 이미지는 DINOv3-Base, 고유감각과 힘 입력은 MLP 토큰, 행동 청크 30.
- 기준선: Base Policy, Base Policy + Torque, FACTR(흐림 커리큘럼), TA-VLA(보조 목표). FIRST는 힘 입력을 쓰고 업샘플링합니다.
- 과제 5개(부록 C.1, 표 7): LEGO 조립(LEAP Hand v2), NIST 벨트, NIST 삽입, 공구 정리, 캡 나사 조이기. 과제마다 시연 250개, 카메라 4대(손목 2, 위 2), 평가 롤아웃 20회.
- 평가 지표: 과제 진행도(단계 완료 비율, 부록 C.2). 캡 나사 조이기는 과회전마다 0.02씩 감점합니다.

## 4. 한계 (논문 §9 및 본문)

- **절대 토크 척도**는 토크 상수 K에 달려 있습니다. K가 틀리면 외부 센서로 보정해야 합니다. 저자들은 원격조작(힘 스케일링)과 정책 학습(정규화)에서는 덜 문제라고 봅니다(§9).
- **로봇별 재학습**이 필요합니다(§9). 여러 팔에 같은 모델을 쓸 수 없습니다.
- 논문이 직접 밝힌 한계 외에, 본문에서 확인되지 않는 항목은 `03`과 `04`에 정리했습니다. 주요 항목: 과제 수 5개, 과제당 평가 롤아웃 20회, 시드 수 보고 없음, 기준선 구현 세부(FILIC·DO는 부록 A.4), FIRST 임계값 미공개.

## 5. 주의할 점 (읽기 전)

1. 초록의 "17%"는 정확한 기준선과 계산 방식이 본문에 없습니다. 그림 6, 11의 막대에서 읽을 수밖에 없습니다.
2. 표 1의 "접촉" 열과 표 4의 "접촉" 열은 숫자가 같습니다(0.547 ± 0.348). 표 4는 자유 공간 모델의 검증 오차로 정의되어 있는데, 표 1은 Franka 내장 외부 토크 추정과 비교합니다. 둘 중 어느 정의인지 본문만으로는 가릴 수 없습니다.
3. 표 4의 LSTM H = 50 행이 선택된 설정인데, 같은 보류 데이터에서 고른 뒤 표 1에 같은 수치를 보고합니다. 선택과 평가가 같은 데이터를 씁니다.
4. 배율 m과 과제별 최적 비(표 8)는 평가 롤아웃으로 골랐습니다(부록 D.3). 그래서 표 2의 FIRST 값은 선택 편향을 받을 수 있습니다.
5. 표 2에는 업샘플링을 하지 않은 기준 행이 없습니다. "접촉만 업샘플링은 효과 없다"는 문장(§6.2)을 표 2 안에서 검증할 수 없습니다.
