## 1. 한 문단 요약

정책은 물체의 숨은 물리량(질량 분포, 마찰, 문의 개방 방향)을 모른 채 행동합니다. SCOUT는 정책(점군 FiLM 트랜스포머 + GMM 헤드)과 순방향 동역학 모델 f를 **같은 잠재 신념 q**로 묶습니다. 배포 중에는 정책과 모든 네트워크 가중치를 고정하고, 지금까지의 실패 시도들에서 "예측한 결과 잠재 f(q, a_t, o_t)"와 "관측된 결과 잠재 E(o_{t+1})"의 MSE를 최소화하도록 q만 경사하강으로 갱신합니다(내부 루프). 메타학습(외부 루프)은 이 내부 갱신을 미분 가능하게 펼쳐서 초기값 q0와 전체 가중치를 "한두 번의 갱신으로 행동이 잘 바뀌도록" 학습합니다. 시뮬레이션 5개 ISE 과제에서 평균 시도 수가 기준선보다 적고, 문 벤치마크에서 성공률이 높으며, 실로봇 Pick Bar와 Push Bar에서 시도 수가 줄었다고 보고합니다.

## 2. 문제 설정과 방법

### 2.1 문제 설정 (§2)

- 숨은 잠재 z를 가진 POMDP 족 {M_z}. 상태 전이 s_{t+1} ~ T_z(s_t, a_t), 관측 o_t ~ Ω(s_t)입니다.
- 에이전트는 상호작용 기록 H = {(o_t, a_t, o_{t+1})}에서 z를 암묵적으로든 명시적으로든 추정해야 합니다.
- 행동 a_t ∈ R^3 (ISE 과제: 접촉점, 들어 올릴 정점 등), 문 과제 a_t ∈ R^6 (흡착점 3D + 당기는 방향 3D).

### 2.2 공유 신념 잠재 (§4.1, 부록 A.2–A.3)

| 구성 요소 | 입력 | 출력 | 원문 위치 |
|---|---|---|---|
| 결과 인코더 E | 사후 점군 o_{t+1} (ISE) 또는 점별 흐름 + 사후 점군 (문) | z_target ∈ R^64, LayerNorm으로 끝남 | §4.1, A.3 |
| 동역학 f | q (FiLM), a_t, o_t 점별 트랜스포머 | z_pred ∈ R^64 (평균 풀링 후 사영) | §4.1 |
| 정책 π (GMM) | q (FiLM + 0 초기화 잔차), 쿼리 점군 o_query | 혼합 가중치 w, 평균 μ | §4.1, A.2 |

- 원문은 f가 "사후 원시 관측이 아니라 결과 잠재를 예측한다"는 점을 강조합니다. 이 설계가 내부 루프를 안정적으로 만든다고 주장합니다(§4.1).
- 점군 d_model = 128, L = 4, 헤드 4, 잠재 차원 64처럼 아키텍처 수치는 원문에 있습니다.
- 정책은 점마다 K개 성분을 제안하는 구조로 보입니다(A.2: "each mean consists of a contact point offset relative to the corresponding point cloud location"). 공식 코드가 이를 확인합니다(`04` D10).

### 2.3 내부 루프: 배포 중 신념 갱신 (§4.2)

- 손실: L_inner(q) = (1/T) Σ_t ‖f(q, a_t, o_t) − E(o_{t+1})‖², 원문 식 그대로.
- 갱신: q_{j+1} = q_j − α ∇_q L_inner(q_j), k번. α와 k는 원문 본문에서 고정 값으로 주지 않습니다(§4.2는 "α는 학습률"만 적음).
- 가중치 고정: 정책, E, f는 모두 동결. 바뀌는 것은 q뿐입니다. 원문은 이 점을 "catastrophic forgetting 없음"의 근거로 씁니다(§4.2, §6).

### 2.4 외부 루프: 메타학습 (§4.3, Algorithm 1)

- 외부 손실: 쿼리 행동 a*_query에 대한 GMM의 NLL. 등방 공분산 σ(원문은 값을 적지 않음).
- 역전파: 외부 손실을 가중치 θ와 초기 q0에 대해 내부 루프 갱신을 통과시켜 미분합니다(Algorithm 1, 줄 16). 1차 근사가 아니라 2차 항까지 포함한다고 읽힙니다.
- 샘플: 오프라인 데이터 D_offline에서 (이력 H, 쿼리 상태와 정답 행동) 쌍을 뽑습니다.
- 붕괴 방지: 높은 모호성 과제(ISE)는 외부 손실이 E를 정보 있게 유지한다고 주장합니다. 낮은 모호성 과제(문 일부 개방 상태)는 정책이 쿼리만 보고 이력을 무시하는 지름길이 생겨 E의 기울기가 사라지고, E가 상수로 붕괴할 수 있다고 씁니다. 그래서 흐름 재구성 보조 손실 L_recon을 문 과제에만 넣습니다(A.4, 식 없이 설명).

### 2.5 오프라인 데이터 (§4.4)

- 훈련 이력에 **잘못된 행동**이 반드시 들어가야 한다고 씁니다. 그래서 무작위 행동(시뮬 실패를 흉내 냄)과 특권 정보가 있는 정답 행동을 섞어서 이력을 수집합니다.
- 이 원문은 데이터 생성의 세부(에피소드 수, 시도 횟수 분포)를 본문에 적지 않습니다. 공식 저장소의 `collect_data.py`와 `configs.py`에서 일부를 확인했습니다(`04` §2).

### 3.3 실로봇 (그림 3, 표 5 부록 C.2, §5.1)

- 장비: Franka Emika Panda, Franka 그리퍼, ZED 카메라. 시뮬에서만 학습한 모델을 씀(§5.1, 부록 E).
- 과제: Pick Bar, Push Bar. 무게중심 3위치 (좌, 중, 우)에 각 10회, 두 방법 각각 10회, 최대 10 시도. 총 120 시행.
- 그림 3 값 (95% CI): Pick Bar 비-TTT 3.2±1.9 / 3.6±1.8 / 3.0±1.6, SCOUT 2.0±0.5 / 2.7±2.0 / 1.8±0.7. Push Bar 비-TTT 6.1±3.0 / 6.1±2.5 / 4.6±2.0, SCOUT 2.9±0.8 / 3.7±0.5 / 2.1±2.0.
- 표 5 (풀링, n = 30 대 30): Pick Bar 중앙값 2 대 3, 평균 2.17 대 3.27, p = 0.035 (Holm 0.035), Psup 0.65. Push Bar 중앙값 3 대 4, 평균 2.90 대 5.60, p = 0.003 (Holm 0.005), Psup 0.72.
- Psup 정의: 원문은 "U counts the pairs in which SCOUT needed fewer attempts"라고 쓰지만, 보고된 Psup(0.65, 0.72)은 U/900이 아니라 1 − U/900과 맞습니다(U/900 = 0.35, 0.28). 따라서 보고된 U는 실제로 SCOUT가 **더 많이** 걸린 쌍을 센 값으로 보입니다. 수치 자체는 평균 방향과 맞고, 문장의 정의만 뒤집혀 있습니다(`03` C14).
- 원문은 실로봇 결과가 "significantly fewer attempts"라고 씁니다. 표본이 10회씩이라 효과가 크지 않습니다(Pick Bar Psup 0.65).

### 3.4 분석 (§5.2, 부록 D)

- 잠재 공간 진화 (그림 4): 문 4개 모드에서 q_k의 PCA 궤적이 q0에서 모드별 군집으로 이동. kNN 정확도 29.2% → 70.8% → 95.8%.

- 분포 밖 동역학 (표 3): 구간 1·3·5로 학습하고 구간 2·4에서 평가. Slide Brick 보류 3.36 대 학습 구간 3.14. 단순평균으로 다시 계산하면 3.35 대 3.23입니다(`03` C6).
- 흐름 추정 (표 6): 위와 같습니다.
- 잠재 디코딩 (D.2): MLP 프로브로 q_k에서 무게중심을 R² 0.982 (Pick Bar), 0.965 (Push Bar)로 예측. 5겹 교차검증. 프로브 코드와 데이터는 공개되지 않았습니다.
- 교차 궤적 전이 (표 7): 같은 모드 문 A에서 만든 q를 문 B에 쓰면 NLL 3.59, 자기 궤적 3.62, 적응 없음 6.41. 상위 100 정확도 0.91, 0.89, 0.26.
- 실로봇 프로브 (그림 7): 첫 시도에서 공통 값에서 시작해 실제 무게중심으로 수렴한다고 보고. 선형 프로브.

### 3.5 기준선 구현 (부록 B)

- ISE 기준선 BC, CQL, AVDC, ISE는 원문 ISE 벤치마크(Ko et al.)의 정의를 따릅니다(B.1). 구현 코드는 저장소에 없습니다.
- PEARL 계열(B.2): 맥락 인코더와 PoG 사후, 지도 학습 GMM 헤드로 바꿨다고 적음. 원문은 "PEARL-style baseline rather than a reproduction of the full actor–critic algorithm"이라고 명시합니다.
- Raw GMM(B.3)은 q가 없고 내부 루프와 메타학습이 없음. 학습은 같은 데모로 독립 실행.
- 이력 조건 GMM(B.4)은 이력 인코더로 단일 전방 패스에서 조건 벡터를 만듦. 가장 강한 비교 대상이라는 점이 원문의 주장과 맞습니다.

## 4. 한계 (§7 원문 요약)

- 실험은 물리적 모호성에 한정. 기하 제약, 인식 오류, 기타 불확실성은 평가하지 않았다고 명시.
- 대규모 파운데이션 정책 구조(확산 정책, VLA)와 통합하지 않았다고 명시.
- 원문 논의에 없는 한계: 실로봇 실험이 물체 1종(빈 긴 상자 + 무거운 추의 위치)과 2과제, 10회씩입니다.

## 6. 기호와 표기

- q: 공유 신념 잠재, q0: 메타학습된 초기값, q_k: k번 내부 갱신 후 값.
- f: 동역학 모델, E: 결과 인코더, π: GMM 정책 (w, μ).
- L_inner: 내부 MSE, L_outer 또는 L_meta: 외부 NLL.
- ISE: Implicit State Estimation 벤치마크 (Ko et al., 저자가 인용 [40]).
- Psup: 무작위로 고른 SCOUT 시행이 무작위로 고른 기준선 시행보다 적게 걸릴 확률 (Mann-Whitney U / (n1 n2) 해석).
