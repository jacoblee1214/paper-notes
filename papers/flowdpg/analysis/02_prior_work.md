# 02. 선행연구와 계보

> 참고문헌 번호는 FlowDPG v2의 [n]을 따릅니다. 본문에서 이름만 확인한 외부 논문은 "초록만 확인" 또는 "본문 미확인"으로 적었고, 이 분석에서 새로 원문을 읽은 것은 FlowDPG 하나입니다.

## 1. 계보

```
DPG [45] → DDPG [3] → TD3 (쌍둥이 크리틱) [44]            결정적 정책 경사의 오프폴리시 actor-critic
IQL [43]                                                   행동 분포 안의 기대분위 회귀로 가치 추정
Flow matching [1] / diffusion policy [2] → π0 [14], GR00T [17]   다단계 ODE 행동 머리
        │
        ├─ ODE 전체 역전파:      Diffusion-QL [34]                       BPTT
        ├─ 한 단계 추정으로 대체: EDP [4] (확산 정책, NeurIPS 2023)       ← FlowDPG의 직접 선행
        ├─ 점수 정합:            Q-score matching [32]
        ├─ 수반 정합:            QAM [5, 33] (Li & Levine 2026)          ← 가장 가까운 비교 대상
        ├─ 한 단계 정책으로 증류: FQL [38], QC-FQL [39], SSCQL [40], OFQL [41], DriftQL [42]
        ├─ 노이즈 공간 RL:       DSRL [29]                               고정 기반 + 보조 모듈
        ├─ 잔차 / 보조 머리:     PLD [30], RLT [31]
        ├─ 값 조건화:            RA-BC [26], AWR [27], RECAP [28]
        └─ 온폴리시 우도:        DPPO [35], ReinFlow [36], Flow-GRPO [37]
보상: SARM [26] (단계 인식 진행도 모델)
```

한 줄 위치: FlowDPG는 **EDP의 "한 단계 깨끗한 행동 추정에서 크리틱 기울기를 구한다"를 흐름 정합 정책에 옮기고, 기울기를 정책에 직접 역전파하는 대신 정규화한 L2 증류 목표로 바꾼 것**입니다. 새 이론 도구가 아니라 부품의 조합과 안정화이고, 실로봇 두 과제에서의 규모가 기여입니다.

**제3자 구현에서 얻은 정보(독립 검증이 아니라 참고).** 이 저장소는 식 4–9를 그대로 구현하고(α = 0.5, λ를 2,000 스텝 동안 0 → 0.5, w_c = 1.0) LIBERO-Spatial 과제 0에서 오프라인 FlowDPG 86%(43/50) 대 흐름 정합 BC 74%(37/50), Fisher p = 0.21로 유의하지 않다고 스스로 적었습니다(시드 하나). 그리고 "FlowDPG 논문은 t를 균등하게 뽑지만 LeRobot 기본값은 작은 t에 치우친 베타 분포"라는 구현 선택을 짚었습니다. 이 결과는 FlowDPG의 재현이 아니라 방법이 시뮬레이션 단일 과제에서 작동하는지 보는 약한 신호이며, 저자들이 "식 9의 일관성 항과 목표의 정확한 형태는 내 해석"이라고 명시했습니다.
