# 03. 재계산과 일관성 검사

재현은 하지 않았습니다. 논문에 실린 표 값으로만 계산했습니다. 계산 스크립트는 `recompute.py`, 결과는 `recompute_results.json`(수 초)입니다. 그래프는 `plot_figures.py`가 `report/figures/own_*.png`로 만듭니다.

**중요한 전제:** 표 2, 3, 4에는 SD, 구간, 시드 수, 평가 에피소드 수가 없습니다. 그래서 평균 차이의 검정은 할 수 없습니다. 실제로 계산한 것은 (a) 상대 변화, (b) 소수 셋째 자리 반올림이 만드는 해상도, (c) 시도 수가 있는 이진 결과(시뮬 MPC 10회, 표 5 정확도)의 검정과 구간, (d) 표와 본문과 부록 사이의 일관성입니다.

## 1. 표 4: DROID에서 PointWorld 대비 상대 변화

| 체제 | RMSE (PW → 우리) | 상대 변화 | CD 상대 변화 | Laplacian 또는 Rigidity |
|---|---|---|---|---|
| 강체 비파지 | 0.031 → 0.023 | −25.8% | −14.8% | 0.0003 → 0.0 (반올림 한계, 해석 불가) |
| 변형체 비파지 | 0.028 → 0.014 | **−50.0%** | −16.1% | 0.0041 → 0.0022 (−46.3%) |
| 변형체 파지 | 0.029 → 0.021 | −27.6% | −11.4% | 0.0063 → 0.0051 (−19.0%) |

- 본문 "50%"(프로젝트 페이지의 "−50% RMSE vs PointWorld (DROID, soft pushing)")는 변형체 비파지 RMSE에서 맞습니다.
- 세 칸 모두 우리 값이 낮습니다. 다만 평가 에피소드 수, 물체 점 선택 방법(우리 마스크 대 PointWorld의 장면 흐름), 두 모델의 학습 데이터가 다릅니다. 그래서 차이가 방법 때문인지 조건 때문인지 나눌 수 없습니다. 이 비교는 방향만 지지합니다.

## 2. 시뮬 MPC: 10회 중 5회 대 2회

본문 §4.3은 "10 MPC evaluations in simulation: 50% 대 20%(DINO-WM)"라고 씁니다.

| 항목 | 값 |
|---|---|
| MoRE 5/10 Wilson 95% | [23.7%, 76.3%] |
| DINO-WM 2/10 Wilson 95% | [5.7%, 51.0%] |
| 차이 (Newcombe 95%) | [−10.7 pp, +60.0 pp] |
| Fisher 정확 검정 (양측) | **p = 0.35** |
| 50% 대 20%를 80% 검정력으로 찾는 1군당 n | 약 39 (정규 근사) |

- 구간이 0을 포함합니다. "DINO-WM보다 낫다"는 이 실험으로는 지지되지 않습니다. 결과는 방향과 크기에 대한 큰 불확실성을 보여 줍니다.
- 논문도 "relatively low absolute MPC success rates"라고 씁니다. 절대 성공률이 낮은 것은 설계 문제로 봐야 합니다.

## 3. 표 5: 기체 정확도

부록 A.4는 "범주당 50번 무작위 상호작용"이라고 씁니다. 그러면 정확도는 k/50이어야 합니다(2% 간격).

| 범주 | 보고 값 | 가장 가까운 k/50 | 일치 여부 |
|---|---|---|---|
| Push-X | 95.4% | 48/50 = 96.0% | **불일치** (k = 47.7) |
| Manipulate Toy | 94.9% | 47/50 = 94.0% | **불일치** (k = 47.45) |
| Soft Grasp | 99.8% | 50/50 = 100% | **불일치** (k = 49.9) |
| 전체 | 96.7% | 145/150 = 96.67% | 일치 (또는 세 값의 단순 평균 96.7) |

- 범주 값은 50회 기준으로 정수가 되지 않습니다. 평균이거나 다른 분모(예: 시간 스텝 단위)일 수 있습니다. 논문이 밝히지 않습니다.
- 전체 145/150의 Wilson 95%는 [92.4%, 98.6%]입니다. 범주별 Wilson 구간(최근접 k 기준)은 약 84–100%로 넓습니다.
- **더 큰 문제는 측정 경로입니다.** 공식 코드에서 테스트 시 전문가는 데이터셋의 물성 라벨로 정해집니다(`04` D1). 그러면 "라우팅 정확도"는 정의상 100%에 가깝습니다. 학습된 게이트의 정확도는 공식 코드로 재현할 수 없습니다. 96.7%가 무엇을 재는지 논문이 설명해야 합니다.

## 4. 표 3: 절제

지표 셋(RMSE, CD, Lap/Rig) 중 전체 모델보다 나쁜(>), 같은(=) 지표 수입니다. 전체 모델의 강체 Rig 값은 0이라 상대 비교가 안 됩니다.

| 변형 | 강체 비파지 | 변형체 비파지 | 변형체 파지 |
|---|---|---|---|
| 단일 전문가 | 3 나쁨 | 3 나쁨 | 3 나쁨 |
| 암묵 라우터 | 2 나쁨, 1 같음 | 3 나쁨 | 3 나쁨 |
| 암묵 MoE | 3 나쁨 | 3 나쁨 | 2 나쁨, **1 같음 (CD 0.039 = 0.039)** |
| 자기 롤아웃 제거 | 2 나쁨, 1 같음 | 3 나쁨 | 3 나쁨 |

- 방향은 논문 주장과 맞습니다. 전체 모델이 대부분의 지표에서 가장 좋습니다.
- **그러나 크기를 판단할 수 없습니다.** 지표마다 SD가 없고, RMSE의 반올림 해상도가 전체 모델 값 대비 약 1.9–2.3%입니다. 그래서 2% 안쪽 차이는 반올림과 구별되지 않습니다. 큰 차이(예: 단일 전문가 강체 RMSE 0.030 대 0.022, +36%)는 해상도보다 크지만, 시드 변동은 모릅니다.
- 본문 §4.4의 "consistently underperforms across all regimes"는 암묵 MoE의 변형체 파지 CD 동률 때문에 정확하지 않습니다(표 3 값 그대로).
