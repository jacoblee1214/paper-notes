### 2.1 추가로 확인한 항목

- 시간 샘플링 기본값: `time_sampling_beta_alpha=1.5`, `beta=1.0`, `scale=0.999`, `offset=0.001`. 식 (2)와 일치.
- 학습 설정: LIBERO `num_buffer_slots: 4`, `chunk_size: 10`, `steps: 50000`, `lr: 1e-4`, warm-up 1000. RoboTwin `num_buffer_slots: 4`, `chunk_size: 20`, `n_action_steps: 16`, `steps: 100000`, `lr: 5e-5`, warm-up 5000. 논문 부록 A.1과 일치.
- SmolVLA 설정: `num_buffer_slots: 5`, `chunk_size: 10`. 부록 A.1과 일치.
- LingBot 설정: `num_buffer_slots: 4`, `chunk_size: 20`. 부록 A.1과 일치.
- 코드 기본값(`configuration_pi05.py`): `chunk_size=10`, `num_buffer_slots=5`. 학습 설정 파일은 4입니다. 기본값과 논문 주 설정이 다릅니다. 사소하지만 재현 때 혼동의 원인이 됩니다.
- 정규화 재초기화(부록 A.4): `train.py`는 "train-from-scratch" 변조 투영(`dense`, `gamma`, `beta`, `gate`)을 `random` 또는 `zero`로 재설정합니다. 논문의 "정규화 층 재초기화"는 이 범위로 해석됩니다. 범위가 같은지는 학습 로그 없이 확인할 수 없습니다.
- 비동기 관리자(`async_manager.py`): `overlap_steps`, `skip_stale_actions`, 콜드 스타트 대기 행동(`hold-pose` 패딩)이 있습니다. 논문의 2스텝 지연 설정과 맞는 인자입니다(부록 A.2).
- README 표(LIBERO, RoboTwin, 교차 아키텍처, 지연)와 논문 Tab. 1, 3, 5, Tab. 2의 수치는 모두 같습니다.
