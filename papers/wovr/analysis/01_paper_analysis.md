## 1. 한 문단 요약

학습된 행동조건부 영상 세계모델을 시뮬레이터로 써서 VLA 정책(OpenVLA-OFT, π0.5)을 GRPO로 학습하는 WoVR를 제안합니다. 세계모델은 Wan2.2-TI2V-5B를 행동조건부로 고친 것입니다. 세 가지 장치로 "상상 속 성공(가짜 성공)"을 줄이려 합니다. 첫째, 행동을 두 경로로 넣고 첫 프레임을 고정 앵커로 쓰는 안정화된 세계모델(§2.2). 둘째, 임계 상태 근처에서 시작하는 Keyframe-Initialized Rollouts(KIR, §2.4). 셋째, 정책이 바뀔 때 세계모델을 낮은 빈도로 다시 학습하는 PACE(§2.6). 실험은 LIBERO 네 스위트 (one-trajectory SFT 평균 40.5 → 69.5, full-trajectory SFT 88.1 → 96.0)와 실로봇 두 플랫폼(Franka 3과제, AgileX 3과제, 30회씩)입니다.

## 2. 문제 설정과 방법

### 2.1 문제 설정 (§1, §3)

- 자기회귀 롤아웃에서 예측 오차가 두 가지 이유로 쌓인다고 봅니다: (i) 모델이 자기 생성 프레임을 조건으로 쓰는 자기회귀 피드백, (ii) 정책이 바뀌면서 행동 분포가 세계모델 학습 분포에서 멀어지는 분포 이동 (§1).
- 목표: "세계모델이 실제와 완벽히 같다"고 가정하지 않고, 상상된 상호작용을 **어떻게 쓸지**를 바꿔 신뢰할 수 있는 RL을 만드는 것 (§1, "reliability problem").

### 2.2 행동조건부 세계모델 (§3.1, 식 2–5, 부록 B.1, 그림 3)

- 백본: Wan2.2-TI2V-5B. 행동은 두 경로로 들어갑니다. (a) 시간 조건 정규화의 scale과 shift로 denoising 특징 변조, (b) 교차어텐션에서 텍스트 임베딩을 행동 임베딩으로 대체 (§3.1).
- 컨텍스트: 매 자기회귀 단계에서 [o_0, o_{t-c:t}] (첫 프레임 앵커 + 최근 메모리 프레임). 첫 프레임은 깨끗하게 유지 (§3.1, 부록 B.1).
- 학습: Rectified Flow 목표, 식 (2)–(4). 메모리 컨텍스트에 노이즈 증강을 식 (5)처럼 섞습니다. τ_ctx는 1에 가까운 값이고, 첫 프레임 앵커는 제외 (부록 B.1).
- 추론: 5 denoising 스텝, 청크 8, 조건 프레임 5, 해상도 256×256 (코드 설정과 일치, `04` D10).
- 보상: 두 가지 선택. 가벼운 ResNet 이진 분류(식 6–7, 주 실험에 사용)와 Qwen3-VL 2B 기반 11단계 서수 진행도 보상(식 8–10). 밀집 보상은 초기 학습을 빠르게 하지만 약 3배 느리고 최종 성능은 비슷합니다 (부록 D.3).

### 2.3 정책 최적화 (§3.2, 식 1)

GRPO 목적 식 (1)을 씁니다. 상상 궤적 G개의 그룹 상대 이득을 쓰고, 성공 이후 스텝은 마스크로 뺍니다(T_valid는 첫 성공까지의 유효 스텝 수). 저자들은 길이 정규화가 짧은 키프레임 롤아웃의 기여를 키운다고 주장합니다(§3.2). G 값은 본문에 없습니다(공식 설정은 8, `04` D10).

### 2.4 Keyframe-Initialized Rollouts (§3.2, 그림 4, 부록 B.3, 식 11–15)

- 롤아웃 일부를 초기 상태 대신, 정책이 실패하기 쉬운 임계 상태 근처의 키프레임 o_{T_KIR}에서 시작합니다. 컨텍스트는 [o_0, o_{T_KIR-3..T_KIR}] (식 14).
- 작업마다 고정된 T_KIR을 씁니다. 근거는 "기본 정책이 임계 실패 영역에 접근하는 시점"이며, 키프레임을 하나씩 고르지 않습니다(부록 B.3).
- 효과 주장: 유효 예측 깊이를 줄여 가짜 성공(오차 누적으로 생긴 성공)을 막습니다. KIR를 빼면 두 스위트 평균 82.5 → 79.7 (표 6).
- **비율은 본문에 없습니다.** "a portion of rollouts"라고만 적혀 있습니다.

### 2.5 PACE: 정책-세계모델 공진화 (§3.3, 그림 8)

1. WM_Base를 기본 정책의 궤적 1,500개로 학습합니다.
2. WM_Base 안에서 1차 정책 최적화를 합니다.
3. 진화된 정책으로 궤적 1,000개를 더 모아 WM_Evo로 다시 학습합니다.

재학습 빈도는 아주 낮습니다(온라인 모델 기반 RL과 구별). 그림 8은 PACE 이후 상상 학습 곡선이 실제 평가 곡선과 가까워지는 현상을 보여 줍니다(정성적). **실로봇 실험에서는 PACE를 쓰지 않았습니다.** 여러 SFT 체크포인트의 롤아웃으로 세계모델을 학습했습니다(부록 F.4). 본문의 방법 설명과 실로봇 설정이 다릅니다.

### 2.6 실로봇 설정 (부록 F.1–F.3, 표 7)

- 행동 공간: 델타 EEF 10차원 (Δx, Δy, Δz, Δ6D 회전, 그리퍼). 6D 회전은 식 (21)–(26)으로 복원합니다. Piper는 누적 목표 자세 방식, Franka는 증분 방식을 씁니다 (상태 추정 잡음 차이).
- 데이터: Franka 과제당 SFT 시연 25개, 세계모델 롤아웃 120개. Piper는 과제별 시연 50–75개, 롤아웃 180–210개 (표 7(a)).
- 평가: 과제당 30회, 단일 실행.

## 3. 실험 결과

### 3.1 세계모델 품질 (표 1, §4.1)

LIBERO 환경 롤아웃, 3,000 궤적으로 학습, 200 held-out. WoVR는 LPIPS, FID, FVD, FloLPIPS에서 세 가지 horizon(512, 256, 128) 모두 최선입니다(재계산 `03` §1.6). 실제 FPS는 23(WoVR), OpenSora 7.0, Cosmos 3.5, EVAC 1.35 (표 1, v3 기준). 측정 하드웨어는 적혀 있지 않습니다.

### 3.4 절제 (표 5, 6, 그림 8, 9)

- 세계모델 (표 5, LIBERO-Spatial, held-out 24 궤적): 참조 프레임 제거, 메모리 1프레임, 노이즈 증강 제거 모두 512 horizon에서 FVD와 FloLPIPS가 나빠짐.
- RL 절제 (표 6, 한 궤적 SFT, Spatial/Object 평균):
  - OFT 기본 50.0
  - PACE 없이 기본 1,500 궤적 75.8
  - PACE 없이 기본 2,500 궤적 77.5
  - KIR 없이 79.7
  - 전체 82.5
- 보상 (그림 9): 밀집 보상은 초기 속도만 빠르고 최종 수렴은 같음.

### 3.5 저자가 인정한 한계 (§6)

형식적 분석이 없음 (후회 상계 없음), 긴 horizon과 이동 조작은 미검증, 실험이 경험적.
