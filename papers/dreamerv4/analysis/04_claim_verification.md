## 2. 세부 검토

### C1 다이아몬드 최초
- 주장은 "오프라인 데이터만으로 다이아몬드"입니다. 7/1000이 맞다면 0이 아닙니다.
- 0.7%의 Wilson 95% 구간은 0.34–1.44%입니다. 1000 에피소드 중 7회라 평가 편차가 큽니다.
- 한계: 시드 반복이 없어, 학습 실행 간 분산은 알 수 없습니다.

### C2 100배
- Table 3은 VPT가 2.5K 시간 계약자 데이터와 270K 시간 웹 데이터를 쓴다고 씁니다. 272.5K/2.5K = 109이므로 숫자는 맞습니다.
- 그러나 VPT 웹 데이터는 IDM으로 주석을 붙인 영상이고, Dreamer 4는 웹 영상을 전혀 쓰지 않습니다. "데이터 효율"이라는 말은 맞지만 "100배 적은 데이터로 같은 것을 배운다"는 아닙니다. 실제 비교는 다이아몬드 성공률 0.7% 대 VPT(finetuned) 0%입니다.

### C3 VLA 대비
- 29.0 / 11.2 = 2.59배. "거의 3배"는 과장입니다. 2.6배라고 쓰는 것이 정확합니다.

### C8, C9 행동 일반화
- 단일 실행, 행동 라벨은 "처음 순서대로" 고른 부분집합입니다(§4.3). 무작위 선택과 다르므로 일반적인 데이터 양 주장으로 확장하기 어렵습니다.
- 본문 85%와 캡션 "80% 이상"은 같은 값의 두 표현입니다.

### C10, C11 FVD
- Table 2는 "+X-Prediction" 326, "+X-Loss" 151을 보여 x-space 손실의 효과를 보여 줍니다. 그러나 본문이 말하는 "v-space 완성 구조 124"는 표에 없습니다. 어떤 실험이 124인지 본문만으로는 알 수 없습니다. **이 한 값이 본문과 표의 유일한 불일치입니다.**

### C13 Fig. 8
- 그림 판독은 하지 않았습니다(벡터 데이터 없음, 판독 오차). 본문 설명과 Table 2의 샘플링 스텝 4 FVD 대비만 확인 가능합니다.

### C15 속도
- Table 8의 평균 시간은 성공한 에피소드만 씁니다. 모든 항목에서 Dreamer 4가 빠르지만, 이는 성공 집단이 같은 항목에서 비교되어야 의미가 있습니다.

### C18 평가 방식
- §4.2: "a human player tries to accomplish tasks". 평가자 수, 판정 기준, 반복, 과제 선택 기준이 본문과 부록에 없습니다. 14/16의 결과를 재현하려면 이 정보가 필요합니다.

## 4. 구현 가능성 (맥 기준)

기기: Apple M4 Pro, 약 24 GiB 통합 메모리, MPS, CUDA 없음.

- **이 맥에서 논문 수치 재현은 불가능합니다.** 2B 모델의 학습 상태(가중치 외 옵티마이저 상태 포함)는 24 GiB를 넘고, 공식 체크포인트와 학습 설정도 없습니다. 2541 시간 Minecraft 영상의 다운로드와 전처리도 큰 부담입니다.
- **CPU 또는 MPS로 가능한 것**: 식 (7)의 shortcut 손실, 식 (11)의 PMPO 손실을 토이 데이터에서 구현해 방향을 확인하는 일. 효율 구조의 추론 시간을 랜덤 가중치로 재는 일. 표 수치 재계산(`03`, 완료).
- **조건부**: 64×64 Minecraft 축소판 world model. MPS에서 수 시간에서 하루 정도로 추정하지만 측정하지 않았습니다. 데이터 다운로드 크기를 확인한 뒤 승인받아야 합니다.
- **불가**: 2B 규모 학습, Table 7 재현, 행동 라벨 곡선, FVD 재계산, 로봇 SOAR 재현.
- **노력(추정)**: 토이 구현은 반나절에서 이틀. 축소판 world model은 1–2주. 논문 규모 재현은 이 맥에서 현실적이지 않습니다.
