# 04. 주장 검증 (공식 코드 없음)

공식 코드를 찾지 못했습니다(`02_prior_work.md` §2). 그래서 코드 대조(D1–Dn) 대신 **주장 검증(C1–Cn)** 을 합니다. 원문 표와 본문 수치의 재계산과 내부 일치는 `03_analysis.md`에 있습니다. 이 문서는 주장마다 근거 수준과 재현 가능성을 판정합니다.

## 1. 확인한 사실

| 항목 | 확인 결과 | 날짜 |
|---|---|---|
| arXiv 라이선스 | abs 페이지 "view license" → `arxiv.org/licenses/nonexclusive-distrib/1.0/`. **CC BY 4.0이 아닙니다.** | 2026-11-21 |
| 원문 PDF 저작권 표시 | 본문 1–2쪽과 전체 텍스트에서 ©, "All rights reserved", 회사 고지, 상표 표시를 찾지 못했습니다. 저자 소속(Sharpa Robotics 등)만 있습니다 | `pdftotext`, 28쪽 |
| 학회 | 학회 표기 없음. CoRL 2026 채택 목록(`conferences/corl2026/papers.json`)에 없음 | 2026-11-21 |
| 공식 코드, 가중치, 데이터 | 없음 | `02` §2 |
| 시연 영상 | 프로젝트 페이지에 있음(실로봇, 시뮬) | 프로젝트 페이지 |

**공개 범위 판정.** 라이선스가 CC BY가 아니므로 **논문 그림은 공개 산출물에 넣지 않습니다.** 공개본은 우리가 그린 그래프 두 장(재계산 결과)과 글만 씁니다. 원문 PDF는 저장소에 있지만 게시본 패키지에는 넣지 않습니다.

**주요 간격 요약.**
- 실험 대부분이 **단일 사전학습 실행과 단일 파인튜닝 실행**입니다. 원문은 실행 간 변동을 보고하지 않습니다(C2, C7, C8의 불확실성을 과소평가할 수 있습니다).
- H2R 결과는 **기준선이 없습니다**(C3).
- 관절 스트림 H2R 실패(C4)는 강한 주장인데 원인 검증이 없습니다.

## 3. 구현 가능성 판정 (구현할 수 있는지)

**결론: 논문 전체는 이 맥에서 재현할 수 없습니다. 방법의 핵심 아이디어(토큰 보조 목표와 두 스트림 전문가)를 작은 규모로 옮기는 것은 조건부로 가능합니다.**

### 3.2 가능한 축소 실험 (계획만, 실행 안 함)

1. **토큰 보조 목표 대 연속 헤드 (토이).** 2-스트림 전문가와 소형 시퀀스 모델(예: 수백만 파라미터)을 두고, 같은 구조에서 (a) FAST 식 토큰 보조 목표, (b) 그래디언트 크기를 맞춘 연속 L1 헤드, (c) 없음을 비교합니다. 합성 데이터(두 손 로봇의 간단한 운동학 모델과 사람 손 궤적 근사)로 "사람 데이터가 관절 스트림을 돕는가"만 봅니다. 논문 수치와 직접 비교는 안 됩니다.
2. **FAST 토크나이저 단독.** 청크를 토큰으로 바꾸는 단계와 복원 오차만 확인합니다. 구현 설치 전에 어떤 패키지를 쓸지 사용자에게 먼저 보여야 합니다(프로젝트 규칙).
3. **H2R 기준선 측정 (불가 판정 유지).** 사람 데이터로 π0.5를 미세조정하는 실험은 4B 학습이므로 불가입니다.

### 3.3 노력 추정 (측정 전, 추정)

- 축소 토이 1: 2–4일 (구현 1–2일, 실행 수 분).
- 공개 손 추적 데이터셋 기반 소형 실험: 2–3주 (데이터 준비와 리타게팅 포함).
- 논문 전체 재현: 해당 없음.

## 4. 정리: 원문 자원 없이 할 수 있는 검증 범위

- 논문의 실험 질문은 실로봇과 대규모 사람 데이터에서 나옵니다. 재계산과 내부 일치만으로도 논문이 제시한 **표 수치는 대체로 맞습니다.**
- 남은 질문(토큰의 메커니즘, 관절 H2R 실패 원인, 사전학습 실행 간 변동)은 원문 자원 없이 검증할 수 없습니다.
