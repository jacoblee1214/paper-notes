# 03. 수치 재계산, 일관성 검사, 주장 판정

재계산 스크립트는 `analysis/recompute.py`이고 결과는 `analysis/recompute_results.json`입니다(수 초, 인터넷 불필요). 그래프는 `analysis/plot_figures.py`로 `report/figures/own_*.png` 세 장을 만듭니다. 재현 실험은 하지 않았습니다. 이 절은 논문이 보고한 개수와 평균을 다시 계산하는 것이 전부입니다.

## 0. 요약

- **시행 수는 20회(표 I, III, IV)와 10회(표 II)가 맞습니다.** 보고된 ASR이 모두 5%(20회)나 10%(10회)의 배수이고, 닦기 점수는 0.025(반점 한 개) 격자에 있습니다.
- **점수 기준으로 FoAR가 ACT, FoAR (3D-cls), 닦기의 Diffusion Policy보다 높은 것은 Holm 보정 후에도 유의합니다.** RISE 계열 세 기준선 대비 점수 우위는 세 과제 모두 Holm 보정 후 유의하지 않습니다(최소 p_Holm = 0.064).
- **썰기의 조각 수 차이(3.9 대 1.8)는 보고된 SD를 믿으면 p < 0.001입니다.** 다만 n = 10이고 SD가 SD인지 SE인지 논문이 밝히지 않았습니다.
- **본문 주장 두 개가 표와 맞지 않습니다.** "RISE (force-token)은 복합 외란에서 성능이 떨어진다"(표 IV와 반대)와 "접촉 검출 변형"(표 III에 없음)입니다.
- **표 V(껍질, MLP 인코더)의 FoAR 값(0.588)이 표 I의 같은 방법·과제 값(0.756)과 다릅니다.** v1과 v2 모두 그렇습니다.

## 1. 재계산과 검정

검정 방법은 세 가지입니다. ASR은 Wilson 95% 구간과 Fisher 정확 검정입니다. 점수는 개별 시행이 공개되지 않아 Welch 검정을 쓰되, 분산을 Bhatia–Davis 상한(μ(1−μ), 0–1 변수)으로 잡았습니다. 이 상한은 실제 분산보다 크므로 p는 보수적입니다. 표 II는 보고된 SD로 Welch 검정을 했습니다. 다중 비교는 Holm으로 보정했습니다.

ASR은 "행동 성공"이고 Peeling 열은 껍질 벗기기 성공(peel)입니다. 그립 성공은 FoAR와 RISE 계열(세 변형 포함)에서 85–100%입니다. FoAR 대 RISE의 그립 Fisher p는 1.0, 0.49, 1.0입니다. FoAR (3D-cls)의 닦기 그립 8/20은 예외로 FoAR와 p < 0.001입니다.

요약하면, Holm 보정 뒤에도 유의한 것은 ACT, FoAR (3D-cls), Diffusion Policy(닦기 두 과제)뿐입니다. RISE, RISE (force-token), RISE (force-concat)에 대한 점수 우위는 세 과제 모두 0.05에서 유의하지 않습니다.

ASR(과제 성공)의 보정 전 Fisher 검정은 다음과 같습니다. 닦기 FoAR 20/20 대 RISE 15/20은 p = 0.047입니다(대 RISE (force-token) 16/20은 p = 0.106). 껍질 FoAR 20/20 대 RISE 10/20은 p = 0.0004입니다(대 RISE (force-concat) 16/20은 p = 0.106). 방법 여섯 개와 과제 세 개를 같이 보면 보정이 필요합니다.

Peeling 점수는 시연 평균 0.778로 나눈 정규화 비율이라서 1을 넘을 수 있습니다. 따라서 Bhatia–Davis 상한은 근사입니다. 방향은 바뀌지 않을 가능성이 크지만 정확한 p는 아닙니다.

### 1.3 표 II: 썰기 (10회)

| 지표 | FoAR | RISE | 검정 |
|---|---|---|---|
| 조각 수 (평균 ± SD) | 3.9 ± 0.9 | 1.8 ± 0.6 | Welch (SD 가정), 차이 2.1, t = 6.14, p = 1.6 × 10⁻⁵ |
| 정규화 길이 평균 | 0.353 | 0.727 | 차이 −0.374, t = −2.81, p = 0.019 |
| 정규화 길이 SD | 0.094 | 0.411 | (표 II 값, 검정 생략) |
| 배치 성공 | 7/10 (39.7–89.2) | 3/10 (10.8–60.3) | Fisher p = 0.18 |
| 그립 성공 | 10/10 | 10/10 | - |

비율 계산: 3.9 / 1.8 = 2.17 (본문 "over double"과 일치). 0.353 / 0.727 = 0.486.

오라클(시연)은 5.0개, 평균 길이 0.200, SD 0.056입니다. FoAR은 조각 수와 길이 평균 모두 오라클에 가깝지만 SD는 0.094로 오라클보다 큽니다.

### 1.4 표 III: 설계 선택 (닦기, 20회)

| 설정 | 점수 | 배치 (wipe) | 완전 모델 대비 차이 | p (Welch) | p (Fisher, wipe) |
|---|---|---|---|---|---|
| 100 Hz, 반응 제어만 | 0.650 | 17/20 | −0.225 | 0.100 | 0.231 |
| 100 Hz, 예측기만 | 0.650 | 16/20 | −0.225 | 0.100 | 0.106 |
| 2 Hz, 예측기 + 반응 | 0.625 | 17/20 | −0.250 | 0.072 | 0.231 |
| 10 Hz, 예측기 + 반응 | 0.800 | 20/20 | −0.075 | 0.533 | 1.000 |
| 100 Hz, 예측기 + 반응 (FoAR) | 0.875 | 20/20 | - | - | - |

- 표 III의 완전 모델 0.875는 표 I의 닦기 FoAR과 같습니다(K2).
- 반응 제어를 빼면 점수가 0.225 떨어지지만, p = 0.10으로 0.05에서 유의하지 않습니다.
- 100 Hz 대 2 Hz 차이(0.250)도 p = 0.07입니다. 10 Hz와 100 Hz의 차이는 0.075로 작습니다.
- **"무 설정" 행(예측기도 반응도 없는 행)이 없습니다.** 두 요소의 결합 효과(상호작용)는 이 표로 판단할 수 없습니다.

### 1.5 표 IV: 외란 (Wiping (General), 시행 수 미기재, 20회 추정)

| 방법 | 원래 | 재작성 | 이동 | 재작성 + 이동 |
|---|---|---|---|---|
| RISE | 0.500 (18, 16) | 0.500 (18, 14) | 0.600 (20, 20) | 0.500 (20, 14) |
| RISE (force-token) | 0.600 (18, 16) | 0.450 (16, 18) | 0.500 (18, 16) | 0.600 (20, 20) |
| FoAR | 0.850 (20, 20) | 0.800 (20, 20) | 0.850 (20, 20) | 0.800 (20, 20) |

괄호는 (그립, 배치) 성공 수입니다. 그림은 `report/figures/own_robust_ci.png`입니다.

- FoAR은 네 조건에서 점수 0.80–0.85, 성공률 100%입니다. 원래 조건과의 차이는 없습니다.
- RISE의 이동 조건 점수(0.600)는 원래 조건(0.500)보다 높습니다. p = 0.54로 차이가 없습니다.
- RISE (force-token)의 재작성 + 이동 점수는 0.600으로 원래와 같고, 성공률은 100/100으로 원래(90/80)보다 높습니다. 본문 주장과 반대입니다(K6).
- 재작성 + 이동에서 FoAR 대 RISE: 점수 0.800 대 0.500, p = 0.049. 배치 20/20 대 14/20, Fisher p = 0.020. 같은 조건에서 RISE (force-token)의 배치 20/20 대 RISE의 14/20도 p = 0.020입니다.
- 시행 수가 적혀 있지 않습니다. ASR 값이 모두 5%의 배수이므로 20회 가정이 가능하지만 확인은 아닙니다.

### 1.6 검출력

Wilson, Welch, Fisher 검정의 힘을 80%로 두고 계산한 최소 검출 차이(MDE)는 다음과 같습니다.

| 조건 | MDE |
|---|---|
| 점수, n = 20 per arm, SD 0.33 | 0.29 |
| 점수, n = 20 per arm, SD 0.40 | 0.35 |
| 점수, n = 10 per arm, SD 0.40 (썰기 규모) | 0.50 |
| ASR, n = 20, p = 0.5 | 0.44 |
| ASR, n = 20, p = 0.9 | 0.27 |

즉 20회 시행으로는 점수 차이 0.3 이하, 성공률 차이 0.27 이하를 80% 검출력으로 구분할 수 없습니다. 표 III의 차이(0.075–0.25)는 모두 이 MDE보다 작거나 비슷하므로 "효과가 없다"는 결론도 "효과가 있다"는 결론도 내리기 어렵습니다.

## 4. 한계와 가정

- 점수의 개별 시행 값이 없습니다. 모든 점수 검정은 평균, 개수, 상한 분산에 기댑니다.
- 표 II의 ±가 SD인지 SE인지 논문이 밝히지 않았습니다. SE라면 SD는 √10배 크고 썰기 차이는 덜 강하지만 여전히 유의할 가능성이 큽니다. 계산은 SD 가정입니다.
- 시행 집합이 원정 연구와 다른 로봇, 날, 물체 배치인지 논문은 밝히지 않았습니다. 같은 날 같은 설정이라면 p 값은 과대할 수 있습니다.
- 재현은 하지 않았으므로 표 값이 실제로 맞는지는 확인하지 못했습니다. 확인한 것은 논문 내부의 수치 일관성과 주장의 지지 정도입니다.
