# 03. 수치 재계산, 일관성 검사, 작은 계산 실험

재계산은 `analysis/recompute.py`(결과 `recompute_results.json`, 약 10초)와 `analysis/digitize_attention.py`(결과 `digitize_attention_results.json`)로 합니다. 점검 항목은 V1–V8(재계산과 일관성), K1–K4(내부 일관성과 작은 계산 실험)입니다. 논문 주장의 판정(C1–C16)은 `04`에 있습니다. 공식 코드가 없어서 코드 대조는 하지 않았고, 학습이나 실행은 하지 않았습니다. 쪽·표·그림 번호는 arXiv v2 기준입니다.

## 0. 가정과 읽는 방법

- **시행 수.** 모델·과제당 20회(§4.2)이고, 두 데이터셋을 합친 칸은 40회입니다. 퍼센트는 모두 5의 배수여서 k/20으로 정수 횟수가 됩니다(V1). 합친 칸의 퍼센트(예: 82.5)는 그림 4에서 반올림되어 표시됩니다(V2).
- **두 데이터셋.** 데이터셋 1은 표 9(= v1 표 7), 데이터셋 2는 표 10입니다. 표 1은 표 10의 일부, 표 2와 표 3은 표 9의 일부입니다(V1). 표 8이 성공 수를 직접 줍니다.
- **통계.** 성공률은 Fisher 정확 검정(양측)과 Wilson 구간, 층화 비교는 Mantel-Haenszel(CMH), 정책 단위 비교는 (과제, 데이터셋) 10칸의 쌍 검정입니다. 시행 단위 Fisher는 시행이 서로 독립이라고 가정합니다. 이 가정은 같은 학습 결과로 20회를 돌린 한 칸 안에서 가장 의심스럽고, V7과 K4가 이 가정을 흔들 때 결론이 어떻게 되는지 봅니다.
- **그림에서 읽은 값.** 부록 그림 9의 어텐션은 래스터 곡선을 색으로 분리해 읽은 값(K1의 판독 오차 약 ±0.01–0.02)입니다. 논문 값이 아닙니다.
- **p 값은 다중 비교 보정 전**입니다. 표에서 5개 과제를 각각 검정할 때 Holm 보정을 하면 달라지는 곳은 본문에 적었습니다.

### V7. 두 데이터셋 사이의 같은 모델·과제 차이

두 데이터셋에서 모두 평가된 5개 모델(ViT-CNN, ViT, Sparsh-X V+G+E, MiTaS V+G+E, MiTaS V+G MTD) × 5과제 = **25칸**에서 같은 모델·과제의 20회 결과를 Fisher 검정으로 비교했습니다. 그림: `own_dataset_gap.png`.

- **p < 0.05인 칸은 5개**입니다(우연만으로 기대되는 수는 1.25). 5개 중 **4개가 Key in Lock**(ViT-CNN 0 대 7, ViT 0 대 9, Sparsh-X 2 대 12, MiTaS MTD V+G 4 대 13)이고 하나는 Lightbulb의 ViT-CNN(0 대 6)입니다. MiTaS V+G+E는 Key에서 15 대 15로 같습니다.
- 모델 행 평균(데이터셋 1 → 2): ViT-CNN 26 → 43, ViT 31 → 40, Sparsh-X 54 → 57, MiTaS V+G MTD 53 → 60, MiTaS V+G+E 80 → 80.
- 두 데이터셋의 칸별 차이의 분산을 이항 분산(칸당 (2 · p̂ (1 − p̂) / 20))과 비교하면, 초과분이 있고 이를 "서로 독립인 두 학습 실행 각각의 칸 성공 확률 SD"로 환산하면 **약 9.4%p**입니다(관측 SD 19.3%p, 이항만이면 14.0%p). 이 값은 학습 실행의 우연과 데이터셋의 체계적 차이를 구분하지 못합니다(분산 분해가 아니라 상한 감각용).
- 이 결과는 v1에서 "시각 전용은 Key와 Lightbulb에서 0%"였던 문장이 v2에서 "not able to consistently solve"로 바뀐 이유와 맞습니다. 데이터셋 2에서는 시각 전용이 Key 35–45%, Lightbulb 20–30%입니다.

### V8. 표 5 (파라미터, 토큰, 지연)

- **총합.** 9개 행 모두 "인코더 파라미터 + 머리 13,701,508 = 총합"이 맞습니다(예: MiTaS V+G+E 10,764,824 + 13,701,508 = 24,466,332).
- **가산성.** MiTaS 인코더는 시각 3,079,232(ViT-CNN) + GelSight 스템 1,995,544(V+G − V) + Evetac 스템 5,690,048(V+E − V) = 10,764,824로 V+G+E와 **정확히 같습니다**. 융합 트랜스포머의 파라미터가 센서 수에 의존하지 않고 센서별 스템이 합쳐진다는 구조 서술과 맞습니다. Evetac 3D 스템은 GelSight 2D 스템의 2.85배입니다.
- **MTD 모델 파라미터.** MTD V+G의 "인코더 10,764,824"는 V+G+E와 같으므로 표는 학습 때의 크기(Evetac 스템 포함)입니다. 배포 때 Evetac 인코더를 뺀다는 §3.3과 같이 읽으면 배포 모델은 5.07 M(MiTaS V+G)과 같을 것입니다(추측이 아니라 표의 계산값).
- **Hz 열.** 보고된 Hz는 1000 / ms와 맞지 않습니다. 35.5 ms는 28.2 Hz인데 표는 227.4 Hz입니다. **Hz × ms / 1000이 7.85–8.38 사이**(행마다 7.85, 7.91, 7.96, 7.98, 7.99, 8.07, 8.11, 8.31, 8.38)로, 보고된 Hz는 1 / ms의 약 8배입니다. 부록은 "100회 평균 실행 시간, 플로 매칭 10스텝"만 적어 Hz가 무엇의 속도인지(예: 한 번에 여러 개를 처리한 처리량) 알 수 없습니다. 저자 확인이 필요합니다. 제어 주기가 15 Hz(§5)이므로 어느 쪽이든 지연이 병목은 아닙니다.
- **추론 시간 차이.** V+G → V+G+E의 증가는 MiTaS +8.2 ms(35.3 → 43.5), Sparsh-X +15.4 ms(39.2 → 54.6)입니다.

## 2. 내부 일관성과 작은 계산

### K1. 토큰 수 640 대 644, 그리고 어텐션 판독

- 센서 토큰은 256 + 192 + 192 = **640**인데, 본문(§3.1)과 표 5는 N_cond = **644**, Tok/obs 644(MiTaS V+G+E), 452(V+G, V+E), 260(ViT, ViT-CNN)입니다. 640, 448, 256과의 차이는 모두 **정확히 4**입니다. Sparsh-X 행(448, 640)에는 이 4가 없습니다. 4개 토큰이 무엇인지(클래스 토큰 등 학습 가능한 토큰, 관측 창 n_obs = 4와의 관계)는 본문에 서술이 없습니다. 정책 계산에는 영향이 작지만 어텐션 점유율 해석(아래)에서 이 4개가 어디에 들어가는지가 정해져야 합니다.
- **그림 9 판독.** 다섯 과제의 곡선을 읽어 시간 단계마다 세 어텐션을 더하면 **평균 0.999–1.003, 범위 0.976–1.035**입니다(판독 오차 안). 즉 모달리티별 어텐션은 합이 1이고 4개 추가 토큰의 몫은 따로 그려지지 않았습니다.
- 모달리티별 평균(성공 에피소드 1개): Vision / GelSight / Evetac = Gear 0.38 / 0.46 / 0.16, Board 0.47 / 0.42 / 0.11, Lamp 0.31 / 0.41 / 0.28, Key 0.55 / 0.26 / 0.19, Lightbulb 0.38 / 0.50 / 0.11. **토큰 수에 비례한 균등 점유율은 Vision 0.40, GelSight와 Evetac 각 0.30**입니다. Evetac의 에피소드 평균 어텐션은 다섯 과제 모두 0.30 아래(0.11–0.28)입니다. Evetac 어텐션은 접촉 구간에서 일시적으로 올라가는 모양입니다(그림 5, 10과 일치). 그림: `own_attention.png`.
- 이 결과가 말하는 것: 본문의 "Evetac가 표현을 주도하지는 않는다"와 방향이 같습니다. 어텐션은 입력 중요도의 인과적 증거가 아니라서 "센서 중요도가 단계마다 바뀐다"는 서술의 근거로는 한 에피소드의 어텐션 곡선이 약하고, 센서 제거 절제(V5)가 더 직접적인 증거입니다. 어느 층과 헤드의 어텐션인지(DiT 10블록)와 평균 방식은 적혀 있지 않습니다.
- 부록 그림 9와 10의 x축 길이가 같은 과제에서 다릅니다: Lamp 100 대 201, Lightbulb 136 대 440, Board 90 대 93, Gear와 Key는 같음(119, 51). 두 그림이 같은 에피소드인지, 시간 단위가 정책 스텝인지 센서 프레임인지는 적혀 있지 않습니다.

### K2. Evetac 프레임 수와 표본화 창

관측은 Evetac 16프레임(200 Hz 센서)이고 센서 프레임은 "0.06 s 창에서 균일 표본화"됩니다(§3, §4). 200 Hz에서 0.06 s에 들어가는 프레임은 12개이고, 16프레임이 0.06 s에 들어가려면 약 267 Hz가 필요합니다. 16프레임이 200 Hz로 연속이면 80 ms를 덮습니다. 프레임 복제나 보간이 있는지, 창이 0.06 s인지 0.08 s인지는 서술이 없습니다. 비전과 GelSight 두 프레임(25 Hz)은 40 ms를 덮어 창 안에 들어갑니다. 합성곱 산술은 맞습니다: Evetac는 시간 16 → 8 → 4 → 2(stride 2 세 번) 후 마지막 시간 커널 2로 1, 공간 120 × 160 → 15 × 20(stride 2 세 번) 후 4 × 5 합성곱으로 12 × 16입니다. 비전 128 × 128은 stride 2를 세 번 쓰면 16 × 16(본문의 "4단"은 한 단이 stride 1이라는 뜻으로 읽힘).

### K3. DiT 머리 파라미터 추정

폭 256, 10블록, 헤드 8, MLP 4배, 시간 임베딩 128, AdaLN-Zero(셀프, 크로스, MLP마다 β·γ·g = 9D 출력)를 가정하면 블록당 1,349,120개, 10블록 13,491,200개이고 시간 임베딩 MLP, 입력·출력 사영, 위치 임베딩을 더해 약 **13,662,468**개입니다. 보고된 13,701,508과 **0.28% 차이**입니다. 층 구성이 모두 서술되지 않아 정확히 맞출 수는 없으나 표 7(L = 10, D = 256, 헤드 8, MLP 비율 4)이 보고한 크기와 모순되지 않습니다. 융합 트랜스포머의 깊이는 표 7에 없고, 인코더 파라미터(3.08 M)에서 비전 스템을 뺀 나머지로만 추정할 수 있습니다.

### K4. 20회 칸의 검출력과 학습 실행 변동 토이 (합성, 몬테카를로)

**검출력(Fisher p < 0.05, 몬테카를로 1500–3000회).** 두 모델의 참 성공률이 0.50 대 0.65 / 0.75 / 0.85일 때:

| 칸당 시행 수 | 0.50 대 0.65 | 0.50 대 0.75 | 0.50 대 0.85 | 0.30 대 0.55 |
|---|---|---|---|---|
| 20 | 9% | 27% | 55% | 23% |
| 40 | 22% | 56% | 89% | 56% |
| 100 | 53% | 95% | 100% | 94% |
| 200 | 83% | 100% | 100% | 100% |

표의 과제별 15–25%p 차이는 20회 칸에서는 대체로 구분되지 않는 크기입니다. 합계(100–200회)에서는 구분됩니다.

**학습 실행 변동이 있을 때의 영향.** 과제마다 모델이 따로 학습되고 칸마다 학습이 한 번이므로, 칸의 참 성공률에 학습 실행 변동(SD σ)이 들어간다고 보고 "참 성공률이 0.6으로 같은 두 모델"의 5과제 평균 차이가 관측된 24.5%p 이상이 될 확률을 시뮬레이션했습니다(칸당 20회, 20,000회).

| σ (칸의 참 성공률 SD) | 5과제 평균 차이의 SD | P(차이 ≥ 24.5%p) | 두 데이터셋 10칸 평균 차이의 SD | P(차이의 절댓값 ≥ 24.5%p) |
|---|---|---|---|---|
| 0 (이항만) | 6.9%p | 0.03% | 4.9%p | < 0.01% |
| 0.094 (V7 추정) | 9.1%p | 0.3% | 6.4%p | 0.01% |
| 0.15 | 11.6%p | 1.6% | 8.1%p | 0.23% |

학습 실행 변동을 이항 변동에 더해도, 두 데이터셋 10칸에서 본 24.5%p의 차이가 같은 모델 사이의 우연으로 나올 확률은 작습니다(σ = 0.15에서도 0.23%). **헤드라인 순서(MiTaS가 높다)는 이 가정에서 유지되고, 크기(24.5%p)의 구간이 넓어집니다**(V4의 쌍 t 검정 기준 SD 18.6%p, 10칸). 이 토이는 칸의 σ가 모델 사이 같다는 가정과 칸이 독립이라는 가정 위에 있고, 모델마다 σ가 다르면(예: 기준선이 불안정) 달라질 수 있습니다.

## 3. 해석 요약

1. 표와 본문의 수치는 서로 정확히 맞고(V1, V2, V8의 총합과 가산성), 데이터셋 1의 값은 v1과 v2에서 같습니다.
2. 주된 결론인 MiTaS(V+G+E)가 Sparsh-X, 시각 전용보다 높다는 것은 시행 단위, 정책 단위, 학습 변동을 더한 토이에서 모두 유지됩니다(V4, K4). 과제별로는 Gear와 Key에서만 구분됩니다.
3. 센서 절제(Evetac를 더하면 V+G보다 높다, +29%p)는 데이터셋 1에서 확실하고(V5), 과제별로는 Gear와 Lightbulb에서만 구분됩니다.
4. MTD는 데이터셋 1에서 합계가 구분되지 않고, 과제별로 구분되는 칸은 각 모델에 하나이며 MiTaS의 그 칸은 하락입니다. 데이터셋 2의 같은 모델 Key 값과 비교하면 데이터셋 사이의 차이가 MTD 전후의 차이만큼 큽니다(V6, V7).
5. 두 데이터셋의 같은 칸이 Key in Lock에서 체계적으로 다릅니다(V7). "합친 40회가 더 견고하다"는 문장은 합친 칸의 이항 구간(V3)보다 넓은 불확실성을 가진 값으로 읽는 것이 맞습니다.
6. 표 5의 Hz, 토큰 +4, Evetac 프레임 16대 0.06 s는 저자 확인 항목입니다(V8, K1, K2).
