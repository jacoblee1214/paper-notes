# 03. 수치 재계산, 일관성 검사, 주장 판정

재현 실험은 하지 않았다. 논문이 보고한 표 값만 다시 계산했다. 스크립트는 `analysis/recompute.py`(수 초, 결과 `analysis/recompute_results.json`)다.

## 0. 가정 (V1, V2)

- **V1 (과제당 시도 10회).** 본문 v2에는 실로봇 시도 수가 없다. 셀 값이 모두 0.1 단위이고, v1(`paper/paper_v1.txt`)의 표가 `10⁄10`, `22⁄40` 같은 분수로 적혀 있어 과제당 10회가 확인된다. 주방 장기 과제 ALL은 30회, 스터디 데스크 학습 과제 ALL은 40회, 미학습 ALL은 30회다.
- **V2 (표 4의 ±는 SD).** 본문이 SD인지 SE인지 밝히지 않는다. 표 4의 캡션은 "success rates %"라고 쓰지만 값은 0–1 소수다. 값을 그대로 썼다.
- 시뮬 표 4의 검정은 독립 가정 근사다. 시드 단위 원자료가 없다.

## 1. 일관성 검사 (논문 내부)

| 검사 | 결과 |
|---|---|
| 표 1–3의 ALL 열이 과제 열의 평균과 맞는가 (허용 0.006) | **모두 맞음** (불일치 0건) |
| v1과 v2의 실로봇 값 비교 (확인한 범위: 주방 표의 과제별 값, 스터디 데스크 ALL, 다중 과제 표) | **같음**. v2는 v1의 성공 수를 비율로 바꾼 것으로 보인다 |
| 본문 "2000–4000 행동 스텝 = 100–200초 (20 Hz)" | 맞음 (2000/20 = 100, 4000/20 = 200) |
| 사람 play 10분 = 36k 프레임 (60 fps) | 맞음 (600 s x 60 = 36,000) |
| "사람 5초 = 로봇 90초" 를 근거로 10분 사람 play ≈ 3시간 로봇 | 산술은 맞음 (90/5 = 18, 10분 x 18 = 180분). 근거는 과제 하나의 시연 시간 한 번 |
| 제어 주파수 | **불일치**: 본문 §4는 20 Hz, §5 실시간 추론은 17 Hz, 부록 A는 17–20 Hz |
| 사람 영상 프레임률 | **불일치**: 부록 A는 60 fps, 부록 D는 100 fps |
| 기준선의 추가 로봇 데이터 | **불일치**: 본문 §4는 "추가 로봇 시연 10분", 부록 A는 "추가 시연 5개". 두 값의 시간 비용 차이가 크다 |
| 표 4 캡션 "%" 대 값 | 불일치 (값은 0–1) |

**읽는 법.** 과제당 10회라서 셀 하나의 구간 폭은 약 ±30%p다. 20시연 장기 과제에서 사람 play의 효과(23%p)는 방향만 맞고 통계적으로 확실하지 않다. 40시연에서는 간신히 유의하다. 기준선과의 큰 차이는 과제 수가 적어도 유의하다.

**다중 과제 감소 (표 3).** 단일 대 다중의 감소는 Ours 3%p, LMP 8%p, R3M 10%p다. Ours가 가장 작다는 방향은 맞다. 다만 Ours-single과 Ours의 차이는 통계적으로 0과 구별되지 않는다.

## 3. 시뮬 표 4 (LIBERO, 5 시드 평균 ± SD)

| 행 | 부분 과제 (5개 평균) | 장기 과제 (5개 평균, 근사 95% 구간) |
|---|---|---|
| GC-BC (BC-RNN) | 0.19 | 0.00 |
| GC-BC (BC-trans) | 0.19 | 0.00 |
| Ours (0% human) | 0.79 (0.76–0.82) | 0.55 (0.52–0.58) |

- 과제 1의 부분 과제에서는 BC-RNN(0.96)과 BC-trans(0.95)가 Ours(0.92)보다 높다. 나머지 과제에서는 Ours가 높다.
- 장기 과제 Welch 검정은 BC 쪽 분산이 0이라 의미가 없다. 크기(0.29–0.67 대 0.00)만 의미가 있다.
- 기준선은 두 가지뿐이다. C-BeT, LMP, R3M은 시뮬에 없다. 본문의 "시뮬에서도 같은 결론"은 두 기준선에 한정된다.

## 6. 요약 판단

- 실로봇 결과의 방향은 일관된다. 사람 play와 GMM의 효과는 대체로 유의하다. KL 정렬과 다중 과제 감소의 효과는 방향만 맞다.
- 과제당 10회라는 규모는 셀 하나의 구간이 ±30%p를 넘는다. 논문의 "유의한 개선"은 과제 평균을 쓸 때에만 드러난다.
- 시뮬 결과는 기준선이 두 개뿐이라 "모든 기준선보다 낫다"는 주장에 근거가 부족하다.
- 수치를 바꾸는 불일치는 없었다. 그러나 데이터 수집 비용의 기준(C15)과 주파수(C16, C17)는 서로 맞지 않는다.
