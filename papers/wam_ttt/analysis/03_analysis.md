# 03. 수치 재계산과 해석: WAM-TTT (arXiv:2607.06988)

`analysis/recompute.py`(numpy, scipy, 수 초)가 논문 v3의 표 1, C.1, 2, 3, 4, E.1, E.2, E.3과 부록 D 루브릭을 다시 계산하고 결과를 `recompute_results.json`에 저장합니다. 토이는 `analysis/toy_fast_weight.py`(torch CPU, 약 6초)입니다. 번호 V는 재계산, K는 일관성 검사이고, 번호는 JSON 키와 맞춥니다.

**전제.** 논문은 시행별 점수를 주지 않습니다. 그래서 (1) 평균 열, 차이, 비율은 정확히 다시 계산하고, (2) 검정은 "분산 상계"로 합니다. [0, 1] 값의 분산은 m(1−m) 이하이므로 시행 n개 평균의 표준오차를 sqrt(m(1−m)/n)로 놓으면 실제보다 넓은 구간이 되어 보수적입니다. (3) 시행 수는 본문이 밝힌 값(표 1, C.1, E.1, E.3: 25회, 표 3, E.2: 10회)을 쓰고, 표 2와 4는 밝히지 않아 25회로 **가정**합니다. 진행도는 성공률이 아니라 부분 점수이므로 Fisher 검정은 쓰지 않았습니다.

## 1. 평균 열과 본문 증가량 (V1, V2)

- **V1.** 표 C.1의 12개 행(6 방법 × Orig/New)의 9과제 산술평균을 모두 다시 계산했습니다. **12개 모두 소수 첫째 자리까지 일치합니다**(최대 차이 0.05 이내).
- **V2 본문 증가량.** New: WAM-TTT − LDA 13.7, WAM-Cotrain 20.9, EgoScale 31.2, π0.5 31.4, WAM-ICL 39.1(§4.2와 일치). Orig: LDA +10.9, ICL +12.7, π0.5 +29.3, EgoScale +31.0, Cotrain +31.3(부록 C와 일치).
- **유지율과 차이(부록 C 요약표).** 6행 모두 일치합니다: WAM-TTT 0.756 → 0.76 / −14.9, Cotrain 0.849 → 0.85 / −4.5, LDA 0.647 → 0.65 / −17.7, EgoScale 0.498 → 0.50 / −15.1, π0.5 0.465 → 0.47 / −17.0, ICL 0.147 → 0.15 / −41.3.
- **절제·부록 산술.** E.1의 3과제 평균 5개(59.5, 51.4, 74.1, 73.7, 73.3), +14.6(= 74.1 − 59.5), 표 E.2의 −28, −20, −46과 "고정이 DiT만보다 낮음(54 대 72)", 표 E.3의 평균 72.3(72.25)과 28.9(28.875), 차이 41.4, 66.7, 39.9, 25.5, 43.4가 모두 맞습니다. 표 E.1의 (100,100) 행과 표 E.3의 비디오만 행은 표 C.1의 New WAM-TTT 값과 같습니다(Transfer Bottle 55.6, Table Bussing 100.0, Deliver Drink 66.7, Swap Place 66.7).

- **K3 (부록 C "같은 표준 설정에서 WAM 백본보다 엄격히 개선한다").** 9과제 평균(61.1 대 50.2)으로는 맞고, 과제별로는 Stamp Paper에서 35.0 대 LDA 50.0입니다.

## 3. 시행 수와 점수 격자 (V4–V10)

부록 D는 과제마다 항목 가중치를 주고 "진행도 = 도달한 항목 가중치의 합, 25회 평균"으로 정의합니다. 가중치 합은 9과제 모두 1.0입니다(V4). 항목 가중치의 최대공약수가 시행 점수의 최소 단위이므로(Transfer Bottle, Pour Water, Stamp Paper 0.05, Deliver Drink와 Swap Place 0.10, Flip Steak, Pyramid, Multi-step Steak 0.01, Table Bussing은 항목 수 N에 따라 0.5/N), 시행 n회의 평균이 가질 수 있는 값은 격자 위에 있습니다.

- **V4 표 C.1.** n = 25를 가정하면 **108칸 중 27칸의 값이 격자에 없습니다**(그림 `own_grid_check.png`). 예: π0.5 Orig Transfer Bottle 55.5(격자는 0.2 간격이라 55.4 또는 55.6), LDA Orig Swap Place 66.7, WAM-TTT New Deliver Drink 66.7, WAM-TTT New Stamp Paper 8.3, WAM-ICL Orig Deliver Drink 70.3.
- 27칸 중 많은 값이 1/3, 1/6, 1/9, 1/12 꼴입니다(66.7, 33.3, 8.3, 88.9, 44.4 등). 이 값들은 시행 수가 6, 9, 12, 18, 24 같은 수일 때 만들어지는 값입니다. 예: WAM-TTT New의 Deliver Drink 66.7, Swap Place 66.7, Stamp Paper 8.3은 n = 6, 9, 12, 15, 18, 21, 24, 27, 30 가운데 하나일 때 각각 가능합니다(칸마다 목록은 `recompute_results.json` `V4_feasibility_C1`).
- 가능한 설명은 (a) 일부 칸의 시행 수가 25가 아니라 다른 수, (b) 실제 채점이 부록 D 루브릭과 다른 규칙(§4.1은 "서브골 수에 비례한 분수"라고도 서술), (c) 표의 값이 여러 값의 평균이라는 것입니다. 본문 표 캡션의 "all cells averaged over 25 trials"와 어느 쪽이 맞는지는 저자 확인이 필요합니다.
- **V5 표 2 (n = 25 가정).** WAM-TTT 66.7만 격자에 없고 44.4, 50.0, 10.4, 15.2는 있습니다.
- **V6 표 3 (n = 10).** Swap Place의 WAM-TTT 88.9와 w/o TTT 74.1은 격자(Swap Place 항목 가중치가 0.1의 배수라 10회 평균은 1% 간격)에 없습니다. 이 두 값은 표 C.1의 **Orig. 열**의 WAM-TTT Swap Place 88.9와 WAM-Cotrain Swap Place 74.1과 같습니다. 표 3의 Table Bussing w/o TTT 40.0도 표 C.1 Orig.의 WAM-Cotrain Table Bussing 40.0과 같지만 40.0은 10회 격자에 있어 구분할 수 없습니다. 캡션은 New 설정, 10회라고 적습니다. 가능성은 (a) 이 열이 Orig 설정 값이거나 (b) 다른 시행 수·채점일 수 있으며 저자 확인이 필요합니다(K4). 한편 같은 표의 Table Bussing 행은 9.0이 항목 수 N = 5에서만, 66.7이 N = 3 또는 6에서만 10회 격자에 있어, 한 행이 같은 N이라는 가정과는 맞지 않습니다.
- **V7 표 4 (n = 25 가정).** 여덟 값 모두 Deliver Drink의 0.4% 격자에 있습니다.
- **V8 표 E.1 (n = 25).** 15칸 중 7칸이 격자 밖입니다: Transfer Bottle 44.1, 42.1, 47.9, 58.9(0.2 간격), Deliver Drink 44.2, 66.7, 61.0(0.4 간격).
- **V9 표 E.2 (n = 10).** Table Bussing 72.0과 54.0은 항목 수 N = 5일 때만 가능하고(기본 N = 1이면 5% 간격이라 불가), 80.0과 100.0은 N과 무관합니다. 본문은 "default N = 1"이라고 씁니다.
- **V10 표 E.3 (n = 25).** Deliver Drink 66.7과 Swap Place 66.7이 격자 밖입니다(표 C.1과 같은 값).

해석: 이 검사는 "값이 틀렸다"가 아니라 "표의 시행 수·채점 규칙 서술과 값의 격자가 맞지 않는 칸이 있다"는 것입니다. 정수 복원이 되지 않으므로 이 분석의 Wilson, Fisher 검정은 하지 않았고 아래 분산 상계 검정으로 대신했습니다.

## 6. 데이터와 규모 산술 (V12)

- 에피소드 합 600 + 544 + 1,142 = 2,286(부록 B와 일치). 과제 수로 나누면 평균 254(G1 과제 3개 200, gripper 2개 272, sharpa 4개 285.5).
- **K5.** 부록 E.4는 "기본 메타 학습 예산이 (r, h) = (100, 100) 짝 에피소드/과제"라고 쓰고, 이를 9과제로 곱하면 900입니다. 부록 B의 2,286과 다릅니다. 두 숫자가 다른 단위(예: 평가 데이터 부분집합, 절제용 하위 표본)인지 본문에 없습니다. 이 때문에 표 E.1의 (100,100) 행이 "표 1의 모델"과 같은 학습을 가리키는지 확인할 수 없고, 표 E.1의 (100,100) 행은 표 1의 값과 같습니다(V11).
- 외부 루프 샘플: 100k 스텝 × 128 = 1.28천만, 에피소드당 약 5,600번 표본 추출(표 B.1). 로봇 평가 시행: 표 C.1만 6 × 9 × 2 × 25 = 2,700회입니다.
- 고속 가중치 크기(가정): d = 48, 폭 128 MLP가 헤드마다 따로이면 층당 393,216개, 공유이면 12,288개. 슬로우 투영(θK, θV, θQ, θO를 은닉 1536 전체로 가정)은 층당 약 9.4M입니다. "lightweight adaptive memory"의 크기는 고속 가중치 쪽을 가리키며 슬로우 투영은 크지 않다고 말할 수 없습니다(TTT 블록 수는 본문에 없음).

## 8. 토이: 선형 기억과 inner 한 단계 (T1, T2)

논문 부록 A는 선형 고속 가중치에서 L_KVM의 최소해가 선형 어텐션 읽기라고 설명하고(식 A.2–A.4), 표 B.1은 inner 한 단계(N = 1, 메타 학습 η = 0.1, 시험 시 η = 0.01)를 씁니다. `analysis/toy_fast_weight.py`는 d = 48, 폭 128의 소형 모델로 이 두 가지를 봅니다(그림 `own_toy_fast_weight.png`, 키·값 분산 1 가정, 사람 토큰 수 L ∈ {64, 256, 1024}, 한 시드).

- **T1 (용량).** 서로 무관한 L쌍을 d × d 선형 기억에 넣으면 값 복원 코사인은 닫힌 해 0.74(L = 64), 0.41(L = 256), 0.21(L = 1024)로 L이 커질수록 떨어집니다(softmax 읽기는 0.98, 0.94, 0.85). 키가 비등방(조건수 약 100–2,000)이면 닫힌 해와 외적(헤비안) 근사의 코사인은 0.34–0.57로 벌어지고, 등방일 때(L = 256 이상) 0.91–0.98로 가깝습니다. 부록 A의 등방 가정은 "sanity check"라고 쓰여 있고 토이에서는 그 가정이 닫힌 해와 외적 근사의 일치를 좌우했습니다. 실제 DINOv3 특징의 비등방성은 측정하지 않았습니다.
- **T2 (단계 수와 η).** 키의 선형 함수를 값으로 하는 구조 있는 대응(L = 256)에서 읽기 출력과 목표 값의 코사인이 0.9를 넘는 데 η = 0.1이면 선형 310단계, MLP 340단계가 걸렸고, η = 0.01이면 2000단계에서 선형 0.85, MLP 0.87로 0.9에 못 미쳤습니다. **한 단계(N = 1)의 읽기 출력 상대 변화는 η = 0.1에서 1.8%(선형)–3.6%(MLP), η = 0.01에서 0.17–0.36%**입니다(같은 설정). 변화량의 방향은 목표와 코사인 0.45–0.63으로 맞지만 크기가 작아, 출력 전체의 목표 코사인은 한 단계 뒤에도 0.01 이하(초기 무작위 출력이 지배)입니다. 식 3의 1/(B L_h d) 정규화와 η가 작을수록 한 단계 갱신은 작습니다. 서로 무관한 값을 외우는 경우에는 L이 커질수록 한 단계 변화의 방향도 목표에서 멀어집니다(코사인 0.18 → 0.01–0.06).
- **한계.** 이 토이는 식 3의 MSE 갱신을 그대로 쓴 것입니다. 인용된 Spatial-TTT류 층은 per-token 학습률, L2 정규화, 선택적 Muon을 쓰고(공개 코드 확인), 실제 비디오 손실 L_vg의 기울기도 갱신에 더해집니다. 토이는 이런 요소가 만드는 갱신 크기를 모릅니다. 따라서 "N = 1, η = 0.01로 충분한 기억이 쓰인다"는 주장은 토이가 반증하는 것이 아니라, **논문이 N, η, 특징 크기에 대한 절제를 보이지 않아 확인되지 않은 부분**이라는 뜻입니다(`04` C11).
