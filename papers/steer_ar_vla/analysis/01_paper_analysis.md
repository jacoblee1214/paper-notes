## 1. 한 문단 요약

π0-FAST(자기회귀 VLA)는 행동 청크를 DCT 기반 FAST 토큰 열로 생성합니다. TS는 사용자가 누른 방향키를 말단 속도 → 야코비안 의사역행렬로 관절 속도 → 시간축으로 복제한 청크 → FAST 토큰으로 바꾼 뒤, 정책이 디코딩하는 토큰 열의 앞쪽 몇 개(시작 인덱스 b, 창 크기 w)를 이 "조향 토큰"으로 덮어쓰고 나머지는 정책이 이어서 생성하게 합니다(§3.2). 추가 학습은 없습니다. 실험은 DROID(Franka + Robotiq)에서 공개 π0-FAST-DROID를 제로샷으로 씁니다(§3.3). 창 크기·시작 인덱스 스윕(§4.1, §4.2), 엔트로피(§4.3), 언어 따르기 교정(§4.4), 사용자 7명의 두 과제(§4.5)를 보고합니다.

## 2. 방법

### 2.1 FAST 토큰화 (§3.1)

행동 청크 A ∈ R^{H×D}(H = 10, D = 8)를 정규화하고 시간축 DCT를 적용한 뒤 계수를 양자화합니다. 저주파부터 평탄화해 BPE로 압축합니다(§3.1 식). FAST 논문은 평탄화를 "같은 주파수의 모든 차원을 먼저" 하는 순서로 한다고 씁니다(FAST 논문 §V-B). TS 논문은 "토큰이 저주파에서 고주파 순서"라는 성질을 §4.2의 근거로 씁니다.

### 2.2 조향 식 (§3.2)

- 입력 u ∈ R^6은 키보드 6방향 중 하나(left, right, back, forward, up, down)입니다. v_cart = m·u (m은 크기).
- q̇ = J(q)† v_cart (무어–펜로즈 의사역행렬). q̇를 행동 horizon H로 "padded"해 ã_{1:H}를 만들고 z̃_{1:K} = E_FAST(ã)로 토큰화합니다.
- 주입: i ∈ [b, b+w)에서 z_i = z̃_i (디랙 질량), 그 밖에서는 p_θ(· | z̃_{<i}, z_{<i}, o_t, ℓ, q_t)에서 샘플링합니다.
- 저자 설명 그림 1a는 앞 두 토큰(z̃_0, z̃_1)을 조향 토큰으로 보입니다.

### 2.3 설정 (§3.3, 부록 A)

DROID 플랫폼(Franka Panda, Robotiq 2F-85, ZED 장면 카메라 1대, ZED mini 손목 카메라 1대), π0-FAST를 DROID로 학습한 공개 체크포인트(행동 horizon 10, 행동 차원 8), 추론은 RTX 5090 1장입니다. 학습과 미세조정은 하지 않습니다.

## 3. 실험과 수치

### 3.1 창 크기 (§4.1, 표 1, 그림 2)

네 방향(앞·뒤·왼·오른쪽)에 블록 하나씩, 그릇은 로봇 아래. 지시문 "pick up the block and place it in the bowl"(방향 정보 없음). 1 m/s, 1초 분량 속도를 한 방향으로 주입합니다(§4.1, 부록 A.1(1)). 조향 의도율 SIR은 의도한 방향 블록을 집어 넣은 비율, 평균 경로 효율 MPE는 성공 시행의 (직선 거리 ÷ 실제 경로 길이)입니다.

| 창 w | SIR | MPE |
|---|---|---|
| 1 | 0.38 | 0.724 |
| 2 | 1.00 | 0.663 |
| 4 | 1.00 | 0.602 |
| 6 | 0.94 | 0.564 |

저자 해석: 토큰 하나는 방향 정보가 부족하고(w = 1), 창이 커질수록 경로 효율이 떨어지며 블록을 지나쳐 가는 현상이 보인다(§4.1). 시퀀스 길이는 8–36 토큰(EOS 2개 포함)이라고 씁니다.

### 3.2 시작 인덱스 (§4.2, 그림 3)

w = 2 고정, b ∈ {0, 1, 2, 3}. 그림 3b의 SIR은 막대 위 숫자로 100%, 88%, 88%, 14%(b = 0..3), 과제 완료율은 100%, 88%, 100%, 100%입니다. 저자 해석: 저주파 토큰(앞쪽)을 편집하는 것이 더 효과적이고, 고주파 쪽으로 가면 조향 의도가 무시되지만 정책은 여전히 블록을 집어 넣는다(§4.2).

### 3.3 엔트로피 (§4.3, 그림 4, 부록 B.5, C)

20개 무작위 장면 × 4방향 = 80회에서 앞 두 토큰을 주입하고(부록 A.1(3)), 이후 각 생성 토큰의 다음 토큰 분포 엔트로피를 잽니다. 저자 해석: 주입 직후(3번째) 토큰 엔트로피는 작지만 그 뒤 크게 올라가고, 후반에 확신이 생기며 다시 낮아진다. 따라서 "엔트로피 붕괴 없음"입니다. 그림 7은 같은 조향 prefix 뒤 토큰 열이 장면마다 다름을 색 격자로 보입니다.

### 3.4 언어 따르기 교정 (§4.4, 그림 5, 부록 A.1(4))

파란 정육면체·초록 정육면체·파란 직육면체·초록 직육면체 4개를 그릇 주변에 놓고 지시문 4개를 번갈아 40회(지시문당 10회). π0-FAST는 "초록 정육면체"와 "파란 직육면체" 지시에서 0%였고, 올바른 물체 쪽으로 0.5 m/s, w = 2, b = 0 조향을 넣으면 두 경우 모두 100%였습니다(그림 5b). 조향 토큰 사용 비율은 "전체 궤적 토큰의 25% 미만"(§4.4 본문)이고 그림 5c는 21%와 26%입니다.

### 3.5 사용자 연구 (§4.5, 표 2, 부록 A.2, B.3, B.4)

- 사용자 7명, 연습 최대 3회, 키 입력 한 번에 0.5 m/s, w = 4. IRB 승인.
- 과제 1(바나나를 서랍에 넣고 서랍 닫기): 자율 10.0% / 조향 72.5%, 중앙 완료 시간 74.0 s / 42.0 s. 제한 시간 800 timestep(§4.5). 순위합 검정 p = 0.003(성공률), p = 0.020(시간).
- 과제 2(접시 세 개 위 스펀지 두 개 교환): 자율 전체 성공 0%, 진행률 16.7%. 조향 93.8%(p < 0.001). 중앙 시간 133.8 s. 최대 4분. 진행률은 이동 3회 각각 1/3(부록 B.3).
- 시행 수, 사용자별 횟수, 신뢰구간, 사분위는 어디에도 없습니다.

## 4. 저자가 인정한 한계 (§5.1)

- 자기회귀 디코딩은 flow·diffusion VLA보다 지연이 큽니다. 비동기 청크 실행과 결합하는 것은 다루지 않았습니다.
- 경쟁 방법과의 비교, 사용자 연구의 조건 구성(예: 순수 원격 조작 대조)은 한계로 적히지 않았습니다(`03` 참조).
