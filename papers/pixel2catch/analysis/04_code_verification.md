## 3. 라이선스와 사용 범위

- **코드**: LICENSE가 없고 README에도 라이선스가 정해지지 않았습니다. 권리는 저자에게 남아 있다고 보는 것이 안전합니다. 따라서 공개본에는 코드를 넣지 않습니다. 설정 값, 함수 이름, 파일 경로처럼 사실을 나타내는 짧은 식별자만 씁니다.
- **논문**: arXiv 라이선스는 **CC BY-NC-ND 4.0**입니다(arXiv 초록 페이지 확인, 2026-11-17). CC BY가 아니므로 논문 그림은 공개본에 넣지 않고 개인용 리포트에만 넣습니다. 공개본은 우리 말로 쓴 분석과 우리가 그린 그래프만 씁니다. 논문 문장을 길게 옮기지도 않습니다. ND 조항 때문에 논문을 "변형"하는 것으로 보일 수 있는 긴 요약도 피합니다.
- **의존성**: IsaacLab은 API에서 라이선스가 NOASSERTION으로 나왔습니다. skrl은 MIT, SAM2는 Apache-2.0입니다. 실제 사용 전에 각 저장소의 LICENSE 파일을 다시 확인해야 합니다.

**판정: 공개본은 분석과 그래프만, 코드와 논문 그림 없음.**

**결론: 이 맥에서 논문의 실험은 재현할 수 없습니다. 축소된 재구현과 정보량 검증은 가능합니다.**

| 항목 | 판정 | 이유 |
|---|---|---|
| 공식 환경에서 학습 (Isaac Lab, 512 환경) | **불가** | Isaac Sim/Lab은 NVIDIA GPU를 전제합니다(README). 이 맥(M4 Pro, MPS, CUDA 없음)에서는 실행할 수 없습니다 |
| 공식 체크포인트로 평가 | **불가** | 체크포인트가 저장소에 없습니다. 학습을 거쳐야 합니다 |
| 실로봇 실험 (UR5e, Allegro, RealSense, ROS 2) | **불가** | 하드웨어가 없습니다. 실로봇 파이프라인도 저장소에 없습니다 |
| SAM2 지연 측정 (30 Hz 확인) | **조건부** | SAM2 가중치 다운로드가 필요합니다(승인 필요). MPS 호환성을 확인해야 합니다. 측정 전 |
| 픽셀 특징 정보량 검증 (토이 T1) | **시작 가능, 완료** | numpy만 씀. `analysis/toy_pixel_features.py`, 수 초 |
| 축소 재구현 (팔 한 개, 손 고정, 구 물체, MAPPO를 torch로) | **조건부** | MuJoCo나 다른 CPU 시뮬로 UR5e 모델이 필요합니다. 저장소에는 USD만 있어 MJCF 변환이 필요하고, 공개 MJCF 존재 여부는 확인하지 않았습니다. 이미 설치된 torch를 쓸 수 있습니다 (새 설치는 승인 필요) |

**노력 추정 (측정 전, 추정치).**

- 토이 T1: 완료.
- 축소 재구현 (팔 한 개, 구 물체, 2 에이전트 중 팔만 또는 팔 + 고정 손): 1–2주 (추정). 환경 작성, MJCF 변환, 특징 추출, MAPPO 구현, 소규모 학습을 포함합니다.
- 전체 재구현 (팔 + 손, 두 에이전트, 현실적 던지기 분포): 3–6주 (추정). 계산 시간은 측정해야 합니다.

## 5. 이 대조가 `01`–`03`에 주는 것

- D1, D2, D3, D4는 논문 수치의 **정의**에 영향을 줍니다(`03` §2의 4–5번). 같은 이름의 지표라도 값이 다를 수 있습니다.
- D5, D6은 **sim-to-real 간극**의 두 원인입니다. 시뮬은 지연과 색 분할이 있고 실로봇은 SAM2 분할입니다. 논문은 두 차이가 결과에 주는 영향을 측정하지 않았습니다.
- D11, D12는 **시뮬 분포**가 실로봇 분포와 다르다는 근거입니다. 논문은 이를 "궤적 분포 차이"로 설명합니다(§V-D). 이 설명은 맞을 수 있지만 코드가 보여 주는 시뮬 분포는 목표 지향 던지기라서 "무작위 방향과 속도"라는 설명과 다릅니다.
- D13의 `timesteps`는 학습 규모를 가늠하는 데 필요하지만, 저자가 학습 스텝을 보고하지 않아 비교 근거가 없습니다.
