# DexTouch-WM 주장 검증 (04)

공식 코드가 없어서(02 §4) 코드 대조(`04_code_verification.md`)는 하지 않았습니다. 대신 논문 표·본문 수치를 재계산하고(03), 주장별로 판정했습니다.

판정 기준: **재현됨**(표 수치와 본문이 일치하고 계산이 맞음), **부분**(방향은 맞으나 근거가 약하거나 조건이 붙음), **확인 불가**(논문에 정보가 없음), **불일치**(본문과 표가 어긋남).

## 4. 구현 가능성 판정

### 4.1 공식 재현: **불가**
- 코드, 가중치, 데이터셋 공개가 없고(02 §4), 학습 설정도 부족합니다(§2).
- 필요한 것: 촉각 장갑 두 벌(사람용·로봇용 동일 배치), 손 추적기(MANUS, VIVE), 20-DoF 로봇 손(Wuji)과 팔(Tianji), 사람 데이터 100시간, 로봇 데이터 5시간, 사전학습 비디오 백본(Wan2.2-TI2V-5B, 공개 가중치).
- 장비 목록 중 촉각 장갑과 Wuji 손은 구입 가능 여부가 불분명합니다. 공개 SDK 중 Wuji 손 제어 라이브러리(`wujihandpy`, MIT)는 있습니다.

### 4.2 이 맥(Apple M4 Pro, 통합 메모리 약 24 GiB, MPS, CUDA 없음, torch 미설치)에서

| 항목 | 판정 |
|---|---|
| 논문 학습 재현 (100h 사람 + 5h 로봇 + 5B 백본 미세조정) | **불가**. CUDA 없음. 데이터도 없음. 학습 시간을 계산한 것은 아님 |
| 토이 수준 검증 (numpy, 이 저장소 완료) | **가능** |
| 작은 촉각 인코더·잔차 잠재 학습 (합성 또는 공개 촉각 데이터) | **조건부**. torch 설치 승인 필요. MPS로 소형 모델은 가능할 것으로 추정(실행 안 함) |
| Wan2.2-5B 로드와 추론 | **조건부**. 메모리는 24 GiB에서 빠듯할 수 있다는 추정(실행 안 함). 미세조정은 비현실적 |

### 4.3 같은 아이디어를 새로 구현하는 노력
- **중간에서 높음.** 구성 요소: (a) Wan2.2 DiT 위의 두 번째 경량 전문가와 joint attention(MoT 형태), (b) Split-Hands 촉각 토크나이저(공유 손끝 인코더 + 손바닥 인코더 + 패드 임베딩), (c) 초기 상태 기준 잔차 잠재와 접촉 마스크 손실, (d) dual-rate 조건, (e) 사람 자세 → 로봇 행동 리타게팅 파이프라인(IK 필요).
- 가장 값싼 부분은 (b)와 (c)입니다. 작은 촉각 맵 자동인코더 하나로 검증할 수 있습니다.
- 가장 비싼 부분은 (e)입니다. 사람 장갑 데이터 수집과 리타게팅 오차 측정이 없으면 DexTouch-WM의 핵심 주장을 확인할 수 없습니다.
- 줄 수 추정은 하지 않았습니다(근거 없음).

### 4.4 하드웨어 요구
- 학습: 대형 CUDA GPU 필요(근거: 5B 규모 비디오 DiT 미세조정은 보통 대형 GPU 메모리를 씀. 논문에 GPU 정보 없음, **추정**).
- 데이터 수집: 촉각 장갑 두 벌, 손 추적기, 로봇 손·팔.
- 공개 촉각 데이터(예: UniT 계열)로 촉각 인코더 부분만 검증하는 것은 하드웨어 없이도 가능합니다.

### 4.5 판정 요약
- **공식 재현: 불가.**
- **이 맥에서 재현: 불가. 토이와 소형 인코더 검증만 가능.**
- **새로 구현: 가능하나 중간에서 높은 노력. 데이터 수집이 병목.**
- **가치 판단:** 설계 아이디어(Split-Hands, 잔차 잠재, dual-rate)는 값싸게 검증할 수 있고 가치가 있습니다. 주장의 핵심인 "사람 데이터가 로봇 세계모델을 돕는다"는 리타게팅 오차와 도메인 격차를 재지 않으면 검증되지 않습니다.

## 5. 문제와 미확인 항목

- 논문 본문에 한계 절이 없음. 리뷰어가 볼 수 있는 질문(사람 촉각 전이, 리타게팅 오차, 시드 분산)이 본문에 답이 없습니다.
- 본문 밖의 자료(부록, 웹페이지, 보충 자료)를 확인하지 못했습니다. arXiv 페이지에 보충 자료 링크가 없었습니다.
- 워크숍 발표(라이트닝 토크) 여부와 발표 자료는 확인하지 못했습니다.
- 논문 그림 Fig. 4, Fig. 5, Fig. 6은 정성 결과라 재계산 대상이 아닙니다.
