## 0. 분석 가능한 범위

- 논문은 **집계 값만** 보고합니다. 작업별 결과, 실행별 결과, 쌍(paired) 구조의 불일치 수는 없습니다. 쌍 검정은 불일치 수를 알아야 하는데 일부만 구할 수 있습니다. 그래서 실현 가능한 모든 분할에 대한 정확 McNemar p의 **최솟값과 최댓값**을 구간으로 보고합니다(§2).
- 표본은 대부분 작습니다. 표 13은 32개, 표 14는 40쌍, 그림 19는 12건(모델 4 × 3시행), 표 5는 방법당 20회.
- 정책 결과가 없으므로 **24/7-BENCH의 정책 순위나 차이에 대한 검정은 불가능합니다.** 대신 §4의 토이로 "실행 수를 얼마나 잡아야 하는가"를 물을 수 있습니다.

## 3. 유도와 점검

### 3.1 압력 법칙과 감쇠 (식 (4), (5), (8))

- 식 (5)를 p(x) = k x (1 + β x²/ℓ²)로 쓰면 p(0) = 0, p′(0) = k(초기 기울기), p′(x) = k(1 + 3β x²/ℓ²) ≥ 0입니다. 따라서 β ≥ 0이면 압력은 깊이에 따라 단조 증가하고, β = 0이면 식 (4)의 선형 법칙으로 돌아갑니다. 논문 식과 일치합니다.
- 식 (8): µ(0) = µ_s[r + (1 − r)] = µ_s, µ(v → ∞) = r µ_s. 0 ≤ r ≤ 1이면 µ는 v에 대해 감소하지 않습니다. 논문 설명(r = 1이면 쿨롱)과 일치합니다.
- Hunt–Crossley 형태 f = K δ [1 − α v_n]_+: v_n > 0(분리)이면 힘이 줄고, v_n < 0(접근)이면 힘이 늘어납니다. [·]_+ 때문에 힘은 음수가 되지 않습니다(인장이 없는 접촉). 논문의 "분리 속도가 빠르면 감쇠가 크다"는 설명과 부호가 맞습니다.

### 3.2 작업 이벤트 재귀 (식 (19))

- 논문 추출 텍스트는 r_t = b_t r_{t−1} + 1로 읽히지만, **페이지 이미지(33쪽)에서 r_t = b_t (r_{t−1} + 1)**가 맞습니다.
- 해석: 술어가 참인 연속 스텝 수를 세고 거짓이 되면 0으로 돌아갑니다. e_t = 1[r_t = K_hold]는 연속 K_hold 스텝마다 **한 번** 발생합니다(K_hold보다 길게 참이어도 정확히 한 번). 접촉 잡음이 이벤트를 만들지 않게 하는 장치입니다.

### 3.3 처리량과 검열

- 처리량 = 3600 N_done / T_run (작업/시간, T_run 초). 예: 600 s에 10개 완료 = 60 작업/시간.
- 완료하지 못한 작업의 지연은 검열입니다. 완료 지연만 평균하면 쉬운 작업으로 편향됩니다(논문 §5.2.2). 이 편향의 크기는 자료가 없어서 측정할 수 없습니다.

### 3.4 쌍 McNemar의 실현 가능 범위

- 쌍 n개에서 A가 x번, B가 y번 성공하면 b = #(B 성공, A 실패), c = #(A 성공, B 실패)에 대해 b − c = y − x입니다.
- 가능한 c는 max(0, x − y)에서 시작해 b ≤ n − x, c ≤ n − y를 만족하는 값이고, 각각의 정확 McNemar p를 계산해 범위를 냅니다. `table_check.py`의 `mcnemar_range`가 이를 구현합니다. 표 13 E RIS 대 독립은 가능한 분할이 1개뿐이라 p가 고정됩니다.

## 4. 토이: 작업 의존성에서의 검정 설계 (`analysis/power_toy.py`)

### 4.1 설정과 가정

- 실행 r의 작업 성공 확률: logit p_r = logit p_0 + s u_r, u_r ~ N(0, 1). 작업은 Bernoulli(p_r)입니다(실행 안에서는 독립, 실행 사이에 의존).
- 가정: 실행당 작업 수 M = 20, 기준 성공률 p_0 = 0.80, 실행 효과 s ∈ {0, 0.5, 1.0}, 차이 Δ ∈ {0, 0.05, 0.10}, 정책당 실행 수 R ∈ {3, 5, 10, 20, 40, 80}, 시뮬레이션 4000회, α = 0.05, 양측.
- 논문에 **없는** 값입니다. 목적은 설계 원리를 보여 주는 것입니다. 실제 설계에는 파일럿 실행으로 s를 추정해야 합니다.
- 두 검정:
  - **작업 독립 검정(naive):** 작업 전체를 독립 표본으로 보는 합동 비율 z 검정.
  - **실행 검정(run):** 실행별 성공률 평균에 대한 Welch t 검정.

### 4.2 결과 1: 1종 오류 (Δ = 0, R = 10)

| s | 작업 독립 검정 | 실행 검정 | 설계 효과 1 + (M−1)ICC |
|---|---|---|---|
| 0 | 0.053 | 0.050 | 1.00 |
| 0.5 | 0.135 | 0.046 | 1.75 |
| 1.0 | 0.321 | 0.052 | 3.73 |

(ICC = 실행 확률의 분산 / (θ(1−θ)), θ는 주변 성공률. 설계 효과는 `ci_coverage_R10`의 값입니다.)

**해석:** 실행 효과가 있으면 작업을 독립으로 보는 검정은 **명목 5%의 2.7배(s = 0.5)에서 6.4배(s = 1.0)**까지 기각합니다. 실행 검정은 R = 10에서도 명목 수준을 지킵니다. 이는 논문이 "실행을 통계 단위로 써야 한다"고 한 권고(§5.3, §6.6)를 수치로 뒷받침합니다.

### 4.3 결과 2: 포함 확률 (R = 10, 95% 구간)

| s | 참값(주변 성공률) | 작업 독립 Wilson 포함 | 실행 군집 t 포함 |
|---|---|---|---|
| 0 | 0.800 | 0.953 | 0.947 |
| 0.5 | 0.789 | 0.866 | 0.941 |
| 1.0 | 0.761 | 0.692 | 0.933 |

**해석:** 작업 독립 구간은 실행 효과가 클수록 덜 덮습니다(s = 1에서 0.69). 실행 군집 구간은 R = 10에서도 0.93 이상을 유지합니다.

### 4.4 결과 3: 검정력과 필요한 실행 수 (실행 검정)

| s | Δ = 0.10에 필요한 R (검정력 0.8) | Δ = 0.05에 필요한 R |
|---|---|---|
| 0 | 20 | 80 |
| 0.5 | 20 | 80 |
| 1.0 | 40 | 80 초과 (R = 80에서 0.44) |

R = 10에서 검정력: Δ = 0.10이면 s = 0에서 0.75, s = 0.5에서 0.54, s = 1.0에서 0.25입니다.

**해석:**
- 정책 간 차이가 10 pp 정도면 정책당 실행 20–40회가 필요합니다. 실행당 작업 20개(=총 400–800 작업)입니다.
- 5 pp 차이를 80%로 잡으려면 실행 80회 이상이 필요할 수 있고 s가 크면 실행 수를 늘려도 부족합니다.
- 작업 독립 검정의 높은 "검정력"(예: s = 1, R = 10에서 0.65)은 1종 오류가 0.32로 부풀려진 결과이므로 믿으면 안 됩니다.
- 이 수치는 M = 20과 p_0 = 0.8 가정에 민감합니다. 실제 설계에는 파일럿 실행으로 s를 추정한 뒤 다시 계산해야 합니다.

### 4.5 토이의 한계

- 실행 효과를 로짓 정규로 둔 한 가지 모형입니다. 작업 사이 자기상관(예: 같은 물체가 계속 실패)과 과제 간 이질성은 넣지 않았습니다.
- 정책 차이를 확률 차이로 넣었는데, s > 0에서 주변 성공률은 P_0 + Δ와 정확히 같지 않습니다(표의 참값 열이 이 차이를 보여 줍니다).
- 과제 7개의 순위 안정성은 계산하지 않았습니다. 논문에 정책 결과가 없어 입력이 없기 때문입니다.

## 5. 해석: 이 논문에 대한 평가 설계 시사점

1. **실행을 단위로**: 24/7-BENCH의 신뢰구간은 작업이 아니라 실행 단위로 잡아야 합니다(§4.4, §4.3). 작업을 독립으로 세면 구간이 좁아지고 1종 오류가 커집니다.
2. **실행 수의 요구량**: 10 pp 차이를 보려면 정책당 실행 20–40회가 필요합니다(s = 0.5–1). 논문에 실행 수가 없으므로 **지금 보고된 결과로는 차이를 판단할 수 없습니다.**
3. **쌍 설계를 쓸 것**: 같은 초기 장면과 같은 작업 공급으로 정책을 돌리면 장면 분산이 상쇄되어 필요 실행 수가 줄 수 있습니다. 논문은 "같은 분포에서 초기 조건을 뽑는다"는 원칙만 말하고 쌍 설계는 쓰지 않습니다(§5.3).
4. **생성 실험의 작은 표본**: 표 13, 14, 그림 14, 19의 대부분은 표본이 작고 쌍 구조를 알 수 없습니다. 헤드라인 수치는 구간과 함께 읽어야 합니다.

## 6. 추가로 필요한 자료

- 정책 결과: 같은 장면·같은 작업 공급에서 정책 2–3개의 작업별 기록(완료, 실패, 시간 초과, 지연, 에너지). 그래야 run 단위 검정과 ICC를 추정할 수 있습니다.
- 생성 실험: 시행별 결과(쌍 표). 모델 × 과제 × 시드 구조.
- 물리 모델의 실물 측정(예: 배터리 들기, 손가락 하중·제하 루프). 현재는 수치 기준과의 비교뿐입니다.
