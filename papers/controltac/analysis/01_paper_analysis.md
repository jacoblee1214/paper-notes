## 1. 한 문단 요약

비전 기반 촉각 센서(GelSight Mini)의 데이터를 늘리기 위해, 참조 촉각 영상 한 장과 목표 3D 힘 변화 ΔF, 목표 접촉 마스크를 받아 목표 촉각 영상을 생성하는 두 단계 조건부 확산 모델을 제안합니다. 1단계(힘 제어)는 FeelAnyForce의 영상 20,000장으로, 2단계(자세 제어)는 7,000장으로 학습합니다(부록 B.1). 생성 영상으로 힘 추정, 접촉 자세 추정, 미관측 물체 분류를 학습하고, 실로봇에서 물체 밀기 힘 측정, 실시간 자세 추적, 3 mm 여유 삽입, 모방학습 정책(ACT)에 적용합니다(§4.3).

## 2. 문제 설정과 방법

### 2.1 문제와 입력 (§3, 그림 3)

- 입력은 (i) 배경을 뺀 참조 촉각 영상 x(초기 접촉), (ii) 상대 3D 힘 ΔF = 목표 힘 − 초기 힘, (iii) 목표 접촉 자세를 나타내는 2D 이진 마스크 P입니다(§3.2). 출력은 목표 촉각 영상 y입니다.
- 센서 편차(조명 등)를 줄이기 위해 배경 B를 빼서 접촉 특징만 남기고, 사전학습 오토인코더로 잠재 공간에서 확산합니다(§3.2 Stage 1). 오토인코더는 SANA(부록 B.1)입니다.

### 2.2 1단계: 힘 제어 생성 (§3.2, 부록 B.1, C)

참조 잠재와 ΔF를 받아 힘이 바뀐 중간 영상 y_Int의 잠재를 생성합니다. 생성기는 DiT 계열 확산 변환기이고 DDIM 샘플러를 씁니다. 손실은 0.5·L1 + 0.5·MSE(부록 B.2)입니다. v3 본문에는 식이 없고, 모델 입력 식은 부록 C의 기준선 설명(`y = D(F_h(z(x), z(c), Δf))` 등)에만 있습니다.

### 2.3 2단계: 자세 제어 어댑터 (§3.2, 그림 3(b))

- 물체별 이진 마스크 P는 모양과 크기가 고정이고, 접촉 자세는 마스크의 2D 강체 변환(이동·회전)으로만 바꿉니다. 학습에서는 마스크를 정답 촉각 영상에 ±3 픽셀, ±1°로 손으로 정렬합니다(§3.2).
- ControlNet 방식으로 힘 제어 백본을 얼려 두고 어댑터만 학습합니다. v1은 "DiT 블록의 앞 절반에 ControlNet 적용"(PixArt-δ 방식)이라고 적었고, v3 본문에는 이 문장이 없습니다.
- 학습 설정(부록 B.2): AdamW, 코사인 감쇠, 학습률 1e-4→1e-5(힘)와 1e-5→1e-6(자세), 75,000 스텝, 배치 4, RTX A5000 1장. 힘 생성기 147.53M 파라미터·50 에폭·에폭당 약 1,500 s·20.83 시간, 자세 생성기 222.93M·30 에폭·에폭당 약 550 s·4.58 시간, 합계 370.46M·25.41 시간.
- 추론(부록 B.3): A6000 1장, 배치 128에서 초당 6.5장(Hybrid 7장, Separate 3.7장), 최대 GPU 메모리 29.97 GB.

### 2.4 하류 과제 (§3.3, 부록 B.4, D)

- 힘 추정: FeelAnyForce 틀(DINOv2 ViT)로 3D 힘 회귀. 자세 추정: 같은 ViT에서 (x, y, θ) 회귀. 분류: CNN, ViT(처음부터), ViT(ImageNet 사전학습), 6개 미관측 물체(§4.2).
- 생성 데이터 사용 방식은 과제마다 다릅니다. 힘 추정은 실제 데이터에 15k–60k 생성 영상을 섞고, 자세 추정은 생성 영상만으로 학습하며, 분류는 참조 영상 한 장씩에서 만든 영상으로 학습합니다.

부록 E.1은 참조 영상을 그대로 복사한 기준선을 따로 보고합니다. FeelAnyForce 미관측에서 MSE 233±25, SSIM 0.78±0.05, AnyTouch2에서 MSE 81±12, SSIM 0.80±0.03입니다. 이 값은 표 1에는 없습니다. `03` V2에서 표 1과 함께 비교합니다.

### 3.2 교차 센서 (그림 5)

9DTact 데이터에서 미세조정 영상 수에 따라 MSE는 약 40(0장)에서 약 16(2,000장), SSIM은 약 0.80에서 약 0.85로 움직입니다(그림 판독 값). 본문은 "학습 센서와 비슷한 성능"이라고 적습니다(§4.1).

### 3.3 힘 추정 (그림 6(b), 표 6, 그림 12)

15,000–30,000장을 생성해 실제 데이터 일부와 함께 학습합니다. 본문은 "실제 데이터의 1/3에 생성 데이터를 더하면 전체 실제 데이터 성능과 맞먹는다"고 적습니다(§4.2). 표 6에서 실제 15k의 MAE는 0.053±0.012, 실제 15k + 생성 15k는 0.055±0.021이고, 생성 단독은 0.16–0.21입니다(부록 E.7).

### 3.4 자세 추정 (표 2, 그림 13–15)

생성 영상만으로 학습한 추정기(힘을 바꿔 가며 생성한 unfixed 행)는 원통에서 X/Y/각도 오차 4/5/3, 십자에서 3/4/1로 실제 데이터 학습(8/8/4, 6/6/2)보다 낮습니다. 힘을 6.5 N으로 고정해 생성한 행(원통 9/8/5, 십자 7/9/4)은 실제 데이터와 같거나 높습니다(`03` V6).

### 3.5 분류 (그림 6(a))

6개 미관측 물체에서 Ours는 CNN 0.87, ViT(처음부터) 0.95, ViT(ImageNet) 0.99이고, Geo+Col 0.69/0.65/0.79, Simulator 0.79/0.85/0.92, Text2Tac 0.22/0.16/0.14입니다. 시험 표본 수는 본문에 없습니다.

### 3.6 실로봇 (§4.3, 그림 7, 8, 부록 E.10–E.12)

- 물체 밀기(표 7): 센서 정답 2.24/0.96/1.06/1.08 N에 대해 실제 학습 추정기 2.38/1.08/1.18/1.14, 생성 학습 추정기 2.36/1.11/1.17/1.16 N(평균).
- 실시간 자세 추적: 10 Hz(§4.3).
- 삽입(여유 3 mm): 물체당 20회, 원통 90%, 십자·T자 85%, Type-C 75%(§4.3).
- 모방학습(그림 8): Pick and Peg-in-Hole, ACT, 칸당 25회, 실제 시연 20/35/50/70/100개, 증강 사본 0/1/2/4/9개. 50개 시연에서 증강 없음 48%, 사본 9개 72%입니다. 25회 시행 수와 칸별 Wilson 구간은 부록 E.2에 일부(5/25, 6/25)만 있습니다.

### 3.7 한계 (§5, 부록 F)

저자가 적은 한계는 (1) 마스크 수동 정렬, (2) 비전 기반 센서 한정, (3) 로봇 행동 신호 없음입니다. 부록 F는 PLA로 3D 인쇄한 곡면 물체만 학습했다는 동질성을 지적하고, 평면 큐브 영상 1,000장을 더하면 MSE 35→27, SSIM 0.80→0.83이 된다고 보고합니다.

## 4. 주장과 근거의 간격 (요약)

자세한 계산은 `03`에 있습니다.

1. **"참조 복사가 아님"의 근거는 MSE에서만 뚜렷합니다.** MSE는 참조 복사가 Ours의 9.0배(FeelAnyForce)·2.8배(AnyTouch2)이지만, SSIM은 0.78 대 0.79, 0.80 대 0.81로 효과 크기 d = 0.2–0.4입니다. Sim2Real, Hybrid, Separate, Simulator의 SSIM은 참조 복사 0.78보다 낮습니다(`03` V2).
2. **"1/3 실제 + 생성이 전체 실제와 맞먹는다"는 그림 6(b)에서 약 1.7–2배입니다.** 그림 판독 값 기준 1/3 + 30k가 약 0.10, 전체 실제가 약 0.06입니다. 본문 표현은 표 6의 15k + 15k가 15k 실제와 같다는 사실에 가깝습니다(`03` V5).
3. **생성 데이터 단독 MAE가 세 곳에서 다릅니다.** 표 6은 0.21/0.17, 그림 6(b) 판독은 약 0.27/0.23, v1 표 5(1–10 N)는 0.35/0.33입니다. v3 본문은 1–10 N 범위를 쓰고 v1은 4–10 N 부분집합에서 평가했습니다(`03` V5).
4. **모방학습 개선은 방향은 일관되지만 칸별로는 구별되지 않습니다.** 25회 가정에서 20개 비교 중 가장 작은 Fisher p는 0.148이고 Holm 보정 후 모두 1입니다. 사본 9개의 5개 시연 규모 합산(CMH)은 p = 0.045, 네 증강 팔 보정 후 약 0.18입니다(`03` V9).
5. **삽입 실험에는 증강 없음 대조군이 없습니다.** 20회 성공률 75–90%의 Wilson 구간은 53–97%입니다(`03` V8).
6. **자세 추정 "생성이 실제보다 낫다"는 힘을 바꿔 생성한 행에서만 해당합니다.** 고정 힘 행은 같거나 높습니다. 학습 데이터 크기(실제 3,000/1,000장 대 생성 12,000/4,000장, 그림 13–14 라벨)와 힘 범위가 다릅니다(`03` V6).
7. **표 2 캡션의 단위(mm)가 본문·부록(픽셀)과 다릅니다.** 부록 E.11의 1 픽셀 = 1/20 mm로 환산하면 원통 실제 X 8은 0.4 mm이고, mm로 읽으면 3 mm 삽입 여유보다 큽니다(`03` V6). 저자 확인이 필요합니다.
