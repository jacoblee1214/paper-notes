## 2. 차이를 만드는 조건 (해석 주의)

1. **기준선의 종류.** 표 3의 "MPPI → 기본 정책"은 같은 사전 정책을 정제 없이 실행한 것입니다. 정제가 얼마나 기여하는지 보이지만, "정제가 사전 정책의 다른 개선(더 많은 시연, 비용 안내 재학습, 단순 재계획)보다 낫다"는 것은 이 표에서 보이지 않습니다.
2. **순방향 모델의 비교.** 서론의 논지("시뮬레이터가 가장 자연스러운 순방향 모델, 학습 동역학의 근사 오차를 없앰")는 학습 동역학 모델 행(예: [18])과의 종단 비교로 검정되지 않습니다. 표 3의 시뮬레이터 행은 Isaac Sim 하나이고, 표 2는 상태 추정기 비교입니다.
3. **상태 추정기 평가의 분포.** 표 2는 학습과 같은 무작위화·같은 시뮬레이터에서 나온 검증 분할(A.1의 90/10 에피소드 분할)입니다. 실관측 오차는 한 수치(10.2 ± 1.4 mm, 5궤적)입니다.
4. **파라미터 조정이 사람 몫.** 질량·굽힘·마찰이 옷마다 손으로 맞춰지고(A.3) 시뮬레이터 비교의 파라미터는 "미리 정한 접힘 궤적"으로 골랐다고 프로젝트 페이지가 적습니다. 비교한 세 시뮬레이터 모두에 같은 조정 노력이 들어갔는지는 확인할 수 없습니다(논문은 "as carefully as we could" 수준, 프로젝트 페이지).
5. **시도 수 10.** 표 3, 4, D.1은 10회 시도이고 신뢰구간이 없습니다. 검출 가능한 격차는 약 60%p입니다(`03` V7).

## 4. 구현할 수 있는지 (판정)

**이 맥(Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)에서 논문 시스템의 전체 재현은 불가능합니다. 논문의 구조를 줄인 소형 재구현은 가능하고, 이 분석에서는 하지 않았습니다.**

|---|---|---|

**노력 추정(측정 전).** 소형 재구현은 3–5주입니다. MuJoCo 천 장면과 사전 정책 증류 약 1주, 사전 안내 MPPI와 모델 불일치(질량·마찰 변경) 실험 약 1–2주, 상태 추정기 학습과 평가 약 1–2주입니다. 논문 규모(FLASH + 실로봇)는 저자 자원이 필요합니다.

**FLASH와 코드가 공개되면** FLASH의 CPU 지원 여부와 라이선스(FLASH 논문은 CC BY-NC-SA)에 따라 표 1의 부분 재현 가능 여부를 다시 판단해야 합니다.
