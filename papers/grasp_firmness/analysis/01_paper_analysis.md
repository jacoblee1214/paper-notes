## 1. 한눈에

물체를 쥐는 힘을 "물체를 떨어뜨리지 않는 최소 힘"에 가깝게 맞추려는 연구입니다. 비전으로 물체 종류(class)를 알아 재료 사전분포를 얻고, 쥐는 동안 GelSight 촉각 이미지와 로드셀 힘의 시계열로 탄성률 E, 질량 m, 마찰 µ, 계면 전단 강도 τ의 사후 분포를 갱신하고, 사후 평균 최소 힘을 그리퍼 힘 목표로 줍니다. 과일·채소 52종 270개의 실측 데이터셋 Squash와 IPC 기반 변형체 시뮬레이션 200k 시퀀스로 학습하고 UR5 + WSG50 + GelSight Mini에서 검증합니다.

핵심 숫자: 시뮬 5k 파지에서 평균 절대 힘 오차(MAE) 0.51 N(표 1, Class prior 0.70 N), 실물 29개 물체에서 MAE 0.21 N·성공률 0.97(그림 6e, Class prior 0.46 N·0.72, Naive 1.99 N·1.00).

## 2. 방법

### 2.1 물리: 부드러운 물체는 덜 쥐어도 된다 (§3, 식 1–2, 그림 2)

- 식 1: µF + τ·A_real = mg. Coulomb 마찰에 접촉 면적 비례 항 τA를 더함. 부드러우면 A_real ≈ A_app(관측 가능)이라고 가정합니다(§3).
- 식 2: Hertz 접촉, A_app(F) = π(3FR*/4E*)^{2/3}, 1/E* = (1−ν_obj²)/E_obj + (1−ν_grip²)/E_grip, R* = R_obj R_grip/(R_obj+R_grip). 지문은 거의 평면, 물체는 국소 구로 근사.
- 식 5: f(θ) = min_{F≥0}{F : µF + τA(F;E) ≥ mg}, θ = (E, m, µ, τ).
- 식 1은 한 턱의 힘인지 두 턱의 합인지 본문에 적혀 있지 않습니다. 표 1은 "per jaw" 힘으로 보고합니다. 두 턱이 하중을 나누는 해석(턱당 mg/2)이 그림 6b–c의 값과 맞습니다(`03` K5).
- 그림 2는 µ = 0.5에서 질량 0.05 kg과 0.50 kg의 힘 감소율을 E에 따라 그립니다(판독: E = 50 kPa에서 18.7%·8.7%, 1000 kPa에서 약 2.4%·1.2%). 이 곡선의 E 의존성이 어떤 접촉 모델과 맞는지는 `03` T1에 있습니다.

### 2.2 Squash 데이터셋 (§4, 부록 S1, 그림 3, S1)

- 270개 인스턴스, 52개 class. 구조광 스캐너(Einscan SP V2)로 메쉬와 부피, 주방 저울로 질량, 듀로미터로 Shore 경도를 잽니다.
- 탄성률: 그리퍼로 압축하며 힘·접촉 면적·압입 깊이로 E* = (3F/4L)·√(π/A)를 계산해 평균(식 유도는 `03` V8). 젤 패드 탄성으로 보정하고, 푸아송비 ν를 모르므로 E를 ν의 함수로 보고합니다.
- 마찰: 물체를 든 상태에서 그리퍼를 벌려 미끄러짐 직전의 (F_slip, A_slip) 쌍을 모으고 µF + τA = mg를 최소제곱으로 풂니다. 위치마다 곡률이 달라 µ와 τ를 분리할 수 있다는 설명입니다. 예시(그림 S1b, 복숭아 한 개): µ = 0.41, τ = 17 kPa.
- 시뮬에서는 class별 가우시안(물리적 범위로 절단)에서 θ를 뽑고, 모든 물체가 ν = 0.48이라고 가정해 E를 조정합니다(S2.2).

### 2.3 모델 ψ (§5, 부록 S3, 그림 4–5)

- 인코더: 턱마다 Conv 3층(1→16→32→64, stride 2) + 평균 풀링 + 선형 → 128차원, 두 턱 결합 후 선형. 제어 벡터 28차원(원 신호 18 + 차분 10)은 MLP로 128차원.
- 시퀀스: CfC(closed-form continuous-time) 순환망, 은닉 256, 엄격히 인과적.
- 가능도 헤드: 후보 z̃ = (ln E, ln m, ln µ, ln τ)를 MLP로 투영하고 은닉 상태와 이어 붙여 점수 S_ψ(h, z̃)를 냅니다(학습 온도 β).
- 사후: class 사전에서 N = 512개 샘플을 **한 번만** 뽑아 고정하고, 매 시각 점수의 softmax로 가중치만 갱신합니다(식 4, S6). 목표 힘은 F_min = Σ α_j f(θ_j)(S8, 사후 기댓값).
- 손실: InfoNCE(양성 1개, 사전에서 뽑은 음성 K = 127개 + 배치 내 교차 음성) + λ = 0.1의 MSE 회귀(S10–S11). Adam lr 1e-4, 500 에폭, 배치 8, 코사인 스케줄, RTX 6000 Ada 8장 약 48시간.

### 2.4 시뮬레이터와 제어 (부록 S2, S5)

- UIPC(GPU IPC)를 접착 효과(τ)를 넣도록 수정. 안정 Neo-Hookean, 사면체 FEM, d̂ = 1 mm, Δt = 4 ms. 젤 패드도 변형체(E_grip = 245 kPa, ν = 0.48, µ_grip = 0.9, τ_grip = 100 kPa).
- 제어: 4 mm/s로 닫다가 접촉 0.25 N, 비례 제어 x ← x + K_p(F* − F)·sgn(v), K_p = 1e-4 m/N(S1), 이어서 100 ms 대기 후 10 mm/s로 2 mm 들어 올림.
- 실물: ROS 노드가 250 Hz로 목표 힘을 내고 PID가 서보합니다. GelSight Mini는 25 Hz라 이미지를 보간해 250 Hz에 맞춥니다(S5).

## 3. 실험

### 3.1 시뮬레이션 (표 1, 표 S1, 그림 S3)

- 학습·검증은 Squash 객체의 85%에서 200k 시퀀스, 평가는 나머지 15%에서 5k 시뮬(§6). 정답 "이상 힘"은 힘을 줄이며 gross slip이 날 때까지 내리는 drop test.
- 기준선: Naive(3 N 고정), Class prior(식 1에 class 평균 재료), Direct force predictor, Slip-reactive 네 종(휴리스틱 전단, 휴리스틱 접촉 면적, GBM, 이미지).
- 표 1 요약(점추정): Ours MAE 0.51, 편향 −0.05, 성공률 0.95. Class prior MAE 0.70, 편향 −0.26, 성공률 0.89. Slip-reactive(이미지) 성공률 0.97, MAE 0.88. Ours + safety margin(γ = 1.25, p = 0.5): 성공률 0.99, MAE 1.00.
- 재료 추정 Pearson r: E 0.65, m 0.88, µ 0.28, τ 0.57(§6). 표 S1 MAPE: Ours E 0.56, m 0.49, µ 0.56, τ 0.44 (Class prior 1.07, 1.50, 1.21, 0.77).
- 절제: 사전 제거(no prior), 틀린 사전(wrong prior), τA 제거(Coulomb-only)에서 MAE 0.61–0.62로 약간 나빠짐. 저자는 "작은 성능 저하"로 해석(§6).
- 부록 S4: 83.0%의 경우 Ours가 가장 정확, Class prior 15.4%, Naive 1.6%.

### 3.2 실물 파지

- 29개 실물 과일·채소, 물체당 3회(서로 다른 파지 자세), 파지 뒤 힘을 줄여 gross slip이 나는 힘을 최적 힘으로 측정(§6).
- 그림 6e: Ours MAPE 0.23 ± 0.18, MAE 0.21 ± 0.14 N, 성공률 0.97. Class prior 0.57 ± 0.61, 0.46 ± 0.40, 0.72. Naive 2.44 ± 1.49, 1.99 ± 0.33, 1.00.
- 그림 6b–c(네크타린 1개): 최적 힘 1.12 N. 탄성은 파지 단계에서, 질량·마찰은 들어 올릴 때 갱신됩니다. 파지 시작 0.32 s 전후가 경계입니다(그림 판독).
- 그림 6f–g: 추정 탄성률로 아보카도·토마토 4개씩을 경도 순으로 분류(Shore 경도 순위와 일치하게 보임).

### 3.3 정성 손상 평가 (그림 7–8)

- 사과 하나: fast separation으로 내부 멍을 촬영. Naive, Class prior는 흔적이 있고 Ours는 없음. 바나나 하루 뒤 표면 손상도 Ours만 없음. 각 방법 한 개씩의 사례입니다.

### 3.4 논문 그림 (CC BY 4.0, 출처: © 저자, CC BY 4.0, arXiv:2610.11221)

- 그림 2: 부드러운 물체일수록 필요한 힘이 줄어드는 정도(식 1–2).
- 그림 6c: 네크타린 한 번의 파지에서 탄성·질량·마찰 추정 곡선.
- 그림 6e: 실물 파지 절대 힘 오차 밀도와 요약표.

## 4. 한계 (논문 §7)

- 평행 그리퍼, 주어진 파지 자세. 다지 손으로 확장하려면 파지 물리 분석이 더 필요.
- 촉각 센서의 공간·시간 해상도 상충을 보간으로 보완. 더 빠르고 선명한 센서가 필요.
- 과일·채소 class 사전. 사전이 없는 물체에는 추가 검증 필요.
- 재료가 표면 전체에서 균일하다고 가정.

## 5. 주장과 근거의 간격

1. 서론의 "excess applied force가 non-adaptive 기준선 대비 2× 이상 감소"(§1)는 표 1의 Excess로는 Naive 대비 약 9.9배(2.07 → 0.21)이고 Class prior 대비 1.05배(0.22 → 0.21)입니다. 실물 MAE로는 Class prior 대비 2.19배(0.46 → 0.21)입니다(`03` V9).
2. 표 1에서 Ours는 MAE에서 가장 낮지만 신뢰 구간이 Class prior와 겹치고(0.19–0.84 대 0.50–0.95), Excess는 두 Slip-reactive(접촉 면적·GBM)가 더 낮고(0.10), 성공률은 Slip-reactive(이미지) 0.97, Direct 0.96이 더 높습니다.
3. 절제 결과의 "작은 저하"와 "fruits and vegetables 밖으로 일반화할 수 있다"(§6)는 같은 produce 분포에서 사전만 바꾼 실험입니다. 다른 재료 도메인을 다룬 실험은 없습니다(`04` C8).
4. 질적 손상 평가는 사과 한 개·바나나 한 개로 방법당 1회입니다(`04` C10).
5. 그림 6d의 막대는 25개인데 본문은 29개 물체라고 씁니다(`03` K6).
