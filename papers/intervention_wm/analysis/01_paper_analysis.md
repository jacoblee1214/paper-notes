## 1. 한눈에

| 항목 | 내용 |
|---|---|
| 문제 | 16-DoF 손(LEAP Hand)으로 하는 실로봇 RL은 한 번의 실수가 비싸다. 사람이 위험 직전에 개입하는 HIL RL은 개입을 한 번 쓰고 버린다(1절) |
| 아이디어 | 개입 라벨을 "다음 스텝에 운영자가 넘겨받을 확률" 예측 머리의 감독으로 쓰고, 이 확률을 actor의 보조 손실에만 넣는다(식 5–6). 보상이나 Bellman 목표에는 넣지 않는다(3.3절, 부록 C) |
| 골격 | 동결된 청크 BC 사전 정책 + 잔차 off-policy RL(ResFiT 계열), 손 잔차는 K = 3의 시너지 기저에 제한(3.2절, 식 2) |
| 세계모델 | 비평가 인코더의 분리된 잠재 z에 대한 1스텝 결정론적 모델. 동역학 앙상블 5개, 보상·종료·개입 머리(3.3절, 식 3) |
| 결과 | 5과제 실로봇. WHIRL 성공 30/30, 29/30, 27/30, 19/20, 17/20(표 1). 개입 비율 곡선이 먼저 0 근처에 닿음(그림 5, 6) |
| 한계(저자) | 한 시드, 한 운영자, 구역 안 일반화만, 개입 머리가 운영자 습관을 물려받음(5절) |

## 2. 방법

### 2.1 텔레오퍼레이션 (3.1절, 부록 A, F)

- SpaceMouse(Franka FR3 말단), Manus Quantum 장갑(LEAP 손), 발 페달(자율/사람 전환)의 세 채널. 페달 상태가 전환마다 이진 라벨 i_t를 만든다. 평가 지표와 개입 머리의 감독을 겸한다.
- 손 리타게터: 검지·중지·약지는 세 보정 자세로 맞춘 관절별 아핀 사상(식 7), 4-DoF 엄지는 손끝 IK에 엄지-검지 대립 방향 항을 더한 가우스-뉴턴(식 8–10).
- 개입 시점 t0의 이음매 제거(식 1, 식 11): q_cmd(t) = q_robot(t0) + R(g_t) − R(g_t0). 첫 명령이 현재 로봇 손 자세와 같다.
- 제어 주기: 팔 20 Hz(Cartesian 임피던스), 손과 장갑 120 Hz, 카메라 30 Hz(부록 F). 표 3의 지평(300 스텝 = 15 s 등)은 모두 20 Hz와 일치한다(`03` V13).

### 2.2 잔차 RL (3.2절)

- 실행 행동 a_t = a_BC(o_t) + Δ_θ(o_t). 사전 정책은 15–30개 시연으로 학습해 동결한다(4.4절).
- 손 잔차는 W ∈ R^{K×16}(K = 3)의 시너지 기저로 투영한다. 기저는 과제 간 공유되고 만드는 방법은 본문에 없다(참고문헌 [31, 33]만 있다).
- actor 손실(식 2): −Q(o, a_BC + Δ) + α_arm‖Δ_arm‖² + α_hand‖z_hand‖². 비평가는 실행 행동과 사전 행동을 함께 받는다 Q(z, [a, a_BC]).
- 재생 버퍼 D = D_demo ∪ D_auto ∪ D_int. 개입 전환은 정책 합성 행동이 아니라 운영자 명령을 저장한다.

### 2.3 개입 인식 세계모델 (3.3절, 부록 B, C)

- 입력: (z_t, a_t), z_t = E(s_t)는 비평가 인코더 출력이고 모델 쪽에서는 분리(detach)된다.
- 머리: 동역학 ẑ_{t+1}^{(m)} = z_t + g_m(z_t, a_t), m = 1..5. 불확실성 u = std_m ẑ. 보상 확률 r̂, 종료 d̂, 다음 스텝 개입 확률 p̂_intv.
- 손실(식 3): MSE(ẑ, z') + BCE(r̂, 1[r > 0]) + BCE(d̂, d') + m_t · BCE(p̂_intv, i_{t+1}). m_t는 라벨 가용 마스크다.
- 비평가 경로(식 4): y_imag = r̂ + γ(1 − d̂) min_k Q_tgt(ẑ', [ã, a_BC]); 불확실성 게이트 g_u = σ((τ − u)/β), (τ, β) = (0.03, 0.01). L_critic = L_TD + λ_c L_WM-critic, λ_c = 0.05. **개입 머리는 이 목표에서 뺀다.**
- actor 경로(식 5–6): J_WM = r̂ − α_d d̂ − α_i p̂_intv − α_u u, (α_d, α_i, α_u) = (1.0, 0.4, 1.0). L_actor_total = L_actor + λ_a L_WM-actor, λ_a = 0.40. 모델 쪽 기울기는 분리된다.
- 보정된 보상: r̂ = p̂_r R_succ + (1 − p̂_r) R_step, (R_succ, R_step) = (10.0, −0.01)(부록 B, C).
- 설계 근거(부록 C): (i) 보상 보너스로 넣으면 최적 정책이 바뀌고 운영자 습관이 가치 역전파에 섞인다, (ii) Bellman 목표에서 빼면 p̂의 오차가 Q로 새지 않는다, (iii) α_i = 0이 깨끗한 절제가 된다. 1스텝 결정론적 모델을 쓰는 이유는 다단계 상상이 16-DoF 손에서 오차를 누적시킨다는 관찰이다(근거 수치 없음).

### 2.4 하이퍼파라미터 (표 2)

잠재 256, 머리 2×512, Adam 1e-4, 배치 128, γ = 0.97, 시너지 차원 3, 잔차 스케일 (팔/시너지/손) = (1.5e-3, 0.25, 0.15), 재생 용량 (온라인/오프라인/개입) = (10k, 500, 5k). **actor와 비평가의 학습률, 업데이트-데이터 비율, 엔트로피 온도, 청크 길이, 이미지 인코더 구조는 표에 없다**(`04` C13).

## 3. 실험

### 3.1 설정 (4.1–4.4절, 부록 D, F)

- 하드웨어: Franka FR3 + 16-DoF LEAP Hand, 손목 D405와 3인칭 D435 RGB 두 대, RTX 4090 한 장.
- 과제 다섯 개: Pick Cube, Pick LEGO, Pick & Place, Pull Drawer, Long Horizon(서랍 열기, 물체 넣기, 닫기). 지평은 300/300/600/450/2100 스텝(표 3).
- 기준선 사다리: BC → ResFiT(개입 없음, 모델 없음) → Residual RL model-free(개입 인식 비평가) → WHIRL. 네 방법이 관측·행동 공간, 재생 버퍼, 시너지 잔차 파라미터화를 공유한다(부록 D). HIL-SERL과 SiLRI는 "핵심 메커니즘을 자체 구현"해 쓴 것이고 공개 코드로 돌린 것이 아니다.
- 운영자: 한 명이 모든 (과제, 방법) 칸을 진행하고 방법을 안다. 규칙은 두 경우에만 페달을 누르는 것이다. (i) 정책이 작업 공간 한계를 넘으려 할 때, (ii) 물체를 떨어뜨렸거나 잡기를 풀었는데 아직 잡을 수 있을 때. 사전 교정이나 자세 정리는 하지 않는다(부록 D).
- 시드: (과제, 방법) 칸마다 하나. 학습 예산은 선택·서랍 약 8k 스텝, Long Horizon 약 50k 스텝(부록 D, F).
- 성공률(표 1): 페달을 끈 자율 평가. 운영자는 비상정지만 한다. 시간 초과, 떨어뜨림, 작업 공간 위반은 실패. 체크포인트는 "명목 예산에 가장 가까운 것"(4.4절, 부록 D).

### 3.2 표 1 (성공 수 / 시행 수)

| 과제 | BC | ResFiT | Residual RL | WHIRL |
|---|---|---|---|---|
| Pick Cube | 20/30 | 25/30 | 25/30 | 30/30 |
| Pick LEGO | 19/30 | 24/30 | 23/30 | 29/30 |
| Pick & Place | 13/30 | 19/30 | 18/30 | 27/30 |
| Pull Drawer | 11/20 | 14/20 | 15/20 | 19/20 |

부록 D 통계: WHIRL의 Wilson 95% 구간 [89,100], [83,99], [74,97], [76,99], [64,95]%. WHIRL 대 Residual RL의 비수정 단측 Fisher p = 0.026, 0.026, 0.008, 0.091, 0.078. 모두 재계산과 소수 셋째 자리까지 일치한다(`03` V2, V3).

### 3.3 개입 부담 (그림 5, 6, 7)

- 지표: 5-에피소드 굴림, 스텝 가중 개입 비율 ρ_k = Σu_i / ΣT_i(4.3절).
- 본문 수치: Pull Drawer에서 기준선 0.113 → WHIRL 0.018, 84% 감소(4.5절 Q2). 초록과 결론의 "최대 84%"는 이 값이다. 결론은 이를 "운영자 제어 학습 스텝 감소"로 적는다.
- 그림 6(Pick LEGO, Pull Drawer): w/o WM, α_i = 0, 전체 WHIRL의 세 곡선. 전체가 가장 먼저 0 근처에 닿고 α_i = 0이 중간, w/o WM이 가장 늦다. 저자는 Pull Drawer에서 초반에 "잠깐 비용"이 있다고 쓴다.
- 그림 7(부록 E): 에피소드별 u_i/T_i. 같은 방향이고 더 거칠다.

## 4. 이 글이 확인한 것과 남는 질문 (요약)

세부 수치는 `03`, 주장 판정은 `04`에 있다.

1. **Table 1의 산수와 부록 D 통계는 재계산과 일치합니다.** 백분율, Wilson 구간, Fisher p 다섯 개 모두 맞습니다(`03` V1–V3).
2. **"가장 강한 기준선" 대비는 다릅니다.** 본문은 Residual RL을 가장 강한 기준선이라 부르지만 Pick LEGO, Pick & Place, Long Horizon에서는 ResFiT가 1–2회 더 높습니다. ResFiT 대비 단측 p는 LEGO 0.051, P&P 0.015, LH 0.137, Drawer 0.046입니다(`03` V3, V5).
3. **통계의 단위는 롤아웃이고 시드는 하나입니다.** 4.4절이 밝히듯 칸마다 시드와 운영자가 하나이므로 Fisher p는 "그 체크포인트의 N번 굴림"의 표본 오차만 담습니다. 시드 SD가 0.10이면 두 방법이 같아도 N = 30에서 단측 p < 0.05가 약 12%로 늘어납니다(시드 SD 가정, `03` 토이 1).
4. **84%는 마지막 굴림 값 하나의 비율입니다.** 그림 5 판독 값에서 Pull Drawer의 마지막 마커는 기준선 0.047, WHIRL 0.000이고, 본문의 0.113과 0.018에 해당하는 마지막 점은 보이지 않습니다. 곡선 아래 면적(누적 개입량 대용)으로 보면 Pull Drawer는 공통 구간에서 약 3% 감소이고 나머지 네 과제는 31–37%입니다(그림 판독 값, `03` V7, V8).
5. **그림 5와 6의 같은 조건 곡선이 다릅니다.** Pull Drawer의 w/o WM 곡선은 그림 5에서 7686 스텝에 끝나고 그림 6에서 9393 스텝에 끝납니다. 평균 절대 차이 0.13입니다(그림 판독 값, `03` V9).
6. **개입 머리는 운영자의 두 가지 규칙(작업 공간 한계, 떨어뜨림)을 라벨로 받습니다.** 작업 공간 한계는 표 3에 이미 수치로 있어, 머리가 새 정보를 주는지는 이 실험만으로 가를 수 없습니다(`04` C7, C8).
7. **식 (4)와 식 (12)의 다음 상태 행동 인자가 다릅니다.** 상상 목표는 다음 상태 잠재에 현재 스텝의 행동을 넣고, 실제 전환의 목표는 다음 상태의 행동을 씁니다. 모델이 잠재만 예측해 다음 상태의 사전 행동을 만들 수 없기 때문일 가능성이 있으나 본문에 설명이 없습니다(`04` C24).

## 5. 저자가 적은 한계와 그 해석 (5절, 부록 D)

- 구역 안 일반화(물체 위치, 접근 오프셋, 손잡이 위치)만 본다. 새 물체, 배치, 손 안 조작은 아니다.
- 한 시드, 한 운영자. 운영자가 방법을 안다(부록 D가 규칙을 고정해 이를 줄인다고 설명).
- Pull Drawer와 Long Horizon의 성공 차이는 "시사적" 수준(p ≈ 0.08–0.09).
- 개입 머리는 운영자의 개입 문턱과 습관을 물려받는다.
