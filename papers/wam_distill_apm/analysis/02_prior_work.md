# 02. 선행연구

## 1. 계보

**WAM(World Action Model)과 교사.**
- 원류 개념: 영상과 행동을 함께 예측하는 로봇 정책. 이 논문의 소개가 인용하는 것은 Unified World Models [46](영상·행동 결합 확산, RSS 2025), World Action Models are zero-shot policies [36](arXiv:2602.15922), LingBot-VA [17](arXiv:2601.21998, 이 논문의 교사이자 기반).
- 효율화 방향: 배포 때 영상 생성을 없앰(Fast-WAM [40], arXiv:2603.16666), 잠재 부표(latent subgoal) 사용(LaWAM [5], arXiv:2606.15768), 경량 백본(Efficient-WAM [16], arXiv:2606.10040; Light-WAM [19], arXiv:2606.08242), 이미지 편집 특징 사용(ImageWAM [42], arXiv:2606.19531).

**몇 단계 증류(distillation)의 계보.** 이 논문이 쓰는 도구는 다음 계보에 있습니다.
- 점진 증류: Progressive distillation [28]. 교사 두 단계를 학생 한 단계로 압축.
- 일관성 모델: Consistency models [30], Consistency trajectory models [14], LCM [24]. 궤적 위의 점을 같은 끝점으로 보내는 목표.
- 흐름 맵(flow map): Flow map matching [4], Align your flow [27], MeanFlow [10] (평균 속도로 유한 구간 전이를 모수화), Shortcut models [9] (단계 조건 예측).
- 비디오 확산 증류: AnyFlow [11] (임의 단계 비디오 증류, 온폴리시 흐름 맵 증류). 이 논문의 **단계 I 기반**입니다.
- 분포 정합: DMD [37, 38], SiD [44], ADD [29].
- 궤적 교정: Rectified flow [22], InstaFlow [23], PeRFlow [34], TRACT [2].

**상태 분포 불일치 대응.** 이 논문의 주장(학생이 간 상태에서 감독)은 다음과 가깝습니다.
- Self Forcing [12]: 자기회귀 비디오 생성에서 학습 시 학생 생성 이력을 사용.
- WAM-OPD (Yang 외) [35]: 영상과 행동 함께 감독의 온폴리시 후학습.
- WAM-OPD (Liu 외) [21]: 재생된 이력 아래 새 디노이징 경로를 만들고 실행 인지 속도 감독.
- FlowMap-OPD [18], FastOPD [26], DanceOPD [45], 교사 속도 회귀 [45]·경로 예측 교정 [31].
- 기울기 충돌: PCGrad [39](충돌 성분 제거, 대칭), CAGrad [20](평균 하강과 국소 과제 개선의 균형), GradNorm [7], 불확실성 가중 [13].

## 2. 가까운 대안 (직접 경쟁하는 WAM 증류)

| 방법 | arXiv | 핵심 아이디어 | 이 논문과의 관계 |
|---|---|---|---|
| Flash-WAM [1] (Akbari 외) | 2606.05254 | 영상과 행동의 잡음 체계에 맞춘 일관성 학습, 모달리티 인지 증류 | 직접 비교 대상. 1단계 값은 DirectWAM [43] 보고값 (78.2%), 2·4단계는 저자 로컬 실행 |
| AnyStep-WAM [32] (Wang 외) | 2609.33748 | 예산 정렬 전이와 미리보기 복구 | 같은 목표(예산 여러 개)를 다른 방식으로 푼 방법. 이 논문은 AnyStep의 "별도 끝점 손실"이 학생 상태가 아닌 교사 궤적 상태에서 계산된다고 지적 |
| RealtimeWAM [25] (Lv 외) | 2610.06617 | 교사 끝점 목표를 행동 일관성 학습에 넣음, 영상 조건 고정 | 끝점 감독은 같지만, 이 논문은 같은 학생 상태에서 지역 전이를 함께 맞춘다는 점이 다름 |
| WAM-OPD [35], [21] | 2608.22364, 2609.34250 | 온폴리시 후학습 | 학생 이력 사용은 공통. 이 논문은 증류 후 **동결 기반 + 어댑터** 보정 |
| DirectWAM / De-diffusing WAMs [43] | 2610.28122 | 행동 충분 직접 예측 | 1단계 Flash-WAM 수치의 출처 |
| Fast-WAM [40] | 2603.16666 | 테스트 시 미래 상상 제거 | 다른 축(상상 자체를 없앰). 이 논문은 상상을 남기고 단계 수를 줄임 |

## 4. 구성 요소별 출처

| 구성 요소 | 출처 (논문 인용) | 비고 |
|---|---|---|
| 유한 구간 전이 맵과 AnyFlow식 증류(단계 I) | AnyFlow [11] | 기반 |
| 학생 상태 샘플링(접두 상태, detach) | 명시적 인용 없음 | 학생 이력 학습(Self Forcing [12], WAM-OPD [21, 35])과 가까움 |
| 복원 앵커(교사 끝점을 같은 상태에서) | 명시적 인용 없음 | 일관성 궤적(consistency trajectory [14])과 비슷한 목표 |
| 지역 전이 목표(교사 첫 단계) | 흐름 맵·평균 속도 [4, 10, 27] | 식 (7)–(8). 공식 코드는 순간 방향장으로 구현(`04` D1) |
| 모달리티별 한쪽 투영 | PCGrad [39], CAGrad [20] | 충돌 성분 제거를 한쪽 기준으로 바꾼 것. 두 방법과 비교 없음 |
| Beta(5, 2) 상태 샘플링 | 명시적 인용 없음 | 낮은 잡음 쪽 편향. 근거 실험 없음 |
| 예산 간 가중치 공유 | 명시적 인용 없음 | 단일 체크포인트 |
| 기반 동결 + 모달리티 어댑터 | LoRA(인용 없음) | 학습 가능 파라미터 수를 Continued와 맞춤 |

## 5. 확인하지 않은 것

- 인용된 논문 [1], [25], [32]의 원문은 이번에 읽지 않았습니다. 표 값은 이 논문이 옮긴 것을 그대로 썼습니다.
- Hugging Face에서 찾은 모델 카드와 프로젝트 페이지의 "Stage I EMA4000" 기준선의 정의는 이 논문과 같은 것인지 확인하지 않았습니다.
