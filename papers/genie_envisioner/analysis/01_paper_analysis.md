## 1. 문제 설정과 한 줄 요약

- 로봇 조작의 감지, 정책 학습, 평가를 **하나의 영상 생성 세계모델**로 묶으려는 플랫폼 논문입니다 (§1, Figure 1).
- 구성 요소는 네 가지입니다.
  - **GE-Base** (§2): 지시문과 초기 관측으로 다시점(머리, 좌·우 손목) 영상 청크를 자기회귀로 생성하는 DiT. 백본은 LTX-Video 2B (기본)와 Cosmos2 2B (§2.1).
  - **GE-Act** (§3): GE-Base에 병렬 행동 분기 (약 160M 파라미터, 동일 깊이, 축소 은닉 차원)를 붙여 flow matching으로 14자유도 행동 청크를 냅니다.
  - **GE-Sim** (§5): 행동 조건부 영상 시뮬레이터. 포즈를 영상 위에 그리는 pose2image 조건과 모션 델타 조건을 씁니다.
  - **EWMBench** (§6): 장면 일관성, 행동 궤적 품질, 의미 정렬을 재는 평가 묶음.
- 핵심 주장은 세 가지입니다: (a) 대규모 실로봇 영상 사전학습이 행동 정책에 도움이 된다 (Table 1), (b) 적은 시연 (약 1시간, 250회)으로 새 구현체에 옮겨진다 (§4), (c) 생성 영상 기반 시뮬레이션과 EWMBench가 사람 선호와 맞는다 (§6.5, Figure 18).

## 2. 방법 (GE-Base, GE-Act, GE-Sim)

### 2.1 GE-Base (§2.1–2.3)
- 수식: $\hat x^{(t)}_{1:N} = W(\hat x_{0:t-1}, x_0, q)$. 희소 메모리 (과거 프레임 4장을 무작위 샘플, 학습 중 증강)를 조건에 넣습니다.
- 다시점 처리: 각 시점의 토큰에 2D 회전 위치 임베딩과 시점별 학습 임베딩을 더하고, 일부 DiT 블록에서만 시점 간 교차 자기주의를 씁니다 (§2.1, Figure 3b). 계산량을 줄이려는 설계입니다.
- 지시문은 **동결된** T5-XXL 인코더로 임베딩하고 교차 주의로 넣습니다 (§2.1).
- 학습 단계 (§2.2):
  - Stage I (GE-Base-MR): 57프레임 클립, 3–30 Hz 무작위 샘플링, 잠재 8프레임. 32 A100 x 약 7일.
  - Stage II (GE-Base-LF): 9프레임 클립, 5 Hz 고정, 잠재 2프레임. 메모리 4프레임. 32 A100 x 약 3일.
  - 데이터: AgiBot-World-Beta, "약 100만 에피소드, 2,967시간" (§2.2).

### 2.2 GE-Act (§3.1–3.4)
- 행동 분기는 GE-Base와 블록 수를 맞추고 은닉 차원을 줄입니다. 행동 토큰은 교차 주의로 영상 은닉 상태를 읽습니다 (식 $a_i = B^{act}_i(z_{act}, \mathrm{CrossAttn}(z_{act}, v_i))$).
- 행동 표현: 팔마다 7차원 [x, y, z, roll, pitch, yaw, gripper], 두 팔 합쳐 14차원, 54스텝 (30 Hz) (§5.1, §3.2).
- 학습 (§3.2): 행동 사전학습 (영상 생성은 끄고, 메모리 4프레임 at 5 Hz 조건, 행동 54스텝 예측, 16 A100 x 약 3일), 작업별 영상 적응 (8 A100 x 약 12시간, 전체 AgiBot 말뭉치 + 작업 데이터 10배 가중), 작업별 행동 특화 (8 A100 x 약 36시간).
- 비동기 추론 (§3.3): 영상 DiT는 5 Hz에서 **단 한 번** 흐름 디노이징하고 은닉을 캐시합니다. 행동 모델은 같은 캐시를 써서 **5번** 디노이징합니다. 이 비율은 1:6 (5 Hz 대 30 Hz)입니다. 54스텝 추론을 RTX 4090에서 200 ms로 주장합니다.

### 2.3 GE-Sim (§5)
- 행동 조건: (i) pose2image, 팔 끝 위치를 카메라 내부·외부 파라미터로 영상 평면에 투영하고, 과거 프레임 임베딩과 더함 (식 1); (ii) 모션 델타 $\Delta a_i$를 토큰으로 바꿔 교차 주의로 주입 (식 2).
- 기준 영상은 **동결 CLIP** 이미지 인코더로 임베딩해 스타일 앵커로 씁니다 (§5, §5.2).
- 학습: GE-Base-MR에서 시작, AgiBot-World-Beta 전체와 실패 궤적 (오류 실행, 불완전 동작, 나쁜 제어 궤적) 증강. 흐름 매칭 손실 (§5.2).
- 폐루프 (§5.4): 정책 → 행동 → GE-Sim 영상 → 정책 반복.

## 4. 주장과 근거의 간격 (요약)

자세한 검사는 `04_code_verification.md`와 `03_analysis.md`에 있습니다. 여기서는 논문 안에서 보이는 간격만 적습니다.

1. **"torque trajectories" (§1, 초록 아래)** 와 본문 "7차원 pose + gripper" (§5.1) 가 다릅니다. 실제 행동은 EEF 자세 델타이고 토크가 아닙니다 (`04` D2).
2. **Table 1 해석.** 본문은 "scratch 또는 일반 영상 모델 적응은 거의 0"이라고 씁니다. 그런데 표의 (✗,✗) 행은 E2E 0.15와 0.30이고 SR 0.05와 0.11입니다. "거의 0"은 (✗,✓) 행에만 맞습니다 (`03` §2).
3. **"일반 영상 사전학습" 대 "in-domain 사전학습" 용어.** 표에는 `VidAW` (GE-Base 초기화)와 `VidAda` (작업 영상 적응)만 있습니다. 본문의 "general video pretraining"이 어느 행인지 표에서 확정할 수 없습니다.
4. **Figure 8의 "consistently outperforms"** 는 Packing detergent 작업에서 GE-Act Slow가 π0보다 낮다는 근사값과 맞지 않습니다 (SR 약 0.25 대 0.50, E2E 약 0.45 대 0.80). Fast 모드만 우세합니다 (`03` §3).
5. **시도 횟수가 어디에도 없습니다.** SR과 E2E 모든 값에 n이 없어서 신뢰구간과 검정이 불가능합니다. 가정한 n에 따른 민감도만 계산했습니다 (`03` §2, §3).
6. **데이터 규모.** 2,967시간과 약 100만 에피소드를 나누면 에피소드당 약 10.7초입니다. 같은 논문의 "250회 = 약 1시간"과 맞습니다 (14.4초). "약 100만"을 의미하는 근사값으로 볼 수 있습니다.
7. **GE-Sim의 CLIP 기준 영상과 교차 시점 조건** 은 논문에만 있고 공식 저장소에서 찾지 못했습니다 (`04` D4).

## 5. 재현 관점에서 본 논문 (분석 요약)

- 학습 자원: GE-Base 약 7,680 A100-시간 (영상 단계 두 개 합), GE-Act 단계 약 1,536 A100-시간 (`03` §4). 이 맥 (MPS, CUDA 없음)에서는 재현할 수 없습니다.
- 추론: 가중치 (GE-Base fast, GE-Sim cosmos) 는 공개되어 있습니다. 실로봇 GE-Act 가중치는 저장소에서 찾지 못했습니다 (`04` §0).
- 평가: EWMBench는 별도 저장소에 있습니다 (`02` GitHub 표). 이 논문의 Qwen2.5-VL, GPT 기반 판정 (§6.2) 은 API 호출이 필요합니다.
