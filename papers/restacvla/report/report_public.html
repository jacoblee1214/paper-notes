핵심 요약

  1. 무엇을 하는가: π0.5에 촉각을 넣되, 원시 촉각 대신 "손목 영상으로 예측한 촉각 잠재와 실제 촉각 잠재의 차이"(잔차)를 VQ로 이산화해 action expert에 토큰 하나로 붙인다. 시각 예측의 불확실성 σ로 그 토큰의 세기를 조절한다(Eq. 1–4).
  2. 표는 정수로 맞지만 헤드라인은 부풀려져 있다: "최대 86.7% task success"는 Peg-in-Hole의 정렬 칸이다(완료 기준 최고 80.0). "+34.6%"는 π0.5 대비 pp다. Peg Transfer에서는 T-UniT가 더 높아(66.7 대 60.0) "모든 과제에서 앞선다"가 논문 표와 어긋난다.
  3. 최강 기준선과는 합산해야 구분된다: π0.5 대비 5과제 합산 p = 4.7×10⁻⁷로 확실하다. 같은 UniT 인코더를 쓴 T-UniT 대비로는 과제별로 유의한 차이가 없고(p = 0.088–1.0), 합산 p = 0.004다.
  4. 이득은 주로 정렬 단계에서 나온다: T-UniT 대비 완료 성공 이득의 74%(log)가 정렬 성공률 차이다. 정렬 뒤 완료율 P(I|A) 차이는 p = 0.28이다.
  5. 게이트는 surprise가 아니라 영상 기반 접촉 국면 검출기다: Eq. 1의 최적 σ는 손목 영상만의 함수다. Fig. 5에서 g가 접촉 전부터 오르는 것도 이와 맞다. toy에서 σ 게이트는 시각에 보이지 않는 충돌을 0% 열었고, 예측 오차를 넣으면 100%가 됐다.
  6. 잔차의 효과는 분리되지 않았다: 잔차 대 원시 ablation이 없고, 연속 잔차(w/o VQ 33.3)가 같은 두 과제의 T-UniT(32.7)와 같다. toy에서 잔차는 "시각 차원 ≫ 데이터, 정확한 CMP, 높은 ρ²"일 때만 이기고(25–38%), CMP를 정책 데이터로 학습하면 진다.
  7. 강건성 표는 교란 전 차이를 보여 준다: 교란에 따른 하락폭이 세 방법에서 같다(Dynamic 모두 −13.3pp, Height− 모두 −20.0pp).
  8. 구현 가능성: 코드·데이터 미공개라 공식 재현은 불가능하다. 아이디어는 수백 줄로 옮길 수 있다. 장벽은 GelSight 하드웨어와 촉각 시연, π0.5 미세조정용 24 GB급 CUDA GPU다. 이 맥에서는 재계산·toy를 끝냈고, CMP 단독 학습은 torch 설치와 데이터가 있으면 MPS로 가능해 보인다.

1. Abstract: 무엇을 주장하나

VLA에 촉각을 그냥 넣으면 고대역 시각 특징이 희소한 촉각 신호를 덮는 "modality collapse"가 생긴다고 봅니다(Sec. I, [9]). 저자들은 뇌가 예측 가능한 입력을 약화하고 예측에서 벗어난 자극(surprise)에 집중한다는 predictive coding [12–15]에서 착안했습니다.

  1. 촉각을 원시 입력 대신 잔차 촉각 표현 r_t = z_t − ẑ_t로 바꿉니다. 손목 영상으로 예측한 촉각 잠재와 실제 촉각 잠재의 차이입니다.
  2. 잔차를 VQ 병목으로 이산화해 Latent Contact Primitive를 만듭니다.
  3. 시각 예측의 불확실성 σ_t로 촉각 주입을 조절하는 **Surprise-Aware Gate(SAG)**를 둡니다.

주장은 세 가지입니다. 다섯 실물 과제에서 모든 기준선을 일관되게 앞서고, 예상 밖의 동적 교란에 강건하며, "최대 86.7% task success, 평균 34.6% 향상"입니다(Abstract, Sec. I 기여 3).

2. Method

2.1 문제 설정 (Sec. III 첫 문단)

관측은 O_t = {V_base, V_side, V_wrist, I_tac, s_t}이고 s_t ∈ R⁷는 고유 감각입니다. 정책 π(A_t | O_t, L)은 길이 H의 행동 chunk를 냅니다. 바탕 모델은 π0.5 [2]입니다. PaliGemma VLM [27]이 영상·지시·상태를 인코딩하고, action expert가 조건부 flow matching [26]으로 행동을 생성합니다(Sec. III-A).

2.2 Cross-Modal Predictor (Sec. III-B-1, Eq. 1)

  • 손목 영상 V_wrist → 학습 가능한 ResNet-18 + MLP → 평균 μ_t ∈ R^{3×H′×W′}와 스칼라 표준편차 σ_t ∈ R를 냅니다. 둘은 예측 촉각 잠재 ẑ_t의 가우시안을 정의합니다.
  • 실제 촉각 영상 I_tac는 UniT [21] 기반 촉각 인코더가 같은 공간의 z_t로 보냅니다. UniT는 VQVAE 기반 촉각 표현입니다.
  • 잔차는 r_t = z_t − ẑ_t입니다. ẑ_t가 μ_t인지 표본인지는 적혀 있지 않습니다.
  • 손실은 가중 NLL [28]입니다: L_pred = λ_σ log σ_t² + ‖z_t − μ_t‖² / σ_t² (Eq. 1). λ_σ는 "불확실성 붕괴"를 막는 가중치입니다.
  • 논문은 "σ_t가 cross-modal surprise의 원리적 척도"라고 씁니다. 하지만 Eq. 1이 학습하는 σ_t는 Kendall & Gal [28]의 aleatoric 불확실성이고, 손목 영상만의 함수입니다. 실제 촉각이 예측에서 얼마나 벗어났는지(예측 오차)는 σ_t에 들어가지 않습니다(03 §2).

2.3 Latent Contact Primitive (Sec. III-B-2, Eq. 2)

  • event encoder f_φ(conv residual block + global max pooling)가 r_t를 전역 사건 벡터 h_t ∈ R^D로 줄입니다.
  • VQ [29] 코드북 C = {c_k}로 h_t를 q_t로 이산화합니다. 코드북 붕괴를 막으려고 네 가지를 씁니다: 저차원 코드 [30], 코사인 유사도 [30], EMA 갱신 [31], 비활성 코드 재초기화 [32].
  • 복원 경로: q_t가 FiLM [33]으로 예측 사전 ẑ_t를 변조해 z̃_t를 만들고, decoder가 촉각 영상 Î_t로 되돌립니다.
  • CMP 전체 손실은 L_CMP = L_rec + λ_p L_pred + L_vq입니다(Eq. 2). L_rec는 촉각 영상 MSE입니다.
  • 정보 관점: q_t는 코드북 index 하나라서 프레임당 많아야 log₂K 비트입니다. 정책이 받는 촉각 정보는 모두 이 index를 거칩니다. K와 D는 논문에 없습니다.

2.4 Surprise-Aware Gate와 정책 주입 (Sec. III-C, Eq. 3–4)

  • g_t = Sigmoid(MLP(σ_t)) (Eq. 3). 입력은 스칼라 σ_t 하나입니다.
  • q_t를 선형층으로 p_t ∈ R^d에 투영하고, 학습되는 "접촉 없음" 토큰 e_0와 섞습니다: e_t = g_t p_t + (1 − g_t) e_0 (Eq. 4).
  • e_t는 VLM 쪽이 아니라 action expert의 noise 토큰 옆에 이어 붙입니다. VLM의 사전학습 표현을 해치지 않으려는 선택입니다.
  • 정책이 촉각을 받는 경로는 이 토큰 하나뿐입니다. g_t → 0이면 e_t → e_0가 되어 정책은 촉각을 보지 못합니다.

2.5 학습 순서 (Sec. III-A, III-C)

  1. CMP를 여러 과제의 상호작용 데이터로 따로 사전학습합니다.
  2. CMP를 고정하고 촉각 확장 정책 전체를 flow matching으로 end-to-end 미세조정합니다. 게이트 MLP와 투영층도 이때 학습되므로, 게이트는 surprise를 직접 감독받지 않고 행동 손실만으로 배웁니다.

CMP 학습 데이터가 정책 데이터와 같은지는 적혀 있지 않습니다. 같다면 학습 중 잔차가 시험 때보다 작아지는 분포 차이가 생길 수 있습니다(03 §3).

3. Experiments

3.1 설정 (Sec. IV-A)

  • 플랫폼: Franka Research 3 + Robotiq 2F-85. GelSight Mini 하나를 한쪽 손가락에만 달았습니다. RealSense D435 세 대(정면, 측면, 손목)와 RTX 4090 워크스테이션 하나로 수집과 평가를 했습니다.
  • 과제 다섯 개: Lightbulb Screwing, Plug Insertion, Peg-in-Hole, Peg Transfer, Plate Wiping(Fig. 3). 과제마다 시연은 약 100개이고, 작업자는 실시간 촉각 영상을 보면서 시연했습니다.
  • 평가 시행: Lightbulb·Plug는 25회, 나머지 셋은 15회("롤아웃이 길어서")입니다. Lightbulb·Plug·Peg-in-Hole은 정렬(A)과 완료(I) 두 단계로 나눠 씁니다.
  • 기준선 다섯 개: DP w/o T, DP w/ T-ResTac, π0.5 w/o T, π0.5 w/ T-ResNet(ResNet-18 촉각 인코더), π0.5 w/ T-UniT(사전학습 UniT 특징).
    • 기준선의 촉각 주입 위치(VLM 입력 / action expert)와 게이트 유무는 적혀 있지 않습니다.
    • T-UniT는 ResTacVLA와 같은 촉각 인코더를 쓰므로, 둘의 차이가 CMP 잔차 + VQ + 게이트 + 주입 방식 전체입니다.

3.2 Q1: 주요 결과 (Table I)

  • 평균 62.8%로 π0.5 28.2%보다 34.6, DP w/o T 18.8%보다 44.0 높다고 씁니다. 단위는 퍼센트포인트입니다.
  • 이 평균은 8칸 평균입니다. A와 I를 같은 무게로 섞고, 두 단계 과제를 두 번 셉니다. 과제 성공(최종 단계) 기준 5과제 평균은 ResTacVLA 58.4%, T-UniT 39.5%, π0.5 22.9%입니다(04 C3).
  • "최대 86.7% task success"는 Peg-in-Hole의 정렬(A) 칸입니다. 과제 완료 기준 최고값은 Peg-in-Hole I의 80.0%입니다(04 C1).
  • Peg Transfer에서는 T-UniT 66.7%(굵게)가 ResTacVLA 60.0%(밑줄)보다 높습니다. 논문 표 자신의 강조 표시로도 "모든 과제에서 앞선다"(Abstract, Sec. IV-B)는 성립하지 않습니다(04 C2).
  • T-ResNet이 Lightbulb에서 "성능을 떨어뜨린다"(28.0 → 16.0)는 A칸 7/25 대 4/25이고 Fisher p = 0.50입니다.
  • DP에 잔차 촉각을 넣으면 +19.2(38.0 대 18.8)입니다. DP w/ T-UniT 같은 "원시 촉각 DP" 칸이 없어서, 이 이득이 잔차 때문인지 촉각 자체 때문인지 가를 수 없습니다.

우리 분석: Table I의 과제 성공(최종 단계) 칸과 Wilson 95% 구간. 위 숫자는 ResTacVLA 대 T-UniT 과제별 Fisher p.

3.3 Q2: Ablation (Table II)

  • Plug Insertion과 Plate Wiping 두 과제의 평균만 보고합니다: Full 60.0, w/o VQ(연속 잔차) 33.3, w/o Gating(g = 1 고정) 46.7, π0.5 20.0.
  • 정성 설명: VQ가 없으면 "잦은 떨림과 파지 자세 민감도"가 생기고, 게이트가 없으면 "촉각 잡음과 초기 파지 오차로 궤적이 표류"합니다.
  • 잔차 대 원시 촉각을 직접 비교한 ablation은 없습니다. w/o VQ 33.3은 같은 두 과제의 T-UniT 평균 32.7과 거의 같습니다. VQ를 뺀 잔차 경로가 원시 UniT 특징보다 나은지 이 표로는 보이지 않습니다(04 C5).
  • 두 과제 평균(25회 + 15회)은 정수 조합이 여러 개라 과제별 값을 복원할 수 없습니다. 예를 들어 33.3은 (Plug, Wiping) = (0/25, 10/15), (5, 7), (10, 4), (15, 1) 중 하나입니다.

4. Limitations

논문에는 한계 절이 없습니다. 읽으면서 확인한 한계는 다음과 같습니다.

  1. 게이트가 예상 밖 사건을 볼 수 없는 구조입니다. g는 손목 영상만의 함수인 σ_t로 정해집니다. 그래서 영상으로 보이지 않는 자유 공간 충돌에서는 게이트가 닫힌 채로 남습니다. 제목의 "Feeling the Unexpected"와 Fig. 4의 "unexpected collision" 군집은 CMP 안의 표현이고, 정책까지 전달된다는 보장은 없습니다(03 §2, toy).
  2. 잔차의 기여가 분리되지 않았습니다. 잔차 대 원시 ablation이 없고, Table II는 두 과제 평균입니다.
  3. 통계 근거가 약합니다. 과제당 15–25회이고 시드, 반복, 신뢰구간이 없습니다. 최강 기준선 T-UniT와는 과제별로 유의한 차이가 하나도 없습니다(최소 Fisher p = 0.088). 다섯 과제를 합치면 CMH p = 0.004입니다.
  4. 이득이 대부분 정렬 단계에서 나옵니다. T-UniT 대비 완료 성공 이득의 74%(로그 배율)가 정렬 성공률 차이입니다. "촉각이 상호작용 단계에서 시각의 빈틈을 메운다"는 서술(Sec. IV-B)과 결이 다릅니다(03 §1).
  5. 하드웨어 범위가 좁습니다. GelSight Mini 하나, 한 손가락, 평행 그리퍼, 한 연구실 환경입니다.
  6. 재현 정보가 부족합니다. λ_σ, λ_p, K, D, H, 게이트 MLP, 학습 step, 기준선 조율 방법, 추론 지연이 없습니다.
  7. 해석 그림이 정성적입니다. Fig. 5는 시행 하나, Fig. 4는 정량 지표가 없습니다.

5. 한 줄 평가

"촉각을 시각 예측과의 차이로 표현하고, 접촉 국면에서만 주입한다"는 설계는 간단하고 옮기기 쉽습니다. 다만 논문의 증거는 ResTacVLA 전체가 π0.5보다 낫다까지만 보여 줍니다(5과제 합산 p < 10⁻⁶). 잔차·surprise라는 명명이 성능의 원인이라는 주장은 실험으로 분리되지 않았습니다. 게이트는 surprise 검출기라기보다 영상 기반 접촉 국면 검출기로 읽는 편이 정확합니다.

2. 게이트가 실제로 보는 것

2.1 Eq. 1의 최적해

손목 영상 v가 주어졌을 때 n = 3H′W′차원 잠재 z에 대해 기대 손실은 E[λ_σ log σ² + ‖z − μ‖²/σ² | v]입니다. 이를 최소화하면 다음을 얻습니다.

  • μ*(v) = E[z | v]
  • σ*(v)² = E[‖z − μ*(v)‖² | v] / λ_σ (σ²로 미분: λ_σ/σ² − E[‖·‖²|v]/σ⁴ = 0)

λ_σ = n이면 σ²가 차원당 분산이 되어 보정된 값이 됩니다. 다른 값이면 배율만 달라지고, 그 배율은 게이트 MLP가 흡수합니다. 핵심은 σ*가 v만의 함수라는 점입니다. 이 σ는 "이 영상에서 촉각이 얼마나 퍼져 있을지"(기대 불확실성, aleatoric)를 나타냅니다. 지금 들어온 촉각이 예측에서 얼마나 벗어났는지(예측 오차)와는 다른 양입니다. predictive coding의 surprise는 정밀도로 가중한 예측 오차 (z − μ)/σ이고, 실제 z가 있어야 계산됩니다.

결과적으로 g_t = Sigmoid(MLP(σ_t))는 다음 성질을 가집니다.

  1. 영상이 "접촉이 가까움"을 보이면 촉각이 실제로 어떻든 열립니다. Fig. 5에서 접촉 전(pre-contact)부터 0.35로 오르는 것과 맞습니다.
  2. 영상이 자유 공간처럼 보이면 예상 밖 충돌이 있어도 닫혀 있습니다. 예상 밖 사건이 가장 중요한 순간에 촉각 경로를 낮춥니다.
  3. Sigmoid는 0이 되지 않으므로 "차단"이 아니라 감쇠입니다. Fig. 5의 접근 단계 g ≈ 0.12는 p_t를 약 8배 줄인 것입니다. 정책이 이 신호를 다시 키워 쓸 수 있는지는 학습에 달렸습니다.

3. 잔차 대 원시 촉각

3.1 선형 재매개화라는 점

CMP가 고정된 함수 ẑ = f(v)이면 잔차 특징 [v, r] = [v, z − f(v)]는 원시 특징 [v, z]의 가역 변환입니다. 정책이 v와 z를 모두 받는다면 정보량은 같습니다(데이터 처리 부등식에서 등호). f가 선형이면 OLS 예측이 정확히 같습니다. toy에서 최대 차이는 6×10⁻¹³이었습니다.

그래서 잔차화의 이득은 다음 세 경로로만 생길 수 있습니다.

  1. 정규화·최적화의 귀납 편향. 모달리티별로 표준화하면 원시 z에서는 시각으로 예측되는 성분이 분산을 차지합니다. 그러면 촉각 고유 성분의 계수가 1/√(1 − ρ²)배로 커져야 하고, ridge나 weight decay가 이를 더 강하게 누릅니다.
  2. 정책이 f를 스스로 배우기 어려울 때. ResNet-18 CMP가 별도 데이터로 배운 f를 정책이 공짜로 받습니다.
  3. VQ 병목과의 결합. 원시 z를 K개 코드로 자르면 대부분의 비트가 예측 가능한 성분에 쓰입니다. 잔차를 자르면 비트가 예측 불가능한 성분에 갑니다(§5).

반대로 잔차가 손해인 경우도 있습니다. CMP가 정책 데이터와 같은 데이터로 학습되어 과적합하면, 학습 중 잔차는 작고 시험 중 잔차는 큽니다.

추가 검증 1: 행동 손실만으로 학습한 게이트는 드문 예상 밖 충돌을 여는가

목적. §2.2에서 σ 게이트가 예상 밖 충돌을 못 본다는 것을 확인했다. 여기서는 게이트를 행동 손실만으로 학습할 때(논문 Sec. III-C), 학습 데이터의 충돌 비율(1–20%)에 따라 충돌 구간에서 게이트가 열리는지, 보조 감독(게이트 라벨의 BCE)과 입력(σ만, σ와 예측 오차)을 바꾸면 달라지는지 본다.

설정. analysis/extra_gate_rare.py (numpy, 약 3분, 단일 스레드). gate_toy.py의 에피소드(200스텝, 접촉 시작 ≈120, 충돌은 접촉 전 20–90 스텝 사이 6스텝)와 CMP(분위수 구간 평균)를 그대로 썼다.

  • 게이트: g = Sigmoid(MLP(입력)), MLP는 2→4→1(tanh). 입력은 log σ(논문 Eq. 3) 또는 [log σ, log 예측 오차]. 입력은 학습 데이터로 표준화한다.
  • 정책: p = w₀ + w₁·v + w₂·g·‖z‖ + w₃·g·‖z‖·v. 처음에는 w₃ 항이 없었는데, 그때는 게이트를 완전히 열어도 충돌 구간 출력이 후퇴 쪽으로 내려가지 않아서 상호작용 항을 추가했다.

  • 학습: 에피소드 200개, Adam 800스텝, 학습률 0.03. 시험은 에피소드 200개이고 절반에 충돌을 넣었다. 시드 3개(표준편차를 표에 같이 적었다).

2. 가까운 대안

2.1 촉각·힘을 넣은 VLA·정책 (논문 Sec. II-C)

  • 촉각을 토큰으로 넣는 VLA: VLA-Touch [7], VTLA [8], TLA [19], Tactile-VLA [25]. 논문은 이들이 촉각을 "보조 시각 특징"으로 다뤄 modality collapse를 겪는다고 봅니다. 하지만 이 논문 표에 이들과의 직접 비교는 없습니다. 비교한 촉각 기준선은 π0.5 + ResNet·UniT 인코더 두 개입니다.
  • 언어로 정렬: Beyond Sight [6]은 이종 센서를 언어 grounding으로 미세조정합니다. VITaL·"Touch begins where vision ends" [22]은 대조 학습으로 촉각을 시각·언어 공간에 맞춥니다. 논문은 정렬이 촉각 고유의 잔차 정보를 지운다고 비판합니다(Sec. II-B).
  • 힘·토크: ForceVLA [23](힘 인지 MoE), TA-VLA [24](토크 인지 설계 공간). 손목 F/T는 접촉 기하를 잃는다는 이유로 촉각과 구분합니다.
  • 모달리티 불균형: Chaudhuri et al. [9](표현 붕괴), multi-modal policy consensus [10], ImplicitRDP [11].

2.2 논문이 인용하지 않은 가까운 연구

  • FoAR (He et al., arXiv:2411.15753, RA-L 2025)는 미래 접촉 예측기가 힘 특징의 주입을 조절합니다. "접촉 국면에서만 비시각 신호를 쓰는 gating"이라는 점에서 SAG와 가장 가까운 선행입니다. 다만 FoAR의 게이트는 시각과 힘 신호 둘 다에서 접촉을 예측합니다.
  • Reactive Diffusion Policy (Xue et al., arXiv:2503.02881)는 촉각·힘으로 빠른 루프를 따로 돌리는 slow-fast 구조입니다. ImplicitRDP [11]의 전작입니다.
  • Connecting Touch and Vision (Li et al., arXiv:1906.06322)는 위 §1 표에 적었습니다. 이 연구가 영상에서 촉각을 예측한 지 7년이 지났는데, 예측 오차 자체를 정책 입력으로 쓴 것이 ResTacVLA의 새 점입니다.
