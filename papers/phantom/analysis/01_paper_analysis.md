## 1. 문제와 주장

- **문제:** 로봇 데이터 수집은 느리고 비쌉니다. 사람 영상은 많지만 행동 레이블이 없고, 사람 팔은 로봇 팔과 외형이 다릅니다(서론, 1쪽).
- **주장 (서론 마지막 문단과 초록):** RGBD 카메라로 찍은 사람의 핀치 잡기 시연을 **로봇 데이터 없이** 학습 데이터로 바꿀 수 있고, 그 정책을 **추가 학습 없이** 실로봇에 배포하면 최대 **92%** 성공한다(표 1). 장면을 바꾼 환경에서도 동작한다(표 2).
- **기여 (서론):** 데이터 편집 기법(RoviAug 계열)을 사람 대 로봇 전이에 옮긴 것. 새로운 것은 **행동 레이블을 사람 손 자세 추정으로 만드는 파이프라인과 결합**한 점입니다.

## 2. 방법

### 2.1 문제 설정 (3.1절)

- 입력: 제3자 시점 RGBD 영상의 사람 시연 N개. 시연은 엄지와 검지로 하는 핀치 잡기만 씁니다.
- 출력: 로봇 관측-행동 쌍 `I_h,t → (I_r,t, a_r,t)`, 행동 `a = (p, R6D, g)`.
- 가정: 배포 카메라의 외부 파라미터를 안다(3.1절 끝). 데이터 수집 카메라는 배포 카메라와 비슷한 시점.

### 2.2 행동 레이블 만들기 (3.2절, 그림 3)

1. **HaMeR**로 프레임별 손 키포인트 21개와 메시 778개 정점을 추정합니다(단안 RGB, 절대 위치는 부정확).
2. **SAM2**로 손 마스크를 만들고 깊이로 부분 점군을 얻습니다.
3. **ICP**로 HaMeR 메시를 점군에 맞춰 강체 변환 `T_t`를 얻고, 키포인트에 적용합니다.
4. 손가락 마지막 두 관절(엄지, 검지)을 **자유도 1로 제한**해 가려짐에서의 비현실적 자세를 줄입니다(3.2절). 
5. 위치 `p_t` = 엄지 끝과 검지 끝의 중점. 방향 `R_t` = 손가락 키포인트에 맞춘 평면 법선과 엄지 주축. 개폐 `g_t` = 두 끝 사이 거리, 하위 20% 백분위 값은 완전히 닫힘으로 둡니다(슬립 완화).
6. 카메라 좌표계의 결과를 **알려진 외부 파라미터로 로봇 좌표계로 옮깁니다.**

### 2.3 시각 영역 차이 줄이기 (3.3절, 그림 2)

- **학습 시:** SAM2로 사람 팔 마스크를 만들고 **E2FGVI**로 인페인팅합니다. 목표 로봇(MuJoCo Menagerie 모델)을 추정한 엔드이펙터 자세로 렌더링하고, 깊이로 가려짐(occlusion)을 처리해 덧씌웁니다.
- **배포 시:** 실제 로봇 위에도 **가상 로봇을 덧씌워** 학습 영상과 같은 분포로 맞춥니다(추론 시 오버레이). 색과 질감 차이를 학습 증강으로 흡수하는 RoviAug 방식 대신 이 방법을 택했습니다(3.3절).

### 2.4 정책

- Diffusion Policy (DDIM, 학습 100 스텝, 추론 10 스텝). 관측 2, 행동 8, 영상 해상도 240, 배치 200(Kinova는 256), 학습률 1e-4, 증강 RandomCrop·RandomRotation·ColorJitter (표 8).
- 로봇별 저수준 제어: Franka는 OSC, Kinova는 IK (4절 서두).

### 3.1 주요 결과 해석 (논문의 주장)

- **Hand Inpaint(Phantom)와 Hand Mask는 비슷합니다.** 본문은 Hand Mask가 rollout이 평균 73% 길다고 적고, 이를 Hand Inpaint 선택의 이유로 듭니다(4.2, 4.3절). 시간 수치는 측정 자료가 없습니다.
- **Red Line(EgoMimic의 데이터 편집)과 Vanilla는 모든 과제에서 0입니다** (표 1). 논문은 이를 "시각 차이가 크다"로 설명하며 EgoMimic의 전체 방법(로봇 데이터 포함)은 비교하지 않았습니다(부록 6.1).
- **인페인팅 품질:** 마스크만 두면 24 %p 떨어진다고 하지만(표 3), 이 차이는 p=0.11입니다.
- **공동 학습:** 로봇 데이터만 있으면 새 장면에서 0%, 사람 영상 950개를 더하면 80%입니다(표 5). 논문에서 가장 강한 결과입니다.
- **사람 대 로봇:** 같은 장면에서 사람 시연 50, 100개는 로봇 시연보다 낮지만 p>0.05이므로 "차이 없음"이라고 쓰지 않고 "유의하지 않음"이라고 해야 합니다. 논문은 이 차이를 "작다"고 읽습니다(6.4절).

## 4. 한계 (6절과 본문)

1. 행동은 손 자세 추정 정확도의 한계를 그대로 물려받습니다(가려짐 포함).
2. 사람이 하는 전략을 로봇이 똑같이 따라 할 수 있어야 합니다. 로봇이 사람 손이 피하는 곳에서 충돌할 수 있습니다. 사람 손가락과 평행 잡기의 표면 특성 차이로 물체 움직임도 다를 수 있습니다.
3. **핀치 잡기만** 다룹니다(평행 턱 그리퍼 한계).
4. **준정적 과제만** 다룹니다. 사람과 로봇 사이의 지연 차이는 다루지 않았습니다.
5. 본문에 명시되지 않은 것: 외부 파라미터를 모르는 경우(v1 표 VIII에서는 증강으로 보완), 조명과 장면 변화에 대한 정량 평가, 실험 시간, 한 과제 시연 수의 장면별 분포(4.3절의 "훈련 데이터의 80%가 실내"는 수치 자료가 없음).

## 5. 주장과 근거의 간격 (요약, 세부는 `03` §4)

- **확실한 것:** 로봇 데이터 없이 사람 영상만으로 한 장면에서 여러 과제 성공(표 1), 공동 학습 효과(표 5), 레드라인 방식의 실패(표 1).
- **방향만 맞는 것:** Hand Inpaint 대 Hand Mask, 인페인팅 품질 차이, 증강 효과. 모두 25회 기준으로 유의하지 않습니다.
- **근거가 약한 것:** "사람 데이터로 로봇과 격차가 좁아진다"(표 6의 비유의 결과를 차이 없음으로 읽음), "zero-shot"(추론 시 가상 로봇 덧씌우기와 외부 파라미터 가정이 필요함), "Hand Mask 73% 느림"(측정치 미공개).
