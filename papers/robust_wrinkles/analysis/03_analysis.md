# 03. 수치 재계산, 일관성 검사, 토이 실험

논문 값은 arXiv v1 본문 표 1과 부록 F의 표 2, 3에서 옮겼고, 코드에서 읽은 설정(horizon, dt)은 공식 저장소 커밋 `77e82b4`의 정적 읽기입니다. 재계산 스크립트는 `analysis/recompute.py`(결과 `recompute_results.json`), 토이는 `toy_cp_coverage.py`, `toy_scan_riccati.py`입니다. 재현 실험(공식 코드 실행, 학습, 데이터 다운로드)은 하지 않았습니다.

## 0. 가정

- **표 1의 시도 수, 시드 수, ±의 정의가 논문에 없습니다.** 그래서 ±를 표준편차(SD)로 보고, 검정은 n = 5, 10, 30, 100 가정별로 Welch t를 계산해 민감도로 보입니다. n이 모르는 값이므로 p 값은 "n이 이 정도라면"의 조건부 값입니다.
- 표 3의 ±도 SD로 보며, 검증 분할이 30%이므로 잔차 모델 행은 n = 30, 기본 시뮬 행은 n = 100 또는 30으로 봅니다(논문이 어느 쪽인지 밝히지 않음).
- 부록 B의 하드웨어 교정 100개 제어와 부록 F의 100개 하드웨어 표본이 같은 데이터인지는 논문에 없습니다(둘 다 "100개 무작위 동작"). V7은 "같은 데이터라면"의 조건부 검사입니다.

| 과제 (상태 차원) | Ours 단계당 | 실시간 계수 | MPPI 평가 횟수 비 | MPPI 시간 비 | MPPI 실시간 계수 |

### 1.3 안전율 값의 정수 가능성 (V3)

안전율이 에피소드 단위 성공/실패의 평균이라면, 소수 첫째 자리까지 보고된 값을 낼 수 있는 최소 시도 수가 있습니다.

| 값 | 최소 에피소드 수 (에피소드 단위) | 최소 시드 수 (단계 단위, 200/500 단계) |
|---|---|---|
| 99.9 (끌기 Ours) | **667** | 2 |
| 96.5 (들기 PPO) | **57** | 1 |
| 97.0 / 93.0 (끌기 PPO / APG) | 33 / 43 | 1 |
| 64.0 (접기 MPPI) | 25 | 1 |
| 80.0 (펴기 MPPI) | 5 | 1 |

- 시도 수가 보통의 5–30회라면 에피소드 단위 읽기는 99.9, 96.5, 93.0 등을 만들 수 없습니다. 따라서 표 1의 안전율은 **한 에피소드 안의 단계 비율(또는 표본 비율)**로 읽어야 정합적입니다. 코드의 `num_constraint_violations_steps`가 그것입니다(`04` D1).
- 이 읽기에서는 "안전율 100.0 ± 0.0"이 **모든 단계(밧줄 200, 500 단계)가 제약을 만족했다**는 뜻입니다. 한 단계 위반이 있으면 0.2%, 0.5%가 빠집니다.

### 1.4 동역학 평가 횟수의 산술 (V4)

| 항목 | 논문 값 | 산술 |
|---|---|---|
| Ours 들기 / 끌기 | 5400 / 13,500 | = 27 × 200 / 27 × 500. 비 2.5는 horizon 비 500/200과 같음 → **총 횟수**이고 단계당 27회 |
| Ours 접기 / 펴기 | 3400 / 3400 | = 17 × 200. 단계당 17회 |
| MPPI 들기 / 끌기 | 1,024,000 / 2,560,000 | = 5120 × 200 / 5120 × 500. 단계당 5120 = 1024 표본 × **5** |
| MPPI 천 | 64,000 | = 320 × 200. 단계당 320 (32표본 × 10 또는 64표본 × 5) |
| PPO, APG 들기 / 끌기 | 16M / 40M | = 8 × 200 × 10⁴ / 8 × 500 × 10⁴ (배치 8, 에포크 10⁴) |

- Ours의 단계당 횟수가 밧줄 27 = 20 + 7, 천 17 = 10 + 7로 **MPC horizon N(20, 10) + 7**입니다. 코드의 N(밧줄 20, 천 10)과 맞습니다(`04` D15).
- **MPPI는 코드의 설정(표본 1024, N = 20 밧줄, 10 천)과 맞지 않습니다.** 1024 표본으로 단계당 5120회면 N = 5입니다. 코드의 N = 20이면 20,480회, 천은 10,240회입니다(`04` D15). 표의 MPPI 횟수가 다른 설정에서 나왔거나 횟수 계수 방식이 다르다는 뜻입니다.
- APG 횟수는 코드 기본값과 정확히 맞고(배치 8, horizon, 에포크 10,000), **PPO의 같은 칸은 코드 기본값 총 타임스텝(10,000 × horizon = 2M / 5M)의 8배**입니다(`04` D6). 그림 6의 가로축이 1.6e7, 4e7까지인 것은 PPO를 그만큼 돌렸다는 뜻이라 8배 값은 실행 설정이었을 수 있고, 코드 기본값과 다를 뿐입니다.
- 한 열에 "계획 시간의 동역학 평가"(Ours, MPPI: 실행 중 매 단계 반복)와 "학습 중 시뮬레이터 호출"(PPO, APG: 한 번 학습)을 같이 놓은 것은 단위가 다릅니다(K7).

### 1.6 표 3: 시뮬레이터 정확도 (V6)

| 비교 | 값 | Welch p (n = 30 / n = 100) |
|---|---|---|
| 기본: Ours 0.0150 ± 0.0040, DEFORM 0.0139 ± 0.0029 | DEFORM이 7.3% 낮음 | 0.23 / **0.027** |
| 잔차 포함: 0.0075 ± 0.0068, 0.0071 ± 0.0032 | DEFORM이 5.3% 낮음 | 0.77 / 0.60 |

- 학습된 잔차가 Ours 오차를 정확히 50.0% 줄입니다(0.0150 → 0.0075). 다만 잔차 포함 SD 0.0068이 평균 0.0075의 91%라 오차 분포가 오른쪽으로 긴 꼬리를 가집니다.
- "DEFORM이 약 7% 낮다"는 n이 크면(100) 유의하고 n = 30이면 아닙니다. 잔차를 붙이면 차이가 사라집니다. 즉 "정확도가 비슷하다"는 표현은 잔차 포함 조건에서는 지지되고, 기본 조건에서는 n에 달려 있습니다.
- 데이터가 **저자의 지각 파이프라인으로 추정한 안정화된 준정적 상태**이므로 준정적 모델인 Ours에 유리하고(DEFORM은 영 제어로 평형까지 굴려 비교), 비틀림 등은 비교하지 못합니다(부록 F 본문).

### 1.7 CP 교정과 표 3의 정합성 (V7)

**(a) 표본 수와 궤적 수준 δ.** 교정 표본 n = 100에서 q = s_(⌈(n+1)(1−δ̄)⌉)가 유한하려면 δ̄ ≥ 1/101 ≈ 0.0099입니다. 궤적 수준 δ = T·δ̄이므로 δ ≥ T/101입니다.

| 호라이즌 T | 유한한 q를 위한 최소 δ | n = 100에서 δ = 0.1을 얻으려면 필요한 n | 87% 반지름의 합집합 상계 δ = 0.13 T |
|---|---|---|---|
| 5 | 0.05 | 49 | 0.65 |
| 10 | 0.099 | 99 | 1.30 |
| 20 | 0.198 | 199 | 2.6 |
| 50 | 0.495 | 499 | 6.5 |
| 200 | 1.98 | 1999 | 26 |

- 하드웨어는 n = 100이고 반지름 0.03 m가 **단계별 87%**만 덮습니다(δ̄ ≈ 0.13). 이 값은 분위수 인덱스 규칙으로 정한 것이 아니라 "반올림한 경험적 반지름"이며, 합집합 상계로 궤적 수준 δ를 환산하면 T ≥ 8에서 1을 넘어(0.13 × 8 = 1.04) **보장이 공허**합니다. 논문은 계획 horizon T, δ, 교정이 어느 데이터인지를 적지 않습니다.
- 교정 표본이 100개이면 "87%"라는 값 자체도 흔들립니다. 분할 CP에서 87% 분위수가 실제로 덮는 비율은 Beta(88, 13) 분포이고 평균 0.871, 5–95% 범위가 0.813–0.921입니다(`toy_cp_coverage.py` d).

**(b) 표 3과의 정합성.** 두 100개가 같은 데이터라면 표 3의 기본 시뮬 평균 L2 오차 0.0150 m, SD 0.0040 m와 "0.03 m가 잔차의 87%를 덮는다(13%가 0.03 초과)"는 양립하기 어렵습니다. 평균 0.0150에 13%가 0.03 이상이려면 SD는 **최소 0.0058**(나머지가 모두 0.0128로 같고 상위 13%가 정확히 0.03일 때)이 되어야 하는데 보고된 SD는 0.0040입니다. 정규분포라면 0.03은 평균에서 3.75 SD라 초과 확률이 0.0088%입니다. 해소 가능한 이유는 (i) 두 데이터가 다르다, (ii) 표 3의 ±가 표본 SD가 아니라 다른 양이다(예: 분할 반복 간), (iii) CP 잔차는 지각 잡음(ρ에 해당)까지 포함한다 정도입니다. 논문은 이를 구분하지 않습니다(K4).

## 3. 토이 실험

### 3.1 토이 T1: 정합 예측 교정이 궤적 수준에서 무엇을 보장하는가 (약 1 s, numpy)

`analysis/toy_cp_coverage.py`. 잔차 점수를 로그정규(평균 0.015 m, σ = 0.6)로 두고, 시간 상관을 AR(1) 가우시안 코풀라 ρ로 바꿔 20,000회 모의합니다. 로그정규와 상관은 가정이며 실제 잔차 분포는 알려져 있지 않습니다.

| 설정 | 결과 |
|---|---|
| (a) n = 100에서 유한한 q를 위한 최소 δ | T = 10이면 0.099, T = 20이면 0.198, T = 50이면 0.495, T = 200이면 1.98 |
| (b) 올바른 CP (δ = 0.1, 유한한 경우 T = 5, 8, 10) | 궤적 포함 확률 0.909–0.928(독립), 0.921–0.937(ρ = 0.5), 0.952–0.967(ρ = 0.9): **목표 0.9를 만족** |
| (c) 87%를 덮는 반지름 (토이 분포의 0.87 분위수 0.0246 m)의 궤적 포함 확률, T = 10 | 독립 0.246, ρ = 0.5에서 0.373, ρ = 0.9에서 0.651, ρ = 0.99에서 0.802 |
| (c) 같은 반지름, T = 50 | 독립 0.001, ρ = 0.5에서 0.009, ρ = 0.9에서 0.238, ρ = 0.99에서 0.684 |
| (c) T = 200 | 독립 0.000, ρ = 0.9에서 0.005, ρ = 0.99에서 0.42 |

- 올바른 CP(인덱스 규칙을 지킨 경우)는 목표를 지킵니다. **하드웨어에서 쓴 "87%를 덮는 반올림 반지름"은 단계 오차가 독립이면 길이 10 궤적에서 25%, 50 단계에서 0.1%만 관 안에 머뭅니다.** 상관이 매우 높아야(ρ ≥ 0.99) 80% 근처가 유지됩니다.
- 이 토이는 관(SLS가 만드는 공칭 + 피드백 관)이 아니라 "잔차가 반지름 안에 든다"는 사건만 봅니다. 실제 관에는 SLS의 응답 연산자 Φ가 곱해지므로 직접 환산은 아닙니다. 다만 논문의 가정(정리 1의 "관 포함 확률 ≥ 1−δ")은 **단계별 잔차 포함이 궤적 수준으로 올라갈 때의 분배 δ̄ = δ/T에 달려 있는데 교정은 그 분배를 따르지 않았다**는 점은 변하지 않습니다.
- 한계: 한 가지 분포 가정, 시드 하나(20,000회), 폐루프 분포 이동은 모델링하지 않음(교환 가능성 가정이 깨질 때는 더 나빠짐).

### 3.2 토이 T2: 병렬 연관 스캔의 결합 규칙 (식 13 대 식 16–17, 1 s 미만)

`analysis/toy_scan_riccati.py`. 임의의 선형 시변 계통(n = 4, 출력 2개, 길이 16)에서 식 (13)의 순차 칼만 공분산 재귀와 식 (16)–(17)의 결합을 비교합니다.

| 결합 순서 | 식 (13) 대비 최대 절대 오차 |
|---|---|
| 식 (17)의 원소 (Ã = Aᵀ), **나중 단계를 왼쪽**에 놓음 | **1.05e-15** |
| 같은 원소, 이른 단계를 왼쪽에 놓음 (본문 오름차순 표기를 그대로 읽은 경우) | 3.20 |
| Ã = A (전치 없음), 나중 단계 왼쪽 | 1.69 |
| 표준 병렬 칼만 결합 (Särkkä 형), 이른 단계 왼쪽 | 1.05e-15 |
| 이진 트리 결합 (식 (17) 원소) | 3.3e-15 |

- **식 (16)–(17)은 올바르게 병렬화된 칼만 재귀입니다.** 이진 트리 결합이 순차와 같으므로 결합법칙도 성립합니다. 병렬 스캔의 전제가 확인되었습니다.
- 다만 (17)이 "P̃_{i+1,i}"처럼 내려가는 인덱스로 원소를 정의하는데 본문은 "P̃_{0,j} := P̃_{0,1} ⊗ P̃_{1,2} ⊗ ⋯"로 오름차순 인덱스를 쓰므로, 문자 그대로 읽으면 순서가 반대라 틀립니다(K12). 표기 문제이고 방법의 문제는 아닙니다. 식 (17)의 D̃ = Cᵀ(FFᵀ)⁻¹C, P̃ = EEᵀ가 서로 다른 결합식(첫째 줄과 셋째 줄)에 들어가는 구조는 표준 병렬 칼만 결합과 역할이 뒤바뀌어 있으므로 시간 방향을 뒤집은 형태로 읽어야 합니다.
