# 03. 수치 재계산, 통계 검정, 표·본문 일관성 (VLA-JEPA)

대상: arXiv:2602.10098 v2의 Table 1–4와 본문 주장. 계산 스크립트는 `analysis/recompute.py`, 결과는 `analysis/recompute_results.json`입니다. 토이는 `analysis/toy_leakage.py`, 결과는 `analysis/toy_leakage_results.json`입니다. 둘 다 numpy와 scipy만 쓰고 CPU에서 몇 초 안에 끝납니다.

입력 수치는 `paper/paper.txt`(pdftotext -layout)에서 옮겼습니다. 원본 PDF 표의 숫자는 pdftotext 결과와 대조했고, 불일치는 없었습니다.

## 1. LIBERO (Table 1): 500 에피소드/스위트

**평균 재계산은 모든 행에서 맞습니다.** VLA-JEPA 97.2, w/o human videos 96.05(표 96.1), OpenVLA-OFT 97.1, π0.5 96.85(표 96.9), villa-X 90.125(표 90.1).

**Wilson 95% 신뢰구간 (VLA-JEPA)**

| 스위트 | 성공 | 성공률 | 95% CI |
|---|---|---|---|
| Spatial | 481/500 | 96.2 | [94.1, 97.6] |
| Object | 498/500 | 99.6 | [98.6, 99.9] |
| Goal | 486/500 | 97.2 | [95.4, 98.3] |
| LIBERO-10 | 479/500 | 95.8 | [93.7, 97.2] |
| 평균 (2000 에피소드) | 1944/2000 | 97.2 | [96.4, 97.8] |

**두 비율 z 검정 (독립 표본 근사, 에피소드 단위 대응 자료는 없음)**

| 비교 | 스위트 | 차이 (pp) | p (양측) |
|---|---|---|---|
| vs OpenVLA-OFT | 평균 | +0.1 | 0.85 |
| vs OpenVLA-OFT | Object | +1.2 | 0.06 |
| vs π0.5 | 평균 | +0.3 | 0.58 |
| vs π0.5 | Spatial | −2.6 | 0.008 |
| vs π0.5 | Object | +1.4 | 0.03 |
| vs π0.5 | LIBERO-10 | +3.4 | 0.02 |

**해석.**
- 논문이 말하는 "평균 SOTA"(97.2 대 OpenVLA-OFT 97.1)는 통계적으로 구별되지 않습니다. p = 0.85입니다.
- 스위트별로 보면 π0.5보다 Spatial은 낮고(p = 0.008) LIBERO-10과 Object는 높습니다. 네 스위트 검정은 다중 비교 보정을 하지 않았습니다. 보정하면 Object와 LIBERO-10의 유의성도 약해질 수 있습니다.
- 토이(시뮬레이션, n = 2000, p = 0.972): 두 방법이 실제로 같은 성공률을 가질 때 평균 차이가 0.1 pp 이상 날 확률은 **0.84**입니다. 차이의 표준편차는 0.52 pp입니다. 0.1 pp 차이는 우연과 구별되지 않습니다.
- 한계: 같은 시드, 같은 초기 상태에서 나온 쌍 대응 자료가 없어 대응 검정이 불가능합니다. 시드 반복 분산도 보고되지 않았습니다. 따라서 이 검정은 **이항 표본 변동**만 반영합니다.

## 2. SimplerEnv (Table 2)

**Google Robot.** 네 과제 평균은 표의 평균과 맞습니다(VLA-JEPA 65.2, w/o 78.4, villa-X 44.9, RoboVLMs 51.7).

**WidowX.** 대부분 맞지만 다음 불일치가 있습니다.

- **π0-Fast 평균 48.3과 과제 값이 맞지 않습니다.** 과제 값 29.1, 21.9, 10.8, 66.7의 평균은 **32.1**입니다. 표는 48.3입니다. 같은 행 Google 열에는 Pick, Move, Drawer 값이 있고 Place와 평균은 "-"입니다. 48.3은 잘못 옮긴 값이거나 다른 계산에서 온 값일 가능성이 있습니다. 원저자에게 확인이 필요합니다.
- **LAPA와의 동률.** VLA-JEPA 평균 57.3과 LAPA(∗ 표시, 시뮬레이션 학습 데이터 사용) 평균 57.3이 같습니다. 본문은 "WidowX에서 두 번째로 높은 평균"이라고 씁니다. 표에서는 최상위와 동률입니다. ∗ 표시를 제외하면 VLA-JEPA가 최고입니다.

**시도 횟수 추정.** WidowX 값은 모두 1/24의 배수입니다(예: 70.8 = 17/24, 12.5 = 3/24). 과제당 24회 시도로 보입니다. 논문은 시도 수를 쓰지 않았습니다. Google 열은 n ≤ 200 범위에서 맞는 정수 분모가 없습니다. Google 시도 수는 **확인되지 않습니다.**

**WidowX 과제별 95% CI (n = 24 추정).** Spoon 75.0 [55, 88], Carrot 70.8 [51, 85], Block 12.5 [4, 31], Eggplant 70.8 [51, 85]. 과제별 CI 폭이 30–35 pp입니다. 과제 한 개의 차이로 순위를 말하기 어렵습니다.

**표 안의 w/o 행.** w/o human videos는 Google에서 Move 66.7, Drawer 75.5, Place 86.1, 평균 78.4로 **완전 모델보다 높습니다**. 완전 모델이 높은 것은 Pick 88.3뿐입니다. 논문도 Q1에서 이 점을 인정하지만, 본문 표 설명("best on 2 of 4 tasks")은 행을 어떻게 세느냐에 따라 달라집니다. 기준선 행만 세면 Pick, Drawer(59.3 > 43.5), Place(49.1 > 24.1)가 기준선을 넘어 3/4입니다. 본문 셈법을 확인할 수 없습니다.

## 3. LIBERO-Plus (Table 3)

**평균이 재현되지 않습니다 (단순 평균 기준).** 7개 차원의 단순 평균과 표의 평균이 다릅니다.

| 방법 | 표 평균 | 단순 평균 | 차이 |
|---|---|---|---|
| VLA-JEPA | 79.5 | 79.49 | 0.0 |
| w/o human videos | 62.9 | 62.91 | 0.0 |
| OpenVLA-OFT | 69.6 | 71.40 | −1.8 |
| π0 | 53.6 | 56.13 | −2.5 |
| UniVLA | 42.9 | 45.81 | −2.9 |
| π0-Fast | 61.6 | 62.47 | −0.9 |
| WorldVLA | 25.0 | 25.61 | −0.6 |

VLA-JEPA 두 행만 맞고 나머지는 맞지 않습니다. 차원별 에피소드 수가 다르다면 가중 평균일 수 있습니다. 그러나 차원별 에피소드 수가 논문에 없어 **검증할 수 없습니다.** 가중치를 추정하는 것은 더 큰 추정을 낳으므로 하지 않았습니다.

**"7개 중 5개 최고" 주장은 맞습니다.** Robot 67.1, Language 85.4, Light 95.6, Background 93.6, Layout 85.1에서 VLA-JEPA가 최고입니다. Camera는 π0-Fast 65.1이 63.3보다 높고, Noise는 π0 79.0이 66.3보다 높습니다.

**"유의한 우위" 표현.** 본문은 Language, Light, Background, Layout에서 "significant advantage"라고 합니다. 하지만 Background는 93.6 대 93.3(OpenVLA-OFT)로 **0.3 pp 차이**입니다. 이 표로는 유의성을 말할 수 없습니다. 차원별 샘플 수가 없어 검정도 불가능합니다.

**human video 제거 효과.** VLA-JEPA 79.5에서 w/o 62.9로 **16.6 pp 하락**합니다. 본문 Q1은 "LIBERO와 SimplerEnv에서는 크지 않다"고 하고 LIBERO-Plus에서는 "상당한 이득"이라고 합니다. 이 방향은 표와 맞습니다. 다만 같은 에피소드 수 가정 없이 단순 비교하면 Camera(63.3 → 40.3), Noise(66.3 → 38.2)가 특히 큽니다.

## 4. 누수 경로 토이 (코드 D4와 연결)

`analysis/toy_leakage.py`는 잠재 상태가 AR(1)로 움직이고 관측에 노이즈가 섞인 선형 토이입니다. 두 가지 인코더를 비교했습니다. 인과 인코더는 프레임 0..t만 섞고, 양방향 인코더는 프레임 0..T 전체를 섞습니다. 입력은 **스텝 0..T−1의 특징만** 씁니다. 목표는 마지막 상태 s_T입니다.

| 입력 | 미래 상태 s_T 예측의 R² (테스트) |
|---|---|
| 현재 프레임만 (x_0) | 0.609 |
| 인과 인코더의 과거 특징 | 0.867 |
| 양방향 인코더의 과거 특징 | 0.920 |

**읽는 법.** 양방향 인코더는 과거 특징만으로도 미래 상태를 더 잘 맞춥니다. 차이는 0.05 정도입니다. 이 차이는 "과거 상태의 AR 동역학" 위에 얹힌 **추가 미래 정보**입니다. 토이는 실제 V-JEPA2의 어텐션 구조를 모사하지 않습니다. 따라서 이 숫자는 **메커니즘이 존재한다는 점만** 보여 줍니다. 실제 모델에서 누수의 크기는 알 수 없습니다. 실측하려면 이 저장소의 `get_vision_features`를 실행하거나 HF V-JEPA2 구현의 마스크를 확인해야 합니다. 둘 다 이번 작업에서는 하지 않았습니다(04 D4).

## 5. 본문과 표의 다른 일관성 점검

- **Table 4 대 Table 1.** Table 4의 T = 8 행(94.8, 99.8, 95.8, 94.0, 평균 96.1)은 Table 1의 완전 모델 행(96.2, 99.6, 97.2, 95.8, 평균 97.2)과 **다릅니다**. 오히려 Table 1의 w/o human videos 행(94.8, 99.6, 95.8, 94.0, 평균 96.1)과 Object 한 칸만 다르고 거의 같습니다. 논문은 Table 4가 어떤 체크포인트인지 밝히지 않았습니다. 완전 모델의 T = 8 값인지, 다른 설정인지 알 수 없습니다.
- **T 값 자체의 일관성.** K = 24/T이고 T = 8이면 K = 3입니다(A.1, Table 5). 코드의 사전학습 설정은 8입니다(04 D3).
- **Table 4 평균.** 세 행 모두 재계산과 맞습니다(94.75, 96.1, 95.45).
