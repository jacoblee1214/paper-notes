## 3. 공개 결과와의 일치 요약

일치: 18개 과제 구조, 시드 10000–10099, 3,000스텝 50 Hz, 0.08 m 들기, 1초 유지, 디코이 사양, 32/36 차원, 열린 루프 청크, 실로봇 데이터 91개, 학습 업데이트 수·배치, 매개변수 수.
논문에 없는 규칙: 모든 수준에서 올바른 도구 사용을 요구하지 않는 성공 조건(D2), IceBreak 임계(D9), 디코이가 시각적으로 더 크다는 점(D7), 실로봇 행동 35차원(D18).
확인되지 않은 것: 논문 수치를 만든 코드 판(D16), 강한 정책 5개의 평가 설정(D1), 층화 샘플링(D17).

## 4. 구현할 수 있는가 (이 맥: Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)

**판정: 이 맥에서 논문의 평가(표 III, IV)와 학습은 구현할 수 없고, 점검·재계산·소규모 재구현만 가능합니다.**

## 5. 정적 읽기의 한계

- 정책 로더, 렌더링, 제어기 모듈, 테스트, 영상 검증은 읽지 않았습니다. 성공 판정과 배치 상수만 읽었습니다.
- 배치 상수(예: 팔 도달 0.62 m)가 실제 동역학에서 도구 없이 성공을 허용하는지는 시뮬을 돌려야 알 수 있어 확인하지 않았습니다(D2).
- 모델 카드의 `training_provenance`와 `argv.txt`는 ACT만 읽었습니다. 다른 정책의 학습 설정은 공개되지 않았습니다.
- D16의 영향 범위는 코드 주석에 적힌 시드 목록에서 낸 상한이며, 논문 평가가 수정 전 판이었는지는 모릅니다.
