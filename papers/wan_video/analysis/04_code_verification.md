# 04 논문과 공식 코드 대조 (Wan2.1, 정적 읽기)

- 코드: https://github.com/Wan-Video/Wan2.1, Apache-2.0, 얕은 clone `repo/` (HEAD `9737cba`, 2026-03-05).
- 방법: 파일을 읽어 논문의 설정·구조와 맞춰 봤습니다. 실행, import, 설치는 하지 않았습니다. 설정 값은 `wan/configs/*.py`, 구조는 `wan/modules/*.py`, 샘플링은 `wan/text2video.py`와 `generate.py`에서 확인했습니다.
- 판정 기호: **일치**(코드와 논문이 같음), **차이**(다르거나 논문에 없는 기본값이 코드에 있음), **누락**(논문이 말하지만 저장소에 없음), **확인 불가**(가중치나 데이터가 있어야 함).
- 저장소 자체는 **추론 전용**입니다. 학습 스크립트, 옵티마이저, 손실 함수 구현이 없습니다.

## 3. 프롬프트 재작성과 외부 모델

- 논문은 재작성에 **Qwen2.5-Plus**를 씁니다(§4.5). 저장소 기본값은 `local_qwen`이고, 로컬 Qwen2.5 계열을 Hugging Face에서 받아 씁니다(`generate.py` 192행). `dashscope`는 API 옵션입니다(`qwen-plus`, `qwen-vl-max`).
- 결과 차이: 논문 수치는 API 재작성 결과입니다. 로컬 모델로 바꾸면 프롬프트가 달라질 수 있습니다. 논문은 재작성 지시문 전문을 싣지 않았고, 저장소의 `prompt_extend.py`에 지시문이 있습니다.
- 이 부분은 **D23**으로 기록합니다: 프롬프트 재작성 모델과 지시문이 논문에 빠져 있고 코드에서 확인된 것만 쓸 수 있습니다.

## 4. 메모리와 하드웨어 주장, 구현 가능성 판정

**구현 가능성 판정 (이 맥, Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음):**

- **추론 14B: 불가.** bf16 가중치만 26.6 GiB라서 24 GiB에 올라가지 않습니다. CPU 오프로드로 돌릴 수는 있지만 720p 5초 한 편이 수십 시간입니다(`03` V10, V11).
- **추론 1.3B: 조건부.** 가중치는 2.6 GiB이고 480p 5초 한 편은 추정 1–2시간입니다(`03` §6). 장치 지정과 autocast를 포팅해야 하고, 가중치 다운로드는 승인이 필요합니다(D28).
- **학습과 미세조정: 불가.** 학습 코드가 없고(D1), 1.3B 전체 미세조정은 AdamW 상태만 10 GB를 넘고 활성 메모리가 더해집니다. 저랭크 어댑터 학습도 토큰이 3만 개를 넘어 맥에서는 실용적이지 않습니다.
- **로봇 데이터 적용: 조건부 (VAE만).** VAE 재구성은 가중치가 작아 맥에서 시도할 수 있습니다. 로봇 영상의 세부 보존을 보는 데 쓸 수 있습니다.
- **노력(추정):** 1.3B 추론 포팅과 측정 1–2일. VAE 재구성 측정 1주 안팎. 학습 재현은 연구 규모 작업이고 맥 범위 밖입니다.

| 번호 | 항목 | 논문 | 저장소 | 판정 |
|---|---|---|---|---|
| D24 | 1.3B VRAM 8.19 GB | 초록, 서론 (설정 없음) | README 17행은 8.19 GB를 설정 없이 적음. 효율 표 주석은 1.3B를 RTX 4090에서 `--offload_model True --t5_cpu`로 돌렸다고 씀 (`README.md` 600행 부근). `offload_model` 기본값은 단일 GPU에서 True | **차이** (설정을 논문에 적지 않음, 8.19 GB의 설정 근거 없음) |
| D25 | 텍스트 인코더 메모리 "20 GB 넘음" | §4.3.2 | `t5_dtype = bfloat16` (`shared_config.py`). bf16이면 약 10 GB, fp32이면 약 20 GB (`recompute_results.json`) | **확인 불가** (로드 정밀도 미지정) |
| D26 | 14B 단일 GPU 약 30분 | §6 | README 효율 표는 이미지라 값을 읽지 못함. `--offload_model`이 14B 기본 설명에 나옴 | **확인 불가** |

## 5. 병렬화

- 논문의 2D 컨텍스트 병렬(Ring 바깥, Ulysses 안, §4.3.2)은 저장소에서 `xfuser` 라이브러리의 시퀀스 병렬 호출로 구현됩니다(`text2video.py` 91–101행, `wan/distributed/xdit_context_parallel.py`). 외부 라이브러리 내부 구성은 확인하지 않았습니다.
- FSDP 구현은 `wan/distributed/fsdp.py`에 있습니다. 논문과 일치합니다.
- **D27**: 논문의 "1M 토큰에서 8 TB 활성 메모리"와 "2D CP 통신 10%에서 1% 미만"은 측정 설정이 없어 **확인 불가**입니다.

## 6. 어텐션 백엔드와 하드웨어 가정 (맥 관련)

- `modules/attention.py`는 `flash_attn_interface`(FA3), `flash_attn`(FA2)를 먼저 찾고, 없으면 `scaled_dot_product_attention`으로 떨어집니다.
- `generate.py`는 분산일 때 `torch.cuda.set_device`를 호출합니다. `text2video.py`는 `amp.autocast(dtype=...)`를 씁니다. 기본 장치가 CUDA라서 MPS에서는 포팅이 필요합니다. 이것은 정적 판단이며 실행해 확인하지 않았습니다.
- **D28**: 맥에서 1.3B 추론을 쓰려면 장치 지정(CPU·MPS 대체), `autocast` 대체, bf16 연산 지원 확인이 필요합니다. 이 작업은 재현 계획에서 조건부로 다룹니다.

## 7. 논문 대 저장소, 요약

- **일치 (구조):** DiT 설정, 패치, VAE 압축과 특징 캐시, 텍스트 길이, 전체 어텐션, I2V 구조, VACE 구조, 프레임과 fps.
- **차이 (기본값):** 시프트, CFG, I2V 스텝 40, 솔버. 논문에 없는 값이 결과를 바꿉니다. 특히 시프트는 논문이 말하지 않아 같은 프롬프트에서 결과가 달라질 수 있습니다.
- **누락 (기능):** 학습 전체, 데이터, 평가 코드, 가속(캐시, FP8, INT8), 실시간, 카메라, 개인화, V2A. README는 V2A를 기능으로 적었지만 코드가 없습니다.
- **확인 불가:** 가중치가 있어야 하는 값(I2V 채널 수, 파라미터 수, VAE 127M), 측정 설정이 필요한 값(8.19 GB, 시간과 메모리).
