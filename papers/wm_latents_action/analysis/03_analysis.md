# 03. 수치 재계산, 일관성 검사, 주장 판정

재계산은 `analysis/recompute.py`가 하고, 결과는 `analysis/recompute_results.json`에 있습니다(수 초, numpy와 scipy). 입력은 공식 저장소의 원자료 CSV(`repo/results/`)입니다. 논문 표 값은 v2 본문과 부록에서 옮겨 적었습니다.

## 0. 가정과 한계

- **분석 단위.** 폐루프 성공률은 시도 100회(과제 10개 x 10회)를 이항으로 보고 Wilson, Newcombe, Fisher 검정을 썼습니다. 과제 간 군집을 무시하므로 구간이 좁게 나올 수 있습니다. 그래서 과제별 쌍체 검정(C2)을 따로 했습니다.
- **매칭 대조 값.** 원자료는 학습 시드 x 프로브 시드 단위의 R²만 있습니다. 26개 과제 단위 자료가 없어서 ∆26의 CI는 다시 계산할 수 없었습니다. 200 에피소드 기준의 값만 재계산했습니다.
- **다중 비교.** 폐루프 표에는 여러 셀이 있으므로 위치 이동 열 7행에 대해 Holm과 Bonferroni 보정을 같이 적었습니다.
- **추정하지 않은 것.** 검사할 수 없는 값(PSNR 그림의 점 좌표, 표 10의 CALVIN 전체 프로토콜)은 판정하지 않았습니다.

## 1. 재계산 결과

### 1.1 폐루프 표 (표 4, 표 20)

원자료 CSV(`closed_loop_success_by_suite.csv`)로 만든 값이 논문 표와 모두 맞습니다(K1). 기준선 LIBERO 평균 93.0, DIFF + ID 93.8, LIBERO-PRO 전체 평균 68.7과 69.0, LIBERO-10 위치 이동 8과 24입니다. 과제별 성공 수의 합도 셀 값과 같습니다(K2).

LIBERO-10 위치 이동 (시도 100회, 대 기준선 8/100):

| 행 | 성공 | 차이 (%p) | Newcombe 95% | Fisher p | Holm (7행) |
|---|---|---|---|---|---|
| DIFF + ID (시드 0) | 24 | +16.0 | [5.9, 26.0] | 0.0033 | 0.023 |
| V-JEPA 2 + ID (w 0.01) | 23 | +15.0 | [5.0, 24.9] | 0.0056 | 0.034 |
| DIFF + ID (시드 1) | 18 | +10.0 | [0.6, 19.5] | 0.057 | 0.28 |
| 배치 섞기 대조 | 15 | +7.0 | [−2.0, 16.2] | 0.18 | 0.73 |
| 무작위 초기화 대조 | 14 | +6.0 | [−2.9, 15.0] | 0.26 | 0.77 |
| Web-DINO (w 0.01) | 14 | +6.0 | [−2.9, 15.0] | 0.26 | 0.77 |
| V-JEPA 2 + ID (w 0.05) | 8 | 0 | [−8.0, 8.0] | 1.0 | 1.0 |

- 표적과 대조의 직접 비교(C1b): DIFF + ID 24 대 배치 섞기 15는 차이 9%p, Fisher p = 0.15입니다. DIFF + ID 24 대 무작위 초기화 14는 p = 0.10입니다. V-JEPA 2 + ID 23 대 Web-DINO 14는 p = 0.14입니다. **기준선 대비 차이는 두 표적에서 확인되지만, 표적과 대조군의 차이는 확인되지 않습니다.**
- 과제별 쌍체 검정(C2, DIFF + ID 대 기준선, 과제 10개): 과제별 차이 [1, 4, −1, 0, 0, 5, 3, 4, 0, 0], 평균 +1.6회입니다. Wilcoxon p = 0.058(양 5, 음 1, 0 4)입니다. 과제 단위로 보면 방향은 맞지만 약합니다.
- 두 DIFF + ID 시드를 합치면 42/200 대 8/100, Fisher p = 0.005입니다(C1c). 다만 시드 간 차이(24 대 18)가 있으므로 참고용입니다.
- 4개 스위트 평균 위치 이동: DIFF + ID 47.5 대 기준선 46.8이고, 400회씩의 Fisher p = 0.89입니다. LIBERO-PRO 전체 2000회: 69.0 대 68.7, p = 0.86입니다(군집 무시).

### 1.2 매칭 대조 (표 2)

- 원자료 평균과 표 2 절대값은 모두 0.001 안에서 같습니다(K3). 예를 들면 V-JEPA 참 ID 0.8626(표 0.863), 섞기 0.1838(표 0.184), FD 0.3256(표 0.326)입니다.
- 학습 시드 간 차이(K4, 시드 0과 시드 1의 평균 차이): V-JEPA 참 ID 0.009, **V-JEPA 섞기 ID 0.080**, V-JEPA FD 0.010, VideoMAE 참 ID 0.006, Web-DINO 참 ID 0.055입니다. 섞기 조건에서 학습 시드 변동이 크므로, 학습 시드 2개를 조건부로 둔 CI는 좁게 나올 수 있습니다.
- 200 에피소드 기준의 대비(C5, 프로브 시드를 독립으로 취급하므로 과소평가된 p, 참고용): V-JEPA 0.679, VideoMAE 0.406, Web-DINO 0.093입니다.
- ∆26(표 2): V-JEPA 0.836은 200 에피소드 절대 차이 0.679보다 큽니다. 저자들은 두 값이 산술 차이가 아니라고 적었으므로 모순은 아닙니다. 다만 26개 과제 자료가 없어서 이 차이를 검증할 수 없습니다(K13).

### 1.3 다른 벤치마크 순위 (표 10)

표 10의 8개 백본 값으로 Spearman 순위 상관을 다시 계산했습니다(K5). LIBERO와 MetaWorld는 ρ = 0.881(논문 0.88), LIBERO와 CALVIN은 0.833(0.83), CALVIN과 MetaWorld는 0.667(0.67)입니다. 모두 논문과 맞습니다. 백본 8개뿐이므로 ρ의 표준오차가 큽니다(n = 8).

### 1.4 표 1, 표 11, 표 19의 산술

- 표 1 Δ(K6): 모든 행이 0.01 안에서 맞습니다. DIFF만 0.14(반올림) 대 0.15입니다. 비반올림 값 0.572 − 0.426 = 0.146이므로 반올림 차이입니다.
- 표 11 (K7): 블록별 +ID − 프리즈 차이의 최대 오차는 0.001입니다. 프리즈 최고는 블록 15(0.516), +ID 최고는 블록 21(0.721)입니다. 마지막 네 블록의 증가는 0.248–0.317, 블록 12–18의 증가는 0.072–0.141입니다. 프리즈 블록 15에서 22로 가는 감소는 0.122입니다.
- 표 19 (K8): 세 행 모두 "R² − 상수 예측"의 오프셋이 −0.034 또는 −0.035로 같습니다. 열이 같은 상수 기준을 씁니다.

### 1.5 학습 설정 (부록 G, 부록 M, 표 13)

- 표 13의 V-JEPA 실효 배치는 4이고 30k 업데이트입니다. 부록 M의 매칭 대조는 실효 배치 16, 20k 업데이트입니다(K12). 두 설정은 같은 백본에서 다르므로 표 1과 표 2의 절대값 차이(0.84 대 0.863)를 이것으로 설명할 수 있습니다.

## 5. 재실행

```bash
python3 analysis/recompute.py          # 표 재계산과 검정 (repo/results/ 필요)
python3 analysis/plot_figures.py       # 우리가 그린 그래프 두 장
```

재계산은 CSV 원자료와 논문 표 값을 함께 씁니다. 원자료 CSV는 공식 저장소(`repo/`)에 있으며, 이 폴더에서 `git clone --depth 1`로 받을 수 있습니다. 토이 실험은 하지 않았습니다. 논문의 핵심 주장이 공개 원자료로 검증 가능했고, 토이로 재현할 만한 중심 주장이 없었습니다.
