## 1. 한 줄 요약과 주장

사람 영상에서 "다음 1초 동안 물체가 어떻게 움직여야 하는가(3D 점 흐름)와 손바닥(palm)이 어디에 있어야 하는가(palm pose)"를 예측하는 **의도 모델 f_θ**를 배우고, 시뮬레이션에서 그 참조를 따라가는 **로봇별 sensorimotor 정책 π**를 따로 배웁니다. 배포할 때는 f_θ를 약 1 Hz로 다시 질의합니다(폐루프). 로봇 시연도 원격조종 데이터도 쓰지 않습니다(초록, §1).

저자가 세운 네 가지 주장(§1, 4번째 문단):

1. 새 장면, 카메라 시점, 물체 인스턴스에 영점(zero-shot)으로 전이되는 의도를 배웁니다.
2. 폐루프 의도 예측이 견고성을 높입니다.
3. 같은 의도 모델이 다른 로봇(손, 평행 그리퍼)에 쓰입니다.
4. 학습 영상의 양에 따라 의도 손실과 과제 성공이 예측 가능하게 좋아집니다.

대표 수치(§1): 웹 영상 과제 3개 평균 성공률 73%(폐루프 LUCID) 대 28%(개루프 기준선), 자체 수집 영상 과제 2개에서 손과 그리퍼 모두 63%(19/30)입니다.

## 2. 방법

### 2.1 의도 모델 f_θ (§3.1, 부록 A)

- **입력과 출력.** 최근 F = 2 프레임 RGB-D 스택 I_t, 대상 물체 위의 N = 16개 질의점 x_{n,0}, 현재 palm pose (p_0, R_0). 출력은 미래 T = 8 스텝(8 Hz, 지평 1 s)의 각 점의 3D 위치와 palm pose입니다(표 1). 물체 헤드는 Linear(768 → 3), palm 헤드는 Linear(768 → 9)(표 1; 9는 위치 3 + 회전 6의 표현으로 읽히나 논문은 구성을 적지 않습니다).
- **구조.** CoTracker3 [55]의 EfficientUpdateFormer(깊이 12, 폭 768, 12 헤드)를 점 토큰 트랜스포머로 가져오고 세 가지를 바꿉니다. (1) 동결된 DINOv3 ViT-B/16 [56] 패치 토큰에 조건화하고 깊이를 0으로 초기화한 잔차 어댑터(Conv2d → LayerNorm → Linear)로 같은 토큰 공간에 합칩니다. (2) 관측된 프레임이 아니라 미래를 예측합니다. (3) 물체 토큰 N개 옆에 palm 토큰 하나를 둡니다(부록 A.2.1).
- **손실.** L = L_trk + L_palm,p + L_palm,r, 세 MSE의 합이며 T 스텝에 걸쳐 평균합니다(§3.1). 목표값은 채널별로 표준화합니다(부록 A.2.2). 따라서 그림 6의 held-out 손실(약 2.8–3.2)은 표준화된 단위의 합이며 단위 해석은 논문에 없습니다.
- **증강.** 일반 기하/색 증강(확률 0.8)과 사람 영역 증강(확률 0.6, 사람 마스크 픽셀을 색 지터 0.40, 균일 RGB 0.25, 색 패치 격자 0.25, 픽셀별 임의 RGB 0.10 중 하나로 교체)(부록 A.2.3). 배포 때 보이는 손이 로봇이라 사람 외형에 기대지 않게 하려는 장치입니다.
- **학습 설정**(표 2). AdamW, 100 에폭, 배치 16, 학습률 1e-4(코사인, 최소 1e-6, 워밍업 5 에폭), 가중치 감쇠 0.01, 기울기 클립 1.0, EMA 0.999. **과제마다 별도의 의도 모델을 학습합니다**(부록 A.2.2). 감독 추출과 학습은 A100 노드 한 대입니다.

### 2.2 영상에서 감독 신호 추출 (§3.1, 부록 A.1, 그림 8)

과제마다 영상 클립 20k개를 공개 데이터(Panda-70M [57], Action100M [58], Something-Something-V2 [59], EPIC-Kitchens [60], LVP 메타데이터 [54])에서 행동 라벨과 길이로 걸러 모읍니다. 대표 과제가 부족하면 iPhone으로 직접 약 100개를 찍습니다(push-T, cable routing은 각 1시간). 클립은 8 Hz로 다시 표집하고 stride 2의 겹치는 창(과거 2 + 미래 8 프레임, 1.25 s)으로 자릅니다. 네 단계 추출:

| 단계 | 도구 | 산출 |
|---|---|---|
| (a) 카메라와 깊이 | ViPE [61] | 내부/외부 파라미터, 미터 깊이 |
| (b) 마스크 | SAM 3.1 [62] (행동 명사로 프롬프트) | 물체 마스크, 사람 마스크(물체 마스크에서 사람 영역을 뺌) |
| (c) 물체 흐름 | DenseTrack3Dv2 = DELTAv2 [63] | 질의 N개 점의 3D 궤적 |
| (d) 손 | WiLoR [64] + MANO [65], 식 (1)의 강체 정렬 | palm pose (스케일 s와 이동 t를 깊이에 맞춰 닫힌 형태로 풂) |

**"유일한 주석은 물체 이름"**(부록 A.1.1)이라고 쓰지만, 같은 문서의 한계 (2)는 "새 과제를 학습하려면 수동 코퍼스 필터링이 필요하다"고 씁니다. 클립 선별 기준과 걸러 낸 비율은 본문에 없습니다.

### 2.3 Sensorimotor 정책 π (§3.2, 부록 B)

- **로봇.** UR5e 팔 + LEAP 손(16 자유도, 총 22), 평행 그리퍼 변형은 부록 C.1. 손목 깊이 카메라 Gemini 305와 외부 RGB-D 한 대(그림 10, 부록 B.7).
- **참조 형식.** 정책은 f_θ나 영상이 아니라 **절차적으로 생성한 참조**로 학습합니다. 물체는 원시 도형(상자, 구, 캡슐, 원기둥, 판)의 합집합 약 1k개, 배율 [0.65, 1.1](부록 B.1, 그림 9). 궤적은 네 구간(표 3): 접근 2.5 s(손-물체 결합 full), 손 안 운동 0–7.5 s(0–2 경유점, full 또는 position-only 각 0.5), 목표 3.0 s, 분리 2.5 s(결합 none). 에피소드 길이는 8–15.5 s, 50 Hz로 400–775 스텝입니다(`03` §4 K5).
- **행동.** a = [arm(6); eig(5); hnd(16)], 모두 tanh 출력. eigen-grasp 기저 E ∈ R^{16×5}는 재타게팅한 사람 파지의 상위 5개 주성분(부록 B.2, [23, 67]). 목표 q̃_t = EMA(q̃_{t-1} + η[a_arm; E a_eig + a_hnd]) (η = 0.1, α_arm = 0.15, α_hnd = 0.75, SimToolReal [9] 방식). tanh 한계에서 팔 목표는 스텝당 0.015 rad(50 Hz에서 0.75 rad/s)까지 움직입니다(`03` §4 K6).
- **관측**(표 4). 교사 π^T는 특권 상태(전표면 질의점, 물체 포즈, 접촉력, 관절 속도), 학생 π^S는 외부 카메라에서 보이는 질의점(N = 16)과 손목 깊이 80×60, 고유감각입니다. 학생의 비영상 관측 차원은 N = 16, T = 8에서 1,153(+ 깊이 4,800 픽셀)입니다(`03` §4 K7).
- **보상**(표 6). 단일 과제 무관 보상: 전방 추적 +8.0, 궤적 성공 +25.0, 추적 진척 +4.0, 손바닥 추종 +3.5, 좋은 손가락 접촉 +1.5, 손가락 조작 +6.0, 시간 종료 보너스 +200, 조기 종료 −100과 여러 규제항. 접촉 인자 c(f)(식 2)와 손바닥 게이트 g_hp(식 3)가 추적 보상을 가립니다.
- **구조**(표 7). AME [68] 기반 교차 어텐션. 점마다 궤적 전체를 점별 MLP로 토큰화하고(순열 불변), 학생은 손목 깊이를 4개 stride-2 conv로 토큰화해 합칩니다. 교사 토큰 폭 64, 학생 128.
- **학습**(표 8, 9, 10). 교사는 PPO(환경 20,480개, 지평 32, 최소배치 32,768, 학습률 5e-4 적응 KL, γ = 0.998), 1B 환경 스텝(그림 7A 축). 적응 도메인 무작위화 변수 ρ ∈ [0, 1]이 중력 0.0981 → 9.81 m/s², 물체 외력 0 → ±0.15 N, 종료·성공 허용오차를 함께 조입니다. 학생은 PPO + 교사 행동 평균 MSE(식 4, κ = 10, λ_D를 1,000 에폭에 걸쳐 1.0 → 0.1)로 증류하고(PHP [71] 방식), 환경 2,048개, 100M 환경 스텝(그림 7B 축). 단일 RTX 5090입니다.
- **현실 보정**(부록 B.7). CMA-ES [78]로 UR5e와 LEAP의 관절 강성, 감쇠, 마찰을 식별하고, 깊이 센서 잡음 모델 [72]을 입힙니다. 손목 깊이는 센서 내장 깊이가 가까운 거리에서 잡음이 크다며 Fast-FoundationStereo [79]의 적외선 쌍 추정을 씁니다(그림 10).

### 2.4 실세계 실행 (§3.3, 부록 B.8, 표 11)

SAM 3.1 마스크 새로고침 1 Hz, 의도 모델 f_θ 1 Hz, DenseTrack3Dv2 슬라이딩 윈도우 추적 30 Hz, 정책 π^S 50 Hz. 참조 창이 1 s 지평 끝에 닿으면 f_θ를 다시 질의합니다. f_θ의 출력은 외부 카메라 좌표계라 로봇 기저 좌표로 변환합니다. 스택 전체가 RTX 5090 한 장에서 돕니다.

## 3. 실험과 보고 수치

### 3.1 웹 영상 과제 (§4.1, 그림 5A, 그림 12)

세 과제(Stirring, Wiping, Binning)를 시나리오 3개(물체 인스턴스, 책상 세팅, 외부 카메라 자세를 **함께** 바꿈)에서 시나리오당 10회, 즉 과제당 30회 평가합니다. 개루프 기준선은 Veo 3.1 [73]이 초기 RGB로 영상을 만들고(롤아웃당 2–3분), 같은 추출 파이프라인(창 없이 전체 영상 한 구간)으로 얻은 참조를 같은 π에 넣습니다. 그럴듯하지 않은 영상은 걸러 다시 생성합니다(부록 C.1).

그림 12의 막대 라벨(성공 / 복구 불가 상태 / 지각 손실 / 부정확한 행동):

| 과제 | LUCID (3 시나리오) | 개루프 (3 시나리오) |
|---|---|---|
| Stirring | 6, 8, 5 → 19/30 | 4, 3, 0 → 7/30 |
| Wiping | 9, 7, 10 → 26/30 | 3, 2, 8 → 13/30 |
| Binning | 7, 9, 5 → 21/30 | 4, 1, 0 → 5/30 |
| 합 | 66/90 = 73.3% | 25/90 = 27.8% |

본문 "73% 대 28%"는 이 합과 일치합니다(`03` §1).

### 3.2 데이터 스케일링 (§4.2, 그림 6, 부록 C.3)

binning에서 학습 클립 {1k, 2k, 5k, 10k, 20k}를 시나리오 3개 x 10회(= 30회)로 평가하고, 별도의 held-out 1k 클립에서 의도 손실을 잽니다. 그림 6 판독 값: 성공률 약 3, 10, 40, 63, 73%(30회 기준 1, 3, 12, 19, 22회로 읽힘), 손실 약 3.18, 3.08, 2.98, 2.90, 2.82. 부록 C.3은 고정 지수 α ∈ {0.05, ..., 0.25}의 멱법칙 L(M) = c + a M^{-α}를 적합해 1000배 외삽하고 "관측 범위가 많은 비슷한 적합을 지지하며 외삽은 불확실하다"고 씁니다(그림 14).

### 3.3 체화(embodiment) 간 전이 (§4.3, 그림 5B, 그림 13)

push-T와 cable routing(각 1시간 스마트폰 영상으로 학습)을 같은 의도 예측으로 LEAP 손 정책과 평행 그리퍼 정책에 적용, 칸당 15회. 손: push-T 12/15, cable 7/15. 그리퍼: 10/15, 9/15. 합계 각 19/30. 그림 13의 실패는 모두 "부정확한 행동"으로 분류됩니다.

### 3.4 정책 절제 (§4.4, 그림 7, 15)

시뮬레이션, 시드 3개. 교사: MLP 인코더(토큰화 없음), eigen-grasp 기저 제거. 학생: DAgger-BC 혼합(교사/학생 롤아웃 50/50), 손목 카메라 제거. 판독 값(곡선 끝, 에피소드 보상): 교사 Ours 약 67, MLP 약 27, No eigen 약 13; 학생 Ours 약 61, DAgger+BC 약 47, No wrist cam 약 42. 질의점 수 N 절제(그림 15, 부록 C.4)에서 N = 16을 고릅니다("보상 대부분을 얻고 의도 모델 학습을 빠르게 유지").

## 4. 한계 (논문 §5)

(1) 모듈 연쇄가 깨지기 쉽습니다(SAM 3.1, DenseTrack3Dv2, ViPE, WiLoR 각각이 실패 지점). (2) 종료 조건이 없는 과제에서 의도 모델이 무한 반복합니다(stirring은 외부에서 멈춤을 줘야 함). 새 과제는 수동 코퍼스 필터링이 필요합니다. (3) 3D 흐름 + palm pose 인터페이스는 손으로 설계한 것이라 손가락 구성과 세밀한 접촉 정보를 버립니다.

## 5. 주장과 근거 사이 (정리)

`03`과 `04`에 번호를 붙여 두었습니다. 여기서는 읽는 이가 먼저 알아 두면 좋은 점만 적습니다.

- **개루프 기준선은 두 가지가 한꺼번에 다릅니다.** 의도의 출처(Veo 3.1 영상 대 학습된 f_θ)와 질의 횟수(1회 대 약 1 Hz)입니다. "폐루프 의도의 기여를 분리하기 위해 비교한다"(§4.1)는 문장과 달리, 같은 f_θ를 한 번만 질의하는 변형은 실험에 없습니다(`04` C3, `03` §3).
- **"새 장면, 시점, 물체" 일반화는 세 요인을 함께 바꾼 시나리오 3개로 보였습니다.** 요인별 분리와 시나리오 수는 한 줄로 요약됩니다(`04` C2).
- **스케일링 곡선은 한 과제(binning), 점 5개, 점당 30회입니다.** 그림 6의 20k 점(판독 22/30)과 그림 12 binning(21/30)이 한 회 차이로 다릅니다(`03` §2, V10).
- **"체화에 무관한 의도"는 의도 모델이 과제별이고, 그리퍼에는 palm 프레임을 닫힘 축에 맞추는 매핑이 들어갑니다**(부록 C.1). 손과 그리퍼의 19/30 일치는 칸당 15회로 ±23 %p 안에서만 말할 수 있습니다(`03` §1.3).
- **코드, 가중치, 데이터가 공개되지 않았습니다**(`02` §2). 재현에는 UR5e, LEAP, 센서, 영상 추출 모듈 4종과 Isaac Lab 대규모 PPO가 필요합니다(`04` §4).
