# 03. 재계산, 일관성 검사, 토이 검사

이 문서의 숫자는 `analysis/recompute.py`(→ `recompute_results.json`)와 `analysis/toy_value_target.py`(→ `toy_value_target_results.json`)가 냅니다. 논문 표 값은 본문과 부록 표에서 옮겼고, 시드별 결과나 에피소드별 값은 논문에 없어서 쓰지 않았습니다.

## 0. 가정

- **시뮬 시행 수.** 장면당 20회 × 시드 3 = 60회입니다. 표의 모든 SR이 1/60(1.67%)의 배수라서 맞는 가정으로 보입니다(§1.1).
- **± 정의.** 시드 3개의 SD입니다. 모집단(ddof = 0)과 표본(ddof = 1) 중 어느 쪽인지는 §1.4에서 확인합니다.
- **실로봇.** 과제당 20회, 단일 실행입니다. 시드와 SD가 없습니다.
- **실로봇 "Overall Avg".** 장면 3개의 단순 평균입니다(표 8 캡션). 풀링 비율과 다르므로 둘 다 냅니다(§4).
- **검정 독립성.** 시행을 독립으로 보는 풀링 검정은 과대평가입니다. 장면 쌍체(n = 10)와 시드 Welch(n = 3)를 함께 봅니다.

### 1.4 ± 정의 확인 (표본 SD 대 모집단 SD)

장면 하나에서 시드별 성공 횟수 $k_i \in \{0, \ldots, 20\}$를 찾아, 평균과 ±가 동시에 맞는 정수 해가 있는지 봤습니다.

| 셀 | 보고 | 모집단 SD(ddof = 0) 해 | 표본 SD(ddof = 1) 해 |
|---|---|---|---|
| PhysVAM, Avocado | 60.00 ± 10.80 | 있음 (k = 9, 13, 14) | 없음 |
| PhysVAM, Beer | 41.67 ± 10.27 | 있음 (k = 6, 8, 11) | 없음 |
| PhysVAM, Lemon | 88.33 ± 6.24 | 있음 (k = 16, 18, 19) | 없음 |
| PUMA+, Beer | 85.00 ± 12.25 | 있음 (k = 14, 17, 20) | 없음 |
| DynamicVLA, Avocado | 23.33 ± 2.36 | 있음 (k = 4, 5, 5) | 없음 |
| PUMA, Avocado | 10.00 ± 0.00 | 있음 | 있음 (값이 같아 구분 불가) |

- PUMA+ 장면 Cup의 31.67 ± 31.71은 시드별 0%, 20%, 75%(k = 0, 4, 15)와 맞습니다. 세 시드의 편차가 극단적이라 이 장면의 평균은 불안정합니다.
- 정수 해로 본 결과 ±는 **모집단 SD(÷3)**로 계산된 것으로 보입니다. 표본 SD(÷2)로 계산했다면 맞는 정수 해가 없었어야 하는데 모든 검사 셀에서 해가 있었습니다. 다만 해가 유일하지 않아 증명은 아닙니다.
- 영향: 같은 데이터를 표본 SD로 읽으면 ±가 약 22% 커집니다(√(3/2) 배). 이 차이는 검정 결과를 바꿀 수 있습니다. 이 분석의 Welch 검정은 논문이 보고한 값을 그대로 썼습니다.

## 3. 토이 검사: 가치 목표 식 (V1–V3)

이 검사는 PhysVAM의 중심 주장을 학습 없이 확인하려는 것이 아닙니다. 식 (2)–(4)를 그대로 옮겨 목표의 성질을 확인합니다. 실행 시간은 0.2초 미만입니다(`analysis/toy_value_target.py`).

- **V1. 범위와 종료 값.** Te ∈ {60, 100, 150, 200, 300, 400}에서 모든 시점의 V_t가 [−1, 1]에 있고, V_{Te−1} = c(e)입니다. **성립.**
- **V2. 지평 클리핑.** Te를 넘는 지평은 종료 값을 갖습니다. **성립.**
- **V3. 목표의 시간 구조와 ±16 변화.**
  - 성공 에피소드의 목표는 모든 Te에서 시점에 대해 **비감소**입니다. 실패 에피소드는 **비증가**입니다. 식 (3)의 지수항이 모두 같은 방향으로 움직이기 때문입니다.
  - 따라서 부록 B.1의 "목표가 모든 잡기 실패 근처에서 증가한다(28/28)"는 사실은 식에서 나옵니다. 상호작용을 봐서 얻은 증거가 아닙니다.
  - 성공 에피소드에서 h = 4 목표의 ±16 변화는 Te와 위치에 따라 0.005에서 0.351까지 달라집니다. 논문이 보고한 목표 쪽 Lift–Miss 차이 +0.043은 이 범위 안에 있으며, 시점 분포에 따라 달라지는 값입니다.
  - 실패 에피소드의 같은 창 변화(Te = 100, 200, 300, 중간 시점)는 −0.33, −0.16, −0.13입니다.

**함의.** 쌍체 차이 +0.277(예측 +0.319 대 목표 +0.043)은 "예측이 목표에 없는 국소 변화를 보인다"는 근거로 쓸 수 있습니다. 목표 쪽 변화는 식 자체가 만든 시간 효과이므로, 이 비교는 상호작용 반응을 목표 대비로 보여 주는 것으로 읽어야 합니다. 과장된 "정답 대비 우위"로 읽으면 안 됩니다(`04` C18).

### 4.3 해석

- 저자가 "PhysVAM은 DynamicVLA, PUMA 기준선 초기화에 쓴 시뮬 미세조정 체크포인트와 같은 출발점인가"를 본문에 쓰지 않았습니다. 이 점이 공정성의 빈칸입니다(`04` C22).
