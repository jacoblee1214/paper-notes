# Play2Perfect 선행연구와 이 저장소의 다른 논문과의 관계

출처 번호 [n]은 논문 참고문헌 번호(v4)입니다. 논문 본문 인용은 "§" 또는 "부록"으로 표시했습니다.

## 1. 선행연구 계보

### 1.1 놀이(play)에서 배우기

| 계열 | 논문 | 이 논문과의 차이 |
|---|---|---|
| 잠재 계획 학습 | Lynch 외, Learning latent plans from play [22] | 사람이 원격조작한 놀이 데이터. 이 논문은 RL로 로봇 놀이를 만듭니다 |
| 인간 놀이 영상 | MimicPlay [23] | 사람 손 영상 기반 계획. 로봇 접촉 정보가 없습니다 |
| 과제 무관 놀이 + 원격조작 | Kedia 외 SimToolReal [25] | **같은 저자 그룹.** 객체 중심 정책, 데모 기반 테스트 시 적응. 이 논문은 "놀이를 사전학습으로 쓰고 희소 보상으로 정밀 조립을 미세조정"합니다 |
| 과제 무관 점 추적 | Dex4D [24] | 점 추적으로 일반화. 목표는 6D 자세 대신 점 추적입니다 |

§2는 "놀이 정책을 제로샷으로 쓰고 정밀 접촉 과제에는 약하다"는 점을 이 논문의 출발점으로 씁니다.

### 1.2 다지 손 조작과 강화학습

- 기초: Andrychowicz 외 in-hand 조작 [9], Dextreme [10], 손 재배향 Visual dexterity [8].
- 밀집 보상 접촉 과제: Lin 외 two-hand lids [11], Chen 외 Sequential Dexterity [12]. §2의 "밀집 보상에 의존" 계열입니다.
- 사람 손 참조 학습: ManipTrans [47], Dex 계열 [48, 49].
- 원격조작으로 워밍업: [50, 51].
- 잔차 RL: Ankile 외 "From imitation to refinement" [18] (병렬 그리퍼 조립). 이 논문은 같은 "사전 정책 + RL 정제" 구조지만 사전 정책을 원격조작이 아닌 놀이로 만듭니다.
- 재설정 분포 기반 탐색 [54]: 조립 분해(assembly-by-disassembly)와 같은 계열이며, 논문 §3.2에서 그 방식을 빌립니다.

### 1.3 조립 벤치마크와 희소 보상 조립

| 논문 | 역할 |
|---|---|
| Fabrica [21] | 다중 부품 조립 벤치마크. 이 논문의 빔 과제 원형(3배 확대 적용) |
| FurnitureBench [26] | 의자 다리 스크류 과제 원형(3배 긴 다리로 변형) |
| IndustReal [19], AutoMate [20] | 밀집 보상·사람 설계 보상 조립 기준선 |
| Juicer [17] | 원격조작 모방 조립 |
| FMB [13], Shao 외 [14] | 고정구 설계로 조립 난이도를 낮추는 계열 |
| RoboCook [16], Fit2Form [15] | 전용 도구·그리퍼 설계 계열 |

### 1.4 사전학습 기반 일반 손 정책

- VLA 계열 [55–57], OXE 등 데이터셋 [58, 59]: 병렬 그리퍼 중심이라는 점을 논문이 지적합니다.
- 사람 영상으로 손 사전학습 [60–62, 33].
- DexWild [33], DexUMI [34], DexOp [35]: 사람 손 인터페이스.

### 1.5 이 논문이 쓰는 도구

- SAPG (Split and Aggregate Policy Gradients) [64]: 대규모 병렬 PPO 변형, 부록 I.
- FoundationPose [66]: 실로봇 6D 자세 추적, 학습 없이 CAD 메시로 추적.
- Isaac Sim 시뮬레이션(부록 H).

## 2. 가까운 대안 (이 논문이 비교하는 대상과 비교하지 않는 대상)

| 대안 | 이 논문이 비교했나 | 메모 |
|---|---|---|
| 사전학습 없음 + 희소 보상 | 예 (Fig. 4, 5) | 24 h에 성공 0 |
| 사전학습 없음 + 밀집 보상 | 예 (Fig. 4, 5) | 같은 시간에 실패, 고정구 단순화 시 100 h 이상 |
| 사전학습만 (미세조정 없음) | 예 (Fig. 7, Table 1 해석) | 정밀 삽입 실패 |
| 원격조작 모방 (Juicer, 잔차 RL [18]) | **아니오** | 비교 없음. 원격조작 데이터 비용 비교가 빠져 있습니다 |
| 사람 손 참조 RL (ManipTrans 계열) | 아니오 | 비교 없음 |
| 고정구·전용 그리퍼로 단순화 | 아니오 | 논문은 "특수 장비 없이"를 주장하므로 비교가 필요한 지점 |
| SimToolReal [25] (같은 저자) | 아니오 | 같은 연구 흐름. 차이를 직접 설명하지 않습니다 |

## 4. 주장 관점에서 정리한 선행 연구 질문

1. "놀이 사전학습"이라는 주장은 Lynch [22]와 SimToolReal [25] 대비 무엇이 새로운가. 답: 원격조작 없이 RL로 만든 6D 목표 놀이 정책. 이 차이가 논문 헤드라인입니다.
2. 6D 목표 대 평행이동 목표 비교는 "보상 설계" 문제인가 "데이터 다양성" 문제인가. 논문은 보상 (Fig. 6) 쪽으로 해석합니다.
3. 조립 벤치마크 수정(3배 확대)이 결과에 얼마나 영향을 주는가. 논문은 추적 가림 때문이라고 설명하지만 확대 전후 비교 실험은 없습니다 (부록 D는 그림만).
