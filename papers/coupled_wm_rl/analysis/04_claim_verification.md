공식 코드가 공개되어 있지 않습니다(프로젝트 페이지의 "Code (release soon)" 단추만 있음, 확인 2026-11-24, `02_prior_work.md` §4). 그래서 논문과 코드의 대조(D 항목) 대신 **논문의 주장을 근거와 하나씩 맞춰 보는 검증(C 항목)** 을 씁니다. 근거는 `03_analysis.md`의 점검 V1–V8과 토이 T1, 논문의 절·표·그림 번호입니다. 판정은 "지지", "방향만"(방향은 맞으나 통계적으로 구분되지 않음), "조건부"(조건을 달면 성립), "확인 불가"(근거 자료가 없음)입니다.

## 2. 코드 없이 구현할 때 논문에 있는 것과 없는 것

논문과 부록(표 4, 알고리즘 1, 식 1–3, 부록 A.7)에서 **있는 것**: 호라이즌 H = 16, 액터 128, 감마 0.99, 람다 0.95, 미니배치 1024, 에폭 8, AdamW(0.7, 0.95), 학습률(액터 2e-3, 크리틱 5e-4, 엔트로피 5e-3), 비평가 10개 앙상블, 엔트로피 정규화 식, 국소 RSSM 크기(순환 1024 또는 4096), 전역 모델 층 수와 차원, 확산 단계(3 또는 4), 컨텍스트 길이, 모델 갱신 횟수(첫 에폭 10,000, 이후 64), BC(ACT) 설정.

**없는 것**(구현자가 정해야 함): 실로봇 평가 프로토콜(제한 시간, 시드, 배포 정책 선택), 보상 모델의 라벨 부여 규칙 상세(버튼 입력의 타이밍, 라벨 값 10의 근거), Push-T 대조 에너지 모델의 구조와 학습 설정, shortcut 학습과 diffusion forcing의 세부 설정, 학습 곡선의 이동 평균 창, 그림 5 정규화의 lo, hi 범위, 데이터 수집 정책(놀이 데이터를 어떤 규칙으로 모았는지의 분포), 시드 간 분산(그림 8에 음영만 있음). 이 항목들은 공식 코드나 원자료가 있어야 확인됩니다.

**부분 공개된 재료**(같은 연구실, `02_prior_work.md` §4): `machines-in-motion/dreamer-v4`(GPL-3.0, 토크나이저와 동역학 모델, KV 캐시 실시간 환경, 체크포인트는 HF에 공개, RL 코드 없음), `machines-in-motion/DMO_code`(DMO-SHAC, 이미지 공간 코드 없음, DMO-SAPO는 "coming soon"). 공식 이미지 공간 DMO-SAPO 코드, 놀이 데이터, 보상 라벨, 체크포인트는 공개되지 않았습니다.

## 3. 이 분석에서 확인한 것과 하지 않은 것

- 확인: 표 1–3의 정수성과 Wilson, Fisher, Welch 검정, 부록 A.3 비율, 차원·시간·데이터 합 산술, 그림 5와 8의 판독(그림 판독 값), 분리 기울기의 방향성(토이 T1).
- 하지 않음: 어떤 학습도, 공식 체크포인트나 데이터 다운로드도, 실로봇이나 GPU 재현도 하지 않았습니다. 학습 곡선의 시드별 값은 논문에 없어 곡선 간 차이의 유의성은 계산하지 못했습니다.
- 공식 코드가 공개되면 이 문서의 C9–C11을 코드 대조(손실, 하이퍼파라미터, 평가 프로토콜)로 바꿔 확인하는 것이 좋습니다.

## 4. 구현 가능성 (Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)

**판정: 논문 전체의 재현은 이 맥에서 불가능합니다. 알고리즘의 핵심(분리형 기울기, DMO-SAPO 루프)을 저차원 또는 소형 이미지 환경으로 축소해 구현하는 것은 가능합니다.** 공식 코드가 없으므로 모든 단계가 논문만 보고 직접 짜는 구현입니다.

| 수준 | 판정 | 필요한 것 | 근거 |
|---|---|---|---|
| 실로봇 실험(Push-T, Go2, G1, 표 1–3) | 불가 | Flexiv Rizon-10S, Go2, G1과 BrainCo 손, SONIC, 놀이 데이터 | 하드웨어가 저장소 밖에 있음 |
| 전역 세계모델 학습(Push Cube 1.0B, G1 1.4B) | 불가 | 24–64 H100/H200, 12–20.9 h 놀이 데이터(비공개) | 표 4의 Compute 항목. 이 맥은 24 GiB에 CUDA 없음 |
| Push-T 전역 모델(DIAMOND 4M) | 조건부 | 4 h 놀이 데이터 또는 공개 Push-T 이미지 데이터, 64 x 64 확산 모델 구현(MPS), 데이터 다운로드 승인 | 논문은 RTX4090 한 장에서 학습. 모델이 작아 MPS로 가능성은 있으나 학습 시간은 측정 전. 4 h 데이터는 비공개 |
| DMO-SAPO 전체 루프의 축소판(저차원 연속 제어, 진자 또는 MuJoCo) | 가능 | torch(설치됨), mujoco(설치됨), 새 설치 없음 | 분리 기울기, 국소 RSSM, 10개 앙상블 비평가, 엔트로피 정규화를 식 1–3과 알고리즘 1대로 구현. 기울기 정렬은 이미 토이 T1(`03` §6)으로 확인 |
| 비용 산술과 그림 판독 재계산 | 가능, 완료 | numpy | `03` V3, V5 |
| 부록 A.3의 기울기 정렬, 비용 재현(G1) | 불가 | G1 세계모델과 45.6 GB 역전파 | 모델이 비공개 |

- **노력 추정(측정 전 추정):** 저차원 환경의 DMO-SAPO 축소 구현은 3–5일(식 1–3, 알고리즘 1은 논문에 완전히 있음). 소형 이미지 환경(2D Push-T 직접 렌더링, 작은 확산 세계모델을 MPS에서)은 2–3주이며, 세계모델이 만든 표본과 실제 시뮬레이터 표본의 차이를 평가할 수 있다는 장점이 있지만 논문의 이미지 확산 구성과 같지 않습니다. 1B 규모의 DreamerV4식 모델은 이 맥의 범위를 벗어납니다.
- **재현 승인 필요:** 데이터 다운로드(공개 Push-T 이미지 데이터를 쓴다면 크기 확인 후), 새 환경 설치. 직접 짠 torch/mujoco 스크립트는 사용자 승인 범위 안에서 가능합니다.
