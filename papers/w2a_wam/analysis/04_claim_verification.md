# 04. 주장 대조와 구현 가능성

공식 코드가 아직 없습니다(`02` §2: 저자 계정의 `W2A_code`는 README 한 줄뿐). 그래서 코드와 논문의 대조(D 항목) 대신 **논문의 주장(C 항목)을 표·그림 수치와 대조**합니다. 근거는 `03`의 계산(V, K 항목)과 원문 위치입니다. 판정 어휘는 다음과 같습니다.

- **지지**: 표·그림 수치가 주장과 맞고 가능한 대안 설명이 약함.
- **부분 지지**: 수치는 맞지만 비교 조건이나 해석이 열려 있음.
- **방향만**: 효과의 방향은 맞지만 시행 수나 시드 때문에 크기·순서를 확정하기 어려움.
- **미검증**: 논문 안의 증거로는 판단할 수 없음.

## 2. 판정 요약

- **지지:** C1(산술), C4(유형 수준), C7(증류 효과 크기), C10(구조화된 교사 필요).
- **부분 지지:** C2, C3, C6, C8, C11, C12, C13, C15, C16.
- **방향만:** C9, C14, C18.
- **미검증 또는 조건 불명:** C5, C17, C19, C20, C21.

핵심 인상: 이 논문의 가장 강한 증거는 **증류 제거 효과(−11.5)와 통제 교사 실험(표 5)**이고, 가장 약한 곳은 **기준선 비교의 조건(표 1의 두 행, 지연의 기준선 조건)**과 **교사 잠재의 생성 방식(C20)**입니다. 공식 코드가 공개되면 우선 C20, C5, K1–K3을 코드에서 확인할 수 있습니다.

## 3. 구현에 필요하지만 논문에 없는 설정

코드가 없으므로 아래 항목은 재구현 때 정해야 합니다.

1. 교사 잠재의 생성 방식(생성 vs 정답 미래 잡음화)과 사용하는 시간 토큰(`03` K1).
2. LoRA 순위와 적응 데이터, 1단계 학습 길이와 하드웨어.
3. PCA를 적합하는 표본 집합 크기와 갱신 여부.
4. Q-Former의 쿼리 수 배치(그룹당 14×14 = 196개로 읽힘), 은닉 128 → 출력 482 투영(K2).
5. 추론 순전파 횟수(20스텝 vs 웜스타트 후 약 10스텝)와 지연 측정 조건(K3).
6. 시드의 의미(학습/평가)와 절제의 시드 수, K·깊이 선택에 쓴 데이터.
7. LIBERO와 CALVIN의 평가 횟수, 기준선 행의 출처.

## 4. 구현할 수 있는가 (이 맥: Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)

**전체 재현은 불가능합니다. 학생 모델과 증류 구조의 축소 재구현은 이 맥에서 가능하고, 이미 표 재계산(V)과 구조 토이를 끝냈습니다.**

| 단계 | 필요한 것 | 이 맥 | 노력 (추정) |
|---|---|---|---|
| 표 재계산, 일관성 검사 | 논문 PDF | 가능, 완료 (`recompute.py`) | 완료 |
| 구조 토이 (PCA 증류, 통제 교사) | torch CPU | 가능, 완료 (`toy_pca_distill.py`, 약 1분) | 완료 |

- **GPU·로봇·데이터가 필요한 것:** 교사 LoRA 적응과 증류 학습(CUDA), CALVIN ABC→D 학습·평가(대용량 데이터), 실로봇 750개 시연과 평가, 지연 55 ms의 A100 측정.
- **이 맥에서 할 수 있는 것:** 학생 모델의 구조·크기·MPS 순전파 시간, 소형 교사로 증류 구조의 방향성(통제 교사, K 훑기), 논문 수치의 재계산.
- 공식 코드가 공개되면 체크포인트 추론의 MPS 포팅 가능성을 다시 볼 수 있습니다(가중치 크기는 공개 전이라 모릅니다).
