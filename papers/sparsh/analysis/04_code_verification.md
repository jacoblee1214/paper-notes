# 04. 공식 코드 대조와 구현 가능성

공식 저장소 `facebookresearch/sparsh`(커밋 `fee6a05`, 2025-02-27, archived)를 얕은 복제해 **정적으로만** 읽었습니다(`repo/`, gitignore). 설치하거나 실행하거나 import하지 않았습니다. 복제된 내용은 신뢰하지 않는 데이터로 취급했습니다. 대조 기준은 논문 본문 §3·§5–7과 부록 B–E, 표 1(학습 설정)입니다.

## 1. 권리와 라이선스

- **논문 (arXiv 라이선스):** 초록 페이지의 라이선스 링크는 `licenses/nonexclusive-distrib/1.0` ("view license")입니다. **CC BY 4.0이 아닙니다.** PDF에는 ©, copyright, All rights reserved 문구가 없습니다.
- **판정:** 공개본(`publish/`, `report_public.pdf`)에 논문 그림은 넣지 않았습니다. 그래프는 모두 직접 그린 것입니다(`report/figures/own_*.png`). 표 수치는 인용하고 출처를 적습니다.
- **공식 코드:** `LICENSE.md` = **Attribution-NonCommercial 4.0 International**. 연구·비영리 목적으로만 쓸 수 있습니다. 공개본에 코드는 넣지 않습니다.
- **가중치:** Hugging Face `facebook/sparsh`. 모델 카드에 license 필드가 없고 저장소 README는 "LICENSE" 링크만 둡니다. 가중치의 조건은 확인하지 못했습니다. 이 분석에서 다운로드하지 않았습니다.

## 2. 저장소 상태

- 아카이브 상태(`archived: true`), 마지막 커밋 2025-02-27. 이후 유지보수 없음.
- `setup.py`·`environment.yml`은 CUDA 전제의 conda 환경(`tactile_ssl`)입니다.

## 3. 논문과 코드의 차이 (D1–Dn)

차이는 정적 읽기로 본 것입니다. "확인 필요"는 실행이나 가중치 확인 없이는 결론을 낼 수 없다는 뜻입니다.

| 번호 | 항목 | 논문 | 공식 코드 | 판정 |
|---|---|---|---|---|
| D1 | 사전학습 에폭 | 150 (§C.1, 표 1 "All models run for 150 epochs") | 5개 실험 설정 모두 `trainer.max_epochs: 200` | **불일치** |
| D2 | 입력 해상도 | 224×224로 바꿔 ViT에 넣음 (§3, C.2) | `img_size: [320, 240]`, 데이터 `resize: [320, 240]` | **불일치** |
| D3 | 패치 크기 | ViT-B/14 (표 1) | `vit_base(patch_size=16)` 기본값. 모델 설정도 16 | **불일치** |
| D4 | I-JEPA 학습률 | 6.25e-4 (표 1) | `ijepa_vit.yaml`: `lr: 1e-3` | **불일치** |
| D5 | V-JEPA 학습 세부 | EMA 0.996, 웜업 30 에폭 (표 1) | `vjepa_vit.yaml`: EMA `[0.997, 1.0]`, 웜업 40 에폭, 시작 학습률 2e-4 | **불일치** |
| D6 | 배치 크기 | 표 1의 "Batch size"(MAE 100, 나머지 150으로 읽힘) | 데이터 설정 기본 64, DINOv2 실험 32 | **불일치 또는 표 해석 오류**. 표 1 열 배치가 불명확 |
| D7 | DINOv2 설정 | 표 13·그림에 DINOv2 결과가 있음 | 설정 있음 (학습률 0.002, 배치 32, 중심화 `centering`). **표 1과 부록 C에는 DINOv2 설정이 없음** | **문서 누락** |
| D8 | DINO 레지스터 | "DINO는 ViT 레지스터로 클래스 출력" (C.2) | `model/dino_vit.yaml`에 `num_register_tokens: 1` | 일치 (실험 설정으로 상속되는지는 실행 없이 확정 불가) |
| D9 | EMA·스케줄 (DINO, I-JEPA) | EMA 0.998·0.996, 가중치 감쇠 코사인 0.04→0.4, 웜업 30 (표 1) | DINO: EMA 0.998, 웜업 30, WD 0.04→0.4. I-JEPA: EMA 0.996 | 일치 |
| D10 | 입력 시차와 프레임 | 두 장, 시차 5 (§3). V-JEPA 4프레임 간격 2 (§3) | `num_frames: 2, frame_stride: 5`, V-JEPA `num_frames: 4, frame_stride: 2` | 일치 |
| D11 | 배경 제거 | DIGIT·GelSight Mini에서 무접촉 배경 차감 (§3) | `remove_bg: true` | 일치 |
| D12 | 객체 분할 | YCB-Slide 10 객체 × 5궤적, 4 학습·1 검증 (C.3) | `dataset_ids_train: [0–3]`, `val: [4]`, 19개 객체(YCB 10 + Touch-Slide 9) | 일치 |
| D13 | 힘 손실 | "L1 loss" (§5.1) | `F.smooth_l1_loss(..., beta=0.02)` (`force_sl.py`) | **부분 불일치**. Huber형이 L1과 다름 |
| D14 | 힘 디코더 | 2층 MLP 192·3, Adam 1e-4 (D.3) | 과제 설정 Adam 1e-4, 51 에폭 | 일치. 학습 "수렴까지"(D.3)와 51 에폭의 관계는 미기재 |
| D15 | 슬립 라벨 마찰계수 | 논문 본문 **값 없음** ("실험적으로 추정", §5.3·D.5) | 라벨 스크립트 기본값 μ = 1.6, 접촉 임계 0.04 N, 주파수 70 Hz (`scripts/slip_labelling.py`). 기본 입력 경로가 다른 센서 데이터 이름 | **누락**. 재현에 필요한 값이 논문에 없음 |
| D16 | 자세 추정 빈 경계 | ±5 mm, ±2° 분해능 (§6.1) | `bins_translation [0.1…5.0]`, `bins_rotation [0.03…2.0]` (단위 미기재) | 부분 일치. 단위 확인 필요 |
| D17 | T4 데이터 규모 | 부록 C.3 "100 unique objects" | 저장소 README "약 9k trials over 100k objects" | 문서 오타로 보임 |
| D18 | 인용 번호 | T4를 [4](DigiTac)로 인용 (C.3) | 본문 T4 인용은 [8] | **논문 내 인용 오류** |
| D19 | T6 시연 수 | §7.1 50회, D.9 30회 | 저장소에 T6 설정은 없음 (확인 불가) | **논문 내 불일치** |
| D20 | 가중치 패치 크기 | 논문 표 1은 ViT-B/14 | HF 가중치 `dino_vitbase`의 패치 크기는 다운로드 전 확인 불가 | 확인 필요 |

- 논문의 주장 방향을 바꾸는 차이는 없습니다. D1–D5는 학습 설정 차이라서 수치 재현에 영향을 줍니다. D13·D15는 평가 정의에 영향을 줍니다.
- 논문 표 1은 MAE·DINO·I-JEPA·V-JEPA만 있고 DINOv2는 없습니다(D7). 본문 표에는 DINOv2가 있습니다.

## 4. 구현 가능성 판정

**결론: 이 맥(Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)에서 논문 전체 재현은 불가능합니다. 추론과 동결 특징 평가는 조건부로 가능합니다.** 아래 노력 추정은 측정 전 추정입니다.

| 작업 | 필요 자원 | 이 맥 | 판정 |
|---|---|---|---|
| 사전학습 전체 (ViT-B, 150–200 에폭, 46만 장) | A100 80GB 8장 (논문 C.1) | 불가 | **불가** |
| 사전학습 축소판 (ViT-S 또는 작은 데이터, 목적 함수 재구현) | MPS 또는 CPU, 데이터 수 GB | 소규모 가능성 | **조건부** (추정 1–2주 구현) |
| 공식 가중치로 추론 (DINO ViT-B, 345 MB safetensors) | 가중치 다운로드 승인, 공식 코드 설치 승인 | 순전파 가능성 높음 (측정 전) | **조건부** (승인 후 1–2일 추정) |
| 동결 특징 + attentive probe, 슬립·자세 소예산 | 데이터 다운로드(크기 미확인), 특징 추출 | 특징 추출 MPS 가능성 | **조건부** |
| 힘 추정 (DIGIT·GelSight Mini) | 데이터 다운로드 | 조건부 | **조건부** |
| 실로봇 bead maze, 실로봇 정책 | Franka 등 실로봇, 힘 제어 | 불가 | **불가** |
| 표 재계산과 CI·검정 점검 | 보고 수치만 | 완료 | **시작 완료** (`03`) |

- 재구현 노력 추정: 목적 함수(DINO, I-JEPA, MAE)를 작은 데이터에서 맞추는 소형 버전은 2–3주(추정, 측정 전). 공식 가중치를 쓰는 평가 파이프라인은 승인 뒤 수일입니다.
- 차이 D15(마찰계수)와 D7(DINOv2 설정)은 재현 전에 저자에게 확인해야 하는 항목입니다.
