## 1. 한눈에 보기

- **무엇을 주장하는가.** 모델 기반 RL인 EfficientZero(MCTS 기반, 이산 행동만 가능)를 **연속 행동 공간까지** 확장하고, 저데이터 설정에서 DreamerV3보다 여러 벤치마크에서 낫다는 주장입니다(Abstract, §1 Figure 1).
- **핵심 아이디어 두 가지.**
  1. **샘플링 기반 Gumbel 탐색(§4.2).** 연속 행동을 K=16개 샘플(현재 정책 pt에서 일부, 평평하게 만든 분포 p't에서 일부)로 줄이고 Sequential Halving으로 고릅니다. 정책 개선 조건 식 (6)–(7)을 보입니다.
  2. **탐색 기반 가치 추정 SVE와 혼합 가치 목표(§4.3, 식 (10), (16)).** 오래된 전이(stale transition)에는 탐색 결과로 만든 가치를 쓰고, 최근 전이에는 다단계 TD 목표를 씁니다.
- **주요 수치(논문 값).** Atari 100k 정규화 평균 2.428 / 중앙값 1.286(Table 1). DMC Proprio 100k 평균 723.2, Vision 200k 평균 726.1(Table 2). "66개 과제 중 50개에서 DreamerV3보다 우수"(Abstract).
- **이 분석의 가장 큰 발견.** 공개된 표 값으로 다시 계산하면 Atari 정규화 평균은 **2.680**이고 논문 값 2.428과 맞지 않습니다. 또 "66개 중 50개"는 표에서 **56/65**로 나옵니다. 자세한 수치는 `03_analysis.md` §2–§3에 있습니다.

## 2. 문제 설정과 배경 (§1–§2)

- **문제.** 실제 환경에서 데이터는 비싸므로 샘플 효율이 중요합니다(§1 첫 단락). 논문은 "여러 영역에서 일관되게 최고인 알고리즘이 없다"는 점을 출발점으로 삼습니다(§1, 두 번째 단락).
- **비교 대상 계보.**
  - TD-MPC / TD-MPC2: MPPI 계획. 많은 잠재 상태 예측 비용이 큼(§1).
  - EfficientZero: MCTS 기반, 이산 행동 전용(§1, §2.2).
  - DreamerV3: 범용이지만 특정 영역에서 SOTA와 차이가 큼(Figure 1).
  - Gumbel MuZero: 큰 행동 공간의 탐색 비용을 줄이지만 연속 행동에는 확장되지 않음(§2.2).
  - Sampled MuZero: 연속 행동용 샘플 MCTS. 본 논문은 이보다 시뮬레이션 수가 적다고 주장(§2.2, Fig. 3).
- **자기 위치.** "EfficientZero를 연속 제어로 확장하고, 탐색과 가치 추정을 바꿨다"는 것입니다(부록 A, 요약 표).

## 3. 방법 (§3–§4)

### 3.1 모델 구성 (§3.3.1)

표현 H, 동역학 G, 보상 R, 가치 V, 정책 p의 다섯 부분입니다. 표현 H는 관측을 잠재 상태로, G는 잠재 상태와 행동 임베딩을 받아 다음 잠재 상태와 보상을 예측합니다. 보상과 가치는 51개 구간의 범주형 표현을 씁니다(부록 G).

### 3.2 학습 목표 (§3.3.2, 식 (3)–(5))

전체 손실은 보상 손실 LR, 정책 손실 LP, 가치 손실 LV, 일관성 손실 LG의 가중합이며, 계수는 λ1=1.0, λ2=1.0, λ3=0.25, λ4=2.0입니다(Table 3). 일관성 손실은 SimSiam식 음의 코사인 유사도이고(식 (4)), 언롤 길이 l_unroll=5만큼 펼쳐 평균합니다(식 (5)).

### 3.3 샘플링 기반 Gumbel 탐색 (§4.1, §4.2, 부록 B)

- **Gumbel top-k 아이디어.** 이산 분포에서 Gumbel 잡음으로 중복 없이 상위 n개를 뽑는 방법입니다(§3.2). 원래 Gumbel MuZero는 이산 행동만 다룹니다.
- **연속 확장.** 각 상태에서 K개 행동을 샘플합니다. 일부는 현재 가우시안 정책 p_t에서, 나머지는 p_t를 평평하게 만든 p'_t에서 뽑습니다(§4.1). 이렇게 하면 p_t 아래 확률이 낮은 행동도 탐색할 수 있습니다.
- **정책 개선 조건.** 선택된 행동 a*_S가 식 (6), 즉 q(s, a*_S) ≥ E_{a~p_t}[q(s,a)]를 만족하면 정책 개선이 보장된다고 정의합니다(Definition 4.1). 식 (7)에서 |A_S1|→∞일 때 대수의 법칙으로 이 조건을 보입니다. 부록 A는 연속 설정에서도 이 증명이 성립한다고 말합니다.
- **비루트 노드.** 비루트에서는 p_t에서만 샘플하고 개수를 줄여 탐색 깊이를 늘립니다(§4.1).
- **목표 정책.** 탐색 후 두 종류의 목표를 만듭니다. (a) 추천 행동 a*_S, (b) 루트 행동의 Q값 기반 분포(부록 B에서 연속 설정 수정식 제시).

### 3.4 정책 학습 (§4.2.2, 식 (8)–(9))

정책 p_t를 목표 정책 π_t와의 교차 엔트로피로 학습하고(식 (8)), 고차원 행동 공간에서는 추천 행동 a*_S의 로그우도도 함께 씁니다(식 (9)). 식 (9)가 빠른 초기 착취에 도움이 된다고 주장하며, 예로 DMC Quadruped Walk를 듭니다(부록 C 예시).

### 3.5 탐색 기반 가치 추정 SVE와 혼합 목표 (§4.3, 식 (10)–(16))

- **SVE(식 (10)–(11)).** 탐색 트리에서 나온 N개 부트스트랩 추정의 평균을 목표 가치로 씁니다. 같은 탐색 과정이 정책 재분석(MuZero의 reanalysis)을 대신하므로 추가 계산이 없다고 말합니다.
- **오차 상한(Theorem 4.3 / Corollary 4.3, 식 (12)–(15)).** 모델 오차 ε_s, ε_r, ε_v가 있을 때 SVE 오차가 어떻게 커지는지 보입니다. 결론은 모델이 부정확한 초기 학습이나 새 전이 샘플링에서 오차가 커진다는 것입니다. 이것이 혼합 목표를 쓰는 이유입니다.
- **혼합 목표(식 (16)).** 학습 초기 T1 = 4×10⁴ 스텝 이전이거나 버퍼 인덱스가 |D|−T2(T2 = 2×10⁴) 이후인 전이는 다단계 TD 목표, 그 밖은 SVE 목표를 씁니다. 부록 F는 "최근 전이는 TD, 오래된 전이는 SVE"라고 풀어 씁니다.
- **우선순위 사전 계산(부록 A).** 새 궤적의 우선순위를 최대값으로 두지 않고 현재 모델로 계산한 베르만 오차로 초기화합니다.

### 3.6 구조와 학습 설정 (부록 G–I)

- 1차원 관측: 실행 평균 정규화 → 선형층 → LayerNorm·tanh → Pre-LN 잔차 3블록(폭 128). 정책 평균은 5·tanh로 자르고 표준편차는 softplus로 만듭니다.
- 이미지: EfficientZero 구조를 따릅니다.
- 공통: 배치 256, 할인율 0.997, TD 단계 5, 언롤 5, 버퍼 10⁶, 시뮬레이션 32(Atari는 16), 샘플 행동 K=16(Atari는 8)(Table 3).
- 옵티마이저: 저차원 DMC는 Adam(lr 3×10⁻⁴), 이미지 DMC와 Atari는 SGD(lr 0.2, momentum 0.9)(Table 3, 부록 I.1).
- **중요.** 부록 I.1은 "EZ-V2 하이퍼파라미터는 여러 영역에 맞게 튜닝했다"고 하고(부록 A, 마지막 항목), 기준선은 "저자 권장값을 쓰고 없으면 튜닝했다"고 합니다. 튜닝 예산과 방식은 공정하게 맞춰지지 않았습니다(`04` D9 참고).

## 5. 주요 결과 (§5.2, Table 1–2)

- **Atari 100k.** 정규화 평균 2.428, 중앙값 1.286. BBF(2.247 / 0.917)보다 높다고 보고합니다(Table 1). 본문은 BBF보다 파라미터와 재생 비율이 낮다고 말합니다.
- **Proprio.** 평균 723.2(Proprio 100k 블록 표기). TD-MPC2(740.9)와 비슷하고, 추론 시 32개 잠재 상태만 씁니다. TD-MPC2는 MPPI로 9216개를 예측합니다(본문).
- **Vision.** 평균 726.1로 DreamerV3(498.5)보다 45% 높다고 합니다. 20개 과제 중 16개에서 새 기록(본문, Table 2).
- **희소 보상.** Cartpole Swingup Sparse에서 763.6 대 DreamerV3 392.4(Vision 200k, Table 2).
- **계산량(부록 J.3, Table 7).** 파라미터 1.3×10⁶ 대 4.9×10⁶, 결정 단계당 FLOPs 4.7×10⁷ 대 3.6×10¹⁰, 10만 스텝 학습 시간 2.7 h 대 3.3 h(8×RTX 3090). 본문은 FLOPs가 "1000배 적다"고 씁니다(`03` V9 참고).

## 6. 절제 실험 (§5.3, 부록 J.2, Table 4–6)

- **탐색.** 샘플 MCTS(n=50)보다 S-Gumbel(n=32)이 낫고, n=8만으로도 샘플 MCTS를 이긴다고 합니다(Figure 3).
- **가치 목표.** 혼합 목표가 다단계 TD, GAE, 이중 Q 목표보다 낫다고 합니다(Figure 4, Table 4–6).
- **표.** Table 4(Proprio, 7과제): 원본 대 다단계 TD 6승 1패(정확 Wilcoxon p=0.031), 대 GAE 7승(p=0.016), 대 샘플 MCTS 7승(p=0.016). 시드 수와 분산 정보가 없어서 이 p값은 "과제 사이" 비교일 뿐입니다(`03` §4).
- **한계.** 절제 실험은 Atari에서 3게임만 씁니다(부록 J.2).

## 7. 논문이 스스로 밝힌 한계

- **별도의 한계 절이 없습니다.** v1, v2 모두 Limitations 절이 없습니다.
- **결론의 언급.** 기준선이 더 많은 데이터를 쓸 때는 격차가 줄어든다고 씁니다(§6). 실제 로봇 과제는 향후 과제로 남겨 둡니다(§6, "real-world tasks like robotic manipulation").
- **재현성 한계(분석자 판단).** 시드별 점수와 분산이 없습니다. Atari 시드 수도 없습니다. 하이퍼파라미터 튜닝 불균형이 있습니다.

## 9. 버전 차이 (v1 2024-03-01 → v2 2024-09-12)

- **구조 재편.** v1은 §4.1 개요, §4.2 학습과 계획, §4.3 트리 탐색 정책 학습, §4.4 SVE의 4개 하위절이었습니다. v2는 §3.3.2로 학습 과정을 옮기고, §4를 4.1–4.3으로 줄였습니다. 부록 문자도 바뀌었습니다(v1 F.1 증명 → v2 E.1).
- **정리 이름.** v1 Theorem 4.3 → v2 Corollary 4.3(식 (15)의 내용 비교는 하지 않았습니다).
- **Table 1 EfficientZero 열, Qbert.** v1은 14448.5, v2는 13781.9입니다. 이 바뀜으로 v2 정규화 중앙값(1.116 → 1.090)이 바뀌었지만 **평균 1.945는 그대로**입니다. 평균 1.945는 v1의 14448.5로 계산한 값과 같고(재계산 1.945 / 1.115), v2의 13781.9로 계산하면 1.943입니다. 즉 **v2 표의 EfficientZero 평균 1.945는 v2 표의 Qbert 값과 맞지 않습니다**(`03` V4).
- **저자 소속.** v2에서 Texas A&M 소속 번호가 Shaohuai Liu에 붙었습니다. 저자 명단은 같습니다.
- **Table 2, 평균·중앙값 행.** v1과 v2가 같습니다(값 변화 없음).
- **Atari EZ-V2 정규화 평균 2.428과 중앙값 1.286.** 두 버전이 같습니다.
- **결론.** v2에 "실제 로봇 과제(robotic manipulation)"와 "데이터가 늘수록 격차가 줄어든다"는 문장이 새로 들어갔습니다(텍스트 검색으로 v1에 없음을 확인했습니다).
- 요약: v2는 표를 바꾸지 않은 곳이 많지만, Atari EfficientZero 열의 한 값이 바뀌면서 정규화 평균과 중앙값이 서로 맞지 않게 되었습니다.

## 10. 이 논문에서 가져갈 질문 (분석자 메모)

1. "샘플링 Gumbel + SVE"의 기여를 분리하려면, 시드별 점수가 있어야 합니다. 현재 공개 값은 과제 수준 평균뿐입니다.
2. 연속 제어에서 K=16 샘플과 시뮬레이션 32의 관계가 계산량과 성능을 어떻게 바꾸는지 `03` §5에서 보았습니다.
3. 로봇 적용의 가장 큰 장애는 실시간 계획 비용보다 **모델 오차에 따른 SVE 편향**과 **지연 피드백**일 가능성이 큽니다(추정, 검증 안 함).
