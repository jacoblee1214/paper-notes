핵심은 두 가지입니다. 첫째, v3에서 수집 효율의 근거가 "채택률"에서 "유효 시연 수 + 매칭 예산 성공률"로 바뀌었고, 둘째, 로봇 성공 횟수(17/20 등)는 v1–v3에서 변하지 않았습니다. 즉 평가 자체는 그대로이고 비교 설계와 서술이 보강되었습니다.

## 1. 문제 설정

휴머노이드 전신 조작(쪼그려 앉기, 무릎 꿇기, 던지기, 걷기 + 닦기, 양손 조작)을 로봇 없이 모은 사람 시연에서 학습합니다. 기존 경로는 시뮬 RL(보상 설계, 도메인 무작위화)이나 텔레오퍼레이션(조작자가 균형과 추종 오차를 보상)입니다(§1). UMI류 "로봇 없는 수집"은 손목 궤적만 담아 전신 자유도가 불확정이고, 인체-로봇 형태 차이로 사람 시연이 로봇에게 불가능할 수 있으며, 최신 전신 추적기의 실행 오차(4–6 cm)가 정책 인터페이스를 깨뜨린다는 세 가지 간극을 지적합니다(§1).

## 2. 방법

### 2.1 시연 시스템 (§3.1, 부록 A)

- 하드웨어: UMI 그리퍼 2개(GoPro 손목 카메라, ArUco 그리퍼 폭) + HTC Vive Ultimate Tracker 5개(그리퍼 2, 골반, 발 2). 기지국이 필요 없습니다(부록 A.1). SteamVR이 도는 노트북이 필요합니다.
- **사람-루프 운동학 적응.** 사람 동작을 척도 조정하지 않고 그대로(축척 없는 SE(3)) IK 목표로 씁니다. 척도는 골반 높이에만 적용합니다(부록 A.2). 로봇(Unitree G1, 약 130 cm)이 도달 못 하는 동작은 실시간 IK 미리보기(Mink, Viser)를 보고 시연자가 자세를 바꿔 피합니다. IK 하위 과제는 5개 키포인트 추적, 자기 충돌 회피, 자세 정규화입니다.
- 데이터는 두 갈래로 포장합니다: (고수준) 영상 + 키포인트 궤적 + 그리퍼 폭, (저수준) 키포인트 궤적 + 전신 IK 해(부록 A.3).

### 2.2 조작 중심 전신 제어기 (§3.2, 부록 E)

- 시뮬(Isaac Lab, 4096환경)에서 RL로 전신 기준 동작을 추종합니다. 교사(특권 정보)-학생(실제 상태 + 10개 웨이포인트 명령) 구조, 학생은 DAgger로 증류합니다.
- 기본 보상 r(ē, σ)=exp(−ē/σ²)를 위치·회전·선속도·각속도에 더합니다(식 §3.2, 표 1).
- **적응형 EE 보상** r_EE = 𝟙(‖v_base^ref‖<δ)·Σ r(ē_EE, σ(v_EE^ref)). 기준 EE 속도 0.05→0.10 m/s 사이에서 σ_p를 0.01→0.1 m, σ_θ를 5°→20°로 보간합니다. 가중치를 0→0.5로 올리고 σ_p^min을 0.1→0.01 m로 낮추는 커리큘럼을 학습 10,000–15,000 스텝에 적용합니다(부록 E).
- **가변 속도 증강.** 기준 동작의 재생 속도를 s∼N[0.25,1.25](1, σ²)에서 0.02 s마다 뽑고 σ를 1e-4→1.0으로 올립니다(부록 E, 표 2).

### 2.3 정책 인터페이스 (§3.3, 부록 F)

- 고수준: Diffusion Policy(실제로는 UNet 흐름 정합, DINOv2 ViT-B/14 두 손목 카메라, 입력은 영상 + 하체 관절각), 5 Hz로 2초(10웨이포인트) 상대 키포인트 덩어리를 냅니다(그림 3, 표 3).
- **이전 "예정" 자세를 기준으로** 새 덩어리를 잇습니다(그림 4). 실행된 자세를 기준으로 하면 추종 지연이 경계마다 되돌림을 만듭니다.
- **시각 피드백이 없는 키포인트(골반, 발)는 덩어리 안 상대 변환만** 추적합니다(그림 5). 기본은 3키포인트(그리퍼 2 + 골반), 5키포인트(발 추가)도 시험합니다.

## 3. 실험과 수치

모든 수치는 논문이 적은 성공 횟수이며, 재계산은 `03`에 있습니다.

### 3.1 전신 조작 능력 (§4.1, 그림 6)

| 과제 | 본 방법 | 절제 |
|---|---|---|
| 단일 무릎 줍기 | 17/20 = 85% | 인간 개입 없음 1/10 = 10%, EE만 지정 0/10 |
| 칼 뽑기 | 17/20 = 85%, 칼끝 추종 오차 15.7 mm | 가변 속도 없음 5/10 = 50%, 오차 21.2 mm |
| 장난감 던지기 | 15/20 = 75% | 실행 자세 기준 4/10 = 40% |
| 걸으며 닦기 | EE+골반 15/20 = 75% | EE만 6/10 = 60%, EE+골반+발 7/10 = 70%, 절대 골반 추적 0/10 |

시연은 과제당 100개(단일 환경), 쪼그려 집기만 350개(7환경 × 50, 부록 F.3)입니다.

### 3.2 일반화 (§4.2, 부록 D)

쪼그려 집기에서 학습에 없던 환경 4곳(각 5회) × 보지 못한 물체 6종으로 20회 시도해 14/20 = 70%입니다(환경과 물체를 동시에 새로 함).

### 3.3 수집 효율 (§4.3, 그림 7, 부록 C)

- 칼 뽑기 15분 세션: HuMI 유효 시연 60개, TWIST2(텔레옵) 18개(3배 이상).
- 매칭 예산(같은 총 시연 시간 약 22분): HuMI 85% 대 TWIST2 50%. TWIST2 쪽 시도 수는 적혀 있지 않습니다.
- 양손 집어 놓기 시연 100개: 6.3분 대 TWIST2 논문 보고 18.5분. 단일 무릎 줍기: 15분에 50개, TWIST2는 불안정으로 0개(부록 C.2).
- IK 미리보기: 없이 모은 20개 중 6개(30%)만 운동학적으로 가능, 있으면 100%. 오른손-골반 거리 76.7 → 90.7 cm(부록 A.2, 그림 10).

### 3.4 적응형 EE 보상 절제 (부록 C.1)

쪼그려 집기에서 균일하게 빡빡한 EE 허용 오차(σ_p=0.01 m, σ_θ=5°, w=0.5)로 바꾸면 17/20 = 85% → 5/10 = 50%. 본문은 이를 "적응형 보상의 결정적 역할"이라 서술합니다.

## 4. 한계 (§5)

(1) 추적기가 환경 텍스처와 조명에 의존, (2) 저수준 제어기가 과제별이고 가끔 균형을 잃음, (3) 미지의 임베디먼트 일반화 없음, 단일 휴머노이드(G1)만 평가.

## 5. 주장과 근거의 간격 (요약)

1. 보고된 모든 비교는 칸당 10–20회입니다. 절제 8개 비교 중 **큰 효과는 3개**(인간 개입, EE만, 절대 골반 추적)만 Holm 보정 뒤에도 유의하고, 가변 속도(p = 0.078), 실행 자세 기준(p = 0.108), 적응형 EE 보상(p = 0.078)은 유의하지 않습니다(`03` K2). "EE만 대 EE+골반"(p = 0.43)도 같습니다.
2. "70% 미지 환경"은 14/20이고 구간이 48–86%입니다. 같은 과제의 정의역 내 성공률과 직접 비교하지 않았습니다(`03` K4).
3. "3배 수집 효율"은 한 세션 대 한 세션이고 칼 뽑기 한 과제입니다. 다른 과제 배율은 2.9배(100개 시연)이고 HuMI의 분당 시연 수는 과제에 따라 4.0에서 15.9로 다릅니다(`03` K5).
4. 매칭 예산 비교는 시연 수가 다른 두 정책(HuMI 약 100개, TWIST2 약 26개, 추정)을 비교하므로 "수집 시간당 성능"을 말하는 것이지 인터페이스의 품질 차이를 분리하지 않습니다.
5. 논문은 평가 롤아웃의 시드, 초기 조건 무작위화, 정책 체크포인트 선택 규칙, 성공 판정 기준을 적지 않았습니다(표/본문 어디에도 없음).
