## 3. 재현 장벽 (정적으로 확인한 것)

- **CUDA 전제.** `train_eval.py`의 기기 설정은 `cuda:{gpu}`만 씁니다(112–113행). README는 CUDA 12.x와 DGL cu124와 `diff-gaussian-rasterization-w-depth` 빌드를 요구합니다. 이 맥에는 CUDA가 없습니다.
- **Warp 버전 고정.** `requirements.txt`는 `warp-lang==1.1.0`, `numpy==1.26.4`입니다. 학습 경로의 `wp.launch`는 Warp 장치를 쓰므로 CPU 백엔드에서 되는지 설치 전에는 알 수 없습니다(**확인 불가**).
- **제3자 렌더러의 라이선스.** Gaussian-Splatting License. 렌더링 재현에는 이 렌더러가 필요하고, 비상업 조건을 따릅니다.
- **데이터 크기.** 공식 데이터셋은 압축 해제 350 GB, 중복 제거 101 GB입니다. 범주별로는 빵 7.1 GB, 상자 12.0 GB, 천 27.8 GB, 봉투 11.4 GB, 끈 35.9 GB, 인형 6.8 GB입니다(중복 제거 기준, `02` §4). 이 분석은 매니페스트만 읽었습니다.
- **체크포인트.** 범주당 3.4 MB, 합계 20.3 MB입니다. 추론 모델 자체는 작습니다.

## 4. 구현 가능성 판정 (이 맥 기준)

- **이 맥에서 PGND 학습은 불가능합니다.** CUDA 전제이고, 논문도 4090에서 약 8시간이 걸린다고 적습니다. MPS와 Warp CPU 포팅은 가능성이 있지만 측정하지 않았습니다.
- **공식 체크포인트 추론은 조건부입니다.** 체크포인트는 작지만(3.4 MB) Warp CPU 실행과 데이터 일부 다운로드가 필요합니다. 데이터 다운로드는 1 GB 이상이므로 승인 대상입니다.
- **3DGS 영상 지표는 불가능합니다.** CUDA 래스터라이저와 비상업 라이선스 때문입니다.
- **계획 코드는 현 상태로 실행되지 않을 가능성이 큽니다.** D12의 import 누락 때문입니다. 실행해 보지 않았으므로 확인된 것이 아니라 정적 추정입니다.
- **직접 구현 (토이 또는 소형 실험)은 가능합니다.** 격자 속도장, G2P 보간, 입자 인코더는 torch로 짤 수 있습니다. 노력은 1–2주로 추정합니다(측정 전).

## 5. 확인하지 않은 것

- 공식 코드를 실행하지 않았습니다. D12의 import 실패는 정적 확인입니다.
- 체크포인트의 실제 설정(`hydra.yaml`)을 받지 않았습니다. D13은 그 파일로 확인할 수 있습니다.
- 프로젝트 페이지의 데모와 Hugging Face Space는 열지 않았습니다.
