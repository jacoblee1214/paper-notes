# 02. 선행연구와 자료 지도: Wiggle and Go! (arXiv:2604.22102)

논문 인용 번호는 v2의 [번호]입니다. 논문 스스로 쓰는 위치(§1–2)와 구성 요소별 출처를 먼저 정리하고, 이 저장소의 관련 분석과 공식 자료 상태를 뒤에 둡니다.

## 1. 연구 계보 (논문이 스스로 쓰는 위치)

논문은 다섯 갈래의 선행연구와 자신을 구분합니다(§1, §2).

1. **반복 학습 계열.** Chi 외 [1]과 Zhang 외 [2]는 로프마다 5–10회의 실기 시도로 정밀도를 높입니다. Suresh와 Atkeson [30]은 과제 수준 반복 학습 제어(ILC)로 flying knot을 학습합니다. 논문은 이 방법이 실패 비용이 큰 상황에서 쓸 수 없다고 봅니다.
2. **대규모 데이터와 자기지도.** Nair 외 [3]은 약 60,000회의 자율 상호작용을 씁니다. Wang 외 [6]은 자기지도로 이 비용을 줄이지만 여전히 많은 롤아웃이 필요합니다.
3. **시뮬레이션 기반 파라미터 조건 정책.** GenORM [4]과 GenDOM [5]는 점군에서 영률과 포아송 비를 추정해 정책을 조건화합니다. 이 계열은 물성 두 개만 쓰고, 단순 평면 과제 한 개에서 평가합니다. Lim 외 [21](Real2Sim2Real)은 동적 던지기 로프를 시뮬 파라미터에 맞추지만, 새 로프마다 실기 실험이 필요합니다. 논문의 로프 모형(볼 조인트 사슬)도 Lim 외를 따릅니다.
4. **암묵적 적응.** RMA [25–27]는 실행 중에 숨은 요인을 잠재 변수로 추정합니다. 논문은 이와 달리 파라미터를 명시적으로, 오프라인으로, 안전한 관측 동작 하나로 추정합니다.
5. **학습형 동역학.** Yang 외 [22], Wang 외 [23](GNN), Yu 외 [24]는 국소 선형이나 그래프 모형으로 변형 선형 물체의 상태를 예측합니다. 이들은 해석 가능한 물리 파라미터가 없어서 분석 시뮬레이터 안의 궤적 최적화에 쓰기 어렵다고 봅니다.

이 논문의 기여는 **(a) 파라미터를 명시적으로 추정하는 짧은 wiggle 식별, (b) 한 번의 관측을 여러 과제에 재사용하는 분리 구조, (c) 로프 종류별 실기 평가**입니다(§1, §3).
