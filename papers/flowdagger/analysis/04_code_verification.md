## 3. 주장과 코드의 일치 (확인한 항목)

- **단계별 고정점 구조.** `x_next = x_prev + dt·v(x_est, t_next)`를 `fp_per_step`회 반복하며 `K = num_denoise_steps = 10`, Δt = 0.1. 논문 식 (3)과 같은 구조입니다(시작점과 횟수는 D8).
- **회귀 손실.** 식 (5): `MSE(actor.mode(), target)`(`steering_policy.py: _bc_step`). 결정적 배포는 mode 사용으로 일치.
- **기본 가중치는 갱신하지 않음.** 옵티마이저는 잡음 정책(`PixelMultiplexer`)만 가지고, 기본 모델은 `raw_model`을 샘플링 정책과 역변환기가 공유해 추가 메모리 없이 쓴다. 역변환은 `torch.no_grad`·JAX 순전파만 쓰고 단계별 FP에는 역전파가 없다(§4.1 "no backpropagation"과 일치).
- **GR00T의 잡음 정책이 전체 (40 × 132) 잡음을 직접 회귀**하므로 부록 A.3의 서술과 맞는다. 압축하는 쪽은 π0.5 백엔드다(D4).
- **표 5의 비교 대상 구현이 있다.** 역변환기 클래스는 `euler_reverse`, `adam`, `hybrid`, `fixed_point`(궤적), `perstep_fp`를 모두 갖는다. 다만 실험 스크립트(표 5·6)는 없다.
- 평가 롤아웃 수 25, 최대 길이 300 스텝(MetaWorld), 개입 주기(query_freq 10)는 코드에 명시돼 있다.

## 5. 문제점과 확인하지 못한 점

- 서브모듈 `openpi` 포크의 내용(π0.5 샘플러, `embed_suffix`)은 읽지 못했습니다. 따라서 `get_velocity`가 학습·추론의 시간 규약과 일치하는지는 확인하지 못했습니다.
- `ReplayBuffer`의 가중치 표본(`_has_nonuniform_weights`)은 기본값 1.0이라 쓰이지 않습니다. 개입 가중치(`intervention_weight`, `pre_intervention_weight`)는 논문에 없는 옵션입니다.
- D9의 제외 비율, D7의 패딩 영향, D4의 압축 손실은 실제 모델이 없어 측정하지 못했습니다.
- `TRANSPARENCY.md`의 수치(기본 약 0.5, 최고 약 0.96)는 코드 실행 결과가 아니라 저자가 적은 문장이며 재현하지 않았습니다.
- 공식 저장소에는 Cosmos-Policy 역변환(부록 A.1의 Adam 종결 풀이 포함)이 없어서 §4.2와 표 2의 방법 구현은 대조하지 못했습니다.
