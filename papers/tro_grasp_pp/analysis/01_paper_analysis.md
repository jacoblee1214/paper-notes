## 1. 한 문단 요약

어지러운(cluttered) 장면에서 표적 물체를 집는 손 자세를, **여러 손 형태에 대해 하나의 확산 모델**로 만듭니다. 손 링크마다 6D 자세를 확산 변수로 두고, 링크 노드·물체 패치 노드·환경 패치 노드와 이들 사이의 상대 6D 자세 간선으로 이루어진 그래프 T(R,O) Graph++를 입력합니다(§4.1, 식 1–5). 노이즈 예측 트랜스포머(0.2B)가 링크 자세 노이즈를 내고(식 6–8), DDIM으로 샘플링한 링크 자세를 Pyroki IK로 관절 값으로 바꿉니다(§4, §9). 함께 8개 손 × 약 5만 물체, 4.44억 개 파지 주석의 시뮬레이션 벤치마크(표 1)를 만들었습니다. 손 8종 평균 성공률 87.96%(표 2), 지연 0.336 s(표 4)와 제안당 성공 1.15개(PPS)를 보고하며, 실로봇은 XHand 85%, LEAP 82%(그림 5, 표 7)입니다.

## 2. 문제 설정과 방법

### 2.1 입력, 출력 (§4 도입)

입력은 표적 물체 점군 P_obj(512×3), 주변 환경 점군 P_env(2048×3), 손 URDF입니다(§9). 출력은 링크별 SE(3)이고, IK로 관절 값을 얻습니다. 8개 손(표 2): Allegro, Ability, Barrett, DClaw, LEAP, Schunk, Shadow, XHand.

### 2.2 데이터 만들기 (§3, §8.1)

| 단계 | 내용 | 출처 |
|---|---|---|
| 1 | 손·물체 부분집합(≤128개)마다 PPO 정책 둘(power, precision)을 Isaac Gym에서 학습해 부유 물체 위 파지를 모음. 보상 식 (9)(10), 다양성 보상 r_div | §8.1 Stage 1 |
| 2 | 물체를 128개 초기 자세에서 떨어뜨려 안정 자세를 얻고, 파지를 변환하며 테이블 관통 후보를 제외 | §8.1 Stage 2 |
| 3 | 파지 영역의 2D 볼록 껍질 밖에 장애물 15–25개를 놓아 tabletop·shelf·box 장면을 구성 | §8.1 Stage 3 |

- 물체: UniDexGrasp 13,049개 + ObjaverseXL 40,626개 = 53,675개. 학습 47,737, 시험 5,938(§3.1).
- 주석: 약 1K개/(물체·손), 총 4.44억(표 1). 손바닥에 원통 마운트 링크를 붙여 충돌 검사에 포함(§3.2).
- 난이도(§3.3, §8.2): D_obj는 RL 최적화 스텝 수에서(식 11), D_env는 장애물 근접과 둘러싸임(enclosure)에서(식 12, 13), D_avg = (D_obj + D_env)/2.

### 2.3 그래프 표현 T(R,O) Graph++ (§4.1)

| 요소 | 정의 | 식 |
|---|---|---|
| 물체·환경 노드 | PointNet++ 기반 VQ-VAE 특징 + 패치 중심 좌표, 둘 다 환경 중심·스케일로 정규화. P = E = 25 | 식 1 |
| 로봇 노드 | [링크 월드 6D 자세, BPS 기하 특징, 위치 특징 F_pos] | 식 3 |
| 위치·운동학 특징 | N개 무작위 관절 구성에서 FK로 구한 T_base ∈ R^{N×L×6}를 ϕ_pos로, 관절 연결 링크쌍의 상대 변환 T_rel ∈ R^{L×L×N×6}을 ϕ_kine으로 인코딩 | 식 2 |
| 간선 | Eor, Eer는 노드 간 상대 6D 자세. Err는 링크 간 상대 자세와 F_kine의 연결 | 식 4, 5 |

핵심 주장은 **링크 지문(link footprint)**, 즉 BPS(기하) + 위치 + 운동학 특징이 있어야 비슷한 모양의 링크를 구분해 여러 손을 한 모델로 학습한다는 것입니다(§4.1, 표 6).

### 2.4 확산 모델 (§4.2, §4.3, §9)

- 순방향: 링크 자세에 가우시안 잡음(식 6). 코사인 스케줄, T = 1000, s = 0.008. 각 배치 샘플에서 N_t = 5개 시간 단계를 뽑아 지도.
- 디노이저: K개 그래프 어텐션 층에서 각 로봇 링크 노드가 물체 노드 → 환경 노드 → 다른 링크 노드 순으로 간선 조건부 어텐션(식 7). 모든 층의 링크 특징을 모아 위치·회전 잡음을 디코딩.
- 손실: 위치·회전 잡음 MSE, γ_pos = γ_rot = 1(식 8).
- 학습: AdamW, lr 1e-4, 워밍업 1,000, 클리핑 1.0, bf16, 배치 48/GPU, A100 80GB 8장(§9).
- 추론: DDIM 20단계, η = 1.0. IK는 8개 초기값 병렬 후 링크 위치 오차가 가장 작은 해를 고름(§9).
- 모델 크기(표 10): 10M, 50M, 0.2B(기본, 8층·12헤드·768차원), 1B.

## 3. 실험 결과

### 3.1 시뮬 평가 프로토콜 (§3.4, §5.1)

Isaac Gym에서 "환경과 충돌 없이 표적을 정해진 높이 이상 들어 올리면" 성공입니다. 손은 outer 자세에서 inner 자세로 위치 제어로 움직인 뒤 들어 올립니다. 모든 방법에 같은 프로토콜입니다. 베이스라인은 AnyDexGrasp[4]와 DexGraspNet2[1]이고, 각각 Allegro, LEAP 한 손에서만 비교합니다("공통 손만", §5.1). AnyDexGrasp는 장면 전체 제안 중 표적에 속하는 것의 최고 점수 하나, DexGraspNet2도 최고 점수 하나를 씁니다.

### 3.2 주요 결과

### 3.3 저자가 인정한 한계 (§6)

RGB·힘·촉각 등 다중 모달 입력이 없고, 기능적 파지 주석이 약해 기능 파지 합성을 지원하지 않는다는 두 가지만 적었습니다. 멀티 시도의 닫힌 루프 피드백은 향후 과제로 남겼습니다(§5.4 마지막 문장).
