# 03. 수치 재계산, 일관성 검사, 토이

논문 표의 수치를 다시 계산하고(§1), 표와 본문의 일관성을 점검하며(§2), 작은 CPU 토이 두 개로 중심 주장 두 곳을 확인합니다(§3). 재현은 없습니다(데이터, 센서, 코드가 공개되어 있지 않음). 재계산은 `analysis/recompute.py`(약 80초, numpy, scipy), 토이는 `analysis/toy_lse_invariance.py`(1초)와 `analysis/toy_latency_budget.py`(torch, 1분 안팎)입니다. 점검 번호는 V(재계산), K(일관성), 주장 판정은 `04`의 C입니다.

## 0. 가정과 표기

- 논문은 시행·사건 수를 표 6(부록 G)에서만 줍니다. 속도별 n = 36, 31, 37, 32, 31(합 167)이고, 그림 7(a) 막대 높이(약 72, 55, 25, 15)와 맞아 **그림 7(a)의 n도 167로 읽었습니다(그림 판독 값)**.
- 그림 7(a)의 43%, 33%, 15%, 9%는 그림에 적힌 퍼센트를 그대로 썼습니다. 그림 7(b), (c)의 값(93.7, 96.7, 83.2, 88.0, 96.7)은 본문과 그림에 적힌 숫자입니다.
- 표 1·2·3·4·5의 모든 값은 3 시드 평균입니다(§5.1). 분산이 없어 시드 간 변동을 반영한 검정은 하지 않았습니다. 클래스 비율은 시험 분할별 값이 없어 전체 데이터 비율을 가정한 곳에서만 씁니다(V6).
- 지연의 "프레임"은 1/240 s = 4.167 ms로 환산합니다.

### V2 센서 기하와 단위 (§3.1, §2)

- 밀도 100 / (0.7 × 0.92) = 155.3 taxels/cm². 본문 155와 일치합니다. 32×32 격자 면적은 22.4 × 29.4 mm = 6.59 cm², 1024 / 6.59 = 155.3입니다. "활성 taxel 942개"는 격자의 92.0%이므로 활성 개수만 세면 약 143 taxels/cm²가 됩니다. 155는 격자 전체 기준이라는 점이 본문에 명시되지 않았습니다(K10).
- 0–5 MPa × 1 cm² = 500 N(본문 일치), 12비트 4096 레벨이면 눈금당 약 1.22 kPa. 소자 면적 비율은 0.45² / (0.7 × 0.92) = 31.4%.
- "38.8배(Schürmann 등 [7])"와 "6.2배(FlexiTac [9])"는 비교 대상의 밀도가 각각 4.0과 25.1 taxels/cm²일 때 성립하며, 피치로는 5 mm와 2 mm에 해당합니다. 인용 논문의 값은 확인하지 않았고 이 환산이 자연스러운 피치와 맞는다는 것만 확인했습니다.

### V5 지연 값의 격자 가능성

표 1·2·3·4·5의 지연 21개는 모두 k/6 격자(3 시드 중앙값의 평균)에 위치합니다. 예: 4.67 = 14/3, 36.17 = 217/6, 20.50 = 123/6. 어긋나는 값은 없습니다.

### V6 표 1·2의 (정확도, FPR, Macro F1)이 동시에 가능한가

세 지표를 3×3 혼동행렬 하나에서 모두 만족시킬 수 있는지 15개 행에 대해 최적화로 확인했습니다(클래스 비율 가정: 접촉 없음 57.6, 슬립 없음 18.8, 슬립 23.7%를 정규화; 시험 분할별 비율은 논문에 없음). FPR 정의는 둘을 시험했습니다. **neg**: 슬립이 아닌 프레임 중 슬립으로 예측된 비율, **all**: 전체 프레임 중 슬립이 아닌데 슬립으로 예측된 비율.

| 읽기 | 결과 |
|---|---|
| neg (슬립 아닌 프레임 기준) | 15행 모두 가능 |
| all (전체 프레임 기준) | 13행 가능, **XL 기준선 두 행(ID, OOD)은 불가능** |

all 읽기의 불가능은 클래스 비율과 무관한 부등식으로 보입니다. 슬립이 아닌데 슬립으로 예측한 프레임은 오류의 일부이므로 FPR(all) ≤ 100 − Acc여야 하는데, XL 기준선은 ID에서 22.98 > 100 − 79.41 = 20.59, OOD에서 19.31 > 100 − 82.99 = 17.01입니다. 그러므로 표의 FPR은 분모가 슬립이 아닌 프레임이라는 neg 읽기와 맞고, 논문은 이 정의를 적지 않았습니다(K4).

neg 읽기에서 최적화로 찾은 슬립 프레임 재현율 범위(탐색으로 찾은 범위이며 실제 범위는 더 넓을 수 있음): 융합 모델 ID 0.91–1.0, OOD 0.88–1.0, Piezo 기준선 ID 0.55–0.73, XL 기준선 ID 0.87–0.95. 즉 표 1의 세 지표만으로는 학습 모델 한 모달 행의 슬립 재현율을 좁히지 못하고(0.46–1.0), 융합 모델은 슬립 프레임의 약 9할 이상을 맞힌다는 것까지만 읽힙니다.

### V7 지연의 우연 수준 기준

프레임마다 독립으로 확률 p로 슬립을 내는 정보 없는 검출기의 첫 검출 지연 중앙값은 ceil(ln 0.5 / ln(1−p)) 프레임입니다. 표 1의 FPR을 p로 쓰면(시간 상관과 사건 직전 상태는 무시):

| 행 | FPR % | 우연 수준 중앙값 (프레임) | 보고된 지연 (프레임) |
|---|---|---|---|
| 기준선 Piezo (ID / OOD) | 21.69 / 21.08 | 3 / 3 | 1.00 / 2.00 |
| 기준선 XL | 22.98 / 19.31 | 3 / 4 | 1.00 / 2.00 |
| 기준선 AND | 9.28 / 7.40 | 8 / 10 | 1.00 / 2.00 |
| SlipSense Piezo | 7.54 / 8.43 | 9 / 8 | 20.50 / 36.17 |
| SlipSense XL | 2.14 / 3.24 | 33 / 22 | 4.67 / 3.00 |
| SlipSense 융합 | 1.33 / 1.57 | 52 / 44 | 2.00 / 1.50 |

FPR이 20%대인 기준선은 우연 수준 자체가 3–4 프레임이라 지연 1–2 프레임이 FPR 없이는 해석하기 어렵습니다. SlipSense의 학습 모델은 자신의 FPR에서 우연 수준(융합 44–52 프레임)보다 훨씬 짧아, 지연과 FPR을 함께 읽을 때 의미가 있습니다. SlipSense Piezo 단독(20.50, 36.17 프레임)은 FPR 7.5–8.4%의 우연 수준(8–9 프레임)보다 길어서, 이 변형은 지연이 우연 수준보다 느립니다(이 한 줄은 중앙값과 시드 평균을 비교한 것이라 근사입니다).

### V8 실로봇 비율의 구간과 프레임 FPR의 시간 환산

| 보고 | 구간 (Wilson / Clopper-Pearson, 95%) |
|---|---|
| 슬립 검출 100/100 | 96.3–100% / 96.4–100% (시행 100 가정, 독립 가정) |
| 낙하 방지 95/100 | 88.8–97.8% / 88.7–98.4% |
| 실패 5/100 | 2.2–11.2% / 1.6–11.3% |

- 100/100이면 놓침률의 95% 상한은 약 3%(rule of three)입니다.
- 프레임 FPR을 시간으로 바꾸면(neg 읽기, 모든 비슬립 프레임에 균일 적용): 융합 ID 1.33%는 초당 3.2 프레임, OOD 1.57%는 3.8, Tesollo 2F 1.14%는 2.7, 3F 3.12%는 7.5 프레임입니다. 프레임이 독립이라면 2 s 구간에 오탐이 0일 확률은 0.2–0.4% 이하입니다. 실로봇 100회에서 "오탐 없음"(§5.3)이 보고되므로, 오류가 시간적으로 군집한다는 가능성이나 제어기 쪽에서 별도 필터(예: 연속 프레임 조건)를 쓸 가능성이 있습니다. 논문은 오탐의 정의와 제어기 트리거 조건을 적지 않았습니다(K5).

### V9 표 간 일치

- UMI OOD의 융합 행 (1.50, 1.57, 95.99, 95.75)은 표 1, 표 3(Custom CNN†과 Tiny-SSAST†), 표 4(SlipSense), 표 5(교차 어텐션)에서 같습니다. Tesollo 2-Finger의 (3.00, 1.14, 95.89, 94.39)는 표 2, 표 4, 표 5에서 같습니다.
- 융합 이득: ID에서 최고 단일 모달 대비 F1 +13.23 %p(96.77 대 83.54), OOD에서 +13.84 %p(95.75 대 81.91). ID에서 OOD로 F1 −1.02 %p, 정확도 −0.99 %p.
- 표 5의 교차 어텐션과 연결의 F1 차이: UMI OOD 0.47 %p, Tesollo 2F 1.32 %p. 표 3에서 CNN과 ViT-MAE(고정)의 F1 차이: 0.24 %p. 시드 분산이 없어 이 차이가 시드 변동보다 큰지는 알 수 없습니다(K8).

## 3. 토이

### T1 부록 I의 방향 불변성 (`analysis/toy_lse_invariance.py`)

합성 광대역 진동 s(t)를 단위 방향 d로 세 축에 투영하고, 논문의 처리(10 Hz 고역 통과는 모든 축에 같은 선형 필터라 생략, 16 ms = 128 샘플 창, 16 bin 멜, 프레임 이동 33샘플)를 numpy로 구현해 로그합지수 결과가 방향에 따라 변하는지 봅니다.

| 시험 | 결과 |
|---|---|
| T1 가정 1–4 아래, 방향 200개 | 로그합지수 최대 편차 2.2e-15. 같은 방향들에서 한 축의 log-mel은 방향 간 표준편차 1.7(ln 단위)로 크게 변함 |
| T2 두 진동원(슬립원 s와 방해 진동 v), s의 방향 d만 회전 | 최대 편차 1.52 (ln 단위). 단일 진동원 가정(가정 4)이 깨지면 방향 의존성이 생김 |
| T3 두 진동원 전체를 같은 직교행렬로 회전(센서 좌표계 회전) | 최대 편차 1.8e-15. 두 진동원이어도 불변 |

- 증명(식 6–14)은 가정 아래서 맞고, 수치도 일치합니다.
- 더 일반적으로, 축별 파워의 합은 세 성분 벡터의 노름 제곱이라 직교 회전에 불변이므로 **센서 좌표계의 회전**에 대한 불변성은 가정 4 없이 성립합니다(T3). 반면 슬립 방향을 바꿀 때 진동원의 상대 방향이나 세기까지 바뀌면 T2처럼 불변이 깨질 수 있습니다. 즉 불변성은 "진동 벡터장이 강체로 회전하는 경우"까지 보장하고, 실제 슬립 방향 변화가 거기에 해당하는지는 가정입니다.
- 이 토이는 불변성의 수식만 확인합니다. "방향 불변 XL 인코딩이 보지 못한 슬립 방향(Fig. 13)으로의 일반화에 기여했다"는 주장은 이 토이로도 검증되지 않았고, 논문에 로그합지수와 축별 쌓기를 비교한 절제가 없습니다(`04` C14).

### T2 지연 예산 (`analysis/toy_latency_budget.py`)

논문 §5.2는 모델 추론 2.3 ms(RTX A4500)가 프레임 예산 4.17 ms 안이라고 하고, §7은 GPU 워크스테이션에서만 측정했다고 한계로 적습니다. 논문이 적지 않은 크기를 가정해(채널 16/32/64, SSAST-Tiny 규모 폭 192·12층·헤드 3, 교차 어텐션 폭 128·헤드 4; 총 약 5.9M 매개변수, XL 인코더가 5.4M) 임의 초기화 모델의 한 번 순전파 시간을 쟀습니다. 창 60프레임을 매 프레임 통째로 다시 계산하는 최악 경로입니다(캐시 없음).

| 장치 | 센서 2개(UMI) 중앙값 | 센서 3개(Tesollo) 중앙값 |
|---|---|---|
| Apple M4 Pro CPU, 1 스레드 | 18.3 ms | 26.4 ms |
| CPU, 4 스레드 | 16.1 ms | 18.8 ms |
| MPS (Apple GPU) | 3.0 ms | 3.2 ms |

- 가정한 구조에서 CPU는 프레임 예산(4.17 ms)의 4–6배이고 MPS는 예산 안입니다. 이 결과는 구조 크기 가정에 의존하며 논문 모델의 시간이 아닙니다. 캐시를 쓰는 증분 추론이나 더 작은 XL 인코더로 CPU에서 예산을 맞출 수 있는지는 확인하지 않았습니다.
- 논문이 한계로 적은 "임베디드 배포"가 쉽지 않을 수 있다는 정황으로 읽을 수 있습니다. 가정한 구조에서는 총 5.9M 중 5.4M이 XL 트랜스포머라 이 부분이 비용을 좌우합니다.

## 4. 요약

1. 표 6, 그림 7(a), 본문 76%/43%는 서로 맞습니다. 76%는 76번째 백분위수이고 평균은 28.7 ms(추론 포함 31.0 ms), 시행 수가 167이라 구간이 ±6 %p입니다(V4).
2. FPR의 분모는 비슬립 프레임으로 읽어야 표와 맞습니다. 정의가 없습니다(V6, K4).
3. 지연은 FPR과 함께 읽어야 합니다. 20%대 FPR 기준선의 지연 1–2 프레임은 우연 수준(3–4 프레임)과 같은 크기입니다(V7).
4. 헤드라인 수치(96.7%)는 학습 물체의 시험 분할이고, 보류 물체는 95.75%입니다. 일부 문장(최저 지연, sub-frame, 모든 지표 최고)은 표와 일부만 맞습니다(K1, K3).
5. 시드 분산이 없어 표 3–5의 작은 차이(0.2–1.3 %p)는 판단하기 어렵습니다(K8).
6. 실로봇 100/100과 95/100은 구간 하한이 96.3%와 88.8%입니다. 시행 정의가 부족해 오탐 없음과 낙하 방지의 일반화 범위는 제한적입니다(V8, K5).
7. 방향 불변성 증명은 맞고, 센서 회전 불변성은 단일 진동원 가정 없이도 성립합니다(T1). 가정한 구조의 CPU 추론은 프레임 예산을 넘고 MPS는 안에 듭니다(T2).
