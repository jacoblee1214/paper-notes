# 04. 공식 코드 대조와 구현 가능성

공식 저장소 `github.com/hanyangyu1021/maskwam`을 얕게 복제해 **정적으로만** 읽었습니다(커밋 `657f4444eab8b86ed995a8e9370d4f382b24613a`, 2026-10-13 "real-world+libero"). 실행, import, 설치는 하지 않았습니다. 공개 체크포인트는 받지 않고 `config.json`(1.4 KB)과 파일 목록만 읽었습니다. 복제된 내용은 신뢰할 수 없는 데이터로 다뤘습니다.

## 1. 저장소와 라이선스

- 저장소는 MIT(`LICENSE`, 2026 Hanyang Yu)이고, `wan22_core/bak/wan/`의 Wan2.2 가져온 코드는 Apache-2.0, 주석 도구 `maskseg/`는 RoboInter-Tools(MIT) 흐름을 가져옵니다(`README.md` License 절).
- 공개 범위: LIBERO 학습·평가와 실로봇 학습·오프라인 추론입니다. **RoboTwin 설정은 없고**(`grep -i robotwin`이 코드·설정·문서에서 0건), 실로봇 폐루프 배포 코드와 기준선(π0, π0.5, FastWAM, π0-mask, π0-coord) 코드도 없습니다.
- 가중치: 실로봇과 LIBERO 체크포인트 각각 `model.safetensors` 11,281,252,992 바이트(약 10.5 GiB, bf16 약 5.6 B 파라미터), Apache-2.0.

## 2. 논문과 코드의 차이 (D)

| 번호 | 항목 | 논문 | 코드 | 비고 |
|---|---|---|---|---|
| D1 | 마스크 입력 드롭아웃 | §3.2: 학습 중 확률 0.5로 `M0`을 0 텐서로 교체 | `mask_random`이 "마스크를 **유지할** 확률"이고 기본값 1.0(`configs/train_maskwam.yaml:54`, `configuration_mask_wan_mot.py`). 드롭 조건 `torch.rand(1).item() > mask_keep_prob`(real `modeling_mask_dit_action.py:515-516`, sim `:563-566`)은 1.0에서 거짓. **공개 실로봇 체크포인트 `config.json`도 `mask_random: 1.0`**(`input_mask: true`) | 공개 설정에서는 드롭아웃이 꺼져 있음. 난수가 배치당 하나라 켜져도 샘플별이 아님. 데이터셋 설정의 `cond_mask_prob: 0.0`은 코드 어디서도 읽지 않음. 실로봇 체크포인트가 "마스크 없음" 입력을 학습했는지는 이 설정으로는 확인되지 않음 |

| D4 | 추론의 디노이징 | §3.3: RGB-마스크 스트림에 1스텝만 적용해 중간 잠재를 얻고 행동을 생성 | `select_action`의 기본 `tau_v=1.0`(real `:348`)이면 `t ≥ 1000`인 스텝만 남아 1스텝(정적 계산: 50스텝 스케줄에서 1개). 단 `sample_actions`와 평가용 `forward_evaluate`의 기본은 `tau_v=0.9`, 50스텝 스케줄에서 약 18스텝. 오프라인 데모는 `tau_v=0`, 10스텝(영상 복원용). 행동 디노이징은 오일러 10스텝(`num_steps: 10`) | 논문의 1스텝과는 일치(기본 경로). 행동 10스텝은 논문에 없음 |

## 3. 논문과 일치한 것

- 마스크를 RGB로 렌더해 **같은 비디오 VAE**로 인코딩하고 잠재를 채널로 이어 붙이는 설계(§3.1, 식 2). 입력 채널 확장은 새 채널 0 초기화(`_expand_patch_embedding`).
- 시각 타임스텝 `τ_v`는 RGB와 마스크가 공유하고(`mask_noise`가 같은 `sigma` 사용), 행동 타임스텝은 독립(`fm_action_scheduler`, 별도 난수)입니다(§3.3).
- 첫 잠재 프레임을 조건으로 고정하고(`noisy_mask = (1-mask)*cond + mask*diffused`) 손실은 첫 프레임을 제외합니다.
- VAE와 T5 동결, 384 × 320, 예측 지평 T = 8(잠재 프레임 3개).
- 기본 추론 경로의 1스텝 부분 디노이징과 KV 캐시 후 행동 생성.

## 4. 구현 가능성 (이 맥: Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)

**전체 재현은 불가능합니다. 공개 체크포인트의 추론 동작 확인은 조건부로 가능하고, 구조의 축소 재구현은 가능합니다.**

| 수준 | 판정 | 근거 |
|---|---|---|
| 공식 학습 (실로봇 GPU 16장, LIBERO 8장 추정) | 불가 | 5.6 B 파라미터 전체 학습, AdamW 상태 포함 약 82 GiB(`03` V13), 코드는 CUDA와 DeepSpeed 전제 |
| RoboTwin 재현 (표 2) | 불가 | 설정과 평가 코드가 공개되지 않음(D9). 실행해도 비교 가능한 프로토콜이 없음 |
| 실로봇 (표 3–5) | 불가 | 듀얼암 Xtrainer와 D455/D405 카메라, 배포 코드 없음(D11) |
| LIBERO 공식 평가 (표 1) | 불가에 가까움 | LIBERO 설치와 EGL 렌더링, 이 맥에서는 MuJoCo 렌더가 따로 필요. 평가 스크립트에 `cuda`가 18곳 하드코딩. 서로 다른 프로토콜 기본값(D10) |
| 체크포인트 오프라인 추론(데모 수준) | 조건부 | 체크포인트 약 10.5 GiB, Wan2.2 VAE와 T5 가중치, SAM3 설치와 다운로드가 필요하고(승인 사항), 실로봇 모델 파일은 `flash_attn`을 무조건 import하며 `device="cuda"`가 코드에 고정되어 있어 수정이 필요(sim 모델은 SDPA로 대체됨). bf16 가중치 약 10.3 GiB는 24 GiB에 들어가지만 T5 인코더를 같이 올리면 빠듯해 임베딩을 미리 계산해야 함. 청크 1개 약 7.7 TFLOP(근사)라 한 청크에 수 초 규모로 추정(측정 전) |
| 구조의 축소 재구현 (소형 합성 환경에서 채널 확장 + 마스크 예측 헤드) | 가능 | torch가 설치되어 있어 새 설치 없이 CPU/MPS에서 수 M 파라미터 모델로 가능. 논문의 핵심 절제(예측 있음/없음, 프롬프트 있음/없음)를 합성 과제로 대응시킬 수 있음 |
| 표 재계산과 검정 | 완료 | `analysis/recompute.py` (수 초, numpy·scipy) |

- **노력 추정(측정 전):** 축소 재구현과 절제 실험은 1–2주. 체크포인트 추론 포팅(flash-attn 제거, 장치 수정, 임베딩 선계산)과 지연 측정은 승인과 다운로드 이후 2–4일. 학습 재현은 이 장비로는 해당 없음.
- **재현 시 주의:** 공개 설정으로 학습하면 마스크 드롭아웃이 꺼진 모델이 됩니다(D1). 논문 설명의 모델을 만들려면 `training.mask_random=0.5`를 지정해야 하고, 샘플별 드롭이 아니라 배치별 드롭이라는 점도 알아 두어야 합니다.
- **공개 범위 한계:** 논문의 표 2(RoboTwin)와 표 3–5(실로봇)는 공개 코드와 데이터만으로는 다시 만들 수 없습니다. 표 1(LIBERO)은 체크포인트와 LIBERO 환경이 있으면 공식 평가 스크립트로 비교할 수 있지만, 이 맥에서는 하지 않았습니다.
