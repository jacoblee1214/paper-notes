## 4. 구현 가능성 (구현할 수 있는지)

**판정: 부분적으로 가능합니다. PlayArena 통계 파이프라인(매칭, 소프트 BT, ANOVA와 BH, 조건부 예측)과 시뮬레이션 축소판은 이 맥(Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)에서 구현하고 돌릴 수 있습니다. 논문의 실험(DROID Franka 여러 대, 정책 5개 서빙, 상용 VLM 채점, 3,000+ 롤아웃)은 이 맥에서 불가능합니다.**

| 구성 요소 | 이 맥에서 | 필요한 것 | 노력(추정, 측정 없음) |
|---|---|---|---|
| 표 재계산과 일관성 검사 | 완료 | numpy, scipy | 완료(`03`) |
| 소프트 BT·매칭·ANOVA 파이프라인(합성 롤아웃 입력) | 가능 | numpy, scipy(헝가리안은 `linear_sum_assignment`), 새 설치 없음 | 2–4일. 유사도 식과 가중치는 가정해야 함 |
| 프롬프트당 8회 순서 예측의 검정력 계산 | 가능(완료한 토이 2의 확장) | numpy | 1일 |
| MuJoCo 재설정 없는 평가장 축소판(스크립트 정책 여러 개, 규칙 채점기, 소프트 BT 대 정답 순위) | 가능 | mujoco 4.0, torch 2.15(설치됨), 자작 모델 | 1–2주 |
| AutoPrompter류 과제 생성을 오픈 VLM으로 | 조건부 | 로컬 VLM(가중치 다운로드, 이 맥 메모리와 속도 미확인), 장면 사진 | 1–2주 |
| AutoGrader 재현(Gemini 3 Flash) | 불가 | 롤아웃 영상 미공개, 상용 API 호출 | 해당 없음 |
| DROID 평가 현장(Franka, 아크릴 벽, 원격 개입, 알림) | 불가 | 로봇 여러 대, 연구실 | 월 단위 |
| 정책 5개 서빙(GR00T N1.6·N1.7, DreamZero, MolmoAct2, π0.5) | 불가 | CUDA GPU, 가중치 | 해당 없음 |
| YAM 양팔 실험 | 불가 | 로봇 | 해당 없음 |

노력 추정은 측정이 아니라 거친 어림입니다. 논문 수치 자체는 데이터 비공개로 이 맥에서 재현할 수 없습니다.
