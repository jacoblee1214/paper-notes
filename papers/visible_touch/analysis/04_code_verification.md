# Visible Touch 논문 ↔ 공식 저장소 대조와 구현 가능성 (arXiv:2609.14156 v2)

분석일 2026-11-15. 대상 저장소는 `qaz1678249/visibletouch`(프로젝트 페이지가 링크, 소유자는 개인 계정, 커밋 1개 `b31be56`, 2026-06-10, LICENSE 없음)입니다. `repo/`에 shallow clone하고 **정적으로만** 읽었습니다. `generate_model.py`를 실행하거나 `cadquery`를 설치하지 않았고, 생성된 STL을 열지 않았습니다. 설치 대상 `requirements.txt`는 `cadquery>=2.4.0`, `pyyaml`, `plotly`입니다.

## 1. 저장소 범위

| 파일 | 내용 | 논문과의 관계 |
|---|---|---|
| `generate_model.py` (228줄) | CadQuery로 몰드 3개(STL)와 Plotly HTML 미리보기를 만듦 | App. B.2의 CAD-몰드 파이프라인과 대응 |
| `sensor_1.yaml`, `sensor_2.yaml`, `sensor_3.yaml` | 사각 3×3(40 mm 본체, 자석 Ø3), 원형 Ø35(자석 Ø5), 사각 변형 | 센서 기하 매개변수. 논문 3×3 구성은 `sensor_1` |
| `sensor_*_mold{1,2,3}.stl`, `sensor_2_sensor.stl` | 생성된 몰드 파일 | 몰드 결과물 |
| `pictures/sensor_{1,2,3}.png` | 센서 사진 또는 렌더 | 논문 Fig. 2d와 비교 대상 |
| `README.md` | 파이프라인 설명, YAML 매개변수 표, 실행 방법 | — |

저장소에 **없는 것**: 오버레이 투영 코드(§3.1), LIBERO와 BC-Transformer 학습·평가, miniVLA와 π0.5 학습 설정, 실로봇 제어, ESP32 펌웨어, 자력계 PCB 레이아웃(논문 App. B.2는 "release the PCB board layout"이라고 씀), 데이터, 라이선스 파일.

## 2. 대조표 (D1–D12)

| ID | 논문 주장 (위치) | 저장소에서 확인한 것 | 판정 |
|---|---|---|---|
| D1 | 파라메트릭 CAD-몰드 파이프라인을 공개 (§3.2, App. B.2) | `generate_model.py`와 YAML 3개 | **일치** |

| D8 | 파라메트릭 변형(원형 등) 가능 (§3.2) | `shape: circular`를 받는 분기와 `sensor_2.yaml`(원형 Ø35) | **일치** |
| D9 | 몰드와 조립의 PLA 스페이서 (App. B.2) | 스페이서 생성 코드 없음 | 논문 설명만 있음 |
| D10 | 다른 센서의 자석 배치(원형 등) 동작 (§3.2) | `sensor_2.yaml` 자석 위치 목록은 다름(부분 확인) | 생성은 가능하다고 보임. 실행 확인은 안 함 |

| D12 | 재현에 필요한 버전 | `cadquery>=2.4.0`(상한 없음), 버전 고정 없음 | 재현성 약함 |

- **D6은 실물과 연결되는 항목입니다.** BOM의 자석 치수(Ø2 mm)와 저장소 기본 설정(Ø3 mm)이 다릅니다. 몰드 자석 구멍 치수를 잘못 잡으면 자석이 안 들어갑니다. 실제 실험 센서가 어느 치수였는지는 논문과 저장소 어느 쪽도 확정하지 않습니다.
- **D2, D3은 논문의 두 주요 주장과 직접 관련됩니다.** 센서 제작(D1)은 공개되었지만, 실험에 쓴 센서 신호 처리와 오버레이는 없습니다. 실험을 다시 만들려면 저자에게 요청하거나 직접 구현해야 합니다.
- 정적 확인으로는 `generate_model.py`의 기하 계산이 논문 수치(40 mm 본체 등)와 맞는지 실행으로 확인하지 못했습니다. 실행하면 몰드 치수가 YAML과 맞는지 볼 수 있지만, 이번 작업에서는 실행하지 않았습니다.

## 4. 구현 가능성 판정

### 4.1 결론

- **이 맥(Apple M4 Pro, 약 24 GiB 통합 메모리, MPS, CUDA 없음)에서 논문의 실험 결과를 재현하는 것은 불가능합니다.** 이유는 세 가지입니다. (a) 공식 실험 코드가 없어서 BC-Transformer·miniVLA·π0.5 학습 설정을 맞출 수 없습니다. (b) π0.5 실험은 H200 4장 학습이 필요하고(App. E.5), 실로봇(xArm7, 실물 센서, RealSense 두 대)이 필요합니다. (c) 오버레이 구현을 논문 설명만으로 맞추려면 저자 질문이 필요합니다.
- **부분 구현은 가능합니다.** 아래 표의 CPU 항목은 수 시간에서 수 일 안에 끝납니다.
- **판정: 전면 재현 불가, 부분 구현 가능.** 다만 구현의 핵심(오버레이 투영)은 논문 식(App. A)으로 처음부터 쓰면 됩니다. 공식 코드에는 없습니다.

### 4.2 자원별 정리

| 항목 | 필요 자원 | 이 맥에서 | 노력 추정 |
|---|---|---|---|
| 몰드 STL 재생성, 치수 확인 | CadQuery, CPU | 가능 | 반나절 (의존성 설치 승인 후) |
| 투영 오버레이 구현(App. A 식) | numpy, CPU | 가능 | 1–2일 (단위 테스트와 시각 확인 포함) |
| 토이 A, B 확장 | numpy, CPU | 가능(완료) | — |
| LIBERO BC-Transformer 학습(접촉 있음·없음) | LIBERO 설치, GPU 권장 | 제한적. MPS로 작은 설정은 가능하나 시간이 큼 | 설치와 데이터 1–2일, 학습 수십 시간 이상 |
| miniVLA 사전학습·미세조정 | GPU 다수, 대형 VLM | 불가 | — |
| π0.5 LoRA 미세조정 | H200급 GPU, JAX 또는 PyTorch 코드 | 불가 | — |
| 실제 센서 제작과 실험 | 실물 센서, xArm7, RealSense, 원격 조작 장치 | 불가 | 수 주 |

- 권장 순서: (1) 몰드 재생성과 D6 확인, (2) 투영 오버레이를 numpy로 구현해 논문 본문 그림(overview, 화살표 예시)의 위치와 맞는지 눈으로 확인, (3) LIBERO 소형 BC 설정에서 접촉 유무 비교. 3단계는 저자 설정 질문 후에 합니다.
- 저자에게 물을 항목: 실험 센서의 자석 치수(D6), 오버레이 코드 공개 여부, LIBERO 접촉 추출 코드, 사실상의 BC 평가 설정, 조건당 학습 시드 수.

## 6. 정리

- 공개된 것은 센서 몰드 생성 도구뿐입니다. 논문의 방법 핵심과 실험 코드는 없습니다.
