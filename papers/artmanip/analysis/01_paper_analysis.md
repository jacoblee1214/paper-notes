## 1. 문제와 기여

관절형 물체(칼, 라이터, 스테이플러, 집게)를 **손 안에서** 작동시키는 범주 수준(category-level) 정책을 학습합니다. 물체 밑동이 고정되지 않으므로 손은 자유롭게 떠 있는 물체를 안정적으로 쥐면서 관절을 접촉으로만 움직여야 합니다(§1). 저자가 꼽는 두 병목은 (i) 관절 구동과 파지 안정성이 결합되어 있다는 점, (ii) 초기 grasp에 민감해서 다양한 물체와 기능적 grasp를 대량으로 만들어야 한다는 점입니다(Abstract).

기여는 세 가지입니다(§1).
1. 관절형 in-hand 조작의 범주 수준 학습 틀.
2. **primitive 기반 물체 생성 + 기능적 grasp 합성**과 **관절 물리 무작위화**를 묶은 시뮬레이션 분포.
3. 22자유도 Sharpa 손 평가. 시뮬레이션에서 미지 인스턴스 일반화, 실물 12개에 zero-shot 전이, 300회 실로봇 시도에서 열고 닫기 성공 85.7%.

## 2. 방법

### 2.1 초기 구성 생성 (§3.2, Fig. 2, App. C.1–C.2)

- **물체:** 박스 primitive 두 개를 관절 하나(칼은 prismatic, 나머지는 revolute)로 연결한 2-링크 물체. 링크 크기와 관절 한계를 범주별 범위에서 뽑음(Tab. 6). 범주당 30개 학습, 5개 미지 시험 인스턴스(§4.1).
- **기능적 grasp:** Lightning Grasp [26]에 **손가락별 허용·금지 접촉 영역 템플릿**을 얹음. 범주마다 한 번만 손으로 정하면 모든 인스턴스에 자동 전달됨(§3.2). 인스턴스당 후보 1000개를 만들고, 시뮬레이션에서 1초 동안 안 떨어지는 것만 남김(App. C.2). 생성에 범주별 약 8–24시간.

### 2.2 교사 정책 (§3.3, App. C.3–C.6)

- **알고리즘:** SAPG [27](PPO 변형, 분할 후 집계). 입력은 초기 관측 `o_init`(57차원: 손 관절 22, 두 링크 자세 2x7, 손끝 위치 5x3, 링크 박스 크기 2x3), 고유감각 `o_prop`(59차원: 관절 22, 손끝 15, 이전 행동 22), 목표 `g`(1차원: 목표 관절값 − 초기 관절값), 특권 정보 잠재 변수 `z`(16차원).
- **특권 관측(21차원, App. C.4):** 링크 자세 2x7, 관절 상태 1, 관절 속도 1, 링크 질량 2, 마찰 1, 감쇠 1, 강성 1. MLP [256,128,16] 인코더가 16차원 `z`로 줄임.
- **행동(식 2):** `q_target(t) = q_target(t-1) + α a(t)`, α = 1/40. 30 Hz 제어.
- **보상(식 3, Tab. 7):** `w1 r_progress + w2 r_stable + w3 r_regulate + w4 r_terminate`. 진행항은 `max(0, d_prev − d_goal)`(최선 거리 갱신)과 `exp[−(d_goal/τ)²]`, 안정항은 물체 선속도·각속도 제곱, 접촉 손가락 수 부족분, 정규화항은 손 자세 편차와 행동 변화, 종료항은 낙하 −1과 성공 +50.
- **보상 커리큘럼:** 안정항 가중치를 최종값의 0.1배에서 시작해 에폭 100–1100 사이에 선형 증가(식 7, App. C.3). 본문은 "연속 성공 사이클이 늘수록 올린다"고 쓰지만(§3.3) 부록은 에폭 기반 일정으로 구현했다고 밝힘.
- **관절 물리 무작위화:** 칼·라이터는 감쇠가 있는 수동 관절, 스테이플러·집게는 관절에 PD를 걸어 복원력을 흉내 내고 감쇠·강성을 범주별로 무작위화(Tab. 8).
- **학습:** RTX 5090 두 장, 병렬 환경 20,000개, 약 48시간, 환경 스텝 20억(App. C.6, Tab. 9).

### 2.3 학생 정책과 잠재 증류 (§3.4, 식 4–6)

학생은 특권 정보 대신 **고유감각 이력(길이 H = 50)과 초기 관측**으로 교사의 잠재 `z`를 회귀합니다(TCN, 식 4–5: `L = ||z' − z||²`). 기반 정책(LSTM)은 교사에서 복사해 동결하고, 증류 중 행동은 **학생이 예측한 `z'`로 구동**합니다(닫힌 루프, DAgger와 유사). 배포 시 학생 인코더 + 동결 정책만 씁니다.

## 3. 실험 (§4, App. A–B)

### 3.1 설정과 지표 (§4.1)

- IsaacGym, 시뮬레이션 120 Hz, 제어 30 Hz, 에피소드 1200 제어 스텝(40 s). 질량, 마찰, 관절 파라미터 무작위화.
- 실로봇: 범주당 3개, 총 12개 미지 물체. 같은 매개변수 표현으로 **primitive 디지털 트윈**을 만들고, 후보 grasp를 시뮬레이션에서 굴려 상위 K = 5를 골라 실로봇에서 grasp당 5회 시도(40 s). 물체는 렌더링 화면을 보며 **손으로 초기 배치**, 목표(열기↔닫기) 전환은 **실험자가 수동**, 라이터에만 손등 접촉면에 거즈를 붙임.
- 지표: 인스턴스 수준 IC(성공 grasp가 하나라도 있는 비율), GC(인스턴스별 성공 grasp 비율의 평균), CSC_mean(성공 grasp의 평균 완주 사이클), CSC_max(인스턴스별 최대 사이클의 평균), SR(모든 롤아웃 중 한 사이클 이상 완료한 비율). 시뮬 R = 100 롤아웃, 실로봇 R = 5.
- 평가 허용 오차: 학습 임계값의 2배(App. C.3). 학습 시 `τ`는 칼 0.005(m), 라이터 0.10, 스테이플러·집게 0.05(rad).

### 3.3 절제 (Tab. 2, Fig. 5)

- **훈련 인스턴스 수(칼):** Unseen SR 29.4%(1개) → 64.6%(5) → 70.5%(10) → 85.0%(30). Anchor는 99.2 → 87.0 → 88.8 → 93.9로 단조롭지 않음. Geo-OOD 30.8 → 55.5%, Dyn-OOD 20.7 → 74.9%(§4.3).
- **SAPG 대 PPO, 커리큘럼, 기능적 grasp (Fig. 5):** SAPG가 PPO보다 최종 누적 성공 약 8.4 대 7.6, 커리큘럼 제거는 약 3.7, 기능적 grasp를 빼면 0 근처(모두 그림 판독 값, App. B).

## 4. 한계 (§6과 우리가 본 것)

논문이 쓴 한계: 기능적 grasp가 처음부터 주어져야 함, 2-링크 1자유도 물체만 평가, 고유감각만 써서 큰 기하·접촉 오차를 온라인으로 고칠 수 없음.

문서화된 구현·평가에서 추가로 본 것(자세한 근거는 `03`, `04`):
- 학습 곡선 한 줄(시드와 오차 범위 없음), 절제 표 한 줄(칼 하나)(Tab. 2, Fig. 5).
- 시뮬 SR은 시험 인스턴스의 **모든 생성 grasp**, 실로봇 SR은 **시뮬레이션에서 고른 상위 5개 grasp**를 평가해 모집단이 다름(`03` K3).
- 실로봇 사이클 수는 40 s 시도와 수동 전환에 의해 위에서 잘렸을 가능성이 있음(스테이플러 시도 75회 중 56회가 7사이클, `03` K4).
- 초기 grasp 선정, 접촉 영역 템플릿, 물리 파라미터(감쇠·강성)의 "실효값"이 모두 실로봇 보정 물체 하나에서 열린 루프 재생으로 정해짐(App. C.5).
- 기준선(다른 방법)과의 정량 비교가 없음. 비교 대상은 자기 절제뿐(Tab. 2, Fig. 5).

## 5. 이 논문을 읽는 방법 (요약)

- 강한 부분: 생성 파이프라인(primitive 물체 + 템플릿 접촉 제약 + Lightning Grasp)이 구체적이고, 공개 코드와 대부분 설정이 일치함(`04`). 표 3은 표 4에서 그대로 재계산되고(`03` V1–V3), 학습 범위 밖(Geo-OOD, Dyn-OOD) 평가가 구간이 서로 겹치지 않게 설계됨(`03` V12).
- 확인이 더 필요한 부분: 증류가 성능 하락의 주원인이라는 해석(표 5에 SR이 없음), 실로봇 85.7%의 일반화 해석(선택 효과와 군집 구조), 시뮬 SR과 실로봇 SR의 직접 비교.
