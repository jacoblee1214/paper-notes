# What Are We Actually Benchmarking in Robot Manipulation? (arXiv:2606.04233) 분석

*What Are We Actually Benchmarking in Robot Manipulation?* (Jiang, Tan, Wheeler, Sun, Ayalew, Walter; TTIC, UChicago, Argonne). 학회는 CoRL 2026 구두 발표입니다(사용자 확인, corl.org 공식 채택 목록의 "Also" 배지에 Oral O3가 표시됨, 2026-11-15 재확인). 목록의 기본 행은 포스터 Poster Session 1, No. 116입니다. 분석 대상은 arXiv **v1 하나**입니다(2026-06-02 제출, 31쪽. 2026-11-15에 v2 없음을 확인). 원문은 `paper/paper.pdf`, 텍스트는 `paper/paper.txt`입니다.

## 0. 한눈에 보기

- **무엇을 주장하나.** 벤치마크 점수는 "고정된 평가 조건 하나에서의 성공률"인데, 이를 일반 조작 능력의 증거처럼 읽는다. 네 가지 실패 양식을 정하고, 양식마다 진단 하나를 제안한 뒤 LIBERO, CALVIN, SimplerEnv, RoboCasa, RoboTwin 2.0에 적용한다.
- **네 진단.** (1) 지름길로 풀림(shortcut solvability), (2) 통계적 유의성 부족, (3) 과적합의 누적(creeping overfitting: 분포 과적합과 표본 과적합), (4) 데이터 출처 의존.
- **핵심 수치 (논문 값).** LIBERO에서 언어 인코더가 없는 0.09B 프로브가 최고 보고치와 1pp 이내(표 1). LIBERO와 SimplerEnv의 SOTA 주장 중 "명백히 유의"는 19.8%와 19.7%(그림 3). CALVIN ABC→D에서 블록 포즈만 학습 범위 안에서 다시 뽑으면 ATC가 3개 정책 모두 내려감(표 6). 22M 정책이 학습 데이터를 평가 격자 가까이 모으면 94.8%(91/96), X-VLA 0.9B는 95.8%(92/96)(표 9).
- **우리 재계산 요약.** 표 2, 3, 5, 6, 7, 8과 LIBERO Goal 쌍 불일치 D는 모두 논문 값과 맞습니다(§5 와 `03` §1). 그림 3의 LIBERO 19.8%는 공개 릴리스의 현재 분류(18.3%)와 다릅니다. 행 88개가 다른 범주로 들어갔고, 그중 68개는 보고 격차가 0인 동점입니다(`03` §2).

## 1. 문제 설정 (Introduction, p.1–3)

- 2026년 3월에만 LIBERO 결과를 보고한 arXiv 논문이 79편입니다(그림 2, 부록 D.5). 벤치마크가 곧 "진보의 정의"가 되고 있다는 출발점입니다.
- 이상적인 검증(같은 데모로 여러 정책을 학습하고, 실제 과제 순위와 벤치마크 순위를 비교)은 실행하기 어렵다고 봅니다. 여러 벤치마크에서 순위를 비교하는 방법도 저자가 골라 보고한 벤치마크 때문에 작동하지 않는다고 봅니다(§1 두 번째 단락).
- 따라서 네 진단으로 "점수가 능력의 증거인가"를 간접적으로 묻습니다.

## 2. 프레임과 용어

- 벤치마크 점수 = 고정된 시험 분포에서 성공의 경험적 평균. 이 평균이 능력의 증거가 되려면 (a) 지름길이 없고, (b) 평균이 주장하는 차이를 구분할 만큼 정밀하고, (c) 시험 분포가 중요한 변이를 대표하고, (d) 학습 데이터와 시험 사이 거리가 점수를 주도하지 않아야 합니다.
- 용어: 분포 과적합(distribution overfitting)은 좁은 시험 분포에 맞추는 것, 표본 과적합(sample overfitting)은 고정된 시험 표본 자체에 맞추는 것입니다(§5).

## 3. 네 가지 진단

### 3.1 지름길로 풀림 (§3, 표 1, 부록 A.1, 그림 1a)

- **방법.** DINOv2 ViT-B/14 (LIBERO, CALVIN, RoboTwin 2.0; RoboCasa는 ViT-S/14) 인코더 위에 작은 MLP를 얹은 "프로브"입니다. 언어 인코더가 없고, 과제는 학습된 과제별 임베딩으로만 구분합니다. 확산 헤드와 행동 토큰화도 없습니다.
- **LIBERO 결과.** Spatial 99.0%, Object 100.0%, Goal 98.8%, Long 92.4%입니다. 최고 보고치와의 차이는 +0.8, +0.0, +0.7, +6.4pp입니다(표 1). 세 스위트에서 최고 보고치와 1pp 안입니다.
- **CALVIN 결과.** D→D 3.123, ABC→D 3.242, ABCD→D 3.872 ATC. 최고 보고치와 차이는 +1.40, +1.54, +0.93입니다. 저자는 지름길이 실제로 있지만 LIBERO만큼 강하지는 않다고 씁니다(프로브가 널리 쓰는 정책과 맞먹고, 현재 최고치에는 못 미침).
- **다른 벤치마크.** RoboTwin 2.0 clean 60.4%, randomized 59.4%(최고 보고치보다 35–37pp 낮음), RoboCasa RSS24 18.8%, SimplerEnv WidowX 0.0%(표 1). 이 셋에서는 지름길이 없다는 근거입니다.
- **선택 절차의 한계.** 저자는 스위트마다 따로 학습하고, 여러 체크포인트 중 시험 점수가 가장 높은 것을 보고합니다(부록 A.1). 최종 체크포인트와 비교하면 LIBERO 평균이 97.6%에서 95.1%로 내려갑니다(표 2). 저자도 이를 "벤치마크의 약점"으로 인정합니다. CALVIN D→D는 최종 체크포인트를 그대로 씁니다.
- **주장의 범위.** 논문은 "LIBERO 점수가 일반 능력의 증거는 아니다"까지만 주장하고, 높은 점수를 낸 정책이 능력이 없다고는 주장하지 않습니다(§3 각주 2).

### 3.2 통계적 유의성 (§4, 그림 3, 부록 C)

- **방법.** 집계 점수만 있을 때 쌍체 Wald 검정의 기각 여부를 두 경계로 나눕니다. 기각이 불가능한 하한(rejection-feasibility)과 기각이 보장되는 상한(rejection-guarantee)입니다. 두 경계 사이는 "판정 불가"입니다(부록 C.5). T 과제, S 시도, R 점수 상한, α = 0.05.
- **그림 3 결과(논문 v1).** 공개 점수에서 새 정책 대 이전 SOTA를 네 범주로 나눈 비율입니다.
  - LIBERO (Spatial+Object+Goal, n = 789): 무개선 38.3%, 명백히 무유의 20.8%, 판정 불가 21.2%, 명백히 유의 19.8%.
  - CALVIN ABC→D (n = 107): 명백히 유의 43.9%.
  - SimplerEnv WidowX (n = 122): 명백히 유의 19.7%.
  - RoboCasa RSS24 (n = 30): 53.3%. RoboTwin 2.0 (n = 19): 73.7%.
- **읽는 법.** RoboCasa와 RoboTwin은 보고 수가 적어 격차가 크게 나오기 쉽다고 저자도 씁니다(§4 끝).
- **우리 재계산.** 공개 릴리스의 행 단위 분류를 다시 셉니다. LIBERO 명백히 유의는 144/789 = 18.3%입니다. CALVIN, SimplerEnv, RoboCasa, RoboTwin의 명백히 유의 수는 논문과 같습니다(`03` §2.1).
- **가정.** SimplerEnv는 4개 과제 x 24 시도로 층화했고, 나머지는 과제 평균을 씁니다. 각 비교의 이전 SOTA 점수는 새 논문이 보고한 값입니다(그림 3 설명). 프로토콜이 다른 논문끼리 비교하는 문제는 저자가 다루지 않습니다.

### 3.3 과적합의 누적 (§5, 표 4–8, 그림 1c, 그림 4, 부록 A.2)

- **분포 과적합 (CALVIN).** 학습 범위에서 블록 포즈를 다시 뽑으면 ATC가 X-VLA 4.165→3.138(−1.027), GR-1 3.244→2.495(−0.749), RoboFlamingo 2.367→1.869(−0.498)로 떨어집니다. 5/5 연쇄 성공률 하락은 25.0, 13.5, 6.4pp입니다(표 6). 세 정책 모두 떨어지고 순위는 그대로입니다.
- **분포 과적합 (SimplerEnv).** WidowX 쌓기 과제에서 지시문 반전, 지지 블록 위에 쌓기, 무작위 포즈·팔 자세의 세 가지 변화를 줍니다(그림 4, 표 4–5). 저자는 세 변화가 학습 데이터에 얼마나 나오는지 셉니다(부록 A.2: "block" 869, "cube" 751, "tower" 282, 53,192 데모 기준). 보정 값(같은 하드웨어에서 288 에피소드) 대비 하락은 정책마다 다릅니다. 가장 큰 하락은 X-VLA의 지지 블록 변화 28.47pp(95% CI 20.46–35.96)입니다(표 5).
- **표본 과적합 (LIBERO).** 같은 생성기로 init-state 파일을 새로 만들어 10,000 롤아웃을 돌리면 차이가 1pp보다 작습니다. Spatial Forcing +0.62, SimVLA −0.30, π0.5 LeRobot +0.14(표 7). CALVIN 새 시퀀스 매니페스트 두 개는 ATC 차이가 0.11 이하입니다(표 8).
- **해석.** 저자는 표본 과적합 결과가 작다는 점과 분포 과적합이 크다는 점을 대조하고, "이는 분포 과적합이지 약한 일반화가 아니다"라고 씁니다. 같은 분포 안에서 입력만 바꿨기 때문입니다(§5 첫 단락). 다만 SimplerEnv 변화의 "분포 안"이라는 주장은 학습 데이터 출현 빈도에 기댑니다(부록 A.2).
- **닫힌 루프 비결정성.** 부록 B는 하드웨어만 바꿔도 시뮬레이터 상태가 갈라지고 결과가 바뀔 수 있음을 보입니다(표 10, 그림 6). 그래서 "같은 점수"를 독립 재현의 기준으로 쓰지 말고 "프로토콜과 통계적 재현"을 기준으로 쓰자고 권합니다(부록 B.3).

### 3.4 데이터 출처 의존 (§6, 표 9, 부록 A.3)

- **문제.** SimplerEnv는 실제 BridgeData V2로 학습하지만 시험은 시뮬레이션 WidowX 격자입니다. 출처 간 거리가 실제로 있습니다. SimplerEnv는 학습 데이터 출처를 제한하지 않으므로, 격자 근처에서 스크립트 시연 120개를 모으면 거리를 "건너는" 대신 "없앨" 수 있습니다.
- **결과.** 과제당 DINOv2-S + MLP 정책(22M)을 따로 학습해 stack 24/24, carrot 23/24, spoon 21/24, eggplant 23/24를 얻습니다. 합계 91/96 = 94.8%입니다(표 9). X-VLA 0.9B의 보고치는 92/96 = 95.8%입니다.
- **우리 재계산.** 두 값의 Fisher 정확 양측 p = 1.0입니다(`03` §1.7). "같은 점수"라는 주장은 성립하지만, 이 결과로 "22M이 더 낫다"는 주장은 저자도 하지 않습니다(§6 끝).
- **주의.** 부록 A.3은 생성기 설정을 "격자 존재 증명"을 위해 골랐다고 명시합니다("generator fixes were selected"). 따라서 이 셀은 편향된 존재 증명이지 비편향 추정이 아닙니다.
