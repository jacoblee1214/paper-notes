## 1. 한 문단 요약

변형체(밧줄, 천) 조작에서 접촉을 찾는 단계의 기울기가 없다는 문제를 **접촉 평활화(surrogate gradient)를 넣은 GPU 병렬 미분 가능 시뮬레이터**(JAX, 암묵적 시간 적분, 암묵 미분)로 풀고, 그 시뮬레이터 위에 **GPU 병렬 출력 피드백 시스템 수준 합성(SLS) 기반 견고 MPC**를 올립니다(GPU-SLS의 출력 피드백 확장). 지각 오차와 모델 오차의 상계는 **정합 예측(conformal prediction, CP)**으로 교정해 도달 가능 관(reachable tube)을 만들고, 정리 1로 "지각 상태 관 + 지각 오차 반지름 ρ"가 참 상태 관이 된다고 주장합니다. 시뮬레이터를 쓰는 해석적 정책 기울기(APG) 모델 기반 RL도 보입니다. 시뮬레이션 네 과제(밧줄 들기, 밧줄 끌기, 천 접기, 천 펴기)에서 MPPI, PPO, APG와 비교하고(표 1), 실로봇(KUKA iiwa 두 대)으로 장애물 위로 밧줄 넘기기와 천 접기를 보입니다(그림 1).

## 2. 문제 설정과 방법

### 2.1 문제 설정 (§3, 식 1–2)

- 상태 q ∈ R^{n_q}(밧줄 노드, 천 메쉬 노드 3차원 위치와 구동 자유도), 제어 u, 불확실 동역학 q_{k+1} = f(q_k, u_k) + E(q_k) w_k (식 1a), 지연된 관측 y_{k+1} = h(q_k) + F(q_k) e_k (식 1b). w, e는 단위 2-노름 공에 있는 유계 외란입니다.
- 문제 1은 미분 가능, GPU 병렬, 접촉을 통과하는 유익한 기울기를 주는 시뮬레이터 f (식 2)입니다. 문제 2는 공칭 궤적 (z, v)과 인과 출력 피드백 제어기 π를 함께 찾아 제약 집합 S를 폐루프로 만족시키는 것입니다.

### 2.2 시뮬레이터 (§4.1, 식 3–10)

- 준정적 가정의 암묵 적분: M(q⁺ − q)/δt² + ∂E(q⁺)/∂q = τ(u) + Σ J_iᵀλ_i (식 3). 속도가 상태에 없는 과감쇠 모델입니다. 탄성 에너지는 늘어남과 굽힘만 있고 비틀림은 없습니다(부록 F).
- 구속은 두 단계로 풉니다. 1단계는 홀로노믹 구속(그리퍼 부착)을 뉴턴법으로 풀어 중간 형상 q*를 구하고(식 6), 2단계는 접촉(Anitescu 볼록 완화 [53], 식 5)을 q*에서 선형화한 최적화(식 7)로 풉니다. 풀이기는 JAX입니다.
- 미분은 전개한 반복이 아니라 암묵 미분입니다. 1단계는 식 8, 2단계는 KKT 조건의 미분(식 9)이고, 합쳐 식 10의 수반(adjoint)이 됩니다. 인수분해가 순방향의 부산물이라 역전파는 추가 비용이 없다고 주장합니다.
- **접촉 평활화**: 그리퍼 부착 강성을 D_i = D_{i,max} exp(−‖c_i(q)‖²/κ)로 바꾸고, 접촉 상보성을 (J(q⁺−q) + [φ 0 0])ᵀλ = κ로 완화합니다. 평활화된 동역학은 **기울기 계산에만** 쓰고 순방향 전개와 실행은 비평활 동역학을 씁니다(편향된 surrogate gradient, [54]).

### 2.3 출력 피드백 SLS (§4.2, 식 11–17)

- 이상적 문제 (11)을 근사하기 위해 GPU-SLS [49]를 상태 피드백에서 출력 피드백으로 확장합니다(Vision-SLS [52]의 합성을 따름). 합성 문제 (12)는 공칭 (z, v), 폐루프 응답 Φ, 관 폭 τ를 변수로 하고, 제약 조임 (12d)–(12e)가 관을 만듭니다.
- [52]의 세 단계(공칭 궤적, 상태 피드백 Φ̄, 출력 피드백 Φ̂) 중 앞 두 단계는 GPU-SLS가 하고, 이 논문은 세 번째를 병렬화합니다. 칼만 이득 재귀 (13)과 N개의 독립 순방향 전파 (14)를 **병렬 연관 스캔**으로 바꾸는 결합 규칙이 식 (16)–(17)입니다. 시간 복잡도는 GPU-SLS와 같은 로그 시간이라고 주장합니다. 이 결합 규칙은 우리가 수치로 확인했습니다(`03` §3.2).

### 2.4 APG (§4.3)

시뮬레이터를 미분 가능 층으로 넣어 해석적 정책 기울기로 신경망 정책을 학습합니다(식 10). 두 용도를 듭니다. 전문가 궤적 생성(CORD-SLS가 만든 궤적으로 학습 안내)과 직접 정책 기울기입니다. 본문은 방법을 세 문장으로 설명하고, 손실, 신경망, 학습률을 적지 않습니다. 이 정보는 코드에서만 알 수 있습니다(`04` D6, D7).

### 2.5 정합 예측과 정리 1 (§4.4, 부록 A)

- 하드웨어에서는 독립 라벨이 없으므로 모델 예측 다음 관측과 지각이 돌려준 다음 관측의 차이 s_i = ‖q̄⁺_i − f(q̄_i, u_i)‖₂를 비적합 점수로 씁니다. 궤적 수준 오류율 δ를 T로 나눠 δ̄ = δ/T, q = s_(⌈(n+1)(1−δ̄)⌉) (인덱스가 n을 넘으면 +∞)입니다. 지각 상태 모델을 q̄_{k+1} = f(q̄_k, u_k) + r_CP I w_k로 두고 SLS를 돌립니다.
- **정리 1**: y_{k+1} = q_k + e_k, ‖e_k‖₂ ≤ ρ이고 지각 상태 관 포함 확률이 ≥ 1−δ이면 참 상태 q_k ∈ T̄ ⊕ ρB의 확률도 ≥ 1−δ입니다. 증명(부록 A)은 두 줄입니다. q_k = q̄_k − e_k이고 ‖e_k‖ ≤ ρ이므로 같은 사건에서 민코프스키 합에 들어갑니다. 결정론적 포함 관계라 CP와는 무관합니다. 참 안전은 T̄ ⊆ Q_safe ⊖ ρB를 요구합니다.

- 천: 300 DoF에서도 MPC 한 번이 1초 안에 계산된다고 씁니다. RL 기준선은 "학습이 과도하게 표본 집약적"이라는 이유로 뺍니다.
- 그림 2는 네 과제의 시뮬레이션 타임랩스입니다(리포트에 실음).

### 3.2 출력 피드백 (그림 3, 부록 E 그림 9)

장애물 위로 밧줄을 넘기는 시뮬레이션에서 "시뮬레이션된 측정과 동역학 잡음" 아래 관 안에 롤아웃이 머무는 것을 보입니다. 부록 E는 39개 상태(노드 11개 × 3 + 그리퍼 2개 × 3)의 관 전체입니다. 롤아웃 횟수, 잡음 크기, 관 위반 횟수는 적지 않습니다.

### 3.3 하드웨어 (§5 Hardware, 그림 1, 부록 B)

- 장비: KUKA LBR iiwa 두 대(Schunk 그리퍼), Orbbec Gemini 336L 두 대(앞, 뒤), 지각용 RTX 4090 한 대와 솔버용 RTX 4070 Ti Super 한 대(본문에는 "RTX4070 Ti"), ROS2 이더넷.
- 지각: SAM3(약 200 ms, 간헐적 재접지)로 분할, 골격화 후 TAPNext++로 키포인트 추적(15–25 Hz), 깊이로 3D화, 스플라인과 재표본화로 밧줄 상태 복원. 밧줄은 지름 약 1 cm 꼰 줄 1.5 m의 양끝을 묶어 유효 길이 약 0.8 m, 모델은 10링크. **그리퍼가 잡은 뒤에는 지각 대신 그리퍼 자세와 밧줄 길이로 "중력 처짐이 지배한다"고 가정한 복원**을 씁니다.
- 천 38 cm × 38 cm, 8×8 노드 (198차원). 지각을 쉽게 하려고 **각 행의 x, z를 일정(직선)이라고 가정하고 두 그리퍼의 x, z 차이를 5 cm 이내로 제한**합니다.
- CP 교정: 무작위 제어 **100번**을 하드웨어에서 하고, 한 단계 예측 오차의 "반올림한 경험적 반지름 0.03 m가 교정 잔차의 87%를 덮는다"고 씁니다. ρ(카메라 사양 기반 최악 측정 오차)의 값은 어디에도 없습니다.
- 하드웨어 결과는 두 가지 정성 시연(그림 1)이고, **시도 횟수, 성공률, 안전 위반 횟수가 없습니다.**

### 3.4 RL 수렴 (부록 C, 그림 6)

PPO와 APG의 비용 곡선(밧줄 들기, 끌기)을 보이고, 같은 비용에 도달하는 데 APG가 평균 45.95%(중앙값 36.01%, 들기), 16.63%(중앙값 27.43%, 끌기) 적은 스텝이 든다고 씁니다. 곡선의 음영(신뢰대 또는 SD, 시드 수)은 정의되지 않았습니다.

### 3.5 시뮬레이터 비교 (부록 F, 표 2, 표 3)

- 표 2: 20노드 밧줄과 100노드 천의 순방향 시뮬레이션과 동역학 야코비안 시간. 밧줄 순방향 1.095 ms (DEFORM 49.03, DaXBench 786.48), 야코비안 5.198 ms (2128.81, 11561.57). 천은 15.08/10.06 ms (DaXBench 21.71/110.19). 본문은 "최대 700배, 2000배"라고 요약합니다.
- 표 3: 하드웨어 100개 임의 동작의 한 단계 예측 평균 L2 오차(m). Ours 0.0150 ± 0.0040, DEFORM 0.0139 ± 0.0029 (7% 낮음), 학습된 잔차를 붙이면 0.0075 ± 0.0068 대 0.0071 ± 0.0032. 데이터는 70% 학습, 30% 검증이며 검증 오차를 보고합니다. 측정된 다음 상태는 "안정된(settled) 준정적 형상"이라 DEFORM은 영 제어로 평형까지 전파한 뒤 비교합니다.

### 3.6 저자가 인정한 한계 (§6)

접촉 평활화는 접촉 전이 근처에서 오차를 만든다([17]로 다룰 수 있음), 변형체 지각은 가림과 복잡한 위상에서 어렵다, 고차원과 긴 horizon에서 메모리가 병목이라 저랭크 SLS 응답 연산자가 필요하다는 세 가지입니다. 부록 D는 MPC가 매번 다시 계획하므로 **실행 궤적이 이전에 계산한 관 안에 머문다는 보장이 없다**고 따로 적고, 재귀적 실현 가능성 보장은 [61]을 쓰라고 합니다.
