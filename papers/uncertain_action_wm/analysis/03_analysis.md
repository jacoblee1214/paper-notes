재현은 하지 않았습니다. 논문이 보고한 표 값을 다시 계산하고, 본문과 표가 서로 맞는지 검사하고, 검출 법칙의 수학 값을 CPU 토이 두 개로 확인했습니다. 결과 파일은 `analysis/recompute_results.json`, `analysis/auroc_mc_check_results.json`입니다. 검사 번호는 `V`로 붙였습니다.

## 1. 표 값 재계산

### 1.1 표 1 산술 (V1)

- 14행 모두 SR 차이와 표의 ∆Frozen, ∆ACTUS가 허용 오차 0.15점 안에서 맞습니다(`recompute_results.json`의 `table1_arithmetic`, 불일치 0건).
- 기준 값: PushT Frozen 0.650, ACTUS 0.862. Cube Frozen 0.378, ACTUS 0.432.
- 명목 감소: 적응 방법 PushT 최대 6.6점(OpTTA: 0.873 → 0.807). JEPA-TTT는 +6.7 (0.940).
- 본문 "22.3점과 14.2점 손실": 명목 − Frozen = 22.3 (PushT), 14.2 (Cube) ✓.
- ACTUS 회복 비율: PushT 21.2 / 22.3 = 95%, Cube 5.4 / 14.2 = 38%. Cube에서는 손실의 62%가 남습니다. 초록의 "levels with an oracle"은 오라클과 같다는 뜻이지 손실 전체를 되찾았다는 뜻은 아닙니다.

### 1.3 표 1 신뢰구간 (재계산 불가)

∆ACTUS의 95% 구간은 논문 부트스트랩 값입니다. 구간 생성에 쓴 에피소드별, 이동별 자료가 없어서 다시 계산할 수 없습니다. 구간 중심과 점 추정치는 모든 행에서 대략 대칭입니다(예: Frozen −21.2, [−28.0, −14.9]). 구간 폭만으로 유효 표본 수를 역산하는 것은 가정이 많아서 하지 않았습니다.

## 3. 검출 법칙 수치 확인 (V9)

`analysis/recompute.py` §3.

- **정확 λ0.75 (K=4):** 3.58 → 논문 3.6과 일치 ✓. **(K=6):** 4.20 → 논문 4.2와 일치 ✓.
- **식 (8) 근사:** λ0.75 = 3.76 (K=4), 4.34 (K=6). 근사는 4–5% 크고, 곡선 차이는 λ = 4–12 구간에서 0.02–0.03입니다(그림 `own_auroc_law.png`).
- **해석:** 논문의 수치는 정확 비중심 χ²에서 나왔고, 식 (8)은 대략적인 근사입니다. 논문 본문은 식 (8)을 "≈"로 쓰므로 모순은 아니지만, 본문이 "smallest shift visible at AUROC a is ‖δ‖ = √(κλ_a/n)"로 쓴 관계는 정확 λ를 써야 합니다.

## 4. 토이 검증

### 4.1 κ 보정 후 검출 AUROC (V10): `analysis/auroc_mc_check.py`

- 모형: K=4 방향, 점수 s_t = δ + ε_t, ε_t는 AR(1) (ρ = 0.5), n = 20, 몬테카를로 4000 쌍. κ는 명목 윈도 20000개의 Var(S)/F 평균에서 추정 (2.798; 긴 윈도 극한 3.0).
- 결과(실제 AUROC, κ 추정): λ = 0.6 → 0.560 (정확 0.554), λ = 1.67 → 0.639 (정확 0.636), λ = 3.27 → 0.753 (정확 0.734), λ = 5.4 → 0.843 (정확 0.827).
- **해석:** 명목 데이터로만 κ를 맞춘 Rao 검출은 비백색 잡음에서도 정확 법칙의 0.02 안쪽입니다. 같은 행의 식 (8) 근사는 0.02–0.03 낮게 나옵니다(V9와 같은 방향).
- **한계:** 이 토이는 ε가 K 방향에서 독립이고 F_t = I인 가장 단순한 경우입니다. 논문 모형의 실제 잔차(LeWM 인코더 공간, 시각 잡음, 계획 선택)는 확인하지 못했습니다. 논문의 "예측이 0.05 안쪽"은 이 토이로 검증된 것이 아닙니다.

### 4.2 토이로 확인하지 않은 것

- 잔차 에너지와 점수의 차이(명제 1)는 선형 모형에서 자명하므로 토이를 만들지 않았습니다.
- 가우스-뉴턴 추정량의 Cramér–Rao 도달(명제 3)과 귀속 규칙의 정확도(22/24 등)는 실제 세계모델 없이는 검증할 수 없습니다.
