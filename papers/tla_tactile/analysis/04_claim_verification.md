# TLA 주장 검증 (공식 코드 없음)

공식 코드 저장소를 찾지 못했습니다(`02_prior_work.md` §2). 따라서 코드 대조(D-항목) 대신 **논문 주장을 근거와 대조하는 검증(C-항목)** 을 했습니다. 저장소를 클론하거나 실행하지 않았습니다. 분석일 2026-11-22.

## 1. 라이선스와 공개 범위

- **arXiv abs 페이지 (2026-11-22 확인):** "view license" 링크가 `http://creativecommons.org/licenses/by-nc-sa/4.0/`를 가리킵니다. 아이콘 이미지도 `by-nc-sa-4.0.png`입니다. 제목 옆 라벨은 "Rights to this article"입니다.
- **PDF 본문 확인:** 저작권 표시(©, IEEE, All rights reserved, 회사 고지)는 v1 PDF에서 찾지 못했습니다. 이 문서의 라이선스는 arXiv 링크가 정합니다.
- **판정:** CC BY-NC-SA 4.0입니다. CC BY가 아니므로 **공개본에는 논문 그림을 넣지 않습니다.** 공개 그래프는 우리가 그린 것 세 장뿐입니다.
- **저널 게재본의 라이선스:** 게재본 1쪽은 CC BY 4.0이라고 씁니다. 이 분석이 대상으로 하는 arXiv v1에는 적용되지 않습니다. 게재본 그림을 쓰려면 별도 확인이 필요하고, 이 분석에서는 쓰지 않았습니다.
- **NC-SA 조건의 해석:** 공개 게시본은 논문을 옮기지 않고 분석하는 글입니다. 다만 "ShareAlike"가 2차 저작물에 붙는지는 해석 여지가 있습니다. 게시 전에 사용자가 판단하는 것이 맞습니다(보고에 올림).
- **개인용 리포트와 PPT:** 논문 그림은 넣지 않았습니다. 개인용 자료에 넣을지는 사용자가 정하도록 남겨 둡니다.

## 4. 구현 가능성 판정

**판정: 이 맥에서 논문의 TLA를 그대로 구현하거나 재현하는 것은 불가능합니다. 공식 코드와 데이터가 없고, 학습은 GPU와 Isaac Gym을 전제합니다. 소형 재구현(라벨 식과 소형 촉각 회귀기)은 조건부로 가능합니다.**

| 구성 요소 | 필요 자원 | 이 맥에서 | 노력 추정 (측정 전) |
|---|---|---|---|
| Qwen2-VL 7B + LoRA 학습 (8 A6000, 20 에폭) | GPU 메모리 수십 GB 이상, CUDA | **불가** (MPS에서 7B 학습은 메모리와 시간 모두 부족) | 해당 없음 |
| 시뮬레이션 데이터 생성 (Isaac Gym, FEM, 촉각 렌더링) | CUDA, Isaac Gym | **불가** (Isaac Gym은 CUDA 전제) | 다른 물리 엔진으로 옮기면 수 주 이상 (추정) |
| 실로봇 삽입 (UR3, GelStereo 2 두 개, Robotiq-85) | 실로봇, 센서 | **불가** | 해당 없음 |
| 공개 데이터·가중치 | 없음 | **불가** (문의 필요) | 해당 없음 |
| 라벨 식 (1–3)과 규칙 정책의 numpy 재구현 | numpy | **가능** | 1–2일 (추정) |
| 소형 촉각 회귀기 (ResNet-18 수준, 8장 3×3 합성 입력) 학습 후 간격 외삽 | 합성 촉각 데이터, MPS | **조건부** (합성 데이터를 어떻게 만들지가 관건) | 1–2주 (추정, 라벨과 합성 데이터 포함) |

**근거:** 논문이 주는 설정 가운데 입력 형식(8장 3×3, 616×616), 라벨 식(1–3), 평가 프로토콜(50회, 최대 15회 시도)은 재구현할 만큼 충분합니다. 반면 s, δ의 값, 빔 폭, 학습률, LoRA 랭크, 기준선 DP의 입력과 설정, 촉각 시뮬레이션 세부가 없습니다. 이 빈칸 때문에 "같은 TLA"를 만들었다고 말하기 어렵습니다.

## 5. 미확인 항목

1. 공식 저장소의 존재 여부. GitHub 코드 검색이 요청 제한으로 실패했습니다. 다른 경로(저자 연락, 논문 게재본의 보충 자료)는 확인하지 않았습니다.
2. 저널 게재본과 arXiv v1 사이의 수치 차이. 표 1, 3, 4는 같지만 본문 표현과 실험 목록이 다릅니다. 게재본 전체를 다시 대조하지는 않았습니다.
3. 학회 게재 여부. CoRL 2026 목록에 없음을 확인했습니다. 다른 학회 게재는 확인하지 않았습니다.
