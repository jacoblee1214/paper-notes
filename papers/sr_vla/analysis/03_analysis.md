# 03. 재계산과 일관성 검사: SR-VLA

재계산 스크립트는 `analysis/recompute.py`이고, 결과는 `analysis/recompute_results.json`입니다. 표준 라이브러리만 쓰고 수 초 안에 끝납니다. 이 문서는 논문 표의 숫자만 다시 계산합니다. 로봇이나 시뮬레이션은 돌리지 않았습니다(`04` §4).

**시행 수 가정.** 논문은 LIBERO 스위트별 시행 수(에피소드 수)를 밝히지 않습니다. 이 문서는 **스위트당 500 시행**(LIBERO 표준: 50 starts × 10 tasks)을 가정합니다. 결과는 이 가정에 따라 달라지므로, 검정 결과마다 가정을 명시합니다. 실제 시행 수를 알면 `N_TRIALS`만 바꿔 다시 돌리면 됩니다.

## 2. 성공률 차이 검정 (가정: 스위트당 500 시행, 비쌍)

비쌍 두 비율 검정(정규 근사, 양측)과 Newcombe(Wilson) 95% 구간입니다. 논문의 실험은 같은 초기 상태에서 짝지어 돌렸을 가능성이 있으나 짝 정보가 없으므로 쌍체 검정은 할 수 없습니다. 비쌍 검정은 대체로 보수적입니다(짝을 맞추면 분산이 줄어 검정력이 올라갑니다).

| 비교 | Spatial | Object | Goal | Long | 4개 스위트 평균 (근사 95% 구간, p) |
|---|---|---|---|---|---|
| SR-VLA(π0.5) − π0.5 동기 | 0.0 (p = 1.00) | +1.8 (p = 0.028) | +0.2 (p = 0.85) | 0.0 (p = 1.00) | **+0.5 pp** [−0.61, +1.61], p = 0.38 |
| SR-VLA(π0.5) − VLASH | +0.6 (p = 0.54) | −0.4 (p = 0.41) | +1.6 (p = 0.17) | −0.6 (p = 0.70) | **+0.3 pp** [−0.79, +1.39], p = 0.59 |
| SR-VLA(OFT) − OFT 동기 | +1.2 (p = 0.15) | −0.2 (p = 0.81) | −0.3 (p = 0.75) | −0.3 (p = 0.84) | **+0.1 pp** [−0.93, +1.13], p = 0.85 |
| SR-VLA(OFT) − VLA-Cache | +0.5 (p = 0.51) | +0.7 (p = 0.45) | −0.7 (p = 0.43) | −1.2 (p = 0.39) | **−0.2 pp** [−1.18, +0.83], p = 0.73 |

- **Object 스위트의 +1.8 pp (p = 0.028)** 하나만 명목상 0.05 아래입니다. 16개 검정(4 비교 × 4 스위트)에 Holm 보정을 하면 최소 p 0.028 × 16 = 0.44이므로 유의하지 않습니다.
- **검정력.** 시행 수 500이면 평균 차이 0.5 pp를 검정력 80%로 잡을 수 없습니다. 기준 성공률 97%에서 0.5 pp를 80% 검정력(양측 0.05, 비쌍)으로 보려면 **약 18,000 시행/팔**이 필요하고, 1.0 pp는 약 4,600 시행/팔이 필요합니다(`recompute_results.json`의 `derived`).
- **결론.** 논문이 쓴 "comparable" 성공률 표현은 이 가정 아래에서 "차이가 0.5 pp 이내로 측정되었지만 불확실하다"와 맞습니다. "동등하다"는 주장은 동치 검정(equivalence test)을 해야 하는데 논문은 하지 않았습니다.

## 3. 일관성 검사 (K2–K7)

**K2. 본문 속도비.** 초록의 2.67×는 0.37 잔여의 역수와 맞습니다(128.11 / 47.95 = 2.672). 1.27×는 OFT 동기 대 SR-VLA(OFT) (16.90 / 13.27 = 1.274). 본문의 1.25×(대 VLASH, 2.67 / 2.13 = 1.257), 1.15×(대 VLA-Cache, 15.24 / 13.27 = 1.148)도 맞습니다.

**K3. 표 IV 평균.** 본문의 τ_img 0.63, τ_p 0.51, C_max 22, k_e 148, α_r 0.0225, 수리율 35.98%, KV 갱신률 20.48%가 모두 맞습니다.

**K4. 표 II와 표 IV 일치.** 표 II 전체 정책의 수리율 31.68%와 KV 갱신률 27.37%가 표 IV Spatial 행과 같습니다.

**K5. 지연 주입 노출량 (§IV-C).** SR-VLA: 74.36 − 47.95 = 26.41 ms로 본문과 맞습니다(40 ms 중 66%). VLASH: 100.25 − 60.25 = 40.00 ms로 "전부 노출"과 맞습니다.

**K6. 표 II 본문의 정지 수치 (불일치 가능).** 본문은 동기 139.72 ms, 전체 재계산 대체 60.44 ms, 선택적 수리 54.78 ms라고 합니다. 표 III의 동기 128.11 ms와 SR-VLA 47.95 ms와 다릅니다. 표 II가 Spatial 한 스위트만 보는 것으로 보이나 원문이 범위를 말하지 않습니다. 표 III에는 스위트별 정지가 없어 검증할 수 없습니다. **미해결 항목입니다.**

**K7. 목표 이동 속도비.** 본문과 초록의 1.93×(1 cm)와 1.52×(5 cm)는 표가 없고 그림 5(c)에만 있습니다. 1.93은 표 III의 SR-VLA(OFT) 속도비(0 cm 대 π0.5 동기)와 우연히 같습니다. 두 조건(목표 이동 1 cm의 π0.5 대 0 cm의 OFT)이 다르므로 혼동하면 안 됩니다. 그림에서 값을 읽을 수 없어 검증하지 못했습니다.

**K8. 기타 확인.**
- 초록의 "1.52× to 1.93×" 범위와 §IV-D의 1.52×, 1.93×는 같은 값을 말합니다(K7과 같은 항목).
- 본문의 "Tpred가 5.6%" 주장은 그림 5(a)에서만 확인할 수 있습니다(검증 불가).
- 식 (2)를 30 Hz와 K = 5로 근사하면 동기 π0.5의 r_stall = 128.11 / (166.7 + 128.11) = 43.5%, SR-VLA(π0.5) = 47.95 / (166.7 + 47.95) = 22.3%입니다. 논문은 T_exec을 명시하지 않아 이 값은 근사입니다.

## 4. 정지 시간의 불확실성

- 원문은 질의당 정지의 **평균만** 줍니다. 분산, 구간, 질의 수가 없습니다. 따라서 속도비 2.67 또는 1.27의 구간을 계산할 수 없습니다.
- 속도비가 "같은 K 안에서" 정의된 것은 맞습니다. 그러나 질의 수와 측정 반복 횟수를 모르므로, 정지 차이가 측정 잡음보다 큰지 알 수 없습니다.
- 스위트별 정지가 없어 표 III의 평균 정지가 어떤 스위트 가중치로 나온 값인지 알 수 없습니다(K6과 연결).

## 5. 이 재계산이 말하지 않는 것

- 실제 시행 수는 모릅니다. 가정 500을 바꾸면 검정 결과가 바뀝니다. 예를 들어 시행이 50이면 차이 0.5 pp는 무의미하고, 5,000이면 1 pp도 유의할 수 있습니다.
- 쌍체 설계 여부를 모릅니다. 같은 초기 상태를 썼다면 검정력이 올라갑니다.
- 지연 수치는 A100 한 장에서 잰 값입니다. 다른 하드웨어(이 맥의 MPS 포함)에서 같은 비율이 나온다는 근거는 없습니다.
