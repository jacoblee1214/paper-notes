# 03. 수치 재계산, 통계 검정, 일관성 검사

## 0. 방법과 입력

- **입력:** 논문 Table 1 (v3, §5) 값 6행 × 9열. 값은 모두 0.05의 배수이고, 과제당 평가 20회와 맞습니다 (V2). 시도 기록과 시드 정보는 공개되지 않았습니다.
- **스크립트:** `analysis/recompute.py` → `analysis/recompute_results.json` (scipy만 사용, 수 초). 그래프 `analysis/plot_figures.py` → `report/figures/own_*.png`.
- **검정 단위:** 셀마다 20회 이항 표본으로 봅니다. 셀 사이의 정책 학습 분산은 반영하지 못합니다. 학습 실행이 셀당 한 번으로 보이고 시드를 보고하지 않았으므로 (V12), 아래 p값은 평가 에피소드 샘플링의 범위입니다.
- **다중 비교:** 열 단위 비교는 Holm 보정을 씁니다. 큐브·카턴 합산(독립 과제 2개)은 Fisher 정확 검정입니다.
- **재현 범위:** 실험(로봇, 학습)은 하지 않았습니다. 표 값에서 나오는 통계와 텍스트 주장만 확인했습니다.

## 1. 재계산 결과

### 1.1 초록의 86%

최종 단계 5셀 (IH 큐브 1.00, IH 카턴 0.85, IH 차 잎 0.85, XH 차 잎 0.85, XH 소금 0.75)의 평균은 **0.860**입니다. 초록의 86%와 맞습니다. 9셀 평균은 0.911입니다. 논문은 평균 방법을 쓰지 않았으므로, 86%는 "최종 단계 5셀 평균"이라고 읽는 것이 맞습니다 (V1).

| 행 | 최종 단계 5셀 평균 | 셀 수 |
|---|---|---|
| 상대·촉각 있음·Inpaint (주 설정) | 0.86 | 5 |
| 절대·촉각 있음·Inpaint | 0.14 | 5 |
| 상대·촉각 없음·Inpaint | 0.74 | 5 |
| 절대·촉각 없음·Inpaint | 0.62 | 5 |
| 상대·촉각 없음·Mask | 0.40 | 3 (Inspire만) |
| 상대·촉각 없음·Raw | 0.10 | 3 (Inspire만) |

### 1.2 셀별 Wilson 95% 구간 (주 설정, 최종 단계, n = 20)

| 셀 | 성공 | 95% 구간 |
|---|---|---|
| IH 큐브 | 20/20 (1.00) | [0.84, 1.00] |
| IH 카턴 | 17/20 (0.85) | [0.64, 0.95] |
| IH 차 잎 | 17/20 (0.85) | [0.64, 0.95] |
| XH 차 잎 | 17/20 (0.85) | [0.64, 0.95] |
| XH 소금 | 15/20 (0.75) | [0.53, 0.89] |

구간 폭이 약 ±0.15에서 ±0.2입니다. 두 셀의 차이가 0.15 미만이면 20회로는 구분할 수 없습니다.

### 1.3 상대 대 절대 행동 (열별 Fisher, Holm 보정)

- **촉각 있음:** 9열 중 **7열**에서 상대가 유의하게 높습니다 (Holm p < 0.05). 예외는 IH 차 도구 (20 대 16, p_holm = 0.21)와 XH 차 도구 (20 대 20, 동점)입니다. 상대 우위 8열, 동점 1열, 절대 우위 0열입니다.
- **촉각 없음:** 9열 중 **0열**이 Holm 후 유의합니다. 상대가 높은 열은 8열이고, XH 차 도구 한 열만 절대가 높습니다 (0.95 대 1.00, 1회 차이).
- 해석: 상대 행동의 우위는 촉각과 함께 있을 때 뚜렷합니다. 촉각이 없으면 열 단위 차이는 검출되지 않습니다. 본문의 "모든 과제에서 일관되게 더 좋다" (§5.1)는 촉각 없음 조건에서는 과장입니다 (V3).

### 1.4 촉각 효과 (같은 행동 표현 안에서 있음 대 없음)

- **XHand 5열 (차 도구, 차 잎, knob, pan, 소금):** 상대 행동에서 촉각이 3열 개선, 악화 0열, 같음 2열입니다. 절대 행동에서는 개선 0열, 악화 3열, 같음 2열입니다.
- **XHand 소금 (상대):** 15/20 대 3/20, Fisher p = 3.3e-4. 촉각의 가장 큰 효과입니다.
- **Inspire 4열 (상대):** 개선 1열 (큐브 1.00 대 0.95), 악화 2열 (카턴 0.85 대 0.90, 차 잎 0.85 대 0.90), 같음 1열입니다.

### 1.5 소프트웨어 적응 절제 (Inspire, 촉각 없음, 상대)

| 비교 | 큐브 p_holm | 카턴 p_holm | 차 도구 p_holm | 차 잎 p_holm |
|---|---|---|---|---|
| Inpaint 대 Mask | 0.041 | 2e-6 | 0.49 | 0.041 |
| Inpaint 대 Raw | 4e-6 | 0 | 0.23 | 0 |

- 큐브와 카턴을 합하면 (각 40회) Inpaint 37/40, Mask 14/40 (p = 9e-8), Raw 5/40 (p < 1e-7). 영상 적응의 효과는 확실합니다.
- 차 도구는 Inpaint 1.00 대 Mask 0.90으로 차이가 없습니다 (천장 효과).
- 절제는 Inspire 3과제에만 있습니다. XHand에서의 적응 효과는 측정되지 않았습니다 (V6).

### 1.6 검정력 (20회 대 20회, 양측 α = 0.05, 검정력 0.8, Cohen's h 근사)

| 기저 | 차이 | 1군당 필요 표본 |
|---|---|---|
| 0.85 | 0.15 | 60 |
| 0.85 | 0.20 | 36 |
| 0.85 | 0.30 | 18 |
| 0.60 | 0.20 | 49 |
| 0.60 | 0.30 | 21 |

20회로 구분할 수 있는 최소 차이는 기저 0.85에서 약 0.25–0.30, 기저 0.60에서 약 0.30입니다. XH 소금의 촉각 효과 (0.75 대 0.15)나 상대 대 절대 (촉각 있음, 0.4–0.9 차이)처럼 큰 차이만 확실하게 나타납니다. 10~15점 차이는 검출할 수 없습니다.

### 1.7 수집 효율 (그림 7)

- 그림 7의 막대 위 숫자 (텍스트 레이어에서 추출): 사람 손 51, DexUMI 36, 텔레오퍼레이션 11.
- 비율 36/11 = **3.27**입니다. 논문의 "3.2배"는 소수점 절삭과 맞습니다.
- 한계: 세션 수, 세션 반복, 분산이 없습니다. 과제는 차 집기 하나입니다. 구간을 만들 수 없으므로 "3.2배"는 한 번의 세션 비교로만 근거가 있습니다 (V9).

## 3. 요약

- **재현되는 것:** 초록 86% (최종 단계 5셀 평균), 수집 효율 3.2배 (36/11), 촉각 효과 (XH 소금), 상대 대 절대 (촉각 있음에서 7/9열).
- **재현되지 않는 것 또는 과장된 것:** 촉각에 대한 "대부분 악화" 서술 (V4), Inspire "모든 방법 악화" (V5), 촉각 없음 조건의 "모든 과제 우위" (V3), 적응 절제의 범위 (V6).
- **통계의 한계:** 셀당 20회, 학습 반복 없음. 10–15점 차이는 검출 불가 (1.6). 검정은 에피소드 샘플링만 반영합니다.
- **재계산 가능성:** 표 값만으로 재계산은 완료했습니다. 원자료(에피소드 로그, 시도 기록)는 공개되지 않았고, 저장소에도 평가 결과 파일이 없습니다.
