## 1. 한 문단 요약

행동 조건 영상 세계모델은 보통 로봇 제어 신호(관절·EEF 벡터)를 조건층에 넣는다. 그러면 모델이 (가) 제어 신호가 로봇 움직임으로 실현되는 과정과 (나) 장면이 그 움직임에 반응하는 과정을 함께 배워야 한다. 이 논문은 (가)를 모델 밖으로 뺀다(§3.1). 행동열을 로봇 자체의 컨트롤러와 기구학으로 **접촉 없이** 굴려 얻은 *명목(nominal) 궤적*을 만들고, 이를 URDF 메시 RGB와 EEF 깊이 영상으로 렌더링해, 정적 장면 RGB·깊이와 함께 비디오 확산모델(Wan2.1-Fun 14B InP, LoRA rank 64)의 입력 채널로 넣는다(식 1–6). DROID와 RoboCasa-GR1에서 AdaLN 상태 벡터 기준선보다 재구성 지표가 높고(표 1), 보지 못한 로봇(RoboTwin의 ur5-wsg, ARX-X5, HRDexDB의 xArm6–Inspire)에 영점 전이되며(표 5), 사람 시연을 retarget한 렌더링으로 로봇 영상을 만든다(그림 6).

## 2. 방법 (§3)

### 2.1 인터페이스 (§3.1, 식 1–4)

| 기호 | 뜻 | 식 |
|---|---|---|
| a_{1:F} | 원시 행동(관절 목표, 태스크 공간 명령) | |
| q_{1:F} = Φ_R(a_{1:F}; q_0) | 접촉 없이 로봇 컨트롤러·기구학으로 실현한 명목 궤적 | (1) |
| (M^rgb, D^eef) = Π_R(q; C) | URDF 메시 RGB와 EEF 전용 깊이, 카메라 궤적 C를 따라 렌더링 | (2) |
| (B^rgb, D^scene) = Π_S(S_0; C) | 초기 장면 상태의 정적 RGB·깊이 | (3) |
| p_θ(V | B, D^scene, M, D^eef, T) | 조건 분포. T는 장면만 설명하는 텍스트 | (4) |

- Φ_R과 Π_R은 학습하지 않는 전처리다(§3.1 끝). 학습되는 것은 확산모델뿐이다.
- 세 신호를 구분한다(§3.2, 그림 2): 원시 행동 a, 명목 궤적 q(배포 시 계산 가능), 실현 상태 x(접촉 결과가 섞인 로그, 배포 시 없음). 격차 둘 중 "행동-명목 격차"는 로봇별 실현 과정에, "명목-실현 격차"(접촉으로 인한 이탈, 물체 운동, 가림 변화)는 세계모델에 맡긴다.
- 고정 카메라에서는 정적 문맥이 **첫 프레임 반복**이다(§3.3). 로봇이 보이면 로봇도 포함한다(부록 A: "robot-free 재구성이 아님").
- 깊이는 EEF만 렌더링한다(§3.4). 로봇 전체 깊이는 쓰지 않는다.

### 2.2 학습 (§3.5, 식 5–6, 부록 B, 표 6)

- 백본: Wan2.1-Fun-V1.1-14B-InP. 정적 영상은 inpainting 경로로 들어가고 마스크는 "전부 알려짐(m=1)"이다(부록 B).
- 조건 스트림(정적 RGB, 로봇 메시 RGB, 장면 깊이, EEF 깊이)을 각각 VAE로 16채널 잠재로 인코딩해 노이즈 잠재에 채널 연결한다(식 5). 패치 임베딩이 36 + C 채널로 확장된다(메시만 C = 16, 메시 + 두 깊이 C = 48).
- 학습 가능: 확장 패치 임베딩 + LoRA(rank 64, α 64). 나머지는 고정.
- 손실은 잠재 flow matching(식 6, 속도 u = ε − z_0). AdamW(β = 0.9/0.95), 가중치 감쇠 0.01, 학습률 1e-4, 코사인 + 재시작, 워밍업 100, 클립 1.0, GPU당 배치 1 · 누적 4, bf16, 480×832, 81프레임, 16 fps(표 6). **GPU 수는 논문에 없다.**
- 추론: LightX2V의 CFG·스텝 증류 LoRA로 4 스텝, 가이던스 1.0. SVD 변형은 25 Euler 스텝, 192×320(부록 B).
- 학습 스텝: DROID nominal 진단 모델 15,010, 나머지 10,000(부록 B). 이 문장은 "nominal/logged 진단" 맥락에 있어, 표 1 모델의 스텝 수는 명시되지 않는다.

| 데이터 | 규모 | 명목 궤적 만드는 법 |

## 4. 한계 (논문이 쓴 것, §5)

- URDF, 카메라-로봇 보정, 로봇 로컬 컨트롤러 모델이 필요하다. 동적 시점은 정적 장면 표현과 카메라 궤적이 필요하고, 실세계 재구성은 오차를 낸다.
- 명목 재생은 **지정된 행동열에** 대해 미래 상태 입력을 없애지만, 로그된 폐루프 행동에 이미 들어 있는 결과 상관은 없애지 못한다.
- 깊이는 기하 단서일 뿐 접촉 물리를 보장하지 않는다. 로봇 제외 재구성도 물체 동역학의 불완전한 척도다.
- 과제 결과 연구는 시뮬레이터 라벨과 자동 판정자이며 물리 실행, 행동 순위 매기기, 정책 개선이 아니다. 실패 데이터가 적다.

## 6. 버전 차이 (v1 2026-07-24 → v2 2026-11-02)

| 위치 | v1 | v2 |
|---|---|---|
| 초록 | "logged future states leaks the interaction outcomes", 두 가지 과정의 서술, "generalizes to unseen robot embodiments" | 같은 틀을 줄여 쓰고 "supports transfer to unseen robot embodiments"로 표현을 바꿈. 누출 문장 삭제 |
| 서론 | "Rendering them therefore provides an aligned prompt while leaking the interaction" | "may therefore expose interaction outcomes" (단정 → 가능성) |
| 명목 궤적 정의 | "agrees with realized motion in free space, and diverges where contact..." | "approximates free-space motion while leaving contact-mediated deviations to be predicted, subject to the fidelity of the robot-local controller model" |
| 절제 표 | 표 2: 원시 21.57/0.860/0.175, 명목 22.44/0.872/0.164, +깊이 23.08/0.874/0.161. "깊이는 세 지표를 모두 개선" | 표 3: 21.34/0.848/0.187, 21.76/0.858/0.179, 21.96/0.856/0.179. "PSNR이 오르고 SSIM은 조금 낮고 LPIPS는 비슷" |

| 새 실험 | 정성 위주 | 표 2(과제 결과, 부록 E 혼동 행렬), 표 5(RoboTwin, HRDexDB 정량), 표 7(로봇 제외 평가, 부록 C) 추가 |
