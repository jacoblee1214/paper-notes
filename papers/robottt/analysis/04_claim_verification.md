# 04. 주장 검증과 구현 가능성: RoboTTT (arXiv:2607.15275)

공식 코드가 없어서(`analysis/02_prior_work.md` §2) 논문 ↔ 코드 대조(D 항목) 대신, 논문의 주장 C1–C21을 표·그림·본문 수치로 대조했습니다. 계산 근거는 `03`(V 항목)에 있습니다. 판정 표기: 일치 / 일치하나 조건 있음 / 불일치 / 검증 불가(자료 부족).

## 1. 공개 자료 현황

- 공식 코드, 체크포인트, 데이터: 2026-11-24 기준 찾지 못했습니다(논문과 프로젝트 페이지에 링크 없음, GitHub 검색 "RoboTTT"에서 공식 저장소로 보이는 것이 없음, 기반 저장소 NVIDIA/Isaac-GR00T에도 TTT 관련 코드 없음).
- 기반 모델 GR00T N1.7: 코드 Apache-2.0, 가중치 NVIDIA Open Model License. 설정 파일(`gr00t/configs/model/gr00t_n1d7.py`)에서 DiT 16층, 32헤드 x 48(내부 1536), action_horizon 40, 디노이징 4단계, 노이즈 Beta(1.5, 1), s = 0.999를 읽었습니다. 식 5의 노이즈 분포(Beta(1.5, 1), s = 0.999)는 이 설정과 같습니다.
- 비공식 구현 두 개(lucidrains/robo_ttt, Bala-la-la/lerobot-pi0-ttt)는 논문 저자의 것이 아니고 논문에 없는 요소(망각 게이트, 선택적 Muon, 다음 잠재 예측기)를 포함하므로 대조의 기준으로 쓰지 않았습니다.

## 4. 구현 가능성 판정 ("구현할 수 있는지")

**논문 수치의 재현은 이 맥(Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)에서 불가능합니다.** 사전학습 16 GPU(GB200) x 30K 스텝, 실로봇 YAM 양팔 세 과제, 공개되지 않은 사전학습 혼합 데이터, 체크포인트·코드 부재가 겹칩니다. 이유별로 정리합니다.

| 항목 | 이 맥에서 | 필요 |
|---|---|---|
| 논문 표 1–3, 그림 7–12 재현 | 불가 | YAM 로봇, 세 과제 데이터(8, 6, 5시간), 체크포인트(미공개) |
| 8K 사전학습 | 불가 | GB200 16개, 30K 스텝, 큐레이션된 21만 궤적 혼합(비공개) |
| GR00T N1.7 위 TTT 포팅 | 불가(GPU 필요), 조건부(CUDA 기기) | 공개 코드와 가중치(Open Model License)는 있음. TTT 층 구현, VLM 2B 통과, 8K 시퀀스 학습 파이프라인은 새로 작성. 노력 추정 2–4주(CUDA 기기, 데이터 별도) |
| TTT 층(식 1–3), 시퀀스 행동 강제(식 5), TBPTT, 일회 모방 마스킹을 소형 모델에 직접 구현 | **가능** | torch 2.15 설치됨. PyTorch 100–200줄, CPU/MPS에서 합성 과제. 노력 추정 1–2주 |
| 합성 과제에서 TTT-MLP, TTT-Linear, GDN류 선형 순환, 고정 창 이력의 비교 | **가능** | 상태 에일리어싱 과제(같아 보이는 단계를 기억해야 함)와 키-값 연상 스트림. 이 맥에서 몇 분–수 시간 |
| DAgger Distillation 마스킹을 MuJoCo 단순 과제로 | **가능** (mujoco 4.0, torch 2.15 설치됨) | 노력 추정 1–2주 |
| 고속 가중치 크기와 KV 캐시 비용 모델 | 완료 (03 §7) | |

판정 근거는 숫자로 두 가지입니다. 첫째, 8K 시퀀스 하나는 타임스텝마다 4대의 카메라 영상이 VLM을 통과하는 구조로 보여서(미기재, 백본이 얼려 있어도 순전파 비용이 있음) 이 맥의 MPS로 학습할 규모가 아닙니다. 둘째, 논문이 사용한 데이터와 체크포인트가 없어서 같은 조건으로 값을 비교할 수 없습니다. 이 맥에서 할 수 있는 것은 방법의 **작동 원리**(고속 가중치가 키-값을 저장하는지, 마스킹된 문맥이 갱신만 하는지, TBPTT가 경사를 끊는지)를 합성 과제에서 확인하는 것이고, 로봇 성능 수치와는 관계가 없습니다.

## 5. 저자에게 물을 질문

1. 타임스텝은 제어 스텝(30 Hz)입니까, 청크 단위입니까? VLM은 몇 스텝마다 호출합니까?
2. 그림 8의 1K 지점(43.9%)과 짧은 문맥 기준선(45.6%)의 관계에 대해 캡션의 "1K부터"는 어떤 의미입니까?

4. 8K 사전학습만 전역 배치 16인데, 배치 크기를 맞춘 8K 실험이 있습니까?
5. 사후학습 문맥 1K에서 일회 모방(사람 영상 1분 + 로봇 1분) 시퀀스는 어떻게 구성했습니까?

9. 시퀀스 모델의 "전체 궤적, 모든 행동에 손실" DAgger 조건은 측정했습니까?
10. 부록 A.1의 "Eagle" VLM과 공개된 GR00T N1.7(Cosmos-Reason2-2B)은 같은 백본입니까?
11. 코드와 체크포인트 공개 계획이 있습니까?
