## 1. 표 1 (음영 복원)

### 1.1 분할과 시험 표본 (V1)

- 객체 54 × 자세 20 = 1,080(식 12, 4.1절). 미관측 객체 5개 → 100장, 미관측 자세 → 49개 객체 × 1장 = 49장, 학습 = 49 × 19 = 931장. 합 1,080으로 일치합니다.
- **표본 크기의 의미.** 미관측 객체 시험은 5개 질감이고 한 객체의 20장은 같은 질감을 20가지 회전으로 누른 것입니다(그림 3). 미관측 자세 시험은 학습에 쓰인 객체의 19자세를 학습한 모델이 같은 객체의 20번째 자세를 보는 구성입니다. FID는 Inception 2048차원 특징의 공분산을 쓰는데 표본 공분산의 계수는 49장에서 최대 48, 100장에서 최대 99입니다. 이 구성에서의 FID 절대값은 표본 수에 민감한 값으로 읽는 것이 안전하며, 방법 간 순서는 격차가 큰 쪽(DeTac 17–26 대 나머지 104 이상)에서 의미가 있습니다. 시드나 부트스트랩 구간은 논문에 없습니다.
- 학습 규모: 에폭당 ⌈931 / 2⌉ = 466 스텝, 300 epoch = 139,800 스텝. 보조 손실은 100 epoch 뒤 켜지므로 93,200 스텝 동안 사용됩니다(V1, V10).

### 1.2 "TacDiff 대비 7 dB" (V2)

| 비교 | 미관측 자세 | 미관측 객체 |
|---|---|---|
| DeTac(전체) − TacDiff | +7.93 dB | +7.67 dB |
| DeTac(전체) − U-Net 회귀 | +0.89 dB | +0.04 dB |
| DeTac(전체) − 회귀 기준선 중 최고 | +0.89 dB | +0.04 dB |

기여 항목의 "over 7 dB"는 숫자로는 성립합니다. 다만 TacDiff는 합성 데이터로, U-Net·Pix2Pix·dual-head는 같은 쌍 데이터로 학습했으므로(4.1절 Baselines) 7 dB에는 데이터 차이가 섞여 있습니다. 쌍 데이터를 쓴 회귀 기준선과 비교하면 PSNR 차이는 0.04–0.89 dB입니다. 논문도 회귀 기준선이 "지각·분포 유사도에서 더 나쁘다"고 서술하며(4.2절), FID는 그 서술과 맞습니다(V12: 5.1배 / 6.2배).

### 1.3 열별 최고 (V3, V11)

DeTac 전체는 8개 열(2분할 × 4지표) 모두에서 최고입니다. 가장 좁은 차이는 SSIM 0.953 대 0.951(자세), 0.950 대 0.948(객체), PSNR 39.07 대 39.03(객체, 0.04 dB)입니다. 시험 표본이 49–100장이고 구간이 없어, 이 좁은 차이에 대해서는 우열을 말하기 어렵습니다(논문도 이 차이를 따로 주장하지 않음). 열별 순위의 평균은 DeTac 전체 1.0, L_con 제거 3.0, Pix2Pix·dual-head 4.12, L_sur 제거 4.38, U-Net 4.75입니다.

### 1.4 절제 (V4)

| 제거 | ΔFID(자세/객체) | ΔPSNR(dB) | ΔSSIM |
|---|---|---|---|
| L_sur | +5.34 / +5.53 | −4.81 / −4.02 | −0.007 / −0.005 |
| L_con | +2.21 / +2.38 | −1.68 / −0.79 | −0.004 / −0.002 |

- 4.3절의 "L_sur 제거가 가장 큰 열화"는 표와 일치합니다(FID 비 1.26 / 1.32배 대 1.11 / 1.14배).
- L_sur를 뺀 DeTac의 PSNR 34.64 / 35.05는 U-Net(38.56 / 39.03), Pix2Pix(38.53 / 38.98), dual-head(37.99 / 38.37)보다 낮습니다. 확산 모델의 FID 우위는 유지됩니다(25.78 / 22.59). 즉 PSNR·SSIM 기준에서 DeTac의 우위는 L_sur(마커 고리 L1)를 넣은 설정에서 나옵니다.
- L_sur의 가중치 0.05는 L_sha(노이즈 MSE)에 대한 상대값입니다. 가중치 민감도는 보고되지 않았습니다.

### 1.5 확대 마스크 (V5)

| 기준선 | ΔFID(자세/객체) | ΔPSNR(dB) | ΔSSIM | 개선된 지표 |
|---|---|---|---|---|
| TacDiff → 확대 마스크 | +13.07 / +25.33 | −0.59 / −0.56 | −0.014 / −0.016 | 없음(4/4 악화, 두 분할) |
| LaMa → 확대 마스크 | −28.03 / −29.70 | +1.14 / +1.11 | +0.036 / +0.036 | 4/4 개선 |

본문(4.2절)은 "확대 마스크 TacDiff와 LaMa가 여전히 DeTac보다 낮다"고 서술합니다. TacDiff에서는 마스크를 키운 변형이 원래 설정보다 모든 지표에서 낮아, "마스크를 키우면 함입 흔적이 지워진다"는 논지가 TacDiff 쪽에서는 표로 나타나지 않습니다. 원인은 표만으로 알 수 없고(가능성: TacDiff 학습 데이터와 마스크 규모의 불일치, 큰 마스크에서의 정보 손실), 저자 확인이 필요합니다.

### 1.6 FID 비 (V12)

회귀 기준선 중 최저 FID는 dual-head 104.27 / 105.18로 DeTac 20.44 / 17.06의 5.10배 / 6.17배입니다. SD 1.5는 121.70(5.95배, 자세)입니다.

## 2. 표 2 (마커 추출, V6)

| 비교 | 값 |
|---|---|
| UVTac / DeTac | 0.21 / 0.00762 = 27.6배 |
| SAM 3.1 / DeTac | 0.41 / 0.00762 = 53.8배 |
| L_sur 제거 / 전체 | +10.1% |
| L_con 제거 / 전체 | +9.2% |
| (L_sur 제거) − (L_con 제거) | 전체 값의 0.9% |

- DeTac 전체의 0.00762 mm는 7.62 µm입니다. 이미지 해상도와 센서 mm/픽셀이 논문에 없어(가정이 필요) 픽셀 단위로 옮기지 않았습니다.
- **절제의 읽기.** 4.3절은 "L_con 제거가 마커 추출 오차를 약간 늘린다"고 서술하고, L_con 제거(+9.2%)와 L_sur 제거(+10.1%)는 서로 0.9%p 차이입니다. L_sur의 이진화(식 7)는 미분되지 않으므로 L_sur가 마커 분기를 직접 바꾸지는 않고, 음영 분기를 거쳐 I_chg(식 9)가 달라지는 경로로만 영향을 줍니다. 시드가 하나인 단일 실행에서 10% 안팎의 차이가 방법의 효과인지 실행 간 변동인지는 가를 수 없습니다.
- 기준선 정의: UVTac(자외선 마커 전환 하드웨어 방식)을 혼합 이미지에 어떻게 적용했는지, SAM 3.1에 프롬프트를 주었는지는 본문에 없습니다.

## 4. 표 A1 (직물 분류, V8)

보고 백분율은 직물당 30회의 정수 성공 수와 맞습니다(소수 한 자리). 복원한 성공 수는 아래와 같습니다. 시행이 서로 독립이라고 **가정**하고 Wilson 95% 구간과 Fisher 정확 검정을 계산했습니다.

| 직물 | 혼합 이미지 | DeTac 음영 | Fisher p (양측) | Holm 보정(3개) |
|---|---|---|---|---|
| A | 5/30 = 16.7% [7.3, 33.6] | 25/30 = 83.3% [66.4, 92.7] | 3.6e-07 | 1.1e-06 |
| B | 13/30 = 43.3% [27.4, 60.8] | 22/30 = 73.3% [55.6, 85.8] | 0.035 | 0.070 |
| C | 27/30 = 90.0% [74.4, 96.5] | 29/30 = 96.7% [83.3, 99.4] | 0.61 | 0.61 |
| 합 | 45/90 = 50.0% [39.9, 60.1] | 76/90 = 84.4% [75.6, 90.5] | 1.3e-06 | - |

- 표의 "Overall"(50.0%, 84.4%)은 세 직물의 단순 합과 일치합니다(45/90, 76/90).
- 직물 A의 혼합 이미지 성공률 16.7%는 분류 범주가 3, 4, 5개일 때의 우연 수준 33.3%, 25%, 20%보다 낮은 값입니다. 부록 C는 범주를 "several"이라고만 적습니다. 마커가 있는 입력이 한 방향으로 체계적으로 틀리는 것이 가능한 설명이지만 확인하려면 혼동 행렬이 필요합니다.
- 직물 C는 혼합 이미지도 90.0%라 두 입력 차이가 구간 안에서 겹칩니다. 개선은 직물 A에 집중되어 있고 B는 보정 전 p = 0.035입니다.
- 분류 입력은 마커 센서의 혼합 이미지 대 DeTac 음영이고, 분류망은 마커 없는 센서 데이터로 학습했습니다(부록 C). 직물 3종이라 일반적인 질감 분류 성능으로 확장하기는 어렵습니다.

## 5. 부록 A.3: 힘 변화의 크기 (V9)

200 g과 500 g 이미지의 픽셀별 MAE 3.072(0–255)는 같은 쌍의 RMSE가 MAE 이상이므로 PSNR 20·log10(255 / 3.072) = **38.38 dB 이하**에 해당합니다. 표 1의 DeTac PSNR 39.45 / 39.07은 이 값과 같은 크기입니다. 저자는 이 수치로 "200 g 고정이 데이터의 시각적 다양성을 크게 제한하지 않는다"고 서술합니다. 한편 이 비교로 알 수 있는 것은 (a) 2.5배의 누름 힘 변화가 만드는 이미지 차이와 (b) 모델 오차가 비슷한 크기라는 점이고, 쌍 정렬(자세 편차, 마커 제작 전후의 엘라스토머 차이) 자체가 만드는 잡음 바닥은 보고되지 않았습니다. 정답 I_sha와 I_mix 사이의 정렬 정밀도는 그림 A1 한 장으로만 제시됩니다.

## 6. 학습 비용과 맥 속도 (V10, V13)

| 항목 | 값 |
|---|---|
| 보고 | RTX 4090, 300 epoch, 배치 2, 약 14 h → 스텝당 0.36 s(139,800 스텝 기준, V10) |
| 구조 산술(V13) | 인코더 4단계 × 2 + 병목 2 + 디코더 4단계 × 3 = 22개로 부록 A.1과 일치 |
| 가정한 구조 | 6채널 입력, 채널 (64, 128, 256, 256), 사인 시간 임베딩, stride-2 합성곱 다운샘플, 최근접 업샘플, 어텐션 없음 → **23.77 M 파라미터** |

랜덤 가중치로 한 스텝(순전파 + 역전파 + AdamW)과 샘플링 한 단계를 맥(Apple M4 Pro, MPS 또는 CPU)에서 쟀습니다. 해상도는 논문에 없어서 128, 256 둘을 가정했습니다.

| 장치, 해상도 | 학습 스텝(배치 2) | 300 epoch 추정 | 샘플링 한 단계(배치 1) | T = 1000 단계 추정 |
|---|---|---|---|---|
| CPU 128 | 0.82 s | 31.8 h | 0.139 s | 139 s |
| CPU 256 | 2.84 s | 110.4 h | 0.432 s | 432 s |
| MPS 128 | 0.144 s | 5.6 h | 0.015 s | 15 s |
| MPS 256 | 0.528 s | 20.5 h | 0.056 s | 56 s |

- 데이터 로딩, L_sur·L_con 계산(고리 팽창, 이진화), 마커 분기, 증강은 포함하지 않았고 샘플링은 단계 수를 1,000으로 **가정**한 곱셈입니다(논문은 "수백 단계"라고만 적음).
- 보고된 4090의 스텝당 0.36 s는 이 측정의 MPS 128과 256 사이입니다. 입력 해상도가 128과 256 사이이거나 데이터 로딩이 포함된 값일 가능성이 있습니다(추정).
- 결론: 모델 크기(24 M)와 데이터(1,080쌍)만 보면 이 맥에서 학습할 수 있는 규모입니다. 막히는 것은 데이터(공개 여부 미확인)와 마커 정답 생성, 센서입니다(`04` 4절).
