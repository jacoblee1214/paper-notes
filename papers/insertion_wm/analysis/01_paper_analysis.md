## 0. 한 문단 요약

저자들은 TD-MPC2(잠재 공간 세계 모델 + MPPI 계획)를 **삽입(insertion) 과제 하나**에 적용하고, 그 모델 하나로 **90개 조립품**(AutoMate 데이터셋 100쌍 중 90쌍)을 학습합니다. 입력은 손목 카메라의 96×96 깊이 영상과 로봇 고유감각(24차원)입니다. 학습에는 CAD 기반 역분해 시연을 쓴 보상이 들어갑니다. 학습하지 않은 10쌍(ID가 가장 큰 10개)에서 **제로샷 성공률 56%**(100회 × 10쌍)를 보고하고, 비교 대상으로 AutoMate의 **7%**를 씁니다. 이 7%는 저자들이 AutoMate 논문에서 가져온 수치이며, 같은 분할과 같은 학습 규모에서 재측정한 값이 아닙니다. 실험은 전부 Isaac Gym 시뮬레이션이고, 실물 실험은 없습니다.

## 1. Abstract과 Introduction

**주장 (Abstract, I절).**
1. 고정된 조립 쌍마다 정책을 따로 학습하는 방식(specialist)은 확장이 어렵다.
2. 세계 모델 하나를 90개 조립품에 학습하면 학습하지 않은 조립품에서 56% 제로샷 성공을 보인다. 모델 없는 기준선은 7%다.
3. 학습 객체가 늘수록 성능이 오른다(확장성).
4. 생성 모델을 미지 객체에 미세조정하면 처음부터 학습보다 데이터 효율이 좋고, 일부는 점근 성능도 높다.
5. "기하를 모르는 미지 객체를 완전히 데이터로만 조립한 첫 시스템"이라고 주장한다.

**기여 (I절 마지막 문단).** 새 알고리즘보다 "시각 모델 기반 RL이 산업 조립에서 쓸모 있다"는 것을 보이는 데 무게를 둡니다. 저자들은 스스로 기여를 "설계 선택의 실용 지침"이라고 씁니다(I절, "Notably, the key contribution ... is not to propose a new algorithm").

**문제 설정 (I절, III절).** 실물 조립은 손으로 짠 제어기나 부품별 전문 정책에 의존합니다. 제안은 정책 학습을 **다수 객체의 한 모델**로 옮기는 것입니다.

## 2. Preliminaries와 TD-MPC2 (III절)

논문은 II절 "Related Work" 제목 아래 본문이 없고, 관련 연구 문단이 III절 "Preliminaries" 제목 아래 들어 있습니다(편집 오류로 보입니다). 여기서는 실제 내용 위치를 따라 씁니다.

**MDP 정의 (III절, "Robotic insertion with RL").** 상태는 깊이 영상 x ∈ R^{96×96}과 고유감각 q ∈ R^24로 근사하고, 부분 관측 MDP로 봅니다. 행동은 6자유도 end-effector 증분 자세(정규화 [-1, 1])입니다. 저자들은 "full state s는 실제 응용에서 알 수 없어 [x, q]로 근사한다"고 씁니다.

**TD-MPC2 구조 (식 1).** 잠재 세계 모델은 다섯 부분으로 구성됩니다.
- 인코더 z = h(s), 잠재 전이 z′ = d(z, a), 보상 r̂ = R(z), 가치 q̂ = Q(z, a), 정책 사전분포 â ∼ p(z).

**학습 목적 (식 2–4).** 잠재 예측 손실을 시간 지수 가중 λ로 합산합니다. 단계 손실은 보상 교차엔트로피, 가치 교차엔트로피, 그리고 잠재 공간 예측 손실 ∥z′_t − sg(h(s′_t))∥²입니다(식 4, stop-gradient). **픽셀을 복원하는 디코더는 없습니다.** 저자는 "without decoding raw observations"라고 씁니다(III절 첫 단락). 따라서 이 세계 모델이 **예측하는 것은 잠재 상태, 보상, 가치**이고, 영상이나 물체 자세, 접촉력을 직접 예측하지 않습니다.

**계획.** 추론 때는 MPPI(Williams 외 2015)로 행동 시퀀스를 샘플링하고, 정책 사전분포를 샘플에 섞습니다. 샘플 수, 호라이즌, 반복 수, 온도는 **이 논문에 없습니다**. TD-MPC2 참조(III절 "Refer to [30], [31]")에만 있습니다. 저장소 기본값은 `03_analysis.md` §7에 있습니다.

## 3. 방법 (V절)

**관측과 행동.** 깊이 영상 96×96(손목 카메라 한 대, 시뮬레이션용 RealSense D435 모사), 고유감각 24차원입니다. 고유감각은 다음과 같습니다(IV절 "Observations").
- 관절각 R^7
- 끝점 자세의 잡음 섞인 추정 R^7 (위치 3 + 쿼터니언 4)
- **소켓 자세의 잡음 섞인 추정 R^7** (위치 3 + 쿼터니언 4)
- 목표 위치 R^3 (플러그가 완전히 삽입된 점)

**중요한 점:** 소켓 자세는 시뮬레이터의 참값에 백색 잡음을 더한 것으로 보입니다. 실제 장비에서는 이것을 추정하는 단계가 필요하고, 그 단계는 논문에서 다루지 않습니다. 저자들이 말하는 "CAD와 객체 ID가 필요 없다"는 것은 **객체 기하 정보에 한정된 주장**입니다. 자세 추정은 포함하지 않습니다(§4 C12).

**인코더 (식 6).** h(x, q) = h_fuse(h_depth(x) + h_prop(q)). h_depth는 얕은 CNN, h_prop과 h_fuse는 2층 MLP이고, 모두 SimNorm 출력입니다. 저자들은 "객체 ID의 one-hot은 미지 객체에 옮길 수 없으므로 시각 정보만으로 구별한다"고 씁니다(V절 "Zero-shot generalization").

**행동 출력.** 학습된 정책 사전분포와 MPPI 계획으로 행동을 냅니다(III절과 V절).

**보상 (식 5).** R = r_penetration·(r_dist + r_imitation + r_success). r_dist는 플러그와 목표의 음의 거리, r_imitation은 **역분해 절차로 만든 시연**을 따라가는 항, r_success는 성공 이진항입니다. 계수는 생략했고, 저자들은 이 보상을 [6]과 [1]에서 "수정 없이" 가져왔다고 씁니다. 이 보상은 학습 객체마다 역분해 시연이 필요하므로, **학습 단계에서는 객체 기하(CAD에서 만든 시연)를 쓴다**는 뜻입니다. 저자들은 이 점을 "privileged"라고 따로 쓰지 않습니다.

**학습 설정 (VI-A "Implementation details", IV절).**
- 세계 모델 약 5M 파라미터(모든 변형 동일)
- 특수 모델(specialist, 객체 100개 각각) 2M 스텝, AutoMate는 50M 스텝
- 생성 모델(generalist, 90개) 7M 스텝
- 계산: 특수 모델 40시간, 생성 모델 3일, 둘 다 RTX 3090 1장(VI-A)
- 병렬 환경: 생성 모델은 객체마다 환경 하나(90개 병렬), 무작위화된 장면 설정(IV절 "Zero-shot generalization")
- 커리큘럼: 학습 성공률에 따라 초기 상태 분포를 쉬운 쪽에서 어려운 쪽으로 옮김(V절·VI-B)

**학습 구현 세부가 빠진 것.** 샘플 수와 호라이즌은 없습니다. 환경 스텝의 정의(병렬 수 포함)는 없어, AutoMate의 "50M 스텝"과 직접 비교는 단위가 맞지 않을 수 있습니다. 두 방법의 단계 수를 같다고 가정하면 안 됩니다.

## 4. 데이터와 환경 (IV절)

- **데이터:** AutoMate[1]의 조립 자산 100쌍(플러그를 소켓에 넣는 두 부품). [4][5]에서 가져왔고, 자산마다 번호(ID)가 있습니다.
- **환경:** AutoMate의 Isaac Gym 환경을 "closely follow"로 재현(Franka Panda, 평행 그리퍼, 테이블 위 소켓은 상향 자세로 무작위 배치, 플러그는 모션 플래닝으로 잡은 뒤 시작).
- **실물 장비 주장:** 저자들은 장비 구성이 [1][6][7][10]의 실물 실험과 같다고 씁니다. 그러나 **이 논문에는 실물 결과가 없습니다**(VII절 "deployment of visual policies on real hardware is still challenging").

## 5. 실험 (VI절)

### 5.1 평가 프로토콜 (VI-A "Evaluation")
- **미지 객체 분할:** 100개 가운데 ID가 가장 큰 10개를 고정된 테스트 세트로 둡니다. 나머지 90개로 학습합니다. ID는 1036, 1041, 1053, 1079, 1092, 1102, 1125, 1129, 1132, 1136입니다(Fig. 6 제목에서 확인).
- **Fig. 2 설명:** "Training and test assemblies are drawn from the same data distribution." 즉, 미지 객체는 **같은 데이터 분포의 다른 자산**입니다. "unknown geometry"는 정책이 기하를 입력으로 받지 않는다는 뜻이고, 기하가 본질적으로 다른 객체라는 뜻은 아닙니다.
- **분할 근거:** "선택 편향을 줄이려고 ID 순서로 자른다"고 씁니다. 그러나 ID가 자산 출처나 기하 계열과 관련이 있으면 이 분할은 계열 단위의 분할일 수 있습니다. 논문은 이를 확인하지 않았습니다.
- **학습 규모 실험:** 생성 모델은 학습 객체 수를 5, 15, 45, 75, 90으로 바꿔 학습합니다(Fig. 1 오른쪽). 학습 객체의 부분집합은 ID 오름차순으로 고릅니다.
- **시도 수:** 생성 모델은 객체당 100회, 특수 모델은 객체당 5 seed × 100회입니다. 미세조정은 5 seed(95% 신뢰 구간 음영, Fig. 6).

### 5.2 기준선 (VI-A "Baselines")
- **AutoMate[1] (주 기준선):** PPO로 특수 모델을 학습합니다. 생성 모델은 특수 모델을 BC, DAgger, 온라인 RL로 증류하고, **CAD 모델의 점군 임베딩을 조건으로 씁니다**(VI-A). 배포 때도 객체별 CAD와 자세 추정 파이프라인이 필요하다고 씁니다.
- **수치 출처:** "AutoMate 생성 모델 수치는 [1]에서 가져왔다". 분할은 저자들도 **알 수 없다**고 씁니다("exact training and test splits for AutoMate are not known"). 그래서 Fig. 1의 AutoMate 수치는 AutoMate 논문의 값입니다. 재측정이 아닙니다.
- **내부 변형:** 시각 없는 모델(blind), 카메라 위치 변경, 커리큘럼 유무와 종류, 전문가 롤아웃 100개를 받는 생성 모델.

### 5.3 주요 결과 (VI-B, Fig. 1, Fig. 5, Fig. 6)

| 특수 모델 100개 평균 | 79.78% (AutoMate 70.31%) | VI-B "Single-assembly", Fig. 5 |
| 생성 모델, 학습 객체 90개(seen) | 55.0% (본문), 54.5% (Fig. 7) | VI-B, Fig. 7 |
| 생성 모델, 미지 10개 | 56% (제로샷) | Abstract, VI-B, Fig. 1 |

**특수 모델.** 79.78%대 70.31%입니다. 저자들은 AutoMate가 "큰 소켓"에서 이기고 우리 방법은 "작고 얇은 소켓"에서 이긴다고 씁니다. 296과 726에서 떨어짐(VI-B)을 인정합니다. 가림(occlusion)이 원인일 것이라고 추측합니다.

**생성 모델 확장.** 학습 객체가 늘면 seen 성능은 약간 떨어지고(59 → 55), unseen 성능은 오릅니다(27 → 56). 저자들은 "in-domain과 out-of-domain이 이 수준에서 saturation할 것"이라고 가정합니다(VI-B). 이것은 가설로 표시되어 있습니다.

**미세조정 (Fig. 6, VI-B).** 90개 생성 모델을 10개 미지 객체에 미세조정하고 처음부터 학습과 비교합니다. x축은 0–30k 환경 스텝이고, 처음부터 학습 기준선은 2M 스텝 값을 점선으로 씁니다. 두 곡선의 스텝 범위가 다릅니다. 또 **1053**에서는 미세조정(약 0.4–0.6)이 처음부터(약 0)보다 낫지만 2M 기준선(0.8)에 못 미치고, **1132**에서는 두 방법 모두 낮습니다(처음부터 2M 기준선 0.25, 미세조정 약 0.05). 저자들이 말한 "in some cases exceeds"는 1036과 1041 두 개를 가리킵니다.

**절제 (Fig. 7, VI-B).**
- 센서: 고유감각만(39.6) 대 깊이 + 고유감각(54.5) 대 대체 카메라 위치(46.4), 생성 모델 기준. 특수 모델은 55.2 / 79.8 / 72.7.
- 커리큘럼: 없음 52.1 / 기본 54.5 / 시연 56.5(생성 모델). 특수 모델은 76.2 / 79.8 / 79.5(역커리큘럼).
- 저자들의 결론: 시각이 "critical"이고, 커리큘럼은 "consistently improves"하지만 종류는 덜 중요하다.

### 5.4 한계 (VII절, VI-B)
저자들이 인정하는 한계는 네 가지입니다. (i) 가림이 큰 조립품에서 실패, (ii) 학습 객체가 늘수록 seen 성능이 약간 떨어짐, (iii) 생성 학습용 조립 데이터셋이 부족함, (iv) 실물 배포는 아직 어렵고 깊이 잡음과 얇은 부품, 실시간 처리가 문제. 논문은 **실물 결과가 없음**을 명시하지 않고 "still challenging"이라고 씁니다.

## 6. 해석이 갈리는 곳 (읽을 때 조심할 것)

1. **"unseen"의 뜻.** 같은 데이터 분포의 객체이며, 기하 계열이 떨어진 객체가 아닙니다. 분할은 ID 기준입니다.
2. **"model-free baseline 7%"의 뜻.** AutoMate는 PPO 기반의 모델 없는 방법이지만, 이 수치는 AutoMate가 **CAD를 입력으로 쓴 생성 모델의 점**이고, 학습 객체 수도 다릅니다(Fig. 1에서 7%는 학습 객체 약 15–25개 부근). 헤드라인의 "56 대 7"은 같은 조건의 비교가 아닙니다.
3. **"vision-only, no privileged information"의 뜻.** 배포 때는 CAD를 안 쓰지만, 관측에 **시뮬레이터 소켓 자세(잡음 있음)**가 들어 있고, 학습 보상에는 CAD 기반 역분해 시연이 들어 있습니다.
4. **"world model"의 뜻.** 픽셀 예측 모델이 아니라 잠재 공간 보상·가치 모델입니다. 접촉이나 자세를 명시적으로 예측하지 않습니다.
5. **시도 수와 신뢰 구간.** 미지 10개 × 100회라는 시도 수는 객체 간 분산을 무시합니다(`03_analysis.md` §2).
6. **Fig. 7 수치 불일치.** 본문 55.0%와 Fig. 7의 54.5%가 다릅니다. 같은 평가의 반올림 차이인지 확인되지 않았습니다.
7. **"zero-shot reaches in-domain at this scale"(VI-B).** 56 대 55는 차이가 우연일 가능성이 큽니다. 미지 10개의 객체 간 분산을 고려하면 구간이 매우 넓습니다.

## 9. 용어

- **specialist:** 객체 쌍 하나에 학습한 정책. **generalist:** 여러 쌍을 한 모델로 학습한 정책.
- **seen / in-domain:** 학습 객체. **unseen / zero-shot / out-of-domain:** 학습하지 않은 10개 테스트 객체.
