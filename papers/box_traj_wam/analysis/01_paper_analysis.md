# 01. 논문 분석: Box Trajectories as Compact State Representations for World Action Models (BoxWAM)

*Qinxi Yu, Wenzhou Ding, Gloria X. Wang, Albert J. Zhai, Shenlong Wang (UIUC).* arXiv:2610.17526 v1 (2026-10-13, 유일한 판본). CoRL 2026 포스터(공식 채택 목록 확인, §7). 쪽·표 번호는 arXiv PDF 기준입니다.

## 1. 한 줄 요약

월드 액션 모델(WAM)이 미래 영상 프레임을 예측하는 대신, **지금 조작 중인 물체의 3D 방향 경계 상자(OBB) 여덟 꼭짓점을 카메라 화면에 투영한 16차원 좌표**를 미래 상태로 예측하고, 이 상자 궤적을 보고 행동 토큰이 만들어지도록 어텐션을 한 방향으로 열어 둔 정류 흐름(rectified-flow) 트랜스포머입니다. 시뮬레이션(RoboTwin 2.0)과 xArm7 실로봇 세 과제에서 같은 구조의 행동 전용 변형과 확산 정책보다 높은 성공률을 보고하고, 밀집 표현(VAE, DINO 토큰)보다 지연이 낮다고 보고합니다(초록, 표 1–5).

## 2. 문제와 아이디어

- **질문(1절):** "미래 상태를 예측하는 것이 행동 예측에 도움이 된다면, 어떤 압축된 미래 표현이 그 이점을 보존하는가?" 밀집 프레임은 배경과 조명까지 예측해야 해 비싸고, 잠재 표현은 학습이 어렵고 해석이 안 된다는 것이 저자의 동기입니다.
- **제안(3.1절):** 미래 상태 x_{T+1:T+H}를 "능동 물체"의 상자 궤적으로 둡니다. 능동 물체는 학습 때 현재 조작 중인 물체, 없으면 시연에서 다음에 접촉할 물체입니다(3.1절 "미래 접촉 정보는 감독 신호를 만드는 데만 쓴다"). 추론 때는 정답 상자도 접촉 순서도 받지 않고, RGB, 고유감각, 언어 지시만 받습니다.
- **상태 표현(3.1절):** x_t = [u_1, v_1, ..., u_8, v_8] ∈ R^16, 제3자 시점 카메라 화면 좌표. 양팔 설정에서는 왼팔·오른팔 슬롯을 따로 두고, 팔에 대상이 없으면 0으로 채우고 상태 손실에서 마스크합니다.

## 3. 방법

### 3.1 구조 (그림 2, 3.2절)

1. 관측 이미지(장면 카메라, 손목 카메라)를 동결된 DINOv3로 인코딩해 시각 문맥 토큰을 만듭니다.
2. 문맥 토큰, 잡음이 섞인 미래 상자 토큰 H개, 잡음이 섞인 행동 토큰 H개를 한 시퀀스로 이어 붙입니다(미래 시각마다 상자 토큰 하나, 행동 토큰 하나).
3. 고유감각 q_T와 흐름 시각 τ는 적응형 레이어 정규화로 각 블록에 넣습니다. 출력은 선형 헤드 둘(미래 상태, 행동)입니다.
4. 어텐션 규칙: 행동 토큰은 문맥, 상자, 행동 토큰을 보고, 상자 토큰은 문맥과 상자 토큰만 봅니다(그림 2 오른쪽). 상자가 미래 행동에 의존하지 않으므로 상자 궤적이 "물체 운동 계획"처럼 행동을 이끈다는 설명입니다.

### 3.2 학습과 추론

- 식 (1): p_θ(x_{T+1:T+H}, a_{T+1:T+H} | I_T, q_T, ℓ). 과제 조건 ℓ은 단일 과제 정책에서 비고, 다과제에서는 언어 지시입니다.
- 식 (2): L = E[λ_X ‖v̂^X − (x^1 − ε_X)‖² + λ_A ‖v̂^A − (a^1 − ε_A)‖²], λ_X = λ_A. τ는 Beta(1.5, 1.0)에서 u를 뽑아 τ = 0.999(1 − u) (π0.5 방식).
- 추론: τ = 0에서 1까지 Euler 적분, 제곱 일정 τ_k = 1 − (1 − k/N)². 행동 덩어리를 모두 실행한 뒤 다시 계획합니다(27,500 시연 비교만 50개 중 36개 실행).
- 행동 표현: 관절 위치 제어에서 a_t = q_target − q_curr (상대 명령, [−1, 1] 정규화). 예측 구간 H = 15(단일 과제 시뮬), H = 50(다과제와 실로봇).
- **π0.5 통합(3.2절):** π0.5 행동 전문가에 상자 토큰 50개와 선형 투영 둘을 더하고 같은 어텐션 마스크를 씁니다. 표 2의 두 모델은 같은 체크포인트에서 2,500 시연으로 30,000 스텝 미세조정합니다.
- **실로봇 정답(부록 A):** SAM 3 마스크와 FoundationPose로 물체 자세를 구하고, 파지 이후에는 말단장치 궤적으로 자세를 전파해 8개 꼭짓점을 투영합니다. 재구성 오차는 정량 평가하지 않았다고 적혀 있습니다.

## 5. 보고된 결과

### 5.1 단일 과제 (표 1)

| 설정 | 평균: DP / ACT / DP3 / π0 / Flow / BoxWAM | 비고 |
|---|---|---|
| 청정 | 55.4 / 60.4 / 81.2 / 71.4 / 73.2 / **78.3** | DP3는 깊이(RGBD) 입력 |
| 무작위 | 0.7 / 6.3 / 5.1 / 33.1 / 32.6 / **37.8** | |

본문은 "청정에서는 깊이를 쓰는 DP3를 제외한 모든 기준선보다 높고, 무작위에서는 평균이 가장 높다"고 씁니다(4.2절). 과제 단위로 보면 BoxWAM이 Flow보다 높은 과제는 청정 7/9, 무작위 5/9입니다(`03` V3).

### 5.2 다과제 (표 2, 표 7–9)

| 모델 | 청정 | 무작위 | 지연(ms) |
|---|---|---|---|
| π0.5 | 52.6 | 26.9 | 55.3 |
| π0.5 + BoxWAM | 61.5 | 34.0 | 57.7 |

50개 과제별 표(부록 C)에서 상승 과제는 청정 37개, 무작위 33개, 하락 과제는 각각 8개, 16개입니다(`03` V4). 본문도 "개선은 과제마다 고르지 않다"고 적습니다.

### 5.3 실로봇 (표 3)

| 방법 | 커피 SR / 진행 | 물주기 SR / 진행 | 포켓몬 SR / 진행 | 평균 |
|---|---|---|---|---|
| Diffusion Policy | 10.0 / 34.0 | 8.0 / 9.4 | 34.0 / 47.0 | 23.7 |
| Flow (행동만) | 24.0 / 48.0 | 48.0 / 54.7 | 60.0 / 72.0 | 51.1 |
| BoxWAM | 26.0 / 54.4 | 66.0 / 70.7 | 70.0 / 78.0 | 60.9 (본문 60.85) |

표의 "Average"는 성공률 세 값과 진행률 세 값을 함께 평균한 수입니다(`03` V5).

### 5.4 절제 (표 4, 표 5)

- **미래 상태 표현(표 4, 청정 / 무작위 SR):** 행동만 73.2 / 32.6, VAE 80.1 / 34.5, DINO 69.9 / 29.0, 6D 포즈 73.2 / 32.1, 2D OBB 74.2 / 30.7, 기능 키포인트 75.3 / 27.8, EE 궤적 74.0 / 32.6, 3D OBB(BoxWAM) 78.3 / 37.8. 지연은 행동만 168.3 ms, VAE 250.5 ms, DINO 251.4 ms, 상자 172.4 ms. 행동만과 상자는 6,000 스텝, 밀집 표현은 수렴이 느려 15,000 스텝 학습했다고 적습니다(4.3절).
- **상태-행동 결합(표 5):** 완전 분리 76.6 / 37.4, 완전 결합 76.7 / 32.9, 행동 → 상태 76.1 / 35.5, 상태 → 행동(BoxWAM) 78.3 / 37.8.
- 표 4의 행동만과 상자 행은 표 1의 Flow, BoxWAM 평균과 같은 값(73.2 / 32.6, 78.3 / 37.8)입니다(`03` V7).

### 5.5 큰 시연 수와 IK 기준선 (그림 6, 4.3절)

27,500 시연, 35,000 스텝으로 미세조정한 π0.5 + BoxWAM이 Easy 87.94%, Hard 87.62%, 지연 64.9 ms, 3.35B 파라미터라고 적습니다. 그림 6(거품 차트)에서 읽은 값(그림 판독 값)은 BoxWAM이 약 87.8%, π0.5가 약 80%, Fast-WAM이 약 92%입니다. 정답 계획·자세·깊이·마스크를 주는 Mink + M2T2 미분 IK 기준선은 Easy 26.78%, Hard 26.30%입니다.

## 6. 한계 (6절)와 우리가 보는 추가 한계

저자가 적은 한계: 정답 상자를 만들 객체 추적에 의존하고, 심한 가림, 변형 물체, 상자 정보가 부족한 과제에서는 성능이 떨어질 수 있다.

표와 서술에서 더 읽히는 것:

- **정답 상자가 필요합니다.** 시뮬에서는 시뮬레이터 상태에서, 실로봇에서는 메시, 보정, SAM 3, FoundationPose가 필요합니다(3.1절, 부록 A). 밀집 변형(VAE, DINO)에는 이런 주석이 필요 없습니다. 지연 비교는 있지만 주석 비용 비교는 논문에 없습니다.
- **행동 전용 기준선도 DINOv3를 씁니다.** 본문이 "행동 전용 변형이 강한 것은 DINOv3 덕분일 가능성"이라고 직접 적습니다(4.2절). 따라서 Diffusion Policy와의 격차(실로봇 평균 23.7 대 51.1)는 상자의 효과와 인코더 차이가 섞여 있습니다.
- **통계 정보가 적습니다.** 단일 과제 표 1은 학습 시드가 하나일 가능성이 있고(평가 시드와 구분되지 않음), 표 2는 한 시드, 표 3은 과제당 50회입니다. 구간·검정이 논문에 없습니다(`03` V3–V5, V10).
- **표 2의 큰 설정과 공개 설정이 다릅니다.** 공개 코드의 다과제 설정은 27,500 시연·말단장치 제어이고 표 2(2,500 시연, 관절 제어, 30,000 스텝)의 설정은 저장소에 없습니다(`04` D12).
