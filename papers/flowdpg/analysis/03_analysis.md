## 3. 유도와 토이 (K1–K4)

설정: 행동 2차원, 상태 1차원 s ∈ [−1, 1], 데모 x1 ~ N(0, 0.3² I), 해석적 크리틱 Q(s, a) = −‖a − c(s)‖², c(s) = (0.5, 0.5 sin 3s)(데모 중심에서 약 2σ 떨어짐), 정책은 128–128 MLP, 추론 오일러 12단계, 하이퍼파라미터는 v1 부록 값(α = 0.5, λ_max = 0.5, µ = 1, ε = 1e-6). BC 1,000스텝 후 1,200스텝 미세조정, 3 시드. **크리틱을 해석식으로 둔 것은 정책 추출 규칙만 보려는 의도이며, 학습된 크리틱의 오류는 모형에 없습니다.**

### 3.1 K1: 식 (8)–(9)가 속도를 얼마나 옮기는가

â = x_t + (1−t)v̄(v̄는 분리된 v)이고 x_t = x0 + t·u_t이므로 u\* = â + Δ − x0 = t·u_t + (1−t)v̄ + Δ입니다. 증류 항의 기울기는 2λ(v − u\*), 정상점에서 v = v̄이면

(v − u_t)·[λt + (1−λ) + µ(1−t)²] = λΔ

이고 정상점의 속도 이동은 **s(t) = λΔ / (λt + 1 − λ + µ(1−t)²)** 입니다(L_cons가 (1−t)²‖v − u_t‖²와 동치인 식 9 아래 논문의 항등식 사용). λ = 0.5, µ = 1이면 s(0) = Δ/3, s(0.5) = Δ/2, 최대 s(0.75) = 0.533Δ, s(1) = Δ/2입니다. 점 5개(t = 0.05–0.95)에서 목표를 매번 갱신하는 고정점 반복으로 구한 수치 해가 이 식과 소수 다섯째 자리까지 같습니다(`own_shift_phi.png` 왼쪽).

읽을 점:
- **Δ가 속도장에 그대로 들어가지 않습니다.** 정상점의 이동은 Δ의 33–53%이고, ‖Δ‖ = α‖u_t‖ = 0.5‖u_t‖이므로 속도 이동은 ‖u_t‖의 약 17–27%입니다.
- **BC 앵커가 1/t 발산을 막습니다.** BC 항과 L_cons가 없으면(λ = 1, µ = 0) s(t) = Δ/t로 t → 0에서 발산합니다. (1−λ) 항이 하한입니다.
- **이동 크기는 크리틱 기울기의 크기와 무관합니다.** 식 6이 ĝ = g/(‖g‖ + ε)만 쓰므로 ‖g‖가 아주 작아도 ε = 1e-6보다 크면 같은 크기로 밀립니다. 기울기가 거의 평평한(정보가 없는) 상태도 단위 방향 하나로 같은 힘을 받습니다. 이 방향이 잡음이면 K4처럼 평균 이동이 줄어듭니다.

### 3.2 K2: 근사 (i), Φ(1,t) → I

BC로 학습한 토이 망에서 t ∈ {0, 0.25, 0.5, 0.75, 0.9}에서 ODE 야코비안 Φ(1,t) = ∂x1/∂x_t를 자동미분으로 구했습니다(상태 3개 × 6점 평균).

| t | ‖Φ − I‖_F/√d | 평균 특이값 |
|---|---|---|
| 0 | 0.73 | 0.27 |
| 0.25 | 0.63 | 0.37 |
| 0.5 | 0.49 | 0.51 |
| 0.75 | 0.29 | 0.72 |
| 0.9 | 0.12 | 0.88 |

토이의 데모 분포는 σ = 0.3인 가우시안이라 노이즈를 σ로 수축시키는 흐름이어서, t가 0에 가까울수록 Φ가 I에서 멀고(특이값 약 0.27) 속도의 영향이 3–4배 작게 전달됩니다. 바닐라 DPG(식 10)는 gᵀΦ(1,t)∇θv로 가중하지만 FlowDPG는 Φ ≡ I를 쓰므로, **작은 t(높은 노이즈) 구간의 가중이 바닐라 DPG보다 상대적으로 커집니다.** 이는 오류라기보다 근사 (i)의 구체적 내용입니다. 다만 "정확히 바닐라 DPG를 회복한다"가 아니라 "Φ를 항등으로 둔 DPG"이고, 다봉 분포나 고차원에서 Φ의 방향이 얼마나 바뀌는지는 이 토이로 알 수 없습니다(`own_shift_phi.png` 오른쪽).

### 3.3 K3: FlowDPG 대 ODE 역전파 DPG 대 BC

BPTT 기준선은 BC 손실 + η·(−Q(s, ODE 끝점))이며 12단계 오일러를 통해 역전파합니다.

| 방법 | 평균 Q (3 시드, ± SD) | 생성 행동의 표준편차 | c(s)까지 평균 거리 |
|---|---|---|---|
| BC | −0.501 ± 0.025 | 0.257 | 0.663 |
| **FlowDPG** | **−0.342 ± 0.005** | 0.223 | 0.543 |
| FlowDPG (L_cons 없음) | −0.314 ± 0.005 | 0.221 | 0.518 |
| ODE 역전파 η = 1 | −0.371 ± 0.016 | 0.207 | 0.569 |
| ODE 역전파 η = 3 | −0.247 ± 0.006 | 0.165 | 0.459 |

- FlowDPG는 BPTT 없이 Q를 +0.16 올렸고 η = 1과 η = 3 사이에 놓입니다. 두 η 점 사이 보간으로는 같은 Q에서 BPTT보다 분산을 더 보존하는 쪽이지만, 점이 둘뿐이라 확정하지 않습니다.
- **BPTT의 "수치 취약성"은 이 규모(2차원, 12단계, 작은 MLP)에서 나타나지 않았습니다.** 3 시드 모두 안정적으로 학습됐습니다. 논문이 말한 폭주와 소멸은 큰 DiT, 높은 차원, 학습 초기 속도장에서의 현상이라 이 토이는 그 주장을 시험하지 못합니다.
- **L_cons 제거가 Q를 더 올렸습니다**(−0.342 → −0.314, SD 0.005의 약 5배). L_cons가 (1−t)²로 가중한 BC 항이라는 식 9 아래의 항등식 그대로입니다: 제거하면 BC 가중이 줄어 크리틱 항의 상대 비중이 커집니다. 실로봇에서 L_cons를 빼면 성공률이 92 → 80%로 내려간 것(그림 5d)은 이 효과(BC 가중 감소)와 "투영 오차 감소" 효과를 구분하지 못하는 실험입니다(`04` C5). 토이에서 L_cons는 데모 근처에 정책을 묶는 방향으로 일했습니다.

### 3.4 K4: 크리틱 기울기 잡음

g에 ‖g‖의 σ_g배 크기의 방향 잡음을 더했습니다(시드 0).

| 방식 | σ_g = 0 | σ_g = 3 | 분산 (σ_g = 0 / 3) |
|---|---|---|---|
| 적응 이동 (정규화, 식 6) | −0.340 | −0.484 | 0.224 / 0.253 |
| 원시 αg | −0.131 | −0.138 | 0.009 / 0.016 |
| BC | −0.501 | | |

- 정규화한 단위 방향은 잡음이 크면 평균 밀기가 크게 약해집니다(이득 +0.16 → +0.02). 표 3에서 변화가 작은 것(Wasserstein +0.9–1.8%, 분산 −2–6%)과 ρ가 0.28–0.36인 것과 같은 방향의 증거이지만, 두 현상을 연결하는 증명은 아닙니다.
- 원시 αg는 이 토이에서 불안정하지 않았고 **Q를 더 올리되 분산이 0.009로 붕괴**했습니다(α = 0.5, g = −2(â − c)면 a\* = c로 투영됨). 논문이 말한 "손실 진동"은 토이에서 재현되지 않았고(해석적이고 유계인 크리틱이므로 당연), 정규화의 쓸모는 "크기를 고정해 목표 붕괴를 막는 것"으로 읽을 수 있습니다.

## 4. 한계와 가정

- 토이의 크리틱은 해석식이고 데이터는 가우시안이며 상태 의존성이 약합니다. 학습된 크리틱의 외삽 오류, 시각 입력, 청크 구조, 다봉 분포는 모형에 없습니다.
- BPTT 기준선의 η는 두 값뿐이고 공정한 하이퍼파라미터 탐색을 하지 않았습니다. "같은 Q에서 분산이 더 크다"는 약한 관찰입니다.
- V2의 k/n 검사는 n ≤ 75를 기본으로 하고, 표본이 더 클 가능성(기준선만 다른 집계)은 배제하지 않았습니다. 논문이 단계별 분모를 공개하면 확정됩니다.
- V3의 Fisher 검정은 케이스가 쌍이 아니라고 가정했습니다. 쌍 비교(같은 초기 배치)였다면 검정력이 달라집니다.
- 그림 5d와 6의 n = 25는 값이 4의 배수라는 사실에서 나온 추정입니다.
- 보상 척도 비교는 v1 하이퍼파라미터에 의존합니다. v2에서 값이 바뀌었다면 결론이 달라집니다.
