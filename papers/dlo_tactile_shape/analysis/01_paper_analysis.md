## 1. 문제 설정과 주장

**문제.** DLO(케이블, 와이어, 튜브)의 3D 형상 추정은 조작 계획에 필요합니다. 외부 카메라는 손과 물체의 가림, 배경 복잡성, 케이블 묶음에서 실패할 수 있습니다. F/T 기반 방법은 점접촉 가정과 고정 장착을 요구합니다(§I, 논문 저자의 서술).

**가설.** 시각 없이 촉각 이미지와 손목 자세만으로 DLO 전체 형상을 추정할 수 있다(§I). 촉각 이미지가 "경계 조건과 접촉 기울기"를 담는다고 주장합니다.

**논문의 기여 네 가지(§I).**
1. 촉각과 고유감각만으로 DLO 전체 3D 형상을 재구성하는 첫 프레임워크라고 주장합니다. 시각을 쓰지 않습니다.
2. Sparsh 촉각 기반 모델(ViT-S)을 다중 스케일 주의 융합과 교차 주의 디코더로 씁니다.
3. 이산 탄성 막대(DER) 기반 물리 가중 손실 `L_weighted`(식 8–12)를 씁니다.
4. 실험: 기준선, 센서 구성 절제, 전이 학습을 제시하고 학습된 모델과 라벨 데이터셋을 공개한다고 밝힙니다(각주 1: "will be available upon acceptance").

## 2. 방법

### 2.1 문제 정식화 (식 1)

- 두 그리퍼 G1(고정, 전역 좌표계 O의 원점)과 G2(로봇 팔 끝단)가 DLO 양 끝을 잡습니다.
- 손가락마다 DIGIT 센서 1개, 총 4개의 촉각 이미지 `I_t = {I11, I12, I21, I22}`.
- 자세 `A_t ∈ SE(3)`는 G2의 포즈로, 논문은 **로봇 순기구학(FK)으로 계산한다고 씁니다**(§II.A).
- 목표 사상 `Ψ_t : J_t × SE(3) → X_t`, `X_t = {x_1..x_n}`, `x_i ∈ R³`(식 1).

### 2.2 학습 라벨 (§II.B)

- 모션캡처(OptiTrack, 반사 마커 m = 14개)로 DLO 위 마커 위치를 측정하고, 이를 K = 16개 등간격 정점으로 B-spline 재표본화합니다. 순서는 모멘텀 기반 탐욕 정렬로 정합니다.
- 논문은 모션캡처가 "**라벨링에만 쓰이며, 배포 시에는 촉각과 고유감각만 쓴다**"고 명시합니다(§II.B).
- 데이터: 학습 `N = 196,678`개(에피소드 36개, 평균 약 5,460개), 시험 `21,853`개(독립 에피소드 4개). 시험 데이터는 "독립 에피소드"로 수집했다고 씁니다.
- 방법론 가정: 준정적(quasi-static) 평형 상태만 다룹니다.

### 2.3 모델 (§II.C, 그림 2)

1. **촉각 인코더.** 센서마다 현재 프레임과 직전 프레임을 쌓은 6채널 입력(시간 차분 단서)을 씁니다. 공유 Sparsh ViT-S(패치 16×16, DINO 자기 증류로 사전학습, 논문은 46만 장 이상이라고 씀)를 쓰고, 마지막 2개 블록과 LayerNorm만 학습합니다. 중간 층 `S = {3, 6, 9, 12}`의 출력을 학습 가능한 가중 합(식 2, 소프트맥스 가중치)으로 합칩니다. 배경 보정으로 무접촉 기준 이미지를 뺍니다.
2. **고유감각 인코더.** 7차원 자세(위치 + 쿼터니언)를 3층 MLP로 `K`개 제어점 질의 토큰으로 바꿉니다. 고정 사인파 위치 부호화를 더합니다.
3. **교차 주의 디코더.** 질의가 촉각 토큰에 주의를 두는 교차 주의 한 층(식 3)과 질의끼리 주의하는 자기 주의 한 층(식 4)을 거칩니다. 공유 MLP가 제어점 `C ∈ R^{K×3}`을 냅니다.
4. **미분 가능한 B-spline 층(식 5).** 3차 균일 B-spline, 구간 `u ∈ [-1, 1]`, 파라미터 없음. 제어점 수 K를 출력 해상도 n과 분리합니다.

### 2.4 손실 (식 6–13)

- `L = λ_w L_weighted + λ_c L_chamfer`, `λ_w = 1.0`, `λ_c = 0.25`(식 6).
- `L_weighted = w_n L_pos + w_e L_tan + w_ℓ L_len + w_κ L_curv` (식 8). 값은 `w_n = 1.0`, `w_e = 0.05`, `w_ℓ = 0.5`, `w_κ = 0.01`(§III.C).
  - `L_pos`: 정점 위치 MSE(식 9).
  - `L_tan`: 단위 접선 벡터 MSE(식 10).
  - `L_len`: 모서리 길이 MSE(식 11).
  - `L_curv`: 이산 곡률 이항 벡터(식 7, `κ_i = 2 e_{i-1}×e_i / (ℓ_{i-1}ℓ_i + e_{i-1}·e_i)`)의 MSE(식 12).
- `L_chamfer`: 대칭 Chamfer 거리(식 13). 순서 불변 신호로 쓰입니다.
- 논문의 설명: 접선, 길이, 곡률 항이 "비신장성(inextensibility)"과 "굽힘의 물리적 타당성"을 강제한다고 씁니다(§II.D). 이 표현은 `03` C15에서 따로 검토합니다.

### 2.5 학습 설정 (§III.C)

- AdamW(β = 0.9, 0.999), OneCycleLR(warmup 10%), 기본 학습률 `1e-4`, 가중치 감쇠 `1e-4`, 배치 32, 10 에폭.
- 논문 본문의 백본 학습률은 "기본 학습률의 ×0.05(§II.C)"이지만 같은 논문의 §III.C에는 "`1e-5`"로 적혀 있습니다. 두 값은 맞지 않습니다(`03` K3).
- 학습 장비: RTX 5090, 혼합 정밀도.

### 3.3 데이터 요구량과 전이 (§III.E, §III.F, 그림 4·5)

- 그림 4: 학습 데이터 양에 따른 오차 곡선. 본문은 "에피소드 수"라고 쓰지만, 그림의 축 라벨과 캡션은 "샘플 수 (×10³)"입니다(`03` K5).
- 본문 주장: 에피소드 5개 뒤 RMSE 35%, Chamfer 28% 감소, 에피소드 15개(전체의 약 42%)면 충분.
- 그림 5: 새 DLO 두 종류(USB 4.5 mm × 550 mm, 강철 2 mm × 750 mm)에 대한 미세 조정. 각 5만 샘플 학습, 1.4만 샘플 시험. 미세 조정 학습률은 원래보다 10배 작습니다. 처음부터 학습한 모델보다 낫다고 씁니다.
- 길이 변화(무재학습): 유효 길이 500 mm 36 mm, 580 mm 40 mm.

### 3.4 노이즈와 추론 속도 (§III.F, 그림 6, 표 I)

- 촉각 이미지에 가우시안 잡음 `α ∈ [0, 1]`을 더한 실험. 본문은 "적당히 악화"라고만 씁니다. 수치 표는 없습니다.
- 추론 지연 61.5 ms(16 Hz), 저자 주장: 기존 DLO 상태 추정 파이프라인(10–15 Hz)과 비슷하거나 낫고, 제어 주파수(5–15 Hz)보다 빠릅니다.

### 3.5 논문이 말하는 한계 (§IV, 결론 직전 단락)

- 급격한 센서 고장, 근접 좌굴, 빠른 미끄러짐 같은 분포 밖 상태에서 성능이 떨어집니다.
- 향후 과제: 고충실도 시뮬레이션으로 데이터 생성, 센서 고장 대비 확률적 드롭아웃 학습, 강성과 마찰 변화, 케이블 길이를 입력으로 넣기.
- 길이 일반화가 약하다고 인정합니다(500, 580 mm 전이 오차 증가).

## 4. 논문 안에서 빠진 것과 보이는 간격

1. **단일 케이블, 단일 센서 조합.** 주 데이터는 1.5 mm 강철 편조 와이어 하나입니다. 전이 실험도 같은 계열의 두 케이블입니다. 다양한 굵기, 재질, 꼬임은 없습니다.
2. **그리퍼 방향 범위.** 데이터 절은 "그립 방향 범위 [−45°, 45°]가 물리적 한계"라고 씁니다. 그러나 저장소의 세션 이름에는 `deg115`, `deg135`처럼 더 큰 각도가 있습니다. 이 둘이 같은 뜻인지 논문만으로는 알 수 없습니다(`03` K9, `04` D18).
3. **시험 표본과 독립성.** 시험은 에피소드 4개입니다. 표준편차는 프레임 단위이며, 에피소드 사이 변동은 보고되지 않았습니다. 프레임은 같은 에피소드 안에서 서로 강하게 상관됩니다.
4. **추론 파이프라인.** 실시간 배포 코드와 FK 기반 자세 입력은 논문에도 저장소에도 설명이 없습니다(`04` D1–D3).
5. **통계 검정 없음.** 논문은 p값이나 구간을 보고하지 않습니다.
6. **오차 지표 정의.** "RMSE"의 식이 없고, 정점 대응 방식(정렬 후 재표본)이 평가에도 영향을 줍니다.

## 5. 한눈에 본 주장의 강도

- 강한 지지: 자세만 쓴 모델보다 촉각을 쓴 모델이 훨씬 낫다(표 I). 길이 변화에서 성능이 떨어진다(한계로 인정).
- 방향은 맞지만 증거가 얇음: 물리 손실과 B-spline 층의 기여(표 I). 단일 학습 seed와 에피소드 4개 기준으로는 기여가 확정되지 않습니다.
- 증거가 본문에 없음: 데이터 요구량 15 에피소드, 노이즈 강건성, 전이 학습의 정량 우위(그림만 있음).
- 충돌하는 서술: "모션캡처는 라벨링 전용"과 저장소의 입력 구성(`04` D1), "캘리브레이션 불필요"와 고정 좌표계 의존(`03` C13).

세부 판정은 `03_analysis.md`(재계산, 일관성, 주장 C1–C18), 코드 대조는 `04_code_verification.md`(D1–D18)에 있습니다.
