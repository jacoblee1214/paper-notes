# 01. 논문 분석: StressDream (arXiv:2606.00267 v2)

*StressDream: Steering Video World Models for Robust Policy Evaluation and Improvement* (Junwon Seo, Sushant Veer, Ran Tian, Wenhao Ding, Apoorva Sharma, Karen Leung, Edward Schmerling, Marco Pavone, Andrea Bajcsy; Carnegie Mellon University, NVIDIA Research, University of Washington, Stanford University). CoRL 2026 포스터. 분석 대상은 **arXiv v2 (2026-10-06, 44쪽)**입니다. v1(2026-05-29, 43쪽)과의 차이는 §6에 있습니다. 쪽·절·표·그림 번호는 v2 기준이고, 표시한 값 중 "그림 판독 값"은 그림을 렌더링해 읽은 값(오차 약 ±1 %p)입니다.

## 1. 한 문단 요약

행동 조건부 영상 세계모델(WM)은 같은 행동에 대해 여러 미래를 만들 수 있지만, 정책 평가와 개선에서는 보통 한두 개의 "평균적인" 상상만 씁니다. 저자들은 확산 모델의 **초기 잡음을 기울기 상승으로 최적화**해 "우유가 쏟아진다", "충돌한다" 같은 **추론 시점에 글로 지정한 사건** 쪽으로 상상을 조종합니다(식 5). 잡음 공간이 크기 때문에(드라이빙 921,600차원, 조작 57,600차원) 두 가지를 더합니다. 하나는 **VLM의 yes/no 로그 확률 차이**를 미분 가능한 보상으로 쓰는 의미 목적(식 6)이고, 다른 하나는 잡음이 가우시안의 타이피컬 셋을 벗어나지 않게 하는 세 항(노름 집중, 블록 등방성, 스펙트럼 백색성; 4.2절)입니다. 반복 확산 전체를 역전파하는 대신 **생성 결과에 대한 기울기를 잡음 기울기의 배수로 근사**합니다(식 7, 부록 B.4). 결과로 Ctrl-World에서 실패 회수율 54%(공칭) → 94%(조종)가 나오고, 이 조종으로 시연에 0.1/1.0 가중을 주어 미세조정한 π0.5의 성공률이 39%에서 71%로 오릅니다(그림 5, 8). 단, 평가는 6개 과제의 한 연구실 데이터이고, "그럴듯함"은 **WM 분포가 지지하는 범위**로 정의됩니다(5절 한계).

## 3. 방법

### 3.1 설정과 목적식

- **WM** o ~ f_θ(·| o_hist, a) (식 1). 관측은 카메라 영상과 고유감각. 확산 WM은 확률 흐름 ODE로 결정적이라 **초기 잡음 ε 이 결과를 정함**(식 2, 3; 부록 A.2).
- **강건 평가·개선 이중 문제** a* = argmin_a max_ε C_test(f_θ(ε, o_hist, a)) (식 4). 안쪽 최대화가 이 논문의 대상(잡음 조종)이고, 바깥 최소화는 샘플링 기반 선택(§6.1은 행동 후보 평가) 또는 정책 학습(§6.2는 가중 회귀)입니다.
- **잡음 기울기 상승** ε_{i+1} = ε_i + η ∇_ε C_test(o_i) (식 5).
- **C_test = C_sem + C_pla** (§4).

### 3.2 의미 목적 (4.1절, 부록 B.3)

Qwen-VL에 "영상이 문장 ℓ과 맞는가"를 묻고 한 토큰(yes/no)의 로그 확률 차이를 쓴다: C_sem(o; ℓ) = log p(yes| o, ℓ) − log p(no| o, ℓ) (식 6).

| 영역 | VLM | 비고 |
|---|---|---|
| 드라이빙 (Vista) | Qwen2.5-VL-7B(Wolf로 미세조정, [51]) + X-CLIP [52] | CLIP류는 양성/음성 문장의 코사인 유사도 차를 씀 (B.3). 일반 Qwen은 주행 장면과 시간 구조에 약하다고 서술 |
| 조작 (Ctrl-World) | Qwen3-VL-4B-Instruct | 세 카메라 영상을 함께 입력. 한 시점만 쓰면 "상당히 나쁨"(B.3) |

### 3.3 그럴듯함 목적 (4.2절, A.5, B.1–B.2)

C_pla = λ1 C_norm + λ2 C_iso + λ3 C_spec.

- **노름 집중** C_norm = −(‖ε‖ − √D)². R = ‖ε‖ 은 chi 분포이고 표준편차는 D 와 무관하게 1/√2 로 수렴(보조정리 1, 따름정리 1–2).
- **블록 등방성** ε 의 좌표를 무작위로 섞어 크기 k 인 m = D/k 개 부분벡터로 나누고 경험 이차 모멘트 Σ̂ 와 I_k 의 Frobenius 거리를 k 로 나눈다: C_iso = −(1/k)‖Σ̂ − I_k‖²_F (여러 순열 평균). 보조정리 2는 E|C_iso| = (k+1)/m 이고 m ≳ log(2k²/δ) 일 때 고확률 상계를 준다.
- **스펙트럼 백색성** 슬라이스별 2D 단위 DFT의 파워를 B 개 공간 주파수 구간으로 평균해 그 분산을 벌점으로: C_spec = −(1/B)Σ(p̂_b − p̄)². 보조정리 3은 구간 크기가 클 때 작다고 보인다. B 값은 본문·부록에 없다.

### 3.4 근사 기울기 (4.3절, 부록 B.4)

∇_ε C(f_θ(ε)) ≈ β ∇_o C(o), o = f_θ(ε) (식 7). 근거는 Ahn et al. [45]의 관찰입니다. 디노이저 야코비안이 대각에 가깝고 시간 의존 스칼라 ρ_τ 배라고 두면 샘플러 야코비안의 곱이 스칼라 β·I 가 됩니다(B.4). 따라서 **VLM 쪽 역전파만 하면 되고** 반복 확산 전체의 계산 그래프를 저장하지 않습니다. 합친 기울기는 식 (8): β∇_o C_sem + ∇_ε C_pla.

### 3.5 알고리즘 1 (부록 B.5)

1. ε0 ~ N(0, I). 2. 각 반복에서 o_i = f_θ(ε_i), C_i 계산. 3. g_vlm = β∇_o C, g_reg = ∇_ε C_pla, g_total = g_vlm + g_reg. 4. **성분별 클램프 ±0.3**, 이어서 **노름 클립 1.0**. 5. ε_{i+1} = ε_i + η g_total. 6. **|‖ε_{i+1}‖ − √D| > 3.0 이면 ε 을 √D·ε/‖ε‖ 로 되돌림**. 7. 가장 높은 C_i 의 생성 o* 를 반환. 모멘텀은 쓰지 않는다("누적 업데이트가 타이피컬 셋 밖으로 밀 수 있다").

## 4. 실험과 수치

### 4.1 Naughty Dubins Car (§5, 부록 C)

- **설정.** 이미지 기반 3D Dubins 차, 각속도 행동 ±1.25 rad/s, 속도 1 m/s, Δt = 0.05 s. 각 시각 p = 0.2 로 제어 부호가 뒤집힌다(식 9). 반지름 0.25 m 원이 실패 집합, 안전 점수 C(s) = p_x² + p_y² − 0.25². WM은 SVD풍 잠재 확산(D = 1,024, 5단계 오일러), 학습 궤적 4,000개.
- **평가.** 초기 상태·행동열 5,000개에 정답 라벨(10,000회 몬테카를로 중 하나라도 실패 집합에 들어가면 양성). WM을 열린 고리로 굴려 안전 점수 최솟값이 0 미만이면 양성 판정.
- **그림 2(a) (그림 판독 값, TPR / TNR).** Nominal 0.64 / 0.975, Best-of-N(N=10) 0.765 / 0.96, StressDream 0.89 / 0.925, Classifier Guidance 0.685 / 0.84, StressDream w/o C_pla 0.905 / 0.735 (`03` V4).
- **부록 C.2 낙관 조종(그림 16).** 최대 안전 점수 정답 0.55. Nominal 0.49, Best-of-N 0.50, CG 0.63, 잡음 최적화(규제 없음) 1.66, 규제 있음 0.53.
- **부록 C.3 표 4.** 노름 집중(최소 χ² 로그확률 ↑) / 등방성 ↓ / 스펙트럼 ↓ / OOD 점수 ↓: Nominal −7.6 / 0.02 / 0.03 / 167.1, Best-of-N −7.6 / 0.02 / 0.03 / 167.4, CG −7.6 / 0.02 / 0.03 / 194.5, StressDream −6.3 / 0.02 / 0.00 / 171.7, 규제 전부 제거 −717.6 / 0.83 / 0.36 / 696.6, C_norm 제거 −31.7 / 0.08 / 0.06 / 206.1, C_iso 제거 −5.6 / 0.03 / 0.11 / 187.3, C_spec 제거 −6.3 / 0.00 / 0.11 / 172.2.

### 4.2 드라이빙 (Vista, §6, 부록 D.3–E.3)

- **WM.** Vista(25프레임, 576 x 1024, 8차원 행동 = 웨이포인트 4개), PAI-AV·nuScenes·Nexar 충돌 데이터로 13,750 반복, 배치 256 미세조정(D.1).
- **평가 세트.** PAI-AV 100쌍(8개 안전 위험 범주, 사람이 사건 시각 라벨, 사건 2.5초 전 프레임을 초기 관측으로 사용)과 Nexar 충돌 200개(D.3).
- **지표.** 최적화에 쓰이지 않은 WorldModelBench(지시 따르기 0–3, 물리 법칙 0–5, 상식 0–2)와 Gemini-3.0 판정(0–10) (D.4). 그림 4는 단계 10, 20에서 StressDream 이 w/o C_pla 와 Best-of-N 보다 목표 정렬이 높고(축 1.8–2.6), 영상 품질은 C_pla 가 있을 때 더 높다(축 4.8–5.0). 수치 표는 없고 곡선만 있다.
- **충돌 대 기본 모델(그림 6, 24).** 충돌 미세조정 모델에서는 조종이 목표 정렬 약 2.2–2.4 까지 오르고(Best-of-N 약 1.8–1.9), 기본 Vista 는 약 1.2–1.4 에 머문다(그림 판독 값).
- **희귀 사건(그림 23).** 5개 예, Gemini 정렬 점수. StressDream 20단계가 Best-of-N 40개보다 높다.

### 4.3 조작 (Ctrl-World, §6.1, 부록 D.1–E.1)

- **WM.** Ctrl-World(DROID 설정, 3 카메라 192 x 320, 5프레임, 관절 위치 행동), 6과제, 표 7의 텔레오퍼레이션 궤적(성공·실패 포함)으로 10,000 반복, 배치 64, 학습률 1e-6.
- **과제.** Block Stack, Knife Put, Stacked Utensil Pick, Coffee Bean Pour, Open Coffee Bag, Open Candy Bag (D.2). 과제마다 VLM 프롬프트(예: "Is the coffee bean spilled?").
- **평가.** 실패 궤적 100개(과제 분포는 미기재). 초기 이미지와 행동열로 WM 상상을 만들고 **사람이 성공·실패로 라벨**한다(D.4). 추가로 Robometer 점수(그림 21).
- **그림 5.** Recall Rate 54%(Nominal, N=1), 71%(Best-of-N, N=10), 94%(StressDream).
- **그림 22 (그림 판독 값).** 과제별 회수율(Nominal / Best-of-N / StressDream): Block 45 / 59 / 95, Utensil 61 / 66 / 94, Knife 79 / 93 / 100, Coffee Bean 79 / 100 / 100, Coffee Bag 41 / 70 / 100, Candy 29 / 50 / 71. 오른쪽 패널(정답이 실패 아닌 궤적 중 WM이 실패를 상상한 비율, StressDream): Block 16, Utensil 33, Knife 49, Coffee Bean 46, Coffee Bag 13, Candy 1. 저자는 이를 "엄밀한 거짓 양성 비율로 해석하면 안 된다"고 적는다(E.1).

### 4.4 정책 개선 (π0.5-DROID, §6.2, 부록 D.5, E.4)

- **설정.** 과제당 성공 시연 40개로 π0.5-DROID 를 **가중 흐름 매칭 손실**로 10k 스텝(H100 한 장) 미세조정. **Nominal**: 모든 궤적 가중 1.0. **Robust**: 시연의 행동열을 WM에서 실패 쪽으로 조종해 상상한 뒤 **성공으로 남으면 1.0, 실패로 가면 0.1**. 가중은 손실과 데이터 샘플링 모두에 적용. 관절 위치 행동으로 미세조정(기본 정책은 관절 속도로 학습, 컨트롤러 제약).
- **결과.** 그림 8: 39% → 71%(과제당 20회, 6과제). 그림 26(그림 판독 값, Nominal / Robust): Block 30 / 52, Utensil 66 / 88, Knife 46 / 81, Coffee Bean 15 / 60, Coffee Bag 30 / 74, Candy 50 / 74. 6과제 모두 Robust 가 높다.

## 5. 한계

**논문이 적은 것(부록 F, §7).** 프롬프트 품질 의존, 보상 해킹 가능성, 그럴듯함이 WM 분포에 한정(현실 물리의 그럴듯함 아님), WM 분포 밖 사건은 상상 불가, 최적화가 국소 정제일 뿐 전역 탐색이 아님(초기·최적 잡음 거리는 √(2D)보다 훨씬 작다고만 서술, 수치 없음), 자기회귀 롤아웃은 순차 최적화, 한 번 상상에 수 분.

**이 분석에서 추가로 본 것.**

1. **평가 지표의 균형.** 본문은 회수율만 보여 주고(그림 5), 정답이 실패 아닌 궤적에서의 실패 상상 비율은 부록 그림 22 오른쪽에 있다. 그림 판독 값으로 StressDream 은 4개 과제에서 16–49%, 과제 평균 26%로 Nominal 4%, Best-of-N 9% 보다 높다. 이 수치가 "위험하지만 우연히 성공한 시연"을 올바르게 잡은 것인지 틀린 경보인지는 구분할 수 없다(`03` V3).
2. **기준선 구성.** 정책 개선(그림 8)의 비교는 균일 가중 하나다. 같은 수의 시연을 무작위로 0.1 로 내리거나, 공칭 WM 상상으로 가중하는 대조가 없어 개선 중 조종 자체의 몫을 가를 수 없다(`03` C9).
3. **평가 세트와 WM 미세조정 데이터의 관계.** 100개 실패 궤적이 표 7의 WM 미세조정 궤적과 겹치는지 적혀 있지 않다(`03` K3).
4. **타이피컬 통계의 감도.** 노름·등방성·스펙트럼은 전역 통계라, 보상 방향 한 축으로의 이동은 이동량이 작으면 거의 보이지 않는다(`03` V9, §5).
5. **공개 코드가 보여 주는 설정 차이**는 `04` 에 정리했다.
