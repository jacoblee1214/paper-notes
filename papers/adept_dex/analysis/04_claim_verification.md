## 1. 주장 목록과 판정

| C7 | 처음부터 학습 대비 ADEPT가 가속한다 (3B 대 9B, §4.1, 그림 3) | **근거보다 강한 서술** | 처음부터 학습은 9B에서 ADR 6/50(10 시드 중 6개는 ADR 0, `03` V12). 비교 조건이 다름: ADEPT는 ADR 20에서 시작, 사전학습만 PBT, 처음부터 학습은 사전학습이 거친 접촉 게이트·들기 보상 없이 하류 보상(부록 A.2)만 사용. 사전학습 비용 8B는 구성원 하나 기준이고 누적 108B(Kuka)–432B(Flexiv)(`03` K1) |
| C8 | 사전학습 비용이 모든 하류 과제에 걸쳐 상각된다 (§4.1) | **미검증** | 하류 과제는 FMB 펙 둘과 접시. 과제 수 N이 작으면 본전이 아님. 손익분기 N은 누적 비용 기준 18–72(S = 9B 가정). 처음부터 학습의 ADR 50 도달 비용 S가 측정되지 않음(`03` K1) |
| C9 | 사전학습이 자연스러운 파지를 창발시킨다 (§4.1, 그림 12, 부록 J) | **미검증(질적)** | 시드별 정량(파지 유형 비율, 접촉 수, 안정성)이 없고 그림 12의 대표 장면만 있음 |
| C10 | 사후학습이 새 행동을 발견한다(접시 놓기, 뒤집어 다시 잡기) (§4.1) | **부분 지지** | 접시 영샷 파지 불가는 질적 서술. 사후학습 성공률(시뮬)과 처음부터 학습 기준선이 접시에는 없어 "새 행동 발견"과 "아무 RL이나 풀 수 있는 과제"를 구분할 수 없음. 실로봇 6/10(Wilson 31–83%) |
| C11 | 학생이 영샷 sim-to-real로 실로봇에서 동작한다 (표 4) | **지지됨(방향), 불확실(크기)** | 5개 조건 모두 10회 중 최소 3회 성공(전체 50회 중 25회 = 50%, Wilson 37–63%). 조건당 구간이 ±25 %p 이상(`03` V1). 학습 시드 변동 없음 |
| C12 | 촉각이 실로봇 성공을 3/10 → 8/10으로 올린다 (§4.2) | **부분 지지** | 삽입 p = 0.070(`03` V2). 들기(p = 0.033)·재방향(p = 0.020)은 사후 선택 단계라 보정하면 유의하지 않음. Flexiv 안의 비교로만 읽을 수 있음. v1의 "decisive"는 v2에서 "improves"로 약해짐 |
| C13 | 관절 공간 패브릭이 전체 자유도와 안전을 함께 준다 (§3.5, 부록 B) | **미검증** | 패브릭 제거 절제 없음(관절 PD 직접 대 패브릭 대 PCA 부분공간). 충돌·관절 한계 위반 통계 없음. 기여 2번의 "동시에 하드웨어 안전"은 정량 근거가 없음 |
| C14 | 2단계 증류가 단일 단계보다 낫다 (0/10 대 ?, 약 10%) (§4.2) | **미검증** | 단일 단계 기준선 0/10 결과가 표 4에 없고, "약 10%"는 어느 곡선인지 그림이 없음 |
| C15 | 사람 수준 속도: 5–10 s, FMB 대비 2×–14× (§4.2, 기여 4) | **근거보다 강한 서술** | 극단값끼리 짝지은 비율(같은 쪽끼리 4×–7×). 시행당 시간 측정 표 없음. FMB 20–70 s는 다른 시스템의 인간 시연 파이프라인. 사람의 수행 시간 측정 없음(`03` V10) |
| C16 | 실로봇 거동이 시뮬레이션과 가깝다 (§5) | **불충분** | 비교 가능한 두 점(Kuka 사각-원, 별)에서 방향은 실 < 시뮬, p = 0.35, 0.33으로 구별 안 됨. Flexiv·접시는 시뮬 학생 수치 없음(`03` V3) |

추가로 논문이 사실로 서술하지만 이 분석에서 확인한 것: **표 6–7의 관측 차원 12개 합 모두 일치(C17)**, **부록 C 식 29–30 산술 일치(C18)**, **표 5 비율 일치, 단 미니배치 24,576은 4096 × 16과 맞지 않음(C19)**.

기타 미검증 주장: "object point clouds ... better zero-shot generalization"(§3.2, 근거 인용·절제 없음), "first demonstration of pick-reorient-insert ... from raw perception"(v2에서 "To our knowledge" 추가, 부재 증명이므로 확인 불가), "demonstrations ... not easily possible with human demonstrations"(§1, 근거 없음).

## 2. 코드 없이 검증한 것과 못 한 것

- **했음:** 표 1–7과 부록 C의 수치 재계산, 정수 가능성, 표↔본문 문장 대조, v1↔v2 대조, 쌍별 검정과 Wilson 구간, 훈련 곡선 눈 판독, 프로젝트 페이지 문구 대조.
- **못 했음:** 보상·ADR 스케줄·패브릭 파라미터·학습률 스케줄의 실제 구현, 시뮬 평가 프로토콜(어떤 시드·펙), 실로봇 시행 로그. 코드와 데이터가 없습니다.
- 코드가 공개되면 `04_code_verification.md`로 전환해 부록 A.3(하이퍼파라미터), 부록 B(패브릭 파라미터), 식 31(BC 손실), 학습률 감쇠(최종 학습률), ADR 규칙을 대조할 항목으로 삼을 수 있습니다.

## 4. 구현할 수 있는지 (이 맥 기준)

### 4.1 이 맥(Apple M4 Pro, 약 24 GiB 통합 메모리, MPS, CUDA 없음)에서 가능한 것

- **재계산과 검정:** 이미 끝냈습니다(`analysis/recompute.py`, 수 초).
- **사후학습 레시피의 축소 재현(조건부 가능, 승인 후):** 소형 연속 제어 문제(직접 짠 PyTorch 환경, 또는 mujoco 4.0의 작은 팔-손 모델)에서 PPO로 "reposing 유사" 과제를 사전학습하고, 관측·보상을 바꾼 하류 과제에서 단순 파인튜닝, BC 증류, 비평가 워밍업, 학습률·클립 변경의 붕괴와 안정화를 비교합니다. torch 2.15와 mujoco 4.0이 이미 설치되어 있습니다. 결과는 논문 수치와 비교할 수 없습니다.
- **기하 패브릭 소형 구현:** NumPy로 관절 한계, 구 충돌, 속도 제어가 있는 소형 관절 공간 2차 시스템(부록 B의 식 4–28)을 구현해 정책 인터페이스(상대 델타 → 목표)를 확인할 수 있습니다. 공식 구현(NVlabs/FABRICS)은 NVIDIA 라이선스(NVIDIA 프로세서 한정)이므로 정적으로만 읽습니다.
- **증류와 촉각 인코더의 구조 시험:** 작은 이미지 입력으로 DAgger 증류와 FiLM 앵커링 구조를 MPS에서 시험할 수 있습니다(논문 규모의 렌더링 없음).

### 4.2 GPU·로봇·데이터가 필요해 못 하는 것

- **논문 학습 재현:** Isaac Lab과 NVIDIA GPU(L40S 4장, 사전학습은 16 노드 PBT 약 100시간)가 필요하고, 맥(MPS)에서 불가합니다.
- **실로봇:** Kuka iiwa7 + Allegro, Flexiv Rizon + Sharpa 손(촉각 5개), RealSense, Jetson AGX Orin, 1 kHz 어드미턴스 제어기. 하드웨어가 없습니다.
- **공식 코드·체크포인트:** 없음(Coming soon). 사전학습 정책, 패브릭 Cspace 확장, 환경·보상 구현이 없어 논문 그대로의 재현은 코드 공개 전에는 불가능합니다.
- **TacMap 촉각 시뮬레이션:** Sharpa 센서와 교정이 필요합니다.

### 4.3 노력 추정 (추정, 측정 전)

- 레시피 축소 재현(소형 PPO, 3요소 절제): 코드 약 300–500줄, 환경과 실험 3–5일.
- 소형 팔-손 MuJoCo 환경(손 모델 다운로드 필요, 보상 직접 설계) 포함: 2–4주.
- 패브릭 소형 구현: 1–2주(식은 부록에 있으나 파라미터 값 다수가 비공개).
- 논문 규모 재현: 코드 공개와 GPU 서버가 있어야 시작할 수 있고, 맥에서는 추정 불가.

### 4.4 한 줄 결론

**이 맥에서 논문 수치의 재현은 불가능합니다**(Isaac Lab·GPU·두 대의 팔-손 로봇·공식 코드 없음). **사후학습 레시피(BC 증류, 비평가 워밍업, 낮은 학습률)의 소형 PyTorch 축소 재현과 패브릭 소형 구현은 조건부로 가능**하고, 표 재계산과 검정은 완료했습니다.
