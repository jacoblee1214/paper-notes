# 04. 논문 ↔ 공식 코드 대조

대상: `ACERobotics-VLA/ACE-Ego-0`, 얕은 clone, 커밋 `4ee59acd25070dbc248b2ef44597ba1114693239`(2026-09-14, "Release public Common23 SFT for RoboCasa 24 and ARX"). 재현하려면 `git clone https://github.com/ACERobotics-VLA/ACE-Ego-0 repo && git -C repo checkout 4ee59acd25070dbc248b2ef44597ba1114693239`. 정적 읽기만 했고 실행, import, 설치, 가중치·데이터 다운로드는 하지 않았습니다. 코드는 MIT, 약 40 MB(대부분 로봇 메쉬)입니다.

## 1. 공개 범위

README와 `docs/open_source_sft_training.md` §1에 따르면 공개된 것은 GR1 RoboCasa 24 추론·평가, RoboCasa 24와 ARX의 경량 SFT 학습기, 사전학습 초기화·정책 체크포인트(Hugging Face)입니다. 공개하지 않는다고 적힌 것: Common23 449-혼합 사전학습 코드, 통계 계산, RoboCasa365, RoboTwin 평가, 실로봇 ARX 배포, **사람 영상 데이터 정리, dynamic chunking, 메모리 분기**(문서 §1과 §4: "human auxiliary loss ... 분기는 이식하지 않으며, 설정이 요구하면 오류를 낸다"). 따라서 논문의 두 번째 기여(신뢰도 가중 목적)와 5단계 데이터 파이프라인, 시간 정렬 청킹은 코드로 확인할 수 없습니다.

## 2. 대조표 (D1–D14)

판정: 일치 / 불일치 / 빈칸(논문에 없음) / 미공개(코드에 없음).

| ID | 항목 | 논문 | 코드 | 판정 |
|---|---|---|---|---|
| D1 | 행동 차원 | 22차원 = 팔당 위치 3 + 6D 회전 6 + 그리퍼 1 + 활동 플래그 1 (식 14–15, 표 2) | 23차원 "Common23": 팔당 위치 3 + 6D 회전 6 + 그리퍼 1 = 20, 허리 3 추가. 활동 플래그 없음. ARX는 허리 3차원을 0으로 채우고 마스크 False (`common23.py`, `configs/common_sft.yaml`) | 불일치. 허리 차원은 GR1용이고 활동 플래그는 마스크로 대체된 것으로 보임 |
| D2 | 행동 지평과 청킹 | H_d = round(f_d T*), T* = 2 s, RoboCasa 20 Hz는 40스텝 (식 3, 표 8). 위상·지평 버킷 배치 (식 4–5) | 모든 설정에서 `action_horizon: 30`, `future_action_window_size: 29`. 데이터 로더는 `frame_index + offset`으로 프레임 인덱스 청크를 만들고 `dynamic_action_chunking`이 켜지면 오류 (`data/lerobot.py`, `training/trainer.py`) | 불일치(SFT 경로) / 사전학습 쪽은 미공개. 20 Hz에서 30스텝은 1.5 s |
| D3 | 입력 이미지 | 머리·손목 카메라, 256x256 (표 7–8) | RoboCasa: `ego_view` 한 대, 224x224. ARX: 세 대(`cam_high`, 양 손목), 256x256 (`datasets.vla_data.image_size`, `docs` §5) | 불일치(RoboCasa). ARX는 논문과 비슷 |
| D4 | 고유감각 상태 | 서술 없음 | `include_state: true`, `state_injection_mode: timestep_conditioning`(RDT2 방식). 23차원 현재 상태가 행동 전문가에 들어감(`flow_matching_action_expert.py`, 공개 SFT는 이 모드를 강제) | 빈칸. 입력이 논문 그림 2의 "이미지 + 언어 + 형태 토큰"보다 많음 |
| D5 | 흐름 정합 세부 | 보간 a_s = s·a + (1−s)ε, s ~ U(0,1) (식 7). 행동 전문가 DiT 36층 | 보간식은 같고 목표 속도 = a − ε. 시간은 s = (0.999 − Beta(1.5, 1.0))/0.999에서 뽑음(평균 약 0.4). DiT는 마지막 36개 VLM 은닉 상태를 층마다 교차 주의에 넣음. 드롭아웃 0.2. 추론 Euler 4스텝 | 시간 분포·층별 교차 주의·드롭아웃은 빈칸. 구조 수치(36층, 1024, 16헤드, 4스텝)는 일치 |
| D6 | 델타 행동과 평가 정책 | 델타 행동 청크를 π0처럼 머리 카메라 좌표에서 씀(3.2절). 표 3이 어느 정책인지 미기재 | Absolute와 Delta 두 레시피·체크포인트를 공개. Delta는 청크 시작 시점의 상태를 기준으로 위치·6D 회전·허리를 뺄셈(회전도 6D 성분 뺄셈), 그리퍼는 절대값 | 빈칸(표 3 수치가 어느 쪽인지, 평균에서 두 체크포인트 값은 README에 없음) |
| D7 | 신뢰도 가중 인간 보조 손실 | 식 6–9, 20–24, 표 6 (Huber β=1, λ=0.1, ρ=1/0.001, w_step, w_data) | 공개 코드의 `ACEEgoPolicy.forward`는 `aux_loss_dict`를 빈 사전으로 반환하고 마스크된 속도 MSE 하나가 유일한 손실. Huber, 채널별 가중, 사람 샘플 경로 없음. 문서가 "human auxiliary loss ... 분기는 이식하지 않음" | 미공개 |
| D8 | 사람 대리 임베딩 | 데이터셋마다 하나 (A.4), 6개 소스 | 사전학습 체크포인트에 대리 키 10개(`human_video`, `..__ego4d_cooking`, `__ego4d_other`, `__egodex`, `__egoexo4d`, `__epic`, 그리고 `__0402`, `__0403`, `__0411_pnppotatotomicrowaveclose`, `__0413_pnpcuptodrawerclose`). SFT 초기화는 이 10개만 정확히 버리도록 허용 목록으로 강제 | 빈칸. 이름 중 네 개는 표 1의 여섯 소스에 대응하지 않으며 의미가 문서에 없음(과제 이름이 붙은 이름이 있음) |
| D9 | 형태 토큰과 URDF 인코더 | 29차원 노드 특징, 잔차 메시지 전달, body·chain 평균 풀링 후 MLP (A.2–A.3, 식 17–19), VLM에는 안 넣음 | 노드 특징 이름 29개, 잔차 메시지 레이어 2개, 은닉 256, body·chain 토큰을 게이트 융합해 행동 전문가의 시퀀스 앞에 붙임. GR1은 34노드 캐시(58관절 URDF는 IK용이라 캐시 재생성 금지). 자동 재생성 꺼짐 | 일치(층 수와 은닉 크기는 논문에 없는 빈칸 보충) |
| D10 | 학습 하이퍼파라미터 | AdamW(0.9, 0.95, 1e-8), VLM lr 2e-5, 전문가 1e-4, 코사인 최소 5e-7, 워밍업 5000, 클리핑 1.0, 반복 확산 4, 사전학습 200K, 장치당 8 x 128 GPU, 미세조정 16 GPU (표 8) | 모두 같은 값(wd 1e-8 포함). RoboCasa 레시피는 200K 스텝, 공통 기본과 ARX는 100K. 장치당 배치 16 x 8프로세스 = 128 (논문 8 x 16 = 128과 전역 배치 같음). VLM bf16, 전문가 fp32, `mixed_precision=no` | 일치(전역 배치), 스텝 수는 레시피마다 다름 |
| D11 | 평가 프로토콜 | 과제당 50회, 한 모델로 24과제, 성공률 평균 (5.2.1절) | 기본 50회, 시드 7 하나, 환경 1개, 에피소드 중 한 번이라도 성공하면 성공으로 기록, 최대 스텝 600(CLI 기본, 환경 기본 1440), 청크 전체 30스텝 실행, 정책 출력(카메라 좌표 말단 포즈)을 Mink 역기구학으로 관절 목표로 변환 | 빈칸(시드 수, 최대 스텝, IK 설정이 논문에 없음) |
| D12 | 그리퍼 대응 | 엄지-손바닥 거리로 사람 손을 그리퍼로(4.2절). GR1 손은 서술 없음 | GR1의 Fourier 손은 앞 네 손가락 관절을 (x + 1.5)/3으로 [0, 1]에 대응해 평균낸 스칼라 그리퍼로 줄이고, 추론 시 6D 손 명령으로 되돌림 | 빈칸 |
| D13 | ARX 과제 | 6과제: Pick Tea, Scoop Coffee, Category Sorting, Sweep Cubes, Stack Bowls, Pack Shoes (C.1) | ARX 레시피 4개: `heat_sandwich`, `stack_ceramic_bowls`, `pour_coffee_beans`, `scan_pencil_case_new`. 공식 검증은 `stack_ceramic_bowls`만. 문서 §1: 논문의 6과제 중 4개만 정식 레시피가 있다고 적으나 과제 이름은 대부분 다름 | 불일치(이름). 어느 레시피가 논문의 어느 과제인지 대응표 없음 |
| D14 | 라이선스·자산 | | 코드 MIT, 체크포인트·데이터 Hugging Face Apache-2.0, Qwen 가중치와 로봇·시뮬레이션 자산은 각자 조건(THIRD_PARTY_NOTICES) | 정보 |

D5 보충: 코드의 `# TODO miss self att and _process_output` 주석이 추론 경로에 남아 있습니다. 동작 확인은 하지 않았습니다.

## 3. 일치하는 것

학습 하이퍼파라미터의 대부분(D10), 모델 구조 수치(Qwen3-VL-4B + 36층 1024 DiT, 추론 4스텝), 29차원 URDF 노드 특징, body·chain 두 토큰, 흐름 정합 속도 손실의 보간과 목표(D5), RoboCasa 24과제 목록과 50회 기본값, 마스크 처리(무효 차원의 목표와 노이즈를 함께 0으로)가 논문과 같습니다. 공개 체크포인트의 입출력 계약(정규화 통계는 데이터셋별로 출고, 런타임에 계산하지 않음)은 엄격하게 검증됩니다.

## 4. 구현할 수 있는지

**판정: 이 맥(Apple M4 Pro, 약 24 GiB, MPS, CUDA 없음)에서 논문 수치의 재현은 불가능합니다. 부분적인 정적·소형 구현만 가능합니다.**

| 무엇 | 이 맥에서 | 이유 |
|---|---|---|
| 공식 RoboCasa 24 평가 (체크포인트 12.3 GB) | 불가 | 코드가 CUDA, FlashAttention 2.8.3(cu124), `torch.autocast("cuda")`, 리눅스·EGL을 가정. 추론 메모리 자체는 bf16 VLM + fp32 전문가로 24 GiB 안일 수 있으나 CUDA 경로 이식과 RoboCasa 자산 설치가 필요(승인 대상) |
| RoboCasa 24 SFT (200K 스텝, 8 GPU, 데이터 약 53 GB) | 불가 | 전역 배치 128, 4B VLM 풀 파라미터 학습 |
| 사전학습 (128 x A800, 6.0K h) | 불가 | 사람 파이프라인과 449-혼합 학습 코드 미공개, 자체 수집 데이터 미공개 |
| 사람 영상 → 의사 행동 5단계 파이프라인 | 불가(미공개) | 코드 없음. HaMeR, SAM3, VIPE는 모두 GPU 의존. 식 10–13과 필터는 numpy로 구현 가능 |
| 신뢰도 가중 보조 손실 (식 6–9, 20–24) | 가능 (소형) | 식이 완전하고 torch 몇십 줄. 작은 흐름 정합 정책(MuJoCo 도달 과제)에 넣어 w/ w/o 비교 가능 |
| 카메라 좌표 행동, 6D 회전, 델타 변환 | 가능 | numpy |
| 시간 정렬 청킹의 버킷 샘플러 | 가능 | 합성 데이터로 패딩 비율 측정 |
| 형태 토큰 인코더 (URDF 그래프) | 가능 (소형) | 공개 GR1·ARX 캐시 구조만 필요. 모델은 약 수백만 파라미터 |
| 실로봇 ARX 6과제 | 불가 | 하드웨어·데이터 |

노력 추정(측정 없음): 소형 대리 실험(신뢰도 가중과 청킹의 효과 확인)은 설계 2–3일, 구현과 실행 1–2주. 공식 파이프라인을 CUDA 기기에서 돌리면 설치와 자산 준비 1–2일, 공개 체크포인트로 평가 1–2일이며, SFT 재현은 GPU 8장 규모입니다. 논문의 사전학습은 외부에서 재현할 수 없는 범위입니다.
